La desigualdad $2^n \geq n + 1$, para todo $n \in \mathbb{N}$, es un caso particular de la desigualdad de Bernoulli $(1 + x)^n \geq 1 + nx$, válida para $x \geq -1$. ¿Para qué valor de $x$ se obtiene?

- $x = 2$
- $x = \dfrac{1}{2}$
- $x = 1$
- $x = -1$

## Explicación

El primer miembro $(1 + x)^n$ coincide con $2^n$ cuando $1 + x = 2$, es decir, para $x = 1$. El valor $x = 1$ cumple la hipótesis $x \geq -1$, por lo que se puede aplicar la **desigualdad de Bernoulli**. Con $x = 1$, el segundo miembro queda $1 + n$ y se obtiene $2^n \geq n + 1$ para todo $n \in \mathbb{N}$. Con $x = 2$ se obtiene en cambio $3^n \geq 1 + 2n$.
