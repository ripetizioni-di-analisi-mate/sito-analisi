## Exercise 1

Five hypotheses are tested with familywise error rate $0.05$. The two smallest p-values are $0.008$ and $0.013$. How many rejections does the Bonferroni procedure give?

$$
\begin{aligned}
\alpha_{\mathrm{individual}}&=\frac{\alpha}{m}=\frac{0.05}{5}=0.01,\\[6pt]
0.008&\le0.01\quad\Longrightarrow\quad\text{rejection},\\[6pt]
0.013&>0.01\quad\Longrightarrow\quad\text{failure to reject}.
\end{aligned}
$$

$$
5\cdot0.008=0.04\le0.05,
\qquad
5\cdot0.013=0.065>0.05
$$

<div class="spiegazione">

The **Bonferroni** procedure runs each test at level $\dfrac{\alpha}{m}$, where $m$ is the number of tests. This keeps the probability of at least one false rejection among the five decisions at most $0.05$ regardless of dependence between the statistics. Dividing the risk bound among five decisions gives each $0.01$.

The first p-value $0.008$ is below the cutoff and the second $0.013$ exceeds it. The second is the smallest of the remaining p-values, so the other three also exceed the cutoff. There is **only one rejection**.

The adjusted p-values give the same comparison after multiplication by five. The first becomes $0.04$, which is at most $0.05$. The second becomes $0.065$, which exceeds the cutoff.

The value $0.013$ would be significant in a single five-percent test. Here part of the error allowance goes to the other four decisions.

</div>

## Exercise 2

Four parameters are examined using two-sided tests with familywise error rate $0.04$. For the first parameter, inverting the test gives a $99\%$ confidence interval with endpoints $1.1$ and $2.9$. With all else fixed, determine the Bonferroni decision for null value $1$ and for null value $2$.

$$
\begin{aligned}
\alpha_{\mathrm{individual}}&=\frac{0.04}{4}=0.01,\\[6pt]
1-\alpha_{\mathrm{individual}}&=0.99,\\[6pt]
\theta_0=1&\notin[1.1;\ 2.9]\quad\Longrightarrow\quad\text{rejection},\\[6pt]
\theta_0=2&\in[1.1;\ 2.9]\quad\Longrightarrow\quad\text{failure to reject}.
\end{aligned}
$$

<div class="spiegazione">

Dividing familywise error rate $0.04$ among four tests gives per-test level $0.01$, or one percent. The corresponding confidence level is $1-0.01=0.99$, exactly that of the given interval.

By **duality of tests and confidence intervals**, the interval obtained by inverting the test contains precisely the null values the level-$0.01$ test does not reject. Decide by checking whether the proposed null value belongs to the interval.

The value $1$ is below the lower endpoint $1.1$, so it is outside the interval and hypothesis $\theta=1$ is **rejected**. The value $2$ lies between $1.1$ and $2.9$, so it is inside and the result is **nonrejection**.

A $95\%$ interval would be narrower and would not correspond to the Bonferroni adjustment because it matches test level $0.05$ instead of $0.01$.

</div>
