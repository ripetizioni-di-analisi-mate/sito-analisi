## Exercise 1

A normal population mean is to be estimated with known standard deviation $10\,\mathrm{g}$. Find the smallest sample size giving a two-sided $95\,\%$ margin of at most $2\,\mathrm{g}$. Use $z=1.96$.

$$
\begin{aligned}
1.96\frac{10}{\sqrt n}&\leq2,\\[6pt]
\sqrt n&\geq\frac{1.96\cdot10}{2}=9.8,\\[6pt]
n&\geq9.8^2=96.04,\\[6pt]
n_{\min}&=\lceil96.04\rceil=97,\\[6pt]
n=96:\quad \frac{19.6}{\sqrt{96}}&\approx2.0004>2,\\[6pt]
n=97:\quad \frac{19.6}{\sqrt{97}}&\approx1.9901\leq2.
\end{aligned}
$$

<div class="spiegazione">

The standard deviation is known and the population normal, so the two-sided interval has half-width $z\dfrac{\sigma}{\sqrt n}$. Require this to be at most the specified margin $E=2\,\mathrm{g}$.

The margin decreases as sample size increases because $\sqrt n$ is in the denominator. Isolate the square root by multiplying by $\sqrt n$ and dividing by $2$, giving $\sqrt n\geq9.8$.

All quantities are positive, so squaring preserves order and gives $n\geq96.04$. Sample size must be an integer, so **round up** using $n_{\min}=\left\lceil\left(\dfrac{z\sigma}{E}\right)^2\right\rceil$.

Checking $n=96$ and $n=97$ confirms the rounding. Since $96<96.04$, the margin with ninety-six units is approximately $2.0004\,\mathrm{g}$, still above $2\,\mathrm{g}$. With ninety-seven units it is approximately $1.990\,\mathrm{g}$, so the smallest admissible size is **ninety-seven**.

</div>

## Exercise 2

Plan a survey of a proportion with normal margin at most $0.05$, using $z=1.96$. Find the minimum sample size using pilot value $p_*=0.20$ and using the conservative value when no pilot data exist.

$$
\begin{aligned}
z^2&=1.96^2=3.8416,\qquad E^2=0.05^2=0.0025,\\[6pt]
p_*(1-p_*)&=0.20\cdot0.80=0.16,\\[6pt]
n_{\mathrm{pilot}}
&=\left\lceil\frac{3.8416\cdot0.16}{0.0025}\right\rceil
=\left\lceil\frac{0.614656}{0.0025}\right\rceil\\[6pt]
&=\lceil245.8624\rceil=246,\\[6pt]
\frac12\left(1-\frac12\right)&=0.25,\\[6pt]
n_{\mathrm{conservative}}
&=\left\lceil\frac{3.8416\cdot0.25}{0.0025}\right\rceil
=\left\lceil\frac{0.9604}{0.0025}\right\rceil\\[6pt]
&=\lceil384.16\rceil=385.
\end{aligned}
$$

<div class="spiegazione">

The normal margin for a proportion is $z\sqrt{\dfrac{p(1-p)}{n}}$. Requiring it to be at most $E$ and squaring gives $n\geq\dfrac{z^2p_*(1-p_*)}{E^2}$, where $p_*$ is the value chosen for planning.

With the pilot estimate, the product $p_*(1-p_*)$ equals $0.16$. Dividing numerator $3.8416\cdot0.16=0.614656$ by $0.0025$ gives $245.8624$, so $246$ units are needed.

The conservative calculation uses the maximum of $p_*(1-p_*)$ on $[0,1]$. This maximum is $0.25$ and occurs at the midpoint, as the figure shows. The quotient is $384.16$ and the conservative sample size is $385$.

The conservative size is larger because it meets the margin requirement even for the proportion with the **greatest variance**. Round up in both cases because a smaller integer would give a margin above $0.05$.

</div>
