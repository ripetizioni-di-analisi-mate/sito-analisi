## Exercise 1

Stack `s` holds $\langle 2,5,8\rangle$ from the base and queue `q` is empty. Allocation fails in the second call to `enqueue`. Determine the final state of both structures. Use the functions from the chapter.
```c
int current;
while (stack_pop(&s, &current)) {
    if (!enqueue(&q, current)) {
        (void)stack_push(&s, current);
        break;
    }
}
```

The final stack holds $\langle 2,5\rangle$ from the base. The final queue holds $\langle 8\rangle$.

<div class="spiegazione">

The first pop retrieves $8$ and the first enqueue succeeds. The stack retains $2$ and $5$. The loop then pops $5$, making one stack cell available. The allocator fails before updating the queue, so it retains its sole element $8$. Restoring the stack uses the cell just vacated and succeeds. The `break` terminates the transfer with $5$ back at the top.

To check, track where each key belongs. Key $8$ is in the queue, and $2$ and $5$ remain in the stack in their original relative order. The total count is $1+2=3$, equal to the initial count. Failure thus interrupts the transfer after one success, and no value is left outside both structures.

</div>

## Exercise 2

Linked queue `q` holds $\langle 1,3,5,7\rangle$ and stack `s`, of capacity $5$, holds $\langle 2,4,6,8\rangle$ from the base. Find the final states after the fragment, with no concurrent changes.
```c
int current;
while (s.used < CAPACITY && dequeue(&q, &current)) {
    (void)stack_push(&s, current);
}
```

The final stack holds $\langle 2,4,6,8,1\rangle$. The final queue holds $\langle 3,5,7\rangle$.

<div class="spiegazione">

At the first guard test `used` is $4$, so `dequeue` is evaluated. The queue is nonempty and returns $1$, the oldest node. The body still finds a free stack cell because removal changed only the queue. Inserting $1$ reaches occupancy $5$. At the next guard test the first operand of `&&` is false. Short-circuit evaluation therefore leaves the queue in the state after the first removal.

To check, start from the remaining stack capacity of $5-4=1$. Only one element can enter. The first element of the original queue is $1$, and its transfer leaves exactly three queue nodes. The final occupancies $5$ and $3$ add to $8$, just as the initial occupancies $4$ and $4$ do.

</div>

## Exercise 3

Linked queue `q` holds $\langle 1,2,3,4,5,6,7,8\rangle$ and stack `s`, of capacity $5$, is empty. Every allocation succeeds. Determine the content of both structures after the first loop and at the end. Use the functions from the chapter.

```c
int current;
while (dequeue(&q, &current)) {
    if (!stack_push(&s, current)) {
        (void)enqueue(&q, current);
        break;
    }
}
while (stack_pop(&s, &current)) {
    (void)enqueue(&q, current);
}
```

| Stage | Stack from the base | Queue from `front` |
|---|---|---|
| After the first loop | $\langle 1,2,3,4,5\rangle$ | $\langle 7,8,6\rangle$ |
| At the end | empty stack | $\langle 7,8,6,5,4,3,2,1\rangle$ |

<div class="spiegazione">

The first loop removes from the queue in FIFO order and pushes onto the stack. The values from $1$ to $5$ fill the five cells. At the next removal `dequeue` returns $6$, and `stack_push` finds `used` equal to capacity, so it returns `false`. The restore branch appends $6$ after the values still present, $7$ and $8$. The queue therefore becomes $\langle 7,8,6\rangle$ and `break` ends the loop.

The second loop pops from the stack in LIFO order, that is $5$, $4$, $3$, $2$, $1$, and appends each value after $\langle 7,8,6\rangle$. The loop ends when `stack_pop` finds `used` equal to zero. The order is reversed only for the five values that passed through the stack. Values $7$ and $8$ never entered the stack, and $6$ was appended after them, so the first three elements of the final queue are $7$, $8$, $6$.

The count confirms that no value was lost. The final queue has $3+5=8$ nodes, as many as at the start, and the stack is empty.

</div>
