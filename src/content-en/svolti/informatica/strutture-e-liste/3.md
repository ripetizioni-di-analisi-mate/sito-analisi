## Exercise 1

Reconstruct the keys of the list reachable from `head` at the end of the fragment. The two automatic nodes remain alive. The fragment uses `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node *head = NULL;
struct Node x = {2, head};
head = &x;
struct Node y = {3, head};
head = &y;
```

| Stage | Nodes from the head |
|---|---|
| Start | Empty list |
| After the first update | $2$ |
| After the second update | $\langle 3,2\rangle$ |

<div class="spiegazione">

The first link is initialized from the initial null value of `head`. Thus `x.next` is null and, once the head is set to `&x`, the list contains only the node with key $2$. When initializing `y`, the current head is `&x`. The new node therefore keeps a link to the existing node. Moving the head to `&y` makes the new node the first one.

To check the order, start from the final head and visit each successor. `head` designates `y`, `y.next` designates `x` and `x.next` is null. The traversal makes exactly two visits in the order $\langle 3,2\rangle$ and stops after the node inserted first.

</div>

## Exercise 2

Find the final order. The automatic nodes remain alive and the fragment uses `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node tail = {21, NULL};
struct Node first = {8, &tail};
struct Node one = {13, first.next};
first.next = &one;
struct Node two = {5, first.next};
first.next = &two;
```

The initial chain is $\langle 8,21\rangle$. The first insertion after `first` gives $\langle 8,13,21\rangle$. The second gives $\langle 8,5,13,21\rangle$.

<div class="spiegazione">

The new `one` receives the previous `first.next`, which is `&tail`, as its successor. Assigning `&one` to the link of `first` inserts it between the first and last nodes. The second insertion reads the updated link, so `two.next` receives `&one`. After setting the link of `first` to `&two`, `one` and `tail` both remain reachable.

To verify, rebuild the suffix from the end. `tail` ends the sequence with $21$. `one.next` leads to `tail` and adds $13$ in front. `two.next` leads to `one` and adds $5$ in front. `first.next` leads to `two` and adds $8$ in front. The traversal visits four distinct objects and confirms the resulting order.

</div>
