## Exercise 1

Records `a` and `b` have integer members `code` and `qty`, initialized as shown in the figure. Determine the pairs of members of the two records after the fragment.

![Record a has code 7 and quantity 4. Record b has code 9 and quantity 2.](/immagini/informatica/strutture-e-liste/dati-svolto-en.png)

```c
b = a;
a.qty += 3;
```

| Object | Final code | Final quantity |
|---|---|---|
| `a` | $7$ | $7$ |
| `b` | $7$ | $4$ |

<div class="spiegazione">

The first assignment uses the value of the whole structure `a`. Code $7$ and quantity $4$ therefore replace the two previous members of `b`. The destination of the second assignment is member `qty` of `a`. It changes the quantity from $4$ to $7$ and leaves `code` at its previous value. Structure assignment stored both values in `b`, so `b.qty` retains $4$.

To check the result, follow each member separately. The only write to `b.code` after initialization copies code $7$, and the only write to `b.qty` copies value $4$. The quantities of `a` and `b` must therefore differ by just the increment, and indeed $7-4=3$.

</div>

## Exercise 2

Find the final members of `item` and `copy`.

```c
struct Item { int code; int qty; };
struct Item item = {.code = 12};
struct Item *p = &item;
struct Item copy = item;
p->qty = 6;
copy.code = 9;
```

| Object | Final code | Final quantity |
|---|---|---|
| `item` | $12$ | $6$ |
| `copy` | $9$ | $0$ |

<div class="spiegazione">

The initializer designates `code` and omits `qty`. The omitted integer member is initialized to zero. The copy is therefore made when `item` contains the pair $(12,0)$. Pointer `p` designates `item`, so `p->qty` updates the member of the original record. Writing `copy.code` affects the other object, which retains the copied quantity.

To check, rewrite `p->qty = 6;` as `(*p).qty = 6;`. Since `p` was initialized with `&item` and then remains unchanged, the member written is `item.qty`. The only subsequent write destinations are `item.qty` and `copy.code`. This confirms that `copy.qty` retains $0$ and `item.code` retains $12$.

</div>
