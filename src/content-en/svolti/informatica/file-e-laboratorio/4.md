## Exercise 1

In the C locale, the line `" -18!\n"` is passed to `strtol(line, &end, 10)`. Find the converted value and decide whether the line is valid when only one integer and whitespace are allowed.

Conversion returns $-18$. `end` points to `!`, so the line is rejected.

<div class="spiegazione">

The conversion skips leading whitespace, recognises the sign and consumes digits up to the first non-digit character. The character `!` remains in the unparsed part. Because it is not whitespace, the final check fails even though the converted value is representable. Compare with the line `" -18\n"` as a check. In that case the end pointer refers to a newline, which the whitespace check can step over to reach the terminator.

</div>

## Exercise 2

The format requires two integers separated by at least one space or tab. Compare the lines `"7-2\n"` and `"7 -2\n"`. Determine validity and give both fields for a valid line.

`"7-2\n"` is rejected. `"7 -2\n"` yields the fields $7$ and $-2$.

<div class="spiegazione">

After the first integer, the end pointer refers to `-` in the first line. The required separator is missing, so the procedure stops before trying the second conversion. In the second line the pointer refers to the space. The next conversion can skip it and then use the minus sign. The digits end before the newline allowed by the specification. To check, split the valid line at its space. The resulting tokens are exactly the two required integers.

</div>
