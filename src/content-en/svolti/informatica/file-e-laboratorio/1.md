## Exercise 1

The file in the figure contains the lines $14$ and $19$. A program opens it in mode `"a"` and appends $6$ as a new line. All operations succeed. Find the final contents.

![Initial file with lines 14 and 19, new line 6.](/immagini/informatica/file-e-laboratorio/dati-svolto-en.png)

```text
14
19
6
```

<div class="spiegazione">

Append mode retains the existing characters. The two initial lines therefore occupy the first two positions. A newline is already present after `19`, so writing `"6\n"` begins a separate line. Closing the stream successfully completes the operation. As a check, rereading the file and dropping its final line yields exactly the original sequence, `14` followed by `19`. The number of newline delimiters increases from two to three.

</div>

## Exercise 2

A file contains the line $51$. A program opens it in mode `"w"`, writes `"-6\n"` and closes it. The operations succeed. Give the final contents and the number of characters transmitted.

The file contains only the line `-6` and its newline. The write transmits $1+1+1=3$ characters.

<div class="spiegazione">

Opening in mode `"w"` truncates the file. The subsequent write therefore starts with an empty file and transmits, in order, a minus sign, the digit six and a newline. Check the result by counting the string elements visible to the stream. The string terminator tells `fputs` where the string ends and remains in the array. After closing the file, line input finds a single line because the old data was removed when opening succeeded.

</div>
