## Exercise 1

The file in the figure contains the lines $14$ and $19$. A program opens it in mode `"a"` and appends $6$ as a new line. All operations succeed. Find the final contents.

![Initial file with lines 14 and 19, new line 6.](/immagini/informatica/file-e-laboratorio/dati-svolto-en.png)

```text
14
19
6
```

<div class="spiegazione">

Append mode retains the existing characters. The two initial lines therefore occupy the first two positions. A newline is already present after `19`, so writing `"6\n"` begins a separate line. Closing the stream successfully completes the operation. As a check, rereading the file and dropping its final line yields exactly the original sequence, `14` followed by `19`. The number of newline delimiters increases from two to three.

</div>

## Exercise 2

A file contains the line $51$. A program opens it in mode `"w"`, writes `"-6\n"` and closes it. The operations succeed. Give the final contents and the number of characters transmitted.

The file contains only the line `-6` and its newline. The write transmits $1+1+1=3$ characters.

<div class="spiegazione">

Opening in mode `"w"` truncates the file. The subsequent write therefore starts with an empty file and transmits, in order, a minus sign, the digit six and a newline. Check the result by counting the string elements visible to the stream. The string terminator tells `fputs` where the string ends and remains in the array. After closing the file, line input finds a single line because the old data was removed when opening succeeded.

</div>

## Exercise 3

The file `report.txt` contains the lines `70`, `80` and `90`. A program calls the following function twice on the name `"report.txt"`, first with the array `{12, 5, -1, 40}` and `count` equal to $4$, then with the same array and `count` equal to $0$. All opens, writes and closes succeed. Find the file contents and the return value after each call.

```c
static int write_report(const char *name, const int *values, size_t count)
{
    FILE *out = fopen(name, "w");
    if (out == NULL) {
        return 0;
    }
    int ok = 1;
    for (size_t i = 0; i < count && ok; ++i) {
        if (values[i] < 0 || fprintf(out, "%d\n", values[i]) < 0) {
            ok = 0;
        }
    }
    if (fclose(out) != 0) {
        ok = 0;
    }
    return ok;
}
```

| Call | Contents of `report.txt` | Characters in the file | Return value |
|---|---|---:|---:|
| first, `count` equal to $4$ | `12` and `5` | $5$ | $0$ |
| second, `count` equal to $0$ | no lines | $0$ | $1$ |

<div class="spiegazione">

A successful open in mode `"w"` truncates the file, so the three initial lines are removed before any write. In the first call the loop writes `"12\n"` and `"5\n"`, that is $3+2=5$ characters. At the third element the condition `values[i] < 0` is true. Because of the short-circuit evaluation of `||`, the call to `fprintf` with $-1$ is not evaluated. Since `ok` becomes zero, the guard `i < count && ok` is false and the value $40$ is never examined. The close is still executed, so the two lines already transmitted remain in the file and the function returns $0$. In the second call the guard is already false with `i` equal to zero. The open in mode `"w"` has nevertheless truncated the file, and the function returns $1$ because no operation failed. After the second call the file is therefore **empty** and the result reports success.

</div>
