## Exercise 1

A reader has validated and stored the `(time, level)` records `(2, 1)`, `(5, 3)`, `(9, 3)`, `(12, 1)` and `(15, 2)` in chronological order. Each value applies until the next record. Time is a nonnegative `long`. Write the core calculation on the array `records` of length `count` and find the duration at level $3$.

```c
long duration = 0;
for (size_t i = 1; i < count; ++i) {
    if (records[i - 1].level == 3) {
        duration += records[i].time - records[i - 1].time;
    }
}
```

The duration is $(9-5)+(12-9)=7$.

<div class="spiegazione">

Each iteration assigns the left-hand record’s level to the interval. The interval $[2,5)$ has level $1$, so it does not contribute. The intervals $[5,9)$ and $[9,12)$ both have level $3$ and add $4$ and $3$, respectively. The final completed interval has level $1$. For an independent check, merge the two adjacent stretches at level $3$ and measure the length of $[5,12)$, which is $7$. Every partial sum is at most the final time minus the first, which is representable. The code uses `size_t` from `<stddef.h>`.

</div>

## Exercise 2

The model permits nondecreasing times. Using the same interval rule, find the duration at level $3$ for records `(4, 3)`, `(4, 2)`, `(8, 3)` and `(11, 1)`. Also find the result if the only record is `(21, 3)`.

In the first case the duration is $(4-4)+(11-8)=3$. For a single record it is $0$.

<div class="spiegazione">

The two records at time $4$ bound an empty interval, so the first level $3$ lasts zero time. From $4$ to $8$ the level is $2$. The interval from $8$ to $11$ has level $3$ and contributes its full length. With a single record, the loop starts at index $1$ and the length is $1$, so the body does not run. Check directly from the definition by counting intervals between consecutive records. A single record gives no consecutive pairs and the empty sum is zero.

</div>
