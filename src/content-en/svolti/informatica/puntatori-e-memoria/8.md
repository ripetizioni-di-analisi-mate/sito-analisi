## Exercise 1

A block of five initialized integers contains $(3,12,7,20,9)$ in that order. Assume that `p` owns the block, that `<stdlib.h>` is included and that `realloc` succeeds. Find the sum of the integers in the resulting block before release.
```c
int *next = realloc(p, 3 * sizeof *p);
```

The first three integers are preserved. The resulting block contains $(3,12,7)$, so the sum is $3+12+7=22$.

<div class="spiegazione">

The request reduces the number of bytes. The guaranteed portion is the prefix of the new size, because that is the smaller of the two sizes. Use `next` to read and eventually release the resulting block. The elements at indices $3$ and $4$ belonged to the earlier block and are outside the resulting block.

To check the sum, add the five original values to obtain $51$. The final two contributed $20+9=29$. Removing that contribution gives $51-29=22$.

</div>

## Exercise 2

Implement `grow_zeroed` with two output parameters, the owning reference and the capacity. At entry, either `*slot` is `NULL` and `*capacity` is zero, or the pointer owns a block of `*capacity` initialized integers. The two output variables are modifiable and outside the block. If the capacity is sufficient, the function returns `true` without changing it. If the request is too large or fails, it returns `false` and leaves the state unchanged. On growth, it preserves the prefix and initializes the new integers to zero. Find the block after successful growth from two to five elements starting from $(4,9)$, and the value read after rebuilding a reference to the element at index $1$.

```c
#include <stdbool.h>
#include <stdint.h>
#include <stdlib.h>

bool grow_zeroed(int **slot, size_t *capacity,
                 size_t need)
{
    size_t old = *capacity;
    if (need <= old) {
        return true;
    }
    if (need > SIZE_MAX / sizeof **slot) {
        return false;
    }

    int *next = realloc(*slot, need * sizeof *next);
    if (next == NULL) {
        return false;
    }
    for (size_t i = old; i < need; ++i) {
        next[i] = 0;
    }
    *slot = next;
    *capacity = need;
    return true;
}
```

The result is $(4,9,0,0,0)$. The reference rebuilt from the updated owning address plus $1$ designates the value $9$.

<div class="spiegazione">

If growth is needed, `need` is strictly positive. The bound check ensures that the request is representable. The result is held in `next`, so a failure leaves the old reference and capacity intact. On success, the loop writes each new element once, starting at `old`. The final two assignments update the owner and the capacity of the block now available.

Check the preserved prefix and the added section separately. Indices $0$ and $1$ keep $4$ and $9$ by the guarantee of `realloc`. The three positions from $2$ through $4$ are exactly the indices written by the loop. Index $1$ was retained as an integer, so it can still be used to calculate a valid pointer from the new block.

</div>
