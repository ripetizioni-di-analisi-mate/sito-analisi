## Exercise 1

Find `*(q - 1)` and `end - p` with the following declarations. The required pointer differences are representable in `ptrdiff_t`.

```c
const int a[] = {3, 8, 1, 6, 4};
const int *p = a + 2;
const int *q = p + 2;
const int *end = a + 5;
```

The positions of `p`, `q` and `end` have indices $2$, $4$ and $5$. Thus `q - 1` has index $3$ and `*(q - 1)` is $6$. The difference `end - p` is $5-2=3$ elements.

<div class="spiegazione">

Advancing by two from `p` adds to index $2$, which has already been reached. The backward step starts at index $4$ and reaches the element at index $3$. Index $5$ is the one-past position. It is allowed as the other endpoint for counting, while the value is read at index $3$, which is within the array.

To check the distance, count the steps from `a + 2` to `a + 3`, then to `a + 4` and finally to `a + 5`. There are three steps. The fourth value in the initializer confirms the read value of $6$.

</div>

## Exercise 2

An array `a` contains eight elements of type `int`. With `end = a + 8`, compute `p = end - 3` and `q = p - 4`. Find the indices of `p` and `q`, the difference `q - p`, and the distance between their addresses in bytes on a machine where `sizeof(int)` is $4$.

The index of `p` is $8-3=5$ and the index of `q` is $5-4=1$. The signed difference is $1-5=-4$ elements. The byte distance is $4\cdot 4=16$.

<div class="spiegazione">

The array allows positions $0$ through $8$ for pointer arithmetic. Both offsets reach actual element indices. Subtracting the pointer at the higher index from the one at the lower index gives a negative difference. Here the word “distance” denotes the nonnegative length between the two positions, so take the absolute value before converting units.

As a check, calculate the offset of each element from the start of the array. Element $5$ starts $20$ bytes from the start and element $1$ starts $4$ bytes from it. The unsigned distance is therefore $20-4=16$ bytes.

</div>
