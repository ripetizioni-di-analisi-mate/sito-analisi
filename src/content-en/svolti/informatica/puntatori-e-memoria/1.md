## Exercise 1

Find the final values of $x$ and $y$. In a function body, `int x = 12;`, `int y = 5;`, `int *p = &x;` and `int *q = p;` have been executed. The statements shown then run.

![Before the statements, p and q point to x with value 12. y is a separate integer with value 5.](/immagini/informatica/puntatori-e-memoria/dati-svolto-en.png)

```c
*p += 3;
q = &y;
*q = *p - 4;
```

| After | Target of `q` | `x` | `y` |
|---|---|---:|---:|
| `*p += 3;` | `x` | 15 | 5 |
| `q = &y;` | `y` | 15 | 5 |
| `*q = *p - 4;` | `y` | 15 | 11 |

The final pair is $(15,11)$.

<div class="spiegazione">

The increment uses `p` as the destination address, so it changes `x` from $12$ to $15$. Changing the contents of `q` moves that pointer’s target to `y`. The final assignment therefore reads $15$ from `x` through `p` and writes $15-4=11$ through `q`, which now identifies `y`.

To check the result, substitute the names of the pointed-to objects into the two writes. This gives `x += 3;` and `y = x - 4;` in that order. The differences $15-12=3$ and $15-11=4$ agree with the two operations.

</div>

## Exercise 2

Find the final pair $(x,y)$ and the value of `saved`. The fragment occurs in a function body.

```c
int x = 6;
int y = 4;
int *p = &x;
int *q = &y;
int saved = *p;
int *tmp = p;
p = q;
q = tmp;
*q += *p;
```

After the addresses are copied, `p = &y` and `q = &x`. The write becomes `x += y;`, giving
$$
(x,y)=(6+4,4)=(10,4).
$$
The value of `saved` is $6$.

<div class="spiegazione">

Initializing `saved` reads the contents of `x` before the targets are exchanged and stores the value in a separate object. The variable `tmp`, on the other hand, stores an address. After `p` receives the address previously held in `q`, copying from `tmp` gives `q` the original address of `x`. The only write to the integers adds the value of `y` to `x`.

To verify the exchange, check the equalities `p == &y` and `q == &x` directly. The difference between the new `x` and the saved value is $10-6=4$, exactly the contribution of the integer designated by `p`.

</div>
