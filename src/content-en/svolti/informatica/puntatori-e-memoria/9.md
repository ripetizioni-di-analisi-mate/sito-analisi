## Exercise 1

Write the exact output of the program. Assume 32-bit `int` and successful output.

```c
#include <stdio.h>

int main(void)
{
    int a[] = {5, 1, 8, 3, 6};
    int *p = a;
    int *q = a + 4;
    while (p < q) {
        int tmp = *p;
        *p = *q;
        *q = tmp;
        p += 2;
        --q;
    }
    printf("%d", a[0]);
    for (size_t i = 1; i < 5; ++i) {
        printf(" %d", a[i]);
    }
    printf("\n%td %td\n", p - a, p - q);
    return 0;
}
```

| Iteration | Indices swapped | Array after the swap | Indices of `p` and `q` after the updates |
|---:|---|---|---|
| 1 | $0$ and $4$ | `{6, 1, 8, 3, 5}` | $2$ and $3$ |
| 2 | $2$ and $3$ | `{6, 1, 3, 8, 5}` | $4$ and $2$ |

```text
6 1 3 8 5
4 2
```

<div class="spiegazione">

The comparison `p < q` between pointers is defined because both designate elements of the same array, and it is true when the index of `p` is less than that of `q`. On each iteration `p` advances two positions and `q` moves back one. After the second swap `p` has index $4$ and `q` has index $2$, so the comparison is false and the loop ends without touching index $1$.

The indices computed for `p` are $0$, $2$ and $4$, all inside the five-element array. Advancing beyond the one-past position would have undefined behaviour, and here the largest index computed is $4$. The second line prints two pointer differences with `%td`, the format for the type `ptrdiff_t`. The difference `p - a` is $4-0=4$ and `p - q` is $4-2=2$.

</div>

## Exercise 2

Write the exact output of the program. The function `hop` moves a cursor forward by as many positions as the value of the designated element, provided that the new position does not go beyond the endpoint `end`.

```c
#include <stdio.h>

static int hop(const int **cursor, const int *end)
{
    int step = **cursor;
    if (step <= 0 || step > end - *cursor) {
        return 0;
    }
    *cursor += step;
    return 1;
}

int main(void)
{
    const int a[] = {2, 5, 3, 1, 4, 1, 1};
    const int *end = a + 7;
    const int *c = a;
    int jumps = 0;
    while (c != end && hop(&c, end)) {
        ++jumps;
        printf("%td %d\n", c - a, c != end ? *c : -1);
    }
    printf("jumps=%d\n", jumps);
    return 0;
}
```

| Index of `c` | Value read | `end - c` | New index |
|---:|---:|---:|---:|
| 0 | 2 | 7 | 2 |
| 2 | 3 | 5 | 5 |
| 5 | 1 | 2 | 6 |
| 6 | 1 | 1 | 7 |

```text
2 3
5 1
6 1
7 -1
jumps=4
```

<div class="spiegazione">

The parameter `cursor` has type `const int **` and receives the address of `c`, so `*cursor += step` updates the caller’s variable. The test `step > end - *cursor` compares the jump with the number of remaining elements. If the jump is accepted, the new position is at most `end`, that is, the one-past position, which is among the allowed positions.

The last jump starts from index $6$ with value $1$ and $7-6=1$ element remains, so the jump is accepted and `c` becomes equal to `end`. In the `printf` call the conditional operator evaluates only one of its last two operands. Since `c != end` is false, $-1$ is printed without reading `*c`, a read that would have undefined behaviour. At the next test of the `while` loop the first operand of `&&` is false, so by the **short-circuit** rule the function `hop` is not called and the loop ends after four jumps.

</div>

## Exercise 3

Write the exact output of the program. Assume 32-bit `int`, successful allocations and successful output.

```c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

static int *make_squares(size_t n)
{
    int *v;
    if (n == 0 || n > SIZE_MAX / sizeof *v) {
        return NULL;
    }
    v = malloc(n * sizeof *v);
    if (v == NULL) {
        return NULL;
    }
    for (size_t i = 0; i < n; ++i) {
        v[i] = (int)(i * i);
    }
    return v;
}

int main(void)
{
    int *v = make_squares(4);
    if (v == NULL) {
        return EXIT_FAILURE;
    }
    int *next = realloc(v, 6 * sizeof *v);
    if (next == NULL) {
        free(v);
        return EXIT_FAILURE;
    }
    v = next;
    v[4] = v[3] - v[1];
    v[5] = v[4] + v[2];
    int *mid = v + 2;
    mid[1] += *mid;
    for (size_t i = 0; i < 6; ++i) {
        printf("%d%c", v[i], i + 1 < 6 ? ' ' : '\n');
    }
    printf("%td\n", (v + 6) - mid);
    free(v);
    return 0;
}
```

$$
\begin{aligned}
(v_0,v_1,v_2,v_3) &= (0,1,4,9) \\[6pt]
v_4 &= v_3-v_1 = 9-1 = 8 \\[6pt]
v_5 &= v_4+v_2 = 8+4 = 12 \\[6pt]
v_3 &= v_3+v_2 = 9+4 = 13
\end{aligned}
$$

```text
0 1 4 13 8 12
4
```

<div class="spiegazione">

The function `make_squares` checks the size before the multiplication and returns a block of four integers initialized with the squares of the indices. The block passes to the caller through the return value, so `main` has its **ownership** and releases it at the end. Resizing to six integers preserves the first four values, while `v[4]` and `v[5]` have indeterminate contents until they are written. The next two assignments write them before any read, and their right-hand sides use only elements that are already initialized.

The pointer `mid` is computed from the resized block, so it is valid. In `mid[1] += *mid` the expression `mid[1]` designates `v[3]` and `*mid` designates `v[2]`, so `v[3]` changes from $9$ to $13$. Since `v[4]` had already been computed with the earlier value $9$, it stays equal to $8$. The second line prints `(v + 6) - mid`, the number of elements from index $2$ to the one-past position, which is $6-2=4$.

</div>
