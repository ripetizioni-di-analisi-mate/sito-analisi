## Exercise 1

For `a = {9, 1, 2, 9, 5, 9}`, find the index of the element designated by the result of `first_match(a + 1, a + 5, 9)`. The function returns the final endpoint when the key is absent.

```c
const int *first_match(const int *first, const int *last, int key)
{
    while (first != last && *first != key) {
        ++first;
    }
    return first;
}
```

The range contains indices $1$, $2$, $3$ and $4$. The reads give $1$, $2$ and $9$, in that order. The loop ends on the third read, so the returned pointer is `a + 3` and the index is $3$.

<div class="spiegazione">

At the start of each iteration, every value already passed differs from the key. The first test checks the endpoint before reading the element. When the loop reads $9$ at index $3$, comparison with the key ends the loop without advancing. The call therefore returns a pointer to the first element equal to the key in the given range.

A separate check lists all occurrences of $9$ in the full array. They are at indices $0$, $3$ and $5$. Intersecting with indices $1$–$4$ leaves only index $3$.

</div>

## Exercise 2

Find `count_at_least(a + 1, a + 4, 9)` for `a = {5, 10, 9, 6, 12}` and `count_at_least(NULL, NULL, 9)`. The contract allows the second case to represent an empty range.

```c
#include <stddef.h>

size_t count_at_least(const int *first, const int *last, int limit)
{
    size_t count = 0;
    for (const int *p = first; p != last; ++p) {
        if (*p >= limit) {
            ++count;
        }
    }
    return count;
}
```

The first call visits $10$, $9$ and $6$. The contributions to the count give $1+1+0=2$. In the second call the endpoints are equal at the first comparison, so the count stays at $0$.

<div class="spiegazione">

The position at index $4$, containing $12$, is the excluded endpoint. Among the three internal positions, values $10$ and $9$ satisfy `>=`, so equality with the threshold is included. In the null empty case, the pointer equality comparison is performed. The body and the pointer increment are skipped.

To check the results, count the excluded elements. In the first range of length $3$ there is one value strictly below $9$, leaving $3-1=2$ elements. The empty range has length $0$ and can contribute only zero.

</div>
