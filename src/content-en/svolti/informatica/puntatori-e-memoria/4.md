## Exercise 1

Find the final pair $(x,y)$ in the caller’s function body and the final target of `p`. The body shown at the bottom runs after the two functions are declared.
```c
void retarget_local(int *out, int *target)
{
    out = target;
    *out = 25;
}

void retarget_caller(int **slot, int *target)
{
    *slot = target;
}

/* Caller body */
int x = 3;
int y = 7;
int *p = &x;
retarget_local(p, &y);
*p += 2;
retarget_caller(&p, &y);
*p += 4;
```

| Step | Target of `p` | `x` | `y` |
|---|---|---:|---:|
| Return from `retarget_local` | `x` | 3 | 25 |
| First increment | `x` | 5 | 25 |
| Return from `retarget_caller` | `y` | 5 | 25 |
| Second increment | `y` | 5 | 29 |

The final pair is $(5,29)$ and `p` points to `y`.

<div class="spiegazione">

The first function receives an address in `out` and then changes that local parameter. Writing through `out` affects `y` and sets it to $25$. On return, the caller’s `p` still holds the address of `x`. The second function receives the address of the variable `p` in `slot`, so writing to `*slot` changes the value of `p` in the caller.

To check the calculation, assign each increment to the object it changes. The first affects only `x` and gives $3+2=5$. The second affects only `y` after the write of $25$ and gives $25+4=29$.

</div>

## Exercise 2

Write a function `quotient_and_remainder` that delivers an unsigned integer quotient and remainder through two output parameters. If the divisor is zero, either parameter is null, or both parameters designate the same object, it returns `false` without writing. A non-null parameter must designate a live, modifiable `unsigned`. Check the result for $29$ divided by $6$ and a subsequent call with divisor zero.

```c
#include <stdbool.h>
#include <stddef.h>

bool quotient_and_remainder(unsigned n, unsigned d,
                            unsigned *q, unsigned *r)
{
    if (d == 0 || q == NULL || r == NULL || q == r) {
        return false;
    }
    *q = n / d;
    *r = n % d;
    return true;
}
```

With distinct destinations, the first call returns `true` and writes $4$ and $5$. The call with divisor zero returns `false` and leaves both values unchanged.

<div class="spiegazione">

The check occurs before any computation or write, so the two objects keep their contents on the error path. On the valid path the division is defined because the divisor is positive, and the two writes reach distinct objects. The last condition prevents the remainder from overwriting the quotient in the same object.

The result for $29$ is verified by $6\cdot4+5=29$ and $0\leq5<6$. In a test with destinations initialized to sentinel values and equal pointers, the function must return before either assignment, so the sentinel remains.

</div>

## Exercise 3

Find the results of `locate_extremes`, which delivers through two output parameters the position of the first minimum and that of the first maximum of a half-open range. If the range is empty or an output parameter is null, the function returns `false` without writing. The caller starts from `const int a[] = {7, 2, 9, 2, 9, 4};`, `const int *lo = NULL;` and `const int *hi = NULL;`, then calls `locate_extremes(a, a + 6, &lo, &hi)` and `locate_extremes(a + 3, a + 3, &lo, &hi)`. Also find `hi - lo` and `*hi - *lo` after the first call.

```c
#include <stdbool.h>
#include <stddef.h>

bool locate_extremes(const int *first, const int *last,
                     const int **low, const int **high)
{
    if (first == last || low == NULL || high == NULL) {
        return false;
    }
    *low = first;
    *high = first;
    for (const int *p = first + 1; p != last; ++p) {
        if (*p < **low) {
            *low = p;
        }
        if (*p > **high) {
            *high = p;
        }
    }
    return true;
}
```

The first call returns `true` and writes `lo = a + 1` and `hi = a + 2`. Therefore `hi - lo` is $2-1=1$ and `*hi - *lo` is $9-2=7$. The second call returns `false` and leaves `lo` and `hi` at indices $1$ and $2$.

<div class="spiegazione">

The caller owns two variables of type `const int *` and passes their addresses, which have type `const int **`. Therefore `*low` is the caller’s variable `lo` and `**low` is the array integer it designates. The `const` qualifier applies to the integer, so the function can update the two positions and cannot write to the elements.

After the initial check the range contains at least one element, so `first + 1` is at most the one-past position and the loop starts from an allowed position. The comparisons are strict, so a value equal to the current minimum or maximum leaves the recorded position unchanged. For this reason the second $2$, at index $3$, and the second $9$, at index $4$, do not change the results. In the second call `first == last` holds, so the function returns before any write to `*low` or `*high`.

</div>
