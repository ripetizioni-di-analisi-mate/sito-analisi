## Exercise 1

An integer `score` belongs to the domain from $0$ to $30$. The specification assigns $2$ up to $7$, $4$ from $8$ to $20$, and $6$ from $21$ onwards. Build one test per class and compute the expected results using representatives $3$, $14$ and $24$.
```c
int tier(int score)
{
    if (score <= 7) {
        return 2;
    }
    if (score <= 20) {
        return 4;
    }
    return 6;
}
```

| Integers in class | Representative | Expected |
| --- | --- | --- |
| $[0,7]$ | $3$ | $2$ |
| $[8,20]$ | $14$ | $4$ |
| $[21,30]$ | $24$ | $6$ |

<div class="spiegazione">

The three bands are nonempty, disjoint and cover the integers in the domain. Each representative lies in a distinct band, giving full coverage. To compute the oracle, read the band to which the input belongs. For example, $14$ satisfies $8\leq14\leq20$, so its expected value is $4$.

As a separate check, at $14$ the first comparison in the code is false and the second is true, so execution reaches `return 4;`. At $3$ the first comparison is true, while at $24$ both are false. The three branches agree with the expected results.

</div>

## Exercise 2

The two integer inputs `x` and `y` are both between $-10$ and $10$. The specification distinguishes the negative case from the non-negative case for each input. Find the minimum number of tests that cover the combinations and compute the expected results for four chosen cases using the function.
```c
int zone(int x, int y)
{
    return 2 * (x >= 0) + (y >= 0);
}
```

| `x` | `y` | Expected |
| --- | --- | --- |
| $-2$ | $-3$ | $0$ |
| $-2$ | $3$ | $1$ |
| $2$ | $-3$ | $2$ |
| $2$ | $3$ | $3$ |

The minimum is $4$ tests.

<div class="spiegazione">

Each input has two classes and every combination is possible in the domain. There are therefore $2\cdot2=4$ classes of pairs. A pair belongs to just one class, so fewer than $4$ tests would miss a combination. The four cases shown reach the minimum. A non-negative `x` adds $2$ and a non-negative `y` adds $1$.

To check, read those indicators as two bits. The cases in the table have binary values $00$, $01$, $10$ and $11$, which correspond to the expected values from $0$ to $3$.

</div>

## Exercise 3

The function `fee` receives an integer weight from $1$ to $30$ and a flag `express` equal to $0$ or $1$. The base rate is $4$ up to weight $10$ and $7$ from $11$ to $30$. Express shipping adds $5$ to the base up to weight $20$; with `express` equal to $1$ and a weight greater than $20$ the function returns $-1$. Find the classes of the specification, the minimum number of tests and the expected results, then decide whether the four combinations of weight band and `express` are enough.
```c
int fee(int weight, int express)
{
    int base = weight <= 10 ? 4 : 7;
    if (express) {
        if (weight > 20) {
            return -1;
        }
        return base + 5;
    }
    return base;
}
```

| Weight | `express` | Representative | Expected |
| --- | --- | --- | --- |
| $[1,10]$ | $0$ | $(6,0)$ | $4$ |
| $[11,30]$ | $0$ | $(25,0)$ | $7$ |
| $[1,10]$ | $1$ | $(6,1)$ | $9$ |
| $[11,20]$ | $1$ | $(15,1)$ | $12$ |
| $[21,30]$ | $1$ | $(25,1)$ | $-1$ |

The minimum is $5$ tests.

<div class="spiegazione">

With `express` equal to $0$ only the base rate matters, so the classes are the two weight bands. With `express` equal to $1$ the threshold $20$ is added to the threshold $10$, so the weights split into three bands. The five classes are nonempty, disjoint and cover the domain, so at least $5$ calls are needed. For example, for $(15,1)$ the base is $7$ and express shipping is allowed, so the expected value is $7+5=12$.

The four combinations of weight band and `express` form a coarser partition. The combination with weight from $11$ to $30$ and `express` equal to $1$ contains two different rules, since $(15,1)$ requires $12$ and $(25,1)$ requires $-1$. A plan with four tests has only one representative of that set, so one of the two rules remains untested. The five calls in the table return $4$, $7$, $9$, $12$ and $-1$, in agreement with the expected results.

</div>
