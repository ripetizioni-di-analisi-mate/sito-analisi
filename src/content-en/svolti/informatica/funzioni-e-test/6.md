## Exercise 1

An integer `score` belongs to the domain from $0$ to $30$. The specification assigns $2$ up to $7$, $4$ from $8$ to $20$, and $6$ from $21$ onwards. Build one test per class and compute the expected results using representatives $3$, $14$ and $24$.
```c
int tier(int score)
{
    if (score <= 7) {
        return 2;
    }
    if (score <= 20) {
        return 4;
    }
    return 6;
}
```

| Integers in class | Representative | Expected |
| --- | --- | --- |
| $[0,7]$ | $3$ | $2$ |
| $[8,20]$ | $14$ | $4$ |
| $[21,30]$ | $24$ | $6$ |

<div class="spiegazione">

The three bands are nonempty, disjoint and cover the integers in the domain. Each representative lies in a distinct band, giving full coverage. To compute the oracle, read the band to which the input belongs. For example, $14$ satisfies $8\leq14\leq20$, so its expected value is $4$.

As a separate check, at $14$ the first comparison in the code is false and the second is true, so execution reaches `return 4;`. At $3$ the first comparison is true, while at $24$ both are false. The three branches agree with the expected results.

</div>

## Exercise 2

The two integer inputs `x` and `y` are both between $-10$ and $10$. The specification distinguishes the negative case from the non-negative case for each input. Find the minimum number of tests that cover the combinations and compute the expected results for four chosen cases using the function.
```c
int zone(int x, int y)
{
    return 2 * (x >= 0) + (y >= 0);
}
```

| `x` | `y` | Expected |
| --- | --- | --- |
| $-2$ | $-3$ | $0$ |
| $-2$ | $3$ | $1$ |
| $2$ | $-3$ | $2$ |
| $2$ | $3$ | $3$ |

The minimum is $4$ tests.

<div class="spiegazione">

Each input has two classes and every combination is possible in the domain. There are therefore $2\cdot2=4$ classes of pairs. A pair belongs to just one class, so fewer than $4$ tests would miss a combination. The four cases shown reach the minimum. A non-negative `x` adds $2$ and a non-negative `y` adds $1$.

To check, read those indicators as two bits. The cases in the table have binary values $00$, $01$, $10$ and $11$, which correspond to the expected values from $0$ to $3$.

</div>
