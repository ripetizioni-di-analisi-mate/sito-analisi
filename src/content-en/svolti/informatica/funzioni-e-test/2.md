## Exercise 1

Write the prototype that belongs before the caller for this definition of `rate`. Then find the value and type of the result of `rate(6, 2)`.

```c
long rate(int units, int band)
{
    return units * (band + 1L);
}
```

The prototype is `long rate(int units, int band);`. The call computes $6(2+1)=18$ and returns a `long`.

<div class="spiegazione">

The prototype types come from the definition. The type to the left of the name is `long`. Both parameters are `int`, so the arguments $6$ and $2$ already have the required type. In the body, the suffix `L` gives `1L` type `long`, so `band + 1L` is computed in `long`. Then `units` is also converted to `long` for multiplication. All values used here are representable.

The computation can be checked as the sum of three terms equal to $6$. To check the type as well, the C17 `_Generic` operator applied to the call would select the `long` association.

</div>

## Exercise 2

Find the result of `classify(-5)`, `classify(0)` and `classify(19)`. Identify the `return` executed in each call.

```c
int classify(int x)
{
    if (x < 0) {
        return -1;
    }
    if (x == 0) {
        return 0;
    }
    return 1;
}
```

| `x` | `return` executed | Result |
| --- | --- | --- |
| $-5$ | `return -1;` | $-1$ |
| $0$ | `return 0;` | $0$ |
| $19$ | `return 1;` | $1$ |

<div class="spiegazione">

For $-5$ the first condition is true, so control returns to the caller before the second condition is tested. For $0$ the first comparison is false and the second is true. For $19$ both are false, so execution reaches the final statement. The three cases cover all integers because every integer has exactly one of the signs in the classification.

For a check, use `(x > 0) - (x < 0)`. Comparisons in C produce $0$ or $1$. On the three arguments the difference is $-1$, $0$ and $1$ in that order, which agrees with the three paths.

</div>
