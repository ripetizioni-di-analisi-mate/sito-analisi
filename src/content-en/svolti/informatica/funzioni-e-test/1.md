## Exercise 1

In the caller, `a` and `b` have type `int` and values $6$ and $3$. The caller initializes `int r = scale(a, b);`. Find `r` and the values of `a` and `b` after the call.

![The values 6 and 3 are copied into the two parameters amount and step.](/immagini/informatica/funzioni-e-test/dati-svolto-en.png)

```c
int scale(int amount, int step)
{
    amount += step;
    return 2 * amount;
}
```

| Point in the call | `amount` | `step` |
| --- | --- | --- |
| Entry | $6$ | $3$ |
| After `amount += step` | $9$ | $3$ |

The value of `r` is $2\cdot9=18$. In the caller, `a` is $6$ and `b` is $3$.

<div class="spiegazione">

The figure distinguishes the caller’s objects from the parameters. The call passes the argument values, so the addition assigns $6+3$ to the object `amount`. The multiplication uses the updated value $9$. The return value initializes `r` to $18$. No statement assigns to `a` or `b`, so the caller still reads $6$ and $3$ from those objects.

To check the result, rewrite it as the equivalent expression $2a+2b$ on the original values. This gives $12+6=18$. Checking that the argument values match before and after the call also gives a check independent of the product.

</div>

## Exercise 2

The caller initializes `double reading = 9.75;` and evaluates `measure(reading)` with the prototype visible. Find the result of the call and the value of `reading` afterwards.

```c
int measure(int n)
{
    return n / 2 + n % 2;
}
```

The integer part of the initial value is $9$. Since $9 = 2\cdot4 + 1$, `n / 2` is $4$ and `n % 2` is $1$. The function returns $4+1=5$. `reading` retains its initial value in its own type.

<div class="spiegazione">

The parameter has type `int`, so the conversion discards the fractional part before the body starts. The value is representable. The body performs integer division and remainder operations and combines their results. The conversion initializes `n`, while `reading` remains a `double`.

For $n=9$, one check is to find the smallest integer $k$ with $2k\geq9$. Since $2\cdot4<9$ and $2\cdot5\geq9$, $k=5$. The returned expression produces that value because it adds one to the quotient when the remainder is one.

</div>
