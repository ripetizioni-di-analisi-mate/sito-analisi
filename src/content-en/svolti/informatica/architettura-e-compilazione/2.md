## Exercise 1

A machine uses eight-bit bytes. In a two-byte unsigned word, the lower address holds `0x05` and the next address holds `0xA0`. Compute the decimal value of the word if the order is big endian.

$$
\begin{aligned}
\text{value} &= 5\cdot 256+160\\[6pt]
 &= 1280+160=1440 .
\end{aligned}
$$

<div class="spiegazione">

In **big-endian** order, the byte at the lower address carries the higher weight. The byte at the following address has weight one, so it contributes its value directly. The hexadecimal digit `A` has value ten, so `0xA0` equals $10\cdot 16=160$.

As a check, divide the result $1440$ by $256$. The quotient is $5$ and the remainder is $160$. The quotient and remainder therefore recover the two original bytes in order.

</div>

## Exercise 2

Store the unsigned word `0x1234ABCD` at addresses `0x100` through `0x103` on a machine with eight-bit bytes. Give the contents of each address for both byte orders.

| Address | Big endian | Little endian |
|---|---|---|
| `0x100` | `0x12` | `0xCD` |
| `0x101` | `0x34` | `0xAB` |
| `0x102` | `0xAB` | `0x34` |
| `0x103` | `0xCD` | `0x12` |

<div class="spiegazione">

A byte holds two hexadecimal digits because two digits provide $16^2=256$ patterns. Split the representation into four groups of two digits. In big-endian order, assign the most significant byte to address `0x100`. In little-endian order, start with the least significant byte, `0xCD`. The value of each group of two digits stays the same.

To check the word, read the groups in each column from the greatest weight to the least. In the big-endian column this follows increasing addresses. In the little-endian column it follows decreasing addresses. Both readings give `12 34 AB CD` and reconstruct the same word.

</div>
