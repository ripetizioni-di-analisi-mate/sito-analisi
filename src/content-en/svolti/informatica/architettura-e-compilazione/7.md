## Exercise 1

The file `report.c` contains the following program. Use a GCC-compatible driver in a hosted POSIX-style environment. Identify the kind of file produced by each command, then give the command that builds `app` from the second output.
```c
int main(void)
{
    return 0;
}
```
```shell
cc -std=c17 -S report.c -o plan.s
cc -c plan.s -o report.o
```

File `plan.s` is an assembly listing. File `report.o` is an object file. The link command is

```shell
cc report.o -o app
```

<div class="spiegazione">

Since the first input has extension `.c`, the driver preprocesses and compiles it before stopping at `-S`. The input of the second command, with extension `.s`, is already assembly, so `-c` gives the object file produced by the assembler. The last command passes that object to the linker along with the inputs the driver supplies for a hosted executable.

Check the path by running the three commands in order. `plan.s` is readable as assembly text, `report.o` holds the definition of `main` and the executable terminates with a success status. The outputs are of different kinds even though `-o` selects their names.

</div>

## Exercise 2

A hosted project consists of four objects. The references in the table are the only project references still to be resolved. Building the executable requires `main`. All listed symbols are strong and the function declarations are compatible. Find the smallest set of object files sufficient for the link.
| Object | Defines | Requires |
|---|---|---|
| `main.o` | `main` | `scale` |
| `scale.o` | `scale` | `offset` |
| `constants.o` | `offset` | no symbol |
| `diag.o` | `diagnose` | no symbol |

The required objects are `main.o`, `scale.o` and `constants.o`.

<div class="spiegazione">

`main.o` is the only object defining `main`, so it belongs in the set. From `main.o` the dependency reaches `scale`, whose definition is in `scale.o`. Adding that object introduces a reference to `offset`, resolved by `constants.o`. The chain of dependencies ends there.

To check minimality, remove each of the three objects in turn. Removing `main.o` leaves no entry point. Removing `scale.o` or `constants.o` leaves `scale` or `offset` unresolved, respectively. No object requires `diagnose`, so `diag.o` is unnecessary.

</div>
