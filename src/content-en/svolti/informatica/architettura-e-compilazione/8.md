## Exercise 1

Translate `main.c` with `cc -std=c17 -pedantic-errors -c main.c -o main.o` using a GCC-compatible driver. On the first attempt, `units_local.h` is missing from all search paths. On the second attempt, the file is present and contains the declaration `int read_value(void);`. Identify the stage that reveals the problem on each attempt and correct the call.
```c
#include "units_local.h"

int main(void)
{
    return read_value(5);
}
```

| Attempt | Stage that detects the problem |
|---|---|
| Header missing | Preprocessing |
| Header present | C constraint checking |

The correct call is `read_value()`.

<div class="spiegazione">

On the first attempt, `#include` requests a file absent from the search paths. The driver stops before producing the preprocessed source. On the second attempt, the contents of the header become part of the translation unit. The parameter list spelled `void` means the function takes zero arguments. The compiler can therefore detect the extra argument $5$.

To check, remove the argument and repeat the command with the header in place. The command produces `main.o`. The definition of `read_value` can be in another translation unit, so the reference remains available for later linking.

</div>

## Exercise 2

The specification requires incrementing $9$ by one and then doubling it. An executable was built successfully from the source below. Assuming all writes succeed, determine the program’s output, its termination status and the smallest change that meets the specification.
```c
#include <stdio.h>

int main(void)
{
    int value = 9;
    printf("%d\n", 2 * value + 1);
    return 0;
}
```

$$
\begin{aligned}
\text{value printed} &= 2\cdot9+1=19\\[6pt]
\text{required value} &= 2\cdot(9+1)=20 .
\end{aligned}
$$

The program prints `19` and a newline, then reports success. The correct value argument is `2 * (value + 1)`.

<div class="spiegazione">

Multiplication has higher precedence than addition, so the expression as written doubles the input before adding one. The specification requires the reverse order, so the parentheses make `value + 1` an operand of the multiplication. `return 0;` reports success to the environment in both programs. This return value is independent of the digits written to `stdout`.

To check, run the original and corrected programs while capturing standard output separately. The first produces the digits of $19$ and the second those of $20$. Expanding the product confirms the second output because $2(9+1)=2\cdot 9+2$.

</div>

## Exercise 3

The specification requires the program to print the integer mean, rounded down, of $7$ and $9$. The function `mean` receives integers with $0\leq a\leq1000$ and $0\leq b\leq1000$, so the sums are representable in `int`. The three commands shown are run in order on a GCC-compatible driver. Identify the command that fails and the corresponding stage. Correct the defect, determine the output of the resulting program and finally correct the calculation according to the specification.
```c
/* stats.h */
#ifndef STATS_H_INCLUDED
#define STATS_H_INCLUDED
int mean(int a, int b);
#endif
```
```c
/* stats.c */
#include "stats.h"

int average(int a, int b)
{
    return a + b / 2;
}
```
```c
/* main.c */
#include <stdio.h>
#include "stats.h"

int main(void)
{
    printf("%d\n", mean(7, 9));
    return 0;
}
```
```shell
cc -std=c17 -pedantic-errors -c main.c -o main.o
cc -std=c17 -pedantic-errors -c stats.c -o stats.o
cc main.o stats.o -o app
```

| Command | Result |
|---|---|
| Translation of `main.c` | succeeds |
| Translation of `stats.c` | succeeds |
| Link | unresolved reference to `mean` |

After renaming `average` to `mean` in the definition, the link succeeds and the program prints `11`. With `return (a + b) / 2;` it prints `8`.

$$
\begin{aligned}
7+\left\lfloor\frac{9}{2}\right\rfloor &= 7+4=11\\[6pt]
\left\lfloor\frac{7+9}{2}\right\rfloor &= 8 .
\end{aligned}
$$

<div class="spiegazione">

`main.c` includes the header and sees the prototype of `mean`, so the call satisfies the constraints and `main.o` contains an external reference to `mean`. `stats.c` also translates without diagnostics, because `average` is a different name from `mean` and no rule requires a source file to define the functions declared in the headers it includes. The defect therefore shows up only at **link** time, where neither object defines `mean`.

After the name is corrected, the program builds and produces a wrong output. Division has higher precedence than addition, so the expression computes `a + (b / 2)`. Division between non-negative integers truncates the quotient, so `9 / 2` equals `4` and the output is `11`. Parentheses around `a + b` make the sum the dividend, and the output becomes `8`, the required mean rounded down. By the hypothesis on the data the sum does not exceed $2000$, so it remains representable in `int`.

</div>
