## Exercise 1

A counter represents every integer from $0$ to $255$. Find the minimum width of the unsigned format. Then find the minimum width if the counter must reach $256$.

$$
\begin{aligned}
2^7-1 &= 127 < 255 \\
2^8-1 &= 255 \\
2^9-1 &= 511 \geq 256 .
\end{aligned}
$$

The first counter requires **eight bits**. The new maximum requires **nine bits**.

<div class="spiegazione">

With $n$ bits, the maximum value occurs when every bit equals $1$ and is $2^n-1$. With seven bits the maximum is $127$, so the capacity is insufficient. Eight bits reach $255$ and can represent every nonnegative integer up to that maximum. Once the counter has to reach $256$, eight bits are insufficient. Nine bits give a maximum of $511$ and can represent $256$.

Verify the threshold by counting the values. From $0$ to $255$ there are $256=2^8$ values, so every eight-bit pattern is used. The updated counter has to represent $257$ values and therefore requires more than the original $256$ patterns.

</div>

## Exercise 2

A device needs a distinct unsigned integer code for each of $1300$ possible measurements and for each of $64$ device states. Find the minimum width and the number of bit patterns left available.

$$
\begin{aligned}
1300+64 &= 1364 \\
2^{10} &= 1024 < 1364 \\
2^{11} &= 2048 \geq 1364 \\
2048-1364 &= 684 .
\end{aligned}
$$

The format requires **eleven bits**, with $684$ bit patterns left available.

<div class="spiegazione">

Each measurement and each state needs a different code, so the number of required words is the sum of the two counts. Ten bits give $1024$ words, which is fewer than required. Eleven bits give a capacity of $2048$, so the format accommodates all $1364$ codes. The number of remaining patterns is the capacity minus the number of assigned codes.

As a check, assign the codes in order from $0$ to $1363$. The last code exceeds the ten-bit maximum of $1023$ and is within the eleven-bit maximum of $2047$. The remaining patterns correspond to the integers from $1364$ to $2047$, giving $2047-1364+1=684$ patterns.

</div>
