## Exercise 1

A nondecreasing array has $30$ elements, all greater than `key`. Find the number of key comparisons for `linear_first`, `lower_bound`, and `binary_first`.

$$
\begin{aligned}
\text{remaining lengths}&\quad 30,15,7,3,1,0,\\[6pt]
C_{\mathrm{lin}}&=30,\\
C_{\mathrm{lb}}&=5,\\
C_{\mathrm{bin}}&=5+1=6.
\end{aligned}
$$

<div class="spiegazione">

Every equality comparison in the scan is false, so it reaches the end after examining all elements. In the lower-bound search, the strict less-than test is always false. Each step therefore sets `hi = mid` and rounds the halved length down. The five transitions in the sequence exhaust the range. The lower bound is $0$, so `binary_first` reads that element and compares it with the key, adding one false test.

We have $2^4=16\le 30<32=2^5$. Five is the first exponent giving a power above $30$, in agreement with the trace. The scan's comparison count follows directly from the number of readable indices.

</div>

## Exercise 2

Find the largest array length for which lower bound uses at most $4$ key comparisons on every nondecreasing array and every key.

$$
\begin{aligned}
2^4&=16,\\
n&<16,\\
n_{\max}&=15 .
\end{aligned}
$$

<div class="spiegazione">

After four comparisons, the greatest number of remaining elements is $\left\lfloor\dfrac{n}{2^4}\right\rfloor$. This bound is attainable with a search key at most every element, because each split retains the maximal left range. To guarantee completion after four tests, the maximal remainder must be zero. This is equivalent to $n<16$.

Check the two consecutive lengths around the bound by halving. Length $15$ becomes $7$, $3$, $1$, and $0$. Length $16$ becomes $8$, $4$, $2$, and $1$. The latter still needs a test, so $15$ is the maximum.

</div>

## Exercise 3

The array `a` holds the $12$ elements $a_i=10(i+1)$. The $13$ keys $10p+5$, with $p=0,\ldots,12$, produce every possible result of `lower_bound`, the function from the theory with `++comparisons;` before the test. Count the comparisons for each key and find the minimum, the maximum, and the total.
```c
for (int p = 0; p <= 12; ++p) {
    comparisons = 0;
    size_t r = lower_bound(a, 12, 10 * p + 5);
    printf("%d %zu %zu\n", 10 * p + 5, r, comparisons);
}
```

| Results $p$ | Remaining lengths | Comparisons |
|---|---|---:|
| 0, 1, 2, 3 | 12, 6, 3, 1, 0 | 4 |
| 4, 5 | 12, 6, 2, 1, 0 | 4 |
| 6 | 12, 6, 2, 0 | 3 |
| 7, 8, 10, 11 | 12, 5, 2, 1, 0 | 4 |
| 9, 12 | 12, 5, 2, 0 | 3 |

The minimum is $3$, the maximum is $4$, and the total is $10\cdot4+3\cdot3=49$.

<div class="spiegazione">

A range of length $m$ has $\left\lfloor\dfrac{m}{2}\right\rfloor$ elements to the left of `mid`. If the test is false those elements remain, and if it is true $m-\left\lfloor\dfrac{m}{2}\right\rfloor-1$ remain. Length $12$ therefore becomes $6$ or $5$, length $6$ becomes $3$ or $2$, length $5$ becomes $2$, and length $3$ becomes $1$. In a range of length $2$ the midpoint is the second position, so a true test empties the range and a false test leaves one element. Results $6$, $9$, and $12$ are reached by a true test on a range of length $2$, and therefore need one comparison fewer.

The maximum equals $1+\lfloor\log_2 12\rfloor=4$, as stated by the theorem on the **cost of binary search**. Every path goes through three positive lengths, namely $12$, one of $6$ and $5$, and one of $3$ and $2$, so the minimum is $3$. The average over the $13$ keys is $\dfrac{49}{13}\approx3.77$.

</div>
