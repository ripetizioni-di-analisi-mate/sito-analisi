## Exercise 1

A nondecreasing array has $30$ elements, all greater than `key`. Find the number of key comparisons for `linear_first`, `lower_bound`, and `binary_first`.

$$
\begin{aligned}
\text{remaining lengths}&\quad 30,15,7,3,1,0,\\[6pt]
C_{\mathrm{lin}}&=30,\\
C_{\mathrm{lb}}&=5,\\
C_{\mathrm{bin}}&=5+1=6.
\end{aligned}
$$

<div class="spiegazione">

Every equality comparison in the scan is false, so it reaches the end after examining all elements. In the lower-bound search, the strict less-than test is always false. Each step therefore sets `hi = mid` and rounds the halved length down. The five transitions in the sequence exhaust the range. The lower bound is $0$, so `binary_first` reads that element and compares it with the key, adding one false test.

We have $2^4=16\le 30<32=2^5$. Five is the first exponent giving a power above $30$, in agreement with the trace. The scan's comparison count follows directly from the number of readable indices.

</div>

## Exercise 2

Find the largest array length for which lower bound uses at most $4$ key comparisons on every nondecreasing array and every key.

$$
\begin{aligned}
2^4&=16,\\
n&<16,\\
n_{\max}&=15 .
\end{aligned}
$$

<div class="spiegazione">

After four comparisons, the greatest number of remaining elements is $\left\lfloor\dfrac{n}{2^4}\right\rfloor$. This bound is attainable with a search key at most every element, because each split retains the maximal left range. To guarantee completion after four tests, the maximal remainder must be zero. This is equivalent to $n<16$.

Check the two consecutive lengths around the bound by halving. Length $15$ becomes $7$, $3$, $1$, and $0$. Length $16$ becomes $8$, $4$, $2$, and $1$. The latter still needs a test, so $15$ is the maximum.

</div>
