## Exercise 1

For an increasing array of $64$ distinct keys, count the key comparisons performed by the insertion sort, selection sort, and merge sort from the theory fragments.

$$
\begin{aligned}
C_{\mathrm{ins}}&=64-1=63,\\[6pt]
C_{\mathrm{sel}}&=\frac{64\cdot63}{2}=2016,\\[6pt]
C_{\mathrm{merge}}&=\frac{64}{2}\cdot 6=192 .
\end{aligned}
$$

<div class="spiegazione">

For the first algorithm, each prefix already contains keys smaller than the new key. The first comparison of each pass is false, so one test per pass suffices. Selection scans every suffix even when the minimum is in its first position. Adding the scanned lengths gives the second count.

In merge sort with equal halves, every merge receives left-run values smaller than all those in the right run. Each comparison consumes one left position until that run is exhausted. Thus each complete level compares each of the $32$ positions in the left halves once. Since $64=2^6$, there are six merge levels. As a check, the final merge uses $32$ comparisons and the two merges immediately below it use $16+16=32$.

</div>

## Exercise 2

The merge sort from the fragments sorts $16$ elements without skipping merges. Count the auxiliary array positions, the maximum number of simultaneous `merge_sort` calls, and the copy-back writes. Include the base case in the call count.

$$
\begin{aligned}
\text{lengths along the path}&\quad 16,8,4,2,1,\\[6pt]
\text{auxiliary positions}&\quad 16,\\
\text{maximum active calls}&\quad 5,\\
\text{copy-back writes}&\quad 16\cdot4=64 .
\end{aligned}
$$

<div class="spiegazione">

The path from the outer call to the base case contains four splits. The initial call and four descendant calls are therefore active on reaching the base case. The second child of a call starts after the first returns, so the two path depths do not add. `merge_sort` reuses the same auxiliary positions, and the outer merge uses all sixteen.

Check the write count by counting runs from the lowest merge level to the highest. There are eight runs of two, four of four, two of eight, and one of sixteen. Every level totals sixteen. The writes therefore number sixty-four, while sixteen positions are reserved because they are reused.

</div>
