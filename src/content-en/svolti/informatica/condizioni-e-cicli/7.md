## Exercise 1

Use an invariant to prove which power `p` contains at each test. Calculate `p` on exit.
```c
int i = 0, p = 1;
while (i < 5) {
    p *= 3;
    ++i;
}
```

$$
\begin{aligned}
i=0 &\implies p=1=3^0, \\[6pt]
p=3^i &\implies p'=3p=3^{i+1}=3^{i'}, \\[6pt]
i=5 &\implies p=3^5=243 .
\end{aligned}
$$

<div class="spiegazione">

On arrival at the guard, the property $0\le i\le 5$ holds together with $p=3^i$. The first relation follows from initialization at zero and the second from assigning one. If the guard is true, $0\le i<5$. After the two updates, $i'=i+1\le 5$ and $p'=3p$, so both relations are preserved. All values of `p` lie between `1` and `243`. The type `int` can represent them.

Since `i` increases by one at each iteration, the false guard is reached. The guard gives $i\ge 5$ and the invariant gives $i\le 5$. Together they determine the final exponent. As a separate numerical check, $3^5=3^2\cdot3^3=9\cdot27=243$.

</div>


## Exercise 2

The proposed invariant at the guard is `s = i`. Check the proposal, find a useful invariant, and derive the final value of `s`.
```c
int i = 0, s = 0;
while (i < 6) {
    ++i;
    if (i % 2 == 0) {
        s += i;
    }
}
```

After the first update, `i = 1` and `s = 0`. A property that is preserved is

$$
m=\left\lfloor\frac{i}{2}\right\rfloor,
\qquad s=m(m+1),
\qquad 0\le i\le 6 .
$$

At the end $i=6$, so $m=3$ and $s=3\cdot4=12$.

<div class="spiegazione">

The first visit to the guard satisfies `s = i`. The second visit disproves it, because the counter has advanced to one and the selection skipped the addition. To account for the selection, let $m$ be the number of positive even integers up to $i$. Their sum is $m(m+1)$, which also holds initially when $m=0$.

If the new `i` is odd, $m$ remains unchanged and the selection leaves `s` unchanged. If the new `i` is even, it equals $2(m+1)$ with $m$ taken from the previous state. The update gives $m(m+1)+2(m+1)=(m+1)(m+2)$, so it preserves the relation with the new number of even terms. Since `i` advances by one and the guard stops at six, the final values are $m=3$ and `s = 12`. Direct addition, $2+4+6=12$, confirms the result.

</div>


## Exercise 3

Prove that $\mathrm{result}\cdot\mathrm{base}^{e}=3^{13}$ holds at every test of the guard, and derive the final value of `result`. Assume a 32-bit `unsigned`.
```c
unsigned base = 3u, e = 13u, result = 1u;
while (e > 0u) {
    if (e % 2u == 1u) {
        result *= base;
    }
    base *= base;
    e /= 2u;
}
```

| `result` | `base` | `e` | $\mathrm{result}\cdot\mathrm{base}^{e}$ |
|---:|---:|---:|---|
| 1 | 3 | 13 | $3^{13}$ |
| 3 | 9 | 6 | $3\cdot 3^{12}$ |
| 3 | 81 | 3 | $3\cdot 3^{12}$ |
| 243 | 6561 | 1 | $3^{5}\cdot 3^{8}$ |
| 1594323 | 43046721 | 0 | $3^{13}$ |

$$
\begin{aligned}
e=2h &\implies \mathrm{result}\cdot\left(\mathrm{base}^{2}\right)^{h}=\mathrm{result}\cdot\mathrm{base}^{e}, \\[6pt]
e=2h+1 &\implies \left(\mathrm{result}\cdot\mathrm{base}\right)\cdot\left(\mathrm{base}^{2}\right)^{h}=\mathrm{result}\cdot\mathrm{base}^{e}.
\end{aligned}
$$

On exit $e=0$, so $\mathrm{result}=3^{13}=1594323$.

<div class="spiegazione">

Initially `result` is `1`, `base` is `3`, and `e` is `13`, so the relation holds with the product $1\cdot 3^{13}$. Suppose it holds at a test where the guard is true, and let $h$ be the integer quotient of $e$ by two. After the body, the new exponent is $h$ and the new base is $\mathrm{base}^2$. If $e$ is even, `result` is unchanged, and the first equality of the computation shows that the product is preserved. If $e$ is odd, `result` is multiplied by `base`, and the same conclusion follows from the second equality. The relation is therefore a **loop invariant**.

The exponent goes from `13` to `6`, `3`, `1`, and `0`, so the guard becomes false after four iterations. At that test $\mathrm{base}^0=1$, so the invariant gives $\mathrm{result}=3^{13}$. The largest value computed is the last base, $3^{16}=43046721$, which is less than $2^{32}$. It follows that no multiplication leaves the range of `unsigned` and that the program values coincide with the mathematical values used in the proof. The last square is computed but does not contribute to the result, because the remaining exponent is zero.

</div>
