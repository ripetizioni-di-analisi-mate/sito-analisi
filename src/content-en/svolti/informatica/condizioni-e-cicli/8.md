## Exercise 1

Find a nonnegative integer variant and use the trace to determine `current` and `steps` on exit.
```c
int current = 2, steps = 0;
while (current < 12) {
    current += 3;
    ++steps;
}
```

| `current` | Variant $\max(0,12-\mathrm{current})$ |
|---:|---:|
| 2 | 10 |
| 5 | 7 |
| 8 | 4 |
| 11 | 1 |
| 14 | 0 |

The final values are `current = 14` and `steps = 4`.

<div class="spiegazione">

When the guard is true, the integer distance $12-\mathrm{current}$ is at least one. The update reduces that distance by three. Taking the maximum with zero replaces a negative distance with zero, strictly below the previous variant value. If the distance stays positive, it decreases by exactly three. Thus the variant remains nonnegative even when the final update overshoots the threshold.

The counter `steps` provides an independent check. After $k$ iterations, $\mathrm{current}=2+3k$. The first $k$ satisfying $2+3k\ge 12$ is $\left\lceil\dfrac{10}{3}\right\rceil=4$. This also confirms the value $2+3\cdot4=14$.

</div>


## Exercise 2

Prove that the loop terminates and that `a` on exit is the greatest common divisor of the initial inputs. Calculate the result for the fragment's values.
```c
int a = 84, b = 30;
while (a != b) {
    if (a > b) {
        a -= b;
    } else {
        b -= a;
    }
}
```

| `a` | `b` | $a+b$ |
|---:|---:|---:|
| 84 | 30 | 114 |
| 54 | 30 | 84 |
| 24 | 30 | 54 |
| 24 | 6 | 30 |
| 18 | 6 | 24 |
| 12 | 6 | 18 |
| 6 | 6 | 12 |

The result is `a = b = 6`.

<div class="spiegazione">

The loop starts with two positive integers. The guard makes them distinct at every iteration that begins, so the larger value minus the smaller is still positive. The mathematical sum $a+b$ decreases strictly by the smaller value and remains positive, so it is a variant.

For the invariant, consider the set of common positive divisors. If $a>b$, a divisor of both values also divides $a-b$. Conversely, a divisor of $a-b$ and $b$ divides $(a-b)+b=a$. The branch $b>a$ preserves the set by the same argument with the roles exchanged. On the false guard the values coincide, so the largest common divisor is the common value itself. To check the numerical case, $84=2^2\cdot3\cdot7$ and $30=2\cdot3\cdot5$, so the greatest common divisor is $2\cdot3=6$.

</div>
