## Exercise 1

Calculate `count` and describe the common property of the pairs that reach the increment.
```c
int count = 0;
for (int i = 0; i < 4; ++i) {
    for (int j = 0; j <= i; ++j) {
        if ((i + j) % 2 == 0) {
            ++count;
        }
    }
}
```

| `i` | `j` with even sum | Increments |
|---:|---|---:|
| 0 | 0 | 1 |
| 1 | 1 | 1 |
| 2 | 0, 2 | 2 |
| 3 | 1, 3 | 2 |

The pairs have indices of the same parity, and `count = 6`.

<div class="spiegazione">

Fix `i`. The inner loop visits each integer from `0` through `i`. The increment requires an even sum, so `j` must be even when `i` is even and odd when `i` is odd. Count the values of `j` satisfying both conditions in each row, then add the row counts.

A second count groups the pairs by parity. Among the even indices $0$ and $2$, there are two diagonal pairs and one with `j < i`. The odd indices $1$ and $3$ give another three pairs for the same reason. The two sets are disjoint, so the total is $3+3=6$.

</div>


## Exercise 2

Determine `score`. For each row, identify which columns contribute to the addition.
```c
int score = 0;
for (int row = 1; row <= 3; ++row) {
    for (int col = 1; col <= 4; ++col) {
        if (row + col >= 5) {
            break;
        }
        if (col == 1) {
            continue;
        }
        score += 2 * row + col;
    }
}
```

| Row | Columns used | Contribution |
|---:|---|---|
| 1 | 2, 3 | `4 + 5 = 9` |
| 2 | 2 | `6` |
| 3 | none | `0` |

The final score is `9 + 6 + 0 = 15`.

<div class="spiegazione">

In every row the first candidate column is `1`. At that point `row + col` is less than `5` for all three possible values of `row`, so `continue` executes and the column advances. Next, `row + col >= 5` exits the inner loop at the first column where it holds. There are three exit points, at columns `4`, `3`, and `2`. At each exit the outer `for` continues with the next row, if there is one.

Check the contributions by solving the conditions $2\le \mathrm{col}\le 4$ and $\mathrm{col}<5-\mathrm{row}$ together. In each row, the second condition also excludes every column after the first break because `col` increases. The remaining pairs are $(1,2)$, $(1,3)$, and $(2,2)$. Substitution into `2 * row + col` gives `4`, `5`, and `6` again.

</div>
