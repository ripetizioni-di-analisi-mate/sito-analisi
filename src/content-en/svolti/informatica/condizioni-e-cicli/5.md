## Exercise 1

Write a `while` loop that adds the integers from `1` to `7`, using `continue` to skip those with remainder `1` when divided by `3`. Calculate the resulting sum.

```c
int i = 1, sum = 0;
while (i <= 7) {
    int current = i;
    ++i;
    if (current % 3 == 1) {
        continue;
    }
    sum += current;
}
```

$$
\begin{aligned}
\text{Skipped values} &\quad 1,4,7, \\
\text{Added values} &\quad 2,3,5,6, \\[6pt]
\mathrm{sum} &= 2+3+5+6=16 .
\end{aligned}
$$

<div class="spiegazione">

The variable `current` retains the value under consideration while `i` advances to the next visit. Because `++i` precedes `continue`, every path through the body updates the counter. When `current = 7`, the selection skips the addition, but control returns with `i = 8` and makes the guard false. With the only increment after the possible jump, the initial value `i = 1` would return the same state to the guard.

To check the sum, the integers from $1$ to $7$ add up to $\dfrac{7\cdot 8}{2}=28$. The skipped values give $1+4+7=12$. Subtraction confirms $28-12=16$.

</div>


## Exercise 2

Calculate `s` and `i` when the loop exits. Identify the last term actually added.
```c
int s = 0, i;
for (i = 1; i <= 9; ++i) {
    if (i % 2 == 0) {
        continue;
    }
    if (s + i > 12) {
        break;
    }
    s += i;
}
```

| Odd value examined | Proposed sum | Outcome |
|---:|---:|---|
| 1 | 1 | updates `s` |
| 3 | 4 | updates `s` |
| 5 | 9 | updates `s` |
| 7 | 16 | exits |

The loop exits with `s = 9` and `i = 7`. The last term added is `5`.

<div class="spiegazione">

The selection on even values precedes the comparison with the limit. An even value therefore transfers control to the `for` update and leaves `s` unchanged. For an odd value, `s + i` computes a candidate sum without writing it to `s`. The first candidate above `12` is `16`, when `i = 7`. The `break` executes before `s += i` and before the `for` update.

As a check, the sum of the first $k$ odd integers is $k^2$. Three terms give $9\le 12$, while four would give $16>12$. The admissible prefix therefore has three terms and ends at `5`.

</div>
