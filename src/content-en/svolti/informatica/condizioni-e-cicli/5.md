## Exercise 1

Write a `while` loop that adds the integers from `1` to `7`, using `continue` to skip those with remainder `1` when divided by `3`. Calculate the resulting sum.

```c
int i = 1, sum = 0;
while (i <= 7) {
    int current = i;
    ++i;
    if (current % 3 == 1) {
        continue;
    }
    sum += current;
}
```

$$
\begin{aligned}
\text{Skipped values} &\quad 1,4,7, \\
\text{Added values} &\quad 2,3,5,6, \\[6pt]
\mathrm{sum} &= 2+3+5+6=16 .
\end{aligned}
$$

<div class="spiegazione">

The variable `current` retains the value under consideration while `i` advances to the next visit. Because `++i` precedes `continue`, every path through the body updates the counter. When `current = 7`, the selection skips the addition, but control returns with `i = 8` and makes the guard false. With the only increment after the possible jump, the initial value `i = 1` would return the same state to the guard.

To check the sum, the integers from $1$ to $7$ add up to $\dfrac{7\cdot 8}{2}=28$. The skipped values give $1+4+7=12$. Subtraction confirms $28-12=16$.

</div>


## Exercise 2

Calculate `s` and `i` when the loop exits. Identify the last term actually added.
```c
int s = 0, i;
for (i = 1; i <= 9; ++i) {
    if (i % 2 == 0) {
        continue;
    }
    if (s + i > 12) {
        break;
    }
    s += i;
}
```

| Odd value examined | Proposed sum | Outcome |
|---:|---:|---|
| 1 | 1 | updates `s` |
| 3 | 4 | updates `s` |
| 5 | 9 | updates `s` |
| 7 | 16 | exits |

The loop exits with `s = 9` and `i = 7`. The last term added is `5`.

<div class="spiegazione">

The selection on even values precedes the comparison with the limit. An even value therefore transfers control to the `for` update and leaves `s` unchanged. For an odd value, `s + i` computes a candidate sum without writing it to `s`. The first candidate above `12` is `16`, when `i = 7`. The `break` executes before `s += i` and before the `for` update.

As a check, the sum of the first $k$ odd integers is $k^2$. Three terms give $9\le 12$, while four would give $16>12$. The admissible prefix therefore has three terms and ends at `5`.

</div>


## Exercise 3

Find the final values of `total` and `i` and the number of executions of the multiplication `total *= 2`, taking into account the destinations of `break` and `continue` inside the `switch`.
```c
int total = 0, i = 0;
while (i < 6) {
    ++i;
    switch (i % 3) {
    case 0:
        continue;
    case 1:
        total += i;
        break;
    default:
        total -= 1;
    }
    total *= 2;
}
```

| `i` | `i % 3` | Path | `total` at the end of the iteration |
|---:|---:|---|---:|
| 1 | 1 | `total += i`, doubling | 2 |
| 2 | 2 | `total -= 1`, doubling | 2 |
| 3 | 0 | `continue` | 2 |
| 4 | 1 | `total += i`, doubling | 12 |
| 5 | 2 | `total -= 1`, doubling | 22 |
| 6 | 0 | `continue` | 22 |

The loop exits with `total = 22` and `i = 6`. The multiplication executes four times.

<div class="spiegazione">

The `break` under `case 1` terminates the innermost enclosing loop or `switch`, which is the `switch`. Control therefore passes to the multiplication that follows the `switch`, inside the body of the `while`. The `default` branch is the last one in the body of the `switch`, so after `total -= 1` control reaches the same statement without a `break`. The `continue` under `case 0` belongs to the `while`, because a `switch` has no continuation point for `continue`. Consequently control returns to the guard and the multiplication is skipped.

The increment `++i` is the first statement of the body, so every path updates the counter, including the one that ends with `continue`. The remainder `0` occurs for `i = 3` and `i = 6`, so the multiplication executes four times, with the computations $(0+1)\cdot 2=2$, $(2-1)\cdot 2=2$, $(2+4)\cdot 2=12$, and $(12-1)\cdot 2=22$. After the `continue` with `i = 6`, the guard `6 < 6` is false and the loop ends.

</div>
