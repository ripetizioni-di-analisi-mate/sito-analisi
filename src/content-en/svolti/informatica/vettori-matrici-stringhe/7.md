## Exercise 1

Append `"UV"` to `"largo"` within the destination array. Compare `char dst[8] = "largo";` and `char dst[7] = "largo";`. For each declaration, determine whether the append can produce a C string stored entirely in the array.

$$
\begin{aligned}
u &= 5,\qquad v=2,\\[6pt]
u+v &= 7,\\[6pt]
B_{\min} &= u+v+1=8 .
\end{aligned}
$$

```text
0   1   2   3   4   5   6   7
l   a   r   g   o   U   V   \0
```

<div class="spiegazione">

The original prefix takes five cells. The two new characters go at indices $5$ and $6$ because the added text starts where the original terminator was. The new string ends at index $7$. With a capacity of eight cells that index is valid, so the result is `"largoUV"`. With seven cells, index $7$ is the first excluded index and the terminator has no space.

An equivalent check starts from the space left for new characters after reserving the null cell. With eight cells, $8-1-5=2$ remain, exactly as required. With seven cells, $7-1-5=1$ remains, too little for both characters. Reserving one C byte for the null accounts for the two outcomes.

</div>

## Exercise 2

Write a function that appends one character different from `'\0'` to a string of known length. When there is too little space, the function must leave the array unchanged. Compare appending `'A'` to `char a[1] = "";` and `char b[2] = "";`.

```c
#include <stdbool.h>
#include <stddef.h>

bool append_char(char s[], size_t cap, size_t len, char ch)
{
    if (len >= cap || cap - len < 2 || ch == '\0') {
        return false;
    }
    s[len] = ch;
    s[len + 1] = '\0';
    return true;
}
```

| `s` | `cap` | `len` | `cap-len` | |
| --- | ---: | ---: | ---: | --- |
| `a` | $1$ | $0$ | $1$ | `false`, `""` |
| `b` | $2$ | $0$ | $2$ | `true`, `"A"` |

<div class="spiegazione">

The initial string is empty in both cases, so the terminator is at index $0$. Appending requires writing `'A'` into that cell and a new null into the next cell. The check first compares length with capacity. The subtraction is evaluated only when length is less than capacity, so it measures a positive number of available cells starting at that index. For `a` there is one cell left and the function returns before writing. For `b` the two assignments use indices $0$ and $1$.

To check, after the attempt the first element of `a` still holds `'\0'`, so its length remains $0$. In the second array `'\0'` is at index $1$, giving length $1$. In both arrays the terminator index is less than the capacity.

</div>
