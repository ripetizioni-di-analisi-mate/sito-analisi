## Exercise 1

Find the output of the following program on a machine where `sizeof(int)` is $4$ and `sizeof(const int *)` is $8$. Assume that writing to `stdout` succeeds. Identify the error in the function `sum_all`, correct it and give the output of the corrected program.

```c
#include <stdio.h>
#include <stddef.h>

int sum_all(const int a[])
{
    size_t n = sizeof a / sizeof a[0];
    int sum = 0;
    for (size_t i = 0; i < n; ++i) {
        sum += a[i];
    }
    return sum;
}

int main(void)
{
    int v[6] = {3, 1, 4, 1, 5, 9};
    size_t n = sizeof v / sizeof v[0];
    printf("%zu %d\n", n, sum_all(v));
    return 0;
}
```

$$
\begin{aligned}
\text{in } \texttt{main}:&\quad \frac{\texttt{sizeof v}}{\texttt{sizeof v[0]}}=\frac{24}{4}=6,\\[6pt]
\text{in } \texttt{sum\_all}:&\quad \frac{\texttt{sizeof a}}{\texttt{sizeof a[0]}}=\frac{8}{4}=2,\qquad 3+1=4 .
\end{aligned}
$$

```text
6 4
```

The correction passes the number of elements as a parameter.

```c
int sum_all(const int a[], size_t n)
{
    int sum = 0;
    for (size_t i = 0; i < n; ++i) {
        sum += a[i];
    }
    return sum;
}
```

With the call `sum_all(v, n)` the program prints `6 23`.

<div class="spiegazione">

In `main` the identifier `v` denotes the array object, so `sizeof v` is $6\cdot4=24$ and the quotient gives the element count $6$. In the declaration of `sum_all` the parameter `const int a[]` is adjusted to `const int *a`. The operator `sizeof a` therefore measures the pointer and is $8$, while `sizeof a[0]` measures an `int` and is $4$. The function thus computes $n=2$ and adds only `a[0]` and `a[1]`, that is $3+1=4$. The value of $n$ computed in the function therefore depends only on the widths of `const int *` and `int`, whatever the length of the array passed. The GCC compiler reports this case with the warning `-Wsizeof-array-argument`, which is enabled even without `-Wall`. In the corrected version the element count is computed in the block where `v` is an array object and passed as an argument of type `size_t`. The function then adds all six elements, with partial sums $3$, $4$, $8$, $9$, $14$ and $23$.

As a check, note that the wrong value $4$ equals the sum of the first $\dfrac{8}{4}=2$ elements. On a machine with four-byte pointers the wrong function would instead add only the first element.

</div>

## Exercise 2

Find the output of the following program and the contents of the matrix at the end of the loops. Assume that writing to `stdout` succeeds.

```c
#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int m[3][4];
    int row[3] = {0};
    int diag = 0;
    for (size_t r = 0; r < 3; ++r) {
        for (size_t c = 0; c < 4; ++c) {
            m[r][c] = (int)((r + 1) * c + r);
            row[r] += m[r][c];
        }
    }
    for (size_t i = 0; i < 3; ++i) {
        diag += m[i][i];
    }
    for (size_t r = 0; r < 3; ++r) {
        printf("%d ", row[r]);
    }
    printf("| %d %d\n", diag, m[2][3] - m[1][3]);
    return 0;
}
```

$$
m=\begin{pmatrix}
0&1&2&3\\
1&3&5&7\\
2&5&8&11
\end{pmatrix},\qquad
\begin{aligned}
\texttt{row} &= (6,16,26),\\[6pt]
\texttt{diag} &= 0+3+8=11,\\[6pt]
m[2][3]-m[1][3] &= 11-7=4 .
\end{aligned}
$$

```text
6 16 26 | 11 4
```

<div class="spiegazione">

The list `{0}` initializes the first element of `row` and, since the declaration provides a list, the other two elements also receive zero. The matrix `m` has automatic storage duration and no initializer, so its initial contents are indeterminate. Every cell, however, receives a value in the inner loop before being read. The expression `(r + 1) * c + r` has `size_t` operands and is at most $3\cdot3+2=11$, so the conversion to `int` preserves the value. With row $r$ fixed, the inner loop writes the row and immediately accumulates its sum in `row[r]`. The diagonal of a $3\times4$ matrix contains $\min(3,4)=3$ cells, so the second loop uses indices $0$, $1$ and $2$, all valid as column indices too. The last field compares two cells of column $3$, which hold $11$ and $7$.

As a check, compute the sum of row $r$ with the formula. The column indices add up to $0+1+2+3=6$, so row $r$ sums to $6(r+1)+4r=10r+6$. For $r=0,1,2$ this gives $6$, $16$ and $26$.

</div>

## Exercise 3

The following program counts the letters of a word made only of lowercase letters and writes into `out` each letter that appears more than once, followed by its frequency. Assume an execution character set in which the letters from `'a'` to `'z'` have consecutive increasing codes, as in ASCII, and that every frequency is at most $9$. Find the output and the contents of `out` up to the terminator.

```c
#include <stdio.h>
#include <stddef.h>

int main(void)
{
    const char word[] = "banana";
    int freq[26] = {0};
    for (size_t i = 0; word[i] != '\0'; ++i) {
        ++freq[word[i] - 'a'];
    }
    char out[2 * 26 + 1];
    size_t k = 0;
    for (size_t j = 0; j < 26; ++j) {
        if (freq[j] > 1) {
            out[k] = (char)('a' + j);
            out[k + 1] = (char)('0' + freq[j]);
            k += 2;
        }
    }
    out[k] = '\0';
    printf("%s %zu %zu\n", out, k, sizeof word);
    return 0;
}
```

| letter | `a` | `b` | `n` |
| --- | ---: | ---: | ---: |
| index in `freq` | $0$ | $1$ | $13$ |
| frequency | $3$ | $1$ | $2$ |

| $i$ | $0$ | $1$ | $2$ | $3$ | $4$ |
| --- | --- | --- | --- | --- | --- |
| `out[i]` | `'a'` | `'3'` | `'n'` | `'2'` | `'\0'` |

```text
a3n2 4 7
```

<div class="spiegazione">

The array `freq` receives zero in all $26$ cells, because the list `{0}` sets the elements without an explicit value to zero. Under the assumption on letter codes, `word[i] - 'a'` is an index in $[0,26)$, equal to $0$ for `'a'`, $1$ for `'b'` and $13$ for `'n'`. The first loop reads the six characters of `"banana"` and stops at the null at index $6$, so the final frequencies are $3$, $1$ and $2$. The second loop examines the letters in alphabetical order and uses $k$ as a write index, which advances by two for each letter kept. The letter `'b'` has frequency $1$ and is skipped. The digits from `'0'` to `'9'` have consecutive codes in every character set that conforms to C, so `'0' + freq[j]` is the digit of the frequency when it is at most $9$. The terminator goes into `out[4]`, so `%s` prints `a3n2` and $k$ is $4$. The operator `sizeof word` counts the six characters and the null of the literal, that is $7$. The capacity of `out` is $53$, enough even if all $26$ letters appeared at least twice, with $2\cdot26$ characters and a null.

</div>
