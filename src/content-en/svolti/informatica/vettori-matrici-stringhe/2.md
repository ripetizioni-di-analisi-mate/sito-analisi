## Exercise 1

Find the contents of all the cells declared by `int a[6] = {7, -2, 5};`. Then calculate `a[2] - a[5]`.

| $i$ | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $a[i]$ | $7$ | $-2$ | $5$ | $0$ | $0$ | $0$ |

$$
a[2]-a[5]=5-0=5 .
$$

<div class="spiegazione">

The declared size is $6$, so indices run from $0$ to $5$. The three explicit initializers are assigned in increasing index order. In particular, the third value in the list, $5$, is assigned to `a[2]`. The aggregate initializer list contains fewer values than there are cells, so the last three integers receive zero. Since `a[5]` is one of them, the subtraction uses the definite value $0$.

As a check, sum all the values in the array. There are three zeros, so the total is $7-2+5=10$. Subtracting the other five cells, $7-2+0+0+0=5$, recovers the value $5$ for `a[2]`. The requested subtraction preserves that value because `a[5]` is zero.

</div>

## Exercise 2

On a machine where `sizeof(int)` is $4$, declare `int v[9];`. Find `sizeof v` and the value of `sizeof v / sizeof v[0]`.

$$
\begin{aligned}
\texttt{sizeof v} &= 9\cdot4=36,\\[6pt]
\frac{\texttt{sizeof v}}{\texttt{sizeof v[0]}}
  &=\frac{36}{4}=9 .
\end{aligned}
$$

<div class="spiegazione">

In the block containing the declaration, `v` is the array object. All elements have the same type, so the object size is the product of nine elements and four C bytes per element. The expression `sizeof v[0]` measures one integer. The operator measures the type’s size, so the individual element values are unnecessary for these calculations.

To check the total space, split the array into index segments $[0,4)$ and $[4,9)$. The first has four elements and occupies $4\cdot4=16$ C bytes. The second has five and occupies $5\cdot4=20$ C bytes. Together they occupy $16+20=36$, enough for nine groups of four C bytes.

</div>
