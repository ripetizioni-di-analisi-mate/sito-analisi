## Exercise 1

Find the contents of all the cells declared by `int a[6] = {7, -2, 5};`. Then calculate `a[2] - a[5]`.

| $i$ | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $a[i]$ | $7$ | $-2$ | $5$ | $0$ | $0$ | $0$ |

$$
a[2]-a[5]=5-0=5 .
$$

<div class="spiegazione">

The declared size is $6$, so indices run from $0$ to $5$. The three explicit initializers are assigned in increasing index order. In particular, the third value in the list, $5$, is assigned to `a[2]`. The aggregate initializer list contains fewer values than there are cells, so the last three integers receive zero. Since `a[5]` is one of them, the subtraction uses the definite value $0$.

As a check, sum all the values in the array. There are three zeros, so the total is $7-2+5=10$. Subtracting the other five cells, $7-2+0+0+0=5$, recovers the value $5$ for `a[2]`. The requested subtraction preserves that value because `a[5]` is zero.

</div>

## Exercise 2

On a machine where `sizeof(int)` is $4$, declare `int v[9];`. Find `sizeof v` and the value of `sizeof v / sizeof v[0]`.

$$
\begin{aligned}
\texttt{sizeof v} &= 9\cdot4=36,\\[6pt]
\frac{\texttt{sizeof v}}{\texttt{sizeof v[0]}}
  &=\frac{36}{4}=9 .
\end{aligned}
$$

<div class="spiegazione">

In the block containing the declaration, `v` is the array object. All elements have the same type, so the object size is the product of nine elements and four C bytes per element. The expression `sizeof v[0]` measures one integer. The operator measures the type’s size, so the individual element values are unnecessary for these calculations.

To check the total space, split the array into index segments $[0,4)$ and $[4,9)$. The first has four elements and occupies $4\cdot4=16$ C bytes. The second has five and occupies $5\cdot4=20$ C bytes. Together they occupy $16+20=36$, enough for nine groups of four C bytes.

</div>

## Exercise 3

Find the output of the following program on a machine where `sizeof(int)` is $4$. Assume that writing to `stdout` succeeds.

```c
#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int a[] = {5, -3, 0, 8, 2};
    int b[8] = {5, -3, 0, 8, 2};
    size_t na = sizeof a / sizeof a[0];
    size_t nb = sizeof b / sizeof b[0];
    size_t zeros = 0;
    for (size_t i = 0; i < nb; ++i) {
        if (b[i] == 0) {
            ++zeros;
        }
    }
    printf("%zu %zu %zu %d\n", na, nb, zeros, b[nb - 1] - a[na - 1]);
    return 0;
}
```

$$
\begin{aligned}
\texttt{sizeof a} &= 5\cdot4=20, &\qquad n_a&=\frac{20}{4}=5,\\[6pt]
\texttt{sizeof b} &= 8\cdot4=32, &\qquad n_b&=\frac{32}{4}=8 .
\end{aligned}
$$

| $i$ | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ | $7$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `b[i]` | $5$ | $-3$ | $0$ | $8$ | $2$ | $0$ | $0$ | $0$ |

```text
5 8 4 -2
```

<div class="spiegazione">

The declaration of `a` gives no size, so the compiler deduces it from the list of five values. For `b` the declared size is $8$ and the list provides five values, so the elements at indices $5$, $6$ and $7$ receive zero. Both divisions appear in the block of the declarations, where `a` and `b` are array objects. Consequently they give the element counts, $5$ and $8$, whatever the value of `sizeof(int)`. The loop visits the eight indices of `b`. The explicit zero at index $2$ and the three zeros from implicit initialization bring `zeros` to $4$. The last element of `b` has index $n_b-1=7$ and holds $0$, while the last element of `a` has index $4$ and holds $2$. The last field is therefore $0-2=-2$. The specifier `%zu` matches the `size_t` type of the first three arguments and `%d` matches the `int` type of the difference.

As a check, compare the two arrays. They hold the same values at the first five indices because the lists coincide. In `a` zero appears once, and the $8-5=3$ extra cells of `b` hold zero, so `b` contains $1+3=4$ zeros.

</div>
