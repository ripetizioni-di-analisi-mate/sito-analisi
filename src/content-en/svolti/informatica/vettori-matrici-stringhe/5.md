## Exercise 1

Find the sum of column index $2$ in the following $4\times3$ matrix. Write a function for a valid column and a variable number of rows, each with three elements.
$$
M=\begin{pmatrix}
7&1&3\\
-1&4&5\\
2&9&-2\\
3&0&4
\end{pmatrix}.
$$

```c
#include <stddef.h>

int column_sum(const int m[][3], size_t rows, size_t c)
{
    int sum = 0;
    for (size_t r = 0; r < rows; ++r) {
        sum += m[r][c];
    }
    return sum;
}
```

$$
\begin{aligned}
S_2&=m[0][2]+m[1][2]+m[2][2]+m[3][2]\\[6pt]
   &=3+5-2+4=10 .
\end{aligned}
$$

<div class="spiegazione">

Declare the input matrix with elements of type `const int`, and have the caller pass the number of initialized rows. The second index stays fixed at $2$, so the loop changes only the row. The values added are $3$, $5$, $-2$ and $4$ in order. The partial sums $3$, $8$, $6$ and $10$ are representable in `int`. A general call requires exactly this condition and a column index less than three.

To check the sum, compute the four row sums, $11$, $8$, $9$ and $7$. The complete matrix therefore sums to $35$. The first two columns sum to $11$ and $14$, respectively, so the third contributes $35-11-14=10$. The check traverses the same matrix by rows and then partitions it by columns.

</div>

## Exercise 2

Transpose the following $2\times4$ matrix into a separate matrix. Give the dimensions of the result and the contents of each row.
$$
M=\begin{pmatrix}
8&0&-2&5\\
4&7&3&1
\end{pmatrix}.
$$

```c
#include <stddef.h>

void transpose(const int m[][4], int t[][2])
{
    for (size_t r = 0; r < 2; ++r) {
        for (size_t c = 0; c < 4; ++c) {
            t[c][r] = m[r][c];
        }
    }
}
```

$$
T=\begin{pmatrix}
8&4\\
0&7\\
-2&3\\
5&1
\end{pmatrix}.
$$

<div class="spiegazione">

In the destination object, the first index equals the second source index. Its values lie in $[0,4)$, giving four rows. The second index comes from a source row, so it ranges over $[0,2)$ and requires two columns. Declare the source as a matrix of `const int` with two initialized rows and the destination as `int t[4][2];`. In particular, the two elements in column $2$ are $-2$ and $3$, so they form row $2$ of the transpose.

To check the result, read columns $0$ and $1$ of the output. The first gives $(8,0,-2,5)$ and the second gives $(4,7,3,1)$. These are exactly the two source rows. The eight index pairs reach eight distinct cells, so every destination cell receives a value.

</div>

## Exercise 3

The following function is meant to transpose a square $3\times3$ matrix in place, swapping `m[r][c]` with `m[c][r]`. Apply it to the matrix $M$, explain why the result equals $M$ and correct the bounds of the inner loop. Give the result of the corrected version.
$$
M=\begin{pmatrix}
2&-1&5\\
0&3&7\\
4&8&-6
\end{pmatrix}.
$$

```c
#include <stddef.h>

void transpose_in_place(int m[][3])
{
    for (size_t r = 0; r < 3; ++r) {
        for (size_t c = 0; c < 3; ++c) {
            int saved = m[r][c];
            m[r][c] = m[c][r];
            m[c][r] = saved;
        }
    }
}
```

The correction starts the inner loop at `c = r + 1`.

```c
#include <stddef.h>

void transpose_in_place(int m[][3])
{
    for (size_t r = 0; r < 3; ++r) {
        for (size_t c = r + 1; c < 3; ++c) {
            int saved = m[r][c];
            m[r][c] = m[c][r];
            m[c][r] = saved;
        }
    }
}
```

$$
T=\begin{pmatrix}
2&0&4\\
-1&3&8\\
5&7&-6
\end{pmatrix}.
$$

<div class="spiegazione">

In the original version each pair of symmetric positions $(r,c)$ and $(c,r)$, with $r\neq c$, is swapped twice. The first swap happens when the outer loop is at $\min(r,c)$, the second when it is at $\max(r,c)$. The second swap returns the two values to their starting positions. For example, with $(r,c)=(0,1)$ the cells `m[0][1]` and `m[1][0]` go from $-1$ and $0$ to $0$ and $-1$, and with $(r,c)=(1,0)$ they return to $-1$ and $0$. The diagonal cells, with $r=c$, are swapped with themselves. Consequently every cell ends with its initial value and the matrix remains $M$. With the inner loop starting at $r+1$, only the positions above the diagonal are visited, namely $(0,1)$, $(0,2)$ and $(1,2)$. Each symmetric pair is therefore swapped exactly once, with $\dfrac{3\cdot2}{2}=3$ swaps. In-place transposition requires a square matrix, because the transpose of an $R\times C$ matrix with $R\neq C$ has shape $C\times R$ and hence a different row type.

As a check, compare the rows of $T$ with the columns of $M$. Column $1$ of $M$ is $(-1,3,8)$ and agrees with row $1$ of $T$. The same holds for columns $0$ and $2$, which give $(2,0,4)$ and $(5,7,-6)$.

</div>
