## Exercise 1

Given `char s[7] = "A\0CD";`, find the capacity, `strlen(s)` and `strlen(&s[2])`. In the last expression the read starts at cell index $2$. Assume `<string.h>` is available.

| $i$ | $0$ | $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `s[i]` | `'A'` | `'\0'` | `'C'` | `'D'` | `'\0'` | `'\0'` | `'\0'` |

$$
\texttt{sizeof s}=7,\quad
\texttt{strlen(s)}=1,\quad
\texttt{strlen(\&s[2])}=2 .
$$

<div class="spiegazione">

The first null, written in the literal with the escape `\0`, lies at index $1$. It is followed by the two visible characters `'C'` and `'D'` and by the null that terminates the literal. The two remaining cells are initialized to zero. Finding the capacity means measuring the full object of seven one-byte cells. The length from index $0$ counts the characters before index $1$. The second length starts at index $2$ and reaches its first null at index $4$.

For verification use the read ranges visible in the table. The range $[0,1)$ contains only `'A'`, so it has length $1$. The range $[2,4)$ contains `'C'` and `'D'`, so it has length $4-2=2$. Both endpoint indices hold zero within the declared capacity.

</div>

## Exercise 2

For `char a[9] = {'u', 'v', '\0', 'w', 'x', '\0', '#', '!', '?'};`, consider a read that starts at index $4$, $5$ or $6$. For each start, determine whether there is a C string within `a`. Where the string is valid, find its length.

$$
\begin{aligned}
[4,5)&\longmapsto \texttt{"x"}, &5-4&=1,\\[6pt]
[5,5)&\longmapsto \texttt{""}, &5-5&=0 .
\end{aligned}
$$

```text
a[6] = '#'
a[7] = '!'
a[8] = '?'
```

<div class="spiegazione">

Starting at index $4$ reaches `'x'` and then the terminator in `a[5]`. The string therefore contains one visible character. Starting at index $5$ reaches the terminator immediately, so the string is empty. After index $5$ there are three characters with nonzero values. After `a[8]` lies the object boundary, so there is no terminator in the read range starting at index $6$.

To check the three cases, list the only indices in the array holding zero, $2$ and $5$. The first null index at or above $4$ is $5$. The same choice applies to start $5$. For start $6$ the set of possible null indices is empty, so no C string length is defined within the object.

</div>
