## Exercise 1

Given `int v[6] = {4, 7, 1, 6, 9, 2};`, calculate the sum of the elements with indices in $[1,4)$.

![Array 4, 7, 1, 6, 9, 2 with indices 0 through 5 and a highlighted range from index 1 to index 3.](/immagini/informatica/vettori-matrici-stringhe/dati-svolto-en.png)

$$
\begin{aligned}
S_1 &= 0,\\[6pt]
S_2 &= S_1+7=7,\\[6pt]
S_3 &= S_2+1=8,\\[6pt]
S_4 &= S_3+6=14 .
\end{aligned}
$$

<div class="spiegazione">

Before reading the element at index $i$, the accumulator $S_i$ holds the sum over $[1,i)$. Initially $S_1=0$ because the range is empty. The loop reads indices $1$, $2$ and $3$, so it adds $7$, $1$ and $6$ in that order. When $i$ reaches $4$, the last addition is complete. The cell at index $4$ holds $9$ and lies at the excluded endpoint, so its value stays out of $S_4$.

As a check, subtract the data outside the segment from the sum of the full array. The total is $4+7+1+6+9+2=29$. The excluded cells have indices $0$, $4$ and $5$ and add up to $4+9+2=15$. The difference $29-15=14$ agrees with the final accumulator.

</div>

## Exercise 2

Given `int a[7] = {-4, 5, 0, -3, 2, -1, 9};`, count the strictly negative elements with indices in $[2,6)$.

$$
\begin{aligned}
(a[2],a[3],a[4],a[5]) &= (0,-3,2,-1),\\[6pt]
\{i\in[2,6)\cap\mathbb Z\mid a[i]<0\} &= \{3,5\},\\[6pt]
N &= 2 .
\end{aligned}
$$

<div class="spiegazione">

The segment contains four indices because $6-2=4$. The zero at index $2$ leaves the count unchanged because the inequality is strict. The value $-3$ at index $3$ raises the count from $0$ to $1$. After the positive value $2$, the value $-1$ at index $5$ adds the second unit. Each index is visited once, so the final number agrees with the cardinality of the chosen set.

To check the result, count negatives in the prefixes $[0,6)$ and $[0,2)$. The first contains $-4$, $-3$ and $-1$, while the second contains only $-4$. Subtracting the two counts gives $3-1=2$, as required for the segment.

</div>

## Exercise 3

The following function returns the maximum sum over the segments $[i,i+w)$ of length $w$ of an array of $n$ initialized elements, with $1\leq w\leq n$. Every partial sum and every difference `a[i] - a[i - w]` is representable in `int`. Find the value returned for `int a[8] = {3, -1, 4, 1, -5, 9, 4, -6};` with $n=8$ and $w=3$, giving the sum of each segment.

```c
#include <stddef.h>

int max_window_sum(const int a[], size_t n, size_t w)
{
    int sum = 0;
    for (size_t i = 0; i < w; ++i) {
        sum += a[i];
    }
    int best = sum;
    for (size_t i = w; i < n; ++i) {
        sum += a[i] - a[i - w];
        if (sum > best) {
            best = sum;
        }
    }
    return best;
}
```

| $i$ | `a[i]` | `a[i - w]` | segment | `sum` | `best` |
| --- | ---: | ---: | --- | ---: | ---: |
| initial | | | $[0,3)$ | $6$ | $6$ |
| $3$ | $1$ | $3$ | $[1,4)$ | $4$ | $6$ |
| $4$ | $-5$ | $-1$ | $[2,5)$ | $0$ | $6$ |
| $5$ | $9$ | $4$ | $[3,6)$ | $5$ | $6$ |
| $6$ | $4$ | $1$ | $[4,7)$ | $8$ | $8$ |
| $7$ | $-6$ | $-5$ | $[5,8)$ | $7$ | $8$ |

The function returns $8$, the sum of the segment $[4,7)$.

<div class="spiegazione">

The first loop adds the elements with indices in $[0,3)$, so `sum` is $3-1+4=6$ and this value initializes `best`. On entry to the iteration of the second loop with index $i$, `sum` holds the sum over $[i-w,i)$. The next segment $[i-w+1,i+1)$ gains the element at index $i$ and loses the one at index $i-w$. Therefore the update `sum += a[i] - a[i - w]` preserves the invariant with a single new cell per iteration. The loop starts at $i=w$, so the subtraction `i - w` between `size_t` values never goes below zero and gives a valid index. The strict comparison changes `best` only for $i=6$, where the sum is $-5+9+4=8$. The last segment $[5,8)$ has excluded endpoint $n=8$, so the loop examines all $n-w+1=6$ segments.

As a check, recompute two rows of the table directly. The segment $[3,6)$ contains $1$, $-5$ and $9$, with sum $5$, while the segment $[5,8)$ contains $9$, $4$ and $-6$, with sum $7$. None of the six sums exceeds $8$.

</div>
