## Exercise 1

Given `int v[6] = {4, 7, 1, 6, 9, 2};`, calculate the sum of the elements with indices in $[1,4)$.

![Array 4, 7, 1, 6, 9, 2 with indices 0 through 5 and a highlighted range from index 1 to index 3.](/immagini/informatica/vettori-matrici-stringhe/dati-svolto-en.png)

$$
\begin{aligned}
S_1 &= 0,\\[6pt]
S_2 &= S_1+7=7,\\[6pt]
S_3 &= S_2+1=8,\\[6pt]
S_4 &= S_3+6=14 .
\end{aligned}
$$

<div class="spiegazione">

Before reading the element at index $i$, the accumulator $S_i$ holds the sum over $[1,i)$. Initially $S_1=0$ because the range is empty. The loop reads indices $1$, $2$ and $3$, so it adds $7$, $1$ and $6$ in that order. When $i$ reaches $4$, the last addition is complete. The cell at index $4$ holds $9$ and lies at the excluded endpoint, so its value stays out of $S_4$.

As a check, subtract the data outside the segment from the sum of the full array. The total is $4+7+1+6+9+2=29$. The excluded cells have indices $0$, $4$ and $5$ and add up to $4+9+2=15$. The difference $29-15=14$ agrees with the final accumulator.

</div>

## Exercise 2

Given `int a[7] = {-4, 5, 0, -3, 2, -1, 9};`, count the strictly negative elements with indices in $[2,6)$.

$$
\begin{aligned}
(a[2],a[3],a[4],a[5]) &= (0,-3,2,-1),\\[6pt]
\{i\in[2,6)\cap\mathbb Z\mid a[i]<0\} &= \{3,5\},\\[6pt]
N &= 2 .
\end{aligned}
$$

<div class="spiegazione">

The segment contains four indices because $6-2=4$. The zero at index $2$ leaves the count unchanged because the inequality is strict. The value $-3$ at index $3$ raises the count from $0$ to $1$. After the positive value $2$, the value $-1$ at index $5$ adds the second unit. Each index is visited once, so the final number agrees with the cardinality of the chosen set.

To check the result, count negatives in the prefixes $[0,6)$ and $[0,2)$. The first contains $-4$, $-3$ and $-1$, while the second contains only $-4$. Subtracting the two counts gives $3-1=2$, as required for the segment.

</div>
