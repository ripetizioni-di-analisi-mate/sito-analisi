## Exercise 1

Copy the text `"tattica"` into a separate array, removing every `'t'` and preserving the order of the other characters. Write a fragment that produces a valid C string even if all characters are removed.

```c
char s[] = "tattica";
char out[sizeof s];
size_t k = 0;

for (size_t i = 0; s[i] != '\0'; ++i) {
    if (s[i] != 't') {
        out[k] = s[i];
        ++k;
    }
}
out[k] = '\0';
```

$$
(i_0,i_1,i_2,i_3)=(1,4,5,6),\qquad k=4 .
$$

```text
aica
```

<div class="spiegazione">

The fragment uses `size_t` from `<stddef.h>`. The array `s` measures eight C bytes because it holds seven visible characters and a null. The same capacity is therefore sufficient for the output. The loop reads all seven characters and skips `'t'` at indices $0$, $2$ and $3$. It writes the other cells to successive output indices $0$, $1$, $2$ and $3$. After the last write, $k=4$. The null goes into `out[4]`, giving `"aica"`. If every character is removed, $k$ stays at zero and the null is written to the first cell.

To check, select the input characters directly at indices $1$, $4$, $5$ and $6$. They are `'a'`, `'i'`, `'c'` and `'a'`, respectively. The count $7-3=4$ matches $k$, so the solution preserves exactly the required characters.

</div>

## Exercise 2

Design a method for counting occurrences, including overlaps, of a nonempty string `p` in a string `s`. Apply it to `"abababa"` and `"aba"` and give the starting indices of the occurrences.

```c
#include <stddef.h>
#include <string.h>

size_t occurrences(const char s[], const char p[])
{
    size_t n = strlen(s);
    size_t m = strlen(p);
    if (m == 0 || m > n) {
        return 0;
    }
    size_t count = 0;
    for (size_t i = 0; i <= n - m; ++i) {
        if (strncmp(s + i, p, m) == 0) {
            ++count;
        }
    }
    return count;
}
```

$$
7-3=4,\qquad
\{i\mid\texttt{s[i..i+3)}=\texttt{"aba"}\}
 =\{0,2,4\},\qquad N=3 .
$$

<div class="spiegazione">

Both arguments must be valid C strings. Compute the length of each once. If the pattern is longer than the text, every start would be outside the valid range, so the function returns zero before the subtraction. With these data the last possible start is $4$. Compare three characters at each start. The five trials read `"aba"`, `"bab"`, `"aba"`, `"bab"` and `"aba"` in order. Advancing by one position after each comparison preserves occurrences that share characters.

To check the result without repeating the comparisons, observe that the text alternates `'a'` and `'b'`, starting with `'a'`. An occurrence of `"aba"` must therefore start at an even index and have two more characters available. The only even indices in $[0,5)$ are $0$, $2$ and $4$. There are therefore $3$ occurrences.

</div>
