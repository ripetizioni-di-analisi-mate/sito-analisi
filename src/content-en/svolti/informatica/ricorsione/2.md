## Exercise 1

Prove that `reduce` terminates on $0\leq n\leq63$ and find how many recursive transitions occur starting from $11$.

```c
unsigned reduce(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    if (n % 2u == 0u) {
        return 1u + reduce(n / 2u);
    }
    return 1u + reduce(n - 1u);
}
```

$$
11 \longrightarrow 10 \longrightarrow 5 \longrightarrow 4
\longrightarrow 2 \longrightarrow 1 \longrightarrow 0.
$$

There are six transitions.

<div class="spiegazione">

Use $n$ as the measure. In the even branch with $n>0$, the quotient `n / 2` is smaller than $n$ and stays nonnegative. In the odd branch, the function subtracts one only after the base test, so the new argument also remains in the domain and decreases. The termination criterion applies to both branches. The return value counts transitions because the base counts zero and each inner level adds one.

To check, the reductions from odd arguments are $11\to10$, $5\to4$ and $1\to0$. The divisions are $10\to5$, $4\to2$ and $2\to1$. The two groups give $3+3=6$ steps.

</div>

## Exercise 2

In the logical call model, find all initial arguments in $\{0,1,2,3,4,5\}$ for which `hold` reaches the base branch.

```c
unsigned hold(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return hold(n - n % 2u);
}
```

| Initial argument | Evolution |
|---:|---|
| $0$ | immediate base case |
| $1$ | moves to $0$ |
| $2$, $4$ | the new argument equals the current one |
| $3$, $5$ | move to $2$, $4$, respectively |

Only $0$ and $1$ reach the base.

<div class="spiegazione">

The remainder on division by two is zero for even values and one for odd values. For a positive even input, subtraction leaves that same value and the trace repeats it. For an odd input greater than one, the first subtraction reaches a positive even value, so the same case applies. The input $1$ reaches zero exactly.

To check, the expression `n - n % 2u` produces the greatest even value at most $n$. This value is zero only for $0$ and $1$. For any other argument in the set, it is a positive even value and remains fixed.

</div>
