## Exercise 1

Compute the result of `product(4)` and the number of logical invocations, including the initial and base calls. The function domain is $0\leq n\leq8$.

![Initial call product(4), step product(n−1) for positive n, base n=0 with result 1.](/immagini/informatica/ricorsione/dati-svolto-en.png)

```c
unsigned long product(unsigned n)
{
    if (n == 0u) {
        return 1ul;
    }
    return n * product(n - 1u);
}
```

| Argument | Result on return |
|---:|---:|
| $0$ | $1$ |
| $1$ | $1$ |
| $2$ | $2$ |
| $3$ | $6$ |
| $4$ | $24$ |

The function returns $24$ after five logical invocations.

<div class="spiegazione">

The call with $n=4$ asks for the product through $3$. Each successive positive call does the same for its own argument, so the base $0$ is reached after four decrements. The base returns the multiplicative identity. On the way back, each caller multiplies the received result by its own $n$. The initial call, the three inner positive arguments and the base give five invocations.

The direct product $4\cdot3\cdot2\cdot1=24$ confirms the result. The largest product on the domain is $40320$, so the intermediate products are representable in `unsigned long`.

</div>

## Exercise 2

On the domain $0\leq n\leq20$, find the base-case argument and the total result for `unfold(7)`.

```c
unsigned unfold(unsigned n)
{
    if (n <= 2u) {
        return n;
    }
    return 3u + unfold(n - 2u);
}
```

$$
\begin{aligned}
\text{arguments} &:\quad 7,\ 5,\ 3,\ 1\\[6pt]
\text{return value} &= 3+(3+(3+1))=10 .
\end{aligned}
$$

<div class="spiegazione">

Each step decreases the argument by two and preserves its parity. Starting from an odd number, the first reachable base is $1$. The function then returns the argument, namely one. Each of the three invocations with an argument greater than $2$ adds three to the result it receives.

To check, count the subtractions from $7$ to $1$. The difference is $6$, so there are three steps of two. The return value is $1+3\cdot3=10$. This check uses the number of steps and confirms the reconstruction one call at a time.

</div>
