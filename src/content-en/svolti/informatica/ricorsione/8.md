## Exercise 1

Translate the function into an equivalent loop and check the result of `tally(5, 2)`. The domain satisfies $0\leq n\leq20$ and $d+\dfrac{n(n+1)}{2}\leq65535$, where $d$ is the value of `done`.
```c
unsigned tally(unsigned n, unsigned done)
{
    if (n == 0u) {
        return done;
    }
    return tally(n - 1u, done + n);
}
```

```c
unsigned tally_loop(unsigned n, unsigned done)
{
    while (n != 0u) {
        done += n;
        n -= 1u;
    }
    return done;
}
```

Argument $5$ increases the accumulator from $2$ to $17$.

<div class="spiegazione">

Each call transfers the pair $(n-1,d+n)$. In the loop the old $n$ is added to `done` before $n$ decreases, so the same pair is formed. The inner call’s return value is also the caller’s result, so the loop needs only a single current pair. The invariant $d+\dfrac{n(n+1)}{2}$ stays constant and shows that C addition remains representable.

As a check, initially the invariant is $2+\dfrac{5\cdot6}{2}=17$. At the end, $n=0$, so the invariant is the value of `done`. Both forms return $17$.

</div>

## Exercise 2

To calculate the greatest common divisor, each step must transform $(a,b)$ into $(b,a\bmod b)$ while $b>0$. Analyse the following loop with $a=35$ and $b=15$. Find its actual result, then give the corrected body and check the intended result.
```c
unsigned wrong_gcd(unsigned a, unsigned b)
{
    while (b != 0u) {
        a = b;
        b = a % b;
    }
    return a;
}
```

The given loop goes from $(35,15)$ to $(15,0)$ and returns $15$. The corrected body keeps the remainder before assigning the new parameters.

```c
unsigned fixed_gcd(unsigned a, unsigned b)
{
    while (b != 0u) {
        unsigned rest = a % b;
        a = b;
        b = rest;
    }
    return a;
}
```

The correct path is $(35,15)$, $(15,5)$, $(5,0)$ and the result is $5$.

<div class="spiegazione">

In the first body, `a = b` makes the two values equal before the remainder is calculated, so the remainder becomes zero on the first step. In Euclid’s recursive call, both new arguments come from the caller’s pair. Variable `rest` keeps the value calculated from the old pair and lets the loop reproduce that state.

To check, $5$ divides $35$ and $15$. Also, $35-2\cdot15=5$, so any common divisor divides $5$ as well. The corrected value is therefore the greatest common divisor.

</div>
