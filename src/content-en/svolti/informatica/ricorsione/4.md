## Exercise 1

Prove that, for $0\leq n\leq10$, `squares(n)` returns $\dfrac{n(n+1)(2n+1)}{6}$.
```c
unsigned squares(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return n * n + squares(n - 1u);
}
```

For $n=0$, both the returned value and the formula give zero. For $n\geq1$, apply the induction hypothesis to the call with argument $n-1$.

$$
\begin{aligned}
n^2+\frac{(n-1)n(2n-1)}{6}
 &= \frac{n((n-1)(2n-1)+6n)}{6}\\[6pt]
 &= \frac{n(2n^2+3n+1)}{6}\\[6pt]
 &= \frac{n(n+1)(2n+1)}{6} .
\end{aligned}
$$

<div class="spiegazione">

The measure $n$ decreases on every call with positive argument. Each square is at most $100$, and the total can be bounded even without the formula because there are at most ten terms. The bound $1000$ suffices to ensure the C computations are representable. The induction hypothesis applies the formula to the smaller problem. Adding $n^2$ gives exactly the new value proved by the identity.

To check a case distinct from the base, with $n=4$ the direct sum is $1+4+9+16=30$. The formula gives $\dfrac{4\cdot5\cdot9}{6}=30$.

</div>

## Exercise 2

Find and prove a formula for the result of `odd_sum(n)` on $0\leq n\leq20$.
```c
unsigned odd_sum(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return (2u * n - 1u) + odd_sum(n - 1u);
}
```

The formula is $n^2$. In the base case, the function returns $0$. If the formula holds at argument $n-1$, then

$$
(2n-1)+(n-1)^2=n^2 .
$$

<div class="spiegazione">

For every $n\geq1$, `2u * n - 1u` generates the next odd integer. At $n=0$ the function returns before subtraction, so subtraction stays nonnegative on the domain. The call uses the preceding argument and reaches the base. The sums are representable because there are at most twenty terms, each at most $39$. The difference of two consecutive squares exactly matches the term in the code, so the induction step preserves the formula.

As a check, for $n=5$ the sum $1+3+5+7+9=25$ agrees with $5^2$.

</div>

## Exercise 3

Prove that, for $0\leq n\leq40$, `stride_sum(n)` returns
$$
f(n)=\begin{cases}
m(m+1) & \text{if } n=2m,\\[4pt]
(m+1)^2 & \text{if } n=2m+1.
\end{cases}
$$
```c
unsigned stride_sum(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    return n + stride_sum(n - 2u);
}
```

For $n=0$ and $n=1$ the function returns $n$, and the formula gives $0\cdot1=0$ and $1^2=1$. For $n\geq2$, apply the induction hypothesis to the argument $n-2$, which has the same parity as $n$.

$$
\begin{aligned}
\text{for } n=2m,\ m\geq1 &\qquad 2m+(m-1)m=m^2+m=m(m+1)\\[6pt]
\text{for } n=2m+1,\ m\geq1 &\qquad (2m+1)+m^2=(m+1)^2 .
\end{aligned}
$$

<div class="spiegazione">

The inner call reduces the argument by two, so the induction step uses the formula at argument $n-2$. The proof therefore proceeds by **strong induction**, with the two base cases $0$ and $1$. The test `n <= 1u` catches both base cases, so the subtraction `n - 2u` happens only for $n\geq2$ and always gives a natural result. With the test `n == 0u` alone, the argument $1$ would produce `1u - 2u`, which equals `UINT_MAX` by the modular arithmetic of unsigned integers.

If $n=2m$ with $m\geq1$, the argument $n-2=2(m-1)$ is even and the induction hypothesis gives $(m-1)m$. Adding $2m$ gives $m(m+1)$. If $n=2m+1$ with $m\geq1$, the argument $n-2=2(m-1)+1$ is odd and the hypothesis gives $m^2$. Adding $2m+1$ gives $(m+1)^2$. In both cases the returned value equals $f(n)$.

The measure $n$ decreases by two on every call and stays nonnegative, so the function terminates. The largest value on the domain is $f(40)=20\cdot21=420$, so the sums are representable in `unsigned`. As a check, `stride_sum(7)` adds $7+5+3+1=16$, which equals $(3+1)^2$.

</div>
