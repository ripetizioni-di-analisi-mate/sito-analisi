## Exercise 1

For `score(3)`, give the arguments in launch order and calculate the final result. Assume $0\leq n\leq8$.
```c
unsigned score(unsigned n)
{
    if (n <= 1u) {
        return n + 1u;
    }
    unsigned first = score(n - 2u);
    unsigned second = score(n - 1u);
    return first + second;
}
```

The order is $3$, $1$, $2$, $0$, $1$. The two results received by the root are $2$ and $3$, so the initial call returns $5$.

<div class="spiegazione">

The initializer for `first` starts the call with argument $1$ and completes it before the next initializer. The call with $2$ in turn starts the base cases $0$ and $1$, in that order. The base values are $1$ for argument zero and $2$ for argument one. The call with $2$ therefore returns $3$, and the root adds the $2$ that its record retained.

To check, add only the leaf values. The leaf arguments in order are $1$, $0$, $1$, and each inner node adds its children’s results. The leaf total is $2+1+2=5$.

</div>

## Exercise 2

For `split(3)`, find the permitted arguments for the first call started by the root and compute the result. The domain is $0\leq n\leq8$.
```c
unsigned split(unsigned n)
{
    if (n <= 1u) {
        return 1u;
    }
    return split(n - 1u) + split(n - 2u);
}
```

The first child may have argument $2$ or $1$. In either case the result is $3$.

<div class="spiegazione">

The two operands of `+` correspond to the call with argument $2$ and the one with argument $1$. C17 permits either to be evaluated first. The call with $1$ returns one. The call with $2$ adds the results of its two base cases and returns two. The two subtrees are independent, so both orders give the sum $2+1$.

To check, count the leaves. The child with argument $2$ has two leaves, and the child with argument $1$ is a leaf. Every leaf contributes one, so the result is the total leaf count.

</div>
