## Exercise 1

The input contains the line `185`. Find `read`, the characters written and `written`. Assume successful input and output. The fragment uses `<stdio.h>`.
```c
int seconds = 0;
int read = scanf("%d", &seconds);
int minutes = seconds / 60;
int rest = seconds % 60;
int written = printf("%d:%02d", minutes, rest);
```

$$
185=60\cdot3+5,\qquad 0\leq5<60 .
$$

`read` is $1$, `written` is $4$ and the output is `3:05`.

<div class="spiegazione">

`%d` reads $185$ into `seconds`. It records one assignment. Division by $60$ has two `int` operands and gives the number of whole minutes. The remainder of $5$ is the part still expressed in seconds. The first output field uses the ordinary decimal specification. The second has a minimum width of $2$ and zero padding. Since $5$ takes one position, it is written as `05`.

To check the values, reconstruct the original measurement from the output text. Three minutes and five seconds give $3\cdot60+5=185$ seconds. The string has one digit for minutes, one separator and two digits for seconds. The sum $1+1+2=4$ verifies the value returned by `printf`.

</div>

## Exercise 2

The input contains the line `033`. Find `read`, the characters written and `written`. Assume a C17 Annex F implementation in round-to-nearest mode, the C numeric locale and successful input and output. The fragment uses `<stdio.h>`.
```c
int units = 0;
int read = scanf("%i", &units);
unsigned int whole = (unsigned int)(units / 4);
double exact = (double)units / 4;
int written = printf("%u %.2f", whole, exact);
```

$$
\begin{aligned}
(33)_8 &= 3\cdot8+3=27,\\[6pt]
27 &=4\cdot6+3,\\[6pt]
\dfrac{27}{4} &=6+\dfrac{3}{4}=6.75 .
\end{aligned}
$$

`read` is $1$, `written` is $6$ and the output is `6 6.75`.

<div class="spiegazione">

The `%i` specification reads an integer by detecting its base. The leading zero selects base eight, so the two digits `33` give $27$ and the function performs one assignment. For the first field, division takes place between `int` operands. The operand of the cast is the quotient $6$, which is representable in `unsigned int`. For the second field the cast converts `units` before division. The arithmetic conversion makes the divisor `double`, so the fractional contribution of three quarters is retained.

Check the second field by multiplying $6.75$ by $4$ to obtain $27$. The integer part $6$ is consistent with $24\leq 27<28$. The format uses one digit for the first field, one space and four characters for the second. The count is $1+1+4=6$.

</div>
