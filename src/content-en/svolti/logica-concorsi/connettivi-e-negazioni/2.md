## Exercise 1

Proposition $A$ is true and proposition $B$ is false. Which of the following propositions is true?

- A) $A$ and $B$
- B) if $A$ then $B$
- C) $A$ or $B$
- D) not $A$ and not $B$
- E) $A$ if and only if $B$

| connective | value when $A$ = T and $B$ = F |
| --- | --- |
| $A \land B$ | F |
| $A \Rightarrow B$ | F |
| $A \lor B$ | T |
| $\lnot A \land \lnot B$ | F |
| $A \Leftrightarrow B$ | F |

<div class="spiegazione">

Use row TF of each truth table. The **disjunction** $A \lor B$ is true when at least one of the two propositions is true, and $A$ is true, so $A \lor B$ is true. The conjunction is true only when both are true, so it is false. The implication is false precisely when its antecedent is true and its consequent is false. The biconditional is false because $A$ and $B$ have different values, and $\lnot A \land \lnot B$ is false because $\lnot A$ is false. The correct answer is **C**.

</div>

## Exercise 2

The statement "If Lucia is in a meeting, then she answers the phone" is false. Which of the following statements must be true?

- A) Lucia is in a meeting and does not answer the phone
- B) Lucia is not in a meeting and answers the phone
- C) Lucia is in a meeting and answers the phone
- D) Lucia is not in a meeting
- E) Lucia answers the phone or is not in a meeting

| $R$ | $T$ | $R \Rightarrow T$ |
| --- | --- | --- |
| T | T | T |
| T | F | **F** |
| F | T | T |
| F | F | T |

<div class="spiegazione">

Let $R$ = "Lucia is in a meeting" and $T$ = "Lucia answers the phone." An **implication** is false in only one case, when its antecedent is true and its consequent is false, so $R$ is true and $T$ is false. Therefore Lucia is in a meeting and does not answer the phone. Option D contradicts the fact that $R$ is true. Option E is $\lnot R \lor T$, which is equivalent to the original implication and is therefore false. The correct answer is **A**.

</div>

## Exercise 3

At an office today, Paola is present, Quirino is absent, and Rita is present. Let $P$ = "Paola is present," $Q$ = "Quirino is present," and $R$ = "Rita is present." Which of the following propositions is false?

- A) $(P \lor Q) \land R$
- B) $Q \Rightarrow \lnot R$
- C) $\lnot Q \land R$
- D) $P \Leftrightarrow R$
- E) $(P \lor R) \Rightarrow Q$

$$
P = \text{T}, \qquad Q = \text{F}, \qquad R = \text{T}
$$
$$
\begin{aligned}
(P \lor Q) \land R &= \text{T} \land \text{T} = \text{T} \\[4pt]
Q \Rightarrow \lnot R &= \text{F} \Rightarrow \text{F} = \text{T} \\[4pt]
\lnot Q \land R &= \text{T} \land \text{T} = \text{T} \\[4pt]
P \Leftrightarrow R &= \text{T} \Leftrightarrow \text{T} = \text{T} \\[4pt]
(P \lor R) \Rightarrow Q &= \text{T} \Rightarrow \text{F} = \text{F}
\end{aligned}
$$

<div class="spiegazione">

Substitute the truth values and evaluate the innermost expressions first. In option E the antecedent $P \lor R$ is true because Paola is present, and the consequent $Q$ is false, so the **implication** is false. Option B has a false antecedent $Q$, so it is true regardless of its consequent. Choosing B overlooks the fact that an implication with a false antecedent is true. Option D is true because $P$ and $R$ are both true. The correct answer is **E**.

</div>
