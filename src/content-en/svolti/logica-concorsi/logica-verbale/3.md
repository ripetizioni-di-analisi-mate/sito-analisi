## Exercise 1

Petal is to flower as … is to tree.

- A) leaf
- B) forest
- C) gardener
- D) shade
- E) prune

| connecting sentence | with the option | true? |
| --- | --- | --- |
| a petal is part of a flower | a leaf is part of a tree | yes |
|  | a forest is part of a tree | no |
|  | a gardener is part of a tree | no |
|  | shade is part of a tree | no |
|  | pruning is part of a tree | no |

<div class="spiegazione">

A petal is part of a flower, so the relationship is **part and whole**, with the part first. The missing word must therefore be part of a tree, namely a *leaf*. Option B appeals to anyone who recognizes the relationship without checking its direction: a tree is part of a forest, so the connecting sentence with “forest” reverses the part and the whole. Shade is an effect produced by the tree. The gardener is the person who tends the tree, and the verb “prune” names an activity involving it. The correct answer is **A**.

</div>

## Exercise 2

Find the pair of words that completes the analogy: … is to bread as tailor is to ….

- A) flour – fabric
- B) baker – needle
- C) bakery – tailor’s shop
- D) baker – garment
- E) oven – sewing machine

| option | first pair | second pair | same type? |
| --- | --- | --- | --- |
| A | material and product | person and material | no |
| B | person and product | person and tool | no |
| C | place and product | person and place | no |
| D | person and product | person and product | yes |
| E | tool and product | person and tool | no |

<div class="spiegazione">

When two words are missing, each option forms two pairs, and both must have the same relationship. In option D, the baker makes bread and the tailor makes a garment, so each pair consists of a person and the product of that person’s work. In option B, the first word is correct, but the tailor uses a needle to work, so the second pair expresses **person and tool**. Options A and E form meaningful pairs, such as “Flour is used to make bread,” but the two pairs within each option have different relationships. The correct answer is **D**.

</div>

## Exercise 3

Training is to endurance as studying is to:

- A) book
- B) exam
- C) school
- D) teacher
- E) knowledge

| connecting sentence | with the option | does it complete the sentence? |
| --- | --- | --- |
| training increases endurance | studying increases knowledge | yes |
|  | studying increases the exam | no |
|  | studying increases the book | no |
|  | studying increases the school | no |
|  | studying increases the teacher | no |

<div class="spiegazione">

The connecting sentence “Training is useful for endurance” is too general, because studying is also useful for an exam. With the **precise sentence** “Training increases endurance,” the relationship is cause and effect, and the effect is a quality that increases. The second sentence becomes “Studying increases …”, which only *knowledge* completes. Option B would correspond to a first pair such as “training is to competition,” in which the second word denotes the event one prepares for. The correct answer is **E**.

</div>
