## Exercise 1

Which figure completes the matrix?

::figura{tipo="matrice" celle="cerchio piccolo x1 | quadrato piccolo x2 | triangolo piccolo x3 | quadrato piccolo x1 | triangolo piccolo x2 | cerchio piccolo x3 | triangolo piccolo x1 | cerchio piccolo x2 | ?"}

::figura{tipo="opzioni" celle="quadrato piccolo x2 | quadrato piccolo x3 | cerchio piccolo x3 | triangolo piccolo x3 | quadrato piccolo pieno x3"}

- A) figure A
- B) figure B
- C) figure C
- D) figure D
- E) figure E

| row | first column | second column | third column |
| --- | --- | --- | --- |
| 1 | circle | square | triangle |
| 2 | square | triangle | circle |
| 3 | triangle | circle | square |
| number of figures | $1$ | $2$ | $3$ |

<div class="spiegazione">

Each row contains one circle, one square, and one triangle. The third row already has the triangle and the circle, so the missing cell contains squares by the **three values in each row** rule. The number of figures depends only on the column: $1$ in the first column, $2$ in the second, and $3$ in the third. Therefore, the missing cell contains three unfilled squares. Figures C and D have the correct number but the wrong shape. Figure A has the correct shape but the wrong number, and figure E changes the fill, which is always unfilled in the matrix. The correct answer is **B**.

</div>

## Exercise 2

A floor has three rows of tiles laid in a pattern, and one tile has come loose. Which tile belongs in the position marked with a question mark?

::figura{tipo="matrice" celle="freccia | freccia r90 | freccia r180 | freccia grigio r90 | freccia grigio r180 | freccia grigio r-90 | freccia pieno r180 | freccia pieno r-90 | ?" titolo="The nine floor tiles"}

::figura{tipo="opzioni" celle="freccia pieno r90 | freccia grigio | freccia pieno r180 | freccia pieno r-90 | freccia pieno"}

- A) figure A
- B) figure B
- C) figure C
- D) figure D
- E) figure E

| row | fill | orientations from left to right |
| --- | --- | --- |
| 1 | unfilled | up, right, down |
| 2 | gray | right, down, left |
| 3 | solid | down, left, ? |

<div class="spiegazione">

Within each row the fill stays the same: unfilled in the first, gray in the second, and solid in the third. Between adjacent tiles in the same row the arrow undergoes a clockwise **rotation** through $90°$. In the third row the arrow points down and then left. Another clockwise rotation through $90°$ therefore makes it point up in the missing tile. The same rule holds down the columns, because moving down a row also rotates the arrow through $90°$ clockwise. Thus the missing tile contains a solid arrow pointing up. Figure D repeats the preceding cell, C rotates in the wrong direction, A rotates through $180°$, and B has the fill of the second row. The correct answer is **E**.

</div>

## Exercise 3

Which figure completes the matrix?

::figura{tipo="matrice" celle="triangolo piccolo x1 | triangolo piccolo x2 | triangolo piccolo x3 | quadrato piccolo x2 | quadrato piccolo x2 | quadrato piccolo x4 | cerchio piccolo x3 | cerchio piccolo x2 | ?"}

::figura{tipo="opzioni" celle="cerchio piccolo x5 | cerchio piccolo x4 | cerchio piccolo x6 | quadrato piccolo x5 | cerchio piccolo x1"}

- A) figure A
- B) figure B
- C) figure C
- D) figure D
- E) figure E

$$
1 + 2 = 3,
\qquad
2 + 2 = 4,
\qquad
3 + 2 = 5
$$

<div class="spiegazione">

The shape stays the same within each row, so the missing cell contains circles. The first row has $1$, $2$, and $3$ triangles, and the second has $2$, $2$, and $4$ squares. In both rows the count in the third cell is the **sum** of the counts in the first two, so in the third row the number of circles is $3 + 2 = 5$. Figure C comes from the product $3 \cdot 2 = 6$, which in the first row would give $2$ instead of $3$. Figure E comes from the difference $3 - 2 = 1$, which in the first row would give $1$ instead of $3$. Figure B continues the second row with the number $4$. The correct answer is **A**.

</div>
