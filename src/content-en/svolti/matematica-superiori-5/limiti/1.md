## Exercise 1

Use the definition to verify that $\displaystyle\lim_{x \to 2} (3x - 1) = 5$, and find $\delta$ when $\varepsilon = 0.3$.

$$
|f(x) - 5| < \varepsilon
\iff
|3x - 6| < \varepsilon
\iff
3\,|x - 2| < \varepsilon
\iff
|x - 2| < \frac{\varepsilon}{3}
$$
$$
\delta = \frac{\varepsilon}{3},
\qquad
\varepsilon = 0.3
\quad \Longrightarrow \quad
\delta = 0.1
$$

::grafico{f="3*x-1" area="5.3;4.7;1.9;2.1" segmenti="0,5.3,2.1,5.3;0,4.7,1.9,4.7;1.9,0,1.9,4.7;2.1,0,2.1,5.3" punti="2,5,pieno" xmin=0 xmax=3 ymin=-1 ymax=7 legenda="y = 3x - 1" titolo="For $1.9 < x < 2.1$ the graph of $y = 3x - 1$ lies in the strip $4.7 < y < 5.3$, so $\delta = 0.1$ corresponds to $\varepsilon = 0.3$"}

<div class="spiegazione">

To verify the limit, start with the condition on the function values, $|f(x) - 5| < \varepsilon$, and solve it for $x$. The difference $3x - 1 - 5$ equals $3x - 6$, or $3\,(x - 2)$, and the absolute value of a product is the product of the absolute values. Dividing by $3$ gives $|x - 2| < \dfrac{\varepsilon}{3}$.

The solutions form the symmetric neighborhood of $2$ of radius $\dfrac{\varepsilon}{3}$, so for every $\varepsilon > 0$ the number $\delta = \dfrac{\varepsilon}{3}$ satisfies the **definition of a limit**, and the limit is **verified**. With $\varepsilon = 0.3$ we obtain $\delta = 0.1$, so for every $x$ between $1.9$ and $2.1$ the value $3x - 1$ lies between $4.7$ and $5.3$.

</div>

## Exercise 2

Use the definition to verify that $\displaystyle\lim_{x \to 2} x^2 = 4$.

$$
|x^2 - 4| < \varepsilon
\iff
4 - \varepsilon < x^2 < 4 + \varepsilon
$$
$$
\text{for } 0 < \varepsilon < 4 \text{ and } x > 0:
\qquad
\sqrt{4 - \varepsilon} < x < \sqrt{4 + \varepsilon}
$$
$$
\sqrt{4 - \varepsilon} < 2 < \sqrt{4 + \varepsilon}
$$

<div class="spiegazione">

The inequality $|x^2 - 4| < \varepsilon$ is equivalent to the compound inequality $4 - \varepsilon < x^2 < 4 + \varepsilon$. It is enough to consider a small $\varepsilon$ with $0 < \varepsilon < 4$, because a neighborhood that works for a given $\varepsilon$ also works for all larger $\varepsilon$. Then $4 - \varepsilon$ is positive, and for positive $x$, taking square roots gives $\sqrt{4 - \varepsilon} < x < \sqrt{4 + \varepsilon}$.

Since $4 - \varepsilon < 4 < 4 + \varepsilon$, we have $\sqrt{4 - \varepsilon} < 2 < \sqrt{4 + \varepsilon}$. The solution interval is therefore a **neighborhood** of $2$, although it is not symmetric about that point because $2$ is not its midpoint. For every $\varepsilon$ there is thus a neighborhood of $2$ in which $|x^2 - 4| < \varepsilon$, and the limit is **verified**. For example, with $\varepsilon = 0.41$ the neighborhood is $(\sqrt{3.59};\ \sqrt{4.41})$, and $\sqrt{4.41} = 2.1$.

</div>

## Exercise 3

Use the definition to verify that $\displaystyle\lim_{x \to +\infty} \frac{3x - 2}{x + 1} = 3$, and find how large $x$ must be for the function to differ from $3$ by less than $0.1$.

$$
\frac{3x - 2}{x + 1} - 3 = \frac{3x - 2 - 3x - 3}{x + 1} = -\frac{5}{x + 1}
$$
$$
\text{for } x > -1:
\qquad
\left| -\frac{5}{x + 1} \right| < \varepsilon
\iff
\frac{5}{x + 1} < \varepsilon
\iff
x + 1 > \frac{5}{\varepsilon}
\iff
x > \frac{5}{\varepsilon} - 1
$$
$$
\varepsilon = 0.1
\quad \Longrightarrow \quad
x > 50 - 1 = 49
$$

<div class="spiegazione">

First find the difference between the function and its limit using a common denominator. This leaves $-5$ in the numerator. For $x \to +\infty$ we are concerned with large values of $x$, so we can assume $x > -1$. In this case $x + 1$ is positive, and the absolute value of $-\dfrac{5}{x + 1}$ is $\dfrac{5}{x + 1}$.

Solve the inequality $\dfrac{5}{x + 1} < \varepsilon$ by multiplying by $x + 1$, which is positive, and dividing by $\varepsilon$. This gives $x > \dfrac{5}{\varepsilon} - 1$, a **neighborhood of positive infinity**. Thus $N = \dfrac{5}{\varepsilon} - 1$ satisfies the definition, and the limit is verified. With $\varepsilon = 0.1$ the function differs from $3$ by less than $0.1$ for every $x > 49$.

</div>

## Exercise 4

Use the definition to verify that $\displaystyle\lim_{x \to 1} \frac{2}{(x - 1)^2} = +\infty$, and find $\delta$ when $M = 200$.

$$
\frac{2}{(x - 1)^2} > M
\iff
(x - 1)^2 < \frac{2}{M}
\iff
|x - 1| < \sqrt{\frac{2}{M}}
\qquad (x \neq 1)
$$
$$
\delta = \sqrt{\frac{2}{M}},
\qquad
M = 200
\quad \Longrightarrow \quad
\delta = \sqrt{\frac{2}{200}} = \sqrt{\frac{1}{100}} = \frac{1}{10}
$$

<div class="spiegazione">

For a limit equal to $+\infty$, the condition on the function values is $f(x) > M$, with $M$ positive and arbitrarily large. For $x \neq 1$ the denominator $(x - 1)^2$ is positive, so we can take the reciprocals of both positive sides, reversing the inequality, and multiply by $2$. This gives $(x - 1)^2 < \dfrac{2}{M}$, and taking square roots gives $|x - 1| < \sqrt{\dfrac{2}{M}}$.

The solutions form a symmetric neighborhood of $1$ with the point $1$ removed, so for every $M$ the number $\delta = \sqrt{\dfrac{2}{M}}$ satisfies the definition of an **infinite limit**. With $M = 200$ we have $\delta = \dfrac{1}{10}$, so for $0.9 < x < 1.1$ and $x \neq 1$ the function exceeds $200$.

</div>
