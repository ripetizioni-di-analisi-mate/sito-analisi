## Exercise 1

Evaluate $\displaystyle\int x\,(x - 2)^5\,dx$ using the substitution $t = x - 2$.

$$
t = x - 2,
\qquad
x = t + 2,
\qquad
dx = dt
$$
$$
\begin{aligned}
\int x\,(x - 2)^5\,dx
&= \int (t + 2)\,t^5\,dt \\[6pt]
&= \int \left( t^6 + 2t^5 \right) dt \\[6pt]
&= \frac{t^7}{7} + \frac{2t^6}{6} + c \\[6pt]
&= \frac{(x - 2)^7}{7} + \frac{(x - 2)^6}{3} + c
\end{aligned}
$$

<div class="spiegazione">

Expanding $(x - 2)^5$ by the binomial theorem takes a lengthy calculation. With the new variable $t = x - 2$, the power becomes $t^5$ and the factor $x$ becomes $t + 2$. Since $x = t + 2$, the derivative of $x$ with respect to $t$ is $1$, so $dx = dt$.

In the new variable, the integrand is the polynomial $t^6 + 2t^5$, which we integrate term by term. Finally, we return to the variable $x$ by substituting $t = x - 2$, and the fraction $\dfrac{2}{6}$ simplifies to $\dfrac{1}{3}$.

</div>

## Exercise 2

Evaluate $\displaystyle\int \frac{x}{\sqrt{x + 4}}\,dx$ for $x > -4$.

$$
t = \sqrt{x + 4},
\qquad
x = t^2 - 4,
\qquad
dx = 2t\,dt
$$
$$
\begin{aligned}
\int \frac{x}{\sqrt{x + 4}}\,dx
&= \int \frac{t^2 - 4}{t} \cdot 2t\,dt \\[6pt]
&= 2 \int \left( t^2 - 4 \right) dt \\[6pt]
&= \frac{2}{3}\,t^3 - 8t + c \\[6pt]
&= \frac{2}{3}\,(x + 4)\sqrt{x + 4} - 8\sqrt{x + 4} + c \\[6pt]
&= \frac{2}{3}\,(x - 8)\sqrt{x + 4} + c
\end{aligned}
$$

<div class="spiegazione">

The root contains the linear expression $x + 4$, so set $t = \sqrt{x + 4}$ with $t > 0$. Squaring gives $t^2 = x + 4$, that is, $x = t^2 - 4$. Differentiating $x$ with respect to $t$ gives $dx = 2t\,dt$.

In the new variable, the factor $t$ in the denominator cancels with the factor $t$ in $dx$, leaving the polynomial $2\left( t^2 - 4 \right)$. After integration, return to $x$ using $t^3 = (x + 4)\sqrt{x + 4}$. Factoring out $\dfrac{2}{3}\sqrt{x + 4}$ gives $\dfrac{2}{3}\sqrt{x + 4}\,(x + 4 - 12)$, the compact form in the last line.

</div>

## Exercise 3

Evaluate $\displaystyle\int \frac{\sqrt{x}}{1 + x}\,dx$ for $x \geq 0$.

$$
t = \sqrt{x},
\qquad
x = t^2,
\qquad
dx = 2t\,dt
$$
$$
\frac{t^2}{1 + t^2} = \frac{(1 + t^2) - 1}{1 + t^2} = 1 - \frac{1}{1 + t^2}
$$
$$
\begin{aligned}
\int \frac{\sqrt{x}}{1 + x}\,dx
&= \int \frac{t}{1 + t^2} \cdot 2t\,dt \\[6pt]
&= 2 \int \frac{t^2}{1 + t^2}\,dt \\[6pt]
&= 2 \int \left( 1 - \frac{1}{1 + t^2} \right) dt \\[6pt]
&= 2t - 2\arctan t + c \\[6pt]
&= 2\sqrt{x} - 2\arctan \sqrt{x} + c
\end{aligned}
$$

<div class="spiegazione">

The substitution $t = \sqrt{x}$ gives $x = t^2$ and $dx = 2t\,dt$, so the integrand becomes the rational function $\dfrac{2t^2}{1 + t^2}$. The numerator and denominator have the same degree. Add and subtract $1$ in the numerator to split the fraction as $1 - \dfrac{1}{1 + t^2}$.

The integral of $1$ is $t$, and the integral of $\dfrac{1}{1 + t^2}$ is $\arctan t$, from the table of basic integrals. Returning to the variable $x$ using $t = \sqrt{x}$ gives the result.

</div>

## Exercise 4

Evaluate $\displaystyle\int \frac{e^{2x}}{e^{x} + 1}\,dx$.

$$
t = e^{x},
\qquad
dt = e^{x}\,dx,
\qquad
e^{2x} = e^{x} \cdot e^{x}
$$
$$
\frac{t}{t + 1} = \frac{(t + 1) - 1}{t + 1} = 1 - \frac{1}{t + 1}
$$
$$
\begin{aligned}
\int \frac{e^{2x}}{e^{x} + 1}\,dx
&= \int \frac{e^{x}}{e^{x} + 1} \cdot e^{x}\,dx \\[6pt]
&= \int \frac{t}{t + 1}\,dt \\[6pt]
&= \int \left( 1 - \frac{1}{t + 1} \right) dt \\[6pt]
&= t - \ln (t + 1) + c \\[6pt]
&= e^{x} - \ln \left( e^{x} + 1 \right) + c
\end{aligned}
$$

<div class="spiegazione">

Set $t = e^{x}$. Differentiating with respect to $x$ gives $dt = e^{x}\,dx$, so we replace the product $e^{x}\,dx$ with $dt$. For this reason, we write $e^{2x}$ as the product $e^{x} \cdot e^{x}$. The first factor, together with $dx$, is replaced by $dt$, and the second becomes $t$.

In the new variable, we are integrating the rational function $\dfrac{t}{t + 1}$, whose denominator is linear. Adding and subtracting $1$ in the numerator splits the fraction as $1 - \dfrac{1}{t + 1}$, which we integrate using the basic formulas. The logarithm requires no absolute value because $t + 1 = e^{x} + 1$ is always positive.

</div>
