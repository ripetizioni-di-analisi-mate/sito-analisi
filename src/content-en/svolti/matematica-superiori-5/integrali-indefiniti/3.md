## Exercise 1

Find the antiderivative of $f(x) = 3x^2 - 4x + 1$ whose graph passes through the point $P(2, 5)$.

$$
\int \left( 3x^2 - 4x + 1 \right) dx = x^3 - 2x^2 + x + c
$$
$$
F(2) = 5
\iff
8 - 8 + 2 + c = 5
\iff
c = 3
$$
$$
F(x) = x^3 - 2x^2 + x + 3
$$

::grafico{f="x^3-2*x^2+x+3;x^3-2*x^2+x" punti="2,5,pieno,P" xmin=-1 xmax=3 ymin=-2 ymax=8 legenda="y = x^3 - 2x^2 + x + 3;y = x^3 - 2x^2 + x" titolo="The graph of the antiderivative $F(x) = x^3 - 2x^2 + x + 3$ passes through $P(2, 5)$. The graph of the antiderivative with $c = 0$ has the same shape and is shifted down by $3$"}

<div class="spiegazione">

First find the indefinite integral, which includes all antiderivatives of $f$. By linearity and the power rule, we obtain $x^3 - 2x^2 + x + c$, where $c$ is an arbitrary constant.

The graph of $F$ passes through $P(2, 5)$ if $F(2) = 5$. Substituting $x = 2$ into the expression for the antiderivatives gives $2 + c = 5$, so $c = 3$. By the theorem on **antiderivatives of the same function**, every other antiderivative differs from this one by a constant other than $0$, so its graph does not pass through $P$. The desired antiderivative is therefore **unique**.

</div>

## Exercise 2

Find the antiderivative of $f(x) = \sin x + 2\cos x$ with value $1$ at $x = \dfrac{\pi}{2}$.

$$
\int (\sin x + 2\cos x)\,dx = -\cos x + 2\sin x + c
$$
$$
F\left( \frac{\pi}{2} \right) = 1
\iff
-\cos \frac{\pi}{2} + 2\sin \frac{\pi}{2} + c = 1
\iff
0 + 2 + c = 1
\iff
c = -1
$$
$$
F(x) = 2\sin x - \cos x - 1
$$

<div class="spiegazione">

From the table of basic integrals, an antiderivative of $\sin x$ is $-\cos x$ and an antiderivative of $\cos x$ is $\sin x$. By linearity, the integral of $\sin x + 2\cos x$ is therefore $-\cos x + 2\sin x + c$.

Write the condition $F\left( \dfrac{\pi}{2} \right) = 1$ by substituting $x = \dfrac{\pi}{2}$. Since $\cos \dfrac{\pi}{2} = 0$ and $\sin \dfrac{\pi}{2} = 1$, this gives $2 + c = 1$, that is, $c = -1$. As a check, $F'(x) = 2\cos x + \sin x = f(x)$ and $F\left( \dfrac{\pi}{2} \right) = 2 - 0 - 1 = 1$.

</div>

## Exercise 3

Find the function $y = f(x)$ such that $f''(x) = 6x - 2$ for every real $x$, given that its graph passes through the point $A(1, 2)$ and that its tangent line at $A$ is parallel to the line $y = 3x$.

$$
f'(x) = \int (6x - 2)\,dx = 3x^2 - 2x + c_1
$$
$$
f'(1) = 3
\iff
3 - 2 + c_1 = 3
\iff
c_1 = 2
$$
$$
f(x) = \int \left( 3x^2 - 2x + 2 \right) dx = x^3 - x^2 + 2x + c_2
$$
$$
f(1) = 2
\iff
1 - 1 + 2 + c_2 = 2
\iff
c_2 = 0
$$
$$
f(x) = x^3 - x^2 + 2x
$$

<div class="spiegazione">

The second derivative is the derivative of $f'$, so $f'$ is an antiderivative of $f''$. Integrating $6x - 2$ gives $f'(x) = 3x^2 - 2x + c_1$. The line $y = 3x$ has slope $3$, and the tangent at $A$ is parallel to it if it has the same slope. By the geometric meaning of the derivative, this condition is $f'(1) = 3$, which gives $c_1 = 2$.

Similarly, $f$ is an antiderivative of $f'(x) = 3x^2 - 2x + 2$, and integration introduces a second constant $c_2$. Since the graph passes through $A(1, 2)$, we have $f(1) = 2$, that is, $2 + c_2 = 2$, so $c_2 = 0$. Two separate conditions determine the two constants because we have integrated twice. The required function is $f(x) = x^3 - x^2 + 2x$. As a check, $f''(x) = 6x - 2$, $f(1) = 2$, and $f'(1) = 3 - 2 + 2 = 3$.

</div>
