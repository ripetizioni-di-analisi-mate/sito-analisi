## Exercise 1

Find the domain of the function $f(x) = \dfrac{2x + 1}{x^2 - 5x + 6}$.

$$
x^2 - 5x + 6 \neq 0
$$
$$
x^2 - 5x + 6 = (x - 2)(x - 3) = 0
\iff
x = 2 \quad \text{or} \quad x = 3
$$
$$
D = \mathbb{R} \setminus \{2, 3\}
$$

<div class="spiegazione">

The function is **rational** because the variable appears in the denominator and not under a radical. The only restriction is therefore that the denominator must differ from $0$.

First find the values that make the denominator zero. To factor the trinomial $x^2 - 5x + 6$, we need two numbers with sum $5$ and product $6$, namely $2$ and $3$, so the factorization is $(x - 2)(x - 3)$. A product is zero when one of its factors is zero, so the denominator vanishes at $x = 2$ and $x = 3$. These two numbers are excluded, and the domain is $D = \mathbb{R} \setminus \{2, 3\}$.

</div>

## Exercise 2

Find the domain of the function $f(x) = \sqrt{x^2 - 4x}$.

$$
x^2 - 4x \geq 0
\iff
x\,(x - 4) \geq 0
$$
$$
x \leq 0 \quad \text{or} \quad x \geq 4
$$
$$
D = (-\infty, 0] \cup [4, +\infty)
$$

<div class="spiegazione">

This is a **radical function** containing a square root, which has even index. The radicand must therefore be greater than or equal to $0$.

The trinomial $x^2 - 4x$ can be factored by taking out $x$, and it vanishes at $x = 0$ and $x = 4$. Its graph is a parabola that opens upward because the coefficient of $x^2$ is positive. The parabola lies above the $x$-axis outside the interval between the roots, so the trinomial is positive for $x < 0$ and for $x > 4$. The values $0$ and $4$ belong to the domain because the square root equals $\sqrt{0} = 0$ at those points.

</div>

## Exercise 3

Find the domain of the function $f(x) = \sqrt{\dfrac{x + 1}{3 - x}}$.

$$
\frac{x + 1}{3 - x} \geq 0
$$

| | $x < -1$ | $-1 < x < 3$ | $x > 3$ |
| --- | --- | --- | --- |
| $x + 1$ | $-$ | $+$ | $+$ |
| $3 - x$ | $+$ | $+$ | $-$ |
| fraction | $-$ | $+$ | $-$ |

$$
D = [-1, 3)
$$

<div class="spiegazione">

The radicand is a fraction, so the condition is the rational inequality $\dfrac{x + 1}{3 - x} \geq 0$. The numerator is positive for $x > -1$. The denominator $3 - x$ is positive for $x < 3$ because $3 - x > 0$ is equivalent to $x < 3$.

The table gives the sign of each factor on each interval. The sign of the fraction is the product of the signs. The fraction is positive for $-1 < x < 3$. It also equals $0$ at $x = -1$, where the numerator vanishes, so $-1$ belongs to the domain. The number $3$ makes the denominator zero and the fraction undefined, so $3$ is excluded. The domain is therefore $D = [-1, 3)$.

</div>

## Exercise 4

Find the domain of the function $f(x) = \dfrac{\sqrt{4 - x^2}}{x - 1} + \sqrt[3]{x + 5}$.

$$
\begin{cases}
4 - x^2 \geq 0 \\[4pt]
x - 1 \neq 0
\end{cases}
\iff
\begin{cases}
-2 \leq x \leq 2 \\[4pt]
x \neq 1
\end{cases}
$$
$$
D = [-2, 1) \cup (1, 2]
$$

<div class="spiegazione">

The function contains a square root, a denominator, and a cube root. The cube root has odd index and therefore imposes no restrictions. For example, $\sqrt[3]{-8} = -2$. Two conditions remain, and both must hold, so we write a system.

The first condition, $4 - x^2 \geq 0$, is equivalent to $x^2 \leq 4$, or $-2 \leq x \leq 2$. The second condition excludes the number $1$, which makes the denominator zero. The number $1$ lies in the interval $[-2, 2]$, so it must be removed from that interval and the domain is $D = [-2, 1) \cup (1, 2]$.

</div>
