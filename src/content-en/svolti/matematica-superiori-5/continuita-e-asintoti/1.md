## Exercise 1

Determine whether the function
$$
f(x) =
\begin{cases}
x^2 + 1 & \text{if } x \leq 1 \\
3x - 1 & \text{if } x > 1
\end{cases}
$$
is continuous at $x_0 = 1$.

$$
f(1) = 1^2 + 1 = 2
$$
$$
\lim_{x \to 1^-} f(x) = \lim_{x \to 1^-} \left( x^2 + 1 \right) = 2
$$
$$
\lim_{x \to 1^+} f(x) = \lim_{x \to 1^+} (3x - 1) = 2
$$
$$
\lim_{x \to 1} f(x) = 2 = f(1)
$$

The function is continuous at $x_0 = 1$.

<div class="spiegazione">

At $1$, the formula for the function changes, so the two one-sided limits must be calculated from different expressions. We use the first expression to find $f(1)$ because the condition $x \leq 1$ includes $1$.

As $x \to 1^-$, we consider values $x < 1$, for which $f(x) = x^2 + 1$. This polynomial is continuous, so substitution gives a limit of $2$. As $x \to 1^+$, we consider values $x > 1$, for which $f(x) = 3x - 1$, and this limit also equals $2$. The right- and left-hand limits agree, so the limit exists and equals $2$. Since it equals $f(1)$, the function is **continuous** at $1$.

</div>

## Exercise 2

Determine whether the function
$$
f(x) =
\begin{cases}
\dfrac{\sin x}{x} & \text{if } x \neq 0 \\[8pt]
1 & \text{if } x = 0
\end{cases}
$$
is continuous at $x_0 = 0$.

$$
f(0) = 1
$$
$$
\lim_{x \to 0} f(x) = \lim_{x \to 0} \frac{\sin x}{x} = 1
$$
$$
\lim_{x \to 0} f(x) = f(0)
$$

The function is continuous at $x_0 = 0$.

<div class="spiegazione">

The second line of the definition gives the value at $0$, so $f(0) = 1$. To find the limit, we consider values $x \neq 0$, for which the function equals $\dfrac{\sin x}{x}$. The limit has the form $\dfrac{0}{0}$ and is the **standard limit** involving sine, which equals $1$.

The limit exists, is finite and equals $f(0)$, so the function is **continuous** at $0$. In this case there is no need to distinguish the right-hand limit from the left-hand limit because the function has the same formula on both sides of $0$.

</div>

## Exercise 3

Investigate continuity on $\mathbb{R}$ for the function
$$
f(x) =
\begin{cases}
x + 2 & \text{if } x < -1 \\
x^2 & \text{if } -1 \leq x \leq 2 \\
5 - x & \text{if } x > 2
\end{cases}
$$

**At $x_0 = -1$**
$$
f(-1) = (-1)^2 = 1,
\qquad
\lim_{x \to -1^-} (x + 2) = 1,
\qquad
\lim_{x \to -1^+} x^2 = 1
$$

**At $x_0 = 2$**
$$
f(2) = 2^2 = 4,
\qquad
\lim_{x \to 2^-} x^2 = 4,
\qquad
\lim_{x \to 2^+} (5 - x) = 3
$$

The function is continuous at every point except $2$. At $x_0 = 2$ it is continuous from the left but not from the right and has a discontinuity of the first kind with a jump of size $|3 - 4| = 1$.

::grafico{f="(x+2)*(1-sign(x+1))/2+x^2*(sign(x+1)+1)*(1-sign(x-2))/4+(5-x)*(sign(x-2)+1)/2+0*sqrt(abs(x-2)-0.01)" punti="-1,1,pieno;2,4,pieno;2,3,vuoto" segmenti="2,3,2,4" xmin=-4 xmax=6 ymin=-2 ymax=6 legenda=0 titolo="The function is continuous at $x = -1$, whereas at $x = 2$ the left-hand limit is $4$ and the right-hand limit is $3$"}

<div class="spiegazione">

On each of the three intervals the function is a polynomial, so it is continuous by the theorem on **continuity of elementary functions**. The two points where the formula changes remain to be examined, namely $-1$ and $2$.

At $-1$, we use the second expression to find the value of the function because $-1 \leq x \leq 2$ includes $-1$. We use $x + 2$ for the left-hand limit and $x^2$ for the right-hand limit. Both limits equal $1$, as does $f(-1)$. Therefore, the function is continuous at $-1$.

At $2$, both the function value and the left-hand limit are found using $x^2$ and equal $4$, so the function is continuous from the left. The right-hand limit is found using $5 - x$ and equals $3$, which differs from $4$. The one-sided limits are finite and unequal, so $2$ is a **discontinuity of the first kind**, with a jump of size $1$.

</div>
