## Exercise 1

Find the value of the real parameter $a$ for which the function
$$
f(x) =
\begin{cases}
a x + 3 & \text{if } x < 2 \\
x^2 - a & \text{if } x \geq 2
\end{cases}
$$
is continuous on $\mathbb{R}$.

$$
f(2) = 4 - a,
\qquad
\lim_{x \to 2^-} (a x + 3) = 2a + 3,
\qquad
\lim_{x \to 2^+} \left( x^2 - a \right) = 4 - a
$$
$$
2a + 3 = 4 - a
\iff
3a = 1
\iff
a = \frac{1}{3}
$$

The function is continuous on $\mathbb{R}$ when $a = \dfrac{1}{3}$.

<div class="spiegazione">

For both $x < 2$ and $x > 2$ the function is a polynomial for every value of $a$, so it is continuous. The only point to check is $2$, where the formula changes.

To find both $f(2)$ and the right-hand limit, we use $x^2 - a$, so the two are equal and the function is always continuous from the right at $2$. Using $a x + 3$ gives a left-hand limit of $2a + 3$. The function is continuous at $2$ if the left-hand limit equals $f(2)$, that is, if $2a + 3 = 4 - a$. This linear equation has the unique solution $a = \dfrac{1}{3}$. For this value both sides equal $\dfrac{11}{3}$.

</div>

## Exercise 2

Find the value of the real parameter $k$ for which the function
$$
f(x) =
\begin{cases}
\dfrac{1 - \cos x}{x^2} & \text{if } x \neq 0 \\[8pt]
k & \text{if } x = 0
\end{cases}
$$
is continuous at $x_0 = 0$.

$$
\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac{1}{2}
$$
$$
f(0) = k = \frac{1}{2}
$$

The function is continuous at $0$ when $k = \dfrac{1}{2}$.

<div class="spiegazione">

For $x \neq 0$ the function is the quotient of two continuous functions with a denominator different from $0$, so it is continuous. At $0$ the limit has the form $\dfrac{0}{0}$ and is the **standard limit** $\displaystyle\lim_{x \to 0} \dfrac{1 - \cos x}{x^2} = \dfrac{1}{2}$ from the chapter on limits.

The function is continuous at $0$ if the limit equals the function value $f(0) = k$, hence when $k = \dfrac{1}{2}$. For any other value of $k$, the point $0$ is a discontinuity of the third kind because the limit is finite but differs from $f(0)$.

</div>

## Exercise 3

Find the values of the real parameters $a$ and $b$ for which the function
$$
f(x) =
\begin{cases}
a \cdot 2^{x} & \text{if } x \leq 1 \\
x^2 + b & \text{if } 1 < x < 2 \\
3x - b & \text{if } x \geq 2
\end{cases}
$$
is continuous on $\mathbb{R}$.

$$
\text{at } x = 1: \qquad f(1) = 2a, \qquad \lim_{x \to 1^+} \left( x^2 + b \right) = 1 + b
$$
$$
\text{at } x = 2: \qquad \lim_{x \to 2^-} \left( x^2 + b \right) = 4 + b, \qquad f(2) = 6 - b
$$
$$
\begin{cases}
2a = 1 + b \\
4 + b = 6 - b
\end{cases}
\qquad
\Longrightarrow
\qquad
\begin{cases}
a = 1 \\
b = 1
\end{cases}
$$

The function is continuous on $\mathbb{R}$ when $a = 1$ and $b = 1$.

::grafico{f="2^x*(1-sign(x-1))/2+(x^2+1)*(sign(x-1)+1)*(1-sign(x-2))/4+(3*x-1)*(sign(x-2)+1)/2" punti="1,2,pieno;2,5,pieno" xmin=-3 xmax=4 ymin=-2 ymax=12 legenda=0 titolo="With $a = 1$ and $b = 1$, the three pieces $2^{x}$, $x^2 + 1$ and $3x - 1$ join at $(1, 2)$ and $(2, 5)$"}

<div class="spiegazione">

The function is continuous on each of the three intervals because each formula is either exponential or polynomial. The points to check are $1$ and $2$, and we need one condition at each point.

At $1$ we use $a \cdot 2^{x}$ for both the function value and the left-hand limit, so both equal $2a$. For the right-hand limit we use $x^2 + b$, which gives $1 + b$. At $2$ we use $x^2 + b$ for the left-hand limit, giving $4 + b$. We use $3x - b$ for the function value and the right-hand limit, and both equal $6 - b$.

The two conditions must hold simultaneously, so they form a system. The second equation contains only $b$ and gives $2b = 2$, or $b = 1$. Substituting into the first gives $2a = 2$, or $a = 1$. With these values the three pieces join at $(1, 2)$ and $(2, 5)$, as the figure shows.

</div>

## Exercise 4

Given $f(x) = \dfrac{x^2 + a x + 6}{x - 2}$, where $a$ is a real parameter, find the values of $a$ for which $x = 2$ is a removable discontinuity and give the continuous extension in that case.

$$
x^2 + a x + 6 = 0 \quad \text{for } x = 2
\iff
4 + 2a + 6 = 0
\iff
a = -5
$$
$$
a = -5:
\qquad
\frac{x^2 - 5x + 6}{x - 2} = \frac{(x - 2)(x - 3)}{x - 2} = x - 3,
\qquad
\lim_{x \to 2} f(x) = -1
$$
$$
a \neq -5:
\qquad
\lim_{x \to 2} \left( x^2 + a x + 6 \right) = 10 + 2a \neq 0,
\qquad
\lim_{x \to 2} (x - 2) = 0
$$
$$
g(x) =
\begin{cases}
\dfrac{x^2 - 5x + 6}{x - 2} & \text{if } x \neq 2 \\[8pt]
-1 & \text{if } x = 2
\end{cases}
$$

The point $x = 2$ is a removable discontinuity only when $a = -5$. The continuous extension is $g$, which agrees with $x - 3$ throughout $\mathbb{R}$. For $a \neq -5$, the point $2$ is a discontinuity of the second kind.

<div class="spiegazione">

As $x \to 2$, the denominator approaches $0$. If the numerator approaches a number different from $0$, the quotient becomes unbounded and the point is a discontinuity of the second kind. The limit can be finite only if the numerator also approaches $0$, that is, if $2$ is a root of the numerator. This condition gives the equation $10 + 2a = 0$, so $a = -5$.

When $a = -5$, the numerator $x^2 - 5x + 6$ has roots $2$ and $3$, so it factors as $(x - 2)(x - 3)$. The factor $x - 2$ cancels and the limit equals $2 - 3 = -1$. The limit is finite and the function is undefined at $2$, so the point is a **removable discontinuity**. To obtain the continuous extension, assign to the function at $2$ the limiting value $-1$.

When $a \neq -5$, the numerator approaches $10 + 2a \neq 0$ and the denominator changes sign at $2$, so the two one-sided limits are infinite with opposite signs. In this case the line $x = 2$ is a vertical asymptote, and the point is a **discontinuity of the second kind**.

</div>
