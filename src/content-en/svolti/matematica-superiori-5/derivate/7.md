## Exercise 1

Find the values of the real parameters $a$ and $b$ for which the function
$$
f(x) =
\begin{cases}
e^{x} & \text{if } x \leq 0 \\
a x + b & \text{if } x > 0
\end{cases}
$$
is continuous and differentiable at $x = 0$.

$$
\lim_{x \to 0^-} e^{x} = 1 = f(0),
\qquad
\lim_{x \to 0^+} (a x + b) = b
$$
$$
\text{continuity:} \quad b = 1
$$
$$
f'_-(0) = \lim_{x \to 0^-} e^{x} = 1,
\qquad
f'_+(0) = \lim_{x \to 0^+} a = a
$$
$$
\text{differentiability:} \quad a = 1
$$

The function is continuous and differentiable at $0$ for $a = 1$ and $b = 1$.

<div class="spiegazione">

By the theorem on **continuity of differentiable functions**, a function differentiable at $0$ is also continuous at $0$, so continuity is the first condition to impose. The value $f(0) = e^{0} = 1$ and the left-hand limit both equal $1$, whereas the right-hand limit is $b$. The function is therefore continuous at $0$ if and only if $b = 1$.

With $b = 1$ the function is continuous at $0$ and differentiable on either side of $0$, so the **differentiability criterion** applies. On the left the derivative is $e^{x}$, which approaches $1$. On the right the derivative is the constant $a$. The two derivatives are equal if $a = 1$. For these values the second piece is the line $y = x + 1$, which is tangent to the graph of $e^{x}$ at $(0, 1)$.

</div>

## Exercise 2

Find the values of the real parameters $a$ and $b$ for which the function
$$
f(x) =
\begin{cases}
a x^2 + b & \text{if } x \leq 1 \\
\dfrac{1}{x} & \text{if } x > 1
\end{cases}
$$
is differentiable on all of $\mathbb{R}$.

$$
\text{continuity at } 1: \quad f(1) = a + b, \qquad \lim_{x \to 1^+} \frac{1}{x} = 1
$$
$$
f'(x) =
\begin{cases}
2a x & \text{if } x < 1 \\
-\dfrac{1}{x^2} & \text{if } x > 1
\end{cases}
\qquad
f'_-(1) = 2a, \qquad f'_+(1) = -1
$$
$$
\begin{cases}
a + b = 1 \\
2a = -1
\end{cases}
\qquad
\Longrightarrow
\qquad
a = -\frac{1}{2}, \quad b = \frac{3}{2}
$$

::grafico{f="x<=1 ? -x^2/2+1.5 : 1/x" punti="1,1,pieno" xmin=-3 xmax=5 ymin=-3 ymax=2 legenda="0" titolo="For $a = -\dfrac{1}{2}$ and $b = \dfrac{3}{2}$, the parabola and the branch of the hyperbola meet at $(1, 1)$ with a common tangent of slope $-1$"}

<div class="spiegazione">

For $x < 1$ the function is a polynomial, and for $x > 1$ it is $\dfrac{1}{x}$, which is differentiable because $x \neq 0$. Thus the only point to examine is $x = 1$, where the two pieces meet. A function differentiable at $1$ is continuous at $1$, so we first require continuity. The value $f(1) = a + b$ agrees with the left-hand limit because the first piece is a polynomial, whereas the right-hand limit is $1$. Continuity therefore gives the condition $a + b = 1$.

If the function is continuous at $1$, then by the **differentiability criterion** the left-hand derivative is the limit of $2ax$, namely $2a$, and the right-hand derivative is the limit of $-\dfrac{1}{x^2}$, namely $-1$. The function is differentiable at $1$ if the two derivatives are equal, so $2a = -1$. The two conditions must hold simultaneously, so they form a system. The second equation gives $a = -\dfrac{1}{2}$, and substituting into the first gives $b = \dfrac{3}{2}$.

</div>

## Exercise 3

Find the values of the real parameters $b$ and $c$ for which the function
$$
f(x) =
\begin{cases}
x^2 + b x + c & \text{if } x < 2 \\
\ln (x - 1) & \text{if } x \geq 2
\end{cases}
$$
is differentiable at $x = 2$. Then write the equation of the tangent to the graph at the point with horizontal coordinate $2$.

$$
f(2) = \ln 1 = 0,
\qquad
\lim_{x \to 2^-} \left( x^2 + b x + c \right) = 4 + 2b + c
$$
$$
f'_-(2) = \lim_{x \to 2^-} (2x + b) = 4 + b,
\qquad
f'_+(2) = \lim_{x \to 2^+} \frac{1}{x - 1} = 1
$$
$$
\begin{cases}
4 + 2b + c = 0 \\
4 + b = 1
\end{cases}
\qquad
\Longrightarrow
\qquad
b = -3, \quad c = 2
$$
$$
y - 0 = 1 \cdot (x - 2)
\qquad
\Longrightarrow
\qquad
y = x - 2
$$

<div class="spiegazione">

The point $x = 2$ belongs to the second piece, so $f(2) = \ln (2 - 1) = \ln 1 = 0$. The function is continuous at $2$ if the left-hand limit, which is the value of the polynomial at $2$, equals $0$. This gives the first equation, $4 + 2b + c = 0$.

With continuity established, the **differentiability criterion** applies. The derivative of the first piece is $2x + b$, which approaches $4 + b$. The derivative of the second piece is $\dfrac{1}{x - 1}$ by the chain rule and approaches $1$. Equating the two derivatives gives the second equation, $4 + b = 1$, so $b = -3$ and, from the first equation, $c = -4 - 2b = 2$.

For these values the first piece is $x^2 - 3x + 2 = (x - 1)(x - 2)$, which vanishes at $2$ just as the logarithm does. The tangent line at $(2, 0)$ has slope $f'(2) = 1$ and equation $y = x - 2$.

</div>
