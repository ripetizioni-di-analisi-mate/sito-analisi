## Exercise 1

Solve the initial value problem
$$
\begin{cases}
y' = 3x^2 y \\
y(0) = 2
\end{cases}
$$

$$
y = 0 \quad \text{constant solution}
$$
$$
\int \frac{dy}{y} = \int 3x^2\,dx
\qquad
\Longrightarrow
\qquad
\ln |y| = x^3 + c
$$
$$
|y| = e^{c}\,e^{x^3}
\qquad
\Longrightarrow
\qquad
y = k\,e^{x^3}, \quad k \in \mathbb{R}
$$
$$
y(0) = k = 2
\qquad
\Longrightarrow
\qquad
y = 2\,e^{x^3}
$$

<div class="spiegazione">

The right-hand side is the product of $g(x) = 3x^2$ and $h(y) = y$, so the equation is **separable**. The function $h(y) = y$ vanishes for $y = 0$, so the constant function $y = 0$ is a solution.

For $y \neq 0$ we divide by $y$ and integrate. An antiderivative of $\dfrac{1}{y}$ is $\ln |y|$ and an antiderivative of $3x^2$ is $x^3$. Exponentiating gives $|y| = e^{c}\,e^{x^3}$. The number $e^{c}$ is positive, and on removing the absolute value we find that $y$ can be either positive or negative. We therefore write $y = k\,e^{x^3}$ with $k \neq 0$. The value $k = 0$ gives the constant solution, so the general solution is $y = k\,e^{x^3}$ with $k$ real.

For $x = 0$ we have $e^{0} = 1$, so the condition $y(0) = 2$ gives $k = 2$. The solution of the problem is $y = 2\,e^{x^3}$, defined for every real $x$.

</div>

## Exercise 2

Solve the initial value problem
$$
\begin{cases}
y' = x \left( 1 + y^2 \right) \\
y(0) = 0
\end{cases}
$$
and state the interval on which the solution is defined.

$$
\int \frac{dy}{1 + y^2} = \int x\,dx
\qquad
\Longrightarrow
\qquad
\arctan y = \frac{x^2}{2} + c
$$
$$
\arctan 0 = 0 + c
\qquad
\Longrightarrow
\qquad
c = 0
$$
$$
y = \tan \frac{x^2}{2},
\qquad
-\frac{\pi}{2} < \frac{x^2}{2} < \frac{\pi}{2}
\iff
x^2 < \pi
\iff
-\sqrt{\pi} < x < \sqrt{\pi}
$$

<div class="spiegazione">

The equation is separable with $g(x) = x$ and $h(y) = 1 + y^2$. The function $h(y)$ is positive for every $y$, so there are no constant solutions and we can divide by $1 + y^2$ without losing any solutions. An antiderivative of $\dfrac{1}{1 + y^2}$ is $\arctan y$, and an antiderivative of $x$ is $\dfrac{x^2}{2}$.

Substituting $x = 0$ and $y = 0$ gives $c = 0$, so $\arctan y = \dfrac{x^2}{2}$. The inverse tangent takes only values between $-\dfrac{\pi}{2}$ and $\dfrac{\pi}{2}$, so we can solve the equality for $y$ only if $\dfrac{x^2}{2}$ is less than $\dfrac{\pi}{2}$. In that case we obtain $y = \tan \dfrac{x^2}{2}$.

The condition $\dfrac{x^2}{2} < \dfrac{\pi}{2}$ is equivalent to $x^2 < \pi$, so the solution is defined on the interval $\left( -\sqrt{\pi}, \sqrt{\pi} \right)$. At the endpoints of the interval the function approaches $+\infty$ because the argument of the tangent approaches $\dfrac{\pi}{2}$.

</div>

## Exercise 3

Solve the initial value problem
$$
\begin{cases}
y' = e^{x - y} \\
y(0) = \ln 2
\end{cases}
$$

$$
y' = e^{x} \cdot e^{-y}
\qquad
\Longrightarrow
\qquad
\int e^{y}\,dy = \int e^{x}\,dx
\qquad
\Longrightarrow
\qquad
e^{y} = e^{x} + c
$$
$$
e^{\ln 2} = e^{0} + c
\iff
2 = 1 + c
\iff
c = 1
$$
$$
e^{y} = e^{x} + 1
\qquad
\Longrightarrow
\qquad
y = \ln \left( e^{x} + 1 \right)
$$

<div class="spiegazione">

By a law of exponents, $e^{x - y} = e^{x} \cdot e^{-y}$, so the equation is separable with $g(x) = e^{x}$ and $h(y) = e^{-y}$. The function $h(y)$ never vanishes, so there are no constant solutions. Dividing by $e^{-y}$ is equivalent to multiplying by $e^{y}$, and integrating gives $e^{y} = e^{x} + c$.

Substitute the initial condition before solving for $y$. Since $e^{\ln 2} = 2$ and $e^{0} = 1$, we find $c = 1$. The right-hand side $e^{x} + 1$ is positive for every $x$, so we may take the logarithm, and the solution $y = \ln \left( e^{x} + 1 \right)$ is defined on all of $\mathbb{R}$.

</div>

## Exercise 4

Solve the initial value problem
$$
\begin{cases}
y' = 2x\,y^2 \\
y(1) = -1
\end{cases}
$$
and state the interval on which the solution is defined.

$$
y = 0 \quad \text{constant solution, which does not satisfy } y(1) = -1
$$
$$
\int \frac{dy}{y^2} = \int 2x\,dx
\qquad
\Longrightarrow
\qquad
-\frac{1}{y} = x^2 + c
$$
$$
-\frac{1}{-1} = 1 + c
\iff
c = 0
$$
$$
-\frac{1}{y} = x^2
\qquad
\Longrightarrow
\qquad
y = -\frac{1}{x^2},
\qquad
x > 0
$$

::grafico{f="-1/x^2+0*sqrt(x)" legenda="y = -\dfrac{1}{x^2}" punti="1,-1,pieno" asintoti="x=0" xmin=-1 xmax=5 ymin=-5 ymax=1 titolo="The solution of $y' = 2xy^2$ with $y(1) = -1$ is $y = -\dfrac{1}{x^2}$ on the interval $x > 0$"}

<div class="spiegazione">

The equation is separable with $g(x) = 2x$ and $h(y) = y^2$. The function $h$ vanishes for $y = 0$, so $y = 0$ is a constant solution. This solution equals $0$ at $x = 1$ and therefore does *not* satisfy the condition $y(1) = -1$. We find the required solution by separating the variables.

An antiderivative of $\dfrac{1}{y^2} = y^{-2}$ is $-y^{-1} = -\dfrac{1}{y}$, and an antiderivative of $2x$ is $x^2$. Substituting $x = 1$ and $y = -1$ makes the left-hand side equal to $1$, so $1 = 1 + c$ and $c = 0$. Solving $-\dfrac{1}{y} = x^2$ gives $y = -\dfrac{1}{x^2}$.

The function $-\dfrac{1}{x^2}$ is undefined at $x = 0$. The solution of an initial value problem is defined on an interval containing the initial point $x_0 = 1$, so the solution is defined on the interval $(0, +\infty)$. As the figure shows, the line $x = 0$ is a vertical asymptote.

</div>
