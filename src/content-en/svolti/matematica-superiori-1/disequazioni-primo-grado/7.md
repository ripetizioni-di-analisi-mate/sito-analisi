## Exercise 1

Solve $2x+9>2x+10$ and interpret the comparison using the lines.

$$
\begin{aligned}
2x+9>2x+10&\iff9>10,\\[6pt]
S&=\varnothing.
\end{aligned}
$$

::grafico{f="2*x+9;2*x+10" xmin=-2.5 xmax=3.65 ymin=3.8 ymax=18 nomi="x,y" legenda="2x+9;2x+10" punti="1,11,pieno;1,12,pieno" segmenti="1,11,1,12" titolo="The lines are parallel and the first stays below the second."}

<div class="spiegazione">

Subtracting $2x$ from both sides preserves the sign and removes the unknown. This leaves $9>10$, which is always false. The first expression minus the second is $-1$ for every $x$. On the graph, the lines have the same slope and the first stays one unit below the second. An intersection would require a difference of zero. Equality is impossible too, so the solution set is empty.

</div>

## Exercise 2

Solve $3x-10\le3x-9$ over the reals. Which solutions remain if $x\in\{1,2,3\}$?

$$
\begin{aligned}
3x-10\le3x-9&\iff -10\le-9,\\[6pt]
S_\mathbb R&=\mathbb R,\qquad
S_{\{1,2,3\}}=\{1,2,3\}.
\end{aligned}
$$

<div class="spiegazione">

The two sides share the term $3x$. Subtracting it from both sides compares the constants $-10$ and $-9$. The first is smaller, so the comparison holds for every real number. When the domain is restricted, only values allowed from the start may be used. Here all three permitted integers are solutions. For example, at $x=3$ the original comparison is $-1\le0$. The difference between the two expressions is always $-1$, even when the domain for $x$ changes.

</div>

## Exercise 3

Find the real values of $a$ for which $2x+a\le2x+4$ holds for every $x$. How does the condition change with the sign $<$?

$$
\begin{aligned}
2x+a\le2x+4&\iff a\le4,\\[6pt]
2x+a<2x+4&\iff a<4.
\end{aligned}
$$

<div class="spiegazione">

The parameter $a$ stays fixed while the possible values of $x$ are considered. Subtracting $2x$ reduces the inequality to a comparison between $a$ and $4$. At $a=4$, the original expressions agree for every $x$, so $\le$ is true and $<$ is false. For $a<4$, the first expression is smaller regardless of $x$. For $a>4$, for example $a=5$, already $x=0$ gives $5\le4$, which is false. The difference is constant, so no other $x$ restores the condition.

</div>
