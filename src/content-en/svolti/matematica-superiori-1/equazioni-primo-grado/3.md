## Exercise 1

Find the real solution set of $2(x+8)=2x+17$.

$$
\begin{aligned}
2x+16 &= 2x+17 \\[6pt]
16 &= 17
\end{aligned}
$$

<div class="spiegazione">

The distributive property gives the same term $2x$ on both sides. Subtracting it leaves two different numbers. In fact, the right-hand side is always $1$ greater than the left-hand side, regardless of $x$. The equation has no solution, so the solution set is $\varnothing$.

</div>

## Exercise 2

Find the real solution set of $3(x-9)=3x-27$.

$$
\begin{aligned}
3x-27 &= 3x-27 \\[6pt]
0 &= 0
\end{aligned}
$$

<div class="spiegazione">

The expanded left-hand side agrees with the right-hand side for every value of the unknown. Subtracting the common terms gives $0=0$. The expressions are defined on all of $\mathbb R$, so the solution set is $\mathbb R$.

</div>

## Exercise 3

Find the values of $c$ for which $cx+10=2x+10$ holds for every $x\in\mathbb R$.

$$
\begin{aligned}
cx-2x &= 0 \\[6pt]
(c-2)x &= 0 \\[6pt]
(c-2)\cdot1 &= 0 \\[6pt]
c &= 2
\end{aligned}
$$

<div class="spiegazione">

For any value of the parameter $c$, the equation holds at $x=0$. For it to be an identity, it must also hold at $x=1$, which requires $c=2$. This value makes the coefficients and the constant terms agree, so the condition is also sufficient.

</div>
