## Exercise 1

Let $A=\left\{8, 9, 10\right\}$. Which statement is true?

- $11$ $\in A$
- $8$ $\notin A$
- $10$ $\notin A$
- $9$ $\in A$

$$
9\in A
$$

<div class="spiegazione">

The symbol $\in$ tests whether an element is in the list. Set $A$ contains $8$, $9$, and $10$, so $9\in A$ is true. Statements excluding $8$ or $10$ are false for the same reason. The number $11$ is absent, so $11\notin A$ holds.

</div>

## Exercise 2

Let $C=\left\{9, 10\right\}$ and $D=\left\{9, 10, 11\right\}$. Which relation holds?

- $C\subsetneq D$
- $D\subseteq C$
- $C=D$
- $C\cap D=\varnothing$

$$
C\subsetneq D
$$

<div class="spiegazione">

Both $9$ and $10$ belong to $D$, so every element of $C$ is in $D$. Also, $11$ belongs to $D$ and is absent from $C$. The sets are therefore distinct, and the inclusion is proper. The statement that the intersection is empty is also false because $C\cap D=C$.

</div>

## Exercise 3

Let $A=\left\{8, 9, 10\right\}$ and $B=\left\{10, 11\right\}$. What is $A\setminus B$?

$$
A\setminus B=\{8;9\}
$$

<div class="spiegazione">

The set difference starts with the elements of $A$. Since $10$ also occurs in $B$, exclude it. The result contains $8$ and $9$. The number $11$ belongs only to $B$, so it was outside the set under consideration from the start.

</div>
