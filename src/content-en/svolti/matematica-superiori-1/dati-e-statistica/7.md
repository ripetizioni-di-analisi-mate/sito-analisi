## Exercise 1

A survey records how students get to school. What type of variable is this?

- Continuous quantitative variable
- Discrete quantitative variable
- Nominal categorical variable
- Ordinal categorical variable with a fixed natural order

<div class="spiegazione">

The responses may be categories such as bus, bicycle, or walking. Each describes a means of transport. Because these categories are names that can be listed in any order without changing their meaning, the variable is nominal categorical. The category frequencies are numbers, while the observed responses are still categories.

</div>

## Exercise 2

A survey records the number of books read in a month. What type of variable is this?

- Continuous quantitative variable
- Nominal categorical variable
- Ordinal categorical variable with no numerical values
- Discrete quantitative variable

<div class="spiegazione">

The number of books read is found by counting. It can be zero or any positive integer. These values can be ordered and compared using numerical differences, so the variable is quantitative. Its values are separate because the number of books read is an integer. The variable is therefore discrete.

</div>

## Exercise 3

What is the mode of the data $10, 11, 11, 11, 13, 13$?

<div class="spiegazione">

The frequencies of $10$, $11$, and $13$ are one, three, and two, respectively. The greatest frequency is three. It corresponds to $11$, so that value is the mode. A numerical data set can be summarized by stating which value occurs most often.

</div>
