## Exercise 1

Evaluate $\dfrac{x+1}{x-8}$ at $x=10$.

$$
\frac{10+1}{10-8}=\frac{11}2=\frac{11}{2}
$$

<div class="spiegazione">

The given input does not make the denominator zero, so substitution is valid. Substitute the same value of x in the numerator and denominator. Divide the two results.

The result is $\dfrac{11}{2}$.

The input $10$ gives denominator $10-8=2$, so the quotient can be evaluated. At the same input, the numerator is $11$. The quotient is $\dfrac{11}{2}$.

</div>

## Exercise 2

At what value of $x$ is the fraction $\dfrac{x-9}{x+1}$ equal to zero?

$$
x-9=0\Rightarrow x=9,\qquad 9+1\ne0
$$

<div class="spiegazione">

A fraction equals zero when its numerator is zero and its denominator is nonzero. The numerator vanishes at the given value. The denominator is $9$ plus one there, which is nonzero.

The result is $9$.

At $x=9$, the numerator is zero and the denominator is $10$, so the fraction equals zero. At $x=-1$, the fraction is undefined. The first value satisfies both conditions for a zero.

</div>

## Exercise 3

The fraction $\dfrac{x-8}{x-8}$ simplifies to $1$. Which statement correctly preserves its domain?

- It equals $1$ for every real number, including $x=8$
- It equals $0$ when $x=8$
- It is defined only for $x>8$
- It equals $1$ for every $x\ne 8$

<div class="spiegazione">

Simplification requires the canceled factor to be nonzero. The value excluded by the original denominator remains excluded. The simplified formula represents the same fraction only on that domain.

The fraction equals $1$ for every $x\ne 8$.

Read the domain before simplifying by solving $x-8=0$. The point $x=8$ remains excluded. At any other real input, the ratio of a nonzero number to itself is $1$.

</div>
