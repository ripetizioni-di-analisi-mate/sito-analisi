## Exercise 1

On $[0,1]$, set $f(x)=x^2$ except at $x=\dfrac12$, where it equals $10$. Find $\|f\|_2$ and $\|f\|_\infty$.

$$
\begin{aligned}
f(x)&=x^2\qquad\text{almost everywhere in }[0,1]. \\[5pt]
\|f\|_2^2&=\int_0^1x^4\,dx \\
&=\left[\frac{x^5}{5}\right]_0^1 \\
&=\frac15. \\[5pt]
\mu\{|f|>1\}&=\mu\left(\left\{\frac12\right\}\right) \\
&=0. \\[5pt]
\mu\{|f|>a\}&\ge 1-\sqrt a>0\qquad(0\le a<1). \\[5pt]
\|f\|_2&=\frac1{\sqrt5},\qquad \|f\|_\infty=1.
\end{aligned}
$$

::grafico{curve="t,t^2,0,1" punti="0.5,0.25,vuoto;0.5,10,pieno" segmenti="0,1,1,1" legenda="x^2" xmin=-0.08 xmax=1.16 ymin=-0.36 ymax=10.9 titolo="The point at height $10$ is isolated. The level $1$ is an upper bound almost everywhere."}

<div class="spiegazione">

The exceptional value is attained on a set of measure zero. The function therefore agrees almost everywhere with $x^2$, so its squared norm can be computed using the monomial. The integral of $x^4$ gives the squared norm, so take the square root of $\dfrac15$.

The $L^\infty$ norm is the **essential supremum**. The threshold one is exceeded only at the exceptional point, so it is an upper bound almost everywhere. If $a$ is a nonnegative threshold below one, the interval $(\sqrt a,1]$ has positive length and $|f|$ exceeds $a$ there. Thus no threshold below one suffices. The value ten changes the pointwise maximum, while the least almost-everywhere upper bound remains one.

</div>

## Exercise 2

Determine whether $f(x)=x^{-\dfrac23}$ on $(1,\infty)$ belongs to $L^1$ and to $L^2$.

$$
\begin{aligned}
\int_1^R |f(x)|\,dx &= \int_1^R x^{-\frac23}\,dx \\
&= \left[3x^{\frac13}\right]_1^R \\
&= 3R^{\frac13}-3 \longrightarrow +\infty. \\[6pt]
\int_1^R |f(x)|^2\,dx &= \int_1^R x^{-\frac43}\,dx \\
&= \left[-3x^{-\frac13}\right]_1^R \\
&= 3-3R^{-\frac13} \longrightarrow 3. \\[6pt]
f&\notin L^1(1,\infty),\\
f&\in L^2(1,\infty),\qquad \|f\|_2=\sqrt3.
\end{aligned}
$$

<div class="spiegazione">

The function is positive, so it equals its absolute value. The half-line has infinite measure, so the inclusion between $L^p$ spaces on finite intervals does not apply. To determine membership, compute the two truncated integrals. Monotone convergence allows passage to the half-line because the integrands are nonnegative and the intervals increase with $R$.

For $L^1$ the exponent in the antiderivative is $\dfrac13$, which is positive, so the value at the upper limit grows without bound. For $L^2$, squaring changes the integrand exponent to $-\dfrac43$. The antiderivative has exponent $-\dfrac13$, so the contribution at the upper endpoint tends to zero. The remaining positive value three is the squared $L^2$ norm.

</div>

## Exercise 3

Study convergence almost everywhere and in $L^1(0,1)$ and $L^2(0,1)$ for the sequence $f_n=\sqrt n\,\mathbf1_{(0,\dfrac1n)}$.

$$
\begin{aligned}
x\in(0,1),\ n>\frac1x &\implies f_n(x)=0. \\[4pt]
\|f_n\|_1&=\sqrt n\int_0^{\frac1n}1\,dx \\
&=\frac{\sqrt n}{n} \\
&=\frac1{\sqrt n}\longrightarrow0. \\[4pt]
\|f_n\|_2^2&=n\int_0^{\frac1n}1\,dx \\
&=n\cdot\frac1n \\
&=1. \\[4pt]
f_n&\longrightarrow 0\quad\text{pointwise and in }L^1(0,1),\\
(f_n)&\text{ does not converge in }L^2(0,1).
\end{aligned}
$$

<div class="spiegazione">

Fix a positive point $x$. The interval $(0,\dfrac1n)$ excludes it as soon as $n>\dfrac1x$. From that point on, the terms vanish there, so the pointwise limit is zero everywhere on $(0,1)$. For the $L^1$ norm the integrand has height $\sqrt n$, whereas for the squared $L^2$ norm it has height $n$. In both cases the integrand is positive on an interval of length $\dfrac1n$.

The first area tends to zero, so the sequence converges in $L^1$. If a limit existed in $L^2$, a subsequence would converge almost everywhere to that same limit. The entire sequence converges pointwise to zero, so any limit in $L^2$ would be the zero class. The constant L² norm rules this out.

</div>
