## Exercise 1

Solve $\begin{cases}x^2-8x+15\le0\\x>4\end{cases}$.

$$
\begin{aligned}
x^2-8x+15\le0 &\iff x\in[3,5],\\
x>4 &\iff x\in(4,+\infty),\\
S&=[3,5]\cap(4,+\infty)=(4,5].
\end{aligned}
$$

<div class="spiegazione">

The first inequality puts $x$ between $3$ and $5$, including both endpoints. The second imposes $x>4$. The overlap starts just above $4$ and reaches $5$. At $4$ the quadratic equals $-1$, but the linear bound excludes that point. At $5$ the quadratic is zero and $5>4$, so the point is allowed. Finding both sets separately explains why the two endpoints have different brackets. The number $6$ exceeds $4$ but gives a positive quadratic, so the first condition excludes it.

</div>

## Exercise 2

Solve $\begin{cases}x^2-4>0\\-3\le x\le2\end{cases}$.

$$
\begin{aligned}
x^2-4>0 &\iff x\in(-\infty,-2)\cup(2,+\infty),\\
S&=\bigl(( -\infty,-2)\cup(2,+\infty)\bigr)\cap[-3,2]\\
&=[-3,-2).
\end{aligned}
$$

<div class="spiegazione">

The quadratic $x^2-4$ is positive below $-2$ and above $2$. The second constraint keeps only values from $-3$ to $2$, including both ends. On the left, the interval goes from $-3$ up to the excluded endpoint $-2$. The right branch would require $x>2$ and $x\le2$ at once, so none of it remains. The number $-3$ gives the quadratic value $5$, while $-2$ gives zero and the first comparison is strict. The first two number lines show the separate constraints, while the third keeps only the overlap.

</div>

## Exercise 3

Solve $\begin{cases}(x-1)^2\le0\\x>1\end{cases}$.

$$
\begin{aligned}
(x-1)^2\le0&\iff x=1,\\
S&=\{1\}\cap(1,+\infty)=\varnothing.
\end{aligned}
$$

<div class="spiegazione">

The square is nonnegative for every real number, so the first comparison $\le0$ is true only when the square equals zero. This happens at $x=1$. The second constraint requires a value strictly above $1$, excluding the only candidate. The solution set is empty. If the condition were $x\ge1$, the first constraint would still leave only $1$ and the second would allow it. The intersection would then be $\{1\}$. For example, $x=2$ meets the second comparison and gives a square of $1$.

</div>
