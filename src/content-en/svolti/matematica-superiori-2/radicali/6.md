## Exercise 1

For which real values is $\sqrt{x-4}$ defined?

$$
x-4\ge0\iff x\ge4
$$

<div class="spiegazione">

The index is even, so the radicand must be nonnegative. Equality is allowed because the square root of zero is defined. Solving the linear inequality gives the domain.

The value $4$ is included because it makes the radicand zero. Every value below $4$ makes the difference $x-4$ negative. The endpoint would be excluded if the same square root were in the denominator.

The result is $[4,+\infty)$.

</div>

## Exercise 3

Find the domain of $\dfrac{\sqrt{x-2}}{\sqrt{6-x}}$.

$$
\begin{cases}
x-2\ge0\\
6-x>0
\end{cases}
\qquad\iff\qquad
\begin{cases}
x\ge2\\
x<6.
\end{cases}
$$

::grafico{f="sqrt(x-2)/sqrt(6-x)" xmin=1 xmax=6.5 ymin=-0.5 ymax=5 punti="2,0,pieno,A" asintoti="x=6" titolo="$x=2$ belongs to the domain and $x=6$ is excluded"}

<div class="spiegazione">

The numerator can be zero, so it requires $x\ge2$. The denominator must be defined and nonzero, so it requires $6-x>0$, which means $x<6$. Both conditions must hold at the same time, so the domain is $[2,6)$. At the point with x-coordinate $2$, the numerator is zero and the denominator is $2$.

</div>
