## Exercise 1

Compute the iterated integral
$$
\int_0^1 \left( \int_x^1 e^{y^2}\, dy \right) dx .
$$

$$
D = \{ (x, y) : 0 \leq x \leq 1, \ x \leq y \leq 1 \}
= \{ (x, y) : 0 \leq y \leq 1, \ 0 \leq x \leq y \}
$$
$$
\int_0^1 \left( \int_x^1 e^{y^2}\, dy \right) dx
= \int_0^1 \left( \int_0^y e^{y^2}\, dx \right) dy
= \int_0^1 y\, e^{y^2}\, dy
$$
$$
\int_0^1 y\, e^{y^2}\, dy
= \left[ \frac{e^{y^2}}{2} \right]_0^1
= \frac{e - 1}{2}
$$

<div class="spiegazione">

The function $e^{y^2}$ does *not* have an elementary antiderivative with respect to $y$, so the given inner integral cannot be computed directly and the only way forward is **changing the order of integration**. The given limits describe the triangle lying between the line $y = x$, the line $y = 1$ and the $y$-axis: the same triangle, described with respect to the $y$-axis, has $y \in [0, 1]$ and, for each fixed $y$, $x \in [0, y]$. With the new order the function does not depend on $x$, therefore the inner integral equals $y\, e^{y^2}$. The factor $y$ is, up to the constant $2$, the derivative of the exponent $y^2$, so the antiderivative is $\dfrac{e^{y^2}}{2}$ and the **result** is $\dfrac{e - 1}{2}$.

</div>

## Exercise 2

Compute the iterated integral
$$
\int_0^1 \left( \int_{\sqrt{x}}^1 \sin( y^3 )\, dy \right) dx .
$$

$$
D = \{ (x, y) : 0 \leq x \leq 1, \ \sqrt{x} \leq y \leq 1 \}
= \{ (x, y) : 0 \leq y \leq 1, \ 0 \leq x \leq y^2 \}
$$
$$
\int_0^1 \left( \int_{\sqrt{x}}^1 \sin( y^3 )\, dy \right) dx
= \int_0^1 \left( \int_0^{y^2} \sin( y^3 )\, dx \right) dy
= \int_0^1 y^2 \sin( y^3 )\, dy
$$
$$
\int_0^1 y^2 \sin( y^3 )\, dy
= \left[ -\frac{\cos( y^3 )}{3} \right]_0^1
= \frac{1 - \cos 1}{3}
$$

<div class="spiegazione">

In this case too the function $\sin(y^3)$ has no elementary antiderivative, so we **change the order of integration**. The condition $\sqrt{x} \leq y$ with $x, y \geq 0$ is equivalent to $x \leq y^2$, therefore the region is the one lying between the $y$-axis, the line $y = 1$ and the parabola $x = y^2$: with respect to the $y$-axis we have $y \in [0, 1]$ and $x \in [0, y^2]$. The inner integral in the new order equals $y^2 \sin(y^3)$, and the factor $y^2$ is, up to the constant $3$, the derivative of $y^3$. The antiderivative is therefore $-\dfrac{\cos(y^3)}{3}$ and the **result** is $\dfrac{1 - \cos 1}{3}$.

</div>

## Exercise 3

Compute the iterated integral
$$
\int_0^1 \left( \int_y^1 \frac{\sin x}{x}\, dx \right) dy .
$$

$$
D = \{ (x, y) : 0 \leq y \leq 1, \ y \leq x \leq 1 \}
= \{ (x, y) : 0 \leq x \leq 1, \ 0 \leq y \leq x \}
$$
$$
\int_0^1 \left( \int_y^1 \frac{\sin x}{x}\, dx \right) dy
= \int_0^1 \left( \int_0^x \frac{\sin x}{x}\, dy \right) dx
= \int_0^1 \frac{\sin x}{x} \cdot x \, dx
$$
$$
\int_0^1 \sin x \, dx
= \Bigl[ -\cos x \Bigr]_0^1
= 1 - \cos 1
$$

<div class="spiegazione">

The function $\dfrac{\sin x}{x}$ has no elementary antiderivative, so the given inner integral, which is in $x$, *cannot* be computed directly. The region described by the limits is the triangle bounded by the lines $x = y$, $x = 1$ and by the $x$-axis; described with respect to the $x$-axis, it has $x \in [0, 1]$ and $y \in [0, x]$. With the new order the function does not depend on $y$, therefore the inner integral equals $\dfrac{\sin x}{x}$ multiplied by the **length** $x$ of the vertical segment. The product **simplifies** to $\sin x$, whose integral over $[0, 1]$ equals $1 - \cos 1$.

</div>
