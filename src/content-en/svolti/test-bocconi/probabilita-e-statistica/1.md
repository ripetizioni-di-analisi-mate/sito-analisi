## Exercise 1

A library offers three time slots for an in-person lesson. For each slot, either of two rooms can be booked. The online lesson is available in four time slots. How many bookings are possible if each booking specifies the slot and the room where applicable?

$$
N_{\text{in-person}}=3\cdot2=6,\qquad
N_{\text{online}}=4,\qquad N=6+4=10.
$$

<div class="spiegazione">

Each in-person time slot gives two bookings, one per room, so the multiplication rule applies. For an online lesson, the time slot alone identifies the booking. Since the two formats are disjoint cases, their counts are added. There are **ten possible bookings**.

</div>

## Exercise 2

A code consists of one letter from $A,B,C,D$ followed by two digits. If the letter is $A$ or $B$, the first digit must be even. If the letter is $C$ or $D$, the first digit must be $1$ or $3$. In both cases the two digits must differ, and zero may appear. How many codes can be formed?

$$
\begin{aligned}
N_{A,B}&=2\cdot 5\cdot 9=90,\\[6pt]
N_{C,D}&=2\cdot 2\cdot 9=36,\\[6pt]
N&=90+36=126.
\end{aligned}
$$

<div class="spiegazione">

For $A$ and $B$ there are five possibilities for the first digit, because it is chosen from $0,2,4,6,8$. For $C$ and $D$ there are two. Once the first digit has been chosen, only that symbol is excluded, so there are nine choices for the second digit. The letter determines which case the code belongs to. Adding the counts gives a total of $126$.

</div>
