## Exercise 1

An editorial team’s manual distinguishes submitting a draft from its approval. The author uploads the text by Monday; the reviewer then has two working days to request changes. If none are requested, the draft is considered approved when that period expires. If corrections are requested, the two-day count restarts when the new version is uploaded. An automated message confirms only that the file has arrived.

The coordinator notes that this system prevents a receipt from being confused with a judgment on the content. She also explains that the deadline is a maximum: explicit approval may arrive earlier. However, the manual sets no maximum duration for the whole process, because revision may require more than one resubmission. Authors must therefore keep the dates of their versions, not just the date of the first submission.

An author receives only the automated message. What can they claim?

- The file arrived, but the message does not establish approval
- The text received explicit approval
- All corrections were accepted
- The review period has already expired
- The reviewer will request no changes

| Event | Status it establishes |
| --- | --- |
| Automated message | File received |
| Explicit approval | Draft approved |
| Period expired without requests | Draft approved under the manual’s rule |
| Request for corrections | Need for a new version |

<div class="spiegazione">

The message is assigned only the role of confirming arrival. Approval depends on an explicit decision or the period expiring without requests. Neither condition can be inferred from the receipt alone.

Receipt and approval are different document states. The receipt may arrive before the reviewer has read the file, so it does not certify a favorable judgment. Even a temporary absence of requests is insufficient if the period has not expired. The correct answer states only what the message establishes; it does not assert that the draft is certainly unapproved, since a separate approval may exist. The point is that such approval cannot be inferred from the automated communication alone.

**Answer.** The file arrived, but the message does not establish approval.

</div>

## Exercise 2

A study center announces that, from the following month, its archive room will be open by reservation. Both members and external visitors may book. Consulting fragile documents will additionally require the supervisor’s authorization; a reservation alone will suffice for regularly used volumes. Requests to take photographs will be assessed separately and are not included in authorization to consult documents.

The notice clarifies that the new rules concern the archive room, while admission to the ground-floor exhibition will remain unrestricted during ordinary opening hours. The center explains reservations by citing the limited number of seats and the need to prepare materials. It announces neither an admission charge nor a requirement to become a member. Finally, it asks readers to distinguish a room being open to the public from every document being immediately available.

Does authorization to consult a document imply permission to photograph it?

- No: requests to take photographs are assessed separately
- Yes, because the two permissions are identical
- Yes, but only for external visitors
- No, because all photography is always forbidden
- Yes, provided the exhibition is open

| Operation | Stated rule |
| --- | --- |
| Consult regularly used volumes | Reservation sufficient |
| Consult fragile documents | Reservation and authorization |
| Take photographs | Request assessed separately |
| Visit the exhibition | Unrestricted admission during ordinary hours |

<div class="spiegazione">

The text excludes photography permission from authorization to consult and provides for separate assessment. This does not amount to an absolute ban: a request can be considered, but its outcome does not follow automatically from the first permission.

The answer requires keeping each permission’s object and scope separate. Authorization to consult concerns reading the document; the text excludes automatically including photographs. The separate process nevertheless leaves open the possibility of obtaining another permission. Saying “photographs are always forbidden” would therefore add a ban absent from the notice. Unrestricted exhibition admission also concerns a different activity and does not remove the archive room’s conditions.

**Answer.** No: requests to take photographs are assessed separately.

</div>

## Exercise 3

An internal guide explains how to handle a device that will not switch on. First, check that its cable is connected correctly; then try an outlet already tested with another appliance. Only if the device still will not switch on should a technical-support request be opened. Users are forbidden to open the casing.

| Test result | Required action |
| --- | --- |
| The device switches on in the tested outlet | Report the original outlet |
| The device does not switch on in the tested outlet | Submit a technical-support request |

The supervisor explains that the procedure orders checks accessible to users without giving a definitive diagnosis of internal faults. Even when technical support is necessary, the test alone does not establish which component is damaged. The request should describe the checks already completed so that the technician can use them and decide what further tests to perform.

After the checks, the device still does not switch on. Which conclusion is not warranted?

- The power button is certainly damaged
- A technical-support request should be submitted
- The completed checks should be described in the request
- The technician may decide on further tests
- The user must not open the casing

| Available information | Warranted conclusion |
| --- | --- |
| Connection checked and unsuccessful start test | Move to technical support |
| Negative test result | Specific component not identified |
| Checks already completed | Information to pass to the technician |
| Ban on opening the casing | User does not proceed with internal repair |

<div class="spiegazione">

The test determines the procedure’s next step but does not identify the faulty component. The supervisor explicitly states that diagnostic limit. The other options repeat actions or prohibitions present in the guide.

The procedure determines when to request support without claiming to distinguish all possible internal faults. For example, two different components could cause the same failure to start; the passage supplies no test separating those cases. A determined operational step does not make the diagnosis determined too. The question specifically asks for the conclusion exceeding the data, while the other options describe prescribed actions. This distinction between practical decision and complete knowledge also occurs in protocols and user instructions.

**Answer.** The power button is certainly damaged.

</div>
