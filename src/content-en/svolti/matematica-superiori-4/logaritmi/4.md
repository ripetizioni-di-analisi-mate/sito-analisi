## Exercise 1

Find the domain of the function $f(x) = \ln \left( x^2 - 5x + 6 \right)$.

$$
x^2 - 5x + 6 > 0
$$
$$
x^2 - 5x + 6 = 0
\iff
(x - 2)(x - 3) = 0
\iff
x = 2 \quad \text{or} \quad x = 3
$$
$$
x^2 - 5x + 6 > 0
\iff
x < 2 \quad \text{or} \quad x > 3
$$
$$
D = (-\infty, 2) \cup (3, +\infty)
$$

<div class="spiegazione">

The function contains just one logarithm with base $e$, so the only domain condition is that the argument be **strictly positive**. The inequality is strict because the logarithm of $0$ is undefined, since no power of $e$ equals $0$.

To solve the quadratic inequality $x^2 - 5x + 6 > 0$, first find the zeros of the trinomial. Two numbers with sum $5$ and product $6$ are $2$ and $3$, so the trinomial factors as $(x - 2)(x - 3)$ and vanishes at $x = 2$ and $x = 3$.

The graph of $y = x^2 - 5x + 6$ is an upward-opening parabola because the coefficient of $x^2$ is positive. The parabola lies above the $x$-axis outside the interval between the roots, that is, for $x < 2$ and for $x > 3$. At $2$ and $3$ the trinomial equals $0$, so these points are excluded.

The domain is therefore the union of the two open rays $(-\infty, 2)$ and $(3, +\infty)$. For example, $f(0) = \ln 6$ is defined, whereas at $x = \dfrac{5}{2}$ the argument equals $\dfrac{25}{4} - \dfrac{25}{2} + 6 = -\dfrac{1}{4}$ and the function is undefined.

</div>

## Exercise 2

Find the domain of the function $f(x) = \dfrac{\log_2 (x + 1)}{\ln (3 - x)}$.

$$
\begin{cases}
x + 1 > 0 \\[4pt]
3 - x > 0 \\[4pt]
\ln (3 - x) \neq 0
\end{cases}
\iff
\begin{cases}
x > -1 \\[4pt]
x < 3 \\[4pt]
3 - x \neq 1
\end{cases}
\iff
\begin{cases}
x > -1 \\[4pt]
x < 3 \\[4pt]
x \neq 2
\end{cases}
$$
$$
D = (-1, 2) \cup (2, 3)
$$

<div class="spiegazione">

The function is a quotient of two logarithms. It is defined when both the numerator and the denominator are defined and the denominator is different from $0$, so there are three **domain conditions**, which we write as a system.

The argument of the logarithm in the numerator must be positive, and $x + 1 > 0$ gives $x > -1$. The argument of the logarithm in the denominator must be positive, and $3 - x > 0$ gives $x < 3$.

The third condition requires a nonzero denominator. The only number whose logarithm is zero is $1$ because $e^0 = 1$, so $\ln (3 - x) = 0$ is equivalent to $3 - x = 1$, that is, to $x = 2$. The condition $\ln (3 - x) \neq 0$ therefore excludes just the value $x = 2$.

The first two conditions give the interval $(-1, 3)$, from which we remove $2$. The domain is therefore $D = (-1, 2) \cup (2, 3)$. The numerator vanishes at $x = 0$, but this value is in the domain because a zero numerator makes the fraction zero without making it undefined.

</div>

## Exercise 3

Find the domain of the function $f(x) = \sqrt{\log_{\frac{1}{2}} (x - 1)}$.

$$
\begin{cases}
x - 1 > 0 \\[4pt]
\log_{\frac{1}{2}} (x - 1) \geq 0
\end{cases}
$$
$$
\log_{\frac{1}{2}} (x - 1) \geq 0 = \log_{\frac{1}{2}} 1
\iff
x - 1 \leq 1
\iff
x \leq 2
$$
$$
\begin{cases}
x > 1 \\[4pt]
x \leq 2
\end{cases}
\iff
1 < x \leq 2
\qquad
D = (1, 2]
$$

::grafico{f="log(x-1)/log(0.5)" punti="2,0,pieno;1,0,vuoto" asintoti="x=1" area="log(x-1)/log(0.5);0;1.02;2" xmin=-1 xmax=6 ymin=-3 ymax=4 legenda="y = \log_{\frac{1}{2}} (x - 1)" titolo="The logarithm $\log_{\frac{1}{2}} (x - 1)$ is greater than or equal to $0$ for $1 < x \leq 2$, which is the domain of $f$"}

<div class="spiegazione">

The function is the square root of a logarithm. The logarithm is defined if its argument is positive, and the square root is defined if its radicand is greater than or equal to $0$. Both conditions must hold simultaneously and together form the system.

The first condition, $x - 1 > 0$, gives $x > 1$. For the second, write $0$ as a logarithm to the same base, $0 = \log_{\frac{1}{2}} 1$. The base $\dfrac{1}{2}$ is less than $1$, so the logarithmic function is **decreasing**, and the inequality between the logarithms is equivalent to the reversed inequality between their arguments. We obtain $x - 1 \leq 1$, that is, $x \leq 2$.

Combining the conditions gives $1 < x \leq 2$. The endpoint $1$ is excluded because the logarithm of $0$ is undefined. The endpoint $2$ is included because at $x = 2$ the radicand equals $\log_{\frac{1}{2}} 1 = 0$ and $\sqrt{0} = 0$.

The graph confirms the result. The logarithm to base $\dfrac{1}{2}$ of $x - 1$ is positive only where its argument is between $0$ and $1$, that is, for $1 < x < 2$. The domain is therefore $D = (1, 2]$.

</div>

## Exercise 4

Find the domain of the function $f(x) = \log_{x - 1} (5 - x)$.

$$
\begin{cases}
x - 1 > 0 \\[4pt]
x - 1 \neq 1 \\[4pt]
5 - x > 0
\end{cases}
\iff
\begin{cases}
x > 1 \\[4pt]
x \neq 2 \\[4pt]
x < 5
\end{cases}
$$
$$
D = (1, 2) \cup (2, 5)
$$

<div class="spiegazione">

In this function the variable appears in both the **base** and the argument of the logarithm. The base of a logarithm must be positive and different from $1$, and the argument must be positive, so there are three conditions.

The base $x - 1$ is positive for $x > 1$. The base equals $1$ when $x - 1 = 1$, that is, when $x = 2$, and this value must be excluded. The argument $5 - x$ is positive for $x < 5$.

The interval satisfying both $x > 1$ and $x < 5$ is $(1, 5)$, from which we remove $2$. The domain is therefore $D = (1, 2) \cup (2, 5)$.

The value $x = 2$ is excluded for a different reason from the endpoints. At $x = 2$ the function would be $\log_1 3$, that is, the exponent to which $1$ must be raised to obtain $3$. No such exponent exists because $1^y = 1$ for every $y$. At points in the domain the function takes real values, for example $f(3) = \log_2 2 = 1$ and $f(4) = \log_3 1 = 0$.

</div>
