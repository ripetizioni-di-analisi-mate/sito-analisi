## Exercise 1

Solve the inequality $\left( \dfrac{1}{2} \right)^{x - 2} > 8$.

$$
8 = 2^3 = \left( \frac{1}{2} \right)^{-3}
$$
$$
\left( \frac{1}{2} \right)^{x - 2} > \left( \frac{1}{2} \right)^{-3}
\iff
x - 2 < -3
\iff
x < -1
$$

The inequality holds for $x < -1$.

::grafico{f="0.5^(x-2);8" punti="-1,8,vuoto" segmenti="-1,0,-1,8" xmin=-3 xmax=4 ymin=-1 ymax=12 legenda="y = \left(\frac{1}{2}\right)^{x-2};y = 8" titolo="The decreasing graph of $\left(\dfrac{1}{2}\right)^{x-2}$ lies above the line $y = 8$ for $x < -1$"}

<div class="spiegazione">

To compare the two sides, write them as powers with the same base $\dfrac{1}{2}$. The number $8$ is $2^3$, and $2 = \left( \dfrac{1}{2} \right)^{-1}$, so $8 = \left( \dfrac{1}{2} \right)^{-3}$.

The base $\dfrac{1}{2}$ is between $0$ and $1$, so the function $\left( \dfrac{1}{2} \right)^x$ is **decreasing**. By the theorem on inequalities with the same base, comparing the powers in this case is equivalent to comparing the exponents with the **direction reversed**, because for a base less than $1$ the smaller exponent gives the larger power. We therefore obtain $x - 2 < -3$, that is, $x < -1$.

The figure confirms the result. The graph of $\left( \dfrac{1}{2} \right)^{x - 2}$ intersects the line $y = 8$ at the point with horizontal coordinate $-1$ because $\left( \dfrac{1}{2} \right)^{-3} = 8$, and lies above the line to the left of that point. For example, at $x = -2$ the left-hand side is $\left( \dfrac{1}{2} \right)^{-4} = 16 > 8$. The point $x = -1$ is excluded because equality holds there and the inequality is strict.

</div>

## Exercise 2

Solve the inequality $9^{x^2} \leq 3^{x + 3}$.

$$
9^{x^2} = \left( 3^2 \right)^{x^2} = 3^{2x^2}
$$
$$
3^{2x^2} \leq 3^{x + 3}
\iff
2x^2 \leq x + 3
\iff
2x^2 - x - 3 \leq 0
$$
$$
2x^2 - x - 3 = 0
\iff
x = \frac{1 \pm \sqrt{1 + 24}}{4} = \frac{1 \pm 5}{4}
\iff
x = -1 \quad \text{or} \quad x = \frac{3}{2}
$$
$$
2x^2 - x - 3 \leq 0
\iff
-1 \leq x \leq \frac{3}{2}
$$

The inequality holds for $-1 \leq x \leq \dfrac{3}{2}$.

<div class="spiegazione">

The base $9$ is $3^2$, so the power-of-a-power rule gives $3^{2x^2}$ for the left-hand side. Multiplying the exponent $x^2$ by $2$ gives $2x^2$.

Both sides now have the same base $3$, greater than $1$. The function $3^x$ is **increasing**, so comparing the powers is equivalent to comparing their exponents in the **same direction**, and the inequality becomes $2x^2 \leq x + 3$. Moving all terms to the left gives the quadratic inequality $2x^2 - x - 3 \leq 0$.

The corresponding equation has discriminant $1 + 4 \cdot 2 \cdot 3 = 25$, so its two roots are $x = \dfrac{1 - 5}{4} = -1$ and $x = \dfrac{1 + 5}{4} = \dfrac{3}{2}$. The coefficient of $x^2$ is positive, so the parabola $y = 2x^2 - x - 3$ opens upward and takes nonpositive values between its roots. The endpoints are included because the inequality allows equality.

At $x = 0$, which is in the interval, the inequality gives $9^0 = 1 \leq 27 = 3^3$, which is true.

</div>

## Exercise 3

Solve the inequality $0.2^{\frac{x + 1}{x}} \geq 25$.

$$
\text{Domain condition:} \quad x \neq 0 ,
\qquad
0.2 = \frac{1}{5} ,
\qquad
25 = 5^2 = \left( \frac{1}{5} \right)^{-2}
$$
$$
\left( \frac{1}{5} \right)^{\frac{x + 1}{x}} \geq \left( \frac{1}{5} \right)^{-2}
\iff
\frac{x + 1}{x} \leq -2
$$
$$
\frac{x + 1}{x} + 2 \leq 0
\iff
\frac{x + 1 + 2x}{x} \leq 0
\iff
\frac{3x + 1}{x} \leq 0
$$
$$
-\frac{1}{3} \leq x < 0
$$

The inequality holds for $-\dfrac{1}{3} \leq x < 0$.

<div class="spiegazione">

The exponent is a fraction with the unknown in the denominator, so the **domain condition** is $x \neq 0$. The decimal $0.2$ is the fraction $\dfrac{1}{5}$, and $25 = 5^2 = \left( \dfrac{1}{5} \right)^{-2}$, so both sides can be written as powers of $\dfrac{1}{5}$.

The base $\dfrac{1}{5}$ is between $0$ and $1$, so the direction **reverses** when we compare the exponents, giving $\dfrac{x + 1}{x} \leq -2$. This is a rational inequality, and we cannot multiply by $x$ without knowing its sign. Therefore move $-2$ to the left and put the terms over a common denominator to obtain $\dfrac{3x + 1}{x} \leq 0$.

Examine the signs of the two factors. The numerator $3x + 1$ is positive for $x > -\dfrac{1}{3}$ and vanishes at $x = -\dfrac{1}{3}$. The denominator $x$ is positive for $x > 0$. The quotient is negative where the signs are opposite, that is, for $-\dfrac{1}{3} < x < 0$, and vanishes at $x = -\dfrac{1}{3}$, which is included. The value $x = 0$ is excluded by the domain condition.

At $x = -\dfrac{1}{3}$ the exponent is $\dfrac{2}{3} \cdot (-3) = -2$ and the left-hand side is $\left( \dfrac{1}{5} \right)^{-2} = 25$.

</div>
