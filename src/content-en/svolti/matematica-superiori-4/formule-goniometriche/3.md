## Exercise 1

Simplify the expression $E = \sin\left( \dfrac{\pi}{3} + x \right) + \sin\left( \dfrac{\pi}{3} - x \right)$.

$$
\sin\left( \frac{\pi}{3} + x \right) = \sin\frac{\pi}{3}\cos x + \cos\frac{\pi}{3}\sin x = \frac{\sqrt{3}}{2}\cos x + \frac{1}{2}\sin x
$$
$$
\sin\left( \frac{\pi}{3} - x \right) = \sin\frac{\pi}{3}\cos x - \cos\frac{\pi}{3}\sin x = \frac{\sqrt{3}}{2}\cos x - \frac{1}{2}\sin x
$$
$$
E = \frac{\sqrt{3}}{2}\cos x + \frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x - \frac{1}{2}\sin x = \sqrt{3}\cos x
$$

<div class="spiegazione">

The expression contains the sine of a sum and the sine of a difference, both formed from the special angle $\dfrac{\pi}{3}$ and the variable $x$. The trigonometric functions of $\dfrac{\pi}{3}$ have known numerical values, so expand both terms using the formulas until only $\sin x$ and $\cos x$ remain.

For the first term apply the **sine sum** formula with $\alpha = \dfrac{\pi}{3}$ and $\beta = x$, substituting $\sin\dfrac{\pi}{3} = \dfrac{\sqrt{3}}{2}$ and $\cos\dfrac{\pi}{3} = \dfrac{1}{2}$. For the second term apply the **sine difference** formula, which has the same two products with a minus sign between them.

In the sum, $\dfrac{1}{2}\sin x$ and $-\dfrac{1}{2}\sin x$ are opposites and therefore cancel. The two terms $\dfrac{\sqrt{3}}{2}\cos x$ are equal and their sum is $\sqrt{3}\cos x$.

The expression is defined for every real $x$, as is $\sqrt{3}\cos x$, so the equality $E = \sqrt{3}\cos x$ holds for every $x$. For example, with $x = 0$ the left-hand side is $\sin\dfrac{\pi}{3} + \sin\dfrac{\pi}{3} = \sqrt{3}$ and the right-hand side is $\sqrt{3}\cos 0 = \sqrt{3}$.

The first sum-to-product formula gives the same result. Half the sum of $\dfrac{\pi}{3} + x$ and $\dfrac{\pi}{3} - x$ is $\dfrac{\pi}{3}$ and half their difference is $x$, so $E = 2\sin\dfrac{\pi}{3}\cos x = \sqrt{3}\cos x$.

</div>

## Exercise 2

Simplify the expression $E = \cos\left( x + \dfrac{\pi}{4} \right)\cos\left( x - \dfrac{\pi}{4} \right)$.

$$
\cos\left( x + \frac{\pi}{4} \right) = \frac{\sqrt{2}}{2}\cos x - \frac{\sqrt{2}}{2}\sin x = \frac{\sqrt{2}}{2}\,(\cos x - \sin x)
$$
$$
\cos\left( x - \frac{\pi}{4} \right) = \frac{\sqrt{2}}{2}\cos x + \frac{\sqrt{2}}{2}\sin x = \frac{\sqrt{2}}{2}\,(\cos x + \sin x)
$$
$$
\begin{aligned}
E &= \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{2}}{2}\,(\cos x - \sin x)(\cos x + \sin x) \\[6pt]
&= \frac{1}{2}\left( \cos^2 x - \sin^2 x \right) \\[6pt]
&= \frac{1}{2}\cos 2x
\end{aligned}
$$

<div class="spiegazione">

Expand the two factors using the **cosine sum** formula and the **cosine difference** formula, with $\cos\dfrac{\pi}{4} = \sin\dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2}$. In both expansions, factor out the common factor $\dfrac{\sqrt{2}}{2}$. This leaves $\cos x - \sin x$ in the first and $\cos x + \sin x$ in the second.

The product of the two numerical factors is $\dfrac{\sqrt{2}}{2} \cdot \dfrac{\sqrt{2}}{2} = \dfrac{2}{4} = \dfrac{1}{2}$. The product $(\cos x - \sin x)(\cos x + \sin x)$ is a difference times the sum of the same terms, so it equals the difference of squares $\cos^2 x - \sin^2 x$.

The difference $\cos^2 x - \sin^2 x$ is one form of the **cosine double-angle formula**, so it equals $\cos 2x$. The expression therefore simplifies to $\dfrac{1}{2}\cos 2x$, and the equality holds for every real $x$ because both sides are defined everywhere.

The second of Werner's formulas gives the same result. With $\alpha = x + \dfrac{\pi}{4}$ and $\beta = x - \dfrac{\pi}{4}$ we have $\alpha + \beta = 2x$ and $\alpha - \beta = \dfrac{\pi}{2}$, so $E = \dfrac{1}{2}\left( \cos 2x + \cos\dfrac{\pi}{2} \right) = \dfrac{1}{2}\cos 2x$ because $\cos\dfrac{\pi}{2} = 0$.

</div>

## Exercise 3

Simplify the expression $E = \dfrac{\sin 2x + \sin x}{1 + \cos 2x + \cos x}$, stating the values of $x$ for which it is defined.

$$
1 + \cos 2x + \cos x = 1 + 2\cos^2 x - 1 + \cos x = \cos x\,(2\cos x + 1)
$$
$$
\sin 2x + \sin x = 2\sin x\cos x + \sin x = \sin x\,(2\cos x + 1)
$$
$$
\begin{cases}
\cos x \neq 0 \\[4pt]
2\cos x + 1 \neq 0
\end{cases}
\iff
\begin{cases}
x \neq \dfrac{\pi}{2} + k\pi \\[8pt]
x \neq \pm\dfrac{2\pi}{3} + 2k\pi
\end{cases}
$$
$$
E = \frac{\sin x\,(2\cos x + 1)}{\cos x\,(2\cos x + 1)} = \frac{\sin x}{\cos x} = \tan x
$$

<div class="spiegazione">

The denominator contains $\cos 2x$ and $\cos x$, so for $\cos 2x$ choose the form of the **double-angle** formula that uses only cosine, $\cos 2x = 2\cos^2 x - 1$. The terms $1$ and $-1$ cancel, leaving $2\cos^2 x + \cos x$, from which we factor out $\cos x$.

In the numerator, use $\sin 2x = 2\sin x\cos x$ and factor out $\sin x$. This gives the same factor $2\cos x + 1$ as in the denominator.

The fraction is defined when its denominator differs from $0$. A product is zero when one of its factors is zero, so both factors must differ from $0$. Write the two conditions as a system. The first gives $x \neq \dfrac{\pi}{2} + k\pi$. The second is equivalent to $\cos x \neq -\dfrac{1}{2}$, and the angles whose cosine is $-\dfrac{1}{2}$ are $\pm\dfrac{2\pi}{3} + 2k\pi$.

Under these conditions the factor $2\cos x + 1$ differs from $0$ and can be canceled. The remaining quotient is $\dfrac{\sin x}{\cos x}$, the tangent of $x$.

Therefore $E = \tan x$ for $x \neq \dfrac{\pi}{2} + k\pi$ and $x \neq \pm\dfrac{2\pi}{3} + 2k\pi$. At the points $x = \pm\dfrac{2\pi}{3} + 2k\pi$ the tangent exists but the original expression is undefined, so the equality holds only on the indicated set.

</div>
