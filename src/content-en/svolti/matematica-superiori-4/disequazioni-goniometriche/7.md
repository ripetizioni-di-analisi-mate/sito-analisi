## Exercise 1

Solve the system
$$
\begin{cases}
2\sin x \geq 1 \\[4pt]
2\cos x < \sqrt{3}
\end{cases}
$$

$$
2\sin x \geq 1 \iff \sin x \geq \frac{1}{2} \iff \frac{\pi}{6} \leq x \leq \frac{5\pi}{6} \qquad \text{in } [0, 2\pi)
$$
$$
2\cos x < \sqrt{3} \iff \cos x < \frac{\sqrt{3}}{2} \iff \frac{\pi}{6} < x < \frac{11\pi}{6} \qquad \text{in } [0, 2\pi)
$$
$$
\frac{\pi}{6} < x \leq \frac{5\pi}{6}
$$
$$
\frac{\pi}{6} + 2k\pi < x \leq \frac{5\pi}{6} + 2k\pi , \qquad k \in \mathbb{Z}
$$

::grafico{curve="cos(t),sin(t),0.5236,2.618;cos(t),sin(t),2.618,6.8068;t,0.5,-1.4,1.4" segmenti="0.866,-1.35,0.866,1.35" punti="0.866,0.5,vuoto,π/6;-0.866,0.5,pieno,5π/6" etichette="1.15,1.2,x = √3/2;1.25,0.35,y = 1/2" xmin=-1.6 xmax=1.6 ymin=-1.4 ymax=1.4 uguale=1 legenda=0 titolo="The solid arc lies above the line $y = \dfrac{1}{2}$ and to the left of the line $x = \dfrac{\sqrt{3}}{2}$. The point $\dfrac{\pi}{6}$ is excluded and the point $\dfrac{5\pi}{6}$ is included"}

<div class="spiegazione">

In a **system**, both inequalities must be satisfied simultaneously, so the solution set is the intersection of the individual solution sets. Both inequalities have period $2\pi$, so solve them in the same interval $[0, 2\pi)$.

The first becomes $\sin x \geq \dfrac{1}{2}$ on dividing by $2$. The points on the circle with vertical coordinate greater than or equal to $\dfrac{1}{2}$ form the arc from $\dfrac{\pi}{6}$ to $\dfrac{5\pi}{6}$, including the endpoints. The second becomes $\cos x < \dfrac{\sqrt{3}}{2}$. The cosine equals $\dfrac{\sqrt{3}}{2}$ at $\dfrac{\pi}{6}$ and $\dfrac{11\pi}{6}$, and the points with smaller horizontal coordinate lie on the arc from $\dfrac{\pi}{6}$ to $\dfrac{11\pi}{6}$ through $\pi$, excluding the endpoints.

The first condition gives the interval $\left[ \dfrac{\pi}{6}, \dfrac{5\pi}{6} \right]$, and the second excludes only the point $\dfrac{\pi}{6}$, where $\cos x = \dfrac{\sqrt{3}}{2}$. The point $\dfrac{5\pi}{6}$ remains because $\sin x = \dfrac{1}{2}$ there, which satisfies the first inequality, and $\cos x = -\dfrac{\sqrt{3}}{2} < \dfrac{\sqrt{3}}{2}$. The solutions of the system are $\dfrac{\pi}{6} + 2k\pi < x \leq \dfrac{5\pi}{6} + 2k\pi$.

</div>

## Exercise 2

Find the domain of the function $f(x) = \sqrt{2\cos x - 1} + \ln(\sin x)$.

$$
\begin{cases}
2\cos x - 1 \geq 0 \\[4pt]
\sin x > 0
\end{cases}
\iff
\begin{cases}
\cos x \geq \dfrac{1}{2} \\[6pt]
\sin x > 0
\end{cases}
$$
$$
\text{in } [-\pi, \pi) : \qquad
\cos x \geq \frac{1}{2} \iff -\frac{\pi}{3} \leq x \leq \frac{\pi}{3} ,
\qquad
\sin x > 0 \iff 0 < x < \pi
$$
$$
0 < x \leq \frac{\pi}{3}
$$
$$
D = \left\{ x \in \mathbb{R} : 2k\pi < x \leq \frac{\pi}{3} + 2k\pi ,\ k \in \mathbb{Z} \right\}
$$

<div class="spiegazione">

The function is the sum of two terms, and a sum is defined if both terms are defined. The first term is a square root, so its radicand $2\cos x - 1$ must be greater than or equal to $0$. The second is a logarithm, so its argument $\sin x$ must be greater than $0$. The inequality is strict because the logarithm of $0$ is undefined. Write these two conditions as a system.

Work in the interval $[-\pi, \pi)$ because the solutions of the first condition lie around $x = 0$ and form one interval there. The cosine equals $\dfrac{1}{2}$ at $\pm\dfrac{\pi}{3}$ and is greater than or equal to $\dfrac{1}{2}$ between those two angles. The sine is positive for $0 < x < \pi$, where the points on the circle have positive vertical coordinates.

The common part of the intervals runs from $0$, excluded, to $\dfrac{\pi}{3}$, included. The number $0$ is excluded because $\ln(\sin 0) = \ln 0$ is undefined. Adding integer multiples of the period $2\pi$ gives the **domain** $2k\pi < x \leq \dfrac{\pi}{3} + 2k\pi$. For example, $f\left( \dfrac{\pi}{3} \right) = \sqrt{0} + \ln\dfrac{\sqrt{3}}{2}$ is defined, whereas for $x = -\dfrac{\pi}{6}$ the sine is negative and its logarithm is undefined.

</div>

## Exercise 3

Find the domain of the function $f(x) = \dfrac{\sqrt{\sin 2x}}{2\sin x - 1}$ in the interval $[0, 2\pi)$.

$$
\begin{cases}
\sin 2x \geq 0 \\[4pt]
2\sin x - 1 \neq 0
\end{cases}
$$
$$
\sin 2x \geq 0
\iff
2k\pi \leq 2x \leq \pi + 2k\pi
\iff
k\pi \leq x \leq \frac{\pi}{2} + k\pi
$$
$$
\text{in } [0, 2\pi) : \qquad 0 \leq x \leq \frac{\pi}{2} \quad \text{or} \quad \pi \leq x \leq \frac{3\pi}{2}
$$
$$
2\sin x - 1 \neq 0 \iff x \neq \frac{\pi}{6} ,\ x \neq \frac{5\pi}{6}
$$
$$
D \cap [0, 2\pi) = \left[ 0, \frac{\pi}{6} \right) \cup \left( \frac{\pi}{6}, \frac{\pi}{2} \right] \cup \left[ \pi, \frac{3\pi}{2} \right]
$$

<div class="spiegazione">

There are two domain restrictions, and both must hold. The radicand $\sin 2x$ must be greater than or equal to $0$, and the denominator $2\sin x - 1$ must differ from $0$.

The first condition is an inequality with a **transformed argument**. The sine of an angle $t$ is greater than or equal to $0$ for $2k\pi \leq t \leq \pi + 2k\pi$. With $t = 2x$, divide by $2$, and the period becomes $k\pi$. In $[0, 2\pi)$, take $k = 0$ and $k = 1$ to obtain the intervals $\left[ 0, \dfrac{\pi}{2} \right]$ and $\left[ \pi, \dfrac{3\pi}{2} \right]$. With $k = 2$, the interval starts at $2\pi$, which does not belong to $[0, 2\pi)$.

The second condition excludes angles with $\sin x = \dfrac{1}{2}$, namely $\dfrac{\pi}{6}$ and $\dfrac{5\pi}{6}$. The value $\dfrac{5\pi}{6}$ does not lie in the intervals found, so it removes nothing. The value $\dfrac{\pi}{6}$ lies in the first interval, splitting it into two parts. The domain in $[0, 2\pi)$ therefore consists of **three intervals**. For example, at $x = \pi$ we have $\sin 2\pi = 0$ and the denominator equals $-1$, so $f(\pi) = 0$ is defined.

</div>
