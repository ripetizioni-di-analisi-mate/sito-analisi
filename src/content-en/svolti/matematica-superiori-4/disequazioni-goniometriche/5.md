## Exercise 1

Solve the inequality $\sin^2 x + (\sqrt{3} - 1)\sin x\cos x - \sqrt{3}\cos^2 x < 0$.

$$
\cos x \neq 0 :
\qquad
\tan^2 x + (\sqrt{3} - 1)\tan x - \sqrt{3} < 0
$$
$$
t = \tan x ,
\qquad
t^2 + (\sqrt{3} - 1)\,t - \sqrt{3} = (t + \sqrt{3})(t - 1)
$$
$$
(t + \sqrt{3})(t - 1) < 0
\iff
-\sqrt{3} < t < 1
\iff
-\frac{\pi}{3} + k\pi < x < \frac{\pi}{4} + k\pi
$$
$$
\cos x = 0 :
\qquad
\sin^2 x = 1 ,
\qquad
1 < 0 \quad \text{false}
$$
$$
-\frac{\pi}{3} + k\pi < x < \frac{\pi}{4} + k\pi , \qquad k \in \mathbb{Z}
$$

<div class="spiegazione">

Every term on the left-hand side has total degree $2$ in $\sin x$ and $\cos x$, so the inequality is **homogeneous** of degree two. There are two cases. If $\cos x \neq 0$, divide both sides by $\cos^2 x$, which is positive, so the direction is unchanged. Since $\dfrac{\sin^2 x}{\cos^2 x} = \tan^2 x$ and $\dfrac{\sin x\cos x}{\cos^2 x} = \tan x$, this gives a quadratic inequality in the tangent.

With $t = \tan x$, the trinomial factors by finding two numbers with sum $\sqrt{3} - 1$ and product $-\sqrt{3}$, namely $\sqrt{3}$ and $-1$. Indeed, $(t + \sqrt{3})(t - 1) = t^2 - t + \sqrt{3}\,t - \sqrt{3}$. The graph of the trinomial opens upward, and the trinomial is negative between the roots $-\sqrt{3}$ and $1$. Tangent is increasing on each branch and equals $-\sqrt{3}$ at $-\dfrac{\pi}{3}$ and $1$ at $\dfrac{\pi}{4}$, so $-\sqrt{3} < \tan x < 1$ for $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{4} + k\pi$.

If $\cos x = 0$, that is, $x = \dfrac{\pi}{2} + k\pi$, the Pythagorean identity gives $\sin^2 x = 1$, and the left-hand side equals $1$, which is not negative. These values therefore **are not solutions**, and the solution set is the one found in the first case. For $x = 0$, the left-hand side equals $-\sqrt{3} < 0$, and indeed $0$ is a solution.

</div>

## Exercise 2

Solve the inequality $\sqrt{3}\sin^2 x + 2\sin x\cos x - \sqrt{3}\cos^2 x \geq 0$.

$$
\cos x \neq 0 :
\qquad
\sqrt{3}\,t^2 + 2t - \sqrt{3} \geq 0 , \qquad t = \tan x
$$
$$
t = \frac{-2 \pm \sqrt{4 + 12}}{2\sqrt{3}} = \frac{-2 \pm 4}{2\sqrt{3}}
\qquad
\Longrightarrow
\qquad
t_1 = -\sqrt{3} , \quad t_2 = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}
$$
$$
\tan x \leq -\sqrt{3} \quad \text{or} \quad \tan x \geq \frac{\sqrt{3}}{3}
$$
$$
\frac{\pi}{2} + k\pi < x \leq \frac{2\pi}{3} + k\pi
\quad \text{or} \quad
\frac{\pi}{6} + k\pi \leq x < \frac{\pi}{2} + k\pi
$$
$$
\cos x = 0 :
\qquad
\sqrt{3} \geq 0 \quad \text{true}
$$
$$
\frac{\pi}{6} + k\pi \leq x \leq \frac{2\pi}{3} + k\pi , \qquad k \in \mathbb{Z}
$$

<div class="spiegazione">

The inequality is homogeneous. For $\cos x \neq 0$, divide by $\cos^2 x > 0$ and, with $t = \tan x$, obtain the trinomial $\sqrt{3}\,t^2 + 2t - \sqrt{3}$. The discriminant is $4 + 4 \cdot 3 = 16$, so the roots are $\dfrac{-6}{2\sqrt{3}} = -\sqrt{3}$ and $\dfrac{2}{2\sqrt{3}} = \dfrac{\sqrt{3}}{3}$. The coefficient of $t^2$ is positive, hence the trinomial is greater than or equal to $0$ for values at or below the smaller root or at or above the larger root.

Examine the two conditions on the branch $\left( -\dfrac{\pi}{2}, \dfrac{\pi}{2} \right)$ of tangent. The condition $\tan x \geq \dfrac{\sqrt{3}}{3}$ holds from $\dfrac{\pi}{6}$, included, to the asymptote $\dfrac{\pi}{2}$. The condition $\tan x \leq -\sqrt{3}$ holds from $-\dfrac{\pi}{2}$, excluded, to $-\dfrac{\pi}{3}$, included. Adding the period $\pi$ expresses the same interval from $\dfrac{\pi}{2}$ to $\dfrac{2\pi}{3}$, placing the two intervals next to each other.

For $\cos x = 0$, we have $\sin^2 x = 1$ and the left-hand side equals $\sqrt{3}$, which is greater than $0$. Therefore $x = \dfrac{\pi}{2} + k\pi$ is also a solution, and this value joins the two intervals found. The solutions are $\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{2\pi}{3} + k\pi$. By the double-angle identities, the left-hand side becomes $\sin 2x - \sqrt{3}\cos 2x = 2\sin\left( 2x - \dfrac{\pi}{3} \right)$, and the condition $0 \leq 2x - \dfrac{\pi}{3} \leq \pi$ gives the same result.

</div>

## Exercise 3

Solve the inequality $\sin^2 x + 2\sqrt{3}\sin x\cos x - \cos^2 x \leq 1$.

$$
1 = \sin^2 x + \cos^2 x
$$
$$
\sin^2 x + 2\sqrt{3}\sin x\cos x - \cos^2 x - \sin^2 x - \cos^2 x \leq 0
$$
$$
2\sqrt{3}\sin x\cos x - 2\cos^2 x \leq 0
\iff
\sqrt{3}\sin x\cos x - \cos^2 x \leq 0
$$
$$
\cos x \neq 0 :
\qquad
\sqrt{3}\tan x - 1 \leq 0
\iff
\tan x \leq \frac{\sqrt{3}}{3}
\iff
-\frac{\pi}{2} + k\pi < x \leq \frac{\pi}{6} + k\pi
$$
$$
\cos x = 0 :
\qquad
0 \leq 0 \quad \text{true}
$$
$$
-\frac{\pi}{2} + k\pi \leq x \leq \frac{\pi}{6} + k\pi , \qquad k \in \mathbb{Z}
$$

<div class="spiegazione">

The left-hand side is homogeneous of degree two, but the right-hand side is the constant term $1$, of degree $0$. By the **Pythagorean identity**, write $1 = \sin^2 x + \cos^2 x$. After all terms are moved to the left-hand side, the terms in $\sin^2 x$ cancel and the terms in $\cos^2 x$ give $-\cos^2 x - \cos^2 x = -2\cos^2 x$. Dividing by $2$, which is positive, gives an inequality **reducible to homogeneous form** in which the coefficient of $\sin^2 x$ is $0$.

For $\cos x \neq 0$, dividing by $\cos^2 x > 0$ gives $\sqrt{3}\tan x - 1 \leq 0$, that is, $\tan x \leq \dfrac{1}{\sqrt{3}} = \dfrac{\sqrt{3}}{3}$. Tangent is increasing on the branch $\left( -\dfrac{\pi}{2}, \dfrac{\pi}{2} \right)$ and equals $\dfrac{\sqrt{3}}{3}$ at $\dfrac{\pi}{6}$, so the condition holds from $-\dfrac{\pi}{2}$, excluded, to $\dfrac{\pi}{6}$, included.

For $\cos x = 0$, the left-hand side $\sqrt{3}\sin x\cos x - \cos^2 x$ equals $0$, and the inequality $0 \leq 0$ is true. Hence the values $x = -\dfrac{\pi}{2} + k\pi$, excluded in the first case, are solutions, and the left endpoint is now **included**. Substitution of $x = \dfrac{\pi}{2}$ into the original inequality gives $1 + 0 - 0 = 1 \leq 1$.

</div>
