## Exercise 1

Determine whether the following functions are even, odd, or neither even nor odd:
$$
f(x) = x^4 - 3x^2, \qquad
g(x) = \frac{x^3}{x^2 + 1}, \qquad
h(x) = x^2 + x .
$$

$$
f(-x) = (-x)^4 - 3(-x)^2 = x^4 - 3x^2 = f(x)
$$

$$
g(-x) = \frac{(-x)^3}{(-x)^2 + 1} = \frac{-x^3}{x^2 + 1} = -g(x)
$$

$$
h(1) = 2, \qquad h(-1) = 0
$$

$f$ is **even**, $g$ is **odd**, $h$ is **neither even nor odd**.

::grafico{f="x^4-3*x^2;x^3/(x^2+1)" xmin=-2.5 xmax=2.5 ymin=-3 ymax=4 titolo="$y = x^4 - 3x^2$ is symmetric with respect to the $y$-axis; $y = \dfrac{x^3}{x^2 + 1}$ (dashed) is symmetric with respect to the origin"}

<div class="spiegazione">

The three functions are defined on $\mathbb{R}$, a set **symmetric with respect to the origin**, so checking parity makes sense. For $f$ and $g$ we compute $f(-x)$ by substituting $-x$ for $x$: even powers absorb the sign, because $(-x)^2 = x^2$ and $(-x)^4 = x^4$, while odd powers bring it out, because $(-x)^3 = -x^3$. The result is $f(-x) = f(x)$ for every $x$, so $f$ is **even**; and $g(-x) = -g(x)$ for every $x$, so $g$ is **odd**.

For $h$ a single point contradicting *both* equalities is enough: since $h(-1) = 0$ while $h(1) = 2$ and $-h(1) = -2$, the value $h(-1)$ differs both from $h(1)$ and from $-h(1)$, therefore $h$ is **neither even nor odd**.

</div>

## Exercise 2

Verify that the function
$$
f(x) = \ln \frac{1 - x}{1 + x}
$$
is odd on its natural domain.

$$
\frac{1 - x}{1 + x} > 0
\;\Longrightarrow\;
D = (-1, 1)
$$

$$
f(-x)
= \ln \frac{1 + x}{1 - x}
= \ln \left( \frac{1 - x}{1 + x} \right)^{-1}
= - \ln \frac{1 - x}{1 + x}
= -f(x)
$$

<div class="spiegazione">

The logarithm requires a positive argument: the ratio $\dfrac{1 - x}{1 + x}$ is positive when numerator and denominator have the *same* sign, so for $-1 < x < 1$. The domain $(-1, 1)$ is **symmetric** with respect to the origin, therefore checking parity makes sense.

Substituting $-x$ for $x$, the argument becomes $\dfrac{1 + x}{1 - x}$, which is the **reciprocal** of the original argument. Since the logarithm of a reciprocal is the opposite of the logarithm, $\ln t^{-1} = -\ln t$ for $t > 0$, one obtains $f(-x) = -f(x)$ for every $x$ in the domain, so $f$ is **odd**.

</div>

## Exercise 3

Verify that the function
$$
f(x) = \ln \left( x + \sqrt{x^2 + 1} \right)
$$
is defined and odd on all of $\mathbb{R}$.

$$
\sqrt{x^2 + 1} > \sqrt{x^2} = |x| \geq -x
\;\Longrightarrow\;
x + \sqrt{x^2 + 1} > 0 \ \text{ for every } x
$$

$$
\left( \sqrt{x^2 + 1} - x \right)\left( \sqrt{x^2 + 1} + x \right) = x^2 + 1 - x^2 = 1
\;\Longrightarrow\;
\sqrt{x^2 + 1} - x = \frac{1}{x + \sqrt{x^2 + 1}}
$$

$$
f(-x)
= \ln \left( \sqrt{x^2 + 1} - x \right)
= \ln \frac{1}{x + \sqrt{x^2 + 1}}
= -f(x)
$$

<div class="spiegazione">

The root is defined everywhere, because $x^2 + 1 > 0$ for every $x$. For the domain of the logarithm we need $x + \sqrt{x^2 + 1} > 0$: since $x^2 + 1 > x^2$, the root satisfies $\sqrt{x^2 + 1} > |x|$, and $|x| \geq -x$, so the sum $x + \sqrt{x^2 + 1}$ is **positive** for every $x$, *even* when $x$ is negative. The domain is $\mathbb{R}$, symmetric with respect to the origin.

For parity we compute $f(-x) = \ln\left(\sqrt{x^2 + 1} - x\right)$. The product $\left(\sqrt{x^2 + 1} - x\right)\left(\sqrt{x^2 + 1} + x\right)$ equals $1$, because it is a **difference of squares**, so $\sqrt{x^2 + 1} - x$ is the reciprocal of $x + \sqrt{x^2 + 1}$. Since the logarithm of a reciprocal is the opposite of the logarithm, we conclude that $f(-x) = -f(x)$ for every $x$, therefore $f$ is **odd**.

</div>
