## Exercise 1

An instrument always reads $25\,\mathrm g$ higher than the values of known reference masses. Which description is correct?

- There is a positive systematic offset
- The measurements are exact because the deviation repeats
- Averaging many readings will certainly remove the offset
- The deviation is necessarily random

::grafico{f="x;x+25" xmin=0 xmax=42 ymin=0 ymax=69 punti="30,30,pieno,A;30,55,pieno,B" segmenti="30,30,30,55" nomi="m (g),reading (g)" legenda="\text{ideal};\text{with offset}" titolo="Readings are 25 g above the reference along the scale in use"}

There is a positive systematic offset.

<div class="spiegazione">

Find the deviation by subtracting the reference from the reading. It is positive and repeats for the samples compared. This indicates a systematic offset over the range examined. Averaging many readings would still give a value displaced from the reference masses. Here the reading exceeds the reference by $25\,\mathrm g$.

</div>

## Exercise 2

Two instruments measure the same central value $200\,\mathrm{cm}$. The first has uncertainty $7\,\mathrm{cm}$ and the second has uncertainty $14\,\mathrm{cm}$. Which measurement has smaller relative uncertainty?

- The first instrument’s reading
- The second instrument’s reading
- They have the same relative uncertainty
- The comparison requires a mass measurement

The first instrument’s reading.

<div class="spiegazione">

Relative uncertainty divides the absolute uncertainty by the central value. The denominator is the same for both measurements, and the first instrument has the smaller numerator. It therefore has the smaller ratio. This comparison needs no change of length unit. The ratio $7/200$ is half the ratio $14/200$.

</div>

## Exercise 3

Are measurements $(20\pm2)\,\mathrm{cm}$ and $(23\pm2)\,\mathrm{cm}$ compatible under the interval overlap rule?

- Yes, the intervals overlap
- No, because their central values differ
- Yes, because they always have the same true value
- No, because the uncertainties must be zero

Yes, the intervals overlap.

<div class="spiegazione">

For each measurement, subtract the uncertainty for the lower endpoint and add it for the upper endpoint. Look for a common part of the two intervals. Their inner endpoints leave an overlap, so the rule classifies the readings as compatible. The central values can still differ. The intervals are $[18;22]$ and $[21;25]\,\mathrm{cm}$.

</div>
