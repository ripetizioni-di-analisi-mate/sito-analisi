## Exercise 1

A portal access code has $5$ digits, each from $0$ to $9$. Digits can repeat. How many different codes can be formed?

- A) $50$
- B) $30\,240$
- C) $100\,000$
- D) $59\,049$
- E) $252$

$$
D'_{10,5} = 10^5 = 100\,000
$$

<div class="spiegazione">

Digit order matters in a code and digits may repeat, so count **ordered selections with repetition** from $10$ digits, making $5$ choices for $5$ positions. Each of the $5$ positions can be filled in $10$ ways, giving $10^5 = 100\,000$ codes. Option B, $D_{10,5} = 30\,240$, excludes repeated digits. Option D, $9^5$, excludes $0$. Option A, $10 \cdot 5$, adds the choices at the individual positions instead of multiplying them. The correct answer is **C**.

</div>

## Exercise 2

A case file code consists of $2$ letters chosen from the $21$ letters of the Italian alphabet, followed by $2$ digits from $0$ to $9$. Letters and digits can repeat. How many different codes can be formed?

- A) $44\,100$
- B) $37\,800$
- C) $541$
- D) $4410$
- E) $923\,521$

$$
\begin{aligned}
21^2 \cdot 10^2
&= 441 \cdot 100 \\[6pt]
&= 44\,100
\end{aligned}
$$

<div class="spiegazione">

The code has four positions. By the **multiplication principle**, multiply the number of ways to fill each position, $21$ for each of the two letters and $10$ for each of the two digits. This gives $21^2 \cdot 10^2 = 44\,100$ codes. Option B, $21 \cdot 20 \cdot 10 \cdot 9 = 37\,800$, excludes repetition. Option C, $441 + 100$, adds the counts instead of multiplying. Option E, $31^4$, treats all letters and digits as a single set of $31$ symbols available at every position. The correct answer is **A**.

</div>

## Exercise 3

Each position in a DNA sequence holds one of the $4$ bases A, C, G, and T. Bases may repeat. How many different sequences of $8$ bases are possible?

- A) $256$
- B) $4096$
- C) $32$
- D) $6561$
- E) $65\,536$

$$
\begin{aligned}
4^8 &= \left(4^4\right)^2 \\[6pt]
&= 256^2 \\[6pt]
&= 65\,536
\end{aligned}
$$

<div class="spiegazione">

Each sequence has $8$ positions, each occupied by one of $4$ symbols, with repetition allowed. For **ordered selections with repetition**, the number of sequences is $4^8$. The base of the power is the number of symbols and the exponent is the number of positions. Since $4^4 = 256$, we have $4^8 = 256^2 = 65\,536$. Option B, $8^4 = 4096$, switches the base and the exponent. Option A, $4^4 = 256$, gives only the first step of the calculation. Option C, $4 \cdot 8$, multiplies the number of symbols by the number of positions. The correct answer is **E**.

</div>
