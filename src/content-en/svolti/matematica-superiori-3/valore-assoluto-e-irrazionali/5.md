## Exercise 1

Solve $\sqrt{x-1}=1$.

$$
\begin{aligned}
\sqrt{x-1}=1 &\iff x-1=1 \\[4pt]
&\iff x=2,\\[4pt]
S&=\{2\}.
\end{aligned}
$$

::grafico{f="sqrt(x-1);1" xmin=-0.3 xmax=6 ymin=-1 ymax=3 punti="1,0,pieno;2,1,pieno;5,2,pieno" titolo="The domain begins at $1$ and the equation holds at $2$"}

<div class="spiegazione">

The right-hand side is positive, so we can square both sides. At $x=2$, the radicand equals $1$ and the root equals $\sqrt1=1$, as required.

The square root is real when $x-1\geq0$, so $x\geq1$. Throughout that domain the square root is nonnegative. The equation asks when the radicand has square root $1$. Squaring $1$ gives $1$, so we require $x-1=1$. At the boundary $x=1$, the square root is $0$, so the value belongs to the domain but is not a solution. At $x=5$ the square root is $2$, another allowed value that is too large for the equation. The graph highlights these two conditions. The curve begins where the radicand is zero and meets the line at height $1$ when $x=2$.

Uniqueness also follows because different nonnegative radicands have different square roots. Since $x-1$ increases with $x$, the graph can cross height $1$ only once.

</div>

## Exercise 2

Solve $2-\sqrt{3x+1}=-2$.

$$
\begin{aligned}
2-\sqrt{3x+1}=-2 &\iff \sqrt{3x+1}=4 \\[4pt]
&\iff 3x+1=16\\[4pt]
&\iff x=5.
\end{aligned}
$$

<div class="spiegazione">

Isolating the square root gives the positive right-hand side $4$. Square at this point to avoid expanding the square of a difference that still contains the root. At $x=5$ the original expression equals $2-\sqrt{16}=-2$.

To isolate the radical, subtract $2$ from both sides to obtain $-\sqrt{3x+1}=-4$. Multiplying by $-1$ gives the form used in the calculation. The domain is $x\geq-\dfrac13$, because $3x+1\geq0$ there. On this set the square root is nonnegative and its square equals the radicand. From $3x+1=16$ we get $3x=15$, so $x=5$. This value belongs to the domain and passes the check in the original formula. Squaring before isolating the radical would leave the cross term $-4\sqrt{3x+1}$ on the left. Isolating the radical avoids that intermediate term.

After isolation, squaring requires $4$ to be the square root of $3x+1$. Since $4$ is positive, the step is valid in the reverse direction too.

</div>

## Exercise 3

Solve $\sqrt{2x+5}+3=1$.

$$
\begin{aligned}
\sqrt{2x+5}&=1-3=-2,\\[4pt]
\sqrt{2x+5}&\geq0 \qquad (x\geq-\tfrac52),\\[4pt]
S&=\varnothing.
\end{aligned}
$$

::grafico{f="sqrt(2*x+5)+3;1" xmin=-3.4 xmax=3 ymin=-0.5 ymax=7 punti="-2.5,3,pieno" titolo="The translated root has minimum $3$, above height $1$"}

<div class="spiegazione">

The domain contains the values for which $2x+5\geq0$. Throughout that domain the side containing the square root is nonnegative, so equality with $-2$ is impossible. Squaring would make the squares of $2$ and $-2$ equal and introduce an extraneous candidate.

The result can be seen from the left-hand side even before isolating the root. On the domain, $\sqrt{2x+5}+3\geq3$. The smallest value, $3$, occurs at $x=-\dfrac52$, where the radicand is zero. The required value $1$ is below this minimum. If instead we incorrectly impose only $2x+5=4$, we obtain $x=-\dfrac12$. Substitution in the original expression gives $\sqrt4+3=5$, which is different from $1$. The candidate arises because $2$ and $-2$ have the same square. Checking the signs avoids equating two sides whose signs are opposite.

The translated root graph starts at $\left(-\dfrac52,3\right)$. To the right of that point the ordinates increase. The line $y=1$ always remains below the curve.

</div>
