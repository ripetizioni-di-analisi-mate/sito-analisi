## Exercise 1

Determine the domain of the function
$$
f(x) = \ln \left(4 - x^{2}\right) + \ln (x + 1) .
$$

$$
\begin{cases}
4 - x^{2} > 0 \\
x + 1 > 0
\end{cases}
\iff
\begin{cases}
-2 < x < 2 \\
x > -1
\end{cases}
\iff -1 < x < 2
$$

Domain: $-1 < x < 2$.

<div class="spiegazione">

The **domain** of a function given by a formula is the set of real numbers for which the formula is meaningful. The function is a sum of two natural logarithms, and each logarithm exists only if its argument is positive; the two conditions must be satisfied together, so they form a system.

The first condition is $4 - x^{2} > 0$, that is, $x^{2} < 4$. The trinomial $4 - x^{2} = (2 - x)(2 + x)$ is positive between the roots $-2$ and $2$, therefore the condition is equivalent to $-2 < x < 2$. The second condition, $x + 1 > 0$, is equivalent to $x > -1$.

The intersection of the two sets is the interval $-1 < x < 2$. The endpoint $-1$ is excluded because it makes the argument of the second logarithm zero, and the endpoint $2$ because it makes the argument of the first zero.

The properties of logarithms would allow one to write $f(x) = \ln \bigl((4 - x^{2})(x + 1)\bigr)$, but this expression has a larger domain. For $x = -3$ the argument equals $(4 - 9)(-3 + 1) = 10 > 0$, whereas the given function **is not defined** at $x = -3$, because $\ln(-2)$ does not exist. The domain is therefore computed on the given formula.

</div>

## Exercise 2

Determine the domain of the function
$$
f(x) = \sqrt{\log_{\frac{1}{2}} (x - 1)} .
$$

$$
\begin{cases}
x - 1 > 0 \\
\log_{\frac{1}{2}} (x - 1) \geq 0
\end{cases}
\iff
\begin{cases}
x > 1 \\
x - 1 \leq 1
\end{cases}
\iff 1 < x \leq 2
$$

Domain: $1 < x \leq 2$.

::grafico{f="sqrt(log(x-1)/log(0.5))" xmin=-0.5 xmax=4 ymin=-0.5 ymax=3 asintoti="x=1" punti="2,0,pieno" legenda="y = \sqrt{\log_{\frac{1}{2}} (x - 1)}" titolo="The graph of $y = \sqrt{\log_{\frac{1}{2}} (x - 1)}$ exists only for $1 < x \leq 2$, where the logarithm is nonnegative"}

<div class="spiegazione">

The function is the square root of a logarithm, so two conditions are needed together: the argument of the logarithm must be positive and the radicand, that is, the logarithm itself, must be nonnegative.

The first condition gives $x > 1$. For the second one writes $0 = \log_{\frac{1}{2}} 1$; the base $\dfrac{1}{2}$ lies between $0$ and $1$, so the logarithmic function is strictly decreasing and the direction is **reversed** when passing to the arguments. The condition $\log_{\frac{1}{2}} (x - 1) \geq 0$ is therefore equivalent to $x - 1 \leq 1$, that is, to $x \leq 2$.

The intersection with $x > 1$ gives the domain $1 < x \leq 2$. The point $x = 2$ belongs to the domain, because the argument equals $1$, the logarithm equals $0$ and the root equals $0$. For $x > 2$ the argument exceeds $1$ and the logarithm to base $\dfrac{1}{2}$ is negative: for example, for $x = 3$ one has $\log_{\frac{1}{2}} 2 = -1$, and the root is not defined.

With base $2$ instead of $\dfrac{1}{2}$ the direction would be preserved and the domain would be $x \geq 2$; the result therefore depends on the **monotonicity** of the logarithmic function.

</div>

## Exercise 3

Determine the domain of the function
$$
f(x) = \frac{1}{\log_2 \left(x^{2} - 3\right)} .
$$

$$
\begin{cases}
x^{2} - 3 > 0 \\
\log_2 \left(x^{2} - 3\right) \neq 0
\end{cases}
\iff
\begin{cases}
x^{2} > 3 \\
x^{2} - 3 \neq 1
\end{cases}
\iff
\begin{cases}
x < -\sqrt{3} \ \vee \ x > \sqrt{3} \\
x \neq -2 , \ x \neq 2
\end{cases}
$$

Domain: $x < -2 \ \vee \ -2 < x < -\sqrt{3} \ \vee \ \sqrt{3} < x < 2 \ \vee \ x > 2$.

<div class="spiegazione">

The function is a fraction with a logarithm in the denominator. The logarithm must exist, so its argument must be positive; moreover, the denominator must be nonzero.

The first condition is $x^{2} - 3 > 0$, that is, $x^{2} > 3$. The trinomial $x^{2} - 3$ is positive outside the roots $-\sqrt{3}$ and $\sqrt{3}$, therefore the condition is equivalent to $x < -\sqrt{3}$ or $x > \sqrt{3}$.

For the second condition the **definition of logarithm** is used, according to which $\log_2 A = 0$ if and only if $A = 2^{0} = 1$. The denominator therefore vanishes when $x^{2} - 3 = 1$, that is, when $x^{2} = 4$, and this happens for $x = -2$ and for $x = 2$. Both values satisfy the first condition, because $2 > \sqrt{3} \approx 1.73$, therefore they must be removed from the domain.

The domain consists of four open intervals: $x < -2$, $-2 < x < -\sqrt{3}$, $\sqrt{3} < x < 2$ and $x > 2$. The function is even, because $f(-x) = f(x)$, and indeed the domain is symmetric with respect to the origin.

</div>
