## Exercise 1

Solve the equation
$$
\log_2 (x - 1) = \log_2 (7 - x) .
$$

Domain conditions:
$$
\begin{cases}
x - 1 > 0 \\
7 - x > 0
\end{cases}
\iff
\begin{cases}
x > 1 \\
x < 7
\end{cases}
\iff 1 < x < 7
$$

$$
x - 1 = 7 - x \iff 2x = 8 \iff x = 4
$$

The value $x = 4$ satisfies the domain conditions.

Solution: $x = 4$.

<div class="spiegazione">

The arguments of the two logarithms contain the unknown, so before solving we require *both* of them to be positive; the two conditions must be satisfied together and form the system, which gives $1 < x < 7$. The two sides are logarithms to the same base and the logarithmic function is **injective**, therefore the equation is equivalent to the **equality of the arguments** $x - 1 = 7 - x$, from which $x = 4$. Since $4$ belongs to the interval $(1, 7)$, the domain conditions are satisfied and $x = 4$ is **the solution**.

</div>

## Exercise 2

Solve the equation
$$
\log_3 (2x + 1) = \log_3 (x + 4) .
$$

Domain conditions:
$$
\begin{cases}
2x + 1 > 0 \\
x + 4 > 0
\end{cases}
\iff
\begin{cases}
x > -\dfrac{1}{2} \\[8pt]
x > -4
\end{cases}
\iff x > -\frac{1}{2}
$$

$$
2x + 1 = x + 4 \iff x = 3
$$

The value $x = 3$ satisfies the domain conditions.

Solution: $x = 3$.

<div class="spiegazione">

The system of domain conditions requires *both* arguments to be positive; the **more restrictive** condition is $x > -\dfrac{1}{2}$, so the system is equivalent to this single inequality. By the **injectivity** of the logarithmic function the equation is equivalent to the equality of the arguments, a linear equation with solution $x = 3$. Since $3 > -\dfrac{1}{2}$, the solution is **acceptable**.

</div>

## Exercise 3

Solve the equation
$$
\log_5 (x^{2} - 3) = \log_5 (2x) .
$$

Domain conditions:
$$
\begin{cases}
x^{2} - 3 > 0 \\
2x > 0
\end{cases}
\iff
\begin{cases}
x < -\sqrt{3} \ \text{or} \ x > \sqrt{3} \\
x > 0
\end{cases}
\iff x > \sqrt{3}
$$

$$
x^{2} - 3 = 2x \iff x^{2} - 2x - 3 = 0 \iff x = 3 \ \text{or} \ x = -1
$$

The value $x = 3$ satisfies the domain conditions; the value $x = -1$ does *not* satisfy them and is **discarded**.

Solution: $x = 3$.

<div class="spiegazione">

The first condition of the system is a quadratic inequality: the trinomial $x^{2} - 3$ is positive outside the roots $\pm\sqrt{3}$. The intersection with $2x > 0$, that is $x > 0$, leaves *only* $x > \sqrt{3}$. The equality of the arguments gives the quadratic equation $x^{2} - 2x - 3 = 0$, with solutions $x = 3$ and $x = -1$. Since $3 > \sqrt{3}$, the value $x = 3$ is **acceptable**; for $x = -1$ the argument $2x = -2$ is negative, so the logarithm on the right-hand side does not exist and the solution is **discarded**.

</div>
