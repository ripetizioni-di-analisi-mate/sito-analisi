## Exercise 1

Solve the inequality
$$
(\log_2 x)^{2} - \log_2 x - 2 \leq 0 .
$$

$$
x > 0 , \qquad t = \log_2 x
$$
$$
t^{2} - t - 2 \leq 0 \iff (t - 2)(t + 1) \leq 0 \iff -1 \leq t \leq 2
$$
$$
-1 \leq \log_2 x \leq 2 \iff 2^{-1} \leq x \leq 2^{2} \iff \frac{1}{2} \leq x \leq 4
$$

Solutions: $\dfrac{1}{2} \leq x \leq 4$.

<div class="spiegazione">

The argument of the logarithm is $x$, so the domain restriction is $x > 0$.

The inequality contains $(\log_2 x)^{2}$ and $\log_2 x$, therefore the **substitution method** with $t = \log_2 x$ gives the quadratic inequality $t^{2} - t - 2 \leq 0$. The trinomial factors as $(t - 2)(t + 1)$ and has a positive leading coefficient, so it is less than or equal to zero between the roots, endpoints included, that is, for $-1 \leq t \leq 2$. The new unknown can take any real value, therefore no value of $t$ is discarded because of its sign.

One returns to $x$ by writing the numbers $-1$ and $2$ as logarithms to base $2$, that is, $-1 = \log_2 \dfrac{1}{2}$ and $2 = \log_2 4$. The base $2$ is greater than $1$, so the function $\log_2 x$ is strictly increasing and the direction is **preserved** when passing to the arguments. One obtains $\dfrac{1}{2} \leq x \leq 4$, an interval contained in the domain $x > 0$.

At the endpoints the left-hand side equals zero: for $x = 4$ one has $4 - 2 - 2 = 0$, and for $x = \dfrac{1}{2}$ one has $1 + 1 - 2 = 0$. Both endpoints are therefore **solutions**.

</div>

## Exercise 2

Solve the inequality
$$
\log_2 x + \log_2 (x - 2) < 3 .
$$

$$
\begin{cases}
x > 0 \\
x - 2 > 0
\end{cases}
\iff x > 2
$$
$$
\log_2 \bigl(x(x - 2)\bigr) < \log_2 8
$$
$$
\begin{cases}
x > 2 \\
x^{2} - 2x < 8
\end{cases}
\iff
\begin{cases}
x > 2 \\
x^{2} - 2x - 8 < 0
\end{cases}
\iff
\begin{cases}
x > 2 \\
-2 < x < 4
\end{cases}
$$

Solutions: $2 < x < 4$.

<div class="spiegazione">

The **domain restrictions** require $x > 0$ and $x - 2 > 0$; the second implies the first, so the domain is $x > 2$.

On the domain both arguments are positive, therefore the **product property** applies and the left-hand side becomes $\log_2 \bigl(x(x - 2)\bigr)$. The number $3$ is written as $\log_2 8$, because $2^{3} = 8$. The base $2$ is greater than $1$, so the direction is preserved and the inequality is equivalent, on the domain, to $x(x - 2) < 8$.

The trinomial $x^{2} - 2x - 8$ factors as $(x - 4)(x + 2)$ and is negative between the roots, so the inequality $x^{2} - 2x - 8 < 0$ is satisfied for $-2 < x < 4$. Combining this in a system with the domain $x > 2$ gives $2 < x < 4$.

The domain is obtained from the given inequality, before combining the logarithms, because the expression $\log_2 \bigl(x(x - 2)\bigr)$ also exists for $x < 0$, whereas the given inequality does not exist for those values. For example, $x = -1$ satisfies $x^{2} - 2x - 8 < 0$, but it is not a solution because $\log_2 (-1)$ is not defined.

</div>

## Exercise 3

Solve the inequality
$$
\log_{\frac{1}{2}} \left(x^{2} - 3x\right) \geq -2 .
$$

$$
-2 = \log_{\frac{1}{2}} \left(\frac{1}{2}\right)^{-2} = \log_{\frac{1}{2}} 4
$$
$$
\begin{cases}
x^{2} - 3x \leq 4 \\
x^{2} - 3x > 0
\end{cases}
\iff
\begin{cases}
-1 \leq x \leq 4 \\
x < 0 \ \vee \ x > 3
\end{cases}
$$

Solutions: $-1 \leq x < 0 \ \vee \ 3 < x \leq 4$.

::grafico{f="log(x^2-3*x)/log(0.5);-2" xmin=-2.5 xmax=5.5 ymin=-4 ymax=4 asintoti="x=0;x=3" punti="-1,-2,pieno;4,-2,pieno" legenda="y = \log_{\frac{1}{2}} (x^2 - 3x);y = -2" titolo="The graph of $y = \log_{\frac{1}{2}} \left(x^{2} - 3x\right)$, defined for $x < 0$ and for $x > 3$, lies above the line $y = -2$ for $-1 \leq x < 0$ and for $3 < x \leq 4$"}

<div class="spiegazione">

The right-hand side is written as a logarithm to base $\dfrac{1}{2}$. Since $\left(\dfrac{1}{2}\right)^{-2} = 2^{2} = 4$, one has $-2 = \log_{\frac{1}{2}} 4$.

The base $\dfrac{1}{2}$ lies between $0$ and $1$, so the logarithmic function is strictly decreasing and the direction is **reversed** when passing to the arguments. By the **inequality with a number on the right-hand side**, the system also contains the domain restriction, because the positivity of the argument does not follow from $x^{2} - 3x \leq 4$.

The first inequality is equivalent to $x^{2} - 3x - 4 \leq 0$; the trinomial factors as $(x - 4)(x + 1)$, so the inequality is satisfied for $-1 \leq x \leq 4$. The second, $x(x - 3) > 0$, is satisfied outside the roots, that is, for $x < 0$ or $x > 3$.

The intersection of the two conditions consists of two intervals, $-1 \leq x < 0$ and $3 < x \leq 4$. The endpoints $0$ and $3$ are excluded because they make the argument zero; at the endpoints $-1$ and $4$ the argument equals $4$ and the logarithm equals exactly $-2$, so they are **included**.

</div>
