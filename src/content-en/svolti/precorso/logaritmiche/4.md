## Exercise 1

Solve the inequality
$$
\log_2 (x - 3) > 1 .
$$

$$
\log_2 (x - 3) > \log_2 2 \iff
\begin{cases}
x - 3 > 2 \\
x - 3 > 0
\end{cases}
\iff
\begin{cases}
x > 5 \\
x > 3
\end{cases}
\iff x > 5
$$

Solutions: $x > 5$.

<div class="spiegazione">

The number $1$ is written as $\log_2 2$, so the inequality compares two logarithms to the same base. The base $2$ is greater than $1$, therefore the logarithmic function is strictly increasing and the direction is preserved when passing to the arguments; together with the domain condition we obtain the system. The condition $x - 3 > 2$ is more restrictive than $x - 3 > 0$, so the solutions are $x > 5$.

</div>

## Exercise 2

Solve the inequality
$$
\log_3 (2x + 1) \leq 2 .
$$

$$
\log_3 (2x + 1) \leq \log_3 9 \iff
\begin{cases}
2x + 1 \leq 9 \\
2x + 1 > 0
\end{cases}
\iff
\begin{cases}
x \leq 4 \\[2pt]
x > -\dfrac{1}{2}
\end{cases}
\iff -\frac{1}{2} < x \leq 4
$$

Solutions: $-\dfrac{1}{2} < x \leq 4$.

<div class="spiegazione">

The number $2$ is written as $\log_3 (3^{2}) = \log_3 9$, so the inequality compares two logarithms to base $3$. The base is greater than $1$, therefore the direction is preserved when passing to the arguments; here the domain condition $2x + 1 > 0$ must be written in the system, because the inequality $2x + 1 \leq 9$ alone does not guarantee that the argument is positive. The intersection of the two conditions gives the interval $-\dfrac{1}{2} < x \leq 4$, with the right endpoint included because the symbol of the inequality is $\leq$.

</div>

## Exercise 3

Solve the inequality
$$
\log_2 (x + 1) > \log_2 (3 - x) .
$$

$$
\begin{cases}
x + 1 > 3 - x \\
3 - x > 0
\end{cases}
\iff
\begin{cases}
x > 1 \\
x < 3
\end{cases}
\iff 1 < x < 3
$$

Solutions: $1 < x < 3$.

<div class="spiegazione">

The two sides are logarithms to the same base $2$, greater than $1$, so the direction is preserved when passing to the arguments. The system contains the domain condition of the smaller argument, $3 - x > 0$, because the positivity of $x + 1$ follows from $x + 1 > 3 - x > 0$. From the first inequality we obtain $2x > 2$, that is $x > 1$; the intersection with $x < 3$ gives the interval $1 < x < 3$.

</div>
