## Exercise 1

Solve the equation
$$
|x - 2| = 3x .
$$

The right-hand side contains the variable, so the equation is equivalent to the union of two systems:
$$
\begin{cases}
3x \geq 0 \\
x - 2 = 3x
\end{cases}
\ \cup \
\begin{cases}
3x \geq 0 \\
x - 2 = -3x
\end{cases}
$$

**First system.**
$$
\begin{cases}
x \geq 0 \\
-2x = 2
\end{cases}
\qquad
\begin{cases}
x \geq 0 \\
x = -1
\end{cases}
$$
The system has no solutions.

**Second system.**
$$
\begin{cases}
x \geq 0 \\
4x = 2
\end{cases}
\qquad
\begin{cases}
x \geq 0 \\
x = \dfrac{1}{2}
\end{cases}
$$

The solution is $x = \dfrac{1}{2}$.

<div class="spiegazione">

The left-hand side is an absolute value and is never negative, so the right-hand side must also satisfy $3x \geq 0$: this condition enters both systems. In the first system the equation gives $x = -1$, which is negative, therefore the condition $x \geq 0$ is not satisfied and the value is discarded. In the second system the equation gives $x = \dfrac{1}{2}$, which is positive, therefore the condition is satisfied. Checking by substitution confirms the result: $\left| \dfrac{1}{2} - 2 \right| = \dfrac{3}{2}$ and $3 \cdot \dfrac{1}{2} = \dfrac{3}{2}$.

</div>

## Exercise 2

Solve the equation
$$
|2x + 1| = x + 4 .
$$

$$
\begin{cases}
x + 4 \geq 0 \\
2x + 1 = x + 4
\end{cases}
\ \cup \
\begin{cases}
x + 4 \geq 0 \\
2x + 1 = -(x + 4)
\end{cases}
$$

**First system.**
$$
\begin{cases}
x \geq -4 \\
x = 3
\end{cases}
$$
The solution $x = 3$ is acceptable.

**Second system.**
$$
\begin{cases}
x \geq -4 \\
3x = -5
\end{cases}
\qquad
\begin{cases}
x \geq -4 \\
x = -\dfrac{5}{3}
\end{cases}
$$
The solution $x = -\dfrac{5}{3}$ is acceptable.

The solutions are $x = -\dfrac{5}{3}$ and $x = 3$.

<div class="spiegazione">

The acceptability condition is $x + 4 \geq 0$, that is $x \geq -4$, and it applies to both systems. The first system gives $x = 3$ and the second gives $x = -\dfrac{5}{3}$; both values are greater than $-4$, so neither of them is discarded. Checking by substitution confirms the result: for $x = 3$ we have $|7| = 7 = 3 + 4$, and for $x = -\dfrac{5}{3}$ we have $\left| -\dfrac{7}{3} \right| = \dfrac{7}{3} = -\dfrac{5}{3} + 4$.

</div>

## Exercise 3

Solve the equation
$$
|x^2 - 1| = x + 1 .
$$

$$
\begin{cases}
x + 1 \geq 0 \\
x^2 - 1 = x + 1
\end{cases}
\ \cup \
\begin{cases}
x + 1 \geq 0 \\
x^2 - 1 = -(x + 1)
\end{cases}
$$

**First system.**
$$
\begin{cases}
x \geq -1 \\
x^2 - x - 2 = 0
\end{cases}
\qquad
\begin{cases}
x \geq -1 \\
(x - 2)(x + 1) = 0
\end{cases}
$$
The roots $x = 2$ and $x = -1$ both satisfy the condition $x \geq -1$.

**Second system.**
$$
\begin{cases}
x \geq -1 \\
x^2 + x = 0
\end{cases}
\qquad
\begin{cases}
x \geq -1 \\
x(x + 1) = 0
\end{cases}
$$
The roots $x = 0$ and $x = -1$ both satisfy the condition $x \geq -1$.

The solutions are $x = -1$, $x = 0$ and $x = 2$.

<div class="spiegazione">

The argument of the absolute value is quadratic, so each system contains a quadratic equation. In the first system the equation $x^2 - x - 2 = 0$ factors as $(x - 2)(x + 1) = 0$; in the second the equation $x^2 + x = 0$ is factored by taking out $x$. All the roots found satisfy the condition $x \geq -1$, and the value $x = -1$ appears in both systems, but in the union it is counted only once. Checking by substitution confirms the result: for $x = -1$ both sides equal $0$, for $x = 0$ they equal $1$, for $x = 2$ they equal $3$.

</div>
