## Exercise 1

Solve the inequality
$$
\frac{|x| - 2}{x - 1} \geq 0 .
$$

$$
x - 1 \neq 0 \iff x \neq 1
$$
$$
|x| - 2 > 0 \iff |x| > 2 \iff x < -2 \ \vee \ x > 2 , \qquad |x| - 2 = 0 \iff x = -2 \ \vee \ x = 2
$$
$$
x - 1 > 0 \iff x > 1
$$

- For $x < -2$: numerator positive, denominator negative, fraction negative.
- For $x = -2$: numerator zero, fraction zero.
- For $-2 < x < 1$: numerator and denominator negative, fraction positive.
- For $1 < x < 2$: numerator negative, denominator positive, fraction negative.
- For $x \geq 2$: numerator non-negative, denominator positive, fraction positive or zero.

Solutions: $-2 \leq x < 1 \ \vee \ x \geq 2$.

<div class="spiegazione">

The fraction is defined for $x \neq 1$. Its sign depends on the signs of the numerator and of the denominator, which are studied separately.

The numerator is positive when $|x| > 2$. By the **inequality** $|A| > k$ with $k = 2 > 0$, this condition is equivalent to $x < -2$ or $x > 2$, that is, to the points at distance greater than $2$ from $0$. The numerator vanishes for $|x| = 2$, that is, at $x = -2$ and at $x = 2$, and it is negative for $-2 < x < 2$. The denominator is positive for $x > 1$.

Combining the signs in the intervals bounded by $-2$, $1$ and $2$, the fraction is positive for $-2 < x < 1$ and for $x > 2$, and it is zero at the points $x = -2$ and $x = 2$. The inequality asks for **positive or zero** values, therefore the points $-2$ and $2$ are solutions; the point $1$ is excluded because it makes the denominator zero.

A check with one value per interval confirms the result. For $x = 0$ the fraction equals $\dfrac{-2}{-1} = 2 > 0$; for $x = \dfrac{3}{2}$ it equals $\dfrac{-\frac{1}{2}}{\frac{1}{2}} = -1 < 0$; for $x = -3$ it equals $\dfrac{1}{-4} < 0$.

</div>

## Exercise 2

Solve the inequality
$$
x^{2} - 5|x| + 6 < 0 .
$$

$$
x^{2} = |x|^{2} , \qquad t = |x| , \qquad t \geq 0
$$
$$
t^{2} - 5t + 6 < 0 \iff (t - 2)(t - 3) < 0 \iff 2 < t < 3
$$
$$
2 < |x| < 3 \iff
\begin{cases}
|x| > 2 \\
|x| < 3
\end{cases}
\iff
\begin{cases}
x < -2 \ \vee \ x > 2 \\
-3 < x < 3
\end{cases}
$$

Solutions: $-3 < x < -2 \ \vee \ 2 < x < 3$.

::grafico{f="x^2-5*abs(x)+6" xmin=-4 xmax=4 ymin=-1 ymax=2.5 punti="-3,0,vuoto;-2,0,vuoto;2,0,vuoto;3,0,vuoto" legenda="y = x^2 - 5|x| + 6" titolo="The graph of $y = x^{2} - 5|x| + 6$ is symmetric with respect to the $y$-axis and lies below the $x$-axis for $-3 < x < -2$ and for $2 < x < 3$"}

<div class="spiegazione">

The square of a number coincides with the square of its absolute value, because by the **properties of absolute value** $|x|^{2} = x^{2}$ for every real $x$. The inequality therefore contains only $|x|$ and its square, and with the auxiliary unknown $t = |x|$ it becomes the second-degree inequality $t^{2} - 5t + 6 < 0$. An absolute value is never negative, so $t \geq 0$.

The trinomial factors as $(t - 2)(t - 3)$, because $2$ and $3$ have sum $5$ and product $6$; it has positive leading coefficient, therefore it is negative between the roots. We obtain $2 < t < 3$, and all these values satisfy $t \geq 0$.

Returning to $x$, the two conditions $|x| > 2$ and $|x| < 3$ hold together and form a system. The first gives $x < -2$ or $x > 2$; the second gives $-3 < x < 3$. The intersection consists of the two intervals $-3 < x < -2$ and $2 < x < 3$.

The left-hand side does not change when $x$ is replaced by $-x$, therefore the solution set is **symmetric** with respect to $0$, as the graph shows. For $x = \dfrac{5}{2}$ the left-hand side equals $\dfrac{25}{4} - \dfrac{25}{2} + 6 = -\dfrac{1}{4} < 0$.

</div>

## Exercise 3

Solve the inequality
$$
\frac{|x - 3|}{x + 1} < 1 .
$$

$$
x + 1 \neq 0 \iff x \neq -1
$$

First case, $x \geq 3$:
$$
\frac{x - 3}{x + 1} - 1 < 0 \iff \frac{x - 3 - x - 1}{x + 1} < 0 \iff \frac{-4}{x + 1} < 0 \iff x > -1
$$

Second case, $x < 3$ and $x \neq -1$:
$$
\frac{3 - x}{x + 1} - 1 < 0 \iff \frac{3 - x - x - 1}{x + 1} < 0 \iff \frac{2 - 2x}{x + 1} < 0 \iff x < -1 \ \vee \ x > 1
$$
$$
\begin{cases}
x \geq 3 \\
x > -1
\end{cases}
\iff x \geq 3 ,
\qquad
\begin{cases}
x < 3 \\
x < -1 \ \vee \ x > 1
\end{cases}
\iff x < -1 \ \vee \ 1 < x < 3
$$

Solutions: $x < -1 \ \vee \ x > 1$.

<div class="spiegazione">

The fraction is defined for $x \neq -1$. The sign of the denominator is not constant, therefore the inequality cannot be multiplied by $x + 1$; for the same reason the scheme for $|A| < B$ does not apply directly. The absolute value is written without bars using the **definition**, distinguishing the sign of $x - 3$.

For $x \geq 3$ we have $|x - 3| = x - 3$. Bringing $1$ to the left-hand side and reducing to the same denominator we obtain $\dfrac{-4}{x + 1} < 0$; the numerator is negative, therefore the fraction is negative when the denominator is positive, that is, for $x > -1$. All values $x \geq 3$ satisfy this condition.

For $x < 3$ we have $|x - 3| = 3 - x$, and the inequality becomes $\dfrac{2 - 2x}{x + 1} < 0$. The numerator is positive for $x < 1$ and the denominator is positive for $x > -1$; the fraction is negative when the signs are opposite, that is, for $x < -1$ or $x > 1$. With the condition $x < 3$ there remain $x < -1$ and $1 < x < 3$.

The union of the two cases gives $x < -1$ or $x > 1$. For $x = 0$ the left-hand side equals $3$, greater than $1$, while for $x = -2$ it equals $\dfrac{5}{-1} = -5 < 1$, in agreement with the result.

</div>
