## Exercise 1

Determine for which values of the real parameter $k$ the equation
$$
2\cos x = k - 1
$$
has solutions. Then solve it for $k = 0$.

$$
\cos x = \frac{k - 1}{2}
$$
$$
\begin{cases}
\dfrac{k - 1}{2} \geq -1 \\[8pt]
\dfrac{k - 1}{2} \leq 1
\end{cases}
\qquad\Longleftrightarrow\qquad
\begin{cases}
k - 1 \geq -2 \\[4pt]
k - 1 \leq 2
\end{cases}
\qquad\Longleftrightarrow\qquad
-1 \leq k \leq 3
$$
$$
k = 0: \qquad \cos x = \frac{0 - 1}{2} = -\frac{1}{2}
\qquad\Longrightarrow\qquad
x = \pm\frac{2\pi}{3} + 2n\pi, \quad n \in \mathbb{Z}
$$

<div class="spiegazione">

Dividing both sides by $2$ the equation takes the **elementary form** $\cos x = \dfrac{k - 1}{2}$, in which the right-hand side depends on the parameter. The cosine takes all and only the values between $-1$ and $1$, so the equation has solutions if and only if the right-hand side belongs to the interval $[-1, 1]$.

The two inequalities must hold together, therefore they are written as a system. Multiplying by $2$, which is positive, the directions are unchanged; then adding $1$ we obtain $-1 \leq k \leq 3$. For $k < -1$ or $k > 3$ the right-hand side lies outside the interval $[-1, 1]$, and the equation **has no solutions**.

The value $k = 0$ belongs to $[-1, 3]$, so for it the equation has solutions. Substituting gives $\cos x = -\dfrac{1}{2}$. Since $\cos\dfrac{\pi}{3} = \dfrac{1}{2}$, the supplementary angle $\dfrac{2\pi}{3}$ has cosine $-\dfrac{1}{2}$; the second family is obtained from the opposite angle $-\dfrac{2\pi}{3}$. For $k = 0$ the solutions are therefore $x = \pm\dfrac{2\pi}{3} + 2n\pi$.

At the endpoints of the interval the two families merge into one: for $k = 3$ the equation is $\cos x = 1$, with solutions $x = 2n\pi$, and for $k = -1$ it is $\cos x = -1$, with solutions $x = \pi + 2n\pi$.

</div>

## Exercise 2

Determine for which values of the real parameter $k$ the equation
$$
\sin x + \cos x = k
$$
has solutions. Then solve it for the largest value of $k$ found.

$$
a = 1, \quad b = 1, \qquad R = \sqrt{1^2 + 1^2} = \sqrt{2}
$$
$$
\begin{cases}
\cos\varphi = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2} \\[8pt]
\sin\varphi = \dfrac{\sqrt{2}}{2}
\end{cases}
\qquad\Longrightarrow\qquad
\varphi = \frac{\pi}{4}
$$
$$
\sqrt{2}\,\sin\left(x + \frac{\pi}{4}\right) = k
\qquad\Longleftrightarrow\qquad
\sin\left(x + \frac{\pi}{4}\right) = \frac{k}{\sqrt{2}}
$$
$$
-1 \leq \frac{k}{\sqrt{2}} \leq 1
\qquad\Longleftrightarrow\qquad
-\sqrt{2} \leq k \leq \sqrt{2}
$$
$$
k = \sqrt{2}: \qquad \sin\left(x + \frac{\pi}{4}\right) = 1
\qquad\Longrightarrow\qquad
x + \frac{\pi}{4} = \frac{\pi}{2} + 2n\pi
\qquad\Longrightarrow\qquad
x = \frac{\pi}{4} + 2n\pi
$$

::grafico{f="sin(x)+cos(x);1.4142;-1.4142" legenda="y = \sin x + \cos x;y = \sqrt{2};y = -\sqrt{2}" xmin=-3.5 xmax=6.6 ymin=-2 ymax=2 punti="0.7854,1.4142,pieno,π/4" titolo="The graph of $y = \sin x + \cos x = \sqrt{2}\,\sin\left(x + \dfrac{\pi}{4}\right)$ lies between the lines $y = -\sqrt{2}$ and $y = \sqrt{2}$, and touches the upper line at $x = \dfrac{\pi}{4} + 2n\pi$"}

<div class="spiegazione">

The equation is **linear** in sine and cosine, with $a = b = 1$, so the left-hand side is written as a single sine with the **auxiliary angle method**. The modulus is $R = \sqrt{2}$, and the angle $\varphi$ has cosine and sine both equal to $\dfrac{\sqrt{2}}{2}$, therefore $\varphi = \dfrac{\pi}{4}$.

After dividing by $\sqrt{2}$ the equation is elementary in the unknown $x + \dfrac{\pi}{4}$. The sine takes only values in $[-1, 1]$, so the equation has solutions if and only if $\dfrac{k}{\sqrt{2}}$ belongs to $[-1, 1]$. Multiplying the double inequality by $\sqrt{2}$, which is positive, gives $-\sqrt{2} \leq k \leq \sqrt{2}$. In other words, the sum $\sin x + \cos x$ takes all and only the values between $-\sqrt{2}$ and $\sqrt{2}$, as the graph shows.

The largest admissible value is $k = \sqrt{2}$. For it the sine of $x + \dfrac{\pi}{4}$ must equal $1$, and the sine equals $1$ only at the angles $\dfrac{\pi}{2} + 2n\pi$, therefore we obtain **a single family**. Subtracting $\dfrac{\pi}{4}$ we conclude $x = \dfrac{\pi}{4} + 2n\pi$. Indeed for $x = \dfrac{\pi}{4}$ we have $\sin x + \cos x = \dfrac{\sqrt{2}}{2} + \dfrac{\sqrt{2}}{2} = \sqrt{2}$.

</div>

## Exercise 3

Determine for which values of the real parameter $k$ the equation
$$
\sin^2 x - \sin x = k
$$
has solutions. Then solve it for $k = 0$.

$$
t = \sin x, \qquad g(t) = t^2 - t, \qquad -1 \leq t \leq 1
$$
$$
\text{vertex: } t_V = -\frac{-1}{2 \cdot 1} = \frac{1}{2}, \qquad g\left(\frac{1}{2}\right) = \frac{1}{4} - \frac{1}{2} = -\frac{1}{4}
$$
$$
g(-1) = 1 + 1 = 2, \qquad g(1) = 1 - 1 = 0
$$
$$
-\frac{1}{4} \leq k \leq 2
$$
$$
k = 0: \qquad \sin x\,(\sin x - 1) = 0
\qquad\Longrightarrow\qquad
x = n\pi \quad \text{or} \quad x = \frac{\pi}{2} + 2n\pi
$$

::grafico{f="x^2-x;2;-0.25" xmin=-1.6 xmax=1.6 ymin=-0.8 ymax=2.6 nomi="t,y" punti="-1,2,pieno;0.5,-0.25,pieno,V;1,0,pieno" segmenti="-1,0,-1,2;0.5,0,0.5,-0.25" titolo="For $-1 \leq t \leq 1$ the parabola $y = t^2 - t$ takes all the values between $-\dfrac{1}{4}$, at the vertex $V$, and $2$, at $t = -1$"}

<div class="spiegazione">

With the **substitution** $t = \sin x$ the equation becomes $t^2 - t = k$, with the condition $-1 \leq t \leq 1$. The original equation has solutions if and only if there exists a value $t$ in $[-1, 1]$ with $g(t) = k$, that is, if and only if $k$ is one of the values that $g$ takes on the interval $[-1, 1]$.

The graph of $g(t) = t^2 - t$ is a parabola opening upward, because the coefficient of $t^2$ is positive. The vertex has abscissa $t_V = \dfrac{1}{2}$, which belongs to $[-1, 1]$, so the minimum value of $g$ on the interval is $g\left(\dfrac{1}{2}\right) = -\dfrac{1}{4}$. The maximum value is reached at the endpoint farthest from the vertex, that is, at $t = -1$, where $g(-1) = 2$. The function $g$ is continuous, therefore it takes all the values between $-\dfrac{1}{4}$ and $2$, and the equation has solutions if and only if $-\dfrac{1}{4} \leq k \leq 2$.

The value $k = 0$ belongs to the interval found. Factoring out $\sin x$ we obtain a product equal to zero, which vanishes if and only if one of the two factors vanishes. From $\sin x = 0$ it follows that $x = n\pi$; from $\sin x = 1$ it follows that $x = \dfrac{\pi}{2} + 2n\pi$.

</div>
