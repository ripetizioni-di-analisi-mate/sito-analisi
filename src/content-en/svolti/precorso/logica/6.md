## Exercise 1

Determine for which values of the real parameter $k$ the proposition
$$
\forall x \in \mathbb{R} : x^2 + kx + 1 > 0
$$
is true. Then write the negation and state for which $k$ it is true.

$$
\Delta = k^2 - 4 \cdot 1 \cdot 1 = k^2 - 4
$$

$$
k^2 - 4 < 0 \iff k^2 < 4 \iff -2 < k < 2
$$

$$
\lnot \bigl( \forall x \in \mathbb{R} : x^2 + kx + 1 > 0 \bigr)
\equiv \exists x \in \mathbb{R} : x^2 + kx + 1 \leq 0
$$

$$
k = 2: \quad x^2 + 2x + 1 = (x + 1)^2, \qquad x = -1 \ \Longrightarrow\ (x + 1)^2 = 0 \leq 0
$$

::grafico{f="x^2+x+1;x^2+3*x+1" xmin=-4 xmax=2 ymin=-2 ymax=6 punti="-0.5,0.75,pieno;-2.618,0,pieno;-0.382,0,pieno" legenda="y = x^2 + x + 1;y = x^2 + 3x + 1" titolo="For $k = 1$ the parabola lies entirely above the $x$-axis, with vertex at $\left(-\dfrac{1}{2}, \dfrac{3}{4}\right)$; for $k = 3$ it cuts the $x$-axis at two points and takes negative values between them"}

The proposition is **true for** $-2 < k < 2$; the negation is **true for** $k \leq -2$ and for $k \geq 2$.

<div class="spiegazione">

The predicate states that the trinomial $x^2 + kx + 1$ is positive. The coefficient of $x^2$ is $1 > 0$, therefore the parabola $y = x^2 + kx + 1$ opens upward. A parabola that opens upward lies entirely above the $x$-axis if and only if it has no intersections with the axis, that is, if and only if the **discriminant** is negative.

The discriminant equals $k^2 - 4$. The inequality $k^2 < 4$ has as solutions the values of $k$ with absolute value less than $2$, hence the universal proposition is true for $-2 < k < 2$.

The negation swaps $\forall$ with $\exists$ and negates the predicate, therefore the inequality $> 0$ becomes $\leq 0$. For every $k$ the proposition and its negation have opposite truth values, hence the negation is true exactly for the excluded values of $k$, that is, $k \leq -2$ or $k \geq 2$. For $k = 2$ the discriminant is zero, the trinomial is the square $(x + 1)^2$ and the value $x = -1$ makes it zero, therefore it satisfies $x^2 + 2x + 1 \leq 0$. The figure shows the two cases $k = 1$, inside the interval, and $k = 3$, outside it.

</div>

## Exercise 2

Determine for which values of the real parameter $a$ the proposition
$$
\forall x \in [0, 2] : ax + 1 > 0
$$
is true.

$$
g(x) = ax + 1, \qquad g(0) = 1, \qquad g(2) = 2a + 1
$$

$$
a \geq 0: \qquad \min_{[0, 2]} g = g(0) = 1 > 0
$$

$$
a < 0: \qquad \min_{[0, 2]} g = g(2) = 2a + 1
$$

$$
\begin{cases}
a < 0 \\
2a + 1 > 0
\end{cases}
\iff
-\frac{1}{2} < a < 0
$$

The proposition is **true for** $a > -\dfrac{1}{2}$.

<div class="spiegazione">

The proposition states that the function $g(x) = ax + 1$ is positive at *every* point of the interval $[0, 2]$. This is equivalent to saying that the minimum value of $g$ on the interval is positive, because every other value is greater than or equal to the minimum.

The graph of $g$ is a line with slope $a$, therefore the minimum on a closed interval is attained at an endpoint. If $a \geq 0$, the function is increasing or constant, hence the minimum is $g(0) = 1$, which is positive; therefore for every $a \geq 0$ the proposition is true. If $a < 0$, the function is decreasing, hence the minimum is $g(2) = 2a + 1$, and the proposition is true when $2a + 1 > 0$, that is, when $a > -\dfrac{1}{2}$.

In the second case the two conditions $a < 0$ and $a > -\dfrac{1}{2}$ must be satisfied together, therefore they give $-\dfrac{1}{2} < a < 0$. Combining the two cases gives $a > -\dfrac{1}{2}$.

For $a \leq -\dfrac{1}{2}$, instead, the negation $\exists x \in [0, 2] : ax + 1 \leq 0$ is true, and the value $x = 2$ satisfies it, because $2a + 1 \leq 0$. For example, with $a = -1$ one has $g(2) = -1$.

</div>

## Exercise 3

Determine for which values of the real parameter $k$ the proposition
$$
\exists x \in \mathbb{R} : x^2 + 2x + k < 0
$$
is true, and write the negation.

$$
x^2 + 2x + k = x^2 + 2x + 1 + k - 1 = (x + 1)^2 + k - 1
$$

$$
k < 1: \qquad x = -1 \ \Longrightarrow\ (x + 1)^2 + k - 1 = k - 1 < 0
$$

$$
k \geq 1: \qquad (x + 1)^2 + k - 1 \geq k - 1 \geq 0 \quad \text{for every } x \in \mathbb{R}
$$

$$
\lnot \bigl( \exists x \in \mathbb{R} : x^2 + 2x + k < 0 \bigr)
\equiv \forall x \in \mathbb{R} : x^2 + 2x + k \geq 0
$$

The proposition is **true for** $k < 1$; the negation is true for $k \geq 1$.

<div class="spiegazione">

An existential proposition is true when *at least one* value of $x$ satisfying the predicate is found. To choose the most favorable value we **complete the square**: the first two terms are those of $(x + 1)^2 = x^2 + 2x + 1$, therefore we add and subtract $1$ and the trinomial becomes $(x + 1)^2 + k - 1$.

The square $(x + 1)^2$ is greater than or equal to zero and equals zero only for $x = -1$, hence the minimum value of the trinomial is $k - 1$ and it is attained at $x = -1$. If $k < 1$, then for $x = -1$ the trinomial equals $k - 1 < 0$, therefore $x = -1$ satisfies the predicate and the proposition is true.

If $k \geq 1$, then the trinomial is greater than or equal to $k - 1 \geq 0$ for every $x$, therefore no $x$ makes it negative and the proposition is false. In this case the negation is true; it is obtained by swapping $\exists$ with $\forall$ and negating the inequality $< 0$ into $\geq 0$.

The same result is obtained with the discriminant, because the trinomial takes negative values if and only if $\Delta = 4 - 4k > 0$, that is, $k < 1$.

</div>
