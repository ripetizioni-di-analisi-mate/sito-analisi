## Exercise 1

Determine the values of the real parameter $k$ for which the equation
$$
2^{x} = \frac{k - 1}{k + 2}
$$
has a solution, and those for which the solution is positive.

$$
k \neq -2, \qquad \frac{k - 1}{k + 2} > 0 \iff k < -2 \ \text{or} \ k > 1
$$
$$
x = \log_2 \frac{k - 1}{k + 2}
$$
$$
\begin{aligned}
x > 0 &\iff \frac{k - 1}{k + 2} > 1 = 2^{0} \\[6pt]
&\iff \frac{k - 1 - (k + 2)}{k + 2} > 0 \\[6pt]
&\iff \frac{-3}{k + 2} > 0 \\[6pt]
&\iff k < -2
\end{aligned}
$$

Solution: the equation has a solution for $k < -2$ or $k > 1$, and the solution $x = \log_2 \dfrac{k - 1}{k + 2}$ is positive for $k < -2$.

<div class="spiegazione">

The right-hand side is a fraction in $k$, so it makes sense only for $k \neq -2$. The left-hand side $2^{x}$ is positive for every $x$ and takes *every* positive value, therefore the equation has a solution if and only if the right-hand side is **positive**.

The fraction $\dfrac{k - 1}{k + 2}$ is positive when numerator and denominator have the same sign. The numerator is positive for $k > 1$ and the denominator for $k > -2$, so the fraction is positive for $k < -2$ or $k > 1$. For these values the solution is obtained by definition of logarithm and is $x = \log_2 \dfrac{k - 1}{k + 2}$.

The base $2$ is greater than $1$, so $x > 0$ is equivalent to $2^{x} > 2^{0} = 1$, that is, to $\dfrac{k - 1}{k + 2} > 1$. Moving $1$ to the left-hand side and reducing to a common denominator gives $\dfrac{-3}{k + 2} > 0$. The numerator is negative, therefore the fraction is positive only if the denominator is also negative, that is, for $k < -2$.

For example, with $k = -3$ the right-hand side equals $\dfrac{-4}{-1} = 4$ and the solution is $x = 2$, positive; with $k = 2$ it equals $\dfrac{1}{4}$ and the solution is $x = -2$, negative.

</div>

## Exercise 2

Determine, as the real parameter $k$ varies, the number of solutions of the equation
$$
4^{x} - 2^{x+1} = k .
$$

Setting $t = 2^{x}$, with $t > 0$, since $4^{x} = t^{2}$ and $2^{x+1} = 2t$:
$$
t^{2} - 2t = k \iff t^{2} - 2t - k = 0
$$
$$
\frac{\Delta}{4} = 1 + k, \qquad t = 1 - \sqrt{1 + k} \ \text{or} \ t = 1 + \sqrt{1 + k} \quad (k \geq -1)
$$

- $k < -1$: no solution;
- $k = -1$: $t = 1$, so one solution, $x = 0$;
- $-1 < k < 0$: $0 < 1 - \sqrt{1 + k} < 1 < 1 + \sqrt{1 + k}$, so two solutions;
- $k \geq 0$: $1 - \sqrt{1 + k} \leq 0$ must be discarded, so one solution, $x = \log_2 \left(1 + \sqrt{1 + k}\right)$.

::grafico{f="4^x-2^(x+1);-0.5" xmin=-4 xmax=2 ymin=-1.5 ymax=3 punti="0,-1,pieno;1,0,pieno" legenda="y = 4^x - 2^{x+1};y = -\frac{1}{2}" titolo="The line $y = -\dfrac{1}{2}$ meets twice the graph of $y = 4^{x} - 2^{x + 1}$, which has minimum $-1$ at $x = 0$"}

<div class="spiegazione">

The equation contains $4^{x} = (2^{x})^{2}$ and $2^{x+1} = 2 \cdot 2^{x}$, so the **substitution** $t = 2^{x}$ gives the quadratic equation $t^{2} - 2t - k = 0$, with the condition $t > 0$. Each positive value of $t$ gives exactly one solution $x = \log_2 t$, because the exponential function is injective; therefore the number of solutions in $x$ is the number of *positive* solutions in $t$.

The reduced discriminant is $1 + k$. For $k < -1$ it is negative and the equation in $t$ has no solutions; for $k = -1$ it is zero and $t = 1$ remains, that is, $x = 0$.

For $k > -1$ the solutions are $1 \pm \sqrt{1 + k}$, and the larger one is always positive. The smaller one is positive if and only if $\sqrt{1 + k} < 1$, that is, $1 + k < 1$, that is, $k < 0$. Hence for $-1 < k < 0$ the equation has **two solutions**, while for $k \geq 0$ the smaller one must be discarded and the equation has **one solution**. With $k = 0$, for example, $t = 2$ remains and so $x = 1$.

</div>

## Exercise 3

Solve, as the parameter $a > 0$ varies, the inequality
$$
9^{x} - (a + 1) \cdot 3^{x} + a < 0 .
$$

Setting $t = 3^{x}$, with $t > 0$:
$$
t^{2} - (a + 1) t + a < 0 \iff (t - 1)(t - a) < 0
$$

- $a > 1$: $1 < t < a$, so $3^{0} < 3^{x} < 3^{\log_3 a}$ and $0 < x < \log_3 a$;
- $a = 1$: $(t - 1)^{2} < 0$, so no solution;
- $0 < a < 1$: $a < t < 1$, so $3^{\log_3 a} < 3^{x} < 3^{0}$ and $\log_3 a < x < 0$.

Solutions: $0 < x < \log_3 a$ for $a > 1$; none for $a = 1$; $\log_3 a < x < 0$ for $0 < a < 1$.

<div class="spiegazione">

With the **substitution** $t = 3^{x}$, since $9^{x} = t^{2}$, we obtain a quadratic inequality in $t$. The trinomial $t^{2} - (a + 1) t + a$ has sum of the roots $a + 1$ and product $a$, so the roots are $1$ and $a$ and the trinomial factors as $(t - 1)(t - a)$. The trinomial is negative for the values of $t$ between the two roots, therefore the discussion depends on which of the two is larger.

If $a > 1$ we have $1 < t < a$; if $0 < a < 1$ we have $a < t < 1$. In both cases the interval is contained in $t > 0$, because $a > 0$, so it is entirely acceptable. If $a = 1$ the trinomial is the square $(t - 1)^{2}$, which is never negative, and the inequality has no solutions.

To return to the variable $x$ we write $1 = 3^{0}$ and $a = 3^{\log_3 a}$, which makes sense because $a > 0$. The base $3$ is greater than $1$, so in passing to the exponents the direction **is preserved** in both inequalities. For example, with $a = 9$ the solutions are $0 < x < 2$, and with $a = \dfrac{1}{3}$ they are $-1 < x < 0$.

</div>
