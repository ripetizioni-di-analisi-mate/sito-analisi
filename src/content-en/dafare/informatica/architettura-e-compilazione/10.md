The project produces one object file for each of `main.c`, `scale.c`, and `log.c`. `main.c` includes `scale.h` directly, and `scale.c` includes it through `limits_local.h`. `log.c` does not depend on `scale.h`. The build system recompiles a source file whenever the modification time of a directly or indirectly included file changes. After editing only `scale.h`, how many object files are regenerated before linking?

:::soluzione
$2$.
:::
