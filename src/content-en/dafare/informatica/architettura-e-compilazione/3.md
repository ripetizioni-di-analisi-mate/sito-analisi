titolo: "Reconstructing a little-endian word"

parole: ["little endian", "hexadecimal"]

A machine uses eight-bit bytes. A two-byte unsigned word is stored in little-endian order. The bytes in increasing address order are `0x34` and `0x12`. Find the hexadecimal value of the word.

:::soluzione
`0x1234`.
:::
