The following program finishes writing without errors in a hosted C17 environment. State whether the termination status reported by `return 0;` indicates success or failure.

```c
#include <stdio.h>

int main(void)
{
    printf("%d\n", 7);
    return 0;
}
```

:::soluzione
Success.
:::
