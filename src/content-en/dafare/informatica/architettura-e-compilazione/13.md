---
titolo: "Symbol defined in two object files"
teoria: ["risoluzione-simboli"]
parole: ["external definition", "linking"]

Both `a.o` and `b.o` define an external function `int step(void)`. `a.o` also defines `int main(void)`, and `b.o` defines `int stop(void)`. These are ordinary definitions, with no extensions that allow duplicates. Both object files are linked. Which symbol has two definitions?

:::soluzione
`step`.
:::
