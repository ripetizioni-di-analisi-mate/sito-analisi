titolo: "Filtering multiples with continue"
teoria: ["salto-continue", "ciclo-for"]

Find the value of `s` after the fragment finishes.

```c
int s = 0;
for (int i = 1; i <= 8; ++i) {
    if (i % 3 == 0) {
        continue;
    }
    s += i;
}
```

:::soluzione
$$
27 .
$$
:::
