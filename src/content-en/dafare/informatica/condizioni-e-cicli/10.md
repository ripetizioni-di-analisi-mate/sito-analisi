---
titolo: "Stopping before an addition"
teoria: ["interruzione-break", "ciclo-for"]
parole: ["break", "threshold"]
---

Find the value of `s` after the fragment finishes.

```c
int s = 0;
for (int i = 1; i <= 7; ++i) {
    if (s > 6) {
        break;
    }
    s += i;
}
```

:::soluzione
$$
10 .
$$
:::
