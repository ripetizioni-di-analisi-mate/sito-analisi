---
titolo: "Fall-through to the next case"
teoria: ["selezione-switch"]
parole: ["switch", "fall-through"]
---

Find the value of `s` after the fragment finishes.

```c
int mode = 2, s = 1;
switch (mode) {
case 1:
    s += 2;
    break;
case 2:
    s *= 3;
    /* fall through */
case 3:
    s += 4;
    break;
default:
    s = 0;
}
```

:::soluzione
$$
7 .
$$
:::
