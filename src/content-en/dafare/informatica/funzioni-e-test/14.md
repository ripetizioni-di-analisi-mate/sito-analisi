The macro `NDEBUG` is defined when `<assert.h>` is included. What integer does `probe()` return in this build?

```c
#define NDEBUG
#include <assert.h>

int probe(void)
{
    int n = 4;
    assert(++n == 5);
    return n;
}
```

:::soluzione
$4$.
:::
