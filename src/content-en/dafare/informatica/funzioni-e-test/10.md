titolo: "Domain of an integer product"
teoria: [contratti-di-funzione]

Consider a C17 implementation with `INT_MAX` equal to $32767$. Find the largest non-negative integer `n` for which this function computes the square with defined behaviour.

```c
int square_nonnegative(int n)
{
    return n * n;
}
```

:::soluzione
$181$.
:::
