---
titolo: "Value specified by a contract"
teoria: [contratti-di-funzione]
parole: ["precondition", "postcondition", "clamping"]
---

The function `clamp(x, lo, hi)` requires `lo <= hi`. It returns `lo` if `x < lo` and `hi` if `x > hi`. In the remaining cases it returns `x`. Find the value specified by the contract for `clamp(17, 4, 12)`.

:::soluzione
$12$.
:::
