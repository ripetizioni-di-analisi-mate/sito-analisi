At the start of a new run, `add(2)`, `add(-1)` and `add(4)` are called in that order in three separate statements. What value does the third call return?

```c
int add(int step)
{
    static int total = 5;
    total += step;
    return total;
}
```

:::soluzione
$10$.
:::
