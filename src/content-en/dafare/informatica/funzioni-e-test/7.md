The calls `cost(2)`, `cost(0)` and `cost(3)` are executed in three separate statements. How many times is `int total = 5;` initialized in the C abstract machine?

```c
int cost(int input)
{
    int total = 5;
    total += input;
    return total;
}
```

:::soluzione
$3$ times.
:::
