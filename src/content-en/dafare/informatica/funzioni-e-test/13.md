The contract requires `eligible(x)` to return $1$ when `x >= 20` and $0$ otherwise, for integers from $0$ to $100$. Find the only input in the domain for which this implementation violates the contract.

```c
int eligible(int x)
{
    return x > 20;
}
```

:::soluzione
$20$.
:::
