titolo: "First acceptance threshold"
teoria: [ritorno-dalla-funzione]
parole: ["return", "threshold"]
---

Assume `points` is an integer from $0$ to $30$, inclusive. Find the smallest `points` for which `passed(points)` is $1$.

```c
int passed(int points)
{
    if (points >= 18) {
        return 1;
    }
    return 0;
}
```

:::soluzione
$18$.
:::
