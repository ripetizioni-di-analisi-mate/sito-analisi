A line is valid if it contains exactly two integers, a class between $0$ and $2$ and a reading between $10$ and $30$, with inclusive limits. The lines are `2 20`, `1 31`, `3 25`, `0 10`, `1 24 4` and `2 30`. Find the sum of the valid readings in class $2$.

:::soluzione
$50$
:::
