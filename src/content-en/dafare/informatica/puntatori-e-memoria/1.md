---
titolo: "Two writes to the same object"
teoria: ["indirizzo-e-accesso", "alias-e-const"]
parole: ["aliasing", "dereferencing"]
---

Find the final value of $x$ in the following fragment, executed inside a function.

```c
int x = 11;
int *p = &x;
int *q = p;
*p += 5;
*q += 4;
```

:::soluzione
$$
20 .
$$
:::
