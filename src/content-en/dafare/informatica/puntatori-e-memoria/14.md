Count the blocks allocated in this fragment that are still live at the end. The code is in a function body with `<stdlib.h>` included. Assume both calls to `malloc` succeed.

```c
int *data = malloc(sizeof *data);
int *other = malloc(sizeof *other);
int *alias = data;
free(other);
other = NULL;
```

:::soluzione
$$
1 .
$$
:::
