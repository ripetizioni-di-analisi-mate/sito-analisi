---
titolo: "Changing a pointer’s target"
teoria: ["alias-e-const"]
parole: ["pointer copy", "assignment"]
---

Find the final value of $b$ in the following fragment, executed inside a function.

```c
int a = 4;
int b = 15;
int *p = &a;
int *q = p;
p = &b;
*q += 3;
*p = *q + 2;
```

:::soluzione
$$
9 .
$$
:::
