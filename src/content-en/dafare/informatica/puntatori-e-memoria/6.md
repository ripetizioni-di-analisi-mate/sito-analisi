titolo: "Counting in a half-open range"
teoria: ["intervallo-di-puntatori"]
parole: ["half-open range", "occurrences"]
---

Find the final value of `hits`. The fragment is in a function body and `size_t` is declared by `<stddef.h>`.

```c
const int a[] = {6, 1, 6, 4, 6, 9};
const int *last = a + 5;
size_t hits = 0;
for (const int *p = a + 1; p != last; ++p) {
    if (*p == 6) {
        ++hits;
    }
}
```

:::soluzione
$$
2 .
$$
:::
