The pointer `p` owns a live block obtained with `malloc`. The block contains $8$ and $14$ as two integers in that order. The fragment is executed with `<stdlib.h>` included. Assume the new byte count is representable and `realloc` returns `NULL`. Give the final value of `p[1]`.

```c
int *next = realloc(p, 4 * sizeof *p);
if (next != NULL) {
    p = next;
}
```

:::soluzione
$$
14 .
$$
:::
