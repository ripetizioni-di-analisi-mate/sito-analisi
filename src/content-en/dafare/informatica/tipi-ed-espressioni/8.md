Write the characters emitted by `printf`. Assume a C17 Annex F implementation in round-to-nearest mode, the C numeric locale and successful output. The fragment uses `<stdio.h>`.

```c
printf("%.3f", 1.25);
```

:::soluzione
`1.250`.
:::
