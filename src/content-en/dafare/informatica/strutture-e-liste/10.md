The queue contains the single automatic node `only`. What is the final value of `rear`? The fragment uses `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node only = {7, NULL};
struct Node *front = &only, *rear = &only;
front = front->next;
if (front == NULL) {
    rear = NULL;
}
```

:::soluzione
The null pointer.
:::
