What pointer does `head` represent at the end? The node is automatic and only its list link is removed. The fragment uses `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node only = {6, NULL};
struct Node *head = &only;
head = head->next;
```

:::soluzione
The null pointer.
:::
