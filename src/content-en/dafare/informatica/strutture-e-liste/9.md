titolo: "Freeing a four-node list"
teoria: ["rimozione-e-rilascio", "invariante-lista"]

`head` points to the head of an acyclic list of four distinct nodes, each dynamically allocated and owned by the list. Find `released`. Assume `struct Node` with a `next` member is visible and that `<stdlib.h>` is used.

```c
int released = 0;
while (head != NULL) {
    struct Node *next = head->next;
    free(head);
    head = next;
    ++released;
}
```
