titolo: "Product after returning"
teoria: ["contratto-ricorsivo", "traccia-ritorni"]

Compute the value returned by `product(5)`. The exercise domain is $0\leq n\leq8$.

```c
unsigned long product(unsigned n)
{
    if (n == 0u) {
        return 1ul;
    }
    return n * product(n - 1u);
}
```

:::soluzione
$120$.
:::
