Find the maximum number of simultaneously active logical records for `fib(5)`. Count the initial and base-case records as well. Assume $0\leq n\leq10$.

```c
unsigned fib(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    unsigned left = fib(n - 1u);
    unsigned right = fib(n - 2u);
    return left + right;
}
```

:::soluzione
$5$.
:::
