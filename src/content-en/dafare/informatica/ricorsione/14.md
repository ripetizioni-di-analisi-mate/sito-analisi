How many invocations with argument $2$ occur in the logical tree for `fib(5)`? Assume $0\leq n\leq10$.

```c
unsigned fib(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    unsigned left = fib(n - 1u);
    unsigned right = fib(n - 2u);
    return left + right;
}
```

:::soluzione
$3$.
:::
