In the logical-record model, what is the greatest number of simultaneously active invocations during `steps(18)`? Count the initial and base-case calls.

```c
unsigned steps(unsigned n)
{
    if (n <= 1u) {
        return 0u;
    }
    return 1u + steps(n / 2u);
}
```

:::soluzione
$5$.
:::
