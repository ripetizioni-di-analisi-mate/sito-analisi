Give the two arguments of the first invocations after `select(3)` starts, in their start order. The domain is $0\leq n\leq10$.

```c
unsigned select(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    unsigned first = select(n - 2u);
    unsigned second = select(n - 1u);
    return first + second;
}
```

:::soluzione
$(1,2)$.
:::
