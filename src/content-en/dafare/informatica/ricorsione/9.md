Compute the value returned by `gcd(30, 18)` with the code below.

```c
unsigned gcd(unsigned a, unsigned b)
{
    if (b == 0u) {
        return a;
    }
    return gcd(b, a % b);
}
```

:::soluzione
$6$.
:::
