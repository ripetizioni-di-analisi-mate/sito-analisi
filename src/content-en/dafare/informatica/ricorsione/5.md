How many logical invocations of `fork_count` occur for `fork_count(3)`? Count the root and leaves. The domain is $0\leq n\leq6$.

```c
unsigned fork_count(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned left = fork_count(n - 1u);
    unsigned right = fork_count(n - 1u);
    return left + right;
}
```

:::soluzione
$15$.
:::
