Find a formula in terms of $n$ for the value of `sum(n)` throughout $0\leq n\leq20$.

```c
unsigned sum(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return n + sum(n - 1u);
}
```

:::soluzione
$\dfrac{n(n+1)}{2}$.
:::
