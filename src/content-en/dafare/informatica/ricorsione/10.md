---
titolo: "Reachability of the base branch"
teoria: ["contratto-ricorsivo", "misura-decrescente"]
parole: ["termination", "measure"]
---

In the logical call model, determine whether the base branch is reached starting from `repeat(3)`.

```c
unsigned repeat(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return repeat(n);
}
```

:::soluzione
The base branch is never reached.
:::
