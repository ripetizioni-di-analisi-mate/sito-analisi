titolo: "Recursive sum of the first odd numbers"
teoria: ["induzione-ricorsiva", "traccia-ritorni"]

Compute the value returned by `odd_sum(4)`. Assume $0\leq n\leq20$.

```c
unsigned odd_sum(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return (2u * n - 1u) + odd_sum(n - 1u);
}
```

:::soluzione
$16$.
:::
