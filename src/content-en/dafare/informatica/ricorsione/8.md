The array `values` contains $4$, $1$, $6$ and $2$, in that order. Compute `prefix_sum(values, 4)`. Include `<stddef.h>`.

```c
unsigned prefix_sum(const unsigned a[], size_t n)
{
    if (n == 0) {
        return 0u;
    }
    return prefix_sum(a, n - 1) + a[n - 1];
}
```

$13$.
