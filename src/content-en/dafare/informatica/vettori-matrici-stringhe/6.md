How many times does the loop body run? The type `size_t` is available.

```c
int a[5] = {7, 1, 5, 8, 3};
for (size_t i = 3; i < 3; ++i) {
    a[i] = 0;
}
```

:::soluzione
$$
0 .
$$
:::
