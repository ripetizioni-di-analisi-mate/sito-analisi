What string can be read from `out` after this fragment? The type `size_t` is available.

```c
char s[] = "tela";
char out[5];
size_t k = 0;
for (size_t i = 0; s[i] != '\0'; ++i) {
    if (s[i] != 'e') {
        out[k] = s[i];
        ++k;
    }
}
out[k] = '\0';
```

:::soluzione
`tla`
