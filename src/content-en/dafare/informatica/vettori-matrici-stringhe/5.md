Find the value of `a[3]` after the C17 fragment runs. The type `size_t` is available.

```c
int a[4] = {3, -2, 4, 1};
for (size_t i = 1; i < 4; ++i) {
    a[i] += a[i - 1];
}
```

:::soluzione
$$
6 .
$$
:::
