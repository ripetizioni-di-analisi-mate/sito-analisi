---
titolo: "Shifts in one insertion"
teoria: ["insertion-sort"]
parole: ["sorted prefix", "shift"]
---

Count the writes of the form `a[j] = a[j - 1]`. The final key write is separate. The fragment uses `size_t` from `<stddef.h>`.

```c
int a[] = {2, 4, 8, 3};
int key = a[3];
size_t j = 3, shifts = 0;
while (j > 0 && a[j - 1] > key) {
    a[j] = a[j - 1];
    --j;
    ++shifts;
}
a[j] = key;
```

:::soluzione
$$
2 .
$$
:::
