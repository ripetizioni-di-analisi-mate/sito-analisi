---
titolo: "Comparisons with no match"
teoria: ["ricerca-lineare", "modello-di-costo"]
parole: ["absence", "key equality"]
---

Determine how many equality comparisons between array elements and the key are executed. The fragment uses `size_t` from `<stddef.h>`.

```c
int a[] = {9, 2, 6, 3, 2};
int key = 7;
size_t comparisons = 0;
for (size_t i = 0; i < 5; ++i) {
    ++comparisons;
    if (a[i] == key) {
        break;
    }
}
```

:::soluzione
$$
5 .
$$
:::
