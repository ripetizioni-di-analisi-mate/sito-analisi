titolo: "Copies across merge-sort levels"
teoria: ["merge-sort", "spazio-ausiliario"]
parole: ["levels", "copies back"]

Merge sort splits $8$ elements into equal halves down to runs of length $1$. For each merge it copies the merged run from auxiliary storage back to the array, with one write per element. Count all those copy-back writes, excluding the writes that form the run in auxiliary storage.
