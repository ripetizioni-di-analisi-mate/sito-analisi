titolo: "Lower bound among duplicates"
teoria: ["lower-bound", "dicotomia-invariante"]

Find the value of `lo` on exit from the loop. The fragment uses `size_t` from `<stddef.h>`.

```c
int a[] = {1, 2, 5, 5, 5, 9, 14};
int key = 5;
size_t lo = 0, hi = 7;
while (lo < hi) {
    size_t mid = lo + (hi - lo) / 2;
    if (a[mid] < key) {
        lo = mid + 1;
    } else {
        hi = mid;
    }
}
```

:::soluzione
$$
2 .
$$
:::
