---
titolo: "Value displaced by the first minimum"
teoria: ["selection-sort"]
parole: ["minimum", "swap"]
---

The following fragment performs the first selection-sort pass. Give the final value of `a[3]`. The type `size_t` is from `<stddef.h>`.

```c
int a[] = {9, 4, 6, 1, 3};
size_t min_index = 0;
for (size_t j = 1; j < 5; ++j) {
    if (a[j] < a[min_index]) {
        min_index = j;
    }
}
int saved = a[0];
a[0] = a[min_index];
a[min_index] = saved;
```

:::soluzione
$$
9 .
$$
:::
