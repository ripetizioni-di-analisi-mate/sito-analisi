Find the number of `a[mid] < key` comparisons executed by the fragment. The type `size_t` is from `<stddef.h>`.

```c
int a[] = {1, 3, 5, 7, 9, 11, 13};
int key = 9;
size_t lo = 0, hi = 7, comparisons = 0;
while (lo < hi) {
    size_t mid = lo + (hi - lo) / 2;
    ++comparisons;
    if (a[mid] < key) {
        lo = mid + 1;
    } else {
        hi = mid;
    }
}
```

:::soluzione
$$
3 .
$$
:::
