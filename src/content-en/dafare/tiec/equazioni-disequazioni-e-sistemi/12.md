The inequality
$$
\frac{2x - 4}{x + 3} \leq 0
$$
holds for which values?

- A) $-3 \leq x \leq 2$
- B) $x < -3 \;\vee\; x \geq 2$
- C) $-3 < x < 2$
- D) $-3 < x \leq 2$

:::soluzione
Answer D. $-3 < x \leq 2$.
:::
