Which of the following gives the set $A = \{x \mid x \text{ is an odd number and } 3 \leq x \leq 9\}$ in roster notation?

- A) $\{1, 3, 5, 7, 9\}$
- B) $\{3, 5, 7, 9\}$
- C) $\{3, 5, 7\}$
- D) $\{4, 6, 8\}$
- E) $\{3, 5, 7, 9, 11\}$

:::soluzione
Answer B: $A = \{3, 5, 7, 9\}$.
:::
