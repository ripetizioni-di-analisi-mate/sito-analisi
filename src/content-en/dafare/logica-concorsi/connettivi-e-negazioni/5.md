Proposition $A$ is true and proposition $B$ is false. Which of the following propositions is true?

- A) $A$ and $B$
- B) if $A$ then $B$
- C) not $A$ or $B$
- D) if $B$ then not $A$
- E) $A$ if and only if $B$

:::soluzione
Answer D: If $B$ then not $A$, which is true because the antecedent $B$ is false.
:::
