Which of the following statements does *not* have the same meaning as the other four?

- A) If it is a public holiday, the museum is open.
- B) The fact that it is a public holiday is enough for the museum to be open.
- C) If the museum is closed, it is not a public holiday.
- D) The museum is open on every public holiday.
- E) The museum is open only if it is a public holiday.

:::soluzione
Answer E: the museum is open only if it is a public holiday.
:::
