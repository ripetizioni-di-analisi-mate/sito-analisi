If the statement “An employee receives permission only if they submit the request by Friday” is true, which of the following must be true?

- A) If an employee submits the request by Friday, they receive permission.
- B) If an employee does not receive permission, they did not submit the request by Friday.
- C) An employee receives permission if and only if they submit the request by Friday.
- D) If an employee does not submit the request by Friday, they do not receive permission.
- E) Some employee receives permission without having submitted the request by Friday.

:::soluzione
Answer D: if an employee does not submit the request by Friday, they do not receive permission.
:::
