Today $40$ trains departed from the station. The statements “No train that departed today was late” and “All trains that departed today were late” are

- A) Equivalent
- B) Contradictory, because they can neither both be true nor both be false
- C) Subcontrary, because they can both be true but cannot both be false
- D) Contrary, because they cannot both be true but can both be false
- E) Such that the second is a consequence of the first

:::soluzione
Answer D. Contrary.
:::
