Determine the type of returns to scale of the production function $Q(K, L) = 3\,K^{\frac{1}{2}} L^{\frac{3}{4}}$ and compute the number by which production is multiplied when capital and labor double.

:::soluzione
The function is homogeneous of degree $\dfrac{5}{4} > 1$, so it has increasing returns; doubling the factors multiplies production by $2^{\frac{5}{4}} \approx 2.38$.
:::
