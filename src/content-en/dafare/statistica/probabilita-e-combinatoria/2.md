In an archive, the probability that a file contains a technical attachment is $0.60$, the probability that it contains an invoice is $0.35$, and the probability that it contains at least one of the two documents is $0.75$. Calculate the probability that it contains both.

:::soluzione
$\dfrac{1}{5}$
:::
