---
titolo: "Choosing an urn by rolling a die"
teoria: [probabilita-totale, teorema-bayes, partizione]
parole: ["total probability", "Bayes’ theorem", "urns"]

Roll a die. If it shows $1$ or $2$, draw a ball from urn $A$, which contains $2$ red balls and $3$ blue balls. Otherwise draw from urn $B$, which contains $4$ red balls and $1$ blue balls. Find the probability of drawing a red ball and, given that it is red, the probability that it came from urn $A$.

:::soluzione
$P(R) = \dfrac{2}{3}$; $P(A \mid R) = \dfrac{1}{5}$.
:::
