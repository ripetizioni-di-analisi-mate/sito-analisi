---
titolo: Inconsistent system
teoria: [metodo-di-gauss, sistema-a-scala, rouche-capelli]
parole: [inconsistent system, row reduction, rank]
---

Determine whether the system
$$
\begin{cases}
x + 2y - z = 1 \\[4pt]
2x + 3y + z = 4 \\[4pt]
3x + 5y = 6
\end{cases}
$$
has solutions.

:::soluzione
The system is inconsistent: $\operatorname{rk} A = 2$ and $\operatorname{rk} (A \mid b) = 3$, since the reduction produces the row $(0 \ 0 \ 0 \mid 1)$.
:::
