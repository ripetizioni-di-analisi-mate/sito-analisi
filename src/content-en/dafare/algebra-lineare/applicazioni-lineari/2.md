---
titolo: Linearity as a parameter varies
teoria: [applicazione-lineare, proprieta-elementari]
parole: [linearity, parameter, counterexample]
---

Determine for which values of $k \in \mathbb{R}$ the following function is linear:
$$
f_k(x, y) = (x + k y^2,\ 2x - y)
$$

:::soluzione
The function is linear if and only if $k = 0$; for $k \neq 0$ we have $f_k(0, 2) = (4k, -2)$, different from $2\, f_k(0, 1) = (2k, -2)$.
:::
