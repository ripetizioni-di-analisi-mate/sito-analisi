titolo: Monotonicity from the definition
teoria: [funzioni-monotone]

Use the definition to verify that the function $f(x) = 3 - \dfrac{2}{x}$ is increasing on the interval $(0, +\infty)$.

:::soluzione
For $0 < x_1 < x_2$ we have $f(x_2) - f(x_1) = \dfrac{2}{x_1} - \dfrac{2}{x_2} = \dfrac{2\,(x_2 - x_1)}{x_1\,x_2} > 0$, so $f(x_1) < f(x_2)$.
:::
