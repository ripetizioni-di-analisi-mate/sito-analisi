---
titolo: Domain with a square root and a logarithm in the denominator
teoria: [dominio]
parole: [domain, logarithm, root, denominator]
---

Find the domain of the function $f(x) = \dfrac{\sqrt{x + 4}}{\ln (x + 2)}$.

:::soluzione
$D = (-2, -1) \cup (-1, +\infty)$. The value $-1$ is excluded because $\ln 1 = 0$.
:::
