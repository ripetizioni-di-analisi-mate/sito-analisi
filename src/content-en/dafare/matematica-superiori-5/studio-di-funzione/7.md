titolo: Parameters for an inflection point with a horizontal tangent
teoria: [punto-di-flesso, condizioni-flesso]

Find $a$ and $b$ so that the function $f(x) = x^3 + ax^2 + bx$ has an inflection point with a horizontal tangent at the point with horizontal coordinate $1$.

:::soluzione
$a = -3$ and $b = 3$, that is, $f(x) = x^3 - 3x^2 + 3x$.
:::
