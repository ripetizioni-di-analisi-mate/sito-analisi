---
titolo: Checking a solution
teoria: [equazione-differenziale]
parole: [checking a solution, linear equation]
---

Verify that the function $y = e^{-x} + x - 1$ is a solution of the differential equation $y' + y = x$.

:::soluzione
We have $y' = -e^{-x} + 1$, so $y' + y = -e^{-x} + 1 + e^{-x} + x - 1 = x$ for every $x$, and the function is a solution.
:::
