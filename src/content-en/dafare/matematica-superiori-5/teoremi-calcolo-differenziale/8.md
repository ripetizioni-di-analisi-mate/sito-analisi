---
titolo: An increasing function with a parameter
teoria: [criterio-monotonia]
parole: [monotonicity test, parameter, exponential function, increasing function]
---

Find the values of the parameter $k$ for which the function $f(x) = e^{x} - kx$ is increasing on the interval $[0, +\infty)$.

:::soluzione
The function is increasing on $[0, +\infty)$ for $k \leq 1$.
:::
