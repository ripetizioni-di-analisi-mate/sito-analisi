---
titolo: Two parameters for continuity
teoria: [continuita-punto, continuita-destra-sinistra, continuita-funzioni-elementari]
parole: [continuity, parameters, piecewise function, cosine]
---

Find the values of the real parameters $a$ and $b$ for which the function
$$
f(x) =
\begin{cases}
x + a & \text{if } x < 0 \\
b \cos x & \text{if } 0 \leq x \leq \pi \\
x - \pi + 2 & \text{if } x > \pi
\end{cases}
$$
is continuous on $\mathbb{R}$.

:::soluzione
$a = -2$ and $b = -2$.
:::
