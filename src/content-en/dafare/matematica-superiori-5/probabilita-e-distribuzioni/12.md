titolo: Probability density with a constant
teoria: [densita-probabilita, media-varianza-continua]

Find the constant $k$ for which the function equal to $k\,(2x - x^2)$ for $0 \leq x \leq 2$ and $0$ elsewhere is a probability density. For the random variable $X$ with this density, calculate $P\left( X \leq \dfrac{1}{2} \right)$ and its mean.

:::soluzione
$k = \dfrac{3}{4}$, $P\left( X \leq \dfrac{1}{2} \right) = \dfrac{5}{32}$, $M(X) = 1$.
:::
