A horizontal rectangular channel of width $b = 3.00\,\mathrm{m}$ with $k_s = 60\,\mathrm{m^{1/3}/s}$ carries $Q = 6.00\,\mathrm{m^3/s}$. A sluice gate releases water at a depth of $h_1 = 0.35\,\mathrm{m}$, as shown. Find the critical depth, classify the profile downstream of the gate, state in which direction it should be traced, and find the depth conjugate to $h_1$.

::schema{solidi="0,0 14,0 14,-0.60 0,-0.60;4.85,0.55 5.15,0.55 5.15,2.70 4.85,2.70" acqua="0,0 4.85,0 4.85,2.30 0,2.30;5.15,0 14,0 14,1.10 5.15,0.35" frecce="1.0,1.05,2.6,1.05,Q" etichette="5.0,3.00,gate;7.4,0.85,h_1 = 0.35 m;2.0,-0.95,i = 0" riferimento=0 titolo="Sluice gate in a horizontal rectangular channel of width $3.00\,\mathrm{m}$"}

:::soluzione
$h_c = 0.742\,\mathrm{m}$. There is no normal depth. The **H3** profile (zone 3) rises downstream. The flow is supercritical ($Fr_1 = 3.08$), so the calculation proceeds downstream from the upstream control. The sequent depth is $1.36\,\mathrm{m}$.
:::
