Which statement about the equation $4\,(x + 1) - 3 = 4x + 1$ is true?

- A) Its only solution is $x = 0$
- B) Its only solution is $x = 1$
- C) It has no solution
- D) Its only solution is $x = -1$
- E) Every real number satisfies it

:::soluzione
Answer E. Every real number satisfies the equation.
:::
