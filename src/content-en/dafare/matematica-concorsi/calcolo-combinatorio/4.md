Seven people sit around a round table. Two seatings count as the same if one is a rotation of the other, so each person has the same neighbors on the same sides. How many different seatings are there?

- A) $5040$
- B) $720$
- C) $120$
- D) $360$
- E) $49$

:::soluzione
Answer B, $720$.
:::
