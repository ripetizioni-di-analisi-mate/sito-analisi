A store has $84$ pens and $126$ pencils. It wants to make as many identical packages as possible using all the pens and pencils. How many packages can it make?

- A) $21$
- B) $14$
- C) $6$
- D) $252$
- E) $42$

:::soluzione
Answer E: $42$ packages.
:::
