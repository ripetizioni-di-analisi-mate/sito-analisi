A success frequency of exactly $35\%$ is reported after $47$ trials. Which check tests that report?

- Every percentage below $100\%$ is compatible with $47$ trials.
- $\dfrac{35}{100}\cdot47$ is not an integer, so the reported exact frequency is impossible.
- There are exactly $35$ successes because the percentage is $35\%$.
- There must be $47$ successes because that is the stated total.

## Explanation

The success count would be $\dfrac{35}{100}\cdot47=16.45$. Each trial contributes zero or one to the count, which must be an integer. Here no count yields exactly the reported percentage. A rounded percentage would be checked at its stated precision, while the question specifies an exact value.
