The ordered data are $1,3,4,4,6,9,10,12,15$. Using the upper-rank convention, between which values does the box of the box plot extend?

- From $3$ to $9$
- From $1$ to $15$
- From $4$ to $10$
- From $6$ to $10$

## Explanation

The box of the plot goes from the first to the third quartile. With $N=9$ we have $\dfrac94=2.25$, which rounded up to the next integer gives rank $3$, so $Q_1=4$. For the third quartile we have $\dfrac{3\cdot9}{4}=6.75$, which rounds up to $7$, and the value of rank $7$ is $10$, so $Q_3=10$. Therefore the box extends from $4$ to $10$. The values $1$ and $15$ are the minimum and the maximum, reached by the outer segments, while $3$ and $9$ come from rounding the ranks down to the previous integer.
