The sorted values are $0,2,4,5,8,11,12$. Remove the minimum. Under the nearest-rank convention, what is $Q_3-Q_1$ now?

- $9$
- $10$
- $7$
- $6$

## Explanation

Six values remain. Rounding $\dfrac{6}{4}$ and $\dfrac{3\cdot6}{4}$ up gives second and fifth ranks, occupied by $4$ and $11$. The interquartile range is $11-4=7$. The first quartile changes because, although it still uses rank two, another value now occupies that place.
