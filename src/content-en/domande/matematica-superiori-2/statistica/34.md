A data set contains $90$ observations. One observation with the largest value is doubled and the others stay the same. Which of these measures must increase if the maximum is positive?

- The range.
- The number of observations.
- The mode.
- The median.

## Explanation

The range is the maximum minus the minimum. The minimum stays the same while the maximum increases, so the difference grows.
