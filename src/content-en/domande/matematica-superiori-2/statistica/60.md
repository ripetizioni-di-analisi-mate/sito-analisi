The value $7$ occurs $13$ times and the value $8$ occurs $6$ times. What is the mode?

- $6$
- $8$
- $7$
- $13$

## Explanation

The mode is the value with the greatest frequency. Here $13>6$, so choose the value that occurs more often. The result is $7$.
