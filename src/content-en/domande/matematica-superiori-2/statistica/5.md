Which value is the mode of $6,\,8,\,8,\,8,\,11,\,11$?

- $9$
- $7$
- $16$
- $8$

## Explanation

The mode is the value with the greatest frequency. The occurrences of each value are counted and the frequencies compared. The value $8$ occurs three times, more than any other, so the mode is $8$.

$$
f(6)=1,\quad f(8)=3,\quad f(11)=2
$$
