The value $3$ occurs $5$ times and the value $4$ occurs $2$ times. What is the mode?

- $5$
- $2$
- $4$
- $3$

## Explanation

The mode is the value with the greatest frequency. Here $5>2$, so choose the value that occurs more often. The result is $3$.
