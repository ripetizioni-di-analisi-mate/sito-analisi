The value $5$ occurs $9$ times and the value $6$ occurs $4$ times. What is the mode?

- $9$
- $4$
- $5$
- $6$

## Explanation

The mode is the value with the greatest frequency. Here $9>4$, so choose the value that occurs more often. The result is $5$.
