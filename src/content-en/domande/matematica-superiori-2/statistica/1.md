What is the mean of $6,\,8,\,10,\,12$?

- $10$
- $8$
- $18$
- $9$

## Explanation

Add all the values and divide by the number of observations. Each value carries the same weight because it occurs once. The result lies between the minimum and maximum.

$$
\bar x=\frac{6+8+10+12}4=9
$$

Pairs provide another check. The smallest and largest values have the same sum as the two middle values, so each pair has the same mean as the group.
