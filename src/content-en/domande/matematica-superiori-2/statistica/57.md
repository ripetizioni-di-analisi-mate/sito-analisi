The value $4$ occurs $7$ times and the value $5$ occurs $3$ times. What is the mode?

- $4$
- $7$
- $5$
- $3$

## Explanation

The mode is the value with the greatest frequency. Here $7>3$, so choose the value that occurs more often. The result is $4$.
