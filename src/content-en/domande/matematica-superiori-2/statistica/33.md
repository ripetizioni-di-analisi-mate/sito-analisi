A data set contains $70$ observations. One observation with the largest value is doubled and the others stay the same. Which of these measures must increase if the maximum is positive?

- The number of observations.
- The median.
- The mode.
- The range.

## Explanation

The range is the maximum minus the minimum. The minimum stays the same while the maximum increases, so the difference grows.
