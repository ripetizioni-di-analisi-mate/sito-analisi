Find the mode of $8,\,10,\,10,\,10,\,13,\,13$.

- $11$
- $9$
- $20$
- $10$

## Explanation

The mode is the value with the greatest frequency. Count the occurrences of each value and compare the frequencies. A value in the middle of the written list is a mode only if it has the greatest frequency.

$$
f(8)=1,\quad f(10)=3,\quad f(13)=2
$$
