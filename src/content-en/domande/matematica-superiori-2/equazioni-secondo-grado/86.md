A calculator displays both roots as $1.41$ after rounding to two decimal places. Is this display enough to conclude that there is a double root?

- No, distinct roots can round to the same value
- Yes, because both values are positive
- No, because a double root must be an integer
- Yes, because rounding always preserves distances

## Explanation

For example, $1.411$ and $1.412$ are distinct but are both displayed as $1.41$. Use the exact values or check whether the discriminant is zero.
