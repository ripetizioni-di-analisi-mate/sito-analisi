What is the solution set of $\dfrac{x^2-4x+3}{(x-1)(x-3)}=0$?

- $\{1,3\}$
- $\varnothing$
- $\{3\}$
- $\mathbb R\setminus\{1,3\}$

## Explanation

The domain excludes $1$ and $3$. But $x^2-4x+3=(x-1)(x-3)$, so the only numerator zeroes are the excluded values. At all other values of $x$, the quotient equals $1$. The equation requires zero, so no allowed value works. The result depends on the right side: if it were $1$, every value in the domain would solve the equation.
