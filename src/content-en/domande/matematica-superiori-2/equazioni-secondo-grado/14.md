What are the domain $D$ and solution set $S$ of $\dfrac{x^2-x-6}{x-3}=0$?

- $D=\mathbb R,\quad S=\{-2,3\}$
- $D=\mathbb R\setminus\{-2\},\quad S=\{3\}$
- $D=\mathbb R\setminus\{-2,3\},\quad S=\varnothing$
- $D=\mathbb R\setminus\{3\},\quad S=\{-2\}$

## Explanation

The denominator $x-3$ is zero only for $x=3$, so the domain is $D=\mathbb R\setminus\{3\}$. The numerator factors as $(x-3)(x+2)$ and is zero for $x=3$ and for $x=-2$. The value $3$ does not belong to the domain, therefore it is discarded. For $x=-2$ the numerator is zero and the denominator is $-5$, so the fraction is defined and equal to zero. The solution set is therefore $S=\{-2\}$.
