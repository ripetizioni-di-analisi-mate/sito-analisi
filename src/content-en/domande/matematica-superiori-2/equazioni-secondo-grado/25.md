A program must solve $x^2=20$ only on the interval $[-5,0]$. Which instruction directly selects the required root?

- Return $\sqrt{20}$
- Return $0$ because the interval contains zero
- Return $-\sqrt{20}$
- Return $-20/2$

## Explanation

Of the two roots $\pm\sqrt{20}$, only the negative one is allowed. Since $16<20<25$, it lies between $-5$ and $-4$, inside the interval.
