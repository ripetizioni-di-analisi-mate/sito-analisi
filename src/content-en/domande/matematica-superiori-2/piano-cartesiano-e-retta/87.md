For which real values of $k$ does the family $kx+y=2$ contain a vertical line?

- For every $k\ne0$
- Only for $k=2$
- For no value of $k$
- Only for $k=0$

## Explanation

The coefficient of $y$ is $1$ in every equation, so it can always be written as $y=2-kx$. Each horizontal coordinate gives one height. At $k=0$ the line is horizontal.
