Which line is parallel to $x=-2$ and passes through $P(5;1)$?

- $y=1$
- $x=5$
- $y=5$
- $x=-2$

## Explanation

The given line is vertical because it fixes the horizontal coordinate and leaves the height free. A parallel line must have the same direction, so it is vertical too. To pass through $P$, it must fix the coordinate $5$. The equation $x=5$ allows the point’s height $1$. The fixed coordinates $-2$ and $5$ are different, so the lines have no point in common.
