Which point on $y=1$ is closest to $P(-2;5)$?

- $(1;5)$
- $(2;1)$
- $(-2;1)$
- $(-2;0)$

## Explanation

The perpendicular to the horizontal line is vertical, so it keeps $P$’s horizontal coordinate $-2$. It meets the given line at height $1$. Thus the foot is $(-2;1)$ and is four units away. For another point $(x;1)$ of the same line, the squared distance is $(x+2)^2+16$. That value is minimized only when the first square vanishes.
