Which number is equal to $\sqrt{(1-\sqrt2)^2}$?

- $1-\sqrt2$
- $1+\sqrt2$
- $3-2\sqrt2$
- $\sqrt2-1$

## Explanation

The square root of the square of a real number is the absolute value of that number, so $\sqrt{(1-\sqrt2)^2}=|1-\sqrt2|$. Since $2>1$, we have $\sqrt2>1$, therefore the base $1-\sqrt2$ is negative. The absolute value of a negative number is its opposite, so $|1-\sqrt2|=\sqrt2-1$. The value $3-2\sqrt2$ is the square $(1-\sqrt2)^2$ before the square root is taken.
