For which values of the rational parameter $\lambda$ is $\lambda\sqrt3$ rational?

- $\lambda=0$
- $\lambda\ne0$
- $\lambda>0$
- $\lambda<0$

## Explanation

If $\lambda=0$, the product is zero, which is rational. If $\lambda\ne0$ and the product were rational, dividing that number by $\lambda$ would give another rational number. The quotient would be $\sqrt3$, which is irrational because $3$ is not a perfect square. Thus zero is the only parameter value that meets the condition.
