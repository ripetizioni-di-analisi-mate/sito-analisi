For which real value of $k$ does $\sqrt[3]{k-1}=-2$?

- $-7$
- $-9$
- $7$
- $-1$

## Explanation

By the definition of the cube root, the radicand has to be the cube of $-2$. This gives $k-1=(-2)^3=-8$. Adding one gives $k=-7$. The odd index allows the negative radicand. Substituting the value found gives the cube root of $-7-1$, which is $-2$ because $(-2)^3$ recovers its radicand. Using $k=-1$ would give radicand $-2$, which is not the required cube.
