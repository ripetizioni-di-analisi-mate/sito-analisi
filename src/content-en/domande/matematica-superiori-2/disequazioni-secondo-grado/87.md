The cost of building $n$ modules is $C(n)=n^2-7n+20$ for integers $n\ge0$. What is the first value of $n$ for which adding one module strictly increases the cost?

- $5$
- $7$
- $4$
- $3$

## Explanation

Compare consecutive costs. The difference $C(n+1)-C(n)=2n-6$ is positive for $n>3$. At $n=3$ the cost stays the same, so the first valid integer is $4$.
