After cancellation the inequality is $x+2\ge0$, but the original solution is $[-2,3)\cup(3,+\infty)$. Which cancelled denominator factor accounts for the missing point?

- $x+2$
- $x+3$
- $x-2$
- $x-3$

## Explanation

The simplified inequality includes $3$. Only the factor $x-3$ vanishes there, so it excluded that value from the original domain.
