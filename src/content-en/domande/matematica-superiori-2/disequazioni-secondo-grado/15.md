Which expression equals $\sqrt{(x-3)^2}$ for every real $x$?

- $x-3$
- $|x-3|$
- $3-x$
- $(x-3)^2$

## Explanation

The square root selects the nonnegative value whose square equals the radicand. If $x\ge3$ that value is $x-3$. If $x<3$ it is $3-x$. These are the two pieces of the absolute value. For example, at $x=1$ the root equals $2$, while the expression $x-3$ equals $-2$. At $x=5$ the root has the same value, since the two bases are opposites.
