A setting $x$ must satisfy $(x-t)^2\le1$ both for $t=0$ and for $t=1$. Which settings work in both tests?

- $\{0,1\}$
- $[-1,0]$
- $[0,1]$
- $[-1,2]$

## Explanation

The first test allows $[-1,1]$ and the second allows $[0,2]$. The same setting must work in both tests, so their intersection $[0,1]$ is required.
