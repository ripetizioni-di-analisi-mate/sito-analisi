A device uses only integer inputs $n$ and accepts those satisfying $\dfrac{2n-1}{2n+1}>0$. Which integer input is rejected?

- $-1$ and $0$
- Only $-1$
- All negative integers
- Only $0$

## Explanation

The fraction is negative only between $-1/2$ and $1/2$. The denominator is zero at $-1/2$ and the numerator at $1/2$, neither of which is an integer. The only integer input that fails is therefore $0$.
