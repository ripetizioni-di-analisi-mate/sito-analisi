For what value of $k$ does the system $(x-2)^2\le4$ and $x\ge k$ have exactly one solution?

- $0$
- $4$
- $2$
- $5$

## Explanation

The square gives $-2\le x-2\le2$, or $0\le x\le4$. At $k=4$, the intersection with $[k,+\infty)$ contains only $4$. If $k<4$, it contains every value from the greater of $0$ and $k$ to $4$, so it has more than one point. If $k>4$, the sets do not meet. The included boundary determines the only choice. The system contains that point because both inequalities allow equality.
