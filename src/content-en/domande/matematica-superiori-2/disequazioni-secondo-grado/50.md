An input passes if at least one of $x^2\le4$ and $x\ge1$ holds. Which values pass the combined test?

- $[-2,+\infty)$
- $[1,2]$
- $\mathbb R$
- $[-2,1]$

## Explanation

The first set is $[-2,2]$ and the second is $[1,+\infty)$. One criterion is enough, so their union covers every value from $-2$ upwards.
