Which values of $x$ satisfy both $(x-2)^2\le9$ and $x^2>1$?

- $(1,5]$
- $[-1,5]$
- $[-1,1)$
- $[1,5]$

## Explanation

The first condition gives $-3\le x-2\le3$, so $-1\le x\le5$. The second allows values strictly below $-1$ or strictly above $1$. The left branch does not meet the first interval because it excludes $-1$. This leaves $(1,5]$. The value $1$ fails the strict comparison, while $5$ meets both conditions. The right endpoint stays included because it passes both checks.
