One constraint is $-1\le x\le3$. The condition $x^2\le9$ is added. How does the feasible set change?

- It becomes $[-3,3]$
- Only the value $3$ is lost
- It shrinks to $[-1,1]$
- It stays $[-1,3]$

## Explanation

The added condition allows $[-3,3]$, which contains the entire original interval. Their intersection is the more restrictive interval, including its endpoint $3$.
