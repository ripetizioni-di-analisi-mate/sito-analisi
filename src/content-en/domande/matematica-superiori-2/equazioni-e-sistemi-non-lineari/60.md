What is the set of values taken by the expression $\sqrt{9-t}$ as $t\ge0$ varies in its domain?

- $[0,3]$
- $[0,9]$
- $[-3,3]$
- $[3,+\infty)$

## Explanation

The root is defined for $9-t\geq0$, so, together with the condition $t\geq0$, we have $0\leq t\leq9$. For these values the radicand $9-t$ takes every value in the interval $[0,9]$. Since the square root is increasing, the expression takes every value from $\sqrt0=0$ to $\sqrt9=3$. Therefore the set of values is $[0,3]$.
