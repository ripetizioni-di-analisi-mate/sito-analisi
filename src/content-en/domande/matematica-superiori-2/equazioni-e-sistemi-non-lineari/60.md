A sensor displays $d=\sqrt{9-t}$ at times $t\ge0$. Which set contains exactly the values that the display can show?

- $[0,3]$
- $[0,9]$
- $[-3,3]$
- $[3,+\infty)$

## Explanation

The allowed time runs from $0$ to $9$. The radicand decreases from $9$ to $0$, so the display takes every value from $3$ down to $0$, including both endpoints.
