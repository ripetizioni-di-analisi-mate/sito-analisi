Equating the radicands in $\sqrt{x-3}=\sqrt{2x-5}$ gives $x=2$. What follows?

- $x=2$ is a solution because the radicands agree
- $x=3$ is a solution because it makes the first radicand zero
- All values $x\ge3$ are solutions
- The equation has no real solutions

## Explanation

The common restriction is $x\ge3$: the first radical requires it and the second only requires $x\ge\dfrac52$. At candidate $2$, the radicands agree but both equal $-1$, so neither radical is real. No other value in the domain makes the radicands equal. At $3$, for example, the first is zero but the second equals one, so the sides differ.
