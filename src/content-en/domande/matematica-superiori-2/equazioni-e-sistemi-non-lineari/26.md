The equation $(x-2)(x^2+1)=0$ is multiplied by $x+3$ over all of $\mathbb R$. How does the solution set change?

- The value $2$ is replaced by $-3$
- The value $-3$ is added
- The value $3$ is added
- It stays the same

## Explanation

The factor $x^2+1$ is always positive, so initially the only solution was $2$. The new product also vanishes when $x+3=0$, at $-3$. The solution $2$ remains because its original factor is still present. The set changes because the multiplier vanishes at $-3$. Restricting the domain to $x\ne-3$ would restore equivalence.
