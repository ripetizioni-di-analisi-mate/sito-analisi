A program checks $\sqrt{x+4}=x-2$ using only $x+4=(x-2)^2$. Which extra condition makes the check reliable for every real candidate?

- $x\ge2$
- $x\ge-4$
- $x\ne2$
- $x\le2$

## Explanation

Equality with the square already guarantees a nonnegative radicand. Its principal square root is $|x-2|$, which equals $x-2$ exactly when $x\ge2$.
