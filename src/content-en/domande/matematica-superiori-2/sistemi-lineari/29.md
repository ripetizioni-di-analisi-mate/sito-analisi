For which values of $k$ does the system formed by $x+y=6$ and $x-y=k$ have a solution with both coordinates positive?

- $-6<k<6$
- $k>-6$
- $0<k<6$
- $-3<k<3$

## Explanation

The coefficients of the two equations are not proportional, so the system has exactly one solution for every value of $k$. Adding the equations gives $2x=6+k$, so $x=\dfrac{6+k}{2}$. Subtracting the second from the first gives $2y=6-k$, so $y=\dfrac{6-k}{2}$. The two coordinates must be positive together, so $k$ must satisfy the system
$$
\begin{cases}6+k>0\\6-k>0\end{cases}
$$
The first inequality gives $k>-6$ and the second gives $k<6$, so the solution has both coordinates positive if and only if $-6<k<6$. The condition $k>-6$ concerns only the $x$-coordinate, while $-3<k<3$ comes from dividing only the term $6$ by $2$, writing $x=3+k$ and $y=3-k$.
