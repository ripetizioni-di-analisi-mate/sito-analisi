For which $k$ does the intersection of $2x+y=6$ and $kx-y=9$ lie on the horizontal axis?

- $-3$
- $\dfrac32$
- $3$
- $2$

## Explanation

On the horizontal axis we have $y=0$. The first row then fixes $2x=6$, so $x=3$. The second line passes through the same point if $3k=9$, giving $k=3$. At this value the determinant is $-5$, so the intersection is indeed a single point on the axis.
