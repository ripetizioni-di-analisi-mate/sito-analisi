Consider $x+y=3$, $x-y=1$, and $2x+2y=6$ as a system in $x,y,z$. Which set describes the solution triples?

- $\{(2;1;t):t\in\mathbb R\}$
- $\{(2;1;0)\}$
- $\{(1;2;t):t\in\mathbb R\}$
- $\varnothing$

## Explanation

Adding the first two equations gives $2x=4$, so $x=2$ and $y=1$. The third row is twice the first and is already satisfied. None of the equations contains $z$, so any real number is allowed for the third coordinate. Having three equations does not guarantee three independent constraints.
