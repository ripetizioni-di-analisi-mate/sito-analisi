A box contains $10$ blue and red tokens in total. There are $4$ more blue tokens than red tokens. How many red tokens are there?

- $3$
- $10$
- $7$
- $4$

## Explanation

The sum is known, and the difference is how many more blue tokens there are. Subtracting the difference from the sum gives twice the number of red tokens. The number of red tokens is $3$.
