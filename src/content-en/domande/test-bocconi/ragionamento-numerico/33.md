A table shows the base quantities and current index values for two units.

| Unit | Base volume | Current index |
| --- | ---: | ---: |
| A | 80 | 110 |
| B | 100 | 88 |

Which statement about current volumes is true?

- A exceeds B by 10%.
- A exceeds B by 22 units.
- B exceeds A by 20 units.
- The current volumes are equal.

## Explanation

Apply each unit's index to its own base. A has $80\cdot 1.10=88$ units and B has $100\cdot 0.88=88$ units. The volumes are equal.
