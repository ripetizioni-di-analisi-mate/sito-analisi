The turnstile of a public swimming pool records $840$ entries in one week. Each entry belongs to a pass holder, and the rules allow each pass holder at most three entries per week. Which statement about the number of different pass holders who entered during the week is guaranteed?

- Exactly $280$ pass holders entered.
- At least $280$ pass holders entered.
- At most $280$ pass holders entered.
- Exactly $840$ pass holders entered.

## Explanation

The turnstile counts entries, so the same pass holder appears as many times as they enter. Each pass holder contributes at most $3$ entries, so $n$ pass holders produce at most $3n$ entries. The condition $3n\ge 840$ gives $n\ge 280$. The value $280$ occurs only if everyone enters three times; if each pass holder enters once, there are $840$ pass holders. Hence the data guarantee only the lower bound.
