Taking into account the monotonicity of exponential and logarithmic functions, which inequality is true?

- $\log_{\frac12}3<\log_{\frac12}2$
- $\log_3 5<\log_3 4$
- $\left(\dfrac12\right)^3>\left(\dfrac12\right)^2$
- $\left(\dfrac32\right)^{-2}>\left(\dfrac32\right)^{-1}$

## Explanation

With base $\dfrac12<1$ the logarithm is decreasing, so $3>2$ implies $\log_{\frac12}3<\log_{\frac12}2$. With base $3>1$ the logarithm is increasing, therefore $\log_3 5>\log_3 4$. The exponential function with base $\dfrac12$ is decreasing, so $\left(\dfrac12\right)^3<\left(\dfrac12\right)^2$. The exponential function with base $\dfrac32$ is increasing and $-2<-1$, hence $\left(\dfrac32\right)^{-2}<\left(\dfrac32\right)^{-1}$.
