Using $y$ as the input to the inverse, what is $f^{-1}(y)$ for $f(x)=\dfrac{x-3}{5}$ on $\mathbb R$?

- $5y+3$
- $\dfrac{5}{y-3}$
- $5y-3$
- $\dfrac{y+3}{5}$

## Explanation

From $y=\dfrac{x-3}{5}$ we get $5y=x-3$, hence $x=5y+3$. The original function has nonzero slope and range $\mathbb R$, so the inverse is defined on all real numbers.
