What is the solution set of $\log_{\frac13}x>2$?

- $\left(0,\dfrac19\right]$
- $\left(\dfrac19,+\infty\right)$
- $\left(0,\dfrac13\right)$
- $\left(0,\dfrac19\right)$

## Explanation

The base $\dfrac13$ is below $1$, so the logarithm is decreasing. For the output to exceed $2$, the input must be less than $\left(\dfrac13\right)^2=\dfrac19$ and strictly positive.
