On which interval is the function $f(x)=x^2-6x$ one-to-one?

- $[3,+\infty)$
- $[0,+\infty)$
- $[0,6]$
- $[2,5]$

## Explanation

Completing the square gives $f(x)=(x-3)^2-9$, so the graph is a parabola with axis of symmetry $x=3$. Two inputs symmetric about $3$, such as $2$ and $4$, give the same value $f(2)=f(4)=-8$. The intervals $[0,+\infty)$, $[0,6]$ and $[2,5]$ contain both $2$ and $4$, therefore $f$ is not one-to-one on them. On $[3,+\infty)$ the function is increasing, so different inputs give different values.
