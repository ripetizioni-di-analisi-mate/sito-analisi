For which values of $x$ does the equality $\log_3 x+\log_3(x-8)=2$ hold?

- $\{-1,9\}$
- $\left\{\dfrac{17}{2}\right\}$
- $\{3\}$
- $\{9\}$

## Explanation

Both arguments must be positive, so $x>8$. On this set the sum of the logarithms is $\log_3\bigl(x(x-8)\bigr)$, therefore the equation is equivalent to $x(x-8)=3^2=9$. The equation $x^2-8x-9=0$ factors as $(x-9)(x+1)=0$ and has roots $9$ and $-1$. Only $x=9$ satisfies $x>8$, so it is the only solution.
