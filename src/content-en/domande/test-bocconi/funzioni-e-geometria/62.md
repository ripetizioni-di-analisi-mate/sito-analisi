The equation $9^x-3^{x+1}=54$ has exactly one real solution. Which one?

- $x=9$
- $x=1$
- $x=2$
- $x=3$

## Explanation

Set $t=3^x$, with $t>0$, so $9^x=t^2$ and $3^{x+1}=3t$. The equation becomes $t^2-3t-54=0$, whose roots are $t=9$ and $t=-6$. The root $t=-6$ must be discarded, because $3^x$ is always positive. From $3^x=9=3^2$ we get $x=2$.
