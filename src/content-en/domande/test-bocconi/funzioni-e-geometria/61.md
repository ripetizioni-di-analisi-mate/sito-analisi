A machine's average time per piece is $T(n)=\dfrac{12n+40}{n}$ seconds for a batch of $n\ge1$ pieces. Which value can be approached by increasing the batch size but is never reached?

- $52$ seconds
- $12$ seconds
- $0$ seconds
- $40$ seconds

## Explanation

Separating terms gives $T(n)=12+\dfrac{40}{n}$. For each finite batch $\dfrac{40}{n}$ is positive but can be made arbitrarily small by increasing $n$. The time therefore approaches $12$ seconds from above.
