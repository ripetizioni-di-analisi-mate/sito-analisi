Which symmetry does the graph of $f(x)=x^5-2x$ have?

- Symmetric about the origin.
- Symmetric about the vertical axis.
- Symmetric about the line $y=x$.
- Symmetric about the horizontal axis.

## Explanation

Substituting $-x$ gives $-x^5+2x=-f(x)$. The function is odd, so the points $(x,f(x))$ and $(-x,-f(x))$ are symmetric about the origin.
