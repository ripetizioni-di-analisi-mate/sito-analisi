An application must evaluate $\sqrt{7-4\sqrt3}$ using only a single simple radical. Which expression should it use?

- $7-2\sqrt3$
- $\sqrt3-2$
- $2+\sqrt3$
- $2-\sqrt3$

## Explanation

Recognise $7-4\sqrt3=(2-\sqrt3)^2$. The principal square root is the absolute value of $2-\sqrt3$. Since $4>3$, we have $2>\sqrt3$, giving $2-\sqrt3$.
