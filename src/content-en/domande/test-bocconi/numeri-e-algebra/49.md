A counter starts at $0$. Each command either adds $6$ or subtracts $4$. Which value is impossible to reach by a sequence of commands?

- $8$
- $5$
- $2$
- $-2$

## Explanation

Both commands preserve parity, so starting from $0$ gives only even numbers. The other values are reachable as $6-4=2$, $6-4-4=-2$ and $6+6-4=8$. The excluded value is $5$.
