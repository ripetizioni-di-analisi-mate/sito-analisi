The set $A$ is contained in the set $B$, that is, $A\subseteq B$. Which of the following equalities holds in every case?

- $A\cup B=A$
- $B\setminus A=\varnothing$
- $A\cap B=A$
- $A\cap B=B$

## Explanation

Every element of $A$ also belongs to $B$, so the elements common to the two sets are exactly the elements of $A$. Therefore $A\cap B=A$. The other equalities hold only if $A=B$. For example, with $A=\{1\}$ and $B=\{1,2\}$ we get $A\cup B=B\ne A$ and $B\setminus A=\{2\}$.
