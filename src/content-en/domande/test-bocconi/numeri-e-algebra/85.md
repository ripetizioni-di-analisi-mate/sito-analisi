A display uses four binary digits with weights $8,4,2,1$ from left to right. It reads $0111$ and the counter increases by one. How many positions change digit?

- $3$
- $1$
- $2$
- $4$

## Explanation

The initial value is $4+2+1=7$. The new value is $8$, represented by $1000$. The last three digits change from one to zero and the first changes from zero to one, giving four changes in all.
