A code is a two-digit number whose digits sum to $11$. Reversing the digits gives a number $27$ larger than the original. What is the original code?

- $47$
- $38$
- $56$
- $74$

## Explanation

With tens digit $a$ and units digit $b$, the increase is $(10b+a)-(10a+b)=9(b-a)$. Hence $b-a=3$. Combining this with $a+b=11$ gives $b=7$ and $a=4$, so the code is $47$.
