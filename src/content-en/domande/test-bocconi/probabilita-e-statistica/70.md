A game library marks $120$ tiles from a collection and mixes them back with the rest. A later random sample of $30$ tiles contains $18$ marked ones. Using the sample proportion as an estimate of the marked proportion in the entire collection, what total collection size does it estimate?

- $200$
- $72$
- $138$
- $240$

## Explanation

The observed proportion is $\dfrac{18}{30}=\dfrac35$. If the collection size is $N$, its marked proportion is $\dfrac{120}{N}$. Equating this to the sample estimate gives $3N=600$, hence $N=200$. This is an estimate because the sample proportion may differ from the true proportion.
