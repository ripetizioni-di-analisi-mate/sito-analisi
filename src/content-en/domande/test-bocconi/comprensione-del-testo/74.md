> For centuries there was no common pitch for the note *A*, and each city or orchestra tuned its instruments differently. Musicians on tour therefore had to adapt to the instruments they found. In 1939 an international conference set *A* at 440 vibrations per second, a value that is still the reference standard today.

What role does the first sentence play?

- It explains how a sound vibration is physically produced.
- It reports the value set by the international conference.
- It describes the situation that the 1939 decision changed.
- It presents an exception to the current standard.

## Explanation

The first sentence describes the lack of a common pitch for *A*, and the second gives a practical consequence for musicians. The last sentence reports the decision that set a single value. The first sentence therefore presents **the starting situation** that the conference changed, while the value of 440 vibrations appears only in the last sentence.
