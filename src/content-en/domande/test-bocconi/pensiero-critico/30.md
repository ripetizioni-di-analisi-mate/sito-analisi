Every file in the quarter has a reviewer. All files with two attachments also have a second reviewer. There is a file U with two attachments among the quarter's files. Evaluate I ‘U has at least two reviewers’, II ‘There is a file in the quarter with no reviewer’, and III ‘Every file in the quarter has two attachments’. Which are necessarily false?

- II only.
- III only.
- II and III only.
- I and II only.

## Explanation

I follows from U's number of attachments. II contradicts the requirement that every file have a reviewer. III holds if every file has two attachments and is false if there is also a file with one attachment and one reviewer. Only II is therefore necessarily false.
