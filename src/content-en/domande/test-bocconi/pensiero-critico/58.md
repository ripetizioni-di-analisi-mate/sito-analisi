An airport's regulations state: ‘A flight departs only if visibility exceeds 500 meters.’ Which statement is equivalent to this rule?

- If visibility does not exceed 500 meters, the flight does not depart.
- If visibility exceeds 500 meters, the flight departs.
- If the flight does not depart, visibility does not exceed 500 meters.
- A flight departs if and only if visibility exceeds 500 meters.

## Explanation

Let $P$ be ‘the flight departs’ and $Q$ ‘visibility exceeds 500 meters’. The phrase ‘$P$ only if $Q$’ translates to $P\implies Q$. Its **contrapositive**, ‘if $Q$ is false, then $P$ is false’, is true and false in exactly the same cases, so it is equivalent. The statement ‘if visibility exceeds 500 meters, the flight departs’ is the implication $Q\implies P$, which the rule does not contain. ‘If the flight does not depart, visibility does not exceed 500 meters’ is also equivalent to $Q\implies P$, while ‘if and only if’ adds that same implication to the rule.
