One of three boxes contains only red pencils, one only blue pencils and one a mixture of the two. It is unknown which box has which contents. The labels “red”, “blue” and “mixed” are all wrong. From which box will drawing a single pencil always allow you to correct every label?

- The box labelled “mixed”.
- The box labelled “red”.
- Any of the three boxes.
- The box labelled “blue”.

## Explanation

The box labelled “mixed” must contain a single colour. If a red pencil is drawn, that box is the red one. The box labelled “blue” cannot then be blue because its label is wrong or red because the red box is already identified. It must be mixed, leaving blue pencils in the box labelled “red”. If a blue pencil is drawn, the same reasoning applies with the colours exchanged.
