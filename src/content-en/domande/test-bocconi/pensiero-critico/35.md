A museum displays every restored work that is not a copy. Restored copies may be displayed to complete a cycle of paintings. All that is known about work K is that it is restored and is a copy. Which judgment is supported by the data?

- K must be displayed.
- K must be removed from the collection.
- K cannot be displayed.
- Whether K is displayed cannot be determined.

## Explanation

The first rule concerns only restored works that are not copies. K is a copy, so the first rule says nothing about K. The second rule allows restored copies to be displayed but does not require it, so both the case in which K is displayed and the case in which it is not are compatible with the data. Consequently the data do not determine whether K is displayed.
