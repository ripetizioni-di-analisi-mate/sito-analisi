‘If a water sample is contaminated, the rapid test is positive. The test on sample 7 was negative, so sample 7 is not contaminated.’ Which of the following arguments has the same structure?

- If a registered letter is stamped, it is delivered. Ugo's registered letter was not stamped, so it was not delivered.
- If a registered letter is stamped, it is delivered. Ugo's registered letter was delivered, so it was stamped.
- If a registered letter is stamped, it is delivered. Ugo's registered letter was not delivered, so it was not stamped.
- If a registered letter is stamped, it is delivered. Ugo's registered letter was stamped, so it was delivered.

## Explanation

The argument about the sample has the form ‘if $P$ then $Q$; $Q$ is false; therefore $P$ is false’, that is, it applies **contraposition**. In the argument about the undelivered letter, $P$ is ‘the letter is stamped’ and $Q$ is ‘it is delivered’, and the lack of stamping is concluded from the failed delivery. The structure is therefore the same. The other three arguments start from the negation of $P$, from the truth of $Q$ or from the truth of $P$, so they have different structures.
