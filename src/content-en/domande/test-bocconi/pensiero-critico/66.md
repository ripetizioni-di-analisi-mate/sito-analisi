In a network all links are one-way. B is reachable from A and C is reachable from B. A student concludes that A and C are mutually reachable. Which one fact would complete the proof?

- A and C both have an outgoing link.
- The paths from A to B and from B to C have equal lengths.
- There is also a direct link from A to C.
- There is a path from C to A.

## Explanation

The first two legs already provide a path from A to C. Mutual reachability requires a path in the opposite direction; a second outward route does not supply that missing fact.
