An archive uses a deterministic rule which, according to a clerk, assigns each file to a room using only year and language. Which observation would directly refute that description?

- Every file observed is in Italian.
- One room contains files in three languages.
- Two files from different years end up in the same room.
- Two files of the same year and language are assigned to different rooms.

## Explanation

A deterministic rule using only year and language must produce the same outcome for identical inputs. Different inputs may still lead to the same room.
