A warehouse follows the rule ‘every parcel weighing more than $20\,\mathrm{kg}$ carries a red label’. For each of four parcels only one fact is known: A weighs $25\,\mathrm{kg}$, B weighs $12\,\mathrm{kg}$, C has a red label, D has a white label. Which parcels must be examined to make sure the rule has been followed?

- A and C
- A and D
- A only
- A, C and D

## Explanation

The rule has the form $P\implies Q$, with $P$ ‘the parcel weighs more than $20\,\mathrm{kg}$’ and $Q$ ‘the parcel carries a red label’. A parcel breaks the rule only if $P$ is true and $Q$ is false. A weighs more than $20\,\mathrm{kg}$, so its label must be examined. D has a white label, so its weight must be examined, because a weight above $20\,\mathrm{kg}$ would break the rule. B weighs less than $20\,\mathrm{kg}$ and C has a red label, so neither of them can break the rule, whatever the missing fact is. Therefore **A and D** must be examined.
