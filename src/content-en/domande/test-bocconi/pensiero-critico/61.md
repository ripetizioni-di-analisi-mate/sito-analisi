To obtain a driver's license, a candidate must pass a theory test and a practical test, and anyone who passes both obtains the license. Only candidates who have already passed the theory test are admitted to the practical test. Which condition is necessary but not sufficient for obtaining the license?

- Passing the practical test.
- Passing both tests.
- Taking the theory test only once.
- Passing the theory test.

## Explanation

Passing the theory test is necessary, because anyone who obtains the license has passed both tests. It is not sufficient, because someone who passes the theory test and then fails the practical test gets no license. Passing the practical test is necessary and also sufficient, since only those who have passed the theory test are admitted to it, so anyone who passes it has passed both tests. Passing both tests is necessary and sufficient by the rule itself. Taking the theory test only once is not necessary, because the rule does not forbid retaking it. The condition that is necessary but not sufficient is therefore **passing the theory test**.
