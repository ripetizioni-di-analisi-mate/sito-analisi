A program keeps a document when the archive option is on and deletes it when the cleanup option is on. No rule sets a priority if both options are on. Which case shows that the instructions fail to give a unique choice?

- One document has archiving on and a different one has cleanup on.
- Only the cleanup option is on.
- Only the archive option is on.
- Both options are on for the same document.

## Explanation

With both options on for one document, incompatible instructions apply simultaneously. A priority rule would resolve the conflict.
