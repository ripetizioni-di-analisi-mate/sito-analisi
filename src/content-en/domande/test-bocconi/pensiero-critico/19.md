From Wednesday onward, anyone receiving a temporary pass must return it on the same day. Recipients of an annual pass follow a separate procedure. A technician receives a temporary pass on Wednesday and a visitor receives an annual pass on Thursday. What is certain?

- Only the visitor must return the pass the same day.
- Wednesday is outside the procedure, so the technician's deadline is undetermined.
- The technician must return it on Wednesday, and the visitor's deadline is unspecified.
- Each must return the pass on the day it is received.

## Explanation

The effective date includes Wednesday, and the technician's pass is temporary. It is therefore due back on that day. The annual pass follows a separate procedure for which the passage gives no deadline.
