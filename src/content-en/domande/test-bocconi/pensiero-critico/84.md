A seal is kept in exactly one of drawers A, B and C. A says “The seal is in B”, B says “The seal is not in C”, and C says “The seal is not in A”. Exactly one inscription is true. Which drawers remain possible?

- All three.
- A and B.
- B only.
- A and C.

## Explanation

If the seal is in A, only the inscription on B is true; if it is in C, only the one on C is true. In B all three would be true, so B is excluded.
