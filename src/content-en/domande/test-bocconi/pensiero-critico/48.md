Libraries with more volunteers hold more public readings. A report concludes that recruiting volunteers generates new events. Which observation specifically supports the reverse explanation?

- Some libraries have rooms with the same number of chairs.
- The number of readings was copied from a reliable calendar.
- The reading calendars were approved before volunteers signed up specifically for those readings.
- Volunteers and readers use the same entrance.

## Explanation

The calendar came before the sign-ups and prompted them. This provides a mechanism by which scheduled events could attract volunteers.
