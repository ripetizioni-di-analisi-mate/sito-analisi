Two scales, calibrated with the same reference mass, both read 50 grams for an object. A director concludes that the object weighs exactly 50 grams. What circumstance would weaken this inference while leaving both readings as reported?

- The scales were in different rooms.
- The reference mass used for both calibrations had an incorrect assigned value.
- One display had larger digits.
- Both instruments used grams as their unit.

## Explanation

Agreement between the scales is compatible with a shared systematic error. An incorrect common reference can shift both readings in the same way while leaving them in agreement.
