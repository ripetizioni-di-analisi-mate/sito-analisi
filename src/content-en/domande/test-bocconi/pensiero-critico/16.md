In a locker, every red document holder is numbered. The passage does not say whether there are any red holders. Which situation conflicts with the rule?

- There are numbered holders and none is red.
- There are no red holders.
- There are two holders, a numbered red one and an unnumbered green one.
- There is a red holder with no number.

## Explanation

The unnumbered red holder belongs to the group that the rule requires to be numbered and lacks the required property. In the other cases all red holders, if any, are numbered, including when the red group is empty.
