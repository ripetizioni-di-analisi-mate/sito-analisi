An application is accepted if its written test has been validated. It can appear in the ranking only if it is accepted. Application U appears in the ranking. What follows for U?

- Its test has been validated, and acceptance cannot be determined.
- It is accepted, and its test has definitely been validated.
- It is not accepted.
- It is accepted, and validation of the test cannot be determined.

## Explanation

Appearing in the ranking implies acceptance. Validation suffices for acceptance, so acceptance after validation fits. The passage also allows an application to be accepted for another reason and included in the ranking. Whether U's test was validated remains undetermined.
