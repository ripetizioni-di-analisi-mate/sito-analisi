‘Every violin in the orchestra has been tuned. Livia's instrument has been tuned. So Livia's instrument is a violin in the orchestra.’ Which of the following arguments has the same structure?

- Every apple in the basket is ripe. This fruit is an apple from the basket. So this fruit is ripe.
- Every apple in the basket is ripe. The fruit on the table is ripe. So the fruit on the table is an apple from the basket.
- Every apple in the basket is ripe. This fruit is not ripe. So this fruit is not an apple from the basket.
- No apple in the basket is unripe. This fruit is an apple from the basket. So this fruit is not unripe.

## Explanation

Let $A$ be the set of violins in the orchestra and $B$ the set of tuned instruments. The first premise states $A\subseteq B$, and the second places Livia's instrument in $B$. The conclusion places it in $A$, so the argument goes from an element of $B$ to an element of $A$. The argument about the ripe fruit has **the same structure**, with $A$ the apples in the basket and $B$ the ripe fruit. The other three arguments start from an element of $A$ or from an element outside $B$, so they have a different structure and are valid.
