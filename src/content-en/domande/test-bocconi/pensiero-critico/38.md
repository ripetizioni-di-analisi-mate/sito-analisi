Every package produced on line B has a code. Package R has a code. Package S lacks a code. Evaluate I ‘R was produced on line B’ and II ‘S was produced on line B’.

- I false, II cannot be determined.
- I cannot be determined, II false.
- I true, II false.
- Neither I nor II can be determined.

## Explanation

Lacking a code rules S out of the group produced on line B. R's code fits production on B and also production on another line that uses codes. I cannot be determined and II is false.
