The register says, “All exempt applications are filed in blue.” There might be no exempt applications. Which additional piece of information suffices to conclude that at least one application is filed in blue?

- An empty blue folder exists.
- Application R is exempt.
- An ordinary application is filed in green.
- Some applications are not exempt.

## Explanation

An exempt application R supplies an instance to which the rule applies. Neither the universal rule alone nor an empty folder guarantees such an instance.
