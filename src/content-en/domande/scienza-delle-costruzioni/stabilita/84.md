A pin-ended column of length $4\,\mathrm m$ has $EI=320\,\mathrm{kN\,m^2}$. Evaluate the Rayleigh quotient using the trial function $\varphi=\sin\!\left(\dfrac{2\pi x}{L}\right)$. What value does this give?

- $20\pi^2\,\mathrm{kN}$
- $40\pi^2\,\mathrm{kN}$
- $160\pi^2\,\mathrm{kN}$
- $80\pi^2\,\mathrm{kN}$

## Explanation

The function is admissible because it vanishes at $x=0$ and $x=L$. The numerator is $EI\left(\dfrac{2\pi}{L}\right)^4\dfrac L2$ and the denominator is $\left(\dfrac{2\pi}{L}\right)^2\dfrac L2$. The quotient is therefore $\dfrac{4\pi^2EI}{L^2}=\dfrac{4\pi^2\cdot320}{16}\,\mathrm{kN}=80\pi^2\,\mathrm{kN}$, the buckling load for the second mode. This is an upper bound on the lowest buckling load $20\pi^2\,\mathrm{kN}$. It is a poor approximation because the assumed shape has a node at midspan.
