For the second buckling mode of an ideal pin-ended column, set $v\!\left(\dfrac{L}{4}\right)=+3\,\mathrm{mm}$. What is $v\!\left(\dfrac{3L}{4}\right)$ using the same normalization?

- $-3\,\mathrm{mm}$
- $-6\,\mathrm{mm}$
- $0\,\mathrm{mm}$
- $+3\,\mathrm{mm}$

## Explanation

The second mode shape is $C\sin\!\left(\dfrac{2\pi x}{L}\right)$. The sine at the two points is $+1$ and $-1$, respectively. The normalization sets $C=3$ mm, so the displacement at the second point is $-3\,\mathrm{mm}$.
