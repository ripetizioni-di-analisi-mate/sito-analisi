For a column in compression, the Rayleigh quotient evaluated with the admissible trial function $\varphi$ is $320\,\mathrm{kN}$. For the same column, what is the value of the quotient using trial function $3\varphi$?

- $320\,\mathrm{kN}$
- $2880\,\mathrm{kN}$
- $960\,\mathrm{kN}$
- $107\,\mathrm{kN}$

## Explanation

Multiplying the trial function by $3$ multiplies the numerator $\int EI(\varphi'')^2\,dx$ by $9$. The denominator $\int(\varphi')^2\,dx$ is also multiplied by $9$. The quotient therefore remains $320\,\mathrm{kN}$. The Rayleigh quotient depends on the shape of the trial function. Its amplitude cancels, consistent with the arbitrary amplitude of a buckling mode.
