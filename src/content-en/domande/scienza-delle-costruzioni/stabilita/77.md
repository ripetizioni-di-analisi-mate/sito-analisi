For a column in compression, minimizing the Rayleigh quotient over all linear combinations of two admissible functions gives $P_2$. A third admissible function is added. Minimizing again gives $P_3$. If $P_{\mathrm{cr}}$ denotes the exact critical load, which relation always holds?

- $P_{\mathrm{cr}}\le P_3\le P_2$
- $P_{\mathrm{cr}}\le P_2\le P_3$
- $P_3\le P_{\mathrm{cr}}\le P_2$
- $P_{\mathrm{cr}}\le P_3<P_2$, with the inequality always strict

## Explanation

The three-function space contains every combination of the first two functions, obtained by setting the third coefficient to zero. The minimum over a larger set cannot exceed the minimum over a subset, so $P_3\le P_2$. Every trial function in the set is admissible, so every value of the quotient is at least $P_{\mathrm{cr}}$. It follows that $P_{\mathrm{cr}}\le P_3\le P_2$. Equality $P_3=P_2$ holds when the third function does not improve the approximation to the first mode.
