A stable, statically determinate plane truss with $7$ joints is to be supported by a pin and a roller. How many members are required?

- $14$
- $11$
- $17$
- $7$

## Explanation

A statically determinate truss requires $m + r = 2j$ and independent equilibrium equations. The pin provides two reaction components and the roller one, so $r = 3$. With $j = 7$ we have $2j = 14$, so $m = 14 - 3 = 11$. The count is a necessary condition. The $11$ members must also be arranged so that the equilibrium matrix has rank $14$. For example, start with a triangle and add one joint at a time, using two noncollinear members for each new joint.
