Which description of the radian is correct in SI?

- It has length dimension because it comes from an arc.
- Being dimensionless, one radian equals one degree.
- It is a derived unit of dimension one, useful for identifying angles.
- It is an eighth independent base unit.

## Explanation

The radian is defined by a ratio of lengths, arc and radius, so dimensions cancel. Its symbol nevertheless preserves angular meaning. The degree has a different conversion factor and does not equal the radian merely because both describe angles. No new base quantity is introduced.
