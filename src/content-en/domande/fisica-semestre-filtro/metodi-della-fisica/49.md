A first-quadrant force makes $30^\circ$ with positive $y$. Which relation is correct?

- $F_x=F\sin30^\circ$, $F_y=F\cos30^\circ$.
- $F_x=-F\sin30^\circ$, $F_y=F\cos30^\circ$.
- $F_x=F\cos30^\circ$, $F_y=F\sin30^\circ$.
- $F_x=F\sin30^\circ$, $F_y=-F\cos30^\circ$.

## Explanation

The side adjacent to the given angle is vertical, so it uses cosine. The first quadrant requires positive components. Always pairing cosine with the horizontal component ignores the angle’s reference axis; that rule applies only when measured from positive horizontal.
