Which statement correctly distinguishes scalar and vector?

- A scalar must have the same numerical value in every unit.
- A negative value can describe either a scalar or a vector component.
- Every negative number represents a vector.
- A vector is completely determined by positive magnitude alone.

## Explanation

Sign is insufficient to classify a quantity: Celsius temperature can be negative and remain scalar. A vector also requires direction, including sense; one component can be negative relative to an axis. Changing units changes a scalar’s numerical value too without altering its nature.
