Work and torque have the same dimensions. Which conclusion is correct?

- Torque must be scalar because work is scalar.
- Equal dimensions do not make them the same physical quantity.
- Work necessarily uses the same cross product as torque.
- Work and the torque vector can always be added directly.

## Explanation

Dimensions check compatibility without fully describing a quantity’s nature and meaning. Work is a dot product, torque a cross product about a point. Unit usage also distinguishes them: joules for work and newton metres for torque. Dimensional agreement does not replace the definition.
