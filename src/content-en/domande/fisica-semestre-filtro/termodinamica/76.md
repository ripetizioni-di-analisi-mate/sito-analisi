An actual process is irreversible. To calculate the system’s $\Delta S$ between equilibrium states, which procedure is correct?

- Use actual heat without distinguishing exchange temperatures.
- Use a reversible path between the same states and integrate $\dfrac{\delta Q_{\mathrm{rev}}}{T}$.
- Always divide actual heat by final temperature.
- Set $\Delta S=0$ when the actual path is unknown.

## Explanation

Entropy is a state function, so an auxiliary reversible path gives the same endpoint change. Heat is path dependent: actual heat cannot automatically replace reversible heat. Ideal free expansion provides an example of zero heat with positive entropy change.
