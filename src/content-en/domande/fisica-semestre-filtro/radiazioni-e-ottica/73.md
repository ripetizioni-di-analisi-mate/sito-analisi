A $6.00\,\mathrm{eV}$ photon encounters, alternatively, targets with thresholds $4.00$ and $7.00\,\mathrm{eV}$. Which statement is correct for one photon?

- It is energetically sufficient for the first target, but not the second.
- It is sufficient only for the second, which has the higher threshold.
- It cannot ionize either because it is not an X ray.
- It certainly ionizes both because it is ultraviolet.

## Explanation

The relevant comparison is $6>4$ but $6<7$. A spectral-region name does not replace target ionization energy. For the first target this establishes energetic possibility, not certainty for every interaction; the second lacks sufficient energy in the specified single-photon process.
