For a thin converging lens in air, a real object is at $p=2f$. Which image description is correct?

- $q=f$, real and half-sized.
- $q=2f$, real and inverted, with $M=-1$.
- $q=-2f$, virtual and upright.
- $q=2f$, real and upright, with $M=+1$.

## Explanation

From $\dfrac1q=\dfrac1f-\dfrac{1}{2f}=\dfrac{1}{2f}$, $q=2f$. Magnification is $-\dfrac{q}{p}=-1$: equal size magnitude but inverted orientation. The focal position $q=f$ instead belongs to the limit of a very distant object, not one at finite distance $2f$.
