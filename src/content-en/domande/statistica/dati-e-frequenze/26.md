Ratings are coded 1 for poor, 2 for adequate, and 3 for excellent. Which recoding preserves the order of the categories?

- 80, 20, 10
- 10, 80, 20
- 10, 20, 80
- 20, 20, 80

## Explanation

The scale requires the code for poor to be less than the code for adequate, which in turn must be less than the code for excellent. A new coding preserves the order if the three categories receive strictly increasing values in the same sequence. The gaps can change because the numbers indicate only the ratings' positions in the ordering. A tie would collapse two levels.
