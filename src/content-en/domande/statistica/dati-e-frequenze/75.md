A report expresses each row of a table as percentages of its own total. What does $100\%$ of a nonempty row represent?

- Only the units in the most frequent cell of the row
- All units in the table
- All units in the first column
- All units belonging to that row

## Explanation

In a nonempty row, divide each cell count by the row total and multiply by $100$. Adding the percentages sums all row counts over the same denominator. The result is $100\%$, representing all units in that row, whatever its size.
