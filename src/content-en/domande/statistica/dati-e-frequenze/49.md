The last class in a table is $[25,+\infty)$. What can be determined from the stated endpoints?

- A finite width of 25
- An upper endpoint equal to twice 25
- A midpoint of 25
- The lower endpoint, but no finite midpoint

## Explanation

The lower endpoint $25$ is included. The class is unbounded to the right, so there is no second finite endpoint with which to average the lower endpoint. The lower bound is therefore known, while choosing a representative value requires further information, for example about the observations themselves.
