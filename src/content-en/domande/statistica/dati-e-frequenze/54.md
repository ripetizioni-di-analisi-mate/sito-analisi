Data are assigned to the classes $[0,5]$ and $[5,10]$. What problem arises for the value 5?

- It belongs to neither class
- It belongs only to the second class
- It belongs only to the first class
- It belongs to both classes

## Explanation

The first interval includes $5$ as its right endpoint, and the second includes $5$ as its left endpoint. Thus $5$ would be counted in both classes. For an unambiguous assignment one could use $[0,5)$ and $[5,10]$, for example. The boundary $5$ would then belong only to the second class, with the same overall coverage.
