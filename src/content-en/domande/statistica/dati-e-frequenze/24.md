A table records each person's age and number of visits. Which operation preserves the pairs needed to study the relationship between the variables?

- Sort the two columns independently
- Permute only the column containing the numbers of visits
- Replace each column with its marginal distribution
- Sort complete rows by age

## Explanation

Studying the relationship between age and visits requires both values for the same person. Sorting complete rows by age moves each pair together and preserves the pairing. Sorting the columns separately preserves individual values but can assign one person's number of visits to someone else, changing the observed relationship.
