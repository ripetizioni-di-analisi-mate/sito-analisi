In a table of 100 cases, the first row contains 40 and the second column contains 55. Their common cell contains 18. How many cases belong to the first row or the second column, including those common to both?

- $95$
- $77$
- $18$
- $59$

## Explanation

Adding the $40$ cases in the first row and the $55$ in the second column counts the $18$ in their common cell twice. The question includes these cases once. Subtracting one copy of the intersection gives $40+55-18=77$. Equivalently, count the entire row and add only the $55-18=37$ column cases outside it.
