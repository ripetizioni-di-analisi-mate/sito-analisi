In a frequency density histogram based on counts, the class $[2,9)$ meters has height 3 observations per meter. Find the number of observations in the class.

- $27$
- $3$
- $\dfrac{3}{7}$
- $21$

## Explanation

Since the histogram uses counts, each rectangle's area represents the number of observations in its class. The rectangle has width $(9-2)\,\mathrm{m}=7\,\mathrm{m}$ and height $3$ observations per meter. Multiplying cancels the meters and gives $7\cdot3=21$ observations. The value $3$ is a density: on its own it gives the count per meter of class width.
