A two-by-two table contains 90 units. The first row totals 35 and the first column totals 42. The first cell of the first row contains 18 units. How many units are in the second cell of the second row?

- $17$
- $24$
- $48$
- $31$

## Explanation

The second row contains $90-35=55$ units. To obtain its first cell, subtract the $18$ units in the first row from the first column total, leaving $42-18=24$ units. The second cell of the second row therefore contains $55-24=31$ units. The two recovered cells add to the second row total.
