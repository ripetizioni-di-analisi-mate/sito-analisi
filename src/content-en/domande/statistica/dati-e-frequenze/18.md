In a database, codes 0, 1, and 2 represent sites A, B, and C, respectively, with no relevant ordering. What type of variable is recorded?

- Discrete quantitative
- Ordinal categorical
- Nominal categorical
- Continuous quantitative

## Explanation

The values $0$, $1$, and $2$ identify three sites. For example, if the codes for sites A and C were exchanged, each observation would still identify the same site using the new key. Numerical differences between codes therefore have no meaning for the characteristic being observed. The variable is **nominal categorical**.
