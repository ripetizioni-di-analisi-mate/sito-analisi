Seventy questionnaires are collected. Fourteen people skip question A, and 21 answer yes to A. Find the proportion of yes responses among valid responses to question A.

- $\dfrac{1}{5}$
- $\dfrac{3}{8}$
- $\dfrac{4}{5}$
- $\dfrac{3}{10}$

## Explanation

Only questionnaires with an answer to A can be used for that question. Exclude the $14$ that omit it, leaving $70-14=56$ valid responses. There are $21$ yes responses, so the proportion is $\dfrac{21}{56}=\dfrac38$. Using $70$ would compare yes responses with all questionnaires, including those missing this answer.
