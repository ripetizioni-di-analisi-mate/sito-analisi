Which graph can show the counts for four colors without implying a quantitative scale on the horizontal axis?

- An empirical distribution function on a length axis
- A bar chart with separate bars labeled by color
- A density graph connecting the codes with straight segments
- A histogram with class width equal to the color code

## Explanation

Colors are nominal categories and can be identified by name without assigning them numerical positions. A **bar chart with separate bars** assigns one bar to each color and shows its count on the vertical axis. The spacing and order of the bars can be chosen for readability because each bar's height carries the information.
