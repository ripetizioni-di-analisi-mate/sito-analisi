In a survey, each student's home-to-school travel time is recorded in whole minutes, rounded to the nearest minute. What type of variable is "travel time"?

- Continuous quantitative
- Discrete quantitative
- Ordinal categorical
- Nominal categorical

## Explanation

The values of travel time are numbers, so the variable is quantitative. In principle a trip can last any value in an interval, for example $31$, $31.5$ or $31.47$ minutes, so the variable is continuous. Rounding to the minute only concerns the way the data are recorded. For example, two travel times of $31.2$ and $31.4$ minutes produce the same recorded value $31$, while the variable observed is still the travel time. The variable is therefore **continuous quantitative**.
