A log-likelihood contains the term $-n\log(2\pi)$, which is independent of the parameter. What effect does omitting it have on the maximum likelihood estimate?

- Values at the boundary are excluded
- The maximizers stay the same
- The minimizers are obtained
- The estimated parameter decreases by $n$

## Explanation

The indicated term has the same value for every parameter choice. Removing it shifts the function vertically by $n\log(2\pi)$. Log-likelihood differences between points stay the same, so the same points maximize the function. Its numerical value at the maximum changes while the estimate is preserved.
