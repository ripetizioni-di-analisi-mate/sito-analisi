An estimator $T$ is rounded to the nearest integer, and the true parameter $\theta$ is known to be an integer. Which example shows rounding can increase the squared error on an individual sample?

- $\theta=0,\ T=0.4$
- $\theta=1,\ T=1.1$
- $\theta=0,\ T=0.6$
- $\theta=2,\ T=2$

## Explanation

On the integer grid $0.6$ rounds to $1$. When $\theta=0$ the squared error increases from $0.36$ to $1$. In each of the other examples the rounded value equals the parameter.
