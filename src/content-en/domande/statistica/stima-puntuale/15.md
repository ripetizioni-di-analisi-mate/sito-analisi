The observations are $1,2,3,6$ and the mean is estimated using $\bar X$. Which notation represents the value obtained from the data?

- $E[\bar X]=3$ for every population
- $\bar x=3$
- $n=3$
- $\mu=3$ with certainty

## Explanation

The capital letter in $\bar X$ denotes a rule applied to a still-random sample. The four fixed data values give the number $\dfrac{1+2+3+6}{4}=3$, denoted $\bar x=3$. This number is an estimate of the population mean. The estimator's expectation and the true value of $\mu$ are distinct concepts.
