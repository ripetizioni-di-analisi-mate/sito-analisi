Every urgent application is also a priority application. Let $U$ be the event “the application is urgent” and $Q$ the event “the application is a priority application.” Which event is necessarily impossible?

- $U\cap Q$
- $U\cap Q^c$
- $U^c\cap Q^c$
- $Q\cap U^c$

## Explanation

The assumption “every urgent application is a priority application” means $U\subseteq Q$. Event $Q^c$ contains only nonpriority applications, and all applications in $U$ lie outside $Q^c$. No application can therefore belong to both $U$ and $Q^c$. The intersection $U\cap Q^c$ is empty, although the assumption allows priority applications that are not urgent.
