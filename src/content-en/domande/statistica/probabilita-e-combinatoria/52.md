Every urgent application is also a priority application. Let $U$ and $P$ denote the two events. Which event is necessarily impossible?

- $U\cap P$
- $U\cap P^c$
- $U^c\cap P^c$
- $P\cap U^c$

## Explanation

The assumption “every urgent application is a priority application” means $U\subseteq P$. Event $P^c$ contains only nonpriority applications, and all applications in $U$ lie outside $P^c$. No application can therefore belong to both $U$ and $P^c$. The intersection $U\cap P^c$ is empty, although the assumption allows priority applications that are not urgent.
