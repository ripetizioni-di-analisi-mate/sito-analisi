A menu offers three first courses and two main courses. One first course can be paired only with the first main course. The other two can each be paired with either main course. How many two-course meals are available?

- $5$
- $3$
- $4$
- $6$

## Explanation

A meal is determined by its first course and main course. The restricted first course allows only one pairing. Each other first course allows two, so the three groups contain $1$, $2$ and $2$ meals. The groups are disjoint because their first courses differ, giving $1+2+2=5$ meals in total.
