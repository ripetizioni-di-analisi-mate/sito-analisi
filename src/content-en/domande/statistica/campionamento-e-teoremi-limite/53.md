Each measurement $X_i$ repeats the same value $Y$, which equals $1$ or $3$ with equal probability. For $n\ge2$, what is $P(|\bar X_n-2|>0.5)$?

- $1$
- $\dfrac{1}{2}$
- $0$
- $\dfrac1n$

## Explanation

All measurements equal $Y$, so their mean equals $\bar X_n=Y$ at every sample size. For both $Y=1$ and $Y=3$, the distance from $2$ is $1$, which exceeds $0.5$. These possibilities exhaust the outcomes, so the probability is $1$. Repeating the same variable preserves the original uncertainty.
