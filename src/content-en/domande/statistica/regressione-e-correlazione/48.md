The two-sided $95\%$ interval for $\beta$ is $[0.2;\,1.4]$. For the same data, which of $0$, $0.6$, and $1.2$ would a two-sided test at level $5\%$ reject?

- Only $0.6$.
- Only $1.2$.
- All three.
- Only $0$.

## Explanation

The $95\%$ interval contains the slope values compatible with the two-sided test at level $5\%$ based on the same data. Both $0.6$ and $1.2$ lie between $0.2$ and $1.4$, so their null hypotheses are not rejected. The value $0$ falls below the lower endpoint and is rejected. The comparison uses corresponding levels for both procedures.
