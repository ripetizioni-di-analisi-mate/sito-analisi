A line fitted to temperatures between $15$ and $25\,^\circ\mathrm{C}$ is then used to predict at $50\,^\circ\mathrm{C}$. How should this use be interpreted?

- It is a use of the line within the observed data, because temperature is measured in the same units.
- The prediction is guaranteed to be valid if $R^2$ is high.
- It is a mean prediction that can use the line only if the slope is zero.
- It is extrapolation and assumes that the linear relationship continues beyond the sample.

## Explanation

The value $50\,^\circ\mathrm{C}$ exceeds the upper end of the observed predictor range, $25\,^\circ\mathrm{C}$. Using the fitted line outside its observed range is extrapolation. The prediction assumes the linear relationship extends to the new temperature. A good fit between $15$ and $25\,^\circ\mathrm{C}$ provides information about the relationship within the observed data.
