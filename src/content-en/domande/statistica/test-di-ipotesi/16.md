Under a simple null hypothesis, $Z$ is standard normal. The rule rejects $H_0$ when $Z\ge1.50$. What is the Type I error probability if $\Phi(1.50)=0.9332$?

- $0.0668$
- $0.1336$
- $0.05$
- $0.9332$

## Explanation

When $H_0$ is true, a Type I error means observing $Z\ge1.50$, the rejection region. The given distribution function value $\Phi(1.50)=0.9332$ measures the area to the left of the threshold. For this continuous distribution the critical-region probability is the complement $1-0.9332=0.0668$. Only one tail enters because the rule specifies one upper threshold.
