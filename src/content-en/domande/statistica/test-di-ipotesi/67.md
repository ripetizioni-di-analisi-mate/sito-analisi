Two two-sided z tests have the same nonzero observed deviation and the same $\sigma$ but different sample sizes. The second sample is larger. How do the observed statistics compare?

- The second absolute z value is smaller.
- The absolute values are equal.
- The second absolute z value is larger.
- The sample size changes the sign of z.

## Explanation

In each test $|z_{\mathrm{obs}}|=\dfrac{|\bar x-\mu_0|\sqrt n}{\sigma}$. Both have the same positive deviation magnitude and standard deviation $\sigma$. Only the factor $\sqrt n$ increases in the second sample, so its statistic has greater magnitude. The same difference spans more standard errors because the mean is more precisely estimated.
