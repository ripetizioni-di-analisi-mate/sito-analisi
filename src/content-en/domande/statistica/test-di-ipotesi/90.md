Which interval gives the null values compatible with a two-sided t test of a mean at significance level $0.05$?

- A $95\%$ z interval assuming a different known variance.
- The $95\%$ t interval based on the same data and assumptions.
- A prediction interval for a single future observation.
- The $90\%$ t interval based on the same data.

## Explanation

Inverting the test collects the mean values that would yield nonrejection if proposed as the null. A two-sided test at level $0.05$ corresponds to confidence level $1-0.05=0.95$. Use the $95\%$ t interval because, for the same data and assumptions, its reference distribution and standard error match those of the test.
