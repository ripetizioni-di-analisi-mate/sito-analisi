A $90\%$ confidence interval obtained by inverting a two-sided test extends from $4$ to $10$. At the corresponding significance level, which of $5$, $7$, $9$, and $11$ is rejected as a null value?

- $9$
- $5$
- $7$
- $11$

## Explanation

The interval inverts the two-sided test and contains its nonrejected null values. Confidence level $0.90$ corresponds to test level $1-0.90=0.10$. The values $5$, $7$, and $9$ lie inside $[4,10]$. The value $11$ exceeds the upper endpoint and is the only proposed value rejected.
