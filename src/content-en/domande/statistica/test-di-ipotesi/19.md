A chi-square goodness-of-fit test gives $Q=6$. Under the null, the reference cumulative distribution function at $6$ equals $0.9502$. Calculate the p-value.

- $0.0996$
- $0.0249$
- $0.0498$
- $0.9502$

## Explanation

The goodness-of-fit statistic sums standardized squared differences. Larger $Q$ values indicate larger discrepancies from the null model. The p-value is therefore $P_{H_0}(Q\ge6)$. The given distribution function counts probability up to $6$, so its complement is $1-0.9502=0.0498$. Only one tail is used even when individual categories deviate in opposite directions.
