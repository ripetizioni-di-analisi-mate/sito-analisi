A binomial rule rejects $H_0:p=\dfrac12$ only if all five independent trials are successes. What is the actual Type I error probability?

- $0.15625$
- $0.05$
- $0.0625$
- $0.03125$

## Explanation

Evaluate the Type I error at the null value $p=\dfrac12$. Only the sequence of five successes leads to rejection. Each trial succeeds with probability $\dfrac12$ and the trials are independent, so the sequence has probability $\left(\dfrac12\right)^5=\dfrac1{32}=0.03125$. There is only one such sequence because the required count is the maximum possible.
