In a goodness-of-fit test, two categories have expected counts below the required threshold. They are pooled into a category that makes sense for the problem. Which quantities must be added?

- Add the two original Pearson contributions and use the sum as the new expected count.
- Add the observed and expected counts within each original category.
- Add the observed counts together and, separately, add the expected counts together.
- Use only the category with the larger null probability.

## Explanation

The merged category includes every unit in either original category. The categories are disjoint, so add the observed counts. Their null probabilities also add, giving a new expected count equal to the sum of the two original expected counts. Recalculate the Pearson contribution using the new difference and expected count.
