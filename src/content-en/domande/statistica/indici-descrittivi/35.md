The first of five ordered observations is $4$ and the second is $12$. What is $Q_1$ when quartile ranks are rounded up?

- $4$
- $8$
- $10$
- $12$

## Explanation

For the first quartile, start with $p=0.25$. With five observations, $np=1.25$, so the smallest integer rank at least this large is $2$. The first observation alone represents only one-fifth of the list. The second is $12$, so $Q_1=12$. Under this convention the rank identifies an actual observation.
