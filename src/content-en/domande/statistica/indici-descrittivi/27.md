The ordered values are $2,6,8,14$. Each is transformed by $y=18-x$. Find the first quartile of $y$ using ranks rounded up.

- $10$
- $12$
- $16$
- $4$

## Explanation

With four observations the first quartile has rank $\lceil4\cdot0.25\rceil=1$, so use the smallest transformed value. Since $18-x$ is decreasing, the original maximum $14$ gives the transformed minimum. Thus $Q_1(y)=18-14=4$. Applying the transformation directly to the old first quartile would give the new sample maximum.
