An application is selected from those that required additional information. We want the probability that it was submitted online. Which group supplies the denominator when using counts?

- All applications submitted online or requiring additional information.
- All online applications.
- All applications that required additional information.
- Only online applications that required additional information.

## Explanation

The application is selected after we know that it required additional information. All applications requiring additional information belong in the denominator, including those submitted at the counter. Within this group the numerator counts online applications. Reversing the roles would put the number of online applications in the denominator and give the probability of additional information being required given online submission.
