A run passes the first check with probability $\dfrac{4}{5}$. Among runs that pass, $\dfrac{5}{8}$ also pass the second check. Among those passing both checks, $\dfrac{1}{3}$ undergo an additional inspection. Calculate the probability that a run passes both checks and undergoes the additional inspection.

- $\dfrac{1}{6}$
- $\dfrac{5}{24}$
- $\dfrac{1}{2}$
- $\dfrac{4}{15}$

## Explanation

Runs passing the first check represent $\dfrac45$ of all runs. The second rate refers to that group, so the proportion passing both is $\dfrac45\cdot\dfrac58=\dfrac12$. The additional inspection applies to one third of this half, giving the product $\dfrac12\cdot\dfrac13=\dfrac16$. Each factor after the first refers to runs that completed every preceding stage.
