Two inspections are compared on the same batch. They have the same positive sensitivity, but the second has higher specificity. Both defective and nondefective parts are present. How does positive predictive value change with the second inspection?

- It stays the same because the defective fraction is the same.
- It increases.
- It stays the same because the expected number of true positives is the same.
- It decreases.

## Explanation

On the same batch the defective fraction is fixed and positive. With the same positive sensitivity, the true positive contribution therefore remains fixed and positive. Higher specificity lowers the probability of flagging a nondefective part, reducing the false positive contribution. The numerator of positive predictive value stays fixed while the denominator falls, so the defective fraction among flagged parts increases.
