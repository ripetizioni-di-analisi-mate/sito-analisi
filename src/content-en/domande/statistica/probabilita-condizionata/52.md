Of $900$ transactions, $90$ are fraudulent. A filter flags $72$ fraudulent transactions and $18$ legitimate ones. What proportion of flagged transactions are fraudulent?

- $\dfrac{2}{25}$
- $\dfrac{5}{6}$
- $\dfrac{1}{5}$
- $\dfrac{4}{5}$

## Explanation

The $72$ flagged fraudulent transactions are true positives. The $18$ flagged legitimate transactions are false positives. Both types enter the observed group, giving $72+18=90$ flagged transactions. Positive predictive value is therefore $\dfrac{72}{90}=\dfrac45$. In this example there are also $90$ genuinely fraudulent transactions, so sensitivity happens to equal positive predictive value numerically despite using a different reference group.
