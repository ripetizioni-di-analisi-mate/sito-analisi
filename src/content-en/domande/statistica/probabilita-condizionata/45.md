A model calculates the probability of a return by weighting the rates of two stated categories. Some orders belong to both and have positive probability of being returned. Which change avoids double counting?

- Divide the probability of each category by two.
- Use the overall return rate for both categories.
- Partition the orders into disjoint categories, with a separate group for orders in both.
- Add the contributions anyway because the category rates are conditional.

## Explanation

A returned order in both categories enters both contributions. To count it only once, separate orders in the first category only, the second only and both. Include any orders outside both categories to cover all orders. Each order then belongs to one group, so adding the contributions from returns gives the correct result.
