In $20$ independent Bernoulli trials there are no successes. Calculate the upper endpoint of the two-sided Wilson interval using $z=2$.

- $\dfrac15$
- $\dfrac1{12}$
- $\dfrac16$
- $0$

## Explanation

The Wilson interval keeps the values of $p$ for which $|\widehat p-p|\leq z\sqrt{\dfrac{p(1-p)}{n}}$, with the standard error computed using that same $p$. Squaring and multiplying by $n$, with $\widehat p=0$ the condition becomes $20p^2\leq4p(1-p)$, or $p(24p-4)\leq0$. The value $p=0$ satisfies it. For $p>0$ we obtain $24p\leq4$, giving upper limit $\dfrac4{24}=\dfrac16$.
