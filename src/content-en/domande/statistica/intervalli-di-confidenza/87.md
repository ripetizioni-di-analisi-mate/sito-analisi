An interval for $\mu_X-\mu_Y$ is $[-7,-2]$. Which relationship holds for all difference values in the interval?

- $\mu_X=\mu_Y$
- $\mu_X>\mu_Y$
- $\mu_X<\mu_Y$
- The difference must be positive

## Explanation

The upper endpoint of the interval for $\mu_X-\mu_Y$ is $-2$, making every value in the interval negative. For each such value, $\mu_X-\mu_Y<0$. Adding $\mu_Y$ to both sides gives $\mu_X<\mu_Y$. The same ordering therefore holds for every difference in the interval.
