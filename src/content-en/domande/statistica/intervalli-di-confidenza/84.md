The Wald interval for a proportion is $[-0.01,0.17]$. What happens when it is intersected with the admissible parameter space $[0,1]$?

- It becomes $[0,0.17]$ and automatically achieves exact coverage
- It becomes $[0.01,0.17]$ because the negative endpoint changes sign
- It becomes $[0,0.17]$, and the coverage event for every admissible proportion stays the same
- It becomes $[0,1]$ because every interval with a negative endpoint must be replaced by the entire parameter space

## Explanation

The true proportion $p$ can lie only in $[0,1]$. If the original Wald interval contains it, so does the intersection with $[0,1]$. The converse also holds because the intersection is a subset of the original interval. Replacing the negative endpoint with zero gives $[0,0.17]$ with the same coverage event.
