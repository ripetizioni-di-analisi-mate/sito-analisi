A one-sided $95\,\%$ upper bound for a real-valued mean is $7.4$. Which set is the confidence interval?

- $[0,7.4]$
- $[7.4,+\infty)$
- $(-\infty,7.4]$
- $[7.4,7.4]$

## Explanation

The upper limit specifies the largest value in the confidence set. The parameter must satisfy $\mu\leq7.4$, so $7.4$ is included. Since the mean is real and the procedure supplies only an upper limit, the set extends downward without a finite endpoint. It is written $(-\infty,7.4]$.
