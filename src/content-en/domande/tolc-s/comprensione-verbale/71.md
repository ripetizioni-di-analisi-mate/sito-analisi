A school atlas prints island outlines in different colours. Testing confirms that adjacent islands never share a colour. A teacher observes that some names are illegible because ferry lines cover them. Pupils must identify each island by name.

Which assessment relates the test to the actual task?

- The outlines are distinguishable, but that criterion alone does not ensure the names can be read
- Passing the test already guarantees identification by name
- An illegible name disproves that neighbouring outlines have different colours
- Reading names requires giving all outlines the same colour
- The teacher proposes eliminating all ferry routes from the atlas

## Explanation

The test concerns colour separation between neighbours. The task also requires reading labels, which overprinted lines can prevent even when the test succeeds.
