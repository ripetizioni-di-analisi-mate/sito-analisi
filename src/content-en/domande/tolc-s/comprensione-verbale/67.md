An internal guide explains how to handle a device that will not switch on. First, check that its cable is connected correctly; then try an outlet already tested with another appliance. Only if the device still will not switch on should a technical-support request be opened. Users are forbidden to open the casing.

| Test result | Required action |
| --- | --- |
| The device switches on in the tested outlet | Report the original outlet |
| The device does not switch on in the tested outlet | Submit a technical-support request |

The supervisor explains that the procedure orders checks accessible to users without giving a definitive diagnosis of internal faults. Even when technical support is necessary, the test alone does not establish which component is damaged. The request should describe the checks already completed so that the technician can use them and decide what further tests to perform.

The device switches on in the tested outlet. What action is required?

- Open the casing immediately
- Report the original outlet
- Declare the motor damaged
- Send the request prescribed for failure to start anyway
- Necessarily repeat the test with ten appliances

## Explanation

The table’s first row associates switching on in the tested outlet with reporting the original outlet. The second row’s technical request corresponds to a different outcome. The passage prescribes neither a motor diagnosis nor ten repetitions.
