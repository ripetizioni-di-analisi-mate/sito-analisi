In a report the sentence “The path runs under the chestnut tree” appears only in the hikers’ edition. The archive version says “ran”, with a note dating the felling of the tree to before both editions were last revised.

Which correction would improve the hikers’ edition?

- Treat the archive edition’s past tense as evidence the path no longer exists
- Present the felling as a future event
- Use “ran” while continuing to list the tree as visible today
- Change the felling date to retain the present tense
- Replace the present-day reference with a landmark still there

## Explanation

A hiker needs to recognise a landmark on site. Since the tree has already been felled, the practical edition’s present tense promises a clue that will not be there.
