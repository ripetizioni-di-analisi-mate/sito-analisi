In $\mathrm{Cl_2+2OH^-\to Cl^-+ClO^-+H_2O}$, chlorine changes from oxidation number $0$ to $-1$ in chloride and $+1$ in hypochlorite. How is this transformation described?

- All the chlorine is reduced
- All the chlorine is oxidized
- Chlorine retains the same oxidation number
- Some chlorine is reduced and some is oxidized
- No element changes oxidation number

## Explanation

Elemental chlorine has oxidation number zero. The change to $-1$ is reduction, while the change to $+1$ is oxidation. The same element therefore undergoes both transformations in different particles: this is disproportionation. The oxidizing and reducing species need not initially contain different elements; the overall electron balance must be satisfied.
