Ada says “Bea is lying”. Bea says “Ada and I are both making false statements”. Each statement is true or false. Which assignment is consistent?

- Both are truthful
- Ada is truthful and Bea is false
- Both are false
- Ada is false and Bea truthful
- No assignment is consistent

## Explanation

If Bea were truthful, her statement would require her own statement to be false, so Bea must be false. Ada’s statement, which asserts precisely Bea’s falsity, is then true. With Ada true, the conjunction “both false” is indeed false, so the assignment satisfies both statements.
