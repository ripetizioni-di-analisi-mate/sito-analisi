Showing the code is enough to collect a parcel. The rules also allow collection with a valid identity document when the code is missing. How is showing the code classified relative to being able to collect the parcel?

- Necessary but not sufficient
- Necessary and sufficient
- Neither necessary nor sufficient
- Incompatible with collection
- Sufficient but not necessary

## Explanation

The code guarantees collection, so it is sufficient. Being able to collect using an identity document without a code provides a case in which collection is allowed and the code is absent. The code is therefore not necessary. Both classifications are supported by explicit information in the rules.
