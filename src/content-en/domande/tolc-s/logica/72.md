Consider the statement “All devices in the batch pass the test.” Which observation is enough to show that it is false?

- One device from another batch fails the test
- One device in the batch fails the test
- Ten devices in the batch pass the test
- Most devices pass the test
- One device in the batch has not yet been tested

## Explanation

A universal statement is false when there is an element of the set under consideration that lacks the property. Therefore one device in the batch that fails the test is enough. A device from another batch does not belong to the set the statement refers to, so it does not contradict it. An untested device has an unknown outcome, so it does not show that the statement is false.
