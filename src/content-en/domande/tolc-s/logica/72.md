A report claims: “All devices in the batch pass the test.” Which observation is enough to refute it?

- One device from another batch fails the test
- One device in the batch fails the test
- Ten devices in the batch pass the test
- Most devices pass the test
- One device in the batch has not yet been tested

## Explanation

Refuting a universal property requires an element of the specified set that lacks it. One device from the batch failing is therefore sufficient. An outside device is not in the statement’s domain; an untested device leaves its outcome unknown without establishing failure.
