All and only signed applications have been registered. No signed application is provisional. Which statement follows?

- All provisional applications are registered
- No provisional application is registered
- All nonprovisional applications are signed
- No applications exist
- All signed applications are provisional

## Explanation

“All and only” makes registered and signed equivalent. A registered application is therefore signed and, by the second premise, nonprovisional. Hence the intersection of provisional and registered applications is empty. The second premise cannot be reversed to make every nonprovisional application signed.
