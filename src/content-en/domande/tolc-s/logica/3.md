All A are B. No B is C. Which conclusion holds even if A is empty?

- There is an A that is B
- All C are A
- No A is C
- Some B are C
- A and B are identical

## Explanation

The inclusion $A\subseteq B$ places every possible element of A inside B. Since $B\cap C=\varnothing$, none of those elements can belong to C; therefore $A\cap C=\varnothing$. This conclusion does not require A to contain any elements. Universal premises guarantee no existence and do not require the two sets to be equal.
