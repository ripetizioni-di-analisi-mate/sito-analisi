An undirected network has only the connections A-B, B-C, B-D and D-E. Which pair of intermediate vertices must occur on every path from A to E?

- B and C
- B and D
- C and D
- A and C
- No intermediate vertex is compulsory

## Explanation

A is connected only to B, so every path leaving A must pass through B. E is connected only to D, so every path ending at E must pass through D. The compulsory pair is therefore B and D. C is a side branch and can be avoided in the path A-B-D-E.
