A display starts at $9$. If the value is odd it adds $3$; if even it halves it. What value is shown after five operations?

- $6$
- $12$
- $9$
- $3$
- $18$

## Explanation

The rule depends on the current value each time. The five operations give $9\to12\to6\to3\to6\to3$, so the final value is $3$. The initial value does not count as an operation. This reconstruction distinguishes the fifth update from the fifth listed number, which would be $6$.
