Three components A, B and C operate independently, each with probability $\dfrac12$. The system works if C works or if both A and B work, with inclusive “or”. What is its probability of working?

- $\dfrac18$
- $\dfrac38$
- $\dfrac58$
- $\dfrac34$
- $\dfrac78$

## Explanation

If C works, the system works regardless of the other two components, with probability $\dfrac12$. If C fails, both A and B must work, with probability $\dfrac12\cdot\dfrac12\cdot\dfrac12=\dfrac18$. These disjoint cases add to $\dfrac58$.
