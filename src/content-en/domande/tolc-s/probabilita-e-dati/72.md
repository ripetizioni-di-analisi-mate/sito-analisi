A code is selected uniformly from all two-digit codes from $00$ to $99$. A second procedure chooses the first digit uniformly and then sets the second equal to the first. Which comparison is correct?

- The two procedures produce the same distribution
- Code 33 has probability $\dfrac1{100}$ in the first procedure and $\dfrac1{10}$ in the second
- Code 34 is possible in the second procedure
- Code 33 is impossible in the first procedure
- In the second procedure all one hundred pairs are equally likely with positive probability

## Explanation

The first procedure assigns weight $\dfrac1{100}$ to each of one hundred codes. In the second, only the ten codes with equal digits are possible; each inherits the first digit’s probability $\dfrac1{10}$. Individual digits are uniform in both models, but in the second the second digit depends completely on the first.
