From a $40$-card Italian deck containing four aces and four kings, one card is drawn at random. What is the probability that it is an ace or a king?

- $\dfrac1{10}$
- $\dfrac1{100}$
- $\dfrac15$
- $\dfrac1{20}$
- $\dfrac{19}{100}$

## Explanation

All $40$ cards are equally likely to be drawn, so the event “ace” has probability $\dfrac4{40}=\dfrac1{10}$, and the same holds for the event “king”. No card is both an ace and a king, so the two events are disjoint. For disjoint events the probability of the union is the sum of the probabilities, so the required probability is $\dfrac1{10}+\dfrac1{10}=\dfrac15$. The value $\dfrac{19}{100}$ comes from subtracting the product $\dfrac1{10}\cdot\dfrac1{10}$ as if it were the probability of the intersection, which is in fact empty.
