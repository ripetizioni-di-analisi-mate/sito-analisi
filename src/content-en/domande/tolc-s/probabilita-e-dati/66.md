Let $A$ be any event and $\Omega$ the certain event. Are A and $\Omega$ independent?

- Yes, because $P(A\cap\Omega)=P(A)=P(A)P(\Omega)$
- No, because $\Omega$ contains A
- Only if $P(A)=\dfrac12$
- Only if A is impossible
- It cannot be decided without knowing $P(A)$

## Explanation

Intersecting with the entire space leaves the event unchanged: $A\cap\Omega=A$. Also $P(\Omega)=1$, so $P(A)P(\Omega)$ equals $P(A)$. The independence definition holds for every A, including the limiting cases of a certain or impossible event.
