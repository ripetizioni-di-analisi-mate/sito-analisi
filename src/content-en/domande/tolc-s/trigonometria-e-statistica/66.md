What type of variable is the number of libraries in each municipality?

- Discrete quantitative
- Continuous quantitative
- Nominal qualitative
- Ordinal qualitative
- Necessarily a relative frequency

## Explanation

The number of libraries is a count: it takes nonnegative integer values, and numerical differences are meaningful. It is therefore a discrete quantitative variable. It is not a continuous measurement because no intermediate counts are possible between consecutive integers.
