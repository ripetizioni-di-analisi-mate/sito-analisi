Which expression describes $\dfrac{x^2-4}{x-2}$ with exactly the same domain?

- $x+2$ for $x\ne2$
- $x+2$ for every real number
- $x+2$ for $x\ne-2$
- $x-2$ for $x\ne2$
- $x-2$ for every real number

## Explanation

The original domain excludes $2$. The numerator factors as $(x-2)(x+2)$, so the factor $x-2$ can be canceled only where it is nonzero. This leaves $x+2$ subject to $x\ne2$. Extending the formula to the excluded point would define a new function with an additional value.
