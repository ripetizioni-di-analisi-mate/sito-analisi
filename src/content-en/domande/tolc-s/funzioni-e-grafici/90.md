For which values of $a$ is $f(x)=\log_{a-2}x$ defined for every $x>0$ and strictly increasing?

- $a>2$
- $2<a<3$
- $a\ne3$
- $a\ge3$
- $a>3$

## Explanation

A real logarithmic function has a positive base different from one and is strictly increasing when its base exceeds one. Here the base is $a-2$, so the complete requirement becomes $a-2>1$, namely $a>3$. The value $a=3$ would give base one, which is invalid.
