The function $f$ assigns to each integer the Euclidean remainder on division by $5$. What is $f(-7)+f(13)$?

- $1$
- $6$
- $-4$
- $5$
- $3$

## Explanation

The Euclidean remainder lies between $0$ and $4$, including for a negative dividend. Write $-7=5(-2)+3$, so $f(-7)=3$. Also $13=5\cdot2+3$, so $f(13)=3$. The sum is $6$. Using $-2$ as the first remainder would violate the stated convention.
