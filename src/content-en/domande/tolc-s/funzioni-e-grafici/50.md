All that is known is $f(-2)=4$ and $f(2)=4$, with domain $\mathbb R$. Which property is compatible with the data?

- The function is injective.
- The function is strictly increasing.
- The function is strictly decreasing.
- The function is odd.
- The function is even.

## Explanation

An even function can take the same value at opposite inputs; for example, $f(x)=x^2$ satisfies both data points. Injectivity and strict monotonicity are excluded because distinct inputs share an image. Oddness would require $f(-2)=-f(2)=-4$, contradicting the assigned value.
