What is the complete solution set of $\left(\dfrac12\right)^x>\dfrac14$?

- $x>2$
- $x\le2$
- $x\ge2$
- $x<-2$
- $x<2$

## Explanation

Write $\dfrac14=\left(\dfrac12\right)^2$. The base lies between zero and one, so the exponential function is strictly decreasing. A larger power value therefore corresponds to a smaller exponent, giving $x<2$. The endpoint $2$ is excluded because it would give equality.
