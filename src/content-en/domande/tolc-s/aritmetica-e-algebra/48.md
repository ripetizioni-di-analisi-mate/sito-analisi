A sensor reports $|x+1|$ for a real input $x$. A test report calls for a reading of $-2$. Which change to the formula actually allows that reading for some input?

- Use $|x+1|+2$
- Use $|x+1|^2$
- Use $-|x+1|$
- Use $|x-1|$
- Use $|-(x+1)|$

## Explanation

A minus sign in front of the absolute value reverses the signs of the readings: for example, $x=1$ gives $-|2|=-2$. Every other proposed change produces nonnegative values for all inputs.
