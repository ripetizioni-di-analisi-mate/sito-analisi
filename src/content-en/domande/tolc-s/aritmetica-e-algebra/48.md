What is the solution set of $|x+1|=-2$?

- $\{-1\}$
- $\{-3,1\}$
- $\varnothing$
- $\{-3\}$
- $\{1\}$

## Explanation

Absolute value represents a distance and is therefore always nonnegative. The right-hand side is $-2$, which is negative. No real number can make the two sides equal, so the solution set is empty. Splitting into two sign cases applies when the right-hand side is nonnegative.
