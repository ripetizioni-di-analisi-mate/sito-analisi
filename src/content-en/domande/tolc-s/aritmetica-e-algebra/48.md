Which of the following functions takes the value $-2$ for at least one real number $x$?

- $|x+1|+2$
- $|x+1|^2$
- $-|x+1|$
- $|x-1|$
- $|-(x+1)|$

## Explanation

The absolute value of a real number is never negative, so $|x+1|+2$, $|x+1|^2$, $|x-1|$ and $|-(x+1)|$ are greater than or equal to $0$ for every $x$. The function $-|x+1|$ instead takes only values less than or equal to $0$. The equation $-|x+1|=-2$ is equivalent to $|x+1|=2$, whose solutions are $x=1$ and $x=-3$. Therefore the function $-|x+1|$ takes the value $-2$.
