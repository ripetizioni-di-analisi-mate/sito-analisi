A filter initially accepts real readings with $(x-2)^2\ge0$. One setting is changed and it now requires $(x-2)^2>0$. Which previously accepted reading is now rejected?

- No reading
- Only $x=-2$
- Every $x\le2$
- Every $x<2$
- Only $x=2$

## Explanation

Changing from a weak to a strict inequality removes exactly the equality cases. A square vanishes precisely when its base is zero. Here this happens only when $x-2=0$, that is, at $x=2$.
