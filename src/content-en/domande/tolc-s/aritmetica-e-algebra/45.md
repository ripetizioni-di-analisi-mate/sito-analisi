An association has $43$ members. What is the minimum number of new members needed for the number of members to increase by at least $20\%$, if nobody leaves the association?

- $8$
- $10$
- $11$
- $52$
- $9$

## Explanation

Let $n$ be the number of new members. The percentage increase is computed relative to the $43$ initial members, so we need $\dfrac{n}{43}\ge\dfrac{20}{100}$. Multiplying by $43$ gives $n\ge8.6$. Since $n$ is a whole number, the smallest admissible value is $9$. With $8$ new members the increase is $\dfrac{8}{43}$, about $18.6\%$, so it is not enough. The value $11$ comes instead from computing $20\%$ of the final number of members.
