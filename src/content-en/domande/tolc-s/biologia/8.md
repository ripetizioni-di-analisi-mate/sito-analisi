A cell has one set of chromosomes, each still consisting of two chromatids. It comes from a diploid cell that underwent a regular meiotic division. Which division has just ended?

- S phase
- Mitosis of a diploid cell
- Meiosis I
- Meiosis II
- Fertilization

## Explanation

Meiosis I separates homologous chromosomes: each cell receives one set and is therefore haploid. Sister chromatids remain joined until meiosis II. The description thus combines haploidy and duplicated chromosomes, which is possible. S phase doubles DNA without reducing ploidy; fertilization joins two haploid sets.
