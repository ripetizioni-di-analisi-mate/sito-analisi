Before treatment, a bacterial population contains rare inherited resistant variants. Treatment mainly eliminates susceptible bacteria, and resistant bacteria leave more descendants. Which explanation is supported?

- Voluntary transformation of every susceptible bacterium
- Necessary appearance of the same mutation in all cells
- Selection of resistant variants already present
- Absence of any inherited variation
- Production of resistance by ribosomes without genes

## Explanation

Inherited variation precedes treatment. The environment changes relative reproductive success: resistant bacteria survive and contribute more to the next generation. This is natural selection. There is no need to assume that each individual changes intentionally or that treatment generates the same mutation in all cells; the statement already provides the variation on which selection acts.
