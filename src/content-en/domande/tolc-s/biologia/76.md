An mRNA segment contains $90$ nucleotides, from the first nucleotide of the start codon through the last nucleotide of the stop codon, inclusive. Translation is regular, with no introns. How many amino acids are in the polypeptide before any later modifications?

- $29$
- $30$
- $90$
- $27$
- $31$

## Explanation

Nucleotides are read in groups of three, so the segment contains $\dfrac{90}{3}=30$ codons. The start codon specifies an amino acid, whereas the stop codon specifies none. Thus only one codon is subtracted: $30-1=29$ amino acids. The statement explicitly includes the stop codon and asks about the chain before any later removals.
