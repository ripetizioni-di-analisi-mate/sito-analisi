What are the solutions of the inequality $\sqrt[3]{x + 4} < 2$?

- $-4 \leq x < 4$
- $x < 0$
- $x < 2$
- $x < 4$

## Explanation

The cube root is defined for every real number, so the inequality has no domain conditions. Since the function $y = x^3$ is increasing on all of $\mathbb{R}$, cubing preserves the direction.
$$
x + 4 < 2^3 = 8
$$
Therefore the solution is $x < 4$. The values $x < -4$ are included, because for them the cube root exists and is negative; for example, $\sqrt[3]{-8} = -2 < 2$ for $x = -12$.
