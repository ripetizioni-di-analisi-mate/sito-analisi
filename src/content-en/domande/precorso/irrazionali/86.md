The radicand of $\sqrt{x^3 - 4x}$ is a polynomial of degree three. What is the domain of the root?

- $x \geq 2$
- $-2 \leq x \leq 0 \ \vee \ x \geq 2$
- $x \leq -2 \ \vee \ 0 \leq x \leq 2$
- $-2 < x < 0 \ \vee \ x > 2$

## Explanation

The root is defined where $x^3 - 4x \geq 0$. Factoring out $x$ and factoring the difference of squares gives $x^3 - 4x = x(x - 2)(x + 2)$, which vanishes at $x = -2$, $x = 0$ and $x = 2$. For $x > 2$ the three factors are positive, so the product is positive. The sign changes at each zero, because each factor has degree one and vanishes only once. Therefore the product is positive for $-2 < x < 0$ and for $x > 2$, and negative on the other intervals. Adding the zeros, where the root equals $0$, the domain is $-2 \leq x \leq 0$ or $x \geq 2$.
