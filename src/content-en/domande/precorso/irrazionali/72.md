How many real solutions does the equation $\sqrt{x^2 + 3} = 2x$ have, and which are they?

- $x = -1 \ \vee \ x = 1$
- $x = 1$
- $x = 1 \ \vee \ x = 3$
- No real number

## Explanation

The equation has the form $\sqrt{A} = B$, so it is equivalent to the system
$$
\begin{cases}
2x \geq 0 \\
x^2 + 3 = 4x^2
\end{cases}
$$
The second equation gives $3x^2 = 3$, that is, $x^2 = 1$, with solutions $x = -1$ and $x = 1$. The condition $2x \geq 0$ is equivalent to $x \geq 0$, so $x = -1$ is discarded. For $x = 1$ we have $\sqrt{4} = 2 = 2 \cdot 1$, therefore the only solution is $x = 1$.
