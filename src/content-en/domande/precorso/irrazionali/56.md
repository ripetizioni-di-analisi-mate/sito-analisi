On which set does the expression $(\sqrt{x} - 2)(x + 1)$ take negative values?

- $x > 4$
- $-1 < x < 4$
- $0 < x < 4$
- $0 \leq x < 4$

## Explanation

The expression is defined for $x \geq 0$, and for these values the factor $x + 1$ is positive. So the product has the sign of $\sqrt{x} - 2$ and is negative where $\sqrt{x} < 2$. With both sides nonnegative, squaring preserves the direction, therefore $x < 4$. The solution is $0 \leq x < 4$; at $x = 0$ the product equals $(0 - 2)(0 + 1) = -2$.
