The radicand of $\sqrt{x^3}$ is a cube. For which $x$ is the root less than $8$?

- $x < 4$
- $0 \leq x < 4$
- $0 < x < 4$
- $0 \leq x < 2$

## Explanation

The root is defined for $x^3 \geq 0$, that is, for $x \geq 0$. The right-hand side $8$ is positive, so squaring preserves the direction and gives $x^3 < 64$. Since the function $y = x^3$ is increasing, the inequality $x^3 < 64$ is equivalent to $x < 4$. Therefore the solution is $0 \leq x < 4$; at $x = 4$ we have $\sqrt{64} = 8$.
