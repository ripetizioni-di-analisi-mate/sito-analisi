The expressions $\sqrt{x^2}$ and $\sqrt[3]{x^3}$ are compared. Which statement is true for every real number $x$?

- $\sqrt[3]{x^3} = x$ and $\sqrt{x^2} = |x|$
- $\sqrt[3]{x^3} = |x|$ and $\sqrt{x^2} = |x|$
- $\sqrt[3]{x^3} = x$ and $\sqrt{x^2} = x$
- $\sqrt[3]{x^3} = |x|$ and $\sqrt{x^2} = x$

## Explanation

The function $y = x^3$ is increasing on all of $\mathbb{R}$ and the cube root is its inverse, so $\sqrt[3]{x^3} = x$ for every $x$, negative values included; for example $\sqrt[3]{(-2)^3} = \sqrt[3]{-8} = -2$. The square root, instead, is always nonnegative, therefore $\sqrt{x^2}$ is the nonnegative number whose square is $x^2$, that is, $|x|$. Indeed, for $x = -2$ we have $\sqrt{4} = 2 = |-2|$.
