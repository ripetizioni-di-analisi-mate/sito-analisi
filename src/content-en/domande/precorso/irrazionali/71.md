The radicand of $\sqrt{x^2 - 4x + 4}$ is the square of a binomial. Which real numbers satisfy the inequality $\sqrt{x^2 - 4x + 4} < 3$?

- $-5 < x < 1$
- $x < 5$
- $-1 < x < 5$
- $x < -1 \ \vee \ x > 5$

## Explanation

The radicand is $x^2 - 4x + 4 = (x - 2)^2$, so it is nonnegative for every $x$ and $\sqrt{(x - 2)^2} = |x - 2|$. The inequality becomes $|x - 2| < 3$, which asks for the numbers whose distance from $2$ is less than $3$. Therefore $-3 < x - 2 < 3$, that is, $-1 < x < 5$.
