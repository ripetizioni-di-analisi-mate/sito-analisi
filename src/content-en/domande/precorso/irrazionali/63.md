On which set of real numbers is the equality $(\sqrt{x})^2 = x$ true?

- $x \geq 0$
- Every real number $x$
- $x > 0$
- $x \leq 0$

## Explanation

The left-hand side contains $\sqrt{x}$, which is defined only for $x \geq 0$, so the equality makes sense only for these values. For $x \geq 0$ the number $\sqrt{x}$ is by definition the nonnegative number whose square is $x$, therefore $(\sqrt{x})^2 = x$. Hence the equality is true for $x \geq 0$, including $x = 0$. The expression $\sqrt{x^2}$, instead, is defined for every $x$ and equals $|x|$.
