- $x = 4$
- $x = -1 \ \vee \ x = 4$
- $x = 1 \ \vee \ x = -4$
- $x = 1 \ \vee \ x = 2$

## Explanation

The equation has the form $\sqrt{A} = \sqrt{B}$, so it is equivalent to the system
$$
\begin{cases}
3x + 3 \geq 0 \\
x^2 - 1 = 3x + 3
\end{cases}
$$
The second equation is $x^2 - 3x - 4 = 0$, that is, $(x - 4)(x + 1) = 0$, with roots $x = 4$ and $x = -1$. The condition $3x + 3 \geq 0$ is equivalent to $x \geq -1$, so it is satisfied by both values; the endpoint $x = -1$ is included because the inequality is non-strict. For $x = -1$ both radicands equal $0$ and for $x = 4$ they equal $15$, therefore the solutions are $x = -1$ and $x = 4$.
