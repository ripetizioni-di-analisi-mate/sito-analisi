What are the solutions of the inequality $\sqrt{5 - x} > x - 3$?

- $x < 4$
- $1 < x < 4$
- $3 \leq x < 4$
- $x \leq 5$

## Explanation

The inequality has the form $\sqrt{A} > B$, so it is equivalent to the union of two systems.
$$
\begin{cases}
x - 3 < 0 \\
5 - x \geq 0
\end{cases}
\ \cup \
\begin{cases}
x - 3 \geq 0 \\
5 - x > (x - 3)^2
\end{cases}
$$
The first system requires $x < 3$ and $x \leq 5$, so it gives $x < 3$. In the second, expanding $(x - 3)^2 = x^2 - 6x + 9$, the inequality becomes $x^2 - 5x + 4 < 0$, that is, $1 < x < 4$, and together with $x \geq 3$ the values $3 \leq x < 4$ remain. The **union** of the two systems gives $x < 4$. At $x = 4$ both sides equal $1$, so the endpoint is excluded.
