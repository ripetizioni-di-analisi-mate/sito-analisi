For $x < 1$, which expression is equal to $\sqrt{x^2 - 2x + 1} + x$?

- $1$
- $2x - 1$
- $-1$
- $1 - 2x$

## Explanation

The radicand is $x^2 - 2x + 1 = (x - 1)^2$, so $\sqrt{x^2 - 2x + 1} = |x - 1|$. For $x < 1$ the number $x - 1$ is negative, therefore $|x - 1| = 1 - x$. Hence the expression equals $1 - x + x = 1$ for every $x < 1$. For example, for $x = -2$ we get $\sqrt{9} - 2 = 1$.
