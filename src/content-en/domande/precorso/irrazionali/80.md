Which values of $x$ satisfy the equation $\sqrt{9 - x^2} = x + 3$?

- $x = 0 \ \vee \ x = 3$
- $x = 0$
- $x = -3$
- $x = -3 \ \vee \ x = 0$

## Explanation

The equation has the form $\sqrt{A} = B$, so it is equivalent to the system
$$
\begin{cases}
x + 3 \geq 0 \\
9 - x^2 = (x + 3)^2
\end{cases}
$$
Expanding $(x + 3)^2 = x^2 + 6x + 9$, the second equation becomes $2x^2 + 6x = 0$, that is, $2x(x + 3) = 0$, with solutions $x = 0$ and $x = -3$. Both satisfy the condition $x \geq -3$, so neither is discarded. The check gives $\sqrt{9} = 3 = 0 + 3$ and $\sqrt{0} = 0 = -3 + 3$, therefore the solutions are $x = -3$ and $x = 0$.
