What is the real solution set of $\sqrt{x + 4} = x - 2$?

- $\left\{2\right\}$
- $\left\{0\right\}$
- $\left\{5\right\}$
- $\left\{0, 5\right\}$

## Explanation

The right-hand side requires $x\geq 2$. Squaring produces $0$ and 5, so only the second meets the condition and the result is $\left\{5\right\}$.
