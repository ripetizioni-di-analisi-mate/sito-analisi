Which inequality has the solution set $0 \leq x < 4$?

- $\sqrt{x} \leq 2$
- $\sqrt{x} < 2$
- $\sqrt{4 - x} > 0$
- $\sqrt{x} < 4$

## Explanation

The inequality $\sqrt{x} < 2$ requires $x \geq 0$ for the root to exist. With both sides nonnegative, squaring preserves the direction and gives $x < 4$, so the solutions are $0 \leq x < 4$. The inequality $\sqrt{x} \leq 2$ also includes $x = 4$, where the root equals $2$. The inequality $\sqrt{4 - x} > 0$ is satisfied for every $x < 4$, negative values included. Finally, $\sqrt{x} < 4$ has solutions $0 \leq x < 16$.
