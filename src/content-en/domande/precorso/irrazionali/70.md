Which real numbers belong to the domain of the function $f(x) = \sqrt{x^2 - 1} + \dfrac{1}{\sqrt{5 - x}}$?

- $1 \leq x < 5$
- $x \leq -1 \ \vee \ 1 \leq x \leq 5$
- $x \leq -1 \ \vee \ 1 \leq x < 5$
- $x < -1 \ \vee \ 1 < x < 5$

## Explanation

The function is defined where both roots exist and the denominator is different from $0$. The root $\sqrt{5 - x}$ is in the denominator and equals $0$ only for $x = 5$, so its radicand must be positive.
$$
\begin{cases}
x^2 - 1 \geq 0 \\
5 - x > 0
\end{cases}
$$
The binomial $x^2 - 1$ vanishes at $x = \pm 1$ and, since the coefficient of $x^2$ is positive, it is nonnegative for $x \leq -1$ or $x \geq 1$. The second condition gives $x < 5$. Therefore the domain consists of the values $x \leq -1$ or $1 \leq x < 5$.
