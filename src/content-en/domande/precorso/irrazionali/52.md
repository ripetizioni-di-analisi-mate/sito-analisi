Which values of $x$ satisfy the double inequality $2 < \sqrt{x - 1} < 3$?

- $3 < x < 4$
- $5 \leq x \leq 10$
- $5 < x < 10$
- $1 \leq x < 10$

## Explanation

The root is defined for $x \geq 1$, and for these values the three members $2$, $\sqrt{x - 1}$ and $3$ are nonnegative. Therefore squaring preserves the direction of both inequalities.
$$
4 < x - 1 < 9
$$
Adding $1$ to every member we obtain $5 < x < 10$, and these values also satisfy $x \geq 1$. The endpoints are excluded, because at $x = 5$ the root equals $2$ and at $x = 10$ it equals $3$.
