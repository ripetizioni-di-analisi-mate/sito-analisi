For which real numbers $x$ does the equality $\sqrt{x^2} = -x$ hold?

- $x \leq 0$
- $x = 0$
- $x \geq 0$
- $x < 0$

## Explanation

For every real number we have $\sqrt{x^2} = |x|$, so the equality is equivalent to $|x| = -x$. The absolute value of a number coincides with its opposite when the number is not positive, therefore the equality holds for $x \leq 0$. For example, for $x = -5$ we have $\sqrt{25} = 5 = -(-5)$. At $x = 0$ both sides equal $0$, so $x = 0$ is included as well.
