What are the solutions of the inequality $\sqrt{x^2 - 9} < 4$?

- $-5 < x < 5$
- $3 \leq x < 5$
- $-5 < x \leq -3 \ \vee \ 3 \leq x < 5$
- $-5 < x < -3 \ \vee \ 3 < x < 5$

## Explanation

The inequality has the form $\sqrt{A} < B$ with $B = 4 > 0$, so it is equivalent to the system
$$
\begin{cases}
x^2 - 9 \geq 0 \\
x^2 - 9 < 16
\end{cases}
$$
The first condition is satisfied for $x \leq -3$ or $x \geq 3$. The second is equivalent to $x^2 < 25$, that is, $-5 < x < 5$. The endpoints $x = \pm 3$ are included, because there the root equals $0 < 4$, while $x = \pm 5$ are excluded, because there the root equals $4$. Therefore the solutions are $-5 < x \leq -3$ or $3 \leq x < 5$.
