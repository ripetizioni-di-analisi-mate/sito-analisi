Which of the following inequalities has no solutions?

- $\sqrt{x - 3} \leq 0$
- $\sqrt{x - 3} > -1$
- $\sqrt{x - 3} < 1$
- $\sqrt{x - 3} < 0$

## Explanation

Where it is defined, the root $\sqrt{x - 3}$ is nonnegative, so it is never less than $0$; therefore the inequality $\sqrt{x - 3} < 0$ **has no solutions**. The inequality $\sqrt{x - 3} \leq 0$ is satisfied when the root equals $0$, that is, for $x = 3$. The inequality $\sqrt{x - 3} > -1$ is satisfied on the whole domain $x \geq 3$, because a nonnegative number is greater than every negative number. Finally, $\sqrt{x - 3} < 1$ is equivalent to $0 \leq x - 3 < 1$, that is, $3 \leq x < 4$.
