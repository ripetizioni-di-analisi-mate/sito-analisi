For which $x$ do we have $\sqrt[3]{x} > x$?

- $0 < x < 1$
- $x < -1 \ \vee \ 0 < x < 1$
- $-1 < x < 0 \ \vee \ x > 1$
- $x < 1$

## Explanation

The cube root is defined for every $x$ and cubing preserves the direction, so the inequality is equivalent to $x > x^3$, that is, $x - x^3 > 0$. We factor $x - x^3 = x(1 - x)(1 + x)$, which vanishes at $x = -1$, $x = 0$ and $x = 1$. For $x > 1$ the product is negative, because the only negative factor is $1 - x$. The sign changes at each zero, because the three factors have degree one. Therefore the product is positive for $x < -1$ and for $0 < x < 1$, and these are the required values.
