On which set is the expression $\sqrt{2 - \sqrt{x}}$, which contains a root inside another root, defined?

- $0 \leq x \leq 2$
- $x \leq 4$
- $x \geq 0$
- $0 \leq x \leq 4$

## Explanation

The inner root requires $x \geq 0$, and the outer root requires the radicand $2 - \sqrt{x}$ not to be negative; the two conditions must hold together.
$$
\begin{cases}
x \geq 0 \\
\sqrt{x} \leq 2
\end{cases}
$$
The inequality $\sqrt{x} \leq 2$ has both sides nonnegative, so squaring preserves the direction and gives $x \leq 4$. Therefore the expression is defined for $0 \leq x \leq 4$; at $x = 4$ we have $\sqrt{2 - 2} = 0$.
