For which values of $x$ does the sum $\sqrt{x - 2} + \sqrt{x^2 - 4}$ vanish?

- For no value of $x$
- $x = -2 \ \vee \ x = 2$
- $x = 2$
- $x = -2$

## Explanation

The two terms are square roots, so they are nonnegative where they are defined. A sum of two nonnegative numbers equals $0$ only if both equal $0$, therefore the equation is equivalent to the system
$$
\begin{cases}
x - 2 = 0 \\
x^2 - 4 = 0
\end{cases}
$$
The first equation gives $x = 2$, and for $x = 2$ also $x^2 - 4 = 0$. The value $x = -2$ makes the second radicand vanish, but it makes the first one negative, so it is discarded. Therefore the sum vanishes only for $x = 2$.
