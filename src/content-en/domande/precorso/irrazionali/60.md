The function $f(x) = \sqrt{x + 3} + \sqrt{x}$ equals $3$ at $x = 1$. For which $x$ do we have $f(x) < 3$?

- $0 \leq x \leq 1$
- $-3 \leq x < 1$
- $0 < x < 1$
- $0 \leq x < 1$

## Explanation

The two roots are both defined for $x \geq 0$. The inequality can be written as $\sqrt{x + 3} < 3 - \sqrt{x}$, which has the form $\sqrt{A} < B$ and requires $3 - \sqrt{x} > 0$, that is, $x < 9$. With both sides nonnegative, squaring preserves the direction.
$$
x + 3 < 9 - 6\sqrt{x} + x
$$
Simplifying gives $6\sqrt{x} < 6$, that is, $\sqrt{x} < 1$, so $x < 1$. Therefore the solution is $0 \leq x < 1$, which also satisfies $x < 9$; at $x = 0$ we have $f(0) = \sqrt{3} < 3$.
