Squaring both sides of $\sqrt{x + 2} < x$ without any condition gives $x + 2 < x^2$. Which number satisfies $x + 2 < x^2$ but not the original inequality?

- $x = 3$
- $x = -2$
- $x = 0$
- $x = 1$

## Explanation

For $x = -2$ we have $x + 2 = 0 < 4 = x^2$, while the left-hand side of the original inequality equals $\sqrt{0} = 0$, which is not less than $-2$. The number $x = 3$ satisfies both, because $5 < 9$ and $\sqrt{5} < 3$. The numbers $x = 0$ and $x = 1$ do not satisfy $x + 2 < x^2$, because the inequalities $2 < 0$ and $3 < 1$ are false. Therefore $x = -2$ is one of the values added by squaring; the system that solves $\sqrt{A} < B$ excludes it through the condition $x > 0$.
