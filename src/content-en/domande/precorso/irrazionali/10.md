- $-2 < x < 3$
- $-6 \leq x < 3$
- $0 \leq x < 3$
- $-6 < x < 3$

## Explanation

The inequality has the form $\sqrt{A} > B$, so it is equivalent to the union of two systems.
$$
\begin{cases}
x < 0 \\
x + 6 \geq 0
\end{cases}
\ \cup \
\begin{cases}
x \geq 0 \\
x + 6 > x^2
\end{cases}
$$
The first system gives $-6 \leq x < 0$, with $x = -6$ included because at that point the root exists and equals $0 > -6$. In the second, the inequality $x^2 - x - 6 < 0$ is equivalent to $-2 < x < 3$, so together with $x \geq 0$ the values $0 \leq x < 3$ remain. The **union** of the two systems gives $-6 \leq x < 3$.
