- $x = -1$
- $x = 3$
- $x = -1 \ \vee \ x = 4$
- $x = 4$

## Explanation

The equation has the form $\sqrt{A} = B$, so it is equivalent to the system
$$
\begin{cases}
x - 1 \geq 0 \\
x + 5 = (x - 1)^2
\end{cases}
$$
Expanding $(x - 1)^2 = x^2 - 2x + 1$, the second equation becomes $x^2 - 3x - 4 = 0$, which has roots $x = 4$ and $x = -1$. For $x = -1$ the right-hand side equals $-2 < 0$, so the condition $x - 1 \geq 0$ is not satisfied and the value **is discarded**. For $x = 4$ we have $\sqrt{9} = 3 = 4 - 1$, therefore the only solution is $x = 4$.
