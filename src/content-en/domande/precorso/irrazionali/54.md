The figure shows the semicircle $y = \sqrt{4 - x^2}$ and the line $y = x$.

::grafico{f="sqrt(4-x^2);x" xmin=-3 xmax=3 ymin=-2.5 ymax=3 uguale=1}

For which $x$ does the inequality $\sqrt{4 - x^2} \geq x$ hold?

- $-2 \leq x \leq \sqrt{2}$
- $0 \leq x \leq \sqrt{2}$
- $-\sqrt{2} \leq x \leq \sqrt{2}$
- $-2 < x \leq \sqrt{2}$

## Explanation

The inequality has the form $\sqrt{A} \geq B$, so it is equivalent to the union of two systems.
$$
\begin{cases}
x < 0 \\
4 - x^2 \geq 0
\end{cases}
\ \cup \
\begin{cases}
x \geq 0 \\
4 - x^2 \geq x^2
\end{cases}
$$
The first system gives $-2 \leq x < 0$, because $4 - x^2 \geq 0$ is equivalent to $-2 \leq x \leq 2$. In the second, the inequality $2x^2 \leq 4$ is equivalent to $-\sqrt{2} \leq x \leq \sqrt{2}$, so together with $x \geq 0$ the values $0 \leq x \leq \sqrt{2}$ remain. The **union** of the two systems gives $-2 \leq x \leq \sqrt{2}$, that is, the abscissas of the points where the semicircle does not lie below the line.
