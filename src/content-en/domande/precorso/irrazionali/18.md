What are the solutions of the equation $\sqrt{2x + 7} = x + 2$?

- $x = -3 \ \vee \ x = 1$
- $x = -3$
- $x = 1$
- $x = -1 \ \vee \ x = 3$

## Explanation

The equation has the form $\sqrt{A} = B$, so it is equivalent to the system
$$
\begin{cases}
x + 2 \geq 0 \\
2x + 7 = (x + 2)^2
\end{cases}
$$
Expanding $(x + 2)^2 = x^2 + 4x + 4$, the second equation becomes $x^2 + 2x - 3 = 0$, that is, $(x + 3)(x - 1) = 0$, with roots $x = -3$ and $x = 1$. For $x = -3$ the right-hand side equals $-1 < 0$, so the condition $x + 2 \geq 0$ is not satisfied and the value **is discarded**. For $x = 1$ we have $\sqrt{9} = 3 = 1 + 2$, therefore the only solution is $x = 1$.
