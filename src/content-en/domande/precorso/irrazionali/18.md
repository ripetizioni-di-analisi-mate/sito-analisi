For which values of $x$ is the expression $\dfrac{1}{\sqrt{3 - x}}$ defined?

- $x \leq 3$
- $x \neq 3$
- $x < 3$
- $x > 3$

## Explanation

The root is defined when the radicand is not negative, and the quotient is defined when the denominator is different from $0$; so the two conditions must be satisfied together.
$$
\begin{cases}
3 - x \geq 0 \\
\sqrt{3 - x} \neq 0
\end{cases}
$$
The first condition gives $x \leq 3$. The root equals $0$ only when the radicand equals $0$, that is, for $x = 3$, so the second condition excludes $x = 3$. Therefore the expression is defined for $x < 3$.
