What are the solutions of the inequality $\sqrt{3x + 1} \leq x + 1$?

- $x \leq 0 \ \vee \ x \geq 1$
- $-\dfrac{1}{3} \leq x \leq 0 \ \vee \ x \geq 1$
- $x \geq 1$
- $-1 \leq x \leq 0 \ \vee \ x \geq 1$

## Explanation

The inequality has the form $\sqrt{A} \leq B$, so it is equivalent to the system
$$
\begin{cases}
3x + 1 \geq 0 \\
x + 1 \geq 0 \\
3x + 1 \leq (x + 1)^2
\end{cases}
$$
The third condition becomes $x^2 - x \geq 0$, that is, $x(x - 1) \geq 0$, which is satisfied for $x \leq 0$ or $x \geq 1$. The first condition requires $x \geq -\dfrac{1}{3}$, and the second, $x \geq -1$, follows from the first. At $x = -\dfrac{1}{3}$ the root equals $0$ and the right-hand side equals $\dfrac{2}{3}$, so the endpoint is included. Therefore the solutions are $-\dfrac{1}{3} \leq x \leq 0$ or $x \geq 1$.
