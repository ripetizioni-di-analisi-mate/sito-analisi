The value $x = -2$ is a solution of exactly one of the following equations. Which one?

- $\sqrt{x + 6} = x$
- $\sqrt{2 - x} = x$
- $\sqrt{x^2} = x$
- $\sqrt[3]{x - 6} = x$

## Explanation

For $x = -2$ the right-hand side of each equation equals $-2$. Square roots are nonnegative, so none of the three equations with the square root is satisfied, and indeed in all three cases the left-hand side equals $\sqrt{4} = 2$. The cube root, instead, can take negative values, and for $x = -2$ we have $\sqrt[3]{-8} = -2$. Therefore $x = -2$ solves the equation $\sqrt[3]{x - 6} = x$.
