Which of the following equations has no real solutions?

- $\sqrt{x - 2} = 0$
- $\sqrt{x + 2} = -3$
- $\sqrt[3]{x + 2} = -3$
- $\sqrt{x^2 + 1} = 1$

## Explanation

A root of even index, where it is defined, is nonnegative, so it cannot equal $-3$; therefore the equation $\sqrt{x + 2} = -3$ **has no solutions**. The equation $\sqrt{x - 2} = 0$ is solved by $x = 2$. The cube root can take negative values, and the equation $\sqrt[3]{x + 2} = -3$ is equivalent to $x + 2 = -27$, that is, $x = -29$. Finally, $\sqrt{x^2 + 1} = 1$ is equivalent to $x^2 + 1 = 1$, which is solved by $x = 0$.
