Which equality holds for every real number $x$?

- $\sqrt{(x - 3)^2} = |x - 3|$
- $\sqrt{(x - 3)^2} = x - 3$
- $\sqrt{(x - 3)^2} = 3 - x$
- $\sqrt{(x - 3)^2} = \pm (x - 3)$

## Explanation

The radicand $(x - 3)^2$ is never negative, so the root is defined for every $x$. By definition $\sqrt{(x - 3)^2}$ is the **nonnegative** number whose square is $(x - 3)^2$, and this number is $|x - 3|$. The equality with $x - 3$ holds only for $x \geq 3$; for example, for $x = 1$ we have $\sqrt{4} = 2$, while $x - 3 = -2$. Likewise $3 - x$ coincides with the root only for $x \leq 3$, and the expression $\pm (x - 3)$ denotes two values, while the root has only one.
