What are the solutions of the inequality $\sqrt{x + 4} < x + 2$?

- $x > 0$
- $x \geq 0$
- $x < -3 \ \vee \ x > 0$
- $-4 \leq x < -3 \ \vee \ x > 0$

## Explanation

The inequality has the form $\sqrt{A} < B$, so it is equivalent to the system
$$
\begin{cases}
x + 4 \geq 0 \\
x + 2 > 0 \\
x + 4 < (x + 2)^2
\end{cases}
$$
The third condition becomes $x^2 + 3x > 0$, that is, $x(x + 3) > 0$, which is satisfied for $x < -3$ or $x > 0$. The second condition requires $x > -2$, so only $x > 0$ remains, and for these values the first condition is satisfied as well. The endpoint $x = 0$ is excluded, because at that point $\sqrt{4} = 2 = 0 + 2$ and the inequality is strict. Therefore the solution is $x > 0$.
