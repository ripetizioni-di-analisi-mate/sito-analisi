Which values of $x$ satisfy the inequality $\sqrt{x + 5} < \sqrt{3 - x}$?

- $-5 < x < -1$
- $x < -1$
- $-5 \leq x < -1$
- $-5 \leq x \leq 3$

## Explanation

Where they are defined, both sides are nonnegative, so squaring preserves the direction. The inequality is equivalent to the system
$$
\begin{cases}
x + 5 \geq 0 \\
x + 5 < 3 - x
\end{cases}
$$
The condition $3 - x \geq 0$ need not be added, because it follows from $3 - x > x + 5 \geq 0$. The first condition gives $x \geq -5$ and the second gives $2x < -2$, that is, $x < -1$. Therefore the solution is $-5 \leq x < -1$; at $x = -5$ the left-hand side equals $0$ and the right-hand side equals $\sqrt{8}$.
