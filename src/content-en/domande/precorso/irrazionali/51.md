On which set does $\sqrt[4]{x + 2} < 2$ hold?

- $-2 \leq x < 14$
- $-2 \leq x < 0$
- $x < 14$
- $-2 < x < 14$

## Explanation

The fourth root, like every root of even index, is defined when the radicand is not negative, so we need $x + 2 \geq 0$, that is, $x \geq -2$. Where the root is defined both sides are nonnegative, therefore raising to the fourth power preserves the direction.
$$
x + 2 < 2^4 = 16
$$
Hence $x < 14$, and together with the condition $x \geq -2$ we obtain $-2 \leq x < 14$. At $x = -2$ the root equals $\sqrt[4]{0} = 0 < 2$, therefore the endpoint is included.
