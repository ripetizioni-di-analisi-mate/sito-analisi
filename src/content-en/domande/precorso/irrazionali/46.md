The fourth root $\sqrt[4]{9 - x^2}$ has an even index. On which set is it defined?

- $-3 < x < 3$
- $x \leq -3 \ \vee \ x \geq 3$
- $-3 \leq x \leq 3$
- Every real number $x$

## Explanation

A root of even index is defined when the radicand is not negative, so we solve $9 - x^2 \geq 0$. The binomial $9 - x^2 = (3 - x)(3 + x)$ vanishes at $x = -3$ and at $x = 3$. Since the coefficient of $x^2$ is negative, the binomial is positive between the two values. The endpoints are included, because at $x = \pm 3$ the radicand equals $0$ and $\sqrt[4]{0} = 0$. Therefore the root is defined for $-3 \leq x \leq 3$.
