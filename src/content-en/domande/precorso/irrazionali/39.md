Which statement about the inequality $\sqrt{x + 7} > x + 1$ is true?

- The solutions are obtained by squaring both sides for every $x \geq -7$
- The value $x = -7$ is not a solution, because the root equals $0$
- The solutions are all nonnegative
- Every $x$ with $-7 \leq x < -1$ is a solution

## Explanation

For $-7 \leq x < -1$ the root exists and is nonnegative, while the right-hand side is negative, so the inequality is satisfied. In particular, for $x = -7$ we have $\sqrt{0} = 0 > -6$, therefore $x = -7$ is a solution. Squaring for every $x \geq -7$ gives $x^2 + x - 6 < 0$, that is, $-3 < x < 2$, and the solutions $-7 \leq x \leq -3$ are lost; squaring preserves the direction only where the right-hand side is nonnegative. The complete solution set is $-7 \leq x < 2$, which also contains negative values.
