- $x < 6$
- $-3 < x < 6$
- $-3 \leq x < 0$
- $-3 \leq x < 6$

## Explanation

The inequality has the form $\sqrt{A} < B$, so it is equivalent to the system
$$
\begin{cases}
x + 3 \geq 0 \\
3 > 0 \\
x + 3 < 9
\end{cases}
$$
The condition $3 > 0$ is true for every $x$. The first condition gives $x \geq -3$, with the endpoint included because at $x = -3$ the root equals $0 < 3$. The third gives $x < 6$, with the endpoint excluded because at $x = 6$ the root equals $3$. Therefore the solution is $-3 \leq x < 6$.
