For which values of the parameter $a$ is the function $f(x) = \sqrt{x^2 - 2x + a}$ defined for every real number $x$?

- $a > 1$
- $a \geq 1$
- $a \leq 1$
- $a \geq 0$

## Explanation

The function is defined for every $x$ when the radicand is nonnegative for every $x$. Completing the square we obtain $x^2 - 2x + a = (x - 1)^2 + a - 1$. Since $(x - 1)^2 \geq 0$ and it equals $0$ only for $x = 1$, the minimum value of the radicand is $a - 1$. Hence the radicand is nonnegative for every $x$ if and only if $a - 1 \geq 0$, that is, $a \geq 1$. For $a = 1$ the radicand equals $0$ at $x = 1$, where the root exists and equals $0$. For $a = 0$, instead, the radicand $x^2 - 2x$ is negative for $0 < x < 2$.
