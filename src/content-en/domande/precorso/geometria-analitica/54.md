For which value of $k$ are the points $A(1, 2)$, $B(3, 6)$ and $C(k, 10)$ collinear?

- $-3$
- $5$
- $17$
- $4$

## Explanation

The three points are collinear if and only if $C$ lies on the line $AB$. The slope of the line $AB$ is $m = \dfrac{6 - 2}{3 - 1} = 2$, so the line $AB$ is $y - 2 = 2(x - 1)$, that is, $y = 2x$. The point $C(k, 10)$ lies on this line if and only if $10 = 2k$. Therefore $k = 5$.
