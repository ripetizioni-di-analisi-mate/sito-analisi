Which values can the $x$-coordinate of a point of the ellipse $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$ take?

- $-5 \leq x \leq 5$
- $-25 \leq x \leq 25$
- $-10 \leq x \leq 10$
- $x \leq -5$ or $x \geq 5$

## Explanation

Since $\dfrac{y^2}{9} \geq 0$, every point of the ellipse satisfies $\dfrac{x^2}{25} \leq 1$, that is, $x^2 \leq 25$, so $-5 \leq x \leq 5$. Conversely, for every $x$ with $x^2 \leq 25$ we have $y^2 = 9\left(1 - \dfrac{x^2}{25}\right) \geq 0$, so there is a point of the ellipse with that $x$-coordinate. Therefore the $x$-coordinate ranges between $-5$ and $5$, the $x$-coordinates of the vertices $(\pm 5, 0)$.
