Which statement is true for the equation $2\,(x + 3) - x = x + 6$?

- It is inconsistent
- It is an identity
- It has the unique solution $x = 0$
- It has the unique solution $x = -6$

## Explanation

Expanding the left-hand side we obtain $2x + 6 - x = x + 6$, that is, $x + 6 = x + 6$. Subtracting $x + 6$ from both sides we arrive at $0 \cdot x = 0$, so the equation has the form $ax + b = 0$ with $a = 0$ and $b = 0$. Therefore every real number is a solution and the equation is an **identity**. The value $x = 0$ satisfies the equation like every other real number.
