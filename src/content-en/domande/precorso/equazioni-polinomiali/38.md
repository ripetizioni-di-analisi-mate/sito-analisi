What are the solutions of the inequality $x^4 - 5x^2 + 4 < 0$?

- $-2 < x < -1$ or $1 < x < 2$
- $-2 < x < 2$
- $-1 < x < 1$
- $x < -2$ or $-1 < x < 1$ or $x > 2$

## Explanation

With the substitution $t = x^2$ the trinomial $t^2 - 5t + 4$ has roots $1$ and $4$, so $x^4 - 5x^2 + 4 = (x^2 - 1)(x^2 - 4) = (x + 2)(x + 1)(x - 1)(x - 2)$. The zeros are $-2$, $-1$, $1$, $2$, and each first-degree factor is negative before its own zero and positive after it. From the **sign chart** the product is negative in the columns with an odd number of minus signs, that is, for $-2 < x < -1$ and for $1 < x < 2$. The direction $<$ excludes the zeros, so the solutions are $-2 < x < -1$ or $1 < x < 2$.
