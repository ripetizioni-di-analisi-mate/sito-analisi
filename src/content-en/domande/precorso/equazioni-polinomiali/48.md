What is the real solution set of $\left(x - 9\right)^{2} \left(x + 5\right) \geq 0$?

- $\left(-\infty, -5\right]$
- $\left[-5, \infty\right)$
- $\left(-\infty, -5\right] \cup \left\{9\right\}$
- $\left[-9, \infty\right)$

## Explanation

The squared factor is positive except at 9, where it is zero. The linear factor is nonnegative from -5 onward and that interval already contains 9, so the result is $\left[-5, \infty\right)$.
