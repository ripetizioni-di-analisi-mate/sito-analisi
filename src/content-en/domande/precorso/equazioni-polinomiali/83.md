The number $x = 2$ is a solution of the equation $kx - 3 = x + 5$. What is the value of $k$?

- $k = 5$
- $k = 2$
- $k = 3$
- $k = 4$

## Explanation

The number $2$ is a solution when, substituted for $x$, it makes the equality true. Substituting gives $2k - 3 = 2 + 5$, that is, $2k - 3 = 7$, which is a linear equation in the unknown $k$. Moving $-3$ to the right-hand side with the sign changed gives $2k = 10$, so $k = 5$. Indeed for $k = 5$ the equation becomes $5x - 3 = x + 5$, that is, $4x = 8$, with solution $x = 2$.
