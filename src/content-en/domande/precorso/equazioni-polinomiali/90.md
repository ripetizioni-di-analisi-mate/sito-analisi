The equation $\dfrac{x + a}{x - 2} = 3$ depends on the real parameter $a$. For which value of $a$ does it have no solutions?

- $a = 2$
- $a = -2$
- $a = -6$
- For no value of $a$

## Explanation

The domain restriction is $x \neq 2$. Multiplying both sides by $x - 2$, which is nonzero, gives $x + a = 3x - 6$, so $x = \dfrac{a + 6}{2}$. This value must be discarded when it equals $2$, that is, when $a + 6 = 4$, hence for $a = -2$. For $a = -2$ the equation is $\dfrac{x - 2}{x - 2} = 3$, and the left-hand side equals $1$ for every $x \neq 2$, so there are no solutions.
