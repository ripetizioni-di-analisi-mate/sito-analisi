What is the real solution set of $\left(x - 7\right)^{2} \left(x + 4\right) \geq 0$?

- $\left(-\infty, -4\right] \cup \left\{7\right\}$
- $\left[-7, \infty\right)$
- $\left(-\infty, -4\right]$
- $\left[-4, \infty\right)$

## Explanation

The squared factor is positive except at 7, where it is zero. The linear factor is nonnegative from -4 onward and that interval already contains 7, so the result is $\left[-4, \infty\right)$.
