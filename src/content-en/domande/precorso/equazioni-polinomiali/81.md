For which values of the parameter $a$ does the following system have at least one solution?
$$
\begin{cases}
x > a \\[2pt]
x < 3
\end{cases}
$$

- $a \leq 3$
- $a > 3$
- $a < 3$
- For every real $a$

## Explanation

The solutions of the system are the numbers greater than $a$ and less than $3$, that is, the interval $a < x < 3$. For $a < 3$ this set contains at least one number, for example the midpoint $\dfrac{a + 3}{2}$. For $a = 3$ no number is both greater than $3$ and less than $3$, and for $a > 3$ the two half-lines have no common points. Therefore the system has solutions for $a < 3$.
