For which $x$ does the double inequality $-1 < 2x + 3 \leq 7$ hold?

- $-2 \leq x \leq 2$
- $-2 < x < 2$
- $1 < x \leq 5$
- $-2 < x \leq 2$

## Explanation

The double inequality is equivalent to the system of the inequalities $2x + 3 > -1$ and $2x + 3 \leq 7$, which must hold together. Subtracting $3$ from all three members gives $-4 < 2x \leq 4$. Dividing by the positive number $2$ preserves the directions, so $-2 < x \leq 2$. The endpoint $-2$ is excluded because the first inequality is strict, and the endpoint $2$ is included because the second is non-strict.
