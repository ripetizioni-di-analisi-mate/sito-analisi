What is the real solution set of $\left(x - 4\right)^{2} \left(x + 2\right) \geq 0$?

- $\left(-\infty, -2\right] \cup \left\{4\right\}$
- $\left[-2, \infty\right)$
- $\left[-4, \infty\right)$
- $\left(-\infty, -2\right]$

## Explanation

The squared factor is positive except at 4, where it is zero. The linear factor is nonnegative from -2 onward and that interval already contains 4, so the result is $\left[-2, \infty\right)$.
