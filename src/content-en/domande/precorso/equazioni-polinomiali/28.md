Which statement is true for the equation $x^3 - 5x^2 + 8x - 4 = 0$?

- It has the double root $x = 1$ and the simple root $x = 2$
- It has the three distinct solutions $x = 1$, $x = 2$, $x = 4$
- It has the simple root $x = -1$ and the double root $x = -2$
- It has the simple root $x = 1$ and the double root $x = 2$

## Explanation

Let $P(x) = x^3 - 5x^2 + 8x - 4$. Since $P(1) = 1 - 5 + 8 - 4 = 0$, the binomial $x - 1$ divides $P$, and **synthetic division** gives $P(x) = (x - 1)(x^2 - 4x + 4)$. The trinomial $x^2 - 4x + 4$ is the square $(x - 2)^2$, so $P(x) = (x - 1)(x - 2)^2$. Therefore $x = 1$ is a simple root and $x = 2$ is a **double** root.
