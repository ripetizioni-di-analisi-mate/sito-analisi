The left-hand side of $\sin x + \cos x = \sqrt{2}$ can be rewritten with the auxiliary angle method. Which $x$ solve the equation?

- $x = \dfrac{\pi}{4} + n\pi$, with $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{4} + 2n\pi$, with $n \in \mathbb{Z}$
- $x = \dfrac{3\pi}{4} + 2n\pi$, with $n \in \mathbb{Z}$
- The equation has no solutions

## Explanation

With the auxiliary angle method, for $a = b = 1$ one has $R = \sqrt{2}$ and $\varphi = \dfrac{\pi}{4}$, because $\cos\varphi = \sin\varphi = \dfrac{\sqrt{2}}{2}$. So $\sin x + \cos x = \sqrt{2}\sin\left(x + \dfrac{\pi}{4}\right)$.

The equation becomes $\sin\left(x + \dfrac{\pi}{4}\right) = 1$, whose only solutions are $x + \dfrac{\pi}{4} = \dfrac{\pi}{2} + 2n\pi$, that is, $x = \dfrac{\pi}{4} + 2n\pi$.

The left-hand side reaches up to $R = \sqrt{2}$, so the equation has solutions even though $\sqrt{2} > 1$. For $x = \dfrac{5\pi}{4}$, which belongs to the family $\dfrac{\pi}{4} + n\pi$, the left-hand side equals $-\sqrt{2}$.
