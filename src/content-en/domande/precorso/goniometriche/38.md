The equation $\sin^2 x + \sin x\cos x = 1$ is solved with the fundamental identity. Which solutions are obtained?

- $x = \dfrac{\pi}{4} + n\pi$, with $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{2} + n\pi$ or $x = \dfrac{\pi}{4} + n\pi$, with $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{2} + n\pi$ or $x = -\dfrac{\pi}{4} + n\pi$, with $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{2} + 2n\pi$ or $x = \dfrac{\pi}{4} + 2n\pi$, with $n \in \mathbb{Z}$

## Explanation

By the fundamental identity $1 = \sin^2 x + \cos^2 x$, so the equation becomes $\sin x\cos x = \cos^2 x$, that is,
$$
\cos x\,(\sin x - \cos x) = 0 .
$$
The first factor gives $x = \dfrac{\pi}{2} + n\pi$. In the second factor the points with $\cos x = 0$ give no solutions, because at them $\sin x = \pm 1$; so one can divide by $\cos x$, which gives $\tan x = 1$, that is, $x = \dfrac{\pi}{4} + n\pi$.

Dividing the equation $\sin x\cos x = \cos^2 x$ by $\cos x$ would lose the family $x = \dfrac{\pi}{2} + n\pi$, which is a solution because there $\sin^2 x = 1$ and $\sin x\cos x = 0$.
