Which $x \in [0, 2\pi)$ satisfy the inequality $\dfrac{2\sin x - 1}{\cos x} \geq 0$?

- $\dfrac{\pi}{6} \leq x \leq \dfrac{\pi}{2}$ or $\dfrac{5\pi}{6} \leq x \leq \dfrac{3\pi}{2}$
- $\dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}$
- $\dfrac{\pi}{6} \leq x < \dfrac{\pi}{2}$ or $\dfrac{5\pi}{6} \leq x < \dfrac{3\pi}{2}$
- $0 \leq x \leq \dfrac{\pi}{6}$, $\dfrac{\pi}{2} < x \leq \dfrac{5\pi}{6}$ or $\dfrac{3\pi}{2} < x < 2\pi$

## Explanation

The numerator is greater than or equal to $0$ for $\sin x \geq \dfrac{1}{2}$, that is, for $\dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}$. The denominator is positive for $0 \leq x < \dfrac{\pi}{2}$ and for $\dfrac{3\pi}{2} < x < 2\pi$, negative for $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$, and zero at $\dfrac{\pi}{2}$ and $\dfrac{3\pi}{2}$.

The fraction is positive or zero where numerator and denominator have the same sign or the numerator is zero. This happens for $\dfrac{\pi}{6} \leq x < \dfrac{\pi}{2}$, where the numerator is positive or zero and the denominator is positive, and for $\dfrac{5\pi}{6} \leq x < \dfrac{3\pi}{2}$, where both are negative or the numerator is zero.

The endpoints $\dfrac{\pi}{2}$ and $\dfrac{3\pi}{2}$ are excluded because the denominator vanishes there.
