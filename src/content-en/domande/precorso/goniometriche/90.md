Knowing only that $\sin x = \dfrac{1}{3}$, one can compute $\sin 3x$. What is its value?

- $1$
- $\dfrac{23}{27}$
- $\dfrac{1}{3}$
- $\dfrac{5}{9}$

## Explanation

Since $3x = 2x + x$, the sine addition formula gives $\sin 3x = \sin 2x\cos x + \cos 2x\sin x$.

With the double-angle formulas $\sin 2x = 2\sin x\cos x$ and $\cos 2x = 1 - 2\sin^2 x$, and with $\cos^2 x = 1 - \sin^2 x$, one gets
$$
\begin{aligned}
\sin 3x &= 2\sin x\cos^2 x + (1 - 2\sin^2 x)\sin x \\[6pt]
&= 2\sin x - 2\sin^3 x + \sin x - 2\sin^3 x = 3\sin x - 4\sin^3 x .
\end{aligned}
$$
With $\sin x = \dfrac{1}{3}$ one has $\sin 3x = 1 - \dfrac{4}{27} = \dfrac{23}{27}$, and the result does not depend on the quadrant of $x$. The value $1$ comes from writing $\sin 3x = 3\sin x$, which is not an identity.
