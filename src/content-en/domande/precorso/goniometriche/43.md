What is the general solution of the inequality $\sin x < -\dfrac{1}{2}$?

- $-\dfrac{\pi}{6} + 2n\pi < x < \dfrac{7\pi}{6} + 2n\pi$, with $n \in \mathbb{Z}$
- $\dfrac{\pi}{6} + 2n\pi < x < \dfrac{5\pi}{6} + 2n\pi$, with $n \in \mathbb{Z}$
- $\dfrac{7\pi}{6} + n\pi < x < \dfrac{11\pi}{6} + n\pi$, with $n \in \mathbb{Z}$
- $\dfrac{7\pi}{6} + 2n\pi < x < \dfrac{11\pi}{6} + 2n\pi$, with $n \in \mathbb{Z}$

## Explanation

On $[0, 2\pi)$ the equation $\sin x = -\dfrac{1}{2}$ has the solutions $\pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}$ and $2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}$.

The points with ordinate less than $-\dfrac{1}{2}$ form the lower arc between these two angles, and since the inequality is strict the endpoints are excluded. The sine has period $2\pi$, so the general solution is
$$
\frac{7\pi}{6} + 2n\pi < x < \frac{11\pi}{6} + 2n\pi, \qquad n \in \mathbb{Z} .
$$
With the step $n\pi$, for $n = 1$ one would obtain the interval $\dfrac{13\pi}{6} < x < \dfrac{17\pi}{6}$, which contains $x = \dfrac{5\pi}{2}$, where the sine equals $1$.
