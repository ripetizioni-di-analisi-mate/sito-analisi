What are the solutions on $[0, 2\pi)$ of the inequality $2\sin^2 x - \sin x < 0$?

- $0 < x < \dfrac{\pi}{6}$ or $\dfrac{5\pi}{6} < x < \pi$
- $\dfrac{\pi}{6} < x < \dfrac{5\pi}{6}$
- $0 < x < \dfrac{\pi}{6}$
- $0 \leq x \leq \dfrac{\pi}{6}$ or $\dfrac{5\pi}{6} \leq x \leq \pi$

## Explanation

Setting $t = \sin x$, the inequality becomes $t\,(2t - 1) < 0$. The parabola $y = 2t^2 - t$ is negative between the roots $0$ and $\dfrac{1}{2}$, so the inequality is equivalent to the system
$$
\begin{cases}
\sin x > 0 \\[4pt]
\sin x < \dfrac{1}{2}
\end{cases}
$$
On $[0, 2\pi)$ the sine is positive for $0 < x < \pi$, and in this interval it is less than $\dfrac{1}{2}$ for $0 < x < \dfrac{\pi}{6}$ and for $\dfrac{5\pi}{6} < x < \pi$.

Therefore the solutions are $0 < x < \dfrac{\pi}{6}$ or $\dfrac{5\pi}{6} < x < \pi$, with the endpoints excluded because the inequality is strict.
