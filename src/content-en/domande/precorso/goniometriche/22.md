Which pair of values can be taken by $\sin x$ and $\cos x$ for the same angle $x$?

- $\sin x = \dfrac{1}{3}$ and $\cos x = \dfrac{2\sqrt{2}}{3}$
- $\sin x = \dfrac{1}{2}$ and $\cos x = \dfrac{1}{2}$
- $\sin x = \dfrac{3}{5}$ and $\cos x = \dfrac{2}{5}$
- $\sin x = \dfrac{\sqrt{2}}{2}$ and $\cos x = \dfrac{1}{2}$

## Explanation

For every angle the Pythagorean identity $\sin^2 x + \cos^2 x = 1$ holds, so a pair is possible only if the sum of the squares equals $1$.

For the pair $\sin x = \dfrac{1}{3}$ and $\cos x = \dfrac{2\sqrt{2}}{3}$ we have $\dfrac{1}{9} + \dfrac{8}{9} = 1$. For the others the sums of the squares are $\dfrac{1}{4} + \dfrac{1}{4} = \dfrac{1}{2}$, $\dfrac{9}{25} + \dfrac{4}{25} = \dfrac{13}{25}$ and $\dfrac{1}{2} + \dfrac{1}{4} = \dfrac{3}{4}$.

Therefore only this pair is possible. Indeed the point $\left(\dfrac{2\sqrt{2}}{3}, \dfrac{1}{3}\right)$ lies on the unit circle, so the angle that determines it has exactly these values of cosine and sine.
