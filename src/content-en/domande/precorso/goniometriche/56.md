What is the set of values taken by the function $f(x) = 2 - 3\sin x$?

- $[-3, 3]$
- $[1, 3]$
- $[-1, 5]$
- $[-5, 1]$

## Explanation

The sine takes all values of the interval $[-1, 1]$, so $-3\sin x$ takes all values of the interval $[-3, 3]$.

Adding $2$ shows that $f$ takes all values from $2 - 3 = -1$ to $2 + 3 = 5$.

The minimum $-1$ is attained for $\sin x = 1$, that is, for $x = \dfrac{\pi}{2} + 2n\pi$, and the maximum $5$ for $\sin x = -1$. The interval $[1, 3]$ ignores the coefficient $3$ of the sine.
