For which $x \in [0, 2\pi)$ is $\sin 2x > 0$?

- $0 < x < \dfrac{\pi}{2}$ or $\pi < x < \dfrac{3\pi}{2}$
- $0 < x < \pi$
- $0 < x < \dfrac{\pi}{2}$
- $0 \leq x \leq \dfrac{\pi}{2}$ or $\pi \leq x \leq \dfrac{3\pi}{2}$

## Explanation

The sine of an angle $t$ is positive for $2n\pi < t < \pi + 2n\pi$. With $t = 2x$ the condition becomes $2n\pi < 2x < \pi + 2n\pi$, that is, $n\pi < x < \dfrac{\pi}{2} + n\pi$.

The intervals with $n = 0$ and $n = 1$ lie in $[0, 2\pi)$, that is, $0 < x < \dfrac{\pi}{2}$ and $\pi < x < \dfrac{3\pi}{2}$.

The same result follows from $\sin 2x = 2\sin x\cos x$, which is positive when sine and cosine have the same sign, that is, in the first and in the third quadrant.
