In the equation $3\sin^2 x - 5\sin x - 2 = 0$ one sets $t = \sin x$. Which values of $t$ give solutions of the equation in $x$?

- Only $t = -\dfrac{1}{3}$
- $t = 2$ and $t = -\dfrac{1}{3}$
- Only $t = \dfrac{1}{3}$
- Only $t = 2$

## Explanation

The equation $3t^2 - 5t - 2 = 0$ has discriminant $25 + 24 = 49$, so its roots are $t = \dfrac{5 \pm 7}{6}$, that is, $t = 2$ and $t = -\dfrac{1}{3}$.

The sine takes only values between $-1$ and $1$, so the root $t = 2$ must be discarded, because the condition $-1 \leq t \leq 1$ is not satisfied.

What remains is $\sin x = -\dfrac{1}{3}$, which has solutions because $-1 \leq -\dfrac{1}{3} \leq 1$.
