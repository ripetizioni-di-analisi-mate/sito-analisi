For which values of the real parameter $c$ does the equation $\sin x + \sqrt{3}\cos x = c$ have solutions?

- $-1 \leq c \leq 1$
- $-2 \leq c \leq 2$
- $-1 - \sqrt{3} \leq c \leq 1 + \sqrt{3}$
- $-4 \leq c \leq 4$

## Explanation

With the auxiliary angle method, for $a = 1$ and $b = \sqrt{3}$ we have $R = \sqrt{1 + 3} = 2$ and $\varphi = \dfrac{\pi}{3}$, so $\sin x + \sqrt{3}\cos x = 2\sin\left(x + \dfrac{\pi}{3}\right)$.

The equation becomes $\sin\left(x + \dfrac{\pi}{3}\right) = \dfrac{c}{2}$, which has solutions if and only if $-1 \leq \dfrac{c}{2} \leq 1$. Therefore the equation has solutions for $-2 \leq c \leq 2$.

The maximum of the left-hand side is thus $2$, smaller than the sum of the coefficients $1 + \sqrt{3}$.
