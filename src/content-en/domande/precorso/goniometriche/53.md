What are the solutions of the inequality $\tan x > 1$ in the interval $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$?

- $-\dfrac{\pi}{2} < x < \dfrac{\pi}{4}$
- $\dfrac{\pi}{4} < x < \dfrac{\pi}{2}$
- $\dfrac{\pi}{4} \leq x < \dfrac{\pi}{2}$
- $\dfrac{\pi}{4} < x < \dfrac{3\pi}{4}$

## Explanation

In the interval $\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$ the tangent is defined and increasing. Indeed, as the angle increases, the $y$-coordinate of the point where the line through the origin and the point on the circle meets the line tangent to the circle at $(1, 0)$ increases.

Since $\tan\dfrac{\pi}{4} = 1$, one has $\tan x > 1$ for $\dfrac{\pi}{4} < x < \dfrac{\pi}{2}$, with the endpoint $\dfrac{\pi}{4}$ excluded because the inequality is strict.

The interval $\dfrac{\pi}{4} < x < \dfrac{3\pi}{4}$ goes beyond the given interval and contains $\dfrac{\pi}{2}$, where the tangent is not defined.
