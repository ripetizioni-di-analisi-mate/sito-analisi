Among the angles in $[0, \pi]$, which ones have cosine equal to $-\dfrac{\sqrt{2}}{2}$?

- $\left\{\dfrac{3\pi}{4}, \dfrac{5\pi}{4}\right\}$
- $\left\{\dfrac{\pi}{4}, \dfrac{3\pi}{4}\right\}$
- $\left\{\dfrac{\pi}{4}\right\}$
- $\left\{\dfrac{3\pi}{4}\right\}$

## Explanation

Since $\cos\dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2}$ and $\cos(\pi - x) = -\cos x$, one has $\cos\dfrac{3\pi}{4} = -\dfrac{\sqrt{2}}{2}$. The solutions of the equation are therefore $x = \pm\dfrac{3\pi}{4} + 2n\pi$.

Only $\dfrac{3\pi}{4}$ lies in the interval $[0, \pi]$, because the other solution in the first turn, $\dfrac{5\pi}{4}$, is greater than $\pi$. Indeed, on $[0, \pi]$ the cosine is decreasing and takes each value only once.

The angle $\dfrac{\pi}{4}$ has positive cosine, so it is not a solution.
