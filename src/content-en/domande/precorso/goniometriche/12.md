- $\dfrac{2\pi}{3} < x < \dfrac{4\pi}{3}$
- $0 \leq x < \dfrac{2\pi}{3}$ or $\dfrac{4\pi}{3} < x < 2\pi$
- $0 \leq x < \dfrac{\pi}{3}$ or $\dfrac{5\pi}{3} < x < 2\pi$
- $0 \leq x \leq \dfrac{2\pi}{3}$ or $\dfrac{4\pi}{3} \leq x < 2\pi$

## Explanation

The inequality is equivalent to $\cos x > -\dfrac{1}{2}$. On $[0, 2\pi)$ the equation $\cos x = -\dfrac{1}{2}$ has the solutions $\dfrac{2\pi}{3}$ and $2\pi - \dfrac{2\pi}{3} = \dfrac{4\pi}{3}$.

The points with $x$-coordinate greater than $-\dfrac{1}{2}$ form the arc that contains the point of angle $0$. On $[0, 2\pi)$ this arc corresponds to two intervals, one starting at $0$ and one ending at $2\pi$.

The inequality is strict, so the endpoints $\dfrac{2\pi}{3}$ and $\dfrac{4\pi}{3}$ are excluded. The solutions are therefore $0 \leq x < \dfrac{2\pi}{3}$ or $\dfrac{4\pi}{3} < x < 2\pi$.
