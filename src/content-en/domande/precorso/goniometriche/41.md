Which of the following equations has no solutions?

- $\cos x = \dfrac{\pi}{4}$
- $\tan x = \dfrac{\pi}{3}$
- $\sin x = \dfrac{\pi}{3}$
- $\cos x = -\dfrac{3}{4}$

## Explanation

The equations $\sin x = k$ and $\cos x = k$ have solutions if and only if $-1 \leq k \leq 1$, while $\tan x = k$ has solutions for every $k \in \mathbb{R}$.

Since $\pi > 3$, we have $\dfrac{\pi}{3} > 1$, so **the equation $\sin x = \dfrac{\pi}{3}$ has no solutions**.

Since $\pi < 4$, we have $0 < \dfrac{\pi}{4} < 1$, so $\cos x = \dfrac{\pi}{4}$ has solutions; $\cos x = -\dfrac{3}{4}$ also has solutions, since $-1 < -\dfrac{3}{4} < 1$.
