For which $x$ do sine and cosine have the same absolute value, that is, $\sin^2 x - \cos^2 x = 0$?

- $x = \dfrac{\pi}{4} + n\pi$, with $n \in \mathbb{Z}$
- $x = \pm\dfrac{\pi}{4} + 2n\pi$, with $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{2} + n\pi$, with $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{4} + \dfrac{n\pi}{2}$, with $n \in \mathbb{Z}$

## Explanation

The points with $\cos x = 0$ are not solutions, because at them $\sin^2 x = 1$. Dividing by $\cos^2 x$ gives $\tan^2 x = 1$, that is, $\tan x = 1$ or $\tan x = -1$.

From $\tan x = 1$ it follows that $x = \dfrac{\pi}{4} + n\pi$, and from $\tan x = -1$ it follows that $x = -\dfrac{\pi}{4} + n\pi$. Together the two families give the angles $\dfrac{\pi}{4}$, $\dfrac{3\pi}{4}$, $\dfrac{5\pi}{4}$ and $\dfrac{7\pi}{4}$ of each turn, that is, $x = \dfrac{\pi}{4} + \dfrac{n\pi}{2}$.

The same result follows from the double-angle formula, because $\sin^2 x - \cos^2 x = -\cos 2x$.
