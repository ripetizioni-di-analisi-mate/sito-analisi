The equation $\sin^2 x + \sin x = a$ has solutions only for some values of the real number $a$. Which ones?

- $0 \leq a \leq 2$
- $-\dfrac{1}{4} \leq a \leq 2$
- $a \geq -\dfrac{1}{4}$
- $-1 \leq a \leq 1$

## Explanation

Setting $t = \sin x$, the equation has solutions if and only if $a$ is a value taken by $g(t) = t^2 + t$ for some $t$ with $-1 \leq t \leq 1$.

The parabola $g(t) = t^2 + t$ has its vertex at $t = -\dfrac{1}{2}$, where it equals $\dfrac{1}{4} - \dfrac{1}{2} = -\dfrac{1}{4}$. On $\left[-\dfrac{1}{2}, 1\right]$ it is increasing and goes from $-\dfrac{1}{4}$ to $g(1) = 2$, while on $\left[-1, -\dfrac{1}{2}\right]$ it takes values between $-\dfrac{1}{4}$ and $g(-1) = 0$.

Therefore the equation has solutions for $-\dfrac{1}{4} \leq a \leq 2$. The condition $a \geq -\dfrac{1}{4}$ ignores the constraint $-1 \leq t \leq 1$.
