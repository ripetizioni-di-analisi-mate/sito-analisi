For which values of the real parameter $k$ does the equation $\cos x = 2k - 1$ have solutions?

- $-1 \leq k \leq 1$
- $0 < k < 1$
- $0 \leq k \leq 1$
- $k \leq 1$

## Explanation

The equation $\cos x = c$ has solutions if and only if $-1 \leq c \leq 1$, because the cosine takes exactly the values between $-1$ and $1$.

So we need $-1 \leq 2k - 1 \leq 1$. Adding $1$ gives $0 \leq 2k \leq 2$, and dividing by $2$ gives $0 \leq k \leq 1$.

The endpoints are included, because for $k = 0$ the equation $\cos x = -1$ has the solutions $x = \pi + 2n\pi$, and for $k = 1$ the equation $\cos x = 1$ has the solutions $x = 2n\pi$.
