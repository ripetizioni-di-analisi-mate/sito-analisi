Which of the following inequalities is true?

- $\log_{\frac{1}{2}} 3 > \log_{\frac{1}{2}} 5$
- $\log_2 3 > \log_2 5$
- $\log_{\frac{1}{2}} 3 > 0$
- $\log_3 \dfrac{1}{2} > 0$

## Explanation

The function $\log_{\frac{1}{2}} x$ has base between $0$ and $1$, so it is strictly decreasing. Since $3 < 5$, we have $\log_{\frac{1}{2}} 3 > \log_{\frac{1}{2}} 5$. The function $\log_2 x$, on the other hand, is increasing, so $\log_2 3 < \log_2 5$. From the fact that $\log_{\frac{1}{2}} x$ is decreasing and $3 > 1$ it also follows that $\log_{\frac{1}{2}} 3 < \log_{\frac{1}{2}} 1 = 0$. In the same way $\log_3 x$ is increasing and $\dfrac{1}{2} < 1$, so $\log_3 \dfrac{1}{2} < 0$.
