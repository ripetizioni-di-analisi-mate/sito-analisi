Which values satisfy $\log_{\dfrac{1}{3}}\left(x + 3\right)\leq 0$?

- $\left(-2, \infty\right)$
- $\left[-3, \infty\right)$
- $\left(-3, -2\right]$
- $\left[-2, \infty\right)$

## Explanation

The base is below $1$, so the logarithm is decreasing and is zero when its argument is $1$. Require $x + 3 \geq 1$ to obtain $\left[-2, \infty\right)$.
