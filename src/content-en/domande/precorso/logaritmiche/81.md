For which values of $x$ is the square root $\sqrt{\log_2 (x - 3)}$ defined?

- $x \geq 4$
- $x > 3$
- $x \geq 3$
- $3 < x \leq 4$

## Explanation

The logarithm exists for $x - 3 > 0$ and the square root requires a nonnegative radicand, so the conditions form the system
$$
\begin{cases}
x - 3 > 0 \\
\log_2 (x - 3) \geq 0
\end{cases}
$$
Since $0 = \log_2 1$ and the base $2$ is greater than $1$, the second condition is equivalent to $x - 3 \geq 1$, that is $x \geq 4$. This condition implies the first one, therefore the domain is $x \geq 4$.
