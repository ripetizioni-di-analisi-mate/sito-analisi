Solving $2\log_5 x = \log_5 16$ leads to which set of solutions?

- $x = 4$ and $x = -4$
- $x = 8$
- $x = 2$
- $x = 4$

## Explanation

The domain restriction is $x > 0$. By the power property, $2\log_5 x = \log_5 (x^{2})$, and the equation becomes $\log_5 (x^{2}) = \log_5 16$. Since the logarithmic function is injective, $x^{2} = 16$, that is $x = 4$ or $x = -4$. For $x = -4$ the logarithm $\log_5 x$ of the given equation does not exist, so the only solution is $x = 4$.
