What are the solutions of the inequality $\log_5 (2x - 3) \leq 0$?

- $x \leq 2$
- $x \geq 2$
- $\dfrac{3}{2} < x < 2$
- $\dfrac{3}{2} < x \leq 2$

## Explanation

The number $0$ is written as $\log_5 1$, so the inequality becomes $\log_5 (2x - 3) \leq \log_5 1$. The base $5$ is greater than $1$, therefore the direction is preserved and, together with the domain restriction, we obtain the system
$$
\begin{cases}
2x - 3 \leq 1 \\
2x - 3 > 0
\end{cases}
\iff
\begin{cases}
x \leq 2 \\
x > \dfrac{3}{2}
\end{cases}
$$
The solutions are therefore $\dfrac{3}{2} < x \leq 2$, with the endpoint $2$ included because $\log_5 1 = 0$.
