Which $x$ satisfy the double inequality $1 < \log_3 x < 2$?

- $1 < x < 2$
- $0 < x < 3$ or $x > 9$
- $3 < x < 9$
- $0 < x < 9$

## Explanation

The domain restriction is $x > 0$. The numbers $1$ and $2$ are written as logarithms in base $3$, namely $1 = \log_3 3$ and $2 = \log_3 9$, and the inequality becomes $\log_3 3 < \log_3 x < \log_3 9$. The base $3$ is greater than $1$, so the logarithmic function is increasing and the direction is preserved when passing to the arguments. This gives $3 < x < 9$, and these values satisfy the condition $x > 0$.
