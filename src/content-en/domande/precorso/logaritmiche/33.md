What are the solutions of the inequality $\log_3 (2x - 1) < \log_3 (x + 2)$?

- $\dfrac{1}{2} < x < 3$
- $x < 3$
- $-2 < x < 3$
- $x > 3$

## Explanation

The base $3$ is greater than $1$, so the logarithmic function is increasing and the direction **is preserved** when passing to the arguments. The system contains the domain restriction of the smaller argument, which is $2x - 1$:
$$
\begin{cases}
2x - 1 < x + 2 \\
2x - 1 > 0
\end{cases}
\iff
\begin{cases}
x < 3 \\
x > \dfrac{1}{2}
\end{cases}
$$
The positivity of $x + 2$ follows from $x + 2 > 2x - 1 > 0$, so the solutions are $\dfrac{1}{2} < x < 3$.
