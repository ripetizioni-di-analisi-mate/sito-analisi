Which set of real numbers satisfies the inequality $\log_2 (x + 1) > 1 + \log_2 (x - 2)$?

- $2 < x < 5$
- $x < 5$
- $x > 5$
- $-1 < x < 5$

## Explanation

The number $1$ is written as $\log_2 2$, and by the property of the logarithm of a product the right-hand side becomes $\log_2 \bigl(2(x - 2)\bigr)$. The base $2$ is greater than $1$, so the direction is preserved and the inequality is equivalent to the system
$$
\begin{cases}
x + 1 > 2x - 4 \\
2x - 4 > 0
\end{cases}
\iff
\begin{cases}
x < 5 \\
x > 2
\end{cases}
$$
The domain restriction concerns the smaller argument $2x - 4$, because the positivity of $x + 1$ follows from the first inequality. Therefore the solutions are $2 < x < 5$.
