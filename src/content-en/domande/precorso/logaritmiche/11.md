- $2 < x \leq 5$
- $x \geq 5$
- $x \leq 5$
- $2 < x \leq \dfrac{7}{3}$

## Explanation

The number $-1$ is written as a logarithm in base $\dfrac{1}{3}$, that is $-1 = \log_{\frac{1}{3}} 3$, because $\left(\dfrac{1}{3}\right)^{-1} = 3$. The base lies between $0$ and $1$, therefore the logarithmic function is decreasing and the direction **is reversed** when passing to the arguments. In this case the domain condition does not follow from the inequality, so it must be written in the system
$$
\begin{cases}
x - 2 \leq 3 \\
x - 2 > 0
\end{cases}
\iff
\begin{cases}
x \leq 5 \\
x > 2
\end{cases}
$$
The solutions are therefore $2 < x \leq 5$.
