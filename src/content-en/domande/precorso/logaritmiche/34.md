What are the solutions of the inequality $\log_2 (x + 3) < 3$?

- $x < 5$
- $x > 5$
- $-3 < x < 5$
- $-3 < x < 3$

## Explanation

The number $3$ is written as a logarithm in base $2$, that is $3 = \log_2 (2^{3}) = \log_2 8$. The base is greater than $1$, so the direction is preserved and we obtain $x + 3 < 8$. In this case the positivity of the argument does not follow from the inequality, so it must be written in the system
$$
\begin{cases}
x + 3 < 8 \\
x + 3 > 0
\end{cases}
\iff
\begin{cases}
x < 5 \\
x > -3
\end{cases}
$$
The solutions are therefore $-3 < x < 5$.
