What are the solutions of the equation $\log_2 (x - 3) = \log_2 (1 - x)$?

- $x = 2$
- $x = -1$
- $x = 1$
- The equation has no solutions

## Explanation

The domain restrictions form the system
$$
\begin{cases}
x - 3 > 0 \\
1 - x > 0
\end{cases}
\iff
\begin{cases}
x > 3 \\
x < 1
\end{cases}
$$
No real number is both greater than $3$ and less than $1$, so the two logarithms are never defined for the same value of $x$. Equating the arguments would give $x = 2$, but for this value $x - 3 = -1 < 0$. Therefore the equation **has no solutions**.
