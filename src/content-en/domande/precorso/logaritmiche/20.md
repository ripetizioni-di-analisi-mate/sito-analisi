Which statement about the function $f(x) = \log_{\frac{1}{3}} x$ is true?

- $f$ is increasing and $f(9) = 2$
- $f$ is decreasing and $f(9) = 2$
- $f$ is defined for every real $x$ and $f(1) = 0$
- $f$ is decreasing and $f(9) = -2$

## Explanation

The base $\dfrac{1}{3}$ lies between $0$ and $1$, so the function is strictly **decreasing**. Since $\left(\dfrac{1}{3}\right)^{-2} = 3^{2} = 9$, by the definition of logarithm $f(9) = -2$. The function is defined only for $x > 0$, therefore the statement about the domain is false, even though $f(1) = 0$.
