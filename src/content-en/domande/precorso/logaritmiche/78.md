What is the solution set of the inequality $\log_{\frac{1}{2}} (\log_2 x) > 1$?

- $x > \sqrt{2}$
- $0 < x < \sqrt{2}$
- $1 < x < 4$
- $1 < x < \sqrt{2}$

## Explanation

The argument $x$ of the inner logarithm and the argument $\log_2 x$ of the outer logarithm must be positive, so the domain restrictions form the system
$$
\begin{cases}
x > 0 \\
\log_2 x > 0
\end{cases}
\iff x > 1 .
$$
The number $1$ is written as $\log_{\frac{1}{2}} \dfrac{1}{2}$ and the base $\dfrac{1}{2}$ lies between $0$ and $1$, therefore the direction is reversed and we obtain $\log_2 x < \dfrac{1}{2}$. The number $\dfrac{1}{2}$ is written as $\log_2 \sqrt{2}$ and the base $2$ is greater than $1$, so the direction is preserved and we obtain $x < \sqrt{2}$. Intersecting with the condition $x > 1$, the solutions are $1 < x < \sqrt{2}$.
