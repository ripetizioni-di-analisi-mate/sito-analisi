For which values of the base $a$ does the inequality $\log_a 5 > \log_a 3$ hold?

- $0 < a < 1$
- $a > 1$
- For every $a > 0$ different from $1$
- For no value of $a$

## Explanation

The arguments $5$ and $3$ are positive, so both logarithms exist for every positive base different from $1$. If $a > 1$ the function $\log_a x$ is strictly increasing, and since $5 > 3$ we have $\log_a 5 > \log_a 3$. If $0 < a < 1$ the function is strictly decreasing, therefore $\log_a 5 < \log_a 3$. Hence the inequality holds for $a > 1$.
