The number $\log_2 5$ lies between $2$ and $3$. Which of the following statements about it is true?

- It equals $\dfrac{5}{2}$
- It is an irrational number
- It is a rational number
- It equals $\dfrac{\log_{10} 2}{\log_{10} 5}$

## Explanation

Since $4 < 5 < 8$ and the function $\log_2 x$ is increasing, we have $2 < \log_2 5 < 3$, so $\log_2 5$ is positive. If it were rational, we could write $\log_2 5 = \dfrac{p}{q}$ with $p$ and $q$ positive integers, and by the definition of logarithm $2^{\frac{p}{q}} = 5$; raising both sides to the power $q$ would give $2^{p} = 5^{q}$. This equality is impossible, because $2^{p}$ is even and $5^{q}$ is odd. Therefore $\log_2 5$ is **irrational**, and by the change of base formula it equals $\dfrac{\log_{10} 5}{\log_{10} 2}$.
