Which value of $x$ makes the equality $\log_4 x = \log_4 3 + \dfrac{1}{2}$ true?

- $x = \dfrac{7}{2}$
- $x = 12$
- $x = \dfrac{3}{2}$
- $x = 6$

## Explanation

The domain restriction is $x > 0$. Since $4^{\frac{1}{2}} = \sqrt{4} = 2$, the number $\dfrac{1}{2}$ is written as $\log_4 2$. By the property of the logarithm of a product the right-hand side becomes $\log_4 3 + \log_4 2 = \log_4 6$. The logarithmic function is injective, so $x = 6$, which satisfies the domain restriction.
