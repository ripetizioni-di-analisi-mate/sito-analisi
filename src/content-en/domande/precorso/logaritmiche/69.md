What can be said about the solution set of $\log_3 (x^{2} + 2) > 0$?

- It is the empty set
- It is the set of all real numbers
- It is the set of numbers $x > 0$
- It is the set of numbers $x \neq 0$

## Explanation

The argument $x^{2} + 2$ is positive for every $x$, so the logarithm exists for every real $x$. The number $0$ is written as $\log_3 1$ and the base $3$ is greater than $1$, therefore the inequality is equivalent to $x^{2} + 2 > 1$, that is to $x^{2} > -1$. This inequality holds for every real $x$, so the given inequality is satisfied for every $x$, including $x = 0$, where the left-hand side equals $\log_3 2 > 0$.
