The equation $\log_3 (x + 1) = \log_3 (k - x)$ contains the real parameter $k$. For which values of $k$ does it have a solution?

- For every real $k$
- $k < -1$
- $k \geq -1$
- $k > -1$

## Explanation

By the injectivity of the logarithmic function the equation is equivalent to the system
$$
\begin{cases}
x + 1 = k - x \\
x + 1 > 0
\end{cases}
$$
The first equation gives $x = \dfrac{k - 1}{2}$, and the domain restriction becomes $\dfrac{k - 1}{2} + 1 > 0$, that is $\dfrac{k + 1}{2} > 0$. Hence the equation has a solution if and only if $k > -1$. The condition $k - x > 0$ is redundant, because it follows from the first equation of the system.
