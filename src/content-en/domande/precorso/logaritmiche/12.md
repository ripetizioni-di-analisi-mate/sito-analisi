- $x > 4$
- $x < 4$
- $\dfrac{3}{2} < x < 4$
- $-1 < x < 4$

## Explanation

The base $\dfrac{1}{2}$ lies between $0$ and $1$, therefore the logarithmic function is decreasing and the direction **is reversed** when passing to the arguments. The system contains the domain condition of the smaller argument, which is $2x - 3$:
$$
\begin{cases}
x + 1 > 2x - 3 \\
2x - 3 > 0
\end{cases}
\iff
\begin{cases}
x < 4 \\
x > \dfrac{3}{2}
\end{cases}
$$
The positivity of $x + 1$ follows from $x + 1 > 2x - 3 > 0$, so the solutions are $\dfrac{3}{2} < x < 4$.
