What is the only solution of the equation $(\log_2 x + 3)^{2} = 0$?

- $x = -3$
- $x = \dfrac{1}{8}$
- $x = 8$
- $x = -6$

## Explanation

The domain restriction is $x > 0$. The square of a number is zero if and only if the number is zero, so the equation is equivalent to $\log_2 x + 3 = 0$, that is $\log_2 x = -3$. By the definition of logarithm, $x = 2^{-3} = \dfrac{1}{8}$, which is positive and therefore acceptable.
