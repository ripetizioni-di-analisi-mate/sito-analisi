Written in base $3$, the logarithm $\log_9 x$, with $x > 0$, becomes which expression?

- $\dfrac{1}{2}\log_3 x$
- $2\log_3 x$
- $\dfrac{2}{\log_3 x}$
- $\log_3 x - 2$

## Explanation

By the change of base formula, with the new base $3$, we have $\log_9 x = \dfrac{\log_3 x}{\log_3 9}$. Since $9 = 3^{2}$, the denominator is $\log_3 9 = 2$, so $\log_9 x = \dfrac{1}{2}\log_3 x$. For example, with $x = 81$ we have $\log_9 81 = 2$ and $\dfrac{1}{2}\log_3 81 = \dfrac{4}{2} = 2$.
