What is the domain of the function $f(x) = \log_2 (4 - x^{2})$?

- $x < 2$
- $x > 2$
- $-2 < x < 2$
- $x < -2$ or $x > 2$

## Explanation

The logarithm exists only for positive arguments, so the domain consists of the values of $x$ with $4 - x^{2} > 0$. The inequality is equivalent to $x^{2} < 4$, that is to $-2 < x < 2$. For $x = 2$ and for $x = -2$ the argument equals $0$, therefore the endpoints are excluded.
