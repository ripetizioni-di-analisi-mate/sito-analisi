For which values of $x$ is $\log_{\frac{1}{2}} x > 0$?

- $x > 1$
- $x > 0$
- $x > \dfrac{1}{2}$
- $0 < x < 1$

## Explanation

The number $0$ is written as $\log_{\frac{1}{2}} 1$, so the inequality becomes $\log_{\frac{1}{2}} x > \log_{\frac{1}{2}} 1$. The base lies between $0$ and $1$, therefore the function is decreasing and the direction is reversed, giving $x < 1$. Together with the domain restriction $x > 0$ we obtain $0 < x < 1$.
