For which values of $x$ is the number $\log_{\frac{1}{3}} x$ negative?

- $x > 1$
- $0 < x < 1$
- $x > \dfrac{1}{3}$
- For no value of $x$

## Explanation

The logarithm exists for $x > 0$ and equals $0$ for $x = 1$. The base $\dfrac{1}{3}$ lies between $0$ and $1$, so the function $\log_{\frac{1}{3}} x$ is strictly decreasing. Therefore for $x > 1$ we have $\log_{\frac{1}{3}} x < \log_{\frac{1}{3}} 1 = 0$, while for $0 < x < 1$ the logarithm is positive. For example, $\log_{\frac{1}{3}} 9 = -2$.
