In the logarithm $\log_x (3 - x)$ the base is variable. For which $x$ does the logarithm exist?

- $0 < x < 3$ and $x \neq 1$
- $0 < x < 3$
- $x < 3$
- $x > 0$ and $x \neq 1$

## Explanation

The logarithm $\log_a b$ requires a positive base different from $1$ and a positive argument. With base $x$ and argument $3 - x$ the conditions form the system
$$
\begin{cases}
x > 0 \\
x \neq 1 \\
3 - x > 0
\end{cases}
\iff
\begin{cases}
0 < x < 3 \\
x \neq 1
\end{cases}
$$
Hence the domain consists of the numbers $x$ with $0 < x < 3$ different from $1$.
