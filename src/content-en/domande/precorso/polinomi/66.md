Which number is a possible rational root of $x^{3} - 3 x^{2} - 5 x + 2$ according to the rational root theorem?

- $- \dfrac{2}{3}$
- $3$
- $\dfrac{1}{3}$
- $-2$

## Explanation

The polynomial is monic, so any rational root is an integer that divides the constant term 2. The candidate meeting this requirement is $-2$.
