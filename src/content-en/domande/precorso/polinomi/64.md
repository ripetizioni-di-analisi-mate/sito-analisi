Which number is a possible rational root of $x^{3} - 5 x^{2} - 9 x + 4$ according to the rational root theorem?

- $\dfrac{1}{5}$
- $-4$
- $- \dfrac{4}{5}$
- $5$

## Explanation

The polynomial is monic, so any rational root is an integer that divides the constant term 4. The candidate meeting this requirement is $-4$.
