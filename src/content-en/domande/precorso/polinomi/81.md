Which number is a possible rational root of $x^{3} - 6 x^{2} - 11 x + 5$ according to the rational root theorem?

- $-5$
- $\dfrac{1}{6}$
- $- \dfrac{5}{6}$
- $6$

## Explanation

The polynomial is monic, so any rational root is an integer that divides the constant term 5. The candidate meeting this requirement is $-5$.
