Which number is a possible rational root of $x^{3} - 4 x^{2} - 7 x + 3$ according to the rational root theorem?

- $-3$
- $4$
- $- \dfrac{3}{4}$
- $\dfrac{1}{4}$

## Explanation

The polynomial is monic, so any rational root is an integer that divides the constant term 3. The candidate meeting this requirement is $-3$.
