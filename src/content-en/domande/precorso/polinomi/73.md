Which number is a possible rational root of $x^{3} - 7 x^{2} - 13 x + 6$ according to the rational root theorem?

- $7$
- $-6$
- $\dfrac{1}{7}$
- $- \dfrac{6}{7}$

## Explanation

The polynomial is monic, so any rational root is an integer that divides the constant term 6. The candidate meeting this requirement is $-6$.
