Which of the following equalities holds for every real $x$?

- $(3 - x)^3 = (x - 3)^3$
- $(3 - x)^2 = 9 + x^2$
- $(3 - x)^2 = (x - 3)^2$
- $(3 - x)^2 = -(x - 3)^2$

## Explanation

Since $3 - x = -(x - 3)$, we have $(3 - x)^2 = (-1)^2 (x - 3)^2 = (x - 3)^2$ for every $x$. For the cube, instead, $(3 - x)^3 = (-1)^3 (x - 3)^3 = -(x - 3)^3$, which differs from $(x - 3)^3$ for $x \neq 3$. The expansion $(3 - x)^2 = 9 - 6x + x^2$ contains twice the product $-6x$, so it differs from $9 + x^2$ for $x \neq 0$. Finally $-(x - 3)^2$ is negative for $x \neq 3$, while a square is never negative.
