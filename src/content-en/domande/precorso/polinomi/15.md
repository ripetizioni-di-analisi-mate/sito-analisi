For which value of $k$ does the polynomial $P(x) = \left( k^2 - 4 \right) x^3 + (k - 2)\,x^2 + 3x - 1$ have degree $1$?

- $k = -2$
- $k = 2$
- $k = \pm 2$
- No value of $k$

## Explanation

The polynomial has degree $1$ when the coefficients of $x^3$ and of $x^2$ are both zero, that is, when
$$
\begin{cases}
k^2 - 4 = 0 \\[2pt]
k - 2 = 0
\end{cases}
$$
The first equation is satisfied by $k = 2$ and by $k = -2$, the second only by $k = 2$, so the system has the unique solution $k = 2$. For $k = 2$ one gets $P(x) = 3x - 1$, which has degree $1$. For $k = -2$, on the other hand, one gets $P(x) = -4x^2 + 3x - 1$, which has degree $2$.
