The binomial $x - 2$ divides the polynomial $P(x)$. Which binomial certainly divides the polynomial $Q(x) = P(x + 1)$?

- $x - 1$
- $x - 3$
- $x - 2$
- $x + 1$

## Explanation

Since $x - 2$ divides $P$, by the **factor theorem** we have $P(2) = 0$. At $x = 1$ the polynomial $Q$ takes the value $Q(1) = P(1 + 1) = P(2) = 0$, so $1$ is a root of $Q$. By the same theorem, the binomial $x - 1$ divides $Q$. The other three binomials divide $Q$ only if $Q(3) = P(4)$, $Q(2) = P(3)$ or $Q(-1) = P(0)$ is zero, and these values are not known. For example, with $P(x) = x - 2$ we get $Q(x) = x - 1$, which is divisible by none of the three.
