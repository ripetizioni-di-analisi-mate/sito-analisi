The polynomial $P(x) = (a - 1)x^3 + (b + 2)x^2 + 3x$ depends on the real parameters $a$ and $b$. For which values of the parameters does $P(-x) = -P(x)$ hold for every real $x$?

- $b = -2$, with any $a$
- $a = 1$, with any $b$
- $b = 2$, with any $a$
- No values of $a$ and $b$

## Explanation

Replacing $x$ with $-x$ gives $P(-x) = -(a - 1)x^3 + (b + 2)x^2 - 3x$, while $-P(x) = -(a - 1)x^3 - (b + 2)x^2 - 3x$. By the **identity principle** the two polynomials coincide for every $x$ if and only if they have the same coefficients. The coefficients of $x^3$ and of $x$ coincide for every value of $a$. The coefficients of $x^2$ coincide if and only if $b + 2 = -(b + 2)$, that is, $b = -2$. Therefore the equality holds for $b = -2$ and for every value of $a$.
