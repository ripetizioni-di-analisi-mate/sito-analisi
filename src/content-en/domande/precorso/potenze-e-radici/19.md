The power with exponent zero is defined by setting $a^0 = 1$ for $a \neq 0$. For which real $x$ is the expression $(x - 2)^0$ meaningful, and what value does it take?

- For every real $x$, and it equals $1$
- For $x \neq 2$, and it equals $0$
- For $x \neq 2$, and it equals $1$
- For $x > 2$, and it equals $1$

## Explanation

The power $a^0$ is defined by setting $a^0 = 1$ for $a \neq 0$, while the expression $0^0$ is meaningless. The base $x - 2$ vanishes for $x = 2$, so the expression is meaningful for $x \neq 2$. For every $x \neq 2$ the base is different from zero, therefore $(x - 2)^0 = 1$.

The base may also be negative, as for $x = 0$, where $(-2)^0 = 1$; hence the condition $x > 2$ would exclude values at which the expression is defined.
