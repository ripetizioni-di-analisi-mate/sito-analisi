For which real $x$ is the expression $\sqrt{6 - 2x} + \sqrt[3]{x + 1}$ defined?

- $x \geq 3$
- $-1 \leq x \leq 3$
- $x < 3$
- $x \leq 3$

## Explanation

The root $\sqrt{6 - 2x}$ has an even index, so it exists for $6 - 2x \geq 0$, that is, for $x \leq 3$. The endpoint $3$ is included, because for $x = 3$ the radicand equals $0$ and $\sqrt{0} = 0$. The root $\sqrt[3]{x + 1}$ has an odd index, therefore it exists for every real $x$ and adds no conditions. Hence the expression is defined for $x \leq 3$.

The condition $x + 1 \geq 0$ would concern a root of even index; adding it would give $-1 \leq x \leq 3$.
