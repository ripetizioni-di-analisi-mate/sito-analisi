We compare the powers $a^{5}$ and $a^{3}$ of the same base $a > 0$. For which values of $a$ does the inequality $a^{5} < a^{3}$ hold?

- $a > 1$
- $a \geq 1$
- $0 < a \leq 1$
- $0 < a < 1$

## Explanation

For $a = 1$ both powers equal $1$, so the strict inequality is false. With base $a > 1$ the power increases as the exponent increases, therefore $a^{5} > a^{3}$. With base $0 < a < 1$ the power decreases as the exponent increases, and since $5 > 3$ we have $a^{5} < a^{3}$.

Hence the inequality holds for $0 < a < 1$; for example $\left(\dfrac{1}{2}\right)^{5} = \dfrac{1}{32}$ is less than $\left(\dfrac{1}{2}\right)^{3} = \dfrac{1}{8}$.
