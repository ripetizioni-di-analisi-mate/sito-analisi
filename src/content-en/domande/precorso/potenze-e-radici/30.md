For which real $x$ does the equality $\sqrt{x^2} = x$ hold?

- $x \geq 0$
- For every real $x$
- $x > 0$
- $x \leq 0$

## Explanation

For every real $x$ we have $\sqrt{x^2} = |x|$, so the equality $\sqrt{x^2} = x$ is equivalent to $|x| = x$. The absolute value of $x$ coincides with $x$ exactly when $x \geq 0$, therefore the equality holds for $x \geq 0$. For $x = 0$ both sides equal $0$, so the endpoint is included.

For $x < 0$ the equality is false; for example $\sqrt{(-5)^2} = 5$, which is different from $-5$.
