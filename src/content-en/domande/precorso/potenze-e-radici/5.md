- $4 \leq x \leq 10$
- $4 \leq x < 10$
- $4 < x < 10$
- $4 < x \leq 10$

## Explanation

The root $\sqrt{x - 4}$ has an even index, so it exists for $x - 4 \geq 0$. The root $\sqrt{10 - x}$ is in the denominator, therefore it must exist and be different from zero, and this requires $10 - x > 0$ with the strict inequality. The two conditions must be satisfied simultaneously, so they are combined in a system
$$
\begin{cases}
x - 4 \geq 0 \\
10 - x > 0
\end{cases}
\qquad\Longrightarrow\qquad 4 \leq x < 10 .
$$
The endpoint $4$ is included, because for $x = 4$ the first term equals $\sqrt{0} = 0$. The endpoint $10$ is excluded, because for $x = 10$ the denominator vanishes.
