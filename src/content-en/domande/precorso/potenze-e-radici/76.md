The numbers $\sqrt[3]{16}$, $2^{\sqrt{2}}$ and $2\sqrt{2}$ can be written as powers with base $2$. In which order are they, from smallest to largest?

- $2^{\sqrt{2}} < \sqrt[3]{16} < 2\sqrt{2}$
- $2\sqrt{2} < 2^{\sqrt{2}} < \sqrt[3]{16}$
- $\sqrt[3]{16} < 2\sqrt{2} < 2^{\sqrt{2}}$
- $\sqrt[3]{16} < 2^{\sqrt{2}} < 2\sqrt{2}$

## Explanation

Since $16 = 2^{4}$, by the definition of a power with rational exponent $\sqrt[3]{16} = 2^{\frac{4}{3}}$. By the product of powers with the same base $2\sqrt{2} = 2^{1} \cdot 2^{\frac{1}{2}} = 2^{\frac{3}{2}}$. The base $2$ is greater than $1$, so the power increases as the exponent increases, and the three numbers are in the same order as the exponents $\dfrac{4}{3}$, $\sqrt{2}$ and $\dfrac{3}{2}$.

The exponents are positive, therefore they are in the same order as their squares
$$
\left(\frac{4}{3}\right)^{2} = \frac{16}{9}, \qquad \left(\sqrt{2}\right)^{2} = 2, \qquad \left(\frac{3}{2}\right)^{2} = \frac{9}{4} .
$$
Since $\dfrac{16}{9} < 2 < \dfrac{9}{4}$, we have $\dfrac{4}{3} < \sqrt{2} < \dfrac{3}{2}$, so $\sqrt[3]{16} < 2^{\sqrt{2}} < 2\sqrt{2}$.
