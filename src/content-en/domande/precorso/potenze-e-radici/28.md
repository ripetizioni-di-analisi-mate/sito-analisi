What is the value of $\sqrt{\sqrt[3]{64}}$?

- $4$
- $2$
- $8$
- $\sqrt[5]{64}$

## Explanation

By the property $\sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{a}$ the indices are multiplied, so $\sqrt{\sqrt[3]{64}} = \sqrt[6]{64}$. Since $64 = 2^6$, we have $\sqrt[6]{64} = 2$. The same result follows from computing first $\sqrt[3]{64} = 4$ and then $\sqrt{4} = 2$.

Adding the indices would give $\sqrt[5]{64}$, which is different from $2$, because $2^5 = 32$.
