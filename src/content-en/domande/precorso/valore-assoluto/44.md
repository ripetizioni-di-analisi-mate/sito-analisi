What are the solutions of the equation $|2x - 4| = |x| + 1$?

- $x = 1$
- $x = 1 \ \vee \ x = 5$
- $x = 3 \ \vee \ x = 5$
- $x = 1 \ \vee \ x = 3 \ \vee \ x = 5$

## Explanation

The arguments $2x - 4$ and $x$ vanish at $2$ and at $0$, so there are three regions:
$$
\begin{cases}
x < 0 \\
4 - 2x = -x + 1
\end{cases}
\ \cup \
\begin{cases}
0 \leq x < 2 \\
4 - 2x = x + 1
\end{cases}
\ \cup \
\begin{cases}
x \geq 2 \\
2x - 4 = x + 1
\end{cases}
$$
In the first region we obtain $x = 3$, which does not satisfy $x < 0$ and is discarded. In the second we obtain $3x = 3$, that is, $x = 1$, which is acceptable since $0 \leq 1 < 2$. In the third we obtain $x = 5$, which is acceptable since $5 \geq 2$. The solutions are therefore $x = 1$ and $x = 5$.
