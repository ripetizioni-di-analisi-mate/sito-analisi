The real numbers $a$ and $b$ satisfy $|a| = 3$ and $|b| = 5$. Which values can $|a + b|$ take?

- Only $8$
- Only $2$
- Every number between $2$ and $8$
- $2$ or $8$

## Explanation

From $|a| = 3$ it follows that $a = 3$ or $a = -3$, and from $|b| = 5$ it follows that $b = 5$ or $b = -5$. If $a$ and $b$ have the same sign, then $|a + b| = 3 + 5 = 8$; if they have opposite signs, then $|a + b| = 5 - 3 = 2$. Therefore $|a + b|$ equals $2$ or $8$. The value $8 = |a| + |b|$ is the equality case of the **triangle inequality**, which occurs if and only if $ab \geq 0$.
