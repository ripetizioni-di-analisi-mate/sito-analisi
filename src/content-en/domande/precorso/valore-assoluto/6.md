In $|2x-5|=x+1$ a student proposes dividing both sides by $x+1$. What check is needed before dividing to avoid losing a solution?

- Exclude $x=1$ because it makes the divisor zero.
- Include $x=-1$ because the right side vanishes.
- Substitute $x=-1$. The left side is $7$, so division is valid for every solution.
- Discard every $x$ for which the argument $2x-5$ is negative from the start.

## Explanation

The divisor vanishes only at $x=-1$. There the equation would read $7=0$, which is false. Consequently every possible solution has a nonzero divisor.
