For which real numbers $x$ does $|\sqrt{x} - 2| = 1$ hold?

- $x = 9$
- $x = 1$
- $x = 1 \ \vee \ x = 9$
- $x = 1 \ \vee \ x = 3$

## Explanation

The square root is defined for $x \geq 0$. Since $1 > 0$, the equation is equivalent to $\sqrt{x} - 2 = 1 \ \vee \ \sqrt{x} - 2 = -1$, that is, to $\sqrt{x} = 3 \ \vee \ \sqrt{x} = 1$. Since both sides of each equation are not negative, squaring gives $x = 9$ from the first and $x = 1$ from the second. Both values satisfy $x \geq 0$, so the solutions are $x = 1$ and $x = 9$.
