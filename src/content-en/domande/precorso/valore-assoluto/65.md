What is the complete list of real numbers satisfying $|x| = x^2 - 2$?

- $x = 2$
- $x = -2 \ \vee \ x = -1 \ \vee \ x = 1 \ \vee \ x = 2$
- $x = -1 \ \vee \ x = 2$
- $x = -2 \ \vee \ x = 2$

## Explanation

The equation has the form $|A| = B$ with $B = x^2 - 2$, so it requires the condition $x^2 - 2 \geq 0$. The case $x = x^2 - 2$ gives $x^2 - x - 2 = 0$, that is, $(x - 2)(x + 1) = 0$, so $x = 2$ or $x = -1$. The case $x = -(x^2 - 2)$ gives $x^2 + x - 2 = 0$, that is, $(x + 2)(x - 1) = 0$, so $x = -2$ or $x = 1$. At $x = \pm 2$ we have $x^2 - 2 = 2 \geq 0$, while at $x = \pm 1$ we have $x^2 - 2 = -1 < 0$, therefore the solutions are $x = -2$ and $x = 2$.
