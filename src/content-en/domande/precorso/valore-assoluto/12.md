- $x \leq -3$
- $x \leq -3 \ \vee \ x \geq 5$
- $x < -3 \ \vee \ x > 5$
- $-3 \leq x \leq 5$

## Explanation

The arguments $x + 2$ and $x - 4$ vanish at $-2$ and at $4$, so the real line is divided into three regions:
$$
\begin{cases}
x < -2 \\
-2x + 2 \geq 8
\end{cases}
\ \cup \
\begin{cases}
-2 \leq x < 4 \\
6 \geq 8
\end{cases}
\ \cup \
\begin{cases}
x \geq 4 \\
2x - 2 \geq 8
\end{cases}
$$
In the first region we obtain $x \leq -3$, which satisfies $x < -2$. In the middle region the inequality $6 \geq 8$ is false, so there are no solutions. In the third region we obtain $x \geq 5$, which satisfies $x \geq 4$. The solutions are therefore $x \leq -3 \ \vee \ x \geq 5$, with the endpoints included because the inequality is non-strict.
