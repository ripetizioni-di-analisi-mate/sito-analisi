A real number has distance from the number $1$ equal to twice its distance from the number $-1$. What are all the numbers with this property?

- $x = -3$
- $x = -3 \ \vee \ x = 1$
- $x = -3 \ \vee \ x = -\dfrac{1}{3}$
- $x = \dfrac{1}{3} \ \vee \ x = 3$

## Explanation

The distance of $x$ from $1$ is $|x - 1|$ and the distance of $x$ from $-1$ is $|x + 1|$, so the condition is $|x - 1| = 2\,|x + 1| = |2x + 2|$. By the rule $|A| = |B| \iff A = B \ \vee \ A = -B$ we get $x - 1 = 2x + 2 \ \vee \ x - 1 = -2x - 2$. The first gives $x = -3$, the second gives $3x = -1$, that is, $x = -\dfrac{1}{3}$. For example, $x = -3$ is at distance $4$ from $1$ and at distance $2$ from $-1$.
