- $1 \leq x \leq 3$
- $-3 \leq x \leq -1 \ \vee \ 1 \leq x \leq 3$
- $-3 \leq x \leq 3$
- $-3 < x < -1 \ \vee \ 1 < x < 3$

## Explanation

Since $4 > 0$, the inequality is equivalent to $-4 \leq x^2 - 5 \leq 4$, that is, to $1 \leq x^2 \leq 9$. The two conditions must be satisfied simultaneously:
$$
\begin{cases}
x^2 \geq 1 \\
x^2 \leq 9
\end{cases}
\qquad
\begin{cases}
x \leq -1 \ \vee \ x \geq 1 \\
-3 \leq x \leq 3
\end{cases}
$$
The intersection is $-3 \leq x \leq -1 \ \vee \ 1 \leq x \leq 3$. The endpoints are included, because the inequality is non-strict and at $x = \pm 1$ and $x = \pm 3$ the left-hand side equals exactly $4$.
