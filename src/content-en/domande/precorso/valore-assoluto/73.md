A real number $x$ must satisfy both $|x - 1| < 2$ and $|x + 1| < 2$. For which $x$ does this happen?

- $-3 < x < 3$
- $-1 < x < 1$
- $-1 < x < 3$
- $-3 < x < 1$

## Explanation

The first inequality is equivalent to $-2 < x - 1 < 2$, that is, $-1 < x < 3$. The second is equivalent to $-2 < x + 1 < 2$, that is, $-3 < x < 1$. The two conditions must hold together:
$$
\begin{cases}
-1 < x < 3 \\
-3 < x < 1
\end{cases}
$$
Therefore the solutions are $-1 < x < 1$, that is, the numbers at distance less than $2$ both from $1$ and from $-1$.
