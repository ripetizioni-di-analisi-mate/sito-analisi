Among the real numbers $x$, which satisfy $|x| + |x + 1| = |2x + 1|$?

- $x \geq 0$
- $x \leq -1 \ \vee \ x \geq 0$
- $x = -1 \ \vee \ x = 0$
- $x < -1 \ \vee \ x > 0$

## Explanation

The arguments vanish at $-1$, at $-\dfrac{1}{2}$ and at $0$, so there are four intervals. For $x < -1$ the three arguments are negative and the equation becomes $-x - (x + 1) = -(2x + 1)$, that is, $-2x - 1 = -2x - 1$, which is true for every $x$ in the interval. For $-1 \leq x < -\dfrac{1}{2}$ it becomes $-x + (x + 1) = -(2x + 1)$, that is, $1 = -2x - 1$, which gives $x = -1$, acceptable. For $-\dfrac{1}{2} \leq x < 0$ it becomes $-x + (x + 1) = 2x + 1$, which gives $x = 0$, outside the interval. For $x \geq 0$ it becomes $x + (x + 1) = 2x + 1$, which is true for every $x$ in the interval. The solutions are therefore $x \leq -1 \ \vee \ x \geq 0$, that is, the values for which $x$ and $x + 1$ do not have opposite signs, as in the equality case of the triangle inequality.
