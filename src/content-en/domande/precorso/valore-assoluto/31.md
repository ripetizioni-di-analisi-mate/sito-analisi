What are the solutions of the inequality $|3x + 2| \leq 4$?

- $-2 \leq x \leq \dfrac{2}{3}$
- $-\dfrac{2}{3} \leq x \leq 2$
- $x \leq -2 \ \vee \ x \geq \dfrac{2}{3}$
- $-2 < x < \dfrac{2}{3}$

## Explanation

Since $4 > 0$, the inequality is equivalent to the double inequality $-4 \leq 3x + 2 \leq 4$. Subtracting $2$ from all members gives $-6 \leq 3x \leq 2$. Dividing by $3$, which is positive, leaves the inequality signs unchanged, so $-2 \leq x \leq \dfrac{2}{3}$. The endpoints are included because the inequality is non-strict.
