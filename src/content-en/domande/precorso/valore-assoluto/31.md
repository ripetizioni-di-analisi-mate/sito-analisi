The inequality $x^2 < 9$ can be written with an absolute value. Which of the following inequalities has the same solutions?

- $|x| < 3$
- $x < 3$
- $|x| > 3$
- $|x| < 9$

## Explanation

By the property $|a|^2 = a^2$ we have $x^2 = |x|^2$, so the inequality can be written $|x|^2 < 3^2$. Since $|x|$ and $3$ are not negative, squaring preserves the direction of the inequality, therefore $|x|^2 < 3^2$ is equivalent to $|x| < 3$. The solutions are thus $-3 < x < 3$. The inequality $x < 3$ is also satisfied by $x = -4$, for which instead $x^2 = 16 > 9$.
