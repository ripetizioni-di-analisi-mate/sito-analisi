What is the solution set of $|x - 3| + |3 - x| = 8$?

- $x = -1 \ \vee \ x = 7$
- The equation has no solutions
- $x = 7$
- $x = -5 \ \vee \ x = 11$

## Explanation

The numbers $x - 3$ and $3 - x$ are opposites, because $3 - x = -(x - 3)$, so they have the same absolute value. The equation therefore becomes $2\,|x - 3| = 8$, that is, $|x - 3| = 4$. Since $4 > 0$, this is equivalent to $x - 3 = 4 \ \vee \ x - 3 = -4$, so $x = 7$ or $x = -1$. The solutions are the points at distance $4$ from $3$.
