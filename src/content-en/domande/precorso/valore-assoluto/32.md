What are the solutions of the inequality $|1 - 2x| < 3$?

- $-2 < x < 1$
- $x < -1 \ \vee \ x > 2$
- $-1 \leq x \leq 2$
- $-1 < x < 2$

## Explanation

Since $3 > 0$, the inequality is equivalent to the double inequality $-3 < 1 - 2x < 3$. Subtracting $1$ from all parts of the inequality gives $-4 < -2x < 2$. Dividing by $-2$, which is negative, reverses the inequality signs, so $2 > x > -1$, that is, $-1 < x < 2$. The endpoints are excluded because the inequality is strict.
