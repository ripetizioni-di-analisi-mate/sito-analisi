The equation $\bigl|\,|x| - 3\,\bigr| = 1$ contains an absolute value inside another one. What are all its solutions?

- $x = 2 \ \vee \ x = 4$
- $x = -4 \ \vee \ x = 4$
- $x = -2 \ \vee \ x = 2$
- $x = -4 \ \vee \ x = -2 \ \vee \ x = 2 \ \vee \ x = 4$

## Explanation

Since $1 > 0$, the equation is equivalent to $|x| - 3 = 1 \ \vee \ |x| - 3 = -1$, that is, $|x| = 4 \ \vee \ |x| = 2$. The equation $|x| = 4$ has the solutions $x = \pm 4$, and the equation $|x| = 2$ has the solutions $x = \pm 2$. Therefore the given equation has the four solutions $x = -4$, $x = -2$, $x = 2$ and $x = 4$.
