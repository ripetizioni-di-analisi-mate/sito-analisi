With the variable right-hand side $x + 4$, which solutions does the equation $|x - 1| + |x + 1| = x + 4$ have?

- $x = -\dfrac{4}{3} \ \vee \ x = 4$
- $x = -2 \ \vee \ x = -\dfrac{4}{3} \ \vee \ x = 4$
- $x = 4$
- $x = -1 \ \vee \ x = 1$

## Explanation

The arguments vanish at $-1$ and at $1$. For $x < -1$ the equation becomes $(1 - x) + (-x - 1) = x + 4$, that is, $-2x = x + 4$, so $x = -\dfrac{4}{3}$, which is less than $-1$ and is accepted. For $-1 \leq x < 1$ it becomes $(1 - x) + (x + 1) = x + 4$, that is, $2 = x + 4$, so $x = -2$, which does not belong to the interval and is discarded. For $x \geq 1$ it becomes $(x - 1) + (x + 1) = x + 4$, that is, $2x = x + 4$, so $x = 4$, which is accepted. The solutions are therefore $x = -\dfrac{4}{3}$ and $x = 4$.
