Solving $\dfrac{1}{|x - 3|} > 2$, which solution set is obtained?

- $\dfrac{5}{2} < x < \dfrac{7}{2}$
- $x < \dfrac{5}{2} \ \vee \ x > \dfrac{7}{2}$
- $-\dfrac{7}{2} < x < -3 \ \vee \ -3 < x < -\dfrac{5}{2}$
- $\dfrac{5}{2} < x < 3 \ \vee \ 3 < x < \dfrac{7}{2}$

## Explanation

The fraction is defined for $x \neq 3$, and for these values $|x - 3| > 0$. Multiplying both sides by the positive number $|x - 3|$ does not change the direction, so the inequality is equivalent to $1 > 2\,|x - 3|$, that is, $|x - 3| < \dfrac{1}{2}$. This is equivalent to $-\dfrac{1}{2} < x - 3 < \dfrac{1}{2}$, therefore $\dfrac{5}{2} < x < \dfrac{7}{2}$. Removing the value $x = 3$, excluded by the existence condition, we get $\dfrac{5}{2} < x < 3 \ \vee \ 3 < x < \dfrac{7}{2}$.
