To solve an equation containing $|x + 1| + |x - 2| + |x - 5|$, the real line is divided into intervals by the points where the arguments vanish. How many intervals are there?

- $4$
- $3$
- $8$
- $6$

## Explanation

The arguments $x + 1$, $x - 2$ and $x - 5$ vanish at $x = -1$, $x = 2$ and $x = 5$ respectively. Three distinct points divide the line into **four** intervals, namely $x < -1$, $-1 \leq x < 2$, $2 \leq x < 5$ and $x \geq 5$. In each interval every argument has constant sign, so every absolute value can be rewritten without bars.
