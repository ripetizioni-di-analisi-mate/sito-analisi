The parameter $a$ is a real number. When does the equation $|x - a| = |x - 1|$ have exactly one solution?

- Only for $a = 1$
- For every $a \in \mathbb{R}$
- For no value of $a$
- For every $a \neq 1$

## Explanation

The equation is equivalent to $x - a = x - 1 \ \vee \ x - a = -(x - 1)$. The first case reduces to the equality $a = 1$, which does not contain $x$, so for $a = 1$ every $x$ satisfies it and for $a \neq 1$ it gives no solutions. The second case gives $2x = a + 1$, that is, $x = \dfrac{a + 1}{2}$, the midpoint between $a$ and $1$. Therefore for $a \neq 1$ the equation has the single solution $x = \dfrac{a + 1}{2}$, while for $a = 1$ every real $x$ is a solution.
