Which real number is at distance $2$ from the number $1$ and at distance $6$ from the number $-3$?

- $-1$
- $-9$
- $3$
- No real number

## Explanation

The first requirement is $|x - 1| = 2$, which is equivalent to $x - 1 = 2 \ \vee \ x - 1 = -2$, so $x = 3$ or $x = -1$. The second is $|x + 3| = 6$, which is equivalent to $x + 3 = 6 \ \vee \ x + 3 = -6$, so $x = 3$ or $x = -9$. The required number must satisfy both equations, therefore it is $x = 3$. The number $-1$ is at distance $2$ from $1$, but it is at distance $2$ from $-3$.
