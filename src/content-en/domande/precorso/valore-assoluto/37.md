What is the domain of the function $f(x) = \sqrt{3 - |x - 1|}$?

- $x \geq -2$
- $x \leq -2 \ \vee \ x \geq 4$
- $-4 \leq x \leq 2$
- $-2 \leq x \leq 4$

## Explanation

The square root is defined when the radicand is not negative, so the domain is given by $3 - |x - 1| \geq 0$, that is, $|x - 1| \leq 3$. Since $3 > 0$, this inequality is equivalent to $-3 \leq x - 1 \leq 3$, therefore $-2 \leq x \leq 4$. The endpoints belong to the domain, because at $x = -2$ and at $x = 4$ the radicand equals $0$.
