Which real numbers $x$ satisfy the double inequality $2 \leq |x - 1| \leq 5$?

- $-4 \leq x \leq -1 \ \vee \ 3 \leq x \leq 6$
- $-4 \leq x \leq 6$
- $x \leq -1 \ \vee \ x \geq 3$
- $-4 < x < -1 \ \vee \ 3 < x < 6$

## Explanation

The double inequality is equivalent to the system
$$
\begin{cases}
|x - 1| \geq 2 \\
|x - 1| \leq 5
\end{cases}
$$
Since $2 > 0$, the first condition is equivalent to $x - 1 \leq -2 \ \vee \ x - 1 \geq 2$, that is, to $x \leq -1 \ \vee \ x \geq 3$. Since $5 > 0$, the second is equivalent to $-5 \leq x - 1 \leq 5$, that is, to $-4 \leq x \leq 6$. The two conditions must hold together, so the solutions are $-4 \leq x \leq -1 \ \vee \ 3 \leq x \leq 6$, with the endpoints included because the inequalities are non-strict. They are the points whose distance from $1$ is between $2$ and $5$.
