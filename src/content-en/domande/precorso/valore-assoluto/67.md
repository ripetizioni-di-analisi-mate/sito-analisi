Which of the following statements is the equation $|x^2 - 3| = |2x - 1|$ equivalent to?

- $x^2 - 3 = 2x - 1 \ \vee \ x^2 - 3 = -2x - 1$
- $x^2 - 3 = 2x - 1$
- $x^2 - 3 = 2x - 1 \ \vee \ x^2 - 3 = -2x + 1$
- $x^2 - 3 = 2x - 1 \ \vee \ -x^2 + 3 = -2x + 1$

## Explanation

Two numbers have the same absolute value if and only if they are equal or opposite, so $|A| = |B| \iff A = B \ \vee \ A = -B$. With $A = x^2 - 3$ and $B = 2x - 1$ we have $-B = -2x + 1$, because the opposite changes the sign of both terms of $B$. Therefore the equation is equivalent to $x^2 - 3 = 2x - 1 \ \vee \ x^2 - 3 = -2x + 1$. The equality $-x^2 + 3 = -2x + 1$ is obtained from $x^2 - 3 = 2x - 1$ by changing the sign of both sides, so the pair containing it expresses only one case.
