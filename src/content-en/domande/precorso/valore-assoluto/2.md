Two solutions were found for $|5-2x|=1$. When the restriction $5-2x\leq 0$ is added, which one remains, and why?

- $x=2$, because the argument is $1$.
- Both, because the absolute value is positive.
- Neither, because the argument would have to be zero.
- $x=3$, because the argument is $-1$.

## Explanation

The restriction selects the branch where $|5-2x|=2x-5$. This gives $2x-5=1$, hence $x=3$. At $x=2$ the argument is positive, violating the added restriction.
