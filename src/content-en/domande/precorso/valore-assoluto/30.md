The number $x = 5$ is a solution of only one of the following equations. Which one?

- $|x - 8| = 2 - x$
- $|x - 8| = x - 8$
- $|x + 8| = x - 2$
- $|x - 8| = x - 2$

## Explanation

At $x = 5$ we have $|5 - 8| = 3$, and the right-hand side $x - 2$ equals $5 - 2 = 3$, so $x = 5$ is a solution of $|x - 8| = x - 2$. The right-hand sides $2 - x$ and $x - 8$ instead equal $-3$, and an absolute value is never equal to a negative number, therefore $x = 5$ is a solution neither of $|x - 8| = 2 - x$ nor of $|x - 8| = x - 8$. The value $x = 5$ comes from the case $x - 8 = 2 - x$ of the first of these two equations, but it does not satisfy the condition $2 - x \geq 0$. Finally, at $x = 5$ the equation $|x + 8| = x - 2$ becomes $13 = 3$, which is false.
