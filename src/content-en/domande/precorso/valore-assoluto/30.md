For the equation $|x + 1| = 3x - 5$, the two equations $x + 1 = 3x - 5$ and $x + 1 = -(3x - 5)$ give $x = 3$ and $x = 1$ respectively. Which statement is true?

- Both $x = 3$ and $x = 1$ are solutions
- Only $x = 3$ is a solution
- Only $x = 1$ is a solution
- Neither value is a solution

## Explanation

The left-hand side is never negative, so a solution must satisfy the condition $3x - 5 \geq 0$, that is, $x \geq \dfrac{5}{3}$. The value $x = 3$ satisfies it, and indeed $|3 + 1| = 4 = 3 \cdot 3 - 5$. The value $x = 1$ does not satisfy it, because $3 \cdot 1 - 5 = -2 < 0$, while $|1 + 1| = 2$. Therefore $x = 1$ is discarded and the only solution is $x = 3$.
