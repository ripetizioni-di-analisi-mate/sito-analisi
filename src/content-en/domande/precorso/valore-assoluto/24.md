What are the solutions of the equation $|3x - 2| = |x + 6|$?

- $x = 4$
- $x = -1 \ \vee \ x = 4$
- $x = 2 \ \vee \ x = 4$
- $x = 1 \ \vee \ x = 4$

## Explanation

Two numbers have the same absolute value when they are equal or opposite, so the equation is equivalent to $3x - 2 = x + 6 \ \vee \ 3x - 2 = -(x + 6)$. The first gives $2x = 8$, that is, $x = 4$. In the second the right-hand side equals $-x - 6$, therefore $4x = -4$ and $x = -1$. Both values are solutions, because the two sides are absolute values and the equation requires no sign conditions.
