For $x < -2$, which expression is equal to $|x + 2| + |x - 1|$?

- $2x + 1$
- $-2x - 1$
- $3$
- $-3$

## Explanation

For $x < -2$ we have $x + 2 < 0$, so by the definition of absolute value $|x + 2| = -(x + 2) = -x - 2$. On the same interval $x - 1 < 0$ also holds, because $x < -2 < 1$, therefore $|x - 1| = -(x - 1) = 1 - x$. Adding the two expressions gives $(-x - 2) + (1 - x) = -2x - 1$.
