For real $x$, when does $|x^3| < x$ hold?

- $x < -1 \ \vee \ 0 < x < 1$
- $-1 < x < 1$
- $0 < x < 1$
- $0 \leq x \leq 1$

## Explanation

The inequality $|A| < B$ is equivalent to the system of the two conditions $A < B$ and $A > -B$:
$$
\begin{cases}
x^3 < x \\
x^3 > -x
\end{cases}
\qquad
\begin{cases}
x(x - 1)(x + 1) < 0 \\
x(x^2 + 1) > 0
\end{cases}
$$
The first condition is satisfied for $x < -1$ and for $0 < x < 1$. In the second the factor $x^2 + 1$ is positive, so the condition is equivalent to $x > 0$. The two conditions must hold together, therefore the solutions are $0 < x < 1$.
