Which values of $x$ satisfy the equation $x - |x - 4| = 2$?

- The equation has no solutions
- $x = -1$
- $x = 3$
- $x = 3 \ \vee \ x = 4$

## Explanation

The equation can be rewritten as $|x - 4| = x - 2$, which has the form $|A| = B$ and requires the condition $x - 2 \geq 0$, that is, $x \geq 2$. The case $x - 4 = x - 2$ reduces to $-4 = -2$, which is false. The case $x - 4 = -(x - 2)$ gives $2x = 6$, so $x = 3$, which satisfies $x \geq 2$. Hence the only solution is $x = 3$, and indeed $3 - |3 - 4| = 3 - 1 = 2$.
