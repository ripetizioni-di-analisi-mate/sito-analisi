Solving the equation $|x| + |x - 1| + |x - 2| = 4$ interval by interval, what is the complete solution set?

- $x = -1 \ \vee \ x = -\dfrac{1}{3} \ \vee \ x = \dfrac{7}{3} \ \vee \ x = 3$
- $x = \dfrac{7}{3}$
- $x = 0 \ \vee \ x = 1 \ \vee \ x = 2$
- $x = -\dfrac{1}{3} \ \vee \ x = \dfrac{7}{3}$

## Explanation

The arguments vanish at $0$, $1$ and $2$, so there are four intervals. For $x < 0$ the equation becomes $3 - 3x = 4$, so $x = -\dfrac{1}{3}$, which belongs to the interval. For $0 \leq x < 1$ it becomes $3 - x = 4$, so $x = -1$, outside the interval. For $1 \leq x < 2$ it becomes $x + 1 = 4$, so $x = 3$, outside the interval. For $x \geq 2$ it becomes $3x - 3 = 4$, so $x = \dfrac{7}{3}$, which belongs to the interval. Therefore the solutions are $x = -\dfrac{1}{3}$ and $x = \dfrac{7}{3}$.
