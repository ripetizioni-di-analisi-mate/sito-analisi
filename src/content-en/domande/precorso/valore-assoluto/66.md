The equality $|2x - 6| = |6 - 2x|$ holds for which real numbers $x$?

- Only for $x = 3$
- For no $x \in \mathbb{R}$
- For every $x \in \mathbb{R}$
- Only for $x \geq 3$

## Explanation

The expressions $2x - 6$ and $6 - 2x$ are opposite, because $6 - 2x = -(2x - 6)$. Two opposite numbers have the same absolute value, so the equality holds for every $x \in \mathbb{R}$. The rule $|A| = |B| \iff A = B \ \vee \ A = -B$ leads to the same conclusion, because the case $2x - 6 = -(6 - 2x)$ reduces to $2x - 6 = 2x - 6$, which is true for every $x$.
