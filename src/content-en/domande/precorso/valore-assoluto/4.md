- $x = -3 \ \vee \ x = 1$
- $x = -3$
- $x = -3 \ \vee \ x = \dfrac{3}{2}$
- $x = 1 \ \vee \ x = 3$

## Explanation

Two numbers have the same absolute value when they are equal or opposite, so the equation is equivalent to
$$
x - 5 = 3x + 1 \ \vee \ x - 5 = -(3x + 1) .
$$
The first gives $-2x = 6$, that is, $x = -3$. In the second the right-hand side equals $-3x - 1$, therefore $4x = 4$ and $x = 1$. No additional condition is needed, because both sides are absolute values and are never negative.
