- $x = 3$
- $x = -1 \ \vee \ x = 3$
- $x = -1$
- $x = 1 \ \vee \ x = 3$

## Explanation

The left-hand side is never negative, so the equation requires the condition $2x \geq 0$, that is, $x \geq 0$:
$$
\begin{cases}
x \geq 0 \\
x + 3 = 2x
\end{cases}
\ \cup \
\begin{cases}
x \geq 0 \\
x + 3 = -2x
\end{cases}
$$
The first system gives $x = 3$, which satisfies the condition. The second gives $3x = -3$, that is, $x = -1$, which does not satisfy the condition $x \geq 0$ and is **discarded**. The only solution is therefore $x = 3$.
