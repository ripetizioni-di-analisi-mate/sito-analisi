Given the inequalities $|x - 7| < 0$ and $|x - 7| \leq 0$, which statement is true?

- Neither inequality has solutions
- The first has no solutions, the second has the single solution $x = 7$
- Both have the single solution $x = 7$
- The first is solved by every $x \neq 7$, the second has no solutions

## Explanation

An absolute value is always greater than or equal to $0$, so $|x - 7| < 0$ is satisfied by no $x$ and the first inequality **has no solutions**. In the second, since $|x - 7|$ cannot be negative, the only possibility left is $|x - 7| = 0$. This is equivalent to $x - 7 = 0$, so the second inequality has the single solution $x = 7$.
