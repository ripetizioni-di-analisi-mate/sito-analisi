In the equation $|x^2 + 4| = 5x$ the unknown is $x \in \mathbb{R}$. What are all its solutions?

- $x = -4 \ \vee \ x = -1 \ \vee \ x = 1 \ \vee \ x = 4$
- $x = -4 \ \vee \ x = -1$
- $x = 4$
- $x = 1 \ \vee \ x = 4$

## Explanation

Since $x^2 + 4 > 0$ for every $x$, by the definition of absolute value we have $|x^2 + 4| = x^2 + 4$. The equation becomes $x^2 - 5x + 4 = 0$, that is, $(x - 1)(x - 4) = 0$, with solutions $x = 1$ and $x = 4$. The equation $x^2 + 4 = -5x$ would have the solutions $x = -1$ and $x = -4$, but at these points the right-hand side $5x$ is negative, so they are not solutions.
