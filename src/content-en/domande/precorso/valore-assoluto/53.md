Let $a$ and $b$ be two real numbers with $a < 0 < b$. Which expression is equal to $|a - b| + |a| - |b|$?

- $-2a$
- $-2b$
- $2a - 2b$
- $0$

## Explanation

Since $a < b$, we have $a - b < 0$, so $|a - b| = b - a$. Since $a < 0$, we have $|a| = -a$, and since $b > 0$, we have $|b| = b$. Substituting gives $(b - a) + (-a) - b = -2a$. For example, with $a = -1$ and $b = 2$ the expression equals $|-3| + 1 - 2 = 2$, which agrees with $-2a$.
