All the real solutions of $|x^2 - 4| = 3\,|x|$ are given by which list?

- $x = -1 \ \vee \ x = 4$
- $x = -4 \ \vee \ x = -1 \ \vee \ x = 1 \ \vee \ x = 4$
- $x = -2 \ \vee \ x = 0 \ \vee \ x = 2$
- $x = 1 \ \vee \ x = 4$

## Explanation

Since $3\,|x| = |3x|$, the equation has the form $|A| = |B|$ and is equivalent to $x^2 - 4 = 3x \ \vee \ x^2 - 4 = -3x$. The first becomes $x^2 - 3x - 4 = 0$, that is, $(x - 4)(x + 1) = 0$, with solutions $x = 4$ and $x = -1$. The second becomes $x^2 + 3x - 4 = 0$, that is, $(x + 4)(x - 1) = 0$, with solutions $x = -4$ and $x = 1$. Therefore the solutions are $x = -4$, $x = -1$, $x = 1$ and $x = 4$.
