Given the equations $|x + 4| = -3$ and $|7x - 21| = 0$, which statement is true?

- Neither equation has solutions
- The first has solutions $x = -7$ and $x = -1$, the second has solution $x = 3$
- The first has no solutions, the second has solution $x = 3$
- The first has no solutions, the second has solution $x = -3$

## Explanation

The absolute value of a real number is always greater than or equal to $0$, so $|x + 4|$ cannot equal $-3$ for any $x$. Therefore the first equation **has no solutions**.

The only number with absolute value zero is $0$, so $|7x - 21| = 0$ is equivalent to $7x - 21 = 0$. It follows that $7x = 21$, that is, $x = 3$.
