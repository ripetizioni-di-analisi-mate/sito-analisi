What are the solutions of the inequality $|x^2 - 5x| > 6$?

- $x < -1 \ \vee \ x > 6$
- $2 < x < 3$
- $-1 < x < 2 \ \vee \ 3 < x < 6$
- $x < -1 \ \vee \ 2 < x < 3 \ \vee \ x > 6$

## Explanation

Since $6 > 0$, the inequality is equivalent to $x^2 - 5x < -6 \ \vee \ x^2 - 5x > 6$. The first is written $x^2 - 5x + 6 < 0$, that is, $(x - 2)(x - 3) < 0$, and is satisfied for $2 < x < 3$. The second is written $x^2 - 5x - 6 > 0$, that is, $(x - 6)(x + 1) > 0$, and is satisfied for $x < -1$ and for $x > 6$. The solutions are therefore the **union** of the three intervals, $x < -1 \ \vee \ 2 < x < 3 \ \vee \ x > 6$.
