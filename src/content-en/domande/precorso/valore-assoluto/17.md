With $a = 4$, for which value of $b$ does the equality $|a + b| = |a| + |b|$ hold?

- $b = 3$
- $b = -1$
- $b = -4$
- $b = -7$

## Explanation

In the **triangle inequality** $|a + b| \leq |a| + |b|$, equality holds if and only if $ab \geq 0$. With $a = 4$ the condition becomes $4b \geq 0$, that is, $b \geq 0$, and among the proposed values only $b = 3$ satisfies it. Indeed $|4 + 3| = 7 = |4| + |3|$. For $b = -1$, instead, $|4 - 1| = 3$, while $|4| + |-1| = 5$.
