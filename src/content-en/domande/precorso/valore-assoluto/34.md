What are the solutions of the inequality $|x^2 - 1| < 3$?

- $x < -2 \ \vee \ x > 2$
- $-2 < x < -\sqrt{2} \ \vee \ \sqrt{2} < x < 2$
- $-2 < x < 2$
- $-2 < x < -1 \ \vee \ 1 < x < 2$

## Explanation

Since $3 > 0$, the inequality is equivalent to $-3 < x^2 - 1 < 3$, that is, to the system
$$
\begin{cases}
x^2 > -2 \\
x^2 < 4
\end{cases}
$$
The first condition is satisfied by every real $x$, because a square is never negative. The second is equivalent to $-2 < x < 2$. The solutions are therefore $-2 < x < 2$.
