Consider the equation $|x + 2| + |x - 3| = k$, with $k$ a real parameter. When does it have exactly two solutions?

- For $k \geq 5$
- For $k > 5$
- For $k = 5$
- For $k > 0$

## Explanation

We study $f(x) = |x + 2| + |x - 3|$ interval by interval. For $x < -2$ we have $f(x) = 1 - 2x$, which takes every value greater than $5$ exactly once. For $-2 \leq x \leq 3$ we have $f(x) = 5$. For $x > 3$ we have $f(x) = 2x - 1$, which also takes every value greater than $5$ exactly once. Hence for $k > 5$ the equation has one solution in the first interval and one in the third, for $k = 5$ it has infinitely many and for $k < 5$ it has none.
