Which expression gives the distance on the real line between the number $x$ and the number $-5$?

- $|x - 5|$
- $x + 5$
- $|x + 5|$
- $|x| + 5$

## Explanation

The distance between two numbers $x$ and $c$ is $|x - c|$, so with $c = -5$ we get $|x - (-5)| = |x + 5|$. The absolute value is needed because a distance is never negative; for example, for $x = -8$ we have $|-8 + 5| = 3$, while $x + 5 = -3$. For the same $x = -8$ the expression $|x| + 5$ equals $13$, so it does not give the distance.
