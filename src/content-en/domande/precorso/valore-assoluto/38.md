The solution set of $|x^2 - x| < x$ is equal to which of the following?

- $0 < x < 2$
- $x \neq 0$
- $0 \leq x < 2$
- $x > 0$

## Explanation

The inequality $|A| < B$ is equivalent to the system of the two conditions $A < B$ and $A > -B$:
$$
\begin{cases}
x^2 - x < x \\
x^2 - x > -x
\end{cases}
\qquad
\begin{cases}
x^2 - 2x < 0 \\
x^2 > 0
\end{cases}
$$
The first condition holds for $0 < x < 2$, because $x^2 - 2x = x(x - 2)$ is negative between its roots. The second holds for $x \neq 0$. The two conditions must hold together, so the solutions are $0 < x < 2$.
