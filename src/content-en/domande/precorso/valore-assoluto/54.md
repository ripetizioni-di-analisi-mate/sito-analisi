We want the equality $|x - m| = x - m$ to hold for every $x \geq 2$. Which values of the real parameter $m$ make this possible?

- $m \leq 2$
- $m \geq 2$
- $m > 2$
- Every $m \in \mathbb{R}$

## Explanation

By the definition of absolute value, the equality $|x - m| = x - m$ holds if and only if $x - m \geq 0$, that is, $x \geq m$. So every $x \geq 2$ must satisfy $x \geq m$. Since the smallest of the values considered is $x = 2$, this happens if and only if $2 \geq m$. Therefore the admissible values are $m \leq 2$, including $m = 2$, for which $|x - 2| = x - 2$ holds for every $x \geq 2$.
