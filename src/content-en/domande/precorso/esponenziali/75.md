Which values satisfy $\left(\dfrac{1}{2}\right)^{3 x} > \dfrac{1}{2}$?

- $\left(-\infty, \dfrac{1}{3}\right]$
- $\left(\dfrac{1}{3}, \infty\right)$
- $\left(-\infty, - \dfrac{1}{3}\right)$
- $\left(-\infty, \dfrac{1}{3}\right)$

## Explanation

For a positive base below $1$, the function is decreasing. The comparison is therefore equivalent to $3 x < 1$, giving $\left(-\infty, \dfrac{1}{3}\right)$.
