The figure shows the graph of a function $y = a^{x}$, with $a > 0$ and $a \neq 1$, passing through the point $P(-2, 9)$. What is the base $a$?

::grafico{f="3^(-x)" xmin=-3 xmax=3 ymin=-0.5 ymax=10 legenda=0 punti="-2,9,pieno,P" segmenti="-2,0,-2,9" titolo="The graph of $y = a^{x}$ passes through the point $P$"}

- $a = \dfrac{1}{3}$
- $a = 3$
- $a = \dfrac{1}{9}$
- $a = \dfrac{1}{81}$

## Explanation

The point $P(-2, 9)$ lies on the graph, so $a^{-2} = 9$. Since $a^{-2} = \dfrac{1}{a^{2}}$, we have $\dfrac{1}{a^{2}} = 9$, that is, $a^{2} = \dfrac{1}{9}$. The base is positive, therefore $a = \dfrac{1}{3}$. The result agrees with the figure, in which the function is decreasing.
