Where is the fraction $\dfrac{2^{x} - 4}{2^{x} - 1}$ negative or zero?

- $0 \leq x \leq 2$
- $1 < x \leq 4$
- $0 < x \leq 2$
- $x < 0$ or $x \geq 2$

## Explanation

With the substitution $t = 2^{x}$, $t > 0$, the inequality becomes $\dfrac{t - 4}{t - 1} \leq 0$, with $t \neq 1$. The numerator is positive for $t > 4$ and the denominator is positive for $t > 1$, so the fraction is negative for $1 < t < 4$ and zero for $t = 4$. The value $t = 1$ is excluded because it makes the denominator zero, therefore $1 < t \leq 4$. From $2^{0} < 2^{x} \leq 2^{2}$, since the base $2$ is greater than $1$, it follows that $0 < x \leq 2$.
