For which values of the real parameter $a$ is the function $f(x) = (a - 1)^{x}$ a strictly decreasing exponential function?

- $a < 2$
- $0 < a < 1$
- $a > 2$
- $1 < a < 2$

## Explanation

The exponential function $b^{x}$ is strictly decreasing when the base satisfies $0 < b < 1$. With $b = a - 1$ we therefore obtain the system
$$
\begin{cases}
a - 1 > 0 \\
a - 1 < 1
\end{cases}
$$
The first inequality gives $a > 1$ and the second gives $a < 2$, therefore the function is strictly decreasing for $1 < a < 2$.
