Which values satisfy $\left(\dfrac{1}{5}\right)^{5 x} > \dfrac{1}{25}$?

- $\left(-\infty, - \dfrac{2}{5}\right)$
- $\left(-\infty, \dfrac{2}{5}\right]$
- $\left(-\infty, \dfrac{2}{5}\right)$
- $\left(\dfrac{2}{5}, \infty\right)$

## Explanation

For a positive base below $1$, the function is decreasing. The comparison is therefore equivalent to $5 x < 2$, giving $\left(-\infty, \dfrac{2}{5}\right)$.
