For which values of the base $a$, with $a > 0$ and $a \neq 1$, is the number $x = 1$ a solution of the inequality $a^{x} > a^{2}$?

- $a > 1$
- $0 < a < 1$
- For every $a > 0$ with $a \neq 1$
- For no value of $a$

## Explanation

For $x = 1$ the inequality becomes $a^{1} > a^{2}$. If $a > 1$ the exponential function with base $a$ is increasing, so $a^{1} > a^{2}$ is equivalent to $1 > 2$, which is false. If $0 < a < 1$ the function is decreasing, so the direction of the inequality is reversed and $a^{1} > a^{2}$ is equivalent to $1 < 2$, which is true. Therefore $x = 1$ is a solution if and only if $0 < a < 1$, as shown for example by $a = \dfrac{1}{2}$, with $\dfrac{1}{2} > \dfrac{1}{4}$.
