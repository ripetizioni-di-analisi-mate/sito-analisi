In the equation $2^{\left(2^{x}\right)} = 256$ the exponent of $2$ is itself a power. What is the solution?

- $x = 8$
- $x = 3$
- $x = 4$
- $x = 2$

## Explanation

Since $256 = 2^{8}$, the equation can be written as $2^{\left(2^{x}\right)} = 2^{8}$. By the equality of powers with the same base the exponents are equal, so $2^{x} = 8$. Since $8 = 2^{3}$, applying the equality of powers with the same base again gives $x = 3$. In the expression $2^{\left(2^{x}\right)}$ the exponent is $2^{x}$, therefore it is different from $\left(2^{2}\right)^{x} = 4^{x}$, which equals $256$ for $x = 4$.
