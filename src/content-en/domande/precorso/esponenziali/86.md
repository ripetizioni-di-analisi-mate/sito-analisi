The function $f(x) = 2^{-x^{2}}$ is defined on all of $\mathbb{R}$. Which values does it take?

- $(0, +\infty)$
- $[1, +\infty)$
- $(0, 1]$
- $(0, 1)$

## Explanation

The exponent $-x^{2}$ takes every value less than or equal to $0$, and it equals $0$ only for $x = 0$. The function $y = 2^{u}$ is strictly increasing, so for $u \leq 0$ it takes positive values less than or equal to $2^{0} = 1$, and as $u$ decreases it gets arbitrarily close to $0$. Therefore the set of values of $f$ is $(0, 1]$, with the maximum value $1$ attained at $x = 0$.
