The figure shows the graph of a decreasing function that passes through the point $(0, 3)$ and has the line $y = 2$ as a horizontal asymptote. Which of the following functions has this graph?

::grafico{f="2+0.5^x" xmin=-2.5 xmax=4 ymin=-0.5 ymax=8 legenda=0 asintoti="y=2" punti="0,3,pieno" titolo="The graph passes through $(0, 3)$ and has the asymptote $y = 2$"}

- $f(x) = 2 + \left(\dfrac{1}{2}\right)^{x}$
- $f(x) = 2 + 2^{x}$
- $f(x) = 3 \cdot \left(\dfrac{1}{2}\right)^{x}$
- $f(x) = \left(\dfrac{1}{2}\right)^{x} + 3$

## Explanation

As $x$ increases, the power $\left(\dfrac{1}{2}\right)^{x}$ gets closer to $0$, so $f(x) = 2 + \left(\dfrac{1}{2}\right)^{x}$ gets closer to $2$ and the line $y = 2$ is a horizontal asymptote. Moreover $f(0) = 2 + 1 = 3$, and $f$ is decreasing because the base $\dfrac{1}{2}$ lies between $0$ and $1$. The function $2 + 2^{x}$ is increasing, the function $3 \cdot \left(\dfrac{1}{2}\right)^{x}$ has the line $y = 0$ as its asymptote, and the function $\left(\dfrac{1}{2}\right)^{x} + 3$ equals $4$ at $x = 0$.
