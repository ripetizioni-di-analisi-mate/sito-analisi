Which real numbers $x$ satisfy $3^{|x|} = 27$?

- $x = 3$
- $x = -3$ and $x = 3$
- $x = -9$ and $x = 9$
- The equation has no solutions

## Explanation

Since $27 = 3^{3}$, the equation can be written as $3^{|x|} = 3^{3}$. By the equality of powers with the same base, this is equivalent to $|x| = 3$. A number has absolute value $3$ if and only if it equals $3$ or $-3$, therefore the solutions are $x = -3$ and $x = 3$.
