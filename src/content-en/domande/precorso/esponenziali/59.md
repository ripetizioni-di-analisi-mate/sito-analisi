Which of the following values of $x$ satisfies the inequality $9^{x} - 2 \cdot 3^{x} - 3 < 0$?

- $x = 1$
- $x = 2$
- $x = -2$
- $x = \dfrac{3}{2}$

## Explanation

Since $9^{x} = \left(3^{x}\right)^{2}$, with the substitution $t = 3^{x}$, $t > 0$, the inequality becomes $t^{2} - 2t - 3 < 0$. The trinomial has roots $t = -1$ and $t = 3$ and is negative between the roots, so $-1 < t < 3$. Every value of $t = 3^{x}$ is positive, therefore only the condition $3^{x} < 3^{1}$ remains. The base $3$ is greater than $1$, so the solutions are $x < 1$, negative values included. The value $x = -2$ is less than $1$, and indeed for $x = -2$ the left-hand side equals $\dfrac{1}{81} - \dfrac{2}{9} - 3 < 0$. For $x = 1$ the left-hand side equals $9 - 6 - 3 = 0$, while the inequality is strict.
