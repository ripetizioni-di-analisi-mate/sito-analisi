Which values satisfy $\left(\dfrac{1}{3}\right)^{7 x} > \dfrac{1}{81}$?

- $\left(-\infty, \dfrac{4}{7}\right)$
- $\left(-\infty, \dfrac{4}{7}\right]$
- $\left(-\infty, - \dfrac{4}{7}\right)$
- $\left(\dfrac{4}{7}, \infty\right)$

## Explanation

For a positive base below $1$, the function is decreasing. The comparison is therefore equivalent to $7 x < 4$, giving $\left(-\infty, \dfrac{4}{7}\right)$.
