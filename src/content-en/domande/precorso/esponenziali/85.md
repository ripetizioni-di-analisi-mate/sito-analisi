Which ordering is correct for the numbers $a = 2^{\frac{1}{2}}$, $b = 3^{\frac{1}{3}}$ and $c = 6^{\frac{1}{6}}$?

- $a < b < c$
- $c < b < a$
- $b < a < c$
- $c < a < b$

## Explanation

The three numbers are positive, and the function $y = x^{6}$ is strictly increasing for $x > 0$, so comparing the three numbers is equivalent to comparing their sixth powers. By the power-of-a-power rule $a^{6} = 2^{3} = 8$, $b^{6} = 3^{2} = 9$ and $c^{6} = 6^{1} = 6$. Since $6 < 8 < 9$, we obtain $c < a < b$.
