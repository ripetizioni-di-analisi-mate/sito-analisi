Which fact holds for $f(x)$ given by $\left(5\right)^{x}-25$?

- $25$ is the only zero.
- $2$ is the only zero.
- The function is always positive.
- There are two zeros.

## Explanation

The exponential function with base 5 is strictly increasing. It takes the value $25$ only at $x=2$.
