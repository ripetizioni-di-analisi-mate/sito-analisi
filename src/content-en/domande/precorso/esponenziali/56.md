The solution of the equation $2^{x} = 50$ lies between two consecutive integers. Which ones?

- Between $4$ and $5$
- Between $5$ and $6$
- Between $6$ and $7$
- Between $7$ and $8$

## Explanation

The solution is $x = \log_2 50$. Since $2^{5} = 32$ and $2^{6} = 64$, we have $2^{5} < 50 < 2^{6}$. The function $y = 2^{x}$ is strictly increasing, because the base $2$ is greater than $1$, so the exponent $x$ for which $2^{x} = 50$ lies between $5$ and $6$.
