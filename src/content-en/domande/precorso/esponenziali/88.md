Given that $2^{a} = 3$, which expression in $a$ is the solution of the equation $4^{x} = 27$?

- $x = \dfrac{3a}{2}$
- $x = \dfrac{2a}{3}$
- $x = 6a$
- $x = 3a - 2$

## Explanation

Since $27 = 3^{3}$ and $3 = 2^{a}$, we have $27 = \left(2^{a}\right)^{3} = 2^{3a}$. Moreover $4^{x} = 2^{2x}$, so the equation can be written as $2^{2x} = 2^{3a}$. By the equality of powers with the same base it follows that $2x = 3a$, therefore $x = \dfrac{3a}{2}$.
