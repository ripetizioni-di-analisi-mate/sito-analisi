Which of the following equations has a negative solution?

- $\left(\dfrac{1}{2}\right)^{x} = \dfrac{1}{3}$
- $2^{x} = 3$
- $5^{x} = 1$
- $3^{x} = \dfrac{1}{2}$

## Explanation

For $a > 1$ the function $a^{x}$ is strictly increasing and equals $1$ at $x = 0$, so $a^{x} < 1$ if and only if $x < 0$. In the equation $3^{x} = \dfrac{1}{2}$ the base is greater than $1$ and the right-hand side is less than $1$, therefore the solution $x = \log_3 \dfrac{1}{2}$ is **negative**. The equation $5^{x} = 1$ has the solution $x = 0$, and $2^{x} = 3$ has a positive solution because $3 > 1$. For $0 < a < 1$ the function $a^{x}$ is decreasing, so $\left(\dfrac{1}{2}\right)^{x} < 1$ if and only if $x > 0$, and the solution of $\left(\dfrac{1}{2}\right)^{x} = \dfrac{1}{3}$ is positive as well.
