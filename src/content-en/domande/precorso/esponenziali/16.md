What is the set of values taken by the function $f(x) = 2^{x} - 1$ as $x \in \mathbb{R}$ varies?

- $(0, +\infty)$
- $(-1, +\infty)$
- $[-1, +\infty)$
- $(1, +\infty)$

## Explanation

For every $k > 0$ the equation $2^{x} = k$ has the solution $x = \log_2 k$, and $2^{x}$ is always positive, so $2^{x}$ takes all and only the values of the interval $(0, +\infty)$. Subtracting $1$ decreases each value by $1$, therefore $2^{x} - 1$ takes all and only the values of the interval $(-1, +\infty)$. The value $-1$ is excluded, because $2^{x} - 1 = -1$ is equivalent to $2^{x} = 0$, which has no solutions. The graph of $f$ is the graph of $2^{x}$ shifted down by $1$, with the line $y = -1$ as horizontal asymptote.
