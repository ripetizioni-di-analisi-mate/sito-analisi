Which of the following functions is strictly decreasing on $\mathbb{R}$?

- $f(x) = \left(\dfrac{5}{4}\right)^{x}$
- $f(x) = \left(\dfrac{1}{2}\right)^{-x}$
- $f(x) = 3^{-x}$
- $f(x) = \left(\sqrt{2}\right)^{x}$

## Explanation

An exponential function $a^{x}$ is strictly decreasing when the base lies between $0$ and $1$, so each function must be written in the form $a^{x}$ before comparing the base with $1$. By the rules of powers $3^{-x} = \left(3^{-1}\right)^{x} = \left(\dfrac{1}{3}\right)^{x}$, with base $\dfrac{1}{3}$ between $0$ and $1$, therefore this function is **strictly decreasing**. In the same way $\left(\dfrac{1}{2}\right)^{-x} = 2^{x}$ has base $2$. The bases $2$, $\dfrac{5}{4}$ and $\sqrt{2}$ are greater than $1$, so the other three functions are increasing.
