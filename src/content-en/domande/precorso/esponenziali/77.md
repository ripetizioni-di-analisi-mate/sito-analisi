Which values satisfy $\left(\dfrac{1}{3}\right)^{4 x} > \dfrac{1}{9}$?

- $\left(-\infty, \dfrac{1}{2}\right]$
- $\left(-\infty, \dfrac{1}{2}\right)$
- $\left(-\infty, - \dfrac{1}{2}\right)$
- $\left(\dfrac{1}{2}, \infty\right)$

## Explanation

For a positive base below $1$, the function is decreasing. The comparison is therefore equivalent to $4 x < 2$, giving $\left(-\infty, \dfrac{1}{2}\right)$.
