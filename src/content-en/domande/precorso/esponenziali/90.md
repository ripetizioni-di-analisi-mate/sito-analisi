We look for the real numbers $x$ such that $0 \leq 4^{x} - 2^{x+1} < 3$. What is their set?

- $1 \leq x < \log_2 3$
- $2 \leq x < 3$
- $x < \log_2 3$
- $x \geq 1$

## Explanation

Since $4^{x} = \left(2^{x}\right)^{2}$ and $2^{x+1} = 2 \cdot 2^{x}$, with the substitution $t = 2^{x}$, $t > 0$, the double inequality is equivalent to the system
$$
\begin{cases}
t^{2} - 2t \geq 0 \\
t^{2} - 2t - 3 < 0
\end{cases}
$$
The first inequality can be written as $t \, (t - 2) \geq 0$ and, since $t > 0$, it is satisfied for $t \geq 2$. The trinomial $t^{2} - 2t - 3 = (t + 1)(t - 3)$ is negative between the roots, so the second inequality is satisfied for $-1 < t < 3$. Therefore the system has the solutions $2 \leq t < 3$. Since $3 = 2^{\log_2 3}$ and the base $2$ is greater than $1$, from $2^{1} \leq 2^{x} < 2^{\log_2 3}$ it follows that $1 \leq x < \log_2 3$.
