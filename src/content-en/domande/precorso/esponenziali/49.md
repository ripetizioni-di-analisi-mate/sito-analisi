Which fact holds for $f(x)$ given by $\left(3\right)^{x}-81$?

- $81$ is the only zero.
- The function is always positive.
- There are two zeros.
- $4$ is the only zero.

## Explanation

The exponential function with base 3 is strictly increasing. It takes the value $81$ only at $x=4$.
