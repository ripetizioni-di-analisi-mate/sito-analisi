Which of the following inequalities is true?

- $3^{-2} > 3^{-1}$
- $\left(\dfrac{1}{2}\right)^{-3} < \left(\dfrac{1}{2}\right)^{-1}$
- $2^{\frac{1}{2}} < 2^{\frac{1}{3}}$
- $\left(\dfrac{2}{3}\right)^{5} < \left(\dfrac{2}{3}\right)^{3}$

## Explanation

Two powers with the same base are compared through their exponents, taking into account the monotonicity of the exponential function. The base $\dfrac{2}{3}$ lies between $0$ and $1$, so the function $\left(\dfrac{2}{3}\right)^{x}$ is strictly decreasing and, since $5 > 3$, we have $\left(\dfrac{2}{3}\right)^{5} < \left(\dfrac{2}{3}\right)^{3}$. The base $3$ is greater than $1$, therefore $-2 < -1$ implies $3^{-2} < 3^{-1}$. The base $\dfrac{1}{2}$ is less than $1$, therefore $-3 < -1$ implies $\left(\dfrac{1}{2}\right)^{-3} > \left(\dfrac{1}{2}\right)^{-1}$, that is, $8 > 2$. Finally, the base $2$ is greater than $1$, so $\dfrac{1}{2} > \dfrac{1}{3}$ implies $2^{\frac{1}{2}} > 2^{\frac{1}{3}}$.
