Which values does the function $f(x) = \left(\dfrac{1}{2}\right)^{x}$ take as $x$ varies in the interval $[-1, 2]$?

- $\left[\dfrac{1}{2}, 4\right]$
- $(0, 2]$
- $\left[\dfrac{1}{4}, 2\right]$
- $\left[\dfrac{1}{4}, +\infty\right)$

## Explanation

The base $\dfrac{1}{2}$ lies between $0$ and $1$, so $f$ is strictly decreasing. On $[-1, 2]$ the maximum value is therefore attained at the left endpoint, $f(-1) = 2$, and the minimum value at the right endpoint, $f(2) = \dfrac{1}{4}$. The exponential function is continuous, so it also takes every value between these two, and the set of values is $\left[\dfrac{1}{4}, 2\right]$.
