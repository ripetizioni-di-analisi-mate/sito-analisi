Which values satisfy $\left(\dfrac{1}{2}\right)^{6 x} > \dfrac{1}{8}$?

- $\left(-\infty, - \dfrac{1}{2}\right)$
- $\left(-\infty, \dfrac{1}{2}\right)$
- $\left(\dfrac{1}{2}, \infty\right)$
- $\left(-\infty, \dfrac{1}{2}\right]$

## Explanation

For a positive base below $1$, the function is decreasing. The comparison is therefore equivalent to $6 x < 3$, giving $\left(-\infty, \dfrac{1}{2}\right)$.
