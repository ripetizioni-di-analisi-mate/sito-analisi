Which proposition is true exactly when the proposition "no real number has square equal to $-1$" is false?

- There exists a real number with square equal to $-1$
- Every real number has square equal to $-1$
- There exists a real number with square different from $-1$
- No real number has square equal to $1$

## Explanation

The proposition that is true exactly when a given proposition is false is its negation.

The sentence "no real number has square equal to $-1$" means $\forall x \in \mathbb{R} : x^2 \neq -1$. Its negation is $\exists x \in \mathbb{R} : x^2 = -1$, that is, "there exists a real number with square equal to $-1$".

The original proposition is true, because $x^2 \geq 0$ for every real $x$, so the negation is false. The sentence "there exists a real number with square different from $-1$" changes the quantifier without negating the predicate, and "every real number has square equal to $-1$" negates the predicate without changing the quantifier.
