What is the negation of the proposition $\forall x \in \mathbb{R} : x > 0 \Longrightarrow x + 1 > 2$?

- $\exists x \in \mathbb{R} : x > 0 \ \land \ x + 1 \leq 2$
- $\exists x \in \mathbb{R} : x > 0 \Longrightarrow x + 1 \leq 2$
- $\exists x \in \mathbb{R} : x \leq 0 \ \land \ x + 1 > 2$
- $\forall x \in \mathbb{R} : x > 0 \ \land \ x + 1 \leq 2$

## Explanation

By the **negation of quantifiers** the symbol $\forall$ becomes $\exists$ and the predicate, which is the implication $x > 0 \Rightarrow x + 1 > 2$, is negated.

By the **negation of the implication** we have $\lnot (p \Rightarrow q) \equiv p \land \lnot q$, so the negated predicate is the conjunction of the hypothesis $x > 0$ with the negation of the conclusion. The negation of $x + 1 > 2$ is $x + 1 \leq 2$, therefore the required negation is
$$
\exists x \in \mathbb{R} : x > 0 \ \land \ x + 1 \leq 2 .
$$
This proposition is true, because for $x = \dfrac{1}{2}$ we have $x > 0$ and $x + 1 = \dfrac{3}{2} \leq 2$.
