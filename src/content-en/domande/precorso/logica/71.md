The proposition $\forall a, b \in \mathbb{R} : (a + b)^2 = a^2 + b^2$ is false. Which pairs $(a, b)$ are counterexamples?

- All pairs with $a \neq 0 \lor b \neq 0$
- All pairs with $a \neq 0 \land b \neq 0$
- Only the pairs with $a = b$
- All pairs with $a = -b$

## Explanation

We have $(a + b)^2 = a^2 + 2ab + b^2$, so the equality $(a + b)^2 = a^2 + b^2$ is equivalent to $2ab = 0$, that is, to $a = 0 \lor b = 0$.

A pair is a counterexample when the equality is false, that is, when the negation of $a = 0 \lor b = 0$ holds. By **De Morgan's laws** this negation is $a \neq 0 \land b \neq 0$. Therefore the counterexamples are exactly the pairs with **$a \neq 0$ and $b \neq 0$**.

The pair $(0, 1)$ satisfies $a \neq 0 \lor b \neq 0$ and satisfies the equality, because $1 = 0 + 1$. The pair $(0, 0)$ has $a = b = -b$ and satisfies the equality, while the pair $(1, 2)$ is a counterexample with $a \neq b$.
