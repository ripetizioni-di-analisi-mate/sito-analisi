What is the negation of the proposition $x \leq -1 \ \lor \ x > 2$, with $x$ real?

- $x > -1 \ \lor \ x \leq 2$
- $x \geq -1 \ \land \ x < 2$
- $x > -1 \ \land \ x \leq 2$
- $x \geq -1 \ \land \ x \leq 2$

## Explanation

By **De Morgan's laws** the negation of a disjunction is the conjunction of the negations of the two parts.

The negation of $x \leq -1$ is $x > -1$ and the negation of $x > 2$ is $x \leq 2$. Therefore the required negation is
$$
x > -1 \ \land \ x \leq 2 ,
$$
that is, $-1 < x \leq 2$.

The value $x = -1$ satisfies $x \leq -1$, so it makes the original proposition true and does not belong to the truth set of the negation.
