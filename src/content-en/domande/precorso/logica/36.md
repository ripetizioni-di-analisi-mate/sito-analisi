Which value of $x$ is a counterexample to the proposition $\forall x \in \mathbb{R} : x^3 > x$?

- $x = 2$
- $x = \dfrac{1}{2}$
- $x = -\dfrac{1}{2}$
- $x = \dfrac{3}{2}$

## Explanation

A counterexample is a value of $x$ for which the predicate $x^3 > x$ is false.

For $x = \dfrac{1}{2}$ we have $x^3 = \dfrac{1}{8} < \dfrac{1}{2}$, so $x = \dfrac{1}{2}$ is a **counterexample** and the proposition is false.

For $x = -\dfrac{1}{2}$ we have $x^3 = -\dfrac{1}{8} > -\dfrac{1}{2}$, so the predicate is true. The predicate is also true for $x = 2$ and for $x = \dfrac{3}{2}$, because $8 > 2$ and $\dfrac{27}{8} > \dfrac{3}{2}$.
