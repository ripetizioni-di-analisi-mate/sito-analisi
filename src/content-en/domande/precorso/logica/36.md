The proposition "for every natural number $n \geq 1$, $2^n \geq n^2$" is false. For which of the following values of $n$ does the inequality fail?

- $n = 2$
- $n = 4$
- $n = 3$
- $n = 5$

## Explanation

A counterexample is a value of $n$ for which the inequality $2^n \geq n^2$ is false, that is, $2^n < n^2$.

For $n = 3$ we have $2^3 = 8$ and $3^2 = 9$, so $2^3 < 3^2$. Therefore $n = 3$ is a **counterexample**.

For $n = 2$ we have $2^2 = 4 = 2^2$ and for $n = 4$ we have $2^4 = 16 = 4^2$. The inequality is non-strict, so in these two cases it holds. For $n = 5$ we have $2^5 = 32 \geq 25$.
