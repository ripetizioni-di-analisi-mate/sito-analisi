Which of the following implications about quadrilaterals is false?

- If it is a square, then it has equal diagonals
- If it has equal diagonals, then it is a square
- If it does not have equal diagonals, then it is not a square
- If it is a rectangle, then it has equal diagonals

## Explanation

A rectangle with sides of length $3$ and $4$ has both diagonals of length $5$, so it has equal diagonals, and it is not a square. Therefore the implication "if it has equal diagonals, then it is a square" is **false**.

Every rectangle has equal diagonals, and every square is a rectangle, so the implications about the rectangle and about the square are true.

The implication "if it does not have equal diagonals, then it is not a square" is the contrapositive of "if it is a square, then it has equal diagonals", therefore it is true like that one.
