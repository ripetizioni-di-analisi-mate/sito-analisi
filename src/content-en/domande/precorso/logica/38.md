For which set $D$ is the statement $\forall x \in D \ \exists y \in D : y > x$ true, while the statement $\forall x \in D \ \exists y \in D : y < x$ is false?

- $\mathbb{Z}$
- $\{-2, -1, 0\}$
- $\{0, 1, 2, \ldots\}$
- $\{0\}$

## Explanation

The first statement says that every element of $D$ is exceeded by another element of $D$, so it is false in a set that has a greatest element. The sets $\{-2, -1, 0\}$ and $\{0\}$ have greatest element $0$, therefore the first statement is false in them. In $\{-2, -1, 0\}$ the element $x = -2$ is exceeded by $y = -1$, but the statement requires a greater element for *every* $x$, and for $x = 0$ such an element does not exist.

In the set $\mathbb{Z}$ of integers one has $x + 1 > x$ and $x - 1 < x$ for every $x$, so both statements are true.

In the set $\{0, 1, 2, \ldots\}$ of natural numbers every $x$ is less than $x + 1$, therefore the first statement is true. For $x = 0$ no natural number $y$ satisfies $y < 0$, so the second statement is false. The required set is therefore $\{0, 1, 2, \ldots\}$.
