The implication $p \Rightarrow q$ is false. Which of the following propositions is true?

- $\lnot q \Rightarrow \lnot p$
- $p \land q$
- $\lnot p \lor q$
- $q \Rightarrow p$

## Explanation

An implication is false only when the hypothesis is true and the conclusion is false, so $p$ is true and $q$ is false.

The implication $q \Rightarrow p$ has a false hypothesis, therefore it is **true**.

The contrapositive $\lnot q \Rightarrow \lnot p$ and the proposition $\lnot p \lor q$ are equivalent to $p \Rightarrow q$, so they are false. The conjunction $p \land q$ is false, because $q$ is false.
