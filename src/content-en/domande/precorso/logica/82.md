Consider the proposition "for every real $x$, if $x^2 < 0$, then $x = 5$". Which statement is correct?

- It is true, because the hypothesis $x^2 < 0$ is false for every real $x$
- It is false, because for $x = 0$ hypothesis and conclusion are both false
- It is false, because for $x = 5$ the hypothesis is false
- It is not a proposition, because the hypothesis has no connection with the conclusion

## Explanation

The square of a real number is greater than or equal to zero, so the hypothesis $x^2 < 0$ is false for every real $x$.

An implication with a false hypothesis is true whatever the conclusion is. Therefore the implication is true for every $x$, and the universal proposition is **true**.

For $x = 0$ and for $x = 5$ the hypothesis is false, so the implication is true for these values as well. The truth value of an implication depends only on the truth values of hypothesis and conclusion, therefore the statement is a proposition.
