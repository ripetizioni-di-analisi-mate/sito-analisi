For which real values of $x$ is the proposition $x^2 < 9 \ \land \ x > 1$ true?

- $-3 < x < 3$
- $1 < x < 3$
- $x > 1$
- $x < -3 \ \lor \ x > 1$

## Explanation

The inequality $x^2 < 9$ is satisfied for $-3 < x < 3$.

A conjunction is true when both parts are true, so its truth set is the intersection of the interval $(-3, 3)$ with the half-line $x > 1$. Therefore the proposition is true for $1 < x < 3$.

For $x = -1$ the condition $x^2 < 9$ is satisfied and the condition $x > 1$ is not, so for $x = -1$ the conjunction is false.
