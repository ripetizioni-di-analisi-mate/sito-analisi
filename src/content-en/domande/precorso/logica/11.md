Which of the following statements is a proposition?

- $x^2 - 1 = 0$
- $x + y > 2$
- $\sqrt{2} > 1.5$
- $n$ is an even number

## Explanation

A proposition is a statement that has exactly one of the two truth values. The statements $x^2 - 1 = 0$, $x + y > 2$ and "$n$ is an even number" contain variables with no assigned value, so they are **predicates**, that is, statements whose truth value depends on the values of the variables.

The statement $\sqrt{2} > 1.5$ contains no variables. Since $(1.5)^2 = 2.25 > 2$, we have $\sqrt{2} < 1.5$, therefore the statement is false. A false statement is still a **proposition**, because it has a well-defined truth value.
