An alarm with two sensors activates on $p\lor q$. It should now remain off when both sensors are active, with all other outcomes unchanged. Which condition should be added using a conjunction?

- $\lnot(p\lor q)$
- $\lnot(p\land q)$
- $p\land q$
- $p\Leftrightarrow q$

## Explanation

Only the row where both $p$ and $q$ are true must be excluded. The constraint $\lnot(p\land q)$ is false only on that row. Combined with the original condition, it keeps exactly the two rows with one active sensor.
