For a natural number $n$ greater than $1$, the condition "$n$ is odd" is neither necessary nor sufficient for "$n$ is prime". Which pair of numbers shows, in this order, that it is not necessary and that it is not sufficient?

- $2$ and $9$
- $9$ and $2$
- $3$ and $9$
- $2$ and $4$

## Explanation

The condition is not necessary if there exists a prime number that is not odd. The number $2$ is prime and even, so it shows that the condition is not necessary.

The condition is not sufficient if there exists an odd number that is not prime. The number $9 = 3 \cdot 3$ is odd and not prime, so it shows that the condition is not sufficient.

Therefore the pair is $2$ and $9$, in this order. The number $3$ is prime and odd, so it shows nothing about necessity, and the number $4$ is even, so it shows nothing about sufficiency.
