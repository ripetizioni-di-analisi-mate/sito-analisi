For real $a$ and $b$, the product $ab$ is zero. Which compound proposition describes exactly this situation?

- $a = 0 \land b = 0$
- $a = 0 \lor b = 0$
- $a = -b$
- $a \neq 0 \lor b \neq 0$

## Explanation

By the zero product property, $ab = 0$ if and only if at least one of the two factors is zero. The phrase "at least one" corresponds to a disjunction, so $ab = 0$ is equivalent to $a = 0 \lor b = 0$.

The conjunction $a = 0 \land b = 0$ describes only the case in which both are zero, and leaves out for example $a = 0$, $b = 3$, for which $ab = 0$.

The equality $a = -b$ is satisfied by $a = 1$, $b = -1$, for which $ab = -1$. The proposition $a \neq 0 \lor b \neq 0$ is true for $a = 2$, $b = 3$, for which $ab = 6$.
