Is the proposition $\exists x \in \mathbb{N} : 2x + 1 = 8$ true or false?

- False, because the only real solution is $x = \dfrac{7}{2}$, which is not a natural number
- True, because $x = \dfrac{7}{2}$ satisfies the equation
- False, because for $x = 0$ we have $2x + 1 = 1 \neq 8$
- False, because an equation with a variable is not a proposition

## Explanation

The equation $2x + 1 = 8$ is equivalent to $2x = 7$, whose only real solution is $x = \dfrac{7}{2}$.

The number $\dfrac{7}{2}$ is not natural, so no element of $\mathbb{N}$ satisfies the predicate and the proposition is **false**.

A single value that does not satisfy the predicate, such as $x = 0$, is enough to refute a universal proposition, while an existential proposition is false only when no element satisfies the predicate. The predicate $2x + 1 = 8$ becomes a proposition through the quantifier $\exists$.
