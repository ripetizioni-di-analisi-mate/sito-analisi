In a course, having passed the written exam is a necessary condition for being admitted to the oral exam. Which implication expresses this rule for any student?

- If the student has passed the written exam, then the student is admitted to the oral exam
- If the student is admitted to the oral exam, then the student has passed the written exam
- The student is admitted to the oral exam if and only if the student has passed the written exam
- If the student is not admitted to the oral exam, then the student has not passed the written exam

## Explanation

If $q$ is a necessary condition for $p$, then $p \Rightarrow q$ holds. Here $p$ is "the student is admitted to the oral exam" and $q$ is "the student has passed the written exam".

Therefore the rule is the implication "if the student is admitted to the oral exam, then the student has passed the written exam".

The implication "if the student has passed the written exam, then the student is admitted to the oral exam" would make the written exam a sufficient condition, and the rule does not state that. The implication "if the student is not admitted to the oral exam, then the student has not passed the written exam" is the contrapositive of the latter, so it states the same thing. The equivalence also adds sufficiency.
