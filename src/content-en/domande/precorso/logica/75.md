Which expression translates the sentence "every positive real number is the square of a real number"?

- $\forall x > 0 \ \exists y \in \mathbb{R} : y^2 = x$
- $\exists y \in \mathbb{R} \ \forall x > 0 : y^2 = x$
- $\forall x > 0 \ \forall y \in \mathbb{R} : y^2 = x$
- $\exists x > 0 \ \exists y \in \mathbb{R} : y^2 = x$

## Explanation

The sentence concerns *every* positive number $x$, so it begins with $\forall x > 0$. For each $x$ it states the existence of a real $y$ with $y^2 = x$, and this $y$ may depend on $x$, for example $y = \sqrt{x}$. Therefore the translation is $\forall x > 0 \ \exists y \in \mathbb{R} : y^2 = x$.

The expression $\exists y \ \forall x > 0 : y^2 = x$ requires a single $y$ whose square equals all positive numbers, and it is a different statement. The expression with $\forall y$ requires every real number to have square $x$, and the one with $\exists x$ concerns a single positive number.
