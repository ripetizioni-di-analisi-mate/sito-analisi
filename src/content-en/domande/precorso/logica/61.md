For which of the following values of $a$ is the condition $x > a$ sufficient for $x > 3$, with $x$ real?

- $a = 0$
- $a = 2$
- $a = -3$
- $a = 5$

## Explanation

The condition $x > a$ is sufficient for $x > 3$ when the implication $x > a \Rightarrow x > 3$ is true for every real $x$.

For $a = 5$, from $x > 5$ it follows that $x > 3$, because $5 > 3$. Therefore for $a = 5$ the condition is **sufficient**.

For $a = 2$ the value $x = \dfrac{5}{2}$ satisfies $x > 2$ and does not satisfy $x > 3$, so the implication is false. The same value disproves the implication also for $a = 0$ and for $a = -3$. For these three values of $a$ instead $x > 3 \Rightarrow x > a$ holds, that is, $x > a$ is a necessary condition for $x > 3$.
