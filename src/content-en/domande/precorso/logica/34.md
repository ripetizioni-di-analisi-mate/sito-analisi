For a natural number $n$, the implication "if $n$ is a multiple of $4$, then $n$ is even" is true. Which sentence expresses the same implication?

- $n$ is even only if $n$ is a multiple of $4$
- $n$ is a multiple of $4$ only if $n$ is even
- $n$ is a multiple of $4$ if $n$ is even
- Being a multiple of $4$ is a necessary condition for $n$ to be even

## Explanation

The sentence "$A$ only if $B$" means that $A$ can be true only when $B$ is true, that is, $A \Rightarrow B$. So "$n$ is a multiple of $4$ only if $n$ is even" expresses the implication "if $n$ is a multiple of $4$, then $n$ is even".

The sentence "$n$ is even only if $n$ is a multiple of $4$" expresses the converse, which is false for $n = 6$. The sentence "$n$ is a multiple of $4$ if $n$ is even" also means "if $n$ is even, then $n$ is a multiple of $4$".

From the given implication it follows that being even is a necessary condition for being a multiple of $4$, so the sentence that declares the condition "multiple of $4$" necessary swaps the two roles.
