Which proposition has the same truth table as the implication $p \Rightarrow q$?

- $\lnot p \lor q$
- $p \lor \lnot q$
- $\lnot p \land q$
- $p \land \lnot q$

## Explanation

The implication $p \Rightarrow q$ is false only when $p$ is true and $q$ is false.

The disjunction $\lnot p \lor q$ is false only when $\lnot p$ and $q$ are both false, that is, when $p$ is true and $q$ is false. The two propositions are therefore false in the same row and true in the other three, so they have the **same truth table**.

The proposition $p \land \lnot q$ is the negation of $p \Rightarrow q$. The proposition $p \lor \lnot q$ is false for $p$ false and $q$ true, that is, in a row where the implication is true.
