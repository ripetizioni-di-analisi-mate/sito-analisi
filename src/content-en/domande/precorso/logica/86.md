For real $x$ and $y$, what is the negation of the implication $x > 0 \Rightarrow (y > 0 \lor x + y < 1)$?

- $x > 0 \land y \leq 0 \land x + y \geq 1$
- $x > 0 \land (y \leq 0 \lor x + y \geq 1)$
- $x > 0 \Rightarrow (y \leq 0 \land x + y \geq 1)$
- $x \leq 0 \land (y > 0 \lor x + y < 1)$

## Explanation

By the **negation of an implication**, $\lnot (p \Rightarrow q) \equiv p \land \lnot q$, so the hypothesis $x > 0$ is kept and the conclusion $y > 0 \lor x + y < 1$ is negated.

By De Morgan's laws the negation of the disjunction is the conjunction of the negations, that is, $y \leq 0 \land x + y \geq 1$. Therefore the required negation is
$$
x > 0 \land y \leq 0 \land x + y \geq 1 .
$$
This proposition is true, for example, for $x = 2$ and $y = 0$.
