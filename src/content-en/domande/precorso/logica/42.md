We want to prove by contrapositive that, for every integer $n$, "if $n^2$ is odd, then $n$ is odd". Which implication is proved?

- If $n$ is odd, then $n^2$ is odd
- If $n$ is even, then $n^2$ is even
- If $n$ is even, then $n^2$ is odd
- If $n^2$ is even, then $n$ is even

## Explanation

In a **proof by contrapositive** of $p \Rightarrow q$ one proves $\lnot q \Rightarrow \lnot p$, which is equivalent to $p \Rightarrow q$.

Here $p$ is "$n^2$ is odd" and $q$ is "$n$ is odd". An integer that is not odd is even, so the contrapositive is "if $n$ is even, then $n^2$ is even". This implication is proved at once, because $n = 2a$ gives $n^2 = 4a^2 = 2 \cdot 2a^2$.

The implication "if $n^2$ is even, then $n$ is even" negates hypothesis and conclusion without swapping them, so it is not equivalent to the original implication.
