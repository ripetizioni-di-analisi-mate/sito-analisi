For which real values of $x$ is the proposition $x \leq -2 \ \lor \ x^2 \leq 1$ true?

- $-1 \leq x \leq 1$
- $-2 \leq x \leq 1$
- $x \leq 1$
- $x \leq -2 \ \lor \ -1 \leq x \leq 1$

## Explanation

The inequality $x^2 \leq 1$ is satisfied for $-1 \leq x \leq 1$.

A disjunction is true when at least one of the two parts is true, so its truth set is the union of the half-line $x \leq -2$ with the interval $[-1, 1]$. Therefore the proposition is true for $x \leq -2$ or $-1 \leq x \leq 1$.

For $x = -\dfrac{3}{2}$ we have $x > -2$ and $x^2 = \dfrac{9}{4} > 1$, so neither part is true and the proposition is false.
