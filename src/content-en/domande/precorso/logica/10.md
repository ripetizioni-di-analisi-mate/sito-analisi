We want to prove by contradiction that $1 + \sqrt{2}$ is irrational, knowing that $\sqrt{2}$ is irrational. From which assumption does the proof start?

- $\sqrt{2}$ is rational
- $1 + \sqrt{2}$ is irrational
- $1 + \sqrt{2}$ is rational
- $1 + \sqrt{2}$ is an integer

## Explanation

In a **proof by contradiction** we assume that the conclusion is false. The conclusion is "$1 + \sqrt{2}$ is irrational", so we assume that $1 + \sqrt{2}$ is a rational number $q$.

From $1 + \sqrt{2} = q$ we get $\sqrt{2} = q - 1$, which is a difference of two rationals and is therefore rational. This contradicts the hypothesis that $\sqrt{2}$ is irrational. Therefore the assumption is false and $1 + \sqrt{2}$ is **irrational**.

Assuming that $1 + \sqrt{2}$ is an integer excludes only part of the rational numbers, so it is not the negation of the conclusion.
