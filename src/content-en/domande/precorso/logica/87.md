The proposition $p \Rightarrow (q \Rightarrow r)$ is false. What are the truth values of $p$, $q$ and $r$?

- $p$ true, $q$ true, $r$ false
- $p$ true, $q$ false, $r$ false
- $p$ false, $q$ true, $r$ false
- $p$ true, $q$ true, $r$ true

## Explanation

The implication $p \Rightarrow (q \Rightarrow r)$ is false only when the hypothesis $p$ is true and the conclusion $q \Rightarrow r$ is false.

In turn $q \Rightarrow r$ is false only when $q$ is true and $r$ is false. Therefore **$p$ is true, $q$ is true and $r$ is false**.

With $p$ false the outer implication is true. With $q$ false or with $r$ true the implication $q \Rightarrow r$ is true, so the outer implication is true as well.
