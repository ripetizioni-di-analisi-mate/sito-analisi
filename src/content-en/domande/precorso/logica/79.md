For an integer $n$, which of the following true implications also has a true converse?

- If $n$ is a multiple of $4$, then $n$ is even
- If $n = 2$, then $n^2 = 4$
- If $n > 3$, then $n > 1$
- If $n$ is even, then $n^2$ is even

## Explanation

The converse of "if $n$ is even, then $n^2$ is even" is "if $n^2$ is even, then $n$ is even". Its contrapositive is "if $n$ is odd, then $n^2$ is odd", which is true because $(2a + 1)^2 = 2(2a^2 + 2a) + 1$. Therefore the converse is **true**.

The other converses are false. The number $6$ is even and is not a multiple of $4$, the number $-2$ satisfies $n^2 = 4$ with $n \neq 2$, and the number $2$ satisfies $n > 1$ with $n \leq 3$.
