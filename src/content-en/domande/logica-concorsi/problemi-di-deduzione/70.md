Four rooms, A, B, C, and D, are inspected one per day from Monday through Thursday. A and C are not inspected on consecutive days. B comes before D and D before A. Which order is possible?

- B → C → D → A
- D → B → C → A
- B → C → A → D
- B → D → C → A

## Explanation

In the order B, C, D, A, B comes before D and D comes before A. C is on Tuesday and A on Thursday, so one day separates the two inspections. The other sequences put A and C on consecutive days or violate the required order of B, D, and A.
