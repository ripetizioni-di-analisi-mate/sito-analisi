Four cases, A, B, C, and D, can be selected. If A is selected, B is selected. If B is selected, C is not selected. If C is not selected, D is selected. We know that A is selected. Which conclusion follows?

- Only A and B are selected.
- B is not selected.
- D is selected.
- C is selected.

## Explanation

Selecting A requires selecting B. Selecting B rules out C. If C is absent, D must be selected.
