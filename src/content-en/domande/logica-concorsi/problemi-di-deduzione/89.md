Each of four permits, A, B, C, and D, can be issued or withheld. B is issued if and only if C is not issued. A and B cannot both be issued. If D is issued, A is issued as well. Which two permits can both be issued?

- B and D
- B and C
- A and B
- A and C

## Explanation

A and C can both be issued if B and D are not issued. A rules out B, and B and C must have opposite outcomes under the first condition. B and D are also incompatible because D requires A and A rules out B.
