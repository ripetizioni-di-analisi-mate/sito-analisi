At a gym, Bruna, Ciro, Delia, and Elio each use a different locker, numbered $1$ through $4$. Bruna uses neither locker $1$ nor locker $2$. Ciro uses $2$ or $3$. Delia uses neither $3$ nor $4$. Elio does not use $4$. Which additional piece of information would let you determine everyone’s locker?

- Delia uses locker $1$
- Bruna uses locker $4$
- Ciro uses locker $2$
- Elio does not use locker $1$

## Explanation

Ciro, Delia, and Elio are all ruled out for locker $4$, so it belongs to Bruna. The clues leave three possible assignments for Ciro, Delia, and Elio, respectively: ($2$, $1$, $3$), ($3$, $1$, $2$), or ($3$, $2$, $1$). “Ciro uses locker $2$” leaves only the first assignment, so it is the **additional information** we need. The clues about Delia and Elio each leave two possible assignments, and “Bruna uses locker $4$” already follows from the original clues.
