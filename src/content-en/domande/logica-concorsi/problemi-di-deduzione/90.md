Four checks, A, B, C, and D, can each give a positive or negative result. If A is positive, C is positive too. B and D have the same result. Exactly one of the four checks is positive. Which check is positive?

- C
- D
- A
- B

## Explanation

B and D must both be negative, since otherwise there would be two positive results. A cannot be positive because that would make C positive too. That leaves C as the sole positive result.
