Exactly one of three lamps, A, B, and C, is on in a room. If A is on, B is on. If B is on, C is on. Which lamp is on?

- A
- None
- B
- C

## Explanation

A cannot be on because that would require B to be on as well. The same applies to B: if it were on, C would also have to be on. That leaves C, which can be on while the other two are off.
