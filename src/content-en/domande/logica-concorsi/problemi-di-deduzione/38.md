A winning ticket is sealed in exactly one of four envelopes numbered $1$ through $4$. Envelope $1$ reads “The ticket is not here.” Envelope $2$ reads “The ticket is in envelope $1$ or envelope $3$.” Envelope $3$ reads “The ticket is in envelope $4$.” Envelope $4$ reads “The ticket is not in envelope $2$.” Exactly one of the four labels is true. Which envelope contains the ticket?

- In envelope $1$
- In envelope $3$
- In envelope $2$
- In envelope $4$

## Explanation

Try each envelope and count the true labels. If the ticket is in envelope $1$, the labels on envelopes $2$ and $4$ are true. If it is in envelope $3$ or envelope $4$, three labels are true. If the ticket is in envelope $2$, only the label on envelope $1$ is true. So the ticket is **in envelope $2$**. The answer “In envelope $1$” takes the label on envelope $2$ as true, but in that case it would not be the only true label.
