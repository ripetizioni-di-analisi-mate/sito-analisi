Consider the following argument.

“This year the office received twice as many cases as last year, so it will take twice as many employees to review them all within the time allowed.”

Which of the following is an unstated assumption of the argument?

- Last year, the office received fewer cases than this year.
- This year’s cases are more complicated than last year’s.
- This year an employee will review the same number of cases on average as last year.
- The office currently has $12$ employees.

## Explanation

The argument moves from twice as many cases to twice as many employees, so it assumes that an employee will review the same number of cases on average this year as last year. Apply the **negation test**: if each employee reviewed more cases, perhaps thanks to new software, fewer than twice as many employees would suffice, and the conclusion would no longer follow. Negating the claim that the cases are more complicated leaves the conclusion supportable, so it is not an assumption. The statement about last year follows from the stated premise. The current number of employees does not change the relationship between the number of cases and the number of employees.
