Which connective makes the following sentence coherent? “The game was suspended ___ the field was flooded.”

- so
- though
- because
- however

## Explanation

The flooded field is the reason the game was suspended, so the second part gives the **cause** of the first and the connective is *because*. With “so,” the flooding would become an effect of the suspension, reversing the relationship. “Though” introduces a concession (in Italian, “sebbene” takes the subjunctive “fosse”), and “however” indicates a contrast. A flooded field is exactly the circumstance in which we would expect a game to be suspended.
