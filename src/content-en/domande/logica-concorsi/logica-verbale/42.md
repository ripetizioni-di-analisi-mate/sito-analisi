Consider the following argument.

“This year, class 3B is using a new math textbook, and the class average in math has risen from $6$ to $7$. Therefore, the new book improved the students’ results.”

Which of the following statements, if true, strengthens the argument?

- This year class 3B has a new math teacher.
- The new book costs more than the old one.
- This year the average math grade in class 3B is $7$.
- The other third-year classes at the school, which have the same teacher as class 3B and still use the old book, maintained an average of $6$.

## Explanation

The argument attributes the higher average to the new book. The other third-year classes have the same teacher as class 3B and use the old book, and their average did not change. The difference in results between the classes therefore coincides with the difference in books. This statement **strengthens** the argument. A new teacher, by contrast, would offer another possible cause of the increase and weaken the argument. The price of the book is **irrelevant**, and the average of $7$ repeats information from the text.
