A travel agency claims, “With the Comfort package, checked baggage is always included in the price.” Which of the following facts, if true, is consistent with the agency’s claim?

- Lucia purchased the Comfort package and had to pay separately for checked baggage.
- For travel in August, the Comfort package does not include checked baggage.
- Marco purchased the Basic package and has checked baggage included in the price.
- Checked baggage is included in the price only with the Basic package.

## Explanation

The claim makes the Comfort package a **sufficient condition** for checked baggage to be included: “If a customer has the Comfort package, then checked baggage is included.” An implication is false only when the antecedent is true and the consequent is false, so Lucia’s case and travel in August are **counterexamples**. Saying that baggage is included only with the Basic package excludes the Comfort package and therefore contradicts the agency. Marco has baggage included with another package, so the consequent is true and the antecedent is false. His case is therefore consistent with the claim. It shows only that the Comfort package is not necessary for baggage to be included, and the agency did not claim that it was.
