Some numbered files have been translated. All translated files have been digitized. Which combination of properties must occur?

- At least one digitized file has not been translated.
- At least one file is numbered and translated but has not been digitized.
- At least one file is numbered, translated, and digitized.
- Every numbered file has been digitized.

## Explanation

At least one file has both properties in the first premise. Since that file has been translated, the second premise gives it the third property as well.
