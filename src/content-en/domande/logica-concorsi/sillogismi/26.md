A valid syllogism has a false conclusion. Which of the following statements about its two premises must be true?

- Both premises are false
- Both premises are true
- At least one premise is false
- Exactly one premise is false

## Explanation

In a valid syllogism, if the premises are true, the conclusion is also true. Since the conclusion is false, the premises cannot both be true, so at least one is false. The valid syllogism “All dogs are mammals; all mammals fly; therefore, all dogs fly” has a false conclusion, a true first premise, and a false second premise. The valid syllogism “All dogs are fish; all fish fly; therefore, all dogs fly,” on the other hand, has two false premises.
