Some technicians are volunteers. Some volunteers are musicians. A candidate concludes that some technician is a musician. What is the smallest number of people needed to make the premises true and the conclusion false?

- $1$
- $3$
- $2$
- $4$

## Explanation

A single witness for both premises would have to be both a technician and a musician. Two distinct volunteers suffice if only the first is a technician and only the second is a musician.
