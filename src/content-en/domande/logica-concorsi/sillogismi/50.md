Some signed applications have been approved. None of the approved applications are among those for which payment has been made. Which statement gives a necessary consequence?

- All signed applications have been approved.
- Payment has been made for some signed applications.
- Payment has not been made for some signed applications.
- None of the signed applications are among those for which payment has been made.

## Explanation

The first premise guarantees that at least one application is both signed and approved. By the second premise no approved application has been paid, so that application has not been paid. Therefore there is a signed application that has not been paid, that is, payment has not been made for some signed applications. This is the valid pattern "Some $A$ are $B$, no $B$ is $C$, therefore some $A$ are not $C$". The conclusion "None of the signed applications are among those for which payment has been made" does not follow, because signed applications that have not been approved may have been paid.
