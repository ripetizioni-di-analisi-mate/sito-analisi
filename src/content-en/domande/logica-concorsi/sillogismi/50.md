Some signed applications have been approved. None of the approved applications are among those for which payment has been made. Which statement gives a necessary consequence?

- All signed applications have been approved.
- Payment has been made for some signed applications.
- Payment has not been made for some signed applications.
- None of the signed applications are among those for which payment has been made.

## Explanation

The first premise gives an application that is both signed and approved. The approved applications and those for which payment has been made are disjoint, so that application belongs to the signed applications and lies outside the paid ones.
