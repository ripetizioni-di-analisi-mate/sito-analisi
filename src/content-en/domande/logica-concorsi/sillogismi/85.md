Both “Not all packages are insured” and “Not all packages are fragile” are true. Which situation shows that “There is a package that is neither insured nor fragile” does not follow?

- There is an insured, fragile package and a package that is neither insured nor fragile. There are no other packages.
- There is an insured package that is not fragile and a fragile package that is not insured. There are no other packages.
- There are two fragile packages, only one of which is insured. There are no other packages.
- There are two insured packages, only one of which is fragile. There are no other packages.

## Explanation

The first package makes the statement about fragility true, and the second makes the statement about insurance true. Yet neither package lacks both properties.
