All logged case files are digitized. All digitized case files are archived. The categories may be empty. What further inclusion must hold?

- No logged case file is among the archived files.
- Some logged case files are archived.
- All archived case files are logged.
- All logged case files are archived.

## Explanation

The logged files are included in the digitized files. The latter are included in the archived files, so the first category is also included in the archived files.
