Some urgent requests have been assigned. Some urgent requests are closed. None of the assigned requests are among the closed ones. Which statement do the premises establish?

- All urgent requests have been assigned.
- Some urgent requests are not closed.
- None of the urgent requests are among the closed requests.
- All urgent requests are closed.

## Explanation

According to the first premise, a request is both urgent and assigned. Since “assigned” and “closed” are incompatible, that request falls outside the closed requests.
