An office has $18$ employees. Consider the statements $P$: “Some employees work part-time” and $Q$: “All employees work part-time.” Which of the following is true?

- If $P$ is true, then $Q$ is true
- If $Q$ is true, then $P$ is true
- $P$ and $Q$ cannot both be true
- $P$ and $Q$ cannot both be false

## Explanation

If $Q$ is true, each of the $18$ employees works part-time. Since there is at least one employee, there is a part-time employee, so $P$ is true. The statement $P$ is called the **subaltern** of $Q$. The converse fails because with $5$ part-time employees $P$ is true and $Q$ is false. Both statements are true if everyone works part-time, and both are false if no one does.
