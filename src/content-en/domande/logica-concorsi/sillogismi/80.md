At an art conservation center, “All works in storage are cataloged” is false, and “No work in storage is cataloged” is also false. Which situation describes the storage facility?

- It contains only cataloged works.
- It contains both cataloged and uncataloged works.
- It contains only uncataloged works.
- It is empty.

## Explanation

The first statement is false only if there is an uncataloged work. The second is false only if there is a cataloged work. Thus two works with different cataloging statuses are required.
