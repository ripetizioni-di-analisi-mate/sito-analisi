All approved reports are signed. At least one signed report is still awaiting approval. What is guaranteed about the set of approved reports?

- It is a proper subset of the set of signed reports.
- It is the same as the set of signed reports.
- It contains the set of signed reports as a proper subset.
- It is disjoint from the set of signed reports.

## Explanation

The first statement gives inclusion in the set of signed reports. The signed report awaiting approval shows that this inclusion is proper.
