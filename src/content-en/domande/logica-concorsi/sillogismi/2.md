At an office, “Some employees requested time off for August” is true. Which of the following must be true?

- More than one employee requested time off for August
- Some employees did not request time off for August
- At least one employee requested time off for August
- All employees requested time off for August

## Explanation

In logic, *some* means *at least one, possibly all*, so the given statement is equivalent to “At least one employee requested time off for August.” It is true even if only one employee did so. Therefore “More than one employee requested time off for August” does not follow. “Some employees did not request time off for August” is tempting if we read “some” as “some did and others did not,” but the given statement is true even if all employees requested time off for August.
