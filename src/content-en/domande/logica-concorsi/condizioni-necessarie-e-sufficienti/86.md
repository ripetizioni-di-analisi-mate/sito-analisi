In a collection of case files, at least one is urgent but not digital, and at least one is digital but not urgent. What kind of condition is urgency for a file to be digital?

- Sufficient but not necessary
- Necessary but not sufficient
- Neither necessary nor sufficient
- Necessary and sufficient

## Explanation

The urgent paper file shows that urgency is not sufficient for a file to be digital. The routine digital file shows that urgency is not required.
