A project goes to the technical desk if it receives clearance. All projects that go to the technical desk are assigned a number. A project has no number. Which conclusion gives everything that can be deduced about the two preceding steps?

- It has clearance and did not go to the technical desk.
- It has clearance and went to the technical desk.
- It has no clearance and went to the technical desk.
- It has no clearance and did not go to the technical desk.

## Explanation

A project that had gone to the desk would have a number, so this one did not go to the desk. Applying **modus tollens** to the first rule also rules out clearance.
