A website accepts a file only if it has the PDF extension. If the extension is PDF and the size does not exceed $5$ MB, the website accepts it. A PDF file was rejected. What follows?

- The file is exactly $5$ MB.
- The file has an extension other than PDF.
- The file is larger than $5$ MB.
- The file is smaller than $5$ MB.

## Explanation

For a PDF file, a size no greater than $5$ MB guarantees acceptance. Since the file was rejected, its size must exceed $5$ MB.
