“Without a favorable assessment, the project is not funded.” Which restatement preserves the meaning?

- If the project is funded, it received a favorable assessment.
- If the assessment is favorable, the project is not funded.
- If the project receives a favorable assessment, it is funded.
- If the project is not funded, the assessment is not favorable.

## Explanation

The statement rules out funding in the absence of a favorable assessment. Its **contrapositive** tells us that every funded project must have received such an assessment.
