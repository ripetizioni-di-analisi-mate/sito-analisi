Authorization is granted if and only if the application is complete. The system sends an email whenever authorization is granted. Which entry is consistent with both rules?

- Application incomplete, authorization denied, email sent.
- Application complete, authorization granted, no email sent.
- Application incomplete, authorization granted, email sent.
- Application complete, authorization denied, no email sent.

## Explanation

If the application is incomplete, the **if-and-only-if** rule requires authorization to be denied. The email rule guarantees an email when authorization is granted and leaves open what happens when it is denied.
