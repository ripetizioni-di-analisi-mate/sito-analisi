A system approves a file if the signature is valid or an operator intervenes. Approval means that the file appears on the public list. A file appears on the list and its signature is known to be invalid. Which additional condition would be sufficient to deduce that an operator intervened?

- Files with valid signatures appear on the list.
- When an operator intervenes, the file is approved.
- For a file to appear on the list, it must have a valid signature or an operator must have intervened.
- A valid signature is sufficient for automatic approval.

## Explanation

The additional rule makes at least one of the two events **necessary** for the file to appear on the list. Since the file appears and the signature is invalid, an operator must have intervened.
