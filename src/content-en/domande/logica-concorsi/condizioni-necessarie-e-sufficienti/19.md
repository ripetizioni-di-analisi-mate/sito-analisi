Which statement has the same meaning as “The package is left with the doorman if the recipient is away”?

- The package is left with the doorman only if the recipient is away.
- The package is left with the doorman if and only if the recipient is away.
- The recipient is away or the package is left with the doorman.
- If the recipient is away, the package is left with the doorman.

## Explanation

“$A$ if $B$” translates as “if $B$, then $A$,” so the statement says that when the recipient is away, the package is left with the doorman. The statement with “only if” goes in the opposite direction because it makes the recipient's absence a **necessary condition**. The statement with “or” is true even if the recipient is away and the package is not left with the doorman, the one case that the given statement rules out. Indeed, “if $B$, then $A$” is equivalent to “not $B$ or $A$,” with the first term negated.
