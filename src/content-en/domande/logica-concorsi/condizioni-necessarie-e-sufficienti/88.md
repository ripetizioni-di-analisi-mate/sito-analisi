If an order is urgent, it is given to a courier. An order was given to a courier. Which fact remains undetermined?

- The order was shipped without a courier.
- The order is urgent.
- The order was given to a courier.
- If the order were urgent, it would be given to a courier.

## Explanation

Giving an order to a courier is a consequence of urgency. The same thing can happen with a routine order, for example for an out-of-town delivery.
