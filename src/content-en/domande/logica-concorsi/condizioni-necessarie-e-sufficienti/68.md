In a warehouse, a package must be labeled to be marked “ready to ship.” A labeled package is ready to ship if the weight check is complete. Which log entry violates at least one rule?

- Labeled package, weight to be checked, marked “not ready to ship.”
- Labeled package, weight checked, marked “not ready to ship.”
- Unlabeled package, weight checked, marked “not ready to ship.”
- Labeled package, weight to be checked, marked “ready to ship.”

## Explanation

A label and a completed weight check are jointly **sufficient** for the status “ready to ship.” The entry recording both but marking the package “not ready to ship” contradicts the second rule.
