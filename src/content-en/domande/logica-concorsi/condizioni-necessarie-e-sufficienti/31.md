Which of the following arguments is *not* valid?

- If it rains, the trip is postponed. It is raining. Therefore the trip is postponed.
- If the card terminal is out of order, Ada pays cash. Ada does not pay cash. Therefore the terminal is not out of order.
- If Ivo wins, Lia celebrates. If Lia celebrates, Teo cooks. Therefore, if Ivo wins, Teo cooks.
- If the store is closed, Rino comes back tomorrow. The store is not closed. Therefore Rino does not come back tomorrow.

## Explanation

The argument about the trip uses **modus ponens**, and the argument about the card terminal uses **modus tollens**, so both are valid. The argument about Ivo, Lia, and Teo uses the transitive property of implications and is also valid. The argument about the store negates the antecedent and concludes that the consequent is false. This is the error of **denying the antecedent**. Rino may come back tomorrow even if the store is open, for example to pick up an order.
