A confirmation email is sent if the payment is posted. The payment is posted only if the code is correct. The email was not sent. Which statement is certain?

- The payment was posted.
- The payment was not posted.
- The code is correct.
- The code is incorrect.

## Explanation

If the payment had been posted, the email would have been sent. **Modus tollens** rules out the payment having been posted and leaves the correctness of the code undetermined.
