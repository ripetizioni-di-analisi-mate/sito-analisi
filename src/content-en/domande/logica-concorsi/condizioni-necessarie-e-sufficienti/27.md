The following rule holds: “If Pietro passes the interview, he signs the contract and starts work on Monday.” Pietro did not start work on Monday. Which statement must be true?

- Pietro did not sign the contract.
- Pietro signed the contract and did not pass the interview.
- Pietro passed the interview and did not sign the contract.
- Pietro did not pass the interview.

## Explanation

The consequent is “he signs the contract and starts work on Monday.” It is false because Pietro did not start work on Monday. By **modus tollens**, the antecedent is false as well, so Pietro did not pass the interview. When he does not pass, the rule says nothing about signing the contract. Therefore, neither “Pietro did not sign the contract” nor the statement combining signing with not passing must be true. The statement that Pietro passed the interview contradicts the conclusion.
