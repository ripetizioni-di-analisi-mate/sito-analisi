A store has this rule: “If a product is on sale, it cannot be returned.” Which description of the store's products in terms of sets must be true?

- The set of sale items is contained in the set of returnable items.
- The set of sale items and the set of returnable items have no elements in common.
- The set of nonreturnable items is contained in the set of sale items.
- The set of returnable items is contained in the set of sale items.

## Explanation

The rule says that the set of sale items is contained in the set of items that *cannot* be returned. Thus no sale item is returnable, and the set of sale items and the set of returnable items have no elements in common. Placing the nonreturnable items inside the sale items amounts to the **converse**, “if a product cannot be returned, it is on sale.” This does not follow: a defective product could be excluded from returns without being on sale. An item that is not on sale and can be returned is consistent with the rule and disproves the inclusion of returnable items in sale items. Placing sale items inside returnable items contradicts the rule as soon as the store has a sale item.
