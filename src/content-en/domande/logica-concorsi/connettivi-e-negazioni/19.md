A parking lot gate follows the rule "The gate opens if and only if the code is entered." This morning the gate did not open. Which of the following statements must be true?

- The code was entered
- It is impossible to determine whether the code was entered
- The code was entered or the gate opened
- The code was not entered

## Explanation

A **biconditional** is true when its two parts have the same truth value. The part "the gate opens" is false, so "the code is entered" is false too, and the code was not entered. For the same reason, both parts of the disjunction "The code was entered or the gate opened" are false, so the disjunction is false. The answer "It is impossible to determine" would be correct for the rule "The gate opens only if the code is entered," which says nothing about the code when the gate stays closed.
