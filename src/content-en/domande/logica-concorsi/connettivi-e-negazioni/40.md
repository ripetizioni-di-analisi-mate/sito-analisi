The rule for Dario's leave request is "The manager's signature is required for leave to be granted." Which of the following statements must be true?

- If the request lacks the manager's signature, leave is not granted
- If the request has the manager's signature, leave is granted
- If leave is not granted, the request lacks the manager's signature
- Leave is granted and the request has the manager's signature

## Explanation

The expression "$B$ is required for $A$" means $A \Rightarrow B$, so the rule is "If leave is granted, the request has the manager's signature." By **equivalence to the contrapositive**, this implication is equivalent to "If the request lacks the manager's signature, leave is not granted." "If the request has the manager's signature, leave is granted" is the converse of the rule and is false when the request is signed and leave is denied for another reason. "If leave is not granted, the request lacks the manager's signature" is the inverse, which is equivalent to the converse and false in the same case. The conjunction need not be true because the rule also holds when leave is not granted.
