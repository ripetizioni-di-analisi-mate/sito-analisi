Let $A$ mean “the application is complete,” $B$ “the payment is recorded,” and $C$ “the file is approved.” For every file in an office the rule $\left(A \land B\right) \Rightarrow C$ holds. All that is known about one file is that it is not approved. How many of the four combinations of truth values of $A$ and $B$ are consistent with the rule?

- $1$
- $3$
- $2$
- $0$

## Explanation

An **implication** is false only when its antecedent is true and its consequent is false. Since $C$ is false, the rule is satisfied only if the antecedent $A \land B$ is false. The conjunction $A \land B$ is false when at least one of the two letters is false, so the only excluded combination is the one with $A$ and $B$ both true. There are therefore $3$ consistent combinations. The result $1$ comes from requiring $A$ and $B$ to be both false, as if the antecedent were $A \lor B$.
