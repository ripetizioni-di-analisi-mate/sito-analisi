The rule $(A\lor B)\Rightarrow C$ holds for every file. The only observation is that $C$ is false. How many of the four possible truth-value pairs for $A,B$ remain consistent with the rule?

- $0$
- $1$
- $2$
- $3$

## Explanation

With a false consequent the antecedent must be false. A disjunction is false only if A and B are both false.
