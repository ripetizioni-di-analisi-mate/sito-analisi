Which condition is necessary and sufficient for $\left(A \Rightarrow B\right) \land \left(A \Rightarrow \lnot B\right)$ to be true?

- $\lnot B$
- $A$
- $B$
- $\lnot A$

## Explanation

If $A$ is true, the first implication requires $B$ to be true and the second requires $B$ to be false. The two implications are both true only when $A$ is false.
