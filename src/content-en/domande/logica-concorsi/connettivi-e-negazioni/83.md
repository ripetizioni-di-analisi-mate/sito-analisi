How is $\left(A \Rightarrow B\right) \land \left(A \land \lnot B\right)$ classified as $A$ and $B$ vary in truth value?

- True exactly when both propositions are false.
- True for some assignments and false for others.
- Always true, whatever the truth values of the propositions.
- Always false, whatever the truth values of the propositions.

## Explanation

The inner conjunction requires $A$ to be true and $B$ false. In that case the implication is false, so the full conjunction is always false.
