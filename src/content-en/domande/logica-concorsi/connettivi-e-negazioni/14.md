Which of the following statements is equivalent to "If Luca is on vacation, then if it rains he stays home"? In the answers, "or" is inclusive.

- If Luca is on vacation or it rains, he stays home
- If Luca is on vacation, then it rains and Luca stays home
- If Luca is on vacation and it rains, he stays home
- If Luca stays home, he is on vacation and it rains

## Explanation

Let $F$ = "Luca is on vacation," $P$ = "it rains," and $C$ = "Luca stays home," so the given statement is $F \Rightarrow (P \Rightarrow C)$. This implication is false only when $F$ is true and $P \Rightarrow C$ is false, that is, when $F$ and $P$ are true and $C$ is false. Proposition $(F \land P) \Rightarrow C$ is false in exactly the same case, so the two statements are **equivalent**. "If Luca is on vacation or it rains, he stays home" is also false when Luca is on vacation, it does not rain, and he does not stay home, a case in which the given statement is true. "If Luca is on vacation, then it rains and Luca stays home" is also false in that case. "If Luca stays home, he is on vacation and it rains" is false when Luca stays home without being on vacation, whereas the given statement is true in that case.
