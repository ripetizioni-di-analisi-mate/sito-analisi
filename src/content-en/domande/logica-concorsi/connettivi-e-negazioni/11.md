A compound proposition formed from $A$ and $B$ is true in just one case, when $A$ is false and $B$ is true, and false in the other three cases. Which of the following propositions has this truth table?

- $\lnot (A \Rightarrow B)$
- $\lnot A \lor B$
- $\lnot (A \lor B)$
- $\lnot (B \Rightarrow A)$

## Explanation

By the rule for **negating an implication**, we have $\lnot (B \Rightarrow A) \equiv B \land \lnot A$. This negated implication is true only when $B$ is true and $A$ is false. By contrast, $\lnot (A \Rightarrow B)$ is equivalent to $A \land \lnot B$, which is true only when $A$ is true and $B$ is false. The disjunction $\lnot A \lor B$ is true in three cases because it is false only when $A$ is true and $B$ is false. By **De Morgan's laws**, $\lnot (A \lor B)$ is equivalent to $\lnot A \land \lnot B$, which is true only when $A$ and $B$ are both false.
