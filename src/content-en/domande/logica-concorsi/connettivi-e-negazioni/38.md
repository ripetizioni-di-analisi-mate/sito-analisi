The statement "Neither Oscar nor Pia picked up the package" is true. Which of the following statements is false? In the answers, "or" is inclusive.

- Pia did not pick up the package
- If Oscar picked up the package, Pia did too
- Oscar or Pia picked up the package
- It is not true that Oscar and Pia both picked up the package

## Explanation

"Neither … nor" means "Oscar did not pick up the package and Pia did not pick up the package." By **De Morgan's laws**, this is the negation of "Oscar or Pia picked up the package," so the latter statement is false. "If Oscar picked up the package, Pia did too" has a false antecedent, so it is true. "It is not true that Oscar and Pia both picked up the package" is true because neither of them picked it up.
