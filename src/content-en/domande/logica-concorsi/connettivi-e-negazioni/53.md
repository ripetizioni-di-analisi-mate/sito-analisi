How is $A \Rightarrow \left(A \land B\right)$ classified as $A$ and $B$ vary in truth value?

- Always false, whatever the truth values of the propositions.
- True exactly when $A$ and $B$ have the same truth value.
- Always true, whatever the truth values of the propositions.
- True for some assignments and false for others.

## Explanation

If $A$ is false, the implication is true. If $A$ is true and $B$ is false, the implication is false.
