Which expression represents "The package is picked up only if the code is valid"? Let $A$ = "the package is picked up" and $B$ = "the code is valid."

- $B \Rightarrow A$
- $A \Rightarrow B$
- $A \Leftrightarrow B$
- $A \land \lnot B$

## Explanation

"Only if" indicates a **necessary condition**. Picking up the package requires a valid code, so the arrow points from pickup to validity.
