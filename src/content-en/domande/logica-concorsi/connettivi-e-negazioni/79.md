Which expression represents "Validation is sufficient for the file to be archived"? Let $A$ = "the file is archived" and $B$ = "the file is validated."

- $A \Rightarrow B$
- $A \lor B$
- $A \Leftrightarrow B$
- $B \Rightarrow A$

## Explanation

"Is sufficient for" indicates a **sufficient condition**. Validation implies archiving, so validation is the antecedent.
