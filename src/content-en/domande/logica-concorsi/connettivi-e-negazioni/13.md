Propositions $A$ and $B$ can each be true or false, so there are four possible cases. In how many of these cases is $\lnot (A \land B)$ true?

- $1$
- $3$
- $2$
- $4$

## Explanation

The conjunction $A \land B$ is true in just one case, when $A$ and $B$ are both true. Its negation is true in all the other cases, so in $3$ out of $4$ cases. **De Morgan's laws** give the same count because $\lnot A \lor \lnot B$ is false only when $A$ and $B$ are both true. Choosing $1$ confuses $\lnot (A \land B)$ with $\lnot A \land \lnot B$, which is true only when $A$ and $B$ are both false.
