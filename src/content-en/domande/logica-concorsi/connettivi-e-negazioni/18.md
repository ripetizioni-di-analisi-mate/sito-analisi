Today there is no strike and Elena takes the subway. Which of the following statements is false?

- If there is a strike, Elena takes the subway
- If Elena does not take the subway, there is a strike
- If Elena takes the subway, there is a strike
- If there is a strike, Elena does not take the subway

## Explanation

Let $S$ = "There is a strike," which is false, and $M$ = "Elena takes the subway," which is true. The **implication** "If Elena takes the subway, there is a strike" has a true antecedent $M$ and a false consequent $S$, so it is false. The two statements beginning with "If there is a strike" have a false antecedent, so they are true regardless of the consequent. "If Elena does not take the subway, there is a strike" also has a false antecedent, so it is true.
