Which shorter expression has the same truth table as $A \lor \left(\lnot A \land B\right)$?

- $A \land B$
- $A \lor B$
- $A \Rightarrow B$
- $\lnot A \land B$

## Explanation

If $A$ is true, the entire disjunction is true. If $A$ is false, only $B$ remains to be checked, so the expression is equivalent to the disjunction of $A$ and $B$.
