Propositions $A$ and $B$ can each be true or false, so there are four possible cases. In how many of these cases do $A \Leftrightarrow B$ and $A \Rightarrow B$ have the same truth value?

- $3$
- $2$
- $1$
- $4$

## Explanation

Compare the two truth tables row by row. When $A$ and $B$ are both true or both false, the two propositions are true. When $A$ is true and $B$ is false, both are false. When $A$ is false and $B$ is true, the implication is true and the **biconditional** is false, so the two propositions have the same value in $3$ cases. The answer $4$ treats "if" and "if and only if" as equivalent.
