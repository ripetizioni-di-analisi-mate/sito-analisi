Propositions $A$, $B$, and $C$ can each be true or false, so there are eight possible cases. In how many of these cases is $(A \lor B) \Rightarrow C$ false?

- $1$
- $4$
- $5$
- $3$

## Explanation

An implication is false only when its antecedent is true and its consequent is false. The consequent $C$ is false in $4$ of the $8$ cases, one for each choice of truth values for $A$ and $B$. Among these four choices, the disjunction $A \lor B$ is false only when $A$ and $B$ are both false, so the antecedent is true in $3$ of them. Therefore the proposition is false in $3$ cases. The answer $4$ counts all cases with $C$ false, including the one with a false antecedent, in which the implication is true. The answer $5$ counts the cases in which the proposition is true, and $1$ results from reading $A \lor B$ as $A \land B$.
