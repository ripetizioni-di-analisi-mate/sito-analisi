Which of the following statements means the same as "The class meets in room $3$ unless an exam is in progress"? In the answers, "or" is inclusive unless the words "but not both" appear.

- If an exam is in progress, the class meets in room $3$
- The class meets in room $3$ or an exam is in progress
- Either the class meets in room $3$ or an exam is in progress, but not both
- If no exam is in progress, the class does not meet in room $3$

## Explanation

"$A$ unless $E$" means "if not $E$, then $A$." In the Italian version of this sentence, "non" after "a meno che" does not negate the condition. With $A$ = "the class meets in room $3$" and $E$ = "an exam is in progress," the given statement is therefore $\lnot E \Rightarrow A$. Expressing the **implication as a disjunction** gives the equivalent $E \lor A$, that is, "The class meets in room $3$ or an exam is in progress." Exclusive "or" is false when an exam is in progress and the class still meets in room $3$. The given statement is true in that case because it does not say where the class meets during an exam.
