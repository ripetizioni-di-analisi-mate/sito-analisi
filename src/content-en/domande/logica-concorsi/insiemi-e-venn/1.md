Consider the set $A = \{x \mid x \text{ is a positive divisor of } 36 \text{ and } x > 4\}$. How is $A$ written in roster notation?

- $\{6, 12, 18, 36\}$
- $\{6, 9, 12, 18, 36\}$
- $\{4, 6, 9, 12, 18, 36\}$
- $\{6, 9, 12, 18\}$

## Explanation

The positive divisors of $36$ are $1$, $2$, $3$, $4$, $6$, $9$, $12$, $18$, and $36$. The condition $x > 4$ excludes $1$, $2$, $3$, and also $4$ because the inequality is strict. Therefore, $A = \{6, 9, 12, 18, 36\}$. The number $36$ divides itself and so belongs to $A$. Overlooking it gives the set $\{6, 9, 12, 18\}$. The set $\{4, 6, 9, 12, 18, 36\}$ treats the condition as though it were $x \geq 4$.
