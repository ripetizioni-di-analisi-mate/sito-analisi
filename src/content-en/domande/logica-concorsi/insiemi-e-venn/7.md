Which of the following sets is empty?

- The set of even prime numbers
- The set of integers $x$ such that $x + 5 = 5$
- The set of months of the year with fewer than $28$ days
- The set of days of the week whose Italian names start with the letter s

## Explanation

Every month has at least $28$ days, so none has fewer, and the corresponding set is the **empty set** $\emptyset$. The number $2$ is prime and even, so the set of even primes is $\{2\}$. The equation $x + 5 = 5$ has the solution $x = 0$, so its solution set is $\{0\}$, which has one element and is not empty. The Italian word for Saturday, sabato, starts with s, so the last set also has one element.
