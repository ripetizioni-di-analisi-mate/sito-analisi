Let $A$ be the set of letters in the word ROMA and $B$ the set of letters in the word MARE. What is the set $A \cap B$?

- $\{O\}$
- $\{M, A, R\}$
- $\{O, E\}$
- $\{R, O, M, A, E\}$

## Explanation

We have $A = \{R, O, M, A\}$ and $B = \{M, A, R, E\}$. The **intersection** contains the letters in both words, namely M, A, and R, so $A \cap B = \{M, A, R\}$. The set $\{R, O, M, A, E\}$ is the union, which contains the letters in at least one of the two words. The sets $\{O\}$ and $\{O, E\}$ are, respectively, the difference $A \setminus B$ and the set of letters found in only one of the two words.
