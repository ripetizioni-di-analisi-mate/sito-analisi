How many nonempty proper subsets does the set $\{a, b, c, d, e\}$ have?

- $15$
- $31$
- $30$
- $32$

## Explanation

Each element can be present or absent, so there are $2^5 = 32$ subsets. The condition excludes both the **empty set** and the original set, which is not a proper subset of itself. This leaves $30$.
