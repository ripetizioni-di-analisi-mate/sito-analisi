In the universal set $U = \{1, 2, 3, \ldots, 10\}$, let $A$ be the set of odd numbers and $B$ the set of numbers greater than $6$. How many elements does the set $\overline{A \cap B}$ have?

- $7$
- $8$
- $3$
- $2$

## Explanation

The odd numbers greater than $6$ are $7$ and $9$, so $A \cap B = \{7, 9\}$. The **complement** contains the other elements of $U$, so $\overline{A \cap B}$ has $10 - 2 = 8$ elements. The number $3$ is the size of $\overline{A} \cap \overline{B} = \{2, 4, 6\}$, which by **De Morgan’s law** is the complement of the union rather than of the intersection. The number $7$ is the size of the union $A \cup B = \{1, 3, 5, 7, 8, 9, 10\}$.
