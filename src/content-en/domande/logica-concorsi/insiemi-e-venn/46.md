Which single element can be added to $B=\{2,5\}$ to make $A\setminus B$ lose an element, given $A=\{1,2,3\}$?

- $2$
- $3$
- $4$
- $6$

## Explanation

An element disappears from the difference only if it belongs to A and joins B for the first time. Only 3 meets both requirements.
