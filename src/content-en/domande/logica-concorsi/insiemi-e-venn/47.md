The set $P = \{2, 4, 6, 8\}$ contains the reference numbers of cases already registered. The numbers for which a receipt has arrived form $R = \{1, 2, 4, 7, 8, 9\}$. Which numbers belong to $P \cap R$?

- $\{1, 7, 9\}$
- $\{1, 2, 4, 6, 7, 8, 9\}$
- $\{2, 4, 8\}$
- $\{6\}$

## Explanation

A reference number is in the **intersection** only if it appears in both lists. The numbers $2$, $4$, and $8$ meet this condition. The number $6$ appears only in $P$, while $1$, $7$, and $9$ appear only in $R$.
