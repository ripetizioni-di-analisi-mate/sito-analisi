The complete files form a proper subset of the submitted files. Which statement is guaranteed?

- Every submitted file is complete.
- There is at least one submitted file that is incomplete.
- There is a complete file that has not been submitted.
- There is at least one complete file.

## Explanation

A **proper subset** is contained in the larger set and differs from it. At least one submitted file must therefore lie outside the set of complete files. The set of complete files could even be empty.
