In the universal set $U$, which set contains the elements that fail to belong to at least one of $A$ and $B$?

- $A \cap B$
- $U \setminus (A \cup B)$
- $A \cup B$
- $U \setminus (A \cap B)$

## Explanation

An element is excluded by the description only if it belongs to both $A$ and $B$. The **complement of the intersection** includes all the others, that is, the elements absent from one or both sets.
