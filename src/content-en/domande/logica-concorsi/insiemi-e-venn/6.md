Let $A$ be the set of multiples of $6$, $B$ the set of multiples of $3$, $C$ the set of multiples of $4$, and $D$ the set of even numbers, all within the positive integers. Which of the following relationships is true?

- $A \subseteq C$
- $B \subseteq A$
- $A \subseteq B$
- $D \subseteq C$

## Explanation

Every multiple of $6$ can be written as $6k = 3 \cdot 2k$, so it is also a multiple of $3$. Thus $A \subseteq B$ holds. The inclusion $B \subseteq A$ is false because $3$ is a multiple of $3$ but not of $6$. Similarly, $2$ is even but not a multiple of $4$, so $D \subseteq C$ is false. The number $6$ is a multiple of $6$ but not of $4$, so $A \subseteq C$ is also false. One element of the first set that does not belong to the second suffices to disprove an inclusion.
