How many elements does the set $A = \{x \mid x \text{ is an integer and } x^2 < 10\}$ have? The integers include positive numbers, negative numbers, and zero.

- $6$
- $3$
- $4$
- $7$

## Explanation

We have $3^2 = 9 < 10$ and $4^2 = 16 > 10$, so the positive integers satisfying the condition are $1$, $2$, and $3$. Since $(-x)^2 = x^2$, the condition is also satisfied by $-1$, $-2$, and $-3$, and zero satisfies it because $0^2 = 0$. Therefore, $A = \{-3, -2, -1, 0, 1, 2, 3\}$ and $|A| = 7$. The number $6$ comes from overlooking zero, and $3$ from considering only positive integers.
