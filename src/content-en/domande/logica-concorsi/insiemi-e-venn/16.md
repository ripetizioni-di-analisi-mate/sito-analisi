In the universal set $U = \{1, 2, 3, \ldots, 15\}$, let $A$ be the set of even numbers, $B$ the set of multiples of $3$, and $C$ the set of multiples of $5$. How many elements does the set $(A \cup B) \setminus C$ have?

- $8$
- $9$
- $10$
- $2$

## Explanation

The union of the even numbers and the multiples of $3$ is $A \cup B = \{2, 3, 4, 6, 8, 9, 10, 12, 14, 15\}$, with $10$ elements. The difference removes the multiples of $5$ in the union, namely $10$ and $15$, so $(A \cup B) \setminus C = \{2, 3, 4, 6, 8, 9, 12, 14\}$ has $8$ elements. The number $9$ comes from removing the multiples of $5$ from $B$ only, that is, from calculating $A \cup (B \setminus C)$, which retains $10$. The number $2$ is the size of $(A \cap B) \setminus C = \{6, 12\}$.
