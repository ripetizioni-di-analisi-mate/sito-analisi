Consider the universal set $U = \{A, B, C, D, E, F, G, H\}$. The letters $A, C, E, G$ have a blue mark, and $B, C, F, H$ have a green mark. Which letters have no mark?

- $\{A, E, G\}$
- $\{A, B, D, E, F, G, H\}$
- $\{D\}$
- $\{C\}$

## Explanation

The **union** of the lists contains $A, B, C, E, F, G, H$. Its complement relative to $U$ contains only $D$, the one letter missing from both lists.
