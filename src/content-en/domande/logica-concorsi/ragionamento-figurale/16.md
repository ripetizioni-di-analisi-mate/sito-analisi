Which figure completes the matrix?

::figura{tipo="matrice" celle="stella piccolo x1 | esagono piccolo x2 | rombo piccolo x3 | esagono piccolo x3 | rombo piccolo x1 | stella piccolo x2 | rombo piccolo x2 | stella piccolo x3 | ?"}

- ::figura{tipo="cella" celle="esagono piccolo x2"}
- ::figura{tipo="cella" celle="stella piccolo x1"}
- ::figura{tipo="cella" celle="esagono piccolo x3"}
- ::figura{tipo="cella" celle="esagono piccolo x1"}

## Explanation

Each row contains the star, hexagon, and diamond once; the third row is missing the hexagon shape. The number of figures also follows the **three values in each row** rule: each row contains one cell with $1$ figure, one with $2$, and one with $3$. The third row already contains $2$ diamonds and $3$ stars, so the missing cell contains $1$ figure. The answer is therefore a single hexagon. Two hexagons repeat the count in the first cell of the row. A single star gives the right number but repeats a shape already in the row.
