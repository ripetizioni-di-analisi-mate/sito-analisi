A mosaic uses each of three symbols once in every row and column. All tiles in the same row have the same fill. Which tile is missing?

- ::figura{tipo="cella" celle="rombo grigio"}
- ::figura{tipo="cella" celle="rombo vuoto"}
- ::figura{tipo="cella" celle="rombo pieno"}

## Explanation

The last row already contains the square and the cross, so the diamond is missing. The row's gray fill also applies to the missing tile.
