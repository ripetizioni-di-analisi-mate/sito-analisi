The graph of a function consists only of the points $(-2,4)$, $(0,4)$, and $(3,1)$. What is its domain?

- $\{1,4\}$
- $[-2,3]$
- $\{-2,0,3\}$
- $\{-2,0,1,3,4\}$

## Explanation

The domain is the set of horizontal coordinates of the points on the graph. The given points have horizontal coordinates $-2$, $0$, and $3$, so the domain is $\{-2,0,3\}$. The interval $[-2,3]$ also includes intermediate inputs for which there are no points on the graph. The set $\{1,4\}$ contains the vertical coordinates, which are the values taken by the function. The output $4$ occurs at two different inputs, which the definition of a function allows.
