Which set of ordered pairs represents a function with domain $\{1,2\}$?

- $\{(1,2),(1,3),(2,3)\}$
- $\{(1,3),(2,3)\}$
- $\{(2,1),(2,2)\}$
- $\{(1,2),(3,3)\}$

## Explanation

A function with domain $\{1,2\}$ assigns exactly one output to each of the inputs $1$ and $2$. The set $\{(1,3),(2,3)\}$ satisfies this condition. The two outputs may be equal. The set $\{(1,2),(1,3),(2,3)\}$ assigns two different outputs to the input $1$. The set $\{(2,1),(2,2)\}$ has the same problem at $2$ and does not include the input $1$. The set $\{(1,2),(3,3)\}$ has domain $\{1,3\}$.
