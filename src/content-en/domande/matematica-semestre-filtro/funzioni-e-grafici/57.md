For the function $y=9x-12$, which input gives $y=18$?

- $270$
- $\dfrac{10}{3}$
- $\dfrac{2}{3}$
- $2$

## Explanation

Set $9x-12=18$. Adding $12$ to both sides gives $9x=30$, so
$$
x=\frac{30}{9}=\frac{10}{3}.
$$
Indeed, $9\cdot\dfrac{10}{3}-12=30-12=18$. The value $\dfrac{2}{3}$ comes from subtracting $12$ instead of adding it, that is, solving $9x=6$. The value $270$ multiplies by $9$ instead of dividing.
