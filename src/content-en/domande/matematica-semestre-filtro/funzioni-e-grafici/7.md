An object maintains a velocity of $6\,\mathrm{m/s}$ for $4\,\mathrm{s}$. Calculate the displacement using the area on the velocity–time graph.

- $\dfrac{3}{2}\,\mathrm{m}$
- $12\,\mathrm{m}$
- $24\,\mathrm{m}$
- $10\,\mathrm{m}$

## Explanation

For constant velocity, the velocity–time graph is a horizontal segment at height $6\,\mathrm{m/s}$. The region under the graph is a rectangle of base $4\,\mathrm{s}$ and height $6\,\mathrm{m/s}$, so
$$
\Delta s=(6\,\mathrm{m/s})(4\,\mathrm{s})=24\,\mathrm{m}.
$$
Meters per second times seconds gives meters, as required for a displacement. The value $12\,\mathrm{m}$ uses the triangle formula, which applies when the velocity increases linearly from zero. The value $\dfrac{3}{2}\,\mathrm{m}$ divides velocity by time.
