For which values of $y$ does the relation $x=11$ hold in the Cartesian plane?

- For every real $y$.
- Only when $y$ equals $x$.
- Only for $y=0$.
- For no value of $y$.

## Explanation

The relation $x=11$ puts a condition only on the horizontal coordinate and does not involve $y$. Thus every point $(11,y)$ satisfies it, whatever the real value of $y$. In the Cartesian plane these points form the vertical line that meets the horizontal axis at $11$. The answer $y=0$ gives only the point where the line meets the horizontal axis. For the same reason the relation $x=11$ does not define $y$ as a function of $x$.
