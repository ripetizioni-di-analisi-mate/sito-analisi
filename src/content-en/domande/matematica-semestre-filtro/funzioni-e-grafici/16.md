For the function $f(x)=x^2$ with domain $[-1,3]$, which inputs in the domain have output $4$?

- Only $x=2$
- $x=-2$ and $x=2$
- Only $x=-2$
- Only $x=16$

## Explanation

To work backward from the output, solve $x^2=4$. Over the real numbers this equation has two solutions, $x=-2$ and $x=2$. However, the domain is $[-1,3]$, and $-2<-1$, so $x=-2$ is not an allowed input. Thus the only input in the domain that gives $4$ is $x=2$. The answer “$x=-2$ and $x=2$” omits the domain check, while $x=16$ evaluates $f(4)$ instead of solving $f(x)=4$.
