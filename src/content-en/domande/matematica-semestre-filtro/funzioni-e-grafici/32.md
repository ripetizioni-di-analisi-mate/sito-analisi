A function satisfies $f(1)=4$ and $f(3)=4$. Which statement follows from this information?

- The function is undefined at $x=2$.
- Two different inputs can have the same output.
- The function is constant throughout its domain.
- The output $4$ corresponds to only one input.

## Explanation

The definition of a function requires exactly one output per input and allows different inputs to have the same output. This is precisely what the data show because the distinct inputs $1$ and $3$ both have output $4$. These two values give no information about the value at $x=2$, so we cannot conclude that the function is constant or that it is undefined at $2$. The data contradict the claim that the output $4$ corresponds to only one input.
