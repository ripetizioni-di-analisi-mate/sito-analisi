The relation $x=2$ is defined for every real $y$. Why does its graph fail to represent a function of $x$?

- The horizontal coordinate $2$ is positive.
- The vertical coordinate $0$ does not occur on the graph.
- The same horizontal coordinate $2$ has more than one vertical coordinate.
- The graph contains no points with horizontal coordinate $2$.

## Explanation

On the graph of a function of $x$, each horizontal coordinate in the domain corresponds to exactly one point. The set $x=2$ is a vertical line and contains, for example, the points $(2,0)$ and $(2,1)$. Thus the same horizontal coordinate $2$ has infinitely many vertical coordinates, so the relation does not define $y$ as a function of $x$. The sign of the horizontal coordinate is irrelevant, and the vertical coordinate $0$ does occur on the graph because the point $(2,0)$ satisfies the relation.
