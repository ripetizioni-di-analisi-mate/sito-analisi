Two forces are drawn in the same plane. The second arrow is twice as long as the first on paper. Which condition guarantees that its magnitude is twice as large, irrespective of the directions of the arrows?

- It is enough for the arrows to start at the same point.
- It is enough for the arrows to be perpendicular.
- The same force scale is used for both arrows, and the two axes have the same scale.
- It is enough for the axes of the graph to be labeled.

## Explanation

In a drawing, arrow length is proportional to force magnitude only when a fixed scale is used, for example $1\,\mathrm{cm}$ for $1\,\mathrm{N}$. If both arrows use the same force scale and both axes have the same length scale, an arrow twice as long represents twice the force magnitude in any direction.
