A sensor counts $60$ complete oscillations in $30\,\mathrm{s}$ at constant frequency. What is the frequency in hertz?

- $2\,\mathrm{Hz}$
- $0.5\,\mathrm{Hz}$
- $30\,\mathrm{Hz}$
- $1800\,\mathrm{Hz}$

## Explanation

Frequency is the number of complete oscillations per unit time. In $30\,\mathrm{s}$ the sensor counts $60$ oscillations, so
$$
f=\frac{60}{30\,\mathrm{s}}=2\,\mathrm{s^{-1}}=2\,\mathrm{Hz},
$$
because one hertz corresponds to one oscillation per second. The value $0.5\,\mathrm{Hz}$ comes from inverting the quotient, which gives the period in seconds. The value $1800\,\mathrm{Hz}$ comes from multiplying the number of oscillations by the time. The value $30\,\mathrm{Hz}$ is the numerical value of the measurement duration.
