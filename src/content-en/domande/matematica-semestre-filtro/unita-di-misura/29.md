A positive length expressed in $\mu\mathrm{m}$ is converted to $\mathrm{nm}$. Which statement is correct?

- The numerical value decreases because a smaller unit is used.
- The numerical value stays the same because the quantity is the same.
- The numerical value increases because a smaller unit is used.
- The physical length increases with the numerical value.

## Explanation

One micrometer contains one thousand nanometers, so the conversion multiplies the numerical value by $1000$, as in $2\,\mu\mathrm{m}=2000\,\mathrm{nm}$. The physical length remains the same because only the unit used to measure it changes. Since the nanometer is a smaller unit, more nanometers are needed to span the same length, so the numerical value increases. The claim that the value stays the same confuses the quantity with its numerical value, which depends on the unit chosen.
