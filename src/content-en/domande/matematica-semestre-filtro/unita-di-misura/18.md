How many cm³ equal $3\,\mathrm{L}$?

- $30$
- $3000$
- $0.003$
- $300$

## Explanation

A liter is a cubic decimeter. Since $1\,\mathrm{dm}=10\,\mathrm{cm}$, a cubic decimeter contains $10^3=1000$ cubic centimeters, so
$$
3\,\mathrm{L}=3\,\mathrm{dm^3}=3\cdot10^{3}\,\mathrm{cm^3}=3000\,\mathrm{cm^3}.
$$
The value $30$ comes from using the linear factor $10$ without cubing it. The value $300$ comes from using the square $10^2$, the conversion factor for areas. The value $0.003$ corresponds to the reverse conversion.
