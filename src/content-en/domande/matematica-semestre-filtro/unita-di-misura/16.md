How many nanometers equal $3\,\mu\mathrm{m}$?

- $3$
- $300$
- $0.003$
- $3000$

## Explanation

The prefix micro denotes $10^{-6}$ and the prefix nano denotes $10^{-9}$, so one micrometer contains $\dfrac{10^{-6}}{10^{-9}}=10^{3}$ nanometers. Therefore
$$
3\,\mu\mathrm{m}=3\cdot10^{3}\,\mathrm{nm}=3000\,\mathrm{nm}.
$$
The nanometer is smaller than the micrometer, so the numerical value increases. The value $0.003$ comes from dividing by one thousand, using the reciprocal factor. The value $300$ comes from using the factor $100$ instead of $1000$.
