Convert $6\,\mathrm{mm}$ to micrometers.

- $6000$
- $600$
- $0.006$
- $60$

## Explanation

The prefix milli denotes $10^{-3}$ and the prefix micro denotes $10^{-6}$, so one millimeter contains $\dfrac{10^{-3}}{10^{-6}}=10^{3}$ micrometers. Therefore
$$
6\,\mathrm{mm}=6\cdot10^{3}\,\mu\mathrm{m}=6000\,\mu\mathrm{m}.
$$
The micrometer is smaller than the millimeter, so the numerical value increases. The value $0.006$ comes from inverting the factor and dividing by one thousand. The value $600$ comes from using the factor $100$, as if a micrometer were one hundredth of a millimeter.
