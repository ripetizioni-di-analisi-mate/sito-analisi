Convert $6\,\mathrm{cm^2}$ to $\mathrm{mm^2}$.

- $6000$
- $60$
- $0.06$
- $600$

## Explanation

One centimeter contains $10\,\mathrm{mm}$. Since area is the product of two lengths, the linear factor is squared, so $1\,\mathrm{cm^2}=(10\,\mathrm{mm})^2=100\,\mathrm{mm^2}$. Therefore
$$
6\,\mathrm{cm^2}=6\cdot100\,\mathrm{mm^2}=600\,\mathrm{mm^2}.
$$
The value $60$ comes from using the linear factor $10$ without squaring it. The value $6000$ comes from using the factor $10^3$, which applies to volumes. The value $0.06$ corresponds to the reverse conversion.
