Which of the four values is greatest?

- $\dfrac{7}{15}$
- 0.6
- 0.4
- $\dfrac{8}{15}$

## Explanation

To compare fractions and decimals, write them all with the same denominator $15$. Since $0.6=\dfrac{3}{5}=\dfrac{9}{15}$ and $0.4=\dfrac{2}{5}=\dfrac{6}{15}$, the four values are
$$
\frac{7}{15},\qquad \frac{9}{15},\qquad \frac{6}{15},\qquad \frac{8}{15}.
$$
When fractions have the same positive denominator, the one with the greatest numerator is greatest, so the greatest value is $0.6$. Choosing $\dfrac{8}{15}$ compares only the values originally written as fractions.
