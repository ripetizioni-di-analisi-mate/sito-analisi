The measured value is $48\,\mathrm{g}$ and the reference value is $50\,\mathrm{g}$. What is the absolute error as a percentage of the reference value?

- $2\%$
- $\dfrac{25}{6}\%$
- $4\%$
- $96\%$

## Explanation

The absolute error is the absolute difference between the reference value and the measurement, $50\,\mathrm{g}-48\,\mathrm{g}=2\,\mathrm{g}$. To express it as a percentage of the reference, divide by $50\,\mathrm{g}$.
$$
\frac{2\,\mathrm{g}}{50\,\mathrm{g}}=\frac{4}{100}=4\%.
$$
Dividing by the measured value $48\,\mathrm{g}$ instead of the reference gives $\dfrac{25}{6}\%$. The value $96\%$ is the ratio of the measurement to the reference, while $2\%$ treats the error in grams as a percentage.
