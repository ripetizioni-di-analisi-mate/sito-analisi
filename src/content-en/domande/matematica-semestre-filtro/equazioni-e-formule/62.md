Which statement about the equation $k(x+1)=3x+k$, where $k$ is a fixed real number, is true?

- For $k\ne3$, the only solution is $x=0$. For $k=3$, every real $x$ is a solution.
- For $k\ne3$, the only solution is $x=\dfrac{k}{k-3}$. For $k=3$, there are no solutions.
- For $k=3$, the equation has no solutions. For all other values of $k$, $x=0$ is a solution.
- For every $k$, the only solution is $x=0$.

## Explanation

Expand the left side, subtract $k$ from both sides, and collect the terms in $x$.
$$
kx+k=3x+k,\qquad (k-3)x=0 .
$$
For $k\ne3$, the coefficient is nonzero, so the only solution is $x=0$. For $k=3$, we obtain $0=0$, which is true for every $x$. The formula $x=\dfrac{k}{k-3}$ fails to satisfy the equation because at $k=4$ it would give $x=4$, where the left side equals $20$ and the right side equals $16$.
