To estimate $\sqrt{1.01}$ without a calculator, you want an upper bound that can be checked by squaring just once. Which argument works?

- $1.005^2=1.010025>1.01$, so $\sqrt{1.01}<1.005$.
- $1^2<1.01$, so $\sqrt{1.01}<1$.
- $1.001^2<1.01$, so $\sqrt{1.01}<1.001$.
- $1.005^2>1.01$, so $\sqrt{1.01}>1.005$.

## Explanation

Squaring preserves order on the positive numbers. Here $(1+0.005)^2=1+0.01+0.000025>1.01$. Thus $1.005$ lies above the desired square root. A number whose square is below $1.01$ would give a lower bound.
