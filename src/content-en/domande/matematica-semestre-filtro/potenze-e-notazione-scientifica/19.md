Calculate $\dfrac{\left(6\cdot10^{-2}\right)^3}{\left(3\cdot10^{-1}\right)^3}$ and give the result in scientific notation.

- $8\cdot10^{-1}$
- $2\cdot10^{-1}$
- $8\cdot10^{-9}$
- $8\cdot10^{-3}$

## Explanation

The numerator and denominator have the same exponent $3$, so the quotient rule for powers with the same exponent, $\dfrac{a^3}{b^3}=\left(\dfrac{a}{b}\right)^3$, lets us divide the bases first.
$$
\frac{6\cdot10^{-2}}{3\cdot10^{-1}}=2\cdot10^{-2-(-1)}=2\cdot10^{-1},\qquad\left(2\cdot10^{-1}\right)^3=8\cdot10^{-3}.
$$
The coefficient $8$ lies between $1$ and $10$, so the result is normalized. The value $2\cdot10^{-1}$ comes from omitting the cube. The value $8\cdot10^{-1}$ comes from cubing only the coefficient. The value $8\cdot10^{-9}$ comes from multiplying $10^{-6}$ by $10^{-3}$ instead of dividing.
