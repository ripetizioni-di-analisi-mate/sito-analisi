The identity $x^n=1/x^2$ must hold for every $x>0$. A student uses only $x=1$ to select $n$. Which additional test actually identifies the exponent?

- $x=0$, because $0^n$ is always zero.
- $x=1$, because $1^n=1$ only when $n=1$.
- $x=-1$, because all even powers have different values there.
- $x=2$, because $2^n=1/4$ implies $n=-2$.

## Explanation

Every exponent gives the same answer at base one. Base two belongs to the domain and gives distinct powers for distinct exponents. Since $1/2^2=1/4$, that test selects $n=-2$, which the definition of a negative exponent then confirms.
