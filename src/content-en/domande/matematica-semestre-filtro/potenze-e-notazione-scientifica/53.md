A memory of $1.0\cdot10^6$ bytes is available for complete files of $3.0\cdot10^4$ bytes each. Treat the sizes as exact and ignore file headers. What is the maximum number of files that fit?

- $333$
- $34$
- $30$
- $33$

## Explanation

Dividing capacity by file size gives $100/3=33.33\ldots$. The largest number of whole files is the integer below this quotient. Thirty-three files use $990\,000$ bytes, whereas thirty-four would require $1\,020\,000$ bytes.
