For which real values of $x$ is $(x-2)^0$ defined under the zero-exponent rule?

- For all real numbers.
- Only for $x=2$.
- For all real numbers satisfying $x\ne2$.
- Only for $x>2$.

## Explanation

The convention $a^0=1$ holds only for nonzero bases, so $(x-2)^0$ requires $x-2\ne0$, that is, $x\ne2$. For every real $x\ne2$ the power equals $1$. For $x=2$ the expression would be $0^0$, which the rule does not define. The answer “for all real numbers” overlooks the condition on the base. The answer “only for $x>2$” imposes a positive-base condition used for fractional exponents.
