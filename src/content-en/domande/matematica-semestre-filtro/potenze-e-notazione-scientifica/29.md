Which expression has the smallest value?

- $-4^2$
- $(-4)^2$
- $(-4)^3$
- $4^{-1}$

## Explanation

Evaluate each expression by applying the exponent only to its base. In $-4^2$ the exponent applies to $4$, so $-4^2=-16$. In $(-4)^2$ the base is $-4$ and the exponent is even, so the value is $16$. In $(-4)^3$ the exponent is odd, so the value is $-64$. Finally, $4^{-1}=\dfrac14$. Since $-64<-16<\dfrac14<16$, $(-4)^3$ has the smallest value.
