Calculate $3.02\cdot10^4-4.0\cdot10^2$ using exact values. Express the result in scientific notation.

- $2.62\cdot10^4$
- $2.98\cdot10^2$
- $2.98\cdot10^4$
- $3.06\cdot10^4$

## Explanation

To subtract, express both terms using the same power of ten. Since $4.0\cdot10^{2}=400=0.04\cdot10^{4}$, subtract the coefficients.
$$
3.02\cdot10^4-0.04\cdot10^4=2.98\cdot10^4.
$$
The result is already normalized. The value $2.62\cdot10^{4}$ comes from rewriting $4.0\cdot10^{2}$ as $0.4\cdot10^{4}$, moving the decimal point only one place. The value $3.06\cdot10^4$ comes from adding instead of subtracting. The value $2.98\cdot10^2$ comes from keeping the exponent of the second term.
