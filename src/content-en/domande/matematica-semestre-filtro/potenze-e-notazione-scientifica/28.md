A program accepts a real-valued reading $x$ and calculates the factor $x^{-2}$. Which single value must it exclude for the factor to be defined?

- $0$
- $1$
- $-1$
- $-2$

## Explanation

By definition $x^{-2}=\dfrac{1}{x^2}$, so the factor is defined when its denominator $x^2$ is nonzero. Since $x^2=0$ only when $x=0$, the program must exclude only $0$. For $x=1$, $x=-1$, and $x=-2$, the factor equals $1$, $1$, and $\dfrac14$, respectively. The answer $-2$ comes from confusing the exponent with a value of the base.
