Find the number $k>0$ for which $\log_2 k=\log_4 9$.

- $9$
- $81$
- $\dfrac{9}{2}$
- $3$

## Explanation

Use the change-of-base formula to write $\log_4 9$ in base two, since $\log_2 4=2$.

$$
\log_4 9=\frac{\log_2 9}{\log_2 4}=\frac{\log_2\left(3^2\right)}{2}=\frac{2\log_2 3}{2}=\log_2 3.
$$

The base-two logarithm is one-to-one, so $\log_2 k=\log_2 3$ gives $k=3$. The value $9$ overlooks the change of base. The value $81$ multiplies the logarithm by two instead of dividing it by two, since $\log_2 81=2\log_2 9$. The value $\dfrac92$ divides the argument by two instead of dividing the logarithm.
