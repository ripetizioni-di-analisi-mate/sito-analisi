What is $x$ if $3^x=\dfrac{1}{27}$?

- $-2$
- $-3$
- $3$
- $-6$

## Explanation

Since $27=3^3$, the reciprocal can be written as $\dfrac1{27}=3^{-3}$, because a negative exponent gives the reciprocal of the corresponding power. Both sides are then powers of the same base, and the function $3^x$ is strictly increasing, so the exponents are equal.

$$
3^x=3^{-3},\qquad x=-3.
$$

The value $3$ overlooks the fact that the right-hand side is a reciprocal. The value $-2$ comes from using the wrong power, because $3^{-2}=\dfrac19$.
