Find the approximate value of $x$ if $\log_{10}(x)=-2.30$, using $\log_{10}(2)\approx0.30$.

- $2\cdot10^{-2}$
- $5\cdot10^{-2}$
- $5\cdot10^{-3}$
- $2\cdot10^{-3}$

## Explanation

By definition, $x=10^{-2.30}$. Split the exponent into an integer part and a fractional part, since the exponents add when powers with the same base are multiplied.

$$
x=10^{-2}\cdot10^{-0.30}\approx10^{-2}\cdot\frac12=5\cdot10^{-3}.
$$

Indeed, $10^{0.30}\approx2$, since $\log_{10}2\approx0.30$. The value $2\cdot10^{-3}$ comes from using $10^{-0.30}\approx2$ in place of $\dfrac12$. The values with $10^{-2}$ are of the order of magnitude expected for a number whose logarithm lies between $-2$ and $-1$.
