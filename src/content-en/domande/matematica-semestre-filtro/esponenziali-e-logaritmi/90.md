A quantity increases by $25\%$ each hour, each time relative to its value at the start of the hour. After how many whole hours does it first exceed twice its initial value?

- $4$
- $3$
- $5$
- $8$

## Explanation

After $n$ hours the initial value is multiplied by $1.25^n$, so we seek the smallest integer $n$ for which $1.25^n>2$.

$$
1.25^3=1.953125<2,\qquad 1.25^4=2.44140625>2.
$$

The sequence $1.25^n$ is increasing, so the answer is $n=4$. The value $3$ comes from rounding $\log_{1.25}2\approx3.11$ down. The value $5$ corresponds to a linear model in which four increases of $25\%$ give exactly twice the initial value. The value $8$ equals $\dfrac{2}{0.25}$.
