At times $0$, $1$, and $2$, a quantity has values of $100$, $80$, and $64$ units. According to the constant-factor model consistent with these data, what is its value at time $4$?

- $40.96$ units
- $32$ units
- $48$ units
- $51.2$ units

## Explanation

The ratios of consecutive measurements are equal, since

$$
\frac{80}{100}=\frac{64}{80}=0.8,
$$

so the factor per unit time is $q=0.8$. At time $4$, the initial value is multiplied by $q^4=0.4096$, giving $100\cdot0.4096=40.96$ units. The value $51.2$ units is the value at time $3$. The value $32$ units continues to use the difference $-16$ from the last interval as a constant difference, as in a linear model.
