For which positive coefficients $k$ is $\log_2(kx)=1+\log_2 x$ an identity for every $x>0$?

- For every $k>1$.
- For no $k>0$.
- Only $k=1$.
- Only $k=2$.

## Explanation

Set $x=1$ to see that $\log_2 k=1$ is necessary, so $k=2$. It also suffices because $\log_2(2x)=\log_2 2+\log_2 x=1+\log_2 x$ for every $x>0$.
