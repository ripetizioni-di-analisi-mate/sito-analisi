The sound intensity level is $10\log_{10}\dfrac{I}{I_0}$ decibels. The intensity $I$ is given in $\mathrm{mW/m^2}$ and the reference intensity $I_0$ in $\mathrm{W/m^2}$. Which step must be carried out before calculating the ratio $\dfrac{I}{I_0}$?

- Express both intensities in the same unit.
- None, because the logarithm removes the units.
- Take the logarithm of each value and multiply the results.
- Change the base of the logarithm from ten to one thousand.

## Explanation

The ratio $\dfrac{I}{I_0}$ is a pure number only if the numerator and the denominator are expressed in the same unit. Since $1\,\mathrm{mW/m^2}=10^{-3}\,\mathrm{W/m^2}$, the numerical value of $I$ in milliwatts per square metre must be divided by $1000$ before forming the ratio, or else $I_0$ is expressed in milliwatts per square metre. If the two numerical values are divided directly, the ratio is $1000$ times too large. Consequently the calculated level exceeds the correct one by $10\log_{10}1000=30$ decibels.
