A positive point source generates a field in a vacuum. Use $k=9\cdot10^9\,\mathrm{N\,m^2/C^2}$. The distance is expressed in centimeters. Initially, the given quantities are the source charge value $q = 4\,\mathrm{nC}$ and the distance from the source $r = 6\,\mathrm{cm}$. In the second configuration, we change the source charge value to $9\,\mathrm{nC}$ and the distance from the source to $3\,\mathrm{cm}$, with all other data unchanged. What is the final value minus the initial value of $E$?

- $80000\,\mathrm{N/C}$
- $210000\,\mathrm{N/C}$
- $-80000\,\mathrm{N/C}$
- $80\,\mathrm{N/C}$

## Explanation

We apply $E=kq/r^2$. For the conversion, one nanocoulomb equals $10^{-9}\,\mathrm C$ and one centimeter equals $10^{-2}\,\mathrm m$. Applying $E = \dfrac{90000 \cdot q}{r^{2}}$ gives $10000\,\mathrm{N/C}$ before the change and $90000\,\mathrm{N/C}$ afterward. The final value minus the initial value is $80000\,\mathrm{N/C}$.
