In a Young experiment the slits are $d = 0.30\,\mathrm{mm}$ apart and each is $a = 0.060\,\mathrm{mm}$ wide, so the interference pattern is modulated by the diffraction pattern of each slit. How many bright interference fringes fall inside the central diffraction maximum?

- $11$
- $10$
- $9$
- $5$

## Explanation

The central diffraction maximum lies between the first minima, that is, between the directions with $a\sin\theta = \pm\lambda$, so it contains the directions with $|\sin\theta| < \dfrac{\lambda}{a}$.

The bright interference fringes lie in the directions with $\sin\theta = \dfrac{m\lambda}{d}$. Therefore those with $|m| < \dfrac{d}{a} = 5$ fall in the central maximum.

The fringes with $m = \pm 5$ coincide with the first diffraction minima, where the intensity is zero, so they are not seen. The fringes with $m = -4, \dots, 4$ remain, that is, $9$ bright fringes.
