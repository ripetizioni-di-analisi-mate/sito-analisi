A real object is $p=5\,\mathrm{cm}$ from a converging lens with $f=10\,\mathrm{cm}$. What is $q$, using the convention that virtual images have negative distances?

- $10\,\mathrm{cm}$
- $-10\,\mathrm{cm}$
- $-5\,\mathrm{cm}$
- $20\,\mathrm{cm}$

## Explanation

The lens formula gives $\dfrac{1}{q}=\dfrac{1}{10}-\dfrac{1}{5}=-\dfrac{1}{10}$ in inverse centimeters. The image is virtual because the object is within the focal length. The result is $-10\,\mathrm{cm}$.
