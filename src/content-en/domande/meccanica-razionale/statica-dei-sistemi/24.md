In a system of rigid bodies connected also by an ideal string, the cardinal equations give for the tension of the string the value $T = -\,5\,\mathrm{N}$. How is this result read?

- The tension equals $5\,\mathrm{N}$ and the string is taut
- The string pushes the bodies with magnitude $5\,\mathrm{N}$
- The string goes slack, therefore the configuration is to be re-examined without it
- The system is statically indeterminate

## Explanation

An ideal string is a unilateral constraint, since it pulls the bodies to which it is attached and does not push them, therefore its tension satisfies $T \ge 0$. The negative value means that to maintain the configuration a push would be needed, that is, an action that the string cannot exert, therefore in that configuration the string is slack and exerts no force. The computation is then to be repeated by removing the string from the system, and the equilibrium configuration is to be sought among those compatible with the remaining constraints.

The same reasoning holds for a unilateral support, where a negative normal reaction signals the detachment of the body from the constraint.
