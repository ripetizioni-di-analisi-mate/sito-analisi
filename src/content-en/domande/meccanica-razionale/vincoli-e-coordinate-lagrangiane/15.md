A material point $P$ hangs from the fixed point $O$ by an inextensible and flexible string of length $\ell$, and the string can become slack. Which relation expresses the constraint?

- $|P - O| = \ell$
- $|P - O| \leq \ell$
- $|P - O| \geq \ell$
- $|P - O| < \ell$

## Explanation

The string is inextensible, therefore it prevents the point from moving away from $O$ beyond the length $\ell$; the string is flexible, hence it leaves the point free to come closer to $O$. The constraint then admits all the configurations with $|P - O| \leq \ell$, that is, it is written as the inequality $\ell^2 - |P - O|^2 \geq 0$ and it is a unilateral constraint. The equality $|P - O| = \ell$ holds only in the boundary configurations, those with the string taut, in which the string exerts a tension $T \geq 0$ directed toward $O$; in the ordinary configurations, with $|P - O| < \ell$, the string is slack and exerts no force.
