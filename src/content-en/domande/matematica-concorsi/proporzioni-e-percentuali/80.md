A first branch receives $75$ requests and a second receives $120$. If the first branch is assigned an index of $100$, what is the index of the second branch?

- $145$
- $160$
- $62.5$
- $120$

## Explanation

To find the **index with base $100$**, divide the second branch's count by the first branch's count and multiply by $100$. This gives $(120\div75)\cdot100=160$.
