A supply of hay lasts $20$ days for $15$ horses. If each horse eats the same amount every day, how many days will the same supply feed $12$ horses?

- $25$
- $16$
- $17$
- $23$

## Explanation

For a fixed supply, the number of horses and the number of days are **inversely proportional** because their product is the total number of daily rations. The hay provides $15 \cdot 20 = 300$ rations, so for $12$ horses it lasts $\dfrac{300}{12} = 25$ days. The value $16$ uses direct variation and can be ruled out because the supply lasts longer with fewer horses.
