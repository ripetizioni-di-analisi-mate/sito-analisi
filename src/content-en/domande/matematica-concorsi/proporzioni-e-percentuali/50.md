A print shop uses $15$ reams of paper to print $600$ identical booklets. How many reams does it need for $840$ booklets?

- $21$
- $24$
- $25$
- $18$

## Explanation

The number of booklets is **directly proportional** to the number of reams used. Each ream makes $600\div15=40$ booklets, so $840$ booklets require $21$ reams.
