A print shop uses $15$ reams of paper to print $600$ identical booklets. How many reams does it need for $840$ booklets?

- $21$
- $24$
- $25$
- $18$

## Explanation

The number of booklets is **directly proportional** to the number of reams used. One ream prints $\dfrac{600}{15} = 40$ booklets, so $840$ booklets require $\dfrac{840}{40} = 21$ reams. The same result follows from the ratio $\dfrac{840}{600} = 1.4$, because the reams grow in the same ratio as the booklets and $15 \cdot 1.4 = 21$.
