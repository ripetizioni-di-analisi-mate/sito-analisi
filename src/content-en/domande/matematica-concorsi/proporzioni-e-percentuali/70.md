An index with base 100 rises to 150. It is then rebased so the new value is 100. What index does the original value receive on the new scale?

- $50$
- $75$
- $125$
- $\dfrac{200}{3}$

## Explanation

The new index uses 150 as its denominator. The original value is assigned $100\cdot\dfrac{100}{150}=\dfrac{200}{3}$.
