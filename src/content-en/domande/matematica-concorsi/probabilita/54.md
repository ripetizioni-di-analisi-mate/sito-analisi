A drawer contains $8$ keys that feel identical, only one of which opens a door. One key is chosen at random. What is the probability that it opens the door?

- $\dfrac{1}{7}$
- $\dfrac{7}{8}$
- $\dfrac{1}{8}$
- $\dfrac{1}{2}$

## Explanation

The eight keys are equally likely to be chosen. Only one fits, so the probability is $\dfrac{1}{8}$.
