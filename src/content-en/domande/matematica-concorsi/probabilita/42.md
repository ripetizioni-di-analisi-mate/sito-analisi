A call center received $300$ calls in one month, and $45$ lasted longer than $10$ minutes. Using the relative frequency to estimate the probability, how many calls lasting longer than $10$ minutes would you expect among $1000$ calls?

- $45$
- $15$
- $850$
- $150$

## Explanation

The **relative frequency** of calls lasting longer than $10$ minutes is $\dfrac{45}{300} = 0.15$, which provides an estimate of the probability. The expected count for $1000$ calls is $1000 \cdot 0.15 = 150$. The value $15$ reads the percentage $15\%$ as a number of calls. The value $850$ is the expected count of calls lasting at most $10$ minutes.
