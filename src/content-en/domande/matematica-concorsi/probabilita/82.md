One service counter receives twice as many case files as a second counter. At the first, $\dfrac{1}{10}$ of the files contain an error. At the second, $\dfrac{1}{5}$ contain an error. One of the files with an error is chosen at random. What is the probability that it came from the first counter?

- $\dfrac{1}{10}$
- $\dfrac{1}{3}$
- $\dfrac{2}{3}$
- $\dfrac{1}{2}$

## Explanation

If the second counter receives $10n$ files, the first receives $20n$. Each counter has $2n$ files with an error, so the probability that a file chosen from those with errors came from the first counter is $\dfrac{1}{2}$.
