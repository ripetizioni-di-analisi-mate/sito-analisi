Using the $21$-letter Italian alphabet, which element comes next in the sequence A1, C4, F9, L16, …?

- O25
- Q32
- Q25
- P25

## Explanation

In this **mixed sequence** the letters and numbers follow separate rules. The letters A, C, F, L occupy positions $1, 3, 6, 10$ in the Italian alphabet, with differences $2, 3, 4$, so the next letter is in position $10 + 5 = 15$ and is Q. The numbers $1, 4, 9, 16$ are the squares of $1, 2, 3, 4$, so the next number is $5^2 = 25$. The element Q32 doubles $16$, P25 repeats the difference $4$ between letter positions, and O25 looks up position $15$ in the English alphabet.
