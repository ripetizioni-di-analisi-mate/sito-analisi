In the codes A1, C4, F9, L16, each number is the square of the code's position. The position of its letter in the Italian alphabet is the sum $1+2+\cdots+n$ for code $n$. A clerk records the fifth as P25. Which part needs correcting, given that P and Q occupy positions $14$ and $15$?

- Only the number, from $25$ to $20$
- Neither part
- Only the letter, from P to Q
- Both parts, giving Q36

## Explanation

At position five the numerical part is $5^2=25$, so it is correct. The letter must be at position $1+2+3+4+5=15$, which is Q. The correct code is Q25.
