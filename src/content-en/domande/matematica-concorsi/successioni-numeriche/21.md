A register uses the rule “add the previous two” and reads $3,7,10,?,27,44$. Which value fills the gap consistently with the entries on both sides?

- $13$
- $20$
- $14$
- $17$

## Explanation

The third term is the sum of the two preceding ones because $3 + 7 = 10$, so the sequence follows the rule for the **Fibonacci sequence**. The missing term is therefore $7 + 10 = 17$. The rule also holds for the following terms because $10 + 17 = 27$ and $17 + 27 = 44$. The value $13$ adds $3$ as if the differences were constant, and $20$ doubles the preceding term.
