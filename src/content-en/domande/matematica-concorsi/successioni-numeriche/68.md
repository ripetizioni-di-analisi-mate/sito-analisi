A sequence replaces its current value $u$ by $\dfrac{u}{2}-3$. You want to start at a value that remains unchanged after every update. Which starting value should you choose?

- $6$
- $0$
- $-6$
- $-3$

## Explanation

For the first update to preserve $u$, we need $u=\dfrac{u}{2}-3$. Subtracting $\dfrac{u}{2}$ and multiplying by two gives $u=-6$. Repeating the same rule always returns $-6$.
