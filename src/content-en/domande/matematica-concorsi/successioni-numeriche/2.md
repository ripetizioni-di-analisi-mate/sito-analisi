Which of the following formulas gives the term at position $n$ in the sequence $5, 8, 11, 14, \dots$?

- $a_n = 3n + 5$
- $a_n = 5n + 3$
- $a_n = 2n + 3$
- $a_n = 3n + 2$

## Explanation

The differences between consecutive terms all equal $3$, so this is an arithmetic sequence with $a_1 = 5$ and $d = 3$. The **general term** is therefore $a_n = 5 + (n - 1) \cdot 3 = 3n + 2$, and indeed $a_1 = 3 + 2 = 5$ and $a_4 = 12 + 2 = 14$. The formula $a_n = 3n + 5$ uses the first term as the constant term and gives $a_1 = 8$. The formula $a_n = 2n + 3$ gives the correct first term but yields $a_2 = 7$, so it does not fit all the terms.
