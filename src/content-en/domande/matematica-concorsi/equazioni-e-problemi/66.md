The solutions of the inequality $x+a<5$ in the unknown $x$ form an interval that contains the number $2$ and does not contain the number $3$. For which integer value of $a$ does this happen?

- $1$
- $2$
- $3$
- $4$

## Explanation

The inequality is equivalent to $x<5-a$. The number $2$ is a solution if $2<5-a$, that is if $a<3$, and the number $3$ is not a solution if $3\ge5-a$, that is if $a\ge2$. Both conditions must hold at the same time, so
$$
\begin{cases}
a<3 \\
a\ge2
\end{cases}
$$
and therefore $2\le a<3$. The only integer in this interval is $a=2$. With $a=1$ the solutions are $x<4$, and then $3$ is also a solution.
