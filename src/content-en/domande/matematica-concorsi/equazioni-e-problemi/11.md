A piggy bank contains only $1$-euro and $2$-euro coins, worth $56$ euros in all. There are three times as many $2$-euro coins as $1$-euro coins. How many coins are there?

- $32$
- $8$
- $24$
- $28$

## Explanation

Let $x$ be the number of $1$-euro coins. The number of $2$-euro coins is $3x$. The value of each group is the number of coins times the value per coin, so $1 \cdot x + 2 \cdot 3x = 56$, or $7x = 56$ and $x = 8$. There are therefore $8 + 24 = 32$ coins, and their value is indeed $8 + 48 = 56$ euros. The values $8$ and $24$ count only one type of coin each. The value $28$ divides $56$ euros by $2$ as if all the coins were $2$-euro coins.
