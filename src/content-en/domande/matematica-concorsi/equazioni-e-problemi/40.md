Which equation has no solution?

- $2\,(x + 1) = 2x + 3$
- $2\,(x + 1) = 2x + 2$
- $2\,(x + 1) = 3x + 2$
- $2\,(x + 1) = x + 1$

## Explanation

A linear equation has **no solution** when it reduces to the form $0 \cdot x = b$ with $b \neq 0$. The equation $2\,(x + 1) = 2x + 3$ becomes $2x + 2 = 2x + 3$, or $0 \cdot x = 1$, which is false for every value of $x$. The equation $2\,(x + 1) = 2x + 2$ reduces to $0 \cdot x = 0$ and is an identity, so every number is a solution. The equation $2\,(x + 1) = 3x + 2$ has a unique solution $x = 0$, and $2\,(x + 1) = x + 1$ has a unique solution $x = -1$.
