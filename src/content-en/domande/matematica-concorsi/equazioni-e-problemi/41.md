A room has chairs arranged in equal rows. Each row has $6$ more chairs than there are rows, and there are $160$ chairs in all. How many rows are there?

- $10$
- $16$
- $20$
- $26$

## Explanation

Let $f$ be the number of rows. Each row has $f + 6$ chairs, so $f\,(f + 6) = 160$, or $f^2 + 6f - 160 = 0$. The discriminant is $\Delta = 36 + 640 = 676 = 26^2$, and the **quadratic formula** gives $f = \dfrac{-6 \pm 26}{2}$, or $f = 10$ and $f = -16$. The number of rows is positive, so discard $-16$. There are $10$ rows with $16$ chairs each. The value $16$ is the number of chairs in one row, $20$ omits division by $2a = 2$, and $26$ is the square root of the discriminant.
