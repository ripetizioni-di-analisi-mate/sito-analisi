The table shows the number of grant applications a municipality received over five consecutive months.

| month | January | February | March | April | May |
|---|---|---|---|---|---|
| applications | $80$ | $95$ | $110$ | $140$ | $160$ |

By what percentage did the number of applications increase from January to May?

- $80\%$
- $200\%$
- $100\%$
- $50\%$

## Explanation

The increase from January to May was $160 - 80 = 80$ applications. Calculate the **percent change** using the initial value as the base. The increase was $\dfrac{80}{80} \cdot 100\% = 100\%$, so the number of applications doubled. The value $80\%$ treats the absolute increase as a percentage, $200\%$ treats the ratio $\dfrac{160}{80} = 2$ as the percent increase, and $50\%$ uses the final value $160$ as the base.
