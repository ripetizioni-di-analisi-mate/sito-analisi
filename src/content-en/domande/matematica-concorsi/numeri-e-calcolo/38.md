Which of these powers has the greatest value?

- $2^{60}$
- $7^{20}$
- $3^{40}$
- $10^{15}$

## Explanation

To compare the powers, write them with the same exponent using the identity $(a^m)^n = a^{m \cdot n}$. We obtain $2^{60} = (2^3)^{20} = 8^{20}$ and $3^{40} = (3^2)^{20} = 9^{20}$. Of these powers with the same positive exponent, the one with the greater base is greater, so $9^{20} > 8^{20} > 7^{20}$. Also, $10^{15} = (10^3)^5 = 1\,000^5$ and $3^{40} = (3^8)^5 = 6\,561^5$, so $10^{15} < 3^{40}$ as well. The greatest is therefore $3^{40}$, whereas $2^{60}$ and $10^{15}$ may appeal to someone who looks only at the largest exponent or the largest base.
