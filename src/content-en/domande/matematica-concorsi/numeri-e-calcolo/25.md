A print shop prints $1\,200$ copies of a booklet. One quarter of the copies go to schools, and $\dfrac{2}{3}$ of the remaining copies go to libraries. How many copies does the print shop have left?

- $100$
- $600$
- $900$
- $300$

## Explanation

The schools receive $\dfrac{1\,200}{4} = 300$ copies, leaving $900$. The libraries receive $\dfrac{2}{3}$ of $900$, or $600$ copies, so the print shop has $900 - 600 = 300$ copies left. The result $100$ takes $\dfrac{2}{3}$ of the entire print run as if both fractions referred to the same whole. The result $600$ is the number of copies going to libraries.
