Which of the following orderings of the fractions $\dfrac{2}{3}$, $\dfrac{5}{8}$, and $\dfrac{7}{10}$ is correct?

- $\dfrac{5}{8} < \dfrac{2}{3} < \dfrac{7}{10}$
- $\dfrac{2}{3} < \dfrac{5}{8} < \dfrac{7}{10}$
- $\dfrac{7}{10} < \dfrac{5}{8} < \dfrac{2}{3}$
- $\dfrac{5}{8} < \dfrac{7}{10} < \dfrac{2}{3}$

## Explanation

The least common denominator is $\operatorname{mcm}(3, 8, 10) = 120$, and we have $\dfrac{2}{3} = \dfrac{80}{120}$, $\dfrac{5}{8} = \dfrac{75}{120}$, and $\dfrac{7}{10} = \dfrac{84}{120}$. Of fractions with the same denominator, the one with the greater numerator is greater, so $\dfrac{5}{8} < \dfrac{2}{3} < \dfrac{7}{10}$. The decimal values $0.625$, $0.\overline{6}$, and $0.7$ give the same order. The ordering $\dfrac{2}{3} < \dfrac{5}{8} < \dfrac{7}{10}$ follows the order of the denominators, which by themselves do not determine the value of a fraction.
