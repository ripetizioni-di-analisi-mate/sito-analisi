Which of the following equalities is true?

- $3.2$ cg $= 0.32$ g
- $3.2$ hg $= 320$ g
- $3.2$ dag $= 320$ g
- $3.2$ q $= 32$ kg

## Explanation

A hectogram is $100$ g, so $3.2$ hg $= 320$ g and this equality is true. A decagram is $10$ g, so $3.2$ dag $= 32$ g. A centigram is one-hundredth of a gram, so $3.2$ cg $= 0.032$ g. A metric quintal is $100$ kg, so $3.2$ q $= 320$ kg.
