A floor has an area of $18\ \text{m}^2$, of which $13.2\ \text{m}^2$ is already covered. Each box of flooring covers $80\ \text{dm}^2$. How many more boxes are needed if all the material can be used without waste?

- $6$
- $60$
- $8$
- $5$

## Explanation

The **remaining area** is $18-13.2=4.8\ \text{m}^2$. Since each box covers $80\ \text{dm}^2=0.8\ \text{m}^2$, it takes $4.8\div0.8=6$ boxes.
