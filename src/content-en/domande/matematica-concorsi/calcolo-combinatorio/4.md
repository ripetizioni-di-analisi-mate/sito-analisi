Paolo and Sergio play a best-of-three tennis match that ends as soon as one player wins two sets. The winner of each set played is recorded in order. How many different sequences are possible?

- $6$
- $8$
- $4$
- $9$

## Explanation

The match can last two or three sets, so its length depends on the earlier results. Use a **tree diagram**. Let $P$ denote a set won by Paolo and $S$ a set won by Sergio. If the same player wins the first two sets, the match ends. There are $2$ such sequences, $PP$ and $SS$. If different players win the first two sets, as in $PS$ and $SP$, the third set has $2$ possible winners, giving $2 \cdot 2 = 4$ sequences. There are $2 + 4 = 6$ sequences altogether. The result $8 = 2^3$ assumes that three sets are always played.
