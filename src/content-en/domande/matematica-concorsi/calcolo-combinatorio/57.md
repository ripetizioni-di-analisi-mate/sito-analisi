Four lights are arranged in a line. A command toggles two adjacent lights together. Starting with all lights off, which state is impossible even after several commands?

- All lights off
- Only the first two lights on
- All lights on
- Exactly one light on

## Explanation

Each command changes the number of lit lights by $-2$, 0 or 2, preserving even parity. The other states take zero, one or two commands on disjoint pairs.
