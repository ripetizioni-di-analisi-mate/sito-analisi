A meeting notice has $6$ possible headings. Each heading can be paired with any of $4$ different texts. How many complete versions are possible if one heading and one text are chosen?

- $10$
- $30$
- $24$
- $18$

## Explanation

Each of the six headings can be used with four texts. There are $6\cdot4=24$ pairings.
