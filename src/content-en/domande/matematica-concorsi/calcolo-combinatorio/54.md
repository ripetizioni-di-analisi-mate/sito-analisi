Four tiles carry the letters A, B, B, C, and rows are formed using all four tiles. Two rows are considered the same if one is obtained by reading the other from right to left. How many different rows are there?

- $3$
- $24$
- $6$
- $12$

## Explanation

Without the condition on the reading direction, the rows are the **permutations with repeated objects** of four tiles in which B appears twice, that is $\dfrac{4!}{2!}=12$. A row read from right to left coincides with itself only if it is symmetric, and this is impossible because A and C appear once each. Therefore the $12$ rows split into pairs formed by a row and its reverse, and each pair represents a single row. So the number of different rows is $\dfrac{12}{2}=6$. The value $12$ ignores the condition on the reading direction, and the value $24$ treats the two B tiles as distinct.
