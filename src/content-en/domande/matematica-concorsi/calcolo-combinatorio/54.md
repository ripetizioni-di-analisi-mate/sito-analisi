Four tiles show A, B, B, C. A row and its reversal count as the same arrangement. How many arrangements are there?

- $3$
- $8$
- $6$
- $12$

## Explanation

There are $\dfrac{4!}{2!}=12$ oriented rows. None is a palindrome because A and C each occur once. Each reversal pair counts once.
