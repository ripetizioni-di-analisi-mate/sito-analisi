An archive contains $6$ distinct case files of the same type. A single shipment can contain exactly one or exactly two files. How many different sets of files can be sent?

- $36$
- $30$
- $21$
- $15$

## Explanation

There are six single-file shipments and $\binom{6}{2}=15$ two-file shipments. The cases are disjoint, so there are $6+15=21$ possible shipments.
