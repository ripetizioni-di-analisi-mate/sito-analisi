A four-character code begins with one of the five letters A, B, C, D, and E, followed by three decimal digits. Digits can repeat, but the last must be even. How many codes can be generated?

- $2500$
- $2250$
- $1250$
- $5000$

## Explanation

There are five choices for the letter and ten for each of the first two digits. There are five even digits, including zero, so there are $5\cdot10\cdot10\cdot5=2500$ codes.
