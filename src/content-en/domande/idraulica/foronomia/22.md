A circular sharp-edged, thin-wall orifice has discharge coefficient $\mu = 0.61$. A rounded entrance eliminates contraction and raises this coefficient to $0.97$. At the same head, how does the discharge change?

- It stays the same because the head is unchanged
- It decreases by about $20\%$ because the rounded inlet lengthens the flow path
- It increases by about $60\%$ because discharge is proportional to the discharge coefficient
- It increases by about $3\%$ because only the velocity coefficient changes

## Explanation

At fixed orifice area and head, discharge is proportional to the discharge coefficient because $Q = \mu\,A\,\sqrt{2 g h}$. The discharge ratio is $\dfrac{0.97}{0.61} = 1.59$, so the flow rate **increases by about $60\%$**. A rounded inlet brings the contraction coefficient to $1$. The discharge coefficient then equals the velocity coefficient, which is about $0.97$ for a well-contoured inlet in laboratory tests.
