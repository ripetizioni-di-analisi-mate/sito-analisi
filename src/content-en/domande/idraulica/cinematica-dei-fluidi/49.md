A current meter is fixed at one location in a river, at a specified elevation and distance from the bank. Farther upstream a float is released and its position recorded every ten seconds. Which description of motion does each measurement use?

- Both use the Eulerian description
- The current meter uses the Lagrangian description and the float uses the Eulerian description
- The current meter uses the Eulerian description and the float uses the Lagrangian description
- Both use the Lagrangian description

## Explanation

An Eulerian description records the velocity of successive particles passing a fixed point. The current meter stays in one place and measures the field $\vec{v}(x, y, z, t)$ there over time, so its measurement is **Eulerian**. A float travels with the water. Its successive positions trace the pathline of a surface particle, which gives a **Lagrangian** description. Hydraulic calculations generally use the Eulerian description because discharge and head are evaluated at fixed sections.
