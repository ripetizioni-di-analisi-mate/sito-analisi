At a section carrying gradually varied open-channel flow, the friction slope is smaller than the bed slope and the Froude number is greater than $1$. Which profile passes through the section, and how does its depth change downstream?

- An S2 profile with depth decreasing downstream
- An M3 profile with depth increasing downstream
- An S3 profile with depth increasing downstream
- An M2 profile with depth decreasing downstream

## Explanation

Friction slope decreases as depth increases and equals the bed slope at $h = h_0$, so $J < i$ implies $h > h_0$. The Froude number is $1$ at $h = h_c$ and falls as $h$ increases, so $Fr > 1$ implies $h < h_c$. Together these conditions give $h_0 < h < h_c$, possible only if $h_0 < h_c$, on a steep bed. The flow lies in zone 2 and the profile is **S2**. The numerator $i - J$ is positive and the denominator $1 - Fr^2$ negative, giving $\dfrac{dh}{dx} < 0$, so the depth decreases downstream. M3 and S3 profiles have $h < h_0$, or $J > i$, while an M2 profile has $Fr < 1$.
