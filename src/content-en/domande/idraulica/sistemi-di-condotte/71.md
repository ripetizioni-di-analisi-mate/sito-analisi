The two-loop network shown is solved by the Hardy Cross method, taking both loops clockwise. Before correction, the common branch $B\!-\!E$ carries $30.0\,\mathrm{L/s}$ from $B$ to $E$. At the first iteration, the correction for left-hand loop I is $\Delta Q_{\mathrm{I}} = -4.0\,\mathrm{L/s}$ and that for right-hand loop II is $\Delta Q_{\mathrm{II}} = +6.0\,\mathrm{L/s}$. What is the discharge in $B\!-\!E$ after both corrections?

::schema{nodi="A,4,16;B,15,16;C,26,16;D,4,5;E,15,5;F,26,5" condotte="A-B,0.38,;B-C,0.38,;C-F,0.38,;E-F,0.38,;D-E,0.38,;A-D,0.38,;B-E,0.38," frecce="16.2,11.8,16.2,9.2,30 L/s" etichette="9.5,10.5,loop I;20.5,10.5,loop II" titolo="Two-loop network with shared branch $B\!-\!E$"}

- $32.0\,\mathrm{L/s}$ from $B$ toward $E$
- $26.0\,\mathrm{L/s}$ from $B$ toward $E$
- $20.0\,\mathrm{L/s}$ from $B$ toward $E$
- $36.0\,\mathrm{L/s}$ from $B$ toward $E$

## Explanation

The shared branch receives both loop corrections, each with the sign appropriate to that branch in the corresponding loop.

In clockwise loop I, branch $B\!-\!E$ forms the right side and is traversed from top to bottom, from $B$ to $E$. The flow follows the loop direction, so the branch receives $+\Delta Q_{\mathrm{I}}$. In loop II, the same branch forms the left side and is traversed from $E$ to $B$. The flow opposes this loop direction, so the branch receives $-\Delta Q_{\mathrm{II}}$.

Taking flow from $B$ to $E$ as positive gives
$$
Q_{BE} = 30.0 + \Delta Q_{\mathrm{I}} - \Delta Q_{\mathrm{II}} = 30.0 - 4.0 - 6.0 = 20.0\,\mathrm{L/s} ,
$$
The positive result confirms that flow is still directed from $B$ to $E$.

The value $32.0\,\mathrm{L/s}$ adds both signed corrections as though the flow followed both loop directions. The value $26.0\,\mathrm{L/s}$ applies only the loop I correction, and $36.0\,\mathrm{L/s}$ applies only the loop II correction, with the wrong sign.
