In a real double slit, separation $d$ is four times the width $a$ of each opening. Which first positive order predicted by Young coincides with the first envelope minimum?

- $m=1$.
- $m=2$.
- $m=4$.
- $m=8$.

## Explanation

The first minimum has $\sin\theta=\dfrac{\lambda}{a}$. A Young maximum has $\sin\theta=\dfrac{m\lambda}{d}$. Equating them gives $m=\dfrac da=4$, so fourth order vanishes.
