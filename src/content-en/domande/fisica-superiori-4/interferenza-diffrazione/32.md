The same Young setup first uses $\lambda=450\,\mathrm{nm}$ and then $\lambda=600\,\mathrm{nm}$. The fringe spacing is $3\,\mathrm{mm}$ with the first wavelength. What is it with the second?

- $4\,\mathrm{mm}$.
- $2.25\,\mathrm{mm}$.
- $6\,\mathrm{mm}$.
- $5\,\mathrm{mm}$.

## Explanation

With $L$ and $d$ fixed, fringe spacing is proportional to $\lambda$. The new value is $3\,\mathrm{mm}\cdot\dfrac{600}{450}=4\,\mathrm{mm}$.
