A negative charge enters horizontally into a uniform vertical electric field pointing up, with no other forces. Which description of its motion is correct?

- The path bends upward.
- The path remains horizontal.
- The horizontal velocity component increases and the vertical component stays zero.
- The horizontal velocity component is constant and the path bends downward.

## Explanation

The force has no horizontal component. Vertically it points opposite the field because $q<0$, so horizontal velocity stays constant and a downward deflection develops.
