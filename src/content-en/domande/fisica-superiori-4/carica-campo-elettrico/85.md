Two identical particles enter the same uniform field, one from rest and one with horizontal velocity. Neglecting other forces, which quantity has the same instantaneous value for both?

- Velocity.
- Position.
- Total displacement from entry.
- Acceleration.

## Explanation

Acceleration depends only on $q$, $m$, and $\vec E$, which are the same for both. The different initial velocities can give different positions and displacements.
