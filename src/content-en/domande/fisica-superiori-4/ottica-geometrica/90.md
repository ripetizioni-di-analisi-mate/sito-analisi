For a converging lens with focal length $10\,\mathrm{cm}$ the graph shows image distance $q$ as a function of object distance $p$. Which signed magnification corresponds to point B?

::grafico{f="10*x/(x-10)" xmin=0 xmax=40 ymin=0 ymax=42 nomi="p,q" punti="15,30,pieno,A;30,15,pieno,B" segmenti="0,15,30,15;30,0,30,15" legenda="q=\dfrac{10p}{p-10}" titolo="Real-image branch for $p>10\,\mathrm{cm}$. Point B has coordinates $p=30\,\mathrm{cm}$ and $q=15\,\mathrm{cm}$."}

- $M=-0.5$.
- $M=0.5$.
- $M=-2$.
- $M=2$.

## Explanation

The projections of point B onto the axes give $p=30\,\mathrm{cm}$ and $q=15\,\mathrm{cm}$. The signed ratio is $M=-\dfrac{15}{30}=-0.50$. The image is inverted and reduced.
