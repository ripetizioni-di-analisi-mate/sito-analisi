A rigid loop moves bodily from a weak-field region to a stronger one without rotating. When can stationary magnets still induce an emf?

- Only if the field changes at each fixed point
- Only when copper mass changes
- Only when resistance changes
- When the spatial gradient changes the flux during motion

## Explanation

In a static nonuniform field the moving loop samples different field strengths. Flux through its moving surface can therefore change.
