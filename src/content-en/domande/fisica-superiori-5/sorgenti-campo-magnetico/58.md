A long solenoid has $200$ turns per meter and carries $5$ A. How many turns per meter would maintain the same field if the current fell to $5/2$ A?

- $100$
- $800$
- $400$
- $200$

## Explanation

In a long solenoid, the field is proportional to the number of turns per unit length times the current. Halving the current requires doubling the number of turns per unit length, giving $400$.
