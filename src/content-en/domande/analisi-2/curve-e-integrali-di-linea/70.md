What is the acceleration at $t=0$ for $\left( 3 t, \  5 t^{2}, \  2 t^{3}\right)$?

- $\left( 0, \  10, \  12\right)$
- $\left( 0, \  10, \  0\right)$
- $\left( 3, \  0, \  0\right)$
- $\left( 0, \  5, \  0\right)$

## Explanation

Differentiate each component twice. At zero only the second derivative of the quadratic component remains.
