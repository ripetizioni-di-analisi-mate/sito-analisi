What is the acceleration at $t=0$ for $\left( 2 t, \  3 t^{2}, \  5 t^{3}\right)$?

- $\left( 0, \  6, \  0\right)$
- $\left( 2, \  0, \  0\right)$
- $\left( 0, \  3, \  0\right)$
- $\left( 0, \  6, \  30\right)$

## Explanation

Differentiate each component twice. At zero only the second derivative of the quadratic component remains.
