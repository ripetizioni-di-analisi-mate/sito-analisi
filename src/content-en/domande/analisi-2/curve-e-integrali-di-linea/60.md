For which value of $b > 0$ does the graph of the function $f(x) = \cosh x$, $x \in [0, b]$, have length $\dfrac{3}{4}$?

- $b = \ln \dfrac{7}{4}$
- $b = \ln \dfrac{3}{2}$
- $b = \ln 2$
- $b = \ln 3$

## Explanation

For a Cartesian curve the length is $\displaystyle\int_0^b \sqrt{1 + f'(x)^2} \, dx$.

We have $f'(x) = \sinh x$ and, by the identity $1 + \sinh^2 x = \cosh^2 x$, we obtain $\sqrt{1 + f'(x)^2} = \cosh x$, since $\cosh x > 0$. Hence the length is
$$
\int_0^b \cosh x \, dx = \sinh b .
$$

The condition $\sinh b = \dfrac{3}{4}$ is equivalent to $e^b - e^{-b} = \dfrac{3}{2}$. Setting $z = e^b$, we obtain $2z^2 - 3z - 2 = 0$, whose positive root is $z = 2$; therefore $b = \ln 2$.
