What is the acceleration at $t=0$ for $\left( 4 t, \  2 t^{2}, \  7 t^{3}\right)$?

- $\left( 0, \  4, \  42\right)$
- $\left( 0, \  4, \  0\right)$
- $\left( 4, \  0, \  0\right)$
- $\left( 0, \  2, \  0\right)$

## Explanation

Differentiate each component twice. At zero only the second derivative of the quadratic component remains.
