For the function $f(x, y, z) = e^{xyz}$, which vector is $\operatorname{rot}(\nabla f)$?

- $e^{xyz}\,(yz,\; xz,\; xy)$
- $(0,\; 0,\; 0)$
- $e^{xyz}\,(x - z,\; y - x,\; z - y)$
- $xyz\,e^{xyz}\,(1,\; 1,\; 1)$

## Explanation

The function $f$ is of class $C^2$ on $\mathbb{R}^3$, so the identity $\operatorname{rot}(\nabla f) = \mathbf{0}$ holds, which follows from **Schwarz's theorem**.

For example, the first component of $\operatorname{rot}(\nabla f)$ is $f_{zy} - f_{yz}$, and the two mixed second derivatives are equal. The same holds for the other two components, therefore $\operatorname{rot}(\nabla f) = (0, 0, 0)$ without computing the gradient. The vector $e^{xyz}(yz, xz, xy)$ is the gradient of $f$.
