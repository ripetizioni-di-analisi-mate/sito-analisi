For which value of $a \in \mathbb{R}$ is the field $\mathbf{F}(x, y, z) = \bigl( 2xy + az,\; x^2,\; x \bigr)$ irrotational?

- $a = -1$
- $a = 0$
- $a = 2$
- $a = 1$

## Explanation

A field is **irrotational** when its curl is identically zero. For the given field we have
$$
\operatorname{rot} \mathbf{F} = \left( \frac{\partial x}{\partial y} - \frac{\partial (x^2)}{\partial z},\; \frac{\partial (2xy + az)}{\partial z} - \frac{\partial x}{\partial x},\; \frac{\partial (x^2)}{\partial x} - \frac{\partial (2xy + az)}{\partial y} \right) = \bigl( 0,\; a - 1,\; 0 \bigr) .
$$
The first and third components are zero for every $a$, while the second is zero if and only if $a = 1$. Hence the field is irrotational if and only if $a = 1$.
