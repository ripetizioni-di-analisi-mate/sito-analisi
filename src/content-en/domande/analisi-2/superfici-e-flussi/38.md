The field $G(x,y,z)=(x,y,z)$ is proposed as the curl of a $C^2$ field on all of $\mathbb R^3$. Which calculation decides whether this is possible?

- $\operatorname{div}G=0$, so it is possible.
- $\operatorname{rot}G=0$, so it is possible.
- $G(0,0,0)=0$, so it is impossible.
- $\operatorname{div}G=3$, so it is impossible.

## Explanation

The divergence of a curl is zero for a $C^2$ field because mixed derivatives cancel. Here the divergence equals $1+1+1=3$.
