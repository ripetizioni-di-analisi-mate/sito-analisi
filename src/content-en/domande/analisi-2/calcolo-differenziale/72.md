For which value of the real parameter $a$ is the function
$$
f(x, y) =
\begin{cases}
x + a\,y & y \geq 0 \\[4pt]
x - y & y < 0
\end{cases}
$$
differentiable at $(0, 0)$?

- $a = 1$
- $a = -1$
- $a = 0$
- For every $a \in \mathbb{R}$

## Explanation

On the $x$-axis one has $f(x, 0) = x$, so $f_x(0, 0) = 1$ for every $a$. On the $y$-axis the function equals $a\,y$ for $y \geq 0$ and $-y$ for $y < 0$, so the difference quotient of $f_y$ tends to $a$ from the right and to $-1$ from the left. Therefore $f_y(0, 0)$ exists only for $a = -1$, and for $a \neq -1$ the function is not differentiable. For $a = -1$ one has $f(x, y) = x - y$ on the whole plane, which is linear and hence **differentiable**.
