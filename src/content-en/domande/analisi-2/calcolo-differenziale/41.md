There exists a function $f$ of class $C^2$ on $\mathbb{R}^2$ with $f_x = 3x^2 y + y^3$ and $f_y = x^3 + a\,x y^2$. What is the value of $a$?

- $3$
- $1$
- $2$
- $6$

## Explanation

Since $f$ is of class $C^2$, by the **Schwarz theorem** the mixed second derivatives coincide at every point. Differentiating $f_x$ with respect to $y$ we obtain $f_{xy} = 3x^2 + 3y^2$, and differentiating $f_y$ with respect to $x$ we obtain $f_{yx} = 3x^2 + a\,y^2$. The equality $f_{xy} = f_{yx}$ holds for every $(x, y)$ if and only if $a = 3$. For this value the function $f(x, y) = x^3 y + x y^3$ has exactly the given partial derivatives.
