For which value of $k$ does the function $f(x, y) = x^3 + k\,x y^2$ satisfy $f_{xx} + f_{yy} = 0$ at every point of $\mathbb{R}^2$?

- $3$
- $-3$
- $-6$
- $-\dfrac{1}{3}$

## Explanation

Differentiating twice with respect to $x$ we obtain $f_x = 3x^2 + k\,y^2$ and $f_{xx} = 6x$. Differentiating twice with respect to $y$ we obtain $f_y = 2k\,xy$ and $f_{yy} = 2k\,x$. Therefore $f_{xx} + f_{yy} = (6 + 2k)\,x$, which is zero at every point if and only if $6 + 2k = 0$, that is, $k = -3$.
