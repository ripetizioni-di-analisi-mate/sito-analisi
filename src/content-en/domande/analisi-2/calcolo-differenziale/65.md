Which of the following functions has both partial derivatives at $(0, 0)$ but is not differentiable at $(0, 0)$?

- $f(x, y) = \sqrt{x^2 + y^2}$
- $f(x, y) = x^2 + y^2$
- $f(x, y) = \sqrt[3]{xy}$
- $f(x, y) = x\,|y|$

## Explanation

The function $\sqrt[3]{xy}$ is zero on the axes, so $f_x(0, 0) = f_y(0, 0) = 0$; along the line $k = h$ the differentiability quotient equals $\dfrac{|h|^{\frac{2}{3}}}{\sqrt{2}\,|h|}$, which tends to $+\infty$, therefore $\sqrt[3]{xy}$ is **not differentiable** at $(0, 0)$. The function $\sqrt{x^2 + y^2}$ coincides with $|x|$ on the $x$-axis, so $f_x(0, 0)$ does not exist. The polynomial $x^2 + y^2$ is differentiable. For $x\,|y|$ the quotient is bounded by $\dfrac{\rho}{2}$ with $\rho = \sqrt{h^2 + k^2}$, so it is differentiable with zero differential.
