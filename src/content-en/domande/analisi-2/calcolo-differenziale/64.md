Given the function
$$
f(x, y) = \frac{x^3 \cos(xy) + y\, e^{x^2 y^3}}{1 + x^2},
$$
what is the value of the partial derivative $f_x$ at the point $(1, 0)$?

- $\dfrac{3}{2}$
- $1$
- $\dfrac{1}{2}$
- $2$

## Explanation

When computing $f_x(1, 0)$ the variable $y$ stays fixed at the value $0$, so it suffices to differentiate the restriction $g(x) = f(x, 0)$ and evaluate it at $x = 1$. For $y = 0$ one has $\cos(xy) = 1$ and $y\, e^{x^2 y^3} = 0$, therefore $g(x) = \dfrac{x^3}{1 + x^2}$. By the quotient rule
$$
g'(x) = \frac{3x^2 (1 + x^2) - 2x \cdot x^3}{(1 + x^2)^2},
$$
so $g'(1) = \dfrac{6 - 2}{4} = 1$. Hence $f_x(1, 0) = 1$.
