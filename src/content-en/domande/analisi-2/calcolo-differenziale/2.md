- $\nabla f(2, 0) = (1,\, 0)$
- $\nabla f(2, 0) = (2,\, 1)$
- $\nabla f(2, 0) = (0,\, 2)$
- $\nabla f(2, 0) = (1,\, 2)$

## Explanation

Differentiating with respect to $x$ with $y$ held constant, the factor $e^{y}$ is a constant and $y^2$ has zero derivative, so $f_x = e^{y}$. Differentiating with respect to $y$ with $x$ held constant we obtain $f_y = x\,e^{y} + 2y$, because the derivative of $e^{y}$ with respect to $y$ is $e^{y}$. At the point $(2, 0)$ we have $e^{0} = 1$, therefore $f_x(2, 0) = 1$ and $f_y(2, 0) = 2 + 0 = 2$. The **gradient** is therefore $\nabla f(2, 0) = (1,\, 2)$.
