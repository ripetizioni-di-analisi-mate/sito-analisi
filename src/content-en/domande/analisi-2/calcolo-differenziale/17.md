For the function of three variables $f(x, y, z) = xyz + z^2$, what is the gradient at the point $(1, 2, 3)$?

- $\nabla f(1, 2, 3) = (6,\, 3,\, 2)$
- $\nabla f(1, 2, 3) = (6,\, 3,\, 5)$
- $\nabla f(1, 2, 3) = (3,\, 6,\, 8)$
- $\nabla f(1, 2, 3) = (6,\, 3,\, 8)$

## Explanation

For a function of three variables the gradient has three components, and each one is computed by differentiating with respect to one variable while holding the other two constant. We obtain $f_x = yz$, $f_y = xz$ and $f_z = xy + 2z$, because $z^2$ is constant with respect to $x$ and to $y$. At the point $(1, 2, 3)$ we have $f_x = 6$, $f_y = 3$ and $f_z = 2 + 6 = 8$. Therefore the **gradient** is $(6,\, 3,\, 8)$.
