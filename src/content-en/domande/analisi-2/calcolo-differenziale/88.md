For $f(x, y) = x^2 + xy + y^2$ consider the tangent plane to the graph at the point $(1, 1, 3)$. What is the position of the graph with respect to this plane?

- It lies below the plane, which it touches only at $(1, 1, 3)$
- It has points above and points below the plane in every neighborhood of $(1, 1, 3)$
- It lies above the plane, which it touches only at $(1, 1, 3)$
- It contains a line of the plane through $(1, 1, 3)$

## Explanation

We have $f(1, 1) = 3$, $f_x = 2x + y$ and $f_y = x + 2y$, so $f_x(1, 1) = f_y(1, 1) = 3$ and the tangent plane is $z = 3 + 3(x - 1) + 3(y - 1)$. Setting $h = x - 1$ and $k = y - 1$, the difference between the height of the graph and that of the plane is
$$
f(1 + h,\, 1 + k) - 3 - 3h - 3k = h^2 + hk + k^2 = \left( h + \frac{k}{2} \right)^2 + \frac{3}{4}\,k^2 .
$$
This sum of squares is positive for $(h, k) \neq (0, 0)$ and zero only for $h = k = 0$. Therefore the graph **lies above** the tangent plane and touches it only at the point $(1, 1, 3)$.
