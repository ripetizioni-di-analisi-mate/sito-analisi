Let $f$ be differentiable on $\mathbb{R}^2$ with $f(x, x^2) = x^3$ for every $x \in \mathbb{R}$ and $f_x(1, 1) = 1$. What is the value of $f_y(1, 1)$?

- $2$
- $1$
- $\dfrac{3}{2}$
- $3$

## Explanation

The function $g(x) = f(x, x^2)$ is the composition of $f$ with the curve $(x, x^2)$, whose derivative vector is $(1,\, 2x)$. By the **chain rule** we have $g'(x) = f_x(x, x^2) + 2x\, f_y(x, x^2)$; on the other hand $g(x) = x^3$, so $g'(x) = 3x^2$. For $x = 1$ we obtain $f_x(1, 1) + 2 f_y(1, 1) = 3$, that is, $1 + 2 f_y(1, 1) = 3$. Therefore $f_y(1, 1) = 1$.
