Which of the following points belongs to the region $y < \ln(x - 2)$?

- $(3, 0)$
- $(1, -3)$
- $(4, 0)$
- $(3, 1)$

## Explanation

The function $\ln(x - 2)$ is defined for $x > 2$, so the inequality is equivalent to the system formed by $x > 2$ and $y < \ln(x - 2)$. At the point $(4, 0)$ we have $\ln(4 - 2) = \ln 2$, which is positive because $2 > 1$, so $0 < \ln 2$ is true and the point **belongs** to the region. At the point $(3, 0)$ we have $\ln(3 - 2) = 0$, so the point lies on the boundary, which is excluded because the symbol is $<$. At the point $(3, 1)$ the inequality becomes $1 < 0$, which is false. At the point $(1, -3)$ the argument of the logarithm equals $-1$, so the logarithm is not defined.
