For which of the following inequalities does the point $(3, 1)$ belong to the boundary and is part of the solutions?

- $x + y \geq 4$
- $x - 3y > 0$
- $x^2 - y \leq 10$
- $y \neq x - 2$

## Explanation

A point belongs to the boundary when its coordinates make the two sides equal, and in that case it is part of the solutions only with the symbols $\leq$ and $\geq$. In $x + y \geq 4$ the left-hand side equals $3 + 1 = 4$, so the point lies on the line $x + y = 4$, which with the symbol $\geq$ is **included**. In $x - 3y > 0$ the left-hand side equals $3 - 3 = 0$, so the point lies on the boundary, which with the symbol $>$ is excluded. In $y \neq x - 2$ we have $1 = 3 - 2$, so the point lies on the line $y = x - 2$, which with the symbol $\neq$ is excluded. In $x^2 - y \leq 10$ the left-hand side equals $9 - 1 = 8$, so the point is a solution that lies off the boundary $x^2 - y = 10$.
