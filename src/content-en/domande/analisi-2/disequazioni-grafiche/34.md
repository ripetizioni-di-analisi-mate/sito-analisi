Which of the following lines is entirely contained in the region $x < y^2 - 2y + 3$?

- $x = 2$
- $x = 1$
- $x = 3$
- $y = 1$

## Explanation

Completing the square gives $y^2 - 2y + 3 = (y - 1)^2 + 2$, so the region consists of the points to the left of the parabola with vertex $(2, 1)$, which opens to the right, parabola excluded. For every $y$ we have $(y - 1)^2 + 2 \geq 2$, so all the points of the line $x = 1$ satisfy $1 < (y - 1)^2 + 2$ and the line is **entirely contained** in the region. The line $x = 2$ passes through the vertex $(2, 1)$, which is excluded because $2 < 2$ is false. The lines $x = 3$ and $y = 1$ pass through the point $(3, 1)$, which does not belong to the region because $3 < 2$ is false.
