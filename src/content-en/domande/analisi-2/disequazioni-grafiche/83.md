What is the description in polar coordinates of the disk $x^2 + y^2 \leq 6y$?

- $0 \leq \theta \leq \pi$, $\ 0 \leq \rho \leq 6\sin\theta$
- $-\dfrac{\pi}{2} \leq \theta \leq \dfrac{\pi}{2}$, $\ 0 \leq \rho \leq 6\cos\theta$
- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 3$
- $0 \leq \theta \leq \pi$, $\ 0 \leq \rho \leq 6$

## Explanation

With $x = \rho\cos\theta$ and $y = \rho\sin\theta$ we have $x^2 + y^2 = \rho^2$, so the inequality becomes $\rho^2 \leq 6\rho\sin\theta$. For $\rho > 0$ both sides are divided by $\rho$, and we obtain $\rho \leq 6\sin\theta$. This condition requires $\sin\theta \geq 0$, therefore $0 \leq \theta \leq \pi$. Completing the square, the inequality can be written $x^2 + (y - 3)^2 \leq 9$, so the disk has center $(0, 3)$ and radius $3$ and lies in the half-plane $y \geq 0$, in agreement with the interval of $\theta$. The description $0 \leq \rho \leq 3$ with $0 \leq \theta \leq 2\pi$ is that of the disk of radius $3$ centered at the origin.
