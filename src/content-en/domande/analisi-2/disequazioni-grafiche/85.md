Which of the following sets is bounded?

- $y \geq x^2 - 4$
- $2x^2 + y^2 \leq 8$
- $x^2 - y^2 \leq 1$
- $x^2 + y^2 \geq 1$

## Explanation

A set is bounded if it is contained in a disk. Dividing by $8$, the inequality $2x^2 + y^2 \leq 8$ becomes $\dfrac{x^2}{4} + \dfrac{y^2}{8} \leq 1$, which describes the points inside an ellipse with semi-axes $2$ and $2\sqrt{2}$, with the ellipse included. This set is contained in the disk centered at the origin with radius $3$, so it is **bounded**. The region $y \geq x^2 - 4$, above the parabola, contains the points $(0, n)$ for every natural number $n$, and the same holds for the region $x^2 - y^2 \leq 1$ between the two branches of the hyperbola. The set $x^2 + y^2 \geq 1$ contains the points $(n, 0)$ with $n \geq 1$, therefore none of these three sets is contained in a disk.
