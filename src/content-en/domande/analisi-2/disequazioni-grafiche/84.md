The set $D = \{ (x, y) : 1 \leq x \leq e,\ 0 \leq y \leq \ln x \}$ is written as a normal domain with respect to the $x$-axis. Which expression describes it as a normal domain with respect to the $y$-axis?

- $0 \leq y \leq 1$, $\ 1 \leq x \leq e^y$
- $1 \leq y \leq e$, $\ 0 \leq x \leq \ln y$
- $0 \leq y \leq 1$, $\ e^y \leq x \leq e$
- $0 \leq y \leq 1$, $\ 1 \leq x \leq e$

## Explanation

The curve $y = \ln x$ is increasing and passes through $(1, 0)$ and $(e, 1)$, so the projection of $D$ onto the $y$-axis is the interval $[0, 1]$. The exponential function is increasing, therefore $y \leq \ln x$ is equivalent to $e^y \leq x$. Every horizontal segment with $y$-coordinate between $0$ and $1$ enters $D$ through the curve $x = e^y$, on the left, and exits through the line $x = e$, on the right. Hence $D$ is written $0 \leq y \leq 1$, $e^y \leq x \leq e$. The expression $1 \leq x \leq e^y$ describes the points to the left of the curve, which lie above the graph of $\ln x$.
