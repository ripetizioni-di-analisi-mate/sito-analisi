The boundary of the region $y > 2 - \dfrac{1}{2}x^2$ is a parabola with vertex $(0, 2)$. Which description of the region is correct?

- The points above the parabola, which opens downward, parabola excluded
- The points below the parabola, which opens downward, parabola excluded
- The points above the parabola, which opens upward, parabola excluded
- The points above the parabola, which opens downward, parabola included

## Explanation

The coefficient of $x^2$ is $-\dfrac{1}{2}$, which is negative, so the parabola $y = 2 - \dfrac{1}{2}x^2$ opens downward. The variable $y$ is isolated with the symbol $>$, so by the isolated variable rule the solutions are the points **above** the parabola. The origin lies below the vertex and indeed is not a solution, because $0 > 2$ is false. The symbol is strict, so the parabola is **excluded**.
