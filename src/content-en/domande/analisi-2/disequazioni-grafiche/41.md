For which values of the real parameter $c$ does the inequality $x^2 + y^2 - 4x + 2y + c < 0$ describe the interior points of a circle?

- $c < 5$
- $c \leq 5$
- $c > -5$
- $c > 5$

## Explanation

We complete the squares in $x$ and in $y$.
$$
\begin{aligned}
(x - 2)^2 - 4 + (y + 1)^2 - 1 + c &< 0 \\[6pt]
(x - 2)^2 + (y + 1)^2 &< 5 - c
\end{aligned}
$$
The right-hand side is the square of a radius only if it is positive, so the inequality describes the interior points of a circle when $5 - c > 0$, that is, for $c < 5$. For $c = 5$ the inequality becomes $(x - 2)^2 + (y + 1)^2 < 0$, which **has no solutions** because a sum of squares is greater than or equal to zero.
