For which $x \in \mathbb{R}$ does the sequence $f_n(x) = n^x$ converge, and to which limit?

- For $x < 0$, with limit $0$
- For $x \leq 0$, with limit $0$ if $x < 0$ and $1$ if $x = 0$
- For every $x \in \mathbb{R}$, with limit $1$
- For $x \leq 0$, with limit $0$ at every point

## Explanation

We write $n^x = e^{x \ln n}$, where $\ln n \to +\infty$. If $x < 0$ the exponent $x \ln n$ tends to $-\infty$, so $n^x \to 0$. If $x = 0$ we have $n^0 = 1$ for every $n$, so the limit is $1$. If $x > 0$ the exponent tends to $+\infty$, so the sequence diverges. Therefore the sequence converges exactly for $x \leq 0$, and the limit is discontinuous at $x = 0$.
