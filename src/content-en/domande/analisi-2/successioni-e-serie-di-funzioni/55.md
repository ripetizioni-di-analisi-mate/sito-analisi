The figure shows the graphs of $f_n(x) = \dfrac{1}{1 + (x - n)^2}$ for $n = 1, 3, 6$. The sequence converges pointwise to $0$ on $\mathbb{R}$. Which statement about uniform convergence is true?

::grafico{f="1/(1+(x-1)^2);1/(1+(x-3)^2);1/(1+(x-6)^2)" xmin=-2 xmax=9 ymin=-0.1 ymax=1.3 etichette="1,1.12,n = 1;3,1.12,n = 3;6,1.12,n = 6" titolo="$y = \dfrac{1}{1 + (x - n)^2}$ for $n = 1, 3, 6$"}

- It is uniform on $\mathbb{R}$
- It is uniform on every half-line $[a, +\infty)$, but not on $\mathbb{R}$
- It is uniform on every half-line $(-\infty, a]$, but not on $\mathbb{R}$
- It is not uniform on any half-line $(-\infty, a]$

## Explanation

For fixed $x$ we have $(x - n)^2 \to +\infty$, so $f_n(x) \to 0$. Each $f_n$ has its maximum at $x = n$, where it equals $1$, so $\sup_{\mathbb{R}} |f_n| = 1$ for every $n$ and the convergence is not uniform on $\mathbb{R}$. The same happens on every half-line $[a, +\infty)$, which contains the point $x = n$ for $n \geq a$. On $(-\infty, a]$, for $n > a$, the function $f_n$ is increasing, so
$$
\sup_{(-\infty, a]} |f_n| = f_n(a) = \frac{1}{1 + (a - n)^2} \xrightarrow[n \to +\infty]{} 0 ,
$$
therefore the convergence is uniform on every half-line of this kind.
