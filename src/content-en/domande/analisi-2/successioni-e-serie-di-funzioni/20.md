For the sequence of functions $f_n(x) = \dfrac{n x^2}{1 + n x}$ on $[0, +\infty)$, which converges pointwise to $f(x) = x$, what is $M_n = \displaystyle\sup_{x \geq 0} |f_n(x) - x|$?

- $\dfrac{1}{n + 1}$
- $+\infty$
- $\dfrac{1}{n}$
- $\dfrac{1}{2n}$

## Explanation

For every $x \geq 0$ we have
$$
x - f_n(x) = \frac{x (1 + n x) - n x^2}{1 + n x} = \frac{x}{1 + n x} \geq 0 .
$$
The function $g(x) = \dfrac{x}{1 + n x}$ has derivative $g'(x) = \dfrac{1}{(1 + n x)^2} > 0$, so it is increasing on $[0, +\infty)$ and its supremum is the limit as $x \to +\infty$, that is, $\dfrac{1}{n}$. Therefore $M_n = \dfrac{1}{n}$, a value that is not attained at any point. Since $M_n \to 0$, by the **sup criterion** the convergence is **uniform** on $[0, +\infty)$.
