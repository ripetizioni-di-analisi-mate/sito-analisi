With $f_n(x) = \dfrac{\sin(n x)}{n x}$ for $0 < x \leq \pi$, the pointwise limit is $0$. Which description of uniform convergence is correct?

- It is uniform on $(0, \pi]$, because $|\sin(n x)| \leq 1$
- It is not uniform on any interval $[\delta, \pi]$ with $0 < \delta < \pi$
- It is uniform on every interval $[\delta, \pi]$ with $0 < \delta < \pi$, but not on $(0, \pi]$
- It is uniform on $(0, \pi]$, because $|\sin(n x)| \leq n x$

## Explanation

For fixed $x \in (0, \pi]$ we have $\left|\dfrac{\sin(n x)}{n x}\right| \leq \dfrac{1}{n x} \to 0$. On $[\delta, \pi]$ the same estimate gives $|f_n(x)| \leq \dfrac{1}{n \delta}$, so the supremum tends to $0$ and the convergence is uniform. By the standard limit $\dfrac{\sin t}{t} \to 1$ as $t \to 0$, for every $n$ we have $f_n(x) \to 1$ as $x \to 0^+$, so $\sup_{(0, \pi]} |f_n| \geq 1$. Therefore on $(0, \pi]$ the convergence is not uniform.
