For the $2\pi$-periodic extension of
$$
f(x) =
\begin{cases}
1 & \text{if } 0 \leq x < \frac{\pi}{2} \\
0 & \text{if } -\pi \leq x < 0 \text{ or } \frac{\pi}{2} \leq x < \pi
\end{cases}
$$
what is the value of the Fourier coefficient $b_2$?

- $\dfrac{2}{\pi}$
- $0$
- $\dfrac{1}{\pi}$
- $\dfrac{1}{2\pi}$

## Explanation

The function equals $1$ on $\left[ 0, \dfrac{\pi}{2} \right)$ and is zero on the rest of the period, so
$$
b_2 = \frac{1}{\pi} \int_0^{\frac{\pi}{2}} \sin(2x)\, dx = \frac{1}{\pi} \left[ -\frac{\cos(2x)}{2} \right]_0^{\frac{\pi}{2}} .
$$
Since $\cos\pi = -1$ and $\cos 0 = 1$, we have $-\dfrac{\cos\pi}{2} + \dfrac{\cos 0}{2} = 1$. Therefore $b_2 = \dfrac{1}{\pi}$.
