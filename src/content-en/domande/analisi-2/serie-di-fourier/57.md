A $2\pi$-periodic function $f$ has Fourier coefficients $a_2 = 3$ and $b_2 = 5$. What are the coefficients $a_2$ and $b_2$ of the function $g(x) = \dfrac{f(x) + f(-x)}{2}$?

- $a_2 = 0$ and $b_2 = 5$
- $a_2 = 3$ and $b_2 = 5$
- $a_2 = \dfrac{3}{2}$ and $b_2 = 0$
- $a_2 = 3$ and $b_2 = 0$

## Explanation

The function $h(x) = f(-x)$ has the same coefficients $a_n$ as $f$ and the coefficients $b_n$ with opposite sign, because under the substitution $t = -x$ the cosine stays the same and the sine changes sign. The coefficients depend linearly on the function, so $g = \dfrac{f + h}{2}$ has $a_2 = \dfrac{3 + 3}{2} = 3$ and $b_2 = \dfrac{5 - 5}{2} = 0$. The result is consistent with the fact that $g$ is **even**, therefore its series contains only cosines.
