Which of the following functions is periodic with period $\pi$?

- $\sin x + \cos(2x)$
- $\cos\left( \dfrac{x}{2} \right)$
- $\sin x + \sin(3x)$
- $\sin^2 x$

## Explanation

Since $\sin(x + \pi) = -\sin x$, we have $\sin^2(x + \pi) = \sin^2 x$ for every $x$, so $\sin^2 x$ has period $\pi$. For $f(x) = \sin x + \cos(2x)$ we have $f(x + \pi) = -\sin x + \cos(2x)$, which differs from $f(x)$ for instance at $x = \dfrac{\pi}{2}$. In the same way $\sin(x + \pi) + \sin(3x + 3\pi) = -\sin x - \sin(3x)$, therefore $\pi$ is not a period of $\sin x + \sin(3x)$. Finally $\cos\left( \dfrac{x}{2} \right)$ has minimal period $4\pi$, so $\pi$ is not one of its periods.
