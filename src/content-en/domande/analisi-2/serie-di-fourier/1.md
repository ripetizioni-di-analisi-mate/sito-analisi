For the $2\pi$-periodic extension of
$$
f(x) =
\begin{cases}
-2 & \text{if } -\pi \leq x < 0 \\
2 & \text{if } 0 \leq x < \pi
\end{cases}
$$
what is the value of the Fourier coefficient $b_3$?

- $\dfrac{4}{3\pi}$
- $\dfrac{8}{3\pi}$
- $0$
- $-\dfrac{8}{3\pi}$

## Explanation

For $0 < |x| < \pi$ we have $f(-x) = -f(x)$, and the value of $f$ at a single point does not change the integrals. So the coefficients are computed as for an **odd** function, and
$$
b_n = \frac{2}{\pi} \int_0^{\pi} 2 \sin(nx)\, dx = \frac{4}{\pi} \left[ -\frac{\cos(nx)}{n} \right]_0^{\pi} = \frac{4 \bigl( 1 - (-1)^n \bigr)}{n\pi} .
$$
For $n = 3$ we have $(-1)^3 = -1$, therefore $b_3 = \dfrac{8}{3\pi}$.
