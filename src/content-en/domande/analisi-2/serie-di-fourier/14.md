Which of the following functions is a trigonometric polynomial?

- $\sin^2 x \cos x$
- $|\sin x|$
- $\sin\left( \dfrac{x}{2} \right)$
- $\tan x$

## Explanation

Since $\sin^2 x = 1 - \cos^2 x$ and $\cos^3 x = \dfrac{3\cos x + \cos(3x)}{4}$, we have
$$
\sin^2 x \cos x = \cos x - \cos^3 x = \frac{1}{4} \cos x - \frac{1}{4} \cos(3x) ,
$$
so $\sin^2 x \cos x$ is a **trigonometric polynomial** of degree $3$. Every trigonometric polynomial is defined on $\mathbb{R}$, is $2\pi$-periodic and is infinitely differentiable. The function $|\sin x|$ is not differentiable at $x = 0$, therefore it is not a trigonometric polynomial. The function $\sin\left( \dfrac{x}{2} \right)$ is not $2\pi$-periodic, because $\sin\left( \dfrac{x + 2\pi}{2} \right) = -\sin\left( \dfrac{x}{2} \right)$, and the function $\tan x$ is not defined at the points $\dfrac{\pi}{2} + k\pi$.
