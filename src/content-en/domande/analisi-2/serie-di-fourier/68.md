An odd $2\pi$-periodic square-integrable function $f$ satisfies $\displaystyle\int_0^{\pi} f(x)^2\, dx = \pi$. What is $\displaystyle\sum_{n=1}^{\infty} b_n^2$?

- $1$
- $\pi$
- $2$
- $2\pi$

## Explanation

The function $f^2$ is even, so $\displaystyle\int_{-\pi}^{\pi} f(x)^2\, dx = 2 \int_0^{\pi} f(x)^2\, dx = 2\pi$. Since $f$ is odd, all the $a_n$ are zero. By **Parseval's identity** we therefore have $\displaystyle\sum_{n=1}^{\infty} b_n^2 = \frac{1}{\pi} \cdot 2\pi = 2$.
