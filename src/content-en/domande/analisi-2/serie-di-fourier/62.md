For the trigonometric polynomial $p(x) = 1 + \cos x + \sin(2x)$, which statement is true?

- $p(x + 2\pi) = p(x)$ for every $x \in \mathbb{R}$
- $p(x + \pi) = p(x)$ for every $x \in \mathbb{R}$
- $p$ is an even function
- $p$ is an odd function

## Explanation

Every trigonometric polynomial is $2\pi$-periodic, because every term $\cos(nx)$ and $\sin(nx)$ is; hence $p(x + 2\pi) = p(x)$. The number $\pi$ is not a period, because $p(x + \pi) = 1 - \cos x + \sin(2x)$ and in particular $p(\pi) = 0$, while $p(0) = 2$. The polynomial is neither even nor odd, because $p\left( \dfrac{\pi}{4} \right) = 2 + \dfrac{\sqrt{2}}{2}$ and $p\left( -\dfrac{\pi}{4} \right) = \dfrac{\sqrt{2}}{2}$ are neither equal nor opposite.
