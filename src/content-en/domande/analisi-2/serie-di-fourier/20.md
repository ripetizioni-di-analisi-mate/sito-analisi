For the $2\pi$-periodic extension of
$$
f(x) =
\begin{cases}
0 & \text{se } -\pi \leq x < 0 \\
x & \text{se } 0 \leq x < \pi
\end{cases}
$$
what is the value of the Fourier coefficient $a_1$?

- $\dfrac{2}{\pi}$
- $-\dfrac{4}{\pi}$
- $0$
- $-\dfrac{2}{\pi}$

## Explanation

The function is zero on $[-\pi, 0)$, so the integral defining $a_1$ reduces to the interval $[0, \pi]$ and
$$
a_1 = \frac{1}{\pi} \int_0^{\pi} x \cos x\, dx .
$$
Since $f$ is not even, the factor $\dfrac{2}{\pi}$ of the formulas for even functions does not appear. Integrating by parts gives
$$
\int_0^{\pi} x \cos x\, dx = \bigl[ x \sin x \bigr]_0^{\pi} - \int_0^{\pi} \sin x\, dx = 0 - 2 = -2 ,
$$
therefore $a_1 = -\dfrac{2}{\pi}$.
