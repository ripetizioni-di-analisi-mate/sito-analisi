In polar coordinates, which set describes the disk $D = \{ (x, y) : x^2 + y^2 \leq 2x \}$?

- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 2\cos\theta$
- $-\dfrac{\pi}{2} \leq \theta \leq \dfrac{\pi}{2}$, $\ 0 \leq \rho \leq 2$
- $0 \leq \theta \leq \pi$, $\ 0 \leq \rho \leq 2\cos\theta$
- $-\dfrac{\pi}{2} \leq \theta \leq \dfrac{\pi}{2}$, $\ 0 \leq \rho \leq 2\cos\theta$

## Explanation

The inequality $x^2 + y^2 \leq 2x$ is equivalent to $(x - 1)^2 + y^2 \leq 1$, so $D$ is the disk with center $(1, 0)$ and radius $1$, which passes through the origin. Substituting $x = \rho \cos\theta$ and $y = \rho \sin\theta$ gives $\rho^2 \leq 2\rho \cos\theta$, that is, $\rho \leq 2\cos\theta$ for $\rho > 0$. This condition admits values $\rho > 0$ only if $\cos\theta > 0$, therefore $\theta$ ranges between $-\dfrac{\pi}{2}$ and $\dfrac{\pi}{2}$. The condition $0 \leq \rho \leq 2$ with the same interval for $\theta$ describes the half-disk of radius $2$ with $x \geq 0$, which contains $D$ and does not coincide with it.
