In cylindrical coordinates, which description corresponds to the solid $E = \{ (x, y, z) : x^2 + y^2 \leq 4, \ 0 \leq z \leq x^2 + y^2 \}$?

- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 2$, $\ \rho^2 \leq z \leq 4$
- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 4$, $\ 0 \leq z \leq \rho^2$
- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 2$, $\ 0 \leq z \leq \rho^2$
- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 2$, $\ 0 \leq z \leq \rho$

## Explanation

In **cylindrical coordinates** we have $x^2 + y^2 = \rho^2$, so the condition $x^2 + y^2 \leq 4$ becomes $\rho^2 \leq 4$, that is, $0 \leq \rho \leq 2$. The condition on the height becomes $0 \leq z \leq \rho^2$. The two conditions do not contain $\theta$, therefore $\theta$ ranges over the whole interval $[0, 2\pi]$ and
$$
E = \left\{ (\rho, \theta, z) :
\begin{cases}
0 \leq \theta \leq 2\pi \\
0 \leq \rho \leq 2 \\
0 \leq z \leq \rho^2
\end{cases}
\right\} .
$$
The condition $\rho^2 \leq z \leq 4$ describes the part of the cylinder lying between the paraboloid and the plane $z = 4$, which lies above $E$.
