What is the value of the iterated integral $\displaystyle\int_0^1 \left( \int_{\sqrt{y}}^{1} e^{x^3}\, dx \right) dy$?

- $\dfrac{e - 1}{3}$
- $e - 1$
- $\dfrac{e - 1}{2}$
- $\dfrac{e}{3}$

## Explanation

The function $e^{x^3}$ has no elementary antiderivative with respect to $x$, so we **change the order of integration**. The limits describe the region $0 \leq y \leq 1$, $\sqrt{y} \leq x \leq 1$. For $x \geq 0$ and $y \geq 0$ the condition $\sqrt{y} \leq x$ is equivalent to $y \leq x^2$, so the same region is described by $0 \leq x \leq 1$, $0 \leq y \leq x^2$. Therefore
$$
\int_0^1 \left( \int_0^{x^2} e^{x^3}\, dy \right) dx = \int_0^1 x^2 e^{x^3}\, dx .
$$
The last integral reduces to the standard integral $\displaystyle\int e^{t}\, dt = e^{t} + c$ with $t = x^3$, so it equals $\left[ \dfrac{e^{x^3}}{3} \right]_0^1 = \dfrac{e - 1}{3}$.
