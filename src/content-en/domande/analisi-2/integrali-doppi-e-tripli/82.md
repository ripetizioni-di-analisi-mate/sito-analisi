Which bounds on $r$ and $\varphi$ describe in spherical coordinates, with $0 \leq \theta \leq 2\pi$, the ball $B = \{ (x, y, z) : x^2 + y^2 + z^2 \leq 2z \}$?

- $0 \leq r \leq 1$, $\ 0 \leq \varphi \leq \pi$
- $0 \leq r \leq 2$, $\ 0 \leq \varphi \leq \dfrac{\pi}{2}$
- $0 \leq r \leq 2\sin\varphi$, $\ 0 \leq \varphi \leq \dfrac{\pi}{2}$
- $0 \leq r \leq 2\cos\varphi$, $\ 0 \leq \varphi \leq \dfrac{\pi}{2}$

## Explanation

The inequality is equivalent to $x^2 + y^2 + (z - 1)^2 \leq 1$, so $B$ is the ball with center $(0, 0, 1)$ and radius $1$, which touches the origin. Since $x^2 + y^2 + z^2 = r^2$ and $z = r \cos\varphi$, we get $r^2 \leq 2 r \cos\varphi$, that is, $r \leq 2\cos\varphi$ for $r > 0$. This condition admits values $r > 0$ only if $\cos\varphi > 0$, therefore $0 \leq \varphi \leq \dfrac{\pi}{2}$. The condition $0 \leq r \leq 1$ with $0 \leq \varphi \leq \pi$ describes the ball of radius $1$ centered at the origin, and $0 \leq r \leq 2$ with $0 \leq \varphi \leq \dfrac{\pi}{2}$ describes the half-ball of radius $2$, which contains $B$ without coinciding with it.
