The disk $D = \{ (x, y) : x^2 + y^2 \leq 2y \}$ has center $(0, 1)$ and radius $1$, so it passes through the origin. What is the value of $\displaystyle\iint_D \sqrt{x^2 + y^2}\, dx\, dy$?

- $\dfrac{16}{9}$
- $\dfrac{32}{9}$
- $\pi$
- $\dfrac{8\pi}{3}$

## Explanation

In **polar coordinates** the condition $x^2 + y^2 \leq 2y$ becomes $\rho^2 \leq 2\rho \sin\theta$, that is, $\rho \leq 2\sin\theta$ for $\rho > 0$. This condition admits values $\rho > 0$ only if $\sin\theta > 0$, therefore $D$ is described by $0 \leq \theta \leq \pi$, $0 \leq \rho \leq 2\sin\theta$. The function equals $\rho$ and the area element is $\rho\, d\rho\, d\theta$, so
$$
\iint_D \sqrt{x^2 + y^2}\, dx\, dy = \int_0^{\pi} \left( \int_0^{2\sin\theta} \rho^2\, d\rho \right) d\theta = \frac{8}{3} \int_0^{\pi} \sin^3\theta\, d\theta .
$$
Since $\sin^3\theta = \sin\theta \left( 1 - \cos^2\theta \right)$, the last integral equals $2 - \dfrac{2}{3} = \dfrac{4}{3}$, therefore the result is $\dfrac{8}{3} \cdot \dfrac{4}{3} = \dfrac{32}{9}$. The value $\dfrac{16}{9}$ lets $\theta$ range only between $0$ and $\dfrac{\pi}{2}$, $\pi$ is obtained without the factor $\rho$ of the area element, and $\dfrac{8\pi}{3}$ uses $\rho \leq 2$ instead of $\rho \leq 2\sin\theta$.
