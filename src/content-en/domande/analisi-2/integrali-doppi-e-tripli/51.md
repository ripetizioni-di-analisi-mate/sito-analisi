Let $D$ be the region of the first quadrant between the curves $y = x^3$ and $y = x$. Which description of $D$ as a normal domain with respect to the $x$-axis is correct?

- $0 \leq x \leq 1$, $\ x \leq y \leq x^3$
- $0 \leq x \leq 1$, $\ x^3 \leq y \leq x$
- $0 \leq x \leq 1$, $\ x^3 \leq y \leq 1$
- $0 \leq x \leq 1$, $\ 0 \leq y \leq x$

## Explanation

The two curves meet where $x^3 = x$, that is, at $x = -1$, $x = 0$ and $x = 1$; in the first quadrant only $x = 0$ and $x = 1$ remain. For $0 \leq x \leq 1$ we have $x^3 \leq x$, so the vertical segment at abscissa $x$ enters through the curve $y = x^3$ and exits through the line $y = x$. Therefore
$$
D = \left\{ (x, y) :
\begin{cases}
0 \leq x \leq 1 \\
x^3 \leq y \leq x
\end{cases}
\right\} .
$$
The condition $x^3 \leq y \leq 1$ describes instead the region between the curve $y = x^3$ and the line $y = 1$, which contains $D$ and does not coincide with it.
