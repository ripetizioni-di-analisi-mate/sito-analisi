The circular sector $D$ consists of the points of the disk $x^2 + y^2 \leq 4$ lying between the positive $x$-semiaxis and the bisector $y = x$, that is, with $0 \leq y \leq x$. Which bounds on $\rho$ and $\theta$ describe $D$?

- $0 \leq \theta \leq \dfrac{\pi}{4}$, $\ 0 \leq \rho \leq 2$
- $0 \leq \theta \leq \dfrac{\pi}{2}$, $\ 0 \leq \rho \leq 2$
- $0 \leq \theta \leq \dfrac{\pi}{4}$, $\ 0 \leq \rho \leq 4$
- $\dfrac{\pi}{4} \leq \theta \leq \dfrac{\pi}{2}$, $\ 0 \leq \rho \leq 2$

## Explanation

Since $x^2 + y^2 = \rho^2$, the condition $x^2 + y^2 \leq 4$ becomes $0 \leq \rho \leq 2$. The condition $0 \leq y \leq x$ singles out the points between the positive $x$-semiaxis and the bisector $y = x$ of the first quadrant, so $0 \leq \theta \leq \dfrac{\pi}{4}$. The set $\dfrac{\pi}{4} \leq \theta \leq \dfrac{\pi}{2}$ describes instead the part of the first quadrant above the bisector, where $y \geq x$.
