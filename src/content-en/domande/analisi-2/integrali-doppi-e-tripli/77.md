In spherical coordinates, which set describes the solid $E = \left\{ (x, y, z) : x^2 + y^2 + z^2 \leq 4, \ z \geq \sqrt{x^2 + y^2} \right\}$? In all cases $0 \leq \theta \leq 2\pi$.

- $0 \leq r \leq 2$, $\ \dfrac{\pi}{4} \leq \varphi \leq \dfrac{\pi}{2}$
- $0 \leq r \leq 4$, $\ 0 \leq \varphi \leq \dfrac{\pi}{4}$
- $0 \leq r \leq 2$, $\ 0 \leq \varphi \leq \dfrac{\pi}{4}$
- $0 \leq r \leq 2$, $\ 0 \leq \varphi \leq \dfrac{\pi}{2}$

## Explanation

Since $x^2 + y^2 + z^2 = r^2$, the first condition becomes $0 \leq r \leq 2$. We have $\sqrt{x^2 + y^2} = r \sin\varphi$ and $z = r \cos\varphi$, so the condition $z \geq \sqrt{x^2 + y^2}$ becomes $\cos\varphi \geq \sin\varphi$, which for $\varphi \in [0, \pi]$ holds for $0 \leq \varphi \leq \dfrac{\pi}{4}$. The solid is therefore the part of the ball inside the cone with axis $z$ and half-opening $\dfrac{\pi}{4}$. The interval $0 \leq \varphi \leq \dfrac{\pi}{2}$ describes the whole half-ball with $z \geq 0$.
