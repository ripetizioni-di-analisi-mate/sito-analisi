For the curve $x^2 + 4y^2 = 4$ at the point $(2, 0)$, which statement is true?

- Near the point the curve is the graph of a function $y = \varphi(x)$ with $\varphi'(2) = 0$
- The point is singular and the implicit function theorem gives no information in either direction
- Near the point the curve is the graph of a function $x = \psi(y)$ and the tangent line is horizontal
- Near the point the curve is the graph of a function $x = \psi(y)$ and the tangent line is vertical

## Explanation

Let $F(x, y) = x^2 + 4y^2 - 4$, of class $C^1$ on $\mathbb{R}^2$; we have $F(2, 0) = 0$. The partial derivatives are $F_x = 2x$ and $F_y = 8y$, so $F_x(2, 0) = 4$ and $F_y(2, 0) = 0$. Since $F_y(2, 0) = 0$, the implicit function theorem with respect to $y$ does not apply. Since $F_x(2, 0) \neq 0$, the theorem applies with the roles of the variables **exchanged**, and near the point the curve is the graph of a function $x = \psi(y)$. The tangent line $4(x - 2) + 0 \cdot (y - 0) = 0$ is the line $x = 2$, so it is **vertical**.
