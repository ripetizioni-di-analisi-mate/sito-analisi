- $y = 1 + 2x$
- $y = 1 - \dfrac{1}{2}\,x$
- $y = 1 - 2x$
- $y = 1 - x$

## Explanation

Let $F(x, y) = \ln(x + y) + xy$, of class $C^1$ on the open set where $x + y > 0$; we have $F(0, 1) = \ln 1 + 0 = 0$. The partial derivatives are
$$
F_x = \frac{1}{x + y} + y, \qquad F_y = \frac{1}{x + y} + x ,
$$
so $F_x(0, 1) = 2$ and $F_y(0, 1) = 1 \neq 0$. By **Dini's theorem**, near the point the curve is the graph of a function $y = \varphi(x)$ with $\varphi'(0) = -\dfrac{2}{1} = -2$. Therefore the tangent line is $y = 1 - 2x$.
