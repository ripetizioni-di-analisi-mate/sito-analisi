For $F=\dfrac{x^{2}}{16} + \dfrac{y^{2}}{4} - 1$ and curve $F=0$, which IFT condition holds at $\left( 4, \  0\right)$?

- IFT with respect to $x$ only
- IFT with respect to both variables
- IFT with respect to neither variable
- IFT with respect to $y$ only

## Explanation

At the point $F_x=\dfrac{1}{2}$ and $F_y=0$. Thus one can solve locally for $x$.
