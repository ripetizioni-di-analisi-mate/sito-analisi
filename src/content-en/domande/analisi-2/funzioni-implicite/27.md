The equation $e^{y} + xy = e$ implicitly defines a function $y = \varphi(x)$ near the point $(0, 1)$. What is $\varphi''(0)$?

- $\varphi''(0) = -\dfrac{1}{e^2}$
- $\varphi''(0) = \dfrac{2}{e^2}$
- $\varphi''(0) = \dfrac{1}{e^2}$
- $\varphi''(0) = -\dfrac{3}{e^2}$

## Explanation

Let $F(x, y) = e^{y} + xy - e$, of class $C^2$ on $\mathbb{R}^2$; we have $F(0, 1) = e - e = 0$ and $F_y(0, 1) = e^{y} + x \,\big|_{(0,1)} = e \neq 0$, so the **implicit function theorem** applies. Differentiating the identity with respect to $x$ we obtain $e^{y}\,y' + y + x\,y' = 0$; at the point this gives $e\,y' + 1 = 0$, so $\varphi'(0) = -\dfrac{1}{e}$. Differentiating again we obtain
$$
e^{y} (y')^2 + e^{y}\,y'' + 2y' + x\,y'' = 0 .
$$
At the point we have $\dfrac{1}{e} + e\,y'' - \dfrac{2}{e} = 0$, that is, $e\,y'' = \dfrac{1}{e}$. Hence $\varphi''(0) = \dfrac{1}{e^2}$.
