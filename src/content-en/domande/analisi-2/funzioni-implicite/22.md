The function $F(x, y) = y - |x|$ vanishes at the origin.

::grafico{f="abs(x)" punti="0,0,pieno" xmin=-2 xmax=2 ymin=-0.6 ymax=2 uguale=1 titolo="The zero set of $F(x, y) = y - |x|$"}

Which statement is true?

- The implicit function theorem applies, because $F_y(0, 0) = 1 \neq 0$, so the implicit function is differentiable at $0$
- The implicit function theorem does not apply, so near $(0, 0)$ the zero set is not the graph of any function $y = \varphi(x)$
- $F$ is not of class $C^1$ in any neighborhood of $(0, 0)$, so the implicit function theorem does not apply; the zero set is the graph of $y = |x|$, which is not differentiable at $0$
- The point is singular, because $\nabla F(0, 0) = (0, 0)$

## Explanation

The implicit function theorem requires $F$ to be of class $C^1$ on an open set containing the point. The partial derivative $F_x$ does not exist at the points with $x = 0$, since $|x|$ is not differentiable at $0$, so $F$ **is not of class $C^1$** in any neighborhood of $(0, 0)$ and the theorem does not apply, even though $F_y = 1$. For the same reason the gradient at $(0, 0)$ does not exist, therefore it makes no sense to say that it is zero. The equation $F(x, y) = 0$ is equivalent to $y = |x|$, so the zero set is still the graph of a function, which however is not differentiable at $x = 0$.
