The function $g$ assigns to every $(x, y) \in \mathbb{R}^2$ the unique real number $z$ such that $z^3 + z + x^2 + y^2 = 0$; in particular $g(0, 0) = 0$. What type of point is $(0, 0)$ for $g$?

- A local minimum point
- A saddle point
- It is not a stationary point
- A local maximum point

## Explanation

Differentiating the identity with respect to $x$ gives $(3z^2 + 1)\,g_x + 2x = 0$, and likewise $(3z^2 + 1)\,g_y + 2y = 0$, so $\nabla g(0, 0) = (0, 0)$. Differentiating again with respect to $x$ gives $6z\,g_x^2 + (3z^2 + 1)\,g_{xx} + 2 = 0$, which at the origin gives $g_{xx}(0, 0) = -2$; likewise $g_{yy}(0, 0) = -2$ and $g_{xy}(0, 0) = 0$. The Hessian matrix at $(0, 0)$ is therefore negative definite, so the origin is a **local maximum** point. This is confirmed by the fact that $z^3 + z = -(x^2 + y^2) \leq 0$ implies $g(x, y) \leq 0 = g(0, 0)$.
