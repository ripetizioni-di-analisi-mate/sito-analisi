The curve $F(x, y) = 0$, with $F$ of class $C^1$, passes through $(x_0, y_0)$, where $F_y(x_0, y_0) \neq 0$, and the implicit function $y = \varphi(x)$ has $\varphi'(x_0) = 0$. Which statement is true?

- $F_y(x_0, y_0) = 0$ and the tangent line at the point is vertical
- $\nabla F(x_0, y_0) = (0, 0)$, so the point is singular
- $F_x(x_0, y_0) = 0$, so the implicit function theorem with respect to $x$ does not apply at $(x_0, y_0)$
- Near the point the curve is also the graph of a function $x = \psi(y)$, with $\psi'(y_0) = 0$

## Explanation

Since $\varphi'(x_0) = -\dfrac{F_x(x_0, y_0)}{F_y(x_0, y_0)}$ and $F_y(x_0, y_0) \neq 0$, the condition $\varphi'(x_0) = 0$ is equivalent to $F_x(x_0, y_0) = 0$. The implicit function theorem with respect to $x$ requires $F_x(x_0, y_0) \neq 0$, so at that point it **does not apply**. The gradient is $(0, F_y(x_0, y_0))$, which is not the zero vector, therefore the point is not singular and the tangent line $y = y_0$ is horizontal. If the curve were also the graph of a differentiable function $x = \psi(y)$, from $\psi(\varphi(x)) = x$ it would follow that $\psi'(y_0)\,\varphi'(x_0) = 1$, which is impossible with $\varphi'(x_0) = 0$.
