Consider the curve $x y + \sin y = 0$ at the point $(0, 0)$. With respect to which variable does the implicit function theorem apply?

- It applies with respect to $y$ and does not apply with respect to $x$
- It applies with respect to $x$ and does not apply with respect to $y$
- It applies with respect to both variables
- It applies with respect to neither, because the point is singular

## Explanation

Let $F(x, y) = xy + \sin y$, of class $C^1$ on $\mathbb{R}^2$; we have $F(0, 0) = 0$. The partial derivatives are $F_x = y$ and $F_y = x + \cos y$, so $F_x(0, 0) = 0$ and $F_y(0, 0) = 1$. Since $F_y(0, 0) \neq 0$, the theorem applies with respect to $y$ and near the origin the curve is the graph of a function $y = \varphi(x)$. Since $F_x(0, 0) = 0$, the theorem with respect to $x$ **does not apply**. The gradient $(0, 1)$ is not the zero vector, therefore the point is not singular.
