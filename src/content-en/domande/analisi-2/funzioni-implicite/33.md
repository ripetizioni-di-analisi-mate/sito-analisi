The equation $z\,e^{x} + y z^2 = 2$ implicitly defines a function $z = g(x, y)$ near the point $(0, 1, 1)$. What is $\nabla g(0, 1)$?

- $\left(-\dfrac{1}{3}, -\dfrac{1}{3}\right)$
- $\left(\dfrac{1}{3}, \dfrac{1}{3}\right)$
- $\left(-\dfrac{1}{2}, -\dfrac{1}{2}\right)$
- $(-3, -3)$

## Explanation

Let $F(x, y, z) = z\,e^{x} + y z^2 - 2$, which is of class $C^1$ on $\mathbb{R}^3$; we have $F(0, 1, 1) = 1 + 1 - 2 = 0$. The partial derivatives are $F_x = z\,e^{x}$, $F_y = z^2$ and $F_z = e^{x} + 2yz$, so at the point $F_x = 1$, $F_y = 1$ and $F_z = 3 \neq 0$. Therefore the **implicit function theorem in three variables** applies and
$$
g_x(0, 1) = -\,\frac{F_x}{F_z} = -\,\frac{1}{3},
\qquad
g_y(0, 1) = -\,\frac{F_y}{F_z} = -\,\frac{1}{3} .
$$
