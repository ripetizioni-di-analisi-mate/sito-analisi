For $F=\dfrac{x^{2}}{9} + \dfrac{y^{2}}{25} - 1$ and curve $F=0$, which IFT condition holds at $\left( 3, \  0\right)$?

- IFT with respect to neither variable
- IFT with respect to $y$ only
- IFT with respect to $x$ only
- IFT with respect to both variables

## Explanation

At the point $F_x=\dfrac{2}{3}$ and $F_y=0$. Thus one can solve locally for $x$.
