For $F=\dfrac{x^{2}}{9} + \dfrac{y^{2}}{25} - 1$ and the curve $F=0$, which condition of the implicit function theorem holds at $\left( 3, \  0\right)$?

- Implicit function theorem with respect to neither variable
- Implicit function theorem with respect to $y$ only
- Implicit function theorem with respect to $x$ only
- Implicit function theorem with respect to both variables

## Explanation

At the point $F_x=\dfrac{2}{3}$ and $F_y=0$. Thus one can solve locally for $x$.
