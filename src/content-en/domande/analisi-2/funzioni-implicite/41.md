Consider the branch of the circle $x^2 + y^2 = 9$ contained in the half-plane $y < 0$, the graph of a function $y = \varphi(x)$ for $-3 < x < 3$. Which statement is true?

- $\varphi''(x) = -\dfrac{9}{y^3} < 0$, so the branch is concave
- $\varphi''(x) = \dfrac{9}{y^3} < 0$, so the branch is concave
- $\varphi''(x) = -\dfrac{x}{y} > 0$, so the branch is convex
- $\varphi''(x) = -\dfrac{9}{y^3} > 0$, so the branch is convex

## Explanation

Differentiating the identity $x^2 + y^2 = 9$ gives $2x + 2y\,y' = 0$, so $y' = -\dfrac{x}{y}$. Differentiating again gives $2 + 2(y')^2 + 2y\,y'' = 0$, therefore
$$
y'' = -\,\frac{1 + (y')^2}{y} = -\,\frac{y^2 + x^2}{y^3} = -\,\frac{9}{y^3} ,
$$
where the equation of the curve was used in the last step. On the branch considered $y < 0$, so $y^3 < 0$ and $\varphi''(x) > 0$, therefore the lower branch is **convex**.
