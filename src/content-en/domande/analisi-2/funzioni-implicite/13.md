The equation $x^2 + 2xy + 3y^3 = 6$ implicitly defines a function $y = \varphi(x)$ near the point $(1, 1)$. What is $\varphi'(1)$?

- $\varphi'(1) = -\dfrac{4}{11}$
- $\varphi'(1) = \dfrac{4}{11}$
- $\varphi'(1) = -\dfrac{11}{4}$
- $\varphi'(1) = -\dfrac{4}{5}$

## Explanation

Let $F(x, y) = x^2 + 2xy + 3y^3 - 6$, which is of class $C^1$ on $\mathbb{R}^2$; we have $F(1, 1) = 1 + 2 + 3 - 6 = 0$. The partial derivatives are $F_x = 2x + 2y$ and $F_y = 2x + 9y^2$, so $F_x(1, 1) = 4$ and $F_y(1, 1) = 11 \neq 0$. Therefore the **implicit function theorem** applies and
$$
\varphi'(1) = -\,\frac{F_x(1, 1)}{F_y(1, 1)} = -\,\frac{4}{11} .
$$
