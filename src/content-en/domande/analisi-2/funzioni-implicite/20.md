Which function is implicitly defined by the equation $x^2 + y^2 = 25$ near the point $(3, -4)$?

- $\varphi(x) = \sqrt{25 - x^2}$
- $\varphi(x) = -\sqrt{x^2 + 7}$
- $\varphi(x) = x - 7$
- $\varphi(x) = -\sqrt{25 - x^2}$

## Explanation

A function $\varphi$ is implicitly defined near $(3, -4)$ if $\varphi(3) = -4$ and $x^2 + \varphi(x)^2 = 25$ for every $x$ in a neighborhood of $3$. The function $\sqrt{25 - x^2}$ satisfies the equation, but it equals $4$ at $x = 3$. The functions $-\sqrt{x^2 + 7}$ and $x - 7$ equal $-4$ at $x = 3$, but substituted into the equation they give $2x^2 + 7 = 25$ and $x^2 + (x - 7)^2 = 25$, equalities that hold at only two points. The function $-\sqrt{25 - x^2}$ satisfies both conditions, so it is the function **implicitly defined** near $(3, -4)$.
