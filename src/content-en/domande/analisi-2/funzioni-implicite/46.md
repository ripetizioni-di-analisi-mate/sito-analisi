For which of the following curves does the implicit function $y = \varphi(x)$ have $\varphi''(x) = 0$ near every point of the curve where the implicit function theorem with respect to $y$ applies?

- $x^2 + y^2 = 2$
- $y^3 + y = x$
- $e^{y} = x + 1$
- $(x + 2y)^3 + (x + 2y) = 2$

## Explanation

Setting $s = x + 2y$, the equation $(x + 2y)^3 + (x + 2y) = 2$ becomes $s^3 + s - 2 = 0$, whose only real solution is $s = 1$, since $s \mapsto s^3 + s$ is strictly increasing. Hence the curve is the line $x + 2y = 1$, and the implicit function $\varphi(x) = \dfrac{1 - x}{2}$ has **zero second derivative**. For the circle $x^2 + y^2 = 2$ we have $\varphi'' = -\dfrac{2}{y^3} \neq 0$. For $y^3 + y = x$ we have $\varphi'' = -\dfrac{6y}{(3y^2 + 1)^3}$, which is nonzero for $y \neq 0$, and for $e^y = x + 1$ we have $\varphi(x) = \ln(x + 1)$, with $\varphi''(x) = -\dfrac{1}{(x + 1)^2} \neq 0$.
