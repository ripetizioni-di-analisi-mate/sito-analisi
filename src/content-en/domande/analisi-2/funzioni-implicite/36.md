What is the tangent plane to the surface $z\,e^{xy} + z^2 = 2$ at the point $(0, 0, 1)$?

- $x + y + 3z = 3$
- $z = 0$
- $x + y + 2z = 2$
- $z = 1$

## Explanation

Let $F(x, y, z) = z\,e^{xy} + z^2 - 2$, of class $C^1$ on $\mathbb{R}^3$; we have $F(0, 0, 1) = 1 + 1 - 2 = 0$. By the chain rule the partial derivatives are $F_x = yz\,e^{xy}$, $F_y = xz\,e^{xy}$ and $F_z = e^{xy} + 2z$, so $\nabla F(0, 0, 1) = (0, 0, 3) \neq (0, 0, 0)$. The tangent plane has equation $0 \cdot x + 0 \cdot y + 3(z - 1) = 0$, that is, $z = 1$. The plane is therefore **horizontal**, and the function $z = g(x, y)$ implicitly defined near the point has zero gradient at $(0, 0)$.
