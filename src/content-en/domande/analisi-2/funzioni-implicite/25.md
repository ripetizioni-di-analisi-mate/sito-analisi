The equation $y^3 + y + x^2 - 4x + 2 = 0$ implicitly defines a function $y = \varphi(x)$ for every $x \in \mathbb{R}$. At which point does $\varphi$ have a stationary point, and of what type is it?

- $x_0 = 2$, local maximum point
- $x_0 = 2$, local minimum point
- $x_0 = -2$, local maximum point
- $x_0 = -2$, local minimum point

## Explanation

Let $F(x, y) = y^3 + y + x^2 - 4x + 2$, of class $C^2$ on $\mathbb{R}^2$. Since $F_y = 3y^2 + 1 > 0$, the implicit function theorem applies at every point of the curve. The stationary points of $\varphi$ correspond to the points of the curve with $F_x = 2x - 4 = 0$, that is, $x_0 = 2$. For $x = 2$ the equation becomes $y^3 + y - 2 = 0$, whose only solution is $y = 1$, since $y^3 + y$ is strictly increasing. At $(2, 1)$ we have $F_{xx} = 2$ and $F_y = 4$, so
$$
\varphi''(2) = -\,\frac{F_{xx}(2, 1)}{F_y(2, 1)} = -\,\frac{1}{2} .
$$
Since $\varphi''(2) < 0$, the point $x_0 = 2$ is a **local maximum point** of $\varphi$.
