For $F=\dfrac{x^{2}}{4} + \dfrac{y^{2}}{9} - 1$ and curve $F=0$, which IFT condition holds at $\left( 2, \  0\right)$?

- IFT with respect to $y$ only
- IFT with respect to both variables
- IFT with respect to neither variable
- IFT with respect to $x$ only

## Explanation

At the point $F_x=1$ and $F_y=0$. Thus one can solve locally for $x$.
