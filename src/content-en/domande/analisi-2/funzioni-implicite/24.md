The equation $x^3 + x + y^2 = 3$ implicitly defines a function $x = \psi(y)$ near the point $(1, 1)$. What is $\psi'(1)$?

- $\psi'(1) = -2$
- $\psi'(1) = \dfrac{1}{2}$
- $\psi'(1) = -\dfrac{1}{2}$
- $\psi'(1) = -\dfrac{1}{4}$

## Explanation

Let $F(x, y) = x^3 + x + y^2 - 3$, of class $C^1$ on $\mathbb{R}^2$; we have $F(1, 1) = 0$. The partial derivatives at the point are $F_x(1, 1) = 3x^2 + 1 \,\big|_{(1,1)} = 4$ and $F_y(1, 1) = 2y \,\big|_{(1,1)} = 2$. Since $F_x(1, 1) \neq 0$, the implicit function theorem applies with the roles of the variables **exchanged**, and the derivative of the function $x = \psi(y)$ is
$$
\psi'(1) = -\,\frac{F_y(1, 1)}{F_x(1, 1)} = -\,\frac{2}{4} = -\,\frac{1}{2} .
$$
