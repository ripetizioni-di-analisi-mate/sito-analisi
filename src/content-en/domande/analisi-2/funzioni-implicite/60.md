We want to express the coordinate $x$ of the points of the surface $x\,e^{z} + y^2 + z = 2$ near $(1, 1, 0)$ as a function $x = h(y, z)$. What is $h_y(1, 0)$?

- $h_y(1, 0) = -1$
- $h_y(1, 0) = 2$
- $h_y(1, 0) = -\dfrac{1}{2}$
- $h_y(1, 0) = -2$

## Explanation

Let $F(x, y, z) = x\,e^{z} + y^2 + z - 2$, of class $C^1$, with $F(1, 1, 0) = 1 + 1 + 0 - 2 = 0$. The partial derivatives at the point are $F_x = e^{z} = 1$, $F_y = 2y = 2$ and $F_z = x\,e^{z} + 1 = 2$. Since $F_x(1, 1, 0) \neq 0$, the implicit function theorem applies with respect to $x$, with the formulas obtained by exchanging the roles of the variables, so
$$
h_y(1, 0) = -\,\frac{F_y(1, 1, 0)}{F_x(1, 1, 0)} = -\,\frac{2}{1} = -2 .
$$
