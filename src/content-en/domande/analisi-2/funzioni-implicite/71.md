The cylinder $x^2 + y^2 = 4$ passes through the point $(2, 0, 5)$. Which description of the surface near this point is guaranteed by the implicit function theorem in three variables?

- The graph of a function $z = g(x, y)$
- The graph of a function $y = k(x, z)$
- None, because the gradient at the point is zero
- The graph of a function $x = h(y, z)$

## Explanation

Let $F(x, y, z) = x^2 + y^2 - 4$, with $F(2, 0, 5) = 0$ and $\nabla F = (2x, 2y, 0)$, so $\nabla F(2, 0, 5) = (4, 0, 0)$, which is not the zero vector. Since $F_x(2, 0, 5) = 4 \neq 0$, the theorem applies with respect to $x$ and near the point the surface is the graph of a function $x = h(y, z)$, namely $x = \sqrt{4 - y^2}$. Since $F_y$ and $F_z$ vanish at the point, the theorem applies neither with respect to $y$ nor with respect to $z$. In particular the cylinder, which contains vertical lines, is not the graph of a function $z = g(x, y)$.
