For every value of the real parameter $a$ the system
$$
\begin{cases}
z = x^2 + y^2 \\[4pt]
x + a y + z = 3 + a
\end{cases}
$$
has the solution $(1, 1, 2)$. For which values of $a$ does the implicit function theorem for systems guarantee that, near this point, the system defines two functions $y = y(x)$ and $z = z(x)$?

- $a \neq 2$
- $a \neq -2$
- $a \neq -1$
- For every $a \in \mathbb{R}$

## Explanation

Let $F(x, y, z) = x^2 + y^2 - z$ and $G(x, y, z) = x + a y + z - 3 - a$, of class $C^1$ on $\mathbb{R}^3$; the point solves the system, since $1 + 1 = 2$ and $1 + a + 2 = 3 + a$. The Jacobian determinant with respect to $(y, z)$ at the point is
$$
\frac{\partial(F, G)}{\partial(y, z)}(1, 1, 2) = \det \begin{pmatrix} 2y & -1 \\ a & 1 \end{pmatrix}_{(1,1,2)} = 2 + a .
$$
Therefore the hypotheses of the theorem are satisfied if and only if $a \neq -2$. For $a = -2$ the tangent vector to the intersection curve is parallel to $\nabla F \times \nabla G = (2, 2, -1) \times (1, -2, 1) = (0, -3, -6)$, whose $x$-component is zero, so the variable $x$ cannot serve as the parameter of the curve near the point.
