The curve $a x^2 + xy + y^2 = a + 2$ passes through the point $(1, 1)$ for every $a \in \mathbb{R}$. For which value of $a$ does the function $y = \varphi(x)$ implicitly defined near $(1, 1)$ satisfy $\varphi'(1) = 0$?

- $a = \dfrac{1}{2}$
- $a = -1$
- $a = -\dfrac{1}{2}$
- $a = -2$

## Explanation

Let $F(x, y) = a x^2 + xy + y^2 - a - 2$, of class $C^1$ on $\mathbb{R}^2$, with $F_x = 2ax + y$ and $F_y = x + 2y$. At the point $(1, 1)$ we have $F_x = 2a + 1$ and $F_y = 3 \neq 0$, so **Dini's theorem** applies for every $a$ and
$$
\varphi'(1) = -\,\frac{2a + 1}{3} .
$$
Therefore $\varphi'(1) = 0$ if and only if $2a + 1 = 0$, that is, $a = -\dfrac{1}{2}$.
