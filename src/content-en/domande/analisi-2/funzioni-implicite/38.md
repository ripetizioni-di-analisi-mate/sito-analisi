For a function $F$ of class $C^2$ it is known that at the point $(x_0, y_0)$ of the curve $F(x, y) = 0$ we have $F_x = 0$, $F_y = 4$ and $F_{xx} = -2$. What can be said about the implicit function $y = \varphi(x)$ at $x_0$?

- $\varphi''(x_0) = -\dfrac{1}{2}$, so $x_0$ is a local maximum point
- $\varphi''(x_0) = \dfrac{1}{2}$, so $x_0$ is a local minimum point
- $\varphi''(x_0) = 2$, so $x_0$ is a local minimum point
- $\varphi''(x_0) = -2$, so $x_0$ is a local maximum point

## Explanation

Since $F_y(x_0, y_0) \neq 0$, the implicit function theorem applies, and since $F_x(x_0, y_0) = 0$ we have $\varphi'(x_0) = 0$. At a stationary point the second derivative of the implicit function reduces to
$$
\varphi''(x_0) = -\,\frac{F_{xx}(x_0, y_0)}{F_y(x_0, y_0)} = -\,\frac{-2}{4} = \frac{1}{2} .
$$
Since $\varphi''(x_0) > 0$, the point $x_0$ is a **local minimum point** of $\varphi$.
