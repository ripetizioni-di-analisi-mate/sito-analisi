The equation $z^3 + x^2 z + y = 3$ is satisfied at the point $(1, 1, 1)$, and near it the implicit function theorem defines a function $z = g(x, y)$ with $g(1, 1) = 1$. Which curve in the $xy$-plane is, near $(1, 1)$, the level curve of $g$ through $(1, 1)$?

- $y = 2 - x^2$
- $y = 3 - 2x$
- $y = x^2$
- $x^2 + y^2 = 2$

## Explanation

Let $F(x, y, z) = z^3 + x^2 z + y - 3$, with $F(1, 1, 1) = 0$ and $F_z = 3z^2 + x^2$, so $F_z(1, 1, 1) = 4 \neq 0$ and the implicit function theorem applies with respect to $z$. The required level curve consists of the points $(x, y)$ near $(1, 1)$ where $g(x, y) = 1$. By the uniqueness of the implicit function, near the point we have $g(x, y) = 1$ if and only if $F(x, y, 1) = 0$, that is, $1 + x^2 + y - 3 = 0$. Therefore the level curve is the parabola $y = 2 - x^2$. The line $y = 3 - 2x$ is its tangent line at $(1, 1)$, orthogonal to $\nabla g(1, 1) = \left( -\dfrac{1}{2}, -\dfrac{1}{4} \right)$.
