- $2x + 2y + 2z = 6$
- $x + y + 3z = 5$
- $2x + 2y + 3z = 0$
- $2x + 2y + 3z = 7$

## Explanation

Let $F(x, y, z) = xz + yz^2 + xy - 3$, which is of class $C^1$ on $\mathbb{R}^3$; we have $F(1, 1, 1) = 0$, so the point belongs to the surface. The partial derivatives are $F_x = z + y$, $F_y = z^2 + x$ and $F_z = x + 2yz$, therefore $\nabla F(1, 1, 1) = (2, 2, 3) \neq (0, 0, 0)$. The tangent plane therefore has equation
$$
2(x - 1) + 2(y - 1) + 3(z - 1) = 0 ,
$$
that is, $2x + 2y + 3z = 7$.
