What is the only critical point of the function $f(x, y) = xy - 2x + 3y$?

- $(3, -2)$
- $(-3, 2)$
- $(2, -3)$
- $(-2, 3)$

## Explanation

The partial derivatives are $f_x = y - 2$ and $f_y = x + 3$. The critical point solves the system
$$
\begin{cases}
y - 2 = 0 \\[4pt]
x + 3 = 0
\end{cases}
$$
so it is the point $(-3, 2)$. The system is linear and has only one solution, therefore there are no other critical points.
