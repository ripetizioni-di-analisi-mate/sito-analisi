For which set $K$ does the extreme value theorem guarantee that $f(x, y) = x + y$ has an absolute maximum and an absolute minimum on $K$?

- $\{(x, y) : x^2 + y^2 < 1\}$
- $\{(x, y) : 0 \leq x \leq 1,\ y \geq 0\}$
- $\{(x, y) : 0 < x \leq 1,\ 0 \leq y \leq 1\}$
- $\{(x, y) : x^2 + y^2 \leq 1\}$

## Explanation

The **extreme value theorem** applies to a continuous function on a compact set, that is, a closed and bounded set. The function $f$ is continuous, so it remains to check the set. The disk $x^2 + y^2 < 1$ is bounded but not closed, because it does not contain the circle, and the strip $0 \leq x \leq 1$, $y \geq 0$ is closed but not bounded. The square with $0 < x \leq 1$ is not closed, because it does not contain the side $x = 0$. The disk $x^2 + y^2 \leq 1$ is closed and bounded, therefore only on this set does the theorem guarantee an absolute maximum and an absolute minimum.
