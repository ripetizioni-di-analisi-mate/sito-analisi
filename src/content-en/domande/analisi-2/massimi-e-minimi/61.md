In the family of functions $f(x, y) = x^4 + k\,y^2$, with $k$ real, the origin is always a critical point. For which $k$ is it a local minimum point?

- For $k > 0$
- For every $k$
- For $k \leq 0$
- For $k \geq 0$

## Explanation

The origin is a critical point for every $k$, with Hessian $\begin{pmatrix} 0 & 0 \\ 0 & 2k \end{pmatrix}$, which is degenerate, so we study the sign of $f(x, y) - f(0, 0) = x^4 + k y^2$. If $k > 0$, the difference is a sum of nonnegative terms, so the origin is a minimum point. If $k = 0$, we have $f = x^4 \geq 0$, so the origin is still a minimum point, not a strict one. If $k < 0$, we have $f(x, 0) = x^4 > 0$ and $f(0, y) = k y^2 < 0$, so the origin is a saddle point. Therefore the origin is a local minimum point **for $k \geq 0$**.
