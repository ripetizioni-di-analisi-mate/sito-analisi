The following four functions all have a critical point at the origin with degenerate Hessian. For which one is the origin a saddle point?

- $f(x, y) = x^2 + y^4$
- $f(x, y) = -x^2 - y^4$
- $f(x, y) = x^4 + y^4$
- $f(x, y) = x^2 - y^4$

## Explanation

For $f(x, y) = x^2 - y^4$ we have $f(x, 0) = x^2 > 0$ for $x \neq 0$ and $f(0, y) = -y^4 < 0$ for $y \neq 0$. So in every neighborhood of the origin $f$ takes values both greater and smaller than $f(0, 0) = 0$, and the origin is a **saddle point**. For $x^2 + y^4$ and $x^4 + y^4$ the function is $\geq 0$ everywhere, so the origin is a minimum point; for $-x^2 - y^4$ it is $\leq 0$ everywhere, so it is a maximum point.
