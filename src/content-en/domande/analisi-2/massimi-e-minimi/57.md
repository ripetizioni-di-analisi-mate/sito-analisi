The function $f(x, y) = (x - y)^2$ has a critical point at the origin. What can be said about this point?

- It is a strict local minimum point
- It is a saddle point
- It is an absolute minimum point, but not a strict one
- The Hessian criterion classifies it as a local minimum

## Explanation

We have $f(x, y) \geq 0 = f(0, 0)$ for every $(x, y)$, so the origin is an **absolute minimum point**. The function also equals $0$ at all the points of the line $y = x$, therefore every neighborhood of the origin contains other points with the same value and the minimum **is not strict**. The Hessian matrix is $\begin{pmatrix} 2 & -2 \\ -2 & 2 \end{pmatrix}$, with determinant $0$, so the Hessian criterion is inconclusive.
