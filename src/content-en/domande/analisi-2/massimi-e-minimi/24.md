For the function $f(x, y) = \sqrt{x^2 + y^2}$, which statement about the origin is true?

- It is a local minimum point at which $f$ is differentiable
- It is an absolute minimum point at which $f$ has no partial derivatives
- It is a saddle point
- It is not an extremum, because the gradient does not vanish

## Explanation

Since $f(x, y) \geq 0 = f(0, 0)$ for every $(x, y)$, the origin is an **absolute minimum point**. The restriction to the $x$-axis is $f(x, 0) = |x|$, which is not differentiable at $0$, so $f_x(0, 0)$ does not exist; for the same reason $f_y(0, 0)$ does not exist. Therefore the origin is not a critical point, and Fermat's theorem does not apply, because its hypothesis on the existence of the partial derivatives is not satisfied. The origin is an interior point at which $f$ is not partially differentiable, and points of this kind are among the candidates together with the critical points.
