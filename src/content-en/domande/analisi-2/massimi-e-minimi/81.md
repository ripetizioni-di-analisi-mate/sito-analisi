The set defined by the constraints $g(x, y, z) = z = 0$ and $h(x, y, z) = z - x^2 - y^2 = 0$ consists of the single point $(0, 0, 0)$. For $f(x, y, z) = x$, which statement is true?

- The multiplier system has the solution $\lambda = 1$, $\mu = -1$
- The origin is a maximum and a minimum point of $f$ on the set, but the multiplier system has no solution
- $f$ has no extrema on the set, because the multiplier system has no solution
- The gradients of the constraints are linearly independent at the origin

## Explanation

The set has only one point, so the origin is a **maximum and a minimum point** of $f$ on the set. At the origin $\nabla f = (1, 0, 0)$, $\nabla g = (0, 0, 1)$ and $\nabla h = (-2x, -2y, 1) = (0, 0, 1)$. The gradients of the constraints coincide, so they are not linearly independent and the multiplier theorem does not apply. Indeed $\lambda\,(0, 0, 1) + \mu\,(0, 0, 1)$ has its first two components equal to zero and cannot equal $(1, 0, 0)$, therefore the **system has no solution**.
