For the function $f(x, y) = x^3 - 3x + y^2$, which statement about the critical point $(1, 0)$ is true?

- It is an absolute minimum point
- It is a saddle point
- It is a local minimum point but not an absolute one
- It is a local maximum point

## Explanation

The second derivatives are $f_{xx} = 6x$, $f_{yy} = 2$ and $f_{xy} = 0$, so at $(1, 0)$ we have $\det H = 12 > 0$ and $f_{xx} = 6 > 0$. By the **Hessian test** the point $(1, 0)$ is therefore a local minimum point, with $f(1, 0) = -2$. On the $x$-axis the function equals $f(x, 0) = x^3 - 3x$, which tends to $-\infty$ as $x \to -\infty$; for example $f(-3, 0) = -18 < -2$. Hence $(1, 0)$ is a **local minimum point but not an absolute one**.
