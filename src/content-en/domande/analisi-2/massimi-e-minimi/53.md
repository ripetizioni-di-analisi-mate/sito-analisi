The function $f(x, y) = x^2 + (1 - x)^3\, y^2$ has the origin as its only critical point, where the Hessian matrix is $\begin{pmatrix} 2 & 0 \\ 0 & 2 \end{pmatrix}$. Which statement is true?

- The origin is an absolute minimum point, because it is the only critical point
- The origin is a saddle point
- The origin is a local minimum point and not an absolute minimum point
- The origin is a local maximum point

## Explanation

Since $\det H = 4 > 0$ and $f_{xx} = 2 > 0$, by the Hessian criterion the origin is a **local minimum point**, with $f(0, 0) = 0$. On the line $x = 2$, instead, we have
$$
f(2, y) = 4 - y^2 ,
$$
which is negative for $|y| > 2$, for example $f(2, 3) = -5 < 0$. So the origin **is not an absolute minimum point**. For a differentiable function on an interval, a unique critical point that is a local minimum is also an absolute minimum; the example shows that in two variables this property does not hold.
