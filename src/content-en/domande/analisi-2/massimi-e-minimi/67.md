On the rectangle $K = [0, 1] \times [-1, 2]$ the function $f(x, y) = (x - 3)^2 + y^2$ has an absolute minimum. What is it?

- $0$
- $9$
- $5$
- $4$

## Explanation

The function is the square of the distance from the point $(3, 0)$, so the minimum on $K$ is at the point of $K$ closest to $(3, 0)$. The only critical point is $(3, 0)$, which does not belong to $K$, therefore the minimum lies on the boundary. Since $(x - 3)^2 \geq 4$ for $x \leq 1$ and $y^2 \geq 0$, we have $f(x, y) \geq 4$ on $K$, with equality only at $(1, 0)$. So the **absolute minimum** is $4$.
