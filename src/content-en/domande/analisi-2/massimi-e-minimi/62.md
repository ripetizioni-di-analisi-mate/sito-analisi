The function $f(x, y) = x^3 - 3x + (y - 1)^4$ has the critical points $(1, 1)$ and $(-1, 1)$, both with degenerate Hessian. Which statement is true?

- Both are local minimum points
- $(1, 1)$ is a local minimum point and $(-1, 1)$ is a saddle point
- $(1, 1)$ is a saddle point and $(-1, 1)$ is a local maximum point
- Both are saddle points

## Explanation

Since $f(1, 1) = -2$ and $x^3 - 3x + 2 = (x - 1)^2(x + 2)$, we have
$$
f(x, y) - f(1, 1) = (x - 1)^2 (x + 2) + (y - 1)^4 .
$$
Near $(1, 1)$ we have $x + 2 > 0$, so the difference is $\geq 0$ and $(1, 1)$ is a **local minimum point**. Since $f(-1, 1) = 2$ and $x^3 - 3x - 2 = (x + 1)^2(x - 2)$, we have
$$
f(x, y) - f(-1, 1) = (x + 1)^2 (x - 2) + (y - 1)^4 .
$$
On the line $y = 1$ the difference is negative for $x \neq -1$ near $-1$, while on the line $x = -1$ it equals $(y - 1)^4 > 0$, so $(-1, 1)$ is a **saddle point**.
