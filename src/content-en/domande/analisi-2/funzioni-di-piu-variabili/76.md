Let $f(x, y) = \dfrac{x^3 - 3xy^2}{x^2 + y^2}$. Which of the following functions $g$ satisfies $|f(\rho\cos\theta, \rho\sin\theta)| \leq g$ for every $\theta$ and every $\rho > 0$, with $g \to 0$ as $\rho \to 0^+$?

- $g(\rho) = \rho^2$
- $g = |\cos 3\theta|$
- $g(\rho) = \dfrac{\rho}{2}$
- $g(\rho) = 4\rho$

## Explanation

In polar coordinates the numerator equals $\rho^3 (\cos^3\theta - 3\cos\theta \sin^2\theta)$ and the denominator equals $\rho^2$. Since $|\cos\theta| \leq 1$ and $|\sin\theta| \leq 1$, we get $|\cos^3\theta - 3\cos\theta\sin^2\theta| \leq 1 + 3 = 4$, so $|f| \leq 4\rho$ for every $\theta$, and $4\rho \to 0$. For $\theta = 0$ we have $|f| = \rho$, which exceeds both $\dfrac{\rho}{2}$ and, for $\rho < 1$, $\rho^2$, therefore these are not valid bounds. The function $|\cos 3\theta|$ depends on $\theta$ and does not tend to $0$, so it does not serve the purpose.
