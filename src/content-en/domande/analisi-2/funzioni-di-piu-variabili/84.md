The function $f(x, y) = \arctan\!\left( \dfrac{1}{x^2 + y^2} \right)$ is defined on $\mathbb{R}^2 \setminus \{(0, 0)\}$. Which statement about the continuous extension to the origin is true?

- It extends by setting $\tilde{f}(0, 0) = 0$
- It does not extend, because the limit at the origin is $+\infty$
- It extends by setting $\tilde{f}(0, 0) = 1$
- It extends by setting $\tilde{f}(0, 0) = \dfrac{\pi}{2}$

## Explanation

In polar coordinates the expression becomes $\arctan\dfrac{1}{\rho^2}$, which depends only on $\rho$. As $\rho \to 0^+$ the argument $\dfrac{1}{\rho^2}$ tends to $+\infty$, and $\arctan t \to \dfrac{\pi}{2}$ as $t \to +\infty$. Hence the limit at the origin exists, is finite and equals $\dfrac{\pi}{2}$. Therefore $f$ **extends continuously** by setting $\tilde{f}(0, 0) = \dfrac{\pi}{2}$.
