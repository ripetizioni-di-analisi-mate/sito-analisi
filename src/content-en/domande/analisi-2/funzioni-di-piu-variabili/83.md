Which of the following functions is defined and continuous on all of $\mathbb{R}^2$?

- $f(x, y) = e^{xy} \sin(x + y)$
- $f(x, y) = \ln(1 + xy)$
- $f(x, y) = \dfrac{1}{x^2 + y^2}$
- $f(x, y) = \sqrt{x^2 - y^2}$

## Explanation

The function $e^{xy} \sin(x + y)$ is the product of two compositions of continuous functions of one variable with polynomials, so it is **continuous** on all of $\mathbb{R}^2$. The function $\ln(1 + xy)$ is not defined at the points with $xy \leq -1$, for example at $(1, -1)$. The function $\dfrac{1}{x^2 + y^2}$ is not defined at the origin. The function $\sqrt{x^2 - y^2}$ is not defined at the points with $|y| > |x|$, for example at $(0, 1)$.
