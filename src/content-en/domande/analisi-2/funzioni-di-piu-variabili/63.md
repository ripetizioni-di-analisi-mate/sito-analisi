What set of values does the function $f(x, y) = e^{x} + y^2$ take as $(x, y)$ ranges over $\mathbb{R}^2$?

- $[0, +\infty)$
- $(0, +\infty)$
- $[1, +\infty)$
- $\mathbb{R}$

## Explanation

Since $e^{x} > 0$ and $y^2 \geq 0$, we have $f(x, y) > 0$ for every $(x, y)$, so the range is contained in $(0, +\infty)$. Let $c > 0$. At the point $(\ln c, 0)$ we have $f(\ln c, 0) = e^{\ln c} = c$, so every positive value is attained. Therefore the range of $f$ is $(0, +\infty)$. The value $0$ is not attained, because $e^{x}$ never vanishes.
