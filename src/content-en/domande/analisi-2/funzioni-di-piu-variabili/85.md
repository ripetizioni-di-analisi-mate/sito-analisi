Let $C$ be the circle $x^2 + y^2 = 1$ and let $f(x, y) = x + 2y$. Which statement about the absolute maximum and minimum of $f$ on $C$ is true?

- The extreme value theorem does not apply, because $C$ has no interior points
- The extreme value theorem does not apply, because $C$ is not an open set
- $f$ has an absolute maximum and an absolute minimum on $C$, because $f$ is continuous and $C$ is closed and bounded
- $f$ has no maximum on $C$, because $f$ is not bounded on $\mathbb{R}^2$

## Explanation

The function $f$ is a polynomial, so it is continuous. The set $C$ is defined by an equation between continuous functions, therefore it is closed, and it is contained in the disk of radius $1$, therefore it is bounded. Hence $C$ is compact, and by the **extreme value theorem** $f$ has an **absolute maximum and an absolute minimum** on $C$. The hypotheses of the theorem concern only the continuity of $f$ and the compactness of $C$, so the absence of interior points plays no role. The function is not bounded on $\mathbb{R}^2$, but on $C$ we have $|f(x, y)| \leq |x| + 2|y| \leq 3$.
