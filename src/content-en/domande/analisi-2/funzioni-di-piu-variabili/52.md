A subset of the plane is bounded if it is contained in a disk centered at the origin. Which of the following sets has this property?

- $\{ (x, y) : |xy| \leq 1 \}$
- $\{ (x, y) : x^2 - y^2 \leq 1 \}$
- $\{ (x, y) : |x| \leq 1, \ y \geq x^2 \}$
- $\{ (x, y) : |x| + |y| \leq 1 \}$

## Explanation

If $|x| + |y| \leq 1$, then $|x| \leq 1$ and $|y| \leq 1$, so $x^2 + y^2 \leq 2$ and the set is contained in the disk centered at the origin with radius $\sqrt{2}$. Therefore it is **bounded** (it is the square with vertices $(\pm 1, 0)$ and $(0, \pm 1)$). The other sets contain points arbitrarily far from the origin. The set $|xy| \leq 1$ contains the whole $x$-axis, the set $x^2 - y^2 \leq 1$ contains the whole $y$-axis, and the set $|x| \leq 1, \ y \geq x^2$ contains the points $(0, n)$ for every $n \in \mathbb{N}$.
