Let $f(x, y) = x\, e^{-y}$ on the set $K = \{ (x, y) \in \mathbb{R}^2 : 0 \leq x \leq 1, \ y \geq 0 \}$. Which statement is true?

- The Weierstrass theorem applies, because $K$ is closed and $f$ is continuous
- The Weierstrass theorem does not apply, because $K$ is not bounded, so $f$ has no maximum
- The Weierstrass theorem does not apply, because $K$ is not bounded, but $f$ has maximum $1$ and minimum $0$
- The Weierstrass theorem does not apply, because $K$ is not closed

## Explanation

The set $K$ is closed, because it is defined by non-strict inequalities, but it contains the points $(0, n)$ for every $n \in \mathbb{N}$, so it is not bounded and not compact. Therefore the **Weierstrass theorem** does not apply. The theorem gives a *sufficient* condition, so it does not follow from this that the maximum and the minimum fail to exist. For $(x, y) \in K$ we have $0 < e^{-y} \leq 1$, therefore $0 \leq x\, e^{-y} \leq x \leq 1$. Since $f(1, 0) = 1$ and $f(0, y) = 0$, the function has **maximum** $1$ and **minimum** $0$ on $K$.
