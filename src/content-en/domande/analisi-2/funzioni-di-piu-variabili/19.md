Which of the following subsets of the plane is compact?

- $\{ (x, y) : 0 < x^2 + y^2 \leq 1 \}$
- $\{ (x, y) : |x| \leq 1 \}$
- $\{ (x, y) : x^2 + y^2 < 1 \}$
- $\{ (x, y) : x^2 + y^2 \leq 1, \ x \geq 0 \}$

## Explanation

The half-disk $\{ x^2 + y^2 \leq 1, \ x \geq 0 \}$ is defined by non-strict inequalities between continuous functions, so it is closed. Moreover it is contained in the disk of radius $1$, so it is bounded, and therefore it is **compact**. The set $\{ 0 < x^2 + y^2 \leq 1 \}$ does not contain the origin, which is one of its boundary points, so it is not closed. The strip $|x| \leq 1$ contains the points $(0, n)$ for every $n \in \mathbb{N}$, therefore it is not bounded. The open disk does not contain the circle $x^2 + y^2 = 1$, which is its boundary, so it is not closed.
