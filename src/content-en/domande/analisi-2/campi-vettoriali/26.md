The field $F(x, y) = \left( \dfrac{2x}{1 + x^2 + y^2}, \; \dfrac{2y}{1 + x^2 + y^2} \right)$ is conservative on $\mathbb{R}^2$. What are its potentials?

- $U(x, y) = \dfrac{1}{2} \ln (1 + x^2 + y^2) + k$
- $U(x, y) = \ln (1 + x^2) + \ln (1 + y^2) + k$
- $U(x, y) = 2 \ln (1 + x^2 + y^2) + k$
- $U(x, y) = \ln (1 + x^2 + y^2) + k$

## Explanation

With $y$ fixed, the integral of $\dfrac{2x}{1 + x^2 + y^2}$ with respect to $x$ reduces to the standard integral $\displaystyle\int \frac{g'(x)}{g(x)} \, dx = \ln |g(x)| + c$, so integrating $F_1$ with respect to $x$ gives $U(x, y) = \ln (1 + x^2 + y^2) + c(y)$. Differentiating with respect to $y$ gives $\dfrac{2y}{1 + x^2 + y^2} + c'(y)$, and imposing $U_y = F_2$ yields $c'(y) = 0$. The potentials are therefore $U(x, y) = \ln (1 + x^2 + y^2) + k$ with $k \in \mathbb{R}$. The sum $\ln (1 + x^2) + \ln (1 + y^2)$ has derivative $\dfrac{2x}{1 + x^2}$ with respect to $x$, which is different from $F_1$.
