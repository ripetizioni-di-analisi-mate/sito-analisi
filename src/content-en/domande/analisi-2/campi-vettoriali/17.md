For which value of the real parameter $a$ is the field $F(x, y) = \bigl( 3x^2 y + a y^2, \; x^3 + 4xy \bigr)$ conservative on $\mathbb{R}^2$?

- $a = 4$
- $a = 1$
- $a = 2$
- $a = -2$

## Explanation

The field is of class $C^1$ on $\mathbb{R}^2$, so irrotationality is a necessary condition for it to be conservative. The cross derivatives are $\dfrac{\partial F_1}{\partial y} = 3x^2 + 2ay$ and $\dfrac{\partial F_2}{\partial x} = 3x^2 + 4y$, and they coincide at every point if and only if $2a = 4$, that is $a = 2$. For $a = 2$ the field is irrotational on $\mathbb{R}^2$, which is simply connected, therefore the field is **conservative**. For every other value of $a$ the necessary condition is not satisfied and the field is not conservative.
