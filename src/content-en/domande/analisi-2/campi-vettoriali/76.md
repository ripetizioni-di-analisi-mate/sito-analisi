Let $a, b, c, d$ be real numbers. The linear field $F(x, y) = (ax + by, \; cx + dy)$ is conservative on $\mathbb{R}^2$ if and only if

- $b = c$
- $a = d$
- $b = -c$
- $a = -d$

## Explanation

The field is of class $C^1$ on $\mathbb{R}^2$, which is simply connected, so it is conservative if and only if it is irrotational. The cross derivatives are $\dfrac{\partial F_1}{\partial y} = b$ and $\dfrac{\partial F_2}{\partial x} = c$, therefore the field is conservative if and only if $b = c$. In this case a potential is $U(x, y) = \dfrac{a x^2}{2} + bxy + \dfrac{d y^2}{2}$. The coefficients $a$ and $d$ play no role in the condition.
