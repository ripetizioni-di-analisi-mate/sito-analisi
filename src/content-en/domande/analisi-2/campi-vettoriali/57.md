In the field $F(x, y) = \bigl( e^x, \; 3y^2 \bigr)$ each component depends on one variable only. What are its potentials on $\mathbb{R}^2$?

- $U(x, y) = e^x y^3 + k$
- $U(x, y) = x e^x + y^3 + k$
- $U(x, y) = e^x + y^3 + k$
- $U(x, y) = e^x + 6y + k$

## Explanation

We look for $U$ with $U_x = e^x$ and $U_y = 3y^2$. The function $e^x$ depends only on $x$ and the function $y^3$ depends only on $y$, so $U(x, y) = e^x + y^3$ satisfies both conditions. On $\mathbb{R}^2$, which is connected, two potentials differ by a constant, therefore the potentials are $U(x, y) = e^x + y^3 + k$ with $k \in \mathbb{R}$. The product $e^x y^3$ has gradient $(e^x y^3, \; 3 e^x y^2)$, which is different from $F$.
