The field $F(x, y, z) = \dfrac{(2x, \; 2y, \; 2z)}{x^2 + y^2 + z^2}$ is of class $C^1$ and irrotational on $\mathbb{R}^3 \setminus \{(0, 0, 0)\}$. Is it conservative on this set?

- No, because the domain has a hole at the origin
- No, because the field is not defined at the origin
- It cannot be decided with the given information
- Yes, because $\mathbb{R}^3$ minus a point is simply connected

## Explanation

In space a closed curve can go around a missing point, so every closed curve in $\mathbb{R}^3 \setminus \{(0, 0, 0)\}$ can be shrunk to a point while remaining in the set. Therefore the set is **simply connected**. The field is of class $C^1$ and irrotational, so the theorem on irrotational fields on a simply connected open set applies and $F$ **is conservative**. A potential is $U(x, y, z) = \ln (x^2 + y^2 + z^2)$.
