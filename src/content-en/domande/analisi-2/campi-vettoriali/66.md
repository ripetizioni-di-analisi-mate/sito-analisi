Let $A = \mathbb{R}^2 \setminus \{ (x, 0) : x \leq 0 \}$ be the plane minus the negative half of the $x$-axis, origin included, as in the figure. Is the open set $A$ simply connected?

::grafico{xmin=-3.5 xmax=3.5 ymin=-2.5 ymax=2.5 uguale=1 segmenti="-3.5,0,0,0" punti="0,0,vuoto" curve="1.6+0.8*cos(t),1+0.8*sin(t),0,6.29" etichette="-3.2,0.35,removed half-line;2.6,-1.6,A" titolo="The open set $A$: the plane minus the half-line $\{(x, 0) : x \leq 0\}$, with a closed curve contained in $A$"}

- Yes, because no closed curve in $A$ goes around the origin
- No, because the origin does not belong to $A$
- No, because $A$ is not convex
- No, because $A$ is not bounded

## Explanation

A closed curve contained in $A$ does not cross the removed half-line, so it cannot go around the origin. Every closed curve in $A$ can therefore be continuously deformed to a point while remaining in $A$, so $A$ **is simply connected**, even though it is not convex. Removing an isolated point creates a hole; removing a half-line that reaches infinity does not. For example, the rotation field $\left( \dfrac{-y}{x^2 + y^2}, \dfrac{x}{x^2 + y^2} \right)$ is conservative on $A$.
