Every potential of the conservative field $F(x, y) = \bigl( y e^x, \; e^x + 2y \bigr)$ has the form $U(x, y) = y e^x + c(y)$. Which function $c$ is obtained by imposing $U_y = F_2$?

- $c(y) = 2y + k$
- $c(y) = y^2 + k$
- $c(y) = e^x + y^2 + k$
- $c(y) = k$

## Explanation

Differentiating $U(x, y) = y e^x + c(y)$ with respect to $y$ gives $U_y = e^x + c'(y)$. Imposing $U_y = e^x + 2y$ yields $c'(y) = 2y$, which is a function of $y$ alone, as it must be for a conservative field. Integrating with respect to $y$ gives $c(y) = y^2 + k$ with $k \in \mathbb{R}$, so the potentials are $U(x, y) = y e^x + y^2 + k$. The function $2y + k$ is $c'(y)$ without the last integration.
