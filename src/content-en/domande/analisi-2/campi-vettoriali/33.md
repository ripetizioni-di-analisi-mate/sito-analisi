For which values of the real parameters $a$ and $b$ is the field $F(x, y, z) = \bigl( 2xy + az, \; x^2 + bz, \; x + 2y \bigr)$ conservative on $\mathbb{R}^3$?

- $a = 2, \; b = 1$
- $a = 1, \; b = 1$
- $a = 0, \; b = 2$
- $a = 1, \; b = 2$

## Explanation

The field is of class $C^1$ on $\mathbb{R}^3$, which is simply connected, so the field is conservative if and only if its curl is zero. The components of the curl are
$$
\frac{\partial F_3}{\partial y} - \frac{\partial F_2}{\partial z} = 2 - b, \qquad \frac{\partial F_1}{\partial z} - \frac{\partial F_3}{\partial x} = a - 1, \qquad \frac{\partial F_2}{\partial x} - \frac{\partial F_1}{\partial y} = 2x - 2x = 0 .
$$
The curl is zero if and only if $a = 1$ and $b = 2$, therefore for these values the field is **conservative** and for all other values it is not.
