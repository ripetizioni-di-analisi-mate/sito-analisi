What is the value of $\log_6 6$?

- $\log_6 6=\dfrac16$
- $\log_6 6=0$
- $\log_6 6=1$
- $\log_6 6=6$

## Explanation

In $\log_6 6$ the first $6$ is the base and the second is the required value of the power. Set $6^u=6$. Since $6=6^1$ and the exponential is one-to-one, $u=1$. A zero exponent would give $6^0=1$, which is a different argument. The equality $\log_6 1=0$ shows what goes wrong if the argument is confused with the exponent.
