Evaluate $\log_2(\log_3 81)$.

- $2$
- $9$
- $4$
- $8$

## Explanation

Start with the inner logarithm. Since $81=3^4$, we have $\log_3 81=4$. This value is positive, so it is a valid argument of the outer logarithm. Since $4=2^2$, $\log_2(\log_3 81)=\log_2 4=2$. The value $4$ is just the intermediate result to which the base-$2$ logarithm still applies.
