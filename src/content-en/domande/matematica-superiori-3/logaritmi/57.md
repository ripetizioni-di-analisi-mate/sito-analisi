For which values of the parameter $a$ is it valid to use $\log_a1=0$ in a real calculation?

- $a\in(1,+\infty)$
- $a\in\mathbb R\setminus\{0\}$
- $a\in(0,+\infty)$
- $a\in(0,1)\cup(1,+\infty)$

## Explanation

A real logarithm requires a positive base different from $1$. Under these assumptions $a^x$ is one-to-one and $a^0=1$, so the required exponent is zero. A base between $0$ and $1$ is allowed.
