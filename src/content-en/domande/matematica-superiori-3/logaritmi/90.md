For which $x$ does $\log_9(x^2)=\log_3 x$ hold?

- Only for $x=3$.
- For every $x\ne0$.
- For every $x>0$.
- Only for $x=1$.

## Explanation

The common domain is $x>0$. In base $3$, $\log_9(x^2)=\dfrac{\log_3(x^2)}{\log_3 9}=\dfrac{2\log_3 x}{2}$. The equality holds throughout the domain.
