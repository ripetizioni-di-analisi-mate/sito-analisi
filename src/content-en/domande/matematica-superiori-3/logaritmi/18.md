Which interval contains $\log_2 30$?

- $(3,4)$
- $(5,6)$
- $(4,5)$
- $(14,16)$

## Explanation

Compare $30$ with two consecutive powers of $2$. Since $2^4=16$ and $2^5=32$, we have $2^4<30<2^5$. The base-$2$ logarithm increases, so $4<\log_2 30<5$. In particular, the exponent $5$ would already give $32$, so it is only the upper boundary of the interval. Exponent $4$ gives $16$, which is strictly below the required value.
