For $x>2$, write $\ln(x+2)+\ln(x-2)$ as a single logarithm. Which expression is correct?

- $\ln(x^2-4)$
- $\ln(x^2+4)$
- $\ln\dfrac{x+2}{x-2}$
- $\ln(2x)$

## Explanation

For $x>2$, both $x+2$ and $x-2$ are positive. The sum is therefore $\ln\bigl((x+2)(x-2)\bigr)=\ln(x^2-4)$. The expressions agree on the original domain. If we considered only where $x^2-4$ is positive, the branch $x<-2$ would also appear, where the separate logarithms are undefined. The endpoint $2$ remains excluded because it makes both the second argument and the product $x^2-4$ zero.
