Why is base $1$ excluded from the definition of the logarithm?

- $1^x$ can take negative values.
- $1^x$ is defined only for $x>0$.
- $1^x$ is always zero.
- $1^x$ always takes the same value.

## Explanation

To define $\log_a b$, a single exponent must turn base $a$ into argument $b$. For $a=1$ every real exponent satisfies $1^x=1$. Infinitely many values would correspond to argument $1$, and none to argument $2$. The inverse of a constant function does not assign one value to each argument as a logarithm must.
