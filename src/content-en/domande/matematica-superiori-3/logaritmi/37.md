Which value of $x$ is excluded from the domain of the function $y=\ln\left((x-2)^2\right)$?

- $x=2$
- $x=-2$
- $x=0$
- $x=4$

## Explanation

The logarithm is defined only for strictly positive arguments. The square $(x-2)^2$ is never negative and equals zero only for $x=2$. Therefore the domain of the function consists of all real numbers other than $2$.
