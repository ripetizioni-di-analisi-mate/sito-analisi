A program plots $y=\ln((x-2)^2)$ and skips exactly one horizontal coordinate. Where must the plot be interrupted even though the square is never negative?

- $x=2$
- $x=-2$
- $x=0$
- $x=4$

## Explanation

A logarithm requires a strictly positive argument. The square is zero only when $x-2=0$, so the plot breaks at $x=2$. On either side the square is positive and the function is defined.
