At which $x$ do the curves $y=\log_2x$ and $y=\log_2(x-1)+1$ meet?

- They do not meet.
- $1$
- $2$
- $3$

## Explanation

Set the two function values equal on the common domain $x>1$. Since $1=\log_2 2$, the right-hand side becomes $\log_2\bigl(2(x-1)\bigr)$. Injectivity gives $x=2(x-1)$, so $x=2$. At that input the first curve has height $\log_2 2=1$ and the second $\log_2 1+1=1$, so the intersection is $(2,1)$. The solution is unique because equating the arguments gives a linear equation.
