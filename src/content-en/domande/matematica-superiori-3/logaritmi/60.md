What is the largest $x$ for which $\log_{\frac13}(x+2)>0$ if $x$ must be an integer multiple of $\dfrac14$?

- $-1$
- $-2$
- $-\dfrac54$
- $-\dfrac74$

## Explanation

Since the base $\dfrac13$ is below $1$, the logarithm is positive when $0<x+2<1$. Thus $-2<x<-1$. Writing $x=\dfrac k4$ for integer $k$ gives $-8<k<-4$. The largest admissible integer is $-5$, so the required value is $-\dfrac54$. The endpoint $-1$ would give a zero logarithm. The other endpoint $-2$ is excluded because it makes the argument zero.
