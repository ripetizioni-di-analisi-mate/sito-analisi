Which value solves $\log_4(x+1)=-1$?

- $\dfrac14$
- $-\dfrac34$
- $-\dfrac54$
- $3$

## Explanation

The domain is $x>-1$. By the logarithm's definition we need $x+1=4^{-1}=\dfrac14$. Subtracting $1=\dfrac44$ gives $x=-\dfrac34$. The solution is negative, but the logarithm's argument is $\dfrac14$, which is positive. Substituting gives $\log_4(\frac14)=-1$. The candidate $x=3$ would instead produce argument $4$ and logarithm $1$, the opposite level.
