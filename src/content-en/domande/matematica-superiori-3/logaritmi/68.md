What is the set of all admissible bases for which $\log_a 4>\log_a 2$ holds?

- $a>1$
- For every admissible base.
- $a>4$
- $0<a<1$

## Explanation

The arguments $4$ and $2$ are positive with $4>2$. A logarithm preserves this order if $a>1$. For $0<a<1$ it is decreasing and gives $\log_a 4<\log_a 2$. Base $1$ is excluded. For an example with $a>1$, taking $a=2$ gives the values $2$ and $1$. For reciprocal base $\dfrac12$ the values are $-2$ and $-1$, in the reversed order.
