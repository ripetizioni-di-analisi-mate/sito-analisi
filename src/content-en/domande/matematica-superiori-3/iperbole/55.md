Find $x$ such that $2+\dfrac{6}{x-1}=-1$.

- $-2$
- $3$
- $-1$
- $1$

## Explanation

This gives $\dfrac6{x-1}=-3$, so $x-1=-2$. The solution $x=-1$ differs from $1$ and is in the domain.

At that input the denominator is $-2$, so $2+\dfrac6{-2}=2-3=-1$. The value $x=1$ cannot solve the equation because it would cause division by zero. Geometrically, the level $y=-1$ meets the branch to the left of the asymptote.
