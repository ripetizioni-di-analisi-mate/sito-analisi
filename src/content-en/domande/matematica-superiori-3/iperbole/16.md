For $F_1=(-4,0)$ and $F_2=(4,0)$, which condition on $PF_1-PF_2$ selects the left branch of the hyperbola with constant $6$?

- $PF_1-PF_2=-6$
- $PF_1-PF_2=6$
- $PF_1-PF_2=0$
- $|PF_1-PF_2|=6$

## Explanation

A point on the left branch is closer to $F_1$, so the difference is negative and must be $-6$. Using the absolute value selects both branches.
