For which $x$ can the sum $\sqrt{x-1}+|x-3|$ equal zero?

- For no value.
- $x=1$
- $x=3$
- $x=2$

## Explanation

Both terms are nonnegative, so both would have to be zero. The square root is zero at $1$, and the absolute value at $3$. The zeros are distinct, so the sum is never zero.
