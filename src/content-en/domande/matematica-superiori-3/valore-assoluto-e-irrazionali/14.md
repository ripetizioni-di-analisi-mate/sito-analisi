Which part of the solution set of $\sqrt{x+2}>x$ is lost if the inequality is immediately replaced by $x+2>x^2$?

- $[-2,0)$
- $\{2\}$
- $(-1,0)$
- $[-2,-1]$

## Explanation

For $-2\leq x<0$ the radical is nonnegative and always exceeds $x$. Comparing the squares gives $(x-2)(x+1)<0$, which keeps only $-1<x<2$. Comparing this interval with the full solution $[-2,2)$ identifies the missing part.
