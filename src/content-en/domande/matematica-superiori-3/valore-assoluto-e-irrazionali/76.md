Which set solves $|x+1|\leq2$ and $\sqrt{x}\geq1$ simultaneously?

- $[-3,1]$
- $[1,+\infty)$
- $[0,1]$
- $\{1\}$

## Explanation

The first condition gives $[-3,1]$. The second allows $x\geq1$, which is already in the domain of the root. The only common point is $1$, and it satisfies both conditions at equality.
