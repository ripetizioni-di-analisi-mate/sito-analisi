Which set solves $|x+1|\leq2$ and $\sqrt{x}\geq1$ simultaneously?

- $[-3,1]$
- $[1,+\infty)$
- $[0,1]$
- $\{1\}$

## Explanation

The first condition gives $[-3,1]$. The second allows $x\geq1$, which is already in the domain of the root. The only common point is $1$, and it satisfies both conditions at equality. At $x=1$, $|1+1|=2$ and $\sqrt1=1$. If $x>1$ the absolute value condition fails, and if $0\leq x<1$ the square-root condition fails. The intersection is $\{1\}$.
