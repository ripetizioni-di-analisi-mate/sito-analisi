Which comparison has exactly the solution set $[2,5]$?

- $\sqrt{x-2}\geq\sqrt3$
- $\sqrt{x-2}<\sqrt3$
- $\sqrt{x-2}\leq\sqrt3$
- $\sqrt{x+2}\leq\sqrt3$

## Explanation

The domain of the first root is $x\geq2$. The requirement $\sqrt{x-2}\leq\sqrt3$ adds $x-2\leq3$, or $x\leq5$. The intersection is $[2,5]$.
