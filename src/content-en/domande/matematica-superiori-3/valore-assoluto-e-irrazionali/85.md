On which set does $|x+2|=x+2$ hold?

- $[-2,+\infty)$
- $(-2,+\infty)$
- $(-\infty,-2]$
- $\mathbb R$

## Explanation

An absolute value equals its argument when the argument is nonnegative. Here the condition is $x+2\geq0$, including the point $-2$ where both sides are zero. For $x<-2$, the argument is negative, while the absolute value is positive. For example, at $x=-3$ the two values are $1$ and $-1$. Thus equality holds only on the ray $[-2,+\infty)$.
