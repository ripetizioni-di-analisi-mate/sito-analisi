Solve $\sqrt{x-1}<-1$.

- $[1,+\infty)$
- $\varnothing$
- $(-\infty,2)$
- $[1,2)$

## Explanation

On its domain the square root is always nonnegative. No value is less than $-1$, so the solution set is empty. The minimum occurs at $x=1$, where the radicand is zero. The comparison would require a value below $-1$, which is already below that minimum. The domain contains no solutions.
