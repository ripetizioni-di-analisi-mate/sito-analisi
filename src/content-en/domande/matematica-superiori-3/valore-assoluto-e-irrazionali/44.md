A program first computes $u=\dfrac1{x+2}$, then $v=\sqrt[3]{u}$. Which input makes it stop at the first step?

- $x=-3$
- $x=0$
- $x=-2$
- $x=2$

## Explanation

The first calculation requires $x+2\ne0$, so it fails at $x=-2$. At any other input the quotient is real. The cube root accepts both positive and negative outputs of the first step.
