For which value of $x$ is the expression $\sqrt[3]{\dfrac{1}{x+2}}$ not defined in the real numbers?

- $x=-3$
- $x=0$
- $x=-2$
- $x=2$

## Explanation

The cube root is a root of odd index, so it is defined for every real radicand, including negative ones. The only existence condition therefore concerns the fraction $\dfrac{1}{x+2}$, which is defined when the denominator is not zero. The denominator $x+2$ vanishes at $x=-2$, so the expression is undefined only at $x=-2$. At $x=-3$, for example, the radicand equals $-1$ and the expression equals $\sqrt[3]{-1}=-1$.
