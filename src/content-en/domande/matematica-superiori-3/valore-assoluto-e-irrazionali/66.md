For which values of $x$ does the equality $|x-1|+|x-3|=2x-4$ hold?

- $[2,+\infty)$
- $[1,+\infty)$
- $[3,+\infty)$
- $(3,+\infty)$

## Explanation

The left-hand side is a sum of absolute values, so it is non-negative. Therefore the equality requires $2x-4\geq0$, that is $x\geq2$. For $2\leq x<3$ we have $|x-1|=x-1$ and $|x-3|=3-x$, so the left-hand side equals $2$. In this interval the equality $2=2x-4$ would give $x=3$, which does not belong to $[2,3)$, so there are no solutions. For $x\geq3$ both arguments are non-negative, so the left-hand side equals $(x-1)+(x-3)=2x-4$ and the equality holds for every $x$. The solution set is therefore $[3,+\infty)$.
