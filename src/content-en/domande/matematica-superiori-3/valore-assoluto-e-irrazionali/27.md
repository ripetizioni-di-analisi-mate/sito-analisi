Which inequality has solution set $[-1,5]$?

- $|x-3|\leq2$
- $|x-2|<3$
- $|x-2|\leq3$
- $|x+2|\leq3$

## Explanation

The midpoint of $[-1,5]$ is $2$, and each endpoint is $3$ units from it. Both endpoints are included, so the comparison is $|x-2|\leq3$. The midpoint is $\dfrac{-1+5}{2}=2$ and the radius is $5-2=3$. A strict comparison would remove the points exactly $3$ units away and give an open interval.
