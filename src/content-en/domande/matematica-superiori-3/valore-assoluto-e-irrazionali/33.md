Solve $|x-7|>-2$.

- $\mathbb R$
- $\varnothing$
- $\{7\}$
- $\mathbb R\setminus\{7\}$

## Explanation

Absolute value is always at least zero, so it is always greater than $-2$. The value $x=7$ is allowed as well because the absolute value is $0>-2$. The inequality holds at the minimum point of the graph and at every other point, where the absolute value is greater still. Since $x-7$ is defined for all real numbers, the solution set is $\mathbb R$.
