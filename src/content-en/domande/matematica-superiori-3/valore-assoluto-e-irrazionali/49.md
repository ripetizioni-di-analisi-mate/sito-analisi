The curves $y=\sqrt x$ and $y=x-k$ must pass through the same point with horizontal coordinate $9$. Which value of $k$ is required?

- $3$
- $12$
- $6$
- $81$

## Explanation

The first curve fixes the vertical coordinate at $\sqrt9=3$. The second passes through the same point if $9-k=3$, so $k=6$. With this value the vertical coordinate on the line is indeed positive.
