If $u>0$, how does $\sqrt{(-u)^2}$ simplify?

- $-u$
- $u$
- $u^2$
- $0$

## Explanation

The radicand $(-u)^2$ equals $u^2$. Its square root returns the nonnegative value, which is $u$ because $u>0$. Indeed, $\sqrt{(-u)^2}=|-u|$. Since $u>0$, the number $-u$ is negative, so its absolute value is $-(-u)=u$. The sign assumption is needed to remove the absolute value.
