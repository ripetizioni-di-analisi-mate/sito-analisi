Solve $\sqrt{x+2}\geq-3$.

- $\varnothing$
- $[7,+\infty)$
- $\mathbb R$
- $[-2,+\infty)$

## Explanation

Every value of the square root is nonnegative, so it exceeds $-3$. Only the domain condition $x+2\geq0$ remains. At $x=-2$ the square root is $0$ and satisfies the comparison. For every larger value, the root is positive. For smaller values it is not real, so the result is $[-2,+\infty)$.
