Which condition must be added to $2x+1=(x-1)^2$ to obtain a system equivalent to $\sqrt{2x+1}=x-1$?

- $x\leq1$
- $x>1$
- $x\geq-\dfrac12$
- $x\geq1$

## Explanation

The square root is nonnegative, so we need $x-1\geq0$, or $x\geq1$. Equality of the squares already makes $2x+1$ nonnegative. Include the boundary in the sign condition. For example, $x=0$ satisfies the equality of squares $1=1$, but the original right-hand side is $-1$. The constraint $x\geq1$ removes that value because the root equals $1$.
