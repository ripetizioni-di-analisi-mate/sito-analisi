In $\sqrt{x+3}+\dfrac1{\sqrt{2-x}}$, the points $-3$ and $2$ each make one radical zero. Which interval accounts for the different roles of these zeros?

- $(-3,2]$
- $[-3,2)$
- $(-3,2)$
- $[-3,2]$

## Explanation

The first radical is defined when $x+3=0$, so $x=-3$ is allowed. The second radical is a denominator, so it requires $2-x>0$. Combining $x\geq-3$ and $x<2$ gives $[-3,2)$.
