Which set is the complement in the real numbers of the solution set of $|x-1|\leq4$?

- $(-3,5)$
- $(-\infty,-3)\cup(5,+\infty)$
- $(-\infty,-3]\cup[5,+\infty)$
- $[-3,5]$

## Explanation

The original inequality gives $[-3,5]$. Its complement is the set where $|x-1|>4$, which excludes both endpoints $-3$ and $5$. The value $-4$ belongs to the complement because it is $5$ units from the center. The endpoint $-3$ instead has distance $4$ and belongs to the original interval, as does its right endpoint $5$.
