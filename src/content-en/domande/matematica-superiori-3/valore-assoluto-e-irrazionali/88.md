Let $R(x)=\dfrac{x+|x|}{2}$ for every real $x$. Which equality holds for every real $x$?

- $R(R(x))=2R(x)$
- $R(R(x))=|x|$
- $R(R(x))=R(x)$
- $R(R(x))=x$

## Explanation

For $x<0$ we have $|x|=-x$, so $R(x)=\dfrac{x-x}{2}=0$. For $x\geq0$ we have $|x|=x$, so $R(x)=\dfrac{2x}{2}=x$. Therefore $R(x)$ is a non-negative number for every $x$. Since $R$ leaves every non-negative number unchanged, $R(R(x))=R(x)$ for every real $x$.
