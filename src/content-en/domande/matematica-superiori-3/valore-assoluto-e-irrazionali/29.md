Solve $|x-1|\leq0$.

- $\varnothing$
- $(1,+\infty)$
- $\mathbb R$
- $\{1\}$

## Explanation

The absolute value is nonnegative, so $\leq0$ requires its value to be zero. Thus $x-1=0$, or $x=1$. At $x=1$, the distance from $1$ really is zero. At every other point the distance is strictly positive, so the comparison fails. The requested set is therefore the single point $\{1\}$.
