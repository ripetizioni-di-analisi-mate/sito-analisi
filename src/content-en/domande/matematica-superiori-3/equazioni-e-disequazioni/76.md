For which listed value of $c$ does $x^2-4x+c\geq0$ hold for every real $x$?

- $3$
- $0$
- $2$
- $5$

## Explanation

The expression $(x-2)^2+c-4$ has minimum $c-4$ at $x=2$. We need $c-4\geq0$. Of the listed values, only $5$ satisfies this condition. At $x=2$ the squared term is zero. When $c=5$, the minimum is $1$. With each other value listed, the result is already negative at that point.
