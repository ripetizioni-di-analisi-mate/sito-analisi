For which values of $k$ does $(k-1)x^2-2x+1=0$ have exactly one distinct real solution?

- $k=1$
- $k\in\{1,2\}$
- $k=2$
- $k<2$

## Explanation

At $k=1$ the equation becomes $-2x+1=0$ and has one solution. For $k\neq1$, there is one solution when $\Delta=4(2-k)=0$, which occurs at $k=2$. In the linear case the solution is $x=\dfrac12$. At $k=2$, the equation becomes $(x-1)^2=0$, so the solution is $1$. Both cases count because the question asks for the number of distinct solutions.
