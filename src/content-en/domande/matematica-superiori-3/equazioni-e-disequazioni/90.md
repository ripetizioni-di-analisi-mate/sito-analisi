For which value of $a$ does the trinomial $x^2+ax+4$ vanish at $x=-2$?

- $4$
- $0$
- $-4$
- $2$

## Explanation

The trinomial vanishes at $x=-2$ if $(-2)^2+a\cdot(-2)+4=0$, that is, if $8-2a=0$. Hence $a=4$.

With this value the trinomial is $x^2+4x+4=(x+2)^2$, therefore $-2$ is a double root. The value $-4$ comes from substituting $x=2$ instead of $x=-2$.
