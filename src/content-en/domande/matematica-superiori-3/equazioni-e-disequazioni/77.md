Which line $y=kx$ with $k>0$ meets $y=x^2+4$ at exactly one point?

- $y=2x$
- $y=x$
- $y=8x$
- $y=4x$

## Explanation

The common x-coordinates satisfy $x^2-kx+4=0$. Exactly one intersection requires $k^2-16=0$. Since $k>0$, we obtain $k=4$. Substituting $k=4$ gives $(x-2)^2$, whose only root is $2$. Both y-coordinates there equal $8$. The negative parameter value, $-4$, is excluded by $k>0$.
