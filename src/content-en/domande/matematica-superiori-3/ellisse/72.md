Which equation has the same points as $\dfrac{(x-1)^2}{4}+\dfrac{(y+2)^2}{9}=1$?

- $9(x+1)^2+4(y-2)^2=36$
- $9(x-1)^2+4(y+2)^2=1$
- $9(x-1)^2+4(y+2)^2=36$
- $4(x-1)^2+9(y+2)^2=36$

## Explanation

Multiply every term by the least common multiple $36$. The first square has coefficient $36$ divided by $4$, namely $9$. The second has coefficient $36$ divided by $9$, namely $4$.

This gives $9(x-1)^2+4(y+2)^2=36$. Multiplication is reversible because $36\ne0$, so the point set is unchanged. The point $(3,-2)$ confirms this, giving $1$ in the original and $36$ in the multiplied equation.
