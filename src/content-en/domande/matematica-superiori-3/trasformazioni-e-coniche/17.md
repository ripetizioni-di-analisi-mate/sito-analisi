Two translations, by $(2,-1)$ and $(-5,4)$, are applied in succession. Which single vector produces the same displacement?

- $(7,-5)$
- $(-3,3)$
- $(3,-3)$
- $(-10,-4)$

## Explanation

Each coordinate receives both increments, so add the vectors. This gives $(2-5,-1+4)=(-3,3)$.

For example, the origin first moves to $(2,-1)$ and then to $(-3,3)$. The same difference follows from any starting point, because the same two numbers are added to each coordinate. Their order of addition can therefore be reversed.
