Let $f(x)=3+(x-a)^2$ on $\mathbb R$. What is the minimum as the real parameter $a$ varies?

- $3+a^2$ for every $a$
- $3$ for every $a$
- $0$ for every $a$
- $a$ for every $a$

## Explanation

The minimum of the square is $0$ at $x=a$. The function therefore always has minimum value $3$. The parameter changes the input at which the minimum is reached.
