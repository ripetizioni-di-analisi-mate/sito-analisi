The graph of $f$ contains $P(4,-1)$. Find the corresponding point on $g(x)=f(x+2)-3$.

- $(4,-4)$
- $(2,-4)$
- $(2,2)$
- $(6,-4)$

## Explanation

The input to $f$ must be $4$, so $x+2=4$ gives $x=2$. The vertical coordinate is $g(2)=f(4)-3=-1-3=-4$. Adding $2$ inside the argument makes the rule use $f(4)$ already at the input $2$, so the point shifts left. The outside term $-3$ lowers the original output by three units.
