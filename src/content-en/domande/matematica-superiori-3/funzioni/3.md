Find the set of zeros of $f(x)=\dfrac{x^2-9}{x-3}$.

- $\{-3\}$
- $\{-3,3\}$
- $\{3\}$
- $\varnothing$

## Explanation

The numerator factors as $(x-3)(x+3)$. On the domain $x\neq 3$, cancel $x-3$ to obtain $f(x)=x+3$. Only $-3$ is a zero. A zero requires both a zero numerator and a nonzero denominator. The candidate $3$ makes the quotient undefined. At $x=-3$ the denominator is $-6$, so the quotient is defined and equals zero.
