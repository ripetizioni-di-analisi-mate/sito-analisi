The function $f(x)=|x|$ is changed to $g(x)=|x+2|-3$. Where is the minimum point of $g$?

- $(-2,3)$
- $(2,-3)$
- $(2,3)$
- $(-2,-3)$

## Explanation

The absolute value has minimum $0$ when $x+2=0$. The input is thus $-2$ and the output is $0-3=-3$. Geometrically, the horizontal coordinate is the point from which absolute value measures distance. To either side of $-2$ that distance is positive, so all other outputs exceed $-3$. The constant term determines the height of the vertex.
