Which statement holds for $f(x)=2x+1$ with $x\in[0,3)$?

- The minimum is $1$ and the maximum is $7$.
- The minimum is $0$ and the maximum is $3$.
- The minimum is $1$ and there is no maximum.
- There is no minimum and the maximum is $7$.

## Explanation

The function increases and equals $1$ at the included endpoint $x=0$. As the input approaches $3$, the outputs approach $7$, which is never attained because $3$ is excluded. The number $7$ is an upper bound. For any smaller output, an input sufficiently close to $3$ can be found that exceeds it. The minimum, on the other hand, is attained and equals $1$.
