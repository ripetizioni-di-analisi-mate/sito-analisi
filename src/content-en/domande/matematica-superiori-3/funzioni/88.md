For $f(x)=\dfrac{1}{x^2-1}$, which listed input lies in the domain and gives a negative value?

- $2$
- $0$
- $-1$
- $1$

## Explanation

The numerator is positive, so we require $x^2-1<0$, or $-1<x<1$. Only $0$ is in that interval. The values $-1$ and $1$ make the denominator zero. At $x=0$ the denominator is $-1$, so the function gives $-1$. The input $2$ belongs to the domain but gives denominator $3$ and thus a positive output. Excluded inputs must be distinguished from defined inputs with the wrong sign.
