If $f$ has domain $[1,4)$, what is the domain of $g(x)=f(x+3)$?

- $[4,7)$
- $[1,4)$
- $(-2,1]$
- $[-2,1)$

## Explanation

The input $x+3$ must belong to $[1,4)$, so $1\leq x+3<4$. Subtracting $3$ gives $-2\leq x<1$. At the new left endpoint $x=-2$, the argument is $1$, which belongs to the original domain. At the new right endpoint $x=1$, the argument would be $4$, which is excluded. Translating the interval therefore preserves which endpoints are included.
