A relation consists only of the points $(0,1)$, $(1,1)$ and $(2,3)$. What property does it have?

- It is not a function because $1$ occurs twice as an output.
- It is an injective function.
- It is not a function because the domain is finite.
- It is a function and is not injective.

## Explanation

Each input has one output, so the relation defines a function. However, the distinct inputs $0$ and $1$ share the output $1$, so the function is not injective.
