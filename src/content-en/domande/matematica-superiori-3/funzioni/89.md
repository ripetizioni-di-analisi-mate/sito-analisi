For $f\colon\{0,1,2\}\to\{1,2,3,4\}$ with $f(x)=x+1$, which set is the domain of the inverse defined on the range?

- $\{0,1,2\}$
- $\{1,2,3\}$
- $\{2,3,4\}$
- $\{1,2,3,4\}$

## Explanation

Inputs $0$, $1$ and $2$ give the distinct outputs $1$, $2$ and $3$. Each attained output has one preimage, so the domain of the inverse is exactly $\{1,2,3\}$.
