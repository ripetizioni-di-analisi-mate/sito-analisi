On which interval is $f(x)=(x+3)^2$ strictly decreasing?

- $\mathbb R$
- $(-\infty,-3]$
- $[0,+\infty)$
- $[-3,+\infty)$

## Explanation

To the left of $-3$, the distance $|x+3|$ decreases as $x$ increases towards $-3$. Squaring a nonnegative distance preserves this ordering, so the function decreases on $(-\infty,-3]$. For example, moving from $-5$ to $-4$ changes the value from $4$ to $1$. Beyond the vertex, the distance increases with the input. The endpoint $-3$ can be included in the decreasing interval because the function attains its minimum there.
