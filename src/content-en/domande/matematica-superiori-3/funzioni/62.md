What is the range of $f(x)=4-(x-2)^2$ on $\mathbb R$?

- $[4,+\infty)$
- $(-\infty,2]$
- $[0,4]$
- $(-\infty,4]$

## Explanation

The square is nonnegative, so $f(x)\leq4$, with equality at $x=2$. For each $y\leq4$, the input $2+\sqrt{4-y}$ returns $y$. Any output above $4$ would require a negative square. At $y=4$ the square root is zero, so the input is the vertex's coordinate. The range therefore consists of exactly the outputs in $(-\infty,4]$.
