Let $f$ be odd. If $(3,-2)$ is on its graph, which point must also lie on the graph?

- $(-3,-2)$
- $(3,2)$
- $(-3,2)$
- $(-2,3)$

## Explanation

By oddness, $f(-3)=-f(3)=2$. The corresponding point is $(-3,2)$, reflected through the origin. Point symmetry sends $(x,y)$ to $(-x,-y)$. Applying it to the given point changes both signs. Changing only the sign of the input would reflect the point across the vertical axis, which is a different property.
