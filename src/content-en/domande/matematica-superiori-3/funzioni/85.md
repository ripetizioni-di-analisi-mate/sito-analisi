What is the largest common domain on which $h(x)=\sqrt{x+1}+\dfrac{1}{x-2}$ can be defined?

- $\mathbb R\setminus\{2\}$
- $[-1,+\infty)$
- $(-1,2)\cup(2,+\infty)$
- $[-1,2)\cup(2,+\infty)$

## Explanation

The sum requires both terms to exist. The square root allows $x\geq-1$, and the fraction excludes $2$. At $-1$ the square root equals $0$ and the denominator equals $-3$. The point $2$ lies in the region allowed by the square root, so it must be removed from $[-1,+\infty)$. This leaves two intervals. The point $-1$ is allowed because substituting it gives a real value for both terms.
