For which value of $a$ does $f(x)=ax+3$ on $\mathbb R$ have no inverse?

- $a=-1$
- $a=1$
- $a=3$
- $a=0$

## Explanation

If $a=0$, then $f(x)=3$ for every $x$, so the function is not injective. For $a\neq0$, the equation $y=ax+3$ has one solution for each $y$. In the constant case, for example, $f(0)=f(1)=3$ despite distinct inputs. If the slope is nonzero, solving instead gives $x=\dfrac{y-3}{a}$ for every $y$, so the inverse is defined on the whole real line.
