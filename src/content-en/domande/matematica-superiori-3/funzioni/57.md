The graph of $f$ contains $(1,-3)$. Which point corresponds to it for $g(x)=2f(-x)+1$?

- $(1,-5)$
- $(-1,-7)$
- $(-1,-5)$
- $(-1,7)$

## Explanation

To use input $1$, set $-x=1$, so $x=-1$. The output is $2f(1)+1=2(-3)+1=-5$. Reflection across the vertical axis acts on the horizontal coordinate and sends $1$ to $-1$. The factor $2$ and the addition of $1$ act on the output. This gives $(-1,-5)$ without needing any other values of $f$.
