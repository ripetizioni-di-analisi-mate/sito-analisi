Let $f(x)=2-x$ with domain $[0,2]$ and $g(t)=\sqrt{t-1}$. What is the largest input in the domain of $g\circ f$?

- $0$
- $2$
- $3$
- $1$

## Explanation

The square root requires $f(x)\geq 1$, so $2-x\geq1$ and $x\leq1$. Intersecting with $[0,2]$ gives $[0,1]$, with maximum $1$. At $x=1$ the inner function gives $1$, so the square root is zero and the endpoint is allowed. An input such as $x=2$ lies in the domain of $f$ but gives intermediate value $0$, which would make the radicand negative.
