Let $f(x)=x+1$ and $g(x)=x^2$. What is the difference $(g\circ f)(2)-(f\circ g)(2)$?

- $8$
- $-4$
- $4$
- $0$

## Explanation

In the composition $g\circ f$ the function $f$ is applied first, so $(g\circ f)(2)=g(3)=9$. In the composition $f\circ g$ the function $g$ is applied first, so $(f\circ g)(2)=f(4)=5$. The required difference is therefore $9-5=4$.
