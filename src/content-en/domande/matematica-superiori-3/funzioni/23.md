The real domain of $\dfrac{\sqrt{x-a}}{x-1}$ is a single interval that is closed on the left. Which value of $a$ satisfies this condition?

- $0$
- $2$
- $1$
- $-2$

## Explanation

For $a=2$ the square root requires $x\geq2$, so $1$ is already excluded. With $a=1$ the domain is $(1,+\infty)$, while with $a<1$ the input $1$ splits the domain into two intervals.
