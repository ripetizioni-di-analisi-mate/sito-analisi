Let $f$ be strictly decreasing on $[0,4]$, with $f(0)=7$ and $f(4)=2$. Which value of $f(2)$ is possible?

- $0$
- $\dfrac{9}{2}$
- $2$
- $7$

## Explanation

Since $0<2<4$, we have $f(0)>f(2)>f(4)$, so $2<f(2)<7$. The value $\dfrac{9}{2}$ is possible, for example for the line $f(x)=7-\dfrac{5}{4}x$.
