Let $f(x)=\sqrt{4-x^2}$ with its real domain. Which statement holds?

- It is even and has range $[0,2]$.
- It is odd and has range $[-2,2]$.
- It is odd and has range $[0,2]$.
- It is even and has range $[-2,2]$.

## Explanation

The domain is $[-2,2]$ and the radicand is unchanged when substituting $-x$, so the function is even. The square root takes values from $0$ at $x=\pm2$ up to $2$ at $x=0$. For every $y\in[0,2]$, $f(\sqrt{4-y^2})=y$.
