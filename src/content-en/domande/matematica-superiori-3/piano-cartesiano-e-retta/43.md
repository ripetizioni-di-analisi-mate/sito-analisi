A line is perpendicular to $y=3x+1$. Which line is perpendicular to both?

- $y=3x$
- $y=-\dfrac13x$
- $x=0$
- No line.

## Explanation

To be perpendicular to $y=3x+1$, a line must have slope $-\dfrac13$. The second line already has this slope, so a line in that same direction cannot be perpendicular to it. A line perpendicular to the second would have slope $3$ and thus be parallel to the first. The two requirements would make the same slope equal both $3$ and $-\dfrac13$. A vertical line cannot solve the problem because it is perpendicular only to a horizontal line.
