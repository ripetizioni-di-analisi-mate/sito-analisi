A point moves according to $P(t)=(t,2t+1)$. For which $t$ does it cross $y=7$?

- $3$
- $7$
- $\dfrac72$
- $4$

## Explanation

The intersection requires the point's vertical coordinate to be $7$. Set $2t+1=7$, giving $t=3$. At the resulting time, the point is at $P(3)=(3,7)$, which satisfies the line's equation. Since the vertical coordinate $2t+1$ increases strictly with $t$, it can reach the same height only once. The number $7$ is the height, while the question asks for the time.
