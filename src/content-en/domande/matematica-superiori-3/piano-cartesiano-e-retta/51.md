If all the coefficients of a line's equation are multiplied by $-3$, how does the distance from $P$ change?

- It triples.
- It changes sign.
- It stays the same.
- It becomes one third.

## Explanation

The equation still describes the same line. In the distance formula, both the absolute-value numerator and the denominator are multiplied by $3$, which cancels. If the old expression is $ax_0+by_0+c$ at $P$, the new one is $-3(ax_0+by_0+c)$. The absolute value removes the factor's sign. The new normal vector has length $3\sqrt{a^2+b^2}$, so both parts change by the same scale factor.
