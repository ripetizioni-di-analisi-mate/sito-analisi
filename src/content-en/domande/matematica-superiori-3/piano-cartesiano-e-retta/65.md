For which points $P(x,2)$ does $OP$ have length exactly $2$, where $O$ is the origin?

- All points of the line $y=2$
- Only $(0,2)$
- No point
- $(2,2)$ and $(-2,2)$

## Explanation

The squared distance is $x^2+4$. Requiring distance $2$ is equivalent to $x^2+4=4$, so $x=0$ is the only possible value. The output $2$ already supplies a vertical component of length $2$. Any nonzero horizontal component would add a positive square and lengthen the segment. The squared comparison therefore selects only $(0,2)$, directly above the origin.
