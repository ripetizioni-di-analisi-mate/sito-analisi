For which values of $k$ do the lines $y=kx+4$ and $y=2x-1$ have exactly one point in common?

- $k=4$
- $k=2$
- For all $k\in\mathbb R$
- $k\neq2$

## Explanation

The system is equivalent to $(k-2)x=-5$. If $k\neq2$, there is one horizontal coordinate and then one vertical coordinate. If $k=2$, the equation would require $0=-5$.
