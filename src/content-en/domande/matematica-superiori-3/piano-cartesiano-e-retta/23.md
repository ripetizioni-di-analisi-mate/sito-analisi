Which line contains every point of the form $(3,y)$?

- $y=3x$
- $x=3$
- $y=3$
- $x+y=3$

## Explanation

The horizontal coordinate is always $3$ and the vertical coordinate is free. This describes the vertical line $x=3$. For example, $(3,0)$ and $(3,2)$ must both lie on the line. An equation such as $y=3$ would fix the output instead and exclude both points. The vertical line contains all outputs at the same input and cannot be written as $y=mx+q$.
