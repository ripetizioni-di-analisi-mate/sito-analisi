Which point is on $x=1-2(y+2)^2$?

- $(3,-3)$
- $(-1,3)$
- $(1,-1)$
- $(-1,-3)$

## Explanation

At $y=-3$, $(y+2)^2=1$, so $x=1-2=-1$. This verifies the pair $(-1,-3)$.

In this equation, substitute the ordinate first because the right-hand side uses $y$. At $y=-3$ the only possible x-coordinate is $-1$, so $(3,-3)$ is excluded despite its identical ordinate. Also, $1-2(y+2)^2\le1$ for every $y$. This directly excludes any point with x-coordinate greater than $1$.
