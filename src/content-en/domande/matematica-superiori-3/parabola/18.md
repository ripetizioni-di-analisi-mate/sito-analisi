What is the range of $f(x)=3(x+2)^2-5$ on $\mathbb R$?

- $(-\infty,-5]$
- $(-5,+\infty)$
- $[-5,+\infty)$
- $[-2,+\infty)$

## Explanation

The square takes every value from $0$ upwards, so $3(x+2)^2-5$ takes every value from $-5$ upwards. The endpoint is included because $f(-2)=-5$.

To see that every value above $-5$ is attained, pick a height $y$ and solve $(x+2)^2=\dfrac{y+5}{3}$. For $y\ge-5$, the right-hand side is nonnegative, so at least one real solution exists. At lower heights the square would have to be negative.
