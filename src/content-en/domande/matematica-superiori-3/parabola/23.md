For which values of $k$ does $y=-x^2+6x+k$ stay strictly below the x-axis?

- $k<-9$
- $k\le-9$
- $k>9$
- $k<0$

## Explanation

Write $y=-(x-3)^2+9+k$. Even the maximum $9+k$ must be negative, so $k<-9$. At $k=-9$ the vertex is on the axis.

Check the strict condition at the highest point. For $k=-10$ the highest ordinate is $-1$, so every point is below the axis. At $k=-8$, the value at $x=3$ is $1$. The boundary value is also excluded because it places a point on the axis.
