At consecutive inputs $0,1,2$, the parabola $y=ax^2+bx+c$ takes values $4,7,14$. What is their second difference and which coefficient does it determine?

- $4$, so $a=4$
- $7$, so $a=7$
- $4$, so $a=2$
- $10$, so $a=5$

## Explanation

The first differences are $3$ and $7$, so the second difference is $4$. With unit spacing, $f(2)-2f(1)+f(0)=2a$, giving $a=2$.
