Set A is $4,4,4,8,8,8$ and set B is $4,6,6,6,6,8$. Both means are $6$. Which set has greater variance?

- A, because more observations lie away from the mean.
- B, because more observations equal the mean.
- They are equal because their extremes match.
- They are equal because their means match.

## Explanation

In A all six observations are at distance $2$ from the mean, so the variance is $4$. In B only two are at distance $2$, so the variance is $\dfrac86=\dfrac43$.
