An instrument corrects the values using $y=2x-5$. If $x$ has mean $12$ and standard deviation $3$, what is the standard deviation of $y$?

- $\sigma_y=6$
- $\sigma_y=1$
- $\sigma_y=3$
- $\sigma_y=12$

## Explanation

The deviation from the mean changes according to $y_i-\bar y=2(x_i-\bar x)$. The constant term cancels and the standard deviation doubles, so it equals $2\cdot3=6$.

The corrected mean is $2\cdot12-5=19$. Subtracting it from each value $2x_i-5$ leaves $2x_i-24$, so the term $-5$ is absent from every deviation. Applying the correction directly to the standard deviation would give $1$, as if moving every value by the same amount changed the spread.
