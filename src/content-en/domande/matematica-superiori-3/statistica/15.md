A travel log records duration, number of stops and ticket type. Which variable is categorical?

- Duration.
- Number of stops.
- All three.
- Ticket type.

## Explanation

Ticket types identify categories. Durations are measured and stops are counted, so the other variables are quantitative.

Ticket categories can be given numbers for recording, for instance one code for a single ticket and one for a pass. These numbers act as labels and their mean does not describe a ticket type. Duration is measured on a scale, while the number of stops is an integer count.
