A histogram using absolute frequency density has a bar of height $3$ over the class $[10,16)$. How many observations are in the class?

::grafico{xmin=-0.25 xmax=18.1 ymin=-0.45 ymax=4.2 nomi="x,density" poligoni="10,0 16,0 16,3 10,3" titolo="The class spans $[10,16)$ and the bar height is $3$."}

- $n=3$
- $n=6$
- $n=13$
- $n=18$

## Explanation

The class width is $16-10=6$. Frequency is the area of the rectangle, so the class contains $6\cdot3=18$ observations.
