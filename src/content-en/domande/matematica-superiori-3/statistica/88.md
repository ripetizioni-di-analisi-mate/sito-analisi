Exactly five of ten ordered values are at most $4$. The fifth value is $4$ and the sixth is $8$. Which statement about the median is correct?

- It equals $4$ because the cumulative count reaches half.
- It equals $8$ because that is the first observation above the halfway position.
- It equals $6$, even though no observation equals $6$.
- It can only be found from the full data set.

## Explanation

The number of observations is even, so the median is $\dfrac{4+8}{2}=6$. No value between $4$ and $8$ occurs because they occupy successive positions.
