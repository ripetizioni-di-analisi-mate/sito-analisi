An interval $[4,9)$ contains $20$ measurements. What height should its rectangle have if its area represents the count?

- $5$
- $16$
- $100$
- $4$

## Explanation

The area must be $20$ and the width is $9-4=5$. The required height is $\dfrac{20}{5}=4$.

The class width is the upper endpoint minus the lower one. The value $20$ is the area, and multiplying the height by the width $5$ must give that value. The check is $5\cdot4=20$. Using the count itself as height would instead give a rectangle of area $100$.
