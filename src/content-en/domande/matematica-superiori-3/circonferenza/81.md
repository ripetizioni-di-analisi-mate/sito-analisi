Which distance between centres is compatible with disjoint circles of radii $3$ and $4$ lying outside one another?

- Any $d<7$.
- Any $d\geq1$.
- Any $d>7$.
- Only $d=7$.

## Explanation

The radii sum to $7$. At $d=7$ the circles still touch, so for them to be disjoint and for neither to lie inside the other, we need $d>7$.
