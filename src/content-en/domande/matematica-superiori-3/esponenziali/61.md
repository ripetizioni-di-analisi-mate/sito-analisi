At which $x$-coordinate is $f(x)=2^{x-1}-4$ zero?

- $4$
- $1$
- $3$
- $2$

## Explanation

Set $f(x)=0$, giving $2^{x-1}=4$. Since $4=2^2$ and the exponential is one-to-one, $x-1=2$ and hence $x=3$. Exponent $2$ and input $3$ differ by one because the function contains $x-1$. At $x=2$ the power would be $2$, so the function would still have height $-2$. Substituting $x=3$ explicitly checks $2^{3-1}-4=0$. The exponential increases, so there are no further zeros.
