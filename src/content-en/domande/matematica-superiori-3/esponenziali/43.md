Solve $\left(\dfrac14\right)^x<\dfrac12$.

- $\left(-\infty,\dfrac12\right)$
- $\left[\dfrac12,+\infty\right)$
- $(2,+\infty)$
- $\left(\dfrac12,+\infty\right)$

## Explanation

The value $\dfrac12$ is the square root of $\dfrac14$, so it equals $\left(\dfrac14\right)^{\frac12}$. Because the base lies between zero and one, its exponential decreases. Obtaining a strictly smaller height requires an exponent greater than $\dfrac12$. The endpoint $\dfrac12$ gives equality and is excluded. Input $x=1$ gives $\dfrac14$, below the threshold.
