Let $f(x)=a^x$ with $a>0$, and suppose $f(3)=5$. What is the exact value of $f(7)$?

- $35$
- $25\sqrt[3]5$
- $\dfrac{35}{3}$
- $125$

## Explanation

Since $f(3)=a^3=5$, the base is $a=\sqrt[3]5$. By the properties of powers $a^7=a^3\cdot a^3\cdot a$, so $f(7)=5\cdot5\cdot\sqrt[3]5=25\sqrt[3]5$. The same value can also be written as $5^{\frac73}$.

The value $\dfrac{35}{3}$ is obtained by treating $f$ as a function proportional to $x$. The value $35$ comes from multiplying $f(3)$ by $7$.
