A value is modelled by $Q(t)=100(0{,}9)^t$ for $t\geq0$. What is $Q(2)-Q(1)$?

- $9$
- $-9$
- $-19$
- $-10$

## Explanation

The model gives $Q(1)=100\cdot0{,}9=90$ and $Q(2)=100(0{,}9)^2=81$. The difference in the requested order is $81-90=-9$. It is negative because the model decreases. Subtracting $10$ would match the first period, which starts at $100$. In the second period the $10\%$ decrease is calculated from $90$. The relative decrease is the same in both periods, while the absolute decrease changes.
