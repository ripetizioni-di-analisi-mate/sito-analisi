Two formulas, $A(x)=2^{x+1}+3$ and $B(x)=2\cdot2^x+3$, describe a curve using different transformations. For which $x$ do they agree?

- For no $x\in\mathbb R$.
- Only for $x=0$.
- For every $x\in\mathbb R$.
- Only for $x=1$.

## Explanation

The rule $2^{x+1}=2^x\cdot2$ holds for every real exponent. Both formulas then add the same term $3$, so their values agree point by point.
