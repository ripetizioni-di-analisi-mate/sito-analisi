Which point lies on the graph of $y=\left(\dfrac12\right)^x$?

- $(2,4)$
- $(0,0)$
- $\left(-2,\dfrac14\right)$
- $(-2,4)$

## Explanation

Substituting $x=-2$ gives $\left(\dfrac12\right)^{-2}=2^2=4$, so the required point is $(-2,4)$. At the opposite input $2$, the value is the reciprocal $\dfrac14$. The point at input zero has height $1$ by the zero-exponent rule. These three values follow the decreasing order of the base-$\dfrac12$ function. The point $(0,0)$ is excluded because no power of the base is zero.
