What value of $k\geq0$ makes $[0,9]$ the exact solution set of $\left(\dfrac13\right)^{\sqrt{x}}\geq\left(\dfrac13\right)^k$?

- $3$
- $\dfrac13$
- $9$
- $0$

## Explanation

The base gives a decreasing function, so we need $\sqrt{x}\leq k$ with $x\geq0$. Since $k\geq0$, the solution is $[0,k^2]$. The endpoint $9$ gives $k=\sqrt9=3$.
