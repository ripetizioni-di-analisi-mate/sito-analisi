What value of $k\geq0$ makes $[0,9]$ the exact solution set of $\left(\dfrac13\right)^{\sqrt{x}}\geq\left(\dfrac13\right)^k$?

- $3$
- $\dfrac13$
- $9$
- $0$

## Explanation

The square root's domain is $x\geq0$. Base $\dfrac13$ is below $1$, so comparing exponents reverses the direction and gives $\sqrt x\leq k$. For $k\geq0$ we can square, obtaining $0\leq x\leq k^2$. The right endpoint must be $9$, so $k=3$. The root $-3$ is excluded by the condition on the parameter.
