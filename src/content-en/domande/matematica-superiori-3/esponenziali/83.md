If $N(t)=N_0q^t$ with $N_0,q>0$ and $q\ne1$, which ratio equals $q^3$ for every $t$?

- $\dfrac{N(t+3)}{N(t)}$
- $\dfrac{N(t+1)}{N(t)}$
- $\dfrac{N(t)}{N(t+3)}$
- $\dfrac{N(3t)}{N(t)}$

## Explanation

We have $N(t+3)=N_0q^{t+3}$ and $N(t)=N_0q^t$, which is positive. In the quotient, cancel $N_0$ and subtract the exponents to obtain $\dfrac{N(t+3)}{N(t)}=q^{t+3-t}=q^3$. The starting input can vary because the interval still spans three periods. Reversing the quotient would give $q^{-3}$, different from $q^3$ because $q\ne1$. Using $N(t+1)$ in the numerator would give the multiplier for one period instead of three.
