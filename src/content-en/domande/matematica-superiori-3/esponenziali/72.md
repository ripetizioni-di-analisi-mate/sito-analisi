A value follows $N(t)=80\cdot2^t$ and is observed at nonnegative integer times. When does it first exceed $320$?

- At $t=4$.
- At $t=3$.
- At $t=2$.
- At $t=1$.

## Explanation

Exceeding $320$ requires $80\cdot2^t>320$, so $2^t>4=2^2$. Monotonicity gives $t>2$. The first qualifying integer time is $3$, when the value is $640$. At time $2$ the value reaches $320$ exactly. The word “exceeds” calls for a strict inequality and excludes equality. Equality would have counted if the question had asked when the value is at least $320$.
