Which property of $a^x$ allows us to pass from $a^u=a^v$ to $u=v$ for $a>0$, $a\ne1$?

- The intersection with the $y$-axis.
- The existence of an asymptote.
- Injectivity.
- Positivity.

## Explanation

An injective function gives different values at different inputs. Since $a>0$ and $a\ne1$, the function $x\mapsto a^x$ is either strictly increasing or strictly decreasing. In either case, $a^u=a^v$ implies $u=v$. Positivity alone would be insufficient, as base $1$ illustrates by giving the same value at every exponent.
