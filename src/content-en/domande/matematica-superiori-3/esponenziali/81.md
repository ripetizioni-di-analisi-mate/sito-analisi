In $g(x)=C\cdot2^x+2$, which condition on $C$ makes the range $(-\infty,2)$?

- $C<0$
- $C>0$
- $C<2$
- $C=0$

## Explanation

The power $2^x$ takes every positive value. If $C<0$, the product $C\cdot2^x$ takes exactly the negative values, so adding $2$ gives $(-\infty,2)$. If $C>0$ all heights are above $2$. If $C=0$, only the value $2$ remains. The sign of the coefficient therefore determines which side of the asymptote contains the curve.
