For $f(x)=2^x$, suppose $f(x)+f(x+1)=48$. What is $f(x-1)$?

- $24$
- $16$
- $8$
- $32$

## Explanation

The exponent law gives $f(x+1)=2f(x)$. The given sum is therefore $3f(x)=48$, so $f(x)=16$. Moving one unit back in the input divides the value by $2$, giving $f(x-1)=8$. As a check, $16=2^4$ implies $x=4$, and at the preceding input $3$ the value is $8$. The given sum thus uses heights $16$ and $32$, while the question asks for the preceding height.
