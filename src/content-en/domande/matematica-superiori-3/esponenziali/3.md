Solve $3^{2x-2}\leq81$.

- $[3,+\infty)$
- $(-\infty,2]$
- $(-\infty,3)$
- $(-\infty,3]$

## Explanation

Since $81=3^4$, the powers have the same base. The function $3^u$ is increasing, so $2x-2\leq4$. Adding $2$ gives $2x\leq6$, and division by positive $2$ leaves $x\leq3$. The boundary value $3$ is included because it gives exactly $81$, while $x=4$ would give $3^6>81$. Both algebraic steps preserve the direction, because the only divisor used is positive.
