For which $x$ is the value of $f(x)=2^{x-1}-3$ at least $1$?

- $x\geq3$
- $x\geq2$
- $x>3$
- $x\leq3$

## Explanation

The condition is $2^{x-1}-3\geq1$. Adding $3$ gives $2^{x-1}\geq4=2^2$. The base greater than $1$ preserves the direction, so $x-1\geq2$ and $x\geq3$. The endpoint is included since $2^{3-1}-3=1$. At $x=2$, for instance, the power is $2$ and the function lies below the required level. The final inequality includes every input beyond $3$ because the function is increasing.
