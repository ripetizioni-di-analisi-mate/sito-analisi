For the equality $(x+2)^2=x^2+4x+4$, we seek the values of $x$ that make it true. How many are there?

- Only one, $x=0$
- None
- Two, $x=2$ and $x=-2$
- Infinitely many, since every number is a solution

## Explanation

The square of the binomial is $(x+2)^2=x^2+4x+4$, so the two sides are the same expression. The equality is an identity, true for every value of $x$, and the equation has infinitely many solutions. The solutions $2$ and $-2$ would be those of $x^2=4$, which is a different equation.
