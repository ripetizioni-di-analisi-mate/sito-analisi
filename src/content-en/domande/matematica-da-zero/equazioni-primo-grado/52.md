The equation $(k-2)x=k-2$ is an identity for just one value of the parameter $k$. Which value?

- $k=0$
- $k=1$
- $k=-2$
- $k=2$

## Explanation

The equation is an identity when both sides are zero for every $x$. When $k=2$, we obtain $0\cdot x=0$, which is true for every $x$. When $k=1$, we have $-x=-1$, and when $k=0$, we have $-2x=-2$, both with the single solution $x=1$.
