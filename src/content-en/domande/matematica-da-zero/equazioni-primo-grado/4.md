Marta claims that $x=-2$ is a solution of $3x+8=2x+6$. Which statement is correct?

- $x=-2$ is a solution because both sides equal $2$
- $x=-2$ is not a solution because the sides equal $14$ and $10$
- $x=-2$ is not a solution because the sides equal $2$ and $10$
- $x=-2$ is a solution because both sides equal $-2$

## Explanation

When $x=-2$, the left-hand side equals $3\cdot(-2)+8=-6+8=2$ and the right-hand side equals $2\cdot(-2)+6=-4+6=2$. The two values are equal, so $x=-2$ is a solution. The values $14$ and $10$ result from ignoring the minus sign during substitution. Each side is evaluated separately, and the two values are compared only at the end.
