Starting from $x-9=4$, which equation do we obtain when we add $9$ to both sides?

- $x=-5$
- $x=5$
- $x=4$
- $x=13$

## Explanation

The first equivalence principle allows us to add the same number to both sides. We have $x-9+9=4+9$, that is, $x=13$. The value $4$ results from adding $9$ only on the left-hand side, whereas $-5$ and $5$ result from subtracting $9$ instead of adding it.
