Which statement about zero is true?

- It is a positive number
- It is an integer with no sign
- It is a negative number
- It is not an integer

## Explanation

Zero is the reference level and is an integer. It is not positive because it has no $+$ sign, and it is not negative because it has no $-$ sign. It is therefore an integer with no sign.
