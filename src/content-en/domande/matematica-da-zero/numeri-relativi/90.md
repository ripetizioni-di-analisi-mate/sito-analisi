Which number is obtained by cubing the value of the expression $(-2)^2-7$?

- $+27$
- $-27$
- $-9$
- $-279$

## Explanation

The power $(-2)^2$ has a negative base and an even exponent, so it equals $+4$. Therefore the expression $(-2)^2-7$ equals $4-7=-3$. The power $(-3)^3$ has a negative base and an odd exponent, so it is negative. Its absolute value is $3^3=27$, therefore $(-3)^3=-27$. The value $+27$ ignores the sign of a power with an odd exponent, the value $-9$ multiplies $-3$ by $3$, and the value $-279$ cubes $4$ and $7$ separately.
