A number starts at $+1$ and is multiplied by $-2$ at each step. What is its value after $5$ steps?

- $-32$
- $+32$
- $-10$
- $+10$

## Explanation

After $5$ steps the number is $(-2)^5$, the product of five factors equal to $-2$. There is an odd number of negative factors, so the result is negative. Its absolute value is $2^5=32$, so the number equals $-32$.
