For which values of $k$ does the system formed by $y=2x+1$ and $y=2x+k$ have no solution?

- For $k=1$
- For every value of $k$
- For every $k\neq 1$
- For no value of $k$

## Explanation

The lines have the same slope $2$, so they are parallel. They have no common point when they are distinct, that is, when $k\neq 1$. For $k=1$ the lines coincide and the system has infinitely many solutions, so it is not true that the system has no solution for every value of $k$.
