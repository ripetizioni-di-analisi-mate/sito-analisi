What is the set of all values of $k$ for which the point $(k,-2)$ lies in quadrant III?

- $k>0$
- $k=0$
- $k>-2$
- $k<0$

## Explanation

A point in quadrant III has a negative abscissa and a negative ordinate. The ordinate $-2$ is negative for every $k$, so the only remaining condition is on the abscissa, namely $k<0$. The condition $k>-2$ includes values such as $k=1$, for which the point $(1,-2)$ lies in quadrant IV.
