One selection rule accepts scores satisfying $4x\ge7x-9$. A second rule requires $x<3$. Which real value is accepted only by the first rule?

- $3$
- $0$
- $2$
- $4$

## Explanation

The first rule is equivalent to $9\ge3x$, giving $x\le3$. All values below $3$ satisfy both rules. The first rule also accepts the boundary value $3$.
