Which notation correctly represents the set of numbers $x\leq4$ as an interval?

- $[-\infty,4]$
- $[4,+\infty)$
- $(-\infty,4]$
- $(-\infty,4)$

## Explanation

The symbol $\leq$ includes the endpoint $4$, so a square bracket goes beside $4$. The numbers lie to the left of $4$, so the interval starts at $-\infty$. The symbol $-\infty$ is not a number, so it always takes a parenthesis. We write $(-\infty,4]$.
