A room is in use at temperatures from $18$ °C, inclusive, to $22$ °C, exclusive. Which interval describes the operating temperatures?

- $(18,22]$
- $[18,22]$
- $[18,22)$
- $(18,22)$

## Explanation

The value $18$ is allowed, so the left endpoint is included and takes a square bracket. The value $22$ is not allowed, so the right endpoint is excluded and takes a parenthesis. The temperature interval is $[18,22)$.
