The expression $4^0 + 0^4$ contains both a zero exponent and a zero base. What is its value?

- $0$
- $1$
- $2$
- $4$

## Explanation

Every nonzero number raised to the zeroth power equals $1$, so $4^0 = 1$. The number $0$ raised to any positive natural exponent is $0$, so $0^4 = 0$. The sum is $1 + 0 = 1$. The value $0$ assumes $4^0 = 0$, the value $2$ confuses $0^4$ with $1$ and the value $4$ ignores the zero exponent.
