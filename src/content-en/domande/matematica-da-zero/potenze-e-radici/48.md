How many digits does the integer $3.2\cdot10^{9}$ have?

- $9$
- $11$
- $10$
- $3$

## Explanation

Multiplying by $10^9$ moves the decimal point $9$ places to the right, giving $3.2\cdot10^9 = 3\,200\,000\,000$. The number contains the digit $3$, the digit $2$ and $8$ zeros, so it has $10$ digits. The value $9$ counts only the exponent, while $11$ counts one place too many.
