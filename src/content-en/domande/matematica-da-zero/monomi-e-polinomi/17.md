For which value of $k$ are the monomials $3x^2y^k$ and $-5x^2y^4$ like terms?

- $k = 4$
- $k = 7$
- $k = 2$
- $k = 3$

## Explanation

The two monomials are like terms if they have the same variable part. The variable $x$ already has exponent $2$ in both, so we only need the variable $y$ to have the same exponent. Therefore $k = 4$. The coefficients $3$ and $-5$ have no effect.
