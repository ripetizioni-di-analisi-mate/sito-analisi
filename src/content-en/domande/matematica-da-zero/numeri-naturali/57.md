A box holds $8$ packs, and each pack contains $5$ red pencils and $3$ blue pencils. How many pencils are in the box?

- $24$
- $64$
- $43$
- $16$

## Explanation

Each pack contains $5 + 3 = 8$ pencils, so the box holds $8 \cdot (5 + 3) = 8 \cdot 8 = 64$. By the distributive property we obtain the same number, $8 \cdot 5 + 8 \cdot 3 = 40 + 24$. The value $43$ multiplies the number of packs by the number of red pencils only.
