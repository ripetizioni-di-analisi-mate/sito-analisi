Which of these equalities is correct?

- $0 : 5 = 0$
- $0 : 0 = 1$
- $5 : 0 = 0$
- $5 : 0 = 5$

## Explanation

The division $0 : 5$ has quotient $0$ because $0 \cdot 5 = 0$. The division $5 : 0$ is undefined because no number multiplied by $0$ gives $5$. Likewise, $0 : 0$ has no unique quotient because every number multiplied by $0$ gives $0$.
