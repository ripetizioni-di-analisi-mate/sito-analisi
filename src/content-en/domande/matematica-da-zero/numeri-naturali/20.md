What is the smallest five-digit number that can be written using the digits $3$, $0$, $7$, $1$, and $5$ exactly once each?

- $10\,357$
- $13\,057$
- $30\,157$
- $01\,357$

## Explanation

To make the number small, put the smallest digits as far to the left as possible. The first digit cannot be $0$ because then the number would have four digits. Therefore start with $1$, followed by $0$, then $3$, $5$, and $7$. The number is $10\,357$.
