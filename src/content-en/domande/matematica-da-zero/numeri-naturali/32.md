The value of the sum $489 + 376$ is

- $755$
- $865$
- $765$
- $965$

## Explanation

In the ones place, $9 + 6 = 15$, so write $5$ and carry one ten. In the tens place, $8 + 7 + 1 = 16$, so write $6$ and carry one hundred. In the hundreds place, $4 + 3 + 1 = 8$, so the sum is $865$. The values $765$ and $755$ result from omitting carries, whereas $965$ includes an extra carry.
