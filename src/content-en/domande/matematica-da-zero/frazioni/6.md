Which of the following expressions represents the number $0$?

- $\dfrac{7}{0}$
- $\dfrac{0}{7}$
- $\dfrac{7}{7}$
- $\dfrac{1}{7}$

## Explanation

A fraction with numerator $0$ and denominator different from $0$ equals $0$ because $0 : 7 = 0$. The expression $\dfrac{7}{0}$ is undefined because its denominator is $0$. The fraction $\dfrac{7}{7}$ equals $1$ because $7 : 7 = 1$. The fraction $\dfrac{1}{7}$ represents one part of size one seventh, so it is greater than $0$.
