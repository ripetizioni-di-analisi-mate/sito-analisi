We add $4$ to both the numerator and the denominator of the fraction $\dfrac{3}{5}$. Compared with $\dfrac{3}{5}$, how does the new fraction change?

- It is equal, with value $\dfrac{3}{5}$
- It is greater, with value $\dfrac{7}{9}$
- It is less, with value $\dfrac{3}{9}$
- It is greater, with value $\dfrac{7}{5}$

## Explanation

The new fraction is $\dfrac{3+4}{5+4} = \dfrac{7}{9}$. With denominator $45$ we have $\dfrac{3}{5} = \dfrac{27}{45}$ and $\dfrac{7}{9} = \dfrac{35}{45}$, and $35 > 27$, so it is greater. The invariance property applies to multiplication or division of the two terms by the same number. Adding the same number to both terms does not satisfy this property. The other answers add $4$ to only one term or leave the value unchanged.
