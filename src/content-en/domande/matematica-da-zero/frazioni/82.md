Which of the following statements about rational numbers is true?

- Every rational number is an integer
- The expression $\dfrac{5}{0}$ represents a rational number
- Every integer is also a rational number
- A rational number cannot be negative

## Explanation

A rational number can be written as a fraction with an integer numerator and an integer denominator different from $0$. Every integer $n$ can be written as $\dfrac{n}{1}$, so it is rational. For example, $-2 = -\dfrac{2}{1}$. The expression $\dfrac{5}{0}$ is undefined, and $-\dfrac{3}{4}$ is both rational and negative.
