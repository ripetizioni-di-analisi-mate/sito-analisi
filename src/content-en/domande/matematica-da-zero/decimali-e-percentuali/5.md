What is the order of $1.3$, $1.09$, $1.25$ and $1.125$ from least to greatest?

- $1.3 < 1.09 < 1.25 < 1.125$
- $1.09 < 1.125 < 1.25 < 1.3$
- $1.3 < 1.25 < 1.125 < 1.09$
- $1.09 < 1.3 < 1.125 < 1.25$

## Explanation

The numbers have the same whole-number part, so compare the tenths digits, which are $0$ in $1.09$, $1$ in $1.125$, $2$ in $1.25$ and $3$ in $1.3$. The increasing order is therefore $1.09 < 1.125 < 1.25 < 1.3$. The number of digits after the decimal point does not determine the order.
