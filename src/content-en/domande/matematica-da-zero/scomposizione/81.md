For $x=-3$ the fraction $\dfrac{x^2-9}{x^2+3x}$ becomes $\dfrac{0}{0}$. What follows?

- The value $-3$ is excluded because it makes the denominator zero
- The value $-3$ is allowed because the fraction equals $0$
- The value $-3$ is allowed because the numerator and denominator cancel
- The value $-3$ is excluded only if the fraction cannot be simplified

## Explanation

The denominator $x^2+3x=x\,(x+3)$ equals zero for $x=-3$, so the value is excluded. Simplifying gives $\dfrac{x-3}{x}$, which for $x=-3$ equals $2$, but the original fraction has no value there. Determine the domain restrictions before simplifying.
