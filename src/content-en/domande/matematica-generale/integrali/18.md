What is $\displaystyle\int \dfrac{\sin x}{\cos^2 x}\,dx$, on an interval where $\cos x \neq 0$?

- $-\dfrac{1}{\cos x} + c$
- $\dfrac{1}{\cos x} + c$
- $\ln \lvert \cos x \rvert + c$
- $-\dfrac{1}{3\cos^3 x} + c$

## Explanation

Set $g(x) = \cos x$, so $g'(x) = -\sin x$ and the integrand can be written as $-\big( g(x) \big)^{-2}\,g'(x)$. The integral therefore reduces to the standard integral $\displaystyle\int \big( g(x) \big)^{a} g'(x)\,dx = \dfrac{\big( g(x) \big)^{a + 1}}{a + 1} + c$ with $a = -2$. Since $a + 1 = -1$, one obtains
$$
\int \frac{\sin x}{\cos^2 x}\,dx = -\frac{(\cos x)^{-1}}{-1} + c = \frac{1}{\cos x} + c .
$$
The result $-\dfrac{1}{\cos x} + c$ comes from forgetting the minus sign of the derivative $g'(x) = -\sin x$, and $-\dfrac{1}{3\cos^3 x} + c$ from using the exponent $a - 1 = -3$ instead of $a + 1$.
