For which of the following functions are the hypotheses of the integral mean value theorem satisfied on the interval $[-1, 1]$?

- $f(x) = \lvert x \rvert$
- $f(x) = \dfrac{1}{x}$
- $f(x) = \ln \lvert x \rvert$
- $f(x) = \dfrac{x}{\lvert x \rvert}$ for $x \neq 0$, with $f(0) = 0$

## Explanation

The **integral mean value theorem** requires $f$ to be continuous on the closed interval $[a, b]$. The function $\lvert x \rvert$ is continuous on $\mathbb{R}$, so the hypothesis is satisfied on $[-1, 1]$. The functions $\dfrac{1}{x}$ and $\ln \lvert x \rvert$ are not defined at $x = 0$, which belongs to the interval. The function $\dfrac{x}{\lvert x \rvert}$ equals $-1$ for $x < 0$ and $1$ for $x > 0$; therefore it is not continuous at $x = 0$.
