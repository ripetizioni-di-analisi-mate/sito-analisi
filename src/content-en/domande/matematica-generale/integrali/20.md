Compute $\displaystyle\int \dfrac{e^{2x}}{e^x + 1}\,dx$ with the substitution $t = e^x$.

- $e^x + \ln\left( e^x + 1 \right) + c$
- $\ln\left( e^x + 1 \right) + c$
- $\dfrac{e^{2x}}{2} - \ln\left( e^x + 1 \right) + c$
- $e^x - \ln\left( e^x + 1 \right) + c$

## Explanation

From $t = e^x$ we get $x = \ln t$, so $dx = \dfrac{1}{t}\,dt$ and $e^{2x} = t^2$. Substituting gives
$$
\int \frac{e^{2x}}{e^x + 1}\,dx = \int \frac{t^2}{t + 1} \cdot \frac{1}{t}\,dt = \int \frac{t}{t + 1}\,dt = \int \left( 1 - \frac{1}{t + 1} \right) dt .
$$
The last integral equals $t - \ln (t + 1) + c$, without absolute value because $t = e^x > 0$. Returning to the variable $x$, the result is $e^x - \ln\left( e^x + 1 \right) + c$.
