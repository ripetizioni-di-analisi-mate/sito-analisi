For which value of the real parameter $k$ does an antiderivative of $\dfrac{x + k}{(x - 1)(x - 3)}$ not contain the term $\ln \lvert x - 1 \rvert$?

- $k = -1$
- $k = 1$
- $k = -3$
- $k = 3$

## Explanation

The **partial fraction** decomposition is $\dfrac{x + k}{(x - 1)(x - 3)} = \dfrac{A}{x - 1} + \dfrac{B}{x - 3}$, with $x + k = A\,(x - 3) + B\,(x - 1)$. With $x = 1$ we get $1 + k = -2A$, so $A = -\dfrac{1 + k}{2}$. The term $A \ln \lvert x - 1 \rvert$ is missing from the antiderivative if and only if $A = 0$, that is, for $k = -1$. In that case the function is $\dfrac{x - 1}{(x - 1)(x - 3)} = \dfrac{1}{x - 3}$ for $x \neq 1$, with antiderivative $\ln \lvert x - 3 \rvert + c$. With $k = -3$ the factor $x - 3$ cancels instead, and $\dfrac{1}{x - 1}$ remains.
