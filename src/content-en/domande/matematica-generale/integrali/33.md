Let $F(x) = \displaystyle\int_1^{x} \ln t\,dt$ for $x > 0$. How many solutions does the equation $F(x) = 0$ have?

- None
- Exactly two
- Only one, $x = 1$
- Only one, $x = e$

## Explanation

The function $\ln t$ is continuous on $(0, +\infty)$, so the **fundamental theorem of calculus** gives $F'(x) = \ln x$. Since $\ln x < 0$ for $0 < x < 1$ and $\ln x > 0$ for $x > 1$, the function $F$ is strictly decreasing on $(0, 1]$ and strictly increasing on $[1, +\infty)$. Therefore $x = 1$ is the global minimum point of $F$, and the minimum value is $F(1) = \displaystyle\int_1^{1} \ln t\,dt = 0$. It follows that $F(x) > 0$ for every $x \neq 1$, so the equation $F(x) = 0$ has **only one solution**, $x = 1$. The value at $x = e$ is $F(e) = \Big[ t \ln t - t \Big]_1^{e} = 1$.
