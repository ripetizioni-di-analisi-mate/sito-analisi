Let $f$ be a continuous function on $[1, 4]$ with $\displaystyle\int_1^{4} f(x)\,dx = 9$. Which statement is necessarily true?

- There exists $c \in [1, 4]$ such that $f(c) = 9$
- $f(x) = 3$ for every $x \in [1, 4]$
- There exists $c \in [1, 4]$ such that $f(c) = 3$
- $f(x) \leq 3$ for every $x \in [1, 4]$

## Explanation

The function $f$ is continuous on the closed interval $[1, 4]$, so the hypotheses of the **mean value theorem for integrals** are satisfied. Therefore there exists $c \in [1, 4]$ such that
$$
f(c) = \frac{1}{4 - 1} \int_1^{4} f(x)\,dx = \frac{9}{3} = 3 .
$$
The other statements do not hold for all functions with that integral. The constant function $3$ has integral $9$ on $[1, 4]$ and never takes the value $9$. The function $(x - 1)^2$ has integral $\left[ \dfrac{(x - 1)^3}{3} \right]_1^{4} = 9$, but it equals $9$ at $x = 4$, so it is not equal to $3$ on the whole interval and it is not less than or equal to $3$.
