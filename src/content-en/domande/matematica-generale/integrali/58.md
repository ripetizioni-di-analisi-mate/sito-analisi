We want to compute $\displaystyle\int x^3 \ln x\,dx$ for $x > 0$ with the formula $\displaystyle\int f(x)\,g'(x)\,dx = f(x)\,g(x) - \int f'(x)\,g(x)\,dx$. Which choice of factors leads to a basic integral?

- $f(x) = x^3$ and $g'(x) = \ln x$
- $f(x) = \ln x$ and $g'(x) = x^3$
- $f(x) = x^3 \ln x$ and $g'(x) = 1$
- $f(x) = x$ and $g'(x) = x^2 \ln x$

## Explanation

With $f(x) = \ln x$ and $g'(x) = x^3$ we have $f'(x) = \dfrac{1}{x}$ and $g(x) = \dfrac{x^4}{4}$, so
$$
\int x^3 \ln x\,dx = \frac{x^4}{4} \ln x - \int \frac{x^4}{4} \cdot \frac{1}{x}\,dx = \frac{x^4}{4} \ln x - \int \frac{x^3}{4}\,dx ,
$$
and the last integral is a **basic integral**. The result is $\dfrac{x^4}{4} \ln x - \dfrac{x^4}{16} + c$. With $f(x) = x^3$ and $g'(x) = \ln x$ we have $g(x) = x \ln x - x$, and the remaining integral, $\displaystyle\int 3x^2 \left( x \ln x - x \right) dx$, still contains $x^3 \ln x$. With $g'(x) = x^2 \ln x$, finding $g$ already requires an integration by parts of the same kind as the original one. With $f(x) = x^3 \ln x$ and $g'(x) = 1$ the remaining integral is $\displaystyle\int x \left( 3x^2 \ln x + x^2 \right) dx$, which still contains $x^3 \ln x$.
