- $\dfrac{(2x + 1)^{\frac{5}{2}}}{10} - \dfrac{(2x + 1)^{\frac{3}{2}}}{6} + c$
- $\dfrac{(2x + 1)^{\frac{5}{2}}}{5} - \dfrac{(2x + 1)^{\frac{3}{2}}}{3} + c$
- $\dfrac{(2x + 1)^{\frac{5}{2}}}{10} + \dfrac{(2x + 1)^{\frac{3}{2}}}{6} + c$
- $\dfrac{2\,(2x + 1)^{\frac{5}{2}}}{5} - \dfrac{2\,(2x + 1)^{\frac{3}{2}}}{3} + c$

## Explanation

From $t = 2x + 1$ we obtain $x = \dfrac{t - 1}{2}$, so $dx = \dfrac{1}{2}\,dt$. Substituting gives
$$
\int x \sqrt{2x + 1}\,dx = \int \frac{t - 1}{2}\,\sqrt{t}\,\frac{1}{2}\,dt = \frac{1}{4} \int \left( t^{\frac{3}{2}} - t^{\frac{1}{2}} \right) dt .
$$
By the power formula the last integral equals $\dfrac{1}{4} \left( \dfrac{2}{5}\,t^{\frac{5}{2}} - \dfrac{2}{3}\,t^{\frac{3}{2}} \right) = \dfrac{t^{\frac{5}{2}}}{10} - \dfrac{t^{\frac{3}{2}}}{6}$. Returning to the variable $x$ with $t = 2x + 1$, the result is $\dfrac{(2x + 1)^{\frac{5}{2}}}{10} - \dfrac{(2x + 1)^{\frac{3}{2}}}{6} + c$.
