Which function is an antiderivative of $2 x e^{x^{2} + 5}$?

- $e^{x^{2}}$
- $x e^{x^{2} + 5}$
- $2 e^{x^{2} + 5}$
- $e^{x^{2} + 5}$

## Explanation

Set $u=x^2+b$, where $b$ is the given constant. The factor $2x$ is then the derivative of $u$, so the remaining integral is that of $e^u$.
