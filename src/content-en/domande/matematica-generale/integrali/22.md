Compute $\displaystyle\int x \cos x\,dx$.

- $x \sin x - \cos x + c$
- $\sin x - x \cos x + c$
- $x \sin x + \cos x + c$
- $\dfrac{x^2}{2} \sin x + c$

## Explanation

Apply **integration by parts**, differentiating $f(x) = x$ and integrating $g'(x) = \cos x$. This gives $f'(x) = 1$ and $g(x) = \sin x$. The formula gives
$$
\int x \cos x\,dx = x \sin x - \int \sin x\,dx .
$$
Since $\displaystyle\int \sin x\,dx = -\cos x + c$, the result is $x \sin x + \cos x + c$.
