- $-\ln \lvert x - 1 \rvert + 2 \ln \lvert x + 3 \rvert + c$
- $2 \ln \lvert x + 1 \rvert - \ln \lvert x - 3 \rvert + c$
- $2 \ln \lvert x - 1 \rvert + \ln \lvert x + 3 \rvert + c$
- $2 \ln \lvert x - 1 \rvert - \ln \lvert x + 3 \rvert + c$

## Explanation

The denominator has roots $1$ and $-3$, so $x^2 + 2x - 3 = (x - 1)(x + 3)$ and we look for $A$ and $B$ such that
$$
\frac{x + 7}{(x - 1)(x + 3)} = \frac{A}{x - 1} + \frac{B}{x + 3}
\iff
x + 7 = A\,(x + 3) + B\,(x - 1) .
$$
With $x = 1$ we obtain $8 = 4A$, so $A = 2$. With $x = -3$ we obtain $4 = -4B$, so $B = -1$. Each partial fraction is reducible to the standard integral $\displaystyle\int \dfrac{g'(x)}{g(x)}\,dx = \ln \lvert g(x) \rvert + c$; therefore the integral equals $2 \ln \lvert x - 1 \rvert - \ln \lvert x + 3 \rvert + c$.
