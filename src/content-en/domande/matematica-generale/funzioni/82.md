Which of the following functions has natural domain all of $\mathbb{R}$?

- $f(x) = \ln(x^2 + 1)$
- $f(x) = \ln(x^2)$
- $f(x) = \sqrt{x^2 - 1}$
- $f(x) = \dfrac{1}{x^2 - x}$

## Explanation

For every real $x$ we have $x^2 + 1 \geq 1 > 0$, so the argument of $\ln(x^2 + 1)$ is always positive and the domain of this function is $\mathbb{R}$. The other three functions exclude some numbers. In $\ln(x^2)$ the argument equals $0$ for $x = 0$, which must be excluded. In $\sqrt{x^2 - 1}$ the argument is negative for $-1 < x < 1$, and in $\dfrac{1}{x^2 - x}$ the denominator $x\,(x - 1)$ vanishes for $x = 0$ and for $x = 1$.
