- Vertex $(-2, 27)$, minimum value $27$
- Vertex $(2, -5)$, minimum value $-5$
- Vertex $(4, 3)$, minimum value $3$
- Vertex $(2, -13)$, minimum value $-13$

## Explanation

The parabola has $a = 2$, $b = -8$ and $c = 3$, so the horizontal coordinate of the vertex is
$$
x_V = -\frac{b}{2a} = \frac{8}{4} = 2 .
$$
The vertical coordinate is $y_V = f(2) = 8 - 16 + 3 = -5$. Since $a = 2 > 0$, the parabola opens upward, so $-5$ is the **minimum value** of $f$.
