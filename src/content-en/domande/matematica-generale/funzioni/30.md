For which $x$ is the function $f(x) = x^2 - 6x + 9$ positive?

- $\mathbb{R} \setminus \{3\}$
- $\mathbb{R}$
- $(3, +\infty)$
- $\varnothing$

## Explanation

The discriminant is $\Delta = 36 - 36 = 0$, so the function has a single zero, $x = 3$, which is the $x$-coordinate of the vertex. Indeed $x^2 - 6x + 9 = (x - 3)^2$. Since $a = 1 > 0$, for $x \neq 3$ the function has the sign of $a$, that is, it is positive. At the point $x = 3$ the function equals $0$, which is not positive. Therefore $f(x) > 0$ for every $x \in \mathbb{R} \setminus \{3\}$.
