For which values of $a$ is the interval $[a, a + 2]$ contained in the interval $(0, 5)$?

- $-2 < a < 5$
- $0 \leq a \leq 3$
- $0 < a < 3$
- $0 < a < 5$

## Explanation

The interval $[a, a + 2]$ is contained in $(0, 5)$ if each of its elements belongs to $(0, 5)$. The endpoints $a$ and $a + 2$ are elements of $[a, a + 2]$, so they must belong to $(0, 5)$; conversely, if the two endpoints lie in $(0, 5)$, all the numbers between them lie there too. Therefore the conditions to be satisfied together are
$$
\begin{cases}
a > 0 \\[4pt]
a + 2 < 5
\end{cases}
\iff
0 < a < 3 .
$$
For $a = 0$ the interval $[0, 2]$ contains the number $0$, which does not belong to $(0, 5)$, so $a = 0$ must be excluded. The condition $-2 < a < 5$ expresses instead that the two intervals have at least one point in common.
