Which of the following functions, defined on $\mathbb{R}$, is injective?

- $f(x) = x^2 - 4x$
- $f(x) = x^3 + 1$
- $f(x) = |x + 2|$
- $f(x) = x^4 - 1$

## Explanation

A function is **injective** if different values of the variable have different images. For $x^2 - 4x$ we have $f(0) = f(4) = 0$, for $|x + 2|$ we have $f(-3) = f(-1) = 1$ and for $x^4 - 1$ we have $f(-1) = f(1) = 0$, so these three functions are not injective. For $x_1 < x_2$ we have $x_1^3 < x_2^3$, therefore $x^3 + 1$ is increasing on $\mathbb{R}$. An increasing function is injective, so the answer is $f(x) = x^3 + 1$.
