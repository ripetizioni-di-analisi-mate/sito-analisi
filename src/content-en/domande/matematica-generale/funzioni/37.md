The function $h(x) = \ln(x^2 + 1)$ is written as a composite function $h = g \circ f$. What are $f$ and $g$?

- $f(x) = x^2 + 1$ and $g(x) = \ln x$
- $f(x) = \ln x$ and $g(x) = x^2 + 1$
- $f(x) = x^2$ and $g(x) = \ln x + 1$
- $f(x) = x + 1$ and $g(x) = \ln (x^2)$

## Explanation

The composite $g \circ f$ applies first $f$ and then $g$, so $f$ is the function computed first. To compute $h(x)$ one first computes $x^2 + 1$ and then the logarithm of the result. Therefore $f(x) = x^2 + 1$ and $g(x) = \ln x$, and indeed $g(f(x)) = \ln(x^2 + 1)$. With $f(x) = \ln x$ and $g(x) = x^2 + 1$ we get $(\ln x)^2 + 1$. With $f(x) = x^2$ and $g(x) = \ln x + 1$ we get $\ln(x^2) + 1$, which equals $1$ at $x = 1$, whereas $h(1) = \ln 2$. With $f(x) = x + 1$ and $g(x) = \ln(x^2)$ we get $\ln\big((x + 1)^2\big)$, which equals $\ln 4$ at $x = 1$, whereas $h(1) = \ln 2$.
