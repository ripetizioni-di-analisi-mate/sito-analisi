What is the inverse of the function $f(x) = \dfrac{2x - 3}{5}$?

- $f^{-1}(y) = \dfrac{5y - 3}{2}$
- $f^{-1}(y) = \dfrac{5y + 3}{2}$
- $f^{-1}(y) = \dfrac{5}{2y - 3}$
- $f^{-1}(y) = \dfrac{5y}{2} + 3$

## Explanation

The function is linear with slope $\dfrac{2}{5} > 0$, so it is increasing on $\mathbb{R}$ and is invertible. To find the inverse we solve $y = \dfrac{2x - 3}{5}$ for $x$. Multiplying by $5$ we obtain $5y = 2x - 3$, so $2x = 5y + 3$ and
$$
f^{-1}(y) = \frac{5y + 3}{2} .
$$
