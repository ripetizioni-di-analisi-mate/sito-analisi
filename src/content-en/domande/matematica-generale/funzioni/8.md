- Fixed cost $0$ euros, unit variable cost $32.5$ euros
- Fixed cost $1000$ euros, unit variable cost $20$ euros
- Fixed cost $1800$ euros, unit variable cost $10$ euros
- Fixed cost $4200$ euros, unit variable cost $20$ euros

## Explanation

The cost is linear, so it is written as $C(q) = F + c\,q$, with $F$ the fixed cost and $c$ the unit variable cost. The unit variable cost is the slope of the line through the points $(80, 2600)$ and $(120, 3400)$:
$$
c = \frac{3400 - 2600}{120 - 80} = \frac{800}{40} = 20 .
$$
Since $C(80) = 2600$, we have $F = 2600 - 20 \cdot 80 = 1000$. Hence the fixed cost is $1000$ euros and the unit variable cost is $20$ euros.
