Let $f(x) = \left( \dfrac{1}{2} \right)^{x}$, defined on $\mathbb{R}$. Which statement is true?

- $f$ is increasing on $\mathbb{R}$
- $f$ is decreasing on $\mathbb{R}$ and its image is $(0, +\infty)$
- $f$ is decreasing on $\mathbb{R}$ and its image is $[0, +\infty)$
- $f$ is decreasing on $\mathbb{R}$ and $f(-1) = \dfrac{1}{2}$

## Explanation

The base $\dfrac{1}{2}$ lies between $0$ and $1$, so the exponential function $f$ is decreasing on $\mathbb{R}$. An exponential is always positive, therefore the value $0$ is not an image. Every $y > 0$, instead, is the image of $x = \log_{\frac{1}{2}} y$, so the image of $f$ is $(0, +\infty)$. Finally $f(-1) = \left( \dfrac{1}{2} \right)^{-1} = 2$.
