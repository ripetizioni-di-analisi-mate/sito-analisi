What is the largest interval on which the function $f(x) = x^2 - 6x + 5$ is decreasing?

- $[3, +\infty)$
- $(1, 5)$
- $(-\infty, 5]$
- $(-\infty, 3]$

## Explanation

Completing the square gives $f(x) = (x - 3)^2 - 4$, so the parabola has its vertex at $x_V = 3$ and opens upward. For $x_1 < x_2 \leq 3$ we have $x_1 - 3 < x_2 - 3 \leq 0$, therefore $(x_1 - 3)^2 > (x_2 - 3)^2$ and $f(x_1) > f(x_2)$. Hence $f$ is decreasing on $(-\infty, 3]$. By the same argument $f$ is increasing on $[3, +\infty)$. Therefore an interval containing numbers greater than $3$ cannot be an interval on which the function decreases. The largest interval on which the function decreases is $(-\infty, 3]$.
