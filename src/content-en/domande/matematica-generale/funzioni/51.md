The function $f$ is defined by
$$
f(x) =
\begin{cases}
x^2 & \text{if } x < 1 \\[4pt]
3 - x & \text{if } x \geq 1
\end{cases}
$$
What is $f(-2) + f(4)$?

- $4$
- $3$
- $20$
- $21$

## Explanation

Since $-2 < 1$, the value $f(-2)$ is computed with the first expression, so $f(-2) = (-2)^2 = 4$. Since $4 \geq 1$, the value $f(4)$ is computed with the second expression, so $f(4) = 3 - 4 = -1$. Therefore $f(-2) + f(4) = 4 - 1 = 3$. Using the same expression for both values would give $4$ with $3 - x$ and $20$ with $x^2$.
