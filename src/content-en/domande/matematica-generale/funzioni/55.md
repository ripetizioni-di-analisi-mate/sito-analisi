Which of the following rules defines a function $f : \mathbb{R} \to \mathbb{R}$?

- To each $x$ assign a number $y$ such that $y^2 = x$
- To each $x$ assign the largest integer less than or equal to $x$
- To each $x$ assign the number $\dfrac{1}{x}$
- To each $x$ assign the number $\sqrt{x}$

## Explanation

A function from $\mathbb{R}$ to $\mathbb{R}$ assigns to *every* real number *one and only one* real number. For $x = 4$ there are two numbers with $y^2 = 4$, namely $2$ and $-2$, and for $x = -1$ no real number has square $-1$, so the rule $y^2 = x$ does not define a function. The rule $\dfrac{1}{x}$ assigns nothing to the number $0$, and the rule $\sqrt{x}$ assigns nothing to negative numbers, therefore these two rules do not define a function on all of $\mathbb{R}$ either. Every real number $x$ lies between two consecutive integers $n \leq x < n + 1$, and the largest integer less than or equal to $x$ is exactly $n$. Hence the rule of the largest integer less than or equal to $x$ assigns a single value to each $x$, for example $2$ to $2.7$ and $-1$ to $-0.5$, and it defines a function.
