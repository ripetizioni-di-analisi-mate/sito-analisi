Which of the following functions has maximum value equal to $5$?

- $f(x) = x^2 - 4x + 9$
- $f(x) = -2x^2 + 4x + 3$
- $f(x) = -x^2 + 2x + 5$
- $f(x) = -x^2 + 6x - 5$

## Explanation

A quadratic function has a maximum value only if $a < 0$, and in that case the maximum is the ordinate of the vertex. The function $x^2 - 4x + 9$ has $a = 1 > 0$, so $5 = f(2)$ is its *minimum* value. For $-2x^2 + 4x + 3$ the vertex has abscissa $x_V = -\dfrac{4}{2 \cdot (-2)} = 1$, and $f(1) = -2 + 4 + 3 = 5$. In the same way $-x^2 + 2x + 5$ has maximum $f(1) = 6$ and $-x^2 + 6x - 5$ has maximum $f(3) = 4$. Therefore the answer is $f(x) = -2x^2 + 4x + 3$.
