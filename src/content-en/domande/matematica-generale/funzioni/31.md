Each row lists the values of a function $f$ at $x = 0, 1, 2, 3$, in this order. Which row can consist of the values of an exponential function $f(x) = k \cdot a^{x}$?

- $2, \ 5, \ 8, \ 11$
- $3, \ 6, \ 12, \ 24$
- $1, \ 4, \ 9, \ 16$
- $4, \ 6, \ 9, \ 12$

## Explanation

For $f(x) = k \cdot a^{x}$ we have $\dfrac{f(x + 1)}{f(x)} = a$ for every $x$, so the ratios between consecutive values are all equal. In the row $3, 6, 12, 24$ each value is twice the previous one, therefore the values are those of $f(x) = 3 \cdot 2^{x}$. In the row $2, 5, 8, 11$ the differences are constant, equal to $3$, and the ratios $\dfrac{5}{2}$ and $\dfrac{8}{5}$ are different, so the values are those of a linear function. In the row $1, 4, 9, 16$ the ratios are $4$, $\dfrac{9}{4}$ and $\dfrac{16}{9}$. In the row $4, 6, 9, 12$ the ratios are $\dfrac{3}{2}$, $\dfrac{3}{2}$ and $\dfrac{4}{3}$, so they are not all equal.
