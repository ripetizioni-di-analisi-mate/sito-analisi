The temperature in degrees Fahrenheit is obtained from the temperature in degrees Celsius through the linear function $F = \dfrac{9}{5}\,C + 32$. For which temperature do the value in degrees Celsius and the value in degrees Fahrenheit coincide?

- $40$
- $-\dfrac{160}{9}$
- $-40$
- $-\dfrac{80}{7}$

## Explanation

The two values coincide when $F = C$, so we solve the equation $C = \dfrac{9}{5}\,C + 32$. Moving the terms with $C$ to the left gives $-\dfrac{4}{5}\,C = 32$. Therefore $C = 32 \cdot \left( -\dfrac{5}{4} \right) = -40$. Indeed $\dfrac{9}{5} \cdot (-40) + 32 = -72 + 32 = -40$. The value $-\dfrac{160}{9}$ is instead the temperature in degrees Celsius for which $F = 0$.
