What is the set of all values of $k$ for which the function $f(x) = x^2 + 4x + k$ has no real zeros?

- $k < 4$
- $k \geq 4$
- $k > 4$
- $k > 16$

## Explanation

A quadratic function has no real zeros when the discriminant is negative. Here $\Delta = 16 - 4k$, so the condition is $16 - 4k < 0$, that is, $k > 4$. For $k = 4$ we have $\Delta = 0$ and the function $x^2 + 4x + 4 = (x + 2)^2$ has the zero $x = -2$, therefore $k = 4$ must be excluded. Therefore the solution set is described by $k > 4$.
