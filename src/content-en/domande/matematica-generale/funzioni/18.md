Which of the following equalities holds for every $x \in \mathbb{R}$?

- $e^{\ln x} = x$
- $\ln(x^2) = 2 \ln x$
- $\ln(e^{x}) = x$
- $\sqrt{x^2} = x$

## Explanation

Since $e^{x} > 0$ for every real $x$, the number $\ln(e^{x})$ is defined for every $x \in \mathbb{R}$. The function $\ln x$ is the inverse of $e^{x}$, so $\ln(e^{x}) = x$ for every $x \in \mathbb{R}$. The expression $e^{\ln x}$ is defined only for $x > 0$, therefore the equality $e^{\ln x} = x$ holds only for $x > 0$. For $x = -1$ we have $\ln\big((-1)^2\big) = \ln 1 = 0$, whereas $2 \ln(-1)$ is not defined. Finally $\sqrt{x^2} = |x|$, which equals $2$ and not $-2$ for $x = -2$.
