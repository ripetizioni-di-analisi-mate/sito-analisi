Which ordering of the numbers $2^{30}$, $3^{20}$ and $5^{10}$ is correct?

- $3^{20} < 2^{30} < 5^{10}$
- $5^{10} < 2^{30} < 3^{20}$
- $2^{30} < 5^{10} < 3^{20}$
- $5^{10} < 3^{20} < 2^{30}$

## Explanation

By the property $(a^{x})^{y} = a^{xy}$ the three numbers can be written with the same exponent $10$:
$$
2^{30} = (2^{3})^{10} = 8^{10},
\qquad
3^{20} = (3^{2})^{10} = 9^{10},
\qquad
5^{10} .
$$
The function $x^{10}$ is increasing for $x \geq 0$, so among positive numbers with the same exponent $10$ the one with the larger base is greater. Since $5 < 8 < 9$, we have $5^{10} < 8^{10} < 9^{10}$. Therefore the correct ordering is $5^{10} < 2^{30} < 3^{20}$.
