Between which consecutive integers does $\log_3 50$ lie?

- Between $16$ and $17$
- Between $1$ and $2$
- Between $3$ and $4$
- Between $4$ and $5$

## Explanation

By the definition of **logarithm**, $\log_3 50$ is the exponent to which $3$ must be raised to obtain $50$. We have $3^3 = 27$ and $3^4 = 81$, so $3^3 < 50 < 3^4$. The base-$3$ logarithm is increasing, because the base is greater than $1$, therefore $\log_3 27 < \log_3 50 < \log_3 81$, that is, $3 < \log_3 50 < 4$. The number $\dfrac{50}{3} \approx 16.7$ is the quotient, which has nothing to do with the logarithm.
