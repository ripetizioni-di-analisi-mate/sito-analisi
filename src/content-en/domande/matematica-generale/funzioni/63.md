For which values of the parameter $m$ is the function $f(x) = (m - 2)\,x + 5$ decreasing on $\mathbb{R}$?

- $m > 2$
- $m < 2$
- $m < 0$
- $m \neq 2$

## Explanation

The function is linear with slope $m - 2$. A linear function is decreasing if and only if its slope is negative, so we need $m - 2 < 0$, that is, $m < 2$. For $m = 2$ the function is the constant $f(x) = 5$, which is not decreasing. For $m > 2$ the slope is positive and the function is increasing.
