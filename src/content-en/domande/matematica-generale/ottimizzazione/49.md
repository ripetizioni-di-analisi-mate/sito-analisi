Which statement about the origin is true for $f(x, y) = |x| + |y|$?

- The origin is a stationary minimum point
- The origin is a saddle point
- The origin is not an extremum, because the gradient does not vanish there
- The origin is an absolute minimum point, and the partial derivatives do not exist there

## Explanation

Since $|x| \geq 0$ and $|y| \geq 0$, we have $f(x, y) \geq 0 = f(0, 0)$ for every $(x, y)$, so the origin is an **absolute minimum** point. Along the $x$-axis the function equals $f(x, 0) = |x|$, which is not differentiable at $x = 0$, so $f_x(0, 0)$ does not exist. In the same way $f(0, y) = |y|$, hence $f_y(0, 0)$ does not exist either. Fermat's theorem in two variables requires the partial derivatives to exist, so it does not apply at the origin. An extremum can therefore occur at a non-stationary point, when the partial derivatives do not exist at that point.
