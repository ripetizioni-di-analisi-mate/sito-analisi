Let $K = [0, 1] \times [0, 1]$. For which of the following functions does the Weierstrass theorem guarantee the existence of the absolute maximum and minimum on $K$?

- $f(x, y) = \dfrac{x}{1 + y}$
- $f(x, y) = \dfrac{1}{x + y}$
- $f(x, y) = \ln(xy)$
- $f(x, y) = \dfrac{y}{x - y}$

## Explanation

The set $K$ is closed and bounded, so the Weierstrass theorem applies to every function that is continuous at all points of $K$. The function $\dfrac{x}{1 + y}$ is continuous on $K$, because the denominator $1 + y$ is at least $1$, therefore it has an absolute maximum and minimum. The function $\dfrac{1}{x + y}$ is not defined at the point $(0, 0)$ of $K$, and $\ln(xy)$ is not defined at the points of $K$ on the axes. The function $\dfrac{y}{x - y}$ is not defined at the points of $K$ with $x = y$. For these three functions the continuity hypothesis on $K$ is not satisfied, so the theorem does not apply.
