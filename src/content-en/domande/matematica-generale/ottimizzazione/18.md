What is the stationary point of $f(x, y) = x^2 + xy + y^2 - 3x$?

- $(-2, 1)$
- $\left(\dfrac{3}{2}, 0\right)$
- $(1, -2)$
- $(2, -1)$

## Explanation

The partial derivatives are $f_x = 2x + y - 3$ and $f_y = x + 2y$, so the stationary points solve the system
$$
\begin{cases}
2x + y - 3 = 0 \\[4pt]
x + 2y = 0
\end{cases}
$$
From the second equation we get $x = -2y$, and substituting into the first we obtain $-3y - 3 = 0$, so $y = -1$ and $x = 2$. Therefore the only stationary point is $(2, -1)$. At the point $\left(\dfrac{3}{2}, 0\right)$ we have $f_x = 0$ but $f_y = \dfrac{3}{2}$, so that point is not stationary.
