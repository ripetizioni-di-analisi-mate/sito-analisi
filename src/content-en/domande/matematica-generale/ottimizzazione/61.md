For which value of the real parameter $a$ is the point $(1, 1)$ stationary for $f(x, y) = x^2 + xy + a y^2 - 3x - 5y$?

- $a = 4$
- $a = 1$
- $a = 3$
- $a = 2$

## Explanation

The partial derivatives are $f_x = 2x + y - 3$ and $f_y = x + 2ay - 5$. At $(1, 1)$ the first one equals $2 + 1 - 3 = 0$ for every $a$. The second one equals $1 + 2a - 5 = 2a - 4$, which vanishes only for $a = 2$. Therefore $(1, 1)$ is stationary **if and only if** $a = 2$. With $a = 2$ we also have $\det H = 2 \cdot 4 - 1^2 = 7 > 0$ and $f_{xx} = 2 > 0$, so the point is a local minimum point.
