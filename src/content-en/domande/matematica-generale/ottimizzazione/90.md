A firm has a production capacity of $10$ units and uses all of it for two goods, sold at $20$ and $16$ euros. The production cost is $C(q_1, q_2) = q_1^2 + q_2^2$. How does it split production to maximize profit?

- $q_1 = 6$, $q_2 = 4$
- $q_1 = 5$, $q_2 = 5$
- $q_1 = 10$, $q_2 = 8$
- $q_1 = 4$, $q_2 = 6$

## Explanation

The profit is $\pi = 20q_1 + 16q_2 - q_1^2 - q_2^2$. The Lagrange system with the constraint $q_1 + q_2 = 10$ gives $20 - 2q_1 = \lambda$ and $16 - 2q_2 = \lambda$, so $20 - 2q_1 = 16 - 2q_2$, that is, $q_1 = q_2 + 2$. The constraint becomes $2q_2 + 2 = 10$, therefore $q_2 = 4$, $q_1 = 6$ and $\lambda = 8$. On the constraint, with $q_2 = 10 - q_1$, the profit is a parabola in $q_1$ opening downward, so the point found is the **maximum**, with $\pi = 132$ euros. The quantities $q_1 = 10$ and $q_2 = 8$ maximize profit without the constraint, but their sum is $18$ and exceeds the production capacity.
