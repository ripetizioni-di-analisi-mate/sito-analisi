For the function $f(x, y) = x^2 + y^2 - 4x + 6y$, which point is a minimum point?

- $(2, -3)$
- $(-2, 3)$
- $(2, 3)$
- $(-2, -3)$

## Explanation

The partial derivatives are $f_x = 2x - 4$ and $f_y = 2y + 6$, so the stationary points solve the system
$$
\begin{cases}
2x - 4 = 0 \\[4pt]
2y + 6 = 0
\end{cases}
\iff
\begin{cases}
x = 2 \\[4pt]
y = -3
\end{cases}
$$
The only stationary point is therefore $(2, -3)$. The second derivatives are $f_{xx} = 2$, $f_{xy} = 0$ and $f_{yy} = 2$, so $\det H = 4 > 0$. Since $f_{xx} = 2 > 0$, by the **Hessian test** the point $(2, -3)$ is a **minimum point**, with $f(2, -3) = -13$.
