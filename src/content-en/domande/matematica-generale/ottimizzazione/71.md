Why does the extreme value theorem not apply to $f(x, y) = \dfrac{1}{x^2 + y^2}$ on the set $A = \{(x, y) : 0 < x^2 + y^2 \leq 1\}$?

- Because $A$ is not bounded
- Because $A$ is not closed, and indeed $f$ has no maximum on $A$
- Because $f$ is not continuous at some point of $A$
- The theorem applies, and the maximum of $f$ on $A$ is $1$

## Explanation

The set $A$ is the disk of radius $1$ without its center, so it is bounded. The origin does not belong to $A$, but every disk centered at the origin contains points of $A$, so the origin is a boundary point that is not in $A$ and the set **is not closed**. The function is continuous at every point of $A$, because the denominator $x^2 + y^2$ is positive. On $A$ the function has no maximum, because $f(t, 0) = \dfrac{1}{t^2}$ tends to $+\infty$ as $t \to 0^+$. The value $1$ is instead the minimum, attained on the circle $x^2 + y^2 = 1$.
