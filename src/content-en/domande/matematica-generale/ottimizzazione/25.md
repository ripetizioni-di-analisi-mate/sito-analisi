The function $f(x, y) = x^4 + y^4 - 4x^2y^2$ has the origin as a stationary point. How is the origin classified?

- Relative minimum point
- Saddle point
- Relative maximum point
- Absolute minimum point

## Explanation

The second derivatives $f_{xx} = 12x^2 - 8y^2$, $f_{xy} = -16xy$ and $f_{yy} = 12y^2 - 8x^2$ vanish at the origin, so $\det H(0, 0) = 0$ and the Hessian test does not allow a conclusion. One then studies the sign of $f(x, y) - f(0, 0) = f(x, y)$ along two lines through the origin. On the $x$-axis we have $f(x, 0) = x^4 > 0$ for $x \neq 0$, while on the line $y = x$ we have $f(x, x) = 2x^4 - 4x^4 = -2x^4 < 0$ for $x \neq 0$. In every disk centered at the origin the function therefore takes values greater and values smaller than $f(0, 0) = 0$, so the origin is a **saddle point**.
