Which of the following functions has no stationary points?

- $f(x, y) = x\,e^{y}$
- $f(x, y) = x^2 - y^2 + 2y$
- $f(x, y) = xy + x$
- $f(x, y) = e^{x} + e^{-x} + y^2$

## Explanation

For $f(x, y) = x\,e^{y}$ we have $f_x = e^{y}$, which is positive for every $y$. The first equation of the system $\nabla f = (0, 0)$ therefore has no solutions, and $f$ **has no stationary points**. The other three functions have one stationary point each. For $x^2 - y^2 + 2y$ the system $2x = 0$, $-2y + 2 = 0$ gives $(0, 1)$. For $xy + x$ the system $y + 1 = 0$, $x = 0$ gives $(0, -1)$. For $e^{x} + e^{-x} + y^2$ the system $e^{x} - e^{-x} = 0$, $2y = 0$ gives $(0, 0)$.
