For which values of the real parameter $k$ does the Hessian test establish that the origin is a saddle point of $f(x, y) = kx^2 + 2xy + y^2$?

- $k > 1$
- $k < 1$
- $k \leq 1$
- $k > 0$

## Explanation

The partial derivatives $f_x = 2kx + 2y$ and $f_y = 2x + 2y$ vanish at the origin, so the origin is a stationary point for every $k$. The second derivatives are $f_{xx} = 2k$, $f_{xy} = 2$ and $f_{yy} = 2$, therefore $\det H = 4k - 4$. The test identifies a saddle point when $\det H < 0$, that is, for $k < 1$. For $k = 1$ the determinant is zero and the test is inconclusive, while for $k > 1$ we have $\det H > 0$ and $f_{xx} = 2k > 0$, so the origin is a minimum point. Therefore the **Hessian test** identifies the origin as a saddle point for $k < 1$.
