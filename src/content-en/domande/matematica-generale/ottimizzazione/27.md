For the function $f(x, y) = x^2 + 4xy + y^2$ we consider the origin both as a point of $f$ restricted to the line $y = x$ and as a point of $f$ in the plane. Which statement is true?

- The origin is a constrained minimum point on the line and a relative minimum point in the plane
- The origin is a constrained maximum point on the line and a saddle point in the plane
- The origin is a constrained minimum point on the line and a saddle point in the plane
- The origin is not a constrained extremum on the line and is a saddle point in the plane

## Explanation

On the line $y = x$ we have $f(x, x) = x^2 + 4x^2 + x^2 = 6x^2 \geq 0 = f(0, 0)$, with equality only for $x = 0$, so the origin is a **constrained minimum point**. In the plane the partial derivatives $f_x = 2x + 4y$ and $f_y = 4x + 2y$ vanish at the origin, therefore the origin is a stationary point. The Hessian is constant, with $f_{xx} = f_{yy} = 2$ and $f_{xy} = 4$, so $\det H = 4 - 16 = -12 < 0$ and by the **Hessian test** the origin is a **saddle point**. Indeed, along the line $y = -x$ we have $f(x, -x) = -2x^2 < 0$. Therefore a constrained extremum need not be a relative extremum of the function in the plane.
