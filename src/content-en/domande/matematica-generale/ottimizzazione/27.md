The function $f(x, y) = 1 - x^2 - y^6$ has the origin as its only stationary point. How is the origin classified?

- Saddle point
- Relative but not absolute maximum point
- Absolute maximum point
- Relative minimum point

## Explanation

The second derivatives are $f_{xx} = -2$, $f_{xy} = 0$ and $f_{yy} = -30y^4$, which equals $0$ at the origin, so $\det H(0, 0) = 0$ and the Hessian test does not allow a conclusion. One then studies the difference $f(x, y) - f(0, 0) = -x^2 - y^6$. Both terms are nonpositive and they vanish together only for $x = y = 0$, so $f(x, y) < f(0, 0)$ for every $(x, y) \neq (0, 0)$. Therefore the origin is an **absolute maximum** point.
