The point $(\pi, 0)$ is stationary for $f(x, y) = \cos x + \cos y$. How is it classified?

- Local maximum point
- Saddle point
- Local minimum point
- The Hessian test is inconclusive

## Explanation

The partial derivatives are $f_x = -\sin x$ and $f_y = -\sin y$, which equal $0$ at $(\pi, 0)$. The second derivatives are $f_{xx} = -\cos x$, $f_{yy} = -\cos y$ and $f_{xy} = 0$. At $(\pi, 0)$ we have $f_{xx} = -\cos \pi = 1$ and $f_{yy} = -\cos 0 = -1$, so $\det H = 1 \cdot (-1) - 0 = -1 < 0$. By the **Hessian test** the point $(\pi, 0)$ is therefore a **saddle point**. Indeed, along the $x$-axis the function $\cos x + 1$ has a minimum at $x = \pi$, while along the line $x = \pi$ the function $\cos y - 1$ has a maximum at $y = 0$.
