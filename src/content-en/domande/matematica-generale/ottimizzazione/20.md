For the function $f(x, y) = (x^2 + y^2)\,e^{-x}$, which classification of the stationary points is correct?

- $(0, 0)$ is a saddle point and $(2, 0)$ is a relative maximum point
- $(0, 0)$ is a minimum point and $(2, 0)$ is a relative maximum point
- $(0, 0)$ is a minimum point and there are no other stationary points
- $(0, 0)$ is a minimum point and $(2, 0)$ is a saddle point

## Explanation

By the product rule we have $f_x = e^{-x}\,(2x - x^2 - y^2)$, while $f_y = 2y\,e^{-x}$. Since $e^{-x} > 0$, the condition $f_y = 0$ gives $y = 0$, and then $f_x = 0$ becomes $x\,(2 - x) = 0$; so the stationary points are $(0, 0)$ and $(2, 0)$. The origin is a minimum point, because $f(x, y) \geq 0 = f(0, 0)$ for every $(x, y)$. The second derivatives are $f_{xx} = e^{-x}\,(x^2 + y^2 - 4x + 2)$, $f_{xy} = -2y\,e^{-x}$ and $f_{yy} = 2e^{-x}$, which at $(2, 0)$ equal $-2e^{-2}$, $0$ and $2e^{-2}$. Therefore $\det H(2, 0) = -4e^{-4} < 0$, and by the **Hessian test** the point $(2, 0)$ is a **saddle point**.
