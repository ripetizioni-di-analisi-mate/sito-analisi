What is the set of absolute minimum points of $f(x, y) = (x + 2y - 4)^2$?

- Only the point $(0, 2)$
- All points of the line $x + 2y = 4$
- Only the point $(4, 0)$
- No point, because $\det H = 0$ at every stationary point

## Explanation

A square is always greater than or equal to $0$, so $f(x, y) \geq 0$ for every $(x, y)$. The value $0$ is obtained exactly at the points where $x + 2y - 4 = 0$. Therefore every point of the line $x + 2y = 4$ is an **absolute minimum** point, with value $0$, and none of these minima is strict. The Hessian test is inconclusive, because $f_{xx} = 2$, $f_{xy} = 4$, $f_{yy} = 8$ and hence $\det H = 2 \cdot 8 - 4^2 = 0$. The classification then follows directly from the sign of $f$.
