The function $f(x, y) = (x - y)^2 + y^4$ has the origin as its only stationary point. How is the origin classified?

- Absolute minimum point
- Saddle point
- Local maximum point
- Local minimum point that is not a global minimum

## Explanation

The second derivatives are $f_{xx} = 2$, $f_{xy} = -2$ and $f_{yy} = 2 + 12y^2$, so $\det H(0, 0) = 4 - 4 = 0$ and the Hessian test is inconclusive. One then studies the sign of the difference $f(x, y) - f(0, 0) = (x - y)^2 + y^4$. Both terms are nonnegative, so $f(x, y) \geq 0 = f(0, 0)$ for every $(x, y)$. A sum of two nonnegative terms vanishes only if both are zero, that is, if $y = 0$ and $x = y$, so $f(x, y) > f(0, 0)$ for every $(x, y) \neq (0, 0)$. Therefore the origin is an **absolute minimum** point.
