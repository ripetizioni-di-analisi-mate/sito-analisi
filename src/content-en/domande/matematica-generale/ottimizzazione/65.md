The function $f(x, y) = x^2 + k\,y^4$ has at the origin a stationary point with $\det H(0, 0) = 0$ for every $k \in \mathbb{R}$. What is the set of all values of $k$ for which the origin is a local minimum point?

- $k > 0$
- $k \leq 0$
- For no value of $k$, because $\det H(0, 0) = 0$
- $k \geq 0$

## Explanation

For every $k$ the origin is stationary, and the second derivatives $f_{xx} = 2$, $f_{xy} = 0$ and $f_{yy} = 12k\,y^2$ give $\det H(0, 0) = 0$, so the Hessian test is inconclusive. We then study the sign of $f(x, y) - f(0, 0) = x^2 + k\,y^4$. If $k > 0$, the difference is positive for $(x, y) \neq (0, 0)$, so the origin is a strict absolute minimum point. If $k = 0$, we have $f = x^2 \geq 0$, and the origin is a non-strict absolute minimum point, because $f$ equals $0$ on the whole $y$-axis. If $k < 0$, we have $f(0, y) = k\,y^4 < 0$ for $y \neq 0$ and $f(x, 0) = x^2 > 0$ for $x \neq 0$, so the origin is a saddle point. Therefore the origin is a local minimum point **if and only if** $k \geq 0$.
