The Hessian test does not classify the origin for $f(x, y) = x^4 + 4y^2 - y^4$. Which statement about the sign of $f$ is true?

- $f \geq 0$ on the whole plane, so the origin is an absolute minimum point
- $f$ changes sign in every disk centered at the origin, so the origin is a saddle point
- $f \geq 0$ at the points with $|y| < 2$ and $f(0, 3) < 0$, so the origin is a local minimum point but not an absolute one
- $f \leq 0$ near the origin, so the origin is a local maximum point

## Explanation

We write $f(x, y) = x^4 + y^2\,(4 - y^2)$. At the points with $|y| < 2$ the factor $4 - y^2$ is positive, so $f(x, y) \geq 0 = f(0, 0)$, with equality only at the origin. Therefore the origin is a **local minimum** point. The minimum is not absolute, because $f(0, 3) = 36 - 81 = -45 < 0$. The Hessian test is inconclusive, because $f_{xx} = 12x^2$ vanishes at the origin and hence $\det H(0, 0) = 0 \cdot 8 - 0^2 = 0$.
