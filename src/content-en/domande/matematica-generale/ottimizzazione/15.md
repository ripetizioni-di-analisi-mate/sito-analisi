For the function $f(x, y) = (x^2 + y^2 - 1)^2$, which statement about the origin is true?

- The origin is a local maximum point that is not a global maximum
- The origin is an absolute maximum point
- The origin is a local minimum point
- The origin is a saddle point

## Explanation

At the origin the function equals $f(0, 0) = 1$. For $0 < x^2 + y^2 < 1$ the expression $x^2 + y^2 - 1$ lies between $-1$ and $0$, so its square is less than $1$. Therefore in the disk centered at the origin with radius $1$ we have $f(x, y) < f(0, 0)$ for every $(x, y) \neq (0, 0)$, and the origin is a **local maximum** point. The maximum is not absolute, because for example $f(2, 0) = 9 > 1$.
