On which set does the Weierstrass theorem guarantee that $f(x, y) = x + y$ has an absolute maximum and an absolute minimum?

- $\{(x, y) : x^2 + y^2 < 1\}$
- $\{(x, y) : x \geq 0,\ y \geq 0\}$
- $\{(x, y) : 0 \leq x \leq 1\}$
- $\{(x, y) : x^2 + y^2 \leq 1\}$

## Explanation

The **Weierstrass theorem** applies to a continuous function on a closed and bounded set, and the function $x + y$ is continuous on the whole plane. The disk $x^2 + y^2 \leq 1$ is closed and bounded, so the theorem applies on it and guarantees an absolute maximum and an absolute minimum. The disk $x^2 + y^2 < 1$ is bounded but not closed, because it does not contain the circle that bounds it. The quadrant $x \geq 0$, $y \geq 0$ and the strip $0 \leq x \leq 1$ are closed but not bounded. Therefore on the other three sets the hypothesis of the theorem is not satisfied.
