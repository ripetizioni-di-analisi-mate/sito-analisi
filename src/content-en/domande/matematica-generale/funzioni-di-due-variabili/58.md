The figure shows the level curves $1$ and $4$ of a function $f$. Which function can $f$ be?

::grafico{f="1/x;4/x" xmin=-6 xmax=6 ymin=-6 ymax=6 uguale=1 legenda="f = 1;f = 4" titolo="The level curves $1$ and $4$ of $f$: the hyperbolas $y = \dfrac{1}{x}$ and $y = \dfrac{4}{x}$"}

- $f(x, y) = 2xy$
- $f(x, y) = \sqrt{xy}$
- $f(x, y) = xy$
- $f(x, y) = x^2 y$

## Explanation

For $f(x, y) = xy$ the level curve $1$ is $xy = 1$, that is, $y = \dfrac{1}{x}$, and the level curve $4$ is $xy = 4$, that is, $y = \dfrac{4}{x}$; so **$f(x, y) = xy$** has the curves in the figure. For $2xy$ the level curve $1$ is $y = \dfrac{1}{2x}$, which differs from the one drawn. For $\sqrt{xy}$ the level curve $1$ coincides with $y = \dfrac{1}{x}$, but the level curve $4$ is $xy = 16$. For $x^2 y$ the level curve $1$ is $y = \dfrac{1}{x^2}$, which lies entirely in the half-plane $y > 0$.
