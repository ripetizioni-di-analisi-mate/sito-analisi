For which values of the parameter $a > 0$ does the production function $Q(K, L) = K^{a} L^{\frac{1}{2}}$ have increasing returns to scale?

- $a > 1$
- $0 < a < \dfrac{1}{2}$
- $a \geq \dfrac{1}{2}$
- $a > \dfrac{1}{2}$

## Explanation

The function is a Cobb-Douglas function, so it is homogeneous of degree $a + \dfrac{1}{2}$. Returns to scale are increasing when the degree is greater than $1$, that is, when $a + \dfrac{1}{2} > 1$. Therefore returns are **increasing** for $a > \dfrac{1}{2}$. For $a = \dfrac{1}{2}$ the degree equals $1$ and returns are constant, while for $0 < a < \dfrac{1}{2}$ they are decreasing.
