Which of the following subsets of the plane is bounded?

- $\{ (x, y) : xy \leq 1 \}$
- $\{ (x, y) : y \geq x^2 \}$
- $\{ (x, y) : |x| + |y| \leq 3 \}$
- $\{ (x, y) : x^2 - y^2 \leq 1 \}$

## Explanation

If $|x| + |y| \leq 3$, then $|x| \leq 3$ and $|y| \leq 3$, so $x^2 + y^2 \leq 18$. Therefore the set $\{ |x| + |y| \leq 3 \}$, which is a square with its vertices on the axes, is contained in the disk of radius $\sqrt{18}$ and is **bounded**. The other three sets are unbounded. The set $xy \leq 1$ contains the whole $x$-axis, because $xy = 0$ there. The sets $y \geq x^2$ and $x^2 - y^2 \leq 1$ contain all the points $(0, y)$ with $y \geq 0$, because $y \geq 0$ and $-y^2 \leq 1$.
