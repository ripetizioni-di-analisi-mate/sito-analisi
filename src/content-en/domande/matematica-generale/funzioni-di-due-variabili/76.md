A function $f$ has the partial derivatives $f_x(0, 0)$ and $f_y(0, 0)$, but it is not continuous at the point $(0, 0)$. Which statement is true?

- $f$ is differentiable at $(0, 0)$, because it has the partial derivatives
- $f_x$ and $f_y$ are continuous in a neighborhood of $(0, 0)$
- $f_x(0, 0)$ and $f_y(0, 0)$ are necessarily zero
- $f$ is not differentiable at $(0, 0)$

## Explanation

A function differentiable at a point is continuous at that point. The function $f$ is not continuous at $(0, 0)$, so it is **not differentiable** at $(0, 0)$, even though it has both partial derivatives. If $f_x$ and $f_y$ were continuous in a neighborhood of $(0, 0)$, then by the total differential theorem $f$ would be differentiable, therefore this statement is false as well. Nothing forces the partial derivatives to be zero; for example, adding $x$ to the function $\dfrac{2xy}{x^2 + y^2}$ (with value $0$ at the origin) gives $f_x(0, 0) = 1$, and the function remains discontinuous.
