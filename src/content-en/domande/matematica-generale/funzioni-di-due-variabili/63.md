Let $f(x, y) = (x^2 + y^2) \ln(x^2 + y^2)$ for $(x, y) \neq (0, 0)$ and $f(0, 0) = a$. For which value of $a$ is $f$ continuous at $(0, 0)$?

- $a = 0$
- $a = 1$
- $a = -1$
- For no value of $a$

## Explanation

The function is continuous at $(0, 0)$ if and only if its limit as $(x, y) \to (0, 0)$ equals $f(0, 0) = a$. Set $t = x^2 + y^2$; as $(x, y) \to (0, 0)$ we have $t \to 0^+$. Therefore the limit of $f$ coincides with
$$
\lim_{t \to 0^+} t \ln t = 0 ,
$$
which follows from the comparison of infinities, writing $t \ln t = \dfrac{\ln t}{\dfrac{1}{t}}$ and applying l'Hôpital's rule. So the limit equals $0$, and the function is continuous at $(0, 0)$ for **$a = 0$**.
