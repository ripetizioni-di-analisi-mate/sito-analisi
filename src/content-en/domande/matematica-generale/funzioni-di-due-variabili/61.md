On which of the following sets does the extreme value theorem guarantee that the function $f(x, y) = x + y$ has a maximum value and a minimum value?

- $\{ (x, y) : x^2 + y^2 < 1 \}$
- $\{ (x, y) : x^2 + y^2 \leq 1 \}$
- $\{ (x, y) : x \geq 0, \ y \geq 0 \}$
- $\{ (x, y) : y \geq x^2 \}$

## Explanation

The function $x + y$ is a polynomial, so it is continuous on the whole plane. The extreme value theorem applies when the set is nonempty, closed and bounded. The disk $x^2 + y^2 \leq 1$ contains its boundary circle and is contained in a disk, so it is closed and bounded, and **the theorem applies**. The open disk $x^2 + y^2 < 1$ is bounded but not closed. The first quadrant with the axes and the region $y \geq x^2$ are closed but unbounded.
