What is $\displaystyle\lim_{(x, y) \to (0, 0)} \frac{x^2 + y^2}{\sqrt{x^2 + y^2 + 1} - 1}$?

- $1$
- $\dfrac{1}{2}$
- $0$
- $2$

## Explanation

The function depends only on $s = x^2 + y^2$, which tends to $0$ as $(x, y)$ tends to the origin. Multiplying numerator and denominator by $\sqrt{s + 1} + 1$ gives
$$
\frac{s}{\sqrt{s + 1} - 1} = \frac{s\,\big(\sqrt{s + 1} + 1\big)}{s + 1 - 1} = \sqrt{s + 1} + 1 \qquad \text{for } s \neq 0 .
$$
The function $\sqrt{s + 1} + 1$ is continuous and equals $2$ at $s = 0$, so the limit is $2$. The value $\dfrac{1}{2}$ comes from inverting the ratio.
