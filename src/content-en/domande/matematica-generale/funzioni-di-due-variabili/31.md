Which statement is true for the function $f(x, y) = \sqrt{x^2 + y^2}$ at the point $(0, 0)$?

- It is not continuous
- It has zero partial derivatives and is differentiable
- It has zero partial derivatives and is not differentiable
- It is continuous and has no partial derivatives

## Explanation

The function is the distance of the point from the origin, which tends to $0 = f(0, 0)$ as $(x, y) \to (0, 0)$, so $f$ is **continuous** at the origin. On the $x$-axis we have $f(h, 0) = |h|$, so the difference quotient $\dfrac{f(h, 0) - f(0, 0)}{h} = \dfrac{|h|}{h}$ equals $1$ for $h > 0$ and $-1$ for $h < 0$. The quotient has no limit as $h \to 0$, hence $f_x(0, 0)$ does not exist. In the same way, since $f(0, h) = |h|$, $f_y(0, 0)$ does not exist.
