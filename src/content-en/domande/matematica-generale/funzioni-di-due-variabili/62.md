Let $f(x, y) = \dfrac{1}{x^2 + y^2}$ on the set $D = \{ (x, y) : 0 < x^2 + y^2 \leq 1 \}$. Which statement is true?

- $f$ has maximum $1$ and has no minimum
- $f$ has a maximum and a minimum, by the extreme value theorem
- $f$ has minimum $1$ and has no maximum
- $f$ has neither a maximum nor a minimum

## Explanation

Set $t = x^2 + y^2$, which on $D$ ranges over the interval $(0, 1]$, so that $f = \dfrac{1}{t}$. Since $t \leq 1$, we get $f \geq 1$, and the value $1$ is attained on the circle $x^2 + y^2 = 1$, which belongs to $D$; so the minimum is $1$. As $(x, y) \to (0, 0)$ we have $t \to 0^+$ and $f \to +\infty$, therefore $f$ is not bounded above and **has no maximum**. The extreme value theorem does not apply, because $D$ does not contain the origin, which is one of its boundary points, and hence $D$ is not closed.
