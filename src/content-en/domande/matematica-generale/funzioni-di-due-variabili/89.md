For the production function $Q(K, L) = 2\,K^{\frac{3}{4}} L^{\frac{1}{4}}$, what is output per unit of labor $\dfrac{Q}{L}$ when $K = 16\,L$?

- $8$
- $16$
- $4$
- $32$

## Explanation

Dividing by $L = L^{\frac{3}{4}} L^{\frac{1}{4}}$ gives
$$
\frac{Q}{L} = 2\,\frac{K^{\frac{3}{4}} L^{\frac{1}{4}}}{L^{\frac{3}{4}} L^{\frac{1}{4}}} = 2 \left( \frac{K}{L} \right)^{\frac{3}{4}} .
$$
Output per unit of labor therefore depends only on the ratio $\dfrac{K}{L}$, because the function has constant returns to scale. With $\dfrac{K}{L} = 16$ we have $16^{\frac{3}{4}} = \left( 16^{\frac{1}{4}} \right)^{3} = 2^3 = 8$, so $\dfrac{Q}{L} = 2 \cdot 8 = 16$.
