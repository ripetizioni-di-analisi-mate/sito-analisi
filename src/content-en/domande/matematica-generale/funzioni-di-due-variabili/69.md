For which value of $a$ does there exist a function $f$, defined on the whole plane and with continuous second derivatives, such that $f_x(x, y) = 2xy + ay$ and $f_y(x, y) = x^2 + 3x$?

- $a = 1$
- $a = 3$
- $a = -3$
- $a = 2$

## Explanation

If such an $f$ exists, its mixed derivatives are continuous on the plane, which is open, so by **Schwarz's theorem** $f_{xy} = f_{yx}$. We have $f_{xy} = (f_x)_y = 2x + a$ and $f_{yx} = (f_y)_x = 2x + 3$. The equality $2x + a = 2x + 3$ for every $x$ requires $a = 3$. For $a = 3$ the function $f(x, y) = x^2 y + 3xy$ has exactly the given partial derivatives, so the required value is **$a = 3$**.
