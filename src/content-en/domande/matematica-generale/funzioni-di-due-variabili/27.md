For the function $f(x, y) = x^{y}$, defined for $x > 0$, what is $f_y(2, 3)$?

- $12$
- $8 \ln 2$
- $8$
- $8 \ln 3$

## Explanation

When computing $f_y$ the variable $x$ is a constant, so $x^{y} = e^{y \ln x}$ is an exponential function of $y$. Therefore
$$
f_y(x, y) = x^{y} \ln x ,
$$
and at the point $(2, 3)$ we get $f_y(2, 3) = 2^3 \ln 2 = 8 \ln 2$. The value $12$ is $f_x(2, 3)$, obtained with the power rule $f_x = y\,x^{y - 1}$, which holds only for the derivative with respect to $x$.
