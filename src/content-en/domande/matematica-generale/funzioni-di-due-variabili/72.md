For which value of $a$ does the function $f(x, y) = x^3 + axy^2$ satisfy $f_{xx}(x, y) + f_{yy}(x, y) = 0$ at every point of the plane?

- $a = 3$
- $a = -1$
- $a = -6$
- $a = -3$

## Explanation

We have $f_x = 3x^2 + ay^2$, so $f_{xx} = 6x$. Moreover $f_y = 2axy$, so $f_{yy} = 2ax$. The sum is
$$
f_{xx} + f_{yy} = 6x + 2ax = (6 + 2a)\,x ,
$$
which is zero for every $x$ if and only if $6 + 2a = 0$. Therefore **$a = -3$**.
