The IRR of an investment belongs to the interval $[0;\ 0.16]$ and is approximated with the bisection method. What is the minimum number of steps after which the interval containing the IRR has width less than $0.001$?

- $7$
- $8$
- $16$
- $160$

## Explanation

Each step of the bisection method halves the width of the interval, so after $n$ steps the width is $\dfrac{0.16}{2^{n}}$. The condition $\dfrac{0.16}{2^{n}} < 0.001$ is equivalent to $2^{n} > 160$. Since $2^{7} = 128$ and $2^{8} = 256$, the minimum number of steps is $8$. After $7$ steps the width is $\dfrac{0.16}{128} = 0.00125$, which still exceeds $0.001$.
