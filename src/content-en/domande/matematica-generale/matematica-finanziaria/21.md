With commercial discount at the annual rate $d = 8\%$, for which durations $t$, measured in years, is the present value $V = M\,(1 - d\,t)$ of an amount $M > 0$ positive?

- $0 \leq t < 1$
- $0 \leq t \leq 12.5$
- $0 \leq t < 8$
- $0 \leq t < 12.5$

## Explanation

Since $M > 0$, the present value is positive if and only if $1 - d\,t > 0$, that is, $t < \dfrac{1}{d}$. With $d = 0.08$ one has $\dfrac{1}{d} = \dfrac{1}{0.08} = 12.5$, so the present value is positive for $0 \leq t < 12.5$. For $t = 12.5$ the discount $D = M\,d\,t$ equals $M$ and the present value is zero, therefore the endpoint $12.5$ is excluded. Commercial discount is used in practice for short transactions, but the positivity of the present value only requires $t < 12.5$.
