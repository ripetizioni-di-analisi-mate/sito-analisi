The function $f$ equals $\dfrac{e^{2x} - 1}{x}$ for $x \neq 0$ and $k$ for $x = 0$. For which value of $k$ is the function continuous at $x = 0$?

- $k = 2$
- $k = 1$
- $k = 0$
- $k = \dfrac{1}{2}$

## Explanation

The function is continuous at $0$ if and only if $\displaystyle\lim_{x \to 0} f(x) = f(0) = k$. For $x \neq 0$ we write
$$
\frac{e^{2x} - 1}{x} = 2 \cdot \frac{e^{2x} - 1}{2x} .
$$
By the **standard exponential limit**, with $t = 2x \to 0$, the second factor tends to $1$, so the limit equals $2$. Therefore the function is continuous at $0$ if and only if $k = 2$.
