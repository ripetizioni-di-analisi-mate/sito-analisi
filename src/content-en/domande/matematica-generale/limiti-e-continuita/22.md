The function $f$ is continuous on the interval $[1, 4]$; its minimum value on $[1, 4]$ is $2$ and its maximum value is $7$. Which of the following values is certainly taken by $f$ at some point of $[1, 4]$?

- $1$
- $8$
- $\dfrac{3}{2}$
- $5$

## Explanation

Since the minimum is $2$ and the maximum is $7$, there are two points $x_1$ and $x_2$ of $[1, 4]$ with $f(x_1) = 2$ and $f(x_2) = 7$. The function is continuous on the closed interval with endpoints $x_1$ and $x_2$, so by the **intermediate value theorem** it takes every value between $2$ and $7$. Therefore it takes the value $5$. The values $1$, $\dfrac{3}{2}$ and $8$ do not belong to $[2, 7]$, so $f$ does not take them, because $2 \leq f(x) \leq 7$ for every $x \in [1, 4]$.
