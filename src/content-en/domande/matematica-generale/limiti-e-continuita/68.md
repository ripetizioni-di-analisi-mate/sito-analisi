Which line is an oblique asymptote of the function $f(x) = \sqrt{x^2 + 4x}$ as $x \to -\infty$?

- $y = x + 2$
- $y = -x + 2$
- $y = -x - 2$
- $y = -x$

## Explanation

For $x < 0$ we have $\sqrt{x^2} = |x| = -x$, so $f(x) = -x\,\sqrt{1 + \dfrac{4}{x}}$ and $m = \displaystyle\lim_{x \to -\infty} \frac{f(x)}{x} = -1$. To find $q$ we compute the limit of $f(x) + x$, which has the form $+\infty - \infty$, by rationalizing:
$$
\sqrt{x^2 + 4x} + x = \frac{4x}{\sqrt{x^2 + 4x} - x} = \frac{4x}{-x\left( \sqrt{1 + \dfrac{4}{x}} + 1 \right)} = \frac{-4}{\sqrt{1 + \dfrac{4}{x}} + 1} .
$$
The last expression tends to $-2$, so $q = -2$ and the left oblique asymptote is $y = -x - 2$.
