Which lines are vertical asymptotes of the function $f(x) = \dfrac{x^2 - 9}{x^2 - x - 6}$?

- Only $x = 3$
- $x = -2$ and $x = 3$
- $x = 2$ and $x = -3$
- Only $x = -2$

## Explanation

The denominator factors as $x^2 - x - 6 = (x - 3)(x + 2)$, so the function is not defined at $x = 3$ and at $x = -2$. Since $x^2 - 9 = (x - 3)(x + 3)$, for $x \neq 3$ we have $f(x) = \dfrac{x + 3}{x + 2}$. As $x \to 3$ we therefore obtain the finite limit $\dfrac{6}{5}$, hence $x = 3$ is not an asymptote. As $x \to -2$ the numerator tends to $1$ and the denominator to $0$, so $f$ tends to $\pm\infty$ and only the line $x = -2$ is a **vertical asymptote**.
