For the function $f(x) = \dfrac{x^2 + |x|}{x}$, which statement is true?

- The limit as $x \to 0$ does not exist, because the right-hand limit is $1$ and the left-hand limit is $-1$
- The limit as $x \to 0$ equals $1$
- The limit as $x \to 0$ equals $0$, because the numerator tends to $0$
- At $x = 0$ the function has a removable discontinuity

## Explanation

For $x > 0$ we have $|x| = x$, so $f(x) = \dfrac{x^2 + x}{x} = x + 1$, which tends to $1$ as $x \to 0^{+}$. For $x < 0$ we have $|x| = -x$, so $f(x) = \dfrac{x^2 - x}{x} = x - 1$, which tends to $-1$ as $x \to 0^{-}$. The right-hand limit and the left-hand limit differ, so the limit as $x \to 0$ **does not exist**. For the same reason the discontinuity at $0$ is a jump discontinuity and is not removable.
