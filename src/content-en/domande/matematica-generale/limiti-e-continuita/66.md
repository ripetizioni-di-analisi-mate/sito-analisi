Which asymptotes does the graph of the function $f(x) = \ln(x - 2) + 1$ have?

- Only the vertical asymptote $x = 2$
- The vertical asymptote $x = 2$ and the horizontal asymptote $y = 1$
- Only the vertical asymptote $x = 3$
- The vertical asymptote $x = 2$ and the oblique asymptote $y = x - 1$

## Explanation

The function is defined for $x > 2$. As $x \to 2^+$ the argument $x - 2$ tends to $0^+$, so $\ln(x - 2) \to -\infty$ and the line $x = 2$ is a **vertical asymptote**. As $x \to +\infty$ we have $f(x) \to +\infty$, so there is no horizontal asymptote. Moreover $\dfrac{f(x)}{x} \to 0$ by the hierarchy of growth rates, so $m = 0$ and there is no oblique asymptote either.
