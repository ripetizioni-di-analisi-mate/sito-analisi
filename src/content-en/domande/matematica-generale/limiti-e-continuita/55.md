The function $f$ is defined on the interval $[0, 2]$ and equals $x^2$ for $0 \leq x < 2$ and $1$ for $x = 2$. Which statement is true?

- It has minimum $0$ and maximum $4$
- It has minimum $0$ and no maximum
- It has minimum $0$ and maximum $1$
- It has neither a minimum nor a maximum

## Explanation

For $0 \leq x < 2$ we have $0 \leq x^2 < 4$, and moreover $f(2) = 1$, so $f(x) \geq 0 = f(0)$ for every $x \in [0, 2]$ and the **minimum** is $0$. As $x \to 2^{-}$ we have $f(x) \to 4$, therefore the function takes values as close to $4$ as we like, but never the value $4$, since $f(2) = 1$. Hence the function **has no maximum**. The extreme value theorem does not apply, because $f$ is not continuous at $x = 2$.
