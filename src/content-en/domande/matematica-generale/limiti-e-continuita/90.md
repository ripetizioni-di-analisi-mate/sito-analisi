Which of the following functions has an oblique asymptote as $x \to +\infty$?

- $f(x) = \dfrac{x^2 + 1}{x^2 - 1}$
- $f(x) = \dfrac{x^3}{x + 1}$
- $f(x) = \ln x$
- $f(x) = \dfrac{x^3 + 1}{x^2}$

## Explanation

We have $\dfrac{x^3 + 1}{x^2} = x + \dfrac{1}{x^2}$, so $f(x) - x \to 0$ and the line $y = x$ is an **oblique asymptote**. For $\dfrac{x^2 + 1}{x^2 - 1}$ the degrees are equal, so $f(x) \to 1$ and there is a horizontal asymptote. For $\dfrac{x^3}{x + 1}$ we have $\dfrac{f(x)}{x} = \dfrac{x^2}{x + 1} \to +\infty$, so $m$ is not finite. For $\ln x$ we have $\dfrac{\ln x}{x} \to 0$, so $m = 0$, while $\ln x \to +\infty$, therefore there is neither an oblique nor a horizontal asymptote.
