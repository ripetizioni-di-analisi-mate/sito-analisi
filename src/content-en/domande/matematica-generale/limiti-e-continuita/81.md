Which statement about the function $f(x) = \dfrac{1}{1 + x^2}$ on the interval $[0, +\infty)$ is true?

::grafico{legenda=0 f="1/(1+x^2)+0*sqrt(x)" punti="0,1,pieno" xmin=-1 xmax=8 ymin=-1 ymax=2 titolo="The graph of $f(x) = \dfrac{1}{1 + x^2}$ for $x \geq 0$"}

- It has maximum $1$ and minimum $0$
- It has neither a maximum nor a minimum, because the interval is unbounded
- It has minimum $0$ but no maximum
- It has maximum $1$ but no minimum

## Explanation

The interval $[0, +\infty)$ is unbounded, so the extreme value theorem does not apply and the existence of a maximum and a minimum must be studied directly. For $x \geq 0$ we have $1 + x^2 \geq 1$, so $f(x) \leq 1 = f(0)$, and the **maximum** is $1$. Moreover $f(x) > 0$ for every $x$ and $f(x) \to 0$ as $x \to +\infty$, therefore the function takes values as close to $0$ as we like but never the value $0$. Hence the function **has no minimum**.
