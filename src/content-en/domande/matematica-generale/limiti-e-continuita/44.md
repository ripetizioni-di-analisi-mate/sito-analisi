The function $f(x) = \dfrac{1}{x}$ takes values of opposite sign at the endpoints of the interval $[-1, 1]$, because $f(-1) = -1$ and $f(1) = 1$, but it does not vanish at any point. Which statement is true?

- $f$ is not continuous on $[-1, 1]$, so the intermediate zero theorem does not apply
- The intermediate zero theorem applies, so $f$ vanishes at a point of $(-1, 1)$
- $f(-1)$ and $f(1)$ have the same sign, so the intermediate zero theorem does not apply
- The function $f$ is a counterexample showing that the intermediate zero theorem is false

## Explanation

The **intermediate zero theorem** requires the function to be continuous on the closed interval $[a, b]$ and $f(a)$ and $f(b)$ to have opposite signs. The second hypothesis is satisfied, because $f(-1) = -1 < 0$ and $f(1) = 1 > 0$. The function $\dfrac{1}{x}$ is not defined at $x = 0$, which belongs to $[-1, 1]$, so the first hypothesis is not satisfied and the theorem does not apply. Therefore the absence of zeros does not contradict the theorem.
