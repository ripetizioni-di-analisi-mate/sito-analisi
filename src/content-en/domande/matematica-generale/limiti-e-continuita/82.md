What is the set of values taken by the function $f(x) = x^2 - 2x$ on the interval $[0, 3]$?

- $[-1, 3]$
- $[0, 3]$
- $[-1, 0]$
- $(-1, 3)$

## Explanation

We write $f(x) = (x - 1)^2 - 1$, so $f(x) \geq -1$ and the minimum is $f(1) = -1$. On the interval $[0, 3]$ the distance $|x - 1|$ is at most $2$, so $f(x) \leq 4 - 1 = 3$, and the maximum is $f(3) = 3$. The function is continuous, so by the **intermediate value theorem** applied on $[1, 3]$ it takes every value between $-1$ and $3$. Therefore the set of values is the closed interval $[-1, 3]$.
