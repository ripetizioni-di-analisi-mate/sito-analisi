As $x \to +\infty$ the functions $f$ and $g$ both tend to $+\infty$. For which of the following pairs does the difference $f(x) - g(x)$ tend to $5$?

- $f(x) = x + 5$, $g(x) = x$
- $f(x) = 5x$, $g(x) = x$
- $f(x) = x + 5$, $g(x) = x - 5$
- $f(x) = \sqrt{x^2 + 5}$, $g(x) = x$

## Explanation

For $f(x) = x + 5$ and $g(x) = x$ the difference equals $5$ for every $x$, so it tends to $5$. For $5x$ and $x$ the difference is $4x$, which tends to $+\infty$. For $x + 5$ and $x - 5$ the difference equals $10$. For the last pair, rationalizing gives $\sqrt{x^2 + 5} - x = \dfrac{5}{\sqrt{x^2 + 5} + x}$, which tends to $0$. These examples show that when two functions tend to $+\infty$ their difference can have different limits, therefore $+\infty - \infty$ is an **indeterminate form**.
