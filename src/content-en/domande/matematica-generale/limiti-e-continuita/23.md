For which value of the real parameter $k$ is the limit $\displaystyle\lim_{x \to 1} \frac{x^2 + kx - 3}{x - 1}$ finite?

- $k = -2$
- $k = 3$
- $k = 2$
- $k = 4$

## Explanation

The denominator tends to $0$. If the numerator tends to a value different from $0$, the one-sided limits of the quotient are $\pm\infty$, so the limit can be finite only if the numerator vanishes at $x = 1$. This occurs if $1 + k - 3 = 0$, that is, if $k = 2$. In this case $x^2 + 2x - 3 = (x - 1)(x + 3)$, so for $x \neq 1$ the quotient equals $x + 3$ and the limit is $4$, which is finite.
