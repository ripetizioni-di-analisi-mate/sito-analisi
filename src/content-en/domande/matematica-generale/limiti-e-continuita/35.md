The function $f$ equals $\dfrac{x^2 + x - 6}{x - 2}$ for $x \neq 2$ and $3$ for $x = 2$. What type of discontinuity does it have at $x = 2$?

- Removable
- Jump discontinuity of size $2$
- Of the second kind
- None. The function is continuous at $x = 2$

## Explanation

The numerator factors as $x^2 + x - 6 = (x - 2)(x + 3)$, so for $x \neq 2$ we have $f(x) = x + 3$. Therefore the limit as $x \to 2$ exists and equals $5$. The value $f(2) = 3$ is different from the limit, so the function is not continuous at $x = 2$. Since the limit exists and is finite, the discontinuity is **removable**, and redefining $f(2) = 5$ makes the function continuous. A jump discontinuity has different right-hand and left-hand limits, whereas here both equal $5$.
