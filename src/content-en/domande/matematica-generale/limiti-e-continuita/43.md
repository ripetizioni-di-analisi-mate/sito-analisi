On which of the following intervals does the function $f(x) = \dfrac{1}{x - 2}$ satisfy the hypotheses of the extreme value theorem?

- $[0, 3]$
- $(2, 4]$
- $[3, 5]$
- $[3, +\infty)$

## Explanation

The **extreme value theorem** requires a function that is continuous on a closed and bounded interval. The function $f$ is continuous at every point other than $2$. The interval $[0, 3]$ contains $2$, so $f$ is not continuous on it. The interval $(2, 4]$ is not closed, and indeed $f$ tends to $+\infty$ as $x \to 2^{+}$ and has no maximum. The interval $[3, +\infty)$ is unbounded. On $[3, 5]$, the function $f$ is continuous and the interval is closed and bounded. All the hypotheses hold.
