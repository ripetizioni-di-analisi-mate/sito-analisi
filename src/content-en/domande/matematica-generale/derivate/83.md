For which value of $a$ does the function $f(x) = x^{2} + ax$ satisfy all the hypotheses of Rolle's theorem on the interval $[0, 3]$?

- $a = -3$
- $a = 3$
- $a = 0$
- $a = -9$

## Explanation

The function is a polynomial, so it is continuous on $[0, 3]$ and differentiable on $(0, 3)$ for every $a$. The remaining hypothesis is $f(0) = f(3)$. One has $f(0) = 0$ and $f(3) = 9 + 3a$, so the condition is $9 + 3a = 0$, that is, $a = -3$. In this case $f'(x) = 2x - 3$ vanishes at $c = \dfrac{3}{2}$, which is interior to the interval.
