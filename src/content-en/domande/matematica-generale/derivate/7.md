- $f'(x) = \dfrac{x}{\sqrt{x^2 + 9}}$
- $f'(x) = \dfrac{1}{2\sqrt{x^2 + 9}}$
- $f'(x) = \dfrac{2x}{\sqrt{x^2 + 9}}$
- $f'(x) = \dfrac{x}{2\sqrt{x^2 + 9}}$

## Explanation

Since $x^2 + 9 > 0$ for every $x$, the function is defined and differentiable on all of $\mathbb{R}$. It is a composite function, with outer function $\sqrt{t}$, whose derivative is $\dfrac{1}{2\sqrt{t}}$, and inner function $x^2 + 9$, whose derivative is $2x$. By the **composite function rule** one therefore has
$$
f'(x) = \frac{1}{2\sqrt{x^2 + 9}} \cdot 2x .
$$
Canceling the factor $2$ gives $f'(x) = \dfrac{x}{\sqrt{x^2 + 9}}$.
