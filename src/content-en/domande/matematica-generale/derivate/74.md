The function $f$ is differentiable on $\mathbb{R}$, with $f(0) = 1$ and $|f'(x)| \leq 3$ for every $x$. What is the largest value that $f(2)$ can take?

- $6$
- $4$
- $7$
- $9$

## Explanation

The function is continuous on $[0, 2]$ and differentiable on $(0, 2)$, so the **mean value theorem** applies. Hence there exists $c \in (0, 2)$ with $f(2) - f(0) = f'(c) \cdot 2$. Since $f'(c) \leq 3$, we get $f(2) \leq 1 + 3 \cdot 2 = 7$. The value $7$ is attained by $f(x) = 1 + 3x$, which satisfies the hypotheses. The value $6$ forgets $f(0)$, and the value $4$ uses the increment $1$ instead of $2$.
