What is the set of values of the real parameter $a$ for which the function $f(x) = x^3 + ax$ is increasing on all of $\mathbb{R}$?

- $a \leq 0$
- $a \geq -3$
- $a \geq 0$
- Every real $a$

## Explanation

The derivative is $f'(x) = 3x^2 + a$.

If $a \geq 0$, then $f'(x) \geq 0$ and it vanishes at most at $x = 0$, so $f$ is increasing on $\mathbb{R}$; for $a = 0$ one gets $x^3$, which is increasing.

If $a < 0$, then $f'(x) < 0$ for $|x| < \sqrt{-\dfrac{a}{3}}$, so $f$ decreases in a neighborhood of $0$. For example with $a = -3$ the derivative $3x^2 - 3$ is negative on $(-1, 1)$. Therefore the required set is $a \geq 0$.
