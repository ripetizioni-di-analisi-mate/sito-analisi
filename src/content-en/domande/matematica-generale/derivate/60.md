What is the derivative of $f(x) = \left| x^{2} - 4 \right|$ at the point $x_0 = 1$?

- $2$
- $3$
- The derivative does not exist, because $f$ contains an absolute value
- $-2$

## Explanation

For $-2 < x < 2$ we have $x^{2} - 4 < 0$, so on this interval $f(x) = -\left( x^{2} - 4 \right) = 4 - x^{2}$. The point $1$ is interior to the interval, so near $1$ the function coincides with the polynomial $4 - x^{2}$ and is differentiable. Hence $f'(x) = -2x$ and $f'(1) = -2$. The function $f$ fails to be differentiable only at the points $-2$ and $2$, where $x^{2} - 4$ vanishes and changes sign. The value $2$ comes from differentiating $x^{2} - 4$ without taking the sign into account, and the value $3$ is $f(1)$.
