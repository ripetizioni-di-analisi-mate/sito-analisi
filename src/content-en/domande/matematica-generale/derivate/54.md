For which base $a > 0$ does the function $f(x) = a^{x}$ have derivative equal to $2$ at the point $x_0 = 0$?

- $a = e^{2}$
- $a = 2$
- $a = \ln 2$
- $a = \sqrt{e}$

## Explanation

The derivative of $a^{x}$ is $a^{x} \ln a$, so $f'(0) = a^{0} \ln a = \ln a$. The condition $f'(0) = 2$ becomes $\ln a = 2$, hence $a = e^{2}$. For $a = 2$ one has $f'(0) = \ln 2 \approx 0.69$, and for $a = \sqrt{e}$ one has $f'(0) = \dfrac{1}{2}$.
