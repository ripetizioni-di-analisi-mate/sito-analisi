The polynomial $P(x) = ax^{2} + bx + c$ has $P(0) = 1$, $P'(0) = 2$ and $P''(0) = 6$. Which polynomial is it?

- $P(x) = 6x^{2} + 2x + 1$
- $P(x) = 3x^{2} + 2x + 1$
- $P(x) = x^{2} + 2x + 6$
- $P(x) = 3x^{2} + x + 1$

## Explanation

We have $P'(x) = 2ax + b$ and $P''(x) = 2a$. Hence $P(0) = c$, $P'(0) = b$ and $P''(0) = 2a$. The conditions give $c = 1$, $b = 2$ and $2a = 6$, so $a = 3$ and $P(x) = 3x^{2} + 2x + 1$. The polynomial $6x^{2} + 2x + 1$ comes from setting $a = P''(0)$ without dividing by $2$.
