The function $f(x) = x^{x}$, for $x > 0$, has the variable both in the base and in the exponent. Which expression does $f'(x)$ have?

- $f'(x) = x^{x}$
- $f'(x) = x^{x} (\ln x + 1)$
- $f'(x) = x^{x} \ln x$
- $f'(x) = \ln x + 1$

## Explanation

The variable appears both in the base and in the exponent, so neither the power rule nor the formula for exponentials applies directly. Since $x = e^{\ln x}$, we write $f(x) = e^{x \ln x}$. By the chain rule and the product rule
$$
f'(x) = e^{x \ln x} \left( \ln x + x \cdot \frac{1}{x} \right) = x^{x} (\ln x + 1) .
$$
The result $x^{x}$ comes from treating the exponent as a constant, that is, $x \cdot x^{x - 1}$, and the result $x^{x} \ln x$ from treating the base as a constant.
