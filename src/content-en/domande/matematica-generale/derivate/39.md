For $f(x) = \sqrt{x}$ on the interval $[1, 4]$, which point $c$ satisfies the conclusion of the mean value theorem?

- $c = \dfrac{9}{4}$
- $c = \dfrac{5}{2}$
- $c = \dfrac{3}{2}$
- $c = \dfrac{4}{9}$

## Explanation

The function $\sqrt{x}$ is continuous on $[1, 4]$ and differentiable on $(1, 4)$, so the hypotheses of the **mean value theorem** are satisfied. The slope of the secant through the endpoints is $\dfrac{\sqrt{4} - \sqrt{1}}{4 - 1} = \dfrac{1}{3}$. Since $f'(c) = \dfrac{1}{2\sqrt{c}}$, the equation $\dfrac{1}{2\sqrt{c}} = \dfrac{1}{3}$ gives $\sqrt{c} = \dfrac{3}{2}$, that is, $c = \dfrac{9}{4}$. This point lies in the interval $(1, 4)$.
