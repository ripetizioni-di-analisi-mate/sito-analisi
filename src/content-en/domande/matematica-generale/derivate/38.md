For which of the following functions does Rolle's theorem apply on the interval $[-1, 1]$?

- $|x|$
- $x^3$
- $\dfrac{1}{x^2}$
- $x^4 - x^2$

## Explanation

Rolle's theorem requires the function to be continuous on $[-1, 1]$, differentiable on $(-1, 1)$ and to take the same value at the endpoints. The function $x^4 - x^2$ is a polynomial, so it is continuous and differentiable everywhere, and it equals $0$ both at $-1$ and at $1$; hence **Rolle's theorem** applies. The function $|x|$ takes the same value at the endpoints, but it is not differentiable at $0$. The function $x^3$ equals $-1$ at $-1$ and $1$ at $1$, and the function $\dfrac{1}{x^2}$ is not defined at $0$, so it is not continuous on $[-1, 1]$.
