Let $A$ be a square matrix of order $3$ such that the homogeneous system $A x = 0$ has the solution $(1, 2, -1)$. Which statement is true?

- $\det A \neq 0$, and $(1, 2, -1)$ is the only solution of the system
- $\det A = 0$, and $(1, 2, -1)$ is the only nonzero solution
- For every vector $b$ the system $A x = b$ has exactly one solution
- $\det A = 0$, and $(-2, -4, 2)$ is also a solution of the system

## Explanation

The homogeneous system has the solution $(1, 2, -1)$, which is not the zero solution. A square homogeneous system has nonzero solutions if and only if $\det A = 0$, so $\det A = 0$. Denoting by $v$ the vector $(1, 2, -1)$, by the compatibility of the product with scalars we have
$$
A\,(-2v) = -2\,(A v) = -2 \cdot 0 = 0 ,
$$
therefore $-2v = (-2, -4, 2)$ is also a solution. In the same way every multiple $t\,v$ is a solution, and hence there are infinitely many solutions. Since $\det A = 0$, Cramer's rule does not apply, and already for $b = 0$ the system $A x = b$ has infinitely many solutions.
