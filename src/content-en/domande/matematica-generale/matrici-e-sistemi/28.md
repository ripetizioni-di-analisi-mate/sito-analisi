A square matrix $A$ is called skew-symmetric if $A^{T} = -A$. Let $A$ be a skew-symmetric matrix of order $3$. Which statement about $\det A$ is true?

- $\det A$ can take any real value
- $\det A = 0$ for every choice of $A$
- $\det A > 0$ for every $A$ other than the zero matrix
- $\det A = -1$ for every $A$ other than the zero matrix

## Explanation

The determinant of a matrix equals that of its transpose, so $\det A = \det A^{T} = \det(-A)$. Since $A$ has order $3$, $\det(-A) = (-1)^{3} \det A = -\det A$. It follows that $\det A = -\det A$, that is, $2 \det A = 0$, and therefore $\det A = 0$ for every skew-symmetric matrix of order $3$.

The argument uses the fact that the order is odd. For order $2$ the skew-symmetric matrix $\begin{pmatrix} 0 & a \\ -a & 0 \end{pmatrix}$ has determinant $a^{2}$, which is positive for $a \neq 0$.
