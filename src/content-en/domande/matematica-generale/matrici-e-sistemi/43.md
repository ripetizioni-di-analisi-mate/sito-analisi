For which values of the real parameter $k$ is the system
$$
\begin{cases}
k x + 2y = 2 \\[4pt]
2x + k y = k
\end{cases}
$$
inconsistent?

- For $k = -2$
- For $k = 2$
- For no value of $k$
- For $k = 2$ and for $k = -2$

## Explanation

The determinant of the coefficient matrix is $k^2 - 4$, so for $k \neq \pm 2$ the system is determinate by Cramer's rule. For $k = 2$ both equations coincide with $2x + 2y = 2$, therefore $\operatorname{rk} A = \operatorname{rk}(A \mid b) = 1$. For $k = -2$ the equations are $-2x + 2y = 2$ and $2x - 2y = -2$, and the second is the first multiplied by $-1$, constant term included; hence in this case too $\operatorname{rk} A = \operatorname{rk}(A \mid b) = 1$. By the Rouché-Capelli theorem the system is indeterminate both for $k = 2$ and for $k = -2$. Therefore the system is consistent for every value of $k$, and it is inconsistent **for no value** of $k$.
