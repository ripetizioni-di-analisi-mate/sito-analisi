Consider a linear system of $2$ equations in $3$ unknowns. Which statement is true?

- The system always has infinitely many solutions
- The system cannot have exactly one solution
- If the system is homogeneous, it has only the zero solution
- If $\operatorname{rk} A = 1$, the system is inconsistent

## Explanation

The coefficient matrix is $2 \times 3$, so $\operatorname{rk} A \leq 2 < 3$. By the **Rouché–Capelli theorem**, if the system is consistent its solutions are $\infty^{3 - r}$ with $r \leq 2$, so there are infinitely many, and the system never has exactly one solution. The system can however be inconsistent, like the one formed by $x + y + z = 1$ and $x + y + z = 2$, so it does not always have infinitely many solutions. A homogeneous system is consistent, and by the above it has infinitely many solutions. Finally, with $\operatorname{rk} A = 1$ the system can be consistent, like the one formed by $x + y + z = 1$ and $2x + 2y + 2z = 2$.
