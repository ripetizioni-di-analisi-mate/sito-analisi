Let $A$ be a nonzero $2 \times 4$ matrix. Which values can $\operatorname{rk} A$ take?

- Any value from $1$ to $4$
- Only $2$
- Only $1$ or $2$
- Only $0$, $1$ or $2$

## Explanation

The rank of an $m \times n$ matrix does not exceed $\min(m, n)$, so $\operatorname{rk} A \leq \min(2, 4) = 2$. Since $A$ is not the zero matrix, it has a nonzero entry, which is a nonzero minor of order $1$. Therefore $\operatorname{rk} A \geq 1$. Both values occur, because
$$
\begin{pmatrix} 1 & 0 & 0 & 0 \\ 0 & 0 & 0 & 0 \end{pmatrix}
$$
has rank $1$, while
$$
\begin{pmatrix} 1 & 0 & 0 & 0 \\ 0 & 1 & 0 & 0 \end{pmatrix}
$$
has the minor $\begin{vmatrix} 1 & 0 \\ 0 & 1 \end{vmatrix} = 1 \neq 0$ and hence rank $2$.
