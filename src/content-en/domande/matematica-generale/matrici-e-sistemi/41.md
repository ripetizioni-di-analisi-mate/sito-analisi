For which values of the real parameter $k$ does the homogeneous system
$$
\begin{cases}
k x + y + z = 0 \\[4pt]
x + k y + z = 0 \\[4pt]
x + y + k z = 0
\end{cases}
$$
have solutions other than the zero solution?

- Only for $k = 1$
- For $k = -1$ and for $k = 2$
- For every value of $k$
- For $k = 1$ and for $k = -2$

## Explanation

A homogeneous system is always consistent, and by the Rouché-Capelli theorem it has nonzero solutions if and only if $\operatorname{rk} A < 3$, that is, since it is square, if and only if $\det A = 0$. With Sarrus's rule
$$
\det A = (k^3 + 1 + 1) - (k + k + k) = k^3 - 3k + 2 = (k - 1)^2 (k + 2) .
$$
The determinant vanishes for $k = 1$ and for $k = -2$, so the system has **nonzero solutions** exactly for these two values. For the other values of $k$ the only solution is the zero solution.
