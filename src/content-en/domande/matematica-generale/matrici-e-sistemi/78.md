Let $p$ and $q$ be two solutions of the same linear system $A x = b$, with $b$ different from the zero vector. Which of the following vectors is a solution of the system $A x = b$?

- $2p - q$
- $p + q$
- $p - q$
- $2p$

## Explanation

By hypothesis $A p = b$ and $A q = b$. By the distributive property and the compatibility of the product with scalars,
$$
A\,(2p - q) = 2\,A p - A q = 2b - b = b ,
$$
so $2p - q$ is a solution. The same computation gives $A\,(p + q) = 2b$ and $A\,(2p) = 2b$, which differ from $b$ because $b$ is not zero. Finally $A\,(p - q) = b - b = 0$, therefore $p - q$ is a solution of the homogeneous system $A x = 0$ and not of the system $A x = b$.
