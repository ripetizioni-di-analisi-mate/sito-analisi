A spreadsheet displays $\bigl(1+\dfrac1n\bigr)^n$ to four decimal places. It shows the same value for two consecutive indices. Given that the sequence is strictly increasing, which check distinguishes rounding from equality?

- Multiply the already rounded values by ten.
- Count the matching digits on the screen.
- Compare the difference between the two exact values with zero.
- Compare only the integer parts.

## Explanation

Strict increase guarantees that the exact difference is positive. If both values fall in the same rounding interval, the display shows the same digits. Multiplying the rounded numbers preserves the loss of precision.
