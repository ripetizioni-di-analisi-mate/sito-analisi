For which real values of $x$ does the series $\displaystyle\sum_{k=0}^{\infty} (2x - 1)^{k}$ converge?

- $0 < x < 1$
- $-1 < x < 1$
- $0 \leq x \leq 1$
- $x < 1$

## Explanation

The series is a **geometric series** with first term $1$ and common ratio $q = 2x - 1$.

A geometric series converges if and only if $-1 < q < 1$, so this series converges if and only if $-1 < 2x - 1 < 1$. Adding $1$ gives $0 < 2x < 2$, that is, $0 < x < 1$.

For $x = 0$ the common ratio is $-1$, and the partial sums have neither a finite nor an infinite limit. For $x = 1$ the ratio is $1$, and the series diverges to infinity.
