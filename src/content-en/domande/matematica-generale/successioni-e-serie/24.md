Which of the following sequences, with $n \geq 1$, is bounded above but not bounded below?

- $a_n = 4n - n^2$
- $a_n = n^2 - 4n$
- $a_n = (-1)^n\,n$
- $a_n = \dfrac{1}{n}$

## Explanation

We have $4n - n^2 = 4 - (n - 2)^2$, so $a_n \leq 4$ for every $n$, with equality for $n = 2$. Therefore $a_n = 4n - n^2$ is bounded above.

Since $(n - 2)^2 \to +\infty$, we have $a_n \to -\infty$, so the sequence falls below every threshold and is not bounded below.

The sequence $n^2 - 4n$ is the opposite of the previous one, so it is bounded below by $-4$ and not bounded above. The sequence $(-1)^n\,n$ takes the values $-1$, $2$, $-3$, $4$, $\dots$ and is bounded neither above nor below, while $\dfrac{1}{n}$ satisfies $0 < \dfrac{1}{n} \leq 1$ and is bounded.
