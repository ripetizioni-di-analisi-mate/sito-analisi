A sequence is defined by $a_{n+1} = a_n^2 - 2\,a_n$, with first term $a_1 \neq 0$. For which value of $a_1$ is the sequence constant?

- $a_1 = 2$
- $a_1 = 3$
- $a_1 = 1$
- $a_1 = -1$

## Explanation

If $a_2 = a_1$, the rule applied to $a_2$ gives $a_3 = a_2$, and so on, so the sequence is constant if and only if $a_2 = a_1$.

The condition $a_1^2 - 2\,a_1 = a_1$ is equivalent to $a_1^2 - 3\,a_1 = 0$, that is, $a_1\,(a_1 - 3) = 0$. Since $a_1 \neq 0$, we get $a_1 = 3$, and indeed $3^2 - 2 \cdot 3 = 3$.

With $a_1 = 2$ we get $a_2 = 0$, with $a_1 = 1$ we get $a_2 = -1$, and with $a_1 = -1$ we get $a_2 = 3$, so in these cases the second term differs from the first.
