Which of the following sequences is an arithmetic progression?

- $a_n = n\,(n - 1)$
- $a_n = (n + 1)^2 - n^2$
- $a_n = \dfrac{n + 1}{n}$
- $a_n = 3 \cdot 2^{n}$

## Explanation

Expanding the square gives $(n + 1)^2 - n^2 = n^2 + 2n + 1 - n^2 = 2n + 1$.

The difference between two consecutive terms is then $a_{n+1} - a_n = 2$ for every $n$, so the sequence is an **arithmetic progression** with common difference $2$.

For $n\,(n - 1)$ the difference is $2n$ and depends on $n$. For $\dfrac{n + 1}{n} = 1 + \dfrac{1}{n}$ the difference is $-\dfrac{1}{n\,(n + 1)}$. The sequence $3 \cdot 2^n$ is a geometric progression with common ratio $2$.
