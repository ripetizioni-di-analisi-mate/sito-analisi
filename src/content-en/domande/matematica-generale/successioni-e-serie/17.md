Which of the following sequences, with $n \geq 1$, is decreasing?

- $a_n = \dfrac{n}{n + 1}$
- $a_n = n^2 - 4n$
- $a_n = \dfrac{(-1)^n}{n}$
- $a_n = \dfrac{n + 3}{n + 1}$

## Explanation

For $a_n = \dfrac{n + 3}{n + 1}$ we have
$$
a_{n+1} - a_n = \frac{n + 4}{n + 2} - \frac{n + 3}{n + 1} = \frac{(n + 4)(n + 1) - (n + 3)(n + 2)}{(n + 1)(n + 2)} = -\frac{2}{(n + 1)(n + 2)} .
$$
The difference is negative for every $n$, so the sequence is **decreasing**.

The sequence $\dfrac{n}{n + 1}$ is increasing. The sequence $n^2 - 4n$ takes the values $-3$, $-4$, $-3$ for $n = 1, 2, 3$, therefore it is not monotonic, and $\dfrac{(-1)^n}{n}$ is not monotonic either, because it changes sign at every step.
