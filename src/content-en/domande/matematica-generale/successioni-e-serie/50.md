Starting from $a_1 = 2$, each term of a sequence is obtained from the previous one by the rule $a_{n+1} = \dfrac{1}{1 - a_n}$. What is the value of the term in place $100$?

- $2$
- $-1$
- $\dfrac{1}{2}$
- $-\dfrac{1}{2}$

## Explanation

Applying the rule gives $a_2 = \dfrac{1}{1 - 2} = -1$ and $a_3 = \dfrac{1}{1 - (-1)} = \dfrac{1}{2}$.

Then $a_4 = \dfrac{1}{1 - \frac{1}{2}} = 2 = a_1$. Since each term depends only on the previous one, from $a_4$ on the same values repeat, so the values $2$, $-1$, $\dfrac{1}{2}$ of the sequence repeat every three places.

Therefore $a_n = 2$ for all indices of the form $n = 3m + 1$. Since $100 = 3 \cdot 33 + 1$, we get $a_{100} = 2$. The values $-1$ and $\dfrac{1}{2}$ are the terms in places $3m + 2$ and $3m + 3$, for example $a_{98}$ and $a_{99}$.
