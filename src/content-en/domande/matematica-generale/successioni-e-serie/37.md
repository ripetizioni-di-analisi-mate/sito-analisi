Which of the following sequences is oscillating?

- $a_n = \dfrac{(-1)^n}{n}$
- $a_n = \left( -\dfrac{1}{2} \right)^{n}$
- $a_n = (-1)^n\,\dfrac{n}{n + 2}$
- $a_n = (-1)^{2n}$

## Explanation

For even $n$ the sequence $(-1)^n\,\dfrac{n}{n + 2}$ equals $\dfrac{n}{n + 2}$, which tends to $1$; for odd $n$ it equals $-\dfrac{n}{n + 2}$, which tends to $-1$.

The terms therefore approach $1$ and $-1$ alternately, so the sequence neither converges nor diverges, that is, it is **oscillating**.

The sequences $\dfrac{(-1)^n}{n}$ and $\left( -\dfrac{1}{2} \right)^{n}$ change sign, but their absolute value tends to $0$, so they converge to $0$. Finally $(-1)^{2n} = 1$ for every $n$, therefore the sequence $(-1)^{2n}$ is constant.
