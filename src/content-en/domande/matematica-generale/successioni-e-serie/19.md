Which of the following sequences, with $n \geq 1$, is bounded but not monotonic?

- $a_n = \dfrac{n^2}{n + 1}$
- $a_n = \dfrac{1}{n}$
- $a_n = (-1)^n\,\dfrac{n}{n + 1}$
- $a_n = (-2)^n$

## Explanation

The sequence $(-1)^n\,\dfrac{n}{n + 1}$ changes sign at every step, so it is not monotonic. Since $0 < \dfrac{n}{n + 1} < 1$, we have $|a_n| < 1$ for every $n$, therefore the sequence is **bounded**.

The sequence $(-2)^n$ also changes sign at every step, but its absolute value $2^n$ exceeds any number, so it is not bounded.

The sequences $\dfrac{1}{n}$ and $\dfrac{n^2}{n + 1}$ are monotonic, the first decreasing and the second increasing.
