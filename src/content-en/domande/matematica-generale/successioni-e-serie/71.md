For which real values of $x$ does the sequence $a_n = (x - 1)^n$ converge?

- $0 < x < 2$
- $0 < x \leq 2$
- $0 \leq x \leq 2$
- $-1 < x \leq 1$

## Explanation

The sequence is $q^{\,n}$ with $q = x - 1$. By the limit of a geometric sequence, $q^{\,n}$ converges to $0$ if $-1 < q < 1$ and converges to $1$ if $q = 1$, while it diverges for $q > 1$ and is oscillatory for $q \leq -1$.

Therefore the sequence converges if and only if $-1 < x - 1 \leq 1$, that is, $0 < x \leq 2$.

For $x = 2$ the sequence is constant and equal to $1$, so it converges. For $x = 0$ the sequence is $(-1)^n$, which is oscillatory.
