For the function $f(x) = 2x^3 - 3x^2 - 12x + 4$, the point $x = 2$ is stationary. What does the second derivative test give at $x = 2$?

- $f''(2) = 18$, so $x = 2$ is a relative maximum point
- $f''(2) = 18$, so $x = 2$ is a relative minimum point
- $f''(2) = -18$, so $x = 2$ is a relative maximum point
- $f''(2) = 0$, so the test is inconclusive

## Explanation

The derivative is $f'(x) = 6x^2 - 6x - 12 = 6(x - 2)(x + 1)$, so $f'(2) = 0$. The second derivative is $f''(x) = 12x - 6$, therefore $f''(2) = 24 - 6 = 18 > 0$. By the **second derivative test**, $x = 2$ is therefore a relative minimum point, with $f(2) = 16 - 12 - 24 + 4 = -16$. The value $-18$ is $f''(-1)$, and corresponds to the relative maximum point $x = -1$.
