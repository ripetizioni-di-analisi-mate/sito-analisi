The figure shows the graph of a function, with vertical asymptote $x = 1$, oblique asymptote $y = x + 1$ (dashed) and stationary points $(0, 0)$ and $(2, 4)$. Which function has this graph?

::grafico{f="x^2/(x-1);x+1" asintoti="x=1" punti="0,0,pieno;2,4,pieno" xmin=-4 xmax=6 ymin=-8 ymax=12 legenda=0 titolo="Graph with asymptotes $x = 1$ and $y = x + 1$, local maximum at $(0, 0)$ and local minimum at $(2, 4)$"}

- $f(x) = \dfrac{x^2 + 1}{x - 1}$
- $f(x) = \dfrac{x^2}{x + 1}$
- $f(x) = \dfrac{x^2}{x - 1}$
- $f(x) = \dfrac{x^2}{1 - x}$

## Explanation

The function $\dfrac{x^2}{x + 1}$ has vertical asymptote $x = -1$, so it is ruled out. The function $\dfrac{x^2}{1 - x}$ has oblique asymptote $y = -x - 1$, so it is ruled out as well. The two remaining functions have asymptotes $x = 1$ and $y = x + 1$, because
$$
\frac{x^2}{x - 1} = x + 1 + \frac{1}{x - 1}, \qquad \frac{x^2 + 1}{x - 1} = x + 1 + \frac{2}{x - 1} .
$$
The graph passes through the origin, and $\dfrac{x^2 + 1}{x - 1}$ equals $-1$ at $x = 0$. For $f(x) = \dfrac{x^2}{x - 1}$, instead, $f(0) = 0$, $f(2) = 4$ and $f'(x) = \dfrac{x\,(x - 2)}{(x - 1)^2}$, which vanishes exactly at $0$ and at $2$; therefore the graph is that of $\dfrac{x^2}{x - 1}$.
