For the function $f(x) = x^2 + \dfrac{1}{x}$, defined for $x \neq 0$, on which interval is the graph concave down?

- $(-\infty, -1]$
- $[-1, +\infty)$
- $[-1, 0)$
- $(0, +\infty)$

## Explanation

The second derivative is
$$
f''(x) = 2 + \frac{2}{x^3} = \frac{2\,(x^3 + 1)}{x^3} = \frac{2\,(x + 1)(x^2 - x + 1)}{x^3} .
$$
The factor $x^2 - x + 1$ is always positive, so the sign of $f''$ is that of $\dfrac{x + 1}{x}$. Therefore $f''(x) < 0$ for $-1 < x < 0$, and $f''(x) > 0$ for $x < -1$ and for $x > 0$. The function is thus **concave** on $[-1, 0)$ and convex on $(-\infty, -1]$ and on $(0, +\infty)$. The point $x = -1$ is an inflection point, while at $x = 0$ the concavity changes but the point does not belong to the domain.
