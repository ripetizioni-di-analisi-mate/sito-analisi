The function $f(x) = x + \dfrac{4}{x - 1}$, defined for $x \neq 1$, has a local maximum and a local minimum. How do the two values compare?

- The value of the local minimum, $5$, is greater than the value of the local maximum, $-3$
- The value of the local maximum, $5$, is greater than the value of the local minimum, $-3$
- The value of the local minimum, $5$, is also the absolute minimum of $f$
- The value of the local minimum, $3$, is greater than the value of the local maximum, $-1$

## Explanation

The derivative is
$$
f'(x) = 1 - \frac{4}{(x - 1)^2} = \frac{(x - 3)(x + 1)}{(x - 1)^2} ,
$$
which is positive for $x < -1$ and for $x > 3$ and negative for $-1 < x < 1$ and for $1 < x < 3$. By the first derivative test, $x = -1$ is a local maximum point, with $f(-1) = -1 - 2 = -3$, and $x = 3$ is a local minimum point, with $f(3) = 3 + 2 = 5$. The **local minimum is greater than the local maximum**, and there is no contradiction, because the two points lie on different intervals of the domain separated by the asymptote $x = 1$. The value $5$ is not the absolute minimum, because $f(x) \to -\infty$ as $x \to 1^-$.
