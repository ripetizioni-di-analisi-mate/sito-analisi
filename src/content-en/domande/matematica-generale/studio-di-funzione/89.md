The function $f(x) = x + \ln x$, with $x > 0$, has a negative second derivative at $x = 2$, where $f''(2) = -\dfrac{1}{4}$. What can be concluded about the point $x = 2$?

- $x = 2$ is not a point of local extremum
- $x = 2$ is a local maximum point, because $f''(2) < 0$
- $x = 2$ is a local minimum point, because $f'(2) > 0$
- $x = 2$ is an oblique inflection point, because $f'(2) \neq 0$

## Explanation

The derivative is $f'(x) = 1 + \dfrac{1}{x}$, so $f'(2) = \dfrac{3}{2} \neq 0$. The point $x = 2$ is an interior point of the domain and $f$ is differentiable at $2$, therefore by Fermat's theorem, if $x = 2$ were a local extremum, we would have $f'(2) = 0$. So $x = 2$ **is not a local extremum**; indeed $f'(x) > 0$ for every $x > 0$, and $f$ is increasing on its whole domain. The sign of $f''(2)$ does not classify the point, because the second derivative test assumes $f'(2) = 0$, which is not satisfied here. The point is not an inflection point either, because $f''(x) = -\dfrac{1}{x^2}$ is negative for every $x > 0$, so $f$ is concave on $(0, +\infty)$ and the concavity does not change at $2$.
