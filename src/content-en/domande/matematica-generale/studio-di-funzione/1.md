For the function $f(x) = x^3 - 27x + 4$, which point is a relative minimum point?

- $x = -3$
- $x = 3$
- $x = 3\sqrt{3}$
- $x = 0$

## Explanation

The derivative is $f'(x) = 3x^2 - 27 = 3(x - 3)(x + 3)$, which vanishes at $x = -3$ and at $x = 3$. The product $(x - 3)(x + 3)$ is negative for $-3 < x < 3$ and positive for $|x| > 3$, so $f$ decreases on $[-3, 3]$ and increases on $[3, +\infty)$. By the **first derivative test**, $x = 3$ is therefore a relative minimum point, with $f(3) = 27 - 81 + 4 = -50$. The point $x = -3$, instead, is a relative maximum point, because to the left of $-3$ the function increases and to the right it decreases.
