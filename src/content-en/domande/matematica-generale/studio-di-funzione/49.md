For the graph of $- 5 x + \left(x - 2\right)^{4} + 10$, how is the point at $x=2$ classified?

- Inflection point
- Local minimum
- Neither a local extremum nor an inflection point
- Local maximum

## Explanation

The first derivative there is $-5$, so there is no local extremum. The second derivative is $12(x-2)^2$ and has the same sign on both sides.
