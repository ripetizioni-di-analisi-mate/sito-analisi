Which of the following functions, defined on $\mathbb{R}$, is odd?

- $f(x) = \dfrac{x^2}{x^4 + 1}$
- $f(x) = x^3 + 1$
- $f(x) = x\,e^{x}$
- $f(x) = x\,e^{-x^2}$

## Explanation

A function is odd if $f(-x) = -f(x)$ for every $x$ in the domain. For $f(x) = x\,e^{-x^2}$ we have $f(-x) = -x\,e^{-(-x)^2} = -x\,e^{-x^2} = -f(x)$, so the function is **odd**. The function $\dfrac{x^2}{x^4 + 1}$ is even, because it contains only even powers of $x$. For $x^3 + 1$ we have $f(-1) = 0$ and $f(1) = 2$, so it is neither even nor odd. For $x\,e^{x}$ we have $f(-1) = -\dfrac{1}{e}$ and $-f(1) = -e$, therefore this function is not odd either.
