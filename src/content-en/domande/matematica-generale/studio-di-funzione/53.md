For the function $f(x) = x^3 + k x^2 + 3x$, with $k$ a real parameter, what is the set of all values of $k$ for which $f$ is increasing on $\mathbb{R}$?

- $k \leq -3$ or $k \geq 3$
- $-3 \leq k \leq 3$
- $-6 \leq k \leq 6$
- $-9 \leq k \leq 9$

## Explanation

The derivative is $f'(x) = 3x^2 + 2k x + 3$, a quadratic with positive leading coefficient. The function is increasing on $\mathbb{R}$ if $f'(x) \geq 0$ for every $x$ and $f'$ vanishes at most at isolated points, so if the discriminant is less than or equal to $0$:
$$
\frac{\Delta}{4} = k^2 - 9 \leq 0 \iff -3 \leq k \leq 3 .
$$
For $k = \pm 3$ we have $f'(x) = 3\,(x \pm 1)^2$, which vanishes at a single point, therefore $f$ is still increasing. For $|k| > 3$, instead, $f'$ is negative between its two roots, and $f$ decreases on that interval. The required set is therefore $-3 \leq k \leq 3$.
