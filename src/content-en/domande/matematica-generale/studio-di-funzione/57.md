We want the graph of $f(x) = x^4 + a x^3$ to change concavity at the point with $x$-coordinate $1$. What value must the real parameter $a$ have?

- $a = -\dfrac{4}{3}$
- $a = 2$
- $a = -4$
- $a = -2$

## Explanation

The second derivative is $f''(x) = 12x^2 + 6a x$. The necessary condition for an inflection point at $x = 1$ is $f''(1) = 12 + 6a = 0$, so $a = -2$. With this value
$$
f''(x) = 12x^2 - 12x = 12x\,(x - 1) ,
$$
which is negative for $0 < x < 1$ and positive for $x > 1$. Since $f''$ changes sign at $1$, by the sufficient condition $x = 1$ is an **inflection point**. The value $a = -\dfrac{4}{3}$ is obtained by imposing $f'(1) = 0$, which makes $x = 1$ stationary and has nothing to do with concavity.
