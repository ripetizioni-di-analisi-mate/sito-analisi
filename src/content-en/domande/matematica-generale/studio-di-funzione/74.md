An odd function $f$, defined and differentiable on $\mathbb{R}$, has a local maximum at $x = 2$, with $f(2) = 5$. Which statement about $x = -2$ is true?

- $x = -2$ is a local maximum point, with $f(-2) = 5$
- $x = -2$ is a local minimum point, with $f(-2) = 5$
- $x = -2$ is a local maximum point, with $f(-2) = -5$
- $x = -2$ is a local minimum point, with $f(-2) = -5$

## Explanation

Since $f$ is odd, $f(-x) = -f(x)$ for every $x$, so $f(-2) = -f(2) = -5$. The graph of an odd function is symmetric with respect to the origin. For $x$ near $2$ we have $f(x) \leq 5$, therefore for $x$ near $-2$ we have $f(x) = -f(-x) \geq -5 = f(-2)$, because $-x$ is near $2$. So $x = -2$ is a **local minimum point**, with value $-5$. The exchange between maximum and minimum is typical of symmetry with respect to the origin; for an even function, symmetric with respect to the $y$-axis, $x = -2$ would be a maximum with value $5$.
