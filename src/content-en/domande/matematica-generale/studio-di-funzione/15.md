For the function $f(x) = \sqrt[3]{x^2}$, defined on $\mathbb{R}$, which statement about the point $x = 0$ is true?

- It is a stationary relative minimum point
- It is an inflection point with vertical tangent
- It is an absolute minimum point at which $f$ is not differentiable
- It is not an extremum, because $f$ is not differentiable at $0$

## Explanation

For every $x$ we have $\sqrt[3]{x^2} \geq 0 = f(0)$, so $x = 0$ is an **absolute minimum** point. The difference quotient at $0$ is
$$
\frac{f(x) - f(0)}{x} = \frac{\sqrt[3]{x^2}}{x} = \frac{1}{\sqrt[3]{x}} ,
$$
which tends to $+\infty$ as $x \to 0^+$ and to $-\infty$ as $x \to 0^-$, therefore $f$ is not differentiable at $0$ and the point is not stationary. The point $x = 0$ is one of the candidates for extrema, namely an interior point at which $f$ is not differentiable. It is not an inflection point, because $f''(x) = -\dfrac{2}{9\sqrt[3]{x^4}}$ is negative both to the left and to the right of $0$.
