For the function $f(x) = e^{x} - 2x$, defined on $\mathbb{R}$, what is the value of the absolute minimum?

- $\ln 2$
- $1 - 2\ln 2$
- $2 - 2\ln 2$
- $2 - \ln 2$

## Explanation

The derivative is $f'(x) = e^{x} - 2$, which vanishes for $e^{x} = 2$, that is, for $x = \ln 2$. Since $f''(x) = e^{x} > 0$, by the **second derivative test** $x = \ln 2$ is a point of local minimum. Moreover $f'(x) < 0$ for $x < \ln 2$ and $f'(x) > 0$ for $x > \ln 2$, so by the theorem on functions with a single stationary point the minimum is absolute. The minimum equals $f(\ln 2) = e^{\ln 2} - 2\ln 2 = 2 - 2\ln 2$. The number $\ln 2$ is the x-coordinate of the minimum point.
