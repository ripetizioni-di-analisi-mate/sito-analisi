For the function $f(x) = (x - 1)^4 + 2x$ we have $f''(1) = 0$. Which statement about the point $x = 1$ is true?

- The point $x = 1$ is an oblique inflection point
- The point $x = 1$ is a relative minimum point
- The point $x = 1$ is a horizontal inflection point
- The point $x = 1$ is not an inflection point and $f$ is convex on $\mathbb{R}$

## Explanation

The derivatives are $f'(x) = 4(x - 1)^3 + 2$ and $f''(x) = 12(x - 1)^2$. The second derivative vanishes at $x = 1$ but is positive both to the left and to the right, so it does not change sign and $x = 1$ **is not an inflection point**. Since $f'(x) = 4(x - 1)^3 + 2$ is increasing on all of $\mathbb{R}$, the function $f$ is convex on $\mathbb{R}$. The point $x = 1$ is not an extremum either, because $f'(1) = 2 \neq 0$ and $f$ is differentiable at $1$, so by Fermat's theorem it cannot be a relative maximum or minimum point.
