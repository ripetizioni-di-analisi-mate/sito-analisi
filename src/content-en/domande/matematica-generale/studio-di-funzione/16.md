For the function $f(x) = x^3 - 12x$, defined on $\mathbb{R}$, which statement is true?

- The point $x = -2$ is a point of local maximum but not an absolute maximum point
- The point $x = -2$ is an absolute maximum point
- The point $x = 2$ is a point of local maximum
- The point $x = 0$ is a horizontal inflection point

## Explanation

The derivative is $f'(x) = 3x^2 - 12 = 3(x - 2)(x + 2)$, positive for $|x| > 2$ and negative for $-2 < x < 2$. By the **first derivative test**, $x = -2$ is therefore a point of local maximum, with $f(-2) = -8 + 24 = 16$, and $x = 2$ is a point of local minimum. The maximum is not absolute, because for example $f(5) = 125 - 60 = 65 > 16$. The point $x = 0$ is an inflection point, because $f''(x) = 6x$ changes sign at $0$, but the inflection point is oblique, because $f'(0) = -12 \neq 0$.
