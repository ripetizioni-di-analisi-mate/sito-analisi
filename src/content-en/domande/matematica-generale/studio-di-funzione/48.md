For which values of the real parameters $a$ and $b$ does the function $f(x) = (ax + b)\,e^{x}$ have a local minimum at the point $(0, -1)$?

- $a = 0$ and $b = -1$
- $a = 1$ and $b = -1$
- $a = -1$ and $b = -1$
- $a = -1$ and $b = 1$

## Explanation

The point $(0, -1)$ lies on the graph if $f(0) = b = -1$. The derivative is
$$
f'(x) = a\,e^{x} + (ax + b)\,e^{x} = (ax + a + b)\,e^{x} ,
$$
so $f'(0) = a + b$. Since $x = 0$ is an interior point of the domain and $f$ is differentiable, by Fermat's theorem a local minimum at $0$ requires $f'(0) = 0$, that is $a + b = 0$, therefore $a = 1$. With these values $f(x) = (x - 1)\,e^{x}$ and $f'(x) = x\,e^{x}$, which is negative for $x < 0$ and positive for $x > 0$. By the first derivative test $x = 0$ is therefore a **local minimum point**, with $f(0) = -1$.
