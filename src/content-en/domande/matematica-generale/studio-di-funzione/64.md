For the graph of $- 7 x + \left(x - 3\right)^{4} + 21$, how is the point with x-coordinate $3$ classified?

- Local minimum
- Neither a local extremum nor an inflection point
- Inflection point
- Local maximum

## Explanation

The first derivative there is $-7$, so there is no local extremum. The second derivative is $12(x-3)^2$ and has the same sign on both sides.
