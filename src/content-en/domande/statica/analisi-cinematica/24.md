The beam $AB$ shown, of length $5\,\mathrm{m}$, has at $A$ a roller support that moves along a horizontal plane and at $B$ a parallel-link support with the horizontal links. With reference point $A$, parameters $(u_A, v_A, \varphi)$, and lengths in meters, which rows of the kinematic matrix correspond to the parallel-link support?

::struttura{nodi="A,0,0;B,5,0" aste="A-B" vincoli="A,carrello;B,doppio-pendolo,0" quote="A,B,5 m"}

- $(0,\ 0,\ 1)$ and $(0,\ 1,\ 5)$
- $(1,\ 0,\ 0)$ and $(0,\ 1,\ 5)$
- $(0,\ 0,\ 1)$ and $(1,\ 0,\ -5)$
- $(0,\ 0,\ 1)$ and $(1,\ 0,\ 0)$

## Explanation

Parallel-link support with horizontal links prevents rotation and translation parallel to pin-ended links, i.e. horizontal displacement of $B$. The first condition is $\varphi = 0$, so the line $(0, 0, 1)$.

The horizontal displacement of $B$ equals $u_B = u_A - \varphi\,(y_B - y_A)$. Because $y_B = y_A = 0$, you have $u_B = u_A$, so the second line is $(1, 0, 0)$.

Row $(0, 1, 5)$ corresponds to the vertical displacement of $B$, which horizontal links leave free, and the coefficient $-5$ is obtained using the horizontal coordinate $B$ instead of the elevation. With the line of the roller support, $(0, 1, 0)$, the matrix has determinant $\pm 1 \neq 0$, so the beam is statically determinate.
