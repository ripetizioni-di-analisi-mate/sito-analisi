Which difference allows RNA polymerase to initiate transcription without the same requirement as replicative DNA polymerase?

- It can join the first ribonucleotides without a pre-existing primer.
- It synthesises RNA by adding nucleotides to the 5′ end.
- It reads both gene strands to make one double-stranded RNA.
- It always uses a DNA primer previously made by ligase.

## Explanation

RNA polymerase can initiate a chain using the first ribonucleotides paired to the template. Replicative DNA polymerase instead requires an already initiated chain whose 3′-OH can react. Both enzymes select monomers through complementarity and extend 5′ → 3′. The difference concerns initiation, not the direction of synthesis.
