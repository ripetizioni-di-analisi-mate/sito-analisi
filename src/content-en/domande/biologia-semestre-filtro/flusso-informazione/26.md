Which combination describes telomerase catalytic activity?

- Sealing the terminal phosphodiester bond without adding nucleotides.
- DNA synthesis using an internal RNA as template.
- DNA synthesis using only the complementary telomeric DNA strand as its internal template.
- RNA synthesis using telomeric DNA as template.

## Explanation

Telomerase is a ribonucleoprotein. Its RNA component contains the template region, and its protein component catalyses addition of DNA repeats to the telomeric 3′ end. Because information passes from an RNA template to DNA, this is reverse transcriptase activity. Completing the complementary strand then requires other replication enzymes.
