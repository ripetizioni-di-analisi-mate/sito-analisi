The template strand is given as 5′-AGTC-3′. What is the complementary transcript written 5′ → 3′?

- 5′-GACU-3′
- 5′-GACT-3′
- 5′-UCAG-3′
- 5′-AGUC-3′

## Explanation

Paired to the supplied DNA, the RNA is 3′-UCAG-5′. The question requires 5′ → 3′ orientation, so reversing the written order gives 5′-GACU-3′. This reversal is necessary because the template was initially presented 5′ → 3′. RNA retains U, whereas the sequence containing T would be DNA.
