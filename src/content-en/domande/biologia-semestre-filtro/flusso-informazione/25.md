A primer must pair exactly with the template segment 3′-CGTA-5′. Which DNA sequence, written 5′ → 3′, is complementary?

- 5′-GCAU-3′
- 5′-TACG-3′
- 5′-CGTA-3′
- 5′-GCAT-3′

## Explanation

The requested sequence is DNA, so the pairings are C–G, G–C, T–A and A–T. The template is already written 3′ → 5′, so the complement obtained from left to right is 5′-GCAT-3′. Using U would produce an RNA primer, while reversing the sequence unnecessarily would change the paired segment. The primer's 3′ end in this orientation provides the extendable end.
