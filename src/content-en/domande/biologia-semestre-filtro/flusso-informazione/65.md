In the standard code, UUU and UUC both specify phenylalanine. Which property does this illustrate?

- Overlap: the same nucleotide always belongs to several successive codons.
- Ambiguity: UUU randomly specifies several amino acids in the same context.
- Absolute universality: no code variant can exist in any system.
- Degeneracy: different codons can specify the same amino acid.

## Explanation

Degeneracy describes a many-to-one correspondence: several triplets share an amino acid meaning. In the standard context, UUU still has a defined meaning, so this does not make the code ambiguous. The distinction explains why some nucleotide substitutions leave a protein’s primary sequence unchanged.
