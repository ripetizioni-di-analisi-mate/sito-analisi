A codon that is a stop in the standard nuclear code specifies an amino acid in a mitochondrial system. Which conclusion is appropriate?

- Every codon must have random meanings even within a single system.
- The code is widely conserved, but contextual variants exist.
- The mitochondrial code must obligatorily read groups of four bases.
- The specified codon necessarily retains its stop meaning in every context.

## Explanation

Near universality means strong conservation across organisms and systems, alongside known exceptions. A different meaning in a mitochondrial system requires the code table appropriate to that system. It does not imply that, within one context, the ribosome randomly chooses incompatible meanings for a codon.
