Which sequence correctly orders sister separation?

- APC/C → securin activation → separase inhibition → cohesin cleavage
- Separase → cohesin cleavage → APC/C activation → securin degradation
- APC/C → separase degradation → securin activation → cohesin cleavage
- APC/C → securin degradation → separase → cohesin cleavage

## Explanation

The inhibitor is removed before the protease cleaves a cohesion component. Reversing this order would make securin an activator or release sisters before the regulatory signal. Their DNA does not need to be cut for separation.
