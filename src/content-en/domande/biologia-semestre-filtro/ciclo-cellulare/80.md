Cytochrome c is cytosolic, but APAF1 is absent. Which canonical step is directly impaired?

- Initial ligand recognition by Fas
- Functional apoptosome assembly
- Cytochrome c release, which the observation shows has already occurred
- BAX/BAK activation as the sole site of APAF1 action

## Explanation

APAF1 is part of the complex recruiting procaspase 9. Cytochrome c release is insufficient if this step is missing. The observation localises a defect downstream of mitochondrial release without alone establishing eventual cell fate.
