In a rod in darkness, some cGMP-dependent cation channels remain open. Which property is consistent with this?

- Relative depolarisation and glutamate release.
- Relative hyperpolarisation and reduced glutamate release as the typical dark response.
- Absence of inward cation current despite open cGMP-dependent channels.
- Maximal glutamate release only when cGMP falls and channels close.

## Explanation

In darkness, cGMP supports an inward cation current that keeps the rod relatively depolarised. The terminal can therefore release glutamate. Light reduces this current by activating cGMP degradation; assigning the same effect to darkness would reverse the response. In a rod, light reduces release relative to darkness; sensory activation does not equal increased glutamate release.
