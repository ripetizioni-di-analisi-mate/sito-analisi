A cell maintains Akt active independently of PIP3 production. In a linear PI3K → Akt → response model, which block can be bypassed?

- Inhibition of the terminal effector required for the response.
- Blockade of the introduced Akt's own catalytic function.
- PI3K inhibition, if downstream Akt effectors are functional.
- Absence of the substrate essential to the final step.

## Explanation

Independently active Akt can make the upstream step unnecessary for that response in the model. Downstream elements must still be present and functional. Recovery could not occur if the machinery executing the final response were itself missing. Constitutive activity bypasses an upstream command but does not create a missing downstream effector or substrate.
