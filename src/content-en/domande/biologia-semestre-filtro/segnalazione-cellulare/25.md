Two connexons dock between adjacent cells. How many connexins make up the complete channel if each connexon contains six?

- $6$.
- $3$.
- $12$.
- $36$.

## Explanation

Each cell contributes one connexon containing six subunits. The intercellular channel therefore contains $6+6=12$ connexins. Six describes one hemichannel, whereas continuous passage between the two cytoplasms requires both to dock.
