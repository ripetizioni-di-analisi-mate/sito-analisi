An snRNA participates in a complex that removes introns from a transcript. Which function is described?

- Amino-acid carriage using its own anticodon
- Complementary-DNA synthesis during reverse transcription
- RNA processing by splicing
- Function as a template directly read to produce a protein

## Explanation

snRNAs participate in the spliceosome, which recognises and processes regions of pre-mRNA during splicing. This is an RNA function in the maturation of other RNAs. The snRNA does not need to be translated into a protein to perform it. The case distinguishes functional noncoding RNAs from RNAs used as translation templates.
