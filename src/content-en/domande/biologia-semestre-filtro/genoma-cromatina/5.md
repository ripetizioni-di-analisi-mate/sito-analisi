In a regular model, one nucleosome repeat contains 147 wrapped bp and 43 linker bp. What is the repeat length?

- 147 bp.
- 190 bp.
- 104 bp.
- 294 bp.

## Explanation

The repeat includes both the DNA wrapped around the octamer and the connection to the next particle. Thus $147+43=190$ bp. The value 147 describes the protected nucleosome core; using it as the complete repeat would omit the linker specified in the question.
