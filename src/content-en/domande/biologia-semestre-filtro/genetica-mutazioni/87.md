Splicing removes an internal exon 90 nucleotides long and entirely within the translated region, with boundaries coinciding with codon boundaries. Which direct effect on the translated region is expected?

- No protein-sequence change because splicing concerns only introns.
- Loss of 30 amino acids with the downstream frame preserved.
- A frameshift because an entire exon is lost.
- Loss of 90 amino acids.

## Explanation

Each codon contains three nucleotides, so the tract contains $90\div3=30$ codons. The stated boundaries allow their removal without changing the grouping of subsequent triplets. The frame is preserved, whereas protein function requires assessment of the removed region.
