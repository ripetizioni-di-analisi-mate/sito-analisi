The key to a neighbourhood model says, “The pegs show where trees stand. They are all equally tall so they can be removed with the same pair of tongs.”

Which use of the model respects the information it encodes?

- Identify the tallest trees on the model to select those for pruning
- Establishing whether two trees are equally tall
- Estimate actual mean height by measuring a sample of pegs
- Calculating shadows from peg height
- Locating the square that contains a row of trees

## Explanation

Peg positions correspond to tree positions. Uniform height comes from the tool used to remove them and encodes no tree dimension.
