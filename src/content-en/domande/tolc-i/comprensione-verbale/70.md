A manual distinguishes two commands: “Undo” restores the value before the current edit; “Restore defaults” reloads the factory settings. Before the latest edit the value was already customised.

Which command recovers the previous custom setting?

- Neither, because the manual forbids undoing customisation
- “Restore defaults”, because the factory knows every edit
- Both in sequence with “Restore defaults” last
- Both, because “previous” and “initial” always coincide
- “Undo”, because the reference point is the current edit

## Explanation

The value immediately before the edit is the custom one mentioned in the case. Factory defaults date back to before the customisation.
