A notice says, “Repair includes transport both ways, excluding installation.” A customer takes installation to be included because the product is delivered back to her home.

Which rewriting preserves the scope of the service?

- Installation is included, but return delivery is not
- The return journey is included only with installation
- Any work done at the home is included
- Transport is excluded unless installation is purchased
- Transport is included in both directions and installation is separate

## Explanation

“Both ways” defines the included transport. Home delivery does not cancel the subsequent explicit exclusion of installation.
