A package reads, “Box made from recovered paper. Transparent window detachable before disposal.” A product listing summarises this as “Every component is made from recovered paper.”

Which extension did the listing introduce?

- It recorded that the box material is recovered
- It changed detachability into an obligation to return the product
- It applied to the window a claim made about the box
- It recognised that box and window are separable
- It specified which facility treats the separated window

## Explanation

The first sentence states where the box paper comes from. The second describes only the detachability of the window and leaves its material unspecified.
