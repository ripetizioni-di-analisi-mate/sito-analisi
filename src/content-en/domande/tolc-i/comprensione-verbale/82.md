A label distinguishes “refillable”, meaning fitted with an opening for refilling, from “returned”, meaning actually handed in at the collection desk. The log records only returned containers.

What is missing to determine how many refillable containers never reached the desk?

- The exact time of each return already logged
- A list of refillables distributed, to compare with those actually returned
- The number of days on which the log was opened
- The nominal capacity of the smallest return
- A fresh count of only the returned entries

## Explanation

A container that is never returned does not appear in the returns log. Comparison requires an independent list of distributed refillables and a way to match them to returns.
