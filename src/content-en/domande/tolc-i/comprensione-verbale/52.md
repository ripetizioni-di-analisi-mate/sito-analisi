A workshop tests a handle with two interchangeable grips. Each participant uses both, but half start with the first and the rest with the second. After the first attempt the mechanism is already familiar.

Why alternate which grip is tried first?

- To find the preference of someone who has not tried both grips
- To distribute any advantage from prior experience between the grips
- To give each participant just one grip
- To establish that both grips require the same force
- To guarantee nobody remembers the mechanism

## Explanation

If practice helps on the second trial, placing the same grip second every time would favour it. Alternation distributes that second-trial position between the grips.
