Each commuter chose their transport before receiving the questionnaire. The authors would now also like to know how far respondents live from work.

Under which circumstances would distance complicate the interpretation of the well-being comparison?

- If distance were entered separately in the table but did not vary between groups
- If it influenced both transport choice and well-being
- If distances differed only in the unit used to express them
- If transport choice changed the name given to the distance without changing its value
- If distance affected well-being but was identical for everyone

## Explanation

A short distance could favour cycling and make the commute less tiring. The comparison would then involve groups that also differ on a characteristic relevant to well-being.
