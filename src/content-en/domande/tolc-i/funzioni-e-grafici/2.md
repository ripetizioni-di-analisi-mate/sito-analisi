Which value solves $2^{x+1}=16$?

- $x=4$
- $x=3$
- $x=2$
- $x=8$
- $x=-3$

## Explanation

Write $16$ as $2^4$ so both sides have the same base. Since $2^t$ is strictly increasing, equal powers have equal exponents. Therefore $x+1=4$ and $x=3$. Substitution gives $2^{3+1}=16$, which verifies the original equation.
