The rule is $P\iff Q$. Which truth values make it false?

- P and Q both true
- P and Q both false
- Different values for P and Q
- Any pair with P true
- Any pair with Q false

## Explanation

The biconditional requires both $P\Rightarrow Q$ and $Q\Rightarrow P$. If the values agree, neither implication is violated. If they differ, one implication has a true antecedent and a false consequent. The rule is therefore false exactly when one statement is true and the other is false.
