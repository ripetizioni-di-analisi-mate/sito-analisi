Which set of conditions is impossible to satisfy?

- $P\Rightarrow Q$, $P$ true, $Q$ false
- $P\Rightarrow Q$, $P$ false, $Q$ true
- $P\lor Q$, $P$ true, $Q$ true
- $P\iff Q$, $P$ false, $Q$ false
- $\neg(P\land Q)$, $P$ false, $Q$ false

## Explanation

The combination with $P$ true and $Q$ false requires the implication to hold in its only false case, with $P$ true and $Q$ false. The conditions are therefore incompatible. In every other case, the indicated assignment satisfies the formula: disjunction is inclusive, and the biconditional also allows both values to be false.
