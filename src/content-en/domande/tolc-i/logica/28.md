All eligible applications are signed. A signed application without a report exists. Which additional premise is sufficient to infer that an eligible application without a report exists?

- All applications with a report are signed
- Some eligible applications have a report
- All signed applications are eligible
- No unsigned application is eligible
- An eligible application with a report exists

## Explanation

The available witness is a signed application without a report. To obtain the conclusion, that particular application must be guaranteed eligible. The new inclusion signed $\subseteq$ eligible permits this step. Information about other applications, or a restatement of the original rule, does not necessarily connect the witness to eligibility.
