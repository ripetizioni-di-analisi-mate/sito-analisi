Among tiles, “having the same color” is a relation. A has the same color as B, and B the same color as C. Which conclusion follows?

- A and C have different colors
- The three tiles are the same object
- Only three tiles exist
- The color must be red
- A and C have the same color

## Explanation

The first equality identifies A’s color with B’s, and the second B’s with C’s. By transitivity of equality, A and C have the same color. The equality concerns the color property, not the identity of the tiles. The actual name of the color is not given.
