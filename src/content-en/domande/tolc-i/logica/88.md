Starting from the number $5$, $7$ is added at each step. What is the first number obtained that is strictly greater than $80$?

- $75$
- $80$
- $82$
- $81$
- $89$

## Explanation

After $n$ steps we obtain $5+7n$. The condition $5+7n>80$ is equivalent to $7n>75$, that is $n>\dfrac{75}{7}\approx10.7$, so the first suitable integer is $n=11$. For $n=11$ we obtain $5+77=82$. For $n=10$ we obtain $75$, which does not exceed $80$, therefore $82$ is the first number greater than $80$.
