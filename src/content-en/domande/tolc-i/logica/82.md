For three activities A, B and C, only A preceding B is known. Which additional information makes the order unique?

- C precedes B
- C is immediately after B
- A precedes C
- C is not second
- A is not third

## Explanation

If C is immediately after B, the BC pair must leave A before B; with three activities, only ABC remains. C before B allows ACB and CAB; A before C allows ABC and ACB. The other additions likewise leave multiple orders. Placing C immediately after B is therefore the only proposed addition determining every position.
