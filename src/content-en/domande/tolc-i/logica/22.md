Four facts are known: (i) if the sensor sends an alert, it has power; (ii) if it has power and is in active mode, it sends an alert; (iii) it has power; (iv) it sends no alert. Which fact can be removed while preserving the deduction “the sensor is not in active mode”?

- Fact (ii)
- Fact (i)
- Fact (iii)
- Fact (iv)
- None of the four

## Explanation

Facts (ii), (iii) and (iv) suffice: if the sensor were active, its power supply would require an alert, contradicting (iv). Rule (i) is therefore unnecessary for this conclusion. Without (ii), activity is unrestricted; without (iii), an active but unpowered sensor is compatible; without (iv), an active sensor sending an alert is compatible. None of the other three facts can be removed individually.
