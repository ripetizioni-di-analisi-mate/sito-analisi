Which observation is enough to show that the statement “All devices in the batch pass the test” is false?

- One device from another batch fails the test
- One device in the batch fails the test
- Ten devices in the batch pass the test
- Most devices pass the test
- One device in the batch has not yet been tested

## Explanation

The statement attributes a property to all the elements of a set, so showing that it is false requires an element of that set without the property. Therefore one device in the batch that fails the test is enough. A device from another batch does not belong to the set the statement is about. A device not yet tested has an unknown outcome, so it does not show that the test fails.
