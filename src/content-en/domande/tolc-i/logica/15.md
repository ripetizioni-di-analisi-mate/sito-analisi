Which sentence is equivalent to “There is no urgent file containing a map”?

- Every file contains a map
- At least one urgent file contains a map
- No file is urgent
- Every file without a map is urgent
- No urgent file contains a map

## Explanation

The sentence makes the intersection of urgent files and files containing a map empty. This means that no urgent file also belongs to the map-containing group. Urgent files without maps and nonurgent files with maps may still exist. Ruling out every urgent file would therefore impose an additional condition.
