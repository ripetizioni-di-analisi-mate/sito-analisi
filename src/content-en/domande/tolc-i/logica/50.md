In a tournament with $8$ participants, every pair meets exactly once. How many matches are scheduled?

- $56$
- $16$
- $32$
- $7$
- $28$

## Explanation

Each participant has seven opponents, so $8\cdot7$ counts $56$ match participations. Every match appears twice, once for each player. The number of matches is therefore $\dfrac{8\cdot7}{2}=28$. Reversing the order of the two participants does not create a new match.
