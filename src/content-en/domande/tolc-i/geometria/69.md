For which real values of $k$ is the line $y=k$ tangent to the circle $x^2+y^2=9$?

- $k=1$
- $k=\pm9$
- $k=0$
- $k=\pm3$
- $-3<k<3$

## Explanation

The distance from the origin to the horizontal line $y=k$ is $|k|$. The circle has radius $3$, so tangency requires $|k|=3$, giving $k=3$ or $k=-3$. Values between $-3$ and $3$ would give secants, while values with absolute value greater than $3$ would give exterior lines.
