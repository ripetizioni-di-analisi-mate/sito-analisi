A meter reading is proportional to the energy measured. A technician sets it to read $96$ when the actual value is $100$. Which operation recovers the actual value from a reading $L$?

- $\dfrac{L}{1.04}$
- $L+4$
- $0.96L$
- $\dfrac{L}{0.96}$
- $1.04L$

## Explanation

The ratio of reading to actual value is fixed at $\dfrac{96}{100}=0.96$. If the actual value is $E$, then $L=0.96E$. Dividing by the scale factor recovers $E$ for every reading.
