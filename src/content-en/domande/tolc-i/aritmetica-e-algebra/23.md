A student squares both sides of $x=-2$ and obtains $x^2=4$. Which set consists exactly of the solutions introduced by this step?

- $\{-2\}$
- $\{-2,2\}$
- $\{2\}$
- $\{0\}$
- $\varnothing$

## Explanation

The original equation has only the solution $-2$. After squaring, $x^2=4$ admits both $-2$ and $2$, because opposite numbers have the same square. The added value is therefore $2$. Squaring preserves every original solution but can introduce candidates that must be checked.
