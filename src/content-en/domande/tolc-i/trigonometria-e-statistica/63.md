The function $f$ is defined on $\mathbb R$, is periodic with period $4$, and on the interval $[0,4)$ is given by $f(x)=x^2-3x$. What is $f(-5)$?

- $4$
- $40$
- $0$
- $-2$
- $10$

## Explanation

Since $f$ has period $4$, adding $4$ to the argument does not change the value, so $f(-5)=f(-1)$. The number $-1$ does not yet belong to $[0,4)$, so we add another period and obtain $f(-1)=f(3)$. The number $3$ belongs to the interval on which the formula is given, so $f(3)=3^2-3\cdot3=0$. Therefore $f(-5)=0$. The value $4$ is obtained by applying the formula at $-1$, which lies outside $[0,4)$, while $40$ is obtained by applying it directly at $-5$.
