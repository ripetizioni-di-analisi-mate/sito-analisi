What is the smallest input $x\ge0$ at which $f(x)=2\sin\left(x-\dfrac\pi2\right)+1$ attains its maximum?

::grafico{f="2*sin(x-1.5707963268)+1" xmin=-0.5 xmax=7 ymin=-2 ymax=4 titolo="A sinusoid shifted horizontally and vertically."}

- $\pi$
- $0$
- $\dfrac\pi2$
- $\dfrac{3\pi}{2}$
- $2\pi$

## Explanation

The maximum occurs when sine equals $1$, so $x-\dfrac\pi2=\dfrac\pi2+2k\pi$. Thus $x=\pi+2k\pi$. The smallest nonnegative value is $\pi$, where the function equals $3$. The argument shift changes the positions of the maxima.
