Which process defines an element's first ionization energy?

- Removing one electron from an isolated neutral gaseous atom
- Bringing two polar molecules together
- Adding a neutron to the nucleus
- Melting one mole of solid element
- Removing all electrons simultaneously

## Explanation

First ionization concerns $\mathrm{X(g)\to X^+(g)+e^-}$. It starts with a neutral gaseous atom and removes one electron. Specifying the initial state and phase allows different elements to be compared. Electronegativity instead describes attraction of bonding electrons, while melting is a phase change.
