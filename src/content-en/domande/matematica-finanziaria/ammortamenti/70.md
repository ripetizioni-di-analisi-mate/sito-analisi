At a valuation rate of $6\%$, all installments together are worth $9000\,\mathrm{EUR}$ and the interest-only value is $850\,\mathrm{EUR}$. What is the principal-only value at the same rate?

- $9000\,\mathrm{EUR}$
- $850\,\mathrm{EUR}$
- $8150\,\mathrm{EUR}$
- $9850\,\mathrm{EUR}$

## Explanation

In each period $I_k+C_k=R_k$, so at a common valuation rate the value of the installments is $U(j)+N(j)$. The principal-only value is therefore
$$
N=9000-850=8150\,\mathrm{EUR}.
$$
The value $9850\,\mathrm{EUR}$ adds the interest-only value to the value of the full installments instead of subtracting it. The value $9000\,\mathrm{EUR}$ also includes the interest portions.
