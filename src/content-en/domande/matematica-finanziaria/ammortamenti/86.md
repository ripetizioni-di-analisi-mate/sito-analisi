A borrower repays part of the principal. The bank recalculates the installments using the same rate and number of remaining payments. What happens to the level installment?

- It rises because the number of installments stays fixed.
- It stays the same for any extra principal repayment.
- It decreases in proportion to the remaining principal.
- At each due date it decreases by exactly the entire extra repayment.

## Explanation

The recalculated installment is $R=\dfrac{D}{a_{\overline m|i}}$, using the same rate and the same number $m$ of remaining installments. The annuity factor is unchanged, making the installment proportional to the new balance. It falls by the same percentage. For example, if the balance falls from $4000$ to $3000\,\mathrm{EUR}$, the new installment is three-quarters of its predecessor.
