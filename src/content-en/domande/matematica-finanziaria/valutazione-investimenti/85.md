A project can be launched now or in one year. Each option has an NPV of €110 measured at its own launch date, using a $10\%$ annual discount rate. If only one launch date can be chosen, how much greater is the value today of starting immediately?

- €0
- €11
- €10
- €21

## Explanation

Compare the NPVs on the same date. The delayed project is worth $\dfrac{110}{1.10}=100$ euros today. Starting now is worth €110 today, an advantage of €10.
