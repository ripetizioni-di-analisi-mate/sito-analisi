The value of a schedule of payments between two parties is negative for the borrower. At the same date and rate, what value does it have for the lender?

- It is positive with the same absolute value.
- It is zero because the payments offset each other.
- It is negative with the same absolute value.
- It is positive with a different absolute value because of the payment dates.

## Explanation

Each transfer is an outflow for one party and an inflow for the other, so switching from borrower to lender reverses the sign of every $C_k$. The valuation function $V(\tau)=\sum_kC_kq^{\tau-t_k}$ is linear in the amounts, so the total changes sign. The lender's value is positive and has the same absolute value. The factors are unaffected because the date and rate are the same.
