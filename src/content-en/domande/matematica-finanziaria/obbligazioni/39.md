A search for the yield to maturity starts with an interval from $4\%$ to $8\%$. At the midpoint, the present value of the cash flows is below the price. Which interval should be retained?

- From $2\%$ to $4\%$.
- From $4\%$ to $6\%$.
- From $4\%$ to $8\%$.
- From $6\%$ to $8\%$.

## Explanation

The midpoint is $6\%$. At that rate present value is below the price, so it must increase to reach the price. Present value decreases as the rate increases, so the yield to maturity is below $6\%$ and the interval from $4\%$ to $6\%$ is retained. The interval from $6\%$ to $8\%$ would be retained if present value exceeded the price.
