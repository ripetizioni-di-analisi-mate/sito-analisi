A portfolio receives €100 in one year and pays €100 in two years. The same increment $\varepsilon$ is added to both discount factors, which remain positive. How does the portfolio's net present value change?

- It rises by $200\varepsilon$.
- It rises by $100\varepsilon$.
- It falls by $100\varepsilon$.
- It is unchanged.

## Explanation

The original value is $100v_1-100v_2$. The shifted value is $100(v_1+\varepsilon)-100(v_2+\varepsilon)$. The increments cancel because the face amounts are equal with opposite signs.
