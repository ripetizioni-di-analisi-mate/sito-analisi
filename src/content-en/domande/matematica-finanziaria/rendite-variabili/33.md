The contract's base payment today is $100$ euros. It increases by $10\%$ each year, and the first payment at time $1$ already includes one increase. What is the third payment?

- $121\,\mathrm{EUR}$
- $130\,\mathrm{EUR}$
- $146.41\,\mathrm{EUR}$
- $133.10\,\mathrm{EUR}$

## Explanation

Apply the $10\%$ increase each year, starting from today's reference amount. The first payment already includes one increase, so the amount at time $k$ is $100\cdot1.1^k$ euros. The third has undergone three increases and equals $100\cdot1.1^3=133.10$ euros. The value of $121$ euros counts only two increases, as if the first payment were $100$ euros. The value of $130$ euros uses fixed increments of $10$ euros.
