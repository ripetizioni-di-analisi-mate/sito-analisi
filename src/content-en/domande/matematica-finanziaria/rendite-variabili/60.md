A positive continuous stream pays at a constant rate from today to time $T>0$. Holding the payment rate fixed, what happens to its present value if the constant force changes from $\delta>0$ to $2\delta$?

- It increases.
- It stays the same.
- It decreases.
- It always halves.

## Explanation

The present value is $\int_0^T ce^{-\delta t}\,dt$ with $c>0$. For every $t>0$ we have $e^{-2\delta t}<e^{-\delta t}$ because $2\delta t>\delta t$. The integrand decreases throughout the interval, so present value falls. Its new value $\dfrac{c\left(1-e^{-2\delta T}\right)}{2\delta}$ still exceeds half the original value because $1-e^{-2\delta T}>1-e^{-\delta T}$.
