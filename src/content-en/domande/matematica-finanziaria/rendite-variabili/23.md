A payment of $900$ euros included in a contract's present value is replaced by payments of $400$ and $500$ euros on the same date. At the same interest rate, how does the present value change?

- It increases if the interest rate is positive.
- It decreases if the interest rate is positive.
- It stays the same.
- It doubles.

## Explanation

Both replacement payments have the same date $t_k$ as the original and therefore the same discount factor $v^{t_k}$. Their present values add up to
$$
400v^{t_k}+500v^{t_k}=900v^{t_k},
$$
which equals the present value of the original payment. The contract's present value is therefore unchanged at every interest rate, since only the total due on each date enters the valuation.
