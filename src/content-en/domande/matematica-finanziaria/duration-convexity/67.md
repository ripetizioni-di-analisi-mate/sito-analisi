A and B have the same modified duration. B has the larger portfolio weight. Which statement holds for a parallel shift?

- Portfolio modified duration equals their common duration.
- Portfolio duration equals B's market-value weight.
- Portfolio duration is always twice their common duration.
- Portfolio duration equals B's price.

## Explanation

For a parallel shift, portfolio modified duration is $\omega_AD+\omega_BD$, where $D$ is the common duration. Since market-value weights sum to one,
$$
D_{\mathrm{mod},V}=(\omega_A+\omega_B)D=D .
$$
portfolio duration equals the common duration regardless of B's weight. Giving more weight to B would affect this result only if the individual durations differed.
