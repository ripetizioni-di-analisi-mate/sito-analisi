We want to apply the squeeze theorem to $b_n = \dfrac{n + \sin n}{n}$. Which pair of inequalities, valid for every $n \geq 1$, allows us to do so?

- $0 \leq b_n \leq 2$
- $1 \leq b_n \leq \dfrac{n + 1}{n}$
- $\dfrac{n - 1}{n} \leq b_n \leq 2$
- $\dfrac{n - 1}{n} \leq b_n \leq \dfrac{n + 1}{n}$

## Explanation

From $-1 \leq \sin n \leq 1$ we get $\dfrac{n - 1}{n} \leq b_n \leq \dfrac{n + 1}{n}$. The two outer sequences both tend to $1$, so by the **squeeze theorem** $b_n \to 1$.

The estimates $0 \leq b_n \leq 2$ are true, but the outer sequences have different limits, $0$ and $2$, and the same happens for the pair formed by $\dfrac{n - 1}{n}$ and $2$. The estimate $b_n \geq 1$ is equivalent to $\sin n \geq 0$, which is false for example for $n = 4$, since $\pi < 4 < 2\pi$.
