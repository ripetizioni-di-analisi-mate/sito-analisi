An infinite table has $t_{n,k}=1$ when $n=k$ and $0$ otherwise, for $n,k\geq1$. Every fixed column tends to zero as we move down the rows. What happens to the maximum in each row?

- The row has no maximum.
- It tends to zero like $\dfrac{1}{n}$.
- It is always $1$.
- It is zero starting in the second row.

## Explanation

In fixed column $k$, the only one occurs in row $k$. But each row $n$ always contains a one in column $k=n$. The exceptional position moves, keeping the row maximum equal to one.
