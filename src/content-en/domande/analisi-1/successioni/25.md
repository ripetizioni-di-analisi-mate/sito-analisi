In each pair the two sequences diverge to $+\infty$, so $a_n - b_n$ is in the form $+\infty - \infty$. For which pair does the difference tend to $5$?

- $a_n = \ln\left(e^5 n\right)$, $b_n = \ln n$
- $a_n = \ln(5n)$, $b_n = \ln n$
- $a_n = \ln\left(n^5\right)$, $b_n = \ln n$
- $a_n = \ln(n + 5)$, $b_n = \ln n$

## Explanation

The limit of a form $+\infty - \infty$ depends on the sequences involved. By the properties of logarithms, $\ln\left(e^5 n\right) - \ln n = \ln e^5 = 5$ for every $n$, so the difference is constant and tends to $5$.

In the other pairs we have $\ln(5n) - \ln n = \ln 5$, which is about $1.61$, and $\ln\left(n^5\right) - \ln n = 4 \ln n \to +\infty$. Finally $\ln(n + 5) - \ln n = \ln \left( 1 + \dfrac{5}{n} \right) \to 0$.
