For which real values of $x$ is the sequence $\left( \dfrac{x - 1}{2} \right)^{n}$ convergent?

- $-1 < x < 3$
- $-1 < x \leq 3$
- $-1 \leq x \leq 3$
- $-3 < x \leq 1$

## Explanation

The sequence is geometric with ratio $q = \dfrac{x - 1}{2}$. A geometric sequence converges if and only if $-1 < q \leq 1$, because it tends to $0$ for $|q| < 1$, is constantly $1$ for $q = 1$, diverges for $q > 1$ and has no limit for $q \leq -1$.

The condition $-1 < \dfrac{x - 1}{2} \leq 1$ is equivalent to $-2 < x - 1 \leq 2$, that is, to $-1 < x \leq 3$. The endpoint $x = 3$ is included, because it gives $q = 1$, while $x = -1$ gives $q = -1$ and the sequence $(-1)^n$, which has no limit.
