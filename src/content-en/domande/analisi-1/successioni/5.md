Three of these sequences, defined for $n \geq 0$, have no limit. Which one is convergent instead?

- $a_n = \cos(n\pi)$
- $a_n = \cos \dfrac{n\pi}{2}$
- $a_n = n \sin \dfrac{n\pi}{2}$
- $a_n = \sin(n\pi)$

## Explanation

For every integer $n$ we have $\sin(n\pi) = 0$, so the sequence is constant and **converges** to $0$.

On the other hand $\cos(n\pi) = (-1)^n$, which is indeterminate. The terms of $\cos \dfrac{n\pi}{2}$ repeat with period $4$ and are $1, 0, -1, 0, \dots$, so they take both the value $1$ and the value $-1$ infinitely many times and the sequence has no limit. Finally $n \sin \dfrac{n\pi}{2}$ equals $n$ for $n = 4k + 1$ and $-n$ for $n = 4k + 3$, so this sequence has no limit either.
