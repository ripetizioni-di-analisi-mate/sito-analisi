Only one of these inequalities holds eventually, that is, for every $n$ greater than a suitable index. Which one?

- $n^2 < 100\, n$
- $\dfrac{1}{n} > \dfrac{1}{1000}$
- $2^n > n^3$
- $(-1)^n\, n > 5$

## Explanation

We have $2^{10} = 1024 > 1000 = 10^3$. If $2^n > n^3$ with $n \geq 10$, then $2^{n+1} > 2n^3 \geq (n + 1)^3$, because $\left( 1 + \dfrac{1}{n} \right)^3 \leq 1.1^3 < 2$. By induction $2^n > n^3$ holds for every $n \geq 10$, so it holds **eventually**.

The other three are false for infinitely many indices. The inequality $n^2 < 100\, n$ is equivalent to $n < 100$ and is false for every $n \geq 100$. The inequality $\dfrac{1}{n} > \dfrac{1}{1000}$ is false for every $n \geq 1000$, and $(-1)^n\, n > 5$ is false for every odd $n$.
