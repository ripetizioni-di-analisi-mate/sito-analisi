To prove by a comparison that $a_n = n - 3 \sin n$ diverges to $+\infty$, which inequality, valid for every $n$, is used?

- $n - 3 \sin n \leq n + 3$
- $n - 3 \sin n \geq n - 3$
- $n - 3 \sin n \geq -3$
- $n - 3 \sin n \geq n - \sin n$

## Explanation

Since $\sin n \leq 1$, we have $-3 \sin n \geq -3$ and therefore $n - 3 \sin n \geq n - 3$ for every $n$. The sequence $n - 3$ diverges to $+\infty$, so by the **comparison for divergent sequences** also $a_n \to +\infty$.

The upper bound by $n + 3$ is true, but a sequence bounded above by a divergent sequence can behave in any way. The lower bound by $-3$ is true, but the constant $-3$ does not diverge. The inequality $n - 3 \sin n \geq n - \sin n$ is equivalent to $\sin n \leq 0$, which is false for example for $n = 1$.
