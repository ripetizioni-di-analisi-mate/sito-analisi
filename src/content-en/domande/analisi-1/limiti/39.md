For which value of $a > 0$ is the function
$$
f(x) =
\begin{cases}
\dfrac{\ln(1 + a x)}{x} & \text{if } x > 0 \\[10pt]
x^2 + 4 & \text{if } x \leq 0
\end{cases}
$$
continuous at $x = 0$?

- $a = 4$
- $a = \dfrac{1}{4}$
- $a = 2$
- $a = 1$

## Explanation

We have $f(0) = 4$, and the left-hand limit equals $4$ because $x^2 + 4$ is continuous. For the right-hand limit, with the change of variable $y = ax \to 0^{+}$ we write
$$
\frac{\ln(1 + ax)}{x} = a \cdot \frac{\ln(1 + ax)}{ax} ,
$$
and the second factor tends to $1$ by the fundamental limit of the logarithm. Hence the right-hand limit equals $a$. The function is continuous at $0$ if and only if the right-hand limit coincides with $f(0)$, that is, for $a = 4$.
