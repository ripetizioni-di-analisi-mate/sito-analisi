On which of the following sets does the extreme value theorem apply to the function $f(x) = \dfrac{1}{x - 1}$?

- $[0, 2]$
- $(1, 2]$
- $[2, +\infty)$
- $[2, 3]$

## Explanation

The extreme value theorem requires a continuous function on a closed and bounded interval. The function $f$ is continuous at every point other than $1$, so it is continuous on $[2, 3]$, which is closed and bounded; therefore the theorem applies and $f$ has maximum $1$ and minimum $\dfrac{1}{2}$. The interval $[0, 2]$ contains the point $1$, where $f$ is not defined. The interval $(1, 2]$ is not closed and $[2, +\infty)$ is not bounded, so in these cases the hypotheses of the theorem are not satisfied.
