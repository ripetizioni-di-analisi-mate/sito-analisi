What are the vertical asymptotes of the function $f(x) = \dfrac{x - 2}{x^{2} - 4}$?

- $x = -2$ and $x = 2$
- Only $x = 2$
- No vertical asymptote
- Only $x = -2$

## Explanation

The denominator vanishes at $x = 2$ and at $x = -2$, so these are the candidate vertical asymptotes.

Since $x^{2} - 4 = (x - 2)(x + 2)$, for $x \neq 2$ we have $f(x) = \dfrac{1}{x + 2}$. As $x \to 2$ the limit therefore equals $\dfrac{1}{4}$, which is finite, so $x = 2$ is not a vertical asymptote. As $x \to -2^{+}$ we have $f(x) \to +\infty$, so $x = -2$ is a **vertical asymptote**.
