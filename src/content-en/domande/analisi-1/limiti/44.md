What is the image of the interval $[0, 3]$ under the function $f(x) = x^2 - 2x$?

- $[0, 3]$
- $[-1, 3]$
- $(-1, 3)$
- $[-1, +\infty)$

## Explanation

We have $f(x) = (x - 1)^2 - 1$, so on $[0, 3]$ the minimum is $f(1) = -1$. The value $(x - 1)^2$ is largest at the point of $[0, 3]$ farthest from $1$, that is, at $x = 3$, therefore the maximum is $f(3) = 3$. The function is continuous on the interval $[0, 3]$, so by the **intermediate value theorem** it takes every value between the minimum and the maximum. Therefore the image is $[-1, 3]$.
