A function $f$ is continuous on $[1, 4]$, with $f(1) = 2$ and $f(4) = 7$. Which of the following values is certainly taken by $f$ on $[1, 4]$?

- $8$
- $1$
- $5$
- $0$

## Explanation

By the **intermediate value theorem**, a function continuous on an interval takes every value between two values that it takes. Since $f(1) = 2$ and $f(4) = 7$, the function takes every value of $[2, 7]$, so it certainly takes the value $5$.

The values $8$, $1$ and $0$ do not lie between $2$ and $7$. The function $f(x) = \dfrac{5x + 1}{3}$ is continuous, equals $2$ at $1$ and $7$ at $4$, and is increasing, therefore on $[1, 4]$ it takes none of these three values.
