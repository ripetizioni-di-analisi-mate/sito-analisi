For which $\alpha \in \mathbb{R}$ is the integral
$$
\int_0^{\frac{\pi}{2}} (\tan x)^{\alpha}\,dx
$$
convergent?

- $\alpha > -1$
- $\alpha < 1$
- $-1 \leq \alpha \leq 1$
- $-1 < \alpha < 1$

## Explanation

The integrand is positive on $\left(0, \dfrac{\pi}{2}\right)$ and the points to study are $0$ and $\dfrac{\pi}{2}$. As $x \to 0^{+}$ we have $\tan x \sim x$, so $(\tan x)^{\alpha} \sim \dfrac{1}{x^{-\alpha}}$ and the integral near $0$ converges if and only if $-\alpha < 1$, that is $\alpha > -1$. As $x \to \dfrac{\pi}{2}^{-}$ we have $\tan x = \dfrac{1}{\tan\left(\frac{\pi}{2} - x\right)} \sim \dfrac{1}{\frac{\pi}{2} - x}$, so $(\tan x)^{\alpha} \sim \dfrac{1}{\left(\frac{\pi}{2} - x\right)^{\alpha}}$ and the integral near $\dfrac{\pi}{2}$ converges if and only if $\alpha < 1$. Both pieces converge, so the integral **converges**, if and only if $-1 < \alpha < 1$.
