Which of the following functions $g$ allows one to deduce, by the comparison test on $[1, +\infty)$, the convergence of
$$
\int_1^{+\infty} \frac{dx}{x^{2} + x + 1} ?
$$

- $g(x) = \dfrac{1}{x}$
- $g(x) = \dfrac{1}{x^{2}}$
- $g(x) = \dfrac{1}{x^{3}}$
- $g(x) = \dfrac{1}{x^{2} + x + 2}$

## Explanation

To deduce convergence one needs $g$ with $0 \leq f \leq g$ and convergent integral. For $x \geq 1$ we have $x^{2} + x + 1 > x^{2}$, so $f(x) < \dfrac{1}{x^{2}}$, and the comparison integral with $\alpha = 2$ converges, therefore the function $\dfrac{1}{x^{2}}$ satisfies both conditions. The function $\dfrac{1}{x}$ is an upper bound, but its integral diverges. The function $\dfrac{1}{x^{2} + x + 2}$ is smaller than $f$, and so is $\dfrac{1}{x^{3}}$ for $x \geq 2$, because in that case $x^{3} \geq 2x^{2} \geq x^{2} + 2x > x^{2} + x + 1$.
