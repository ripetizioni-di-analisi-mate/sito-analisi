Determine for which $\alpha \in \mathbb{R}$ the following integral converges:
$$
\int_1^{+\infty} \frac{x^{\alpha}}{\sqrt{x^{3} + 1}}\,dx .
$$

- $\alpha > \dfrac{1}{2}$
- $\alpha < 2$
- $\alpha < \dfrac{1}{2}$
- $\alpha \leq \dfrac{1}{2}$

## Explanation

For $x \geq 1$ the integrand is continuous and positive for every $\alpha$, so the only singular point is $+\infty$. As $x \to +\infty$ one has $\sqrt{x^{3} + 1} \sim x^{\frac{3}{2}}$, so the integrand is asymptotically equivalent to $\dfrac{x^{\alpha}}{x^{\frac{3}{2}}} = \dfrac{1}{x^{\frac{3}{2} - \alpha}}$. The comparison integral converges if and only if $\dfrac{3}{2} - \alpha > 1$, that is $\alpha < \dfrac{1}{2}$. Therefore, by the **limit comparison test**, the integral **converges if and only if** $\alpha < \dfrac{1}{2}$.
