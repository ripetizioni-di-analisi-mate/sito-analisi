For which of the following functions does Rolle's theorem apply on the interval $[-1, 1]$?

- $f(x) = |x|$
- $f(x) = x^3 - x$
- $f(x) = x^3$
- $f(x) = \dfrac{1}{x^2}$

## Explanation

Rolle's theorem requires $f$ continuous on $[-1, 1]$, differentiable on $(-1, 1)$ and $f(-1) = f(1)$. The function $x^3 - x$ is a polynomial, so it is continuous and differentiable, and $f(-1) = 0 = f(1)$; the hypotheses are therefore **satisfied**. For $|x|$ we have $f(-1) = f(1) = 1$, but $|x|$ is not differentiable at $0$. For $x^3$ we have $f(-1) = -1 \neq 1 = f(1)$, while $\dfrac{1}{x^2}$ is not defined at $0$ and hence is not continuous on $[-1, 1]$.
