To which smoothness class does the function $f(x) = |x|^3$ belong on $\mathbb{R}$?

- $C^{1}$ but not $C^{2}$
- $C^{\infty}$
- $C^{2}$ but not $C^{3}$
- $C^{0}$ but not $C^{1}$

## Explanation

For $x \neq 0$ we have $f'(x) = 3x\,|x|$, and at $0$ the difference quotient $\dfrac{|h|^3}{h}$ tends to $0$, so $f'(x) = 3x\,|x|$ on all of $\mathbb{R}$. In the same way the difference quotient of $f'$ at $0$ is $\dfrac{3h\,|h|}{h} = 3|h|$, which tends to $0$, therefore $f''(x) = 6|x|$ on $\mathbb{R}$, and this function is continuous. The function $6|x|$ has a corner point at $0$, so $f'''(0)$ does not exist. Therefore $f$ is of class $C^{2}$ but **not** of class $C^{3}$.
