Which of the following equalities, read from left to right, is true as $x \to 0$?

- $x^2 = o(x^3)$
- $o(x^2) + o(x^3) = o(x^3)$
- $\dfrac{o(x^3)}{x} = o(x^3)$
- $x^3 = o(x^2)$

## Explanation

As $x \to 0$ the notation $g(x) = o\bigl(h(x)\bigr)$ means $\dfrac{g(x)}{h(x)} \to 0$. Since $\dfrac{x^3}{x^2} = x \to 0$, the equality $x^3 = o(x^2)$ holds. The ratio $\dfrac{x^2}{x^3} = \dfrac{1}{x}$ does not tend to $0$, so $x^2$ is not $o(x^3)$. The function $x^2 \sqrt[3]{x}$ is $o(x^2)$ and is not $o(x^3)$, therefore a sum $o(x^2) + o(x^3)$ is in general only $o(x^2)$. Finally the function $x^3 \sqrt[3]{x}$ is $o(x^3)$, while its quotient by $x$ is $x^2 \sqrt[3]{x}$, which is not $o(x^3)$; dividing an $o(x^3)$ by $x$ gives only an $o(x^2)$.
