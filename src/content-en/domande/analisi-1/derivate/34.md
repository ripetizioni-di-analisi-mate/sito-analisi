Let $f(x) = \arctan x + \arctan \dfrac{1}{x}$. What is the value of $f(x)$ for every $x > 0$?

- $\dfrac{\pi}{2}$
- $0$
- $\dfrac{\pi}{4}$
- $-\dfrac{\pi}{2}$

## Explanation

For $x \neq 0$ the derivative of the second term is $\dfrac{1}{1 + \frac{1}{x^2}} \cdot \left( -\dfrac{1}{x^2} \right) = -\dfrac{1}{x^2 + 1}$, so
$$
f'(x) = \frac{1}{1 + x^2} - \frac{1}{1 + x^2} = 0 .
$$
The set $(0, +\infty)$ is an interval, therefore by the theorem on the **zero derivative on an interval** $f$ is constant on $(0, +\infty)$. The value of the constant is computed at $x = 1$, and it is $f(1) = \dfrac{\pi}{4} + \dfrac{\pi}{4} = \dfrac{\pi}{2}$. On $(-\infty, 0)$ the function is also constant, with value $f(-1) = -\dfrac{\pi}{2}$.
