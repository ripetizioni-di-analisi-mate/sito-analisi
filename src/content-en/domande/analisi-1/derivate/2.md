- $f'(x) = \dfrac{1}{(x + 1)^2}$
- $f'(x) = -\dfrac{1}{(x + 1)^2}$
- $f'(x) = -\dfrac{1}{x + 1}$
- $f'(x) = -\dfrac{1}{(x + 1)^3}$

## Explanation

The numerator of the difference quotient is $\dfrac{1}{x + h + 1} - \dfrac{1}{x + 1}$. Bringing it to a common denominator we obtain
$$
\frac{1}{x + h + 1} - \frac{1}{x + 1} = \frac{(x + 1) - (x + h + 1)}{(x + h + 1)(x + 1)} = \frac{-h}{(x + h + 1)(x + 1)} ,
$$
so for $h \neq 0$ the difference quotient equals $-\dfrac{1}{(x + h + 1)(x + 1)}$. As $h \to 0$ the denominator tends to $(x + 1)^2 \neq 0$, therefore $f'(x) = -\dfrac{1}{(x + 1)^2}$. The minus sign comes from the difference $(x + 1) - (x + h + 1) = -h$.
