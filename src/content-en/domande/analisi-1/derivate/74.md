For which values of $a$ is the function $f(x) = x^3 + a x$ strictly increasing on $\mathbb{R}$?

- $a \geq 0$
- $a > 0$
- $a \leq 0$
- For every $a \in \mathbb{R}$

## Explanation

We have $f'(x) = 3x^2 + a$. If $a > 0$, then $f'(x) > 0$ for every $x$, so $f$ is strictly increasing. If $a = 0$, then $f(x) = x^3$, which is strictly increasing on $\mathbb{R}$ even though $f'(0) = 0$, because the derivative vanishes only at the point $x = 0$. If $a < 0$, then $f'(x) < 0$ for $|x| < \sqrt{-\dfrac{a}{3}}$, so $f$ is decreasing on that interval. Therefore $f$ is strictly increasing on $\mathbb{R}$ **if and only if** $a \geq 0$.
