As $x$ ranges over $\mathbb{R}$, which values does the expression $2 + \sin x \cos x$ take?

- $[1, 3]$
- $\left[\dfrac{3}{2}, \dfrac{5}{2}\right)$
- $\left[\dfrac{3}{2}, \dfrac{5}{2}\right]$
- $\left[2, \dfrac{5}{2}\right]$

## Explanation

By the double-angle formula $\sin x \cos x = \dfrac{\sin(2x)}{2}$, so the expression equals
$$
f(x) = 2 + \frac{\sin(2x)}{2} .
$$
As $x$ ranges over $\mathbb{R}$, the function $\sin(2x)$ takes exactly the values in $[-1, 1]$, therefore $\dfrac{\sin(2x)}{2}$ takes all the values in $\left[-\dfrac{1}{2}, \dfrac{1}{2}\right]$. The range of $f$ is thus $\left[\dfrac{3}{2}, \dfrac{5}{2}\right]$, with both endpoints attained, for example at $x = -\dfrac{\pi}{4}$ and at $x = \dfrac{\pi}{4}$.
