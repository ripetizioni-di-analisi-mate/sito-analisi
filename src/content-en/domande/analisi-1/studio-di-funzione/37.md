What is the range of the function $f(x) = \dfrac{e^{x} + e^{-x}}{2}$, defined on $\mathbb{R}$?

- $[1, +\infty)$
- $(1, +\infty)$
- $[0, +\infty)$
- $(0, +\infty)$

## Explanation

The derivative is $f'(x) = \dfrac{e^{x} - e^{-x}}{2}$, positive for $x > 0$ and negative for $x < 0$, so $f$ decreases on $(-\infty, 0]$ and increases on $[0, +\infty)$. Therefore $x = 0$ is the absolute minimum point, with value $f(0) = 1$. Moreover $f(x) \to +\infty$ as $x \to \pm\infty$, and $f$ is continuous, so by the intermediate value theorem it takes every value greater than $1$. The range is therefore $[1, +\infty)$, with the value $1$ included because it is attained.
