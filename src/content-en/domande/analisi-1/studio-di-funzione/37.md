What is the range of the function $f(x) = x\,e^{x}$?

- $\mathbb{R}$
- $\left(-\dfrac{1}{e}, +\infty\right)$
- $\left[-\dfrac{1}{e}, +\infty\right)$
- $[-e, +\infty)$

## Explanation

The derivative $f'(x) = (x + 1)\,e^{x}$ is negative for $x < -1$ and positive for $x > -1$, so $f$ has absolute minimum $f(-1) = -\dfrac{1}{e}$. As $x \to +\infty$ we have $f(x) \to +\infty$, while as $x \to -\infty$ we have $f(x) \to 0^-$, by the hierarchy of infinities. On $[-1, +\infty)$ the function is continuous and increases from $-\dfrac{1}{e}$ to $+\infty$, so by the intermediate value theorem it takes every value $y \geq -\dfrac{1}{e}$. Therefore the range is $\left[-\dfrac{1}{e}, +\infty\right)$; the endpoint $-\dfrac{1}{e}$ is included because it is the value taken at $x = -1$.
