For which values of the real parameter $a$ is the function $f(x) = ax + \sin x$ strictly increasing on $\mathbb{R}$?

- $a > 1$
- $a \geq -1$
- $a \geq 0$
- $a \geq 1$

## Explanation

The derivative is $f'(x) = a + \cos x$, and its minimum value as $x$ varies is $a - 1$, attained where $\cos x = -1$. If $a > 1$ then $f'(x) \geq a - 1 > 0$ for every $x$, so $f$ is strictly increasing. If $a = 1$ then $f'(x) = 1 + \cos x \geq 0$, with isolated zeros at the points $(2k + 1)\pi$; on each interval $\bigl[(2k - 1)\pi, (2k + 1)\pi\bigr]$ the derivative is positive at the interior points, so $f$ is strictly increasing on each of them and hence on $\mathbb{R}$. If $a < 1$ then $f'(\pi) = a - 1 < 0$, so $f$ decreases in a neighborhood of $\pi$. The required condition is therefore $a \geq 1$.
