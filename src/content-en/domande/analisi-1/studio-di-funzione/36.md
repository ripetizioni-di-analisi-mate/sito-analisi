Which statement is true for the function $f(x) = \dfrac{x^2}{x^2 + 1}$, defined on $\mathbb{R}$?

- It has absolute minimum $0$ and absolute maximum $1$
- It has absolute minimum $0$ and no absolute maximum
- It has no absolute minimum and has absolute maximum $1$
- It has neither an absolute minimum nor an absolute maximum

## Explanation

For every $x$ we have $f(x) \geq 0$ and $f(0) = 0$, so $0$ is the **absolute minimum**. Moreover, $f(x) = 1 - \dfrac{1}{x^2 + 1} < 1$ for every $x$, and $f(x) \to 1$ as $x \to \pm\infty$. Therefore the supremum of the function is $1$, but the function does not take the value $1$ at any point, so the absolute maximum **does not exist**. The Weierstrass theorem does not apply, because the domain $\mathbb{R}$ is not bounded.
