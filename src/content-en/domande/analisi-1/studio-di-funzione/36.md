What can be said about the extreme values of the function $f(x) = x^2$ restricted to the open interval $(-1, 2)$?

- It has absolute minimum $0$ and absolute maximum $4$
- It has neither an absolute minimum nor an absolute maximum, because the interval is not closed
- It has absolute minimum $0$ and no absolute maximum
- It has absolute minimum $1$ and absolute maximum $4$

## Explanation

Since $x^2 \geq 0$ and $f(0) = 0$ with $0 \in (-1, 2)$, the value $0$ is attained and is the **absolute minimum**. On $[0, 2)$ the function is increasing, so its values approach $4$ without reaching it, because $x = 2$ does not belong to the interval; on $(-1, 0]$ the values are less than $1$. Therefore $4$ is the supremum and **is not a maximum**. The extreme value theorem does not apply on an open interval, but this does not prevent the existence of the minimum, which is found directly here.
