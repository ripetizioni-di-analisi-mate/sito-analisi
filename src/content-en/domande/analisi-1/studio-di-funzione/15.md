What is the domain of the function $f(x) = \dfrac{\sqrt{4 - x^2}}{\ln(x + 1)}$?

- $(-1, 0) \cup (0, 2]$
- $(-1, 2]$
- $[-2, 0) \cup (0, 2]$
- $(-1, 0) \cup (0, 2)$

## Explanation

The conditions for the function to be defined must be satisfied simultaneously:
$$
\begin{cases} 4 - x^2 \geq 0 \\ x + 1 > 0 \\ \ln(x + 1) \neq 0 \end{cases}
$$
The first gives $-2 \leq x \leq 2$ and the second $x > -1$. Since $\ln(x + 1) = 0$ only for $x + 1 = 1$, the third excludes $x = 0$. Therefore the domain is $(-1, 0) \cup (0, 2]$; the point $x = 2$ belongs to the domain, because there the radicand equals $0$ and the denominator equals $\ln 3 \neq 0$.
