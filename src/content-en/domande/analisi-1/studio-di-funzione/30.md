For the function $f(x) = \sin x - x$, what can be said about the point $x = 0$?

- It is a relative maximum point
- It is a relative minimum point
- It is an inflection point with a horizontal tangent
- It is an inflection point with an oblique tangent

## Explanation

The derivatives are $f'(x) = \cos x - 1$, $f''(x) = -\sin x$ and $f'''(x) = -\cos x$. At $x = 0$ we have $f'(0) = f''(0) = 0$ and $f'''(0) = -1 \neq 0$. By the **higher-order derivative test**, with $n = 3$ odd, the point $x = 0$ is neither a maximum nor a minimum point and it is an **inflection point with a horizontal tangent**, because $f'(0) = 0$. The result agrees with the sign of the first derivative, because $f'(x) = \cos x - 1 \leq 0$ for every $x$ and hence the function is decreasing.
