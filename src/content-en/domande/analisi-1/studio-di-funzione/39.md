On which interval is the function $f(x) = \dfrac{1}{x^2 + 3}$ concave?

- $[-1, 1]$
- $[-\sqrt{3}, \sqrt{3}]$
- $\left[-\dfrac{1}{\sqrt{3}}, \dfrac{1}{\sqrt{3}}\right]$
- $(-\infty, 0]$

## Explanation

The first derivative is $f'(x) = -\dfrac{2x}{(x^2 + 3)^2}$. By the quotient rule,
$$
f''(x) = \frac{-2(x^2 + 3)^2 + 2x \cdot 2(x^2 + 3) \cdot 2x}{(x^2 + 3)^4} = \frac{-2(x^2 + 3) + 8x^2}{(x^2 + 3)^3} = \frac{6(x^2 - 1)}{(x^2 + 3)^3} .
$$
The denominator is positive, so $f''(x) \leq 0$ if and only if $x^2 \leq 1$, that is, for $-1 \leq x \leq 1$. Therefore $f$ is **concave** on $[-1, 1]$ and convex on $(-\infty, -1]$ and on $[1, +\infty)$.
