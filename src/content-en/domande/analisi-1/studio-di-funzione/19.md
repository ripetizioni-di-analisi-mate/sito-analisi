Which symmetry property does the function $f(x) = \ln\!\left(\dfrac{1 - x}{1 + x}\right)$ have?

- It is even
- It is odd
- It is neither even nor odd
- It is both even and odd

## Explanation

The argument of the logarithm is positive for $-1 < x < 1$, so the domain is $(-1, 1)$, which is symmetric with respect to the origin. Since $\ln \dfrac{1}{a} = -\ln a$ for every $a > 0$, for every $x$ in the domain we have
$$
f(-x) = \ln \frac{1 + x}{1 - x} = -\ln \frac{1 - x}{1 + x} = -f(x) .
$$
Therefore the function is **odd** and its graph is symmetric with respect to the origin. The function is not even, because $f\!\left(\dfrac{1}{2}\right) = -\ln 3$ and $f\!\left(-\dfrac{1}{2}\right) = \ln 3$ are different.
