In the open interval $(0, 2\pi)$ the function $f(x) = 2\sin x + \sin(2x)$ has a single relative maximum point. Which one?

- $x = \dfrac{5\pi}{3}$
- $x = \dfrac{\pi}{3}$
- $x = \pi$
- $x = \dfrac{2\pi}{3}$

## Explanation

The derivative is $f'(x) = 2\cos x + 2\cos(2x)$, and with $\cos(2x) = 2\cos^2 x - 1$ we obtain
$$
f'(x) = 2\left(2\cos^2 x + \cos x - 1\right) = 2\,(2\cos x - 1)(\cos x + 1) .
$$
In $(0, 2\pi)$ we have $f'(x) = 0$ for $\cos x = \dfrac{1}{2}$, that is, $x = \dfrac{\pi}{3}$ and $x = \dfrac{5\pi}{3}$, and for $\cos x = -1$, that is, $x = \pi$. The factor $\cos x + 1$ is positive away from $\pi$, so the sign of $f'$ is that of $2\cos x - 1$, which is positive on $\left(0, \dfrac{\pi}{3}\right)$ and on $\left(\dfrac{5\pi}{3}, 2\pi\right)$, negative in between. By the first derivative test $x = \dfrac{\pi}{3}$ is a **relative maximum point**, $x = \dfrac{5\pi}{3}$ a relative minimum point, while $x = \pi$ is stationary but is neither a maximum nor a minimum point.
