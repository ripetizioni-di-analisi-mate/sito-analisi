For the function $f(x) = (x - 1)^4 + x$, which statement about the point $x = 1$ is true?

- It is an oblique inflection point
- It is not an inflection point
- It is a relative minimum point
- It is a horizontal inflection point

## Explanation

The second derivative is $f''(x) = 12(x - 1)^2$, which vanishes at $x = 1$ and is positive for every $x \neq 1$. Since $f''$ does not change sign across $x = 1$, the function is convex in a neighborhood of the point, so $x = 1$ **is not an inflection point**. Moreover, $f'(x) = 4(x - 1)^3 + 1$ equals $1$ at $x = 1$, so by Fermat's theorem the point is neither a relative maximum nor a relative minimum point.
