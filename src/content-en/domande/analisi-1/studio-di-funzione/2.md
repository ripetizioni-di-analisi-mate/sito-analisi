For the function $f(x) = \dfrac{x}{x^2 + 1}$, defined on $\mathbb{R}$, what is the absolute maximum?

- $1$
- $\dfrac{\sqrt{3}}{4}$
- The function has no absolute maximum
- $\dfrac{1}{2}$

## Explanation

By the quotient rule,
$$
f'(x) = \frac{(x^2 + 1) - 2x^2}{(x^2 + 1)^2} = \frac{1 - x^2}{(x^2 + 1)^2} ,
$$
which is positive for $-1 < x < 1$ and negative for $|x| > 1$. Therefore on $[0, +\infty)$ the function increases up to $x = 1$ and then decreases, so $f(x) \leq f(1)$ for every $x \geq 0$. For $x < 0$ the numerator is negative, so $f(x) < 0 < f(1)$. It follows that the **absolute maximum** is $f(1) = \dfrac{1}{2}$.
