Which inequality holds for every $x > 0$?

- $\ln x \geq x - 1$
- $\ln x \leq 1 - x$
- $\ln x \geq 1 - x$
- $\ln x \leq x - 1$

## Explanation

The function $f(x) = \ln x$ has second derivative $f''(x) = -\dfrac{1}{x^2} < 0$, so it is concave on $(0, +\infty)$. The tangent line to the graph at the point $x_0 = 1$ is $y = f(1) + f'(1)\,(x - 1) = x - 1$. By the theorem on the **position with respect to the tangent**, the graph of a concave function lies below each of its tangents, so $\ln x \leq x - 1$ for every $x > 0$. Equality holds only for $x = 1$.
