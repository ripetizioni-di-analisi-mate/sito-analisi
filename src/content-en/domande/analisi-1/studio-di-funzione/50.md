Which vertical line is an axis of symmetry of the graph of $f(x) = |x - 3| + |x + 1|$?

- $x = 1$
- $x = -1$
- $x = 2$
- $x = 0$

## Explanation

The two absolute values vanish at $x = 3$ and at $x = -1$, and the midpoint between these two values is $x = 1$. We set $x = 1 + t$, so
$$
f(1 + t) = |t - 2| + |t + 2| .
$$
Replacing $t$ with $-t$ gives $|-t - 2| + |-t + 2| = |t + 2| + |t - 2|$, that is, the same value. Therefore $f(1 - t) = f(1 + t)$ for every $t \in \mathbb{R}$, and the graph is **symmetric with respect to the line** $x = 1$. The line $x = 0$ is not an axis of symmetry, because $f(3) = 4$ and $f(-3) = 8$ are different.
