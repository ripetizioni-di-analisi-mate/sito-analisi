In the complex plane, the inequality $|z + \bar{z}| \leq 2$ defines a strip. Which one?

- The strip $-2 \leq x \leq 2$
- The strip $-1 \leq y \leq 1$
- The strip $-1 \leq x \leq 1$
- The strip $0 \leq x \leq 1$

## Explanation

Setting $z = x + iy$, one has $z + \bar{z} = 2x$, which is a real number. The inequality becomes $|2x| \leq 2$, that is $|x| \leq 1$. Therefore the set is the vertical strip $-1 \leq x \leq 1$, between the lines $x = -1$ and $x = 1$, boundary included.
