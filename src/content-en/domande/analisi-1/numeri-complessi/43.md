What is the solution in $\mathbb{C}$ of the equation $z + |z| = 2 + i$?

- $\dfrac{3}{4} - i$
- $-\dfrac{3}{4} + i$
- $1 + i$
- $\dfrac{3}{4} + i$

## Explanation

Setting $z = x + iy$, the modulus $|z| = \sqrt{x^2 + y^2}$ is a real number, so the equation is equivalent to the system
$$
\begin{cases}
x + \sqrt{x^2 + y^2} = 2 \\[4pt]
y = 1
\end{cases}
$$
With $y = 1$ the first equation becomes $\sqrt{x^2 + 1} = 2 - x$, which requires $x \leq 2$. Squaring gives $x^2 + 1 = 4 - 4x + x^2$, so $x = \dfrac{3}{4}$, which satisfies $x \leq 2$. Therefore the only solution is $z = \dfrac{3}{4} + i$.
