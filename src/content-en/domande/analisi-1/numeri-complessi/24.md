Let $z$ and $w$ be complex numbers with $|z| = 3$ and $|w| = 5$. Which of the following values can $|z + w|$ take?

- $1$
- $9$
- $15$
- $4$

## Explanation

By the triangle inequality $|z + w| \leq |z| + |w| = 8$. Applying it to $w = (z + w) + (-z)$ one obtains $|w| \leq |z + w| + |z|$, so $|z + w| \geq |w| - |z| = 2$. Therefore $|z + w|$ lies in the interval $[2, 8]$, and among the proposed values only $4$ lies in it. The value $4$ is attained, for example, with $z = 3$ and $w = -3 + 4i$, for which $z + w = 4i$.
