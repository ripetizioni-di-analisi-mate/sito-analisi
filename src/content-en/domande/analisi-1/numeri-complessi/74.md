The sum of the absolute values of the real part and the imaginary part equals $1$, that is, $|\operatorname{Re}(z)| + |\operatorname{Im}(z)| = 1$. Which figure does this condition describe in the complex plane?

- The circle with center the origin and radius $1$
- The square with vertices $1 + i$, $-1 + i$, $-1 - i$, $1 - i$
- The segment with endpoints $1$ and $i$
- The square with vertices $1$, $i$, $-1$, $-i$

## Explanation

Setting $z = x + iy$, the equation is $|x| + |y| = 1$. In the first quadrant, where $x \geq 0$ and $y \geq 0$, it becomes $x + y = 1$, that is, the segment with endpoints $1$ and $i$. The equation does not change if $x$ is replaced by $-x$ or $y$ by $-y$, so the set is symmetric with respect to both axes. Therefore the set consists of the four segments joining $1$, $i$, $-1$, $-i$, that is, of the square with these vertices. The point $\dfrac{1}{2} + \dfrac{1}{2}\, i$ belongs to the set but has modulus $\dfrac{\sqrt{2}}{2}$, so the set is not the circle of radius $1$.
