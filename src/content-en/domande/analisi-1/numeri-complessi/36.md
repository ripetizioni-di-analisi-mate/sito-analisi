What is the smallest integer $n \geq 1$ for which $\left(1 + i\sqrt{3}\right)^n$ is a positive real number?

- $n = 2$
- $n = 3$
- $n = 6$
- $n = 12$

## Explanation

The number $1 + i\sqrt{3}$ has modulus $2$ and argument $\dfrac{\pi}{3}$, so by De Moivre's formula $\left(1 + i\sqrt{3}\right)^n = 2^n e^{i \frac{n\pi}{3}}$. A nonzero number is a positive real number if and only if one of its arguments is an integer multiple of $2\pi$, therefore $\dfrac{n\pi}{3} = 2k\pi$ with $k$ an integer is required, that is $n = 6k$. The smallest value with $n \geq 1$ is $n = 6$, for which the power equals $64$. For $n = 3$ the power equals $-8$, which is real but negative.
