For which real value of $a$ is the number $z = (a + i)(2 - i)$ real?

- $a = -2$
- $a = 2$
- $a = -\dfrac{1}{2}$
- $a = \dfrac{1}{2}$

## Explanation

Expanding the product and using $i^2 = -1$ one obtains
$$
(a + i)(2 - i) = 2a - ai + 2i - i^2 = (2a + 1) + i(2 - a) .
$$
A complex number is real if and only if its imaginary part is zero, so $2 - a = 0$ is required. Therefore $z$ is real for $a = 2$, and in that case $z = 5$. For $a = -\dfrac{1}{2}$ the real part vanishes, and $z = \dfrac{5}{2}\, i$ is purely imaginary.
