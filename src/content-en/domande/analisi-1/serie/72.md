Which description is correct for $\sum_{n=1}^{+\infty} \dfrac{\left(-1\right)^{n}}{4 n + 9}$?

- Diverges to positive infinity
- Converges absolutely
- Converges conditionally
- The partial sums oscillate without a limit

## Explanation

The absolute values $\dfrac{1}{4 n + 9}$ decrease to zero, so the alternating series test applies. The series of absolute values is asymptotically harmonic.
