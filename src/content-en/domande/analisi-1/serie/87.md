Which description is correct for $\sum_{n=1}^{+\infty} \dfrac{4 \left(-1\right)^{n} n}{9 n + 5}$?

- The partial sums oscillate without a limit
- Diverges to negative infinity
- Diverges to positive infinity
- Converges to a finite sum

## Explanation

Even partial sums add the differences between consecutive magnitudes. These differences have order $1/n^2$, so the even subsequence converges. The odd subsequence has a different limit because the magnitudes tend to $\dfrac{4}{9}$.
