Which description is correct for $\sum_{n=1}^{+\infty} \dfrac{3 \left(-1\right)^{n} n}{7 n + 2}$?

- Diverges to positive infinity
- Diverges to negative infinity
- Converges to a finite sum
- The partial sums oscillate without a limit

## Explanation

Even partial sums add the differences between consecutive magnitudes. These differences have order $1/n^2$, so the even subsequence converges. The odd subsequence has a different limit because the magnitudes tend to $\dfrac{3}{7}$.
