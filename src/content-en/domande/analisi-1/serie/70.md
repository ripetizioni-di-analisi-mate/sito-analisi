Which description is correct for $\sum_{n=1}^{+\infty} \dfrac{\left(-1\right)^{n}}{2 n + 5}$?

- Diverges to positive infinity
- Converges conditionally
- Converges absolutely
- The partial sums oscillate without a limit

## Explanation

The absolute values $\dfrac{1}{2 n + 5}$ decrease to zero, so the alternating series test applies. The series of absolute values is asymptotically harmonic.
