Which description is correct for $\sum_{n=1}^{+\infty} \dfrac{\left(-1\right)^{n}}{3 n + 7}$?

- Diverges to positive infinity
- Converges absolutely
- The partial sums oscillate without a limit
- Converges conditionally

## Explanation

The absolute values $\dfrac{1}{3 n + 7}$ decrease to zero, so the alternating series test applies. The series of absolute values is asymptotically harmonic.
