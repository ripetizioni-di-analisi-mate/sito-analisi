- $\dfrac{x^2}{2} + x + 3 \ln|x + 1| + c$
- $\dfrac{x^2}{2} - x + 3 \ln|x + 1| + c$
- $\dfrac{x^2}{2} - x + \ln|x + 1| + c$
- $\dfrac{x^2}{2} - x + 2 \ln|x + 1| + c$

## Explanation

The degree of the numerator is greater than the degree of the denominator, so we perform the **division with remainder**. The quotient of $x^2 + 2$ by $x + 1$ is $x - 1$ with remainder $3$, because $(x + 1)(x - 1) + 3 = x^2 + 2$. Therefore
$$
\int \frac{x^2 + 2}{x + 1}\, dx = \int \left( x - 1 + \frac{3}{x + 1} \right) dx = \frac{x^2}{2} - x + 3 \ln|x + 1| + c .
$$
