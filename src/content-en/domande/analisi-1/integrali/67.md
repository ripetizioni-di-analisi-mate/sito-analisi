Let $f(x) = \dfrac{x + a}{(x - 1)(x + 2)}$, with $a$ a real parameter. For which value of $a$ are the antiderivatives of $f$ written without the term $\ln|x - 1|$?

- $a = 2$
- $a = 1$
- $a = -2$
- $a = -1$

## Explanation

Decompose $f(x) = \dfrac{A}{x - 1} + \dfrac{B}{x + 2}$, with $x + a = A (x + 2) + B (x - 1)$. For $x = 1$ one gets $1 + a = 3A$, so $A = \dfrac{1 + a}{3}$; for $x = -2$ one gets $-2 + a = -3B$, so $B = \dfrac{2 - a}{3}$. The antiderivatives are $A \ln|x - 1| + B \ln|x + 2| + c$, therefore the term $\ln|x - 1|$ is absent if and only if $A = 0$, that is $a = -1$. For $a = 2$ it is $B$ that vanishes, and the term $\ln|x + 2|$ is missing.
