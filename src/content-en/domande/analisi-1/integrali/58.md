Which expression is an antiderivative on $x>0$ of $\dfrac{1}{\left(x + 2\right) \left(x + 3\right)}$?

- $\ln{\left(x + 2 \right)} - \ln{\left(x + 3 \right)}$
- $2 \ln{\left(x + 2 \right)} - \ln{\left(x + 3 \right)}$
- $- \ln{\left(x + 2 \right)} + \ln{\left(x + 3 \right)}$
- $\ln{\left(x + 2 \right)} + \ln{\left(x + 3 \right)}$

## Explanation

Partial fractions give $- \dfrac{1}{x + 3} + \dfrac{1}{x + 2}$. Each term has a logarithmic antiderivative.
