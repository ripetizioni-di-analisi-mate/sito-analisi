The function $x\,(x + 1)^5$ is integrated by parts, differentiating the factor $x$. Which antiderivative is obtained?

- $\dfrac{x (x + 1)^6}{6} + \dfrac{(x + 1)^7}{42}$
- $\dfrac{x^2 (x + 1)^6}{12}$
- $\dfrac{x (x + 1)^6}{6} - \dfrac{(x + 1)^7}{42}$
- $\dfrac{x (x + 1)^6}{6}$

## Explanation

**Integration by parts** is applied with $f(x) = x$ and $g'(x) = (x + 1)^5$. Then $f'(x) = 1$ and, by the power rule, $g(x) = \dfrac{(x + 1)^6}{6}$. The formula gives
$$
\int x (x + 1)^5\, dx = \frac{x (x + 1)^6}{6} - \frac{1}{6} \int (x + 1)^6\, dx = \frac{x (x + 1)^6}{6} - \frac{(x + 1)^7}{42} + c .
$$
The remaining integral reduces to the elementary integral of a power, because the derivative of $x + 1$ is $1$.
