Compute
$$
\int \frac{2x + 3}{x^2 + 2x + 5}\, dx .
$$

- $\ln\left( x^2 + 2x + 5 \right) + \arctan \dfrac{x + 1}{2} + c$
- $\ln\left( x^2 + 2x + 5 \right) + \dfrac{3}{2} \arctan \dfrac{x + 1}{2} + c$
- $\ln\left( x^2 + 2x + 5 \right) + \dfrac{1}{2} \arctan \dfrac{x + 1}{2} + c$
- $\ln\left( x^2 + 2x + 5 \right) + \dfrac{1}{2} \arctan \dfrac{x - 1}{2} + c$

## Explanation

The trinomial $x^2 + 2x + 5$ has discriminant $4 - 20 < 0$, so we isolate in the numerator the derivative of the denominator, $2x + 2$, by writing $2x + 3 = (2x + 2) + 1$. Since $x^2 + 2x + 5 = (x + 1)^2 + 4$, one has
$$
\int \frac{2x + 3}{x^2 + 2x + 5}\, dx = \int \frac{2x + 2}{x^2 + 2x + 5}\, dx + \int \frac{1}{(x + 1)^2 + 4}\, dx .
$$
The first integral equals $\ln\left( x^2 + 2x + 5 \right)$, without absolute value because the trinomial is positive. The second is reducible to the immediate integral $\displaystyle\int \frac{1}{u^2 + k^2}\, du = \frac{1}{k} \arctan \frac{u}{k} + c$ with $u = x + 1$ and $k = 2$. Hence the result is $\ln\left( x^2 + 2x + 5 \right) + \dfrac{1}{2} \arctan \dfrac{x + 1}{2} + c$.
