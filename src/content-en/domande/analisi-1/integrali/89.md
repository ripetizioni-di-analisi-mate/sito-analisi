Let $f(x) = 0$ for $0 \leq x \leq 1$ and $f(x) = 2$ for $1 < x \leq 2$. Which statement is true?

- The average value of $f$ on $[0, 2]$ is $1$ and $f(c) = 1$ for $c = 1$
- The average value of $f$ on $[0, 2]$ is $2$
- The average value of $f$ on $[0, 2]$ is $1$ and $f$ never takes the value $1$
- $f$ is not integrable on $[0, 2]$

## Explanation

The function $f$ is monotone on $[0, 2]$, so it is **integrable**. On $[0, 1]$ it equals $0$, so its integral is $0$. On $[1, 2]$ every upper sum equals $2$, and the lower sum relative to the partition with points $1$, $1 + \delta$, $2$ equals $2(1 - \delta)$, which gets as close to $2$ as desired; therefore $\displaystyle\int_1^2 f(x)\, dx = 2$. By additivity the integral over $[0, 2]$ equals $2$, and the average value is $\dfrac{2}{2} = 1$. The function takes only the values $0$ and $2$, so the conclusion of the **mean value theorem for integrals** does not hold. Indeed the continuity hypothesis is not satisfied, because $f$ has a jump at $x = 1$.
