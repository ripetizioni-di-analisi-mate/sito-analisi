- $x \sin x + \cos x + c$
- $x \sin x - \cos x + c$
- $\dfrac{x^2}{2} \sin x + c$
- $-x \sin x + \cos x + c$

## Explanation

We apply **integration by parts**, differentiating the polynomial, so $f(x) = x$ and $g'(x) = \cos x$. Then $f'(x) = 1$ and $g(x) = \sin x$, and the formula gives
$$
\int x \cos x\, dx = x \sin x - \int \sin x\, dx .
$$
Since $\displaystyle\int \sin x\, dx = -\cos x + c$, one obtains $x \sin x - (-\cos x) + c$, therefore the result is $x \sin x + \cos x + c$.
