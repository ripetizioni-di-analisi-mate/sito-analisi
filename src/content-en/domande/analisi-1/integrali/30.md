The denominator of $\dfrac{x^2 + 1}{x (x - 1)(x + 1)}$ has three simple real roots. What is the indefinite integral of the function?

- $\ln|x| + \ln|x - 1| + \ln|x + 1| + c$
- $-\ln|x| + \ln|x - 1| + \ln|x + 1| + c$
- $-\ln|x| + 2 \ln|x - 1| + 2 \ln|x + 1| + c$
- $\ln|x| - \ln|x - 1| - \ln|x + 1| + c$

## Explanation

The denominator has three simple real roots, $0$, $1$ and $-1$, so it is decomposed into **partial fractions**:
$$
\frac{x^2 + 1}{x (x - 1)(x + 1)} = \frac{A}{x} + \frac{B}{x - 1} + \frac{C}{x + 1}, \qquad x^2 + 1 = A (x - 1)(x + 1) + B x (x + 1) + C x (x - 1) .
$$
For $x = 0$ one gets $1 = -A$, so $A = -1$; for $x = 1$ one gets $2 = 2B$, so $B = 1$; for $x = -1$ one gets $2 = 2C$, so $C = 1$. Therefore the integral equals $-\ln|x| + \ln|x - 1| + \ln|x + 1| + c$.
