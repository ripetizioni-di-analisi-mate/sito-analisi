For $f(x) = \sqrt{x}$ on the interval $[0, 4]$, the mean value theorem for integrals guarantees that there exists $c \in [0, 4]$ such that $\displaystyle\int_0^4 \sqrt{x}\, dx = 4\, f(c)$. What is the value of $c$?

- $2$
- $\dfrac{4}{3}$
- $\dfrac{16}{9}$
- $\dfrac{9}{4}$

## Explanation

The function $\sqrt{x}$ is continuous on $[0, 4]$, so the **mean value theorem for integrals** applies. One has
$$
\int_0^4 \sqrt{x}\, dx = \left[ \frac{2}{3}\, x^{\frac{3}{2}} \right]_0^4 = \frac{16}{3} ,
$$
therefore the average value is $\dfrac{16}{3} \cdot \dfrac{1}{4} = \dfrac{4}{3}$. The point $c$ satisfies $\sqrt{c} = \dfrac{4}{3}$, so $c = \dfrac{16}{9}$, which belongs to $[0, 4]$.
