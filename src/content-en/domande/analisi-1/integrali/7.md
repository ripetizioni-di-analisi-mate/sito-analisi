- $\dfrac{1}{6} \ln \left| \dfrac{x - 3}{x + 3} \right| + c$
- $\dfrac{1}{6} \ln \left| \dfrac{x + 3}{x - 3} \right| + c$
- $\dfrac{1}{3} \ln \left| \dfrac{x - 3}{x + 3} \right| + c$
- $\dfrac{1}{3} \arctan \dfrac{x}{3} + c$

## Explanation

The denominator factors as $x^2 - 9 = (x - 3)(x + 3)$, so it has two simple real roots and the integrand decomposes into **partial fractions**:
$$
\frac{1}{(x - 3)(x + 3)} = \frac{A}{x - 3} + \frac{B}{x + 3}, \qquad 1 = A(x + 3) + B(x - 3) .
$$
For $x = 3$ one obtains $1 = 6A$, so $A = \dfrac{1}{6}$; for $x = -3$ one obtains $1 = -6B$, so $B = -\dfrac{1}{6}$. Therefore the integral equals $\dfrac{1}{6} \ln|x - 3| - \dfrac{1}{6} \ln|x + 3| + c$, which by the properties of the logarithm is written $\dfrac{1}{6} \ln \left| \dfrac{x - 3}{x + 3} \right| + c$.
