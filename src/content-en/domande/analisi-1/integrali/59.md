Which expression is an antiderivative of $\dfrac{1}{\left(x + 3\right) \left(x + 5\right)}$ on $x>0$?

- $- \dfrac{\ln{\left(x + 3 \right)}}{2} + \dfrac{\ln{\left(x + 5 \right)}}{2}$
- $\dfrac{3 \ln{\left(x + 3 \right)}}{2} - \dfrac{\ln{\left(x + 5 \right)}}{2}$
- $\dfrac{\ln{\left(x + 3 \right)}}{2} + \dfrac{\ln{\left(x + 5 \right)}}{2}$
- $\dfrac{\ln{\left(x + 3 \right)}}{2} - \dfrac{\ln{\left(x + 5 \right)}}{2}$

## Explanation

Partial fractions give $- \dfrac{1}{2 x + 10} + \dfrac{1}{2 x + 6}$. Each term has a logarithmic antiderivative.
