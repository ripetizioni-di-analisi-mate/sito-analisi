Which function is the antiderivative of $f(x) = 3x^2 + 2$ that takes the value $5$ at the point $x = 1$?

- $x^3 + 2x + 5$
- $x^3 + 2x + 2$
- $x^3 + 2x - 2$
- $x^3 + 4$

## Explanation

From the table of elementary integrals one obtains $\displaystyle\int \left( 3x^2 + 2 \right) dx = x^3 + 2x + c$. Since two antiderivatives on the interval $\mathbb{R}$ differ by a constant, every antiderivative of $f$ has the form $F(x) = x^3 + 2x + c$.

The condition $F(1) = 5$ gives $1 + 2 + c = 5$, so $c = 2$. Therefore the required antiderivative is $F(x) = x^3 + 2x + 2$.
