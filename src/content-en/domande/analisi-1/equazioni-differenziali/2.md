- $y = C e^{\sin x}$
- $y = C e^{-\sin x}$
- $y = C e^{\cos x}$
- $y = e^{\sin x} + C$

## Explanation

The equation is separable with $g(x) = \cos x$ and $h(y) = y$. Since $h(0) = 0$, the constant function $y \equiv 0$ is a solution. For $y \neq 0$ we separate the variables and, since an antiderivative of $\cos x$ is $\sin x$, we obtain
$$
\int \frac{dy}{y} = \int \cos x \, dx \quad\implies\quad \ln |y| = \sin x + c .
$$
Taking the exponential we get $y = C e^{\sin x}$ with $C = \pm e^{c} \neq 0$. The value $C = 0$ gives the zero solution, therefore the general solution is $y = C e^{\sin x}$ with $C \in \mathbb{R}$.
