- $y = C e^{-x^2}$
- $y = C e^{2x}$
- $y = C e^{x^2}$
- $y = e^{x^2} + C$

## Explanation

The equation is separable with $g(x) = 2x$ and $h(y) = y$. Since $h(0) = 0$, the constant function $y \equiv 0$ is a solution. For $y \neq 0$ we separate the variables and integrate both sides, each in its own variable, obtaining
$$
\int \frac{dy}{y} = \int 2x \, dx \quad\implies\quad \ln |y| = x^2 + c .
$$
Taking the exponential we obtain $y = C e^{x^2}$ with $C = \pm e^{c} \neq 0$. The value $C = 0$ gives the zero solution, so the general solution is $y = C e^{x^2}$ with $C \in \mathbb{R}$.
