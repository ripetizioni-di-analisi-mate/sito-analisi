For which value of the parameter $a$ is the function $y = e^{-2x}$ a solution of the equation $y'' + a\, y' - 2y = 0$?

- $-1$
- $1$
- $3$
- $-3$

## Explanation

The function $e^{rx}$ is a solution if and only if $r$ is a root of the characteristic equation $r^2 + a r - 2 = 0$. We therefore require $r = -2$ to be a root, that is, $4 - 2a - 2 = 0$, hence $a = 1$.

With $a = 1$ the characteristic equation is $r^2 + r - 2 = (r + 2)(r - 1) = 0$, which indeed has the root $-2$.
