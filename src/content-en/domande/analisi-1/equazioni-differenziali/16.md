The solutions of the equation $y' = 3y$ are the functions $y = C e^{3x}$ with $C \in \mathbb{R}$. Which solution has a graph passing through the point $(1, 2)$?

- $y = 2e^{3(x - 1)}$
- $y = 2e^{3x}$
- $y = 2e^{3x - 1}$
- $y = e^{3x} + 2 - e^{3}$

## Explanation

The graph passes through $(1, 2)$ if and only if $y(1) = 2$. Substituting $x = 1$ into the general solution we obtain $C e^{3} = 2$, so $C = 2e^{-3}$. Therefore the solution is
$$
y = 2e^{-3}\, e^{3x} = 2e^{3(x - 1)} .
$$
The function $y = 2e^{3x}$ passes through the point $(0, 2)$. The function $y = e^{3x} + 2 - e^{3}$ passes through $(1, 2)$, but it is not of the form $Ce^{3x}$, so it is not a solution of the equation.
