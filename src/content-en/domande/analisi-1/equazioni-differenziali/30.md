The equation $y' - y = \dfrac{e^{2x}}{y}$ is a Bernoulli equation with a negative exponent. Which function solves the initial value problem formed by this equation and the condition $y(0) = 1$?

- $y = e^{x}$
- $y = e^{x}\sqrt{2x + 1}$
- $y = \sqrt{\dfrac{e^{2x} + e^{-2x}}{2}}$
- $y = (2x + 1)\, e^{2x}$

## Explanation

The equation is a Bernoulli equation with $a(x) = -1$, $b(x) = e^{2x}$ and $\alpha = -1$, so the zero function is not a solution. We set $z = y^{1 - \alpha} = y^2$, which turns the equation into the linear equation
$$
z' - 2z = 2e^{2x} .
$$
With the integrating factor $e^{-2x}$ we get $\left(e^{-2x} z\right)' = 2$, so $z = (2x + C)\, e^{2x}$, and $z(0) = y(0)^2 = 1$ gives $C = 1$. Since $y(0) > 0$, we take the positive root and the solution is $y = e^{x}\sqrt{2x + 1}$, defined for $x > -\dfrac{1}{2}$.
