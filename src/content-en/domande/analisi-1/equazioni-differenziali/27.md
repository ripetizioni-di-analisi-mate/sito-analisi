The function $y_p(x) = x$ is a solution of the equation $y' + y = x + 1$. What is the general solution of the equation?

- $y = x + C e^{x}$
- $y = x + C e^{-x}$
- $y = C x + e^{-x}$
- $y = C \left( x + e^{-x} \right)$

## Explanation

By the **structure of the general solution**, the solutions of a first-order linear equation are obtained by adding the general solution of the associated homogeneous equation to a particular solution. The associated homogeneous equation $y' + y = 0$ has $a(x) = 1$, so its general solution is $C e^{-x}$. Since $y_p = x$ is a solution of the nonhomogeneous equation, the general solution is $y = x + C e^{-x}$ with $C \in \mathbb{R}$. The functions $C x + e^{-x}$ and $C \left( x + e^{-x} \right)$ satisfy $y' + y = C (x + 1)$, so they are solutions only for $C = 1$.
