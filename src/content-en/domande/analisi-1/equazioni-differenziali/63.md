The equation $y' + y = 2\sin x$ is solved with the integrating factor. Which general solution is obtained?

- $y = \sin x - \cos x + C e^{x}$
- $y = \sin x - \cos x + C e^{-x}$
- $y = \sin x + \cos x + C e^{-x}$
- $y = -2\cos x + C e^{-x}$

## Explanation

The equation is linear with $a(x) = 1$, so the integrating factor is $e^{x}$ and the equation is equivalent to
$$
\left(e^{x} y\right)' = 2e^{x} \sin x .
$$
Integrating by parts twice gives the antiderivative $\displaystyle\int 2e^{x}\sin x\, dx = e^{x}(\sin x - \cos x)$. Hence $e^{x} y = e^{x}(\sin x - \cos x) + C$ and, dividing by $e^{x}$, the general solution is $y = \sin x - \cos x + C e^{-x}$ with $C \in \mathbb{R}$.
