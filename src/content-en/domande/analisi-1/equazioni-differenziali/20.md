What is the general solution of the equation $y' = e^{x - y}$?

- $y = x + C$
- $y = \ln\left( C - e^{-x} \right)$
- $y = -\ln\left( e^{-x} + C \right)$
- $y = \ln\left( e^{x} + C \right)$

## Explanation

Since $e^{x - y} = e^{x}\, e^{-y}$, the equation is separable with $g(x) = e^{x}$ and $h(y) = e^{-y}$. The function $h$ never vanishes, so the equation has no constant solutions. Separating the variables we obtain
$$
\int e^{y} \, dy = \int e^{x} \, dx \quad\implies\quad e^{y} = e^{x} + C .
$$
Taking the logarithm we obtain the general solution $y = \ln\left( e^{x} + C \right)$ with $C \in \mathbb{R}$, where each solution is defined on the interval on which $e^{x} + C > 0$. The function $y = x + C$ has derivative $1$, while $e^{x - y} = e^{-C}$, therefore it is a solution only for $C = 0$.
