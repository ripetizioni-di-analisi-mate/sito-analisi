Which of the following functions is a particular solution of $y'' + 9 y=5 \cos{\left(3 x \right)}$?

- $\dfrac{5 x \sin{\left(3 x \right)}}{3}$
- $- \dfrac{5 x \sin{\left(3 x \right)}}{6}$
- $\dfrac{5 x \sin{\left(3 x \right)}}{6}$
- $\dfrac{5 x \cos{\left(3 x \right)}}{6}$

## Explanation

The forcing term is resonant with the homogeneous solutions. Applying the operator to $x \sin{\left(3 x \right)}$ gives $6 \cos{\left(3 x \right)}$.
