For which of the following right-hand sides $f(x)$ is the particular solution of $y'' - 4y = f(x)$ sought with the trial function of the table multiplied by $x$?

- $f(x) = \sin(2x)$
- $f(x) = x^2$
- $f(x) = e^{-2x}$
- $f(x) = e^{4x}$

## Explanation

The characteristic equation $r^2 - 4 = 0$ has the simple real roots $2$ and $-2$. By the **resonance rule** the trial function must be multiplied by $x$ when the number associated with the right-hand side is a root of the characteristic equation.

The number associated with $e^{-2x}$ is $-2$, which is a root, so for $f(x) = e^{-2x}$ one looks for $y_p = a\, x\, e^{-2x}$. The right-hand sides $\sin(2x)$, $x^2$ and $e^{4x}$ are associated with the numbers $\pm 2i$, $0$ and $4$, which are not roots, therefore in these cases the trial function of the table is not multiplied by $x$.
