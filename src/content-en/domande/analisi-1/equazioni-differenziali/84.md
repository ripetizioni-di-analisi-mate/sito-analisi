Which of the following is a particular solution to $y'' + 16 y=7 \cos{\left(4 x \right)}$?

- $\dfrac{7 x \sin{\left(4 x \right)}}{8}$
- $\dfrac{7 x \sin{\left(4 x \right)}}{4}$
- $\dfrac{7 x \cos{\left(4 x \right)}}{8}$
- $- \dfrac{7 x \sin{\left(4 x \right)}}{8}$

## Explanation

The forcing term is resonant with the homogeneous solutions. Applying the operator to $x \sin{\left(4 x \right)}$ gives $8 \cos{\left(4 x \right)}$.
