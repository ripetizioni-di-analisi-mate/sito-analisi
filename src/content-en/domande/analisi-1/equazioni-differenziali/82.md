Which of the following functions is a particular solution of $y'' + 4 y=3 \cos{\left(2 x \right)}$?

- $\dfrac{3 x \sin{\left(2 x \right)}}{2}$
- $\dfrac{3 x \sin{\left(2 x \right)}}{4}$
- $- \dfrac{3 x \sin{\left(2 x \right)}}{4}$
- $\dfrac{3 x \cos{\left(2 x \right)}}{4}$

## Explanation

The forcing term is resonant with the homogeneous solutions. Applying the operator to $x \sin{\left(2 x \right)}$ gives $4 \cos{\left(2 x \right)}$.
