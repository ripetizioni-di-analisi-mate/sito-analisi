For the equation $y'' + 4y = x + \sin(2x)$, which form of particular solution does the method of undetermined coefficients prescribe? The letters $a$, $b$, $c$, $d$ denote constants to be determined.

- $y_p = a x + b + c \cos(2x) + d \sin(2x)$
- $y_p = x (a x + b) + c \cos(2x) + d \sin(2x)$
- $y_p = a x + b + x \bigl( c \cos(2x) + d \sin(2x) \bigr)$
- $y_p = a x + b + x^2 \bigl( c \cos(2x) + d \sin(2x) \bigr)$

## Explanation

The characteristic equation $r^2 + 4 = 0$ has the simple roots $\pm 2i$. By the **linearity** of the equation, we look for a particular solution for each term of $f$ and add the results. The polynomial $x$ is associated with the number $0$, which is not a root, so the trial function is $a x + b$. The term $\sin(2x)$ is associated with the number $\pm 2i$, which is a simple root, so the trial function $c \cos(2x) + d \sin(2x)$ must be multiplied by $x$. Therefore the prescribed form is $y_p = a x + b + x \bigl( c \cos(2x) + d \sin(2x) \bigr)$.
