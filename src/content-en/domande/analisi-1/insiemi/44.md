Given that $\sinh x = \dfrac{3}{4}$, what is the value of $\cosh x$?

- $\dfrac{\sqrt{7}}{4}$
- $\dfrac{5}{4}$
- $\dfrac{7}{4}$
- $\dfrac{25}{16}$

## Explanation

From the fundamental identity $\cosh^2 x - \sinh^2 x = 1$ we obtain $\cosh^2 x = 1 + \dfrac{9}{16} = \dfrac{25}{16}$. The hyperbolic cosine has range $[1, +\infty)$, so it is positive and $\cosh x = \dfrac{5}{4}$. Indeed $\sinh x = \dfrac{3}{4}$ for $x = \ln 2$, and $\cosh(\ln 2) = \dfrac{2 + \frac{1}{2}}{2} = \dfrac{5}{4}$. The value $\dfrac{\sqrt{7}}{4}$ is obtained with the trigonometric identity $\sin^2 x + \cos^2 x = 1$, which does not hold for the hyperbolic functions. The value $\dfrac{25}{16}$ is $\cosh^2 x$.
