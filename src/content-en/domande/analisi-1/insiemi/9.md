The set $A = \left\{ \dfrac{3n + 1}{n} : n \in \mathbb{N},\ n \geq 1 \right\}$ has infimum $3$. Which statement about the minimum of $A$ is true?

- $\min A = 3$, because $3$ is a lower bound
- $\min A = 4$, obtained for $n = 1$
- $A$ has no minimum, because $3 \notin A$
- $A$ has no minimum, because it is not bounded below

## Explanation

The elements of $A$ can be written as $\dfrac{3n + 1}{n} = 3 + \dfrac{1}{n}$. Since $\dfrac{1}{n} > 0$ for every $n \geq 1$, every element is greater than $3$, so $3$ is a lower bound and $A$ is bounded below. The infimum is the minimum of $A$ only if it belongs to $A$. The equation $3 + \dfrac{1}{n} = 3$ is equivalent to $\dfrac{1}{n} = 0$, which has no solutions; therefore $3 \notin A$ and $A$ **has no minimum**. The value $4$, obtained for $n = 1$, is the maximum of $A$.
