Which statement about the supremum of the set $A = \{x \in \mathbb{R} : x^2 < 5\}$ is correct?

- $\sup A = \sqrt{5}$ and $A$ has no maximum
- $\sup A = \max A = \sqrt{5}$
- $\sup A = 5$ and $A$ has no maximum
- $\sup A = +\infty$

## Explanation

The inequality $x^2 < 5$ is satisfied for $-\sqrt{5} < x < \sqrt{5}$, so $A = \left( -\sqrt{5}, \sqrt{5} \right)$.

The set of upper bounds of an interval that is open on the right at $\sqrt{5}$ is $\left[ \sqrt{5}, +\infty \right)$, therefore $\sup A = \sqrt{5}$.

Since $\left( \sqrt{5} \right)^2 = 5$ is not less than $5$, we have $\sqrt{5} \notin A$. The supremum does not belong to the set, so $A$ **has no maximum**.
