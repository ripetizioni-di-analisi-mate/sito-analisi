On which set is the function $f(x) = \dfrac{1}{\sqrt{|x| - x}}$ defined?

- $\mathbb{R}$
- $(-\infty, 0)$
- $\mathbb{R} \setminus \{0\}$
- $(0, +\infty)$

## Explanation

The root is in the denominator, so the radicand must be strictly positive: $|x| - x > 0$.

For $x \geq 0$ we have $|x| = x$, therefore $|x| - x = 0$ and the condition is not satisfied. For $x < 0$ we have $|x| = -x$, therefore $|x| - x = -2x > 0$ and the condition is satisfied.

Hence the domain is $(-\infty, 0)$. The set $\mathbb{R}$ would be obtained by requiring only $|x| - x \geq 0$, that is, by neglecting the condition that the denominator be different from $0$.
