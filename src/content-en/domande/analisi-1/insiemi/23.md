## Explanation

The function is defined where the radicand is greater than or equal to $0$, the argument of the logarithm is positive and the denominator is different from $0$, so the conditions to be satisfied simultaneously are
$$
\begin{cases}
2 - x \geq 0 \\[4pt]
x + 3 > 0 \\[4pt]
\ln(x + 3) \neq 0
\end{cases}
$$
The first gives $x \leq 2$ and the second $x > -3$. Since $\ln(x + 3) = 0$ if and only if $x + 3 = 1$, the third excludes the point $x = -2$. The point $2$ belongs to the domain, because the root of $0$ is defined and at $x = 2$ the denominator equals $\ln 5 \neq 0$. Hence $D = (-3, -2) \cup (-2, 2]$.
