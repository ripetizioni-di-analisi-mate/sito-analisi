Given the intervals $A = [-2, 3)$ and $B = [1, 5]$, which set is the complement $(A \cap B)^{c}$ in $\mathbb{R}$?

- $(-\infty, -2) \cup (5, +\infty)$
- $(-\infty, 1] \cup (3, +\infty)$
- $(-\infty, 1) \cup [3, +\infty)$
- $[-2, 1) \cup [3, 5]$

## Explanation

The intersection contains the points that belong to both intervals, that is, those with $1 \leq x < 3$; so $A \cap B = [1, 3)$. The complement in $\mathbb{R}$ contains the real numbers that do not belong to $[1, 3)$, that is, those with $x < 1$ or $x \geq 3$. The point $1$ belongs to $A \cap B$, therefore it is excluded from the complement, while the point $3$ does not belong to $A$ and so it belongs to the complement. Hence $(A \cap B)^{c} = (-\infty, 1) \cup [3, +\infty)$. The same set is obtained with **De Morgan's law** $(A \cap B)^{c} = A^{c} \cup B^{c}$, since $A^{c} = (-\infty, -2) \cup [3, +\infty)$ and $B^{c} = (-\infty, 1) \cup (5, +\infty)$. The set $(-\infty, -2) \cup (5, +\infty)$ is the complement of the union $A \cup B = [-2, 5]$.
