For every $n \geq 1$ let $I_n = \left( -\dfrac{1}{n},\ 1 + \dfrac{1}{n} \right)$. What is the set of the $x \in \mathbb{R}$ that belong to *all* the intervals $I_n$?

- $(0, 1)$
- $(-1, 2)$
- $[0, 1]$
- $\emptyset$

## Explanation

A number $x$ belongs to all the intervals if and only if $-\dfrac{1}{n} < x < 1 + \dfrac{1}{n}$ for every $n \geq 1$.

If $0 \leq x \leq 1$, then $-\dfrac{1}{n} < 0 \leq x$ and $x \leq 1 < 1 + \dfrac{1}{n}$ for every $n$, so $x$ belongs to every $I_n$. In particular $0$ and $1$ belong to the intersection, even though no $I_n$ has them as endpoints.

If $x < 0$, by the Archimedean property there is a natural number $n$ with $\dfrac{1}{n} < -x$, that is, $x < -\dfrac{1}{n}$, so $x \notin I_n$. If $x > 1$, in the same way there is an $n$ with $\dfrac{1}{n} < x - 1$, therefore $x \notin I_n$. Hence the intersection is $[0, 1]$.
