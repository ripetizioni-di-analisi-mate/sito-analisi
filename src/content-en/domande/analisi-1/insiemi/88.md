The function $f(x) = x - \lfloor x \rfloor$, defined on $\mathbb{R}$, is called the fractional part of $x$; the symbol $\lfloor x \rfloor$ denotes the largest integer less than or equal to $x$. What can be said about the period and the image of $f$?

- $f$ is periodic with period $1$ and its image is $[0, 1]$
- $f$ is periodic with period $1$ and its image is $[0, 1)$
- $f$ is odd and its image is $(-1, 1)$
- $f$ is not periodic and its image is $[0, +\infty)$

## Explanation

By definition $\lfloor x \rfloor \leq x < \lfloor x \rfloor + 1$, so $0 \leq f(x) < 1$ for every $x$. Every value $t \in [0, 1)$ is attained, because $f(t) = t - 0 = t$; the value $1$ is never attained. Therefore the image is $[0, 1)$.

Since $\lfloor x + 1 \rfloor = \lfloor x \rfloor + 1$, we have $f(x + 1) = x + 1 - \lfloor x \rfloor - 1 = f(x)$, so $f$ is periodic with period $1$.

The function is not odd, because $f\left( \dfrac{1}{2} \right) = \dfrac{1}{2}$ and $f\left( -\dfrac{1}{2} \right) = -\dfrac{1}{2} + 1 = \dfrac{1}{2}$.
