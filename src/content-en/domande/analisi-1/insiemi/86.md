For which $x \in \mathbb{R}$ does the equality $|x + 3| = |x| + 3$ hold?

- $x \leq 0$
- $x \geq -3$
- For every $x \in \mathbb{R}$
- $x \geq 0$

## Explanation

The two absolute values change expression at $x = -3$ and at $x = 0$, so three cases are studied.

For $x \geq 0$ we have $|x + 3| = x + 3$ and $|x| = x$, so the equality becomes $x + 3 = x + 3$, which is true. For $-3 \leq x < 0$ we have $|x + 3| = x + 3$ and $|x| = -x$, so the equality becomes $x + 3 = -x + 3$, that is, $x = 0$, which does not belong to this case. For $x < -3$ the equality becomes $-x - 3 = -x + 3$, that is, $-3 = 3$, which is false.

Hence the equality holds for $x \geq 0$. For example, for $x = -1$ we have $|x + 3| = 2$ and $|x| + 3 = 4$.
