Which of the following functions is odd?

- $\cos x + x^2$
- $x^3 + 1$
- $x^2\,|x|$
- $x\,|x|$

## Explanation

For $f(x) = x\,|x|$ we have $f(-x) = (-x)\,|-x| = -x\,|x| = -f(x)$, because $|-x| = |x|$; hence $f$ is **odd**. The functions $\cos x + x^2$ and $x^2\,|x|$ are even, since $\cos(-x) = \cos x$, $(-x)^2 = x^2$ and $|-x| = |x|$. The function $x^3 + 1$ equals $2$ at $x = 1$ and $0$ at $x = -1$. Since $0$ is different from both $2$ and $-2$, the function $x^3 + 1$ is neither even nor odd.
