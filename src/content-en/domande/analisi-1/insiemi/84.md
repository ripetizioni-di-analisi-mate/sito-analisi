Which set of real numbers solves the inequality $|x - 1| > 2x$?

- $x < -1$
- $x < \dfrac{1}{3}$
- $-1 < x < \dfrac{1}{3}$
- $x > \dfrac{1}{3}$

## Explanation

We distinguish the two cases of the absolute value and take the union of the solutions.

If $x \geq 1$, then $|x - 1| = x - 1$ and the inequality becomes $x - 1 > 2x$, that is, $x < -1$; this condition is incompatible with $x \geq 1$, so the first case gives no solutions.

If $x < 1$, then $|x - 1| = 1 - x$ and the inequality becomes $1 - x > 2x$, that is, $x < \dfrac{1}{3}$; these values also satisfy $x < 1$. Therefore the solutions are $x < \dfrac{1}{3}$.
