Let $A$ be the set of positive divisors of $12$ and $B$ the set of positive divisors of $18$. Which set is the symmetric difference $A \,\triangle\, B = (A \setminus B) \cup (B \setminus A)$?

- $\{1, 2, 3, 6\}$
- $\{4, 12\}$
- $\{9, 18\}$
- $\{4, 9, 12, 18\}$

## Explanation

Listing the divisors gives $A = \{1, 2, 3, 4, 6, 12\}$ and $B = \{1, 2, 3, 6, 9, 18\}$.

The common elements are $1$, $2$, $3$, $6$, so $A \cap B = \{1, 2, 3, 6\}$. Removing them from $A$ gives $A \setminus B = \{4, 12\}$, and removing them from $B$ gives $B \setminus A = \{9, 18\}$.

The symmetric difference is the union of the two differences, that is, the set of elements that lie in exactly one of the two sets. Therefore $A \,\triangle\, B = \{4, 9, 12, 18\}$.
