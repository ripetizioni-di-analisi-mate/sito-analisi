Given that $\sin x = \dfrac{3}{5}$ and $\dfrac{\pi}{2} < x < \pi$, what is the value of $\sin 2x$?

- $\dfrac{24}{25}$
- $\dfrac{6}{5}$
- $\dfrac{7}{25}$
- $-\dfrac{24}{25}$

## Explanation

From the identity $\sin^2 x + \cos^2 x = 1$ we obtain $\cos^2 x = 1 - \dfrac{9}{25} = \dfrac{16}{25}$. For $\dfrac{\pi}{2} < x < \pi$ the point on the unit circle has negative abscissa, so $\cos x = -\dfrac{4}{5}$. By the **double-angle formula** we have $\sin 2x = 2 \sin x \cos x = 2 \cdot \dfrac{3}{5} \cdot \left( -\dfrac{4}{5} \right) = -\dfrac{24}{25}$. The value $\dfrac{24}{25}$ is obtained with $\cos x = \dfrac{4}{5}$, without taking into account the interval in which $x$ lies. The value $\dfrac{7}{25}$ is that of $\cos 2x = 1 - 2\sin^2 x$.
