Given $A = \{x \in \mathbb{R} : |x| < 2\}$ and $B = \{x \in \mathbb{R} : x^2 \geq 1\}$, which set is $A \cap B$?

- $(-2, -1] \cup [1, 2)$
- $(-2, -1) \cup (1, 2)$
- $[-2, -1] \cup [1, 2]$
- $(-1, 1)$

## Explanation

The inequality $|x| < 2$ is equivalent to $-2 < x < 2$, so $A = (-2, 2)$. The inequality $x^2 \geq 1$ is satisfied for $x \leq -1$ or $x \geq 1$, so $B = (-\infty, -1] \cup [1, +\infty)$. The intersection contains the points that belong to both sets. The points $-1$ and $1$ belong to both $A$ and $B$, while $-2$ and $2$ do not belong to $A$; therefore $A \cap B = (-2, -1] \cup [1, 2)$.
