What is the set of $x \in \mathbb{R}$ for which the equality $\sqrt{x^2 - 2x + 1} = 1 - x$ holds?

- $(-\infty, 1]$
- $[1, +\infty)$
- $\mathbb{R}$
- $\{1\}$

## Explanation

The radicand is the square $(x - 1)^2$, so it is greater than or equal to $0$ for every $x$ and the root is defined on $\mathbb{R}$. The square root of a square is the absolute value of the base, therefore $\sqrt{(x - 1)^2} = |x - 1|$. The equality $|x - 1| = 1 - x = -(x - 1)$ holds if and only if $x - 1 \leq 0$, that is, for $x \leq 1$. Hence the required set is $(-\infty, 1]$. For example, at $x = 2$ the left-hand side equals $1$ and the right-hand side $-1$. The set $[1, +\infty)$ is the one on which the equality $\sqrt{x^2 - 2x + 1} = x - 1$ holds.
