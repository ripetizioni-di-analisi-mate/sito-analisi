- $x > 10$
- $x < 10$
- $2 < x < \dfrac{17}{8}$
- $2 < x < 10$

## Explanation

Since $\left( \dfrac{1}{2} \right)^{-3} = 8$, we have $-3 = \log_{\frac{1}{2}} 8$, and the inequality can be written as $\log_{\frac{1}{2}} (x - 2) > \log_{\frac{1}{2}} 8$. The base $\dfrac{1}{2}$ is less than $1$, so the logarithm is strictly decreasing and the comparison between the arguments has the opposite direction. Together with the domain condition we obtain the system
$$
\begin{cases}
x - 2 < 8 \\[4pt]
x - 2 > 0
\end{cases}
$$
therefore the solutions are $2 < x < 10$. The result $x > 10$ is obtained without reversing the direction.
