The exponential equation $3^{x+1} = 5$ has exactly one real solution. What is $x$?

- $x = \log_3 5$
- $x = \log_5 3 - 1$
- $x = \log_3 4$
- $x = \log_3 5 - 1$

## Explanation

The right-hand side $5$ is positive, so the equation has a solution; since the exponential with base $3$ is injective, the solution is unique.

By the definition of logarithm, the equality $3^{x+1} = 5$ is equivalent to $x + 1 = \log_3 5$. Therefore $x = \log_3 5 - 1$.

The value $\log_3 5$ is that of $x + 1$. The value $\log_3 4$ is obtained by subtracting $1$ from the right-hand side instead of from the exponent.
