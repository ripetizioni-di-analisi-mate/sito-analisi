For the set $A = \left\{ 3 - \dfrac{1}{n} : n \in \mathbb{N},\ n \geq 1 \right\}$, which statement is true?

- $\sup A = \max A = 2$
- $\sup A = 3$ and the maximum does not exist
- $\sup A = \max A = 3$
- $\sup A = +\infty$ and the maximum does not exist

## Explanation

As $n$ increases, the number $\dfrac{1}{n}$ decreases, so the elements $3 - \dfrac{1}{n}$ increase and the smallest is $2$, obtained for $n = 1$. Since $\dfrac{1}{n} > 0$, every element is less than $3$, and therefore $3$ is an upper bound. Given $\varepsilon > 0$, by the Archimedean property there exists a natural number $n > \dfrac{1}{\varepsilon}$, and for this $n$ we have $3 - \dfrac{1}{n} > 3 - \varepsilon$. By the **characterization of the supremum** we conclude that $\sup A = 3$. The equation $3 - \dfrac{1}{n} = 3$ has no solutions, so $3 \notin A$ and $A$ **has no maximum**.
