Which of the following numbers belongs to the natural domain of $f(x) = (x + 2)^{\frac{1}{x}}$?

- $x = 0$
- $x = -2$
- $x = -3$
- $x = -1$

## Explanation

A power of the form $f(x)^{g(x)}$ requires the base to be positive; moreover the exponent $\dfrac{1}{x}$ has the denominator $x$, which must be different from $0$:
$$
\begin{cases}
x + 2 > 0 \\[4pt]
x \neq 0
\end{cases}
$$
Hence the domain is $(-2, 0) \cup (0, +\infty)$, and $x = -1$ belongs to it; indeed $f(-1) = 1^{-1} = 1$.

The point $x = 0$ is excluded because it makes the denominator of the exponent vanish. The point $x = -2$ is excluded because the base equals $0$, and $x = -3$ because the base equals $-1$; in both cases the condition $x + 2 > 0$ is not satisfied.
