- $\left[ \dfrac{3}{2}, +\infty \right)$
- $\left( 0, \dfrac{3}{2} \right)$
- $\left[ 0, \dfrac{3}{2} \right]$
- $\left( 0, \dfrac{3}{2} \right]$

## Explanation

Since $x^2 + 2 \geq 2$ for every $x$, we have $0 < \dfrac{3}{x^2 + 2} \leq \dfrac{3}{2}$, and the value $\dfrac{3}{2}$ is attained at $x = 0$. For $y > 0$ the equation $\dfrac{3}{x^2 + 2} = y$ is equivalent to $x^2 = \dfrac{3}{y} - 2$. The right-hand side is greater than or equal to $0$ for $0 < y \leq \dfrac{3}{2}$, so every value in $\left( 0, \dfrac{3}{2} \right]$ is attained. The value $0$ is not attained, because the numerator $3$ is different from $0$; therefore $f(\mathbb{R}) = \left( 0, \dfrac{3}{2} \right]$.
