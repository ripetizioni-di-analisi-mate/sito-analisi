Let $A = (-2, 5] \cap \mathbb{Z}$. Which statement is true?

- $\min A = -2$ and $\max A = 5$
- $\inf A = -2$ and $A$ has no minimum
- $\min A = -1$ and $A$ has no maximum
- $\min A = -1$ and $\max A = 5$

## Explanation

The integers $k$ with $-2 < k \leq 5$ are $-1, 0, 1, 2, 3, 4, 5$, so $A = \{-1, 0, 1, 2, 3, 4, 5\}$.

The set is finite, therefore it has a minimum and a maximum. The smallest element is $-1$, since $-2$ is excluded from the interval; the largest is $5$, which belongs to the interval. Hence $\min A = -1$ and $\max A = 5$, and consequently $\inf A = -1$ as well.
