Which statement about the minimum and the supremum of the set $A = \left\{ n + \dfrac{1}{n} : n \in \mathbb{N},\ n \geq 1 \right\}$ is correct?

- $\inf A = 2$, $A$ has no minimum and $\sup A = +\infty$
- $\max A = 2$ and $\inf A = 1$
- $\min A = 2$ and $\sup A = +\infty$
- $\inf A = 1$, $A$ has no minimum and $\sup A = +\infty$

## Explanation

For $n = 1$ we get the element $1 + 1 = 2$. Then we compare two consecutive elements:
$$
\left( n + 1 + \frac{1}{n + 1} \right) - \left( n + \frac{1}{n} \right) = 1 - \frac{1}{n(n + 1)} > 0 ,
$$
since $n(n + 1) \geq 2$. Hence the elements increase with $n$ and the smallest one is $2$, which belongs to $A$, therefore $\min A = 2$.

Moreover $n + \dfrac{1}{n} > n$, and by the Archimedean property for every $M$ there is a natural number $n > M$. Then $A$ is not bounded above and $\sup A = +\infty$.
