For the endomorphism $f(x, y, z) = (x + y,\ y + z,\ x - z)$ of $\mathbb{R}^3$, which of the following vectors belongs to $\operatorname{Im} f$?

- $(3, 1, 2)$
- $(1, -1, 1)$
- $(1, 1, 1)$
- $(2, 1, 3)$

## Explanation

A vector in the image is $(a + b,\ b + c,\ a - c)$, and its first component is the sum of the other two, since $(b + c) + (a - c) = a + b$. So $\operatorname{Im} f$ is contained in the plane $x = y + z$. The third row of the matrix, $(1, 0, -1)$, is the difference of the first two, which are not proportional, therefore the rank is $2$ and the image coincides with the plane. Among the proposed vectors only $(3, 1, 2)$ satisfies $x = y + z$. The vector $(1, -1, 1)$ spans the kernel and does not belong to the image.
