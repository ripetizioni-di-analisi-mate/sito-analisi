For the endomorphism $f(x, y, z) = (x + y,\ y + z,\ z)$ of $\mathbb{R}^3$, what is the set of vectors $v$ such that $f(v) = v$?

- The line $\langle (1, 0, 0) \rangle$
- The line $\langle (0, 0, 1) \rangle$
- Only the zero vector
- The plane $z = 0$

## Explanation

The equality $f(v) = v$ is equivalent to $(f - \operatorname{id})(v) = 0$, so the required set is the kernel of the endomorphism $(f - \operatorname{id})(x, y, z) = (y,\ z,\ 0)$, and it is a subspace. The kernel is given by $y = 0$ and $z = 0$, therefore the set is the **line** $\langle (1, 0, 0) \rangle$. The plane $z = 0$ is not fixed by $f$, since $f(0, 1, 0) = (1, 1, 0)$.
