For which value of $k \in \mathbb{R}$ does there exist a linear map $f : \mathbb{R}^2 \to \mathbb{R}^2$ with $f(1, 0) = (2, 1)$, $f(0, 1) = (1, -1)$ and $f(3, 2) = (8, k)$?

- $k = 1$
- $k = 5$
- $k = -1$
- $k = 0$

## Explanation

The vectors $(1, 0)$ and $(0, 1)$ form the standard basis, so the first two values determine $f$ and the third must be compatible with them. Since $(3, 2) = 3\,(1, 0) + 2\,(0, 1)$, by linearity $f(3, 2) = 3\,(2, 1) + 2\,(1, -1) = (8, 1)$. The first component coincides with the assigned one, and the second is equal to $k$ if and only if $k = 1$. For this value the only map with the required properties is $f(x, y) = (2x + y,\ x - y)$.
