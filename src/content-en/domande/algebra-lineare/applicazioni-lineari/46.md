Which of the following functions $f : \mathbb{R} \to \mathbb{R}^3$ is linear and satisfies $f(2) = (4, -2, 6)$?

- $f(t) = (2t,\ -t,\ 3t)$
- $f(t) = (t + 2,\ -t,\ 3t)$
- $f(t) = (t^2,\ -t,\ 3t)$
- $f(t) = (4t,\ -2t,\ 6t)$

## Explanation

Every $t \in \mathbb{R}$ can be written as $t = \dfrac{t}{2} \cdot 2$, so by linearity $f(t) = \dfrac{t}{2}\, f(2) = \dfrac{t}{2}\,(4, -2, 6) = (2t,\ -t,\ 3t)$. A linear map from $\mathbb{R}$ to $\mathbb{R}^3$ is therefore **determined by its value at a single nonzero point**. The function $(t + 2,\ -t,\ 3t)$ equals $(2, 0, 0)$ at $t = 0$, so it is not linear, and the function $(t^2,\ -t,\ 3t)$ is not linear, since its first component at $t = 2$ equals $4$, while twice the value at $t = 1$ equals $2$. The function $(4t,\ -2t,\ 6t)$ is linear, but at $t = 2$ it equals $(8, -4, 12)$.
