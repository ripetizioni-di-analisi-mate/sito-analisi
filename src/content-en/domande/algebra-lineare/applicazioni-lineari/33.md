Does there exist a linear map $f : \mathbb{R}^3 \to \mathbb{R}^3$ with $\ker f = \operatorname{Im} f$?

- Yes, the zero map
- No, because $\dim \ker f + \dim \operatorname{Im} f = 3$ and $3$ is odd
- Yes, a projection onto a plane
- No, because $\ker f$ and $\operatorname{Im} f$ never have vectors in common

## Explanation

If $\ker f = \operatorname{Im} f$, the two dimensions would be equal to the same number $d$. By the **rank-nullity theorem** one would have $3 = d + d = 2d$, which is impossible because $3$ is odd. Therefore a map with this property **does not exist**. The zero map has $\ker f = \mathbb{R}^3$ and $\operatorname{Im} f = \{0\}$, and a projection onto a plane has a line as kernel and the plane as image. The kernel and the image always contain the zero vector, so they have at least one vector in common.
