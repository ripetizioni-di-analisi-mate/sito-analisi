Let $f : \mathbb{R}^3 \to \mathbb{R}$ be linear, with $\ker f$ equal to the plane $x - 2y + z = 0$ and $f(1, 0, 0) = 2$. What is the expression of $f$?

- $f(x, y, z) = x - 2y + z$
- $f(x, y, z) = 2x - 4y + 2z$
- $f(x, y, z) = 2x - 2y + z$
- $f(x, y, z) = 2x + 4y + 2z$

## Explanation

Write $f(x, y, z) = ax + by + cz$. Since $f(1, 0, 0) = 2$, we have $f \neq 0$, so $\dim \operatorname{Im} f = 1$ and, by the **rank-nullity theorem**, $\ker f$ is a plane. The plane $ax + by + cz = 0$ coincides with the plane $x - 2y + z = 0$ if and only if $(a, b, c) = \lambda\,(1, -2, 1)$ with $\lambda \neq 0$. The condition $f(1, 0, 0) = 2$ gives $\lambda = 2$, therefore $f(x, y, z) = 2x - 4y + 2z$. The expression $x - 2y + z$ has the right kernel, but it equals $1$ at $(1, 0, 0)$.
