Let $f : \mathbb{R}^3 \to \mathbb{R}^2$, $f(x, y, z) = (x + y,\ y - z)$, and $g : \mathbb{R}^2 \to \mathbb{R}^3$, $g(a, b) = (a,\ b,\ a + b)$. What is $\ker(g \circ f)$?

- The zero vector only
- $\langle (1, -1, -1) \rangle$
- $\langle (1, 1, 1) \rangle$
- The plane $x + 2y - z = 0$

## Explanation

If $g(a, b) = (0, 0, 0)$, the first two components give $a = b = 0$, so $\ker g = \{(0, 0)\}$ and $g$ is injective. Therefore $g(f(v)) = 0$ if and only if $f(v) = 0$, that is, $\ker(g \circ f) = \ker f$. The kernel of $f$ is given by the system
$$
\begin{cases}
x + y = 0 \\[4pt]
y - z = 0
\end{cases}
$$
whose solutions are $(t, -t, -t)$ with $t \in \mathbb{R}$. Hence $\ker(g \circ f) = \langle (1, -1, -1) \rangle$. The plane $x + 2y - z = 0$ only makes the third component of $(g \circ f)(x, y, z) = (x + y,\ y - z,\ x + 2y - z)$ vanish, and $f(1, 1, 1) = (2, 0)$ is not zero.
