Let $f_k : \mathbb{R}^3 \to \mathbb{R}^2$, $f_k(x, y, z) = (x + ky + z,\ kx + y + kz)$, with $k \in \mathbb{R}$. For which values of $k$ is $f_k$ not surjective?

- For $k = 1$ and for $k = -1$
- Only for $k = 1$
- Only for $k = 0$
- For no value of $k$

## Explanation

The matrix of $f_k$ has rows $(1, k, 1)$ and $(k, 1, k)$, and $f_k$ is surjective if and only if the rank is $2$, that is, if and only if the two rows are not proportional. The second row is proportional to the first only if it equals $k\,(1, k, 1) = (k, k^2, k)$, hence only if $k^2 = 1$. For $k = 1$ both rows equal $(1, 1, 1)$, and for $k = -1$ the second row is $(-1, 1, -1) = -(1, -1, 1)$. Therefore $f_k$ **is not surjective** for $k = \pm 1$, where the rank equals $1$. For $k = 0$ the rows are $(1, 0, 1)$ and $(0, 1, 0)$, which are not proportional.
