Let $f : \mathbb{R}^3 \to \mathbb{R}^3$ be linear with $f(1, 0, 0) = (1, 2, 0)$, $f(0, 1, 0) = (2, 4, 0)$ and $f(0, 0, 1) = (0, 0, 1)$. Which vector belongs to $\ker f$?

- $(1, 2, 0)$
- $(-2, 1, 1)$
- $(2, -1, 0)$
- $(2, 1, 0)$

## Explanation

By linearity $f(a, b, c) = a\,(1, 2, 0) + b\,(2, 4, 0) + c\,(0, 0, 1) = (a + 2b,\ 2a + 4b,\ c)$. The vector $(a, b, c)$ belongs to the kernel if and only if
$$
\begin{cases}
a + 2b = 0 \\[4pt]
c = 0
\end{cases}
$$
so $\ker f = \langle (2, -1, 0) \rangle$. For the other vectors one has $f(1, 2, 0) = (5, 10, 0)$, $f(-2, 1, 1) = (0, 0, 1)$ and $f(2, 1, 0) = (4, 8, 0)$, which are different from the zero vector.
