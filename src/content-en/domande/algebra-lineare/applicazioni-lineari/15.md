Which of the following functions $M_2(\mathbb{R}) \to \mathbb{R}$ is linear?

- $A \mapsto \det A$
- $A \mapsto \operatorname{tr} A + 1$
- $A \mapsto \operatorname{tr} A$
- $A \mapsto \operatorname{rk} A$

## Explanation

The trace is the sum of the diagonal entries, so $\operatorname{tr}(A + B) = \operatorname{tr} A + \operatorname{tr} B$ and $\operatorname{tr}(\lambda A) = \lambda \operatorname{tr} A$, therefore the trace is **linear**. The determinant is not linear, since $\det(2 I_2) = 4$ is different from $2 \det I_2 = 2$. The function $A \mapsto \operatorname{tr} A + 1$ is not linear, since it sends the zero matrix to $1$. The rank is not linear, since $\operatorname{rk}(2 I_2) = 2$ is different from $2 \operatorname{rk} I_2 = 4$.
