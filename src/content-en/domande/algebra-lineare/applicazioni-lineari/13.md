One looks for a linear map $f : \mathbb{R}^2 \to \mathbb{R}^3$ such that $f(1, 0) = (1, 1, 0)$, $f(1, 1) = (1, 0, 1)$ and $f(2, 1) = (2, 1, 1)$. Which statement is true?

- It exists, it is unique and it is not injective
- It exists, it is unique and it is injective
- It exists and is not unique, because the values are assigned on three vectors
- It does not exist, because the three vectors in $\mathbb{R}^2$ are linearly dependent

## Explanation

One has $(2, 1) = (1, 0) + (1, 1)$, so a linear map $f$ must satisfy $f(2, 1) = f(1, 0) + f(1, 1) = (2, 1, 1)$, and the assigned value respects this relation. The vectors $(1, 0)$ and $(1, 1)$ form a basis of $\mathbb{R}^2$, therefore by the existence and uniqueness theorem $f$ **exists and is unique**. From $f(0, 1) = f(1, 1) - f(1, 0) = (0, -1, 1)$ one obtains $f(x, y) = (x,\ x - y,\ y)$. The matrix has columns $(1, 1, 0)$ and $(0, -1, 1)$, which are not proportional, so it has rank $2$ and $f$ is **injective**.
