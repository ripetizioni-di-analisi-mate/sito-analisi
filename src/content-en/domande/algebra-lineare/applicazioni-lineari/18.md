One looks for a linear map $f : \mathbb{R}^2 \to \mathbb{R}^2$ with $f(1, 2) = (1, 0)$ and $f(2, 4) = (2, 1)$. Which statement is true?

- It exists and is unique
- There are infinitely many maps with these properties
- It does not exist
- It exists and is an isomorphism

## Explanation

One has $(2, 4) = 2\,(1, 2)$, so a linear $f$ must satisfy $f(2, 4) = 2\, f(1, 2) = (2, 0)$. The assigned value is $(2, 1)$, different from $(2, 0)$, therefore the relation between the vectors does not hold between the values and $f$ **does not exist**. If the assigned value were $(2, 0)$, there would be infinitely many maps, since $(1, 2)$ alone does not span $\mathbb{R}^2$ and the value on a second vector of a basis could be chosen freely.
