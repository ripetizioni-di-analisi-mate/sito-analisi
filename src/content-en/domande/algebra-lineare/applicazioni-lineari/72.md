The map $T : \mathbb{R}_2[x] \to \mathbb{R}^3$, $T(p) = \big( p(0),\ p(1),\ p(-1) \big)$, is an isomorphism, so there is exactly one polynomial of degree at most $2$ that takes the value $1$ at $x = 0$, $2$ at $x = 1$ and $4$ at $x = -1$. Which polynomial is it?

- $p(x) = 1 + x + 2x^2$
- $p(x) = 2x^2 - x$
- $p(x) = 1 - x + 2x^2$
- $p(x) = 1 - 3x + 4x^2$

## Explanation

Let $p(x) = a + bx + cx^2$. The conditions $p(0) = 1$, $p(1) = 2$ and $p(-1) = 4$ form the system
$$
\begin{cases}
a = 1 \\[4pt]
a + b + c = 2 \\[4pt]
a - b + c = 4
\end{cases}
$$
Subtracting the third equation from the second gives $2b = -2$, so $b = -1$, and then $c = 2 - a - b = 2$. Therefore $p(x) = 1 - x + 2x^2$, the only polynomial with these values, since $T$ is an isomorphism. The polynomial $1 - 3x + 4x^2$ satisfies the first two conditions and equals $8$ at $x = -1$.
