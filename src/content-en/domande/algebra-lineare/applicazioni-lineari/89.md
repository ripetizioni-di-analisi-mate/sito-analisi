Let $f_k : \mathbb{R}^3 \to \mathbb{R}^2$, $f_k(x, y, z) = (x + ky + z,\ 2x + y - z)$, with $k \in \mathbb{R}$. For which value of $k$ does the vector $(1, -1, 1)$ belong to $\ker f_k$?

- $k = -2$
- $k = 1$
- For no value of $k$
- $k = 2$

## Explanation

One computes $f_k(1, -1, 1) = (1 - k + 1,\ 2 - 1 - 1) = (2 - k,\ 0)$. The second component is zero for every $k$, so the vector belongs to the kernel if and only if $2 - k = 0$. Therefore the required value is $k = 2$. The value $k = -2$ comes from getting the sign of the product $k \cdot (-1)$ wrong.
