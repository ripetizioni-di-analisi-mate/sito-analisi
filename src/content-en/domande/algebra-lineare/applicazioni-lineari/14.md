Which of the following functions $f : \mathbb{R}^2 \to \mathbb{R}^2$ is linear?

- $f(x, y) = (x - 3y,\ 2x)$
- $f(x, y) = (x + y,\ y + 1)$
- $f(x, y) = (xy,\ x - y)$
- $f(x, y) = (x - y,\ |y|)$

## Explanation

The function $f(x, y) = (x - 3y,\ 2x)$ can be written as $f(x, y) = A \begin{pmatrix} x \\ y \end{pmatrix}$ with $A = \begin{pmatrix} 1 & -3 \\ 2 & 0 \end{pmatrix}$, so it is **linear**. The function $f(x, y) = (x + y,\ y + 1)$ is not linear, since $f(0, 0) = (0, 1)$ is different from the zero vector. The function $f(x, y) = (xy,\ x - y)$ is not linear, since $f(2, 2) = (4, 0)$ is different from $2\, f(1, 1) = (2, 0)$. The function $f(x, y) = (x - y,\ |y|)$ is not linear, since $f(0, -1) = (1, 1)$ is different from $-f(0, 1) = (1, -1)$.
