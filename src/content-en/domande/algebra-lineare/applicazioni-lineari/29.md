For which values of $k \in \mathbb{R}$ is the map $f : \mathbb{R}^2 \to \mathbb{R}^3$, $f(x, y) = (x + ky,\ 2x + 4y,\ 3x + 6y)$ injective?

- Only for $k = 2$
- For $k \neq 2$
- For $k \neq 0$
- For every $k \in \mathbb{R}$

## Explanation

The map is injective if and only if the matrix has rank $2$, that is, if the columns $(1, 2, 3)$ and $(k, 4, 6)$ are not proportional. The last two components of the second column are twice those of the first, so the columns are proportional if and only if also $k = 2 \cdot 1 = 2$. Therefore $f$ is **injective** for $k \neq 2$. For $k = 2$ one has $f(x, y) = (x + 2y)\,(1, 2, 3)$, and the vector $(2, -1)$ belongs to the kernel.
