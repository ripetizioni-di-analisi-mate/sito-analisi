For which values of $a, b \in \mathbb{R}$ is the function $f : \mathbb{R}^2 \to \mathbb{R}^2$, $f(x, y) = \big( x + (a - 2)\, y^2,\ 3y + a - b \big)$ linear?

- $a = 2$ and $b$ arbitrary
- $a = 0$ and $b = 0$
- $a = 2$ and $b = 0$
- $a = 2$ and $b = 2$

## Explanation

One has $f(0, 0) = (0,\ a - b)$, so the necessary condition $f(0, 0) = (0, 0)$ requires $a = b$. If $a \neq 2$, the first component of $f(0, 2)$ is $4\,(a - 2)$ and the first component of $2\, f(0, 1)$ is $2\,(a - 2)$. These two numbers are different, therefore for $a \neq 2$ the function is not linear. For $a = b = 2$ one obtains $f(x, y) = (x,\ 3y)$, which is **linear**.
