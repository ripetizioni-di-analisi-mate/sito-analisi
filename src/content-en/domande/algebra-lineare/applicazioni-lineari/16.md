The set of linear maps $f : \mathbb{R}^3 \to \mathbb{R}^2$ such that $f(1, 1, 1) = (0, 0)$ is a vector space. What is its dimension?

- $2$
- $3$
- $6$
- $4$

## Explanation

Every linear map $f : \mathbb{R}^3 \to \mathbb{R}^2$ is determined by its matrix $A \in M_{2,3}(\mathbb{R})$ with respect to the standard bases, and every matrix in $M_{2,3}(\mathbb{R})$ defines a linear map. The space of linear maps therefore has dimension $6$, like $M_{2,3}(\mathbb{R})$. The condition $f(1, 1, 1) = (0, 0)$ is equivalent to $A \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix} = 0$, that is, the sum of the entries of each row must be zero. These are two independent linear equations, one per row, so the dimension is $6 - 2 = 4$.
