The endomorphism $f(x, y, z) = (x + y,\ y + 2z,\ z)$ of $\mathbb{R}^3$ is an isomorphism. What is the inverse map $f^{-1}$?

- $f^{-1}(x, y, z) = (x - y,\ y - 2z,\ z)$
- $f^{-1}(x, y, z) = (x - y - 2z,\ y - 2z,\ z)$
- $f^{-1}(x, y, z) = (x - y + 2z,\ y + 2z,\ z)$
- $f^{-1}(x, y, z) = (x - y + 2z,\ y - 2z,\ z)$

## Explanation

To find $f^{-1}(x, y, z)$ one looks for the vector $(a, b, c)$ such that $f(a, b, c) = (x, y, z)$, that is, one solves the system
$$
\begin{cases}
a + b = x \\[4pt]
b + 2c = y \\[4pt]
c = z
\end{cases}
$$
The third equation gives $c = z$, so the second gives $b = y - 2z$. Substituting into the first one obtains $a = x - b = x - y + 2z$. Therefore $f^{-1}(x, y, z) = (x - y + 2z,\ y - 2z,\ z)$.
