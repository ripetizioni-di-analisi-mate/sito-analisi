Let $f : \mathbb{R}^5 \to \mathbb{R}^3$ be a linear map. Which values can $\dim \ker f$ take?

- $0$, $1$, $2$, $3$
- Only $2$
- $0$, $1$, $2$, $3$, $4$, $5$
- $2$, $3$, $4$, $5$

## Explanation

The image is a subspace of $\mathbb{R}^3$, so $\dim \operatorname{Im} f$ is one of the numbers $0, 1, 2, 3$. By the **rank-nullity theorem** $\dim \ker f = 5 - \dim \operatorname{Im} f$, therefore $\dim \ker f$ is one of the numbers $5, 4, 3, 2$. All these values occur, because for every $r \leq 3$ there is a $3 \times 5$ matrix of rank $r$. In particular the kernel always has dimension at least $2$, and hence $f$ is never injective.
