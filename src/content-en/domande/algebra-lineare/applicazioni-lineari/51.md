Let $f : \mathbb{R}^3 \to \mathbb{R}^3$, $f(x, y, z) = (x - z,\ x - z,\ y)$, and let $U = \langle (1, 0, 1), (0, 1, 0) \rangle$. What is the subspace $f(U) = \{ f(u) : u \in U \}$?

- The plane $\langle (1, 1, 0), (0, 0, 1) \rangle$
- The line $\langle (0, 0, 1) \rangle$
- The plane $U$
- The zero vector only

## Explanation

Every vector of $U$ can be written as $u = a\,(1, 0, 1) + b\,(0, 1, 0)$, so by linearity $f(u) = a\, f(1, 0, 1) + b\, f(0, 1, 0)$. One has $f(1, 0, 1) = (0, 0, 0)$ and $f(0, 1, 0) = (0, 0, 1)$, therefore $f(U)$ is the **line** $\langle (0, 0, 1) \rangle$. The dimension drops from $2$ to $1$ because the generator $(1, 0, 1)$ of $U$ belongs to $\ker f$. The plane $\langle (1, 1, 0), (0, 0, 1) \rangle$ is the image of the whole $\mathbb{R}^3$, spanned by $f(e_1) = (1, 1, 0)$, $f(e_2) = (0, 0, 1)$ and $f(e_3) = (-1, -1, 0)$. The vector $(0, 0, 1)$ does not belong to $U$, so $f(U)$ is different from $U$.
