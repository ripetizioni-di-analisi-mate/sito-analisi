Let $T : \mathbb{R}_2[x] \to \mathbb{R}_2[x]$, $T(p) = p + p'$. Which polynomial $p$ satisfies $T(p) = x^2$?

- $p(x) = x^2 - 2x$
- $p(x) = x^2 + 2x + 2$
- $p(x) = x^2 - 2x - 2$
- $p(x) = x^2 - 2x + 2$

## Explanation

One writes $p(x) = a + bx + cx^2$, so $p'(x) = b + 2cx$ and
$$
T(p) = (a + b) + (b + 2c)\, x + c\, x^2 .
$$
Equating the coefficients with those of $x^2$ gives the system
$$
\begin{cases}
c = 1 \\[4pt]
b + 2c = 0 \\[4pt]
a + b = 0
\end{cases}
$$
therefore $c = 1$, $b = -2$ and $a = 2$, that is, $p(x) = x^2 - 2x + 2$. The matrix of $T$ with respect to $(1, x, x^2)$ is triangular with determinant $1$, so $T$ is an isomorphism and this polynomial is the only one with the required property.
