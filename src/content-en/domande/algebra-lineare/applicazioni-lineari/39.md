We look for an endomorphism $f$ of $\mathbb{R}^3$ with $\ker f = \langle (1, 0, 0) \rangle$ and $\operatorname{Im} f$ equal to the plane $z = 0$. Which statement is true?

- It exists and is unique
- It does not exist, because $\ker f$ is contained in $\operatorname{Im} f$
- It exists and is not unique
- It does not exist, because $\dim \ker f + \dim \operatorname{Im} f \neq 3$

## Explanation

The assigned dimensions are $1$ and $2$, with sum $3$, so the **rank-nullity theorem** is satisfied. The map $f(x, y, z) = (y,\ z,\ 0)$ has kernel given by $y = z = 0$, that is $\langle (1, 0, 0) \rangle$, and image $\langle (1, 0, 0), (0, 1, 0) \rangle$, that is the plane $z = 0$. Therefore an endomorphism with the required properties exists, even though the kernel is contained in the image. The map $g(x, y, z) = (2y,\ z,\ 0)$ also has the same kernel and the same image, so the endomorphism is not unique.
