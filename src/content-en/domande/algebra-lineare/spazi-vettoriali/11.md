Which system describes in Cartesian form the subspace $W = \langle (1, 1, 0, 0), (0, 1, 1, 1) \rangle \subseteq \mathbb{R}^4$?

- $\begin{cases} x_1 + x_2 - x_3 = 0 \\ x_3 - x_4 = 0 \end{cases}$
- $\begin{cases} x_1 - x_2 + x_3 = 0 \\ x_3 + x_4 = 0 \end{cases}$
- $\begin{cases} x_1 - x_2 = 0 \\ x_3 - x_4 = 0 \end{cases}$
- $\begin{cases} x_1 - x_2 + x_3 = 0 \\ x_3 - x_4 = 0 \end{cases}$

## Explanation

The two generators are not proportional, so $\dim W = 2$ and $4 - 2 = 2$ independent equations are needed. The generic vector of $W$ is $s\,(1, 1, 0, 0) + t\,(0, 1, 1, 1) = (s, \ s + t, \ t, \ t)$, therefore $x_1 = s$, $x_2 = s + t$, $x_3 = x_4 = t$. Eliminating the parameters gives $x_2 = x_1 + x_3$ and $x_3 = x_4$, that is, the equations $x_1 - x_2 + x_3 = 0$ and $x_3 - x_4 = 0$. Both generators satisfy them, and the two equations are independent, so they describe $W$.
