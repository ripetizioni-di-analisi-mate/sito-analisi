For $k \in \mathbb{R}$ consider the set $W_k$ of the vectors $(x, y, z)$ of $\mathbb{R}^3$ satisfying the equation $x + (k^2 - 1)\,y^2 - z = 0$. For which $k$ is the set $W_k$ a subspace?

- $k \neq \pm 1$
- $k = \pm 1$
- $k = 0$
- For no value of $k$

## Explanation

For $k = \pm 1$ the coefficient $k^2 - 1$ equals $0$, so $W_k$ is the plane $x - z = 0$, which is a subspace because it is the solution set of a homogeneous linear equation.

Now let $c = k^2 - 1 \neq 0$. The vector $v = (-c, 1, 0)$ belongs to $W_k$, since $-c + c \cdot 1 - 0 = 0$. The vector $2v = (-2c, 2, 0)$ instead gives $-2c + 4c = 2c \neq 0$, so $2v \notin W_k$. Therefore for $c \neq 0$ the set is not closed under scalar multiplication, and $W_k$ **is a subspace if and only if $k = \pm 1$**.
