Which of the following sequences is a basis of the subspace $W = \{ p \in \mathbb{R}_3[x] : p(-x) = p(x) \ \text{for all } x \}$?

- $(1, x^2)$
- $(x, x^3)$
- $(x^2)$
- $(1 + x^2)$

## Explanation

Let $p(x) = a + bx + cx^2 + dx^3$. Then $p(-x) = a - bx + cx^2 - dx^3$, so $p(x) - p(-x) = 2bx + 2dx^3$. Therefore $p(-x) = p(x)$ for all $x$ if and only if $b = d = 0$. Therefore $W$ consists of the polynomials $a + cx^2$, with $a, c \in \mathbb{R}$ arbitrary, and $W = \langle 1, x^2 \rangle$. The polynomials $1$ and $x^2$ are not proportional, so they are independent and $(1, x^2)$ is a **basis** of $W$, which has dimension $2$.
