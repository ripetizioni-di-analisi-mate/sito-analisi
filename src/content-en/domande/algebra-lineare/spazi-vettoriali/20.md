For which coefficients $a, b \in \mathbb{R}$ does $3 + 5x + 2x^2 = a\,(1 + x) + b\,(1 + 2x + x^2)$ hold?

- $a = 2$, $b = 1$
- $a = 3$, $b = 2$
- $a = -1$, $b = 2$
- $a = 1$, $b = 2$

## Explanation

The right-hand side is $(a + b) + (a + 2b)\,x + b\,x^2$. Two polynomials are equal if and only if they have the same coefficients, so we need
$$
\begin{cases}
a + b = 3 \\[4pt]
a + 2b = 5 \\[4pt]
b = 2
\end{cases}
$$
The third equation gives $b = 2$ and the first $a = 3 - 2 = 1$. The second equation is satisfied, since $1 + 4 = 5$, therefore $a = 1$ and $b = 2$.
