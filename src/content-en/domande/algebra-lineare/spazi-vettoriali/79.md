The line $W = \langle (1, 2, 3) \rangle$ of $\mathbb{R}^3$ admits several descriptions by equations. Exactly one of the following systems has solution set exactly $W$. Which one?

- $\begin{cases} 2x - y = 0 \\ 4x - 2y = 0 \end{cases}$
- $\begin{cases} 2x - y = 0 \\ 3y - 2z = 0 \end{cases}$
- $\begin{cases} 3x - z = 0 \\ 6x - 2z = 0 \end{cases}$
- $\begin{cases} 2x - y = 0 \\ x + y + z = 0 \end{cases}$

## Explanation

A homogeneous system describes $W$ if the vector $(1, 2, 3)$ satisfies it and the solution subspace has dimension $1$, that is, if the rank of the coefficient matrix is $3 - 1 = 2$.

The vector $(1, 2, 3)$ satisfies $2x - y = 2 - 2 = 0$ and $3y - 2z = 6 - 6 = 0$, and the two equations are not proportional, so the system $\begin{cases} 2x - y = 0 \\ 3y - 2z = 0 \end{cases}$ **describes $W$**. In the systems with $4x - 2y = 0$ and with $6x - 2z = 0$ the second equation is twice the first, therefore the rank is $1$ and the solutions form a plane. The vector $(1, 2, 3)$ does not satisfy $x + y + z = 0$, since $1 + 2 + 3 = 6$.
