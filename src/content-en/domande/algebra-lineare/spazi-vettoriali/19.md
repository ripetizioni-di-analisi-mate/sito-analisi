For which value of $k \in \mathbb{R}$ does the vector $(1, k, 5)$ belong to the subspace $\langle (1, 1, 1), (1, 2, 3) \rangle$ of $\mathbb{R}^3$?

- $k = -3$
- $k = 3$
- $k = 2$
- $k = 4$

## Explanation

The vector belongs to the subspace if and only if there exist $a, b$ with $a\,(1, 1, 1) + b\,(1, 2, 3) = (1, k, 5)$, that is, if the system $a + b = 1$, $a + 2b = k$, $a + 3b = 5$ has a solution. Subtracting the first equation from the third gives $2b = 4$, so $b = 2$ and $a = 1 - 2 = -1$. Substituting into the second equation gives $k = -1 + 4 = 3$. Therefore $(1, k, 5)$ is a **linear combination** of the two vectors if and only if $k = 3$.
