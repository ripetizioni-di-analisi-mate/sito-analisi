In $\mathbb{R}^4$ consider $U : x_1 + x_2 + x_3 + x_4 = 0$ and $W = \langle (1, -1, 0, 0), (1, 1, 1, 1), (0, 0, 1, -1) \rangle$. Which sequence is a basis of $U \cap W$?

- $\big( (1, 1, 1, 1) \big)$
- $\big( (1, -1, 0, 0) \big)$
- $\big( (1, -1, 0, 0), \ (0, 0, 1, -1) \big)$
- $\big( (1, -1, 0, 0), \ (1, 1, 1, 1), \ (0, 0, 1, -1) \big)$

## Explanation

The generic vector of $W$ is $a\,(1, -1, 0, 0) + b\,(1, 1, 1, 1) + c\,(0, 0, 1, -1) = (a + b, \ b - a, \ b + c, \ b - c)$. Substituting into the equation of $U$ gives $4b = 0$, so $b = 0$ and $U \cap W = \langle (1, -1, 0, 0), (0, 0, 1, -1) \rangle$. The two vectors are not proportional, therefore they form a **basis** of $U \cap W$, which has dimension $2$. The vector $(1, 1, 1, 1)$ does not lie in $U$, since the sum of its components equals $4$.
