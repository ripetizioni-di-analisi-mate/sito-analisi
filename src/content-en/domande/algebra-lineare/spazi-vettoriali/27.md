What are the coordinates of $v = (3, 5, 4)$ with respect to the basis $\mathcal{B} = \big( (1, 1, 0), (0, 1, 1), (1, 0, 1) \big)$ of $\mathbb{R}^3$?

- $(3, 5, 4)$
- $(2, 3, 1)$
- $(1, 3, 2)$
- $(2, 1, 3)$

## Explanation

We look for $a, b, c$ such that $a\,(1, 1, 0) + b\,(0, 1, 1) + c\,(1, 0, 1) = (3, 5, 4)$, that is,
$$
\begin{cases}
a + c = 3 \\[4pt]
a + b = 5 \\[4pt]
b + c = 4
\end{cases}
$$
Adding the three equations gives $2\,(a + b + c) = 12$, so $a + b + c = 6$. Subtracting each equation from this equality gives $b = 3$, $c = 1$ and $a = 2$. Therefore the **coordinates** of $v$ with respect to $\mathcal{B}$ are $(2, 3, 1)$.
