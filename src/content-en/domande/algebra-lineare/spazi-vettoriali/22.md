What is the dimension of the subspace $W = \{ p \in \mathbb{R}_2[x] : p(x + 1) = p(x) \ \text{for every } x \in \mathbb{R} \}$ of $\mathbb{R}_2[x]$?

- $1$
- $0$
- $2$
- $3$

## Explanation

Let $p = a + bx + cx^2$. Then
$$
p(x + 1) - p(x) = b + c\,(2x + 1) = 2c\,x + (b + c) .
$$
This polynomial is zero if and only if $2c = 0$ and $b + c = 0$, that is, if and only if $b = c = 0$. Hence $W$ consists of the constant polynomials $p = a$, so $W = \langle 1 \rangle$ and **$\dim W = 1$**. The dimension is not $0$, because every nonzero constant satisfies the condition.
