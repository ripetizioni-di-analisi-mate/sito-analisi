Exactly one of the following subsets of $\mathbb{R}^3$, defined by nonlinear equations, is a vector subspace. Which one?

- $\{ (x, y, z) : x^2 + y^2 + z^2 = 1 \}$
- $\{ (x, y, z) : x^2 + y^2 = z^2 \}$
- $\{ (x, y, z) : xyz = 0 \}$
- $\{ (x, y, z) : x^2 + y^2 + z^2 = 0 \}$

## Explanation

A sum of squares of real numbers is zero only if every term is zero, so $x^2 + y^2 + z^2 = 0$ is equivalent to $x = y = z = 0$. Therefore the set defined by $x^2 + y^2 + z^2 = 0$ is $\{0\}$, which **is the trivial subspace**.

The sphere $x^2 + y^2 + z^2 = 1$ does not contain the zero vector. The cone $x^2 + y^2 = z^2$ contains $(1, 0, 1)$ and $(0, 1, -1)$, while their sum $(1, 1, 0)$ gives $2 \neq 0$. The set $xyz = 0$ contains $(1, 1, 0)$ and $(0, 0, 1)$, while their sum $(1, 1, 1)$ gives $1 \neq 0$. Hence these three sets are not subspaces.
