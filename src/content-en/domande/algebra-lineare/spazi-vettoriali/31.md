What is the dimension of the subspace $W = \{ p \in \mathbb{R}_3[x] : p(1) = p(-1) = 0 \}$?

- $2$
- $1$
- $3$
- $4$

## Explanation

Let $p(x) = a + bx + cx^2 + dx^3$. The conditions $p(1) = 0$ and $p(-1) = 0$ give the homogeneous system
$$
\begin{cases}
a + b + c + d = 0 \\[4pt]
a - b + c - d = 0
\end{cases}
$$
in the coordinates $(a, b, c, d)$ with respect to the standard basis. The two equations are independent, so the coefficient matrix has rank $2$ and $\dim W = 4 - 2 = 2$. Indeed the system is equivalent to $c = -a$ and $d = -b$, and $W = \langle 1 - x^2, \ x - x^3 \rangle$.
