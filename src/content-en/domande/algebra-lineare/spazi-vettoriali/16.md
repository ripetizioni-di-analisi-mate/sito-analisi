For which values of $k \in \mathbb{R}$ is the set $W_k = \{ (x, y, z) \in \mathbb{R}^3 : x + y - z = k^2 - 3k + 2 \}$ a subspace of $\mathbb{R}^3$?

- $k = -1$ or $k = -2$
- $k = 0$ or $k = 3$
- $k = 1$ or $k = 2$
- Only $k = 0$

## Explanation

A subspace contains the zero vector, and $(0, 0, 0)$ satisfies the equation if and only if $k^2 - 3k + 2 = 0$. Since $k^2 - 3k + 2 = (k - 1)(k - 2)$, this happens for $k = 1$ and for $k = 2$. For these values the equation becomes $x + y - z = 0$, and the solution set of a homogeneous linear equation is a subspace. For every other $k$ the zero vector does not belong to $W_k$, therefore $W_k$ is a subspace if and only if $k = 1$ or $k = 2$.
