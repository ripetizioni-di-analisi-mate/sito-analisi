Is there a matrix $A \in M_3(\mathbb{R})$ such that $A^2 = -I_3$?

- Yes, for example $A = -I_3$
- Yes, every $A$ with $\det A = -1$
- No, because one would have $(\det A)^2 = -1$
- No, because $\det (-I_3) = 1$

## Explanation

The matrix $-I_3$ is obtained by multiplying each of the three rows of $I_3$ by $-1$, so $\det (-I_3) = (-1)^3 = -1$. If $A^2 = -I_3$, by **multiplicativity of the determinant** one would have $(\det A)^2 = \det (A^2) = -1$. The square of a real number is not negative, therefore such a matrix **does not exist**. The matrix $-I_3$ has square $I_3$. In $M_2(\mathbb{R})$ the situation is different, since $\det (-I_2) = 1$ and the matrix $\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ has square $-I_2$.
