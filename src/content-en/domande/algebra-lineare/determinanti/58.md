Let $A \in M_4(\mathbb{R})$ with rows $r_1, r_2, r_3, r_4$ and $\det A = 3$. What is the determinant of the matrix with the same rows in reverse order, that is, $r_4, r_3, r_2, r_1$?

- $-3$
- $3$
- $12$
- $-12$

## Explanation

The order $r_4, r_3, r_2, r_1$ is obtained with two row swaps, $R_1 \leftrightarrow R_4$ and $R_2 \leftrightarrow R_3$. Each swap changes the sign of the determinant, so two swaps multiply it by $(-1)^2 = 1$. Therefore the determinant still equals $3$. For a matrix of order $3$, instead, reversing the order of the rows requires a single swap, $R_1 \leftrightarrow R_3$, and changes the sign.
