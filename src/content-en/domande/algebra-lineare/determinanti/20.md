The matrix $J_4$ has ones on the antidiagonal and zeros elsewhere. When the analogous $J_5$ is constructed, how does the determinant sign change relative to $J_4$, and why?

- It changes because the matrix order increases by one.
- It changes because there are five antidiagonal entries.
- It becomes zero because not every diagonal entry is nonzero.
- It stays the same, because inserting the fifth entry into the reversed order adds four inversions.

## Explanation

Sorting the rows of $J_4$ takes $3+2+1=6$ adjacent swaps. For $J_5$ it takes $4+3+2+1=10$. Each swap changes the sign, so the four extra swaps have positive net sign.
