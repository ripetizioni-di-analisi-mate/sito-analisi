Which of the following planes is parallel to the $z$-axis and does not contain it?

- $2x - y = 0$
- $2x - y = 3$
- $2x - y + z = 3$
- $z = 3$

## Explanation

The $z$-axis is the line through the origin with direction vector $\vec{v} = (0, 0, 1)$. By the theorem on the **relative position of a line and a plane**, the plane $ax + by + cz + d = 0$ is parallel to the $z$-axis if $(a, b, c) \cdot (0, 0, 1) = c = 0$, and it does not contain it if the origin does not satisfy the equation, that is, if $d \neq 0$. The plane $2x - y = 3$ satisfies both conditions. The plane $2x - y = 0$ contains the origin, so it contains the whole axis. The plane $2x - y + z = 3$ has $c = 1$, therefore it meets the axis at a single point, and the plane $z = 3$ has normal vector $(0, 0, 1)$, so it is perpendicular to the axis.
