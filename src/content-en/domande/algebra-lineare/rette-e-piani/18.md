Which of the following is a parametric representation of the plane $2x - y + z = 3$, with $s, t \in \mathbb{R}$?

- $P = (0, -3, 0) + s\,(2, -1, 1) + t\,(0, 1, 1)$
- $P = (0, 3, 0) + s\,(1, 2, 0) + t\,(0, 1, 1)$
- $P = (0, -3, 0) + s\,(1, 2, 0) + t\,(0, 1, 1)$
- $P = (0, -3, 0) + s\,(1, 2, 0) + t\,(2, 4, 0)$

## Explanation

A parametric representation of the plane requires a point of the plane and two vectors parallel to the plane and not parallel to each other. The point $(0, -3, 0)$ belongs to the plane, because $0 + 3 + 0 = 3$, while the point $(0, 3, 0)$ does not, because $0 - 3 + 0 = -3$. The vectors $(1, 2, 0)$ and $(0, 1, 1)$ are orthogonal to the normal vector $\vec{n} = (2, -1, 1)$, since $2 - 2 + 0 = 0$ and $0 - 1 + 1 = 0$, so they are parallel to the plane; moreover, they are not parallel to each other. The vector $(2, -1, 1)$ is the normal vector, therefore it is not parallel to the plane. The vector $(2, 4, 0) = 2\,(1, 2, 0)$ is parallel to $(1, 2, 0)$, so together with it it describes a line.
