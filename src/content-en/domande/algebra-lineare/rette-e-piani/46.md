The line $r$ has Cartesian equations $x - z = 1$, $y + 2z = 3$. Which of the following pairs of equations represents the same line $r$?

- $x + y + z = 4$, $y + z = 3$
- $x + y + z = 4$, $x - z = 1$
- $x - z = 1$, $y + 2z = -3$
- $x - z = 1$, $y - 2z = 3$

## Explanation

The Cartesian equations of a line are not unique, because every pair of distinct planes of the pencil with axis $r$ determines the same line. Adding the two equations of $r$ gives $(x - z) + (y + 2z) = 1 + 3$, that is, $x + y + z = 4$, so the plane $x + y + z = 4$ contains $r$. The plane $x - z = 1$ contains $r$ and is not parallel to the plane $x + y + z = 4$, therefore the pair $x + y + z = 4$, $x - z = 1$ represents exactly $r$. The point $(2, 1, 1)$ of $r$ does not satisfy the equations $y + z = 3$ and $y - 2z = 3$, and the point $(1, 3, 0)$ of $r$ does not satisfy the equation $y + 2z = -3$, so the other three pairs represent lines different from $r$.
