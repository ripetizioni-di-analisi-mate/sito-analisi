For which value of $k$ are the planes $x + 2y - kz = 1$ and $2x + 4y + 6z = 3$ parallel?

- $k = 3$
- $k = -6$
- $k = 6$
- $k = -3$

## Explanation

Two planes are parallel if and only if their normal vectors $(1, 2, -k)$ and $(2, 4, 6)$ are parallel. The second vector is twice $(1, 2, 3)$, so the two vectors are parallel if and only if $-k = 3$, that is, $k = -3$. For $k = -3$ the planes are distinct, because the first has equation $x + 2y + 3z = 1$ and the second, divided by $2$, has equation $x + 2y + 3z = \dfrac{3}{2}$.
