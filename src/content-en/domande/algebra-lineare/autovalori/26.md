A matrix $A \in M_3(\mathbb{R})$ has the eigenvalue $2$, with $V_2 = \langle (1, 0, 1),\ (0, 1, 0) \rangle$, and also has the eigenvalue $5$. Which of the following vectors can be an eigenvector of $A$ associated with the eigenvalue $5$?

- $(1, 1, 1)$
- $(2, 3, 2)$
- $(1, 0, -1)$
- $(0, 2, 0)$

## Explanation

Eigenspaces associated with distinct eigenvalues have only the zero vector in common, so $V_2 \cap V_5 = \{0\}$. Therefore an eigenvector associated with $5$ cannot belong to $V_2$. We have
$$
(1, 1, 1) = (1, 0, 1) + (0, 1, 0), \qquad (2, 3, 2) = 2(1, 0, 1) + 3(0, 1, 0), \qquad (0, 2, 0) = 2(0, 1, 0) ,
$$
so these three vectors lie in $V_2$ and are ruled out. The vector $(1, 0, -1)$ is not a linear combination of $(1, 0, 1)$ and $(0, 1, 0)$, because every combination $a(1, 0, 1) + b(0, 1, 0)$ has equal first and third coordinates. Therefore $(1, 0, -1)$ is the only one of the four vectors that can be an eigenvector associated with $5$.
