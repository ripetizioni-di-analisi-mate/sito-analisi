Let $A \in M_4(\mathbb{R})$ with $p_A(\lambda) = (\lambda - 1)^3(\lambda + 2)$. Which values can $\dim V_1$ take?

- Only $3$
- $0$, $1$, $2$ or $3$
- $1$ or $2$
- $1$, $2$ or $3$

## Explanation

The eigenvalue $1$ has algebraic multiplicity $m_a(1) = 3$. By the **relation between the multiplicities** we have $1 \leq m_g(1) \leq m_a(1)$, so $\dim V_1 = m_g(1)$ can be $1$, $2$ or $3$. The value $0$ is excluded, because $1$ is an eigenvalue and therefore $V_1$ contains a nonzero vector. All three values occur: the diagonal matrix with diagonal $1, 1, 1, -2$ has $m_g(1) = 3$, and adding a $1$ in position $(1, 2)$, or in positions $(1, 2)$ and $(2, 3)$, gives $m_g(1) = 2$ and $m_g(1) = 1$.
