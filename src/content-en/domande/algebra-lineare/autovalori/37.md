Which of the following statements is true for every matrix $A \in M_2(\mathbb{R})$?

- If $A^2$ is diagonalizable, then $A$ is diagonalizable
- If $A$ is diagonalizable, then $A$ is invertible
- If $A$ is diagonalizable, then $A^2$ is diagonalizable
- If $A$ is diagonalizable, then $A$ has two distinct eigenvalues

## Explanation

If $P^{-1}AP = D$ with $D$ diagonal, then $P^{-1}A^2P = (P^{-1}AP)(P^{-1}AP) = D^2$, and $D^2$ is diagonal. Therefore $A^2$ is diagonalizable, with the same matrix $P$. The other implications are false. The rotation $A = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$ has $p_A(\lambda) = \lambda^2 + 1$, so it is not diagonalizable over $\mathbb{R}$, while $A^2 = -I_2$ is diagonal. The zero matrix is diagonal and not invertible, and the matrix $I_2$ is diagonal, hence diagonalizable, although its only eigenvalue is $1$.
