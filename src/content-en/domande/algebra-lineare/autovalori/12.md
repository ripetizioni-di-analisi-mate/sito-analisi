Let $f : \mathbb{R}_2[x] \to \mathbb{R}_2[x]$ be the endomorphism defined by $f(p(x)) = p(x + 1)$. Which statement is true?

- The only eigenvalue is $1$, with $m_g(1) = 3$, so $f$ is diagonalizable
- The only eigenvalue is $1$, with $m_g(1) = 1$, so $f$ is not diagonalizable
- The only eigenvalue is $1$, with $m_g(1) = 2$, so $f$ is not diagonalizable
- The only eigenvalue is $1$, with $m_g(1) = 1$, so $f$ is diagonalizable

## Explanation

With respect to the basis $\{1, x, x^2\}$ we have $f(1) = 1$, $f(x) = 1 + x$ and $f(x^2) = 1 + 2x + x^2$, so the associated matrix is
$$
A = \begin{pmatrix} 1 & 1 & 1 \\ 0 & 1 & 2 \\ 0 & 0 & 1 \end{pmatrix} .
$$
The matrix is triangular, so the only eigenvalue is $1$, with $m_a(1) = 3$. The matrix $A - I_3$ has rank $2$, so $m_g(1) = 3 - 2 = 1$, and the eigenspace consists of the constant polynomials. Since $m_g(1) < m_a(1)$, the endomorphism $f$ **is not diagonalizable**.
