A warehouse stores the inventories of two products in a column vector. Matrix $A=\begin{pmatrix}2&1\\0&3\end{pmatrix}$ transforms them, then $B=\begin{pmatrix}1&0\\1&1\end{pmatrix}$ groups them. Which vector describes the effect of one unit of the second product?

- $\begin{pmatrix}1\\4\end{pmatrix}$
- $\begin{pmatrix}1\\3\end{pmatrix}$
- $\begin{pmatrix}2\\2\end{pmatrix}$
- $\begin{pmatrix}3\\3\end{pmatrix}$

## Explanation

The unit input for the second product is $e_2$. First compute $Ae_2=(1,3)^{\mathsf T}$, then apply $B$, which adds the first coordinate to the second. This gives $(1,4)^{\mathsf T}$.
