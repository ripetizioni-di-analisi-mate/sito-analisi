A matrix $A \in M_n(\mathbb{R})$ satisfies $A^2 + 2A - I_n = O$. Which matrix is $A^{-1}$?

- $A - 2I_n$
- $A + 2I_n$
- $-A - 2I_n$
- $2I_n - A$

## Explanation

From the identity we get $A^2 + 2A = I_n$, that is, $A(A + 2I_n) = I_n$. Since $A$ commutes with $I_n$, we also have $(A + 2I_n)A = I_n$, so $A$ is invertible and $A^{-1} = A + 2I_n$. The matrix $-A - 2I_n$ would give $A(-A - 2I_n) = -I_n$.
