Let $A \in M_n(\mathbb{R})$ be a nonzero matrix and let $k \in \mathbb{R}$ be such that $A^T = kA$. Which values can $k$ take?

- Only $k = 1$
- $k = -1$, $k = 0$ or $k = 1$
- Every $k$ with $-1 \leq k \leq 1$
- $k = 1$ or $k = -1$

## Explanation

Transposing the equality $A^T = kA$ and using $(A^T)^T = A$ we get $A = kA^T$. Substituting $A^T = kA$ gives $A = k^2 A$, that is, $(k^2 - 1)A = O$. Since $A \neq O$, at least one entry of $A$ is nonzero, so $k^2 - 1 = 0$ and $k = \pm 1$. Both values occur: for $k = 1$ the matrix $A$ is symmetric, for example $I_n$, and for $k = -1$ it is skew-symmetric, for example $\begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$ for $n = 2$. The value $k = 0$ would give $A^T = O$, hence $A = O$, which is excluded.
