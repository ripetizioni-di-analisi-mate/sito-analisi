In the matrix $A = (a_{ij}) \in M_4(\mathbb{R})$ each entry is the distance $a_{ij} = |i - j|$ between the row index and the column index. Which property does $A$ have?

- $A$ is skew-symmetric
- $A$ is symmetric and $\operatorname{tr} A = 0$
- $A$ is symmetric and $\operatorname{tr} A = 4$
- $A$ is upper triangular

## Explanation

Since $|i - j| = |j - i|$ for all $i, j$, we have $a_{ij} = a_{ji}$, so $A$ is **symmetric**. The diagonal entries are $a_{ii} = |i - i| = 0$, therefore $\operatorname{tr} A = 0$. The matrix is not skew-symmetric, since $a_{12} = a_{21} = 1$ while skew-symmetry would require $a_{21} = -a_{12}$. It is not upper triangular either, since the entry $a_{21} = 1$ below the diagonal is different from $0$.
