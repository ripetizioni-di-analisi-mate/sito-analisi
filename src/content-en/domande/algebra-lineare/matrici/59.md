The row vector $u^T = (1 \ \ {-1} \ \ 2)$ is multiplied on the right by the matrix
$$
A = \begin{pmatrix} 2 & 0 & 1 \\ 1 & 3 & -1 \\ 0 & 1 & 1 \end{pmatrix} .
$$
Which row vector is the product $u^T A$?

- $(4 \ \ {-4} \ \ 1)$
- $(1 \ \ {-2} \ \ 3)$
- $(1 \ \ {-1} \ \ 4)$
- $(3 \ \ 5 \ \ 2)$

## Explanation

The product of a row vector and a matrix is the linear combination of the rows of the matrix with coefficients the components of the vector, as one sees by transposing $u^T A = (A^T u)^T$. Denoting by $R_1, R_2, R_3$ the rows of $A$, we therefore have
$$
u^T A = R_1 - R_2 + 2R_3 = (2 \ \ 0 \ \ 1) - (1 \ \ 3 \ \ {-1}) + (0 \ \ 2 \ \ 2) = (1 \ \ {-1} \ \ 4) .
$$
The vector $(4 \ \ {-4} \ \ 1)$ is $Au$ written as a row, that is the combination of the *columns* of $A$, and $(1 \ \ {-2} \ \ 3)$ is obtained by forgetting the coefficient $2$ of the third row.
