Which matrices $X \in M_2(\mathbb{R})$ commute with *every* matrix of $M_2(\mathbb{R})$?

- All diagonal matrices
- Only $O$ and $I_2$
- Only the matrices $kI_2$, with $k \in \mathbb{R}$
- All symmetric matrices

## Explanation

Let $X = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$ and let $E = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$. We have $XE = \begin{pmatrix} a & 0 \\ c & 0 \end{pmatrix}$ and $EX = \begin{pmatrix} a & b \\ 0 & 0 \end{pmatrix}$, so $XE = EX$ forces $b = 0$ and $c = 0$. With $F = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$ and $X$ diagonal we get $XF = \begin{pmatrix} 0 & a \\ 0 & 0 \end{pmatrix}$ and $FX = \begin{pmatrix} 0 & d \\ 0 & 0 \end{pmatrix}$, therefore $a = d$. Hence $X = aI_2$. Conversely, every matrix $kI_2$ commutes with every $B$, since $(kI_2)B = kB = B(kI_2)$. The diagonal matrix $\operatorname{diag}(1, 2)$ does not commute with $F$, so not every diagonal matrix commutes with every matrix. The matrix $2I_2$ also commutes with every matrix, therefore the matrices with this property are not only $O$ and $I_2$.
