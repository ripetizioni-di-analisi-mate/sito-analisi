Which of the following vectors is a unit vector?

- $\left( \dfrac{1}{3}, \dfrac{1}{3}, \dfrac{1}{3} \right)$
- $\left( \dfrac{1}{3}, \dfrac{2}{3}, -\dfrac{2}{3} \right)$
- $\left( \dfrac{1}{2}, \dfrac{1}{2}, 0 \right)$
- $\left( \dfrac{1}{2}, \dfrac{1}{2}, \dfrac{1}{2} \right)$

## Explanation

A unit vector is a vector of magnitude $1$, therefore one computes the magnitude of each vector. For $\left( \dfrac{1}{3}, \dfrac{2}{3}, -\dfrac{2}{3} \right)$ one has $\dfrac{1}{9} + \dfrac{4}{9} + \dfrac{4}{9} = 1$, so its magnitude equals $1$. The other three vectors, in the order of the list, have magnitude $\sqrt{\dfrac{3}{9}} = \dfrac{\sqrt{3}}{3}$, $\sqrt{\dfrac{2}{4}} = \dfrac{\sqrt{2}}{2}$ and $\sqrt{\dfrac{3}{4}} = \dfrac{\sqrt{3}}{2}$. The vector $\left( \dfrac{1}{3}, \dfrac{1}{3}, \dfrac{1}{3} \right)$ has components with sum $1$, and this property is different from having magnitude $1$.
