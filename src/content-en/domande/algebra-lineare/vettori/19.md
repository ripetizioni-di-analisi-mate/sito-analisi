For which value of $k \in \mathbb{R}$ is the vector $\vec{w} = (2, k, 3)$ a linear combination of the vectors $\vec{u} = (1, 0, 1)$ and $\vec{v} = (0, 1, 1)$?

- $k = 3$
- $k = 5$
- $k = -1$
- $k = 1$

## Explanation

One has $\alpha\vec{u} + \beta\vec{v} = (\alpha,\ \beta,\ \alpha + \beta)$, therefore $\vec{w}$ is a linear combination of $\vec{u}$ and $\vec{v}$ if the system
$$
\begin{cases}
\alpha = 2 \\[4pt]
\beta = k \\[4pt]
\alpha + \beta = 3
\end{cases}
$$
has a solution. From the first and the third equation it follows that $\beta = 1$, so the system has a solution only for $k = 1$. For $k = 1$ one indeed has $\vec{w} = 2\,\vec{u} + \vec{v}$.
