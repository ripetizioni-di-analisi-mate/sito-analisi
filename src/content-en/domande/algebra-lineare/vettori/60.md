The vectors $\vec{u}$ and $\vec{v}$ have magnitudes $\|\vec{u}\| = 3$ and $\|\vec{v}\| = 5$, and the angle between them is not known. Which of the following values can $\|\vec{u} + \vec{v}\|$ take?

- $1$
- $9$
- $6$
- $10$

## Explanation

Let $\theta \in [0, \pi]$ be the angle between the two vectors. Expanding the square with the properties of the dot product one has
$$
\|\vec{u} + \vec{v}\|^2 = \|\vec{u}\|^2 + 2\,\vec{u} \cdot \vec{v} + \|\vec{v}\|^2 = 34 + 30\cos\theta .
$$
Since $\cos\theta$ takes all values in $[-1, 1]$, the square takes all values in $[4, 64]$, therefore $\|\vec{u} + \vec{v}\|$ takes exactly the values in $[2, 8]$. Among the proposed values only $6$ belongs to this interval, and it is obtained for $\cos\theta = \dfrac{1}{15}$.
