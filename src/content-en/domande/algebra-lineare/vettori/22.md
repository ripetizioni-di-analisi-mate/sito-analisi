Which vector has magnitude $10$ and the same direction and orientation as $\vec{v} = (3, 0, -4)$?

- $(30, 0, -40)$
- $(-6, 0, 8)$
- $\left( \dfrac{30}{7}, 0, -\dfrac{40}{7} \right)$
- $(6, 0, -8)$

## Explanation

The magnitude of $\vec{v}$ is $\sqrt{9 + 0 + 16} = 5$, therefore the unit vector of $\vec{v}$ is $\left( \dfrac{3}{5}, 0, -\dfrac{4}{5} \right)$. The vector of magnitude $10$ with the same direction and orientation is $10$ times the unit vector, so it is $(6, 0, -8)$. The vector $(-6, 0, 8)$ has the same magnitude and the same direction, but opposite orientation.
