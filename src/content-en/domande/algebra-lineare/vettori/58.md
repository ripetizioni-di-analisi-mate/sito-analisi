Which of the following points belongs to the line through $A = (1, -1, 2)$ parallel to the vector $\vec{v} = (2, 1, -1)$?

- $(3, 0, 3)$
- $(3, 1, 1)$
- $(2, 1, -1)$
- $(5, 1, 0)$

## Explanation

A point $P$ lies on the line if and only if $\overrightarrow{AP}$ is parallel to $\vec{v}$, that is, if $P = A + t\,\vec{v}$ for some $t \in \mathbb{R}$. For $P = (5, 1, 0)$ one has $\overrightarrow{AP} = (4, 2, -2) = 2\,\vec{v}$, so $P$ lies on the line. For $(3, 0, 3)$ one has $\overrightarrow{AP} = (2, 1, 1)$, whose first two components equal those of $\vec{v}$ and whose third is opposite. For $(3, 1, 1)$ one has $\overrightarrow{AP} = (2, 2, -1)$, which is not a multiple of $\vec{v}$. The point $(2, 1, -1)$ has coordinates equal to the components of $\vec{v}$, but $\overrightarrow{AP} = (1, 2, -3)$ is not parallel to $\vec{v}$.
