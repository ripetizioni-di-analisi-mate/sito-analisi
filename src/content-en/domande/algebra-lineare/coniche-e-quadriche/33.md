For which values of $k$ is the conic
$$
kx^2 + 2xy + ky^2 - 2 = 0
$$
a real ellipse?

- $|k| > 1$
- $k > 1$
- $k < -1$
- $-1 < k < 1$

## Explanation

The associated matrix has $I_3 = -2(k^2 - 1)$, $I_2 = k^2 - 1$ and $I_1 = 2k$. The conic is an ellipse when $I_2 > 0$, that is, for $|k| > 1$, and for these values $I_3 \neq 0$. The ellipse is real if $I_1 I_3 = -4k(k^2 - 1) < 0$; since $k^2 - 1 > 0$, this happens if and only if $k > 0$. Hence the conic is a **real ellipse** for $k > 1$, while for $k < -1$ it is an imaginary ellipse.
