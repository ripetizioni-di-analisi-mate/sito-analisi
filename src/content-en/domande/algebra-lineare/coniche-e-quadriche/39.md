For which value of $c \in \mathbb{R}$ is the quadric
$$
x^2 + 4y^2 - z^2 + 2x - 4z + c = 0
$$
a cone?

- $c = 3$
- $c = 5$
- $c = -5$
- $c = -3$

## Explanation

Completing the squares gives $x^2 + 2x = (x + 1)^2 - 1$ and $-z^2 - 4z = -(z + 2)^2 + 4$, so the equation becomes
$$
(x + 1)^2 + 4y^2 - (z + 2)^2 + c + 3 = 0 .
$$
The coefficients $1$, $4$, $-1$ of the squares do not all have the same sign, therefore the quadric is a cone if and only if the constant term $c + 3$ is zero, that is, for $c = -3$. In this case the vertex is the point $(-1, 0, -2)$; for the other values of $c$ the quadric is a hyperboloid. The value $c = 3$ comes from a sign error in the constant term, and the value $c = 5$ from the incorrect completion $-z^2 - 4z = -(z + 2)^2 - 4$.
