What set is obtained by intersecting the ellipsoid
$$
\frac{x^2}{4} + \frac{y^2}{9} + \frac{z^2}{9} = 1
$$
with the plane $z = 3$?

- The empty set
- An ellipse
- A circle
- Only the point $(0, 0, 3)$

## Explanation

Substituting $z = 3$ we obtain $\dfrac{x^2}{4} + \dfrac{y^2}{9} + 1 = 1$, that is, $\dfrac{x^2}{4} + \dfrac{y^2}{9} = 0$. A sum of squares with positive coefficients is zero only if $x = 0$ and $y = 0$, so the intersection is **only the point** $(0, 0, 3)$. The semi-axis on the $z$-axis equals $3$, therefore the plane $z = 3$ touches the ellipsoid only at the vertex $(0, 0, 3)$.
