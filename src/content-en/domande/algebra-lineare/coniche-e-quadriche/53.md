All the coefficients of the equation of a non-degenerate conic are multiplied by $-1$, so that the curve stays the same. Which of the following quantities stays the same for every non-degenerate conic?

- $I_1 I_3$
- $I_3$
- $I_1$
- $I_2 I_3$

## Explanation

Multiplying the equation by $-1$, the matrix $A$ becomes $-A$ and the block $A_0$ becomes $-A_0$. Since $A$ has order $3$, we have $\det(-A) = -\det A$, so $I_3$ changes sign. Since $A_0$ has order $2$, we have $\det(-A_0) = \det A_0$, while the trace changes sign, so $I_2$ stays the same and $I_1$ changes sign. Therefore the product $I_1 I_3$ stays the same, while $I_2 I_3$ changes sign. For this reason the distinction between real and imaginary ellipses uses the sign of $I_1 I_3$.
