Let $W = \langle (1, 2, 0, 1), (0, 1, 1, -1) \rangle \subseteq \mathbb{R}^4$. Which of the following vectors belongs to $W^\perp$?

- $(-1, 0, 1, 1)$
- $(2, -1, 0, 0)$
- $(0, 1, -1, 0)$
- $(1, 3, 1, 0)$

## Explanation

A vector belongs to $W^\perp$ if and only if it is orthogonal to both generators. For $x = (-1, 0, 1, 1)$ one has $\langle x, (1, 2, 0, 1) \rangle = -1 + 0 + 0 + 1 = 0$ and $\langle x, (0, 1, 1, -1) \rangle = 0 + 0 + 1 - 1 = 0$, therefore $x \in W^\perp$. The vector $(2, -1, 0, 0)$ is orthogonal only to the first generator, and $(0, 1, -1, 0)$ only to the second. The vector $(1, 3, 1, 0)$ is the sum of the two generators, therefore it belongs to $W$, and the only vector common to $W$ and $W^\perp$ is the zero vector.
