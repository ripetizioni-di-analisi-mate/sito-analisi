Let $A \in M_3(\mathbb{R})$ be a symmetric matrix such that $A\,(1, 1, 0) = (2, 1, -1)$. What is $\langle A\,(1, 2, 0), (1, 1, 0) \rangle$?

- $4$
- $3$
- $6$
- It depends on the matrix $A$

## Explanation

For a symmetric matrix one has $\langle Au, v \rangle = \langle u, Av \rangle$ for every $u, v \in \mathbb{R}^3$, since $(Au)^T v = u^T A^T v = u^T A v$.

With $u = (1, 2, 0)$ and $v = (1, 1, 0)$ one therefore gets
$$
\langle A\,(1, 2, 0), (1, 1, 0) \rangle = \langle (1, 2, 0), A\,(1, 1, 0) \rangle = \langle (1, 2, 0), (2, 1, -1) \rangle = 2 + 2 + 0 = 4 .
$$
The value is the same for every symmetric matrix with $A\,(1, 1, 0) = (2, 1, -1)$, even though the vector $A\,(1, 2, 0)$ changes from one matrix to another.
