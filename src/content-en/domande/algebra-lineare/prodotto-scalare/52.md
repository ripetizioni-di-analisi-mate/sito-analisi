Let $u = (1, 1)$. For which of the following vectors $v$ does the equality $\|u + v\| = \|u\| + \|v\|$ hold?

- $v = (-2, -2)$
- $v = (1, -1)$
- $v = (3, 3)$
- $v = (2, 1)$

## Explanation

By bilinearity $\|u + v\|^2 = \|u\|^2 + 2\langle u, v \rangle + \|v\|^2$, while $\left( \|u\| + \|v\| \right)^2 = \|u\|^2 + 2\|u\|\,\|v\| + \|v\|^2$. Therefore the equality holds if and only if $\langle u, v \rangle = \|u\|\,\|v\|$.

By the equality case of the Cauchy-Schwarz inequality this happens if and only if $v$ is a multiple of $u$ with a nonnegative coefficient. Among the given vectors only $v = (3, 3) = 3u$ has this property. The vector $(-2, -2)$ is dependent on $u$ but has the opposite direction: $\langle u, v \rangle = -4$ and $\|u + v\| = \sqrt{2}$, while $\|u\| + \|v\| = 3\sqrt{2}$.
