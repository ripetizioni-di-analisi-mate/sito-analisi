Which statement holds for every orthogonal matrix $Q$ of order $3$?

- $\det(2Q) = 8$ or $\det(2Q) = -8$
- $\det(2Q) = 2$ or $\det(2Q) = -2$
- $Q^{-1} = Q$
- $\det(-Q) = \det Q$

## Explanation

The determinant of an orthogonal matrix equals $1$ or $-1$. Since $2Q$ is obtained by multiplying each of the three rows of $Q$ by $2$, one has $\det(2Q) = 2^3 \det Q = 8 \det Q$, which equals $8$ or $-8$. For the same reason $\det(-Q) = (-1)^3 \det Q = -\det Q$, which is different from $\det Q$ because $\det Q \neq 0$. Finally $Q^{-1} = Q^T$, which coincides with $Q$ only when $Q$ is symmetric, and the rotation by $\dfrac{\pi}{2}$ about the $z$-axis, for example, is not symmetric.
