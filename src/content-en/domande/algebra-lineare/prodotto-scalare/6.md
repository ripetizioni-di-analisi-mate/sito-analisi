The Gram-Schmidt process is applied to the vectors $v_1 = (1, 1, 1, 1)$, $v_2 = (1, 1, 0, 0)$, $v_3 = (1, 0, 0, 0)$ of $\mathbb{R}^4$, in the given order. What is the third vector $e_3$ of the resulting orthonormal basis?

- $\dfrac{1}{\sqrt{2}}\,(1, -1, 0, 0)$
- $\dfrac{1}{2\sqrt{3}}\,(3, -1, -1, -1)$
- $\dfrac{1}{2\sqrt{3}}\,(3, -1, 1, 1)$
- $\dfrac{1}{\sqrt{2}}\,(0, 0, 1, -1)$

## Explanation

One sets $u_1 = v_1$. Since $\langle v_2, u_1 \rangle = 2$ and $\langle u_1, u_1 \rangle = 4$, one has $u_2 = v_2 - \dfrac{1}{2}\,u_1 = \dfrac{1}{2}\,(1, 1, -1, -1)$, which is replaced by the multiple $(1, 1, -1, -1)$. The third vector is obtained by subtracting from $v_3$ its projections onto both vectors already constructed:
$$
u_3 = (1, 0, 0, 0) - \frac{1}{4}\,(1, 1, 1, 1) - \frac{1}{4}\,(1, 1, -1, -1) = \left( \frac{1}{2}, -\frac{1}{2}, 0, 0 \right) .
$$
One has $\|u_3\| = \dfrac{1}{\sqrt{2}}$, therefore normalization gives $e_3 = \dfrac{1}{\sqrt{2}}\,(1, -1, 0, 0)$.
