The Gram-Schmidt process is applied to the vectors $v_1 = (1, 0, 1, 0)$, $v_2 = (1, 1, 1, 1)$, $v_3 = (0, 1, 2, 3)$ of $\mathbb{R}^4$, in the given order. Before normalization, the third step produces the vector $u_3$, orthogonal to $v_1$ and $v_2$. What is $\|u_3\|$, that is, the distance of $v_3$ from the subspace $\langle v_1, v_2 \rangle$?

- $2$
- $3$
- $4$
- $\sqrt{14}$

## Explanation

We set $u_1 = v_1$. Since $\langle v_2, u_1 \rangle = 2$ and $\langle u_1, u_1 \rangle = 2$, we get $u_2 = v_2 - u_1 = (0, 1, 0, 1)$. Moreover $\langle v_3, u_1 \rangle = 2$ and $\langle v_3, u_2 \rangle = 4$, while $\langle u_2, u_2 \rangle = 2$, so
$$
u_3 = (0, 1, 2, 3) - (1, 0, 1, 0) - 2\,(0, 1, 0, 1) = (-1, -1, 1, 1) .
$$
Therefore $\|u_3\| = \sqrt{4} = 2$. The value $3$ is obtained by projecting $v_3$ onto $v_2$ instead of $u_2$, the value $4$ is $\|u_3\|^2$, and $\sqrt{14}$ is the norm of $v_3$.
