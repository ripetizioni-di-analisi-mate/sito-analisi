Let $W = \langle (1, k, 2), (2, 4, k + 2) \rangle \subseteq \mathbb{R}^3$, with $k \in \mathbb{R}$. For which value of $k$ does the orthogonal complement $W^\perp$ have dimension $2$?

- $k = -2$
- $k = 0$
- $k = 2$
- For no value of $k$

## Explanation

Since $\dim W^\perp = 3 - \dim W$, one has $\dim W^\perp = 2$ if and only if $\dim W = 1$. The two spanning vectors are nonzero, therefore $\dim W = 1$ if and only if they are proportional, and the ratio of the first components forces $(2, 4, k + 2) = 2\,(1, k, 2)$. This requires
$$
\begin{cases}
4 = 2k \\[4pt]
k + 2 = 4
\end{cases}
$$
and both equations are satisfied by $k = 2$. Hence $\dim W^\perp = 2$ only for $k = 2$; for every other $k$ one has $\dim W = 2$ and $W^\perp$ is a line.
