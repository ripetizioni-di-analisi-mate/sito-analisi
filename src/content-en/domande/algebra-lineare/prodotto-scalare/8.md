Let $W = \langle (1, 1, 0, 0), (0, 1, 1, 1) \rangle \subseteq \mathbb{R}^4$. Which of the following subspaces is the orthogonal complement $W^\perp$?

- $\langle (1, -1, 1, 0) \rangle$
- $\langle (1, -1, -1, 0), (1, -1, 0, -1) \rangle$
- $\langle (1, 1, 0, 0), (0, 1, 1, 1) \rangle$
- $\langle (1, -1, 1, 0), (1, -1, 0, 1) \rangle$

## Explanation

A vector $x$ is orthogonal to $W$ if and only if it is orthogonal to the two generators, therefore $W^\perp$ is the solution set of the system
$$
\begin{cases}
x_1 + x_2 = 0 \\[4pt]
x_2 + x_3 + x_4 = 0
\end{cases}
$$
The coefficient matrix has rank $2$, therefore $\dim W^\perp = 4 - 2 = 2$. From the system one obtains $x_2 = -x_1$ and $x_3 = x_1 - x_4$, and setting $(x_1, x_4) = (1, 0)$ and $(x_1, x_4) = (1, 1)$ one gets $(1, -1, 1, 0)$ and $(1, -1, 0, 1)$. These two vectors are independent, therefore $W^\perp = \langle (1, -1, 1, 0), (1, -1, 0, 1) \rangle$.
