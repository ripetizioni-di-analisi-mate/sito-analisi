Let $J \in M_3(\mathbb{R})$ be the matrix with all entries equal to $1$. Which diagonal matrix $D$ satisfies $P^T J P = D$ for a suitable orthogonal matrix $P$?

- $\operatorname{diag}(3, 0, 0)$
- $\operatorname{diag}(1, 1, 1)$
- $\operatorname{diag}(3, 1, 1)$
- $\operatorname{diag}(1, 0, 0)$

## Explanation

The matrix $J$ is symmetric, therefore by the spectral theorem such a $P$ exists, and the diagonal of $D$ contains the eigenvalues of $J$. Since $J(1, 1, 1) = (3, 3, 3)$, the number $3$ is an eigenvalue with eigenvector $(1, 1, 1)$. The rank of $J$ is $1$, therefore $\dim \ker J = 2$ and $0$ is an eigenvalue whose eigenspace is the plane $x + y + z = 0$. The multiplicities add up to $3$, and the trace $3 = 3 + 0 + 0$ confirms it. Hence $D = \operatorname{diag}(3, 0, 0)$, up to the order.
