For which value of $k \in \mathbb{R}$ is the triple $(1, 2, -1)$ a solution of the system
$$
\begin{cases}
x + k y + z = 4 \\[4pt]
k^2 x + y + k z = 4
\end{cases}
$$
in the unknowns $x, y, z$?

- $k = -1$
- $k = 2$ and $k = -1$
- $k = 2$
- $k = 1$

## Explanation

The triple is a solution of the system if it satisfies both equations. Substituting $x = 1$, $y = 2$, $z = -1$ into the first equation gives $1 + 2k - 1 = 4$, so $k = 2$. Substituting into the second gives $k^2 + 2 - k = 4$, that is, $k^2 - k - 2 = 0$, whose solutions are $k = 2$ and $k = -1$. The value $k = -1$ satisfies only the second equation, therefore the triple is a solution of the system **only for** $k = 2$.
