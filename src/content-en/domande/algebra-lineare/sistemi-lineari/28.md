The triple $u = (1, 0, 2)$ is a solution of the system $A x = b_1$ and the triple $v = (0, 1, -1)$ is a solution of the system $A x = b_2$, with the same coefficient matrix $A$. Which triple is *certainly* a solution of the system $A x = 2b_1 - b_2$?

- $(2, 1, 3)$
- $(2, -1, 5)$
- $(1, -1, 3)$
- $(2, -2, 6)$

## Explanation

The row-by-column product is distributive and commutes with multiplication by a scalar. Hence
$$
A(2u - v) = 2\,Au - Av = 2b_1 - b_2 .
$$
Therefore $2u - v = (2, 0, 4) - (0, 1, -1) = (2, -1, 5)$ is a solution of the system $A x = 2b_1 - b_2$ for every matrix $A$ satisfying the hypotheses. The other triples are $2u + v$, $u - v$ and $2u - 2v$, which solve the systems with right-hand side $2b_1 + b_2$, $b_1 - b_2$ and $2b_1 - 2b_2$ respectively.
