A linear system of $3$ equations in $3$ unknowns has $\det A = 0$. Which statement is true?

- The system is inconsistent
- The system has infinitely many solutions
- The system can be inconsistent or have infinitely many solutions
- The system has only the zero solution

## Explanation

Since $\det A = 0$, one has $\operatorname{rk} A < 3$, so the system cannot have a unique solution. By the **Rouché-Capelli theorem** the system is inconsistent if $\operatorname{rk} (A \mid b) > \operatorname{rk} A$ and has infinitely many solutions if the two ranks are equal. Both cases occur. The system formed by $x + y + z = 1$, $x + y + z = 2$ and $z = 0$ is inconsistent, whereas the one formed by $x + y + z = 1$, $2x + 2y + 2z = 2$ and $z = 0$ has the infinitely many solutions $(1 - t, \ t, \ 0)$.
