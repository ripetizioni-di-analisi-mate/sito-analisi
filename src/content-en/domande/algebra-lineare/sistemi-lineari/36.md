For which values of $k \in \mathbb{R}$ does the homogeneous system
$$
\begin{cases}
x + y + z = 0 \\[4pt]
x + k y + z = 0 \\[4pt]
2x + y + k z = 0
\end{cases}
$$
have solutions other than the trivial one?

- $k = -1$ and $k = -2$
- Only $k = 1$
- $k = 1$ and $k = 2$
- $k \neq 1$ and $k \neq 2$

## Explanation

The coefficient matrix is square, so by the theorem on **nontrivial solutions** the homogeneous system has solutions other than the zero one if and only if $\det A = 0$. Expanding along the first row gives
$$
\det A = (k^2 - 1) - (k - 2) + (1 - 2k) = k^2 - 3k + 2 = (k - 1)(k - 2) .
$$
Therefore nontrivial solutions exist for $k = 1$ and for $k = 2$. For the other values of $k$ the system has only the trivial solution.
