The coefficient matrix $A$ of a system $A x = b$ has $3$ rows, $4$ columns and rank $3$. Which statement is true for every choice of the constant term $b \in \mathbb{R}^3$?

- The system is consistent only for $b = 0$
- The system is consistent, with $\infty^1$ solutions
- The system has a unique solution
- The system is consistent, with $\infty^3$ solutions

## Explanation

The augmented matrix $(A \mid b)$ has $3$ rows, so $\operatorname{rk} (A \mid b) \leq 3$. On the other hand $A$ is a submatrix of $(A \mid b)$, therefore $\operatorname{rk} (A \mid b) \geq \operatorname{rk} A = 3$. It follows that $\operatorname{rk} (A \mid b) = \operatorname{rk} A = 3$ for every $b$, and by the **Rouché-Capelli theorem** the system is always consistent, with $\infty^{4 - 3} = \infty^1$ solutions.
