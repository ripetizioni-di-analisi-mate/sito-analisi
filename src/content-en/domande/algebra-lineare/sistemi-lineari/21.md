How many solutions does the system
$$
\begin{cases}
x_1 + x_2 - x_3 + 2x_4 = 1 \\[4pt]
x_2 + x_3 - x_4 = 2 \\[4pt]
x_1 + 2x_2 + x_4 = 3
\end{cases}
$$
in the unknowns $x_1, x_2, x_3, x_4$ have?

- $\infty^1$ solutions
- $\infty^2$ solutions
- Exactly one solution
- No solutions

## Explanation

The third row of the augmented matrix is the sum of the first two, because $(1 \ \ 1 \ \ {-1} \ \ 2 \mid 1) + (0 \ \ 1 \ \ 1 \ \ {-1} \mid 2) = (1 \ \ 2 \ \ 0 \ \ 1 \mid 3)$. With $R_3 \to R_3 - R_1 - R_2$ the third row becomes zero, and the first two already form an echelon matrix with two pivots. Hence $\operatorname{rk} A = \operatorname{rk} (A \mid b) = 2$. By the **Rouché-Capelli theorem** the system is consistent and there are $\infty^{4 - 2} = \infty^2$ solutions. The number of free parameters is the number of unknowns minus the rank.
