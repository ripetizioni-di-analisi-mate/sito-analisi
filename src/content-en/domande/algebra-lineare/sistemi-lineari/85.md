A homogeneous system $A x = 0$ of $3$ equations in the unknowns $x, y, z$ has the solution $(1, 2, -1)$. Which statement is certainly true?

- $\operatorname{rk} A = 2$
- The only solutions are $(0, 0, 0)$ and $(1, 2, -1)$
- $\det A = 0$
- The system $A x = b$ has a unique solution for every $b \in \mathbb{R}^3$

## Explanation

The vector $(1, 2, -1)$ is a solution different from the trivial one. Since $A$ is square, by the theorem on **nontrivial solutions** this happens if and only if $\det A = 0$. The rank can be $2$ or smaller: the matrix with three rows equal to $(1, 0, 1)$ has rank $1$ and sends $(1, 2, -1)$ to zero, so $\operatorname{rk} A = 2$ is not guaranteed. The solutions form a subspace, therefore they contain all multiples $t\,(1, 2, -1)$ and are infinitely many. Finally, since $\det A = 0$, by the Rouché-Capelli theorem the system $A x = b$ is either inconsistent or has infinitely many solutions, and it never has a unique solution.
