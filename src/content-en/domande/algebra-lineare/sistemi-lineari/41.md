The triple $(1, 2, 0)$ is a solution of the system $A x = b$, and the solution space of the associated homogeneous system is $S_0 = \langle (1, -1, 1) \rangle$. Which triple is a solution of $A x = b$?

- $(2, 1, 2)$
- $(1, -1, 1)$
- $(2, 3, 1)$
- $(3, 0, 2)$

## Explanation

By the theorem on the **structure of the solutions** the solutions of $A x = b$ are exactly the triples $(1, 2, 0) + t\,(1, -1, 1) = (1 + t, \ 2 - t, \ t)$ with $t \in \mathbb{R}$. For $t = 2$ one obtains $(3, 0, 2)$. A triple $w$ is a solution if and only if $w - (1, 2, 0)$ is a multiple of $(1, -1, 1)$. For the other triples the differences are $(1, -1, 2)$, $(0, -3, 1)$ and $(1, 1, 1)$, which are not multiples of $(1, -1, 1)$.
