To balance the chemical reaction
$$
a\, \mathrm{CH_4} + b\, \mathrm{O_2} \to c\, \mathrm{CO_2} + d\, \mathrm{H_2O}
$$
one requires each element (carbon, hydrogen, oxygen) to appear the same number of times on the left and on the right. This gives a homogeneous system in the unknowns $a, b, c, d$. What is its solution formed by the smallest positive integers?

- $(a, b, c, d) = (1, 1, 1, 2)$
- $(a, b, c, d) = (1, 2, 1, 1)$
- $(a, b, c, d) = (1, 2, 1, 2)$
- $(a, b, c, d) = (2, 3, 2, 2)$

## Explanation

Counting the carbon, hydrogen and oxygen atoms gives the homogeneous system
$$
\begin{cases}
a - c = 0 \\[4pt]
4a - 2d = 0 \\[4pt]
2b - 2c - d = 0
\end{cases}
$$
in four unknowns. The three equations have rank $3$, so there are $\infty^{4 - 3} = \infty^1$ solutions. Setting $a = t$, the first equation gives $c = t$, the second gives $d = 2t$ and the third gives $2b = 2t + 2t$, that is, $b = 2t$. Therefore the solutions are $t\,(1, 2, 1, 2)$, and the solution with the smallest positive integers is obtained for $t = 1$.
