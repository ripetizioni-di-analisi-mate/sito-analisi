For which values of the real parameters $a$ and $b$ does the following system have $\infty^2$ solutions?
$$
\begin{cases}
x + y - z = 1 \\[4pt]
2x + a y - 2z = 2 \\[4pt]
-x - y + z = b
\end{cases}
$$

- For $a = 2$ and $b = 1$
- For $a = 2$ and $b = -1$
- For $a = -2$ and $b = -1$
- For $a = 2$ and every $b \in \mathbb{R}$

## Explanation

By the **Rouché-Capelli theorem** there are $\infty^2$ solutions when $\operatorname{rk} A = \operatorname{rk} (A \mid b) = 3 - 2 = 1$, that is, when all rows of the augmented matrix are proportional to the first, $(1, 1, -1 \mid 1)$. The second row is $(2, a, -2 \mid 2)$, and it is twice the first if and only if $a = 2$. The third row is $(-1, -1, 1 \mid b)$, and it is the opposite of the first if and only if $b = -1$. Therefore both conditions are needed:
$$
\begin{cases}
a = 2 \\[4pt]
b = -1
\end{cases}
$$
For $a = 2$ and $b \neq -1$ we have $\operatorname{rk} A = 1$ and $\operatorname{rk} (A \mid b) = 2$, so the system is inconsistent.
