Which condition on the constant terms $a, b, c \in \mathbb{R}$ makes the following system consistent?
$$
\begin{cases}
x + y + z = a \\[4pt]
x - y + z = b \\[4pt]
2x + 2z = c
\end{cases}
$$

- $c = a - b$
- $c = 2a + 2b$
- $a + b + c = 0$
- $c = a + b$

## Explanation

The third row of $A$ is the sum of the first two, while the first two are not proportional, so $\operatorname{rk} A = 2$. With $R_3 \to R_3 - R_1 - R_2$ the augmented matrix becomes
$$
\left(\begin{array}{ccc|c}
1 & 1 & 1 & a \\
1 & -1 & 1 & b \\
0 & 0 & 0 & c - a - b
\end{array}\right).
$$
The last row corresponds to the equation $0 = c - a - b$. Therefore, by the **Rouché-Capelli theorem**, the system is consistent if and only if $c - a - b = 0$, that is, $c = a + b$.
