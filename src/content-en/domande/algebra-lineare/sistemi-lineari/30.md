Let $A \in M_3(\mathbb{R})$. The system $A x = b$ with $b = (1, 2, 3)$ has exactly one solution. How many solutions does the system $A x = c$ with $c = (0, 1, 0)$ have?

- Exactly one solution
- No solutions
- $\infty^1$ solutions
- It cannot be determined without knowing $A$

## Explanation

By the **Rouché-Capelli theorem** a system in $3$ unknowns has exactly one solution if and only if $\operatorname{rk} A = \operatorname{rk} (A \mid b) = 3$, so $\operatorname{rk} A = 3$. The matrix $(A \mid c)$ has $3$ rows, therefore its rank is at most $3$; on the other hand it contains the columns of $A$, so its rank is at least $\operatorname{rk} A = 3$. It follows that $\operatorname{rk} A = \operatorname{rk} (A \mid c) = 3$, and the system $A x = c$ has **exactly one solution**, like every system $A x = c$ with $c \in \mathbb{R}^3$.
