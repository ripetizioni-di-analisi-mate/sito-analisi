The solutions of the system $A x = b$ in the unknowns $x, y, z$ are the triples $(1 + 2t, \ -t, \ 3 + t)$ with $t \in \mathbb{R}$. What is the space $S_0$ of solutions of the associated homogeneous system $A x = 0$?

- $\{ (1, 0, 3) + t\,(2, -1, 1) : t \in \mathbb{R} \}$
- $\langle (1, 0, 3) \rangle$
- $\langle (2, 1, 1) \rangle$
- $\langle (2, -1, 1) \rangle$

## Explanation

The solutions can be written as $(1, 0, 3) + t\,(2, -1, 1)$, so $(1, 0, 3)$, obtained for $t = 0$, is a particular solution. By the theorem on the **structure of the solutions** the solution set is $(1, 0, 3) + S_0$. Therefore $S_0$ consists of the differences between the solutions and the particular solution, that is, of the vectors $t\,(2, -1, 1)$, and $S_0 = \langle (2, -1, 1) \rangle$. The set $\{ (1, 0, 3) + t\,(2, -1, 1) \}$ is the solution set of $A x = b$, which does not contain the origin.
