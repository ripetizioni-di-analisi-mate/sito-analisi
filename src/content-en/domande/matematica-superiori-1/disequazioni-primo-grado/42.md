How many integers belong to the interval $(-3.2,2)$?

- $4$
- $5$
- $6$
- $7$

## Explanation

The lower endpoint $-3.2$ lies between $-4$ and $-3$, so the first allowed integer is $-3$. The upper endpoint $2$ is excluded, so the last allowed integer is $1$. The values are $-3,-2,-1,0,1$. The difference $1-(-3)=4$ counts steps between the first and last integers. Including the starting point gives five values.
