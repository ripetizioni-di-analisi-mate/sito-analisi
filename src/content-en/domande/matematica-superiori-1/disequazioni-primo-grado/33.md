Which single condition can be removed from $x>-2$, $x\ge0$, $x\le5$ without changing the values that satisfy all of them?

- $x>-2$
- $x\ge0$
- $x\le5$
- None of the three

## Explanation

Every number satisfying $x\ge0$ is already greater than $-2$. Removing $x>-2$ therefore leaves $[0,5]$ unchanged. Removing $x\ge0$ would also allow $-1$, which is greater than $-2$ and less than $5$. Removing $x\le5$ would allow $6$. These checks identify which condition is already implied by the others.
