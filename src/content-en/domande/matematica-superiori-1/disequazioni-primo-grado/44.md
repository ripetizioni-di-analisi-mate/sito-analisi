Which integers satisfy $1.1<n<1.9$?

- $\{1\}$
- $\{2\}$
- $\{1,2\}$
- $\varnothing$

## Explanation

The smallest integer greater than $1.1$ is $2$. That value is already greater than $1.9$, so no integer satisfies both conditions. The real interval still contains values such as $1.5$. The specified domain is the integers, so having the two bounds in increasing order does not guarantee an allowable solution.
