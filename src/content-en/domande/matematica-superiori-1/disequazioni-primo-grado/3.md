Which comparison is always true when $x>2$?

- $-3x>-6$
- $3x\le6$
- $-3x<-6$
- $x-5>-2$

## Explanation

Multiplication by $-3$ reverses the sign and takes $2$ to $-6$. So $x>2$ implies $-3x<-6$. Multiplication by $3$ would instead give $3x>6$. Subtracting $5$ gives $x-5>-3$, which also allows values between $-3$ and $-2$. For example, $x=\dfrac52$ meets the premise and gives $x-5=-\dfrac52$. That value is below $-2$, so the bound $x-5>-2$ is not guaranteed.
