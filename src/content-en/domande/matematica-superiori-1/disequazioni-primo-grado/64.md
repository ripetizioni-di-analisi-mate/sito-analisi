Which interval describes all the values taken by $2t+1$ when $-2<t\le4$?

- $[-3,9)$
- $(-4,8]$
- $(-1,5]$
- $(-3,9]$

## Explanation

Multiplying all parts of $-2<t\le4$ by $2$ gives $-4<2t\le8$. Adding $1$ gives $-3<2t+1\le9$. At $t=4$ the expression reaches the endpoint $9$. The value $-3$ would require $t=-2$, excluded by the constraint. Every interior value is reached because it corresponds to a value of $t$ between the bounds. To recover it, subtract the added one and then divide by two.
