A table for a linear function gives $F(0)=4$ and $F(2)=0$. On which part of the whole real line is its value strictly positive?

- $x<2$
- $x>2$
- $x\le2$
- $x<0$

## Explanation

The value falls by $4$ from $0$ to $2$, so the slope is negative. Positive values are to the left of the zero $x=2$, which is excluded.
