How many real numbers satisfy $3x+3\le12$ and fail to satisfy $3x+3<12$?

- One
- None
- Two
- Infinitely many

## Explanation

The comparison with $\le$ allows $3x+3$ to be below $12$ or equal to $12$. The strict comparison already contains every value that makes it smaller. Only the condition $3x+3=12$ remains, and it has solution $x=3$. The solution sets therefore follow the same half-line, differing only in whether they include the boundary.
