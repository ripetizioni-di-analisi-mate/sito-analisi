What is the complement of $(-2,3]$ in the real numbers?

- $(-\infty,-2)\cup[3,+\infty)$
- $(-\infty,-2]\cup(3,+\infty)$
- $(-\infty,-2)\cup(3,+\infty)$
- $[-2,3)$

## Explanation

The complement contains all real numbers excluded from the original interval. The value $-2$ is outside $(-2,3]$, so the left half-line includes it. The value $3$ belongs to the interval, so the right half-line excludes it. Every value strictly between $-2$ and $3$ is already in the original set and stays outside its complement.
