Which rewrite of $9\cdot47-4\cdot47$ uses the distributive property so that only one multiplication is needed?

- $(9-4)\cdot47$
- $(9-4)\cdot(47-47)$
- $(9+4)\cdot47$
- $9\cdot(47-4)$

## Explanation

Both products share the factor $47$. Subtracting four groups of forty-seven from nine groups of the same size leaves five groups, each of forty-seven. So the expression is $(9-4)\cdot47=5\cdot47=235$. The shared factor remains $47$ while only the number of times it is counted changes. That is why the two occurrences of $47$ are not subtracted from each other.
