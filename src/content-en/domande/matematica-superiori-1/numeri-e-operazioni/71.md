A bottle contains $\dfrac{3}3$ liters. If the same amount is added, how many liters does it contain?

- $\dfrac{1}{2}\,\mathrm{L}$
- $1\,\mathrm{L}$
- $2\,\mathrm{L}$
- $\dfrac{4}{3}\,\mathrm{L}$

## Explanation

Add the two quantities, which use the same unit. The denominators are equal, so only the numerators are added. The total is twice the initial quantity.

$$
\frac{3}3+\frac{3}3=\frac{6}3
$$

The result is $2\,\mathrm{L}$.
