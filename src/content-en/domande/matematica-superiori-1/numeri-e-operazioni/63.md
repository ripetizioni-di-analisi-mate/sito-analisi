A class wants to divide $42$ pencils and $30$ erasers among identical bags, using every item. What is the greatest possible number of bags?

- $7$
- $12$
- $6$
- $210$

## Explanation

The number of bags must divide both $42$ and $30$, since every bag gets the same number of each item and there are no leftovers. The factorisations $42=2\cdot3\cdot7$ and $30=2\cdot3\cdot5$ share $2\cdot3=6$. With six bags, each holds $42:6=7$ pencils and $30:6=5$ erasers. Seven divides the number of pencils but not the number of erasers.
