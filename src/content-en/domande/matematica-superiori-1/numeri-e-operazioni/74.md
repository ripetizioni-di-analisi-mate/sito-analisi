A bottle contains $\dfrac{6}3$ liters. If the same amount is added, how many liters does it contain?

- $1\,\mathrm{L}$
- $4\,\mathrm{L}$
- $2\,\mathrm{L}$
- $\dfrac{7}{3}\,\mathrm{L}$

## Explanation

Add the two quantities, which use the same unit. The denominators are equal, so only the numerators are added. The total is twice the initial quantity.

$$
\frac{6}3+\frac{6}3=\frac{12}3
$$

The result is $4\,\mathrm{L}$.
