A bottle contains $\dfrac{4}3$ litres. If the same amount is added, how many litres does it contain?

- $\dfrac{2}{3}\,\mathrm{L}$
- $\dfrac{4}{3}\,\mathrm{L}$
- $\dfrac{5}{3}\,\mathrm{L}$
- $\dfrac{8}{3}\,\mathrm{L}$

## Explanation

Add the two quantities, which use the same unit. The denominators are equal, so only the numerators are added. The total is twice the initial quantity.

$$
\frac{4}3+\frac{4}3=\frac{8}3
$$

The result is $\dfrac{8}{3}\,\mathrm{L}$.
