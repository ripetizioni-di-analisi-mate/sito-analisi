What is the solution set of the proportion $0:5=3:x$?

- $\{0\}$
- $\{5\}$
- All nonzero numbers
- Empty set

## Explanation

The quotient on the right requires $x\ne0$. Under this condition both sides can be multiplied by $5x$. The equation would require $0\cdot x=5\cdot3=15$, which is impossible. The two fractions reveal the same obstacle. The left-hand fraction is zero, and the right-hand fraction has a nonzero numerator and denominator. The solution set is therefore empty even though there are many allowed values of the denominator.
