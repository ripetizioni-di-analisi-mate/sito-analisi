A path measures $8\,\mathrm{cm}$ on a map with scale $1:25000$. How long is the same path on a map with scale $1:100000$?

- $32\,\mathrm{cm}$
- $2\,\mathrm{cm}$
- $4\,\mathrm{cm}$
- $8\,\mathrm{cm}$

## Explanation

On the second map each centimetre represents $100000:25000=4$ times as much distance as a centimetre on the first map. The same real distance therefore needs one quarter as many centimetres, giving $8:4=2$. For a check, $8\cdot25000=200000$ and $2\cdot100000=200000$ give the same real length in centimetres.
