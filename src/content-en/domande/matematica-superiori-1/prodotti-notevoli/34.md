At $x=1$, $(x+2)^2$ and $x^2+8$ agree. Which other check is enough to rule out an identity?

- $x=0$, because both values are $4$
- $x=0$, because the values are $4$ and $8$
- $x=2$, because both values are $16$
- $x=-1$, because both values are $1$

## Explanation

Substituting $x=0$ into the first expression gives $2^2=4$, while the second gives $8$. One disagreement is enough to rule out an identity. In general the difference is $4x-4$, so the initial agreement at $x=1$ is isolated. The constants account for the disagreement at zero. This check requires only squaring a constant.
