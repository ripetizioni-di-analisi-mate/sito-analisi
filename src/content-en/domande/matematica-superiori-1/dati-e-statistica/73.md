A register identifies each athlete by jersey number. Which operation is meaningful for these data?

- Count how many athletes wear a given number
- Use the average as a typical size
- Interpret twice the number as twice the performance
- Convert the numbers to minutes

## Explanation

A jersey number is an identifier. It supports grouping and counting athletes, while arithmetic differences between identifiers do not measure sporting performance.
