A survey records the number of bus changes on the way to school. How is this variable classified?

- Discrete quantitative.
- Continuous quantitative.
- Nominal categorical.
- Ordinal categorical.

## Explanation

The variable is a count and can be zero, one, two, and so on. Differences between values are meaningful, so it is quantitative. No number of changes is possible between consecutive whole numbers. That makes it discrete, whereas journey duration is a continuous measurement.
