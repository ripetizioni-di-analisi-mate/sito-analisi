A survey records the number of books read in a month. What type of variable is this?

- Discrete quantitative variable
- Continuous quantitative variable
- Nominal categorical variable
- Ordinal categorical variable with no numerical values

## Explanation

The observed quantity is obtained by counting. Its possible values are nonnegative integers. It is therefore a discrete quantitative variable.

The variable is discrete quantitative.
