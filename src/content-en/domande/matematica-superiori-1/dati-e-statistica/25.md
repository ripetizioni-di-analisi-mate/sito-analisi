The range of a set of measurements is $12\,\mathrm{cm}$. Then $3\,\mathrm{cm}$ is added to each measurement. What is the new range?

- $12\,\mathrm{cm}$
- $15\,\mathrm{cm}$
- $9\,\mathrm{cm}$
- $36\,\mathrm{cm}$

## Explanation

Both the minimum and the maximum also increase by $3\,\mathrm{cm}$. The increases cancel in the difference between the extremes, so the range stays $12\,\mathrm{cm}$.

All the measurements move the same distance. Their relative ordering also stays the same, so the same observations remain the minimum and maximum.
