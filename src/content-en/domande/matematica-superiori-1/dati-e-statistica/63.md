In a histogram, $20$ waits form a class of width $5$ minutes. The density is to be expressed in waits per second. What is the new height?

- $4$
- $240$
- $\dfrac1{15}$
- $15$

## Explanation

The wait count remains $20$. On an axis marked in seconds the class is $5\cdot60=300$ wide, so the height is $\dfrac{20}{300}=\dfrac1{15}$ waits per second. The numerical width is multiplied by $60$ and the height divided by $60$, so the area represents the same count.
