What is the real solution set of $\dfrac{x^2-9}{x-3}=x+3$?

- $\mathbb R$
- $\mathbb R\setminus\{3\}$
- $\mathbb R\setminus\{-3,3\}$
- $\{3\}$

## Explanation

The denominator requires $x\ne3$. We can then factor $x^2-9=(x-3)(x+3)$ and cancel $x-3$. This gives $x+3=x+3$ for every value in the domain. The value $-3$ is allowed: it makes the numerator zero while leaving denominator $-6$, so both sides equal zero. At the excluded point, however, the original expression defines no quotient.
