After simplifying $\dfrac{x+4}{x^2-16}$ we obtain $\dfrac1{x-4}$. Which values must still be excluded to keep the original domain?

- Only $4$
- $-4$ and $4$
- Only $-4$
- $0$ and $4$

## Explanation

The original denominator is $(x-4)(x+4)$, so it vanishes at $4$ and $-4$. We can cancel $x+4$ only when that factor is nonzero. Taken on its own, the new expression would be defined at $-4$ and equal $-\dfrac18$. That value remains excluded because the original fraction would give $0:0$. Set the domain before simplifying.
