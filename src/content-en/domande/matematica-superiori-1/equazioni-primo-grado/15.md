Which equation has the same solution as $7x+1=3x+9$?

- $4x=10$
- $10x=8$
- $4x=8$
- $7x=8$

## Explanation

Subtract $3x$ from both sides so the term in $x$ is only on the left. Then subtract $1$ from both sides. Each subtraction is reversible, so the solution set stays the same.

$$
7x-3x=9-1\quad\Longrightarrow\quad4x=8
$$
