Why can you not cancel $x+1$ directly from both sides of $\dfrac{x+1}{6}=\dfrac{x+1}3$?

- It would lose the solution $x=1$
- It would introduce the solution $x=0$
- It would give an identity
- It would lose the solution $x=-1$

## Explanation

Multiplying by $6$ gives $x+1=2(x+1)$, so $x+1=0$. The value $x=-1$ is allowed: it makes both numerators zero, while the denominators are the fixed numbers $6$ and $3$. Division by $x+1$ would be possible only when $x\ne-1$. It would therefore exclude the equation's only solution. Where division is allowed, what remains is $\dfrac16=\dfrac13$, which is false.
