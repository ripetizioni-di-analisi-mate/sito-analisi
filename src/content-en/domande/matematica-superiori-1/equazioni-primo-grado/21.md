Which of these equations is equivalent to $4x=12$ over the reals?

- $x=3$
- $x+4=12$
- $x^2=9$
- $0x=0$

## Explanation

Dividing by $4$ turns $4x=12$ into $x=3$, with solution set $\{3\}$. The equation $x^2=9$ has the same solution but also $-3$, so its solution set differs. The equation $0x=0$ admits every real number. Equivalence requires all the values that solve the two equations to coincide. In $x+4=12$ the only solution is $8$, so the solution sets have no common value.
