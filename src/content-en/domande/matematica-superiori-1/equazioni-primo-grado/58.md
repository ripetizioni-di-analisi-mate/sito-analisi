Only one of four values is corrected. After the correction the mean increases by $2$. By how much did the corrected value increase?

- $2$
- $8$
- $4$
- $\dfrac12$

## Explanation

If that value changes by $d$, the sum of the four values also changes by $d$. The number of values stays $4$, so the mean changes by $\dfrac d4$. Setting $\dfrac d4=2$ gives $d=8$. For instance, a sum increasing from $20$ to $28$ takes the mean from $5$ to $7$. The result depends on the number of values and the change in the mean.
