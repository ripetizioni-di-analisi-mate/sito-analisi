A machine applies the rule “double and add $3$”. Feed in $x$, then put the output through the same machine again. Which equation describes a final value of $15$?

- $(2x+3)^2=15$
- $2(2x+3)+3=15$
- $2(2x+3)=15$
- $2x+3+3=15$

## Explanation

On the second pass you double the entire first output $2x+3$ and add another $3$. This gives $4x+9=15$, with original input $x=\dfrac32$.
