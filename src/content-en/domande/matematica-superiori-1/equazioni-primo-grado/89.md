For which value of $m$ does $(m-1)x=m-1$ have **exactly two** distinct real solutions?

- For no value
- For $m=1$
- For $m=0$
- For $m=2$

## Explanation

At $m=1$ both sides equal zero for every real number. There are infinitely many solutions, even though choosing two values to check would give two true equalities. If $m\ne1$, we can divide by $m-1$ and obtain only $x=1$. No parameter gives exactly two solutions: a nonzero coefficient in a linear equation permits at most one value.
