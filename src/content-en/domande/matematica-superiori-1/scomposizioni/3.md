Which product equals $5x^2+10x$?

- $5 x + 10$
- $5 x \left(x - 2\right)$
- $5 x \left(x + 2\right)$
- $x \left(x + 10\right)$

## Explanation

Both terms contain the given numerical factor $5$ and an x. Dividing each term by the common factor gives x and two. The distributive property recovers the original polynomial.

$$
5x^2+10x=5x(x+2)
$$

The result is $5 x \left(x + 2\right)$.
