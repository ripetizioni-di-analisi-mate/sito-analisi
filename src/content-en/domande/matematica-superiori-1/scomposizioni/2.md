Which product equals $4x^2+8x$?

- $4 x + 8$
- $4 x \left(x + 2\right)$
- $4 x \left(x - 2\right)$
- $x \left(x + 8\right)$

## Explanation

Both terms contain the given numerical factor $4$ and an x. Dividing each term by the common factor gives x and two. The distributive property recovers the original polynomial.

$$
4x^2+8x=4x(x+2)
$$

The result is $4 x \left(x + 2\right)$.
