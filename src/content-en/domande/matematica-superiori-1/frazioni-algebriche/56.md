The fraction $\dfrac{x-3}{x-3}$ simplifies to $1$. Which statement correctly preserves its domain?

- It equals $1$ for every real number, including $x=3$
- It equals $0$ when $x=3$
- It is defined only for $x>3$
- It equals $1$ for every $x\ne 3$

## Explanation

Simplification requires the cancelled factor to be nonzero. The value excluded by the original denominator remains excluded. The simplified formula represents the same fraction only on that domain.

The fraction equals $1$ for every $x\ne 3$.
