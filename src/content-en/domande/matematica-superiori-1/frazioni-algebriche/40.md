Which value is excluded from $\dfrac{x-2}{x+1}:\dfrac{x-3}{x+1}$ because it makes the divisor zero?

- $-1$
- $2$
- $0$
- $3$

## Explanation

The divisor has numerator $x-3$, which is zero at $3$. Its denominator is $4$ there, so the divisor fraction is defined and equals zero.

The input $x=-1$ is also outside the domain because the two original denominators vanish. The question asks for the input at which the divisor is defined and equals zero.
