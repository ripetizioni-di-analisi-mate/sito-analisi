The fraction $\dfrac{x-6}{x-6}$ simplifies to $1$. Which statement correctly preserves its domain?

- It equals $1$ for every real number, including $x=6$
- It equals $0$ when $x=6$
- It equals $1$ for every $x\ne 6$
- It is defined only for $x>6$

## Explanation

Simplification requires the canceled factor to be nonzero. The value excluded by the original denominator remains excluded. The simplified formula represents the same fraction only on that domain.

The fraction equals $1$ for every $x\ne 6$.
