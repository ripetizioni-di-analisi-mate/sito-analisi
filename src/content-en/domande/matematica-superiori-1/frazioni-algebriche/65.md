For which value of $k$ does $\dfrac{x+k}{x-2}$ never take the value zero on its domain?

- $-2$
- $2$
- $0$
- $1$

## Explanation

The only possible zero is $x=-k$. To exclude it, it must coincide with the forbidden input $2$, so $k=-2$.
