Which expression has the same natural domain and the same values as $\dfrac{2x+6}{x-1}$?

- $\dfrac{x(2x+6)}{x(x-1)}$
- $\dfrac{6x+18}{3x-3}$
- $\dfrac{2x+6}{3x-3}$
- $\dfrac{6x+18}{3x+3}$

## Explanation

Multiply the numerator and denominator by $3$. The new fraction has the same value, and its denominator $3(x-1)$ still vanishes only at $1$. The version multiplied by $x$ has the same value where it is defined, but it also excludes $0$.
