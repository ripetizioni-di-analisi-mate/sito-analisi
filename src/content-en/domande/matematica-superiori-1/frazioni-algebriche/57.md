The fraction $\dfrac{x-4}{x-4}$ simplifies to $1$. Which statement correctly preserves its domain?

- It equals $1$ for every $x\ne 4$
- It equals $1$ for every real number, including $x=4$
- It equals $0$ when $x=4$
- It is defined only for $x>4$

## Explanation

Simplification requires the canceled factor to be nonzero. The value excluded by the original denominator remains excluded. The simplified formula represents the same fraction only on that domain.

The fraction equals $1$ for every $x\ne 4$.
