A student multiplies $\dfrac{x}{x-1}=\dfrac1{x-1}$ by $x-1$ and gets $x=1$. What is the solution set of the original equation?

- $\varnothing$
- $\{1\}$
- $\mathbb R\setminus\{1\}$
- $\{0\}$

## Explanation

The transformation is valid on the domain $x\ne1$, where the factor used is nonzero. The transformed equation has the single candidate $1$. That candidate makes both original denominators zero, so it gives no equality between defined values. The intersection of the candidate set and the domain is empty.
