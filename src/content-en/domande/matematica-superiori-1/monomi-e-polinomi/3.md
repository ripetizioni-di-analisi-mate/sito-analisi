The monomials $A=x^2y$ and $B=xy^2$ have the same value at $(1,1)$. Which statement about their coefficients, variable parts and values is correct?

- They have the same coefficient and the same variable part.
- They have different coefficients and the same variable part.
- They have the same coefficient, different variable parts and different values at $(2,1)$.
- They have different variable parts but the same values for every pair.

## Explanation

The implicit coefficient is $1$ in each monomial. The exponent pairs for $(x,y)$ are $(2,1)$ and $(1,2)$, respectively, so the variable parts differ. Substituting $1$ for every variable makes each product equal to $1$. When $x=2$ and $y=1$, the values are $4$ and $2$. The first substitution therefore establishes agreement at only one point.
