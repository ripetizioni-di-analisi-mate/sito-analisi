For which real value of $a$ does the polynomial $P(x)=x^3+ax+5$ satisfy $P(2)=P(-2)$?

- $4$
- $-8$
- $0$
- $-4$

## Explanation

At $x=2$ the value is $P(2)=13+2a$, while at $x=-2$ it is $P(-2)=-3-2a$. The constant $5$ contributes the same amount at both inputs. Equating the values gives $4a=-16$, so $a=-4$. At that parameter value the odd-degree terms cancel at both points. The common value therefore equals the constant term at the parameter value found.
