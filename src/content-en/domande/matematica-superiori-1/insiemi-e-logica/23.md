The domain is $A=\left\{5, 6, 7\right\}$ and the codomain is $B=\{1;2;3\}$. Which relation, written as a set of ordered pairs, is a function from $A$ to $B$?

- $\{(5;1),(5;2),(6;2),(7;3)\}$
- $\{(5;1),(6;2)\}$
- $\{(5;1),(6;2),(7;2)\}$
- $\{(5;1),(6;2),(7;4)\}$

## Explanation

A function assigns each element of its domain exactly one image in the codomain. In the correct relation, each first element occurs once and each second element belongs to B. Two distinct elements of the domain may have the same image.

The result is $\{(5;1),(6;2),(7;2)\}$.
