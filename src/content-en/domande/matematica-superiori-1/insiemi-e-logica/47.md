Suppose $A\setminus B=\{p\}$ and $B\setminus A=\{q\}$. Which change always preserves both finite set sizes?

- Add $p$ to both
- Remove $q$ from both
- Exchange $p$ and $q$ between the sets
- Replace $p$ with an element already in both

## Explanation

Each set gives up one element and receives one that it did not contain. Thus both cardinalities stay the same.
