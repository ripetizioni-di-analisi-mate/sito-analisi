What are the truth values of $\forall x\in\varnothing,\ x^2<0$ and $\exists x\in\varnothing,\ x^2<0$, in that order?

- False, false.
- True, false.
- False, true.
- True, true.

## Explanation

Making the universal statement false would require a counterexample in the domain. None can be found in the empty domain, so the universal is true. Making the existential statement true would require a domain element satisfying $x^2<0$. That search is also impossible, so the existential is false.
