Let $C=\left\{4, 5\right\}$ and $D=\left\{4, 5, 6\right\}$. Which relation holds?

- $D\subseteq C$
- $C=D$
- $C\cap D=\varnothing$
- $C\subsetneq D$

## Explanation

Every element of C occurs in D. Set D also contains an element that is absent from C. Therefore C is a proper subset of D.

The result is $C\subsetneq D$.
