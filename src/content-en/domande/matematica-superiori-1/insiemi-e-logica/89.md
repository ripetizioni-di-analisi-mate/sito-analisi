Let $A=\{0;1;2\}$ and $B=\{1;2\}$. A relation contains all pairs $(a;b)\in A\times B$ with $a<b$. Which issues prevent it from being a function from $A$ to $B$?

- $0$ has two outputs and $2$ has none.
- Only $0$ has an issue, since it has two outputs.
- Only $2$ has an issue, since it has no outputs.
- $1$ has two outputs and $0$ has none.

## Explanation

For $a=0$, both second coordinates $1$ and $2$ are allowed. For $a=1$, only $2$ is allowed. For $a=2$, there is no strictly larger value in $B$. A function requires an output for every input and allows at most one, so this relation fails the definition in two ways.
