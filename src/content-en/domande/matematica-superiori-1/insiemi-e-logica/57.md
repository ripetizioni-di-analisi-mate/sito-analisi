Exactly one of $p,q$ is true, and $p\Rightarrow q$ is true. Which pair gives the truth values of $p,q$ in that order?

- False, true
- True, false
- True, true
- False, false

## Explanation

Only the two pairs with different values are possible. True, false would make the implication false, leaving false, true.
