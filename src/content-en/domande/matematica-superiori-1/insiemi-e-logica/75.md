In a universal set $U$, let $B$ be the set of elements satisfying $P$. Which relation between the sets is equivalent to “there is no $x\in A$ satisfying $P(x)$,” with $A\subseteq U$?

- $A\cup B=\varnothing$
- $B\subseteq A$
- $A\cap B=\varnothing$
- $A=B$

## Explanation

The elements satisfying both $x\in A$ and $P(x)$ are exactly those in $A\cap B$. Saying that none exist means this intersection is empty. The two sets can still have elements. For instance, $A=\{1\}$ and $B=\{2\}$ have an empty intersection and a nonempty union.
