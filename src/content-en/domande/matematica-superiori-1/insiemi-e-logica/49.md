Let $A$ be any set. Which choice guarantees that $B$ has no elements and that $B\subseteq A$?

- $B=\varnothing$
- $B=\{\varnothing\}$
- $B=\{0\}$
- $B=A$

## Explanation

The empty set has zero elements and satisfies the inclusion because it cannot supply an element outside $A$. The expressions $\{\varnothing\}$ and $\{0\}$ each denote a set with one element. Choosing $B=A$ gives the inclusion, but makes $B$ empty only in the special case that $A$ itself is empty.
