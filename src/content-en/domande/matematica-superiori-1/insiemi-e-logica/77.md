Let $A=\{1;2\}$ and $B=\{a;b;c\}$. How many functions from $A$ to $B$ are there?

- $9$
- $6$
- $8$
- $5$

## Explanation

A function from $A$ to $B$ assigns to each element of $A$ a single element of $B$. For the element $1$ there are $3$ possible choices, and for each of them there are $3$ choices for the element $2$, because the two images are chosen independently. The functions are therefore $3\cdot3=9$. The value $6$ is the number of pairs in $A\times B$, while $8=2^3$ is the number of functions from $B$ to $A$.

Therefore there are $9$ functions from $A$ to $B$.
