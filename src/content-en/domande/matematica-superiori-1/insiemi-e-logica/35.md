One set has $8$ elements and another has $6$. Which of these values could be the cardinality of the union?

- $7$
- $15$
- $10$
- $18$

## Explanation

The union contains the first set, so it has at least $8$ elements. It has at most $8+6=14$. The value $10$ is possible if the sets share four elements because $8+6-4=10$.
