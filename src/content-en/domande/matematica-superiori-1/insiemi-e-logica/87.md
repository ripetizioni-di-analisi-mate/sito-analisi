For any two sets $A$ and $B$, we want to write $A$ as the union of $A\setminus B$ and a set disjoint from $A\setminus B$. Which set must be used, whatever $A$ and $B$ are?

- $B\setminus A$
- $A\cup B$
- $A\cap B$
- $B$

## Explanation

Every element of $A$ either belongs to $B$ or does not. The elements of $A$ that do not belong to $B$ form $A\setminus B$, while those that belong to $B$ form $A\cap B$. The two sets have no elements in common and together contain all the elements of $A$, so $A=(A\setminus B)\cup(A\cap B)$. The set $B$ works only when $B\subseteq A$, because otherwise the union would contain elements outside $A$.

Hence the required set is $A\cap B$.
