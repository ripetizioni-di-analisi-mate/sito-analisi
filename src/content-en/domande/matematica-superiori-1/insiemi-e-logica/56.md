Proposition $p$ states that $3$ is greater than $2$. Proposition $q$ states that $3$ is less than $1$. What is the truth value of $p\land q$?

- True, because one true proposition is enough
- True, because p is true
- The information given is insufficient
- False, because a conjunction requires both propositions to be true

## Explanation

Proposition p is true and q is false. A conjunction is true only when both propositions are true. Since one of them is false, the conjunction is false.

The conjunction is false because it requires both propositions to be true.
