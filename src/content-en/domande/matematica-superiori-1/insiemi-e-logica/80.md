The function $f:\mathbb R\to\mathbb R$ is defined by $f(x)=2x+7$. What is the image of $-5$?

- $17$
- $-17$
- $4$
- $-3$

## Explanation

To find the image, apply the function rule to the given input. Substitute that value for the variable and multiply first. Then add the constant term.

$$
f(-5)=2(-5)+7=-3
$$

The result is $-3$.
