Which statement about functions involving an empty set is true?

- There is exactly one function from $\{1;2\}$ to $\varnothing$.
- There are two functions from $\varnothing$ to $\{1;2\}$.
- There is no function from $\varnothing$ to $\varnothing$.
- There is exactly one function from $\varnothing$ to $\{1;2\}$.

## Explanation

A product with empty first set has no pairs. Its only subset is the empty relation, which meets the definition of a function because there is no domain element in need of an output. In the other direction, with inputs $1$ and $2$ and empty codomain, neither can be assigned an output.
