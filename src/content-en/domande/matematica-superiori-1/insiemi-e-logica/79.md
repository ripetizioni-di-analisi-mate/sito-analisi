Let $f:A\to B$ with $A=\{-3;-2;2;3\}$, $B=\{0;1;2;3\}$, and $f(x)=|x|$, the absolute value of $x$. What is the image set $f(A)$?

- $\{0;1;2;3\}$
- $\{-3;-2;2;3\}$
- $\{2;3\}$
- $\{0;1\}$

## Explanation

The inputs $-3$ and $3$ give output $3$, while $-2$ and $2$ give output $2$. The image set lists each attained value once, so it has two elements. The numbers $0$ and $1$ are in the codomain, but no element of the domain has absolute value $0$ or $1$.
