In $D=\{-3;-1;0;1;3\}$, we want to disprove “there is exactly one $x\in D$ with $x^2=9$.” A check has already found $x=3$. Which further check is decisive?

- $(-3)^2=9$
- $(-1)^2=1$
- $0^2=0$
- $1^2=1$

## Explanation

The first check proves that a value exists. To disprove uniqueness, find a distinct second value that satisfies the same equation. The number $-3$ belongs to $D$ and has square $9$, so it provides the second value. The other three checks test values that are not solutions and leave the question of uniqueness open.
