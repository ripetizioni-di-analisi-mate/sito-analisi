To be accepted, a value must satisfy both $x^2\ge4$ and $x\le5$. Which listed value is rejected?

- $-3$
- $-2$
- $5$
- $1$

## Explanation

All candidates are at most $5$, so the second requirement does not distinguish them. Their squares form the set $\{1;4;9;25\}$. Only $1$ has a square less than $4$. The value $-2$ gives equality $x^2=4$, which is allowed by $\ge$.
