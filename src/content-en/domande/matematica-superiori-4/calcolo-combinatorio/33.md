How many nonempty subsets does a set of $6$ elements have?

- $64$
- $63$
- $36$
- $62$

## Explanation

A subset is determined by choosing for each of the $6$ elements whether it belongs to the subset. Thus the number of subsets, including the empty set and the entire set, equals the number of ordered selections with repetition $D'_{2,6} = 2^6 = 64$. Removing the empty set leaves $64 - 1 = 63$ subsets.
