Five teams want to schedule games in pairs so that each plays exactly three times. Is this possible if both appearances in every game are counted?

- Yes, five games would suffice.
- No, because the total number of appearances would be odd.
- Yes, seven games would suffice.
- No, because the number of teams must always be even.

## Explanation

The required number of appearances is $5\cdot3=15$, but each game produces two. No integer number of games can generate $15$ appearances.
