A committee is chosen from twelve people. Which equality follows by pairing each four-member committee with the group of people left out?

- $\dbinom{12}{4} = \dbinom{11}{3} + \dbinom{11}{5}$
- $\dbinom{12}{4} = \dbinom{12}{8}$
- $\dbinom{12}{4} = 3 \dbinom{12}{3}$
- $\dbinom{12}{4} = \dbinom{12}{3} + \dbinom{12}{5}$

## Explanation

By the symmetry of binomial coefficients, $\dbinom{12}{4} = \dbinom{12}{12 - 4} = \dbinom{12}{8}$, so the equality $\dbinom{12}{4} = \dbinom{12}{8}$ is true. Pascal’s identity gives $\dbinom{12}{4} = \dbinom{11}{3} + \dbinom{11}{4} = 165 + 330 = 495$, whereas $\dbinom{11}{3} + \dbinom{11}{5} = 165 + 462 = 627$. Also $\dbinom{12}{3} = 220$, so $3 \dbinom{12}{3} = 660$ and $\dbinom{12}{3} + \dbinom{12}{5} = 220 + 792 = 1012$, both different from $495$.
