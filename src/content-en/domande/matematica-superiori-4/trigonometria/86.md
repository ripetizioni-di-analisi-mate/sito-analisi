An isosceles triangle has base angles of measure $x$ in radians. What are the geometric restrictions on $x$?

- $0 < x < \pi$
- $0 < x < \dfrac{\pi}{3}$
- $\dfrac{\pi}{4} < x < \dfrac{\pi}{2}$
- $0 < x < \dfrac{\pi}{2}$

## Explanation

The vertex angle measures $\pi - 2x$ because the angles of a triangle add up to $\pi$. Every angle in a triangle is positive, so both of the following conditions must hold:
$$
\begin{cases}
x > 0 \\
\pi - 2x > 0 .
\end{cases}
$$
The second condition is equivalent to $x < \dfrac{\pi}{2}$, so the restrictions are $0 < x < \dfrac{\pi}{2}$.
