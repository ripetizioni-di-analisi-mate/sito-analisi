For which values of $x$ is the triangle with sides $3$, $4$, and $x$, with $x > 4$, obtuse?

- $x > 5$
- $4 < x < 5$
- $5 < x < 7$
- $4 < x < 7$

## Explanation

The longest side is $x$, so the triangle is obtuse if and only if the angle opposite $x$ is obtuse, or equivalently if $x^2 > 3^2 + 4^2 = 25$. With $x > 4$, this condition is equivalent to $x > 5$. The triangle inequality also requires $x < 3 + 4 = 7$. Therefore the triangle is obtuse for $5 < x < 7$.
