In triangle $ABC$ with a right angle at $A$, we have $\sin\beta = \dfrac{3}{5}$. What is $\tan\gamma$?

- $\dfrac{3}{4}$
- $\dfrac{4}{5}$
- $\dfrac{5}{3}$
- $\dfrac{4}{3}$

## Explanation

By the first right-triangle theorem, $\sin\beta = \dfrac{b}{a}$, so we can set $b = 3k$ and $a = 5k$ with $k > 0$. By the Pythagorean theorem, $c = \sqrt{25k^2 - 9k^2} = 4k$. By the second theorem, $c = b\tan\gamma$, so $\tan\gamma = \dfrac{c}{b} = \dfrac{4}{3}$. The value $\dfrac{3}{4}$ is instead $\tan\beta$.
