Consider the statement $P(n)$: “$5^n + 2$ is divisible by $4$.” Which of the following is true?

- The inductive step holds and the base case does not
- The base case holds and the inductive step does not
- Both the base case and the inductive step hold
- Neither the base case nor the inductive step holds

## Explanation

We have $5^{n+1} + 2 = 5\left( 5^n + 2 \right) - 8$. If $5^n + 2$ is divisible by $4$, then so is $5\left( 5^n + 2 \right) - 8$ because $8$ is a multiple of $4$, so the inductive step holds. For $n = 1$, however, $5 + 2 = 7$ is not divisible by $4$, so the base case fails. Indeed, $5^n$ divided by $4$ always leaves remainder $1$, so $5^n + 2$ leaves remainder $3$, and the statement is false for every $n$.
