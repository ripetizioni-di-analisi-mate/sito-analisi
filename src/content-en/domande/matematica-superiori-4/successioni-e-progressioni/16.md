A table starts with $a_0=2,a_1=5,a_2=8$. If the increment is always the same, which expression for $a_n$ uses the correct starting index?

- $2+3n$
- $2+3(n-1)$
- $3+2n$
- $2\cdot3^n$

## Explanation

There are $n$ increments between index zero and index $n$. Each increment is three, so add $3n$ to the initial value $2$.
