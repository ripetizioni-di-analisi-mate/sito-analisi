For which values of $x$ can the sum formula for a geometric progression with common ratio of absolute value less than $1$ be applied to the infinite sum $1 + 2x + 4x^2 + 8x^3 + \dots$?

- $-1 < x < 1$
- $0 < x < \dfrac{1}{2}$
- $-\dfrac{1}{2} < x < \dfrac{1}{2}$
- $x < \dfrac{1}{2}$

## Explanation

The summands are the terms of a geometric progression with $a_1 = 1$ and common ratio $q = 2x$. The formula $\dfrac{a_1}{1 - q}$ applies when $|q| < 1$, that is, when $|2x| < 1$. Thus $-\dfrac{1}{2} < x < \dfrac{1}{2}$, and for these values the sum is $\dfrac{1}{1 - 2x}$.
