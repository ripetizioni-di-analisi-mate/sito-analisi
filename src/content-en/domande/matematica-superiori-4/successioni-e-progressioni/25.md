Which of the following sequences is strictly decreasing?

- $a_n = n^2 - 4n$
- $a_n = \dfrac{(-1)^n}{n}$
- $a_n = \dfrac{3}{n + 2}$
- $a_n = \dfrac{n}{n + 3}$

## Explanation

For $a_n = \dfrac{3}{n + 2}$ we have $a_{n+1} - a_n = \dfrac{3}{n + 3} - \dfrac{3}{n + 2} = -\dfrac{3}{(n + 2)(n + 3)}$, which is negative for every $n$, so the sequence is **strictly decreasing**. For the sequence $n^2 - 4n$ the difference is $2n - 3$, which is negative only for $n = 1$, and $\dfrac{(-1)^n}{n}$ has terms of alternating sign. The sequence $\dfrac{n}{n + 3}$ is strictly increasing because its difference equals $\dfrac{3}{(n + 3)(n + 4)}$.
