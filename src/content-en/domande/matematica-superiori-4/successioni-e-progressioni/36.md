We want to prove the formula $1^3 + 2^3 + \dots + n^3 = \dfrac{n^2(n + 1)^2}{4}$ by induction. Which equality must be verified in the inductive step?

- $\dfrac{n^2(n + 1)^2}{4} + n^3 = \dfrac{(n + 1)^2(n + 2)^2}{4}$
- $\dfrac{n^2(n + 1)^2}{4} + (n + 1)^2 = \dfrac{(n + 1)^2(n + 2)^2}{4}$
- $\dfrac{n^2(n + 1)^2}{4} + (n + 1)^3 = \dfrac{(n + 1)^2(n + 2)^2}{2}$
- $\dfrac{n^2(n + 1)^2}{4} + (n + 1)^3 = \dfrac{(n + 1)^2(n + 2)^2}{4}$

## Explanation

In the inductive step, assume the formula holds for $n$ and add the next term $(n + 1)^3$ to both sides. The right-hand side must become the formula with $n + 1$ in place of $n$, that is, $\dfrac{(n + 1)^2(n + 2)^2}{4}$. The equality holds because factoring out $\dfrac{(n + 1)^2}{4}$ on the left gives $\dfrac{(n + 1)^2}{4}\left( n^2 + 4n + 4 \right) = \dfrac{(n + 1)^2(n + 2)^2}{4}$.
