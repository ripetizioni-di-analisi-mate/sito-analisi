An experiment has three outcomes $a$, $b$, and $c$. Which assignment defines a probability measure?

- $P(a) = \dfrac{1}{2}$, $P(b) = \dfrac{1}{3}$, $P(c) = \dfrac{1}{3}$
- $P(a) = \dfrac{3}{4}$, $P(b) = \dfrac{1}{2}$, $P(c) = -\dfrac{1}{4}$
- $P(a) = \dfrac{1}{2}$, $P(b) = \dfrac{1}{3}$, $P(c) = \dfrac{1}{6}$
- $P(a) = \dfrac{1}{4}$, $P(b) = \dfrac{1}{4}$, $P(c) = \dfrac{1}{4}$

## Explanation

In a finite space, a probability measure is obtained by assigning each outcome a nonnegative number so that all the numbers add up to $1$. The values $\dfrac{1}{2}$, $\dfrac{1}{3}$, and $\dfrac{1}{6}$ satisfy both conditions, since $\dfrac{3 + 2 + 1}{6} = 1$. The triples $\dfrac{1}{2}$, $\dfrac{1}{3}$, $\dfrac{1}{3}$ and $\dfrac{1}{4}$, $\dfrac{1}{4}$, $\dfrac{1}{4}$ have sums $\dfrac{7}{6}$ and $\dfrac{3}{4}$, respectively, different from $1$. The triple containing $-\dfrac{1}{4}$ has sum $1$, but one value is negative, so the first axiom is not satisfied.
