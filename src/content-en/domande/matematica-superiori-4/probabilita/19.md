On a roll of a die, let $A$ be the event “rolling an odd number” and $B$ the event “rolling a number less than $4$.” Which set is $A \cap B$?

- $\{ 1, 3 \}$
- $\{ 1, 2, 3, 5 \}$
- $\{ 5 \}$
- $\{ 2 \}$

## Explanation

As sets of outcomes, $A = \{ 1, 3, 5 \}$ and $B = \{ 1, 2, 3 \}$. The intersection contains the outcomes belonging to both events, so $A \cap B = \{ 1, 3 \}$. The set $\{ 1, 2, 3, 5 \}$ is the union $A \cup B$, which contains the outcomes belonging to at least one of the two events.
