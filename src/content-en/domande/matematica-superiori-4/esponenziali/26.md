For which values of the base $a > 0$ does the inequality $a^{\sqrt{2}} < a^{\sqrt{3}}$ hold?

- $a > 1$
- $0 < a < 1$
- $a > 0$ and $a \neq 1$
- $a \geq 1$

## Explanation

The exponents satisfy $\sqrt{2} < \sqrt{3}$. By the rule for comparing powers with the same base, if $a > 1$, their order is preserved and $a^{\sqrt{2}} < a^{\sqrt{3}}$. If $0 < a < 1$, the order is reversed and $a^{\sqrt{2}} > a^{\sqrt{3}}$. For $a = 1$ both powers equal $1$, so the strict inequality holds only for $a > 1$.
