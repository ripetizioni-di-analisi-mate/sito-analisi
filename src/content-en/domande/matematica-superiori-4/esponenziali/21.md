Using real roots, a student assigns the value $-2$ to $(-8)^{\dfrac{1}{3}}$, then writes $\dfrac{1}{3}=\dfrac{2}{6}$ and computes $\sqrt[6]{(-8)^2}=2$. Which condition ensures this procedure gives the same value for equivalent fractions?

- The exponent is less than one.
- The numerator is positive.
- The base is an integer.
- The base is positive.

## Explanation

For a positive base all principal roots used in the calculation are positive and give the same result for equivalent fractions. In the example, the principal sixth root loses the sign of the cube root.
