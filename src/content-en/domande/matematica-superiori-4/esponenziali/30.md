For which values of the real parameter $k$ is $f(x) = (k - 2)^x$ an increasing exponential function?

- $k > 2$
- $k > 3$
- $2 < k < 3$
- $k > 1$

## Explanation

The exponential function with base $a$ is increasing when $a > 1$. Here the base is $k - 2$, so we need $k - 2 > 1$, that is, $k > 3$. For $2 < k < 3$ the base is between $0$ and $1$ and the function is decreasing. For $k = 3$ the base equals $1$ and the function is constant.
