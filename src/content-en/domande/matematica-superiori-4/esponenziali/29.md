Which of the following functions is strictly decreasing?

- $y = \left( \dfrac{2}{3} \right)^{-x}$
- $y = \left( \dfrac{3}{2} \right)^{-x}$
- $y = \left( \dfrac{1}{e} \right)^{-x}$
- $y = 0.5^{-2x}$

## Explanation

By the exponent laws each function can be written as $b^x$. We have $\left( \dfrac{3}{2} \right)^{-x} = \left( \dfrac{2}{3} \right)^{x}$, with base between $0$ and $1$, so this function is **strictly decreasing**. The other three are $\left( \dfrac{3}{2} \right)^{x}$, $e^{x}$ and $\left( 0.5^{-2} \right)^x = 4^x$, all with bases greater than $1$, so they are increasing.
