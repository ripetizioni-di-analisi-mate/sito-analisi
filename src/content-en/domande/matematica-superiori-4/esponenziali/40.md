Which inequality is true for the number $e^2$?

- $2 < e^2 < 4$
- $4 < e^2 < 9$
- $e^2 > 9$
- $e < e^2 < 4$

## Explanation

Euler's number has the value $e \approx 2.718$, so $2 < e < 3$. For $x = 2 > 0$ the larger base gives the larger power, so $2^2 < e^2 < 3^2$, that is, $4 < e^2 < 9$. The approximate value is $e^2 \approx 7.389$.
