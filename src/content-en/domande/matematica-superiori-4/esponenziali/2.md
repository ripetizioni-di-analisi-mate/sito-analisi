- $2^{1.7} < 4^{0.8} < 2^{\sqrt{3}} < \left( \dfrac{1}{2} \right)^{-2}$
- $4^{0.8} < 2^{1.7} < 2^{\sqrt{3}} < \left( \dfrac{1}{2} \right)^{-2}$
- $\left( \dfrac{1}{2} \right)^{-2} < 4^{0.8} < 2^{1.7} < 2^{\sqrt{3}}$
- $4^{0.8} < 2^{\sqrt{3}} < 2^{1.7} < \left( \dfrac{1}{2} \right)^{-2}$

## Explanation

Write the four numbers as powers with base $2$. Since $4 = 2^2$, we have $4^{0.8} = 2^{1.6}$, and since $\dfrac{1}{2} = 2^{-1}$, we have $\left( \dfrac{1}{2} \right)^{-2} = 2^{2}$. The exponents are therefore $1.6$, $1.7$, $\sqrt{3} \approx 1.732$ and $2$. The base $2$ is greater than $1$, so by the rule for **comparing powers with the same base**, the powers have the same order as their exponents. This gives $4^{0.8} < 2^{1.7} < 2^{\sqrt{3}} < \left( \dfrac{1}{2} \right)^{-2}$.
