Which expression equals $\dfrac{e^{2x + 1}}{e^{x - 2}}$?

- $e^{x - 1}$
- $e^{3x - 1}$
- $e^{\frac{2x + 1}{x - 2}}$
- $e^{x + 3}$

## Explanation

When powers with the same base are divided, the exponents are subtracted. The resulting exponent is $(2x + 1) - (x - 2) = 2x + 1 - x + 2 = x + 3$. Therefore the quotient equals $e^{x + 3}$.
