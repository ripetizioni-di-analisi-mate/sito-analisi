Which statement about the function $y = -\left( \dfrac{1}{2} \right)^x$ is true?

- It is decreasing and has range $(-\infty, 0)$
- It is increasing and has range $(0, +\infty)$
- It is increasing and has range $(-\infty, 0)$
- It is decreasing and has range $(0, +\infty)$

## Explanation

The function $\left( \dfrac{1}{2} \right)^x$ is decreasing because its base is between $0$ and $1$, and its range is $(0, +\infty)$. The graph of $y = -\left( \dfrac{1}{2} \right)^x$ is its reflection across the $x$-axis, so its range is $(-\infty, 0)$. Reflection across the $x$-axis changes the signs of the values and reverses the monotonicity, so the function is **increasing**. For example, it equals $-1$ at $x = 0$ and $-\dfrac{1}{2}$ at $x = 1$.
