The graph of the function $f(x) = a^x$ passes through $(-2, 16)$. What is the value of the base $a$?

- $\dfrac{1}{4}$
- $4$
- $\dfrac{1}{8}$
- $\dfrac{1}{16}$

## Explanation

The point $(-2, 16)$ lies on the graph, so $a^{-2} = 16$, that is, $\dfrac{1}{a^2} = 16$. It follows that $a^2 = \dfrac{1}{16}$, and since the base is positive, $a = \dfrac{1}{4}$. The function $\left( \dfrac{1}{4} \right)^x$ is decreasing. Indeed, at $x = -2$, to the left of the origin, its value is greater than $1$.
