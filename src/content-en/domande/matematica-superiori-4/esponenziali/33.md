A model $f(x)=Ca^x$ with $C,a>0$ gives $f(2)=12$ and $f(6)=48$. What is $f(4)$ without finding $C$?

- $24$
- $30$
- $36$
- $18$

## Explanation

Since $f(x) = Ca^x$, we have $\dfrac{f(4)}{f(2)} = a^2$ and $\dfrac{f(6)}{f(4)} = a^2$, so from $x = 2$ to $x = 4$ and from $x = 4$ to $x = 6$ the value is multiplied by the same factor. Therefore $\dfrac{f(4)}{12} = \dfrac{48}{f(4)}$, that is, $f(4)^2 = 12 \cdot 48 = 576$. The value $f(4) = Ca^4$ is positive, so $f(4) = 24$. The value $30$ is the arithmetic mean of $12$ and $48$, which would be the result for a linear model.
