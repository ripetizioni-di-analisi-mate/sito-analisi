Which of the following equalities is true?

- $2^3 + 2^3 = 2^6$
- $3^{-2} = -9$
- $(-3)^2 = -9$
- $-3^2 = -9$

## Explanation

In the expression $-3^2$ the exponent applies only to $3$, so $-3^2 = -(3^2) = -9$. In the expression $(-3)^2$ the exponent applies to the number $-3$, so $(-3)^2 = 9$. For negative exponents we have $3^{-2} = \dfrac{1}{9}$, which is positive. Finally, $2^3 + 2^3 = 16$, whereas $2^6 = 64$, since there is no sum rule for powers analogous to the product rule.
