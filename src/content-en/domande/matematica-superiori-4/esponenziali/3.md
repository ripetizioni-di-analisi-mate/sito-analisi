- $x = \dfrac{8}{5}$
- $x = \dfrac{7}{5}$
- $x = \dfrac{3}{2}$
- $x = -8$

## Explanation

Since $25 = 5^2$ and $125 = 5^3$, the equation can be written $5^{2(x - 1)} = 5^{3(2 - x)}$. Two powers with the same base are equal only when they have the same exponent, so $2x - 2 = 6 - 3x$. Thus $5x = 8$, that is, $x = \dfrac{8}{5}$.
