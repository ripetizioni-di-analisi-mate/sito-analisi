Which positive numbers $x$ satisfy $2^x = x^2$?

- Only $x = 2$
- $x = 2$ and $x = 4$
- $x = 2$ and $x = 3$
- Only $x = 4$

## Explanation

For $x = 2$ we have $2^2 = 4 = 2^2$, and for $x = 4$ we have $2^4 = 16 = 4^2$, so both values are solutions. For $x = 3$, however, $2^3 = 8$ and $3^2 = 9$, so $3$ is not a solution. Between $0$ and $2$ we have $2^x > x^2$, between $2$ and $4$ we have $2^x < x^2$, and for every $x > 4$ the exponential function exceeds the power function. The only positive solutions are therefore $x = 2$ and $x = 4$.
