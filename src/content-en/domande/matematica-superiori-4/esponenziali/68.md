For which value of the real parameter $k$ does the equation $4^x - 2^{x + 2} + k = 0$ have the solution $x = 1$?

- $k = -4$
- $k = 12$
- $k = 2$
- $k = 4$

## Explanation

The value $x = 1$ is a solution if substituting it makes the equation true. For $x = 1$ we have $4^1 - 2^{3} + k = 4 - 8 + k = k - 4$. The equality $k - 4 = 0$ gives $k = 4$.
