To solve $25^x-5^x-12=0$, set $t=5^x$ and obtain the roots $t=4$ and $t=-3$. Which step correctly returns to the original unknown without introducing a false solution?

- Keep only $t=4$, since $5^x>0$, and set $x=\log _5 4$.
- Keep only $t=4$ because a power of five is always greater than one.
- Set $x=4$ and $x=-3$ directly.
- Take the logarithm of the absolute value of each root.

## Explanation

The substitution takes values in the positive reals. Every positive $t$ corresponds to exactly one $x=\log _5 t$. No real power of five equals $-3$, whereas $4$ gives a solution.
