- $x \leq 1$ or $x \geq 2$
- $1 \leq x \leq 2$
- $-2 \leq x \leq -1$
- $1 < x < 2$

## Explanation

Since $\dfrac{9}{4} = \left( \dfrac{2}{3} \right)^{-2}$, the inequality can be written $\left( \dfrac{2}{3} \right)^{x^2 - 3x} \geq \left( \dfrac{2}{3} \right)^{-2}$. The base $\dfrac{2}{3}$ is between $0$ and $1$, so the inequality **reverses** and we obtain $x^2 - 3x \leq -2$. The inequality $x^2 - 3x + 2 \leq 0$ can be written $(x - 1)(x - 2) \leq 0$, so the solution is $1 \leq x \leq 2$.
