Which of the following inequalities is true?

- $0.3^{\sqrt{2}} < 0.3^{1.5}$
- $3^{\sqrt{2}} > 3^{1.5}$
- $0.3^{\sqrt{2}} > 0.3^{1.5}$
- $2^{-\sqrt{3}} > 2^{-1.7}$

## Explanation

Since $\sqrt{2} \approx 1.414$, we have $\sqrt{2} < 1.5$. With base $0.3$ between $0$ and $1$, **comparing powers with the same base** reverses the order of the exponents, so $0.3^{\sqrt{2}} > 0.3^{1.5}$. With base $3$ greater than $1$, the order is preserved and $3^{\sqrt{2}} < 3^{1.5}$. Finally, $-\sqrt{3} \approx -1.732 < -1.7$, so with base $2$ we have $2^{-\sqrt{3}} < 2^{-1.7}$.
