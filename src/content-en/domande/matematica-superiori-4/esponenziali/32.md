The graph of the function $f(x) = a^x$ passes through $(2, 9)$. What is the value of $f(-1)$?

- $-3$
- $\dfrac{1}{3}$
- $\dfrac{1}{9}$
- $3$

## Explanation

The point $(2, 9)$ lies on the graph, so $a^2 = 9$. The base of an exponential function is positive, so $a = 3$. This gives $f(-1) = 3^{-1} = \dfrac{1}{3}$.
