What is the set of values taken by $y = \tan x$ for $x \in \left[ 0, \dfrac{\pi}{4} \right]$?

- $\left[ 0, \dfrac{\sqrt{2}}{2} \right]$
- $[0, 1]$
- $\left[ 0, \dfrac{\pi}{4} \right]$
- $\left[ 0, \dfrac{\sqrt{3}}{3} \right]$

## Explanation

Tangent is increasing on $\left( -\dfrac{\pi}{2}, \dfrac{\pi}{2} \right)$, so on $\left[ 0, \dfrac{\pi}{4} \right]$ it takes every value between $\tan 0$ and $\tan\dfrac{\pi}{4}$. Since $\tan 0 = 0$ and $\tan\dfrac{\pi}{4} = 1$, its set of values is $[0, 1]$. The interval $\left[ 0, \dfrac{\sqrt{2}}{2} \right]$ gives the values taken by sine on the same interval.
