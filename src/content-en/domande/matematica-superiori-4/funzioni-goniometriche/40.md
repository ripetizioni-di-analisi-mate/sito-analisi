Is there an angle $\alpha$ with $\sin\alpha = \dfrac{3}{5}$ and $\cos\alpha = \dfrac{3}{5}$?

- Yes, the angle $\alpha = \dfrac{\pi}{4}$
- Yes, because $\dfrac{3}{5}$ is between $-1$ and $1$
- No, because the sine and cosine of the same angle always differ
- No, because $\sin^2\alpha + \cos^2\alpha$ would equal $\dfrac{18}{25}$

## Explanation

The first Pythagorean identity $\sin^2\alpha + \cos^2\alpha = 1$ holds for every angle. The given values would give $\dfrac{9}{25} + \dfrac{9}{25} = \dfrac{18}{25} \neq 1$, so no angle has both properties. The condition $-1 \leq \sin\alpha \leq 1$ is necessary but insufficient. For $\alpha = \dfrac{\pi}{4}$ the sine and cosine are equal, and both have the value $\dfrac{\sqrt{2}}{2}$, which differs from $\dfrac{3}{5}$.
