Why is $\arccos (-1)$ defined whereas $\arccos (-2)$ has no real value?

- Only the first number belongs to the range of cosine.
- Arccosine accepts only positive numbers.
- Arccosine has period two.
- An integer can never be an angle.

## Explanation

An inverse function accepts the values attained by the original function as its inputs. Cosine attains all of $[-1,1]$ and no value outside it.
