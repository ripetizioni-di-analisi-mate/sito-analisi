What is the value of the function $y = 4\sin\left( 2x - \dfrac{\pi}{6} \right)$ at $x = \dfrac{\pi}{4}$?

- $2$
- $4$
- $2\sqrt{3}$
- $2\sqrt{2}$

## Explanation

At $x = \dfrac{\pi}{4}$ the argument of the sine is $2 \cdot \dfrac{\pi}{4} - \dfrac{\pi}{6} = \dfrac{\pi}{2} - \dfrac{\pi}{6} = \dfrac{\pi}{3}$, so the function equals $4\sin\dfrac{\pi}{3} = 4 \cdot \dfrac{\sqrt{3}}{2} = 2\sqrt{3}$. The number $2$ results from using $\sin\dfrac{\pi}{6}$ instead of $\sin\dfrac{\pi}{3}$.
