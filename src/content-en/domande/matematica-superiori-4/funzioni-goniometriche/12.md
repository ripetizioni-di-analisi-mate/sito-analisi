- $-\dfrac{\pi}{4}$
- $-\dfrac{\pi}{12}$

## Explanation

Arcsine returns an angle in $\left[ -\dfrac{\pi}{2}, \dfrac{\pi}{2} \right]$, so $\arcsin\left( -\dfrac{1}{2} \right) = -\dfrac{\pi}{6}$. Arccosine returns an angle in $[0, \pi]$, hence $\arccos\dfrac{1}{2} = \dfrac{\pi}{3}$. Arctangent returns an angle in $\left( -\dfrac{\pi}{2}, \dfrac{\pi}{2} \right)$, so $\arctan(-1) = -\dfrac{\pi}{4}$. The sum is
$$
-\frac{\pi}{6} + \frac{\pi}{3} - \frac{\pi}{4} = \frac{-2\pi + 4\pi - 3\pi}{12} = -\frac{\pi}{12} .
$$
