Which of the following functions is even?

- $y = \sin x + \cos x$
- $y = x\sin x$
- $y = x\cos x$
- $y = \tan x$

## Explanation

A function is even if $f(-x) = f(x)$ for every $x$ in its domain. For $f(x) = x\sin x$ we have $f(-x) = (-x)\sin(-x) = (-x)(-\sin x) = x\sin x$ because sine is odd, so the function is even. The functions $x\cos x$ and $\tan x$ are odd. The function $\sin x + \cos x$ is not even, since its value is $1$ at $\dfrac{\pi}{2}$ and $-1$ at $-\dfrac{\pi}{2}$.
