For which values of the real parameter $k$ does the function $y = (k - 1)\sin(2x) + 3$ have range $[1, 5]$?

- $k = 3$ or $k = -1$
- Only $k = 3$
- $k = 1$ or $k = -3$
- $k = 5$ or $k = -3$

## Explanation

Sine takes every value in $[-1, 1]$, so $(k - 1)\sin(2x)$ takes every value between $-|k - 1|$ and $|k - 1|$. Adding $3$ gives the range $\left[ 3 - |k - 1|, 3 + |k - 1| \right]$. This interval equals $[1, 5]$ if and only if $|k - 1| = 2$, that is, $k - 1 = 2$ or $k - 1 = -2$. Therefore $k = 3$ or $k = -1$.
