For which value of $\omega > 0$ does the function $y = \cos(\omega x)$, whose value is $1$ at $x = 0$, first return to $1$ at $x = \dfrac{\pi}{3}$?

- $3$
- $2$
- $6$
- $\dfrac{1}{6}$

## Explanation

After $x = 0$, the function first returns to $1$ one period later, so the period is $T = \dfrac{\pi}{3}$. From the relation $\dfrac{2\pi}{\omega} = \dfrac{\pi}{3}$ we obtain $\omega = 6$. Taking $\omega = 3$ would give $\cos\left( 3 \cdot \dfrac{\pi}{3} \right) = \cos\pi = -1$, the minimum.
