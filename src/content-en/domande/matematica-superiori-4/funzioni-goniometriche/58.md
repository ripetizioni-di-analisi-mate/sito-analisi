For every real number $x$, which expression equals $\sin\left( \dfrac{3\pi}{2} - x \right)$?

- $\cos x$
- $-\sin x$
- $-\cos x$
- $\sin x$

## Explanation

Write $\dfrac{3\pi}{2} - x = \pi + \left( \dfrac{\pi}{2} - x \right)$. The identity for angles that differ by $\pi$ gives $\sin\left( \dfrac{3\pi}{2} - x \right) = -\sin\left( \dfrac{\pi}{2} - x \right)$. By the complementary-angle identity, $\sin\left( \dfrac{\pi}{2} - x \right) = \cos x$, so the expression equals $-\cos x$. Indeed, for $x = 0$ we obtain $\sin\dfrac{3\pi}{2} = -1 = -\cos 0$.
