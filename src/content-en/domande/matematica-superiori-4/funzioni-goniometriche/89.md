Which of the following statements is true?

- $\arccos(-x) = -\arccos x$ for every $x \in [-1, 1]$
- $\arcsin(-x) = -\arcsin x$ for every $x \in [-1, 1]$
- $\arctan x$ is defined only for $x \in [-1, 1]$
- $\arcsin(\sin x) = x$ for every real number $x$

## Explanation

Arcsine is odd because sine is odd and the interval $\left[ -\dfrac{\pi}{2}, \dfrac{\pi}{2} \right]$ is symmetric about $0$. Arccosine is not odd. Indeed, $\arccos(-1) = \pi$ whereas $-\arccos 1 = 0$. Arctangent is defined on all of $\mathbb{R}$ because tangent takes every real value on $\left( -\dfrac{\pi}{2}, \dfrac{\pi}{2} \right)$. Finally, the identity $\arcsin(\sin x) = x$ holds only for $x \in \left[ -\dfrac{\pi}{2}, \dfrac{\pi}{2} \right]$. For example, $\arcsin\left( \sin\dfrac{5\pi}{6} \right) = \dfrac{\pi}{6}$.
