Which statement about the function $y = \sin x$ is true?

- It is odd and has period $2\pi$
- It is even and has period $2\pi$
- It is odd and has period $\pi$
- It is even and has period $\pi$

## Explanation

By the negative-angle identity, $\sin(-x) = -\sin x$, so sine is an odd function. Sine has period $2\pi$ because $\sin(x + 2\pi) = \sin x$ for every $x$ and the value $1$ is attained in $[0, 2\pi)$ only at $x = \dfrac{\pi}{2}$. The number $\pi$ is not a period because $\sin\left( \dfrac{\pi}{2} + \pi \right) = -1$ differs from $\sin\dfrac{\pi}{2} = 1$.
