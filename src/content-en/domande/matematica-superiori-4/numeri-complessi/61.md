The point $(4, 1)$ in the complex plane is rotated counterclockwise about the origin through an angle of $\dfrac{\pi}{2}$. What point does it move to?

- $(-1, 4)$
- $(1, -4)$
- $(-4, 1)$
- $(-4, -1)$

## Explanation

The point $(4, 1)$ represents the number $4 + i$. The number $i$ has modulus $1$ and argument $\dfrac{\pi}{2}$, so multiplication by $i$ is a counterclockwise rotation through $\dfrac{\pi}{2}$ about the origin. Since $i\,(4 + i) = 4i + i^2 = -1 + 4i$, the rotated point is $(-1, 4)$.
