For which real values of $a$ does the number $z = a + 2\sqrt{2}\,i$ have modulus $3$?

- $a = 1$
- $a = \pm\sqrt{17}$
- $a = \pm\left( 3 - 2\sqrt{2} \right)$
- $a = \pm 1$

## Explanation

The modulus is $|z| = \sqrt{a^2 + 8}$ because $\left( 2\sqrt{2} \right)^2 = 8$. The condition $\sqrt{a^2 + 8} = 3$ is equivalent to $a^2 + 8 = 9$ since both sides are nonnegative. Thus $a^2 = 1$, so $a = 1$ or $a = -1$.
