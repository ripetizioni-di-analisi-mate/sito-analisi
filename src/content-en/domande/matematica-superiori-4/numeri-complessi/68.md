What is the value of $(-1 + i)^{-4}$?

- $\dfrac{1}{4}$
- $-\dfrac{1}{4}$
- $-4$
- $\dfrac{1}{16}$

## Explanation

First calculate the power with positive exponent. Squaring gives $(-1 + i)^2 = 1 - 2i + i^2 = -2i$, so $(-1 + i)^4 = (-2i)^2 = 4i^2 = -4$. By definition, $(-1 + i)^{-4} = \dfrac{1}{(-1 + i)^4}$, so the value is $-\dfrac{1}{4}$.
