Which of the following values is never attained by the function $f(x) = 2\sin x + \cos x$?

- $2$
- $-2$
- $\sqrt{5}$
- $\dfrac{9}{4}$

## Explanation

By the **auxiliary-angle formula**, $f(x) = \sqrt{5}\sin(x + \varphi)$ with $r = \sqrt{4 + 1} = \sqrt{5}$. Therefore $f$ takes exactly the values in the interval $\left[ -\sqrt{5}, \sqrt{5} \right]$. Since $\left( \dfrac{9}{4} \right)^2 = \dfrac{81}{16} > 5$, the number $\dfrac{9}{4}$ exceeds $\sqrt{5}$ and therefore is not a value of $f$. The numbers $2$ and $-2$ belong to the interval, and $\sqrt{5}$ is the maximum.
