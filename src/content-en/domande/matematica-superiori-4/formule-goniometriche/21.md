For every real $x$, which expression equals $\sin\left( x + \dfrac{\pi}{4} \right)$?

- $\dfrac{\sqrt{2}}{2}\left( \sin x - \cos x \right)$
- $\sqrt{2}\left( \sin x + \cos x \right)$
- $\sin x + \cos x$
- $\dfrac{\sqrt{2}}{2}\left( \sin x + \cos x \right)$

## Explanation

By the **sine sum** formula,
$$
\sin\left( x + \frac{\pi}{4} \right) = \sin x\cos\frac{\pi}{4} + \cos x\sin\frac{\pi}{4} .
$$
Since $\cos\dfrac{\pi}{4} = \sin\dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2}$, factoring gives $\dfrac{\sqrt{2}}{2}\left( \sin x + \cos x \right)$. The expression containing $\sin x - \cos x$ is $\sin\left( x - \dfrac{\pi}{4} \right)$ instead.
