For which of the following values of $x$ is the substitution $t = \tan\dfrac{x}{2}$ undefined?

- $x = \dfrac{\pi}{2}$
- $x = \dfrac{3\pi}{2}$
- $x = 0$
- $x = \pi$

## Explanation

The tangent of $\dfrac{x}{2}$ is defined only if $\dfrac{x}{2} \neq \dfrac{\pi}{2} + k\pi$, that is, if $x \neq \pi + 2k\pi$. For $x = \pi$ we have $\dfrac{x}{2} = \dfrac{\pi}{2}$, so $t$ is undefined. For the other values, the substitution is defined, giving $t = 1$ for $x = \dfrac{\pi}{2}$, $t = -1$ for $x = \dfrac{3\pi}{2}$, and $t = 0$ for $x = 0$. Therefore the value $x = \pi$ must be checked separately when using the **tangent half-angle substitution**.
