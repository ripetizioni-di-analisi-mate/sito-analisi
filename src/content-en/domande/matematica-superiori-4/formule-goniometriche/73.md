For which values of the real parameter $k$ does the equation $\sin x + \cos x = k$ have solutions?

- $-\sqrt{2} \leq k \leq \sqrt{2}$
- $-2 \leq k \leq 2$
- $-1 \leq k \leq 1$
- $0 \leq k \leq \sqrt{2}$

## Explanation

By the **auxiliary-angle formula**, $\sin x + \cos x = \sqrt{2}\sin\left( x + \dfrac{\pi}{4} \right)$. As $x$ varies over $\mathbb{R}$, this expression takes precisely the values in the interval $\left[ -\sqrt{2}, \sqrt{2} \right]$. Therefore the equation has solutions if and only if $-\sqrt{2} \leq k \leq \sqrt{2}$. The interval $[-2, 2]$ results from adding the maximum values of sine and cosine, which occur at different points.
