At which points does the function $f(x) = \sqrt{3}\sin x - \cos x + 1$ attain its maximum?

- $x = \dfrac{\pi}{3} + 2k\pi$
- $x = \dfrac{2\pi}{3} + 2k\pi$
- $x = \dfrac{5\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{2} + 2k\pi$

## Explanation

For $a = \sqrt{3}$ and $b = -1$ we have $r = \sqrt{3 + 1} = 2$, $\cos\varphi = \dfrac{\sqrt{3}}{2}$, and $\sin\varphi = -\dfrac{1}{2}$, so the **auxiliary angle** is $\varphi = -\dfrac{\pi}{6}$. Therefore
$$
f(x) = 2\sin\left( x - \frac{\pi}{6} \right) + 1 .
$$
The maximum $3$ occurs when $x - \dfrac{\pi}{6} = \dfrac{\pi}{2} + 2k\pi$, that is, at $x = \dfrac{2\pi}{3} + 2k\pi$. The points $x = \dfrac{5\pi}{3} + 2k\pi$ are minima instead, where $f$ equals $-1$.
