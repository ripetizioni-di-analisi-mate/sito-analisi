What is the maximum value of the function $f(x) = 5\sin x + 12\cos x$?

- $17$
- $12$
- $13$
- $\sqrt{17}$

## Explanation

By the **auxiliary-angle formula**, $5\sin x + 12\cos x = r\sin(x + \varphi)$ with
$$
r = \sqrt{5^2 + 12^2} = \sqrt{169} = 13 .
$$
Sine takes every value between $-1$ and $1$, so $f$ takes every value between $-13$ and $13$ and the maximum is $13$. The value $17 = 5 + 12$ would require sine and cosine both to equal $1$ at the same $x$, which is impossible because $\sin^2 x + \cos^2 x = 1$.
