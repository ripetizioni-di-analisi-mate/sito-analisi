On which set do the functions $f(x) = \ln \big( (x - 1)(x - 3) \big)$ and $g(x) = \ln (x - 1) + \ln (x - 3)$ agree?

- On all of $\mathbb{R}$
- On $(-\infty, 1) \cup (3, +\infty)$
- On $(3, +\infty)$
- On $(1, 3)$

## Explanation

The function $f$ is defined where $(x - 1)(x - 3) > 0$, that is, for $x < 1$ or $x > 3$. The function $g$ is defined where both arguments are positive simultaneously, that is, for $x > 3$.

For $x > 3$ the two arguments are positive, so the product rule for logarithms applies and $f(x) = g(x)$.

For $x < 1$ the function $g$ is undefined. Therefore the two functions agree on $(3, +\infty)$.
