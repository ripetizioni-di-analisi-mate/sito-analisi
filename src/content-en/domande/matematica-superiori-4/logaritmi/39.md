Which of the following equalities holds for every $x > 0$?

- $\log_8 x = 3 \log_2 x$
- $\log_{\frac{1}{8}} x = \dfrac{1}{3} \log_2 x$
- $\log_8 x = \dfrac{\log_2 x}{8}$
- $\log_8 x = \dfrac{1}{3} \log_2 x$

## Explanation

Using the change-of-base formula with base $2$ gives
$$
\log_8 x = \frac{\log_2 x}{\log_2 8} = \frac{\log_2 x}{3} .
$$
Therefore $\log_8 x = \dfrac{1}{3} \log_2 x$ for every $x > 0$. For the reciprocal base, however, we have $\log_{\frac{1}{8}} x = -\log_8 x = -\dfrac{1}{3} \log_2 x$, and the denominator of the formula is $\log_2 8 = 3$, which differs from $8$.
