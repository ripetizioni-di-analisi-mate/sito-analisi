Let $a = \log_2 5$, $b = \log_3 5$ and $c = \log_{\frac{1}{2}} 5$. Which ordering is correct?

- $b < a < c$
- $c < a < b$
- $c < b < a$
- $a < b < c$

## Explanation

The number $c$ has base less than $1$ and argument greater than $1$, so it is negative. Indeed, $c = -\log_2 5$.

The numbers $a$ and $b$ are positive. Since $2^2 = 4 < 5 < 8 = 2^3$, we have $2 < a < 3$. Since $3 < 5 < 9$, we have $1 < b < 2$.

Therefore the correct ordering is $c < b < a$.
