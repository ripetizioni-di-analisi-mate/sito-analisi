What are the solutions of the inequality $\left( \log_2 x \right)^2 < 4$?

- $0 < x < 4$
- $-2 < x < 2$
- $\dfrac{1}{4} < x < 4$
- $0 < x < \dfrac{1}{4}$ or $x > 4$

## Explanation

The domain condition is $x > 0$. Set $t = \log_2 x$ and solve $t^2 < 4$, which holds for $-2 < t < 2$.

The base $2$ exceeds $1$, so the direction is preserved and $-2 < \log_2 x < 2$ is equivalent to $2^{-2} < x < 2^2$.

Therefore the solutions are $\dfrac{1}{4} < x < 4$.
