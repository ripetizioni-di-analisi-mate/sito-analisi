- $\dfrac{1}{e} \leq x \leq e$
- $-1 < x \leq 1$
- $\dfrac{1}{e} < x \leq e$
- $0 < x \leq e$

## Explanation

The domain condition is $x > 0$, and the denominator must differ from $0$. Set $t = \ln x$ and examine $\dfrac{t - 1}{t + 1} \leq 0$.

The numerator vanishes at $t = 1$ and the denominator at $t = -1$, so the quotient is nonpositive for $-1 < t \leq 1$. The endpoint $t = -1$ is excluded because it makes the denominator zero.

Since the natural logarithm is increasing, $-1 < \ln x \leq 1$ is equivalent to $e^{-1} < x \leq e$. Therefore the solutions are $\dfrac{1}{e} < x \leq e$.
