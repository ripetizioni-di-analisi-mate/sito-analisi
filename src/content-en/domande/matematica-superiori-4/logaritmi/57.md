What is the domain of the function $f(x) = \ln (x + 1) + \ln (5 - x)$?

- $[-1, 5]$
- $(-\infty, -1) \cup (5, +\infty)$
- $(-1, +\infty)$
- $(-1, 5)$

## Explanation

The arguments of both logarithms must be positive simultaneously:
$$
\begin{cases}
x + 1 > 0 \\[4pt]
5 - x > 0
\end{cases}
\iff
\begin{cases}
x > -1 \\[4pt]
x < 5 .
\end{cases}
$$
The endpoints are excluded because each makes an argument zero. Therefore the domain is $(-1, 5)$.
