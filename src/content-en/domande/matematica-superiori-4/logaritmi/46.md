For which values of $x$ is $y = \log_{\frac{1}{2}} x$ negative?

- $0 < x < 1$
- $x > \dfrac{1}{2}$
- $x > 1$
- $x < 0$

## Explanation

The base $\dfrac{1}{2}$ is less than $1$, so the function is strictly decreasing. Its graph passes through $(1, 0)$ because $\log_{\frac{1}{2}} 1 = 0$.

Since the function is decreasing, for $x > 1$ we have $\log_{\frac{1}{2}} x < \log_{\frac{1}{2}} 1 = 0$. For $0 < x < 1$ the function is positive, whereas for $x \leq 0$ it is undefined.

Therefore the function is negative for $x > 1$.
