Which of the following equalities holds for every $x > 0$?

- $\log_2 (x + 4) = \log_2 x + 2$
- $\log_2 (4x) = 4 \log_2 x$
- $\log_2 (4x) = \log_2 x + 2$
- $\log_2 x^4 = \left( \log_2 x \right)^4$

## Explanation

By the product rule for logarithms, $\log_2 (4x) = \log_2 4 + \log_2 x = 2 + \log_2 x$, so **this equality holds** for every $x > 0$.

There is no corresponding formula for the logarithm of a sum. With $x = 4$, we have $\log_2 8 = 3$, whereas $\log_2 4 + 2 = 4$.

For $x = 2$ we have $\log_2 8 = 3$ and $4 \log_2 2 = 4$, so $\log_2 (4x)$ differs from $4 \log_2 x$. Finally, the power rule for logarithms gives $\log_2 x^4 = 4 \log_2 x$, which at $x = 4$ equals $8$, whereas $\left( \log_2 4 \right)^4 = 16$.
