For which values of the real number $c$ does the equation $3\sin x + 4\cos x = c$ have solutions?

- $-7 \leq c \leq 7$
- $-5 \leq c \leq 5$
- $-1 \leq c \leq 1$
- $-5 < c < 5$

## Explanation

We have $r = \sqrt{3^2 + 4^2} = 5$, so the auxiliary-angle method gives the equation $5\sin(x + \varphi) = c$. The equation $\sin(x + \varphi) = \dfrac{c}{5}$ has solutions if and only if $-1 \leq \dfrac{c}{5} \leq 1$, that is, if and only if $-5 \leq c \leq 5$. The endpoints are included because for $c = \pm 5$ we obtain $\sin(x + \varphi) = \pm 1$, which has solutions.
