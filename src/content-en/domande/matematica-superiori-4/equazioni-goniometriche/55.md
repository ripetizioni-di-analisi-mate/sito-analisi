What are the solutions of the equation $\tan x + \cot x = 2$?

- $x = \dfrac{\pi}{4} + k\pi$
- $x = \dfrac{\pi}{4} + 2k\pi$
- $x = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$
- $x = -\dfrac{\pi}{4} + k\pi$

## Explanation

The domain restrictions require $x \neq \dfrac{k\pi}{2}$, and for these values $\tan x \neq 0$ and $\cot x = \dfrac{1}{\tan x}$. Setting $t = \tan x$ gives the equation $t + \dfrac{1}{t} = 2$. Multiplying by $t$ gives $t^2 - 2t + 1 = 0$, that is, $(t - 1)^2 = 0$. Thus $\tan x = 1$, which gives $x = \dfrac{\pi}{4} + k\pi$, values that satisfy the domain restrictions.
