Which of the following equations has no solutions?

- $3\sin x = -2$
- $5\cos x = 4$
- $2\sin x + 3 = 0$
- $4\tan x = 7$

## Explanation

Basic sine and cosine equations have solutions only if the given function value lies between $-1$ and $1$. The equation $2\sin x + 3 = 0$ is equivalent to $\sin x = -\dfrac{3}{2}$, and $-\dfrac{3}{2} < -1$, so it has no solutions. The equations $3\sin x = -2$ and $5\cos x = 4$ give $\sin x = -\dfrac{2}{3}$ and $\cos x = \dfrac{4}{5}$, values between $-1$ and $1$. The tangent equation has solutions for every value on the right-hand side because tangent takes every real value.
