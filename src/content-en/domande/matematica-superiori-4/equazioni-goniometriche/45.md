What are the solutions of the equation $\sin x = \cos (2x)$?

- $x = \dfrac{\pi}{6} + 2k\pi$
- $x = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$
- $x = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$ or $x = \dfrac{\pi}{2} + 2k\pi$
- $x = \dfrac{\pi}{6} + \dfrac{k\pi}{3}$

## Explanation

By the identity for related angles, $\cos(2x) = \sin\left(\dfrac{\pi}{2} - 2x\right)$, so the equation becomes $\sin x = \sin\left(\dfrac{\pi}{2} - 2x\right)$. The first family gives $x = \dfrac{\pi}{2} - 2x + 2k\pi$, that is, $3x = \dfrac{\pi}{2} + 2k\pi$ and $x = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$. The second gives $x = \pi - \dfrac{\pi}{2} + 2x + 2k\pi$, that is, $x = -\dfrac{\pi}{2} - 2k\pi$, which can also be written as $x = -\dfrac{\pi}{2} + 2k\pi$. These values already belong to the first family, which for $k = -1$ gives $-\dfrac{\pi}{2}$, so the solutions are $x = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$.
