Consider the equation $\sin x + \cos x = c$. For which of the following values of $c$ does the equation have *exactly one* solution in the interval $[0, 2\pi)$?

- $0$
- $\sqrt{2}$
- $1$
- $2$

## Explanation

By the auxiliary angle method, $\sin x + \cos x = \sqrt{2}\sin\left( x + \dfrac{\pi}{4} \right)$, so the equation is equivalent to $\sin\left( x + \dfrac{\pi}{4} \right) = \dfrac{c}{\sqrt{2}}$. As $x$ runs through $[0, 2\pi)$, the angle $x + \dfrac{\pi}{4}$ runs through an interval of length $2\pi$, on which the sine takes the values $1$ and $-1$ exactly once and every value strictly between $-1$ and $1$ twice. For $c = 2$ we get $\dfrac{c}{\sqrt{2}} = \sqrt{2} > 1$, so the equation has no solutions. For $c = 0$ and $c = 1$ the value $\dfrac{c}{\sqrt{2}}$ lies strictly between $-1$ and $1$, so there are two solutions (for $c = 1$ they are $x = 0$ and $x = \dfrac{\pi}{2}$). For $c = \sqrt{2}$ the equation becomes $\sin\left( x + \dfrac{\pi}{4} \right) = 1$, whose only solution is $x = \dfrac{\pi}{4}$, so the required value is $c = \sqrt{2}$.
