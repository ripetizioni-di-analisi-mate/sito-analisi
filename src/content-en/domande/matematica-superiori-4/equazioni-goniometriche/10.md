- $x = 2k\pi$, $x = -\dfrac{\pi}{2} + 2k\pi$, or $x = \pi + 2k\pi$
- $x = 2k\pi$ or $x = \dfrac{\pi}{2} + 2k\pi$
- $x = k\pi$ or $x = -\dfrac{\pi}{4} + k\pi$
- $x = 2k\pi$ or $x = -\dfrac{\pi}{2} + 2k\pi$

## Explanation

At the points $x = \pi + 2k\pi$, we have $\cos x - \sin x = -1 - 0 = -1$, so these values are not solutions. For the other values, set $t = \tan\dfrac{x}{2}$ and multiply by $1 + t^2$ to obtain $1 - t^2 - 2t = 1 + t^2$, that is, $-2t\,(t + 1) = 0$. From $t = 0$ it follows that $\dfrac{x}{2} = k\pi$, that is, $x = 2k\pi$. From $t = -1$ it follows that $\dfrac{x}{2} = -\dfrac{\pi}{4} + k\pi$, that is, $x = -\dfrac{\pi}{2} + 2k\pi$.
