What are the solutions of the equation $\cot x = \sqrt{3}$?

- $x = \dfrac{\pi}{3} + k\pi$
- $x = \dfrac{\pi}{6} + 2k\pi$
- $x = -\dfrac{\pi}{6} + k\pi$
- $x = \dfrac{\pi}{6} + k\pi$

## Explanation

The value $\sqrt{3}$ differs from $0$, so the equation is equivalent to $\tan x = \dfrac{1}{\sqrt{3}} = \dfrac{\sqrt{3}}{3}$. Since $\arctan\dfrac{\sqrt{3}}{3} = \dfrac{\pi}{6}$, the solutions are $x = \dfrac{\pi}{6} + k\pi$. These values satisfy the condition $x \neq k\pi$ required for cotangent to be defined.
