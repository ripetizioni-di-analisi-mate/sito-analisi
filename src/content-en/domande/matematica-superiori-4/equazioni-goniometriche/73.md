What are the solutions of the equation $\sin x + \cos x = -1$?

- $x = \pi + 2k\pi$ or $x = -\dfrac{\pi}{2} + 2k\pi$
- $x = -\dfrac{\pi}{2} + 2k\pi$
- $x = \pi + 2k\pi$ or $x = \dfrac{\pi}{2} + 2k\pi$
- $x = \pi + 2k\pi$ or $x = -\dfrac{\pi}{4} + k\pi$

## Explanation

At the points $x = \pi + 2k\pi$, we have $\sin x + \cos x = 0 - 1 = -1$, so these values are solutions. For the other values, set $t = \tan\dfrac{x}{2}$ and multiply by $1 + t^2$ to obtain $2t + 1 - t^2 = -1 - t^2$, that is, $2t + 2 = 0$. From $t = -1$ it follows that $\dfrac{x}{2} = -\dfrac{\pi}{4} + k\pi$, that is, $x = -\dfrac{\pi}{2} + 2k\pi$. The solutions are therefore $x = \pi + 2k\pi$ or $x = -\dfrac{\pi}{2} + 2k\pi$.
