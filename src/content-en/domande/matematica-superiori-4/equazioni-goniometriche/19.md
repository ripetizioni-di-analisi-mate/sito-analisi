For what integer value of $k$ does the family $x = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$ give the solution $x = \dfrac{11\pi}{4}$?

- $k = 4$
- $k = 5$
- $k = 10$
- $k = 6$

## Explanation

Set $\dfrac{\pi}{4} + \dfrac{k\pi}{2} = \dfrac{11\pi}{4}$, so $\dfrac{k\pi}{2} = \dfrac{10\pi}{4} = \dfrac{5\pi}{2}$. Multiplying by $\dfrac{2}{\pi}$ gives $k = 5$. Indeed, for $k = 5$ we have $\dfrac{\pi}{4} + \dfrac{5\pi}{2} = \dfrac{\pi}{4} + \dfrac{10\pi}{4} = \dfrac{11\pi}{4}$.
