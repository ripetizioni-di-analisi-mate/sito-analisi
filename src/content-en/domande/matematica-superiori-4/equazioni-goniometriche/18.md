Which of the following families describes the same solutions as the family $x = -\dfrac{\pi}{3} + 2k\pi$?

- $x = \dfrac{5\pi}{3} + 2k\pi$
- $x = \dfrac{2\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{3} + 2k\pi$
- $x = -\dfrac{\pi}{3} + k\pi$

## Explanation

Two families with the same period $2\pi$ coincide when their initial values differ by an integer multiple of $2\pi$. We have $-\dfrac{\pi}{3} + 2\pi = \dfrac{5\pi}{3}$, so the family $x = \dfrac{5\pi}{3} + 2k\pi$ is obtained from the given one by replacing $k$ with $k + 1$. Neither $\dfrac{2\pi}{3}$ nor $\dfrac{\pi}{3}$ differs from $-\dfrac{\pi}{3}$ by a multiple of $2\pi$. The family $x = -\dfrac{\pi}{3} + k\pi$ also contains $\dfrac{2\pi}{3}$, which does not belong to the given family.
