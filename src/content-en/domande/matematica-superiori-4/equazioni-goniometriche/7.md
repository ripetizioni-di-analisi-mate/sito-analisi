- $x = \pm\dfrac{\pi}{3} + 2k\pi$
- $x = \dfrac{2\pi}{3} + 2k\pi$ or $x = \dfrac{\pi}{3} + 2k\pi$
- $x = \pm\dfrac{2\pi}{3} + k\pi$
- $x = \pm\dfrac{2\pi}{3} + 2k\pi$

## Explanation

By the Pythagorean identity $\sin^2 x = 1 - \cos^2 x$, the equation becomes $2 - 2\cos^2 x + 3\cos x = 0$, that is, $2\cos^2 x - 3\cos x - 2 = 0$. Setting $t = \cos x$ gives $\Delta = 9 + 16 = 25$, so $t = \dfrac{3 \pm 5}{4}$, that is, $t = 2$ or $t = -\dfrac{1}{2}$. The value $t = 2$ is inadmissible because the cosine cannot exceed $1$. This leaves $\cos x = -\dfrac{1}{2}$, which gives $x = \pm\dfrac{2\pi}{3} + 2k\pi$.
