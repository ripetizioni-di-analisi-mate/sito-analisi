In the equation $2\sin x + 3\cos x = c$, for which value of $c$ are the values $x = \pi + 2k\pi$ solutions?

- $c = 3$
- $c = -3$
- $c = 2$
- $c = -2$

## Explanation

At $x = \pi + 2k\pi$, we have $\sin x = 0$ and $\cos x = -1$. The left-hand side therefore equals $2 \cdot 0 + 3 \cdot (-1) = -3$. Hence these values are solutions if and only if $c = -3$, in agreement with the condition $-b = c$ for the tangent half-angle substitution.
