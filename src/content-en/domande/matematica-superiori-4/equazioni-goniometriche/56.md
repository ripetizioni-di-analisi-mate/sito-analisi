After dividing by $\cos x$ on both sides of the equation $\sin x\cos x = \cos x$, one obtains $\sin x = 1$. Which solutions of the original equation are discarded by this division?

- $x = \dfrac{\pi}{2} + k\pi$
- $x = \dfrac{\pi}{2} + 2k\pi$
- $x = k\pi$
- $x = -\dfrac{\pi}{2} + 2k\pi$

## Explanation

Factoring gives the equation $\cos x\,(\sin x - 1) = 0$, so the solutions are the values satisfying $\cos x = 0$, that is, $x = \dfrac{\pi}{2} + k\pi$, and those satisfying $\sin x = 1$, that is, $x = \dfrac{\pi}{2} + 2k\pi$. The second family is contained in the first, so the solutions are $x = \dfrac{\pi}{2} + k\pi$. The equation $\sin x = 1$ gives only $x = \dfrac{\pi}{2} + 2k\pi$. The division therefore discards the values $x = -\dfrac{\pi}{2} + 2k\pi$, at which $\cos x = 0$ and $\sin x = -1$.
