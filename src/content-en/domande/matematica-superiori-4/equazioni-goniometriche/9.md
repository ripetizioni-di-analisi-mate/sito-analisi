- $x = \dfrac{\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{6} + k\pi$
- $x = \dfrac{\pi}{6} + 2k\pi$
- $x = \dfrac{5\pi}{6} + 2k\pi$

## Explanation

We have $a = 1$, $b = \sqrt{3}$, and $r = \sqrt{1 + 3} = 2$, so the auxiliary angle satisfies $\cos\varphi = \dfrac{1}{2}$ and $\sin\varphi = \dfrac{\sqrt{3}}{2}$, that is, $\varphi = \dfrac{\pi}{3}$. The equation becomes $2\sin\left(x + \dfrac{\pi}{3}\right) = 2$, that is, $\sin\left(x + \dfrac{\pi}{3}\right) = 1$. The special-case formula for sine gives $x + \dfrac{\pi}{3} = \dfrac{\pi}{2} + 2k\pi$, so $x = \dfrac{\pi}{6} + 2k\pi$. The solutions form a single family because $c = r$.
