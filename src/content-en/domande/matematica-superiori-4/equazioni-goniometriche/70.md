Which of the following linear equations in sine and cosine has no solutions?

- $\sin x + \cos x = \dfrac{3}{2}$
- $\sqrt{3}\sin x + \cos x = 2$
- $3\sin x - 4\cos x = 5$
- $\sin x - \cos x = -1$

## Explanation

The equation $a\sin x + b\cos x = c$ has solutions if and only if $c^2 \leq a^2 + b^2$. For $\sin x + \cos x = \dfrac{3}{2}$, we have $c^2 = \dfrac{9}{4}$ and $a^2 + b^2 = 2 = \dfrac{8}{4}$, so the condition is not satisfied and the equation has no solutions. In the other three equations, the condition is satisfied because $4 = 4$, $25 = 25$, and $1 < 2$, respectively.
