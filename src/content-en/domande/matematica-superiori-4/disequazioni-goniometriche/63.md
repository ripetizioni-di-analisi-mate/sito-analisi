Which statement about the inequality $3\sin x + 4\cos x > 5$ is true?

- It holds for every real $x$
- It has only isolated solutions
- It has no solutions
- It holds for $x = 0$

## Explanation

The auxiliary-angle method gives $r = \sqrt{9 + 16} = 5$, so $3\sin x + 4\cos x = 5\sin(x + \varphi)$ for a suitable angle $\varphi$. The inequality becomes $\sin(x + \varphi) > 1$, which **has no solutions** because the sine cannot exceed $1$. The inequality with $\geq$ would have only the isolated solutions for which $\sin(x + \varphi) = 1$. For $x = 0$, the left-hand side equals $4$, which is less than $5$.
