What are the solutions of the inequality $\sin x - \cos x \leq -1$?

- $\pi + 2k\pi \leq x \leq \dfrac{3\pi}{2} + 2k\pi$
- $\dfrac{3\pi}{2} + 2k\pi \leq x \leq 2\pi + 2k\pi$
- $\dfrac{5\pi}{4} + 2k\pi \leq x \leq \dfrac{7\pi}{4} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi \leq x \leq \pi + 2k\pi$

## Explanation

By the auxiliary-angle identity, $\sin x - \cos x = \sqrt{2}\sin\left( x - \dfrac{\pi}{4} \right)$, so the inequality becomes $\sin\left( x - \dfrac{\pi}{4} \right) \leq -\dfrac{1}{\sqrt{2}} = -\dfrac{\sqrt{2}}{2}$. The argument must lie between $\dfrac{5\pi}{4} + 2k\pi$ and $\dfrac{7\pi}{4} + 2k\pi$, including the endpoints. Adding $\dfrac{\pi}{4}$ gives $\dfrac{3\pi}{2} + 2k\pi \leq x \leq 2\pi + 2k\pi$. Indeed, for $x = 2\pi$ we have $\sin x - \cos x = 0 - 1 = -1$.
