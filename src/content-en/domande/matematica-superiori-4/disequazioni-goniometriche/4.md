- $2k\pi < x < \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{12} + k\pi < x < \dfrac{5\pi}{12} + k\pi$
- $k\pi < x < \dfrac{\pi}{3} + k\pi$
- $k\pi < x < \dfrac{2\pi}{3} + k\pi$

## Explanation

Set $t = 2x + \dfrac{\pi}{6}$. The solutions of the inequality $\sin t > \dfrac{1}{2}$ are $\dfrac{\pi}{6} + 2k\pi < t < \dfrac{5\pi}{6} + 2k\pi$. Subtracting $\dfrac{\pi}{6}$ from all three parts gives $2k\pi < 2x < \dfrac{2\pi}{3} + 2k\pi$. Dividing by $2$ gives $k\pi < x < \dfrac{\pi}{3} + k\pi$, since the period $2k\pi$ is also divided by $2$.
