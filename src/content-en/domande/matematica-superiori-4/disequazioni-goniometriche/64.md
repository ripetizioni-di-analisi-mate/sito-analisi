What are the solutions of the inequality $\sin^2 x - \sin x\cos x > 0$?

- $\dfrac{\pi}{4} + k\pi < x < \pi + k\pi$, with $x \neq \dfrac{\pi}{2} + k\pi$
- $k\pi < x < \dfrac{\pi}{4} + k\pi$
- $\dfrac{\pi}{4} + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{4} + k\pi < x < \pi + k\pi$

## Explanation

The inequality is homogeneous with $a = 1$, $b = -1$, and $c = 0$. For $\cos x \neq 0$, dividing by $\cos^2 x > 0$ gives $\tan^2 x - \tan x > 0$, that is, $\tan x < 0$ or $\tan x > 1$. On each branch, these conditions give $\dfrac{\pi}{4} + k\pi < x < \dfrac{\pi}{2} + k\pi$ and $\dfrac{\pi}{2} + k\pi < x < \pi + k\pi$. For $\cos x = 0$, the left-hand side equals $a = 1 > 0$, so the points $\dfrac{\pi}{2} + k\pi$ are also solutions. Taking the union gives $\dfrac{\pi}{4} + k\pi < x < \pi + k\pi$.
