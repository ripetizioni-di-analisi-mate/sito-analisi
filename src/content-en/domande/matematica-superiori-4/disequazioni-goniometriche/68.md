What are the solutions of the inequality $\sin^2 x - 3\sin x\cos x + 2\cos^2 x < 0$?

- $\dfrac{\pi}{4} + k\pi < x < \arctan 2 + k\pi$
- $\dfrac{\pi}{4} + k\pi < x \leq \arctan 2 + k\pi$
- $\arctan 2 + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{4} + 2k\pi < x < \arctan 2 + 2k\pi$

## Explanation

The inequality is homogeneous with $a = 1$, $b = -3$, and $c = 2$. For $\cos x \neq 0$, dividing by $\cos^2 x > 0$ gives $\tan^2 x - 3\tan x + 2 < 0$, that is, $(\tan x - 1)(\tan x - 2) < 0$, which holds for $1 < \tan x < 2$. Since tangent is increasing on each branch, we have $\dfrac{\pi}{4} + k\pi < x < \arctan 2 + k\pi$. For $\cos x = 0$, the left-hand side equals $a = 1$, which is not negative, so there are no further solutions to add.
