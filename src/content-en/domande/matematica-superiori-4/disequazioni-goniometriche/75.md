What are the solutions of the inequality $\dfrac{2\sin x + 1}{\cos x} > 0$ in the interval $[0, 2\pi)$?

- $0 \leq x < \dfrac{\pi}{2}$ or $\dfrac{7\pi}{6} < x < \dfrac{3\pi}{2}$ or $\dfrac{11\pi}{6} < x < 2\pi$
- $0 \leq x < \dfrac{\pi}{2}$ or $\dfrac{3\pi}{2} < x < 2\pi$
- $\dfrac{\pi}{2} < x < \dfrac{7\pi}{6}$ or $\dfrac{3\pi}{2} < x < \dfrac{11\pi}{6}$
- $0 \leq x < \dfrac{\pi}{2}$ or $\dfrac{7\pi}{6} < x < \dfrac{3\pi}{2}$

## Explanation

In $[0, 2\pi)$, the numerator $2\sin x + 1$ is positive for $0 \leq x < \dfrac{7\pi}{6}$ and for $\dfrac{11\pi}{6} < x < 2\pi$ and negative for $\dfrac{7\pi}{6} < x < \dfrac{11\pi}{6}$. The denominator $\cos x$ is positive for $0 \leq x < \dfrac{\pi}{2}$ and for $\dfrac{3\pi}{2} < x < 2\pi$ and negative for $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$. The quotient is positive where its numerator and denominator have the same sign, that is, on $\left[ 0, \dfrac{\pi}{2} \right)$, on $\left( \dfrac{7\pi}{6}, \dfrac{3\pi}{2} \right)$, and on $\left( \dfrac{11\pi}{6}, 2\pi \right)$. The zeros of the denominator, $\dfrac{\pi}{2}$ and $\dfrac{3\pi}{2}$, are excluded.
