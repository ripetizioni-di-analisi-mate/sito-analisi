- $\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{3} + k\pi$
- $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$
- $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$, with $x \neq \dfrac{\pi}{2} + k\pi$

## Explanation

The inequality is homogeneous of degree two, with $a = 1$, $b = 0$, and $c = -3$. For $\cos x \neq 0$, divide by $\cos^2 x > 0$ to obtain $\tan^2 x - 3 > 0$, that is, $\tan x < -\sqrt{3}$ or $\tan x > \sqrt{3}$, which give $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$ with $x \neq \dfrac{\pi}{2} + k\pi$. For $\cos x = 0$, the left-hand side equals $a = 1 > 0$, so the values $x = \dfrac{\pi}{2} + k\pi$ are also solutions. Taking the union of the two parts gives $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$, with no exclusions.
