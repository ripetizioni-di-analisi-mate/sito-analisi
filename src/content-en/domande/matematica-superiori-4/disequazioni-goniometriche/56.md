What are the solutions of the inequality $\sqrt{3}\sin x - \cos x \geq 1$?

- $2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \pi + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\pi + 2k\pi \leq x \leq \dfrac{7\pi}{3} + 2k\pi$

## Explanation

With the auxiliary-angle method, we have $r = \sqrt{3 + 1} = 2$, $\cos\varphi = \dfrac{\sqrt{3}}{2}$, and $\sin\varphi = -\dfrac{1}{2}$, so $\varphi = -\dfrac{\pi}{6}$. The inequality becomes $2\sin\left( x - \dfrac{\pi}{6} \right) \geq 1$, that is, $\sin\left( x - \dfrac{\pi}{6} \right) \geq \dfrac{1}{2}$. The argument must lie between $\dfrac{\pi}{6} + 2k\pi$ and $\dfrac{5\pi}{6} + 2k\pi$, including the endpoints. Adding $\dfrac{\pi}{6}$ gives $\dfrac{\pi}{3} + 2k\pi \leq x \leq \pi + 2k\pi$.
