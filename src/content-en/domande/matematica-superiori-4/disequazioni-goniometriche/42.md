What are the solutions of the inequality $\cos\left( 2x + \dfrac{\pi}{3} \right) > 0$?

- $-\dfrac{5\pi}{12} + k\pi < x < \dfrac{\pi}{12} + k\pi$
- $-\dfrac{5\pi}{12} + 2k\pi < x < \dfrac{\pi}{12} + 2k\pi$
- $-\dfrac{7\pi}{12} + k\pi < x < -\dfrac{\pi}{12} + k\pi$
- $\dfrac{\pi}{12} + k\pi < x < \dfrac{7\pi}{12} + k\pi$

## Explanation

Set $t = 2x + \dfrac{\pi}{3}$. The solutions of the inequality $\cos t > 0$ are $-\dfrac{\pi}{2} + 2k\pi < t < \dfrac{\pi}{2} + 2k\pi$. Subtracting $\dfrac{\pi}{3}$ from all three parts gives $-\dfrac{5\pi}{6} + 2k\pi < 2x < \dfrac{\pi}{6} + 2k\pi$. Dividing by $2$ gives $-\dfrac{5\pi}{12} + k\pi < x < \dfrac{\pi}{12} + k\pi$. The term $\dfrac{\pi}{3}$ is subtracted before dividing because it is added to $2x$.
