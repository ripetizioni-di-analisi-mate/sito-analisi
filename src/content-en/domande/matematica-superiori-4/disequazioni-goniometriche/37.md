What are the solutions of the inequality $\tan 2x > 1$?

- $\dfrac{\pi}{8} + k\pi < x < \dfrac{\pi}{4} + k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \pi + 2k\pi$
- $\dfrac{\pi}{8} + \dfrac{k\pi}{2} < x < \dfrac{\pi}{4} + \dfrac{k\pi}{2}$
- $\dfrac{\pi}{8} + \dfrac{k\pi}{2} < x < \dfrac{\pi}{2} + \dfrac{k\pi}{2}$

## Explanation

Set $t = 2x$. The solutions of the inequality $\tan t > 1$ are $\dfrac{\pi}{4} + k\pi < t < \dfrac{\pi}{2} + k\pi$. Dividing all three parts by $2$ gives $\dfrac{\pi}{8} + \dfrac{k\pi}{2} < x < \dfrac{\pi}{4} + \dfrac{k\pi}{2}$. The period in $x$ is $\dfrac{\pi}{2}$, since the tangent with argument $2x$ has period $\dfrac{\pi}{2}$.
