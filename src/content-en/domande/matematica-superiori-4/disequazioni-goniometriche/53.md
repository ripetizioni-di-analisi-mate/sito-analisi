What are the solutions of the inequality $(2\cos x + 1)^2 \leq 0$?

- No value of $x$
- Every real $x$
- $x = \dfrac{2\pi}{3} + 2k\pi$
- $x = \pm\dfrac{2\pi}{3} + 2k\pi$

## Explanation

A square is always greater than or equal to $0$, so $(2\cos x + 1)^2 \leq 0$ holds only when $(2\cos x + 1)^2 = 0$. This occurs for $2\cos x + 1 = 0$, that is, for $\cos x = -\dfrac{1}{2}$. The equation has solutions $x = \pm\dfrac{2\pi}{3} + 2k\pi$ because $\arccos\left( -\dfrac{1}{2} \right) = \dfrac{2\pi}{3}$. The solution set consists entirely of isolated points.
