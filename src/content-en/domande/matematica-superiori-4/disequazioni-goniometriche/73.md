What are the solutions of the inequality $\dfrac{\cos x}{1 + \sin x} \geq 0$?

- $-\dfrac{\pi}{2} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \dfrac{3\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x \leq \dfrac{\pi}{2} + 2k\pi$

## Explanation

The denominator $1 + \sin x$ is positive for $x \neq \dfrac{3\pi}{2} + 2k\pi$ and vanishes for $x = \dfrac{3\pi}{2} + 2k\pi$. Therefore the inequality is equivalent to the system
$$
\begin{cases}
\cos x \geq 0 \\[4pt]
x \neq \dfrac{3\pi}{2} + 2k\pi
\end{cases}
$$
The first condition gives $-\dfrac{\pi}{2} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$. The second excludes the endpoint $-\dfrac{\pi}{2} + 2k\pi$, which coincides with $\dfrac{3\pi}{2} + 2(k - 1)\pi$. The solutions are therefore $-\dfrac{\pi}{2} + 2k\pi < x \leq \dfrac{\pi}{2} + 2k\pi$.
