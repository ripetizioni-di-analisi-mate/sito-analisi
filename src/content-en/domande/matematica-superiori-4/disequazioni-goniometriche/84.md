What is the domain of the function $f(x) = \sqrt{1 - 2\sin x}$?

- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{13\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi < x < \dfrac{13\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{7\pi}{6} + 2k\pi$

## Explanation

The radicand must be greater than or equal to $0$, so $1 - 2\sin x \geq 0$, that is, $\sin x \leq \dfrac{1}{2}$. The points on the circle with vertical coordinate less than or equal to $\dfrac{1}{2}$ form the arc from $\dfrac{5\pi}{6}$ to $\dfrac{\pi}{6} + 2\pi = \dfrac{13\pi}{6}$ through $\dfrac{3\pi}{2}$. The endpoints are included because the radicand equals $0$ there. The domain is therefore $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{13\pi}{6} + 2k\pi$.
