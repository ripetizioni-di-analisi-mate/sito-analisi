Which inequality has solution set $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$, with $k \in \mathbb{Z}$?

- $\cos x > \dfrac{1}{2}$
- $\sin x > \dfrac{\sqrt{3}}{2}$
- $\cos x < \dfrac{1}{2}$
- $\tan x < \sqrt{3}$

## Explanation

The interval $\left( -\dfrac{\pi}{3}, \dfrac{\pi}{3} \right)$ is symmetric about $0$, like the arcs that solve inequalities of the form $\cos x > m$. Since $\arccos\dfrac{1}{2} = \dfrac{\pi}{3}$, the inequality $\cos x > \dfrac{1}{2}$ has precisely the solutions $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$. The inequality $\sin x > \dfrac{\sqrt{3}}{2}$, on the other hand, has solutions $\dfrac{\pi}{3} + 2k\pi < x < \dfrac{2\pi}{3} + 2k\pi$. The inequality $\tan x < \sqrt{3}$ has period $\pi$, and its solutions also include angles close to $-\dfrac{\pi}{2}$.
