Which of the following numbers is a solution of the inequality $\sin x < -\dfrac{\sqrt{3}}{2}$?

- $\dfrac{4\pi}{3}$
- $\dfrac{7\pi}{6}$
- $\dfrac{3\pi}{2}$
- $\dfrac{5\pi}{6}$

## Explanation

For $x = \dfrac{3\pi}{2}$ we have $\sin x = -1$, and $-1 < -\dfrac{\sqrt{3}}{2}$, so $\dfrac{3\pi}{2}$ is a solution. For $x = \dfrac{4\pi}{3}$ we have $\sin x = -\dfrac{\sqrt{3}}{2}$, which is not less than $-\dfrac{\sqrt{3}}{2}$, so this value is excluded. The values $\sin\dfrac{7\pi}{6} = -\dfrac{1}{2}$ and $\sin\dfrac{5\pi}{6} = \dfrac{1}{2}$ are greater than $-\dfrac{\sqrt{3}}{2}$. The solutions of the inequality are $\dfrac{4\pi}{3} + 2k\pi < x < \dfrac{5\pi}{3} + 2k\pi$, excluding the endpoints.
