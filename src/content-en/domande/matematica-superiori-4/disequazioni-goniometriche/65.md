What are the solutions of the inequality $\sin^2 x + 2\sin x\cos x - 3\cos^2 x \leq 0$?

- $-\arctan 3 + k\pi \leq x \leq \dfrac{\pi}{4} + k\pi$
- $-\dfrac{\pi}{4} + k\pi \leq x \leq \arctan 3 + k\pi$
- $-\arctan 3 + 2k\pi \leq x \leq \dfrac{\pi}{4} + 2k\pi$
- $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$

## Explanation

The inequality is homogeneous with $a = 1$, $b = 2$, and $c = -3$. For $\cos x \neq 0$, dividing by $\cos^2 x > 0$ gives $\tan^2 x + 2\tan x - 3 \leq 0$, that is, $(\tan x + 3)(\tan x - 1) \leq 0$. This condition holds for $-3 \leq \tan x \leq 1$, that is, for $-\arctan 3 + k\pi \leq x \leq \dfrac{\pi}{4} + k\pi$, because $\arctan(-3) = -\arctan 3$. For $\cos x = 0$, the left-hand side equals $a = 1$, which is not less than or equal to $0$, so there are no further solutions to add.
