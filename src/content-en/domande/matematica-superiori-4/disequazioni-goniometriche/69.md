What are the solutions of the inequality $\cos^2 x - \sin^2 x \geq 2\sin x\cos x$?

- $-\dfrac{3\pi}{8} + k\pi \leq x \leq \dfrac{\pi}{8} + k\pi$
- $\dfrac{\pi}{8} + k\pi \leq x \leq \dfrac{5\pi}{8} + k\pi$
- $-\dfrac{3\pi}{8} + 2k\pi \leq x \leq \dfrac{\pi}{8} + 2k\pi$
- $-\dfrac{3\pi}{4} + 2k\pi \leq x \leq \dfrac{\pi}{4} + 2k\pi$

## Explanation

The double-angle identities give $\cos^2 x - \sin^2 x = \cos 2x$ and $2\sin x\cos x = \sin 2x$, so the inequality becomes $\cos 2x - \sin 2x \geq 0$. With the auxiliary-angle method, using $a = -1$ and $b = 1$, we have $r = \sqrt{2}$ and $\varphi = \dfrac{3\pi}{4}$, hence $\cos 2x - \sin 2x = \sqrt{2}\sin\left( 2x + \dfrac{3\pi}{4} \right)$. The condition $\sin\left( 2x + \dfrac{3\pi}{4} \right) \geq 0$ gives $2k\pi \leq 2x + \dfrac{3\pi}{4} \leq \pi + 2k\pi$, that is, $-\dfrac{3\pi}{4} + 2k\pi \leq 2x \leq \dfrac{\pi}{4} + 2k\pi$. Dividing by $2$ gives $-\dfrac{3\pi}{8} + k\pi \leq x \leq \dfrac{\pi}{8} + k\pi$.
