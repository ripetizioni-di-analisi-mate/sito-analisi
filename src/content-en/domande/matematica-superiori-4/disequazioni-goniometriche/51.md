Setting $t = \cos x$ turns the inequality $2\cos^2 x - 5\cos x + 2 > 0$ into $(2t - 1)(t - 2) > 0$, which holds for $t < \dfrac{1}{2}$ or $t > 2$. Which inequality in $\cos x$ is equivalent to the original inequality?

- $\cos x < \dfrac{1}{2}$
- $\cos x > \dfrac{1}{2}$
- $\cos x > 2$
- $\cos x < 2$

## Explanation

The cosine takes only values in the interval $[-1, 1]$, so the condition $\cos x > 2$ is satisfied for no value of $x$. Therefore the original inequality is equivalent to the single condition $\cos x < \dfrac{1}{2}$. Its solutions are $\dfrac{\pi}{3} + 2k\pi < x < \dfrac{5\pi}{3} + 2k\pi$. In contrast, the condition $\cos x < 2$ holds for every $x$, whereas the trinomial is negative for $\cos x = 1$.
