Solve the inequality $\sin x + \cos x \leq -1$ using the tangent half-angle formulas, setting $t = \tan\dfrac{x}{2}$. What are the solutions?

- $\pi + 2k\pi < x \leq \dfrac{3\pi}{2} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi \leq x \leq \pi + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi \leq x \leq 2k\pi$
- $\pi + 2k\pi \leq x \leq \dfrac{3\pi}{2} + 2k\pi$

## Explanation

For $x \neq \pi + 2k\pi$, substitute $\sin x = \dfrac{2t}{1 + t^2}$ and $\cos x = \dfrac{1 - t^2}{1 + t^2}$ and multiply by $1 + t^2 > 0$. This gives $2t + 1 - t^2 \leq -1 - t^2$, that is, $t \leq -1$. The condition $\tan\dfrac{x}{2} \leq -1$ gives $-\dfrac{\pi}{2} + k\pi < \dfrac{x}{2} \leq -\dfrac{\pi}{4} + k\pi$, so $-\pi + 2k\pi < x \leq -\dfrac{\pi}{2} + 2k\pi$, which, on replacing $k$ with $k + 1$, can be written as $\pi + 2k\pi < x \leq \dfrac{3\pi}{2} + 2k\pi$. The value $x = \pi$, excluded by the substitution, satisfies the inequality because $\sin\pi + \cos\pi = -1$. Adding the points $\pi + 2k\pi$ gives $\pi + 2k\pi \leq x \leq \dfrac{3\pi}{2} + 2k\pi$.
