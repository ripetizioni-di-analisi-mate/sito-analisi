What is the domain of the function $f(x) = \arcsin(2\sin x)$?

- $-\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{\pi}{6} + 2k\pi$
- $\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{5\pi}{6} + k\pi$
- $-\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{\pi}{6} + k\pi$
- Every real $x$

## Explanation

The argument of the inverse sine must lie in $[-1, 1]$, so $-1 \leq 2\sin x \leq 1$, that is, $-\dfrac{1}{2} \leq \sin x \leq \dfrac{1}{2}$. The points on the circle with vertical coordinate between $-\dfrac{1}{2}$ and $\dfrac{1}{2}$ form two arcs, one from $-\dfrac{\pi}{6}$ to $\dfrac{\pi}{6}$ and one from $\dfrac{5\pi}{6}$ to $\dfrac{7\pi}{6}$. The second arc is obtained from the first by adding $\pi$. The domain is therefore $-\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{\pi}{6} + k\pi$.
