What are the solutions of the inequality $\sin x + \cos x > 0$?

- $\dfrac{\pi}{4} + 2k\pi < x < \dfrac{5\pi}{4} + 2k\pi$
- $-\dfrac{\pi}{4} + 2k\pi < x < \dfrac{3\pi}{4} + 2k\pi$
- $\dfrac{3\pi}{4} + 2k\pi < x < \dfrac{7\pi}{4} + 2k\pi$
- $-\dfrac{\pi}{4} + k\pi < x < \dfrac{3\pi}{4} + k\pi$

## Explanation

With the **auxiliary-angle method**, we have $r = \sqrt{1 + 1} = \sqrt{2}$ and $\cos\varphi = \sin\varphi = \dfrac{\sqrt{2}}{2}$, so $\varphi = \dfrac{\pi}{4}$. The inequality becomes $\sqrt{2}\sin\left( x + \dfrac{\pi}{4} \right) > 0$, that is, $\sin\left( x + \dfrac{\pi}{4} \right) > 0$. The argument must lie between $2k\pi$ and $\pi + 2k\pi$. Subtracting $\dfrac{\pi}{4}$ gives $-\dfrac{\pi}{4} + 2k\pi < x < \dfrac{3\pi}{4} + 2k\pi$.
