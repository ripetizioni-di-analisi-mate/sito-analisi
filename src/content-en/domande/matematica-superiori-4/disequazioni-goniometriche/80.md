What are the solutions of the system
$$
\begin{cases}
\tan x > 0 \\[4pt]
\cos x < \dfrac{1}{2}
\end{cases}
$$
in the interval $[0, 2\pi)$?

- $\dfrac{\pi}{3} < x < \dfrac{\pi}{2}$
- $0 < x < \dfrac{\pi}{3}$ or $\pi < x < \dfrac{3\pi}{2}$
- $\dfrac{\pi}{3} < x < \dfrac{3\pi}{2}$
- $\dfrac{\pi}{3} < x < \dfrac{\pi}{2}$ or $\pi < x < \dfrac{3\pi}{2}$

## Explanation

In $[0, 2\pi)$, tangent is positive for $0 < x < \dfrac{\pi}{2}$ and for $\pi < x < \dfrac{3\pi}{2}$, that is, in the first and third quadrants. The second inequality has solutions $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$. The intersection of the first tangent interval with $\left( \dfrac{\pi}{3}, \dfrac{5\pi}{3} \right)$ is $\dfrac{\pi}{3} < x < \dfrac{\pi}{2}$, whereas the second interval lies entirely within $\left( \dfrac{\pi}{3}, \dfrac{5\pi}{3} \right)$. The solutions of the system are therefore $\dfrac{\pi}{3} < x < \dfrac{\pi}{2}$ or $\pi < x < \dfrac{3\pi}{2}$.
