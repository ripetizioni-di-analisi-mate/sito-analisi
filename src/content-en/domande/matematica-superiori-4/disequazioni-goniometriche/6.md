- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{13\pi}{6} + 2k\pi$
- $\dfrac{7\pi}{6} + 2k\pi \leq x \leq \dfrac{11\pi}{6} + 2k\pi$ or $x = \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$ or $x = \dfrac{3\pi}{2} + 2k\pi$

## Explanation

Setting $t = \sin x$ gives $2t^2 + t - 1 \geq 0$, that is, $(2t - 1)(t + 1) \geq 0$, which holds for $t \leq -1$ or $t \geq \dfrac{1}{2}$. Since $\sin x \geq -1$ for every $x$, the condition $\sin x \leq -1$ is equivalent to $\sin x = -1$, that is, to $x = \dfrac{3\pi}{2} + 2k\pi$. The condition $\sin x \geq \dfrac{1}{2}$ gives $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$. The solutions are the union of these two sets, and the points $\dfrac{3\pi}{2} + 2k\pi$ are **isolated solutions**.
