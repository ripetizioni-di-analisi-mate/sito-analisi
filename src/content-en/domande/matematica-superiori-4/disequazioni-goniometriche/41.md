What are the solutions of the inequality $\tan\dfrac{x}{2} < 1$?

- $-\dfrac{\pi}{4} + \dfrac{k\pi}{2} < x < \dfrac{\pi}{8} + \dfrac{k\pi}{2}$
- $-\pi + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $-\pi + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \pi + 2k\pi$

## Explanation

Set $t = \dfrac{x}{2}$. The solutions of the inequality $\tan t < 1$ are $-\dfrac{\pi}{2} + k\pi < t < \dfrac{\pi}{4} + k\pi$. Multiplying all three parts by $2$ gives $-\pi + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$. The period becomes $2\pi$, the period of $\tan\dfrac{x}{2}$.
