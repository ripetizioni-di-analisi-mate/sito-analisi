What are the solutions of the inequality $\sin x \leq \dfrac{1}{2}$ in the interval $[0, 2\pi)$?

- $\dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}$
- $0 \leq x \leq \dfrac{\pi}{3}$ or $\dfrac{2\pi}{3} \leq x < 2\pi$
- $0 \leq x \leq \dfrac{\pi}{6}$ or $\dfrac{5\pi}{6} \leq x < 2\pi$
- $0 \leq x < \dfrac{\pi}{6}$ or $\dfrac{5\pi}{6} < x < 2\pi$

## Explanation

In $[0, 2\pi)$, the solutions of the equation $\sin x = \dfrac{1}{2}$ are $\dfrac{\pi}{6}$ and $\dfrac{5\pi}{6}$. The graph of $y = \sin x$ lies above the line $y = \dfrac{1}{2}$ between these two values, so it lies below the line on the rest of the interval. The solutions are $0 \leq x \leq \dfrac{\pi}{6}$ or $\dfrac{5\pi}{6} \leq x < 2\pi$. The endpoints $\dfrac{\pi}{6}$ and $\dfrac{5\pi}{6}$ are included because the inequality allows equality.
