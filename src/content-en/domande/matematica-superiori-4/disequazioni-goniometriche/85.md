What is the domain of the function $f(x) = \dfrac{1}{2\cos x - \sqrt{3}}$?

- $x \neq \pm\dfrac{\pi}{3} + 2k\pi$
- $x \neq \dfrac{\pi}{6} + 2k\pi$ and $x \neq \dfrac{5\pi}{6} + 2k\pi$
- $x \neq \pm\dfrac{\pi}{6} + k\pi$
- $x \neq \pm\dfrac{\pi}{6} + 2k\pi$

## Explanation

The denominator must differ from $0$, so $2\cos x - \sqrt{3} \neq 0$, that is, $\cos x \neq \dfrac{\sqrt{3}}{2}$. Since $\arccos\dfrac{\sqrt{3}}{2} = \dfrac{\pi}{6}$, the equation $\cos x = \dfrac{\sqrt{3}}{2}$ has solutions $x = \pm\dfrac{\pi}{6} + 2k\pi$. The domain consists of all real numbers except these, that is, $x \neq \pm\dfrac{\pi}{6} + 2k\pi$. The values $\dfrac{5\pi}{6} + 2k\pi$ belong to the domain because the cosine equals $-\dfrac{\sqrt{3}}{2}$ at those points.
