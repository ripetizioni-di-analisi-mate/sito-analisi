What are the solutions of the inequality $2\sin x \geq -\sqrt{3}$ in the interval $[0, 2\pi)$?

- $\dfrac{4\pi}{3} \leq x \leq \dfrac{5\pi}{3}$
- $0 \leq x \leq \dfrac{4\pi}{3}$ or $\dfrac{5\pi}{3} \leq x < 2\pi$
- $0 \leq x \leq \dfrac{7\pi}{6}$ or $\dfrac{11\pi}{6} \leq x < 2\pi$
- $0 \leq x < \dfrac{4\pi}{3}$ or $\dfrac{5\pi}{3} < x < 2\pi$

## Explanation

Dividing by $2$ gives $\sin x \geq -\dfrac{\sqrt{3}}{2}$. In $[0, 2\pi)$, the equation $\sin x = -\dfrac{\sqrt{3}}{2}$ has solutions $\dfrac{4\pi}{3}$ and $\dfrac{5\pi}{3}$, in the third and fourth quadrants. The sine graph lies below the line $y = -\dfrac{\sqrt{3}}{2}$ only between these two values, so it lies above or meets the line for $0 \leq x \leq \dfrac{4\pi}{3}$ and for $\dfrac{5\pi}{3} \leq x < 2\pi$. The endpoints $\dfrac{4\pi}{3}$ and $\dfrac{5\pi}{3}$ are included because the inequality allows equality.
