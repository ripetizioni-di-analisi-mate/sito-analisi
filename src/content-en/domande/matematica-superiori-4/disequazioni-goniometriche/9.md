- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi < x < \dfrac{13\pi}{6} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \dfrac{11\pi}{6} + 2k\pi$
- $\dfrac{2\pi}{3} + 2k\pi < x < 2\pi + 2k\pi$

## Explanation

With the **auxiliary-angle method**, we have $r = \sqrt{1 + 3} = 2$, $\cos\varphi = \dfrac{1}{2}$, and $\sin\varphi = \dfrac{\sqrt{3}}{2}$, so $\varphi = \dfrac{\pi}{3}$. The inequality becomes $2\sin\left( x + \dfrac{\pi}{3} \right) < 1$, that is, $\sin\left( x + \dfrac{\pi}{3} \right) < \dfrac{1}{2}$. The argument $x + \dfrac{\pi}{3}$ must lie between $\dfrac{5\pi}{6} + 2k\pi$ and $\dfrac{13\pi}{6} + 2k\pi$, where one full turn has been added to the right endpoint. Subtracting $\dfrac{\pi}{3}$ gives $\dfrac{\pi}{2} + 2k\pi < x < \dfrac{11\pi}{6} + 2k\pi$.
