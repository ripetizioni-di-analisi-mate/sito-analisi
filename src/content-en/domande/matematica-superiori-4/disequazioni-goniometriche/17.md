Which solutions of the inequality $\cos x > \dfrac{1}{2}$ lie in the interval $[-\pi, \pi)$?

- $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$
- $-\pi \leq x < -\dfrac{\pi}{3}$ or $\dfrac{\pi}{3} < x < \pi$
- $-\dfrac{\pi}{3} < x < \dfrac{\pi}{3}$
- $-\dfrac{\pi}{6} < x < \dfrac{\pi}{6}$

## Explanation

Since $\arccos\dfrac{1}{2} = \dfrac{\pi}{3}$, the vertical line with horizontal coordinate $\dfrac{1}{2}$ intersects the unit circle at the points corresponding to $-\dfrac{\pi}{3}$ and $\dfrac{\pi}{3}$. The points with horizontal coordinate greater than $\dfrac{1}{2}$ form the arc between these two angles through $(1, 0)$, the point corresponding to the angle $0$. Within $[-\pi, \pi)$, this arc corresponds to the single interval $-\dfrac{\pi}{3} < x < \dfrac{\pi}{3}$, whereas within $[0, 2\pi)$ the same solutions would form two intervals.
