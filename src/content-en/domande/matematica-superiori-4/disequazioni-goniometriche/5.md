- $-\dfrac{\pi}{2} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{8} + k\pi \leq x \leq \dfrac{\pi}{8} + k\pi$
- $\dfrac{\pi}{2} + 4k\pi \leq x \leq \dfrac{7\pi}{2} + 4k\pi$
- $-\dfrac{\pi}{2} + 4k\pi \leq x \leq \dfrac{\pi}{2} + 4k\pi$

## Explanation

Set $t = \dfrac{x}{2}$. Since $\arccos\dfrac{\sqrt{2}}{2} = \dfrac{\pi}{4}$, the solutions of the inequality $\cos t \geq \dfrac{\sqrt{2}}{2}$ are $-\dfrac{\pi}{4} + 2k\pi \leq t \leq \dfrac{\pi}{4} + 2k\pi$. Multiplying all three parts by $2$ gives $-\dfrac{\pi}{2} + 4k\pi \leq x \leq \dfrac{\pi}{2} + 4k\pi$. The period is also multiplied by $2$, and indeed the period of $\cos\dfrac{x}{2}$ is $4\pi$.
