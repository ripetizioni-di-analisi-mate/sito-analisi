- $\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{4\pi}{3} + 2k\pi$
- $-\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$ or $x = 2k\pi$
- $\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{4\pi}{3} + 2k\pi$ or $x = 2k\pi$

## Explanation

By the double-angle identity $\cos 2x = 2\cos^2 x - 1$, the inequality becomes $2\cos^2 x - \cos x - 1 \geq 0$. Setting $t = \cos x$ gives $(2t + 1)(t - 1) \geq 0$, which holds for $t \leq -\dfrac{1}{2}$ or $t \geq 1$. The condition $\cos x \leq -\dfrac{1}{2}$ gives $\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{4\pi}{3} + 2k\pi$. Since $\cos x \leq 1$ for every $x$, the condition $\cos x \geq 1$ is equivalent to $\cos x = 1$, that is, to $x = 2k\pi$, and these points are **isolated solutions**.
