What are the solutions of the inequality $\cos 2x + \sin x > 0$?

- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$, with $x \neq \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{7\pi}{6} + 2k\pi < x < \dfrac{11\pi}{6} + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{5\pi}{6} + 2k\pi$

## Explanation

By the double-angle identity $\cos 2x = 1 - 2\sin^2 x$, the inequality becomes $-2\sin^2 x + \sin x + 1 > 0$, that is, $2\sin^2 x - \sin x - 1 < 0$. Setting $t = \sin x$ gives $(2t + 1)(t - 1) < 0$, which holds for $-\dfrac{1}{2} < t < 1$. The condition $\sin x > -\dfrac{1}{2}$ gives $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$. The condition $\sin x < 1$ excludes the points $x = \dfrac{\pi}{2} + 2k\pi$, at which the left-hand side equals $\cos\pi + 1 = 0$.
