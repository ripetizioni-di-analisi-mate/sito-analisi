- $-\dfrac{\pi}{2} + k\pi < x < \dfrac{\pi}{3} + k\pi$
- $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{3} + k\pi$
- $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$
- $-\dfrac{\pi}{6} + k\pi < x < \dfrac{\pi}{6} + k\pi$

## Explanation

Setting $t = \tan x$ gives $t^2 - 3 < 0$, which holds for $-\sqrt{3} < t < \sqrt{3}$. Since $\arctan\sqrt{3} = \dfrac{\pi}{3}$, $\arctan\left( -\sqrt{3} \right) = -\dfrac{\pi}{3}$, and tangent is increasing on each branch, we have $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{3} + k\pi$. The period is $\pi$ because tangent is the only trigonometric function in the inequality.
