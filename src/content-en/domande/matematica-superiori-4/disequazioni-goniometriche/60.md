What are the solutions of the inequality $\cos x - \sqrt{3}\sin x > 0$?

- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{5\pi}{6} + 2k\pi$
- $-\dfrac{5\pi}{6} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{2\pi}{3} + 2k\pi$

## Explanation

Write the left-hand side as $-\sqrt{3}\sin x + \cos x$, with $a = -\sqrt{3}$ and $b = 1$. Then $r = \sqrt{3 + 1} = 2$, $\cos\varphi = -\dfrac{\sqrt{3}}{2}$, and $\sin\varphi = \dfrac{1}{2}$, so $\varphi = \dfrac{5\pi}{6}$. The inequality becomes $2\sin\left( x + \dfrac{5\pi}{6} \right) > 0$, and the argument must lie between $2k\pi$ and $\pi + 2k\pi$. Subtracting $\dfrac{5\pi}{6}$ gives $-\dfrac{5\pi}{6} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$.
