What are the solutions of the inequality $2\cos^2 x + 3\cos x - 2 > 0$?

- $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi < x < \dfrac{5\pi}{3} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$
- $\dfrac{2\pi}{3} + 2k\pi < x < \dfrac{4\pi}{3} + 2k\pi$

## Explanation

Setting $t = \cos x$ gives $2t^2 + 3t - 2 > 0$. The trinomial has roots $\dfrac{1}{2}$ and $-2$, so $2t^2 + 3t - 2 = (2t - 1)(t + 2)$, which is positive for $t < -2$ or $t > \dfrac{1}{2}$. Since $\cos x \geq -1$ for every $x$, the condition $\cos x < -2$ has no solutions. This leaves $\cos x > \dfrac{1}{2}$, that is, $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$.
