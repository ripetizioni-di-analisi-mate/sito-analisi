What are the solutions of the inequality $\sin x \geq \dfrac{1}{2}$ in the interval $[-2\pi, 0]$?

- $-\dfrac{5\pi}{6} \leq x \leq -\dfrac{\pi}{6}$
- $-\dfrac{11\pi}{6} \leq x \leq -\dfrac{7\pi}{6}$
- $-2\pi \leq x < -\dfrac{11\pi}{6}$ or $-\dfrac{7\pi}{6} < x \leq 0$
- $-\dfrac{5\pi}{3} \leq x \leq -\dfrac{4\pi}{3}$

## Explanation

On $\mathbb{R}$, the solutions are $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$. The interval for $k = 0$ lies within $[0, \pi]$ and has no points in $[-2\pi, 0]$. Setting $k = -1$ gives $\dfrac{\pi}{6} - 2\pi \leq x \leq \dfrac{5\pi}{6} - 2\pi$, that is, $-\dfrac{11\pi}{6} \leq x \leq -\dfrac{7\pi}{6}$, which lies within $[-2\pi, 0]$. On the interval $\left[ -\dfrac{5\pi}{6}, -\dfrac{\pi}{6} \right]$, however, the sine is negative.
