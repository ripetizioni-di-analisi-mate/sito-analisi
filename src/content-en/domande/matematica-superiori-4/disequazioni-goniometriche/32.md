What are the solutions of the inequality $\tan x \leq 0$ in the interval $[0, 2\pi)$?

- $\dfrac{\pi}{2} < x \leq \pi$ or $\dfrac{3\pi}{2} < x < 2\pi$
- $\dfrac{\pi}{2} \leq x \leq \pi$ or $\dfrac{3\pi}{2} \leq x < 2\pi$
- $x = 0$ or $\dfrac{\pi}{2} < x \leq \pi$ or $\dfrac{3\pi}{2} < x < 2\pi$
- $0 < x < \dfrac{\pi}{2}$ or $\pi < x < \dfrac{3\pi}{2}$

## Explanation

Tangent vanishes at $0$ and $\pi$, is undefined at $\dfrac{\pi}{2}$ and $\dfrac{3\pi}{2}$, and is negative in the second and fourth quadrants. Therefore, in $[0, 2\pi)$, we have $\tan x < 0$ for $\dfrac{\pi}{2} < x < \pi$ and for $\dfrac{3\pi}{2} < x < 2\pi$. Add the zeros $0$ and $\pi$ to these intervals because the inequality allows equality. The values $\dfrac{\pi}{2}$ and $\dfrac{3\pi}{2}$ are excluded because tangent is undefined there.
