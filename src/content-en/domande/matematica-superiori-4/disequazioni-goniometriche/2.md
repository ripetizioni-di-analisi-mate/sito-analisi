- $0 \leq x < \dfrac{\pi}{3}$ or $\dfrac{5\pi}{3} < x \leq 2\pi$
- $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$
- $0 \leq x < \dfrac{\pi}{6}$ or $\dfrac{11\pi}{6} < x \leq 2\pi$
- $-\dfrac{\pi}{3} < x < \dfrac{\pi}{3}$

## Explanation

Isolating the cosine gives $\cos x > \dfrac{1}{2}$. Since $\arccos\dfrac{1}{2} = \dfrac{\pi}{3}$, the points on the unit circle with horizontal coordinate greater than $\dfrac{1}{2}$ form the arc from $-\dfrac{\pi}{3}$ to $\dfrac{\pi}{3}$ through $(1, 0)$, so on $\mathbb{R}$ the solutions are $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$. In the interval $[0, 2\pi]$, choose $k = 0$, which gives $0 \leq x < \dfrac{\pi}{3}$, and $k = 1$, which gives $\dfrac{5\pi}{3} < x \leq 2\pi$. The endpoints $0$ and $2\pi$ are included because $\cos 0 = \cos 2\pi = 1 > \dfrac{1}{2}$.
