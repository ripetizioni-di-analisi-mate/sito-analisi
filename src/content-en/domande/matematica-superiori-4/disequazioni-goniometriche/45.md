What are the solutions of the inequality $4\sin^2 x - 3 \geq 0$?

- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $-\dfrac{\pi}{3} + k\pi \leq x \leq \dfrac{\pi}{3} + k\pi$
- $\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{5\pi}{6} + k\pi$
- $\dfrac{\pi}{3} + k\pi \leq x \leq \dfrac{2\pi}{3} + k\pi$

## Explanation

Setting $t = \sin x$ gives $4t^2 - 3 \geq 0$, which holds for $t \leq -\dfrac{\sqrt{3}}{2}$ or $t \geq \dfrac{\sqrt{3}}{2}$. The condition $\sin x \geq \dfrac{\sqrt{3}}{2}$ gives $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$, and the condition $\sin x \leq -\dfrac{\sqrt{3}}{2}$ gives $\dfrac{4\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$. The second interval is obtained from the first by adding $\pi$. Thus the solutions can be written as $\dfrac{\pi}{3} + k\pi \leq x \leq \dfrac{2\pi}{3} + k\pi$.
