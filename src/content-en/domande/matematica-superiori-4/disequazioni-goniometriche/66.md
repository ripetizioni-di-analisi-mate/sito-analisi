In the inequality $2\sin^2 x - \sin x\cos x - \cos^2 x \geq 0$, are the values $x = \dfrac{\pi}{2} + k\pi$ solutions?

- Yes, because for $\cos x = 0$ the left-hand side equals $2$
- No, because for $\cos x = 0$ the tangent is undefined
- No, because for $\cos x = 0$ the left-hand side equals $-1$
- Yes, because for $\cos x = 0$ the left-hand side equals $0$

## Explanation

For $x = \dfrac{\pi}{2} + k\pi$, we have $\cos x = 0$ and $\sin^2 x = 1$. The left-hand side therefore reduces to $2 \cdot 1 - 0 - 0 = 2$, that is, the coefficient $a$ of $\sin^2 x$. Since $2 \geq 0$, these values are solutions. Division by $\cos^2 x$ is valid only for $\cos x \neq 0$, and points with $\cos x = 0$ must be checked in the original inequality, which does not contain the tangent.
