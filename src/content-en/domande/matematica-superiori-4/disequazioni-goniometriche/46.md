What are the solutions of the inequality $\sin^2 x - \sin x < 0$?

- $2k\pi < x < \pi + 2k\pi$
- $2k\pi < x < \pi + 2k\pi$, with $x \neq \dfrac{\pi}{2} + 2k\pi$
- $\pi + 2k\pi < x < 2\pi + 2k\pi$
- $2k\pi < x < \dfrac{\pi}{2} + 2k\pi$

## Explanation

Factoring out $\sin x$ gives $\sin x\,(\sin x - 1) < 0$. With $t = \sin x$, the product $t\,(t - 1)$ is negative for $0 < t < 1$. The condition $\sin x > 0$ gives $2k\pi < x < \pi + 2k\pi$, while the condition $\sin x < 1$ excludes only the points $x = \dfrac{\pi}{2} + 2k\pi$, where the sine equals $1$. The solutions are therefore $2k\pi < x < \pi + 2k\pi$, with $x \neq \dfrac{\pi}{2} + 2k\pi$.
