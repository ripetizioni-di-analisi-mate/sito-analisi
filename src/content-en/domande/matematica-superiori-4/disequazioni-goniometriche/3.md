- $\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $-\dfrac{\pi}{2} + k\pi < x < \dfrac{\pi}{3} + k\pi$
- $-\dfrac{\pi}{2} + k\pi < x < \dfrac{\pi}{6} + k\pi$
- $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{3} + k\pi$

## Explanation

Tangent is increasing on each interval $\left( -\dfrac{\pi}{2} + k\pi, \dfrac{\pi}{2} + k\pi \right)$, and $\arctan\sqrt{3} = \dfrac{\pi}{3}$. Therefore, on each branch the tangent is less than $\sqrt{3}$ from the asymptote $-\dfrac{\pi}{2} + k\pi$ up to $\dfrac{\pi}{3} + k\pi$. The endpoint $\dfrac{\pi}{3} + k\pi$ is excluded because the inequality is strict, and $-\dfrac{\pi}{2} + k\pi$ is excluded because tangent is undefined there. The period of the solutions is $\pi$, the period of tangent.
