What are the solutions of the inequality $\sqrt{3}\sin x + \cos x \geq \sqrt{3}$?

- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $2k\pi \leq x \leq \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$

## Explanation

With the auxiliary-angle method, we have $r = \sqrt{3 + 1} = 2$, $\cos\varphi = \dfrac{\sqrt{3}}{2}$, and $\sin\varphi = \dfrac{1}{2}$, so $\varphi = \dfrac{\pi}{6}$. The inequality becomes $2\sin\left( x + \dfrac{\pi}{6} \right) \geq \sqrt{3}$, that is, $\sin\left( x + \dfrac{\pi}{6} \right) \geq \dfrac{\sqrt{3}}{2}$. The argument must lie between $\dfrac{\pi}{3} + 2k\pi$ and $\dfrac{2\pi}{3} + 2k\pi$, including the endpoints. Subtracting $\dfrac{\pi}{6}$ gives $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$.
