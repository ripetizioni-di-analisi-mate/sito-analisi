What are the solutions of the inequality $\cos^2 x + 2\sin x\cos x \geq 1$?

- $k\pi \leq x \leq \arctan 2 + k\pi$
- $\arctan 2 + k\pi \leq x < \dfrac{\pi}{2} + k\pi$
- $-\arctan 2 + k\pi \leq x \leq k\pi$
- $k\pi \leq x \leq \arctan 2 + k\pi$ or $x = \dfrac{\pi}{2} + k\pi$

## Explanation

Write $1 = \sin^2 x + \cos^2 x$ and move all terms to the left-hand side to obtain $-\sin^2 x + 2\sin x\cos x \geq 0$, which is homogeneous with $a = -1$, $b = 2$, and $c = 0$. For $\cos x \neq 0$, dividing by $\cos^2 x > 0$ gives $-\tan^2 x + 2\tan x \geq 0$, that is, $\tan x\,(\tan x - 2) \leq 0$. This condition holds for $0 \leq \tan x \leq 2$, that is, for $k\pi \leq x \leq \arctan 2 + k\pi$. For $\cos x = 0$, the left-hand side of the homogeneous form equals $a = -1 < 0$, so there are no further solutions to add.
