What is the domain of the function $f(x) = \dfrac{\sqrt{\sin x}}{\cos x}$?

- $2k\pi \leq x \leq \pi + 2k\pi$
- $2k\pi < x < \pi + 2k\pi$, with $x \neq \dfrac{\pi}{2} + 2k\pi$
- $2k\pi \leq x < \dfrac{\pi}{2} + 2k\pi$
- $2k\pi \leq x \leq \pi + 2k\pi$, with $x \neq \dfrac{\pi}{2} + 2k\pi$

## Explanation

The radicand must be greater than or equal to $0$ and the denominator must differ from $0$, so the domain is the solution set of the system
$$
\begin{cases}
\sin x \geq 0 \\[4pt]
\cos x \neq 0
\end{cases}
$$
The first condition gives $2k\pi \leq x \leq \pi + 2k\pi$. The second excludes the points $\dfrac{\pi}{2} + k\pi$, and among these only the points $\dfrac{\pi}{2} + 2k\pi$ lie in the resulting interval. The domain is therefore $2k\pi \leq x \leq \pi + 2k\pi$, with $x \neq \dfrac{\pi}{2} + 2k\pi$.
