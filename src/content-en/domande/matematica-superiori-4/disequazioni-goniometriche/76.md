What are the solutions of the inequality $\sin x\tan x \geq 0$?

- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$ or $x = \pi + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \dfrac{3\pi}{2} + 2k\pi$

## Explanation

Tangent is defined for $x \neq \dfrac{\pi}{2} + k\pi$, and at these points $\sin x\tan x = \dfrac{\sin^2 x}{\cos x}$. The numerator $\sin^2 x$ is positive for $\sin x \neq 0$ and zero for $x = k\pi$. Where $\sin x \neq 0$, the quotient is positive if and only if $\cos x > 0$, that is, for $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$. The zeros $x = k\pi$ are solutions, and those of the form $\pi + 2k\pi$ do not belong to the resulting interval, so they are added as **isolated solutions**.
