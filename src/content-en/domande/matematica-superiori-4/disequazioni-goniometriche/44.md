What are the solutions of the inequality $\tan x > -1$ in the interval $[0, \pi]$?

- $\dfrac{3\pi}{4} < x \leq \pi$
- $0 \leq x < \dfrac{\pi}{2}$ or $\dfrac{3\pi}{4} \leq x \leq \pi$
- $-\dfrac{\pi}{4} < x < \dfrac{\pi}{2}$
- $0 \leq x < \dfrac{\pi}{2}$ or $\dfrac{3\pi}{4} < x \leq \pi$

## Explanation

Since $\arctan(-1) = -\dfrac{\pi}{4}$, the solutions on $\mathbb{R}$ are $-\dfrac{\pi}{4} + k\pi < x < \dfrac{\pi}{2} + k\pi$. Setting $k = 0$ gives $\left( -\dfrac{\pi}{4}, \dfrac{\pi}{2} \right)$, whose intersection with $[0, \pi]$ is $0 \leq x < \dfrac{\pi}{2}$. Setting $k = 1$ gives $\left( \dfrac{3\pi}{4}, \dfrac{3\pi}{2} \right)$, whose intersection with $[0, \pi]$ is $\dfrac{3\pi}{4} < x \leq \pi$. The endpoints $0$ and $\pi$ are solutions because $\tan 0 = \tan\pi = 0 > -1$.
