What are the solutions of the inequality $\cot x < \sqrt{3}$?

- $k\pi < x < \dfrac{\pi}{6} + k\pi$
- $\dfrac{\pi}{3} + k\pi < x < \pi + k\pi$
- $\dfrac{\pi}{6} + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{6} + k\pi < x < \pi + k\pi$

## Explanation

Cotangent is decreasing on each interval $(k\pi, \pi + k\pi)$, and $\cot\dfrac{\pi}{6} = \sqrt{3}$. Therefore, on each interval the cotangent is less than $\sqrt{3}$ from $\dfrac{\pi}{6} + k\pi$ to the asymptote $\pi + k\pi$. The solutions are consequently $\dfrac{\pi}{6} + k\pi < x < \pi + k\pi$. The right endpoint is excluded because cotangent is undefined at the points $k\pi$.
