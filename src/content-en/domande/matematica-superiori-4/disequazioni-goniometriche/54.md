A tolerance parameter $\varepsilon>0$ imposes $\lvert\cos x\rvert\le\varepsilon$. As $\varepsilon$ is reduced, how does the solution set change?

- It can only grow.
- It shifts rigidly by $\pi$.
- It can only shrink or stay the same.
- It always becomes empty.

## Explanation

Any absolute value meeting the smaller bound also meets the larger bound. When both bounds exceed one, the set remains the whole real line.
