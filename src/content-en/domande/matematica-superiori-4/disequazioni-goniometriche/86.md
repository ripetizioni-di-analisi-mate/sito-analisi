What is the domain of the function $f(x) = \ln(\sin x\cos x)$?

- $2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $k\pi \leq x \leq \dfrac{\pi}{2} + k\pi$
- $k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{2} + k\pi < x < \pi + k\pi$

## Explanation

The argument of the logarithm must be positive, so $\sin x\cos x > 0$. Since $\sin x\cos x = \dfrac{1}{2}\sin 2x$, the condition is equivalent to $\sin 2x > 0$, that is, to $2k\pi < 2x < \pi + 2k\pi$. Dividing by $2$ gives $k\pi < x < \dfrac{\pi}{2} + k\pi$. These intervals correspond to the first and third quadrants, where sine and cosine have the same sign.
