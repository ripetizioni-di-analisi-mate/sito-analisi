- $2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $2k\pi < x \leq \dfrac{5\pi}{6} + 2k\pi$
- $2k\pi < x \leq \dfrac{\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi < x < \pi + 2k\pi$

## Explanation

Work in the interval $[0, 2\pi)$. The first inequality has solutions $0 < x < \pi$. The second is equivalent to $\cos x \geq -\dfrac{\sqrt{3}}{2}$, and since $\arccos\left( -\dfrac{\sqrt{3}}{2} \right) = \dfrac{5\pi}{6}$, it holds for $0 \leq x \leq \dfrac{5\pi}{6}$ and for $\dfrac{7\pi}{6} \leq x < 2\pi$. The intersection of the two sets is $0 < x \leq \dfrac{5\pi}{6}$, and adding integer multiples of the period $2\pi$ gives the solutions of the system.
