What are the solutions of the following system?
$$
\begin{cases}
\cos x > 0 \\[4pt]
\sin x < \dfrac{1}{2}
\end{cases}
$$

- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{5\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$

## Explanation

Work in the interval $[-\pi, \pi)$, whose length is $2\pi$. The solutions of the first inequality are $-\dfrac{\pi}{2} < x < \dfrac{\pi}{2}$. The solutions of the second are $-\pi \leq x < \dfrac{\pi}{6}$ and $\dfrac{5\pi}{6} < x < \pi$, since the sine is greater than or equal to $\dfrac{1}{2}$ only between $\dfrac{\pi}{6}$ and $\dfrac{5\pi}{6}$. The intersection is $-\dfrac{\pi}{2} < x < \dfrac{\pi}{6}$, and adding integer multiples of the period $2\pi$ gives the solutions of the system.
