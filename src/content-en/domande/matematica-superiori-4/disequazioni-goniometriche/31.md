What are the solutions of the inequality $\tan x \geq -1$?

- $-\dfrac{\pi}{2} + k\pi < x \leq -\dfrac{\pi}{4} + k\pi$
- $-\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{\pi}{4} + k\pi$
- $-\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$
- $-\dfrac{\pi}{4} + 2k\pi \leq x < \dfrac{\pi}{2} + 2k\pi$

## Explanation

Since $\arctan(-1) = -\dfrac{\pi}{4}$ and tangent is increasing on each interval $\left( -\dfrac{\pi}{2} + k\pi, \dfrac{\pi}{2} + k\pi \right)$, on each branch tangent is greater than or equal to $-1$ from $-\dfrac{\pi}{4} + k\pi$ to the asymptote $\dfrac{\pi}{2} + k\pi$. The endpoint $-\dfrac{\pi}{4} + k\pi$ is included because the inequality allows equality. The endpoint $\dfrac{\pi}{2} + k\pi$ is excluded because tangent is undefined there. The period of the solutions is $\pi$, the period of tangent.
