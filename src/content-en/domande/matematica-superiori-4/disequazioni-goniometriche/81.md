What are the solutions of the following system?
$$
\begin{cases}
2\sin x \geq 1 \\[4pt]
2\cos x \leq 1
\end{cases}
$$

- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x < \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$

## Explanation

In $[0, 2\pi)$, the first inequality, that is, $\sin x \geq \dfrac{1}{2}$, has solutions $\dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}$. The second, that is, $\cos x \leq \dfrac{1}{2}$, has solutions $\dfrac{\pi}{3} \leq x \leq \dfrac{5\pi}{3}$. The two intervals intersect in $\dfrac{\pi}{3} \leq x \leq \dfrac{5\pi}{6}$, including the endpoints because both inequalities allow equality. Adding integer multiples of the period $2\pi$ gives the solutions of the system.
