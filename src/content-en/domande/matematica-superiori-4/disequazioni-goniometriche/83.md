What are the solutions of the system
$$
\begin{cases}
\sin 2x > 0 \\[4pt]
\cos x < 0
\end{cases}
$$
in the interval $[0, 2\pi)$?

- $\dfrac{\pi}{2} < x < \pi$
- $\pi < x < \dfrac{3\pi}{2}$
- $0 < x < \dfrac{\pi}{2}$ or $\pi < x < \dfrac{3\pi}{2}$
- $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$

## Explanation

With $t = 2x$, the inequality $\sin 2x > 0$ gives $k\pi < x < \dfrac{\pi}{2} + k\pi$, so in $[0, 2\pi)$ the solutions are $0 < x < \dfrac{\pi}{2}$ and $\pi < x < \dfrac{3\pi}{2}$. The second inequality has solutions $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$. The first interval has no points in common with $\left( \dfrac{\pi}{2}, \dfrac{3\pi}{2} \right)$, and the second lies within it. Therefore the solutions of the system are $\pi < x < \dfrac{3\pi}{2}$, the angles in the third quadrant.
