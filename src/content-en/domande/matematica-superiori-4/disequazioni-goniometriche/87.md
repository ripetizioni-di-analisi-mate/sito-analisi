What is the domain of the function $f(x) = \sqrt{\tan x - 1}$?

- $\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{\pi}{2} + k\pi$
- $-\dfrac{\pi}{2} + k\pi < x \leq \dfrac{\pi}{4} + k\pi$
- $\dfrac{\pi}{4} + 2k\pi \leq x < \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$

## Explanation

The function requires tangent to be defined and the radicand to be greater than or equal to $0$, so $x \neq \dfrac{\pi}{2} + k\pi$ and $\tan x \geq 1$. Since $\arctan 1 = \dfrac{\pi}{4}$ and tangent is increasing on each branch, the condition $\tan x \geq 1$ holds for $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$. The endpoint $\dfrac{\pi}{2} + k\pi$ is excluded because tangent is undefined there. The period of the domain is $\pi$, the period of tangent.
