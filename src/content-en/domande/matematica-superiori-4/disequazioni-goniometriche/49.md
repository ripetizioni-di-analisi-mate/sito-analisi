What are the solutions of the inequality $\tan^2 x \geq 1$?

- $\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{3\pi}{4} + k\pi$
- $-\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{\pi}{4} + k\pi$
- $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{3\pi}{4} + k\pi$, with $x \neq \dfrac{\pi}{2} + k\pi$

## Explanation

Setting $t = \tan x$ gives $t^2 \geq 1$, that is, $t \leq -1$ or $t \geq 1$. On each branch of tangent, the condition $\tan x \geq 1$ gives $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$. The condition $\tan x \leq -1$ gives $-\dfrac{\pi}{2} + k\pi < x \leq -\dfrac{\pi}{4} + k\pi$, which, on replacing $k$ with $k + 1$, can be written as $\dfrac{\pi}{2} + k\pi < x \leq \dfrac{3\pi}{4} + k\pi$. Taking the union of the two sets gives $\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{3\pi}{4} + k\pi$, from which the points $\dfrac{\pi}{2} + k\pi$ are removed because tangent is undefined there.
