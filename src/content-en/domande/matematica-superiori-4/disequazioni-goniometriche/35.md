What are the solutions of the inequality $\tan x < -\sqrt{3}$ in the interval $[0, 2\pi)$?

- $\dfrac{2\pi}{3} < x < \pi$ or $\dfrac{5\pi}{3} < x < 2\pi$
- $\dfrac{\pi}{2} < x < \dfrac{2\pi}{3}$ or $\dfrac{3\pi}{2} < x < \dfrac{5\pi}{3}$
- $\dfrac{\pi}{2} < x < \dfrac{5\pi}{6}$ or $\dfrac{3\pi}{2} < x < \dfrac{11\pi}{6}$
- $\dfrac{\pi}{2} < x < \dfrac{2\pi}{3}$

## Explanation

Since $\arctan\left( -\sqrt{3} \right) = -\dfrac{\pi}{3}$, the solutions on $\mathbb{R}$ are $-\dfrac{\pi}{2} + k\pi < x < -\dfrac{\pi}{3} + k\pi$. The period of tangent is $\pi$, so there are two intervals in $[0, 2\pi)$. Setting $k = 1$ gives $\dfrac{\pi}{2} < x < \dfrac{2\pi}{3}$, and setting $k = 2$ gives $\dfrac{3\pi}{2} < x < \dfrac{5\pi}{3}$.
