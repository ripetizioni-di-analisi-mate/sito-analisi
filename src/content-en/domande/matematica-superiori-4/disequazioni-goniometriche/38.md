What are the solutions of the inequality $\sin\left( \dfrac{\pi}{4} - x \right) > 0$?

- $-\dfrac{3\pi}{4} + 2k\pi < x < \dfrac{\pi}{4} + 2k\pi$
- $\dfrac{\pi}{4} + 2k\pi < x < \dfrac{5\pi}{4} + 2k\pi$
- $-\dfrac{\pi}{4} + 2k\pi < x < \dfrac{3\pi}{4} + 2k\pi$
- $-\dfrac{3\pi}{4} + k\pi < x < \dfrac{\pi}{4} + k\pi$

## Explanation

Set $t = \dfrac{\pi}{4} - x$. The solutions of the inequality $\sin t > 0$ are $2k\pi < t < \pi + 2k\pi$. Subtracting $\dfrac{\pi}{4}$ from all three parts gives $-\dfrac{\pi}{4} + 2k\pi < -x < \dfrac{3\pi}{4} + 2k\pi$. Multiplying by $-1$ reverses the direction of the inequalities, so $-\dfrac{3\pi}{4} - 2k\pi < x < \dfrac{\pi}{4} - 2k\pi$. Since $-k$ ranges over all of $\mathbb{Z}$ just as $k$ does, the solutions are $-\dfrac{3\pi}{4} + 2k\pi < x < \dfrac{\pi}{4} + 2k\pi$.
