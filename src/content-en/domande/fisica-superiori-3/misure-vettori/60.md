Which component pair has the same magnitude as $(1,7)$?

- $(5,7)$
- $(1,6)$
- $(0,7)$
- $(-5,5)$

## Explanation

The original squared magnitude is $1^2+7^2=50$. The pair $(-5,5)$ has the same sum of squares, $25+25$. The two arrows can have the same magnitude while pointing in different directions. For example, the first points into the first quadrant, while the one with horizontal component $-5$ points into the second.
