A horizontal component is zero. What follows about the magnitude of the vector?

- It must be zero.
- It equals the vertical component even if that component is negative.
- It exceeds the absolute value of the vertical component.
- It equals the absolute value of the vertical component.

## Explanation

With one zero leg, the Pythagorean theorem reduces to the square root of the square of the other component. This root gives an absolute value. A vertical arrow pointing down has a negative vertical component and a positive magnitude. The magnitude is zero only if the vertical component is also zero.
