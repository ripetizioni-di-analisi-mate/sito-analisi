A force has components $(5,-5)\,\mathrm N$. Which pair represents that force in axes rotated anticlockwise by $90^\circ$?

- $(-5,-5)\,\mathrm N$
- $(5,5)\,\mathrm N$
- $(5,-5)\,\mathrm N$
- $(-5,5)\,\mathrm N$

## Explanation

The new $x'$-axis follows the old $y$-axis, so the first component is $-5$. The new $y'$ points against the old $x$-axis, so the second component is also $-5$.
