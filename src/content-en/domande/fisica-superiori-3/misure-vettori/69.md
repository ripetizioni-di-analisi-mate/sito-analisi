A force has components $(5,-5)\,\mathrm N$. Which pair represents that force in axes rotated anticlockwise by $90^\circ$?

- $(-5,-5)\,\mathrm N$
- $(5,5)\,\mathrm N$
- $(5,-5)\,\mathrm N$
- $(-5,5)\,\mathrm N$

## Explanation

The new $x'$-axis follows the old $y$-axis, so the first component is $-5$. The new $y'$ points against the old $x$-axis, so the second component is also $-5$. The calculation changes the coordinates of the same arrow. The sum of the squared numerical values in newtons is fifty both before and after. Physically turning the arrow with the axes fixed would give different components.
