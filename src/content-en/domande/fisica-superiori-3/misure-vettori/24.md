Which expression represents the same acceleration as $2\,\mathrm{m/s^2}$?

- $0.02\,\mathrm{cm/s^2}$
- $20\,\mathrm{cm/s^2}$
- $200\,\mathrm{cm^2/s}$
- $200\,\mathrm{cm/s^2}$

## Explanation

One metre is one hundred centimetres. The squared second is already in the same unit, so only the numerator is converted.
