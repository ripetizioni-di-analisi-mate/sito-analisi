Two vertical throws pass their launch height once after release, without drag. How do the launch velocity and return velocity of each compare?

- Equal speeds in opposite directions.
- Equal speeds in the same direction.
- Greater return speed in the opposite direction.
- Smaller return speed in the same direction.

## Explanation

At the same height $\Delta y=0$, so $v^2=v_0^2$. The object moves down on its return and up at launch, so it has the opposite sign.
