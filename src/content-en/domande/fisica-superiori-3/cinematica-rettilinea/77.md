A ball is launched vertically upwards and returns to its initial height. With no air resistance and uniform gravity, how do its launch and return velocities compare?

- Equal speeds in opposite directions.
- Equal speeds in the same direction.
- Greater return speed in the opposite direction.
- Smaller return speed in the same direction.

## Explanation

At the same height $\Delta y=0$, so $v^2=v_0^2$. The object moves down on its return and up at launch, so it has the opposite sign. The velocities have equal magnitudes and opposite directions. In the velocity–time graph both values lie equally far in time from the apex.
