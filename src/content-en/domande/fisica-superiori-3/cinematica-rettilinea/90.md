Two objects start at the same coordinate and move in the same direction at the same constant velocity for five seconds. How many solutions does $x_A(t)=x_B(t)$ have in that interval?

- Only $t=0$.
- One for every instant, because the equations coincide.
- Only $t=5\,\mathrm s$.
- None, because the velocities cancel each other.

## Explanation

The initial conditions and slopes match, so the two linear expressions have the same coefficients. Equating positions gives an identity.
