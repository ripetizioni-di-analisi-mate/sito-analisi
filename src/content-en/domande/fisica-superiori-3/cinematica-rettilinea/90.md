Two points start at the same position and have the same constant velocity for five seconds. How many solutions to $x_A(t)=x_B(t)$ lie in the interval?

- Only $t=0$.
- One for every instant, because the equations coincide.
- Only $t=5\,\mathrm{s}$.
- None, because the velocities cancel each other.

## Explanation

The initial conditions and slopes match, so the two linear expressions have the same coefficients. Equating positions gives an identity. Each instant in the five seconds is a solution. The graphs overlap throughout that interval, so there are infinitely many common points.
