With one zero level, a body's gravitational potential energy is $-60\,\mathrm J$ in state A and $30\,\mathrm J$ in state B. With a second zero level it is $20\,\mathrm J$ in state A. What is its energy in state B using the second zero?

- $110\,\mathrm{J}$
- $90\,\mathrm{J}$
- $-50\,\mathrm{J}$
- $20\,\mathrm{J}$

## Explanation

The change from A to B is $30-(-60)=90\,\mathrm J$. Changing the zero adds the same constant to both states, so this difference stays fixed. Using the second zero, B has $(20+90)\,\mathrm J=110\,\mathrm J$. The work done by gravity is $-90\,\mathrm J$ with either zero.
