A stationary surface exerts a constant resisting force magnitude while a body moves. The body returns exactly to its starting point. What is the work done by friction?

- Zero, because position is unchanged
- Negative, set by the total path length
- Positive, because two parts add
- Zero only if the return is fast

## Explanation

Friction opposes motion in both directions, reversing when motion reverses. The two negative work contributions add.
