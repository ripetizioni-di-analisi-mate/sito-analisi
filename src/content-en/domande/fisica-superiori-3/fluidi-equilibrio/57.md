Rotate a small sensor about the same point in a resting liquid. What happens to measured pressure?

- It stays the same
- It changes sign on reversal
- It becomes zero on vertical faces
- It varies with the cosine of angle

## Explanation

Rotating a sufficiently small sensor without moving it changes neither its position nor its pressure reading, which is a scalar. The force vector does change direction because it stays perpendicular to the sensor face. Moving the sensor vertically could also change the pressure.
