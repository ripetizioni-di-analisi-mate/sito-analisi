If both arms have the same imposed pressure, where are the surfaces of a single liquid at rest in a manometer if capillary effects are negligible?

- Always higher in the narrower arm
- Always higher in the wider arm
- It depends on pressure when expressed in pascals
- At the same height

## Explanation

With the same pressure on both surfaces, the difference $\rho g\Delta h$ must be zero. Since density and gravity are positive, there is no height difference. If capillarity is negligible, changing the width of one branch alters the volume needed to move its level, while both surfaces still equilibrate at the same height.
