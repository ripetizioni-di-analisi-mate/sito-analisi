What does a negative predicted tension mean for an initially taut string if pull is taken as positive?

- The pull simply has negative magnitude.
- A push would be needed, so the taut-string model fails.
- The string pushes with that magnitude.
- The towed mass must be zero.

## Explanation

A taut string can pull its ends together. A negative result would require a force pushing them apart, which the model cannot provide.
