Which quantity describes gravity at a point independently of what object is placed there?

- Gravitational field
- Object weight
- Object kinetic energy
- Impulse over each interval

## Explanation

The field is force per unit test mass. At fixed sources and position, doubling the test mass doubles the force but leaves the ratio unchanged. This ratio describes the action of the sources before specifying which body is placed at the point.
