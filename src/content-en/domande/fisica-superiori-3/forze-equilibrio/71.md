An ideal string's calculated equilibrium tension is negative. What is the correct interpretation?

- The string normally supplies compression.
- Tension has negative magnitude but supports weight.
- The assumed configuration would require compression and cannot use that taut string.
- Simply reverse the sign of weight.

## Explanation

A string can pull away from the knot along itself. An opposite sign calls for a different reaction, so the assumed constraint must be reconsidered.
