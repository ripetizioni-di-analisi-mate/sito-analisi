For a particle in plane equilibrium, what condition is necessary and sufficient for zero acceleration?

- Only the horizontal component vanishes.
- Velocity is horizontal.
- Both components of the net force vanish.
- Only weight vanishes.

## Explanation

The second law applies to each component. Any nonzero resultant component would give acceleration along its axis. Any nonzero velocity stays constant. Static equilibrium requires the body to be at rest as well as checking both axes.
