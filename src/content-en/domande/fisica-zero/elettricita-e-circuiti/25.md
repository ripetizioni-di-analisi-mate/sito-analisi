A cable has a copper core and a plastic coating. In a circuit model, which property directly distinguishes the two materials?

- Copper conducts only if it carries a net charge.
- Mobile charges move through copper much more readily.
- Only copper contains electrons.
- Plastic contains only protons.

## Explanation

Conduction requires carriers able to move through the material. Copper has mobile carriers, whereas plastic strongly impedes such movement.
