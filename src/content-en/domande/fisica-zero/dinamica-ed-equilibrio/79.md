A washing machine at rest is pushed with a horizontal force that increases slowly, and for a while the washing machine does not move. How does the static friction change during this interval?

- It stays equal to the maximum value $\mu_sN$
- It increases along with the push and has the same magnitude
- It decreases while the push increases
- It is zero until the washing machine moves

## Explanation

As long as the washing machine is at rest, the horizontal net force is zero, so the static friction has the same magnitude as the push at every instant. Therefore, if the push increases, the frictional force increases too. This holds up to the maximum value $\mu_sN$. When the push exceeds that value, the washing machine starts to slide.
