A crate on a van’s smooth cargo bed is secured by a horizontal string so that it accelerates forwards. On which side of the crate must the anchoring point be?

- Ahead of the crate
- Either side, because a string can push if needed
- Behind the crate
- Above the crate, with the string vertical

## Explanation

The string pulls towards its anchoring point. To provide a forward resultant it must therefore pull the crate from in front.
