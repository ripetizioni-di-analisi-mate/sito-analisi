A $10\,\mathrm{kg}$ toolbox sits on a horizontal workbench, with $\mu_s=0.6$. If it is pushed horizontally with $50\,\mathrm{N}$, using $g=10\,\mathrm{m/s^2}$, what happens?

- It stays at rest and the static friction is $50\,\mathrm{N}$
- It stays at rest and the static friction is $60\,\mathrm{N}$
- It slides, because the push is nonzero
- It slides, because the push exceeds $\mu_s$ times the mass

## Explanation

The normal force is $N=mg=100\,\mathrm{N}$, so the maximum static friction is $\mu_sN=0.6\cdot100\,\mathrm{N}=60\,\mathrm{N}$. The push of $50\,\mathrm{N}$ is less than this limit, so static friction can balance it and the toolbox stays at rest. The actual frictional force equals the push, that is, $50\,\mathrm{N}$ in the opposite direction. The product $\mu_s m=6\,\mathrm{kg}$ is a mass, so it cannot be compared with a force.
