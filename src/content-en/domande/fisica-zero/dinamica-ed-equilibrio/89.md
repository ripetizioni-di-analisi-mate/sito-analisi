In a real-trolley test, a group measures only pull and acceleration and finds $F_{\rm pull}>ma$. Which check directly tests whether friction accounts for the difference?

- Reverse the positive coordinate direction
- Measure the pull required at constant velocity under the same conditions
- Repeat the calculation using weight in place of pull
- Reset only the position origin

## Explanation

At constant velocity the pull balances resistance. Comparing that force with the measured discrepancy tests whether friction can account for it.
