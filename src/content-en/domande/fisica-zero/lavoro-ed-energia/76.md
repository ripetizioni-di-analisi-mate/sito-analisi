A child pushes a toy box $1\,\mathrm{m}$ forward across the floor and then brings it $1\,\mathrm{m}$ back to the starting point. What is the sign of the work done by kinetic friction from the floor on each leg?

- Negative going forward and positive coming back
- Negative on both the forward and the return leg
- Positive going forward and negative coming back
- Zero on each leg, because the box returns to the starting point

## Explanation

Kinetic friction always opposes sliding. Going forward, friction points backward while the box moves forward, so the work is negative. Coming back, the sliding reverses and so does friction, so the work is again negative. Consequently, the work done by friction is **negative on both legs**. Over the whole path, the work done by friction is therefore $-f\cdot2\,\mathrm{m}$, where $f$ is the magnitude of the friction force, and it is not zero.
