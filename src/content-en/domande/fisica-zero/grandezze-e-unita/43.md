A bag contains $5\,\mathrm{kg}$ of rice. How many $125\,\mathrm{g}$ servings can be made?

- $40$
- $4$
- $400$
- $625$

## Explanation

Before dividing, express both masses in the same unit. Since $1\,\mathrm{kg}=1000\,\mathrm{g}$, the bag contains $5000\,\mathrm{g}$ of rice. The number of servings is therefore $\dfrac{5000\,\mathrm{g}}{125\,\mathrm{g}}=40$. The result is a pure number because the units cancel.
