A row is $0.5\,\mathrm{mm}$ long. Each element occupies $250\,\mathrm{nm}$ along the row, with no gaps. How many elements are there?

- $125$
- $200$
- $2000$
- $20000$

## Explanation

One millimetre contains a million nanometres, so the row is $500000\,\mathrm{nm}$ long. Dividing by $250\,\mathrm{nm}$ per element gives $2000$.
