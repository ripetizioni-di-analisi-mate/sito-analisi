A car's registration document gives its mass as $1.2\cdot10^3\,\mathrm{kg}$, while a website lists it as $1.2\,\mathrm{t}$. Which statement is true?

- The first value describes a mass one thousand times greater
- The two values describe the same mass
- The second value describes a mass one thousand times greater
- The first value describes a mass one hundred times greater

## Explanation

The value $1.2\cdot10^3\,\mathrm{kg}$ equals $1.2\cdot1000\,\mathrm{kg}=1200\,\mathrm{kg}$. One metric ton equals $1000\,\mathrm{kg}$, so $1.2\,\mathrm{t}=1200\,\mathrm{kg}$ as well. Therefore, the two values describe **the same mass**. The first changes the way the number is written, and the second changes the unit.
