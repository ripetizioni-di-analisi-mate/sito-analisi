A class wants to compare the roughness of two surfaces using a measurable quantity. Which proposal specifies both what to measure and how to compare the results?

- Measure only the total length of each specimen.
- Record bump height as a number, allowing any unit without recording it.
- Measure the average height of the bumps in micrometres using the same method.
- Give roughness a score from one to ten based on personal impression.

## Explanation

Average height is a numerical property with a unit. A common procedure allows two groups to compare their measurements.
