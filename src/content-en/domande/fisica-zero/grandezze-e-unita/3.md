A shopkeeper measures a curtain and writes $1.5\,\mathrm{m}$; the customer, using a different tape measure, reads $150\,\mathrm{cm}$. Which statement is true?

- The length read by the customer is greater, because $150>1.5$
- The two values describe the same length
- The length written by the shopkeeper is greater, because the meter is larger than the centimeter
- The two values cannot be compared, because the units are different

## Explanation

One meter contains $100$ centimeters, so $1.5\,\mathrm{m}=1.5\cdot100\,\mathrm{cm}=150\,\mathrm{cm}$. Therefore, the two values describe **the same length**. The number $150$ is greater than $1.5$ because the centimeter is a smaller unit than the meter. The two measurements are compared after expressing both in the same unit.
