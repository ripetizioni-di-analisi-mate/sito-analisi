In a drop-from-rest experiment, measured time is erroneously doubled while the height $h$ is correct. What value of $g$ is inferred from $g=\dfrac{2h}{t^2}$?

- Four times the true value
- One quarter of the true value
- Half the true value
- Twice the true value

## Explanation

Doubling time quadruples the denominator while leaving the numerator fixed. The inferred value is therefore divided by four.
