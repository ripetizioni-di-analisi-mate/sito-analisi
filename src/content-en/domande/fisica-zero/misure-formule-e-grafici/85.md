You need to test whether the response is linear over the range from $0$ to $10$. You already have thirty readings all at $x=5$. Which data collection adds the missing information?

- Repeat thirty times only at $x=5$.
- Check only at $x=5$ with a more precise instrument.
- Estimate the response at both endpoints by extending a line chosen before taking more readings.
- Measure at several points spread across the interval, including the ends.

## Explanation

Repeats at one input describe local scatter. To test the shape of the relation, observe how the output changes as the input varies.
