At the same input of 5 units, a sensor repeatedly reads $4.0\,\mathrm{V}$ as the input rises and $4.3\,\mathrm{V}$ as it falls. Each reading has an uncertainty of $0.02\,\mathrm{V}$. What must a model include to reproduce both series?

- Dependence on whether the input was approached from above or below
- One fixed output of $4.15\,\mathrm{V}$ at that input
- The same change of units for both series
- Rounding both outputs to the nearest hundredth of a volt

## Explanation

The central values differ by $0.3\,\mathrm{V}$ and the two uncertainties together span only $0.04\,\mathrm{V}$, so the intervals are separate. The same input gives two reproducible readings, requiring the model to distinguish rising from falling input.
