Two operators use different instruments on the same sample and get different results. Which trial helps separate an operator effect from an instrument effect?

- Have both operators measure the same sample with each instrument.
- Compare only the means of the original operator-instrument pairs.
- Change sample and instrument simultaneously.
- Increase the number of readings with each operator still using their original instrument.

## Explanation

Crossing operators and instruments allows the operators to be compared on one instrument and the instruments to be compared with one operator. This shows which difference the data follow.
