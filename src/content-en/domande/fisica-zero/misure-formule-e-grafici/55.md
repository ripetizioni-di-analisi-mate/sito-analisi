In the model $y=ax+b$ you want to infer $x$ from a reading of $y$. What happens if $a=0$ and the reading is $y=b$?

- The only solution is $x=1$.
- Every value of $x$ fits the reading.
- No value of $x$ fits the reading.
- The only solution is $x=0$.

## Explanation

With zero slope the model returns the same ordinate $b$ for every abscissa. Inversion would divide by zero and cannot select a value of $x$.
