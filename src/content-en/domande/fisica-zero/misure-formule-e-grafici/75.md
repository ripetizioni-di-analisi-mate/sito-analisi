A rectangular area for a dog is fenced with $20\,\mathrm{m}$ of fencing, using all of it. As the shape of the rectangle varies, are the base $b$ and the height $h$ inversely proportional?

- Yes, because when the base increases the height decreases
- Yes, because the product $bh$ is always $20\,\mathrm{m^2}$
- No, because the product $bh$ changes as the base changes
- No, because the base and the height are directly proportional

## Explanation

The perimeter is fixed, so $2(b+h)=20\,\mathrm{m}$, that is, $b+h=10\,\mathrm{m}$. With $b=2\,\mathrm{m}$ we get $h=8\,\mathrm{m}$ and $bh=16\,\mathrm{m^2}$. With $b=4\,\mathrm{m}$ we get $h=6\,\mathrm{m}$ and $bh=24\,\mathrm{m^2}$. The product changes, so base and height are **not** inversely proportional, even though the height decreases when the base increases.
