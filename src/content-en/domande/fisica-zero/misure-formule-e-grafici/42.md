On a windless day an anemometer, the instrument that measures wind speed, reads $(0.0\pm0.2)\,\mathrm{m/s}$. Which statement about the relative uncertainty of this measurement is correct?

- It is $0.2\%$
- It cannot be calculated, because the measured value is zero
- It is $0$, because the measured value is zero
- It is $20\%$

## Explanation

The relative uncertainty is the ratio $u_r=\dfrac{u}{x}$ and is defined for a positive measured value, $x>0$. Here the measured value is $0.0\,\mathrm{m/s}$, so the ratio would require dividing by zero. Therefore the relative uncertainty of this measurement **cannot be calculated**. The absolute uncertainty is still defined and equals $0.2\,\mathrm{m/s}$. The value $0.2\%$ confuses the absolute uncertainty, which has a unit, with a percentage.
