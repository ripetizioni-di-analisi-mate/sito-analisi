A digital bathroom scale has a resolution of $0.1\,\mathrm{kg}$. When no one is standing on it, the display reads $0.8\,\mathrm{kg}$. Which statement correctly describes the situation?

- The scale has an accuracy problem, even though it distinguishes changes of $0.1\,\mathrm{kg}$
- The resolution of the scale is $0.8\,\mathrm{kg}$
- The range of the scale is $0.8\,\mathrm{kg}$
- Averaging many weighings cancels the $0.8\,\mathrm{kg}$ offset

## Explanation

With no load, the scale should read zero, so its readings are offset from the reference value. Agreement with the reference value is **accuracy**, so the scale has an accuracy problem. The resolution is still $0.1\,\mathrm{kg}$, because it describes only the changes the display can distinguish. An offset of this kind affects all readings in the same way, so the mean of several weighings keeps it.
