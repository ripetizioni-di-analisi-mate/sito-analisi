A catalogue lists $2.4\,\mathrm{N/cm}$. What is the same stiffness in newtons per metre?

- $24\,\mathrm{N/m}$
- $0.024\,\mathrm{N/m}$
- $2.4\,\mathrm{N/m}$
- $240\,\mathrm{N/m}$

## Explanation

Each centimetre requires $2.4\,\mathrm{N}$. A metre contains one hundred centimetres, so the value per metre is $100\cdot 2.4=240\,\mathrm{N/m}$.
