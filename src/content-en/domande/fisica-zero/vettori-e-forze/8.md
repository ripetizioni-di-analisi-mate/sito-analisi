In the figure, five arrows represent moves of game pieces on a board. Which arrow represents the same vector as arrow $A$?

::grafico{vettori="1,5,3,6,A;5,5,7,6,P;9,5,7,4,Q;1,1,2,3,S;4,1,8,3,T" uguale=1 xmin=-1 xmax=10 ymin=-1 ymax=7 titolo="Five arrows on a grid; each unit on the axes is the side of one square."}

- Arrow $Q$
- Arrow $S$
- Arrow $T$
- Arrow $P$

## Explanation

Two arrows represent the same vector when they have the same magnitude, direction, and sense, even if they start at different points. Arrow $A$ moves $2$ units to the right and $1$ unit up, and arrow $P$ makes the same move from a different starting point. Arrow $Q$ points the opposite way, arrow $S$ has a different direction, and arrow $T$ is twice as long. Therefore only $P$ represents the same vector as $A$.
