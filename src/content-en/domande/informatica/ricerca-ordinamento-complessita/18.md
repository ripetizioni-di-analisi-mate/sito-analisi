Count the comparisons `a[i] < 6`. The fragment uses `<stddef.h>`.

```c
int a[] = {-1, 3, 3, 7, 9};
size_t i = 0;
while (i < 5 && a[i] < 6) {
    ++i;
}
```

- $3$
- $5$
- $6$
- $4$

## Explanation

The comparison with $6$ is true for $-1$, $3$ and $3$. The scan therefore reaches index $3$, which holds $7$. The comparison that yields false is still evaluated and counted. There are three true tests and one false test.
