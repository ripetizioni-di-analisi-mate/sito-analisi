The first stored value at least as large as key $6$ in the sorted list `{1, 4, 8, 15}` is $8$. We want the stored value with minimum absolute distance from $6$, choosing the smaller value on a tie. Which answer is correct?

- $1$
- $8$
- $4$
- $6$

## Explanation

Only the two neighbours of the boundary, $4$ and $8$, need to be considered. Values farther left or right are at least as distant as the neighbouring candidate on their side. Both candidates have distance $2$, so the tie rule selects $4$.
