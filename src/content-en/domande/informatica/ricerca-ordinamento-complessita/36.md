In a sorted merge of a length-$3$ run and a length-$8$ run, what is the minimum number of key comparisons? Once a run is exhausted, the remainder is copied directly.

- $3$
- $1$
- $8$
- $10$

## Explanation

Ending the comparisons requires exhausting at least one run. The shorter run has length $3$, and each comparison consumes only one element. At least three comparisons are therefore required. If all three values of the short run precede every value of the long run, each of the first three comparisons consumes an element of the short run and the minimum is attained.
