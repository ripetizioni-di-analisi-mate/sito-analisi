An array is in nonincreasing order. We seek the first index with value at most `key`, using `[lo,hi)` and an internal midpoint `mid`. Which comparison allows `lo` to move to `mid+1` while keeping equal values as potential answers?

- `a[mid] > key`
- `a[mid] < key`
- `a[mid] >= key`
- `a[mid] == key`

## Explanation

If the middle value is greater than the key, all preceding values are at least as large. The segment through `mid` can therefore be excluded. On equality, `mid` is already a candidate, so that case requires continuing toward the left.
