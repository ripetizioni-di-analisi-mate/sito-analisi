Merge two increasing runs of records from contiguous segments of the original array. Which test, when true, must emit the left front to obtain a stable merge?

- `left[i].key <= right[j].key`
- `left[i].key < right[j].key`
- `left[i].key > right[j].key`
- `left[i].key != right[j].key`

## Explanation

The front with the smaller key is taken to keep the output increasing. At equality, all remaining records of the left run preceded those of the right run in the original sequence. If each run was sorted stably, choosing the left run on a tie preserves the order for equal keys.
