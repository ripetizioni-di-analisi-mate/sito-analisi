An array of $n$ keys is sorted. The $q$ query values also arrive in nondecreasing order, and each calls for the first index whose key is at least the query. An array cursor resumes at the previous boundary each time. Which bound follows for total cursor advances plus query handling?

- Exactly $n$ operations for every $q$
- At least $nq$ advances for every input
- $O(1)$ independently of $n,q$
- $O(n+q)$

## Explanation

An entry already smaller than the preceding query remains smaller than the new one. The cursor can therefore advance at most $n$ times throughout the sequence. Each query adds constant work beyond its advances, so the total is at most proportional to $n+q$.
