A scan starts at `i = 0` and uses `size_t` indices. For `n = 0`, pointer `a` may be null. Which guard continues up to the first element equal to `key` without reading outside the array?

- `i < n && a[i] != key`
- `a[i] != key && i < n`
- `i <= n && a[i] != key`
- `i < n || a[i] != key`

## Explanation

When `n` is zero, `i < n` is false on the first test. The `&&` operator therefore skips the read. In a nonempty scan, the same guard permits a read only when `i` is a valid index and the specified array has at least `n` elements.
