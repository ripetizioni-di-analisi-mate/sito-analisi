A table has $R$ independent rows, each with $C\ge2$ sorted keys. In each row we seek the first index whose key is at least as large as the query value. The algorithm runs a separate full binary boundary search in each row. What is its tight worst-case key-comparison cost?

- $\Theta(R\log C)$
- $\Theta(R+C)$ for all $R,C$
- $\Theta(RC)$
- $\Theta(\log(RC))$

## Explanation

For one row the worst comparison count is proportional to $\log C$. All rows can be chosen identical to a worst-case row. The worst per-row cost is then incurred $R$ times.
