The sorted runs `{2,4}` and `{1,3}` must be merged within `{2,4,1,3}`. A variant writes its output immediately into the same array starting at index zero, without retaining overwritten values. Which value still needed is lost on the very first write?

- $3$
- $1$
- $2$
- $4$

## Explanation

The first comparison is between $2$ and $1$, so the output starts with $1$. Writing it directly to position zero overwrites the left front value $2$, which has not yet been emitted. A separate auxiliary array preserves both fronts until they are consumed.
