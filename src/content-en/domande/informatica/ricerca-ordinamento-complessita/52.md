In a nondecreasing array, `u` is the first index with a key strictly greater than $k$, or $n$ if there is none. Which procedure returns the last position with value at most $k$ and also handles its absence?

- Whenever `u == n`, report absence.
- Return `u-1` even when `u == 0`.
- Always return `u`.
- If `u > 0`, return `u-1`, otherwise report absence.

## Explanation

The entries at most $k$ occupy precisely the prefix of length `u`. For a nonempty prefix the last index is its length minus one. A zero length means absence and must be handled before subtracting from an unsigned index.
