Selection sort orders $6$ distinct keys that are already increasing. It scans each suffix to the end and swaps only when the minimum is at a different index. What is the pair (key comparisons, swaps)?

- $(0,0)$
- $(5,0)$
- $(15,0)$
- $(15,5)$

## Explanation

The minimum is already at the start of each suffix, so the swap rule leaves it in place. The candidates are still scanned. The count is $5+4+3+2+1=15$ comparisons and zero swaps.
