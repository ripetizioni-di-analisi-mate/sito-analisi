On $\langle 1,5,3,7,2,6,4,8\rangle$, merge sort splits into contiguous halves and compares front keys while both runs are nonempty. How many key comparisons does it make in total?

- $12$
- $16$
- $24$
- $17$

## Explanation

The four singleton-pair merges cost one comparison each. In each length-$4$ run, the values from the sorted pairs alternate, so each merge needs three comparisons. The two final runs separately contain odds and evens, so the final merge needs seven comparisons. The total is $4+6+7=17$.
