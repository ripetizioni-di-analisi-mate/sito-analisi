A program intended to sort `{3,1,2}` returns `{1,1,2}`. Which part of the sorting contract fails when order and preservation of data are checked separately?

- Only stability is violated.
- The output is sorted but is not a permutation of the input.
- The output meets both requirements.
- The output is a permutation but is decreasing.

## Explanation

Consecutive output entries satisfy $1\le1\le2$. However, the $3$ has disappeared and the multiplicity of $1$ has increased from one to two. An order check alone would accept this result.
