A sorted table `a` has a cached index `p` of the first value at least $7$. Under which change is that numerical index guaranteed still to designate the first value at least $7$, given that such an entry existed and order is maintained?

- Change the only $7$ to $6$ when it occurs at $p$.
- Remove an entry before $p$, when there is one.
- Insert value $2$ at the front.
- Append a value at least as large as the last entry.

## Explanation

Appending at the end preserves every previous index and key. The prefix strictly below $7$ therefore has the same length, and `a[p]` still meets the threshold. Inserting or deleting within the prefix can shift the boundary.
