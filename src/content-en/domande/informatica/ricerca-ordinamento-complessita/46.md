A test checks a function returning the first occurrence of key $k$. For a returned index $0\le p<n$ on arbitrary input, which condition certifies exactly this part of its contract?

- No index larger than $p$ contains $k$.
- `a[p] == k` and no index smaller than $p$ contains $k$.
- All cells before $p$ contain values smaller than $k$.
- Only `a[p] == k`.

## Explanation

Equality establishes that the reported position contains the key. Absence of other occurrences in the prefix establishes that this position is the first. In an unsorted array, that prefix may also contain values greater than the key.
