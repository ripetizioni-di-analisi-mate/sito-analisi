In the first pass of selection sort on $\langle 4,1,3,1\rangle$, update the minimum only for a strictly smaller key. Which index is selected at the end of the minimum scan, before swapping?

- $0$
- $1$
- $2$
- $3$

## Explanation

The current minimum updates when value $1$ is found at index $1$. Value $3$ at index $2$ is larger. The second $1$, at index $3$, equals the current minimum and therefore fails the strict comparison. The chosen index remains $1$.
