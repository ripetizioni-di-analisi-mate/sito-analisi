Records must be sorted by key while preserving arrival order for equal keys, using $O(n\log n)$ comparisons even in the worst case. Which algorithm meets both requirements?

- Selection sort with swaps.
- Merge sort with a stable merge.
- Insertion sort on a single array.
- Linear scanning with early exit.

## Explanation

Standard merge sort has worst-case $O(n\log n)$ key comparisons. A merge that chooses the left run on a tie preserves the order of equal records. Selection sort with swaps can reverse duplicates, and insertion sort can require quadratically many comparisons. Scanning finds a key without sorting the records.
