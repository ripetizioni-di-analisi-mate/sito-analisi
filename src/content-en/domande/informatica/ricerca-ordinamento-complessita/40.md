A merge sort reuses one auxiliary array of $n$ elements. At most $O(\log n)$ activation records are live simultaneously, each using constant space. What is the tight order of peak auxiliary space?

- $\Theta(\log n)$
- $\Theta(n\log n)$
- $\Theta(n)$
- $\Theta(n^2)$

## Explanation

The auxiliary array of $n$ elements gives a linear lower bound. The logarithmic height adds only logarithmically many constant-size records, so the total is at most linear for sufficiently large $n$. The measure counts memory that is live at the same time.
