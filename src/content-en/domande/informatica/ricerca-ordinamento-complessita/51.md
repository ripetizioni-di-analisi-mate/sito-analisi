For the single key $5$, binary search seeks the boundary separating values below $5$ from those at least $5$. Which array, although unsorted, already satisfies the partition that justifies binary search for this key?

- `{3, 1, 8, 5}`
- `{1, 7, 2, 8}`
- `{8, 1, 5, 2}`
- `{3, 5, 1, 9}`

## Explanation

It suffices for the predicate “less than $5$” to change from true to false without becoming true again. In the selected array $3,1$ give true and $8,5$ give false. The method finds boundary index $2$ even though the groups are not internally sorted.
