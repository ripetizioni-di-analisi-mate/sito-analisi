The search for the first index with key at least `key` uses the half-open interval $[lo,hi)$. If `a[mid] == key`, which update preserves the possibility of finding an earlier duplicate?

- `lo = mid + 1`
- `hi = mid`
- `lo = mid`
- Return `mid` immediately.

## Explanation

If the key at the midpoint equals the search key, no later position can be the first occurrence. Index `mid` remains a possible result and can be kept as the right endpoint. Earlier positions still need to be examined because they may contain copies of the same key.
