In a search for the first value at least as large as an integer key $k$, the comparison log reports, in order, `14 < k` false, `8 < k` true, and `11 < k` true. Which set contains exactly all integer values of $k$ consistent with the three observations?

- $\{12,13,14\}$
- $\{15,16\}$
- $\{9,10,11,12,13,14\}$
- $\{11,12,13\}$

## Explanation

The first outcome establishes $k\le14$. The other two require $k>8$ and $k>11$, with the latter lower bound being stronger. Their intersection is $11<k\le14$, which contains three integer keys.
