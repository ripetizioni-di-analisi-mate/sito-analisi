The loop is intended to find the first value at least as large as the key. It uses a midpoint rounded down and the updates shown. Which state demonstrates that termination can fail?

```c
while (lo < hi) {
    size_t mid = lo + (hi-lo)/2;
    if (a[mid] < key) lo = mid;
    else hi = mid;
}
```

- `lo=2, hi=3, a[2]<key`
- `lo=0, hi=2, a[1]>=key` with `a[0]>=key`
- `lo=2, hi=3, a[2]>=key`
- `lo=3, hi=3`

## Explanation

For bounds $2$ and $3$ the lower midpoint is $2$. If `a[2]<key`, assigning `lo=mid` writes $2$ back and leaves the interval unchanged. The same condition is tested again on the same entry. Discarding that entry requires moving beyond its index.
