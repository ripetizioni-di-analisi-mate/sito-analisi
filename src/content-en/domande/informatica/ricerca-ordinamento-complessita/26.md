The following array is out of order. What is the value of `lo` after the instructions? The fragment uses `<stddef.h>`.

```c
int a[] = {4, 8, 1, 9};
size_t lo = 0, hi = 4;
while (lo < hi) {
    size_t mid = lo + (hi - lo) / 2;
    if (a[mid] < 1) {
        lo = mid + 1;
    } else {
        hi = mid;
    }
}
```

- $1$
- $2$
- $0$
- $4$

## Explanation

The first midpoint is $2$, where value $1$ moves the right endpoint to $2$. Value $8$ at midpoint $1$ moves it to $1$, then value $4$ at index $0$ moves it to $0$. The endpoints coincide at $0$. This is the result of the fragment, and interpreting it as the first suitable position would require a sorted array.
