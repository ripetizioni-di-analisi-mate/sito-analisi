After `pos = lower_bound(a, n, key)`, which expression tests membership of `key` while respecting the array bounds?

- `pos < n`
- `pos <= n && a[pos] == key`
- `a[pos] == key && pos < n`
- `pos < n && a[pos] == key`

## Explanation

The `lower_bound` function returns a position from zero through `n`. If it is `n`, the test `pos < n` is false and short-circuit evaluation skips the read. In the other cases the index is valid but may hold a key larger than the search key. An equality comparison is therefore also required.
