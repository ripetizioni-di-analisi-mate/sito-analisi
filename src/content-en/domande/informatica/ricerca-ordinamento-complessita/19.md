A `lower_bound` begins at $[0,n)$ on an empty array and returns `lo` when the endpoints coincide. What is the pair (returned index, key comparisons)?

- $(0,1)$
- $(1,0)$
- $(0,0)$
- $(-1,0)$

## Explanation

The lower and upper endpoints both start at $0$. The guard `lo < hi` is false on the first test, so the procedure returns $0$ without comparing any array element. Here the returned index is equal to the length.
