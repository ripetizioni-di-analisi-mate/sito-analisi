Find `found`. The fragment uses `<stddef.h>`.

```c
int a[] = {2, 7, 2, 1, 2, 4};
size_t found = 6;
for (size_t i = 0; i < 6; ++i) {
    if (a[i] == 2) {
        found = i;
    }
}
```

- $0$
- $2$
- $6$
- $4$

## Explanation

The index changes on every match because the body continues after assignment. Key $2$ occurs at indices $0$, $2$ and $4$ in that order. The other visits do not overwrite the result, so the last index $4$ remains.
