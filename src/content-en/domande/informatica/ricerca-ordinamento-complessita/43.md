Scanning takes $16$ comparisons per search. An alternative plan sorts once using $64$ comparisons and then takes $5$ per search. What is the smallest number of searches for which the alternative uses strictly fewer comparisons?

- $4$
- $5$
- $6$
- $7$

## Explanation

For $q$ searches, scanning costs $16q$ comparisons and the plan with sorting costs $64+5q$. The second is cheaper if $11q>64$. At $5$ searches, $55\leq64$, while at $6$, $66>64$. The integer threshold is therefore $6$.
