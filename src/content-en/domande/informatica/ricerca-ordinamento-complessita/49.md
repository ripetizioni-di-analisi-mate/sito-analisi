An index of (code, original position) pairs is built from a chronological log. The available sorting algorithm may be unstable. Which ordering guarantees that the first record for a given code in the index comes from its earliest occurrence?

- Increasing code, then increasing original position.
- Increasing code only.
- Decreasing original position only.
- Increasing code, then decreasing original position.

## Explanation

Sorting by code groups the records with the same code. The second orders each group from the smallest original position to the largest. Original records have distinct indices, so the complete pair determines a unique order within the group even under an unstable sort.
