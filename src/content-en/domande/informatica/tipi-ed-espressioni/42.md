Assume input `0x1F 014` on one line and successful reads. The fragment includes `<stdio.h>`. What decimal pair do `first` and `second` receive?

```c
int first = 0, second = 0;
scanf("%i %d", &first, &second);
```

- $(31,12)$
- $(0,14)$
- $(31,14)$
- $(1,14)$

## Explanation

`%i` recognises the prefix `0x` and interprets the first field in base sixteen. Its value is $1\cdot16+15=31$. `%d` uses base ten even if the field starts with zero, so `014` assigns $14$.
