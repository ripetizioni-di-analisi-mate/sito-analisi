A C17 platform has `CHAR_BIT == 16`. If present, the exact-width type `uint8_t` from `<stdint.h>` must have eight bits and no padding bits. What follows?

- Any type with eight padding bits meets the requirement
- The implementation cannot supply that exact-width type
- `sizeof(uint8_t)` must be half a byte
- `uint8_t` must be `unsigned char`

## Explanation

The size of a complete object is a positive whole number of C bytes. Here just one byte already contains sixteen bits. An object consisting of exactly eight bits with no padding therefore cannot exist on this platform. The exact-width types from `<stdint.h>` are provided when the implementation has the required type.
