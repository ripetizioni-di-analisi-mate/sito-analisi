The value −0.5 is exactly representable in `double`. What values do `flag` and `count` store, in that order?

```c
_Bool flag = -0.5;
int count = -0.5;
```

- `0, 0`
- `-1, 0`
- `1, 0`
- `1, -1`

## Explanation

Conversion to `_Bool` tests whether the value differs from zero. Since −0.5 differs from zero, `flag` is 1. Conversion to `int` discards the fractional part toward zero, so `count` is 0.
