Assume `SCHAR_MAX == 127`. How is the choice of result or signal for this C17 conversion classified?

```c
signed char value = 200;
```

- Unspecified.
- Undefined on every implementation.
- Determined by reduction modulo `UCHAR_MAX + 1`.
- Implementation-defined.

## Explanation

The value $200$ has type `int` and exceeds `SCHAR_MAX`, so the `signed char` destination cannot represent it. For conversion between integer types to a signed type under these conditions, C17 specifies an implementation-defined result or an implementation-defined signal.
