The fragment uses `<stdio.h>`. What is the type of the second argument as passed to `printf` under C17?

```c
float value = 2.5f;
printf("%f", value);
```

- `float`
- `double`
- `long double`
- `float *`

## Explanation

`value` is declared as `float`. The declaration of `printf` has a variadic part, so default argument promotions apply to that value. `float` is promoted to `double`, the type required by `%f` in `printf`.
