Which category describes evaluation of the initializer for `total` in C17?

```c
int n = 1;
int total = n++ + n;
```

- Unspecified.
- Undefined.
- Implementation-defined.
- Defined, with order imposed by `+`.

## Explanation

The post-increment modifies `n`. The other operand of `+` reads the same object, and evaluation of `+` leaves the two operands unsequenced relative to each other. A modification unsequenced relative to a read of the same object causes undefined behaviour.
