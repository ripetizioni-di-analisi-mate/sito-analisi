When classifying integer measurements, the only information about `int x` is `x / 4 == -2`. Which inclusive interval contains exactly all possible values of `x`?

- `[-9, -7]`
- `[-8, -5]`
- `[-12, -9]`
- `[-11, -8]`

## Explanation

For a negative ratio to truncate to −2 it must be greater than −3 and at most −2. Multiplying by 4 gives −12 < x ≤ −8. The integers satisfying both inequalities therefore run from −11 through −8.
