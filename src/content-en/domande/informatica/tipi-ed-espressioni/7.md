## Explanation

The types of `count` and `change` have the same rank, so the addition takes place in `unsigned int`. If $M$ is the number of values in that type, $-2$ converts to $M-2$. Adding $10$ gives a value congruent to $M+8$ modulo $M$, so the representative is $8$.
