In this C17 fragment, which statement holds for both objects after the second declaration? `size_t` is declared in `<stddef.h>`.

```c
int n = 7;
size_t k = sizeof(++n);
```

- `n == 8`, `k == sizeof(int)`
- `n == 8`, `k == 8` guaranteed
- `n == 7`, `k == sizeof(int)`
- `n == 7`, `k == 7` guaranteed

## Explanation

The operand of `sizeof` has type `int`, a fixed-size type. Computing its size does not evaluate `++n`. The variable retains 7, and the recorded size depends on the implementation’s `int` type.
