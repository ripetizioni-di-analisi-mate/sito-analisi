A C17 program declares `double value;`. It must read into `value` from `stdin` and write it to `stdout` in decimal format. Which pair of specifiers is compatible, in the order `scanf` and `printf`?

- `%f` / `%f`
- `%lf` / `%Lf`
- `%lf` / `%f`
- `%Lf` / `%f`

## Explanation

`scanf` receives `&value` of type `double *`, so `%lf` matches the input destination. For output, `printf` receives the `double` value directly and `%f` converts it to decimal text.
