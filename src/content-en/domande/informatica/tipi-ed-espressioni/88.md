A C17 compiler reports `sizeof(int) == sizeof(long)`. The expression `1L + 2` is evaluated. Which conclusion follows from the language rules alone?

- The result type depends on evaluation order
- The result has type `unsigned long` because both constants are positive
- The result has type `long` and value 3
- The result must have type `int` because the sizes match

## Explanation

The `L` suffix gives the first operand type `long`. Of the two signed integer types, `long` ranks above `int` even when both occupy the same number of bytes. Thus 2 is converted to `long` before addition, and the resulting value 3 is representable.
