Two fields are read into the same object `v`. Which pair `(r, v)` results in C17?

```c
int v = 0;
int r = sscanf("4 9", "%d%d", &v, &v);
```

- Undefined behavior
- `(1, 9)`
- `(2, 4)`
- `(2, 9)`

## Explanation

The formatted conversions are carried out in sequence. The first assigns 4, and the second assigns 9 to the same destination. The return value counts completed assignments even when both addresses identify the same object.
