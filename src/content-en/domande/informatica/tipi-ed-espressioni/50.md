Assume `double` represents −0.75 exactly. What value does `unsigned int u = (unsigned int)(-0.75);` give in C17?

- `1u`
- `UINT_MAX`
- Undefined behavior
- `0u`

## Explanation

The source has floating type. Discarding the fractional part toward zero yields 0, which `unsigned int` can represent. The modular rule that would turn the integer −1 into `UINT_MAX` does not apply to this conversion.
