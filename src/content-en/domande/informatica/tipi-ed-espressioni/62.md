An integer field should remain empty when its value is zero. In C17, what text does `printf("X%.0dY%d", 0, 0);` produce on successful output?

- `X0Y0`
- `XY0`
- `X.Y0`
- `XY`

## Explanation

The combination of zero precision and integer value zero in `%.0d` writes no digits. The second conversion, `%d`, uses the default precision and writes one digit, `0`. The literal letters therefore delimit the fields as `XY0`.
