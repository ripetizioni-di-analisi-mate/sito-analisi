These two definitions appear outside all functions. In a subsequent definition, also at file scope, which of `int a[WIDTH];` and `int b[limit];` is guaranteed valid by C17 without extensions?

```c
#define WIDTH (2 + 2)
const int limit = 4;
```

- Both are guaranteed valid.
- Only `int a[WIDTH];`.
- Only `int b[limit];`.
- Neither is guaranteed valid.

## Explanation

After macro replacement, the bound of `a` is `(2 + 2)`, an integer constant expression. In C17 the `const` qualifier prevents modification of the object `limit`, but its name is not a guaranteed integer constant expression. Variably modified types, including arrays with such a bound, are allowed only at block scope or function prototype scope.
