On a C17 implementation where `USHRT_MAX > INT_MAX`, what is the type of the expression `+value`?

```c
unsigned short value = 3;
```

- `int`
- `unsigned short`
- `long`
- `unsigned int`

## Explanation

Unary `+` applies the integer promotions. These depend on the type’s range, so the maximum `unsigned short` value matters even though the object holds only $3$. Since `int` cannot represent the entire range, the promoted type is `unsigned int`.
