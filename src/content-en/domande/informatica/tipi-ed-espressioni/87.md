The implementation has `UCHAR_MAX == 255`. What value is assigned to `mask`, and why is a shift count of 8 permitted?

```c
unsigned char bit = 1;
int mask = bit << 8;
```

- 1, because the shift count is reduced modulo 8
- 256, because the left operand is promoted to `int`
- 0, because arithmetic is reduced to eight bits
- The behavior is undefined because `bit` occupies one byte

## Explanation

The `unsigned char` value 1 is promoted to `int`, which can represent all values from 0 through 255. The shift count 8 is less than the width of `int`, and one times two to the eighth is 256, representable in `int`. The size of the original type does not limit this result.
