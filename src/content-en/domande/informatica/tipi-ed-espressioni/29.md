During a call to `add`, which statements about `total` and the evaluation order of the two calls hold in C17?

```c
int left(void) { return 3; }
int right(void) { return 4; }

int add(void)
{
    int total = left() + right();
    return total;
}
```

- $7$ and `left` always first.
- $7$ and call order documented by the implementation.
- $3$ or $4$, depending on the order.
- $7$ and unspecified call order.

## Explanation

The two functions return $3$ and $4$, respectively. Each produces its value independently of the other, so the sum is $7$ in either order. The `+` operator leaves the evaluation order unspecified, and the order can change while the sum stays the same.
