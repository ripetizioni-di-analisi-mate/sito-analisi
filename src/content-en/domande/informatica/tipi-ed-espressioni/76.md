A code review finds `int tag = 'AB';`, with two characters between single quotes. Which conclusion is correct in C17?

- Its value is always the code for `'B'`
- Its value is always `'A' + 'B'`
- The constant has type `int` and an implementation-defined value
- The constant is an array of three `char` elements including the terminator

## Explanation

Single quotes form an integer character constant, of type `int`. When it contains more than one character, its value is implementation-defined. The string literal `"AB"` would form an array holding `A`, `B`, and a terminator.
