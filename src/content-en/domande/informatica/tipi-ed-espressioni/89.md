With `UCHAR_MAX == 255`, a program calls `printf("%c", 256 + 'A');`. Output succeeds. Which character is emitted without assuming ASCII encoding?

- It depends on the ASCII value of `A`
- `B`
- `A`
- The null character

## Explanation

For `%c`, the `int` argument is converted to `unsigned char` before its character is written. Conversion reduces modulo 256 and removes exactly the 256 added to the code for `A`. This leaves the original character from the execution character set.
