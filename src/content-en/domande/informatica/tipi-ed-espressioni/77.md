At the start of the only call to `sample`, `state` equals 1. What is the set of all possible return values of `sample` under C17?

```c
int state = 1;
int tick(void) {
    int old = state;
    state *= 2;
    return old;
}
int sample(void) { return tick() - tick(); }
```

- `{-1}`
- `{-1, 1}`
- `{0}`
- Undefined behavior

## Explanation

The executions of the two calls to `tick` do not overlap. The first call executed returns 1 and changes the state to 2. The second returns 2 and changes it to 4. C17 does not require either operand of the subtraction to be evaluated first, so the result is either 1 minus 2 or 2 minus 1.
