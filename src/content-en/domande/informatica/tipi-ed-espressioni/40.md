`stdin` is empty and end-of-file is encountered before any character is read. With `<stdio.h>`, what value does the read return in `result`?

```c
int number = 3;
int result = scanf("%d", &number);
```

- $0$
- $1$
- `EOF`
- $2$

## Explanation

End-of-file prevents completion of the first conversion and causes an input failure. In this case `scanf` returns the negative constant `EOF`. A return value of $0$ instead identifies a matching failure before any assignment.
