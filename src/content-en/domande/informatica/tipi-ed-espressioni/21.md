Classify the behaviour of this initialization in C17, with `INT_MAX` from `<limits.h>`.

```c
int limit = INT_MAX;
unsigned int result = limit + 1;
```

- Defined, producing $0$.
- Implementation-defined.
- Unspecified.
- Undefined.

## Explanation

Both `limit` and the constant `1` have type `int`. A signed addition must therefore be evaluated before conversion to the destination type. The mathematical value would exceed `INT_MAX`, so evaluating the sum has undefined behaviour. Conversion to the destination would occur only after the calculation.
