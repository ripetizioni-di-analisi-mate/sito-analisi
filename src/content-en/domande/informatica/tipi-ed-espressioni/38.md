The declaration is `long value = -47L;`. Which specifier lets `printf` write that value as signed decimal in C17?

- `%d`
- `%lu`
- `%ld`
- `%Lf`

## Explanation

`value` has type `long`, so it remains `long` when passed as a variadic argument. The signed decimal specifier for that type combines length modifier `l` with conversion `d`, giving `%ld`.
