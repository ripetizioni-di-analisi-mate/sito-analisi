A C17 machine has `CHAR_BIT == 16` and `sizeof(long) == 4`. How many bits, including any padding bits, does the representation of a `long` object occupy?

- $64$
- $32$
- $16$
- $4$

## Explanation

`sizeof(long)` measures the size in C17 bytes, so an object occupies $4$ bytes. Each byte has $16$ bits by assumption. The product $4\cdot16=64$ counts the bits in the object representation, including any padding bits.
