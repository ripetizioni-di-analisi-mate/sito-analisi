The first field holds an identifier that is to be discarded. Which pair `(r, score)` does the fragment produce?

```c
int score = -1;
int r = sscanf("73 19", "%*d%d", &score);
```

- `(1, 19)`
- `(0, -1)`
- `(1, 73)`
- `(2, 19)`

## Explanation

The asterisk in `%*d` suppresses assignment, although `73` is still recognized and consumed. The second field is assigned to `score`. Only that assignment contributes to the return value.
