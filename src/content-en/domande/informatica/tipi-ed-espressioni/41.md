The C17 fragment includes `<stdio.h>`. The input contains `5`, a newline, two spaces and `-2`, followed by end-of-file. The reads succeed. Compute `sum`.

```c
int first = 0, second = 0;
scanf("%d%d", &first, &second);
int sum = first + second;
```

- $5$
- $7$
- $-2$
- $3$

## Explanation

The first `%d` reads `5` up to the newline. Each numeric conversion skips leading white-space characters for its field, so the second `%d` reaches `-2`. Adding the values assigned gives $5+(-2)=3$.
