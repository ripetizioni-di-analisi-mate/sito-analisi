What is the result of the initialization in C17?

```c
int result = 3 < 2 < 1;
```

- $0$
- $2$
- A language constraint violation.
- $1$

## Explanation

The `<` operators have the same precedence and group from the left. The comparison `3 < 2` yields the `int` value $0$. The second comparison is therefore `0 < 1`, which is true and yields $1$.
