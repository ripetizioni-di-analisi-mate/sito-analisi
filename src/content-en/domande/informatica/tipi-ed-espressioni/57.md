The `%n` conversion records the position reached in the string. Which pair `(pos, r)` does the call produce?

```c
int a, pos, b;
int r = sscanf(" 17,5", " %d%n,%d", &a, &pos, &b);
```

- `(3, 3)`
- `(2, 2)`
- `(3, 2)`
- `(4, 2)`

## Explanation

Before `%n`, one space and two digits have been consumed, so `pos` receives 3. The comma is still in the input at that point. `%n` writes the position without increasing the return count, which includes the two numeric assignments.
