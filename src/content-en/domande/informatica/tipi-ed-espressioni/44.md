Determine the final value of `total`. Assume a C17 Annex F implementation in round-to-nearest mode.

```c
int total = 3;
total *= 1.5;
```

- $5$
- $3$
- $4$
- $6$

## Explanation

The product combines integer value $3$ with a `double` constant, so it gives $3\cdot1.5=4.5$ in `double`. Compound assignment stores the result in `total`, which has type `int`. The conversion discards the fractional part and keeps $4$.
