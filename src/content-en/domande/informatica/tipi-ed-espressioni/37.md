What characters does the C17 call write with `<stdio.h>` and successful output?

```c
printf("%d%%/%u", -3, 8u);
```

- `-3%%/8`
- `3%/8`
- `-3%/8`
- `-3%8`

## Explanation

The `%d` conversion uses the first argument and writes `-3`. The `%%` directive writes one percent character and leaves the next argument available. The character `/` is copied. Finally, `%u` writes `8` using the `unsigned int` argument.
