A register is documented with `enum Mode { IDLE, READY = 4 };`. In C17, which property of the identifier `READY` is guaranteed even if different enumeration types use different storage widths?

- `READY` has type `int` and `sizeof READY == sizeof(int)`
- `sizeof READY` counts the decimal digits of 4
- `READY` always has type `unsigned char` because its value is 4
- `READY` is a modifiable object to which 5 can be assigned

## Explanation

In C17 an identifier declared as an enumeration constant has type `int`. Its value is therefore 4 and its size is that of `int`. The choice of a type compatible with the enumeration type concerns objects declared as `enum Mode` and does not change the type of the constant `READY`.
