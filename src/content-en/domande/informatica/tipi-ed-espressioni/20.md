With `UINT_MAX` from `<limits.h>`, what value does `result` take in C17?

```c
unsigned int result = UINT_MAX - 1u + 4u;
```

- $3$
- $2$
- `UINT_MAX - 2u`
- $0$

## Explanation

Let $M$ be the number of values in `unsigned int`. The first calculation gives $(M-1)-1=M-2$. Adding $4$ gives a quantity congruent to $M+2$ modulo $M$. The result in the type is therefore $2$.
