Use IEEE 754 binary32 `float`, with 24 significant binary digits. Each operation rounds directly to binary32 using round-to-nearest, ties-to-even. Which comparisons are true?

```c
float x = 16777216.0f;
float a = x + 1.0f;
float b = x + 2.0f;
```

- Only `b == x`
- Both
- Neither
- Only `a == x`

## Explanation

The starting value is two to the power of 24. From that point the spacing between successive binary32 values is 2. Adding 1 lands halfway between `x` and `x + 2`, and the low bit of the significand of `x` is zero, so the tie is resolved in favor of `x`. Adding 2 reaches the next value exactly.
