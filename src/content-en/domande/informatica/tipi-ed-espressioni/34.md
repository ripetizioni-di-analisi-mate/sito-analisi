A C17 implementation has `INT_MIN == -32768` and `INT_MAX == 32767`. The fragment includes `<limits.h>`. What is the behaviour category of the expression `value % divisor`?

```c
int value = INT_MIN;
int divisor = -1;
int rest = value % divisor;
```

- Defined, with remainder $0$.
- Undefined.
- Implementation-defined.
- Unspecified.

## Explanation

The mathematical quotient of $-32768$ divided by $-1$ is $32768$. This exceeds the largest `int` value. The quotient-representability requirement applies to both division and remainder, so the `%` operation has undefined behaviour in this case.
