Determine the value of `result` in C17, using `UINT_MAX` for the largest `unsigned int` value.

```c
unsigned int amount = 15u;
int divisor = -4;
unsigned int result = amount / divisor;
```

- $3$
- `UINT_MAX / 4u`
- $0$
- Undefined behaviour.

## Explanation

The usual arithmetic conversions convert `divisor` to `unsigned int` because the unsigned type has the same rank as the signed type. In that type, $-4$ becomes `UINT_MAX - 3u`. The resulting divisor is greater than $15$, so the integer quotient is $0$.
