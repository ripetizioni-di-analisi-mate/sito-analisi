Assume C17 with the ASCII execution character set. Which initializer builds a string containing the letter `A`, the letter `F`, and the terminator in that order? The ASCII code for `A` is hexadecimal `41`.

- `"\x41" "F"`
- `"\\x41F"`
- `"\x4" "1F"`
- `"41" "F"`

## Explanation

A hexadecimal escape consumes all consecutive hexadecimal digits within the same string literal. The quotes after `41` end the escape before the `F`. C concatenates the two literals and adds one final terminator. In contrast, `\\` supplies a backslash, while `\x4` supplies the character with code 4.
