In the following C17 compound assignment, which triple gives the final values of `i`, `a[0]`, and `a[1]`?

```c
int a[2] = {5, 7};
int i = 0;
a[i++] += 3;
```

- `2, 8, 7`
- `1, 5, 10`
- `2, 10, 7`
- `1, 8, 7`

## Explanation

The left operand of `+=` is evaluated exactly once. Post-increment supplies index 0 to locate the object and then raises `i` to 1. The original value of `a[0]`, namely 5, is the one increased by 3.
