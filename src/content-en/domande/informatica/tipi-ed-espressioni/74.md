On an otherwise unspecified C17 implementation, which statement is guaranteed for `int q = -5 / 2;` and `int s = -5 >> 1;`?

- `q == -2` and the result of `>>` is implementation-defined
- `q == -2`, `s == -2` on every implementation
- Both expressions have undefined behavior
- `q == -3`, `s == -3` on every implementation

## Explanation

Integer division truncates −2.5 toward zero, yielding −2. For a right shift of a negative signed value by a valid count, C17 leaves the result to the implementation’s documented choice. Only the division therefore gives a portable numerical prediction.
