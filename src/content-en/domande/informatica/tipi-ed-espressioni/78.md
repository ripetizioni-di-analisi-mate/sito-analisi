A program must print the size of `double` as an unsigned decimal integer. Which call using `<stdio.h>` is portable without knowing the underlying integer type of `size_t`?

- `printf("%zu", sizeof(double))`
- `printf("%lu", sizeof(double))`
- `printf("%f", sizeof(double))`
- `printf("%u", sizeof(double))`

## Explanation

The result of `sizeof` has type `size_t`. The length modifier `z` together with `u` specifies exactly the appropriate type for printing this size. A format specifying `unsigned long` or `unsigned int` would depend on a particular implementation choice.
