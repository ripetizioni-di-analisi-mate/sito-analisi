Which expression violates a C17 constraint on operand types and requires a translation diagnostic?

- `7 / 2.0`
- `(int)7.0 % 2`
- `7.0 % 2`
- `7.0 - 2u`

## Explanation

The `%` operator accepts only integer operands. The constant `7.0` has type `double` even though its value is an integer. In `(int)7.0 % 2`, the cast explicitly converts the left operand to an integer, making the remainder operation valid. Division and subtraction already accept real operands.
