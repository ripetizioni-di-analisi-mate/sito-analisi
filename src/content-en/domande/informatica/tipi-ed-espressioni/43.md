Output from this call with `<stdio.h>` succeeds. What value does `written` receive?

```c
int written = printf("[%6.3d]", 27);
```

- $7$
- $6$
- $8$
- $5$

## Explanation

Precision $3$ gives the digits `027`. The field has minimum width $6$, so three leading spaces complete it. The brackets add two characters to the field. The successful call returns the number of characters written, $6+2=8$.
