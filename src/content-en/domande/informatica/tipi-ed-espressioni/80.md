The word uses only the basic characters shown. What text does `printf("|%6.3s|", "MAPPA");` write when output succeeds? `·` represents one space.

- `|MAP···|`
- `|···PPA|`
- `|···MAP|`
- `|·MAPPA|`

## Explanation

For the `s` conversion, precision 3 limits the number of bytes copied from the start of the string. The first three characters are `MAP`. The minimum width is six, and default alignment puts the three padding spaces before the text.
