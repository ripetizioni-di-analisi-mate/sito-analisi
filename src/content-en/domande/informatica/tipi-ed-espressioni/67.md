What are the type and value of the full C17 expression `1 ? 7 : 0.5`?

- `int`, `7`
- `double`, `0.5`
- `double`, `7.0`
- `float`, `7.0f`

## Explanation

The type of the conditional operator depends on both arithmetic branches. The common type of `int` and `double` is `double`. The true condition selects the branch with value 7, so the expression has the `double` result `7.0`.
