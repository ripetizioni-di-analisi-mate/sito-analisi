Each fragment starts with its own `int n = 4;`. The first initializes `int a = 0 && ++n;`, the second initializes `int b = 0 & ++n;`. What are the final values of `n` in those two cases, respectively?

- `4, 5`
- `4, 4`
- `5, 4`
- `5, 5`

## Explanation

The first operator is logical AND. With zero on the left the result is already determined, so the increment is not evaluated. Bitwise AND evaluates both operands. Its bitwise result is still zero, but the increment updates `n` to 5.
