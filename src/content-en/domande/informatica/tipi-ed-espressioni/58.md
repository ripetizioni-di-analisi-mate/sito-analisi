The input string contains `7`, a newline, and `Q`. Which format reads both 7 into `n` and `Q` into `letter` in `sscanf("7\nQ", format, &n, &letter)`, with `int n; char letter;`?

- `"%dQ%c"`
- `"%d %c"`
- `"%d,%c"`
- `"%d%c"`

## Explanation

The numeric conversion stops at the newline. Whitespace in the format consumes whitespace between the fields, so `%c` reaches `Q`. With no space in the format, `%c` would read the newline itself.
