A program checks the return value `r` of `printf`. A successful call can transmit zero characters. Which condition identifies an output or encoding error according to the `printf` contract?

- `r < 0`
- `r == 0`
- `r <= 0`
- `r == -1` as the only possibility

## Explanation

A nonnegative return value counts transmitted characters. Zero is therefore compatible with successful output that produces no characters. For an error, the function returns a negative value without prescribing one particular negative integer.
