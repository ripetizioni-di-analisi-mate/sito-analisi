Compute `result` in C17. In the answers, `UINT_MAX` denotes the largest `unsigned int` value.

```c
unsigned int result = (unsigned int)(-1) / 2u;
```

- $0$
- `UINT_MAX`
- $1$
- `UINT_MAX / 2u`

## Explanation

Conversion to `unsigned int` replaces $-1$ with its representative modulo the number of values in that type. The result is `UINT_MAX`. The dividend and divisor are then unsigned integers, so integer division gives `UINT_MAX / 2u`.
