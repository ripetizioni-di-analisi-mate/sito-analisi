A page holds `d` items, with `d > 0u`. Given `unsigned int n, d`, which formula always returns the minimum number of pages for `n` items, even when `n` is `UINT_MAX`?

- `n / d + (n % d != 0u)`
- `n / d + n % d`
- `(n + d - 1u) / d`
- `n / d + 1u`

## Explanation

The quotient counts full pages. Testing the remainder adds exactly one page when a partial page is needed and zero otherwise. If the quotient already equals `UINT_MAX`, then necessarily `d == 1u` and the remainder is zero. Forming `n + d - 1u` first can change the numerator through modular reduction.
