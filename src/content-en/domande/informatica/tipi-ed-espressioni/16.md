Determine the value of `result` in C17.

```c
int result = (-3 < 2u);
```

- $1$
- $0$
- Undefined behaviour.
- It depends on the signedness of `char`.

## Explanation

The comparison uses `int` and `unsigned int`, which have the same rank. The operand $-3$ therefore becomes `UINT_MAX - 2u`. That value is greater than $2$ on every C17 implementation because `UINT_MAX` is at least $65535$. The comparison is false and yields $0$.
