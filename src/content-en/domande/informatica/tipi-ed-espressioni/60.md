What text does `printf("%#x/%#x", 0u, 26u);` write if the call succeeds?

- `0/0X1A`
- `0/1a`
- `0x0/0x1a`
- `0/0x1a`

## Explanation

The hexadecimal digit for the first argument is `0`. With `%#x`, the `0x` prefix is added only for a nonzero result. Since 26 is sixteen plus ten, the second field contains `0x1a`, with the lowercase letters requested by `x`.
