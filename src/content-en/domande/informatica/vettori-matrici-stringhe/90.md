A function receives a character array with `cap` readable, initialized cells. It might contain no null character. The function must return the first null index, or `cap` if no null is present. Starting from `size_t i = 0;`, which loop meets the contract even when `cap == 0`?

- `while (i + 1 < cap && a[i] != '\0') ++i;`
- `while (i < cap && a[i] != '\0') ++i;`
- `while (a[i] != '\0' && i < cap) ++i;`
- `while (i < cap && a[i] == '\0') ++i;`

## Explanation

In `&&`, the first operand is evaluated before the second. On reaching the capacity, the index test is false and there is no read. For a valid index, the cell is examined and the loop stops at the first null. If there are no nulls, it traverses all cells and returns the capacity.
