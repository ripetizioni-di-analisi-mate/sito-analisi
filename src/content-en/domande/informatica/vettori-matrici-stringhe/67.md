To transpose a square matrix in place, swap `m[i][j]` with `m[j][i]`. The valid indices run from $0$ to $n-1$. Which condition selects exactly one representative of each pair that needs swapping for every matrix with `n >= 2`?

- `i < j && i == 0`
- `i != j`
- `i < j`
- `i == j`

## Explanation

Off the diagonal, the indices $i,j$ differ. In exactly one of the two arrangements the row index is smaller than the column index. The condition `i != j` would visit both arrangements, so the second swap would undo the first.
