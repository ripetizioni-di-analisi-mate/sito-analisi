Call `read_rows(m, 2)` with `int m[2][4]`. The function must receive the rows without reshaping the matrix. Which C17 prototype is compatible? Assume `size_t` is available.

- `void read_rows(int a[][2], size_t rows);`
- `void read_rows(int a[4][], size_t rows);`
- `void read_rows(int a[4], size_t rows);`
- `void read_rows(int a[][4], size_t rows);`

## Explanation

Parameter `a[][4]` adjusts to a pointer to rows of four integers. The row count is passed separately. Specifying two columns would require a different row type, and omitting the second bound would leave the row type incomplete. A one-dimensional parameter would receive a pointer to a single integer.
