On a system with eight-bit bytes, UTF-8 text occupies the hexadecimal bytes `41 C3 A9 00`. In this encoding, `41` represents the letter A and `C3 A9` represents the letter é. What are `strlen` and the number of Unicode code points before the terminator?

- `strlen` $=3$, code points $=2$
- `strlen` $=4$, code points $=2$
- `strlen` $=2$, code points $=3$
- `strlen` $=3$, code points $=3$

## Explanation

The fourth byte is the first null byte, so `strlen` counts the three bytes preceding it. Decoding consumes one byte for A and two bytes for é. Together the three bytes represent two code points.
