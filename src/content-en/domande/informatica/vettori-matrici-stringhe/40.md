Inside a definition `void inspect(int a[9])`, what object type does `sizeof a` measure?

- An array of $9$ `int` elements.
- A pointer to `int`.
- One object of type `int`.
- An array of $9$ `char` elements.

## Explanation

For a parameter, the syntax `int a[9]` is adjusted to pointer to `int`. Thus `sizeof a` measures that pointer. To measure an element, use `sizeof a[0]`. The number of elements in the caller’s array can be passed to the function explicitly.
