What is `v[1]` after the fragment?

```c
int v[5] = {3, 1, 7, -2, 4};
for (int i = 0; i < 4; ++i) {
    v[i] += v[i + 1];
}
```

- $4$
- $13$
- $8$
- $6$

## Explanation

The iteration with `i = 0` changes only `v[0]`. At `i = 1`, `v[1]` is still $1$ and `v[2]` is still $7$, so the assignment stores $1+7=8$. Subsequent iterations write to higher indices.
