Array `a` has active length `n`, declared as `size_t n`. Its active cells must be visited in reverse order, including when `n == 0`. For `n > 0` the array contains at least `n` initialized elements. Which loop visits exactly the intended indices?

- `for (size_t k=0; k<n; ++k) visit(a[k]);`
- `for (size_t k=n; k>1; --k) visit(a[k-1]);`
- `for (size_t k=n; k>0; --k) visit(a[k-1]);`
- `for (size_t k=n; k>0; --k) visit(a[k]);`

## Explanation

The test `k>0` comes before the index calculation, so `k-1` is representable at every access. If $n>0$, the values of `k` in the body run from $n$ down to $1$, giving indices $n-1$ through $0$. With $n=0$, the initial test prevents any read.
