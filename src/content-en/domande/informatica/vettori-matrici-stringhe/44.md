A filter discards every hyphen and keeps the other characters. Which pair of input strings, both of length $4$, tests an empty output first and an output of length $4$ second?

- `"a---"` and `"abcd"`
- `"----"` and `"abc-"`
- `"--ab"` and `"a-b-"`
- `"----"` and `"abcd"`

## Explanation

In the first case all four characters must be discarded, so the input consists entirely of hyphens. In the second all four must be kept, so none is a hyphen. The pair `"----"` and `"abcd"` forces these two extremes.
