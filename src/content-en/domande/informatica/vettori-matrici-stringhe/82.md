Include `<string.h>` and declare `char tag[] = "lab";`. In C17, which address equals the result of `strchr(tag, '\0')`?

- `tag`
- `&tag[3]`
- `NULL`
- `&tag[2]`

## Explanation

For a `strchr` search, the null character terminating the string is included among the searchable characters. The three letters occupy indices $0,1,2$, so the null is at index $3$. The function returns the address of that cell.
