What is `strlen(s)` after the two statements? Assume `<string.h>` is available.

```c
char s[2] = "";
s[0] = 'A';
```

- $0$
- $2$
- $3$
- $1$

## Explanation

The empty literal contains the final null, so the first cell receives the null and the second is implicitly initialized to zero. The assignment replaces the first cell with `'A'`. The first null is now at index $1$, so the length is $1$.
