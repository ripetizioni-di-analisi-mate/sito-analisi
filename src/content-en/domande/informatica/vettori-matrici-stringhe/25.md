For a matrix object `m`, the compiler gives `sizeof m == 36` and `sizeof m[0] == 12`. How many rows does the matrix have?

- $2$
- $3$
- $12$
- $24$

## Explanation

The matrix is an array of equally sized rows. Each row occupies $12$ C bytes and the total is $36$ C bytes. Because the rows are contiguous, the number of rows is $\dfrac{36}{12}=3$.
