In the same array, each `:` must become `::`, and all other characters must be kept. The final length is known and the capacity is sufficient. Apart from the indices, only the current character may be saved. Which strategy writes the result in one transformation pass without overwriting characters that still need to be read?

- Read and write forwards, starting both indices at zero.
- Immediately overwrite the character following each input `:` with `:`.
- Leave the null at its original index and rewrite only the characters preceding that index.
- Place the null at its final index, then read and fill backwards.

## Explanation

The preliminary count fixes the terminator’s destination. Processing the source from the end places the current character and any second copy at positions no earlier than the read index. In `a:b`, for example, the final `b` is placed first, leaving room for both delimiters.
