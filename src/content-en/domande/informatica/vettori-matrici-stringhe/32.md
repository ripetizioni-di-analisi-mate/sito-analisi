How many cells of the array follow the first null character at the end of this fragment?

```c
char s[7] = "roma";
s[1] = '\0';
```

- $5$
- $6$
- $4$
- $2$

## Explanation

The assignment places the first null at index $1$. Capacity remains $7$ cells because assigning a value leaves the object size unchanged. Cells $2$ through $6$ follow it, for a total of $7-(1+1)=5$. Some of them retain characters stored earlier.
