What is `i` when the loop terminates?

```c
char a[] = "retr";
char b[] = "retta";
int i = 0;
while (a[i] != '\0' && a[i] == b[i]) {
    ++i;
}
```

- $2$
- $4$
- $3$
- $5$

## Explanation

The character pairs match at indices $0$, $1$ and $2$, so the loop increments `i` three times. At index $3$ the cells hold `'r'` and `'t'`. Equality fails and the body does not run, so `i` remains $3$.
