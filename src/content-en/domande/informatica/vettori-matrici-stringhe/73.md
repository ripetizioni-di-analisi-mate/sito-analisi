Array entry `ok[c]` should equal $1$ exactly when every entry in column `c` is positive. All entries of `ok` initially equal $1$. Which update inside a loop over all valid pairs `r,c` meets the requirement?

- `ok[c] = !ok[c];`
- `if (m[r][c] <= 0) ok[c] = 0;`
- `ok[c] = (m[r][c] > 0);`
- `if (m[r][c] > 0) ok[c] = 0;`

## Explanation

A single zero or negative entry suffices to rule out the column. Clearing its flag in that case leaves it zero even if later rows contain positive entries. Assigning the result of the latest comparison on every visit would discard the information accumulated so far.
