A valid string of length `len` occupies an array of capacity `cap`. It is given that `len < cap`. Which condition is necessary and sufficient to append one non-null character and move the terminator?

- `cap - len >= 1`
- `cap - len >= 3`
- `cap - len >= 2`
- `cap == len`

## Explanation

The new character occupies position `len` and the new null occupies `len + 1`. The portion starting at `len` must therefore contain at least $2$ cells. Since `len < cap`, the difference `cap - len` counts exactly these cells.
