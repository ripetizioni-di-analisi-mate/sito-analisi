A circular array has six cells. Starting at `i = 0`, mark the current cell and assign `i = (i + 4) % 6` until the first return to zero. How many distinct cells are marked?

- $4$
- $2$
- $6$
- $3$

## Explanation

The first step from index $0$ reaches $4$. The next gives $8$ modulo $6$, hence $2$, and from $2$ the walk returns to $0$. The visited indices are $0,4,2$. Each step preserves parity, so no odd index is visited.
