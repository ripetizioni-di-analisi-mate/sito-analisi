What values does `out` contain, starting at index zero, after the assignments?

```c
int from[] = {5, 8, 9, 4};
int dest[] = {2, 0, 2, 1};
int out[3] = {0};
for (int i = 0; i < 4; ++i)
    out[dest[i]] = from[i];
```

- `{8, 4, 9}`
- `{5, 8, 9}`
- `{9, 4, 8}`
- `{8, 4, 5}`

## Explanation

The first assignment writes $5$ to `out[2]`, and the second writes $8$ to `out[0]`. Destination index $2$ occurs again on the third step, so $9$ replaces $5$. The fourth step fills `out[1]` with $4$.
