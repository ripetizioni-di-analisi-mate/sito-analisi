`char s[8] = "cane";` contains a valid string. What is the maximum number of non-null characters that can be appended while keeping the terminator inside the array?

- $3$
- $4$
- $2$
- $7$

## Explanation

The capacity is $8$ and the string already holds $4$ characters. The maximum string length in the array is $8-1=7$ because one cell is reserved for the final null. Thus $7-4=3$ characters can be added.
