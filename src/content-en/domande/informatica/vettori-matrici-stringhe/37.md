A valid string is filtered in the same array. Initially `i` and `w` are zero. Each step reads `s[i]`. If it keeps the character, it writes it to `s[w]` and increments `w`. Then it increments `i`. Which relation holds before any write and protects cells that have yet to be read?

- `w > i`
- `w == i + 1`
- `w <= i`
- `w == i`

## Explanation

After the previous iterations, `i` counts characters read and `w` counts those kept. Each read character produces at most one written character, so `w <= i`. The write can overwrite the current cell after its value is obtained, or a preceding cell. Discarding a character can make `w < i`.
