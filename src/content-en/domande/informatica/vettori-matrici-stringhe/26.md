Sum the valid cells whose row index is strictly larger than their column index.

```c
int m[3][2] = {{5, -2}, {4, 7}, {-3, 9}};
```

- $1$
- $10$
- $22$
- $17$

## Explanation

In row $0$ no column has a smaller index. In row $1$ take column $0$, which holds $4$. In row $2$ take both columns, which hold $-3$ and $9$. The result is $4-3+9=10$.
