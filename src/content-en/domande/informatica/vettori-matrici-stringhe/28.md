On a machine with `sizeof(int) == 4`, declare `int m[4][5]`. By how many C bytes does the first byte of `m[3][1]` follow the first byte of `m[1][4]` in row-major layout?

- $7$
- $44$
- $64$
- $28$

## Explanation

The linear indices are $3\cdot5+1=16$ and $1\cdot5+4=9$. They differ by $16-9=7$ positions. Each position occupies $4$ C bytes, so the requested offset is $7\cdot4=28$ C bytes.
