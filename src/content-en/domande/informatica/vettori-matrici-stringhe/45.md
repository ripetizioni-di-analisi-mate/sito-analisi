Let `n` be the length of a valid C string. A test needs to read the first and last non-null characters at indices `0` and `n - 1`. Which length condition guarantees exactly that both exist and occupy distinct positions?

- `n >= 1`
- `n >= 3`
- `n % 2 == 0`
- `n >= 2`

## Explanation

The positions of the non-null characters form $[0,n)$. For `n = 0` the range is empty. For `n = 1` both indices equal $0$. From `n = 2` onwards the last index is at least $1$ and stays in $[0,n)$, so the two positions are valid and distinct.
