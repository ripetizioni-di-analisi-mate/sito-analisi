What index does `best` hold at the end of the fragment?

```c
int a[5] = {10, 5, 9, 9, 8};
int best = 1;
for (int i = 2; i < 5; ++i) {
    if (a[i] > a[best]) {
        best = i;
    }
}
```

- $2$
- $0$
- $3$
- $4$

## Explanation

The scan starts at index $1$, with value $5$. At index $2$, value $9$ exceeds it and updates `best`. Index $3$ also contains $9$, so the strict comparison leaves the index as it is. At index $4$, value $8$ is smaller. The subrange maximum is therefore first attained at index $2$.
