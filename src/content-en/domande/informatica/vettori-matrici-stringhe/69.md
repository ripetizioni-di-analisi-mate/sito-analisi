An image uses a one-dimensional array `pixel[24]`. Each physical row occupies six cells, the first four containing pixels and the last two reserved. A subimage starts at physical row $1$, column $1$. What is the array index of its pixel at local row $2$, local column $1$?

- $20$
- $10$
- $19$
- $14$

## Explanation

Adding the local coordinates to the origin gives physical row $3$, column $2$. The reserved space remains in the array and contributes to the spacing of consecutive row starts. The index is therefore $3\cdot6+2=20$.
