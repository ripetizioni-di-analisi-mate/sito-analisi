Given the declarations below and `<string.h>`, which statement correctly compares the strings and the two array representations?

```c
char a[] = {'K', '\0', 'x', '\0'};
char b[] = {'K', '\0', 'y', '\0'};
```

- `strcmp(a,b) == 0` and `memcmp(a,b,4) != 0`.
- Both calls return a nonzero value.
- Both calls return zero.
- `strcmp(a,b) != 0` and `memcmp(a,b,4) == 0`.

## Explanation

Starting at index zero, both strings end immediately after `K`. The string comparison therefore finds them equal. Comparing four bytes also examines index $2$, where `x` and `y` have distinct representations.
