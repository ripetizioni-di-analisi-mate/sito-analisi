Find a cell whose value is both a minimum in its row and a maximum in its column. Which index pair satisfies both conditions?

```c
int m[3][3] = {{8,5,6}, {4,3,2}, {7,1,9}};
```

- `(2,2)`
- `(2,1)`
- `(1,2)`
- `(0,1)`

## Explanation

The three row minima are $5$, $2$, and $1$. The value $5$ lies in column $1$, which contains $5,3,1$, so it is also the largest value in that column. The minimum $2$ has $6$ above it, and the minimum $1$ shares its column with $5$.
