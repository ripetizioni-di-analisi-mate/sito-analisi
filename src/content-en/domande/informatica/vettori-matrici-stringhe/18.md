What is the final value of `v[2]`?

```c
int v[4] = {2, -3, 4, 6};
v[1] = v[0] + v[2];
v[2] = v[1] - v[3];
```

- $0$
- $-9$
- $4$
- $6$

## Explanation

The first assignment uses $2+4=6$ and writes $6$ to `v[1]`. The second reads that updated cell and subtracts the value $6$ in `v[3]`. Thus `v[2]` receives $6-6=0$. The initial value $-3$ in `v[1]` has already been replaced.
