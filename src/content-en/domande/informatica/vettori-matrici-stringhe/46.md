In C17, how many elements does `a` contain, and what value does the last element receive?

```c
int a[] = {[3] = 8, 5, [1] = -2};
```

- $3$ elements, value $-2$
- $5$ elements, value $0$
- $5$ elements, value $5$
- $4$ elements, value $8$

## Explanation

The designator `[3]` places $8$ at index $3$. The next initializer has no designator, so it continues at index $4$ and places $5$ there. Returning to index $1$ to write $-2$ leaves $4$ as the greatest initialized index, so the inferred array length is $5$.
