Three rows are stored in separate arrays of lengths `{2, 4, 1}`. Column indices start at zero within each row. Column $1$ is to be visited wherever it exists. Which rows contribute?

- $0$ and $1$
- Only $1$
- All three
- $1$ and $2$

## Explanation

Column $1$ exists when the length of the individual row is strictly greater than $1$. Lengths $2$ and $4$ satisfy that condition. The last row has just one element and admits only column $0$.
