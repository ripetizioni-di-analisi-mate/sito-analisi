After the fragment, which valid strings begin at `path` and `tail`, respectively?

```c
char path[] = "/up/down";
char *tail = path + 4;
path[3] = '\0';
```

- `"/up", ""`
- `"/up", "down"`
- `"/up", "/down"`
- `"/up/down", "down"`

## Explanation

The second separator is at index $3$. Replacing it with null ends the initial string after `/up`. Pointer `tail` denotes index $4$, which still holds `d`. The following bytes and the original terminator still form the string `down`.
