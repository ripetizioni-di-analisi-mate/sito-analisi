A text format uses `:` between fields and allows empty fields, including at the beginning and end. How many fields does `":a::"` describe, and how many of them are empty?

- $4$ fields, $2$ empty
- $4$ fields, $3$ empty
- $1$ field, none empty
- $3$ fields, $2$ empty

## Explanation

Each delimiter closes the preceding field, and the end of the string closes the last one. Three delimiters therefore produce four fields. In order, they are the empty string, `a`, the empty string, and one final empty string after the last delimiter.
