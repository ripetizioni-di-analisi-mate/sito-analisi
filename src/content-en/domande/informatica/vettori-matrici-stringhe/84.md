The code calculates the remainder modulo $7$ of the decimal digit prefix of the string. What are `r` and `i` on exit?

```c
char s[] = "507x20";
int i = 0, r = 0;
while (s[i] >= '0' && s[i] <= '9') {
    r = (10*r + (s[i]-'0')) % 7;
    ++i;
}
```

- `(3, 5)`
- `(0, 3)`
- `(3, 3)`
- `(5, 2)`

## Explanation

The digit prefix is `507`. Appending a digit multiplies the previous value by ten and adds the digit value. The remainders go from $0$ to $5$, then to $1$, and finally to $3$. The character at index $3$ is `x`, so the subsequent digits are not read.
