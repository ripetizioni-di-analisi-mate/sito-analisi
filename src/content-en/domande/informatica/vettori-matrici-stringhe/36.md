Which string results in the array `out`?

```c
char source[] = "carta";
char out[4];
int k = 0;
while (k < 3 && source[k] != '\0') {
    out[k] = source[k];
    ++k;
}
out[k] = '\0';
```

- `car`
- `cart`
- `carta`
- `ca`

## Explanation

The loop allows indices $0$, $1$ and $2$ while the source character is non-null. It copies `'c'`, `'a'` and `'r'`. At the end `k` is $3$ and cell $3$ receives the null. Even though the source continues, the destination has room for its terminator.
