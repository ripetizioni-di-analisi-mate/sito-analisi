What is the final value of `total`?

```c
int a[4] = {3, -2, 4, 1};
int b[4] = {2, 3, -1, 5};
int total = 0;
for (int i = 0; i < 4; ++i) {
    total += a[i] * b[3 - i];
}
```

- $1$
- $27$
- $29$
- $31$

## Explanation

The indices in `a` increase from $0$ to $3$, while those in `b` decrease from $3$ to $0$. The products are $3\cdot5=15$, $(-2)(-1)=2$, $4\cdot3=12$ and $1\cdot2=2$. The sum is $15+2+12+2=31$.
