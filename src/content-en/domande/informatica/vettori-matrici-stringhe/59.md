An `int` accumulator starts at zero and adds entries from left to right. Let `M = INT_MAX`. Which array has mathematical sum zero but would require an intermediate value greater than `M`?

- `{-1, M, 1, -M}`
- `{M, -1, 1, -M}`
- `{1, -1, M, -M}`
- `{M, 1, -1, -M}`

## Explanation

In the selected array the first prefix equals `M` and the second would have mathematical value `M + 1`, outside the range of `int`. Later additions would cancel the excess in mathematical arithmetic. In the other orders the prefix reaches at most `M` without exceeding it.
