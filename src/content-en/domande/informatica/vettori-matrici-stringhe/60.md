A function is declared as `void first_pair(const int a[static 4]);`. Its body only reads the first two cells. Which call with an array name satisfies the size requirement expressed by this C17 parameter?

- Pass `x` declared as `int x[] = {1};`.
- Pass `x` declared as `int x[3] = {1, 2};`.
- Pass `x` declared as `int x[5] = {1, 2};`.
- Pass `x` declared as `int x[2] = {1, 2};`.

## Explanation

The keyword `static` together with bound $4$ requires the argument to provide access to the first element of an array with at least four elements. The five-element array satisfies that requirement, and its initializer also sets the remaining cells to zero. The number of cells actually read by the body does not reduce the requirement in the declaration.
