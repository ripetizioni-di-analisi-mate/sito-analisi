Given `int m[2][3] = {{1, 2, 3}, {4, 5, 6}};`, which statement describes the C17 evaluation of `m[0][3]` to read its value?

- The second index is outside the bounds of the row.
- It gives $4$ because that value follows the first row.
- It gives $3$ because the last valid cell is used.
- It gives $0$ because the row is completed automatically.

## Explanation

`m[0]` is an array of three integers, so its valid indices are $0$, $1$ and $2$. Storage order makes the rows contiguous, while the second index operates inside the selected row. To read $4$, use `m[1][0]`. Reading through `m[0][3]` is an out-of-bounds access.
