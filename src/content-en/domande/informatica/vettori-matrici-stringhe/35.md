What is the final value of `runs`?

```c
char s[] = "a--b-c";
int runs = 0;
for (int i = 0; s[i] != '\0'; ++i) {
    if (s[i] == '-' && (i == 0 || s[i - 1] != '-')) {
        ++runs;
    }
}
```

- $3$
- $1$
- $4$
- $2$

## Explanation

The loop increments the counter only at the start of a run of hyphens. The hyphen at index $1$ follows `'a'` and the one at index $4$ follows `'b'`, so each starts a run. The hyphen at index $2$ follows another hyphen and belongs to the run already counted.
