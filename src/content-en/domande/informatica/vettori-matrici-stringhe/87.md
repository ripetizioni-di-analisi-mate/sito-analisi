In this fragment, `<string.h>` is available. What string remains after the trailing line ending is removed? Each of `\r` and `\n` in the options denotes one character.

```c
char s[] = "x\r\ny\r\n";
size_t n = strlen(s);
if (n && s[n-1] == '\n') s[--n] = '\0';
if (n && s[n-1] == '\r') s[--n] = '\0';
```

- `"xy"`
- `"x\r\ny"`
- `"x\r\ny\r"`
- `"x"`

## Explanation

The initial length is $6$. The first condition removes the final newline and reduces `n` to $5$. The second removes the carriage return now at the end and reduces `n` to $4$. The two control characters between `x` and `y` remain in the text.
