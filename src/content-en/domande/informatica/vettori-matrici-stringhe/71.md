Cells of a three-row, four-column matrix are grouped by `r + c`. Which columns, listed in row order $0,1,2$, belong to the group `r + c == 3`?

- `{3, 2, 1}`
- `{2, 1, 0}`
- `{1, 2, 3}`
- `{0, 1, 2}`

## Explanation

For a fixed row, the column is $c=3-r$. Rows $0,1,2$ give columns $3,2,1$, all valid. The next index pair with the same sum would be $(3,0)$, but the last row of this matrix is row $2$.
