Starting from `int i = 3`, visit `a[i]` up to the last element of `int a[7]`, incrementing `i` by one. Which loop condition visits exactly the requested indices?

- `i <= 7`
- `i < 6`
- `i > 3`
- `i < 7`

## Explanation

Valid indices end at $6$, so the requested range is $[3,7)$. The test `i < 7` accepts $3$, $4$, $5$ and $6$ and stops the loop at $7$. An inclusive test would allow an access beyond the array.
