To remove negatives without preserving order, a program replaces the current negative entry with the last active cell and decreases the active length. The value at index $1$ has just been removed from `{8, -1, 4, -7}`. How should a left-to-right scan continue so that no unchecked element is missed?

- Inspect index $1$ again.
- Advance directly to index $2$.
- Inspect index $3$ under the new active length.
- Stop because the scanned prefix is positive.

## Explanation

After the move the active prefix is $8,-7,4$ and has length $3$. Index $1$ now holds an entry moved from the end that the scan has not classified yet. Advancing directly to $2$ would leave $-7$ in the output.
