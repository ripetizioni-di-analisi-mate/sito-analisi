Assume `<stdio.h>` is available and the following formatting operation succeeds. Which pair gives the string stored in `d` and the value returned in `n`?

```c
char d[5];
int n = snprintf(d, sizeof d, "%s%s", "ab", "cde");
```

- `"abcd", 5`
- `"abc", 4`
- `"abcd", 4`
- `"abcde", 5`

## Explanation

The complete text would have five characters, since `ab` and `cde` are concatenated. The array has capacity five, so four cells receive visible characters and one receives the null. The return value counts the five characters that would have been written with sufficient space, excluding the null.
