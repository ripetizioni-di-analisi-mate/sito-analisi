Each boundary cell of a nonempty grid should be counted exactly once. Which test reveals a program that always adds the entire first row and the entire last row, even when they coincide? Any intervening rows are handled correctly.

- A single row `{2, 0, 1}`, with expected sum $3$.
- Two rows `{1, 1}` and `{2, 2}`, with expected sum $6$.
- Two rows `{0}` and `{3}`, with expected sum $3$.
- A single row `{0, 0}`, with expected sum zero.

## Explanation

With one row, “first” and “last” refer to the same cells. On $2,0,1$, the program produces $3+3=6$ instead of $3$. An all-zero row exercises the same case, but the double count is invisible in the result.
