The register contains four rows, and an empty string is a valid entry. The task is to count nonempty entries. What count would a loop produce if it examined rows from index zero and stopped as soon as `tab[r][0] == 0`, and what count is required?

```c
char tab[4][4] = {"A", "", "BB", "C"};
```

- $3$ produced, $3$ required
- $1$ produced, $4$ required
- $1$ produced, $3$ required
- $2$ produced, $3$ required

## Explanation

The first row contains `A`, so the loop counts one entry. The second begins with null and stops the loop before the rows containing `BB` and `C`. The traversal bound must be the number of rows. The first character only determines whether an individual row contributes.
