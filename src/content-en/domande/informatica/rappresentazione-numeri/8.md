- $[-32,31]\cap\mathbb{Z}$
- $[-31,32]\cap\mathbb{Z}$
- $[-32,32]\cap\mathbb{Z}$

## Explanation

With $6$ bits, the leftmost bit has weight $-2^5=-32$ and the other five bits give a value from $0$ to $2^5-1=31$. With the first bit set to $1$, the possible values are all the integers from $-32$ through $-1$. With the first bit set to $0$, the possible values are all the integers from $0$ through $31$. Together, the two cases give the range $[-32,31]\cap\mathbb{Z}$.
