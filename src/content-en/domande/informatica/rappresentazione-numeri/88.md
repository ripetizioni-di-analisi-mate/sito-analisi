A sensor transmits a four-bit word in Gray code. Its leftmost bit equals the original binary bit in that position. Each remaining Gray bit is $1$ if the binary bit in its position differs from its neighbour to the left, and $0$ otherwise. The received word is `1011`. What was the original binary word?

- `1011`
- `1101`
- `1110`
- `1001`

## Explanation

The first binary bit is $1$. The second Gray bit is $0$, so the second binary bit repeats the first and is $1$. The third Gray bit is $1$, so the third binary bit changes to $0$. The last Gray bit is also $1$, giving a change back to $1$. The binary sequence is `1101`.
