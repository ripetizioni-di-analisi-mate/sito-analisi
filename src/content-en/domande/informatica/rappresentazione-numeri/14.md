- $1.011_2\cdot2^2$
- $1.100_2\cdot2^3$
- $1.010_2\cdot2^2$
- $1.100_2\cdot2^2$

## Explanation

The exact normalized form is $1.0111_2\cdot2^2$. With four significant digits, the adjacent values are $1.011_2\cdot2^2$ and $1.100_2\cdot2^2$. The exact number is equidistant from the two candidates because the first discarded bit is $1$ and all the following bits are $0$. The ties-to-even rule selects the candidate whose last significant digit is even, so the result is $1.100_2\cdot2^2$.
