A meter for nonnegative inputs truncates after three fractional bits and does not saturate in the range under consideration. It displays $1.011_2$. What is the exact set of real inputs that produce this reading?

- $\dfrac{11}{8}\leq x<\dfrac{12}{8}$
- $\dfrac{11}{8}< x\leq\dfrac{12}{8}$
- $\dfrac{10}{8}< x\leq\dfrac{11}{8}$
- $\dfrac{21}{16}\leq x<\dfrac{23}{16}$

## Explanation

The displayed value is $1+\dfrac{1}{4}+\dfrac{1}{8}=\dfrac{11}{8}$. Truncating a nonnegative input retains the grid point immediately below it or equal to it. The next grid point is $\dfrac{12}{8}$ and must be excluded because it would give the next reading. The lower threshold, by contrast, is represented exactly.
