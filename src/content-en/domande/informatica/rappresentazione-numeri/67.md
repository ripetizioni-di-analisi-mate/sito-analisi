A binary fraction has $0$ as its first fractional bit, followed by infinitely many $1$ bits. Which real-number equality justifies reading this expansion?

- $\displaystyle\sum_{j=2}^{\infty}2^{-j}=\dfrac{3}{4}$
- $\displaystyle\sum_{j=2}^{\infty}2^{-j}=1$
- $\displaystyle\sum_{j=2}^{\infty}2^{-j}=\dfrac{1}{4}$
- $\displaystyle\sum_{j=2}^{\infty}2^{-j}=\dfrac{1}{2}$

## Explanation

The first one occupies the position of weight $\dfrac{1}{4}$. Each subsequent contribution is half the preceding one. The geometric sum is therefore $\dfrac{\frac14}{1-\frac12}=\dfrac{1}{2}$. Every finite truncation lies below $\dfrac{1}{2}$, while the infinite expansion has exactly the same value as $0.1000\ldots_2$.
