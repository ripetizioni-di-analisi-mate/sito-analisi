In a normalized binary format with three significant digits and unrestricted exponents, $x=\dfrac{13}{10}$ rounds to nearest to give $\dfrac{5}{4}$. If the exact input is multiplied by $8$ first and rounded only at the end, what absolute relative error is obtained, measured against the new exact input?

- $\dfrac{1}{26}$
- $\dfrac{2}{5}$
- $\dfrac{1}{208}$
- $\dfrac{1}{20}$

## Explanation

Multiplication by $8=2^3$ shifts the exponent, so both the input and its neighboring representable values are multiplied by eight. The input becomes $\dfrac{52}{5}$ and the rounded result is $10$. The absolute error is $\dfrac{2}{5}$. Dividing by the exact input gives $\dfrac{2}{5}\cdot\dfrac{5}{52}=\dfrac{1}{26}$.
