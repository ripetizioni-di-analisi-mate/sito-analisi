An older eight-bit format uses the first bit as the sign, with $1$ for negative values, and the other seven as the magnitude. A converter reads $10000000_2$ in this format and writes the same mathematical value in eight-bit two’s complement. Which word does it write?

- $01111111_2$
- $11111111_2$
- $00000000_2$
- $10000000_2$

## Explanation

All seven magnitude bits are zero, so the absolute value is zero. The leading sign marks the source format’s negative zero, whose integer value is zero. Two’s complement has a single encoding for zero, with every bit clear. Keeping the original word would instead produce $-128$.
