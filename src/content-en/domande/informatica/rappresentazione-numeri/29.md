Which $8$-bit word represents $-3.25$ in fixed point with a two's-complement underlying integer and two fractional bits?

- $11110011_2$
- $00001101_2$
- $11110010_2$
- $11111101_2$

## Explanation

Multiplying the value by $2^2=4$ gives the underlying integer $I=-3.25\cdot4=-13$. The corresponding unsigned value is $2^8-13=243$. Since $243=128+64+32+16+2+1$, the required word is $11110011_2$. Its signed value is $243-256=-13$, which represents $\dfrac{-13}{4}=-3.25$ in fixed point.
