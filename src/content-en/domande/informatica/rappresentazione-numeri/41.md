The unsigned value of a $7$-bit word is written as $\mathrm{4E}_{16}$. What is the value of the same word in $7$-bit two's complement?

- $-50$
- $78$
- $-14$
- $-49$

## Explanation

The digit $\mathrm E$ has value $14$, so the unsigned value is $4\cdot16+14=78$. Since $78\geq2^6=64$, the leftmost bit of the seven-bit word is $1$. The two's-complement interpretation therefore gives $78-2^7=78-128=-50$.
