A fixed-point grid with spacing $\dfrac{1}{4}$ includes codes $4$, $5$, and $6$ and uses round to nearest. A tie selects the point with an even stored integer. What is the exact set of inputs that convert to stored integer $5$?

- $\dfrac{9}{8}<x<\dfrac{11}{8}$
- $\dfrac{9}{8}\leq x\leq\dfrac{11}{8}$
- $\dfrac{9}{8}\leq x<\dfrac{11}{8}$
- $\dfrac{9}{8}<x\leq\dfrac{11}{8}$

## Explanation

Code $5$ represents $\dfrac{5}{4}$. Its neighbors are $1$ and $\dfrac{3}{2}$, so the midpoints are $\dfrac{9}{8}$ and $\dfrac{11}{8}$. At the lower midpoint the even code $4$ wins, and at the upper midpoint the even code $6$ wins. Only inputs strictly inside the interval are assigned to code $5$.
