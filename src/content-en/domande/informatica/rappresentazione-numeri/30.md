A binary fixed-point format is to use a two's-complement underlying integer, with minimum $-4$, maximum $3.5$, and step size $0.5$. Which pair $(n,f)$, with $n$ total bits and $f$ fractional bits, meets these conditions?

- $(3,1)$
- $(4,1)$
- $(4,2)$
- $(5,1)$

## Explanation

The step size is $2^{-f}$ and equals $0.5=2^{-1}$, so $f=1$. Before division by $2$, the minimum must be $-8$. In two's complement this requires $n$ such that $-2^{n-1}=-8$. It follows that $n=4$. The maximum underlying integer is then $7$, so the maximum value in the format is $\dfrac{7}{2}=3.5$.
