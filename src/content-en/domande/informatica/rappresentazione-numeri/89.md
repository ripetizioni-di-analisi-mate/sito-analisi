Two unsigned binary codes have variable widths and no leading zeros except for the code $0$. Which comparison rule correctly orders every pair by numerical value?

- Compare the number of one bits first, using length only to break ties.
- Always compare digits from the left, placing a shorter prefix first when one word is a prefix of the other.
- Compare lengths first, then compare digits starting at the right when lengths match.
- Compare lengths first, then for equal lengths compare digits from the left with $0<1$.

## Explanation

Every positive number of length $n$ is at least $2^{n-1}$, while any shorter word has value at most $2^{n-1}-1$. Zero precedes the other one-bit code by $0<1$. For equal lengths the weight of the first differing position exceeds the sum of all lower weights, so that bit decides the order.
