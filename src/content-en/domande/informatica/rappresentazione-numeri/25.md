The width of the word $111110001_2$ is reduced by removing bits from the left. What is the minimum width that preserves its two's-complement value?

- $4$ bits
- $5$ bits
- $6$ bits
- $7$ bits

## Explanation

In nine bits, the word has value $497-512=-15$. Keeping the last five bits gives $10001_2$, whose value is $17-32=-15$. In four bits, the minimum is $-2^3=-8$, so $-15$ is out of range. Since the range narrows as the width decreases, five bits are the minimum.
