A routine can sort only eight-bit unsigned keys. It must sort the values of eight-bit two’s-complement words. Which transformation of each word produces a key that preserves signed numerical order?

- Clear the most significant bit.
- Flip all eight bits.
- Leave the word unchanged.
- Flip only the most significant bit.

## Explanation

Words from $80_{16}$ through $\mathrm{FF}_{16}$ represent $-128$ through $-1$. Flipping the leading bit maps them, in order, to keys $0$ through $127$. Values from $0$ through $127$ acquire keys $128$ through $255$. In both groups the numerical key equals the signed value plus $128$.
