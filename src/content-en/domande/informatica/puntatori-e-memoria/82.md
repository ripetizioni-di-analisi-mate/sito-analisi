In sorted array `{1, 3, 4, 8, 12}`, two pointers start at the first and last elements. While the left pointer is before the right one, the sum of the pointed-to values is compared with $12$. If it is too small the left pointer moves forward; if it is too large the right pointer moves back. Equality ends the search. What are the zero-based pointer indices when it stops?

- $(2,3)$
- $(0,4)$
- $(1,3)$
- $(2,4)$

## Explanation

The first sum is $1+12=13$, so the right pointer moves to value $8$. The sums $1+8=9$ and $3+8=11$ are both too small, moving the left pointer forward twice. The sum $4+8=12$ reaches the target at indices $2$ and $3$.
