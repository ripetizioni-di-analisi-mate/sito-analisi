What is the value of `*p` at the end of this fragment executed inside a function?

```c
int u = 8;
int *p = &u;
int **r = &p;
**r = 12;
```

- $8$
- $12$
- $4$
- $20$

## Explanation

`r` designates the variable `p`, so `*r` has the value stored in `p`. This value is the address of `u`. The second dereference designates `u`, so `**r = 12` changes the value read through `*p`.
