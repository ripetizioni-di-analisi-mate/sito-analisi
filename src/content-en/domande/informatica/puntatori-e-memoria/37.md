With `<stdlib.h>` included, suppose the first allocation succeeds and the second fails. How many blocks obtained here remain alive when `return 0;` runs?

```c
int *left = malloc(sizeof *left);
int *right = malloc(sizeof *right);
if (left == NULL || right == NULL) {
    free(left);
    free(right);
    return 0;
}
```

- $3$
- $0$
- $1$
- $2$

## Explanation

The first call creates one block and the second writes the null value into `right`. The error branch runs. Within it, `free(left)` ends the lifetime of the only allocated block, and `free(right)` has no effect. The live-block count is $1-1=0$.
