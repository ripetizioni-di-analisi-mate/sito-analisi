Structure `v` is copied into `w`. What is the pair `(base[0], v.n)` after the updates?

```c
struct View { int *data; int n; };
int base[] = {3, 6, 9};
struct View v = {base, 3};
struct View w = v;
w.n = 1;
w.data[0] = 8;
```

- $(3,1)$
- $(8,1)$
- $(3,3)$
- $(8,3)$

## Explanation

The assignment copies the structure members. The two `n` fields are distinct objects, so `w.n = 1` leaves `v.n` at 3. The two `data` fields hold the same address, and the write through `w.data` reaches `base[0]`.
