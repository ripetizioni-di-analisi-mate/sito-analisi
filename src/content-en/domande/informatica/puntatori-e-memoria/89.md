Pointer `p` advances while the current prefix matches that of `b`. Both arrays have four elements. What length does the function return for the given data?

```c
#include <stddef.h>

ptrdiff_t prefix(const int a[4], const int b[4]) {
    const int *p = a;
    while (p != a + 4 && *p == b[p - a]) ++p;
    return p - a;
}
/* a = {4,9,2,5}; b = {4,9,8,5} */
```

- $3$
- $4$
- $1$
- $2$

## Explanation

The pairs at indices 0 and 1 have equal values, so after two increments `p` points to `a[2]`. At index 2, the comparison is between 2 and 8 and the condition becomes false. The difference `p - a` counts the two matching prefix elements, and the equality at index 3 is never examined.
