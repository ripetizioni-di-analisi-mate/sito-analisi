How many elements does the following loop read? The type `size_t` is available.

```c
int a[4] = {5, 3, 8, 2};
int *first = a + 2;
int *last = a + 2;
size_t count = 0;
for (int *p = first; p != last; ++p) {
    count += (*p > 0);
}
```

- $4$
- $1$
- $2$
- $0$

## Explanation

`first` and `last` have the same value, `a + 2`. Consequently the initial test is false. The body reads no element and `count` stays at $0$.
