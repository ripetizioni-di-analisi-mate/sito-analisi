The following C17 statements execute in a single block inside a function. What value does `last` receive?

```c
int *p = (int[]){2, 6, 11};
p[1] += p[0];
int last = p[1] + p[2];
```

- The array’s lifetime ends at the first semicolon.
- $13$
- $17$
- $19$

## Explanation

The compound literal creates an array with automatic storage duration in this block. The array is still alive when the second statement changes `p[1]` from 6 to 8. The third adds $8+11=19$. Completing the initialization of `p` does not end the lifetime of the array.
