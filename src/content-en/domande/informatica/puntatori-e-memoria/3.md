- `const int *`
- `const int **`
- `int *const`
- `int *`

## Explanation

`*p` is an expression designating a `const int`. Applying `&` therefore gives a pointer to `const int`, the same type as `p`. The `sizeof` context measures the operand’s type without removing the qualification of the pointed-to object.
