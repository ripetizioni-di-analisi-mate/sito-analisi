Suppose `int *p = NULL;` is in scope. Which expression measures the pointed-to type in C bytes on every C17 implementation without reading an object of that type?

- `sizeof p`
- `sizeof &p`
- `sizeof *p`
- `sizeof(char)`

## Explanation

The operand `*p` has fixed-size type `int`. `sizeof` uses that type and does not evaluate the dereference. The result is therefore `sizeof(int)` even when `p` is null. Pointer and character sizes follow from their own types and need not equal the size of `int`.
