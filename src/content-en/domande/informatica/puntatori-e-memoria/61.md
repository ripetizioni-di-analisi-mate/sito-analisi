A reader advances the caller’s cursor by one element and returns the consumed value. What are `v` and `*next` after the call?

```c
int take(const int **pos) {
    int out = **pos;
    ++*pos;
    return out;
}
void example(void) {
    int a[] = {9, 12, 7};
    const int *next = a + 1;
    int v = take(&next);
}
```

- $(12,12)$
- $(13,7)$
- $(12,7)$
- $(7,7)$

## Explanation

On entry, `*pos` designates the cursor `next` and `**pos` reads `a[1]`. The function saves 12 in `out`. The expression `++*pos` advances the caller’s cursor to `a[2]`, so after the return `*next` is 7.
