A function accepts an `int *` and must clear the integer only if it is positive. Which condition before `*p = 0` also treats a null pointer as “no data”?

- `p != NULL && *p > 0`
- `p == NULL && *p > 0`
- `*p > 0 && p != NULL`
- `p != NULL || *p > 0`

## Explanation

The `&&` operator evaluates its left operand first. If `p` is null, that comparison is false and the second operand is skipped. With a valid pointer, the integer is read and the assignment takes place only when it is strictly positive.
