The goal is to traverse the representation of a live integer `x` one byte at a time. Which pair gives an appropriate starting pointer and the number of C bytes in the integer on every C17 implementation?

- `(const unsigned char *)&x` and `sizeof &x`
- `&x` and `sizeof &x` steps of one integer each
- `(const unsigned char *)&x` and `sizeof x`
- `(const unsigned char *)&x` and always `8`

## Explanation

An unsigned character pointer can read the bytes of the object representation. Each pointer increment advances by one C byte. `sizeof x` measures the whole object, whereas `sizeof &x` measures a pointer to it and may have a different value.
