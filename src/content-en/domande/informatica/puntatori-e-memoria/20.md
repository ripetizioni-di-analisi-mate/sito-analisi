Find the value of `(*row)[1]` after these declarations.

```c
int m[2][3] = {{1, 5, 9}, {4, 7, 2}};
int (*row)[3] = m + 1;
```

- $5$
- $9$
- $7$
- $1$

## Explanation

Here the element type of `m` is `int[3]`. Adding one to the pointer obtained from `m` therefore selects row index $1$. The expression `(*row)[1]` reads element index $1$ of that row, which is $7$.
