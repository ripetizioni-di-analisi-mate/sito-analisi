With `<string.h>` included, `memchr(p,c,n)` returns a pointer to the first of the next `n` bytes equal to `c`, or `NULL` if none matches. What value is assigned to `off` in this C17 fragment?

```c
const unsigned char a[] = {4, 0, 7, 4, 4};
const unsigned char *p = memchr(a + 1, 4, 3);
int off = p == NULL ? -1 : (int)(p - a);
```

- $3$
- $0$
- $2$
- $-1$

## Explanation

The search starts at `a[1]` and covers three bytes with values $0$, $7$ and $4$. The zero byte is data in this explicitly bounded search. The first match in the range is `a[3]`. The subtraction uses base `a`, so `off` is $3$.
