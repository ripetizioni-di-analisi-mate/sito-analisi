The call is `update(&x, &y)` with `int x = 7, y = 12;`. What is the final pair $(x,y)$?

```c
void update(int *out, int *alt)
{
    *out = 3;
    out = alt;
    *out += 4;
}
```

- $(3,12)$
- $(7,16)$
- $(3,16)$
- $(7,12)$

## Explanation

The parameter `out` receives the address of `x`, so the first write sets `x` to $3$. Then `out` takes the address stored in `alt`, namely the address of `y`. The increment through the new destination changes `y` from $12$ to $16$. The final pair is $(3,16)$.
