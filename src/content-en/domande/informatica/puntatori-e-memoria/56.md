`first` and `last` delimit a possibly empty slice of the same array. `last` is the exclusive end. Which pair of operations reads the final element only when one exists?

- `if (first != last) value = first[0];`
- `if (first == last) value = *first;`
- `if (first != last) value = last[-1];`
- `if (first != last) value = *last;`

## Explanation

A nonempty slice satisfies `first != last`. Inside that branch, `last - 1` designates the last included element, and `last[-1]` reads its value. `first[0]` designates the first element, which coincides with the last only for a slice of length one.
