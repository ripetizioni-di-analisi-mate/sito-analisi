With `<stdlib.h>` included, a representable size and a successful `malloc` call, what value does `p[3]` hold after this fragment?

```c
int *p = malloc(4 * sizeof *p);
p[0] = 2;
p[1] = p[0] + 3;
p[2] = p[1] + 2 * p[0];
p[3] = p[2] - p[1];
```

- $9$
- $4$
- $2$
- $5$

## Explanation

`p[0]` receives $2$. The code uses that initialized cell to make `p[1]` equal $2+3=5$. The third write gives $5+2\cdot2=9$. The last subtracts two existing values and assigns $9-5=4$ to `p[3]`.
