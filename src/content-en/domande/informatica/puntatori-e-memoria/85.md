An algorithm receives two separately allocated buffers. A cursor stays within each buffer’s bounds. The distances already travelled by the cursors are to be compared in elements. Which computation uses only defined pointer differences, assuming the results are representable?

- Subtract `base2` from both cursors.
- Convert all four pointers to `char *` and subtract one cursor from the other.
- Compare `cur1 - cur2` with zero.
- Compare `cur1 - base1` with `cur2 - base2`.

## Explanation

Each distance is measured within its own array by subtracting the corresponding base from its cursor. The resulting element counts can then be compared as integers. Changing the pointer type does not turn two separate allocations into one array.
