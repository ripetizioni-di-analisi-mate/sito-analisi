Declare `int a = 2, b = 9; int *p = &a;`. Execute `redirect(&p, &b);` and `(*p)++;`. What is the pair $(a,b)$?

```c
void redirect(int **position, int *next)
{
    *position = next;
}
```

- $(3,9)$
- $(2,9)$
- $(2,10)$
- $(10,10)$

## Explanation

`&p` designates the caller’s pointer variable. The write through `*position` thus modifies `p`, which takes the address of `b`. In `(*p)++`, `b` increases from $9$ to $10$, while `a` stays at $2$. The result is $(2,10)$.
