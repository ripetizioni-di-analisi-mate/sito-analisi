With `<string.h>` included, all the bytes of an integer are saved and then restored to the same object. What value is guaranteed for `x` at the end?

```c
int x = 37;
unsigned char image[sizeof x];
memcpy(image, &x, sizeof x);
x = -1;
memcpy(&x, image, sizeof x);
```

- $0$
- $37$
- $-1$
- It depends on the machine’s byte order.

## Explanation

The first copy saves the complete representation of 37 in a separate array. The next assignment changes `x` while `image` retains those bytes. The second copy restores them in the same order to the same type of object. The machine’s byte order need not be known.
