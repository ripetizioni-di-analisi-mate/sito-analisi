A function swaps two integer values using a temporary variable. What does `x` hold after `exchange(&x,&x)` if initially `x = 7`?

```c
void exchange(int *a, int *b) {
    int old = *a;
    *a = *b;
    *b = old;
}
```

- $0$
- $7$
- The call always needs two distinct addresses for its result to be defined.
- $14$

## Explanation

`old` saves 7 before either write. The next assignment copies `x` to itself through the two pointers. The last writes 7 back into the same cell. These operations occur in successive statements, and the function imposes no distinctness requirement on its arguments.
