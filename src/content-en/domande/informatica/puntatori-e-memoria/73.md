With `<stdlib.h>` included, one `double` is to be allocated, initialized, and then read. Assuming `malloc` succeeds, which pair of operations after the declaration performs that sequence?

```c
double *p = malloc(sizeof *p);
```

- `double x = *p; *p = 1.25;`
- `*p = 1.25; double x = *p;`
- `double x = 1.25; x = *p;`
- `double x = sizeof *p; *p = 1.25;`

## Explanation

The allocation provides suitable storage for the `double`. Assignment through `p` stores the value, and the following initialization of `x` reads that value. `sizeof *p` would measure the size of the type rather than read the stored number.
