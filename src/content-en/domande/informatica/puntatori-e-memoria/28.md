Using the function shown, execute `int *a = counter();`, `int old = *a;` and `int *b = counter();` in order. Calculate `*a + *b - old`.

```c
int *counter(void)
{
    static int count = 4;
    ++count;
    return &count;
}
```

- $5$
- $12$
- $7$
- $6$

## Explanation

The object `count` has static storage duration. The first call changes it to $5$ and `old` copies its value. The second call changes the same object to $6$. Both pointers designate it, so the expression evaluates to $6+6-5=7$.
