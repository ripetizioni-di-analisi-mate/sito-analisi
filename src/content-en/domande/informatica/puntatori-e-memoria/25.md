With the declarations `int a[3], b[3];`, how is evaluation of `(a + 1) - (b + 1)` classified?

- Undefined behavior.
- Implementation-defined byte distance.
- Element distance equal to zero.
- Element distance equal to one.

## Explanation

Pointer subtraction is defined between positions of the same array, possibly including its one-past-the-end boundary. The operands in this example come from separate arrays, so the precondition is absent. The memory layout of those objects does not change the classification.
