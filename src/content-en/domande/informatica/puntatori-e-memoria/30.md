With `<stdlib.h>` included and assuming allocation succeeds, which argument releases the block when passed to `free` after these statements?

```c
int *p = malloc(sizeof *p);
int *q = p;
p = NULL;
```

- `p`
- `q`
- `&q`
- `NULL`

## Explanation

Initializing `q` copies the address returned by `malloc`. Storing `NULL` in `p` affects that variable and the block remains alive. `q` holds the starting address required by `free`. A null argument does not end the lifetime of any block.
