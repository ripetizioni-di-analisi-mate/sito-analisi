With `<stddef.h>` available, use `int a[2] = {3, 8};` and call the following function as `first(a, 0)`. What value is returned?

```c
const int *first(const int a[], size_t n)
{
    return n > 0 ? &a[0] : NULL;
}
```

- `a + 1`
- `a + 2`
- `a`
- `NULL`

## Explanation

When `n` is zero the condition of the conditional operator is false. The expression `NULL` is evaluated, yielding the null pointer of the return type. The selection finishes without reading a cell.
