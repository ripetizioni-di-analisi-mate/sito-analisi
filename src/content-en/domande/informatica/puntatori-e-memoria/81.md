In the function `void inspect(int m[3][5])` the parameter provides access to a matrix with rows of five integers. What is `sizeof *m / sizeof **m`?

- $15$
- $5$
- $3$
- It depends on the size of a pointer.

## Explanation

`*m` designates the first row, an array of five integers. `**m` designates one element of that row, an `int`. Dividing these sizes gives the number of elements per row. The total number of rows does not enter the calculation.
