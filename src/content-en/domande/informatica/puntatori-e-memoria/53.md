With this `typedef`, which operation is allowed after `p` has been initialized?

```c
typedef int *Link;
int x = 3, y = 8;
const Link p = &x;
```

- `p = &x;`
- `*p = y;`
- `p++;`
- `p = &y;`

## Explanation

`Link` names the entire pointer type. Applying `const` to that name qualifies the pointer itself, so `p` keeps the address of `x`. The pointed-to integer is still modifiable, and `*p = y` copies the value 8 into `x`.
