A constructor allocates an array of four pointers, then allocates one row at a time. The first three rows succeed and the fourth allocation fails. The pointer array is itself dynamically allocated. Which cleanup order uses the array to retrieve the row addresses?

- Release just the first row, which includes all the others.
- Release the three allocated rows, then the pointer array.
- Release the pointer array and then use it to retrieve the three row addresses.
- Release only the pointer array.

## Explanation

Each successful request creates a separate block. The three row addresses are stored in the outer array, which must stay alive while those addresses are read. Once the rows have been released, the table can be released too. The failed request produced no fourth row.
