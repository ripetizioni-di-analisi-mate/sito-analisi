A program allows an empty sequence to be represented by `(NULL,0)`. Which start to `sum(const int *a, size_t n)` handles that case before performing pointer arithmetic?

- `const int *end = a + n;`
- `int total = a[0];`
- `const int *next = a + 1;`
- `if (n == 0) return 0;`

## Explanation

The length is sufficient to recognize the empty sequence. The early return gives the empty sum, zero, without using `a`. For positive `n`, the contract must instead supply a valid pointer to a sequence of at least `n` elements.
