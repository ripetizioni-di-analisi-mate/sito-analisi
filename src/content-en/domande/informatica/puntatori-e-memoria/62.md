The same cell is used for both output parameters. What does `x` hold when the call returns?

```c
void split(int total, int *first, int *second) {
    *first = total / 2;
    *second = total - *first;
}
void example(void) {
    int x = 0;
    split(9, &x, &x);
}
```

- $5$
- $0$
- $4$
- $9$

## Explanation

The first statement writes the integer quotient of 9 by 2, namely 4, into `x`. The next statement reads that 4 through `first` and writes $9-4=5$ into the same cell through `second`. The two intermediate results occupy the cell at different times.
