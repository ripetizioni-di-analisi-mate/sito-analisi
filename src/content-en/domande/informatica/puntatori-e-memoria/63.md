The second parameter of `measure` is optional. With `<stddef.h>` included, what is the pair `(score,saved)` after these calls?

```c
#include <stddef.h>

int measure(int x, int *out) {
    if (out != NULL) *out = x * x;
    return x + 1;
}
void example(void) {
    int saved = 0;
    int score = measure(3, &saved);
    score += measure(4, NULL);
}
```

- $(9,9)$
- $(5,9)$
- $(9,16)$
- $(7,0)$

## Explanation

The first call returns 4 and records $3^2=9$ in `saved`. The second returns 5 and skips the write because its output pointer is null. Thus `score` is $4+5=9$ and the recorded value remains 9.
