An operation must replace two dynamic buffers together. If preparing the second new buffer fails, both originals must still be available and unchanged. Which strategy satisfies the specification?

- Resize the first original directly and assume its old address can always be recovered.
- Replace the first original as soon as its new block is ready.
- Release both originals before the first request.
- Prepare two separate new blocks and replace the originals only after both preparations succeed.

## Explanation

Both replacements need a single commit point. Preparing the new blocks separately means that failure requires releasing only the temporary blocks already obtained. The original pointers and data remain available. Ownership is transferred and the old blocks are released only after the second preparation succeeds.
