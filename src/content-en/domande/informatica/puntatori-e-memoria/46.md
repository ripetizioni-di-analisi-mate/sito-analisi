A sensor stores six readings in one array. What difference does this code assign to `d`?

```c
int a[] = {3, 8, 5, 17, 11, 19};
const int *centre = a + 2;
int d = centre[2] - centre[-1];
```

- `3`
- `8`
- `-3`
- `6`

## Explanation

The reference pointer is `&a[2]`. Moving forward two positions reaches `a[4]`, whose value is 11. Moving back one position reaches `a[1]`, whose value is 8. Both indices refer to elements of the same array, so the difference is $11-8=3$.
