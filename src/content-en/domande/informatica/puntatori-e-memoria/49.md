An address table maps three channels to two counters. What is the value of `y` after channels 0 and 2 are updated?

```c
int x = 3, y = 4;
int *channel[] = {&y, &x, &y};
*channel[0] += 2;
*channel[2] *= 3;
```

- $18$
- $14$
- $12$
- $6$

## Explanation

Slots 0 and 2 both hold `&y`. The first write changes `y` from 4 to 6. The second uses that same 6 and multiplies it by 3 to obtain 18. The table has more slots than there are distinct counters.
