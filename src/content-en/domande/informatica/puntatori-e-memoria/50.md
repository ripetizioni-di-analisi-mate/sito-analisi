Two measurements start with the same value. What is the result of `(p == q) + (*p == *q)` with these declarations?

```c
int a[2] = {14, 14};
int *p = &a[0], *q = &a[1];
```

- $0$
- $2$
- $1$
- It depends on `sizeof(int)`.

## Explanation

The pointers designate two different elements of the same array, so the first comparison yields 0. The second reads the two cells, both of which hold 14, and yields 1. In C the sum of the comparison results is therefore $0+1$.
