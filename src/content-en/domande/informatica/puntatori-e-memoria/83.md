During a single program run, a module must save three `int` readings for later retrieval, even the next day. The caller may reuse its array immediately. Which implementation guarantees that the three original values can still be retrieved?

- Retain the separate addresses of the three elements.
- Copy the three values into a module-owned array that stays alive until they are read back.
- Retain only a `const int *` to the first element of the caller’s array.
- Copy the starting pointer and length into a structure.

## Explanation

A snapshot must preserve the values that existed when it was taken. Giving the values independent cells that remain alive meets that requirement. A view, even one of type `const int *`, still refers to the caller’s cells and observes their updates.
