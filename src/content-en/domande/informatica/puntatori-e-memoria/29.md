The fragment is inside a function. What is the result of the read used to initialize `result`?

```c
int value = 31;
int *out;
{
    int *copy = &value;
    out = copy;
}
int result = *out;
```

- $0$
- $1$
- $31$
- Undefined behavior.

## Explanation

The inner block contains the pointer variable `copy`. Before leaving the block, `out` copies its value, which designates `value` in the outer block. The lifetime of `value` is still in progress at the time of the read. Dereferencing therefore returns $31$.
