A function contains a `static` pointer variable with no explicit initializer. Before any assignment in the program, which state is guaranteed?

```c
static int *selected;
```

- `selected` holds a null pointer value.
- `selected` points to a static integer holding zero.
- `selected` receives a new address on each call.
- Its initial value must be inferred from the bit representation of addresses.

## Explanation

An object with static storage duration is initialized even when no explicit initializer is supplied. For a pointer type, the rule gives it a null pointer value. This guarantee concerns the value and holds regardless of its representation in memory.
