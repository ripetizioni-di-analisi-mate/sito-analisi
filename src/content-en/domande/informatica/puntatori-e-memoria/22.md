What value does `sum` have after the backward traversal?

```c
const int a[] = {1, -2, 8, 3, 4, -1};
const int *p = a + 6;
int sum = 0;
while (p != a + 3) {
    --p;
    sum += *p;
}
```

- $14$
- $6$
- $3$
- $5$

## Explanation

`p` starts at the one-past-the-end position. Each iteration steps back before reading, so the visited indices are $5$, $4$ and $3$. The reads give $-1$, $4$ and $3$. The sum is $-1+4+3=6$. Once `p` reaches `a + 3`, the next test stops the loop.
