A budget counts requested storage only and provides $57$ C bytes. Reserve two separate blocks. The first holds $4$ elements of $6$ C bytes each, and the second holds $3$ elements of $8$ C bytes each. How many C bytes remain in the budget?

- $9$
- $24$
- $33$
- $0$

## Explanation

The first block needs $4\cdot6=24$ C bytes. The second needs $3\cdot8=24$ C bytes. Together they use $48$ of the available $57$ C bytes. The remainder is $57-48=9$ C bytes.
