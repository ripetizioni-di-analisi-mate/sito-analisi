The function returns the pointer only after initializing the block. If allocation succeeds, when does the lifetime of the block end?

```c
#include <stdlib.h>

int *make_count(void) {
    int *r = malloc(sizeof *r);
    if (r != NULL) *r = 12;
    return r;
}
void example(void) {
    int *count = make_count();
    if (count != NULL) free(count);
}
```

- When 12 is written to the block.
- When `return r` executes, before the pointer value is copied.
- When the caller executes `free(count)`.
- When the local variable `r` reaches the end of its lifetime.

## Explanation

The automatic lifetime of `r` belongs to the variable that holds the address. The block has allocated storage duration, and the pointer value is returned to the caller. On the successful path the block stays alive until the call to `free(count)`.
