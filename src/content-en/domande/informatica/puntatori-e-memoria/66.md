With `<stddef.h>` included, `probe(1, NULL)` is evaluated. What is the value of the comparison performed in the innermost call?

```c
#include <stddef.h>

int probe(int depth, const int *outer) {
    int cell = 5;
    if (depth == 0) return outer == &cell;
    return probe(depth - 1, &cell);
}
```

- It depends on which way the stack grows.
- $1$
- $0$
- $5$

## Explanation

The outer call is still active when the inner call evaluates the comparison. Each call has its own automatic variable `cell`. `outer` points to the outer one and `&cell` points to the inner one. These distinct, simultaneously live objects yield different pointers here.
