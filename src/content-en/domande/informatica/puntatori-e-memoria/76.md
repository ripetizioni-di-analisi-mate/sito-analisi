`p` is the sole owner of a valid allocated block. The caller executes `clear(&p)` twice using this function. How many of the two calls to `free` actually release that block?

```c
#include <stdlib.h>

void clear(int **slot) {
    free(*slot);
    *slot = NULL;
}
```

- Two.
- It depends on the block size.
- Neither.
- One.

## Explanation

The first call reads the still-valid address, releases the block, and stores `NULL` in the caller’s pointer. On the second call `*slot` therefore holds `NULL`. The corresponding `free(NULL)` is permitted and has no block to release.
