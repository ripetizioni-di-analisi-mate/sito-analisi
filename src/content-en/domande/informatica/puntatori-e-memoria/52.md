A local table must retain the addresses of counters `x` and `y` for its entire lifetime. Code must be able to increment the counters through the table. Which declaration enforces both requirements through its types?

- `int *const t[2] = {&x,&y};`
- `const int *const t[2] = {&x,&y};`
- `int *t[2] = {&x,&y};`
- `const int *t[2] = {&x,&y};`

## Explanation

In `int *const` the qualifier applies to the pointer. Each table slot therefore keeps the address assigned during initialization. The target has type `int`, so `++*t[0]` can update `x`. Qualifying the integer instead would prevent that operation through `t`.
