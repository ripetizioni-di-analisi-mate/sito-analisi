`p` and `q` point to distinct cells containing arbitrary integers. A function must return the address of the cell with the smaller value and choose the first cell (`p`) on a tie. Which expression meets this contract for all values?

- `*p <= *q ? q : p`
- `*p < *q ? p : q`
- `*p <= *q ? p : q`
- `*p >= *q ? p : q`

## Explanation

The comparison is between values, while the result must be an address. When `*p` is smaller, the routine selects `p`. On equality, `<=` still selects `p` as required. A strict `<` would select the second cell on a tie.
