Two queue descriptors, `src` and `dst`, are distinct. The first owns a buffer through `src.data`. The second is empty, with `dst.data == NULL` and `dst.n == 0`. Ownership is transferred without copying samples. Which state allows both to be destroyed afterwards by a function that frees `data`?

- The pointer is transferred and only `src.n` is cleared, leaving both descriptors with the same address.
- Both retain the same owning pointer and length.
- `dst` takes the original pointer and length, `src.data` becomes `NULL`, and `src.n` becomes zero.
- Only the length is transferred and the original buffer is immediately released.

## Explanation

After the transfer, exactly one descriptor must own the block. `dst` retains the address and the sample count. Clearing both fields of `src` restores its empty state: destroying it calls `free(NULL)`, while destroying `dst` releases the block once.
