A table uses an array of three pointers to rows of lengths 2, 4, and 1. Each row and the table are allocated separately. If `sizeof(int *) == 8` and `sizeof(int) == 4`, how many bytes does the program request in total, excluding allocator metadata?

- $56$
- $52$
- $48$
- $28$

## Explanation

The outer table contains three pointers and therefore requests $3\cdot8=24$ bytes. The rows contain seven integers in total, accounting for another $7\cdot4=28$ bytes. The four requests sum to $24+28=52$ bytes.
