An address is saved in a `void *` variable and then converted back to its original pointer type. Which value of `level` does C17 guarantee?

```c
double level = 1.5;
void *slot = &level;
double *reading = slot;
*reading = 2.5;
```

- $1.5$
- A value that depends on the size of `void *`.
- $0$
- $2.5$

## Explanation

Converting an object pointer to `void *` and back to its original type produces a pointer that compares equal to the original. Thus `reading` designates `level`, and the write assigns 2.5 to that object. No second `double` variable is created.
