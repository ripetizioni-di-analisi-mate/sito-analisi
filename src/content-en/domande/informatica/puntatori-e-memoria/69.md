C17 permits more than one outcome for `malloc(0)`. With `<stdlib.h>` included, what can be done portably with its result without reading or writing any purported storage?

- Always use the result as the first element of a one-`int` array.
- Conclude that a null result means the system is out of memory.
- Write one byte if the pointer differs from `NULL`.
- Pass the result to `free` once.

## Explanation

For a request of size zero, the implementation may return `NULL` or a pointer that is not used to access an object. In the first case `free(NULL)` is permitted. In the second case the allocation result can be released with `free`.
