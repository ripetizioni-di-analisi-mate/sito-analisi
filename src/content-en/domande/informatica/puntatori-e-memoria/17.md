Suppose `int x = 1, y = 2;` and `int *const p = &x;` are in scope. Which single command respects the type qualifiers?

- `p = 0;`
- `p = &y;`
- `*p = 5;`
- `++p;`

## Explanation

The `const` after `*` qualifies the variable `p`. Its destination remains `x`. Because `x` has modifiable type `int`, the assignment `*p = 5;` can write to it. The other commands attempt to modify the pointer value.
