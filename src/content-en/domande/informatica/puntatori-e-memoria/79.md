A function declares `int a[7];`. Its helper must accept the address of a complete seven-integer array, with the bound 7 represented in the parameter type. Which parameter and argument pair expresses that type?

- Parameter `int p[7]` and argument `a`.
- Parameter `int **p` and argument `&a`.
- Parameter `int *p` and argument `a`.
- Parameter `int (*p)[7]` and argument `&a`.

## Explanation

`&a` has type pointer to an array of seven integers, written `int (*)[7]`. In a function type, a parameter declared as `int p[7]` adjusts to `int *p` and loses the bound from its type. A pointer to an array and a pointer to a pointer describe different objects.
