With `<stdlib.h>` included, assume the first allocation succeeds and the second fails. What is the state immediately after the release call?

```c
int *p = malloc(sizeof *p);
p[0] = 19;
int *q = malloc(sizeof *q);
free(q);
```

- One live block and value $0$ in `p[0]`.
- Two live blocks and value $19$ in `p[0]`.
- No live block.
- One live block and value $19$ in `p[0]`.

## Explanation

The first allocation starts the lifetime of the block owned by `p`, where $19$ is written. The second returns `NULL`, so it obtains no block. `free(q)` receives the null value and has no effect. The original block remains alive and the stored $19$ is still present.
