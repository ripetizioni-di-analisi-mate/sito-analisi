A recursive function uses its own parameter `n` in a subtraction when a child returns. In the code shown, what does `alternate(4)` return?

```c
int alternate(int n)
{
    if (n == 0) {
        return 0;
    }
    return n - alternate(n - 1);
}
```

- $4$
- $-2$
- $10$
- $2$

## Explanation

The base gives $A(0)=0$. The suspended calls then compute $A(1)=1-0=1$, $A(2)=2-1=1$, $A(3)=3-1=2$, and $A(4)=4-2=2$. Subtraction cannot be regrouped as a sum of all the arguments.
