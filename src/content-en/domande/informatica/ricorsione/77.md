A recursive function returns the exact sum of an `int` array provided every intermediate sum is representable. The tests may use empty arrays, and their intermediate sums lie between $-100$ and $100$. Which test alone distinguishes the correct version from one that returns $1$ instead of $0$ at the empty base and uses the same addition step?

- Check that increasing the last element by one increases the result by one.
- Check that appending a zero leaves the result unchanged.
- Check that permuting the elements leaves the result unchanged.
- Check that the sum of the empty array is $0$.

## Explanation

On representable data the faulty base adds a constant $1$ to every sum. The three properties that compare two runs therefore remain true for both versions because the constant is preserved or cancels. The expected result for the empty array checks the constant directly and distinguishes the implementations.
