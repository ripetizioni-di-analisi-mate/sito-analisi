Two recursive functions A and B read a word made of `a` and `b`, one character per call. Reading `a` keeps the current function and reading `b` switches to the other. At the end A accepts and B rejects. Starting in A, which word is accepted?

- `aaab`
- `babab`
- `bbba`
- `ababa`

## Explanation

The active function changes only when a `b` is read. Two switches return to the initial state A. The word `ababa` contains two occurrences of `b`. The word `aaab` contains one `b`, while `babab` and `bbba` each contain three. Recursion terminates in every case because each call consumes one character.
