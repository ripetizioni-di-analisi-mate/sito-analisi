A tree has root A with left child B and right child C. B has only a right child D. C and D are leaves. The function visits the left child if present, then records the node, then visits the right child if present. In which order are the labels recorded?

- A, B, D, C
- B, A, D, C
- B, D, A, C
- D, B, C, A

## Explanation

Before recording A the entire left subtree must be completed. B has no left child, so it records B immediately and then visits D, recording D. On returning to A the root is recorded. Only the right subtree, consisting of leaf C, remains. Recording occurs between the two child visits.
