The array `a` contains $(5,7,2,7,9)$. Calculate `count_gt(a, 5, 7)`.

```c
#include <stddef.h>

unsigned count_gt(const unsigned a[], size_t n, unsigned limit)
{
    if (n == 0) {
        return 0u;
    }
    return count_gt(a, n - 1, limit) + (a[n - 1] > limit);
}
```

- $0$
- $1$
- $2$
- $3$

## Explanation

The return for the empty prefix is zero. Each extension adds one when the new last element exceeds `limit` and zero otherwise. The strict comparison is false for both occurrences of $7$. Only value $9$ adds one, so the result is $1$.
