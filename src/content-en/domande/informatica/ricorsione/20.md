What is the least integer `n` from $0$ through $20$ for which `jump(n)` returns $4$?

```c
unsigned jump(unsigned n)
{
    if (n < 3u) {
        return 1u;
    }
    return 1u + jump(n - 3u);
}
```

- $8$
- $10$
- $9$
- $12$

## Explanation

The function counts one for the base call and one for each subtraction of three. To return $4$ it must perform exactly three subtractions. Starting from $8$ reaches $2$ after two subtractions, whereas with $9$ the path $9,6,3,0$ contains three. Thus $9$ is the first admissible value.
