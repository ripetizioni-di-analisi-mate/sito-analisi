A recursive function reads a prefix expression. A digit is a complete expression, and a binary operator is followed by its two operand expressions. The tokens are `+ * 2 3 4 9`. After evaluating one expression starting at the first token, what are the result and the first unread token?

- Result $6$, next token `4`.
- Result $14$, next token `9`.
- Result $10$, next token `9`.
- Result $10$, no tokens remaining.

## Explanation

The first call sees `+` and requires two operands. Its first child consumes `* 2 3` and returns $6$. Its second child consumes only `4`. The root now has both values it needs and returns $6+4=10$. The following token, `9`, could belong to a separate expression.
