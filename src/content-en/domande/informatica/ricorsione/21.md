Let $n_0$ be the initial argument. Which integer quantity is nonnegative and decreases strictly at every recursive call?

```c
unsigned reduce(unsigned n)
{
    if (n <= 4u) {
        return n;
    }
    if (n % 2u != 0u) {
        return reduce(n - 3u);
    }
    return reduce(n / 2u);
}
```

- $n\bmod2$
- $n$
- $n_0-n$
- $1$

## Explanation

In the odd branch, `n > 4u` allows subtraction of three while retaining a nonnegative value. In the even branch, integer division by two also gives a strictly smaller value. Therefore $n$ is the required measure. The remainder modulo two may stay the same, for instance in the step from $8$ to $4$.
