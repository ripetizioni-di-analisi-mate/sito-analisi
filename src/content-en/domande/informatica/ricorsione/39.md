Which portable C17 statement describes the recursive return in `end_bit`?

```c
unsigned end_bit(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    return end_bit(n / 2u);
}
```

- The call is in tail position, and C17 guarantees constant physical space.
- The call is in tail position, and C17 leaves physical frame management to the implementation.
- The division in the arguments requires computation after the child returns.
- C17 requires a separate physical frame for every halving step.

## Explanation

Halving produces the argument before entering the child. On return, the received value is returned directly, so the call is in tail position. An implementation may reuse storage here. C17 specifies abstract machine behavior and leaves that implementation choice open.
