What is the outcome of `sum_empty(NULL, 0)`?

```c
#include <stddef.h>

unsigned sum_empty(const unsigned a[], size_t n)
{
    if (n == 0) {
        return 0u;
    }
    return sum_empty(a, n - 1) + a[n - 1];
}
```

- `0u`
- Undefined behavior from reading through `NULL`
- Undefined behavior from subtraction from `n`
- `1u`

## Explanation

The guard `n == 0` is true. The base branch returns before execution reaches the expression that accesses the array. The null pointer is only passed as an argument. The returned value is `0u`.
