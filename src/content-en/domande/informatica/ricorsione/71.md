A grid path goes from $(0,0)$ to $(2,2)$ by increasing exactly one coordinate by one at each step. Cell $(1,1)$ is blocked. A recursion returns zero for blocked cells and adds the contributions of valid predecessors. How many paths does it return at the destination?

- $2$
- $4$
- $3$
- $6$

## Explanation

There is one path along each boundary starting from the origin. Cell $(2,1)$ can receive a contribution only from $(2,0)$ because $(1,1)$ is blocked, so it has one path. Symmetrically $(1,2)$ has one. The destination adds the two counts to obtain $2$.
