During `sum_to(4, 0)`, consider the current arguments `n` and `acc` at the start of each call. Which mathematical expression keeps the same value in all these states?

```c
unsigned sum_to(unsigned n, unsigned acc)
{
    if (n == 0u) {
        return acc;
    }
    return sum_to(n - 1u, acc + n);
}
```

- $\mathrm{acc}+\dfrac{n(n+1)}{2}$
- $\mathrm{acc}-\dfrac{n(n+1)}{2}$
- $\mathrm{acc}+n$
- $2\,\mathrm{acc}+n$

## Explanation

When entering the child, `acc` increases by $n$. The sum of terms still to add changes from $\dfrac{n(n+1)}{2}$ to $\dfrac{(n-1)n}{2}$, a decrease of $n$. These changes cancel. The quantity equals $10$ on initial entry, and at $n=0$ it is the result.
