Among inputs from $0$ through $31$, what is the largest input that gives at most five simultaneous logical records in `halves(n)`? Count the initial call and the base case.

```c
unsigned halves(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return 1u + halves(n / 2u);
}
```

- $15$
- $8$
- $16$
- $31$

## Explanation

A maximum of five records includes the base case and at most four halving steps. After four integer divisions by two, the remaining value is the integer quotient on division by $16$. This is zero for $n$ through $15$. Starting at $16$ leaves at least one, so at least one more step is required.
