How many logical calls result from `duplicate(4)` and from `reuse(4)`, respectively? Count the initial calls and leaves.

```c
unsigned duplicate(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    return duplicate(n - 1u) + duplicate(n - 1u);
}

unsigned reuse(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned child = reuse(n - 1u);
    return child + child;
}
```

- $(16,5)$
- $(31,5)$
- $(31,4)$
- $(15,4)$

## Explanation

With `duplicate` each positive node creates two children even though their arguments match. For `n = 4u` the levels contain $1$, $2$, $4$, $8$, and $16$ nodes, for a total of $31$. In `reuse`, the result of the single child is saved and used twice. The calls along the sole path have arguments $4$, $3$, $2$, $1$, and $0$, for five invocations.
