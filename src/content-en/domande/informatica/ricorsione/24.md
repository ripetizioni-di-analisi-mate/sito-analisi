Let $S(n)$ be the result of `sum_even(n)` for $n$ from $0$ through $20$. For $n>0$, the induction hypothesis is $S(n-1)=(n-1)n$. Which relation completes the induction step?

```c
unsigned sum_even(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return 2u * n + sum_even(n - 1u);
}
```

- $S(n)=2n+n(n+1)$
- $S(n)=(n-1)n$
- $S(n)=(n-1)(n+2)$
- $S(n)=2n+(n-1)n=n(n+1)$

## Explanation

The induction hypothesis gives the value of the call with argument $n-1$. The return statement adds the new even term $2n$. The sum factors as $n(2+n-1)=n(n+1)$, the required formula at step $n$.
