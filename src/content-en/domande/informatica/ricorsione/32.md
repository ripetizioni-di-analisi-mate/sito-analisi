For `weighted_tree(4)`, count the multiplications and additions in the source return expressions together. Count each evaluated operator in the logical model.

```c
unsigned weighted_tree(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned left = weighted_tree(n - 1u);
    unsigned right = weighted_tree(n - 1u);
    return left + 2u * right;
}
```

- $30$
- $15$
- $31$
- $62$

## Explanation

The nodes with positive arguments occupy levels zero through three, giving $1+2+4+8=15$ nodes. Each evaluates a multiplication and an addition in its return expression. The total is $2\cdot15=30$. The sixteen leaves return a constant, so they add no operations of the specified kinds.
