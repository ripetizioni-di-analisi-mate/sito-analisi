A function counts inversions in an array, that is, index pairs $i<j$ with $a[i]>a[j]$. For the array `{2,4,1,3}` it calls itself on the halves `{2,4}` and `{1,3}`. How many inversions must the caller add to the two child results to obtain the total?

- $0$
- $3$
- $2$
- $4$

## Explanation

Each half is increasing, so both child calls return zero. The remaining pairs have their first element on the left and their second on the right. The value $2$ exceeds only $1$, while $4$ exceeds both $1$ and $3$. These three inversions cross the split and can only be counted by the caller.
