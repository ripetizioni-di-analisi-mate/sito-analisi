What is the smallest input from $0$ through $12$ that reaches the base branch with argument $2$ after at least one recursive call?

```c
unsigned bands(unsigned n)
{
    if (n < 3u) {
        return n * n;
    }
    return 1u + bands(n - 3u);
}
```

- $2$
- $3$
- $5$
- $4$

## Explanation

To reach `n = 2u` after a descent, the initial value must get past the base guard and have remainder two modulo three. Input $2$ stops immediately. Inputs $3$ and $4$ lead to $0$ and $1$, respectively. Input $5$ is the first that makes a child call with argument $2$.
