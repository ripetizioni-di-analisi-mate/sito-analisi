In the same program, starting from its initial state, `unsigned a = stamp(2);` is executed and then, in a separate statement, `unsigned b = stamp(1);`. Which values are obtained?

```c
unsigned stamp(unsigned n)
{
    static unsigned seen;
    ++seen;
    if (n == 0u) {
        return seen;
    }
    return stamp(n - 1u);
}
```

- $(3,2)$
- $(3,5)$
- $(1,1)$
- $(2,3)$

## Explanation

The single object `seen` has static storage duration and is shared by every invocation. The first request visits $2,1,0$, so its base reads $3$. The second starts with the same counter and visits $1,0$, bringing it to $5$. Each return propagates the value read by its base call.
