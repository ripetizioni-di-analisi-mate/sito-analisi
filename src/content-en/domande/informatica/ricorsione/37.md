Start `collect(9, 2)`. What are the pairs $(n,\mathrm{acc})$ of the first two calls after the initial call, in order?

```c
unsigned collect(unsigned n, unsigned acc)
{
    if (n <= 1u) {
        return acc + n;
    }
    return collect(n - 2u, acc + n);
}
```

- $(7,9),(5,16)$
- $(7,11),(5,18)$
- $(7,9),(5,14)$
- $(8,11),(7,19)$

## Explanation

From state $(9,2)$ the new argument drops to $7$, and the accumulator is $2+9=11$. The update adds the old `n`. On the next step, the new argument is $5$ and the accumulator is $11+7=18$.
