We recursively test whether all array elements satisfy a predicate $P$. The step returns `P(first) && all(suffix)`. What must the empty case return for the contract to hold even when a nonempty array contains only elements satisfying $P$?

- The opposite of the preceding call’s result.
- True.
- The predicate value for the first element of the empty array.
- False.

## Explanation

An empty array contains no element that violates the predicate. Also, a single valid element must give true after being combined with the result for its empty suffix. The identity for conjunction is true. A false base would make even an entirely valid sequence return false.
