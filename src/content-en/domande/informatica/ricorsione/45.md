Assume `UINT_MAX = 65535`. What is the largest `n` from $0$ through $10$ for which the exact factorial is obtained with no modular reduction in any product?

```c
unsigned factorial(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    return n * factorial(n - 1u);
}
```

- $7$
- $9$
- $10$
- $8$

## Explanation

The base case gives one, and while each product is representable, the return sequence gives the argument's factorial. We have $8!=40320$, which fits the limit, whereas $9!=9\cdot40320=362880$ exceeds it. Factorials increase for these arguments, and a call with $n>9$ still passes through the product at $9$.
