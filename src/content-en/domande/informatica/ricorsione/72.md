A function visits a binary tree with nine real nodes. At every real node it calls the function on both child pointers, including null pointers. A call with a null pointer returns immediately. How many of these immediate returns occur?

- $19$
- $9$
- $10$
- $18$

## Explanation

The nine nodes have $18$ child fields altogether. Exactly eight fields point to real nodes because every node other than the root has one parent. The remaining $18-8=10$ fields are null. The function invokes its base case once for each of them.
