A function searches for the first valid path in a tree, trying the left branch before the right and stopping at the first success. Root R has children A and B. A has two leaves, X which fails and Y which succeeds. B is a successful leaf. Which entry log is actually produced?

- R, A, X, Y
- R, A, B
- R, A, Y
- R, A, X, Y, B

## Explanation

R first enters A. Leaf X returns failure, so A must try Y. Its success is propagated by A back to the root. The search has already found the first valid path and does not enter B, even though B would also succeed.
