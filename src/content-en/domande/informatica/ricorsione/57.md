A Fibonacci routine caches the result for each argument, including $0$ and $1$, after the first computation. For $n\ge 2$ it uses $F_n=F_{n-1}+F_{n-2}$ and evaluates both terms. Starting with an empty cache, it computes $F_6$ and then $F_5$ using the same cache. How many arguments are computed from scratch in total?

- $6$
- $7$
- $12$
- $8$

## Explanation

Computing $F_6$ requires $F_5$ and $F_4$, and continuing reaches both base cases. Every index from $0$ through $6$ occurs, each computed just once. The second request for $F_5$ finds its result already cached. Cache lookups are distinct from computations from scratch.
