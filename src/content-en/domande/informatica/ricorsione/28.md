In `weave(4)`, what are the first three arguments after the initial call, in order of call entry?

```c
unsigned weave(unsigned n)
{
    if (n < 2u) {
        return n;
    }
    unsigned first = weave(n - 1u);
    unsigned second = weave(n - 2u);
    return first + second;
}
```

- $(3,2,0)$
- $(3,2,1)$
- $(3,1,2)$
- $(2,3,1)$

## Explanation

The first call statement starts the child with argument $3$. Its first child has argument $2$, which in turn starts the call with argument $1$ first. These are the first three calls after the root. The declarations computing the second children are reached after their respective first children return.
