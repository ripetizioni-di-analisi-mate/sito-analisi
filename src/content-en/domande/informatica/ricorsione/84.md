In `frame(2, NULL)`, each child receives the address of its caller’s automatic variable, while the initial call receives a null pointer. Which value does it return?

```c
#include <stddef.h>

int frame(int n, int *parent)
{
    int x = n;
    if (parent != NULL) {
        *parent += 10;
    }
    if (n > 0) {
        frame(n - 1, &x);
    }
    return x;
}
```

- $22$
- $2$
- $11$
- $12$

## Explanation

The initial frame creates `x = 2` and passes its address to the child with $n=1$. That child adds ten to the initial frame’s own `x`. The call with $n=0$ instead increments the `x` belonging to the frame with $n=1$. Child return values are ignored, so the initial frame returns its own `x`, equal to $12$.
