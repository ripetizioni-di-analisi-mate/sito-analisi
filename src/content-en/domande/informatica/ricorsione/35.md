How many logical calls occur for `gcd(71, 26)`? Count the initial call and the base case.

```c
unsigned gcd(unsigned a, unsigned b)
{
    if (b == 0u) {
        return a;
    }
    return gcd(b, a % b);
}
```

- $6$
- $5$
- $7$
- $8$

## Explanation

The argument pairs are $(71,26)$, $(26,19)$, $(19,7)$, $(7,5)$, $(5,2)$, $(2,1)$, and $(1,0)$. Each step before the last pair has a positive divisor, so its remainder is defined. There are six transitions to a new pair and seven calls counting the initial call.
