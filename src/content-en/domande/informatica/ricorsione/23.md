On `a = {2, 2, 5, 4, 8}`, how many times does `ordered(a, 5)` compare two array elements?

```c
#include <stddef.h>

int ordered(const int a[], size_t n)
{
    if (n < 2) {
        return 1;
    }
    return a[0] <= a[1] && ordered(a + 1, n - 1);
}
```

- $3$
- $2$
- $4$
- $5$

## Explanation

The first call compares $2$ with $2$, and the second compares $2$ with $5$. Both comparisons are true, so execution can advance. The third call compares $5$ with $4$ and gets false. Short-circuit evaluation skips its child call, leaving three comparisons between values.
