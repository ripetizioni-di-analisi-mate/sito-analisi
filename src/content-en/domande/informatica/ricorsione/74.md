Function `pick` receives a valid three-element array. For input `{1,2,4}`, what values does the array contain after `pick(a,3)`?

```c
#include <stddef.h>

void pick(int a[], size_t n)
{
    if (n < 2) {
        return;
    }
    pick(a + 1, n - 1);
    a[0] += a[1];
}
```

- $\{7,6,4\}$
- $\{3,6,4\}$
- $\{1,3,7\}$
- $\{1,2,4\}$

## Explanation

The length-one call leaves $4$ unchanged. The preceding call resumes on the suffix beginning with $2$ and writes $2+4=6$. Finally the initial frame reads the already updated $6$ and writes $1+6=7$. Reads following a return observe the changes in the shared array.
