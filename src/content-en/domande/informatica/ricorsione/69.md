To count size-$k$ subsets of a set of $n$ distinct elements, a recursion uses the sum $C(n-1,k)+C(n-1,k-1)$ when $0<k<n$. Which argument proves that each subset is counted exactly once?

- Every subset contains the last element except in base cases.
- The branches distinguish absence and presence of one fixed element.
- Each subset occurs in both branches in different orders.
- The two branches always have the same number of leaves.

## Explanation

Fix one element. A subset either excludes it or contains it. In the first case one still chooses $k$ elements from the other $n-1$. In the second one chooses $k-1$ and adds the fixed element. The two classes are disjoint and exhaust the required subsets.
