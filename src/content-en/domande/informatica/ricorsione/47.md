A function accepts integers from $-20$ through $20$. Outside its base case it replaces positive $n$ by $n-2$ and negative $n$ by $n+2$. We want to keep exactly the base values needed for every remaining step to strictly decrease $|n|$. Which set is required?

- $\{0\}$
- $\{-1,0,1\}$
- $\{-2,0,2\}$
- $\{-1,1\}$

## Explanation

From $1$ the step would go to $-1$, and from $-1$ it would go to $1$, preserving the absolute value. At $0$ neither replacement is defined. All three must therefore be base cases. For $|n|\geq2$ the new absolute value is $|n|-2$, which is strictly smaller.
