The contract for `first` returns the first occurrence, or the length when the key is absent. Which condition should replace `FOUND_IN_PREFIX`?

```c
#include <stddef.h>

size_t first(const unsigned a[], size_t n, unsigned key)
{
    if (n == 0) {
        return n;
    }
    size_t position = first(a, n - 1, key);
    if (FOUND_IN_PREFIX) {
        return position;
    }
    return a[n - 1] == key ? n - 1 : n;
}
```

- `position < n - 1`
- `position < n`
- `position == n - 1`
- `position == 0`

## Explanation

The child call has length `n - 1`. A first occurrence in that range has an index strictly smaller than its length. An index equal to `n - 1` denotes absence in the prefix. In that case, the caller still needs to examine the last element of its own range.
