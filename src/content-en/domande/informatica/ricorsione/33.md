How many logical calls occur during `visits(6)`, counting the root and base cases?

```c
unsigned visits(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned first = visits(n / 2u);
    if (n % 2u == 0u) {
        return first;
    }
    return first + visits(n / 2u);
}
```

- $4$
- $7$
- $15$
- $8$

## Explanation

Argument $6$ is even, so it produces one child with argument $3$. Node $3$ is odd and produces two calls with argument $1$. Each of these starts two calls with argument $0$. The levels therefore contain $1$, $1$, $2$, and $4$ calls, for a total of eight.
