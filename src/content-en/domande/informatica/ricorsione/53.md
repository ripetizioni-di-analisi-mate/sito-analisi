Every state has a valid successor in `next`. The function must return the number of steps to the first arrival at `goal`, or $-1$ if the budget `left`, between 0 and 20, is insufficient. Which expression completes the `return` so that each caller returns the correct distance on success and preserves failure even across several return levels?

```c
int steps(const int next[], int v, int goal, int left) {
    if (v == goal) return 0;
    if (left == 0) return -1;
    int d = steps(next, next[v], goal, left - 1);
    return /* expression */;
}
```

- `d + 1`
- `d < 0 ? 0 : d + 1`
- `d < 0 ? -1 : d`
- `d < 0 ? -1 : d + 1`

## Explanation

When the child returns a valid distance `d`, the caller has already taken the first edge and must add one. If the child returns $-1$, the remaining budget is insufficient to reach the goal, so the caller cannot return a valid distance either. The sentinel must therefore remain $-1$. Unconditional addition would turn a failure into a distance of zero.
