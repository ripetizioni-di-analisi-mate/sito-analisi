A recursive function returns a pair $(s,t)$ describing the transformation $x\mapsto sx+t$. A child call returns $(3,4)$. The caller must apply its transformation $y\mapsto 2y-1$ to the child’s result. Which pair must it return, valid for every $x$?

- $(5,3)$
- $(6,7)$
- $(6,1)$
- $(6,3)$

## Explanation

The child applies the rule $3x+4$ first. The caller receives that result and forms $2(3x+4)-1=6x+7$. The returned pair is therefore $(6,7)$. Applying the transformations in reverse order would give $3(2x-1)+4=6x+1$, which keeps the coefficient but changes the constant term.
