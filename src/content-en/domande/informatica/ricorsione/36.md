The array provides exactly $m\geq1$ readable elements. Which interval describes all initial lengths `n` for which the code examines a valid prefix and returns its maximum?

```c
#include <stddef.h>

int max_of(const int a[], size_t n)
{
    if (n == 1) {
        return a[0];
    }
    int previous = max_of(a, n - 1);
    return previous < a[n - 1] ? a[n - 1] : previous;
}
```

- $0\leq n\leq m$
- $1\leq n<m$
- $1\leq n\leq m$
- $n=0$

## Explanation

With `n` at least one, the descent reaches the base case with length one exactly. When `n` is at most `m`, every array access uses an available element. Initial value zero skips the guard and passes the value of `n - 1` converted to `size_t` to the child call, which is greater than zero. The endpoint `n == m` is usable because the largest index read is `m - 1`.
