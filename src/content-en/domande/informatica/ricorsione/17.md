Calculate `scale(4, 3)`.

```c
unsigned scale(unsigned n, unsigned acc)
{
    if (n == 0u) {
        return acc;
    }
    return scale(n - 1u, 2u * acc);
}
```

- $24$
- $48$
- $16$
- $6$

## Explanation

Each step decreases `n` by one and doubles the accumulator. The initial argument $4$ gives four doublings, from $3$ to $6$, $12$, $24$, and $48$. The call with `n == 0u` returns the final accumulator. The result is $3\cdot2^4$.
