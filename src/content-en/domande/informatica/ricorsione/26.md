How many calls in total, including the initial call and the base cases, does `split_leaves(5)` produce?

```c
unsigned split_leaves(unsigned n)
{
    if (n <= 1u) {
        return 1u;
    }
    unsigned left = split_leaves(n / 2u);
    unsigned right = split_leaves(n - n / 2u);
    return left + right;
}
```

- $9$
- $4$
- $5$
- $11$

## Explanation

Node $5$ generates nodes $2$ and $3$. Node $2$ gives two leaves with argument $1$. Node $3$ gives one leaf and another node $2$, which gives two more leaves. Thus there are five leaves and four internal nodes, for nine calls.
