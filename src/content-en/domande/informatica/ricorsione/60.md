In C17, output to standard output succeeds during `emit(2)`. Which character sequences does the language permit?

```c
#include <stdio.h>

int emit(unsigned n)
{
    if (n < 2u) {
        putchar('0' + (int)n);
        return (int)n;
    }
    return emit(0u) + emit(1u);
}
```

- Only `01`.
- Both `01` and `10`.
- One of the two digits may be omitted.
- Only `10`.

## Explanation

The root adds the results of two calls. The `+` operator requires both operands but does not specify which call runs first. Each of the two base calls prints one digit. Their numerical results always add to one, while the digit sequence depends on the chosen order.
