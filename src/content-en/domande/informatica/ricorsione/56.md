Every nonbase invocation starts exactly three calls, and all calls terminate. The computation has $12$ nonbase invocations. How many base calls are there, without knowing the depth of individual branches?

- $36$
- $37$
- $24$
- $25$

## Explanation

Every call except the root has precisely one incoming edge. The twelve internal nodes generate $12\cdot3=36$ edges, so the tree has $37$ nodes including the root. Removing the $12$ internal nodes leaves $25$ leaves. Each leaf executes a base case because every other invocation has three children.
