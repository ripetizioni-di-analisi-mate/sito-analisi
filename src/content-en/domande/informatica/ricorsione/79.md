The function below records the remainder modulo two of each positive argument, but only after its child returns. Which sequence does `digits(12)` record? All writes succeed.

```c
#include <stdio.h>

void digits(unsigned n)
{
    if (n != 0u) {
        digits(n / 2u);
        putchar('0' + (int)(n % 2u));
    }
}
```

- `110`
- `01100`
- `1100`
- `0011`

## Explanation

Descent visits $12,6,3,1,0$. The call with $0$ returns without writing. The four suspended frames write on return, in argument order $1,3,6,12$. Their respective parities are $1,1,0,0$, giving the binary representation of the initial quantity without an extra zero.
