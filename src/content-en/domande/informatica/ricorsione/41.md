Calculate the value of `path(9)`.

```c
unsigned path(unsigned n)
{
    if (n < 3u) {
        return 2u;
    }
    if (n % 2u == 0u) {
        return 1u + path(n - 2u);
    }
    return 1u + path(n - 3u);
}
```

- $5$
- $3$
- $4$
- $6$

## Explanation

Argument $9$ is odd and moves to $6$. From $6$ it moves to $4$ and then to $2$, because both of those steps start at even values. The branch at $2$ returns $2$. Each of the three recursive steps adds one, so the result is $2+3=5$.
