During `explore(4)`, while the descendant call with argument $1$ is active, what value does `saved` hold in the initial call's record?

```c
unsigned explore(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    unsigned saved = n + 2u;
    unsigned child = explore(n - 1u);
    return saved + child;
}
```

- $3$
- $4$
- $5$
- $6$

## Explanation

The initial call with argument $4$ assigns $6$ to `saved` before starting its child. Each call with a smaller argument creates its own object `saved`. While the call with argument $1$ is active, the initial record is waiting and its `saved` still holds $6$.
