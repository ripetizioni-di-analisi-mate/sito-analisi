A recursive algorithm lists the permutations of three distinct symbols. Before descending along a branch it marks the chosen symbol in `used`, which is shared across calls. What must the caller do after returning from that branch and before trying a sibling choice?

- Clear the mark of the symbol it selected at this level.
- Mark the next symbol as well before returning to the loop.
- Leave all marks and move on to the next symbol.
- Clear every mark, including those set by ancestors.

## Explanation

On entry to a level, `used` describes exactly the symbols already in the prefix. The child branch must restore its own changes in the same manner. On return, only the current caller’s choice remains to be undone. The sibling choice then sees the same starting prefix and the ancestor marks are preserved.
