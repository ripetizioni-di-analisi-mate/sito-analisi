Calculate `weighted(3)`.

```c
unsigned weighted(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    unsigned child = weighted(n - 1u);
    return 2u * child + n;
}
```

- $6$
- $11$
- $8$
- $14$

## Explanation

The base value is $0$. For $n=1$ the result is $2\cdot0+1=1$. For $n=2$ it is $2\cdot1+2=4$. The child result in the initial call is therefore $4$, giving $2\cdot4+3=11$. The doubling applies to the child result before adding the current argument.
