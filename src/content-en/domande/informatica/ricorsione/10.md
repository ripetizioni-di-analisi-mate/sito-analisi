- The base branch is reached before any recursive call.
- The base branch is reached after one recursive call.
- The base branch is never reached.
- The base branch is reached after three recursive calls.

## Explanation

The base branch requires `n == 0u`. Starting from `n = 3u`, the child receives exactly the same `n`. By induction every logical call still has argument $3$. The base condition therefore remains false.
