A procedure accepts an unsigned state `(n,fuel)`. If `n == 0u` it succeeds. Otherwise, if `fuel == 0u` it fails. In all other cases it calls itself with `(n & (n - 1u), fuel - 1u)`. What is the minimum `fuel` needed for success at `n = 82u`?

- $4$
- $3$
- $7$
- $2$

## Explanation

The operation clears the least significant one bit of a positive number. For $82=1010010_2$ the sequence is $82,80,64,0$, so three transitions suffice. Starting with three units reaches exactly $(0,0)$, which succeeds because the test of $n$ comes before the fuel test. After only two transitions, $64$ still remains.
