Complete `CONDITION` so that for every initial `n` from $0$ through $30$, the function returns the remainder on division by three by repeated subtraction, with each new argument strictly smaller than the previous one.

```c
unsigned strip(unsigned n)
{
    if (CONDITION) {
        return n;
    }
    return strip(n - 3u);
}
```

- `n == 0u`
- `n == 3u`
- `n < 3u`
- `n > 3u`

## Explanation

The possible remainders are $0$, $1$, and $2$. The condition `n < 3u` returns exactly those values and allows recursion for every `n` at least three. In that branch, subtraction is representable and preserves the remainder modulo three. Starting from `n = 1u` also distinguishes the correct guard from one that stops only at zero.
