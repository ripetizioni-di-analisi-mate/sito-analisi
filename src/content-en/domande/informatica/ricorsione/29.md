For which proposed argument does the first child receive a value greater than the initial argument? Analyze only the first subtraction, without running the full recursion.

```c
unsigned decrease(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    return decrease(n - 3u);
}
```

- $3$
- $4$
- $5$
- $2$

## Explanation

Input $2$ passes the base guard and subtracts three in type `unsigned`. The result is reduced modulo the number of values in the type, so the child argument is `UINT_MAX`, above two. For the other proposed inputs, the first subtraction gives $0$, $1$, and $2$, each smaller than its initial value.
