A mathematical model uses exact nonnegative rationals and handles $x$ by calling itself on $x/2$. Its only base case is $x=0$. Starting from $x=1$, which conclusion about termination is correct?

- The base is reached because the values decrease and are bounded below.
- The base is reached because each division removes a fractional binary digit.
- The base is reached as soon as the value drops below one.
- The base is never reached after any finite number of steps.

## Explanation

After $k$ descending calls the value is $2^{-k}$, positive for every finite integer $k$. The sequence converges to zero without taking the value zero. A decreasing rational measure bounded below can therefore admit an infinite descent. The criterion based on natural-number measures rules out precisely this possibility.
