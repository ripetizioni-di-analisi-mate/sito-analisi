When $n>0$, a function calls itself twice in sequence, first on $n-1$ and then on $n$. At $n=0$ it returns immediately. Which statement identifies the flaw in the argument “the first child has a smaller argument, so the root terminates”?

- The base case should also start two children.
- Having two children always prevents termination.
- To apply this descent argument, the measure must decrease for every call actually made, including the second one.
- Reversing the two children is sufficient to guarantee termination.

## Explanation

Already at $n=1$ the first child at $0$ terminates, and the second recreates state $1$. The computation can therefore repeat the same pair of actions indefinitely. Proving that one branch terminates cannot justify the return of a parent that must wait for both.
