Which sequence of characters does `visit(3)` print, assuming the write operations succeed?

```c
#include <stdio.h>

void visit(unsigned n)
{
    if (n == 0u) {
        putchar('0');
        return;
    }
    printf("%u", n);
    visit(n - 1u);
    printf("%u", n);
}
```

- `3210321`
- `3210`
- `30123`
- `3210123`

## Explanation

Before the child calls, the function prints $3$, $2$, and $1$. The base branch prints $0$ and returns to the call with argument $1$. On return, the calls with arguments $1$, $2$, and $3$ resume in that order at their second print statement. The complete sequence is `3210123`.
