What does `digit_total(5048)` return?

```c
unsigned digit_total(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return n % 10u + digit_total(n / 10u);
}
```

- $12$
- $13$
- $17$
- $5048$

## Explanation

For a nonnegative integer, `n % 10u` gives the last decimal digit and `n / 10u` removes that digit. The calls with $5048$, $504$, $50$, and $5$ add $8$, $4$, $0$, and $5$, respectively. The next argument is zero, and the result is $8+4+0+5=17$.
