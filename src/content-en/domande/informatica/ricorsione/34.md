The three elements of `a` are $2$, $0$, and $7$. Calculate `assemble(a, 3)`.

```c
#include <stddef.h>

unsigned assemble(const unsigned a[], size_t n)
{
    if (n == 0) {
        return 0u;
    }
    return 10u * assemble(a, n - 1) + a[n - 1];
}
```

- $207$
- $27$
- $702$
- $9$

## Explanation

The empty prefix gives $0$. The one-digit prefix gives $10\cdot0+2=2$. The second prefix gives $10\cdot2+0=20$, even though the new digit is zero. Extending it with the last element gives $10\cdot20+7=207$.
