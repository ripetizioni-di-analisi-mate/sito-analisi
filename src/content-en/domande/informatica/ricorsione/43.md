How many `*` operators are evaluated in return expressions during `power3(5)`, in a logical count of the source program?

```c
unsigned power3(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned half = power3(n / 2u);
    if (n % 2u == 0u) {
        return half * half;
    }
    return 3u * half * half;
}
```

- $3$
- $5$
- $4$
- $6$

## Explanation

The arguments are $5$, $2$, $1$, and $0$. The base case contains no multiplication. The odd branch at $1$ has two `*` operators, the even branch at $2$ has one, and the odd branch at $5$ has two. The total is $2+1+2=5$.
