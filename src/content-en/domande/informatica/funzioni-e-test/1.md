- `int limit(int value, int maximum);`
- `void limit(int value, int maximum);`
- `int limit(int value);`
- `int limit(double value, int maximum);`

## Explanation

The type before `limit` specifies the result and must be `int`. The list contains two parameters in the required order, `value` and `maximum`, both declared as `int`. The semicolon ends the declaration. Changing the return type, the number of parameters, or the first parameter type changes the required interface.
