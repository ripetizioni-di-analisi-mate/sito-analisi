What is the value of `status(2)`?

```c
_Bool status(int x)
{
    return x - 4;
}
```

- $-2$
- $0$
- $1$
- $-1$

## Explanation

The body first evaluates `x - 4` with `x = 2` and obtains the integer `-2`. The return type is `_Bool`. A conversion to this type produces `0` for a value equal to zero and `1` for every nonzero value. The returned value is therefore `1`.
