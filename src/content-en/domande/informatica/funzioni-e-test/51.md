A public interface in `measure.h` declares `double measure(int);`. The caller includes it, but the author of the definition accidentally writes `int measure(int n) { return n; }` in a second source file. Which change makes the conflict directly diagnosable when compiling that second file?

- Cast the result to `double` in the caller.
- Compile the caller's file first.
- Rename parameter `n` to `value`.
- Include `measure.h` before the definition as well.

## Explanation

The header and the definition become declarations of the same function visible in one translation unit. Their return types, `double` and `int`, are incompatible, so the compiler must issue a diagnostic. Compiling separate source files in a different order does not create this local comparison.
