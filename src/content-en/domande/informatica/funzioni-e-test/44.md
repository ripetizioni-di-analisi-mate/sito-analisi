In a new run, four separate statements call `saved_total(0)`, `saved_total(1)`, `saved_total(0)`, and `saved_total(1)`. What does the fourth call return?

```c
int saved_total(int accepted)
{
    static int total = 9;
    if (!accepted) {
        return total;
    }
    total -= 2;
    return total;
}
```

- $5$
- $1$
- $7$
- $9$

## Explanation

The first and third calls take the initial branch and return the stored value without updating it. The second and fourth each subtract `2` from the single static object `total`. The returned values are therefore `9`, `7`, `7`, and `5`.
