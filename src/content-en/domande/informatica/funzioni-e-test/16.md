With the definition visible, what does `blend(8.9, -3.7)` return?

```c
int blend(int a, int b)
{
    return a - b;
}
```

- $11$
- $10$
- $12$
- $13$

## Explanation

The floating-point arguments are converted to `int` when passed to the parameters. Both truncated values are representable. The argument `8.9` becomes `8` and `-3.7` becomes `-3` because truncation is toward zero. The subtraction gives $8-(-3)=11$.
