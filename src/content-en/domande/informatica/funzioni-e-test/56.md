Given the prototype `int poll(void);`, the function records an event each time it is called. The event counter starts at zero. After the statements below, what value must the counter hold?

```c
(void)sizeof poll();
(void)poll();
```

- The count is indeterminate.
- $2$
- $0$
- $1$

## Explanation

In `sizeof poll()` the operand has ordinary type `int`, so the call expression is not evaluated. The second statement does evaluate the call even though `(void)` discards its result. Exactly one event is therefore recorded.
