A function must return 1 exactly on the first call after a reset. Two independent test cases each expect 1 on their first call. They pass individually, but the second fails when both follow the same reset. How should the two cases be set up according to the specification?

- Repeat the entire suite until two results of 1 are obtained.
- Check only that the two calls terminate.
- Reset the state before each case and separately test a sequence of two calls.
- Change the expected first call after every reset to 0.

## Explanation

Each isolated case assumes a freshly reset state. With a single reset the second case observes a different history. The sequence with one reset is itself a valid test, but its expected results are 1 followed by 0.
