For integers `amount` from $0$ to $100$, which remainders of `amount` on division by $3$ make `adjust` return $1$?

```c
int units(int amount)
{
    return amount / 3;
}

int adjust(int amount)
{
    return units(amount + 2) - units(amount);
}
```

- $\{0\}$
- $\{1,2\}$
- $\{0,1\}$
- $\{2\}$

## Explanation

Write $\mathrm{amount}=3q+r$ with remainder $r$ from $0$ to $2$. The call `units(amount)` yields $q$. After increasing the amount by $2$, the quotient increases by one exactly when $r+2\geq3$. This holds for $r=1$ and $r=2$, so the difference is $1$ in those two cases.
