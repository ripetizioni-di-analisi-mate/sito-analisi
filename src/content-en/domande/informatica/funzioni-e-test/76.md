A function must grant permission if and only if both flags `member` and `verified` are true. The suite contains (0,0), (1,0) and (0,1), and all expected results are met. Which additional test distinguishes the specification from a body that always returns 0?

- `(1,1)`, expected 1
- `(1,0)`, expected 0
- `(0,1)`, expected 0
- `(0,0)`, expected 0

## Explanation

The existing tests observe each flag at both zero and one, but never set both to one together. The conjunction is 1 exactly for the pair (1,1). The constant implementation therefore fails only for that combination.
