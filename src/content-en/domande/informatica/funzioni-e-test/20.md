In a new run, three separate statements call `score(4)`, `score(-1)`, and `score(0)`. What does the third call return?

```c
int score(int x)
{
    static int calls = 0;
    int start = 10;
    ++calls;
    return start + calls + x;
}
```

- $11$
- $13$
- $16$
- $10$

## Explanation

Each call initializes `start` to `10`. The object `calls` has static storage duration and retains its count, so the three increments give `1`, `2`, and `3` in order. The final argument is `0`, so the last result is $10+3+0=13$.
