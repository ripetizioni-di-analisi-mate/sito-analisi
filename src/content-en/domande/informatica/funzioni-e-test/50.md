Each call must record one visit and return 1 for positive `n` and 0 otherwise. Two separate calls with `2` and `-1` return the expected results. Starting with `visits == 0`, which additional check exposes the defect?

```c
static int visits;
int classify(int n)
{
    if (n > 0) return 1;
    ++visits;
    return 0;
}
```

- Expect 2 visits after both calls.
- Expect 1 visit after both calls.
- Check that the second result is even.
- Check that the first result is positive.

## Explanation

The positive branch returns before the increment. Only the call with −1 reaches `++visits`, so the actual count is 1. The oracle for the side effect requires 2 and tests a part of the contract that the two return values leave unobserved.
