A module `read_code` must translate character `'B'` into integer 2. Module `cost` must map code 2 to 7. An end-to-end test records `'B' → 3 → 7`. What conclusion follows from this single trace?

- The first stage violates its contract, and the test does not exercise `cost(2)`.
- The result 7 proves that `cost(2)` returns 7.
- Both stages satisfy their contracts because the final result is 7.
- The trace proves that `cost(3)` should have returned 2.

## Explanation

For the given input the expected intermediate code is 2, whereas the trace records 3. The second stage was therefore called with 3. The final result happens to be 7, but this run gives no evidence of how `cost` behaves on input 2.
