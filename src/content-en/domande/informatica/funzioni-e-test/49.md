A sensor may produce negative `double` values between −1 and 0. The protocol requires rejecting every negative reading before discarding the fractional part. The program passes the reading to this function. Which call shows that the check happens too late?

```c
int admit(int n)
{
    return n >= 0;
}
```

- `admit(1.5)`
- `admit(0.0)`
- `admit(-0.5)`
- `admit(-2.0)`

## Explanation

The prototype converts −0.5 to `int` by truncating toward zero. Inside the function `n` is already 0, so the comparison accepts the reading. Distinguishing −0.5 from 0 requires testing the reading while it still has type `double`.
