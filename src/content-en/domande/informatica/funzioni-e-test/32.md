Start from `int n = 6;` and include `<assert.h>`. Which sequence sets `n` to `8` and continues normally both with assertions enabled and with `NDEBUG` defined at inclusion?

- `assert((n += 2) == 8);`
- `n += 2; assert(n == 8);`
- `assert(n == 8); n += 2;`
- `n += 2; assert(++n == 9);`

## Explanation

The update before the macro changes `n` from `6` to `8` in both builds. An enabled assertion then compares `8` with `8` and allows the program to continue. An update inside the macro argument would be skipped with `NDEBUG`. A check before the first update would instead compare the initial value.
