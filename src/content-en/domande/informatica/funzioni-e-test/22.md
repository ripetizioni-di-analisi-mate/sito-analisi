What do `code(-4)`, `code(1)`, and `code(3)` return, in that order?

```c
int code(int x)
{
    int r = 2;
    if (x < 0) {
        return r - x;
    }
    r += 3;
    if (x == 1) {
        return r * 2;
    }
    return r + x;
}
```

- $(6,10,8)$
- $(9,10,8)$
- $(6,6,8)$
- $(6,10,6)$

## Explanation

With `x = -4`, the first `return` gives $2-(-4)=6$. For the other two inputs, execution reaches `r += 3` and `r` is `5`. Equality with `1` selects the second return, which gives $5\cdot2=10$. With `x = 3`, execution reaches the last statement and gives $5+3=8$.
