Which pair contains two compatible declarations for the same C17 function?

- `int scale(int, double);` and `double scale(int, double);`
- `int scale(int amount, double rate);` and `int scale(int quantity, double factor);`
- `int scale(int, double);` and `int scale(double, int);`
- `int scale(unsigned, double);` and `int scale(int, double);`

## Explanation

The compatible declarations have result type `int` and parameter types `int` and `double` in the same order. Parameter names in prototypes can change without changing the function type. The other pairs differ in return type, in the order of the types, or in the type of the first parameter.
