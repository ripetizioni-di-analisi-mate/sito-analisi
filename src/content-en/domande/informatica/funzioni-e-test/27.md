What does `bill(8)` return?

```c
int basis(int units)
{
    return 2 * units + 3;
}

int cap(int amount)
{
    if (amount > 15) {
        return 15;
    }
    return amount;
}

int bill(int units)
{
    return 1 + cap(basis(units));
}
```

- $15$
- $16$
- $19$
- $20$

## Explanation

The inner function computes `basis(8)`, which is $2\cdot8+3=19$. This value is passed to `cap`, which returns `15` because `19 > 15`. Finally, `bill` adds `1` to the capped amount and returns `16`.
