A function returns the greater **integer value** of `a` and `b`, with no other effects. Compare `return a > b ? a : b;` and `return a >= b ? a : b;`. Which test based solely on the returned value distinguishes the bodies?

- A pair of distinct negative arguments.
- Exactly the pairs with `a < b`.
- No test on integer pairs.
- Any pair with `a == b`.

## Explanation

For unequal values both conditions choose the same argument. On a tie they choose different arguments, but those arguments contain the same integer. Since the contract makes only that value observable, the two bodies are indistinguishable by this test.
