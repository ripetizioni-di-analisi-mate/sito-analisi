A contract maps each integer minute from −20 to 20 to one of seven positions numbered 0 through 6, with minutes differing by 7 mapped to the same position. The origin maps to 0 and each successive minute advances one position. Which oracle is correct for input −9?

- $-2$
- $6$
- $2$
- $5$

## Explanation

Adding two periods to −9 gives 5. Both minutes must have the same position, and minute 5 corresponds to position 5. In C17 `-9 % 7` gives −2, so using the remainder directly would produce a value outside the required interval.
