The caller executes `int n = 3;` followed by `int r = advance(++n);`. What is the value of `10 * n + r` after these statements?

```c
int advance(int value)
{
    value += 2;
    return value;
}
```

- $36$
- $66$
- $45$
- $46$

## Explanation

The prefix increment changes `n` to `4` before passing its value to `advance`. The function adds `2` to the local copy and returns `6`, so `r` equals `6`. The requested expression combines the `4` retained by the caller with that result and gives $10\cdot4+6=46$.
