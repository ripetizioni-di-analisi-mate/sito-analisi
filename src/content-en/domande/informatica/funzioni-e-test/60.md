A function `clamp10(x)` must return 0 below 0, `x` from 0 through 10, and 10 above 10. The property `clamp10(clamp10(x)) == clamp10(x)` also holds for many incorrect functions. Which additional test catches **every** implementation returning a constant integer?

- Repeat `clamp10(7) == 7` twice.
- Check only that `clamp10(2)` lies between 0 and 10.
- Check only `clamp10(10) == 10`.
- Check both `clamp10(2) == 2` and `clamp10(7) == 7`.

## Explanation

A constant function would produce the same integer on both inputs. The values 2 and 7 lie in the part of the domain where the output equals the input, so their expected outputs differ. No constant can satisfy both comparisons.
