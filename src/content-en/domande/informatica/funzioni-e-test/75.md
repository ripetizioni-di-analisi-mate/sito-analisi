The correct module produces code `x` for integer inputs from 0 through 8. A faulty version produces `x+1`. The caller returns only `code >= 5`. For which input does a test of the caller alone reveal the defect?

- $5$
- $0$
- $8$
- $4$

## Explanation

The external result changes when the correct code is still below 5 and the faulty code reaches the threshold. Both `x < 5` and `x + 1 >= 5` must hold, so the only integer is 4. For the other inputs the comparison masks the internal difference.
