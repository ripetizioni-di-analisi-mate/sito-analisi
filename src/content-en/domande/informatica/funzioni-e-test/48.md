On a machine with `UCHAR_MAX == 255`, the caller executes `int r = next_byte(255);`. Which observation explains the value assigned to `r`?

```c
unsigned char next_byte(unsigned char x)
{
    return x + 1;
}
```

- The addition saturates at 255 before the return.
- The addition produces 256 and the caller receives 256.
- Converting the result causes signed overflow.
- The addition produces 256 and the return converts it to 0.

## Explanation

Every possible parameter value fits in `int`, so integer promotion makes the addition an `int` operation. The function returns an `unsigned char`, and converting 256 modulo 256 gives 0. The subsequent assignment to `int` preserves that zero.
