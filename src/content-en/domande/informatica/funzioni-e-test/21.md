Four separate statements call `left()`, `right()`, `right()`, and `left()` in order. What do the third and fourth calls return?

```c
int left(void)
{
    static int count = 3;
    return ++count;
}

int right(void)
{
    static int count = 8;
    return count++;
}
```

- $(10,5)$
- $(9,4)$
- $(9,5)$
- $(8,5)$

## Explanation

The two declarations of `count` introduce distinct static objects. The first call to `left` raises its counter to `4`. The two calls to `right` return `8` and `9` because the postfix increment yields the previous value. The final `left` performs the second prefix increment of its own counter and returns `5`.
