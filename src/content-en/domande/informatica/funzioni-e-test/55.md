The contract for `pair(a,b)` encodes the ordered pair. The first argument must be the original value of `x` and the second its successor, with `x` incremented exactly once. Initially `x == 4`. Which C17 sequence does this with defined behaviour?

- `int old = x; pair(old, old + 1);`
- `pair(x, ++x);`
- `int old = x; ++x; pair(old, x);`
- `++x; pair(x, x);`

## Explanation

The first assignment saves 4. The increment is a full expression completed before the call, so the second argument is 5 and `x` remains 5. Using `x` and `++x` as separate arguments of the same call would introduce an unsequenced read and modification.
