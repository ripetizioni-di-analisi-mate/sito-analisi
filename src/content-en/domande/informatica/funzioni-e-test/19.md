Determine the value of `read_total()`.

```c
int seed = 6;

int get_seed(void)
{
    return seed;
}

int read_total(void)
{
    int seed = 4;
    return 10 * seed + get_seed();
}
```

- $44$
- $64$
- $46$
- $66$

## Explanation

The product in `read_total` uses its local `seed`, whose value is `4`. The body of `get_seed` uses the name declared at file scope, whose value is `6`. Scope depends on where the name occurs in the source. The result is $10\cdot4+6=46$.
