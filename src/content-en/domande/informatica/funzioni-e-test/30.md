For integers $0\leq x\leq12$, `clip` must return the smaller of $x$ and $8$. Which pair (input, expected result) makes a test of the following body fail?

```c
int clip(int x)
{
    return x > 7 ? 7 : x;
}
```

- $(7,7)$
- $(9,8)$
- $(1,1)$
- $(0,0)$

## Explanation

At input $9$, the specification gives $8$ because the smaller of $9$ and $8$ is $8$. The body uses threshold `7`, so it returns `7` at input `9`. For the other inputs, all at most `7`, both the specification and the code leave the input unchanged.
