After the first call to `record()`, which statement describes the situation outside the block that declares `count`?

```c
void record(void)
{
    {
        static int count = 0;
        ++count;
    }
}
```

- The name is still in scope, and the object's lifetime has ended.
- The name is still in scope, and the object still exists.
- The name has gone out of scope, and the object still exists in the abstract machine.
- Both the name's scope and the object's lifetime have ended.

## Explanation

The name `count` has block scope, so it designates the object only within the inner block after the declaration. `static` gives the object static storage duration. The object therefore still exists after the block ends and retains its value for the next call.
