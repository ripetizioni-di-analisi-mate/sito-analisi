An old function promises to terminate and return `2*x` without side effects for every integer `x` from 0 through 9. Which new contract allows replacement while preserving the promises made to all existing callers?

- For every `x` from −5 through 15 it terminates and returns `2*x` without side effects.
- For every `x` from 0 through 9 it returns any even number and terminates without side effects.
- For every `x` from 1 through 9 it terminates and returns `2*x` without side effects.
- For every `x` from 0 through 9 it terminates, writes to a file, and returns `2*x`.

## Explanation

The replacement must accept every input allowed by the old contract. Extending the domain to −5…15 preserves that property. On the original domain, termination, result and effects are also unchanged, so callers can continue to rely on all the original promises.
