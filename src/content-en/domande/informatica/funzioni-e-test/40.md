With assertions enabled, which of the following tests fails when run individually against the given code?

```c
int buckets(int n)
{
    return n / 3 + (n % 3 != 0);
}
```

- `assert(buckets(0) == 0);`
- `assert(buckets(8) == 2);`
- `assert(buckets(6) == 2);`
- `assert(buckets(7) == 3);`

## Explanation

Nothing is added when the remainder is zero. Accordingly, `buckets(0)` gives `0` and `buckets(6)` gives `2`. The values `7` and `8` have integer quotient `2` and nonzero remainders, so both produce `3`. The comparison for argument `8` is false when the expected value is `2`.
