Every run starts in the same initial state. A deterministic function accepts only the integers −1, 0 and 1. Its contract concerns only termination and the returned value. Which test result establishes these two properties throughout the domain?

- All three calls terminate, but their results are never compared.
- All three calls terminate and every value matches its independent oracle.
- Two calls terminate and give the same result as each other.
- One call is repeated three times with the same value.

## Explanation

Here the three cases exhaust the domain and the initial state is fixed. Observing termination and checking every return against an expected value derived from the contract verifies both promises for every possible case. Termination alone would leave the correctness of the values unresolved.
