On a C17 implementation with `INT_MIN == -32768` and `INT_MAX == 32767`, a function must return the integer quotient `a / b` when it is defined. In addition to `b != 0`, which condition must the caller check?

- `!(a == INT_MAX && b == -1)`
- `!(a == INT_MIN && b == -1)`
- `a % 2 == 0`
- `a != 0`

## Explanation

Dividing −32768 by −1 would require the result 32768, greater than `INT_MAX`. With a nonzero divisor, every other pair of these `int` values has a representable truncated quotient. Zero is a valid dividend and gives a zero quotient.
