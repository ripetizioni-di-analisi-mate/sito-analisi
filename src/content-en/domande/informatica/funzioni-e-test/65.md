For integers `n` from 0 through 40, `packet(n)` returns `n / 4`. A second module logs an alarm exactly when it receives code 3. Which inputs must trigger the alarm in an integration test?

- $3,7,11,15$
- $9,10,11,12$
- $12,13,14,15$
- $12,13,14,15,16$

## Explanation

For nonnegative inputs, integer division gives 3 when the integer is at least 12 and less than 16. Those four values share the same intermediate code. With input 16 the first stage already returns 4, so the alarm must stay off.
