Which C17 declaration supplies a prototype for `ready` with an `int` result and no parameters?

- `int ready(void);`
- `int ready();`
- `int ready(int code);`
- `int ready(int code, ...);`

## Explanation

In C17, `void` alone in a prototype's parameter list specifies that the function has no parameters. An empty list in a declaration that is not a definition leaves the parameters unspecified. An `int` parameter, with or without variadic arguments after it, requires at least one corresponding argument.
