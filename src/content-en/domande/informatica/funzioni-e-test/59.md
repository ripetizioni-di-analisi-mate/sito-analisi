A function must exchange codes 0 and 1. A test applies the function twice and checks only `f(f(x)) == x` for both inputs. Which incorrect implementation nevertheless passes the entire test?

- `return 0;`
- `return 1;`
- `return x;`
- `return 2;`

## Explanation

Applying the identity twice always returns the starting point, so the property holds at both 0 and 1. The specification also requires the swap itself. A single direct check such as `f(0) == 1` distinguishes the identity from the required function.
