Two consecutive calls to `sample()` are to be replaced by a single call whose result is reused. The function terminates and takes no arguments. Which additional contract clause makes the replacement observationally equivalent in a single-threaded program?

- It always returns the same value and produces no observable effects.
- It uses only variables with block scope.
- It returns an `int` and prints nothing on the screen.
- Its body contains a single `return` statement.

## Explanation

Reuse must preserve both values read and the effects of both calls. A constant result covers the first requirement, and the absence of observable effects covers the second. Even a single `return` statement may call another function that records each access.
