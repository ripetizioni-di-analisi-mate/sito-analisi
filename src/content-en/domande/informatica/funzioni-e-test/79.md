The contract requires the absolute value for all integer inputs between −9 and 9. Tests on −1 and 2 check both results and exercise both branches of the body shown. Which input still reveals a defect?

```c
int magnitude(int x)
{
    if (x < 0) return 1;
    return x;
}
```

- $0$
- $1$
- $9$
- $-4$

## Explanation

On the negative branch the function always returns 1. Input −1 passes on that branch because its absolute value happens to be 1, but the expected value for −4 is 4. The three nonnegative inputs offered exercise the branch that correctly returns its argument.
