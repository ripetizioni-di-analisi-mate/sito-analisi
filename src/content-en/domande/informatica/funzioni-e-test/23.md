Three separate statements in the same translation unit call `add_stock(4)`, `add_stock(-2)`, and `add_stock(3)` in order. What is the final value of `stock`?

```c
static int stock = 10;

void add_stock(int value)
{
    if (value < 0) {
        return;
    }
    stock += value;
}
```

- $17$
- $15$
- $10$
- $14$

## Explanation

The first call performs the assignment and raises `stock` to `14`. The negative argument causes `return;` before the update, so the value stays `14`. The final call adds `3`, giving `17`. The function returns `void`, and the observation concerns the object it updates.
