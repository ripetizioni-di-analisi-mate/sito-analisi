Given the same initial state, `lookup(k)` is deterministic. Its contract guarantees a result only for `k` from 0 through 3. A run with `k == 5` returns −1. Which new test can **directly** decide whether the implementation violates the promise “for `k == 2` the result is 8”?

- Try 1 and 3 and average the results.
- Repeat the call with 5 and expect −1 again.
- Call it with 2 in the specified initial state and compare the result with 8.
- Call it with 8 and expect 2, reversing the mapping.

## Explanation

The promise singles out input 2 and its expected output of 8. The observation at 5 lies outside the specified domain. Reversing the mapping or interpolating between neighbours would require further properties that the contract does not state.
