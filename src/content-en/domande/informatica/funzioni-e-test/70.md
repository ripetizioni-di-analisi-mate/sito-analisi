For integer arguments from 0 to 5, the specification of `distance(a,b)` requires the absolute distance and is therefore symmetric. The implementation has not yet been verified. Tests cover only pairs with `a <= b`. What concrete defect might be missed even if all such pairs are tested?

- The body returns 1 when `a == b`.
- On inputs from 0 to 5, the body always returns `b - a` instead of the absolute distance.
- The body signals an error specifically on `(0,5)`.
- The body returns 0 for every pair with `a < b`.

## Explanation

When `a <= b`, the distance is exactly `b - a`. Testing only that half of the domain therefore lets the faulty body pass. Reversing a pair of distinct values, for example from (1,4) to (4,1), produces −3 where the specification still requires 3.
