With assertions enabled, a tester writes `assert("E17");` in a branch that should be unreachable. What happens if execution enters the branch?

- The program stops because the text contains an error message.
- The string is converted to the integer zero, so the assertion fails.
- The assertion always prints the message and continues.
- Execution continues because the address of the string differs from a null pointer.

## Explanation

In this context the string decays to a pointer to its first character. That pointer differs from a null pointer, so the condition is true. To detect entry into this branch with assertions enabled, the test can use a genuinely false condition such as `assert(0);`.
