The file containing `probe` includes `<assert.h>` after `#define NDEBUG 0`. A second file contains `main`, includes the same header without defining `NDEBUG`, and calls `probe()`. What happens on that call, assuming nothing else stops execution?

```c
int probe(void)
{
    assert(0);
    return 7;
}
```

- The outcome depends on which file is compiled first.
- The assertion in `probe` always stops the program.
- `probe()` returns 7.
- Defining `NDEBUG` to zero prevents compilation.

## Explanation

The expansion of `assert` depends on whether `NDEBUG` is defined when the header is included in the file containing the assertion. A definition with value 0 still counts as defined. The check in `probe` is disabled regardless of the configuration used to compile `main`.
