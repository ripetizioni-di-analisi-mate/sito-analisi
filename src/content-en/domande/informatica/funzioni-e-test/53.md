The three statements below execute in the order shown. Each call to `read_flag()` records one read and returns 1. If `enabled == 0` throughout the test, how many reads are recorded?

```c
(void)(enabled && read_flag());
(void)(enabled || read_flag());
(void)(read_flag() && enabled);
```

- $1$
- $2$
- $0$
- $3$

## Explanation

In the first `&&` the left operand is false, so the call is skipped. For `||` that same false value makes it necessary to evaluate the right operand, producing one read. In the third statement the call is on the left and is evaluated before `enabled` is consulted, giving two reads in total.
