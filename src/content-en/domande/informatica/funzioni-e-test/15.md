The prototype `int shelf(int slots, double unit);` is visible. In the call `shelf(6, 2)`, what are the result type and the type of the second parameter?

- `double` result and `int` second parameter
- `int` result and `int` second parameter
- `double` result and `double` second parameter
- `int` result and `double` second parameter

## Explanation

The type before `shelf` is `int` and determines the type of the call expression. The second parameter is declared as `double`, so the argument `2` is converted to `double` before the body starts. The prototype fixes the parameter type.
