A designer wants to initialise a static-storage variable using a reading taken on the first call. The version shown violates a C17 constraint. Which change implements the intended behaviour if `seed()` must be called exactly once and the program is single-threaded? Assume that `seed()` returns normally and never calls `saved_seed`, even indirectly.

```c
int seed(void);
int saved_seed(void)
{
    static int saved = seed();
    return saved;
}
```

- Remove `static` and keep `int saved = seed();`.
- Use two zero-initialised static locals and call `seed()` in the body when the initialisation flag is still zero.
- Write `static int saved = (int)seed();`.
- Add `const` to `saved` without changing the initializer.

## Explanation

A call to `seed()` is not a constant expression permitted as the initializer for this static object. The body can assign its result to `saved` and then set the flag. A separate flag works even when the first reading itself returns zero.
