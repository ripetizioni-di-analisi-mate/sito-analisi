For a time `t` from 0 through 1439 minutes, the result is an integer pair `(h,m)`. The oracle must accept exactly the hours-and-minutes representation within the day. Candidate pairs are already known to satisfy `0 <= h && h < 24` and `-100 <= m && m <= 100`. Which check suffices?

- `60*h + m == t && 0 <= m && m < 60`
- `60*h + m == t`
- `60*h <= t`
- `0 <= m && m < 60`

## Explanation

Reconstruction ensures that the two components describe the assigned total. The bound on the remainder selects its unique canonical representation. For 70 minutes, for example, (0,70) would pass reconstruction alone and (1,11) would pass the remainder check alone, but only (1,10) satisfies both.
