How many integers `n` from $0$ through $16$ satisfy `qualifies(n) == 1`?

```c
int large(int n)
{
    return n >= 9;
}

int aligned(int n)
{
    return n % 4 == 0;
}

int qualifies(int n)
{
    return large(n) && aligned(n);
}
```

- $2$
- $1$
- $3$
- $4$

## Explanation

The first function admits integers from $9$ upward. The second tests divisibility by $4$. Among the integers from $9$ through $16$, the only multiples of $4$ are $12$ and $16$. Exactly two inputs therefore meet both conditions.
