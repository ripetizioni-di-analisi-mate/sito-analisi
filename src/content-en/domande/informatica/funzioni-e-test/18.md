What does `channel()` return in C17? The limit names are from `<limits.h>`.

```c
unsigned int channel(void)
{
    return -1;
}
```

- `0u`
- `1u`
- `INT_MAX`
- `UINT_MAX`

## Explanation

The return expression has the integer value `-1`. The `return` converts it to `unsigned int`. The conversion selects the congruent value modulo the number of values in the type, which is `UINT_MAX` plus one in mathematical arithmetic. The representative of `-1` is therefore `UINT_MAX`.
