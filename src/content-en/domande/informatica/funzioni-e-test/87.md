The contract for `compare(a,b)` requires a negative integer if `a < b`, zero for equal arguments, and a positive integer otherwise. The implementation returns −37 on `compare(2,5)`. Which assertion encodes **exactly** the promise for this pair?

- `assert(compare(2,5) == -1);`
- `assert(compare(2,5) < 0);`
- `assert(compare(2,5) != 0);`
- `assert(compare(2,5) == -37);`

## Explanation

The first argument is smaller, so the promise concerns the sign. Results such as −1 and −37 are permitted, whereas a positive integer violates the contract. Requiring one particular negative value would make the oracle too restrictive, while accepting any nonzero value would make it too weak.
