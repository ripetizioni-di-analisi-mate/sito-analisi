A coverage plan requests every combination of outcomes of the two `if` statements below, in order. Parameter `n` is an integer and is never modified. Both functions return normally when called. Which combination must be excluded as infeasible?

```c
if (n >= 10) high();
if (n > 0) positive();
```

- First false, second true.
- Both true.
- First true, second false.
- Both false.

## Explanation

If the first comparison succeeds, `n` is at least 10 and therefore positive, so the second comparison must also succeed. The other three paths can be exercised, for example using 5, 10 and 0 for false–true, true–true and false–false respectively.
