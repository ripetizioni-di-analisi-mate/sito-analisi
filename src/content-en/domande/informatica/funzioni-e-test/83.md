A small test suite compares four observed outputs with their expected values. The (observed, expected) pairs are (4,4), (5,6), (3,3), and (2,0). It must return **the number of failed cases**. Starting with `int failures = 0;`, which statement should execute once per pair?

- `failures = (observed != expected);`
- `failures += (observed == expected) ? 0 : observed;`
- `failures += observed - expected;`
- `failures += (observed != expected);`

## Explanation

The inequality comparison produces 1 exactly for a failed case and 0 otherwise. Summing the four indicators gives 2. Adding the differences would accumulate signed discrepancies, whereas a plain assignment would remember only the last case.
