The prototype is `int fits(int used, int capacity);`. The contract returns 1 exactly when `used <= capacity`. A caller accidentally passes the arguments in reverse order. Which test reveals the swap?

- `used = 2, capacity = 5`, expected 1
- `used = 0, capacity = 0`, expected 1
- `used = 3, capacity = 3`, expected 1
- `used = 8, capacity = 8`, expected 1

## Explanation

With distinct values the intended comparison is `2 <= 5`, which gives 1. Swapping the arguments changes it to `5 <= 2` and yields 0. Pairs of equal values reach the function in exactly the same order of values even when the caller reverses them.
