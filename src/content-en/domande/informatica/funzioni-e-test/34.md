In a new run, `combine(add(2), add(5))` is evaluated once. Which set describes the values allowed by C17 without fixing the evaluation order of the arguments?

```c
int add(int step)
{
    static int total = 0;
    total += step;
    return total;
}

int combine(int a, int b)
{
    return 10 * a + b;
}
```

- $\{27,75\}$
- $\{25,52\}$
- $\{27\}$
- $\{75\}$

## Explanation

The order of argument evaluation is unspecified. The two executions of the body of `add` are sequenced relative to each other, so one completes before the other. If `add(2)` runs first, the parameters are $(2,7)$ and the result is $27$. If `add(5)` runs first, the second parameter is $5$ and the first is $7$, giving $75$. Parameter positions remain those written in the call.
