A function may return **any** integer nearest to its real-valued input. For the exact input 2.5, which oracle accepts all and only the results permitted by the contract?

- `r % 2 == 0`
- `r == 2 || r == 3`
- `r == 2`
- `r >= 2`

## Explanation

Both 2 and 3 are half a unit from the input. Every other integer is at least one and a half units away. The specification gives no tie-breaking rule, so the oracle must allow both alternatives and exclude the rest.
