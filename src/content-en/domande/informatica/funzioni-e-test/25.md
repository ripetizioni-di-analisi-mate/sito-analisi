The contract for `inside(x, lo, hi)` requires `lo <= hi` and returns $1$ exactly when `lo <= x && x < hi`. With `lo = -3` and `hi = 4`, how many integers `x` from $-10$ to $20$ give $1$?

- $6$
- $8$
- $10$
- $7$

## Explanation

To obtain $1$, the relations $-3\leq x$ and $x<4$ must hold together. The admissible integers therefore run from $-3$ through $3$. The inclusive count is $3-(-3)+1=7$. The value $4$ is the excluded upper bound.
