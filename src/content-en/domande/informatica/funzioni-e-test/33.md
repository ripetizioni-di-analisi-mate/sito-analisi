For integers from $0$ to $9$, a specification requires result $3$ through $4$ and $6$ from $5$ onward. The tests at $2$ and $7$ pass. What follows directly from the observations?

- The function has been tested on all ten inputs.
- The tests covered the first value of each band.
- The tests verified behavior outside the domain.
- The observed results at $2$ and $7$ agree with the specification.

## Explanation

Inputs $2$ and $7$ belong to different bands, so the test plan covers both rules with one representative each. The oracle check concerns those two inputs. A function that returned a wrong value only at $5$ would pass these same tests without meeting the contract over the entire domain.
