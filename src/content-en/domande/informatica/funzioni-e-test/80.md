The function `rise()` is tested in isolation from a physical sensor. A programmable replacement for `read_sensor()` returns 8 and then 3. Which pair of observations checks both the change calculation and the required number of reads?

```c
int read_sensor(void);
int rise(void)
{
    int before = read_sensor();
    int after = read_sensor();
    return after - before;
}
```

- Result −5 and two calls to the replacement.
- Result 5 and two calls to the replacement.
- Result 3 and two calls to the replacement.
- Result −5 and one call to the replacement.

## Explanation

The initializers are in separate statements, so the first read assigns 8 to `before` and the second assigns 3 to `after`. Final minus initial gives 3 − 8 = −5. Counting the calls also tests that exactly two measurements were taken.
