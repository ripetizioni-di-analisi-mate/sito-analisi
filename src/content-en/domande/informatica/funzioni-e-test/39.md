The function `range_ok(lo, hi)` accepts every pair of integers and must return $1$ exactly when `lo <= hi`. The implementation uses `lo < hi`. Which input pair reveals the defect?

- $(8,9)$
- $(8,8)$
- $(9,8)$
- $(7,8)$

## Explanation

The defect changes the result only when `lo` and `hi` are equal. In that case, the required inclusive relation is true and the implementation's strict relation is false. The pair $(8,8)$ is the only candidate with equality.
