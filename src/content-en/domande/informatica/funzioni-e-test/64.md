A decoding stage guarantees an even integer `z` from 0 through 14. A second stage accepts only indices from 0 through 7. Which adapter is justified by the contract alone and also allows `z` to be reconstructed exactly from the index?

- Use `z / 2` and reconstruct with `2 * index`.
- Use `z % 8` and reconstruct with `index`.
- Use `z - 1` and reconstruct with `index + 1`.
- Use `z / 4` and reconstruct with `4 * index`.

## Explanation

The eight permitted values are 0, 2, …, 14. Dividing by 2 puts them in one-to-one correspondence with the indices 0, 1, …, 7. Evenness guarantees exact division, and multiplying by 2 recovers each original value.
