Determine `round_up(0)`, `round_up(2)`, and `round_up(5)` in order.

```c
int round_up(int n)
{
    if (n <= 0) {
        return 0;
    }
    return n % 2 == 0 ? n / 2 : n / 2 + 1;
}
```

- $(1,1,3)$
- $(0,2,3)$
- $(0,1,2)$
- $(0,1,3)$

## Explanation

At `n = 0`, the first branch returns `0`. The value `2` is even, so the exact division gives `1`. With `5`, integer division gives `2` and the remainder is `1`, so one is added and the result is `3`.
