A counter is reduced by subtracting one when it is odd and halving it when it is even. Which pair `(sub, half)` counts the two branches for input 13?

```c
int n = 13, sub = 0, half = 0;
while (n > 0) {
    if (n % 2) { --n; ++sub; }
    else { n /= 2; ++half; }
}
```

- `(3, 4)`
- `(4, 3)`
- `(3, 3)`
- `(2, 4)`

## Explanation

The transitions are $13\to12\to6\to3\to2\to1\to0$. Subtractions start at 13, 3 and 1, whereas halvings start at 12, 6 and 2. Zero ends the scan before another branch can be entered.
