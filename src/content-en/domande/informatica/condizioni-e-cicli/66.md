In a scheduler, `jobs` counts remaining jobs and `phase` belongs to $\{0,1,2\}$. The initial values are nonnegative and representable. Which mathematical quantity decreases by exactly one on every iteration?

```c
while (jobs > 0) {
    if (phase > 0) --phase;
    else { --jobs; phase = 2; }
}
```

- $3\,\text{jobs}-\text{phase}$
- $\text{jobs}+\text{phase}$
- $2\,\text{jobs}+\text{phase}$
- $3\,\text{jobs}+\text{phase}$

## Explanation

In the first branch only the phase changes, decreasing by one. In the second branch one job is removed and the phase goes from 0 to 2. Giving each job weight 3 makes the net change $-3+2=-1$ in this case as well. The quantity is nonnegative, so its decrease proves termination.
