Standard input contains `3 0 9` followed by end-of-file. After the loop one more integer is read. What is the pair `(sum, next)`? Assume `<stdio.h>` is included.

```c
int v, sum = 0, next = -1;
while (scanf("%d", &v) == 1 && v != 0) sum += v;
scanf("%d", &next);
```

- `(12, 9)`
- `(0, 3)`
- `(3, 0)`
- `(3, 9)`

## Explanation

The first conversion assigns 3 to `v`, and the body adds it. The next conversion successfully reads 0, so the sentinel has already been consumed by the time `v != 0` makes the guard false. The `scanf` after the loop therefore finds 9, while `sum` remains 3.
