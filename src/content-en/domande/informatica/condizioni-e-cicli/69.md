A grid is visited only at columns that are powers of two. Over the four rows shown, how many times is `visits` incremented?

```c
int visits = 0;
for (int r = 1; r <= 4; ++r)
    for (int c = 1; c <= r; c *= 2) ++visits;
```

- `9`
- `8`
- `7`
- `10`

## Explanation

The inner loop restarts at 1 on every row and doubles the column. For `r = 1` it visits only 1. For `r = 2` it visits 1 and 2, and for `r = 3` it again visits 1 and 2. For `r = 4` it also reaches 4. Summing the row counts gives $1+2+2+3=8$.
