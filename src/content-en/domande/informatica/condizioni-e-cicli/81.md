A scan uses positive `int` values with `k >= 1` and `n >= 1`. Which guard is mathematically equivalent to $k^2\le n$ and can be evaluated even when the product `k*k` is not representable?

- `n / k <= k`
- `k <= n % k`
- `k < n / k`
- `k <= n / k`

## Explanation

For $k>0$ the inequality is equivalent to $k\le\lfloor n/k\rfloor$. Both operands are positive, so C integer division gives exactly that floor. The divisor is nonzero and the guard avoids forming the product. Equality must be included, as shown by `n = 49` and `k = 7`.
