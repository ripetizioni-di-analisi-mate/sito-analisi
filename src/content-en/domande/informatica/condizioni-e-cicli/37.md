Let `n` be a nonnegative `int`. All intermediate values in the fragment are representable. Which relation holds for every permitted input and at every guard test, including the final one?

```c
int sum = 0;
for (int i = 0; i < n; ++i) {
    sum += 2 * i;
}
```

- $\mathrm{sum}=i(i+1)$
- $\mathrm{sum}=i(i-1)$
- $\mathrm{sum}=2i$
- $\mathrm{sum}=i^2$

## Explanation

At the initial test, `i` and `sum` are both $0$, so the relation is true. If the sum is $i(i-1)$ at the start of an iteration, the body adds $2i$ and obtains $i(i+1)$. After the update, the new index is $i+1$, and the product in the invariant for that index is $(i+1)i$. The equality is preserved.
