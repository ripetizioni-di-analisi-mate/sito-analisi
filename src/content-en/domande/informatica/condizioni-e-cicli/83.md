Array `a` contains `n` round parentheses, where `0 <= n <= 100`. A sequence is balanced if each closing parenthesis has an unmatched opener and every opener is eventually closed. Which test on the final two values recognizes exactly these sequences, including the empty one?

```c
int depth = 0, low = 0;
for (int i = 0; i < n; ++i) {
    depth += (a[i] == '(') ? 1 : -1;
    if (depth < low) low = depth;
}
```

- `depth >= 0 && low <= 0`
- `depth == 0`
- `depth == 0 && low == 0`
- `low == 0`

## Explanation

`depth` is the number of openers minus the number of closers in the prefix read so far. `low` is the minimum of that difference, including its initial zero. Both a zero final balance and the absence of negative prefixes are required. The sequence `)(` ends at zero but falls below it. The sequence `(()` stays nonnegative but leaves one parenthesis open.
