A detector stops on the third consecutive positive signal. With samples numbered from zero, at which index does it stop?

```c
int a[] = {2, 6, 0, 1, 3, 4, 8};
int i, run = 0;
for (i = 0; i < 7; ++i) {
    run = a[i] > 0 ? run + 1 : 0;
    if (run == 3) break;
}
```

- `4`
- `3`
- `5`
- `6`

## Explanation

At indices 0 and 1 the run grows to length 2. The zero sample at index 2 resets `run`. The samples at indices 3, 4 and 5 then build a new run of lengths 1, 2 and 3. The `break` occurs with `i = 5`, before the `for` update.
