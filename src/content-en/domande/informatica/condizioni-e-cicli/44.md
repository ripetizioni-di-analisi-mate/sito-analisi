What value does `value` take?

```c
int value = 0;
for (int i = 0; i < 7; ++i) {
    if (i % 2) {
        value += i;
    } else {
        value -= i;
    }
}
```

- $3$
- $-6$
- $9$
- $-3$

## Explanation

The inner guard is true for odd indices, which are added. Even indices are subtracted. Grouping the indices into $(0,1)$, $(2,3)$ and $(4,5)$ gives a contribution of $1$ per pair. Index $6$ remains and contributes $-6$. The final value is $1+1+1-6=-3$.
