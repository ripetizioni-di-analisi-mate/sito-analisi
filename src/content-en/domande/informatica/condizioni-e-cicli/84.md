To count odd values in a stream of `int` values, including negative numbers, which guard recognizes every odd integer in C17?

- `x % 2 != 0`
- `x % 2 == 1`
- `x % 2 == -1`
- `x / 2 != 0`

## Explanation

An even integer has zero remainder on division by 2. A positive odd integer has remainder 1, whereas a negative odd integer has remainder $-1$ because C integer division truncates toward zero. For example, $-3=(-1)\cdot2-1$. Comparing the remainder with zero covers both signs.
