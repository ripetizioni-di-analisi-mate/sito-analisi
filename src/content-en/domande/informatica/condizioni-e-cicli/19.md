Which `if` owns the `else`?

```c
int x = 2, y = 1, result = 0;
if (x > 0)
    if (y > 2) {
        result = 1;
    } else {
        result = 2;
    }
```

- The `if` with guard `x > 0`.
- Both `if` statements.
- Neither `if` statement.
- The `if` with guard `y > 2`.

## Explanation

An `else` attaches to the closest preceding `if` that can take it under the syntax. Here the inner `if` with guard `y > 2` is the closest and has no other `else`. To attach the `else` to the outer guard, the inner `if` can be enclosed in a block delimited by braces.
