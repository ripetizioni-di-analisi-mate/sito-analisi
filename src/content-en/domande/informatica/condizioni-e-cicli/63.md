A function must average only the strictly positive samples. With this scan, which expression assigns the mean when `used > 0` and retains the fractional part? Assume that `double` represents 3.5 exactly.

```c
int a[] = {2, -1, 5, 0}, sum = 0, used = 0;
for (int i = 0; i < 4; ++i)
    if (a[i] > 0) { sum += a[i]; ++used; }
```

- `(double)sum / used`
- `(double)(sum / used)`
- `(double)sum / 4`
- `(double)used / sum`

## Explanation

The guard keeps 2 and 5, giving `sum = 7` and `used = 2`. Converting `sum` to `double` before division yields 3.5. A conversion after integer division would give 3. Dividing by 4 would include the two discarded samples in the denominator.
