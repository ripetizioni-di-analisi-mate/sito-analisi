What value does `n` have on exit? Consider when the `switch` selects the entry label.

```c
int n = 1;
switch (n++) {
case 1: n += 3; break;
case 5: n *= 2; break;
default: n = 0;
}
```

- `4`
- `5`
- `10`
- `0`

## Explanation

Post-increment supplies the old value 1 for dispatch and raises `n` to 2. Execution starts at `case 1`, which adds 3 to obtain 5. Changing `n` does not trigger a new dispatch. The `break` exits with `n` equal to 5.
