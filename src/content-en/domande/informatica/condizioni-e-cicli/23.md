What is the final pair `(i, bodies)`?

```c
int i = 0, bodies = 0;
do {
    ++bodies;
} while (i++ < 2);
```

- $(2,3)$
- $(3,2)$
- $(3,3)$
- $(2,2)$

## Explanation

The first execution of the body happens immediately. At the three subsequent tests the guard uses the previous values of `i`, namely $0$, $1$ and $2$. The first two tests are true. The third is false and still increments `i` to $3$. The body has executed three times, so `bodies` is also $3$.
