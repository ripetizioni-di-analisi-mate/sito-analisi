What is the last index stored in `last`?

```c
int last = 0;
for (int i = -5; i < 8; i += 3) {
    last = i;
}
```

- $7$
- $4$
- $8$
- $10$

## Explanation

The progression starts at $-5$ and increases by $3$. The permitted indices are $-5$, $-2$, $1$, $4$ and $7$. The next value is $10$, which fails `i < 8`, so `last` retains $7$. The limit $8$ is also excluded because it is not in the progression.
