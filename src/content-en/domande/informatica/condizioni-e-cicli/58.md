The goal is the alternating sum of the `n` entries of `a`, starting with a plus sign. The loop consumes two values at a time. Which statement belongs in the final branch so that the result is correct for every length from 0 to 100? Assume all sums and differences are representable.

```c
int i = 0, total = 0;
while (i + 1 < n) {
    total += a[i] - a[i + 1];
    i += 2;
}
if (i < n) { /* final statement */ }
```

- `total += a[i];`
- `total = a[i];`
- `total -= a[i];`
- `total += i;`

## Explanation

After each iteration `i` is even and `total` contains the contribution from all pairs already consumed. For an even or zero length the final condition is false. If a value remains, it is at even index `i` and therefore has a plus sign. It must be added to the accumulated sum.
