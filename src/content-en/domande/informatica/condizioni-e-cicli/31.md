What is evaluated immediately after `continue`?

```c
int skip = 1, more = 0, count = 0;
do {
    if (skip) {
        continue;
    }
    ++count;
} while (more);
```

- It increments `count`.
- It restarts the body before any test.
- It returns control to the caller of the function.
- It evaluates the guard `more`.

## Explanation

With `skip` equal to $1$, the `continue` branch executes. In a `do while`, the continuation point is the guard at the bottom of the loop. The increment of `count` is skipped and `more` is evaluated. Since `more` is $0$, the guard then terminates the loop.
