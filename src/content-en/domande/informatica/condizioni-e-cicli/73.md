A program counts maximal runs of equal consecutive values. For `{4,4,1,1,1,3}` the count ends at 2. Which correction makes the count valid for every nonempty array without changing the loop body?

```c
int groups = 0;
for (int i = 1; i < n; ++i)
    if (a[i] != a[i - 1]) ++groups;
```

- Start the loop at `i = 2`.
- Replace `i < n` with `i < n - 1`.
- Initialize `groups` to 1.
- Initialize `groups` to `n`.

## Explanation

Each change between adjacent elements marks the beginning of a run after the first one. A nonempty array already has a run at index 0, even when every value is equal. The run count is therefore one plus the number of changes. In the example, the transitions from 4 to 1 and from 1 to 3 identify the second and third runs.
