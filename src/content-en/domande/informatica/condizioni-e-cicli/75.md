The loop processes symmetric pairs in a sequence of length 7, numbered 0 through 6. Which single index is absent from all processed pairs?

```c
int lo = 0, hi = 6;
while (lo < hi) {
    /* process (lo, hi) */
    ++lo;
    --hi;
}
```

- `4`
- `0`
- `3`
- `6`

## Explanation

The successive successful tests give the pairs $(0,6)$, $(1,5)$ and $(2,4)$. After the third step both indices equal 3. The strict guard excludes $(3,3)$, leaving the centre position outside the processed pairs. Including equality would pair the centre with itself.
