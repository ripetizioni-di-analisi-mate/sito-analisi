Two sensors return `int` values `a` and `b`. Any nonzero value indicates activity, including a negative value. Which guard triggers the alarm exactly when one sensor is active?

- `(a != 0) != (b != 0)`
- `a != b`
- `(a == 0) && (b == 0)`
- `a && b`

## Explanation

Each comparison with zero converts the reading to `0` or `1`. The outer comparison yields `1` when these two indicators differ, so exactly one sensor is active. With `a = -2` and `b = 3` both sensors are active. Comparing their readings directly would trigger the alarm.
