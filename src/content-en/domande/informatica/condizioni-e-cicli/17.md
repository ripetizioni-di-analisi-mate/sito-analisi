What value is stored in `flag`?

```c
int flag = 2 && 0 || 3 && !0;
```

- $0$
- $1$
- $3$
- $2$

## Explanation

`&&` binds more tightly than `||`, so the operands of the disjunction are two conjunctions. The first, `2 && 0`, gives $0$. The second is evaluated because the left operand is false. The value $3$ is true and `!0` returns $1$, so the second conjunction is true. The disjunction produces the integer $1$.
