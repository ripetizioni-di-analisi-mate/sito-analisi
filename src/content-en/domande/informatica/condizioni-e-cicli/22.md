How many iterations does `steps` record?

```c
int x = 130, steps = 0;
while (x > 9) {
    x /= 10;
    ++steps;
}
```

- $1$
- $2$
- $3$
- $13$

## Explanation

The guard is true when `x` is $130$ and when it is $13$. Since `x` is an integer, the ratio is truncated at each division by $10$. The two updates therefore take `x` first to $13$ and then to $1$. With $1$ the guard is false and `steps` retains the value $2$.
