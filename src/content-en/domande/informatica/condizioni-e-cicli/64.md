A `for` with update `++i` is being rewritten as a `while`. In the attempted rewrite, what is the first value of `i` for which the body returns to the guard without advancing the counter?

```c
int i = 0;
while (i < 4) {
    if (i % 2) continue;
    ++i;
}
```

- `1`
- `2`
- `4`
- `0`

## Explanation

With `i = 0` the inner condition is false and `++i` raises the counter to 1. Its remainder on division by 2 is now 1, so `continue` takes control directly to the `while` guard. The increment at the bottom of the body is skipped, whereas the original `for` would have reached its update along this path as well.
