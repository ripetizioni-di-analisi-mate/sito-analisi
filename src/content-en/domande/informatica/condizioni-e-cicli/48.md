A configuration must satisfy the rule “whenever `running` is true, `sealed` is true.” When the machine is stopped, either lid state is allowed. Which expression yields `1` for exactly the valid configurations?

- `!sealed || running`
- `running && sealed`
- `!running || sealed`
- `!!running == !!sealed`

## Explanation

The only violation has a true `running` flag and a false `sealed` flag. Negating `running && !sealed` gives `!running || sealed`. When the machine is stopped, the first operand makes the guard true immediately. While it is running, the second operand decides the result.
