Let `n` be a positive `int` and let `a` be an array of `n` integers. Which expression is true after the search for every array and can be evaluated safely even when the key is absent?

```c
int i = 0;
for (; i < n; ++i)
    if (a[i] == key) break;
```

- `i == n && a[n - 1] == key`
- `i == n || a[i] == key`
- `i < n && a[i] == key`
- `a[i] == key || i == n`

## Explanation

A `break` exit retains a valid index and guarantees `a[i] == key`. An exhausted search instead leaves `i == n`. Checking equality with `n` first uses short-circuiting to prevent a read past the last element in the latter case. Reversing the operands would attempt the read before testing for the end.
