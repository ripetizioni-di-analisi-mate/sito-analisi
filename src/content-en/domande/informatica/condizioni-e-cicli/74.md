While narrowing a closed interval, a program computes `mid = lo + (hi - lo) / 2`, where `0 <= lo < hi <= 100`. The selected branch assigns `lo = mid`. For which pair `(lo, hi)` does the branch leave the entire interval unchanged?

- `(6, 9)`
- `(6, 7)`
- `(6, 10)`
- `(6, 8)`

## Explanation

With consecutive endpoints the difference is 1. Integer division `1 / 2` gives 0, so `mid` equals `lo`. The reassignment leaves both endpoints unchanged. For the other pairs the difference is at least 2, making the midpoint strictly greater than the left endpoint.
