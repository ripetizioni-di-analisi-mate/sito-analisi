Find `score` after the two loops.

```c
int score = 0;
for (int i = 1; i <= 3; ++i) {
    for (int j = 1; j <= 4; ++j) {
        if (i * j >= 6) {
            break;
        }
        score += i;
    }
}
```

- $7$
- $11$
- $14$
- $18$

## Explanation

With `i` equal to $1$, all four values of `j` keep the product below $6$, so the contribution is $4$. With `i` equal to $2$, only `j` equal to $1$ and $2$ are used and the contribution is $4$. With `i` equal to $3$, only `j` equal to $1$ is used and the contribution is $3$. The total is $4+4+3=11$.
