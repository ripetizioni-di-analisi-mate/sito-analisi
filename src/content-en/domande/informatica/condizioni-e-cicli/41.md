What is `steps` at the end?

```c
int x = -2, steps = 0;
while (x < 20) {
    x = 2 * x + 5;
    ++steps;
}
```

- $3$
- $5$
- $6$
- $4$

## Explanation

Set $y=x+5$. The update of `x` doubles $y$, since $(2x+5)+5=2(x+5)$. The guard requires $y<25$. Starting from $3$ gives $6$, $12$, $24$ and $48$. The first failure of the test occurs at $48$, so four updates have executed.
