Two strictly increasing lists are compared using two indices. When `a[i] < b[j]`, why can only `i` be advanced when counting common values?

- `a[i]` is the last remaining value in its list.
- Equality between the current values has already been counted.
- `b[j]` is smaller than every remaining value in `a`.
- `a[i]` is smaller than every remaining value in `b`.

## Explanation

The unexamined suffix of `b` starts at `b[j]`. By sortedness, every value in that suffix is at least `b[j]` and thus strictly greater than `a[i]`. Discarding `a[i]` cannot lose a match. The value `b[j]` remains available because it might equal a later value in `a`.
