What is `crossed` on completion?

```c
int crossed = -1, total = 0;
for (int i = 1; i <= 7; ++i) {
    total += 2 * i;
    if (total >= 12) {
        crossed = i;
        break;
    }
}
```

- $3$
- $2$
- $4$
- $-1$

## Explanation

The test runs after adding `2 * i`. With `i` equal to $1$, $2$ and $3$, the values of `total` are $2$, $6$ and $12$. The first value satisfying `total >= 12` is $12$, reached at `i` equal to $3$. That `i` is copied to `crossed` before `break`.
