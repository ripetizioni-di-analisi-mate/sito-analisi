For nonnegative `n`, label `A` should identify multiples of 8, and `B` the remaining multiples of 4. Which guard should replace the comment to implement that classification?

```c
char label;
if (/* guard */) label = 'A';
else if (n % 4 == 0) label = 'B';
else label = 'C';
```

- `n % 8 == 4`
- `n % 4 != 0`
- `n % 4 == 0`
- `n % 8 == 0`

## Explanation

Among multiples of 4, the remainder modulo 8 is either 0 or 4. The first branch must catch only remainder 0. If that test fails, the second branch recognizes the remaining multiples of 4. Testing divisibility by 4 in the first branch would make the assignment of `B` unreachable.
