A search must visit cells in row order and stop at the first negative value. `rows` and `cols` have type `int` and give the valid matrix dimensions. Which outer guard completes the code and prevents any new row from starting once a negative value has been found?

```c
int found = 0;
for (int r = 0; /* outer guard */; ++r)
    for (int c = 0; c < cols; ++c)
        if (a[r][c] < 0) { found = 1; break; }
```

- `r < rows || !found`
- `r < rows && !found`
- `r < rows && found`
- `r < rows`

## Explanation

The `break` belongs to the column loop. On a match it ends the current row, but the outer `for` still performs its update and tests its guard again. Requiring both a valid row and a false `found` flag prevents a second search. The same guard skips the scan entirely when `rows` is zero.
