The code subtracts successive odd numbers from an integer `N` between 0 and 100. Which pair of final properties proves that `k` is the integer part of the square root of `N`?

```c
int k = 0, r = N;
while (r >= 2 * k + 1) {
    r -= 2 * k + 1;
    ++k;
}
```

- $N=k^2+r$ and $0\le r<2k+1$.
- $N=k+r$ and $0\le r<k$.
- $N=k^2-r$ and $r\ge 0$.
- $N=(k+1)^2+r$ and $r\ge 0$.

## Explanation

Initially $N=0^2+N$. A step subtracts $2k+1$ from the remainder and increases $k$ by one. Since $(k+1)^2-k^2=2k+1$, the identity is preserved. The guard keeps the remainder nonnegative. At exit $r<2k+1$, so $k^2\le N<k^2+2k+1=(k+1)^2$.
