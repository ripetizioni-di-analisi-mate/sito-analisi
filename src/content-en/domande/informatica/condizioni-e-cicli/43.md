What is the final pair `(x, visits)`?

```c
int x = 0, visits = 0;
while (x < 4 && ++visits < 3) {
    x += 2;
}
```

- $(4,2)$
- $(4,3)$
- $(6,3)$
- $(2,2)$

## Explanation

The first two tests find `x` below $4$. Both evaluate `++visits < 3`, which is true with `visits` equal to $1$ and then $2$. The body increases `x` to $4$. At the next test the first operand of `&&` is false, so `visits` remains $2$.
