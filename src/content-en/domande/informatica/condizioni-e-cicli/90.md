An array of votes contains only 0 and 1. The vote count `n` is a nonnegative `int`. The following count cancels unlike votes in pairs. Which statement holds after every prefix, including the empty prefix?

```c
int who = 0, bal = 0;
for (int i = 0; i < n; ++i) {
    if (bal == 0) { who = v[i]; bal = 1; }
    else if (who == v[i]) ++bal;
    else --bal;
}
```

- `bal` is the absolute difference between the two counts, and if positive, `who` identifies the more frequent value.
- `bal` becomes zero whenever two consecutive votes differ.
- `bal` is the total number of votes equal to `who` since the start.
- `who` is always the last vote read.

## Explanation

Initially both counts are zero and so is `bal`. From a tie, the next vote creates a lead of one and selects `who`. With a positive lead, a vote for `who` increases it by one, while an opposite vote decreases it by one. These transitions preserve the absolute difference and, as long as it stays positive, the identity of the leading value.
