What is the final value of `seen`?

```c
int seen = 0, k = 0;
while (k < 6) {
    ++k;
    if (k % 2 == 0) {
        continue;
    }
    seen = 10 * seen + k;
}
```

- $12345$
- $246$
- $135$
- $13$

## Explanation

Every iteration increments `k` before a possible `continue`. When `k` is even, the jump skips the assignment to `seen` and returns to the guard test. The values used in the assignments are therefore $1$, $3$ and $5$. The successive results are $1$, $13$ and $135$, and the skip with `k` equal to $6$ leaves that result unchanged.
