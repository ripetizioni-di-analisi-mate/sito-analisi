A digital input starts low. What pair `(rises, falls)` results from counting its transitions?

```c
int a[] = {0, 1, 1, 0, 1, 0, 1};
int previous = 0, rises = 0, falls = 0;
for (int i = 0; i < 7; ++i) {
    if (a[i] > previous) ++rises;
    if (a[i] < previous) ++falls;
    previous = a[i];
}
```

- `(2, 3)`
- `(3, 2)`
- `(4, 3)`
- `(3, 3)`

## Explanation

The signal changes from 0 to 1 at indices 1, 4 and 6. It changes from 1 to 0 at indices 3 and 5. Equal consecutive values, such as the ones at indices 1 and 2, contribute no transition. Rises exceed falls by one, consistent with a signal that starts low and ends high.
