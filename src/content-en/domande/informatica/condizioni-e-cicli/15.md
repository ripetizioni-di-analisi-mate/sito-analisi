What is the final pair `(x, score)`?

```c
int x = 6, score = 1;
if ((x = 0)) {
    score = 5;
} else {
    score += 2;
}
```

- $(6,5)$
- $(0,5)$
- $(0,3)$
- $(6,3)$

## Explanation

The assignment in the guard stores $0$ in `x` and has the assigned value as its result. Since the guard equals $0$, the `else` branch executes. The initial `score` is $1$, and the update gives $1+2=3$. The update to `x` has taken place even though the guard is false.
