A processor starts each row with a fresh credit that can exceed the remaining credit on the previous row. The row count `rows` is a nonnegative `int`. Every row has a readable `int` entry `credit[r]` with a nonnegative value. Which argument proves termination of both loops?

```c
for (int r = 0; r < rows; ++r) {
    int c = credit[r];
    while (c > 0) --c;
}
```

- `c` strictly decreases even when crossing between rows.
- The initial credit must be identical for all rows.
- `rows` decreases at every execution of the inner body.
- Within a row `c` decreases to zero, and once the row finishes the number of unvisited rows decreases.

## Explanation

For a fixed row, the nonnegative quantity `c` falls by one at every inner step. Control therefore returns to the outer `for` after finitely many steps, including when the initial credit is zero. On each return the row index advances and fewer rows remain. The proof allows successive rows to have different initial credits.
