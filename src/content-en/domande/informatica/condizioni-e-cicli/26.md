Determine the final value of `written`.

```c
int i = 2, written = 0;
for (; i < 6; written += i, ++i) {
    i += 1;
}
```

- $6$
- $10$
- $8$
- $12$

## Explanation

In the first body execution `i` changes from $2$ to $3$. The update expression adds the current value $3$ to `written` and then increases `i` to $4$. The second body execution makes `i` equal to $5$, which is added before the following increment. At `i` equal to $6$ the test fails, so `written` is $3+5=8$.
