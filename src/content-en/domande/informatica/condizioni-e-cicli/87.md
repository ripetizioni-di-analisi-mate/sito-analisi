A scan emits one result for each adjacent pair of equal values it merges. Otherwise it emits the current value alone. The code counts outputs in `w` and merged pairs in `merged`, with `0 <= n <= 100`. Which identity holds at every guard test?

```c
int r = 0, w = 0, merged = 0;
while (r < n) {
    if (r + 1 < n && a[r] == a[r + 1]) {
        r += 2;
        ++merged;
    } else {
        ++r;
    }
    ++w;
}
```

- `r == w - 2 * merged`
- `r == 2 * w + merged`
- `r == w + merged`
- `w == r + merged`

## Explanation

Each output consumes at least one value, so `w` counts one input per result. Each merge consumes one additional value, so adding `merged` gives the number `r` of inputs read. In the single-value branch both sides rise by one, and in the double-value branch both rise by two. The equality already holds at entry.
