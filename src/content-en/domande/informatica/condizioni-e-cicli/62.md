A leaderboard must report the first position at which the maximum score occurs. Which guard implements this rule for every array of integer scores whose length `n` is an `int` with `n >= 1`?

```c
int best = 0;
for (int i = 1; i < n; ++i)
    if (/* guard */) best = i;
```

- `i < best`
- `score[i] > score[best]`
- `score[i] >= score[best]`
- `score[i] != score[best]`

## Explanation

Before the loop, `best` identifies the only score examined. A strictly larger score replaces the previous maximum. On a tie the stored index must stay unchanged. It is the smaller one because the scan runs left to right. Using `>=` would select the last occurrence of the maximum.
