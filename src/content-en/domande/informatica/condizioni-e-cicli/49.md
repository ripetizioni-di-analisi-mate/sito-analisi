The code computes `score` for a positive integer `n`. If the second `if` is replaced by `else if`, what is the smallest `n` for which the result changes?

```c
int score = 0;
if (n % 3 == 0) score += 2;
if (n % 5 == 0) score += 4;
```

- `3`
- `8`
- `5`
- `15`

## Explanation

The versions differ only when both conditions hold. The input must therefore be a common multiple of 3 and 5. The smallest positive one is 15. The original code adds both contributions and obtains 6. In the alternative chain the first branch produces 2, and the second test is skipped.
