What is the final value of `count`?

```c
int count = 0, j = 0;
for (int i = 0; i < 3; ++i) {
    while (j < 2) {
        ++j;
        ++count;
    }
}
```

- $2$
- $0$
- $3$
- $6$

## Explanation

`j` is initialized before entry to the outer loop, so the first row is the only one starting with `j` equal to $0$. The first `while` takes it to $2$ and increments `count` twice. In later rows `j` retains $2$, making the inner guard false at its first test. The count remains $2$.
