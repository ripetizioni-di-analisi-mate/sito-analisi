A two-stage operation is enclosed in a `do ... while (0)`. With `ready = 1` and `valid = 0`, what are the final values of `stage` and `logged`?

```c
int ready = 1, valid = 0, stage = 0, logged = 0;
do {
    if (!ready) break;
    stage = 1;
    if (!valid) break;
    stage = 2;
} while (0);
++logged;
```

- `(2, 1)`
- `(1, 0)`
- `(1, 1)`
- `(0, 1)`

## Explanation

The `do` enters its body immediately. The first check allows 1 to be assigned to `stage`. The second finds `!valid` true and leaves the `do` before the assignment of 2. The statement following the loop still executes, raising `logged` to 1. The constant zero guard would prevent a second iteration even on the complete path.
