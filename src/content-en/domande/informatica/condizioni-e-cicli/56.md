After the last guard evaluation, what is the pair `(visits, n)`? `UINT_MAX` denotes the largest `unsigned int`.

```c
unsigned int n = 2;
int visits = 0;
while (n-- > 0) ++visits;
```

- `(2, UINT_MAX)`
- `(2, 0)`
- `(3, UINT_MAX)`
- `(3, 0)`

## Explanation

The guard compares the old values of `n` with zero. In order these are 2, 1 and 0. Only the first two start the body. The false evaluation still performs the post-decrement. Starting at zero, unsigned arithmetic takes `n` to `UINT_MAX`. Thus the value compared and the value stored after the test differ.
