How many pairs are counted by `visits`?

```c
int visits = 0;
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 4; ++j) {
        if ((i + j) % 2 == 0) {
            ++visits;
        }
    }
}
```

- $6$
- $5$
- $8$
- $12$

## Explanation

The sum `i + j` is even exactly when both indices have the same parity. For each `i` there are four values of `j`, two even and two odd. Each of the three rows therefore contributes two increments. The count is $3\cdot 2=6$.
