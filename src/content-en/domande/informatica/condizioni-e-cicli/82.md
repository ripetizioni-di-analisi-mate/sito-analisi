A validator requires the array to be nondecreasing. A programmer updates `ok` on every iteration as shown. Which three-element array demonstrates that this assignment can erase a previously detected violation?

```c
int ok = 1;
for (int i = 1; i < 3; ++i)
    ok = (a[i - 1] <= a[i]);
```

- `{3, 2, 1}`
- `{5, 2, 4}`
- `{1, 2, 3}`
- `{1, 4, 2}`

## Explanation

With $5,2,4$, the first comparison assigns zero because $5>2$. The second assigns one because $2\le4$, so the final result accepts an array containing an inversion. To retain every violation, the program can combine `ok` and the new comparison using `&&` or exit on the first false comparison.
