The right endpoint can move as the counter advances. What is the final pair `(i, end)`?

```c
int i = 0, end = 6;
for (; i < end; ++i) {
    if (i % 2 == 0) --end;
}
```

- `(4, 5)`
- `(4, 4)`
- `(6, 3)`
- `(3, 3)`

## Explanation

The iterations start with `i` equal to 0, 1, 2 and 3. The two even-indexed iterations reduce the endpoint from 6 to 5 and then from 5 to 4. After the body at index 3, the update takes `i` to 4. The test uses the updated endpoint, and `4 < 4` is false.
