Which values of $x$ in the set $\{0,1,7,8\}$ make the guard `0 < x && x <= 7` true?

- $\{0,1,7\}$
- $\{1,7\}$
- $\{1,7,8\}$
- $\{7\}$

## Explanation

The guard requires both that `x` be greater than $0$ and that it be at most $7$. The first comparison excludes $0$. The second excludes $8$. The remaining values are $1$ and $7$, which satisfy both conditions.
