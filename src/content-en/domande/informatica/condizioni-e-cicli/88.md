A check must recognize palindromic decimal representations of positive integers. Which precondition is missing if `rev == original` is to compare the reversed number with the input after the loop? All operations are representable.

```c
int rev = 0;
while (n > 0) {
    rev = 10 * rev + n % 10;
    n /= 10;
}
```

- Before the loop, `original` must equal 0.
- Before the loop, `original` must contain the initial value of `n`.
- `original` must contain the number of digits.
- `original` must be updated to `n` on every iteration.

## Explanation

The loop consumes `n` by dividing it by 10 after each digit. For 121, `rev` goes from 0 to 1, then 12 and finally 121, while `n` ends at zero. To recognize symmetry, the initial value must be saved before the input is consumed. Neither the digit count nor the final remainder provides that comparison value.
