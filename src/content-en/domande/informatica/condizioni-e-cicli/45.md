What is the final pair `(units, remaining)`?

```c
int remaining = 76, price = 6, units = 0;
while (remaining >= price) {
    remaining -= price;
    ++units;
    if (units % 3 == 0) {
        price += 2;
    }
}
```

- $(10,4)$
- $(9,6)$
- $(9,4)$
- $(8,14)$

## Explanation

The increase in `price` occurs after each group of three units. After the first group, $76-3\cdot 6=58$ resource units remain. The next two groups cost $3\cdot 8=24$ and $3\cdot 10=30$, so after nine units $4$ remain. The next price is $12$ and the guard is false.
