What is `score` after the `switch`?

```c
int mode = 9, score = 5;
switch (mode) {
case 0:
    score = 1;
    break;
default:
    score += 2;
    /* fall through */
case 4:
    score *= 2;
    break;
}
```

- $7$
- $10$
- $2$
- $14$

## Explanation

The value $9$ matches no `case`, so control enters at `default`. The addition changes `score` from $5$ to $7$. Since there is no `break` between the labels, execution continues with multiplication by $2$, producing $14$. Entering that block does not require another comparison with $4$.
