What is `count` on exit from the `for`?

```c
int count = 0;
for (int i = 0; i < 3; ++i) {
    switch (i) {
    case 1:
        break;
    default:
        count += 10;
    }
    ++count;
}
```

- $11$
- $23$
- $12$
- $22$

## Explanation

For `i` equal to $0$ and $2$, `default` executes, followed by the increment outside the `switch`. Each of those iterations adds $11$. With `i` equal to $1$, `break` exits the `switch`, so the outer increment still occurs. That iteration contributes $1$, and the total is $11+1+11=23$.
