A `continue` and a `break` occur in the same `switch` inside a `for` loop. What is the final value of `mark`?

```c
int mark = 0;
for (int i = 0; i < 3; ++i) {
    switch (i) {
    case 0: continue;
    case 1: break;
    default: mark += 9;
    }
    mark += 3;
}
```

- `15`
- `21`
- `9`
- `12`

## Explanation

For `i = 0`, `continue` transfers control to the `for` update, skipping the addition of 3. For `i = 1`, `break` leaves only the `switch`, so 3 is added. For `i = 2`, the code adds 9 and then 3. The total is `0 + 3 + 12 = 15`.
