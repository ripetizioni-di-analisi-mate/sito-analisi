The same C17 scope declares `struct A { int x; };` and `struct B { int x; };`. Object `a` is an initialized `struct A` and `b` is a `struct B`. Which assignment is valid and copies the integer value from `a` into the destination record?

- `b = a;`
- `b.x = a.x;`
- `b.x = a;`
- `b = a.x;`

## Explanation

The distinct tags declare different structure types here. Both `x` members have type `int`, so the member-to-member assignment is valid. Assigning one whole structure to the other would require compatible structure types in this case.
