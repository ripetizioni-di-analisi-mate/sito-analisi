A linear queue has `front == &a`. The successor of `a` is `c`, whose successor is null. `rear` points to a separate live node `b`. Which change restores the invariant while retaining exactly the nodes reachable from the current head, in the same order?

- `front = &b;`
- `rear = &c;`
- `rear = &a;`
- `rear = NULL;`

## Explanation

The sequence reachable from `front` visits `a` and then `c`, whose successor is null. The last existing node in that sequence is therefore `c`. Setting `rear` to its address restores the invariant while preserving the logical order.
