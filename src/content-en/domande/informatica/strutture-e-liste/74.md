`push_pair` must add two values in order or, if space is insufficient, report failure with the original logical stack intact. For a valid stack with `used <= capacity` of type `size_t`, which precondition check enforces that contract before changing the state?

- Proceed only if `capacity >= 2`
- Proceed only if `used >= 2`
- Proceed only if `capacity - used >= 2`
- Proceed only if `used < capacity`

## Explanation

Capacity minus occupancy is the number of free cells. The invariant ensures that this subtraction is representable. Requiring at least two free cells before writing prevents the first push from succeeding when the second would have to fail.
