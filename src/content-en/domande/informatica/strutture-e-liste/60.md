An algorithm concatenates lists by linking the former tail of the first to the head of the second. Each input list is linear, but the inputs here are `A→T→NULL` and `B→T→NULL` with the same live node `T`. Which property is lost if only the described link is made?

- Termination of traversal at `NULL`
- The value stored in `B`
- The identity of head `A`
- Reachability of `T` from `A`

## Explanation

The first list ends at `T`. Its new link points to `B`, which already points back to `T`. A traversal from `A` therefore enters the cycle between `T` and `B`. This explains why this concatenation algorithm requires disjoint nodes.
