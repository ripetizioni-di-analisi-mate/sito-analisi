The members in the C17 declaration `struct RGB { int r, g, b; };` occur in the order shown. Inside a function the declaration is `struct RGB c = {.g = 5, 7};`. Which triple gives `c.r`, `c.g` and `c.b`?

- $(0,5,7)$
- $(0,7,5)$
- $(5,7,0)$
- $(7,5,0)$

## Explanation

The designator assigns $5$ to member `g`. The next initializer has no designator, so it continues with the following member, `b`, assigning it $7$. Integer member `r` is omitted from this aggregate initializer and receives zero.
