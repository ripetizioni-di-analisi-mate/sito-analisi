The caller executes `struct Pair a = {2, 5};` and then `struct Pair b = raised(a);`. What pair `(a.x, b.x)` does it get?

```c
struct Pair { int x; int y; };

struct Pair raised(struct Pair p)
{
    p.x += p.y;
    return p;
}
```

- $(2,7)$
- $(7,7)$
- $(2,5)$
- $(7,2)$

## Explanation

Parameter `p` is initialized with a copy of `a`. The update adds $5$ and $2$ within the parameter, so the returned value has `x` equal to $7$. The caller retains $2$ in `a.x` and uses the result to initialize `b.x` to $7$.
