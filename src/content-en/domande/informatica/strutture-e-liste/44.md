Determine the value of `value`. The nodes remain live throughout the trace, and `<stddef.h>` is included.

```c
struct Node { int key; struct Node *next; };
struct Node tail = {9, NULL};
struct Node front = {3, &tail};
struct Node saved = front;
front.next = NULL;
int value = saved.next->key;
```

- $3$
- $0$
- $9$
- Null pointer dereference.

## Explanation

The initializer for `saved` copies the value of `front.next`, the address of `tail`. The later assignment changes only the `next` member of `front`. The copy retains the address of the live node with key $9$.
