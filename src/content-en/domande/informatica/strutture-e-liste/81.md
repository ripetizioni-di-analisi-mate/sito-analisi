A singly linked chain has $n\ge 3$ distinct nodes, known head and tail, only forward links and no auxiliary index. To remove the last node while preserving the rest, which information must generally be located by searching from the head?

- The address of the last node
- The last node’s successor, which is always null
- The address of the first node
- The address of the next-to-last node

## Explanation

The new last node is the predecessor of the old tail. It must be identified so its link can be cleared and the tail updated. The old tail has no backward link, so the search looks for the node whose `next` points to it.
