The type is `struct Item { int code; long amount; };`. Which expression measures all bytes in the representation of an object of that type on every C17 implementation?

- `sizeof(int) + sizeof(long)`
- `sizeof(long)`
- `sizeof(struct Item)`
- `sizeof(struct Item *)`

## Explanation

`sizeof(struct Item)` measures the representation of the entire object, whatever its padding. The sizes of the member types count bytes of each member. The size of `struct Item *` concerns a pointer object.
