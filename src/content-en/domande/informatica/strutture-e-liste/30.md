An empty queue receives node `A` with key $4$, node `B` with key $4$ and node `C` with key $1$, in order. One node is removed and then `D` with key $4$ is inserted. Which node is removed by the second FIFO operation?

- `A`
- `C`
- `B`
- `D`

## Explanation

Identity follows insertion order even when several nodes have the same key. The first dequeue removes `A`. Inserting `D` puts it after `C`, so the sequence becomes `B`, `C`, `D`. The second dequeue removes `B`.
