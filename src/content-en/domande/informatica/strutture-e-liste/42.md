In a circular queue map, $C>3$. `first` is `capacity - 2` and logical position `k` is $3$. Compute `gap = capacity - first`, then use `first + k` if `k < gap` and `k - gap` otherwise. Which index results?

- $2$
- $3$
- $1$
- $0$

## Explanation

From `first = capacity - 2`, two positions remain before wrapping to the start of the array. Since `k` is three, it passes that span and uses `k - gap`. The representable index is therefore $3-2=1$.
