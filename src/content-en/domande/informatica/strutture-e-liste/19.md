Pointer `p` designates a live structure object with an integer member `count`. Which expression is an lvalue that designates the same member as `p->count`?

- `(*p).count`
- `*p.count`
- `p.count`
- `&p->count`

## Explanation

`*p` designates the pointed-to object. The parentheses make `.count` select the member of that object. The `->` form designates exactly the same member.
