A device handles at most $32$ pending requests in FIFO order. Each enqueue and dequeue must take a number of operations independent of the current queue length, without shifting the items still in the queue. Memory must be reserved before startup. Which representation, with the specified operations, meets all requirements?

- A preallocated stack that always removes the latest insertion
- A list that calls `malloc` for every new node
- A linear array that shifts the remaining items on every dequeue
- A preallocated $32$-cell ring buffer with a front index and a count

## Explanation

The ring buffer reserves its cells at startup, and the count distinguishes empty from full so every cell can be used. The front index identifies one end, and the front plus the length determines the other. Enqueue and dequeue update a fixed number of fields while preserving FIFO order.
