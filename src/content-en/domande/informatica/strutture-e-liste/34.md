What are the final values of `out` and `used`, in that order?

```c
int data[2];
int used = 0;
int out = 44;
if (used > 0) {
    out = data[--used];
}
data[used++] = 6;
```

- $(6,1)$
- $(0,1)$
- $(44,1)$
- $(44,0)$

## Explanation

The test `used > 0` is false at the attempted pop. Both the decrement and assignment to `out` are skipped. The subsequent write uses index $0$ and raises `used` to $1$, while `out` stays at $44$.
