A list has strictly increasing keys $2,5,9,13,18$. At each node the search stops if the key equals or exceeds the target and moves on otherwise. When looking for $8$, how many keys are inspected before absence is established?

- $2$
- $5$
- $3$
- $4$

## Explanation

The search first inspects $2$ and $5$, both below the target. The third inspection finds $9>8$. Strictly increasing order guarantees that later nodes also have keys above $8$, so three inspections suffice.
