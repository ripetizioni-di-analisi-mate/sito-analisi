What key sequence is obtained by traversing the chain from `head`? Include `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node c = {8, NULL};
struct Node b = {7, NULL};
struct Node a = {4, &c};
struct Node *head = &a;
```

- $(4,7,8)$
- $(4,8)$
- $(8,4)$
- $(4)$

## Explanation

`head` designates `a`, so the first key is $4$. The successor of `a` is `c`, with key $8$, and its successor is null. Object `b` is live but is absent from the path starting at the head.
