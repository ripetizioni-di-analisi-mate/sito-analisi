What is the final value of `result` in this C17 fragment?

```c
struct Ref { int *slot; int tag; };
int total = 6;
struct Ref a = {&total, 1};
struct Ref b = a;
*b.slot = 8;
b.tag = 4;
int result = *a.slot + a.tag;
```

- $9$
- $12$
- $7$
- $10$

## Explanation

Copying makes `a.slot` and `b.slot` distinct members with the same address. Writing through `b.slot` therefore changes the value read through `a.slot` to $8$. The member `a.tag` retains $1$. The sum is $8+1=9$.
