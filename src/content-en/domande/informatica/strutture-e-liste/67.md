To check for a cycle in a list of live nodes, a traversal records what it has already visited. Duplicate keys are allowed, and the links remain unchanged during the traversal. Which event proves that repeatedly following `next` has actually returned to an earlier node?

- The traversal encounters the same node address a second time
- Two consecutive nodes have the same key
- Two nodes have the same C type
- A key is smaller than the previous one

## Explanation

A link identifies an object by its address. Returning to that same object while links remain unchanged repeats the same sequence of steps. Equal keys can instead belong to different nodes of a finite linear list.
