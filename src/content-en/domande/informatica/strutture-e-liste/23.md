`head` designates a nonempty list and `fresh` points to a live node distinct from every node in the list. Which sequence inserts it at the front while preserving every existing node?

- `head = fresh; fresh->next = head;`
- `fresh->next = NULL; head = fresh;`
- `fresh->next = head; head = fresh;`
- `fresh->next = head->next; head = fresh;`

## Explanation

The new node must contain the address of the former first node. Copy the value of `head` into `fresh->next` before changing the variable. If the head changes immediately, its value becomes the address of `fresh` and can produce a link to the new node itself.
