A queue contains `1,2,3,4,5` from front to rear. Exactly five dequeues are performed. After each dequeue, the value is reinserted at the rear only if it is odd. Which values remain at the end, in FIFO order?

- `2,4`
- `5,3,1`
- `3,5,1`
- `1,3,5`

## Explanation

Fixing the number of dequeues at the initial length examines each original item exactly once. Odd values are appended in the order in which they are encountered. After the fifth dequeue those three reinsertions make up the remaining queue.
