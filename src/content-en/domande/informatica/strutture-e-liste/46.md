In this C17 fragment a compound literal constructs a new point and is assigned to `p`. Which coordinates does `p` contain after the assignment?

```c
struct Point { int x, y; };
struct Point p = {2, 5};
p = (struct Point){.x = -p.y, .y = p.x};
```

- $(2,-5)$
- $(-5,-5)$
- $(5,-2)$
- $(-5,2)$

## Explanation

Both initializers read the members before the value of the whole record is assigned to `p`. The old y-coordinate is $5$, so the new x-coordinate is $-5$. The old x-coordinate is still $2$ when the new y-coordinate is formed. Writing the two members in sequence instead would read an already modified x-coordinate.
