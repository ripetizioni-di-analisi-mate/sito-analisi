Inside the definition of `struct Entry`, which declaration can supply a `next` member that points to a successor of the same type?

- `struct Entry *next;`
- `struct Entry next;`
- `int next;`
- `struct Entry next[1];`

## Explanation

While `struct Entry` is being defined, the structure type is still incomplete. A pointer that designates an object of that type can be declared. A value member or an array of elements of that type would already require a complete type.
