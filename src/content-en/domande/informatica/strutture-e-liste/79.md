A queue is implemented with two stacks. New items go onto the input stack. When the output stack is empty, items are repeatedly popped from the input stack and pushed onto the output stack. The output stack already contains `B,A` bottom to top, and the input stack contains `C,D`. Which step returns the next FIFO item?

- Pop `D` directly from the input stack
- Pop `A` from the output stack without transferring input items
- Remove `B` from the bottom of the output stack
- Transfer the input items immediately, then pop `C`

## Explanation

The output stack still holds items older than those accumulated on input. Its top, `A`, is the oldest of all. Transferring early would place newer items above items that are still waiting to leave.
