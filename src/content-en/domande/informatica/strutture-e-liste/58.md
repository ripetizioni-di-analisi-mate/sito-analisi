A circular list has a live sentinel `s` with no logical data item. The last node always points to `&s`, and in an empty list `s.next == &s`. A traversal starts at `Node *p = s.next;` and advances with `p = p->next;`. Which guard visits each data item once, including when the list is empty?

- `p->next != &s`
- `p == &s`
- `p != &s`
- `p != NULL`

## Explanation

The sentinel is the first position excluded from the traversal. The guard is already false for an empty list and becomes false when the last data node advances to the sentinel. Testing the successor instead of the current node would omit the last data item.
