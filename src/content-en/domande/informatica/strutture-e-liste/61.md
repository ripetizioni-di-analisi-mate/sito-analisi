An owning list headed by `src` must transfer all its nodes to an empty list headed by `dst` without allocating or freeing memory. The two head variables are distinct and the source must represent an empty list afterwards. Which sequence performs the transfer?

- `dst = src; dst = NULL;`
- `src = NULL; dst = src;`
- `dst = src; src = NULL;`
- `src = dst; dst = src;`

## Explanation

The first assignment saves the entry point to the source chain in the destination. Clearing `src` afterwards represents the ownership transfer without changing any node. Clearing `src` first would lose the original reference that must be transferred.
