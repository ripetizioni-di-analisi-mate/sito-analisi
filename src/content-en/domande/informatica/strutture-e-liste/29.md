What is the triple of keys of `front`, `rear` and the successor of `last` after this fragment? Include `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node last = {6, NULL};
struct Node first = {2, &last};
struct Node fresh = {9, NULL};
struct Node *front = &first, *rear = &last;
rear->next = &fresh;
rear = &fresh;
```

- $(2,9,9)$
- $(9,9,6)$
- $(2,6,9)$
- $(6,9,2)$

## Explanation

Insertion copies the new node’s address into `last.next`. The front still designates the node with key $2$, and the rear now designates the node with key $9$. The successor of the former last node also has key $9$.
