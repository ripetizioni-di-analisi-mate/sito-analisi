A read-only function visits live nodes of type `Node`. Local cursor `p` must be able to advance to `p->next`, while a write `p->key = 4` through that cursor must be rejected because of the qualifier. Which declaration meets the contract?

- `Node *p`
- `const Node *p`
- `const Node *const p`
- `Node *const p`

## Explanation

In `const Node *p` the qualifier applies to the node as seen through the pointer. The cursor itself remains assignable and can advance. Qualifying the pointer itself with `const` would prevent the very assignment needed to move to the next node.
