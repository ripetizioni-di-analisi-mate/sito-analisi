A circular queue of capacity $5$ has `first == 4` and `used == 2`. What pair `(first, used)` follows one successful dequeue?

- $(0,1)$
- $(1,1)$
- $(4,1)$
- $(0,2)$

## Explanation

The removed element occupies the initial position $4$. The new start is $(4+1)\bmod5=0$. Since exactly one element is removed, the length changes from $2$ to $1$.
