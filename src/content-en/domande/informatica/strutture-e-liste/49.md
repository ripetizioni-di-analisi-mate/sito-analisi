Two live, initialized records have type `struct T { char kind; int n; };`. They represent the same data exactly when the values of both members match. Which C17 test expresses precisely this criterion even if the type has padding?

- `&a == &b`
- `a.kind == b.kind || a.n == b.n`
- `a.n == b.n`
- `a.kind == b.kind && a.n == b.n`

## Explanation

Both conditions on the data must hold, so `&&` is required. Distinct objects can store the same data and therefore have different addresses. Comparing the members directly leaves any padding bytes out of the test.
