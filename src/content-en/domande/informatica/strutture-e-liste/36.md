An array stack pops its top by decreasing `used`. Which pair gives the physical contents of `data[1]` and the logical top after this fragment?

```c
int data[3] = {5, 8, 0};
int used = 2;
--used;
```

- $(0,5)$
- $(8,5)$
- $(8,8)$
- $(5,5)$

## Explanation

The decrement changes the logical length from $2$ to $1$ and leaves the array cells unchanged. Cell $1$ retains $8$, while the stack contains only cell $0$, with value $5$.
