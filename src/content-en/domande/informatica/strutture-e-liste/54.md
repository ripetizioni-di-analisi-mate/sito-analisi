A sorted list contains a node of key $1$, node `B` of key $3$, node `C` of key $3$, then a node of key $6$, in that order. Starting at the head, the search passes nodes while their keys are strictly less than $3$. Node `N` of key $3$ is inserted immediately before the first node not passed. In what order do the three nodes of key $3$ appear afterwards?

- `N, C, B`
- `B, N, C`
- `B, C, N`
- `N, B, C`

## Explanation

Key $1$ satisfies the strict comparison, but the key in node `B` makes it false. The insertion therefore takes place before `B`. The links within the suffix keep `B` before `C`, giving the order `N, B, C`.
