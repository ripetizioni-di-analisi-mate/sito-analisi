An owning list contains the distinct dynamically allocated nodes `A→B→C`. The caller holds a borrowed reference to `C`. An operation unlinks and frees only `B`, linking `A` to `C`. Which statement about the reference to `C` is correct after the call?

- It changes automatically to point to `A`
- It becomes null when `B` is freed
- It still points to the same live node `C`
- It becomes unusable because `C` is now the second node

## Explanation

The borrowed address belongs to an allocation distinct from `B`. The operation changes the predecessor and logical position of `C` but preserves the object and its lifetime. The reference therefore continues to designate `C`.
