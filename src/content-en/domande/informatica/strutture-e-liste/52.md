The caller’s list starts at node `A`, followed in order by nodes `B` and `C`. Function `void advance(Node *h) { h = h->next; }` is called as `advance(head)`. All three nodes are live and the function returns no pointer. Which node is first in the caller’s list after the call?

- `C`, because the function would have reached the tail
- `A`, because the assignment changed the local parameter
- No node, because the parameter goes out of scope
- `B`, because `h` was initialized from `head`

## Explanation

Local parameter `h` receives a copy of the pointer value in `head`. Assigning a different address to `h` changes only that copy, and the code reads `next` without assigning to it. The caller’s head and the link from `A` to `B` therefore both remain in place.
