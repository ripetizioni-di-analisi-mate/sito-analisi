The head remains `&a`. Which node leaves the chain after the assignment? Include `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node d = {9, NULL};
struct Node c = {7, &d};
struct Node b = {6, &c};
struct Node a = {3, &b};
b.next = c.next;
```

- `c`
- `a`
- `b`
- `d`

## Explanation

`b.next` is updated with the old successor of `c`, namely `d`. The path from the head becomes `a`, `b`, `d`. Thus `c` remains a live automatic object and becomes unreachable in the list.
