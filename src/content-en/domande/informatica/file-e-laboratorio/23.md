A stream supplies only `abcdef` and a newline. How many calls to `fgets(buffer, 4, file)` succeed before the first `NULL` result? There are no read errors.

- $1$
- $2$
- $3$
- $4$

## Explanation

Each call can keep at most $3$ input characters. The first receives `abc`, the second `def` and the third receives only the newline. A further attempt is needed to get `NULL`, so there are $3$ successful calls.
