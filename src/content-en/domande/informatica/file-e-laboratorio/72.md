One team saves an entire `struct record` object directly with `fwrite`. A second team must read it on a different C17 implementation. Which change defines an interoperable format?

- Give the local variables identical names in both programs.
- Specify external field widths, representations and order, and encode the fields explicitly.
- Use filenames with the same extension.
- Check only that `sizeof(struct record)` is the same.

## Explanation

The in-memory layout may include padding, and multibyte fields may have different byte orders. Two structures of the same size can therefore represent the same values differently. Specifying each field in the external format allows both programs to reconstruct the same data.
