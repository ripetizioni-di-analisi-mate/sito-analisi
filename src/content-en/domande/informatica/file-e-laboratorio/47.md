On a seekable stream opened with `"w+"`, a program successfully writes the text `ABC`. It must now read the first letter from that same stream. Which successful call sets the required position and permits the change from writing to reading?

- `fflush(f)`
- `clearerr(f)`
- `fseek(f, 0L, SEEK_SET)`
- `ftell(f)`

## Explanation

Positioning moves to the beginning and supplies the intervening operation required for an update stream. A flush alone also permits the change from output to input, but leaves the position after C, so A will not be the next character read.
