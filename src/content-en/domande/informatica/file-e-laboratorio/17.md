The result of `fgetc(file)` must be kept in its own type so it can be compared with `EOF` before other conversions. Which declaration uses the return type?

- `char ch;`
- `unsigned char ch;`
- `size_t ch;`
- `int ch;`

## Explanation

The return type of `fgetc` is `int`. The comparison with `EOF` happens before converting the result to `char`, because conversion can lose the distinction between the sentinel and a character read from the stream.
