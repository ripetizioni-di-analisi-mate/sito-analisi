Binary output requests four three-byte elements. On a stream initially free of errors, `fwrite(data, 3, 4, f)` returns 2 and the error indicator is set. What does C17 guarantee about the count and file position after this error?

- Two bytes were written and the current position is certainly 2.
- All four elements were completed because the return was positive.
- The count reports two elements written in full. After the error the file position is indeterminate.
- No data can have been written, so it is sufficient to repeat the whole request.

## Explanation

The return value counts elements, so two complete elements account for six bytes. An output error leaves the resulting stream position indeterminate. The count alone cannot establish a safe position for resuming output. A known state must first be re-established according to the file format’s contract.
