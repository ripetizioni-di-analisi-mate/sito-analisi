The format declares a field consisting of **exactly two decimal digits**, followed by the string terminator. The candidate `"7"` converts without any residue and its value lies between 0 and 99. What must the validator still do?

- Replace base 10 with base 2.
- Always accept because 7 is representable.
- Treat the field as valid only if `errno == ERANGE`.
- Check the lexical form and reject `"7"` because it contains only one digit.

## Explanation

The numeric range accepts the value written as `"7"` and the one written as `"07"` equally. The specification distinguishes the spellings by character count. The validator must therefore check two digit positions and the following terminator in addition to any properties of the value.
