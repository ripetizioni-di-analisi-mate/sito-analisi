Assume `INT_MAX == 32767`. A complete `strtol` conversion of `"40000"` succeeds. The integer is to be stored in an `int` only if representable. Which decision satisfies the specification?

- Accept it because `strtol` converted it.
- Accept it and store `INT_MAX`.
- Accept it if the last character indicates the end of the string.
- Reject the data before conversion to `int`.

## Explanation

The `long` result is $40000$, whereas the destination type has maximum $32767$. The text is numerically valid and the value lies outside the required range. Reject it before casting because the contract requires preserving the value exactly.
