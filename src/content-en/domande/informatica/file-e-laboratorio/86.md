A lab task requires a report only after the entire input has been read without error; the total fits in memory. A read error after ten records must produce only a diagnostic. Which arrangement of operations satisfies the contract?

- Treat a failed read as a rejected line and always continue.
- Print the tenth total as final before checking the indicators.
- Accumulate locally, check the read outcome, and write the report only after normal completion.
- Write each prefix to `stdout` and announce the error at the end.

## Explanation

The ten records describe only the observed prefix. By delaying output, the program can still choose between the complete report and the diagnostic alone after inspecting the indicators. A prefix already sent to an output stream cannot be retracted portably.
