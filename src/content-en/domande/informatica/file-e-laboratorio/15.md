A file exists. The first write must add a record after the existing data, without repositioning the stream. Which `fopen` mode guarantees this if opening succeeds?

- `"a"`
- `"w"`
- `"r"`
- `"r+"`

## Explanation

In mode `a`, writes take place at the end of the file. Mode `w` truncates an existing file and `r` permits reading only. Mode `r+` also permits writing, but without repositioning the initial position is at the start.
