A binary file contains the three bytes A, B, C. A program opens it with `"a+b"`, successfully seeks to the beginning, writes X, and closes successfully. What sequence of data bytes remains on a system that adds no padding bytes?

- `ABCX`
- `XBC`
- `X`
- `XABC`

## Explanation

Append mode forces each subsequent write to the current end of the file, even after positioning. Writing X therefore adds a fourth byte. Seeking can be useful for reading, but it does not turn an append-mode write into an overwrite.
