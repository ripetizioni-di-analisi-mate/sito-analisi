A function validates conversion by checking `errno == ERANGE` after `strtol`. Which statement immediately before the call prevents a leftover `ERANGE` from being attributed to it?

- `errno = ERANGE;`
- `errno = 0;`
- `end = NULL;`
- `clearerr(file);`

## Explanation

The value of `errno` can come from an earlier call. Assigning $0$ before `strtol` means a later `ERANGE` reports a range issue in the conversion being examined. The stream error indicator is a separate state.
