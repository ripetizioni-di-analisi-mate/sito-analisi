`fgetc(file)` returns `EOF`. The indicators were clear before the call. Now `ferror(file) != 0` is true and `feof(file) != 0` is false. Which event did the read report?

- End of file reached without error.
- Successful read of a newline.
- A read error.
- Successful read of a null character.

## Explanation

The value `EOF` indicates that the read delivered no character. The indicators identify the cause. Here only the error indicator is set, so the result reports a read error.
