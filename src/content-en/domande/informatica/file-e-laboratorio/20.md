The text starts with `Q`, newline, `R` and newline. After reading to the end, the program successfully repositions with `rewind(file)`. Which character does the next successful `fgetc(file)` read return?

- `R`
- `'\n'`
- `'\0'`
- `Q`

## Explanation

`rewind` restores the position to the start of the stream and allows reading to resume. The first position contains `Q`. Earlier reads advanced the position, but repositioning moved it back before that letter.
