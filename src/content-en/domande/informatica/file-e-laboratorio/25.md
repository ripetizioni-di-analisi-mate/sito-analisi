The buffer already contains the null-terminated string `12`. The next `fgets` call encounters end of file before reading a character and returns `NULL`. Which string is still in the buffer?

- `"12"`
- `""`
- `"1"`
- `"2"`

## Explanation

At end of file before any character is read, `fgets` returns `NULL` and leaves the array unchanged. Thus it retains `12`. The retained data belongs to the previous read and the new `NULL` result prevents counting it as a further line.
