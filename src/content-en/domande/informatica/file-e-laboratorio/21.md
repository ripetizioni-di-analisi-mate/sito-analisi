After a read attempt at end of file, call `clearerr(file)`. The file does not change. Which pair gives `feof(file) != 0` immediately after `clearerr` and after the next read attempt?

- `1, 0`
- `0, 1`
- `1, 1`
- `0, 0`

## Explanation

`clearerr` clears the indicators and keeps the position. The first comparison is therefore $0$. The next attempt starts from the same end position and encounters the end again, so it sets the indicator. The second comparison is $1$.
