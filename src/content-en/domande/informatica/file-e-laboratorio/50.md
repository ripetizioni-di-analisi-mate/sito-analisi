On the given system, text output translates each `'\n'` into two external bytes, CR and LF. Each of the letters A and B occupies one external byte. The successful write is `fprintf(f, "A\nB\n");`. Which pair gives the return value and the number of external bytes occupied by those characters?

- 6 and 6
- 6 and 4
- 4 and 6
- 4 and 4

## Explanation

The format transmits four characters to the stream, so the function returns 4. Externally each of the two letters occupies one byte and each of the two line breaks occupies two. The resulting size is 1 + 2 + 1 + 2 = 6 bytes.
