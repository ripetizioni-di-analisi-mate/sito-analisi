A parser immediately adds the first numeric field of each line to a total. Only afterwards does it check whether the second field is an allowed class. The specification requires excluding **the entire line** on error. Which structure satisfies this rule even with negative values?

- Replace all negative values with zero before the first update.
- Convert and validate every field in local variables, then update the aggregates once if the line is valid.
- Reset the whole total every time a class is wrong.
- Update the total anyway and skip only the line count.

## Explanation

Tentative data stay separate from report state until the entire record is validated. An invalid line then changes neither count nor total, while a valid line contributes its original value regardless of its sign.
