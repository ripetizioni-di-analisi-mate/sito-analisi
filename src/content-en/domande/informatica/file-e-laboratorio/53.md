The next character in a text stream is X. A lab loop repeats `fscanf(f, "%d", &n)` while the result differs from `EOF`, with no other input operation. What describes the first attempt and the risk on the next one?

- It returns 0 and automatically discards the entire record.
- It returns 0 and the next attempt can encounter the same X.
- It returns `EOF` because X is not a digit.
- It returns 1 by assigning the character code for X.

## Explanation

The decimal directive meets a nonmatching character before assigning a value. The result is zero assignments, and X remains unread. A parser that intends to continue must consume or discard the record according to its policy; otherwise the loop can make no progress.
