The specification allows at most $5$ data characters before the newline. `fgets(buffer, 6, file)` has read exactly $5$ characters, none a newline. A successful extra read obtains the newline. Does the line meet the length bound?

- No, it has $6$ data characters.
- Yes, it has exactly $4$ data characters.
- No, the newline belongs to the next line.
- Yes, it has exactly $5$ data characters.

## Explanation

The bound excludes the newline, and the first fragment already contains $5$ data characters. The extra character closes the same line. The line therefore has data length $5$, exactly the permitted maximum.
