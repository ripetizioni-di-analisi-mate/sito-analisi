The format permits a final line without a newline only when the file ends normally. A parser has saved the digits of an unterminated line; the attempt to continue returns `EOF` and `ferror(f)` is nonzero. How should the outcome be classified?

- A definitely overlong line regardless of the limit.
- Normal end because the character variable contains `EOF`.
- A valid record because the digits already read form a number.
- A read error, without accepting the line as a complete final record.

## Explanation

The special return value alone does not identify the reason for stopping. The error indicator shows that the read did not finish normally. The stored digits may be only a prefix, so the contract does not permit counting them as the final record.
