In the C locale, declare `const char text[] = "\t-19;";` and call `strtol(text, &end, 10)`. What is `end - text`, measured in array positions?

- $3$
- $5$
- $2$
- $4$

## Explanation

The tab occupies index $0$ and is skipped. The sign and digits occupy $1$, $2$ and $3$. The first unconsumed character is the separator at the next index $4$, so the difference is $4$.
