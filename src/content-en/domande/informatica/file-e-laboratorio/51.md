On a seekable text stream `f`, `long mark = ftell(f);` returned a valid position immediately before a record. After reading the record, it must be read again. Which portable operation reuses that exact position on the same stream?

- `fseek(f, mark, SEEK_SET)`
- `fseek(f, mark + 1L, SEEK_SET)`
- `fseek(f, -mark, SEEK_END)`
- `fseek(f, mark, SEEK_CUR)`

## Explanation

For a text stream the position returned by `ftell` may encode environment-specific information. To restore it, pass it unchanged to `fseek` with origin `SEEK_SET` and check the result. Treating it as a byte distance is not guaranteed.
