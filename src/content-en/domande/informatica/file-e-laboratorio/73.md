A function calls `fwrite(buf, 1, count, f)` with a valid pointer, a correctly opened binary stream, and `count == 0`. The observed return is zero and the stream had no previous errors. Which interpretation is justified?

- Zero requested and zero written elements constitute a complete result.
- The return indicates that the stream was closed.
- A terminating element was written anyway.
- A zero return always signals a write error.

## Explanation

The relevant comparison is between the numbers of written and requested elements. For an empty request, `fwrite` returns zero without changing the stream state. A rule that treats zero as an error would therefore confuse this empty case with an incomplete write.
