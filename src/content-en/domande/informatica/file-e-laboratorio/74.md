Generating a report completed a call to `fprintf` with a positive return. A subsequent `fflush(out)` on the output stream returns `EOF`. The contract permits reporting success only if all output stages succeed. Which outcome must be retained even if the subsequent close succeeds?

- The successful close proves that no earlier stage failed.
- Saving succeeded because `fprintf` had counted some characters.
- The `fflush` check concerns only the end of input.
- Report generation encountered an output error.

## Explanation

Formatted output may deliver data to the library buffer. The subsequent transfer can still fail, and the return from `fflush` reports that failure. A successful close is a separate outcome and does not erase the error already observed.
