A binary stream supplies exactly seven bytes without error. The array `unsigned char r[3][3];` has room for three three-byte records. After `size_t n = fread(r, sizeof r[0], 3, f);`, how many records can be processed as fully read?

- Zero, because the entire request was not satisfied.
- Three, because one byte of the third record is present.
- Seven, one for each byte received.
- Two, as indicated by the return value `n == 2`.

## Explanation

The first six bytes make two complete records. The seventh is insufficient to make a third, and a partial element is not included in the return count. The program can process the first two and report a truncated file if the format requires every record to be complete.
