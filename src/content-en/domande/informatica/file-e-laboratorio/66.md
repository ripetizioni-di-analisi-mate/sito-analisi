A line is a comment only if its first non-space character is `#`. All other records must contain a decimal integer followed only by spaces. Which classification respects both rules for `"  #7"` and `"7 #fine"`, in that order?

- Two valid readings of value 7.
- Comment, then valid reading 7.
- Comment, then invalid record.
- Two comments.

## Explanation

On the first line the first significant character is the comment marker. On the second it is digit 7, so the numeric-record grammar applies. After the digit and space, `#fine` remains, which that grammar does not allow.
