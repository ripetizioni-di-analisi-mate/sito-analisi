A line may contain at most three digits. The input is `"12345\n7\n"`, and an initial fragment has already shown that the first line is too long. The program must discard it and continue. Which state is correct before parsing measurement 7?

- One rejected record and every character through the first newline consumed.
- Measurement 45 accepted because the suffix has two digits.
- Scanning has restarted at the beginning of the file.
- Two rejected records because the first line arrived in two fragments.

## Explanation

The limit applies to the physical line. Once exceeded, all fragments through its separator still belong to the same rejected record. Consuming the separator as well allows the next read to start at digit 7, which begins a separate record.
