Two numeric fields must be separated by at least one ordinary space or horizontal tab. A parser accepts any character classified by `isspace` in the C locale instead. Which string exposes a difference between the two rules?

- `"2\v5"`
- `"2\t5"`
- `"2 5"`
- `"2 \t5"`

## Explanation

The character `'\v'` is a vertical tab. It belongs to the C locale’s whitespace set, but the record grammar allows only a space or a horizontal tab as the separator. The other strings use delimiters permitted by both rules.
