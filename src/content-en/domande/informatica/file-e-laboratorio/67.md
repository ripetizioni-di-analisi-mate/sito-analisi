On a binary stream, `fwrite(block, 3, 2, f)` succeeds completely; `block` points to at least six initialised bytes. Which comparison checks the return value using the unit specified by the function?

- Compare it with 3, the size of each element.
- Compare it with 2, the number of three-byte elements.
- Compare it with 6, the total number of bytes.
- Compare it with `EOF` as the sole successful outcome.

## Explanation

The product 3 × 2 determines the amount transferred, namely six C bytes. The return value of `fwrite`, however, counts successfully written elements. Each element groups three bytes and there are two groups, so the full return value is 2.
