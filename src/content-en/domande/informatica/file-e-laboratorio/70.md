An input stream `f` is at the start of a file containing A, B, C in that order. The program initializes `FILE *alias = f;`. It then calls `fgetc(f)`, `fgetc(alias)`, and `fgetc(f)` in three separate statements. If there are no errors, which character sequence results?

- A, A, B
- A, B, C
- A, A, A
- A, B, B

## Explanation

Copying the pointer makes both names refer to the same stream, which has a single current position. The first read advances it to B, the read through `alias` advances it to C, and the final call returns C. Independent read positions would require two distinct streams.
