The array `char tag[] = {'A','\0','B','\0'};` contains a three-byte tag followed by an extra zero. A binary format requires **the first three bytes**. Which successful call on a binary stream emits all of them in the required order?

- `fwrite(tag, 1, 3, f)`
- `fwrite(tag, 1, sizeof tag, f)`
- `fprintf(f, "%s", tag)`
- `fputs(tag, f)`

## Explanation

The first zero is part of the required data. Functions treating `tag` as a string stop at that zero and transmit only A. Writing exactly three bytes includes A, zero and B, whereas using `sizeof tag` would also include the fourth byte.
