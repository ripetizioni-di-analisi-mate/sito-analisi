A line contains two decimal integers separated by a comma. After consuming the comma in `"8, +"`, `strtol` is called with base 10 and pointer `p` to the following space. Which check detects precisely that the second field contains no integer?

- `*p == '+'`
- `value == 0`
- `errno == ERANGE`
- `end == p`

## Explanation

There is no digit after the space and sign, so no conversion occurs and `end` is set to the original pointer `p`. A valid field such as `" 0"` would also yield zero, so the numeric return value alone would not distinguish the cases.
