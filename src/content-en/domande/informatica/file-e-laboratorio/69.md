A binary format uses one length byte followed by that many data bytes. Lengths are nonnegative and zero is permitted. The stream supplies hex bytes `02 41 00 00 01 5A`. What are the three record lengths in order?

- `2, 1, 0`
- `2, 0, 1`
- `2, 0, 0`
- `2, 1, 90`

## Explanation

The first 02 announces data bytes 41 and 00. The next 00 is a new header and describes an empty record. The remaining header 01 has one data byte, 5A. The position in the stream determines which zero belongs to the data and which is a length.
