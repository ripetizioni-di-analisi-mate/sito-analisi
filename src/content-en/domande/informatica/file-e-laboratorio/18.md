The indicators are initially clear. A successful `fgetc(file)` call returns the file’s last character. Immediately afterwards, before another read, what is `feof(file) != 0`?

- $1$
- $0$
- $-1$
- $2$

## Explanation

The call returned a character successfully. The end-of-file indicator is set when a read encounters the end. Since no later attempt has encountered it yet, the indicator stays clear and the comparison against zero is $0$.
