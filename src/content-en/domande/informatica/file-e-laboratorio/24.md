Assume a stream delivers only the two characters `35`, followed by end of file without a newline. How many consecutive `fgets(buffer, 8, file)` calls succeed before the first `NULL` result, with no errors?

- $0$
- $1$
- $2$
- $3$

## Explanation

The first call reads two characters before the end, so `fgets` delivers the string `35`. The second reads no characters and returns `NULL`. One call succeeds.
