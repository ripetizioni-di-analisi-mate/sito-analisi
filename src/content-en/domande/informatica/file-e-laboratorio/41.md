A file is read without errors, but all lines are discarded. The contract requires the count of valid records and their maximum, if one exists. Which result meets the contract?

- Count $0$, maximum $0$.
- Count $0$, no maximum.
- Count $0$, maximum `INT_MIN`.
- Read error, no count.

## Explanation

The count increases only for valid records and stays $0$. The set of accepted measurements is empty, so it has no element that could be its maximum. Values sometimes used to initialize an accumulator are not file measurements.
