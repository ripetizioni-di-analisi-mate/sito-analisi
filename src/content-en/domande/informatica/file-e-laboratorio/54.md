Valid readings may be negative and arrive on a stream that cannot be rewound. One pass must count how many readings equal the final maximum. After initializing the maximum and its count from the first valid reading, which update works for each new value `v`?

- If `v` is greater, increase the count without changing the maximum.
- If `v` is equal or greater, replace the maximum and always reset the count to one.
- If `v` is greater, replace the maximum without resetting the old count.
- If `v` is greater, replace the maximum and restart at one. If it is equal, increase the count. Otherwise leave the state unchanged.

## Explanation

After each record the count must give the occurrences of the maximum in the prefix read so far. A new maximum exceeds every earlier value, so its only occurrence so far is the reading just processed. An equal reading adds an occurrence, and a lower one makes no difference. For −3, −3, −1, −1 this takes the count from two occurrences of the old maximum to two of the new one.
