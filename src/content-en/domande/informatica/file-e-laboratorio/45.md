The valid lines supply $4$, $-2$, $6$, $5$ and $-10$ in order. The sum starts at zero and the program stops reading as soon as it exceeds $10$. How many values are added?

- $3$
- $5$
- $4$
- $2$

## Explanation

After the first three updates the sum is $4$, $2$ and $8$ in order, so reading continues. The fourth value takes it to $8+5=13$, which exceeds $10$. The fifth value is not added, so the required count is $4$.
