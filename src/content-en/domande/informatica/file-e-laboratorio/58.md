A binary stream supplies the characters `'A'`, `'\0'`, `'B'`, and `'\n'` in order. The first call to `fgets` into an eight-element array succeeds. What does comparing `strlen(buf)` with the characters actually consumed show?

- `strlen(buf)` is 1 and the read consumed four characters.
- `strlen(buf)` is 1 and B is still in the stream.
- `strlen(buf)` is 0 because the buffer contains an embedded zero.
- `strlen(buf)` is 4 and the read consumed four characters.

## Explanation

The null character from the file is data to `fgets`, which continues to the newline in this example. To `strlen`, that same null at index 1 marks the end of the string. The string length therefore does not measure the number of characters transferred here.
