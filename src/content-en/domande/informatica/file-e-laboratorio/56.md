A seekable input stream contains the characters A, B, C. After reading A, its position is saved with `fgetpos(f, &mark)`, where `mark` has type `fpos_t`. The program then reads B, calls `ungetc('X', f)`, and calls `fsetpos(f, &mark)`. All operations succeed. Which character does the next `fgetc(f)` return?

- A
- B
- C
- X

## Explanation

The saved position is just after A and immediately before B. Initially X is pushed back onto the stream, but successful repositioning undoes the effects of `ungetc` and restores the saved position. The next read therefore encounters B again.
