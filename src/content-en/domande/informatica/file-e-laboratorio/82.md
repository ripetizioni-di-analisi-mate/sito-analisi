The lines are `A 2`, `B 1`, and `A 5`. The file does not promise that records of the same category are adjacent. An algorithm permanently closes a group as soon as the category changes. What property must the required “one line per category” report have?

- One A line totalling 2 because its first run has ended.
- Two A lines, one with 2 and one with 5.
- One B line totalling 6 because the final record follows B.
- One A line totalling 7 and one B line totalling 1.

## Explanation

Grouping uses the category as its key, independent of runs of adjacent equal categories. Both A records must contribute to the same total even with B between them. The algorithm that closes groups at the first change would require an additional ordering precondition.
