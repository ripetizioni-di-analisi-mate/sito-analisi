A seekable text stream must be moved back to the start after reading some characters. No position obtained with `ftell` is available. Which call uses a portable allowed offset and returns to the start if it succeeds?

- `fseek(file, 0L, SEEK_SET)`
- `fseek(file, 1L, SEEK_SET)`
- `fseek(file, 0L, SEEK_CUR)`
- `fseek(file, 0L, SEEK_END)`

## Explanation

A zero offset is allowed for a text stream. With `SEEK_SET` the origin is the start, so repositioning reaches the required position. With `SEEK_CUR` and `SEEK_END` the origin is the current position and the end, respectively. An arbitrary nonzero offset is not portable in this case.
