A C17 program must create a new text report and report failure if the path already identifies an existing file. Which mode expresses both requirements in one call to `fopen`?

- `"w"`
- `"a"`
- `"wx"`
- `"r+"`

## Explanation

The `x` modifier with `w` requires the file not to exist, so an existing file causes the open to fail. Plain `w` can truncate the old report, while `a` can extend it. The program checks the returned pointer before writing.
