A parser reached end-of-file without error. A call to `ungetc('Q', f)` succeeds, and no other operations intervene. What is observed immediately afterwards and on the next `fgetc(f)`?

- The end-of-file indicator is cleared and the read returns character Q.
- Character Q is permanently appended to the external file.
- The read returns Q only after reopening the file.
- The end-of-file indicator remains set and the read returns `EOF`.

## Explanation

A successful pushback makes the character available as the next input character and clears the end-of-file indicator. The pushed character belongs to the stream’s input mechanism. The operation does not modify the persistent contents of the external file.
