A routine writes `"OK"` with `fputs("OK", f)`. The test must determine whether **this call** reports an error without assuming a particular success value. Which condition correctly uses its result `r`?

- `r == 2`
- `r == EOF`
- `r != 0`
- `r != 2`

## Explanation

The contract of `fputs` gives `EOF` on error and a nonnegative value on success. That nonnegative value is not promised to equal the string length. A character count is instead part of the contract of other functions such as `fprintf`.
