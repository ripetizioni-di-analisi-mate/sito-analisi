The text is the decimal representation of `LONG_MAX` followed by digit `0`. In the C locale, clear `errno` and run `strtol(text, &end, 10)`. Which pair gives the returned value and the range indicator?

- `LONG_MAX` and `errno == 0`.
- `LONG_MAX` and `errno == ERANGE`.
- `LONG_MIN` and `errno == ERANGE`.
- `0` and `errno == ERANGE`.

## Explanation

Appending that digit multiplies the positive maximum by $10$. The text therefore represents a number too large for `long`. `strtol` returns `LONG_MAX` and sets `errno` to `ERANGE`. A return of `LONG_MAX` alone would also be consistent with the exact maximum.
