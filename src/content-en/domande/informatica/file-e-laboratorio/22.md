An array of $8$ elements receives a successful `fgets(buffer, 8, file)` call. The next line is `AB` followed by a newline. At which index is the null terminator written by the call?

- $3$
- $2$
- $4$
- $7$

## Explanation

The result contains `A` at index $0$, `B` at index $1$ and the newline at index $2$. There is still room in the buffer, so the null is placed in the next cell, index $3$.
