A program must write a single line containing the literal text `nessun dato` (“no data”) if there are no valid readings. A suite tests only an empty file. Which second input exercises the **same** output rule while also passing through the line-rejection logic?

- A file containing one valid line with zero.
- A file with two valid readings of opposite signs.
- A file containing two complete lines, both nonnumeric.
- A file with one valid reading and one rejected line.

## Explanation

An empty file does not enter the validation loop. Two rejected lines do exercise the parser while leaving the valid count at zero. A valid reading equal to zero is still a data item and must be distinguished from having no readings.
