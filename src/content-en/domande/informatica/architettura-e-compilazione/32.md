A C17 program preprocesses the following code. Which pair gives the string literal in the initializer for `label` and the initial value of `amount`?

```c
#define UNIT 5
char label[] = "UNIT";
int amount = UNIT;
```

- `"5"` and $5$
- `"UNIT"` and $5$
- `"UNIT"` and $4$
- `"5"` and $4$

## Explanation

The string literal already forms one complete token, so its four characters stay `UNIT`. The identifier token `UNIT` in the initializer for `amount` matches the macro and expands to $5$.
