Two C17 source files are translated separately and contain the following code, each in the named file. A third source calls both external functions with compatible declarations. What is `left() + right()` once the project is linked and run?

`left.c`

```c
static int level(void) { return 3; }
int left(void) { return level(); }
```

`right.c`

```c
static int level(void) { return 11; }
int right(void) { return level(); }
```

- $6$
- $22$
- Linking fails due to two definitions of `level`
- $14$

## Explanation

Each `static` definition is internal to its own unit. So `left` calls the function that returns $3$, and `right` the function that returns $11$. The two external names `left` and `right` are distinct. The sum is $3+11=14$.
