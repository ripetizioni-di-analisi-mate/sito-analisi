A machine performs one memory read to fetch each instruction it executes, including `HALT`. The actual trace is `LOAD x`, `JZ fine`, `HALT`. `LOAD` also reads its data operand, while `JZ` has its target encoded in the instruction and tests a register. There are no caches or speculative fetches. How many memory reads does the bus record?

- $3$
- $1$
- $5$
- $4$

## Explanation

There are three fetches, one for each instruction in the trace. Only `LOAD` adds a data read. The branch target was already read as part of `JZ`, giving $3+1=4$ reads in total.
