A circuit receives $10$-bit addresses but uses only the lowest nine bits to select a memory cell. A value is written to address `0x12A`. Which other address must select the same cell?

- `0x1AA`
- `0x02A`
- `0x12B`
- `0x32A`

## Explanation

The ignored bit has weight $2^9=512$, or `0x200`. Flipping only that bit changes `0x12A` to `0x32A` while preserving every bit used by the circuit. Each other choice changes at least one of the nine selection bits.
