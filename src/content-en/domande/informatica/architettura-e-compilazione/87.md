In a hosted C17 environment, the output stream is working normally. This program runs to completion. What termination status does it report?

```c
#include <stdio.h>
int main(void)
{
    puts("ok");
}
```

- Success, as if `main` had executed `return 0;`
- The exact integer value returned by `puts`
- A status derived from the characters in `"ok"`
- Failure because there is no explicit `return`

## Explanation

In C17 reaching the closing brace of the initial call to `main` is equivalent to returning zero. `puts` writes the string and a newline, but the program discards the call’s return value. The status reported to the environment therefore indicates success.
