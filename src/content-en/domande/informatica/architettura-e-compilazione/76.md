With a GCC-compatible driver, `cfg.h` defines `GAIN` as $2$. The result of `cc -E sample.c -o sample.i` is saved for a source containing `int gain = GAIN;` after including `cfg.h`. Later only the header changes, setting `GAIN` to $7$. Which input allows the object file to contain the updated initializer without manually editing intermediate files?

- The old `sample.i`, compiled directly
- The old assembly file, simply reassembled
- The old object file, simply relinked
- `sample.c`, to be preprocessed again with the updated header

## Explanation

The `.i` file already contains the value $2$ and has no active include that would reread `cfg.h`. Preprocessing `sample.c` again picks up the macro value $7$. Compilation then uses the new initializer when generating the object file.
