In a C17 source file `LIMIT` is not defined as a macro. After `enum { LIMIT = 3 };` there is a `#if LIMIT` directive, with `int selected = 1;` in the first branch and `int selected = 2;` in the `#else` branch. What values do `selected` and the enumeration constant `LIMIT` have in the translated program, respectively?

- $2$ and $3$
- $2$ and $0$
- $1$ and $3$
- $1$ and $0$

## Explanation

In a `#if` condition an identifier left over after macro expansion is replaced by zero. The preprocessor therefore selects the branch that initializes `selected` to $2$. The compiler separately processes the `enum` declaration, which gives `LIMIT` the value $3$.
