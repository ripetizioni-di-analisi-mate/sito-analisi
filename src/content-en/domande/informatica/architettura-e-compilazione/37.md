`main.o` contains an external reference to function `adjust`. `math.o` came from source where the only function with that name was defined with file-scope `static`. Ordinary object files are used and no other unit provides `adjust`. Why does linking leave the reference unresolved?

- The function name must match the source filename
- The two project objects can be linked only in separate invocations
- The definition has internal linkage
- A symbol called by main must be defined in a standard library

## Explanation

For that function, file-scope `static` gives it internal linkage. The reference from `main.o` seeks a definition for an external name, so an internal function from another unit cannot satisfy it. Linkage across translation units matters as well as the name written in C.
