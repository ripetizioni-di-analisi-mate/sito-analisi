A shell runs `app > risultato.txt`, redirecting only `stdout` to the empty file. `stderr` remains connected to the terminal. The C17 program writes `"A"` to `stdout` and `"B"` to `stderr`, then exits successfully. Both writes succeed. What does the file contain after termination?

- Only `B`
- `A0`
- `AB`
- Only `A`

## Explanation

Redirection changes the destination of writes to `stdout`, so `A` reaches the file. The second write uses `stderr`, sending `B` to the terminal. Successful termination is reported to the environment separately from the bytes in the file.
