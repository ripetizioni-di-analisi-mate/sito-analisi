Register `A` holds $9$ and cell $12$ contains $4$. After a single transfer, `A` still holds $9$ and cell $12$ contains $9$. The bus reports the address, data and direction separately. Which transaction can account for the change?

- Write to address $9$ with data $12$
- Write to address $12$ with data $9$
- Read from address $9$ with data $12$
- Read from address $12$ with data $4$

## Explanation

The location that changes identifies the destination, so the address on the bus is $12$. The cell’s new contents give the transferred data, namely $9$. A write copies the value of `A` and leaves the register holding $9$.
