The driver is GCC-compatible. `main.o` contains the definition of `main` and a reference resolved only by `model.o`. Both object files are already available. Which command requests the executable `app` using both required definitions?

- `cc -E main.o model.o -o app`
- `cc -c main.o model.o -o app`
- `cc main.o model.o -o app`
- `cc main.o -o app`

## Explanation

With both objects as inputs and no option that stops at an earlier stage, the driver invokes the linker. `-o app` names the resulting executable. Omitting `model.o` would leave the reference without the specified definition.
