A processor uses byte addresses. A branch instruction starts at byte $50$ and is $3$ bytes long. When the branch is taken, the machine adds a signed displacement to the address of the first byte following the instruction. Which displacement sends the next fetch to byte $47$?

- $6$
- $3$
- $-6$
- $-3$

## Explanation

The instruction occupies bytes $50$, $51$ and $52$, so the reference address is $53$. Solving $53+d=47$ gives $d=-6$. Using $50$ as the base would measure the displacement from the start of the instruction.
