A four-line direct-mapped cache starts empty. Its four-byte blocks are numbered from byte $0$, and block $b$ uses line $b\bmod4$. Reading a line that holds a different block or is empty loads the requested block. With no other accesses, how many misses occur for reads $0$, $4$, $8$, $12$, $16$, $4$, $0$, $8$?

- $6$
- $4$
- $5$
- $8$

## Explanation

The first five accesses request blocks $0,1,2,3,4$ in order, all misses. Block $4$ replaces $0$ in line $0$. Address $4$ then finds block $1$, while the return to address $0$ misses. The last access at address $8$ finds block $2$. There are $5+1=6$ misses.
