In hosted C17, the write to standard output succeeds. Which pair describes the characters written by `main` and the termination status category?

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%d", 8);
    return EXIT_FAILURE;
}
```

- `8`, success
- `8`, failure
- `0`, failure
- `EXIT_FAILURE`, failure

## Explanation

`printf` converts the number $8$ to the decimal digit `8` and writes it to `stdout`. Then `main` returns `EXIT_FAILURE`, which indicates failure in a hosted environment. Termination status and the characters written are separate observations.
