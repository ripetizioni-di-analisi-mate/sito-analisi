In a model with explicitly supplied ordinary object files, `main.o` calls `convert`. `conv.o` defines `convert` and calls `norm`. `base.o` defines `norm` with no further references. `plot.o` defines only `plot`, which is never called. No library provides these symbols. Which smallest set of objects satisfies the project’s references?

- All four object files
- `main.o` and `conv.o`
- `main.o`, `conv.o` and `base.o`
- `main.o` and `base.o`

## Explanation

Starting from `main.o`, the reference to `convert` requires `conv.o`. That object introduces a reference to `norm`, requiring `base.o` as well. All references are then satisfied. Adding `plot.o` would give a sufficient but larger set.
