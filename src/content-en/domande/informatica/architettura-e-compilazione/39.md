A shared header declares `int score(int value);`. Which function definition can appear in the same source after inclusion of the header with a compatible type? Consider ordinary external definitions.

- `int score(unsigned input) { return 1; }`
- `long score(int input) { return 1; }`
- `int score(int a, int b) { return 1; }`
- `int score(int input) { return 1; }`

## Explanation

For the given declaration, `score` must return `int` and take one parameter of type `int`. The parameter name may differ. Changing the parameter type, the return type or the number of parameters would change the required function type.
