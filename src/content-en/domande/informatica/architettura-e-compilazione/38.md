In a linker’s byte-placement model, a section starts at decimal address $4096$. Symbol `entry` is $28$ bytes from the start of that section. The reference to update requires the absolute address of the symbol. What value is inserted?

- $4124$
- $4096$
- $4068$
- $28$

## Explanation

The relative value $28$ gives the offset to apply to the starting address. Since it is a forward offset, the absolute address is $4096+28=4124$. The reference needs the position in the final layout, so it includes both the section start and the offset.
