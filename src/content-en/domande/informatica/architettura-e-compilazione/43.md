The executable `app` prints $18$ due to the body of a function contained in `model.o`. The body is changed and `model.o` is rebuilt. Linking the new object would make the program print $23$. The linking is static for that object. The very same previous file `app` is run, with no rebuild or modification. What does it print for the same data?

- $18$
- $23$
- $0$
- $41$

## Explanation

The old executable includes the code linked when it was created. Rebuilding `model.o` creates a different object and leaves the file `app` intact. Running the same file on the same data still produces $18$.
