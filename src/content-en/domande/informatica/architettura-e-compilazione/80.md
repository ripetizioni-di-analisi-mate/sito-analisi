In a C17 environment the header `optional_sensor.h` does not exist. This is the only reference to the file and the rest of the program is valid. Only preprocessing is requested. Which outcome is consistent with the directives?

```c
#define SENSOR 0
#if SENSOR
#include "optional_sensor.h"
#endif
int mode = SENSOR;
```

- The declaration of `mode` is excluded as well
- Preprocessing must fail because the header is missing
- The file is not looked up and `int mode = 0;` remains
- The header is looked up when `main` runs

## Explanation

The condition becomes zero, so the group between `#if` and `#endif` is skipped. The `#include` directive belongs to that group and is not executed. The initializer comes after `#endif` and contains the active macro with value zero.
