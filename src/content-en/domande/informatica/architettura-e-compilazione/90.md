A C17 source contains two implementations of `convert` in alternative branches of `#if MODE`. The executable accepts different input data on each run but loads no other code. The aim is to execute both implementations at least once. Which test plan suffices if each run calls `convert`?

- Change the header between two runs of the same binary
- Build and run one version with `MODE` set to $0$ and another with `MODE` set to $1$
- Run only the binary built with `MODE` set to $0$ twice, varying the input
- Relink the same objects twice and use different inputs

## Explanation

Preprocessing selects the implementation. Each resulting object therefore contains only the body selected for its configuration. Two builds with opposite truth values for the condition, followed by a call in each build, exercise both bodies.
