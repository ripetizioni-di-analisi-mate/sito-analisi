Two C17 files must share a single integer object with external linkage, initially $4$. Both include `state.h` and only `state.c` should supply the definition. Which pair meets these requirements?

- `extern int count;` in the header and `int count = 4;` in `state.c`
- `int count = 4;` in the header and no separate definition
- `extern int count;` in the header and no definition anywhere in the project
- `static int count = 4;` in the header and no separate definition

## Explanation

The `extern` declaration without an initializer makes the name and type known in both units. The definition in `state.c` supplies the single object and its initial value. Using `static` in the header would give each unit its own object, while an externally linked definition with an initializer in the header would introduce two definitions.
