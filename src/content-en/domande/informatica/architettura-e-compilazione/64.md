A two-line direct-mapped cache starts empty, loads a block on every miss and assigns block $b$ to line $b\bmod2$. Block $0$ and block $2$ must each be read twice. The order is free. What is the minimum possible number of misses, and which order attains it?

- $2$ misses with $0,0,2,2$
- $1$ miss with $0,0,2,2$
- $2$ misses with $0,2,0,2$
- $3$ misses with $0,2,2,0$ as the minimum possible

## Explanation

The first access to each block misses, so at least two misses are unavoidable. Grouping the two reads of each block gives miss, hit, miss, hit and attains that bound. Strict alternation evicts the previous block from line zero at every access.
