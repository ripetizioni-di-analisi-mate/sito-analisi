A header with a traditional `#ifndef` and `#define` guard encloses a single declaration `int adjust(int);`. Two separate source files each include that header twice. The guard macro is initially absent in both preprocessing contexts. How many copies of the declaration occur across the two preprocessed results, counting each result separately?

- $2$
- $1$
- $4$
- $0$

## Explanation

Within either unit, the first inclusion produces the declaration and defines the guard. The second inclusion in that unit finds the guard defined, so it skips the declaration. The units have separate contexts, so each contains one copy. Their total is $1+1=2$.
