A linker scans inputs from left to right. It always includes an explicitly named object file. From an archive it extracts only members needed to satisfy currently unresolved references, and it never revisits the archive once it has passed it. `main.o` requires `twice`. The only member of `libcalc.a` defines `twice` and requires no additional symbols. Which order resolves the reference?

- `main.o` first, then `libcalc.a`
- `libcalc.a` first, then `main.o`
- Both orders
- Neither order

## Explanation

With `main.o` first, the reference to `twice` is already unresolved when the linker reaches the archive. It therefore extracts the required member. In the reverse order the archive has already been passed when the reference appears, so its member does not enter the link.
