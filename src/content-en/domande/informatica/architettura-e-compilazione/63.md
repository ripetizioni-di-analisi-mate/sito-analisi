A direct-mapped cache has four lines. Block $b$ uses line $b\bmod4$. Two one-block tables are read alternately with no other accesses. The first occupies block $5$. Which proposed placement of the second table allows both to remain resident after the first access to each?

- Block $10$
- Block $17$
- Block $13$
- Block $9$

## Explanation

Block $5$ occupies line $1$. Blocks $9$, $13$ and $17$ also have remainder $1$ modulo four, so alternating with any of them would evict the previous block. Block $10$ has remainder $2$ and gets a different line.
