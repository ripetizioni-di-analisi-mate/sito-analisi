After these C17 directives, which value initializes `n`?

```c
#define STEP 2
#define SCALE STEP
#undef STEP
#define STEP 5
int n = SCALE;
```

- Preprocessing must report `STEP` as undefined
- $2$
- $0$
- $5$

## Explanation

The replacement list of `SCALE` contains the token `STEP`. When `SCALE` expands in the initializer, the preprocessor rescans that token using the definitions active at that point. `STEP` has already been redefined as $5$, so the result is `int n = 5;`.
