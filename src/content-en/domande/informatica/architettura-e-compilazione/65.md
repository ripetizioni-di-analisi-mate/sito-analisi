A cache starts empty, can hold every block read, and retains them all until the end with no prefetching. The requested blocks are $4,7,4,1,7,9,4$. Which property of the sequence is sufficient by itself to predict the number of misses under these assumptions?

- The largest block number, which is $9$
- The number of reads of block $4$, which is $3$
- The total number of reads, which is $7$
- The number of distinct blocks, which is $4$

## Explanation

Each block must be loaded on its first access. Every later access to that block hits because nothing can evict it. The block set is $\{1,4,7,9\}$, so there are four misses regardless of the order of repeated reads.
