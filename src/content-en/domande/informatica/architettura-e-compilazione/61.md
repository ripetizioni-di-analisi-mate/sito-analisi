At power-up a cache line has tag value zero, but its valid bit is zero. A read selects that line and requests tag zero. Which outcome must the cache report?

- A hit only if the offset is zero
- A miss, because the line does not yet hold a valid block
- A hit, because the two tags match
- A hit only if the requested byte contains zero in memory

## Explanation

A hit requires both a valid line and a matching tag. Only the second condition is satisfied here. Loading the block allows the valid bit to be set for later accesses.
