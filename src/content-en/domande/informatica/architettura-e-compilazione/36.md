With a GCC-compatible driver, all headers are found and the source after preprocessing contains the following fragment. It is compiled in C17 mode with `-c`. At which stage is the constraint violation detected?

```c
int adjust(int);
int main(void)
{
    return adjust(1, 2);
}
```

- Header lookup
- Link-time symbol resolution
- Analysis of the C code
- Execution of main

## Explanation

The visible prototype has one parameter, and the call supplies two arguments. The compiler can therefore diagnose the argument-count constraint violation within the source. The command uses `-c`, so resolving external references during linking is a separate stage.
