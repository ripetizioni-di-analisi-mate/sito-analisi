A symbol report uses `U` for an unresolved reference, `T` for an external definition and `t` for a local function. `main.o` shows `U f` and `U g`. Each option describes the symbols of a single candidate object, with no additional references. Which object, together with `main.o`, resolves both references?

- `t f` and `T g`
- `T f` and `t g`
- `t f` and `t g`
- `T f` and `T g`

## Explanation

Both references come from another object, so each name needs an external definition. Only the pair with two `T` entries supplies both definitions. A local symbol of the same name is available only within the object that contains it.
