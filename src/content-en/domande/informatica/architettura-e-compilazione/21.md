On a C17 implementation, `CHAR_BIT` is $16$ and `sizeof(unsigned short)` is $2$. How many storage bits does the representation of an `unsigned short` object occupy, including any padding bits?

- $16$
- $32$
- $2$
- $8$

## Explanation

`sizeof` counts two C bytes, and each byte has $16$ bits on this implementation. The product is $2\cdot16=32$. The number of bits contributing to the value could be smaller if the representation includes padding.
