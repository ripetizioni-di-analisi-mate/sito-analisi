In a C17 program, `int choose(void) { int t = 5; return t * 3; }` does not access volatile objects, and the function is called through a compatible declaration. A compiler emits a function that returns $15$ directly, with no machine instruction storing `t`. Which property justifies the transformation?

- The return value and observable behaviour are preserved
- C17 requires a fixed number of machine instructions for every multiplication
- Every automatic variable must have a copy in main memory
- Only the linker can eliminate a local object

## Explanation

For these operands the product $5\cdot3=15$ fits in `int`. The caller receives the same result and the local object has no other observable effects. The compiler can therefore evaluate the product during translation and return the constant.
