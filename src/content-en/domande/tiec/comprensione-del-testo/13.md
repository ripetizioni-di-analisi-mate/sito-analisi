> In an exhibition catalogue each ceramic piece carries a letter and a number. The letter identifies the room where the piece was first catalogued, the number its order of arrival in that room. When the exhibition moved, the curators found that the rooms in the new building had different letters. They discussed updating the codes. A restorer showed them photographs taken before the move. On the back of each print he had written only the code of the piece. The curators therefore added a column to the catalogue for the current location and left each object with its old identification code.

What difficulty is avoided by keeping the old code?

- Losing the direct link between earlier photographs and objects
- Displaying pieces from different previous rooms together
- Confusing the arrival number with the date of manufacture
- Having to take photographs in the new rooms

## Explanation

The code was the only reference on the photographs. Keeping it allows users to find the same objects in the catalogue. The new column answers the separate question of where each object is now.
