Read the following passage.

> An accounting firm with twelve employees experienced a data theft last year. Someone guessed an employee’s email password and downloaded documents belonging to several clients. Since then, the firm has used two-factor authentication. A password alone no longer gives employees access to their email. The system sends a code to the employee’s phone. It is valid for a few minutes and must be entered right after the password. Someone who steals a password therefore cannot use it without also having the phone.
>
> Employees complained during the first few weeks because it took a few extra steps to sign in. The owner then allowed the system to remember office computers for thirty days, so employees are asked for a code only the first time they sign in that month or when they sign in from a new device.

It can be inferred from the passage that:

- the firm lost some clients after the theft
- an employee who signs in to email for the first time from a home computer must enter the code
- employees asked the firm to stop using two-factor authentication
- an employee is never asked for the code on an office computer

## Explanation

The last sentence says that employees are asked for a code the first time they sign in that month or when they sign in from a new device. A home computer used for the first time is a new device to the system, so the employee must enter the code. The passage says that employees complained, but it does not say they asked the firm to stop using the system. The claim about office computers contradicts the text because employees must enter a code on those computers the first time they sign in that month. The passage says nothing about losing clients.
