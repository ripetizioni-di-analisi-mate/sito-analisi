Read the following passage.

> An accounting firm with twelve employees experienced a data theft last year. Someone guessed an employee’s email password and downloaded documents belonging to several clients. Since then, the firm has used two-factor authentication. A password alone no longer gives employees access to their email. The system sends a code to the employee’s phone. It is valid for a few minutes and must be entered right after the password. Someone who steals a password therefore cannot use it without also having the phone.
>
> Employees complained during the first few weeks because it took a few extra steps to sign in. The owner then allowed the system to remember office computers for thirty days, so employees are asked for a code only the first time they sign in that month or when they sign in from a new device.

In the passage, having the system “remember office computers for thirty days” means

- reminding employees to shut down the computer every evening
- saving the password on the computer so employees do not have to type it
- having the system recognize the computer as already authorized
- replacing the office computer every thirty days

## Explanation

The sentence says that thanks to this change, employees are asked for the code only the first time they sign in that month. The system therefore *remembers* the computer in the sense that it recognizes it as a device it has already checked and does not ask for a code again for thirty days. Using the **substitution test**, “having the system recognize the computer” preserves the sentence’s meaning. Saving the password is not mentioned. The change concerns the code sent to the phone. The other two interpretations have no connection to the sentence.
