> The first page of a portable sewing machine manual reads: “Before putting the machine away, remove the top spool. If the machine is to be transported, also lower the needle and secure the cover.” After finishing some work the owner wants to put the machine away on the same table overnight without transporting it. A friend reads only the second sentence aloud and insists on finding the cover immediately. The owner goes back to the start of the manual. The two sentences address the same person, but the second introduces a further circumstance. To decide what to do that evening one must recognise the scope of each instruction.

What action does the text definitely require in the case described?

- Secure the cover before removing the spool
- Lower the needle and leave the spool in place
- Remove the top spool
- Carry the machine away from the table

## Explanation

The owner intends to put the machine away, so the first sentence applies. Transport would trigger two further instructions. Keeping it on the same table does not meet that condition.
