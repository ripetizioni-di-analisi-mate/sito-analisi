A rectangle has perimeter $20$ cm. For which lengths $x$ of one side, in centimeters, is the area at least $21$ cm²?

- $x \leq 3 \;\vee\; x \geq 7$
- $3 \leq x \leq 7$
- $0 < x < 10$
- $3 < x < 7$

## Explanation

Two adjacent side lengths add up to half the perimeter, so if one side has length $x$, the other has length $10 - x$, with $0 < x < 10$. The area is $x(10 - x)$, so the requirement is $x(10 - x) \geq 21$, or $x^2 - 10x + 21 \leq 0$. The corresponding equation has roots $3$ and $7$. The quadratic is negative or zero between the roots, including the endpoints, so $3 \leq x \leq 7$. At $x = 3$ the sides measure $3$ and $7$ and the area is exactly $21$, so the answer $3 < x < 7$ excludes two valid values. The answer $0 < x < 10$ gives only the possible side lengths before imposing the area requirement.
