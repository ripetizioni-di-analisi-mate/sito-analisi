What is the solution set of $\dfrac{x^2 - 1}{x} > 0$?

- $x < -1 \;\vee\; 0 < x < 1$
- $x > 1$
- $x < -1 \;\vee\; x > 1$
- $-1 < x < 0 \;\vee\; x > 1$

## Explanation

The numerator $x^2 - 1$ is positive for $x < -1$ and $x > 1$, and the denominator is positive for $x > 0$. The zeros $-1$, $0$, and $1$ divide the number line into four intervals. From left to right, the **sign chart** gives the signs of the quotient as negative, positive, negative, and positive. The solutions are therefore $-1 < x < 0 \;\vee\; x > 1$. The answer $x < -1 \;\vee\; x > 1$ considers only the numerator and ignores the sign of the denominator. The answer $x < -1 \;\vee\; 0 < x < 1$ chooses the intervals where the quotient is negative.
