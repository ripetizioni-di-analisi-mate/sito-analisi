For which values of $x$ is the fraction $\dfrac{3}{x^2 - 9}$ negative?

- $x < -3 \;\vee\; x > 3$
- $x < 3$
- $-3 < x < 3$
- $-3 \leq x \leq 3$

## Explanation

The numerator $3$ is positive, so the fraction has the same sign as its denominator $x^2 - 9$. The quadratic $x^2 - 9$ has zeros $-3$ and $3$ and is negative between them, so the fraction is negative for $-3 < x < 3$. Its denominator makes the fraction undefined at either zero, so the answer $-3 \leq x \leq 3$ is incorrect. The answer $x < -3 \;\vee\; x > 3$ gives the values where the fraction is positive. The answer $x < 3$ treats the denominator as if it were $x - 3$.
