For which values of $x$ does $x^4 - 10x^2 + 9 \leq 0$ hold?

- $-3 \leq x \leq -1 \;\vee\; 1 \leq x \leq 3$
- $1 \leq x \leq 9$
- $-3 \leq x \leq 3$
- $1 \leq x \leq 3$

## Explanation

Setting $t = x^2$ gives $t^2 - 10t + 9 \leq 0$. The corresponding equation has roots $1$ and $9$, and the quadratic is negative or zero between the roots, so $1 \leq x^2 \leq 9$. The condition $x^2 \leq 9$ gives $-3 \leq x \leq 3$, while $x^2 \geq 1$ gives $x \leq -1 \;\vee\; x \geq 1$. The values satisfying both conditions are $-3 \leq x \leq -1 \;\vee\; 1 \leq x \leq 3$. The answer $1 \leq x \leq 9$ stops at the auxiliary variable $t$, and $1 \leq x \leq 3$ omits the negative values.
