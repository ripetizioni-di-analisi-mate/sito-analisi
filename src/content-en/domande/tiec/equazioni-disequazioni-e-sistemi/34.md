A meter uses the rule $y=\dfrac{1}{x+2}$ with $x\ne-2$. Which output $y$ cannot be traced to any real input because it is never produced?

- $0$
- $-2$
- $-1$
- $1/2$

## Explanation

The numerator is always $1$, so no input gives zero. For each $y\ne0$ one may instead take $x=1/y-2$. This input always differs from $-2$ and produces exactly $y$.
