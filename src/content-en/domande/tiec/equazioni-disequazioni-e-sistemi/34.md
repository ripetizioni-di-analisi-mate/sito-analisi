For which of the following values of $m$ does the equation $\dfrac{1}{x+2}=m$ have no real solutions?

- $0$
- $-2$
- $-1$
- $\dfrac{1}{2}$

## Explanation

A fraction with numerator $1$ is never equal to zero, so for $m=0$ the equation has no solutions. For $m\ne0$, instead, the equation is equivalent to $x+2=\dfrac{1}{m}$ and has the solution $x=\dfrac{1}{m}-2$, which differs from $-2$. For example, for $m=-1$ the solution is $x=-3$. Therefore the only value among those given with no solutions is $m=0$.
