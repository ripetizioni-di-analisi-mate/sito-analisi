Which real numbers $x$ satisfy $25 - x^2 > 0$?

- $-5 < x < 5$
- $x < 5$
- $x < -5 \;\vee\; x > 5$
- $0 < x < 5$

## Explanation

The inequality is equivalent to $x^2 < 25$ because we move $x^2$ to the right. The numbers whose square is less than $25$ are between $-5$ and $5$, excluding both endpoints, so $-5 < x < 5$. The answer $x < 5$ misses the restriction on negative values because at $x = -6$ we have $25 - 36 < 0$. The answer $x < -5 \;\vee\; x > 5$ solves $25 - x^2 < 0$, with the inequality reversed.
