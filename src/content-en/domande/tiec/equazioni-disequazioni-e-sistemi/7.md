For which value of $k$ does the equation $x^2+kx+25=0$ have a negative double solution?

- $-5$
- $10$
- $5$
- $-10$

## Explanation

The equation has a double solution when the discriminant is zero, so $k^2-100=0$, that is $k=\pm10$. The double solution equals $-\dfrac{k}{2}$, so it is negative only for $k>0$. Consequently $k=10$, and the double solution is $-5$.
