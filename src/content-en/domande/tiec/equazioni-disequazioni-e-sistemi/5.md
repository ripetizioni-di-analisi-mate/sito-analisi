What is the solution of $\dfrac{x + 1}{x - 2} = 3$?

- $x = \dfrac{3}{2}$
- $x = -\dfrac{7}{2}$
- No real number
- $x = \dfrac{7}{2}$

## Explanation

The unknown appears in the denominator, so the **domain restriction** is $x \neq 2$. Multiplying both sides by $x - 2$ gives $x + 1 = 3x - 6$, or $2x = 7$, so $x = \dfrac{7}{2}$. The value $\dfrac{7}{2}$ differs from $2$, so it satisfies the restriction and is the solution. The value $\dfrac{3}{2}$ comes from the expansion $3(x - 2) = 3x - 2$, which multiplies only the first term by $3$.
