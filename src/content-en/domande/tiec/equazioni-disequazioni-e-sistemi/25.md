For $x^4+x^2-2=0$, the substitution $u=x^2$ gives roots $u=1$ and $u=-2$. Which count describes the real solutions recovered?

- One from the first value of $u$, none from the second
- Two from each value of $u$
- Two from the first value of $u$, none from the second
- One from each value of $u$

## Explanation

The equation $x^2=1$ allows both signs, $x=-1$ and $x=1$. No real square equals $-2$. Counting roots in $u$ alone does not say which solutions can be recovered in $x$.
