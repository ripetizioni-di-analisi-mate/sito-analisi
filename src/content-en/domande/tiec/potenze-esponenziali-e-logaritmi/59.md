Which of the following statements about the function $y = \log_{\frac{1}{5}} x$ is true?

- It is increasing
- It is positive for $0 < x < 1$
- It is defined for every real $x$
- Its graph passes through the point $(0;1)$

## Explanation

The base $\dfrac{1}{5}$ lies between $0$ and $1$, so the function is decreasing and equals $0$ at $x = 1$. It follows that for $0 < x < 1$ the function takes values greater than $\log_{\frac{1}{5}} 1 = 0$, so it is positive. For example, $\log_{\frac{1}{5}} \dfrac{1}{5} = 1$. The function is defined only for $x > 0$. The point $(0;1)$ lies on the graph of the exponential function $y = \left(\dfrac{1}{5}\right)^{x}$, and the logarithm is undefined at $x = 0$.
