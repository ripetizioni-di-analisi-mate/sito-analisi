The inequality $\log_{\frac{1}{3}} (x + 2) \geq -2$ holds for:

- $x \geq 7$
- $-2 < x \leq 7$
- $x \leq 7$
- $-2 < x \leq -\dfrac{17}{9}$

## Explanation

The domain restriction of the logarithm is $x + 2 > 0$. Since $\left( \dfrac{1}{3} \right)^{-2} = 9$, we have $-2 = \log_{\frac{1}{3}} 9$. The base $\dfrac{1}{3}$ is less than $1$, so the inequality sign between the arguments is reversed and the inequality is equivalent to the system
$$
\begin{cases}
x + 2 > 0 \\
x + 2 \leq 9
\end{cases}
$$
Therefore the solutions are $-2 < x \leq 7$. The result $x \geq 7$ keeps the inequality sign, and the result $x \leq 7$ forgets the domain restriction. The interval with endpoint $-\dfrac{17}{9}$ comes from the wrong computation $\left( \dfrac{1}{3} \right)^{-2} = \dfrac{1}{9}$.
