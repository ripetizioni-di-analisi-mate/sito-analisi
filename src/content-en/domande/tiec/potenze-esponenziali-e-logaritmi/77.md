The solutions of the equation $2^{x} = 5^{x}$ are:

- $x = 1$
- $x = \log_{2} 5$
- $x = 0$
- every real number

## Explanation

Divide both sides by $5^{x}$, which is always positive, to obtain $\left(\dfrac{2}{5}\right)^{x} = 1$. A power whose base is positive and different from $1$ equals $1$ only when its exponent is $0$, so the only solution is $x = 0$. The value $x = 1$ would give $2 = 5$, which is false, and $x = \log_{2} 5$ solves the equation $2^{x} = 5$. The solution set does not contain all real numbers because for $x = 1$ the two sides equal $2$ and $5$.
