For a certain number $x > 1$ we have $\log_{b} x < 0$, with $b > 0$ and $b \neq 1$. What can be concluded about the base $b$?

- $0 < b < 1$
- $1 < b < x$
- $b = x$
- $b > x$

## Explanation

If $b > 1$, the function $y = \log_{b} x$ is increasing and equals $0$ at $x = 1$, so for $x > 1$ the logarithm is positive. Since instead $\log_{b} x < 0$ with $x > 1$, the base is not greater than $1$. Hence $0 < b < 1$, and with such a base the logarithm of every number greater than $1$ is negative. The case $b = x$ is excluded, because it would give $\log_{b} x = 1$.
