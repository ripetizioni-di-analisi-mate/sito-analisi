The value of $\log_{\sqrt{2}} 8$ is:

- $6$
- $3$
- $\dfrac{3}{2}$
- $4\sqrt{2}$

## Explanation

Write the base and argument as powers of $2$, namely $\sqrt{2} = 2^{\frac{1}{2}}$ and $8 = 2^{3}$. Find the exponent $c$ such that $\left(2^{\frac{1}{2}}\right)^{c} = 2^{3}$, giving $\dfrac{c}{2} = 3$ and $c = 6$. As a check, $\left(\sqrt{2}\right)^{6} = 2^{3} = 8$. The value $3$ is $\log_{2} 8$, which ignores the root in the base, and $\dfrac{3}{2}$ halves the exponent instead of doubling it. The value $4\sqrt{2}$ divides $8$ by $\sqrt{2}$.
