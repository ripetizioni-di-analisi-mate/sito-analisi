Which point lies on the graph of every function $y = a^{x}$ with $a > 0$ and $a \neq 1$?

- $(1;0)$
- $(0;0)$
- $(1;1)$
- $(0;1)$

## Explanation

For every admissible base, $a^{0} = 1$, so the point $(0;1)$ lies on all the graphs. The graph of $y = a^{x}$ passes through $(1;a)$, so the point $(1;1)$ would lie on it only for $a = 1$, which is an excluded base. The point $(0;0)$ lies on none of the graphs because $a^{x}$ is always positive. The point $(1;0)$ is common to the graphs of the logarithmic functions $y = \log_{a} x$.
