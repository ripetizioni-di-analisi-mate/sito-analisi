The inequality $\left( \dfrac{1}{2} \right)^{x^{2}} > \dfrac{1}{16}$ holds for:

- $x < -2 \;\vee\; x > 2$
- $x < 2$
- $-4 < x < 4$
- $-2 < x < 2$

## Explanation

Since $\dfrac{1}{16} = \left(\dfrac{1}{2}\right)^{4}$, the inequality becomes $\left(\dfrac{1}{2}\right)^{x^{2}} > \left(\dfrac{1}{2}\right)^{4}$. The base is less than $1$, so **the inequality sign reverses**, giving $x^{2} < 4$, or $-2 < x < 2$. The result $x < -2 \;\vee\; x > 2$ keeps the sign, and $x < 2$ takes the square root while overlooking negative values of $x$. The result $-4 < x < 4$ compares $x^{2}$ with $16$ instead of $4$.
