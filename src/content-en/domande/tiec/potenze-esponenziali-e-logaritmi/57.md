Which of the following numbers is the greatest?

- $\log_{2} 3$
- $\log_{4} 3$
- $\log_{8} 3$
- $\log_{16} 3$

## Explanation

The four bases are powers of $2$, so use the **change-of-base formula** to write all the logarithms in base $2$. Since $\log_{2} 4 = 2$, $\log_{2} 8 = 3$, and $\log_{2} 16 = 4$, this gives $\log_{4} 3 = \dfrac{\log_{2} 3}{2}$, $\log_{8} 3 = \dfrac{\log_{2} 3}{3}$, and $\log_{16} 3 = \dfrac{\log_{2} 3}{4}$. The number $\log_{2} 3$ is positive because its base and argument are greater than $1$. Dividing it by $2$, $3$, or $4$ therefore gives smaller numbers. The greatest is thus $\log_{2} 3$. Choosing $\log_{16} 3$ assigns the greatest value to the logarithm with the greatest base, whereas for the same argument greater than $1$, the order is reversed.
