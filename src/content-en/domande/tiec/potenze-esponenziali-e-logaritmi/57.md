An algorithm must decide which side of $3/2$ contains $\log_2 3$. Which integer comparison settles the question, and with what outcome?

- $3^2>2^3$, so $\log_2 3>3/2$
- $3^2<2^3$, so $\log_2 3<3/2$
- $3^3>2^2$, so $\log_2 3<3/2$
- $3^2>2^3$, so $\log_2 3<3/2$

## Explanation

Base two exceeds one, so the issue is whether $3$ exceeds $2^{3/2}$. Squaring the positive numbers gives $9>8$. The logarithm therefore lies to the right of $3/2$.
