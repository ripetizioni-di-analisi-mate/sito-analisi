Which of the following values is a solution of the equation $\log_{2} x + x = 6$?

- $x = 2$
- $x = 4$
- $x = 8$
- $x = 6$

## Explanation

The equation contains $x$ both inside and outside the logarithm, so **substitute the answer choices** into the left side. For $x = 4$, we have $\log_{2} 4 + 4 = 2 + 4 = 6$, so $x = 4$ is a solution. For $x = 2$, the left side equals $1 + 2 = 3$, and for $x = 8$, it equals $3 + 8 = 11$. For $x = 6$, the left side exceeds $6$ because $\log_{2} 6$ is positive.
