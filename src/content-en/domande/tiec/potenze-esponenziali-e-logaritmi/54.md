For which of the following values of $x$ is the number $\log_{2} \dfrac{x - 1}{x + 3}$ defined?

- $x = -4$
- $x = -3$
- $x = 0$
- $x = 1$

## Explanation

The logarithm is defined when the denominator $x + 3$ is not zero and the quotient $\dfrac{x - 1}{x + 3}$ is positive. For $x = -4$ the quotient equals $\dfrac{-5}{-1} = 5$, which is positive, so the logarithm is defined. For $x = -3$ the denominator is zero, for $x = 0$ the quotient equals $-\dfrac{1}{3}$ and for $x = 1$ it equals $0$. Hence the logarithm is defined only for $x = -4$.
