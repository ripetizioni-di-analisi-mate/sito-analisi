The function $y = (k - 2)^{x}$ is a decreasing exponential function if and only if:

- $k < 3$
- $0 < k < 1$
- $2 < k < 3$
- $k > 3$

## Explanation

An exponential function $y = a^{x}$ is decreasing when its base satisfies $0 < a < 1$. Here the base is $k - 2$, so the requirement is $0 < k - 2 < 1$, or $2 < k < 3$. The result $k < 3$ overlooks that the base must be positive, and $0 < k < 1$ imposes the condition on $k$ instead of the base $k - 2$. For $k > 3$, the base is greater than $1$, so the exponential function is increasing.
