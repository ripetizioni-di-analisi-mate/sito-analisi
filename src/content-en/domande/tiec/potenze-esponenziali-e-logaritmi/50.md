The value of $\log_{27} \dfrac{1}{9}$ is:

- $\dfrac{2}{3}$
- $-\dfrac{2}{3}$
- $-\dfrac{3}{2}$
- $-3$

## Explanation

Write the base and argument as powers of $3$, namely $27 = 3^{3}$ and $\dfrac{1}{9} = 3^{-2}$. Find the exponent $c$ such that $\left(3^{3}\right)^{c} = 3^{-2}$. This gives $3c = -2$ and $c = -\dfrac{2}{3}$. The value $-\dfrac{3}{2}$ switches the base and argument, since $\log_{\frac{1}{9}} 27 = -\dfrac{3}{2}$, and $\dfrac{2}{3}$ loses the minus sign from the reciprocal. The value $-3$ divides $27$ by $9$ and adds a minus sign.
