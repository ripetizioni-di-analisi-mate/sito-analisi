A positive integer $x$ has three digits. Which condition does $\log_{10} x$ satisfy?

- $\log_{10} x = 3$
- $3 \leq \log_{10} x < 4$
- $2 < \log_{10} x \leq 3$
- $2 \leq \log_{10} x < 3$

## Explanation

A positive integer has three digits if and only if $100 \leq x < 1000$, that is $10^{2} \leq x < 10^{3}$. Since the base $10$ is greater than $1$, the function $y = \log_{10} x$ is increasing and preserves inequalities. Hence $2 \leq \log_{10} x < 3$. The value $\log_{10} x = 3$ corresponds to $x = 1000$, which has four digits.
