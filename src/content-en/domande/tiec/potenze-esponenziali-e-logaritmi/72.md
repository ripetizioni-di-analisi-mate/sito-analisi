Let $F(x) = 2^{x^{2} - x}$. For which value of $x$, other than $3$, does $F(x) = F(3)$ hold?

- $x = -3$
- $x = 2$
- $x = -2$
- $x = 0$

## Explanation

We have $F(3) = 2^{9 - 3} = 2^{6}$. Since the exponential function takes different values at different points, $F(x) = F(3)$ if and only if $x^{2} - x = 6$. The equation $x^{2} - x - 6 = 0$ has the solutions $x = 3$ and $x = -2$. The value other than $3$ is therefore $x = -2$.
