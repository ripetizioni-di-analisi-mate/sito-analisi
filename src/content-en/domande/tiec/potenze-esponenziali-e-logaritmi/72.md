The solutions of the equation $2^{x^{2} - x} = 4$ are:

- $x = 2$
- $x = 1 \;\vee\; x = -2$
- $x = -1 \;\vee\; x = 2$
- $x = 0 \;\vee\; x = 1$

## Explanation

Since $4 = 2^{2}$, the equation can be written with the same base on both sides, giving $2^{x^{2} - x} = 2^{2}$. Equating the exponents gives $x^{2} - x - 2 = 0$, and since $x^{2} - x - 2 = (x - 2)(x + 1)$, the solutions are $x = 2$ and $x = -1$. Both values are admissible because an exponential equation places no restriction on the exponent. The result $x = 2$ loses the negative solution, $x = 1 \;\vee\; x = -2$ switches the signs, and $x = 0 \;\vee\; x = 1$ sets the exponent equal to $0$ instead of $2$.
