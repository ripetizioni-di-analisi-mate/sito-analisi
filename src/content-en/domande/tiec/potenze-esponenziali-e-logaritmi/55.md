A program for $\log_{x-2}(6-x)$ accepts every input in $2<x<6$. What minimal change completes its real-domain check?

- Reject $x=3$, which gives base one
- Accept $x=6$, which gives argument zero
- Reject all $x$ between $2$ and $3$, which give bases below one
- Reject $x=5$, which gives argument one

## Explanation

Within the stated interval both the base and the argument are positive. The missing condition is $x-2\ne1$, or $x\ne3$. An argument of one is allowed and gives logarithm zero.
