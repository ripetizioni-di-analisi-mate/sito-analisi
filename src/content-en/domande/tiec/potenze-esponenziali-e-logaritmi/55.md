For which values of $x$ is the number $\log_{x-2} (6 - x)$ defined?

- $2 < x < 6 \;\wedge\; x \neq 3$
- $2 < x < 6$
- $3 < x < 6$
- $2 < x < 6 \;\wedge\; x \neq 5$

## Explanation

The logarithm exists if the argument is positive and the base is positive and different from $1$, that is if
$$
\begin{cases}
6 - x > 0 \\
x - 2 > 0 \\
x - 2 \neq 1
\end{cases}
$$
The first condition gives $x < 6$, the second $x > 2$ and the third $x \neq 3$. The number is therefore defined for $2 < x < 6$ with $x \neq 3$. The value $x = 5$ is allowed, because it gives the argument $1$ and the logarithm equals $0$.
