The expression $\log_{x - 2} (6 - x)$ is defined for:

- $2 < x < 3 \;\vee\; 3 < x < 6$
- $2 < x < 6$
- $3 < x < 6$
- $x > 2 \;\wedge\; x \neq 3$

## Explanation

The domain restrictions apply to both the base and the argument and form the system
$$
\begin{cases}
x - 2 > 0 \\
x - 2 \neq 1 \\
6 - x > 0
\end{cases}
\iff
\begin{cases}
x > 2 \\
x \neq 3 \\
x < 6
\end{cases}
$$
The solutions are therefore the numbers between $2$ and $6$ other than $3$. The interval $2 < x < 6$ overlooks that the base must differ from $1$, and $x > 2 \;\wedge\; x \neq 3$ overlooks the restriction on the argument. The interval $3 < x < 6$ requires the base to be greater than $1$, although it only needs to be positive and different from $1$.
