The solution of the equation $3^{x} = 7$ is:

- $x = \dfrac{7}{3}$
- $x = \log_{7} 3$
- $x = \sqrt[3]{7}$
- $x = \log_{3} 7$

## Explanation

The number $7$ is not an integer power of $3$, so use the definition of a logarithm to write the solution as the exponent $\log_{3} 7$ to which $3$ must be raised to obtain $7$. Since $3^{1} < 7 < 3^{2}$, the solution lies between $1$ and $2$. The value $\log_{7} 3$ switches the base and argument and is less than $1$, while $\dfrac{7}{3}$ uses division instead of taking the logarithm. The value $\sqrt[3]{7}$ solves the equation $x^{3} = 7$, in which the unknown is the base.
