Which of the following numbers is the greatest?

- $27^{5}$
- $9^{8}$
- $3^{14}$
- $81^{3}$

## Explanation

All four bases are powers of $3$, so rewrite all the numbers with base $3$. This gives $27^{5} = 3^{15}$, $9^{8} = 3^{16}$, and $81^{3} = 3^{12}$, while $3^{14}$ already has base $3$. With the same base $3 > 1$, the greater exponent gives the greater power, so the greatest number is $9^{8} = 3^{16}$. The number $81^{3}$ has the greatest base but equals only $3^{12}$.
