The inequality $\log_{2} x < \log_{2} (6 - x)$ holds for:

- $x < 3$
- $3 < x < 6$
- $0 < x < 3$
- $0 < x < 6$

## Explanation

The domain restrictions are $x > 0$ and $6 - x > 0$, so $0 < x < 6$. The base $2$ is greater than $1$, so the inequality sign stays the same and gives $x < 6 - x$, or $x < 3$. The solutions must satisfy both the domain restrictions and the inequality between the arguments, so they are $0 < x < 3$. The result $x < 3$ overlooks the domain restrictions, and $0 < x < 6$ stops at them. The interval $3 < x < 6$ reverses the inequality sign as if the base were less than $1$.
