For which values of $x$ does the inequality $\log_{2} x < \log_{2} (6 - x)$ hold?

- $3 < x < 6$
- $0 < x \leq 3$
- $0 < x < 3$
- $x < 3$

## Explanation

The domain conditions are $x > 0$ and $6 - x > 0$, that is $0 < x < 6$. Since the base $2$ is greater than $1$, the inequality between the logarithms is equivalent to the inequality between the arguments $x < 6 - x$, that is $x < 3$. The solutions must satisfy both conditions together, so
$$
\begin{cases}
0 < x < 6 \\
x < 3
\end{cases}
\iff
0 < x < 3 .
$$
