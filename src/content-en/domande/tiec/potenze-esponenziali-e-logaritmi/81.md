The equation $8^{x} = \dfrac{1}{\sqrt{2}}$ has the following solution:

- $x = -\dfrac{1}{2}$
- $x = \dfrac{1}{6}$
- $x = -\dfrac{1}{6}$
- $x = -\dfrac{3}{2}$

## Explanation

Write both sides as powers of $2$, namely $8^{x} = 2^{3x}$ and $\dfrac{1}{\sqrt{2}} = 2^{-\frac{1}{2}}$. Equating the exponents gives $3x = -\dfrac{1}{2}$, so $x = -\dfrac{1}{6}$. The result $-\dfrac{1}{2}$ overlooks the fact that $8$ must be written as $2^{3}$, and $-\dfrac{3}{2}$ multiplies by $3$ instead of dividing. The result $\dfrac{1}{6}$ drops the minus sign from the reciprocal.
