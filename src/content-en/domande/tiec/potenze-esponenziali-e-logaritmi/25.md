The number $\left( \sqrt[3]{4} \right)^{6}$ is equal to:

- $8$
- $2$
- $64$
- $16$

## Explanation

Write the root as a power, $\sqrt[3]{4} = 4^{\frac{1}{3}}$. By the power-of-a-power rule, $\left(4^{\frac{1}{3}}\right)^{6} = 4^{\frac{6}{3}} = 4^{2} = 16$. The result $64$ is $4^{3}$, which uses the index as the exponent, and $2$ is $4^{\frac{3}{6}}$, which inverts the fraction. The result $8$ multiplies $4$ by $\dfrac{6}{3} = 2$.
