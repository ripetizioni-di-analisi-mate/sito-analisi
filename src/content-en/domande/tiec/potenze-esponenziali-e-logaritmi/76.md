What is the solution set of the inequality $9^{x} - 4 \cdot 3^{x} + 3 \leq 0$?

- $1 \leq x \leq 3$
- $x \leq 0 \;\vee\; x \geq 1$
- $x \leq 1$
- $0 \leq x \leq 1$

## Explanation

Using the change of variable $t = 3^{x}$ and the fact that $9^{x} = t^{2}$, the inequality becomes $t^{2} - 4t + 3 \leq 0$. The trinomial has roots $1$ and $3$ and is nonpositive between its roots, including the endpoints, so $1 \leq t \leq 3$. Returning to $x$ gives $3^{0} \leq 3^{x} \leq 3^{1}$. Since the base $3$ is greater than $1$, the inequality sign stays the same, giving $0 \leq x \leq 1$. The result $1 \leq x \leq 3$ stops at the variable $t$, and $x \leq 0 \;\vee\; x \geq 1$ takes the values outside the roots. The result $x \leq 1$ overlooks the condition $3^{x} \geq 1$.
