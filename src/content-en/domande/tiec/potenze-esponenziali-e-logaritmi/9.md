Given the numbers $a = 2^{45}$, $b = 3^{30}$, and $c = 5^{15}$, which of the following relations is true?

- $c < a < b$
- $a < b < c$
- $a < c < b$
- $b < a < c$

## Explanation

All three exponents are multiples of $15$. Use the **power-of-a-power rule** to rewrite all three powers with exponent $15$, obtaining $a = \left(2^{3}\right)^{15} = 8^{15}$, $b = \left(3^{2}\right)^{15} = 9^{15}$, and $c = 5^{15}$. For the same positive exponent, the greater base gives the greater power. Since $5 < 8 < 9$, it follows that $c < a < b$. The order $a < b < c$ follows the bases $2 < 3 < 5$, which alone do not determine the order because the exponents differ.
