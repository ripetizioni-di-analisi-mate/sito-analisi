What condition is necessary and sufficient for an angle $x$ with $\sin x = a$ and $\cos x = 2a$ to exist?

- $a = \dfrac{1}{3}$
- $a = -\dfrac{1}{5}$ or $a = \dfrac{1}{5}$
- $a = -\dfrac{\sqrt{5}}{5}$ or $a = \dfrac{\sqrt{5}}{5}$
- $a = -\dfrac{\sqrt{3}}{3}$ or $a = \dfrac{\sqrt{3}}{3}$

## Explanation

The sine and cosine of the same angle satisfy the **Pythagorean identity**, so $a^2 + 4a^2 = 1$, or $a^2 = \dfrac{1}{5}$. This gives $a = \pm\dfrac{1}{\sqrt{5}} = \pm\dfrac{\sqrt{5}}{5}$. Conversely, for these two values the point $(2a;a)$ lies on the unit circle. Thus the angle exists, in the first quadrant for $a > 0$ and in the third for $a < 0$. The values $\pm\dfrac{\sqrt{3}}{3}$ follow from $a^2 + 2a^2 = 1$, which omits the square on the factor $2$, while the values $\pm\dfrac{1}{5}$ omit the square root. The value $\dfrac{1}{3}$ uses the sum $a + 2a = 1$, which is not the Pythagorean identity.
