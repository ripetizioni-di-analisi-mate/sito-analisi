For what value do the points $A(1;2)$, $B(3;6)$, and $C(k;-4)$ lie on the same line?

- $k = -11$
- $k = 4$
- $k = -2$
- $k = 2$

## Explanation

The three points are collinear if $C$ lies on the line $AB$. The slope of $AB$ is $\dfrac{6 - 2}{3 - 1} = 2$, so the line has equation $y - 2 = 2(x - 1)$, or $y = 2x$. The point $C$ lies on it if $-4 = 2k$, so $k = -2$. The value $k = -11$ uses the reciprocal slope $\dfrac{1}{2}$, and $k = 4$ uses the slope $-2$. The value $k = 2$ uses the wrong sign for the vertical coordinate of $C$.
