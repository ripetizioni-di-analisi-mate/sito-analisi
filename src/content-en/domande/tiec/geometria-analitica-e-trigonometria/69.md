For what value does the point $P(2k - 4;\, k + 1)$ lie on the $y$-axis?

- $k = -1$
- $k = 2$
- $k = -2$
- $k = 4$

## Explanation

Points on the $y$-axis have horizontal coordinate $0$, so we need $2k - 4 = 0$, or $k = 2$. For this value the point is $P(0;3)$. The value $k = -1$ makes the vertical coordinate zero, placing the point on the $x$-axis. The value $k = -2$ comes from the sign error $2k = -4$, and $k = 4$ omits division by $2$.
