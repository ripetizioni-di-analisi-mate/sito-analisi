What is the value of the fraction $\dfrac{x^2 - 1}{x^2 + x}$ at $x = 3$?

- $\dfrac{4}{3}$
- $\dfrac{2}{3}$
- $\dfrac{3}{2}$
- $\dfrac{8}{9}$

## Explanation

At $x = 3$ the denominator equals $12$, which is nonzero, so the fraction is defined. To **simplify**, write $\dfrac{(x - 1)(x + 1)}{x(x + 1)} = \dfrac{x - 1}{x}$, which at $x = 3$ equals $\dfrac{2}{3}$. Direct substitution gives the same value, $\dfrac{9 - 1}{9 + 3} = \dfrac{8}{12} = \dfrac{2}{3}$. The value $\dfrac{8}{9}$ omits the term $x$ in the denominator, while $\dfrac{4}{3}$ is the value of $\dfrac{x + 1}{x}$.
