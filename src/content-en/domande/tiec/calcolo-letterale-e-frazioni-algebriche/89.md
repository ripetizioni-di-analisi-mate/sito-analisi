For $x \neq -1$, which expression equals the fraction $\dfrac{x^2 + 3x + 5}{x + 1}$?

- $x + 2 + \dfrac{3}{x + 1}$
- $x + 2 + \dfrac{5}{x + 1}$
- $x + 4 + \dfrac{9}{x + 1}$
- $x + 3 + \dfrac{5}{x + 1}$

## Explanation

By **polynomial division**, $x^2 + 3x + 5 = (x + 1)\,Q(x) + R$, so dividing by $x + 1$ gives $\dfrac{x^2 + 3x + 5}{x + 1} = Q(x) + \dfrac{R}{x + 1}$. Using **synthetic division** with $-1$ on the left gives the numbers $1$ and $2$ and the remainder $5 - 2 = 3$, so $Q(x) = x + 2$ and $R = 3$. The fraction therefore equals $x + 2 + \dfrac{3}{x + 1}$. The expression $x + 4 + \dfrac{9}{x + 1}$ uses $1$ on the left instead of $-1$, and $x + 2 + \dfrac{5}{x + 1}$ uses the constant term of the dividend as the remainder.
