Which of the following polynomials is divisible by $x + 1$?

- $x^3 - 1$
- $x^2 + 1$
- $x^3 + x^2 + x + 2$
- $x^3 + 1$

## Explanation

A polynomial is **divisible by** $x + 1$ if and only if it is zero at $x = -1$ because $x + 1 = x - (-1)$. The polynomial $x^3 + 1$ equals $-1 + 1 = 0$ at $-1$, so it is divisible by $x + 1$. At $-1$ the other three polynomials have values $-2$, $2$, and $1$, respectively, so none is divisible by $x + 1$.
