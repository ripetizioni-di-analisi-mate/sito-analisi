Which of the following expressions is a monomial?

- $\dfrac{5}{x^2y}$
- $\dfrac{x^2y}{5}$
- $3\sqrt{x}\,y$
- $x^{-2}y$

## Explanation

A **monomial** is a number multiplied by variables raised to nonnegative integer powers. The expression $\dfrac{x^2y}{5}$ equals $\dfrac{1}{5}x^2y$, so it is a monomial with coefficient $\dfrac{1}{5}$. In $\dfrac{5}{x^2y}$ and $x^{-2}y$ the variable $x$ appears in the denominator, giving a negative exponent, so neither expression is a monomial. The expression $3\sqrt{x}\,y$ is also not a monomial because $\sqrt{x} = x^{\frac{1}{2}}$ has a fractional exponent.
