For $x \neq 1$, which expression equals the fraction $\dfrac{x^3 - 1}{x - 1}$?

- $x^2 + 1$
- $x^2 - x + 1$
- $x^2 + x + 1$
- $x^2 + 2x + 1$

## Explanation

The numerator is a **difference of cubes**, so $x^3 - 1 = (x - 1)(x^2 + x + 1)$. Canceling $x - 1$ leaves $x^2 + x + 1$. Check the result by **substituting a value**, for example $x = 2$. The fraction equals $\dfrac{7}{1} = 7$ and $x^2 + x + 1$ equals $7$, whereas $x^2 + 1$ equals $5$, $x^2 - x + 1$ equals $3$, and $x^2 + 2x + 1$ equals $9$.
