Two polynomials have GCD $x - 1$ and LCM $x(x - 1)^2(x + 2)$. One is $x(x - 1)^2$. What is the other?

- $x + 2$
- $(x - 1)^2(x + 2)$
- $(x - 1)(x + 2)$
- $x(x - 1)(x + 2)$

## Explanation

The LCM contains the factor $x + 2$, which the first polynomial lacks, so the second polynomial contains $x + 2$. The GCD contains $x - 1$ with exponent $1$, and in the first polynomial its exponent is $2$. Therefore the second polynomial contains $x - 1$ with exponent $1$. The GCD does not contain the factor $x$, so the second polynomial cannot contain it either. The second polynomial is therefore $(x - 1)(x + 2)$. With $(x - 1)^2(x + 2)$ the GCD would be $(x - 1)^2$, and with $x(x - 1)(x + 2)$ it would be $x(x - 1)$.
