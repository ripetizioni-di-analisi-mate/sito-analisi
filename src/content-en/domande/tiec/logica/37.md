Today the store is open and offers no discounts. Which of the following statements is true?

- The store is open and offers discounts.
- If the store offers discounts, then it is not open.
- The store is not open or it offers discounts.
- If the store is open, then it offers discounts.

## Explanation

Let $A$ = “the store is open,” which is true, and $S$ = “the store offers discounts,” which is false. The conjunction $A \land S$ is false because $S$ is false, and the disjunction $\lnot A \lor S$ is false because both parts are false. The implication $A \Rightarrow S$ has a true antecedent and a false consequent, so it is false. The **implication** $S \Rightarrow \lnot A$, however, has a false antecedent, and an implication with a false antecedent is always true.
