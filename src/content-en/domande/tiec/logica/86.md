Which number shows that “If a number is prime, then it is odd” is false?

- $2$
- $9$
- $1$
- $15$

## Explanation

An implication is false only when its antecedent is true and its consequent is false. We therefore need a prime number that is not odd. The only one is $2$, which is both prime and even. The numbers $9$ and $15$ are odd but not prime, so the antecedent is false for them and neither disproves the statement. The number $1$ is not prime either, so it too is not a **counterexample**.
