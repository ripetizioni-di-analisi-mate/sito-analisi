Which number completes the sequence $5,\ 40,\ 8,\ 35,\ 11,\ 30,\ \ldots$?

- $14$
- $25$
- $33$
- $16$

## Explanation

The sequence goes up and down at every step, so the odd-numbered terms are separated from the even-numbered ones. The odd-numbered terms $5, 8, 11$ increase by $3$, while the even-numbered terms $40, 35, 30$ decrease by $5$, so the sequence is **interleaved**. The missing term is the seventh, which is odd-numbered, so it equals $11 + 3 = 14$. The value $25$ continues the sequence of even-numbered terms, and the value $33$ adds $3$ to the last term written. The value $16$ adds to $11$ the step $5$ of the other sequence.
