Let $a$ and $b$ be real numbers with $0 < a < b$. Which of the following numbers is greatest?

- $\dfrac{a}{b}$
- $\dfrac{a}{b + 1}$
- $\dfrac{a + 1}{b + 1}$
- $\dfrac{a - 1}{b}$

## Explanation

Substituting $a = 1$ and $b = 2$ gives the values $\dfrac{1}{2}$, $\dfrac{1}{3}$, $\dfrac{2}{3}$, and $0$ for $\dfrac{a}{b}$, $\dfrac{a}{b + 1}$, $\dfrac{a + 1}{b + 1}$, and $\dfrac{a - 1}{b}$, respectively. Thus $\dfrac{a + 1}{b + 1}$ is greatest. This holds for every pair with $0 < a < b$ because the difference
$$
\frac{a + 1}{b + 1} - \frac{a}{b} = \frac{b - a}{b(b + 1)}
$$
is positive. Also, $\dfrac{a}{b + 1} < \dfrac{a}{b}$ because the denominator is larger, and $\dfrac{a - 1}{b} < \dfrac{a}{b}$ because the numerator is smaller.
