How many integers belong to the interval $\left[-\sqrt{10}, \sqrt{30}\right]$?

- $9$
- $8$
- $10$
- $7$

## Explanation

Square roots preserve order, so $9 < 10 < 16$ implies $3 < \sqrt{10} < 4$, or $-4 < -\sqrt{10} < -3$. Likewise, $25 < 30 < 36$ implies $5 < \sqrt{30} < 6$. The integers in the interval therefore range from $-3$ through $5$, giving $5 - (-3) + 1 = 9$ in all. The value $8$ comes from calculating $5 - (-3)$ without adding $1$. The value $10$ also includes either the integer $-4$ or the integer $6$.
