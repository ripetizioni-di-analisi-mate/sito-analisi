Let $A = [-3, 2)$ and $B = (0, 5]$. Which of the following is the set $A \cap B$?

- $(0, 2)$
- $[0, 2]$
- $(0, 2]$
- $[-3, 5]$

## Explanation

The intersection contains the numbers that belong to both $A$ and $B$, so they satisfy $-3 \leq x < 2$ and $0 < x \leq 5$. Together, these conditions give $0 < x < 2$, so $A \cap B = (0, 2)$. The endpoint $0$ is excluded because it does not belong to $B$, and $2$ is excluded because it does not belong to $A$. The interval $[-3, 5]$ is the union $A \cup B$.
