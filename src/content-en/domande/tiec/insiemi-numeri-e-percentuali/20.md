Given two sets $A$ and $B$, which set contains the elements that belong to exactly one of them?

- $(A \setminus B) \cap (B \setminus A)$
- $(A \cup B) \setminus (A \cap B)$
- $\overline{A \cap B}$
- $(A \cup B) \setminus A$

## Explanation

The elements that belong to at least one of the sets form the union $A \cup B$, and those that belong to both form the intersection $A \cap B$. Removing the intersection from the union therefore leaves those belonging to exactly one set. The set $(A \setminus B) \cap (B \setminus A)$ is empty because an element of $A \setminus B$ cannot belong to $B$. The set $(A \cup B) \setminus A$ equals $B \setminus A$ and contains only the elements that belong to $B$ and not to $A$. The complement $\overline{A \cap B}$ also contains elements of the universal set outside both $A$ and $B$.
