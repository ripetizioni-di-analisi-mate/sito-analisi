Let $A = \{x \in \mathbb{Z} : -3 < x \leq 2\}$ and $B = \{x \in \mathbb{N} : x \leq 4\}$. Which of the following is the set $A \setminus B$?

- $\{-3, -2, -1\}$
- $\{3, 4\}$
- $\{-2, -1\}$
- $\{-2, -1, 0\}$

## Explanation

Listing the elements gives $A = \{-2, -1, 0, 1, 2\}$ because $-3$ is excluded and $2$ is included, and $B = \{0, 1, 2, 3, 4\}$ because $0$ is a natural number. Removing from $A$ the elements that also belong to $B$ leaves $-2$ and $-1$. The set $\{-2, -1, 0\}$ excludes $0$ from the natural numbers, and $\{-3, -2, -1\}$ includes the endpoint $-3$. The set $\{3, 4\}$ is the difference $B \setminus A$.
