What is the value of $|-7| - |3 - 10|$?

- $14$
- $-14$
- $-6$
- $0$

## Explanation

First evaluate each **absolute value**, giving $|-7| = 7$ and $|3 - 10| = |-7| = 7$. The expression therefore equals $7 - 7 = 0$. The value $14$ adds the two absolute values instead of subtracting them, and $-14$ treats $|-7|$ as $-7$. The value $-6$ evaluates $|3 - 10|$ as $3 + 10 = 13$.
