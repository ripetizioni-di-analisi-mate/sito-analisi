Consider the interval $A = [-1, 4)$ in the universal set $\mathbb{R}$. What is the complement of $A$?

- $(-\infty, -1] \cup (4, +\infty)$
- $(-\infty, -1) \cup [4, +\infty)$
- $(-\infty, -1] \cup [4, +\infty)$
- $(-\infty, -1) \cup (4, +\infty)$

## Explanation

The **complement** of $A$ contains the real numbers outside $A$. The endpoint $-1$ belongs to $A$, so it is excluded from the complement. The complement therefore contains the interval $(-\infty, -1)$ with this endpoint excluded. The endpoint $4$ does not belong to $A$, so it belongs to the complement, which contains the interval $[4, +\infty)$ with this endpoint included. The other choices incorrectly include or exclude the endpoints.
