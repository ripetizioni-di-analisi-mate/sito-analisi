Let $A = \{a, b, c\}$. Which of the following statements uses the correct notation?

- $\{a\} \in A$
- $a \subseteq A$
- $\{a, d\} \subseteq A$
- $\{a\} \subseteq A$

## Explanation

The symbol $\in$ relates an element to a set, whereas $\subseteq$ relates two sets. The only element of $\{a\}$ is $a$, which belongs to $A$, so $\{a\}$ is a **subset** of $A$. Writing $\{a\} \in A$ would say that the set $\{a\}$ is an element of $A$, whose elements are actually the letters $a$, $b$, and $c$. The expression $a \subseteq A$ uses the subset symbol for an element, and $\{a, d\}$ is not contained in $A$ because $d \notin A$.
