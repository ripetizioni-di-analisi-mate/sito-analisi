In a universal set $U$ with $50$ elements, two sets $A$ and $B$ satisfy $|A| = 20$, $|B| = 25$, and $|A \cap B| = 8$. How many elements does $\overline{A} \cup \overline{B}$ contain?

- $13$
- $5$
- $37$
- $42$

## Explanation

The complement rule gives $\overline{A} \cup \overline{B} = \overline{A \cap B}$, so the set contains the elements of $U$ outside $A \cap B$. It therefore has $50 - 8 = 42$ elements. The value $13 = 50 - 37$ counts the elements of $\overline{A} \cap \overline{B} = \overline{A \cup B}$ because $|A \cup B| = 20 + 25 - 8 = 37$. The value $37$ counts the elements of the union $A \cup B$.
