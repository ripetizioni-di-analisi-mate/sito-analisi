For every real number $x$, which expression equals $\sqrt{(x - 2)^2}$?

- $|x - 2|$
- $x - 2$
- $2 - x$
- $|x| - 2$

## Explanation

A square root is nonnegative by definition, so $\sqrt{a^2} = |a|$ and in particular $\sqrt{(x - 2)^2} = |x - 2|$. The expression $x - 2$ is correct only for $x \geq 2$. For $x = 0$, the square root is $\sqrt{4} = 2$, whereas $x - 2 = -2$. Likewise, $2 - x$ is correct only for $x \leq 2$, and $|x| - 2$ evaluated at $x = 0$ is $-2$.
