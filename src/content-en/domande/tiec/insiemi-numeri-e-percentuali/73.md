Which of $3^{40}$, $4^{30}$, $5^{20}$, and $6^{10}$ is greatest?

- $4^{30}$
- $5^{20}$
- $6^{10}$
- $3^{40}$

## Explanation

The exponents are multiples of $10$, so all the numbers can be written as powers with exponent $10$, giving $3^{40} = 81^{10}$, $4^{30} = 64^{10}$, $5^{20} = 25^{10}$, and $6^{10}$. For the same positive exponent, the power with the greater base is greater. The largest base is $81$, so the largest number is $3^{40}$. The answer $6^{10}$ considers only the bases and ignores the exponents.
