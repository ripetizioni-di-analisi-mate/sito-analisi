Which of the sets $\mathbb{N}$, $\mathbb{Z}$, $\mathbb{Q}$, and $\mathbb{R}$ is the smallest one containing $-\dfrac{12}{5}$?

- $\mathbb{Q}$
- $\mathbb{Z}$
- $\mathbb{N}$
- $\mathbb{R}$

## Explanation

The number $-\dfrac{12}{5} = -2.4$ is negative, so it does not belong to $\mathbb{N}$. It is not an integer, so it does not belong to $\mathbb{Z}$. It is the quotient of the two integers $-12$ and $5$, so it belongs to $\mathbb{Q}$. Since $\mathbb{N} \subseteq \mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R}$, the smallest set containing it is $\mathbb{Q}$. The set $\mathbb{R}$ also contains the number, but it contains $\mathbb{Q}$ as a subset.
