What is the set of natural numbers $x$ that satisfy $|x + 1| < 3$?

- $\{0, 1, 2\}$
- $\{-3, -2, -1, 0, 1\}$
- $\{0, 1\}$
- $\{1\}$

## Explanation

The inequality $|x + 1| < 3$ is equivalent to $-3 < x + 1 < 3$, or $-4 < x < 2$. The natural numbers in this range are $0$ and $1$ because $2$ is excluded and natural numbers are nonnegative. The set $\{-3, -2, -1, 0, 1\}$ contains all the integer solutions, but $-3$, $-2$, and $-1$ are not natural numbers. The set $\{0, 1, 2\}$ includes the endpoint $2$, and $\{1\}$ excludes $0$.
