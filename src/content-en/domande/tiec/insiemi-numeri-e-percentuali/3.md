Let $A$ be the set of positive divisors of $18$ and $B$ the set of positive divisors of $24$. Which of the following is $A \cap B$?

- $\{2, 3, 6\}$
- $\{1, 2, 3, 6\}$
- $\{1, 2, 3, 6, 9\}$
- $\{1, 2, 3, 4, 6, 8, 9, 12, 18, 24\}$

## Explanation

The divisors of $18$ are $1$, $2$, $3$, $6$, $9$, and $18$. The divisors of $24$ are $1$, $2$, $3$, $4$, $6$, $8$, $12$, and $24$. The **intersection** contains the numbers that appear in both lists, so $A \cap B = \{1, 2, 3, 6\}$. These are precisely the divisors of $\mathrm{MCD}(18, 24) = 6$. The set $\{2, 3, 6\}$ leaves out $1$, a divisor of every number. The set with ten elements is the union $A \cup B$.
