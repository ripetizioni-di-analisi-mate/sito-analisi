If $-2 < x < 2$, what does $|x - 2| + |x + 2|$ equal?

- $4$
- $2x$
- $-2x$
- $-4$

## Explanation

For $x < 2$, the quantity $x - 2$ is negative, so $|x - 2| = -(x - 2) = 2 - x$. For $x > -2$, the quantity $x + 2$ is positive, so $|x + 2| = x + 2$. The sum is $(2 - x) + (x + 2) = 4$ for every $x$ in the interval. The expression $2x$ results from removing the absolute value signs without checking the signs of the quantities, that is, from writing $(x - 2) + (x + 2)$.
