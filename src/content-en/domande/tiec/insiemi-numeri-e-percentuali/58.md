Which negative real numbers $x$ satisfy the inequality $x^3 < x$?

- $-1 < x < 0$
- $x \leq -1$
- $x < -1$
- $x < 0$

## Explanation

For $x < 0$ both sides of $x^3 < x$ can be divided by $x$, which is negative, so the inequality sign is reversed and we get $x^2 > 1$. Among negative numbers, the inequality $x^2 > 1$ holds if and only if $x < -1$. Therefore the negative numbers satisfying $x^3 < x$ are those with $x < -1$, such as $x = -2$, for which $-8 < -2$. For $x = -1$ we have $x^3 = x$, so the interval $x \leq -1$ contains a value that does not satisfy the strict inequality. The interval $-1 < x < 0$ comes from not reversing the inequality sign after dividing by $x$, and indeed for $x = -\dfrac{1}{2}$ we have $x^3 = -\dfrac{1}{8}$, which is greater than $-\dfrac{1}{2}$.
