For any two sets $A$ and $B$ in a universal set $U$, which expression equals $A \setminus B$?

- $\overline{A} \cap B$
- $A \cup \overline{B}$
- $A \cap \overline{B}$
- $\overline{A \cap B}$

## Explanation

An element belongs to $A \setminus B$ when it belongs to $A$ but not to $B$, that is, when it belongs to both $A$ and the complement $\overline{B}$. Therefore $A \setminus B = A \cap \overline{B}$. The set $\overline{A} \cap B$ is instead the difference $B \setminus A$. The set $A \cup \overline{B}$ also contains the elements outside both sets, and $\overline{A \cap B}$ also contains the elements of $B \setminus A$.
