Which of the following equalities is true?

- $0.4\overline{9} = \dfrac{1}{2}$
- $0.\overline{4} = \dfrac{2}{5}$
- $0.1\overline{2} = \dfrac{4}{33}$
- $1.\overline{1} = \dfrac{11}{10}$

## Explanation

The rule for the **fractional form** gives $0.4\overline{9} = \dfrac{49 - 4}{90} = \dfrac{45}{90} = \dfrac{1}{2}$, so the equality holds. Just as $0.\overline{9} = 1$, the number $0.4\overline{9}$ is another way to write $0.5$. The other equalities are false because $0.\overline{4} = \dfrac{4}{9}$, $0.1\overline{2} = \dfrac{12 - 1}{90} = \dfrac{11}{90}$, and $1.\overline{1} = \dfrac{11 - 1}{9} = \dfrac{10}{9}$.
