Read the note from a design studio. “We used to send clients a drawing before discussing a colour. We now ask for a colour first, as this has cut the number of drawings we have to redo.” What does “this” refer to?

- Sending every drawing twice to the same client.
- The number of drawings that still need changes.
- An individual colour chosen by the studio.
- Asking for the colour before preparing the drawing.

## Explanation

The demonstrative refers back to the change in procedure just described. The note attributes the reduction in rework to the order of the steps, without identifying any particular colour.
