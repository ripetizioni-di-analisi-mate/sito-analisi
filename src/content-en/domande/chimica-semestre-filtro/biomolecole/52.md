At the same residue count, one glucan has more branches than another. An enzyme removes residues only from nonreducing ends. With abundant enzyme and equal accessibility, which effect is plausible?

- More terminal sites can be used simultaneously.
- More branching always lowers the rate, even with more accessible ends.
- Terminal-site count remains equal because residue count is equal.
- Branching creates a new reducing end for every branch.

## Explanation

Branches create additional nonreducing ends, potentially increasing simultaneous enzyme attack sites. The prediction requires the specified enzyme abundance and accessibility; it is not a universal rate law. The branch linkage uses the branch’s anomeric centre, so it does not create a new free reducing centre. The same residue count can form structures with different numbers of ends.
