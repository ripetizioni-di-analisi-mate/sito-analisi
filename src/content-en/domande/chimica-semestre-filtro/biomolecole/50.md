An isolated glucan is a single tree structure without cycles, with one free reducing end and four binary branch points. How many nonreducing ends does it have?

- $4$.
- $8$.
- $1$.
- $5$.

## Explanation

An unbranched chain has one nonreducing end. Each binary branch adds one terminal path, so the total becomes $1+4=5$. Branching increases nonreducing ends without creating new free anomeric centres at the root. The assumptions exclude cycles, multiple molecules and a protein-blocked root.
