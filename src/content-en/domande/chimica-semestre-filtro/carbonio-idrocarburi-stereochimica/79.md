Which structure contains two conjugated double bonds?

- $\mathrm{CH_2{=}CH{-}CH{=}CH_2}$.
- $\mathrm{CH_2{=}CH{-}CH_2{-}CH_3}$.
- $\mathrm{CH_2{=}CH{-}CH_2{-}CH{=}CH_2}$.
- $\mathrm{CH_2{=}C{=}CH_2}$.

## Explanation

In buta-1,3-diene the double bonds are separated by one single bond between carbons with available p orbitals. Penta-1,4-diene contains an sp³ carbon interrupting conjugation. Propadiene is a cumulated diene, whereas but-1-ene contains only one double bond. Classification uses bond arrangement rather than count alone.
