A Fischer projection with one centre and four different groups is rotated 90° in the plane and then reinterpreted using Fischer conventions. What happens?

- Configuration is inverted.
- Configuration is preserved as with a 180° rotation.
- Only the two vertical groups keep the same spatial positions.
- The result represents a racemate rather than a single enantiomer.

## Explanation

After 90°, formerly vertical bonds become horizontal and are reinterpreted as pointing forwards, while the others point backwards. This changes the represented configuration. A 180° rotation instead preserves the horizontal/vertical distinction and produces an equivalent representation of the same centre.
