Let $a_{\mathrm{H^+}}=\gamma[\mathrm{H^+}]/c^\circ$, with $\gamma=0.50$, $[\mathrm{H^+}]=0.020\,\mathrm{mol\,L^{-1}}$ and $c^\circ=1\,\mathrm{mol\,L^{-1}}$. What is pH?

- $2.00$.
- $0.010$.
- Approximately $1.40$.
- Approximately $1.70$.

## Explanation

Apply the given coefficient before taking the logarithm: $a_{\mathrm{H^+}}=0.50\cdot0.020=0.010$, hence $\mathrm{pH}=2.00$. Using concentration alone would ignore the specified nonideality. The coefficient is a problem datum, not a universal value for all solutions.
