For the function $h(x) = \sqrt{1 + x^2}$, defined on $\mathbb{R}$, which of the following numbers is *not* the slope of any tangent line to the graph?

- $0$
- $\dfrac{1}{2}$
- $-\dfrac{1}{2}$
- $1$

## Explanation

By the chain rule, $h'(x) = \dfrac{2x}{2\sqrt{1 + x^2}} = \dfrac{x}{\sqrt{1 + x^2}}$. Since $\sqrt{1 + x^2} > \sqrt{x^2} = |x|$ for every $x$, we have $|h'(x)| < 1$, so no tangent line has slope $1$. At $x = 0$ we have $h'(0) = 0$. For $x > 0$ the equation $\dfrac{x}{\sqrt{1 + x^2}} = \dfrac{1}{2}$ is equivalent to $4x^2 = 1 + x^2$, therefore the slope $\dfrac{1}{2}$ occurs at $x = \dfrac{1}{\sqrt{3}}$. The function $h'$ is odd, so the slope $-\dfrac{1}{2}$ occurs at $x = -\dfrac{1}{\sqrt{3}}$, and the number that is never attained is $1$.
