The function $f(x) = x^{3}$ is approximated near $x_0 = 1$ by its tangent line. Which expression does the error $E(h) = f(1 + h) - \big( f(1) + f'(1)\,h \big)$ have?

- $E(h) = h^{3}$
- $E(h) = 3h + 3h^{2} + h^{3}$
- $E(h) = 3h^{2} + h^{3}$
- $E(h) = 3h^{2}$

## Explanation

We have $f(1) = 1$ and $f'(x) = 3x^{2}$, so $f'(1) = 3$ and the linear approximation is $1 + 3h$. Expanding the cube gives $f(1 + h) = 1 + 3h + 3h^{2} + h^{3}$. Therefore $E(h) = 1 + 3h + 3h^{2} + h^{3} - (1 + 3h) = 3h^{2} + h^{3}$. The ratio $\dfrac{E(h)}{h} = 3h + h^{2}$ tends to $0$ as $h \to 0$, as the theorem on **linear approximation** states. The expression $3h + 3h^{2} + h^{3}$ is the increment $f(1 + h) - f(1)$, which also contains the differential $3h$.
