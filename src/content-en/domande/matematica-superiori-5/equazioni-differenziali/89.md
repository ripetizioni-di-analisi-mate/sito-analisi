All solutions of the equation $y'' + y = 3\cos(2x)$ are described by exactly one of the following families. Which one?

- $y = C_1 \cos x + C_2 \sin x + 3\cos(2x)$
- $y = C_1 \cos x + C_2 \sin x + \cos(2x)$
- $y = C_1 e^{x} + C_2 e^{-x} - \cos(2x)$
- $y = C_1 \cos x + C_2 \sin x - \cos(2x)$

## Explanation

The characteristic equation $r^2 + 1 = 0$ has the roots $\pm i$, so the general solution of the homogeneous equation is $C_1 \cos x + C_2 \sin x$.

The number associated with the right-hand side is $\pm 2i$, which is not a root, so we look for $y_p = a\cos(2x) + b\sin(2x)$. Since $y_p'' = -4y_p$, substituting gives $-3a\cos(2x) - 3b\sin(2x) = 3\cos(2x)$, hence $a = -1$ and $b = 0$. The general solution is $y = C_1 \cos x + C_2 \sin x - \cos(2x)$.
