For the equation $y' = y^2 \sin x$ the condition $y(0) = 0$ is imposed. What can be said about the solutions of this initial value problem?

- It has the solution $y = 1 - \cos x$.
- The zero function $y \equiv 0$ is the only solution.
- It has infinitely many solutions, because $f(x, y) = y^2 \sin x$ vanishes for $y = 0$.
- It has no solutions, because no function $y = \dfrac{1}{\cos x + C}$ equals $0$ at $x = 0$.

## Explanation

The equation is separable with $h(y) = y^2$. Since $h(0) = 0$, the constant function $y \equiv 0$ is a solution and satisfies $y(0) = 0$.

The functions $f(x, y) = y^2 \sin x$ and $\dfrac{\partial f}{\partial y} = 2y \sin x$ are continuous in the whole plane, so by the **local existence and uniqueness theorem** the problem has exactly one solution, which is therefore the zero function.

The functions $y = \dfrac{1}{\cos x + C}$ are obtained by dividing by $y^2$ and do not include the zero solution, which must be found separately. The function $y = 1 - \cos x$ has derivative $\sin x$, which differs from $(1 - \cos x)^2 \sin x$, so it is not a solution.
