For which values of $a \in \mathbb{R}$ and $b > 0$ does $\displaystyle\lim_{x \to +\infty} \left( \sqrt{4x^2 + a x} - b x \right) = 3$ hold?

- $a = 12$, $b = 4$
- $a = 6$, $b = 2$
- $a = 12$, $b = 2$
- $a = 3$, $b = 2$

## Explanation

For $x > 0$ we factor out $x$ and obtain $\sqrt{4x^2 + a x} - b x = x \left( \sqrt{4 + \dfrac{a}{x}} - b \right)$. The second factor tends to $2 - b$, so if $b \neq 2$ the limit is infinite.

The limit can therefore be finite only for $b = 2$. In this case, multiplying and dividing by $\sqrt{4x^2 + a x} + 2x$, we obtain
$$
\sqrt{4x^2 + a x} - 2x = \frac{a x}{\sqrt{4x^2 + a x} + 2x} = \frac{a}{\sqrt{4 + \dfrac{a}{x}} + 2} ,
$$
which tends to $\dfrac{a}{4}$. The condition $\dfrac{a}{4} = 3$ gives $a = 12$.
