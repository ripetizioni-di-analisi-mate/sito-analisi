We have $\displaystyle\lim_{x \to 1} \frac{1}{(x - 1)^2} = +\infty$. What is the set of $x$ for which $\dfrac{1}{(x - 1)^2} > 10{,}000$?

- $0 < |x - 1| < \dfrac{1}{10{,}000}$
- $0 < |x - 1| < \dfrac{1}{100}$
- $|x - 1| > \dfrac{1}{100}$
- $0 < |x - 1| < \dfrac{1}{10}$

## Explanation

The function is defined for $x \neq 1$, and for these $x$ the denominator $(x - 1)^2$ is positive. Therefore the inequality $\dfrac{1}{(x - 1)^2} > 10{,}000$ is equivalent to $(x - 1)^2 < \dfrac{1}{10{,}000}$, that is to $|x - 1| < \dfrac{1}{100}$. Hence the required set is given by $0 < |x - 1| < \dfrac{1}{100}$. This is the $\delta = \dfrac{1}{100}$ of the definition of infinite limit with the threshold $M = 10{,}000$.
