Which statement about the function $f(x) = e^{-x^2}$ is true?

- $f$ has exactly one antiderivative on $\mathbb{R}$
- $-\dfrac{e^{-x^2}}{2x}$ is an antiderivative of it on $(0, +\infty)$
- The function $\displaystyle\int_0^x e^{-t^2}\, dt$ is an antiderivative of it on $\mathbb{R}$
- $f$ has no antiderivatives on $\mathbb{R}$

## Explanation

The function $e^{-x^2}$ is continuous on $\mathbb{R}$, so by the **fundamental theorem of calculus** the integral function $F(x) = \displaystyle\int_0^x e^{-t^2}\, dt$ is differentiable with $F'(x) = e^{-x^2}$, that is it is an antiderivative of $f$. The antiderivatives of $f$ are then exactly the functions $F(x) + c$ with $c \in \mathbb{R}$, and there are infinitely many. They cannot be written with elementary functions, but they exist. The function $-\dfrac{e^{-x^2}}{2x}$ has derivative $e^{-x^2} + \dfrac{e^{-x^2}}{2x^2}$, which differs from $f$.
