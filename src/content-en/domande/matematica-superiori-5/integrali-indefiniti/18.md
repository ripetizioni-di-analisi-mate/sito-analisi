Which of the following equalities is true?

- $\displaystyle\int 2^{x}\,dx = 2^{x} \ln 2 + c$
- $\displaystyle\int \dfrac{1}{x^2}\,dx = -\dfrac{1}{x} + c$ for $x > 0$
- $\displaystyle\int e^{x^2}\,dx = \dfrac{e^{x^2}}{2x} + c$
- $\displaystyle\int \ln x\,dx = \dfrac{1}{x} + c$ for $x > 0$

## Explanation

An equality between an indefinite integral and a function is true when the derivative of the function is the integrand. We have $\left( -\dfrac{1}{x} \right)' = \left( -x^{-1} \right)' = x^{-2} = \dfrac{1}{x^2}$, so the equality $\displaystyle\int \dfrac{1}{x^2}\,dx = -\dfrac{1}{x} + c$ is **true**. The derivative of $\dfrac{e^{x^2}}{2x}$ is $e^{x^2} - \dfrac{e^{x^2}}{2x^2}$, which differs from $e^{x^2}$. The function $\dfrac{1}{x}$ is the derivative of $\ln x$; an antiderivative of $\ln x$ is $x \ln x - x$. Finally, $2^{x} \ln 2$ is the derivative of $2^{x}$, while an antiderivative of $2^{x}$ is $\dfrac{2^{x}}{\ln 2}$.
