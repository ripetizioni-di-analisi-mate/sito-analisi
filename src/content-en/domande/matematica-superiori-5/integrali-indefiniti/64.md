For $x > 0$, which function is $\displaystyle\int (\ln x)^2\, dx$ equal to, up to an additive constant?

- $x (\ln x)^2 - 2x \ln x + 2x$
- $\dfrac{(\ln x)^3}{3}$
- $x (\ln x)^2 - 2x \ln x$
- $x (\ln x)^2 + 2x \ln x - 2x$

## Explanation

Write $(\ln x)^2 = 1 \cdot (\ln x)^2$ and apply **integration by parts** with $f(x) = (\ln x)^2$ and $g'(x) = 1$, so $f'(x) = \dfrac{2 \ln x}{x}$ and $g(x) = x$:
$$
\int (\ln x)^2\, dx = x (\ln x)^2 - \int 2 \ln x\, dx .
$$
A second integration by parts with the factor $1$ gives $\displaystyle\int \ln x\, dx = x \ln x - x + c$. Therefore
$$
\int (\ln x)^2\, dx = x (\ln x)^2 - 2x \ln x + 2x + c .
$$
The function $\dfrac{(\ln x)^3}{3}$ is an antiderivative of $\dfrac{(\ln x)^2}{x}$, where the factor $\dfrac{1}{x}$ appears.
