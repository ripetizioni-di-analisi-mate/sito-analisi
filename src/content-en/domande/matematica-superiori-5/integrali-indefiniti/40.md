Which function is an antiderivative of $f(x)=2x(x^2+9)$?

- $(x^{2} + 9)^{2}$
- $x^{2} + 9$
- $x (x^{2} + 9)$
- $\dfrac{(x^{2} + 9)^{2}}{2}$

## Explanation

Set $u=x^2+9$, so $du=2x\,dx$. The integral becomes $\int u\,du=\dfrac{u^2}{2}+C$. Thus, an antiderivative is $\dfrac{(x^2+9)^2}{2}$.
