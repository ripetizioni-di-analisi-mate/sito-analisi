Which function $F$ satisfies $F''(x) = 6x$ for every $x \in \mathbb{R}$, $F(0) = 1$ and $F'(0) = 2$?

- $F(x) = 3x^3 + 2x + 1$
- $F(x) = x^3 + 2x + 1$
- $F(x) = x^3 + x + 2$
- $F(x) = x^3 + 2x$

## Explanation

The function $F'$ is an antiderivative of $6x$, so $F'(x) = 3x^2 + c_1$. The condition $F'(0) = 2$ gives $c_1 = 2$, therefore $F'(x) = 3x^2 + 2$. Then $F$ is an antiderivative of $3x^2 + 2$, that is, $F(x) = x^3 + 2x + c_2$. The condition $F(0) = 1$ gives $c_2 = 1$, and hence $F(x) = x^3 + 2x + 1$.
