The exponential function $3^{x}$ has a base different from $e$. Which function is an antiderivative of it?

- $\dfrac{3^{x}}{\ln 3}$
- $\dfrac{3^{x + 1}}{x + 1}$
- $x\, 3^{x - 1}$
- $3^{x} \ln 3$

## Explanation

By the formula $\displaystyle\int a^{x}\, dx = \frac{a^{x}}{\ln a} + c$ from the table of **elementary integrals**, valid for $a > 0$ and $a \neq 1$, with $a = 3$ an antiderivative is $\dfrac{3^{x}}{\ln 3}$. The function $\dfrac{3^{x+1}}{x+1}$ comes from the power formula for $x^{\alpha}$, which requires the variable in the base and a constant exponent; in $3^x$ the variable is in the exponent, so that formula does not apply.
