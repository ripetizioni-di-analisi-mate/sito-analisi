With a suitable substitution the integral $\displaystyle\int \frac{\cos x}{\sin^2 x + 3 \sin x + 2}\, dx$ is reduced to that of a rational function. Which result is obtained?

- $\ln \left| \dfrac{\sin x + 2}{\sin x + 1} \right| + c$
- $\ln\left( \sin^2 x + 3 \sin x + 2 \right) + c$
- $\ln \left| \dfrac{\sin x + 1}{\sin x + 2} \right| + c$
- $\cos x \ln \left| \dfrac{\sin x + 1}{\sin x + 2} \right| + c$

## Explanation

With the **substitution** $t = \sin x$ one has $dt = \cos x\, dx$, so the integral becomes $\displaystyle\int \frac{dt}{t^2 + 3t + 2}$. The denominator factors as $(t + 1)(t + 2)$, and from $1 = A(t + 2) + B(t + 1)$ one gets $A = 1$ for $t = -1$ and $B = -1$ for $t = -2$. Therefore
$$
\int \frac{dt}{(t + 1)(t + 2)} = \ln|t + 1| - \ln|t + 2| + c = \ln \left| \frac{t + 1}{t + 2} \right| + c ,
$$
and with $t = \sin x$ one obtains $\ln \left| \dfrac{\sin x + 1}{\sin x + 2} \right| + c$.
