Which function is an antiderivative of $f(x)=2x(x^2+8)$?

- $(x^{2} + 8)^{2}$
- $x^{2} + 8$
- $\dfrac{(x^{2} + 8)^{2}}{2}$
- $x (x^{2} + 8)$

## Explanation

Set $u=x^2+8$, so $du=2x\,dx$. The integral becomes $\int u\,du=\dfrac{u^2}{2}+C$. Thus, an antiderivative is $\dfrac{(x^2+8)^2}{2}$.
