Which function is the antiderivative of $f(x) = \lvert x \rvert$ on $\mathbb{R}$ that equals $0$ at $x = 0$?

- $F(x) = -\dfrac{x^2}{2}$
- $F(x) = \dfrac{x^2}{2}$
- $F(x) = \dfrac{\lvert x \rvert^3}{3}$
- $F(x) = \dfrac{x \lvert x \rvert}{2}$

## Explanation

We have $\lvert x \rvert = x$ for $x \geq 0$ and $\lvert x \rvert = -x$ for $x < 0$, so we look for a function with derivative $x$ to the right of $0$ and $-x$ to the left. The function $F(x) = \dfrac{x \lvert x \rvert}{2}$ equals $\dfrac{x^2}{2}$ for $x \geq 0$ and $-\dfrac{x^2}{2}$ for $x < 0$, therefore
$$
F'(x) =
\begin{cases}
x & \text{if } x > 0 \\
-x & \text{if } x < 0
\end{cases}
$$
and at $x = 0$ the right and left difference quotients both tend to $0 = \lvert 0 \rvert$. Hence $F'(x) = \lvert x \rvert$ for every $x$, and $F(0) = 0$. The function $\dfrac{x^2}{2}$ has derivative $x$, which differs from $\lvert x \rvert$ for $x < 0$; the function $-\dfrac{x^2}{2}$ has derivative $-x$, which differs from $\lvert x \rvert$ for $x > 0$. The derivative of $\dfrac{\lvert x \rvert^3}{3}$ is $x \lvert x \rvert$.
