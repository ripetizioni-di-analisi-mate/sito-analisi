The product $x \arctan x$ is continuous on $\mathbb{R}$. What is the family of its antiderivatives?

- $\dfrac{x^2}{2} \arctan x - \dfrac{x}{2} + c$
- $\dfrac{x^2}{2} \arctan x + c$
- $\dfrac{x^2 - 1}{2} \arctan x + \dfrac{x}{2} + c$
- $\dfrac{x^2 + 1}{2} \arctan x - \dfrac{x}{2} + c$

## Explanation

Apply **integration by parts** differentiating the arctangent, with $f(x) = \arctan x$ and $g'(x) = x$, so $f'(x) = \dfrac{1}{1 + x^2}$ and $g(x) = \dfrac{x^2}{2}$:
$$
\int x \arctan x\, dx = \frac{x^2}{2} \arctan x - \frac{1}{2} \int \frac{x^2}{1 + x^2}\, dx .
$$
Since $x^2 = (1 + x^2) - 1$, one has $\dfrac{x^2}{1 + x^2} = 1 - \dfrac{1}{1 + x^2}$, so the remaining integral equals $x - \arctan x + c$. Therefore
$$
\int x \arctan x\, dx = \frac{x^2}{2} \arctan x - \frac{x}{2} + \frac{1}{2} \arctan x + c = \frac{x^2 + 1}{2} \arctan x - \frac{x}{2} + c .
$$
