Which oblique asymptotes does the function $f(x) = x + 2 + e^{-x}$ have?

- $y = x + 2$, only as $x \to +\infty$
- $y = x + 2$, both as $x \to +\infty$ and as $x \to -\infty$
- $y = x$, only as $x \to +\infty$
- No oblique asymptote

## Explanation

As $x \to +\infty$ we have $e^{-x} \to 0$. So $m = \displaystyle\lim_{x \to +\infty} \frac{f(x)}{x} = 1$ and $q = \displaystyle\lim_{x \to +\infty} \left( f(x) - x \right) = \lim_{x \to +\infty} \left( 2 + e^{-x} \right) = 2$, therefore $y = x + 2$ is an oblique asymptote as $x \to +\infty$.

As $x \to -\infty$ we set $t = -x \to +\infty$. We have $\dfrac{e^{-x}}{x} = -\dfrac{e^{t}}{t} \to -\infty$ by the **hierarchy of infinities**, so $\dfrac{f(x)}{x} \to -\infty$ and there is no oblique asymptote as $x \to -\infty$.
