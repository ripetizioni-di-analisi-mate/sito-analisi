Given a real number $a$, the function $f$ equals $x^2$ for $x \leq a$ and $2x$ for $x > a$. For which values of $a$ is $f$ continuous on $\mathbb{R}$?

- $a = 0$ or $a = 2$
- $a = 2$ only
- For no value of $a$
- $a = 0$ only

## Explanation

For $x < a$ and for $x > a$ the function coincides with a polynomial, so it is continuous; it remains to check the junction point $x = a$. The left-hand limit at $a$ is $a^2$, equal to $f(a)$, and the right-hand limit is $2a$. Therefore $f$ is continuous at $a$ if and only if $a^2 = 2a$, that is, $a(a - 2) = 0$. The solutions are $a = 0$ and $a = 2$, which are the points where the graphs of $x^2$ and $2x$ meet.
