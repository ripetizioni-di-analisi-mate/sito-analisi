For which value of the real parameter $a$ is the line $y = 2x + 5$ an oblique asymptote of the function $f(x) = \dfrac{2x^2 + ax}{x + 1}$ as $x \to +\infty$?

- $a = 7$
- $a = 5$
- $a = -3$
- $a = 3$

## Explanation

The slope is $m = \displaystyle\lim_{x \to +\infty} \frac{2x^2 + ax}{x\,(x + 1)} = 2$ for every $a$. For the intercept we compute
$$
f(x) - 2x = \frac{2x^2 + ax - 2x^2 - 2x}{x + 1} = \frac{(a - 2)\,x}{x + 1} ,
$$
which tends to $a - 2$, so $q = a - 2$. The asymptote is $y = 2x + 5$ if $a - 2 = 5$, that is if $a = 7$.
