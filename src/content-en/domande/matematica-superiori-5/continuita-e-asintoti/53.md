Which statement about the function $f(x) = 2x + \sqrt{x}$, defined for $x \geq 0$, is true as $x \to +\infty$?

- The line $y = 2$ is a horizontal asymptote
- The line $y = 2x + 1$ is an oblique asymptote
- The function has no oblique asymptote, because $f(x) - 2x$ tends to $+\infty$
- The line $y = 2x$ is an oblique asymptote

## Explanation

The function tends to $+\infty$, so it has no horizontal asymptote and we look for an oblique asymptote. The slope is
$$
m = \lim_{x \to +\infty} \frac{2x + \sqrt{x}}{x} = \lim_{x \to +\infty} \left( 2 + \frac{1}{\sqrt{x}} \right) = 2 .
$$
The intercept would be $q = \displaystyle\lim_{x \to +\infty} \big( f(x) - 2x \big) = \lim_{x \to +\infty} \sqrt{x}$, which equals $+\infty$. Since $q$ is not finite, the vertical distance between the graph and every line $y = 2x + c$ tends to $+\infty$, therefore the function has no oblique asymptote even though $m$ is finite and nonzero.
