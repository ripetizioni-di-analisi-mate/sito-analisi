Find the values of the real parameters $a$ and $b$ for which the function
$$
f(x) =
\begin{cases}
x + a & \text{if } x < 0 \\
b \cos x & \text{if } 0 \leq x \leq \pi \\
x - \pi + 2 & \text{if } x > \pi
\end{cases}
$$
is continuous on $\mathbb{R}$.

- $a=-2,\ b=-2$
- $a=2,\ b=2$
- $a=-2,\ b=2$
- $a=0,\ b=-2$

## Explanation

At zero the matching condition is $a=b\cos0=b$. At $\pi$ it is $b\cos\pi=2$, so $-b=2$ and $a=-2$ as well.
