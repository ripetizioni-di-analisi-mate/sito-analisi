The figure shows the graph of a function $f$ with its two asymptotes, dashed. Which of the following can be the expression of $f$?

::grafico{legenda=0 f="(2*x+1)/(x-1)" asintoti="x=1;y=2" xmin=-6 xmax=8 ymin=-6 ymax=10 titolo="The graph of $f$ with the vertical asymptote $x = 1$ and the horizontal asymptote $y = 2$"}

- $f(x) = \dfrac{2x + 1}{1 - x}$
- $f(x) = \dfrac{x + 2}{x - 1}$
- $f(x) = \dfrac{2x + 1}{x - 1}$
- $f(x) = \dfrac{2x + 1}{x + 1}$

## Explanation

The graph has the vertical asymptote $x = 1$, so the denominator vanishes at $x = 1$, and this rules out $\dfrac{2x + 1}{x + 1}$. It also has the horizontal asymptote $y = 2$. For a function $\dfrac{a x + b}{c x + d}$ with $c \neq 0$ the horizontal asymptote is $y = \dfrac{a}{c}$, so $\dfrac{x + 2}{x - 1}$ has asymptote $y = 1$ and $\dfrac{2x + 1}{1 - x}$ has asymptote $y = -2$. Therefore the only expression consistent with the graph is $\dfrac{2x + 1}{x - 1}$.
