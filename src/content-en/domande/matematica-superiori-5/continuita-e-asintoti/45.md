The one-sided limits of $f$ at $x=3$ both equal $5$, but $f(3)=1$. Which change makes the function continuous at that point?

- Set $f(3)=5$.
- Keep $f(3)=1$ and change only the value at $x=5$.
- Set $f(3)=0$.
- Remove $3$ from the domain.

## Explanation

Continuity requires the function value to equal the limit. The one-sided limits agree, so the limit exists and equals five.
