Which of the following planes forms the same angle with each of the three coordinate axes?

- $x - y + z = 2$
- $2x + y + 2z = 3$
- $x + 2y + z = 1$
- $x + y = 1$

## Explanation

Let $\vec{n} = (a, b, c)$ be the normal vector of the plane. By the definition of the angle between a line and a plane, the angle $\theta_x$ with the $x$-axis, whose direction vector is $(1, 0, 0)$, satisfies
$$
\sin\theta_x = \frac{|a|}{\|\vec{n}\|} ,
$$
and in the same way $\sin\theta_y = \dfrac{|b|}{\|\vec{n}\|}$ and $\sin\theta_z = \dfrac{|c|}{\|\vec{n}\|}$. The three angles are therefore equal if and only if $|a| = |b| = |c|$. Among the given planes only $x - y + z = 2$ has coefficients with equal absolute values, and it forms with each axis the angle $\theta$ with $\sin\theta = \dfrac{\sqrt{3}}{3}$. The planes $x + 2y + z = 1$ and $2x + y + 2z = 3$ form equal angles only with the $x$- and $z$-axes, and the plane $x + y = 1$ is parallel to the $z$-axis.
