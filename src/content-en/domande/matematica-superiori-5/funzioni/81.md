The function $f$ maps $A$ to $B$, and $g$ maps $B$ to $C$. If $g\circ f$ is injective, which conclusion always follows?

- $f$ is surjective onto $B$.
- $g$ is injective on all of $B$.
- $f$ is injective.
- $g$ is surjective onto $C$.

## Explanation

If two distinct elements had the same image under $f$, the composition would also map them to the same element. Injectivity of the composition rules this out.
