The figure shows the graph of a quadratic function, which passes through the points $(-1, 0)$, $(3, 0)$ and $(0, -3)$ and has its vertex at $(1, -4)$. Which function is represented?

::grafico{f="x^2-2*x-3" punti="-1,0,pieno;3,0,pieno;0,-3,pieno;1,-4,pieno" xmin=-3 xmax=5 ymin=-5 ymax=5 legenda=0}

- $f(x) = x^2 + 2x - 3$
- $f(x) = -x^2 + 2x + 3$
- $f(x) = x^2 - 2x - 3$
- $f(x) = x^2 - 2x + 3$

## Explanation

The function vanishes at $-1$ and at $3$, so it can be written as $f(x) = a\,(x + 1)(x - 3)$. Since $f(0) = -3a$ and the graph passes through $(0, -3)$, we have $-3a = -3$, that is, $a = 1$. Therefore $f(x) = (x + 1)(x - 3) = x^2 - 2x - 3$, and indeed $f(1) = 1 - 2 - 3 = -4$. The function $-x^2 + 2x + 3$ has the same zeros but equals $3$ at $0$. The function $x^2 + 2x - 3$ vanishes at $-3$ and at $1$, and the function $x^2 - 2x + 3$ has discriminant $4 - 12 < 0$, so it has no zeros.
