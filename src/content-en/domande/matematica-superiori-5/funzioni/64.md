The function $f(x) = x^2 + b x + c$ satisfies $f(1) = f(7)$. What is $b$?

- $8$
- $-8$
- $-4$
- $4$

## Explanation

The parabola is symmetric with respect to the vertical line through the vertex, so two points with the same $y$-coordinate have $x$-coordinates symmetric about $x_V$. Therefore $x_V$ is the midpoint between $1$ and $7$, that is, $x_V = 4$. Since $x_V = -\dfrac{b}{2a}$ with $a = 1$, we have $-\dfrac{b}{2} = 4$, so $b = -8$. Indeed the equality $1 + b + c = 49 + 7b + c$ gives $6b = -48$. The value $-4$ is the $x$-coordinate of the vertex with the sign changed.
