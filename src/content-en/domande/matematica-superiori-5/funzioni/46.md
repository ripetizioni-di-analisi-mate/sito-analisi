For which real values of $x$ is the function $f(x)=\sqrt{\dfrac{x - 2}{x + 5}}$ defined?

- $(-\infty,-5] \cup [2,+\infty)$
- $(-5,2]$
- $[2,+\infty)$
- $(-\infty,-5) \cup [2,+\infty)$

## Explanation

The radicand $\dfrac{x-2}{x+5}$ is positive when the numerator and denominator have the same sign, that is for $x<-5$ or $x>2$, and it is zero for $x=2$. The value $x=-5$ makes the denominator zero, so it is excluded. Therefore the domain is $(-\infty,-5) \cup [2,+\infty)$.
