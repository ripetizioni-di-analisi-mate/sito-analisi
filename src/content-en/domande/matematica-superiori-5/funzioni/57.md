Let $f(x) = -\dfrac{1}{x}$, defined on $\mathbb{R} \setminus \{0\}$. Which statement is true?

- $f$ is increasing on $\mathbb{R} \setminus \{0\}$
- $f$ is increasing on $(-\infty, 0)$ and on $(0, +\infty)$, but not on $\mathbb{R} \setminus \{0\}$
- $f$ is decreasing on $(0, +\infty)$
- $f$ is decreasing on $\mathbb{R} \setminus \{0\}$

## Explanation

If $x_1 < x_2$ have the same sign, then $\dfrac{1}{x_1} > \dfrac{1}{x_2}$, so $-\dfrac{1}{x_1} < -\dfrac{1}{x_2}$. Therefore $f$ is increasing on $(-\infty, 0)$ and on $(0, +\infty)$. On all of $\mathbb{R} \setminus \{0\}$, however, $f$ is not increasing, because $-1 < 1$ and $f(-1) = 1 > f(1) = -1$. It is not decreasing either, because $-2 < -1$ and $f(-2) = \dfrac{1}{2} < f(-1) = 1$.
