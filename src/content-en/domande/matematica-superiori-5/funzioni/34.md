A relation consists only of the points $(0,1)$, $(1,1)$ and $(2,3)$. What property does it have?

- It is a function and is not injective.
- It is an injective function.
- It is not a function because the domain is finite.
- It is not a function because $1$ occurs twice as an output.

## Explanation

Each input has one output, so the relation defines a function. However, the distinct inputs $0$ and $1$ share the output $1$, so the function is not injective. A vertical line selects one input and here meets at most one point. The horizontal line $y=1$, however, meets $(0,1)$ and $(1,1)$. These two checks distinguish uniqueness of the output from uniqueness of its preimage.
