The function $f(x) = x^3 + x + 1$ is increasing on $\mathbb{R}$, so it is invertible. What is $f^{-1}(3)$?

- $31$
- $\dfrac{1}{31}$
- $1$
- $0$

## Explanation

By the definition of **inverse function**, $f^{-1}(3)$ is the unique $x$ such that $f(x) = 3$, that is, such that $x^3 + x - 2 = 0$. The number $x = 1$ satisfies the equation, because $1 + 1 + 1 = 3$. The function is increasing, so it is injective and no other $x$ has image $3$. Therefore $f^{-1}(3) = 1$. The number $31$ is instead $f(3)$, and $\dfrac{1}{31}$ is its reciprocal.
