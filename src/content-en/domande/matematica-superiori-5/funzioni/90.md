A machine applies the same function $f(x)=ax+b$ twice. The result is $x+6$ for every real input $x$. Which pair $(a,b)$ is possible?

- $(-1,3)$
- $(1,3)$
- $(1,6)$
- $(2,2)$

## Explanation

Applying the function twice gives $a^2x+(a+1)b$. We need $a^2=1$ and $(a+1)b=6$. The value $a=-1$ makes the constant term zero, so $a=1$ and $b=3$.
