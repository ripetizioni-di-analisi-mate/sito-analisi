The domain of $\dfrac{\sqrt{x+4}}{\ln(x+2)}$ must satisfy $x>-2$. Which additional value must be excluded, and why?

- $1$, because the logarithm would have argument $1$.
- $0$, because the numerator is zero.
- $-1$, because the denominator is zero.
- $2$, because the denominator changes base.

## Explanation

For $x>-2$ the radicand is positive. The logarithm in the denominator is zero when $x+2=1$, that is, at $x=-1$.
