A system has two parallel branches. Both components $A$ and $B$ must work for the first branch to operate. The second requires only component $C$. The three operating events are mutually independent, each with probability $\dfrac{1}{2}$. What is the system's reliability?

- $\dfrac{5}{8}$
- $\dfrac{3}{4}$
- $\dfrac{1}{8}$
- $\dfrac{7}{8}$

## Explanation

The first branch operates if $A$ and $B$ both work, with probability $\dfrac14$. The second operates if $C$ works, with probability $\dfrac12$. Only one branch is required, so add the two probabilities and subtract the intersection in which all three components work. By mutual independence the intersection has probability $\dfrac18$. System reliability is therefore $\dfrac14+\dfrac12-\dfrac18=\dfrac58$.
