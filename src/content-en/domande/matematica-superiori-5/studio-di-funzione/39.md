The graph of the arctangent and a horizontal line $y = k$ have at least one common point. Which values can $k$ take?

- $-\dfrac{\pi}{2} \leq k \leq \dfrac{\pi}{2}$
- $-\dfrac{\pi}{2} < k < \dfrac{\pi}{2}$
- For every $k \in \mathbb{R}$
- $-1 \leq k \leq 1$

## Explanation

The function $\arctan x$ is continuous and strictly increasing on $\mathbb{R}$, with limits $-\dfrac{\pi}{2}$ as $x \to -\infty$ and $\dfrac{\pi}{2}$ as $x \to +\infty$. By the intermediate value theorem it takes every value strictly between the two limits, and by strict monotonicity it does not reach the values $\pm\dfrac{\pi}{2}$, which are the ordinates of the horizontal asymptotes. Therefore the equation has a solution if and only if $-\dfrac{\pi}{2} < k < \dfrac{\pi}{2}$, and in that case the solution is unique.
