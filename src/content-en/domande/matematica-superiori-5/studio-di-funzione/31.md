The function $f(x) = x^3 + ax^2 - 9x$ depends on the real parameter $a$. For which value of $a$ is the point $x = -3$ a relative maximum point?

- $a = 6$
- $a = -3$
- $a = 3$
- $a = 0$

## Explanation

The function is differentiable on $\mathbb{R}$, with $f'(x) = 3x^2 + 2ax - 9$. By **Fermat's theorem** a relative maximum point in the interior of the domain is stationary, so we need
$$
f'(-3) = 27 - 6a - 9 = 18 - 6a = 0 ,
$$
that is, $a = 3$. With $a = 3$ we have $f'(x) = 3x^2 + 6x - 9 = 3(x + 3)(x - 1)$, positive for $x < -3$ and negative for $-3 < x < 1$. Therefore, by the **first derivative test**, $x = -3$ is a relative maximum point, and the required value is $a = 3$.
