The function $f : \mathbb{R} \to \mathbb{R}$ is defined by $f(x) = x^2$ for $x \neq 0$ and by $f(0) = 1$. Which statement about the point $x = 0$ is true?

- It is a local minimum point
- It is a local maximum point, but not an absolute maximum point
- It is an absolute minimum point
- It is not an extremum, because $f$ is not continuous at $x = 0$

## Explanation

For $0 < |x| < 1$ we have $f(x) = x^2 < 1 = f(0)$, so the inequality $f(x) \leq f(0)$ holds for every $x$ with $|x| < 1$. Therefore, by the definition with $\delta = 1$, the point $x = 0$ is a **local maximum point**. The maximum is not absolute, because for example $f(2) = 4 > 1$. The definition of local maximum requires neither continuity nor differentiability of $f$ at $x = 0$, so the discontinuity does not rule out the extremum.
