A continuous function on a closed interval has minimum $1$ and maximum $7$. We want to approximate it by a constant $c$ while keeping the largest error $\max_x |f(x)-c|$ as small as possible. Which constant should we choose?

- $c=3$
- $c=4$
- $c=6$
- $c=7$

## Explanation

The extreme values are attained, so the largest error is $\max\{|1-c|,|7-c|\}$. An interval centred at $c$ must cover both endpoints, which are $6$ apart. The smallest possible radius is $3$, achieved when $c=(1+7)/2=4$.
