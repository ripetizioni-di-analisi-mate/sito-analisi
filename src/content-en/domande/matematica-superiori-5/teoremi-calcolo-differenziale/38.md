A differentiable function $f$ vanishes at $0$ and $1$. Which auxiliary function allows Rolle's theorem to show that $f'(c)=f(c)$ for some $0<c<1$?

- $h(x)=x-f(x)$
- $h(x)=f(x)+x$
- $h(x)=e^x+f(x)$
- $h(x)=e^{-x}f(x)$

## Explanation

The proposed function vanishes at both endpoints and satisfies $h'(x)=e^{-x}(f'(x)-f(x))$. At the point supplied by Rolle's theorem the exponential is positive, so the difference must vanish.
