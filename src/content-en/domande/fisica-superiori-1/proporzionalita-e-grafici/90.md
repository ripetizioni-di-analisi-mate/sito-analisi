As $x$ changes from $1$ to $2$ and then $4$, $y$ is $12$, $3$, and $0.75$. Which rule exactly fits all three observations?

- $y=12/x$
- $y=12/x^2$
- $y=3x^2$
- $y=15-3x$

## Explanation

Doubling the horizontal value gives one quarter of the vertical value each time. The vertical value times the horizontal value squared remains twelve.
