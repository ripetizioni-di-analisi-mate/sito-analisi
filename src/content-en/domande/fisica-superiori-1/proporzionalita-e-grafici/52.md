In a table, the horizontal values go from $1$ to $2$ to $5$ and vertical values are $3$, $5$, $11$. Which check is appropriate for an affine law?

- Compare only the increases $2$ and $6$
- Require each product $xy$ to be constant
- Calculate one ratio $y/x$ and ignore the others
- Compare $\dfrac{5-3}{2-1}$ and $\dfrac{11-5}{5-2}$

## Explanation

The horizontal intervals differ in width. Divide each increase by its own interval. Both slopes equal two.

The first interval has width one and the second width three. The second vertical increase is three times the first, which is exactly what equal slopes require.
