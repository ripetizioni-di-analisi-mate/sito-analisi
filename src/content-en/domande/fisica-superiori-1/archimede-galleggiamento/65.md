Why subtract float mass from maximum displaced-liquid mass to find available payload?

- Because available buoyancy supports float and payload together
- Because the float loses mass when volume is measured
- Because maximum displaced mass concerns cargo alone
- Because liquid density is added to the mass

## Explanation

Total capacity supports the full weight, including the float. The unloaded float already uses some of that capacity.

For example, with the same maximum volume, a heavier float needs more buoyancy even when empty. It has less capacity for a load before full submersion.
