One arrow has components $(3;b)$ and a second has components $(-6;8)$. The second is obtained by multiplying both components of the first by the same number. What is $b$?

- $4$
- $8$
- $-4$
- $-8$

## Explanation

The first component changes from $3$ to $-6$, so the common multiplier is $-2$. The second component must then satisfy $(-2)b=8$, giving $b=-4$. Check by multiplying both components of $(3;-4)$ by $-2$. This reproduces $(-6;8)$ and reverses the direction of the arrow.
