Which vector is not parallel to $(2;3)$?

- $(3;2)$
- $(4;6)$
- $(-2;-3)$
- $(6;9)$

## Explanation

A parallel arrow uses the same multiplier in both components. Going from $(2;3)$ to $(3;2)$ requires different factors.

The ratio of first components would be $\dfrac32$, while that of the second components would be $\dfrac23$. Since they differ, no single number can multiply both given components to produce that pair.
