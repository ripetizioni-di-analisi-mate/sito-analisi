If only the positive sense of axis $x$ is reversed, which pair represents the same vector previously written $(4;-7)\,\mathrm N$?

- $(-4;7)\,\mathrm N$
- $(4;7)\,\mathrm N$
- $(-7;4)\,\mathrm N$
- $(-4;-7)\,\mathrm N$

## Explanation

The reading convention changed only for the horizontal component. The vertical contribution keeps its numerical value and sign.
