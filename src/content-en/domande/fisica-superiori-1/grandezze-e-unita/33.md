Which factor multiplies a value in millimetres to obtain the corresponding value in centimetres?

- $0.1$
- $10$
- $0.01$
- $0.001$

## Explanation

One centimetre contains ten millimetres. Obtain the number of centimetres by dividing the number of millimetres by ten, or multiplying it by $0.1$. For example, $30\,\mathrm{mm}$ become $3\,\mathrm{cm}$. The numerical result is smaller because the new unit is larger and measures the same segment.
