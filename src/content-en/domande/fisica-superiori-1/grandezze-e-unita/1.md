A tape is $330\,\mathrm{cm}$ long. Express its length in metres.

- $3.3\,\mathrm m$
- $330\,\mathrm m$
- $33\,\mathrm m$
- $33000\,\mathrm m$

## Explanation

The aim is to describe the same length in metres. Each centimetre represents one hundredth of a metre, so the number of centimetres is multiplied by $10^{-2}$. The value in metres is smaller because a metre contains one hundred centimetres. Multiplying the new value by one hundred recovers the original reading.

It follows that $l=330\cdot10^{-2}\,\mathrm m=3.3\,\mathrm m$.
