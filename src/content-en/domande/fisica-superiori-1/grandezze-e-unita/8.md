A sensor records an interval of $30\,\mathrm{{ms}}$. How long is it in seconds?

- $30000\,\mathrm s$
- $0.3\,\mathrm s$
- $0.00003\,\mathrm s$
- $0.03\,\mathrm s$

## Explanation

The symbol $\mathrm{ms}$ means a second with the prefix milli. One second contains a thousand one-millisecond intervals, so an interval of one millisecond represents $10^{-3}\,\mathrm s$. Multiply this value by the number of milliseconds to find the recorded time. The quantity remains a duration.

It follows that $t=30\cdot10^{-3}\,\mathrm s=0.03\,\mathrm s$.
