What does the number $12$ in $l=12\,\mathrm{cm}$ represent?

- How many metres make up the length
- The name of the quantity
- How many one-centimetre units make up the length
- The absolute uncertainty of the measurement

## Explanation

The number $12$ says how many one-centimetre units fit along the segment. If millimetres are chosen, the same segment contains $120$ units because each centimetre contains ten. Changing the unit changes the associated numerical value while leaving the measured length unchanged.
