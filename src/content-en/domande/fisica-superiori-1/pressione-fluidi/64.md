An ideal press transmits work from an input piston to an output piston. The constant input force and the input travel are fixed. Can the constant output force be doubled while keeping the same output travel, by changing only the piston areas?

- Yes, if both areas are doubled
- Yes, if only the output area is doubled
- Yes, if only the input area is halved
- No, it would require twice the input work

## Explanation

In the ideal model, the input and output work are equal. Doubling the force while keeping the same travel would double the output work. The areas change the force and travel ratios, but the available work is fixed by the product of input force and input travel.
