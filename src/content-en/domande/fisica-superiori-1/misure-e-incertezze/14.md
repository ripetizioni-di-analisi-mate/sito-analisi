An instrument always reads $26\,\mathrm g$ higher than the values of known reference masses. Which description is correct?

- The measurements are exact because the deviation repeats
- There is a positive systematic offset
- Averaging many readings will certainly remove the offset
- The deviation is necessarily random

## Explanation

Find the deviation by subtracting the reference from the reading. It is positive and repeats for the samples compared. This indicates a systematic offset over the range examined. Averaging many readings would still give a value displaced from the reference masses.

Here the reading exceeds the reference by $26\,\mathrm g$.
