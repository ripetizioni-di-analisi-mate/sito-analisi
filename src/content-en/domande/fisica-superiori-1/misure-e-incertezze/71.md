An empty balance reads $-6\,\mathrm g$. With an object on it, the balance reads $44\,\mathrm g$. What is the object’s mass if the zero offset stays constant?

- $38\,\mathrm g$
- $44\,\mathrm g$
- $50\,\mathrm g$
- $22\,\mathrm g$

## Explanation

With the balance empty, the reference is zero, so the reading is $6\,\mathrm g$ below the reference value. The same offset applies to the object’s reading. Subtract the signed offset to get $44-(-6)=50\,\mathrm g$. Subtracting $6\,\mathrm g$ from the reading would increase the error.
