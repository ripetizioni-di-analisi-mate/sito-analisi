Which test can detect a repeatable systematic offset in a scale?

- Increase the number of displayed digits
- Measure known reference masses and compare readings with them
- Read only the name of the unit again
- Use the first unknown reading as the reference

## Explanation

Estimating the deviation requires a known mass to compare with the reading. Several reference masses show whether the difference stays constant or depends on the amount weighed. Repeating the measurement of an unknown object can estimate the spread of readings. Detecting a repeatable shift from the true value requires comparison with references.
