The horizontal pull on an initially stationary block with a normal force of $40\,\mathrm{N}$ is slowly increased from zero. The pull is held at $8\,\mathrm{N}$ and the block remains stationary. When the pull is increased again, the block starts sliding before it reaches $12\,\mathrm{N}$. In the Coulomb model, which range contains all the values of $\mu_s$ consistent with both observations?

- $0.20\leq\mu_s<0.30$
- $0.20<\mu_s\leq0.30$
- $0\leq\mu_s<0.20$
- $0.30\leq\mu_s$

## Explanation

While the block is stationary, friction balances the pull. The limit $\mu_sN$ must be at least $8\,\mathrm{N}$ and below $12\,\mathrm{N}$, since sliding starts before that value. Dividing both endpoints by $40\,\mathrm{N}$ gives $0.20\leq\mu_s<0.30$. At a threshold of exactly $8\,\mathrm{N}$, equilibrium is still possible in the model.
