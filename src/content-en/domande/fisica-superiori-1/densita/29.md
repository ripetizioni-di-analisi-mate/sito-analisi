A laboratory density is $0.6\,\mathrm{g/mL}$. What is it in $\mathrm{mg/mL}$?

- $600\,\mathrm{mg/mL}$
- $0.0006\,\mathrm{mg/mL}$
- $60\,\mathrm{mg/mL}$
- $600000\,\mathrm{mg/mL}$

## Explanation

The stated mass for a millilitre is $0.6\,\mathrm{g}$. The same volume contains $600\,\mathrm{mg}$ because there are a thousand milligrams in a gram. The denominator stays in millilitres, so only the number in the numerator changes. Both expressions give the same mass per unit of volume.
