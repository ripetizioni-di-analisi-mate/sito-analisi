An incline problem is set up with horizontal and vertical axes. Which alternative simplifies the equations without changing the physics?

- Use axes parallel and perpendicular to the ramp
- Add all magnitudes in a single equation
- Omit the normal since it is inclined
- Use two axes both parallel to the ramp

## Explanation

Using axes aligned with the plane puts the normal reaction and friction on separate axes. Zero resultant is the same physical condition in both systems.

Recalculate the two components of weight in the rotated axes. This makes it straightforward to put friction in the uphill balance and the normal force in the perpendicular one.
