A block weighing $15\,\mathrm N$ is pressed against a wall with $\mu_s=0.50$. In two trials the push has the same $40\,\mathrm N$ component towards the wall. Its vertical component is $9\,\mathrm N$ upwards in trial A and $9\,\mathrm N$ downwards in trial B. In which trials is rest possible?

- Only in A.
- Only in B.
- In both A and B.
- In neither trial.

## Explanation

The normal force is the same in both trials, so the friction limit is always $0.50\cdot40\,\mathrm N=20\,\mathrm N$. In A the vertical push helps support the weight, and $6\,\mathrm N$ of upward friction is needed. In B the push adds to the weight, so $24\,\mathrm N$ is needed. Only the first value is within the limit.
