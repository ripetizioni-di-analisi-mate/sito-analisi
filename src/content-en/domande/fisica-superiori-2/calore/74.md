An object releases $8400$ joules, and the insulated system contains only two objects without phase changes. What is the signed heat transfer for the other object?

- $-8400\,\mathrm J$
- $+8400\,\mathrm J$
- $0\,\mathrm J$
- $+16800\,\mathrm J$

## Explanation

For an insulated system exchanging only heat internally, the signed contributions add to zero. Use positive capacities and signed changes.
