What stays the same when the zero height changes without moving the object?

- Every numerical value of $U_g$
- Each point's coordinate measured from zero
- Work done by weight between two fixed positions
- The sign of the potential energy at each point

## Explanation

Raising the reference level subtracts the same amount from the energies at both points. The difference $\Delta U_g$ is unchanged because the reference shifts cancel in the subtraction. Gravity does work $-\Delta U_g$, which also stays unchanged even if one of the energies changes sign.
