Under which conditions can the speed $v$ be found from the relation $v^2=v_x^2+v_y^2$?

- For parallel axes only
- For perpendicular axes and consistent units on both components
- Only if both components are positive
- Only if the components agree

## Explanation

Pythagoras applies because the components along perpendicular axes are the legs of a right triangle. Express the components in the same unit before adding their squares. For example, a component of $300\,\mathrm{cm/s}$ must be written as $3\,\mathrm{m/s}$ when the other is in metres per second.
