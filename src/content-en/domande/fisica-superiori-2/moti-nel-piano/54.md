When does $u^2=v_x^2+v_y^2$ hold for vector components?

- For parallel axes only
- For perpendicular axes and consistent units on both components
- Only if both components are positive
- Only if the components agree

## Explanation

Pythagoras requires perpendicular legs and lengths in the same unit. The signs disappear on squaring.
