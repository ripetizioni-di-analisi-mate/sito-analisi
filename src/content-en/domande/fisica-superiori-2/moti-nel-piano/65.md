Take the horizontal and time origins at launch. Given a horizontal coordinate, how can one find the ball’s height during horizontal launch?

- Divide $x$ directly by $g$
- Set height equal to horizontal position
- Add the initial height to time
- First use $t=\frac{x}{u_0}$ and then the vertical equation

## Explanation

The x equation lets you work back to time. The required quantity is the vertical height at the same instant, within the flight phase.
