An experiment launches two balls from the same height and the faster horizontal launch stays in the air longer. Which check concerns the conditions for the vertical motion?

- Use mass alone to predict which ball lands first
- Adjust the value of $g$ using the horizontal launch speed
- Check that both start horizontally and land at the same level
- Attribute the longer time to the greater horizontal distance

## Explanation

In the model without air resistance, vertical motion depends on the initial vertical velocity and the vertical distance to the landing point. A slight launch angle or a different landing height changes flight time. The check tests these conditions for both balls.
