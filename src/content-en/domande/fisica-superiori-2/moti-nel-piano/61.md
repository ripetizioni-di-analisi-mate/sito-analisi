Two balls start horizontally from the same height with different horizontal speeds and reach the same floor. Which arrives first, neglecting air?

- The one with the higher initial speed
- The one with the lower initial speed
- They arrive at the same time
- Necessarily the heavier one

## Explanation

Height follows the same initial zero vertical velocity and the same acceleration. Only the distance covered horizontally changes.
