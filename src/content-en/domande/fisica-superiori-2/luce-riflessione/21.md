Two light pulses leave the same point in the same direction in vacuum, $2.0\,\mathrm{\mu s}$ apart in time. Using $c=3.0\cdot10^8\,\mathrm{m/s}$, what distance separates them after the second pulse leaves?

- $600\,\mathrm m$
- $1200\,\mathrm m$
- $300\,\mathrm m$
- $0\,\mathrm m$

## Explanation

When the second pulse starts, the first has already travelled a distance equal to $c$ times the delay. From then on, both move at the same speed in the same direction. They gain the same displacement in each later interval, so the initial separation stays constant.

$$
s=c\Delta t=3.0\cdot10^8\cdot2.0\cdot10^{-6}\,\mathrm m=600\,\mathrm m.
$$
