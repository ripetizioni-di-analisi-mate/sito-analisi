A thin lens with a real object gives $q>0$. On which side can a screen be placed to catch the image?

- The same side as the real object.
- Any plane gives the same focus.
- Neither side, since positive q indicates a virtual image.
- The side opposite the real object in the image plane.

## Explanation

For a real object light enters from the object side. A positive $q$ measures distance from the centre towards the output. The screen must intercept the rays at the plane where they converge.
