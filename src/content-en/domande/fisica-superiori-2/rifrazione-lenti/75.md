An experiment gives M = −0.4. What do its sign and magnitude describe?

- An upright image forty per cent of the object height.
- A lens with power −0.4 dioptres.
- An inverted image four times taller.
- An inverted image forty per cent of the object height.

## Explanation

The value means the image top lies below the axis when the object top is above it. With an object $5\,\mathrm{cm}$ tall, for example, the signed height would be $-2\,\mathrm{cm}$. The ratio of physical heights is four tenths.
