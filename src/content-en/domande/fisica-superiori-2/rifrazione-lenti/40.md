A thin lens forms an image with $M=0.40$ from a real object at $p=24\,\mathrm{cm}$. Find the signed image position.

- $9.6\,\mathrm{cm}$
- $-60\,\mathrm{cm}$
- $-12\,\mathrm{cm}$
- $-9.6\,\mathrm{cm}$

## Explanation

For a real object the product $Mp$ is positive. The relation for $q$ includes a minus sign, so the image distance is negative. The image is virtual on the object side and has forty per cent of the original height.

$$
q=-Mp=-0.40\cdot24\,\mathrm{cm}=-9.6\,\mathrm{cm}.
$$
