In $x=x_0+v(t-t_0)$, which check identifies the initial value?

- Set $x=0$ and always obtain $t=t_0$
- Set $v=0$ and always obtain $x=0$
- Multiply $x_0$ by $t_0$
- Set $t=t_0$ and obtain $x=x_0$

## Explanation

At the initial time no time has elapsed, so the equation reduces to the initial position.

If the initial measurement occurs when the clock reads $5\,\mathrm s$, perform the check at that instant. Substituting zero would be justified only if $t_0$ were zero as well.
