With the same axis and clock, which condition describes a meeting?

- Velocities have the same value
- Distances from the two starting points are equal
- Speeds are opposite
- The positions are equal at the same time

## Explanation

Objects with different velocities can occupy the same point at the same time. Equate positions to find a meeting.

Passing the same coordinate at different times is insufficient. The position–time graphs need a shared point because the same horizontal coordinate fixes one time and the same vertical coordinate fixes one position.
