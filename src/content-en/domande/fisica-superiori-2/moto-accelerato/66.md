Which displacement term remains if an object starts from rest with constant non-zero acceleration?

- $\frac12 at^2$
- $v_0t$
- $at$
- $x_0$

## Explanation

Starting from rest means $v_0=0$, so the term $v_0t$ makes no contribution to displacement. This leaves $\dfrac12at^2$. The initial position can be nonzero, but it cancels when you subtract $x_0$ to find displacement. The object can therefore start at any position. Acceleration also determines the direction of displacement because time squared is positive after departure. Negative acceleration would give negative displacement.
