A sensor reads $20\,{}^\circ\mathrm C$ when a reference in contact reads $298.15\,\mathrm K$. What is the sensor error, defined as its reading minus the true value?

- $5\,{}^\circ\mathrm C$
- $-25\,{}^\circ\mathrm C$
- $-5\,{}^\circ\mathrm C$
- $278.15\,{}^\circ\mathrm C$

## Explanation

First put the reference on the Celsius scale, then subtract the true value.

$$
e=[20-(298.15-273.15)]\,{}^\circ\mathrm C=-5\,{}^\circ\mathrm C.
$$

The reference on the Celsius scale is $25\,{}^\circ\mathrm C$. The probe reads $20\,{}^\circ\mathrm C$, five degrees below the true value. The error is negative because it is defined as the reading minus the reference. Correcting this reading would require adding five degrees.
