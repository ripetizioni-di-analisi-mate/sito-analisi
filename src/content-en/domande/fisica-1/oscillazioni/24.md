A body attached to an ideal spring oscillates on a smooth horizontal plane with period $0{,}40\,\mathrm{s}$. The same body is then hung from the same spring, placed vertically, and set oscillating about the equilibrium position. Which statement about the new period is true?

- It is greater than $0{,}40\,\mathrm{s}$, because the weight stretches the spring
- It is equal to $0{,}40\,\mathrm{s}$, because the weight only shifts the center of the oscillation
- It is less than $0{,}40\,\mathrm{s}$, because the weight adds to the elastic force
- It can be computed only by knowing the static extension of the spring

## Explanation

We direct the axis downward and denote by $s$ the displacement from the equilibrium position, where the spring is stretched by $\Delta\ell = \dfrac{mg}{k}$. Since the weight is balanced by the part $k\,\Delta\ell$ of the elastic force, Newton's second law gives $m\ddot{s} = -ks$. The equation coincides with that of the horizontal spring, so the angular frequency is still $\omega = \sqrt{\dfrac{k}{m}}$ and the period remains $0{,}40\,\mathrm{s}$. The static extension is determined by $m$ and $k$, therefore the formula $T = 2\pi\sqrt{\dfrac{\Delta\ell}{g}}$ gives the same value without further data.
