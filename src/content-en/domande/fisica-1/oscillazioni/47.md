Which of the following functions is **not** a solution of the equation $\ddot{x} = -9x$?

- $x(t) = 2\cos(3t)$
- $x(t) = \cos(9t)$
- $x(t) = \sin(3t + 1)$
- $x(t) = 5\cos(3t) - \sin(3t)$

## Explanation

The equation has the form $\ddot{x} = -\omega^2 x$ with $\omega^2 = 9$, so its solutions are exactly the functions $A\cos(3t + \varphi)$, that is, the combinations $C_1\cos(3t) + C_2\sin(3t)$. The functions $2\cos(3t)$, $\sin(3t + 1)$ and $5\cos(3t) - \sin(3t)$ have angular frequency $3$, therefore they are solutions. For $x(t) = \cos(9t)$, instead, $\ddot{x} = -81\cos(9t) = -81x$, so
$$
\ddot{x} + 9x = -72\cos(9t) ,
$$
which is not identically zero. The function $\cos(9t)$ has angular frequency $9$, equal to $\omega^2$ instead of $\omega$.
