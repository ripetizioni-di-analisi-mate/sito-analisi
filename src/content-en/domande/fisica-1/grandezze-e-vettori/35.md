The forces $\vec{F}_1 = (3{,}0\,\hat{\imath} + 5{,}0\,\hat{\jmath})\,\mathrm{N}$ and $\vec{F}_2 = (-7{,}0\,\hat{\imath} - 2{,}0\,\hat{\jmath})\,\mathrm{N}$ act on a point particle. Which third force $\vec{F}_3$ makes the resultant zero?

- $(4{,}0\,\hat{\imath} + 3{,}0\,\hat{\jmath})\,\mathrm{N}$
- $(4{,}0\,\hat{\imath} - 3{,}0\,\hat{\jmath})\,\mathrm{N}$
- $(-4{,}0\,\hat{\imath} + 3{,}0\,\hat{\jmath})\,\mathrm{N}$
- $(10\,\hat{\imath} + 7{,}0\,\hat{\jmath})\,\mathrm{N}$

## Explanation

The resultant is zero if $\vec{F}_1 + \vec{F}_2 + \vec{F}_3 = \vec{0}$, that is, if $\vec{F}_3 = -(\vec{F}_1 + \vec{F}_2)$. Adding component by component gives $\vec{F}_1 + \vec{F}_2 = (-4{,}0\,\hat{\imath} + 3{,}0\,\hat{\jmath})\,\mathrm{N}$, so $\vec{F}_3 = (4{,}0\,\hat{\imath} - 3{,}0\,\hat{\jmath})\,\mathrm{N}$. The vector $(-4{,}0\,\hat{\imath} + 3{,}0\,\hat{\jmath})\,\mathrm{N}$ is the sum $\vec{F}_1 + \vec{F}_2$, which, added to the two forces, doubles the resultant. The vector $(10\,\hat{\imath} + 7{,}0\,\hat{\jmath})\,\mathrm{N}$ is the difference $\vec{F}_1 - \vec{F}_2$.
