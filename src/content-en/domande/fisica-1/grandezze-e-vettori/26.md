The lengths $12{,}52\,\mathrm{m}$, $3{,}1\,\mathrm{m}$ and $0{,}256\,\mathrm{m}$ are added. With how many decimal places is the result written?

- With one decimal place
- With no decimal places
- With two decimal places
- With three decimal places

## Explanation

In sums and differences the result has as many decimal places as the given value with the fewest decimal places. The given value $3{,}1\,\mathrm{m}$ has only one decimal place, so the result is written with one decimal place. The sum equals $15{,}876\,\mathrm{m}$, which rounds to the nearest tenth as $15{,}9\,\mathrm{m}$. The result with no decimal places, $16\,\mathrm{m}$, is obtained by applying the rule of significant figures, which holds for products and quotients.
