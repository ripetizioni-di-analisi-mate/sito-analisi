Which of the following equalities is true?

- $1\,\mathrm{mg} = 10^{-3}\,\mathrm{kg}$
- $1\,\mathrm{cm^3} = 10^{-3}\,\mathrm{m^3}$
- $1\,\mathrm{km^2} = 10^{3}\,\mathrm{m^2}$
- $1\,\mathrm{mg} = 10^{-6}\,\mathrm{kg}$

## Explanation

For mass the prefixes are applied to the gram, so $1\,\mathrm{mg} = 10^{-3}\,\mathrm{g}$. Since $1\,\mathrm{g} = 10^{-3}\,\mathrm{kg}$, we have $1\,\mathrm{mg} = 10^{-6}\,\mathrm{kg}$. The equality $1\,\mathrm{mg} = 10^{-3}\,\mathrm{kg}$ applies the prefix milli to the kilogram, which already contains the prefix kilo. The equalities for $\mathrm{cm^3}$ and $\mathrm{km^2}$ have the factor of the prefix not raised to the power of the unit, and the exact values are $1\,\mathrm{cm^3} = (10^{-2}\,\mathrm{m})^3 = 10^{-6}\,\mathrm{m^3}$ and $1\,\mathrm{km^2} = (10^{3}\,\mathrm{m})^2 = 10^{6}\,\mathrm{m^2}$.
