For the problem $-u''=2$ on $(0,1)$ with $u(0)=1$ and $u(1)=3$, which function has zero trace and satisfies the same differential equation?

- $w=u-1$
- $w=u-3x$
- $w=u-x(1-x)$
- $w=u-(1+2x)$

## Explanation

The affine function $1+2x$ has the two prescribed boundary values and zero second derivative. Subtracting it makes the endpoint values zero. The source remains two because the second derivative is unchanged.
