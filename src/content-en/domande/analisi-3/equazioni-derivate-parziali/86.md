If $u_1,u_2$ solve the same weak Poisson problem with zero trace and $w=u_1-u_2$, which test function gives $\int|\nabla w|^2\,dx=0$ directly?

- $v=1$
- $v=w$
- $v=u_1+u_2$
- $v=0$

## Explanation

The difference belongs to the same zero-trace space and satisfies the homogeneous weak equation. Testing with the difference gives the squared gradient norm of $w$ in the integrand. The integral is zero, so Poincaré's inequality gives $w=0$.
