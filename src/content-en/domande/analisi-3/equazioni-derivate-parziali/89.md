On $H_0^1(0,1)$ with norm $\|u'\|_2$, which coefficient ensures that $a(u,v)=\int_0^1p(x)u'v'\,dx$ is coercive?

- $p(x)=2+\cos x$
- $p(x)=-1$
- $p(x)=0$
- $p(x)=x-\dfrac{1}{2}$

## Explanation

For $p(x)=2+\cos x$ we have $p(x)\ge1$, so $a(u,u)$ bounds $\|u'\|_2^2$ from below. For the sign-changing coefficient one can choose a smooth function supported where the coefficient is negative, giving a negative value for the form.
