Which function has a Fourier transform given by an absolutely convergent integral over the entire real line?

- $\dfrac1{1+|x|}$
- $\cos x$
- $x$
- $\dfrac1{1+x^2}$

## Explanation

The kernel has modulus one, so absolute convergence depends only on integrability of the original function. The given rational function is bounded near zero and decays like an inverse square at both ends.
