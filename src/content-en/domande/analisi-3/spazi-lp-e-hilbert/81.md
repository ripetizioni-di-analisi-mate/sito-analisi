Why does the rule $f\mapsto f(\dfrac12)$ fail to define a functional on the elements of $L^2(0,1)$?

- Two representatives of the same class can have different values at $\dfrac12$.
- Every function in $L^2$ is continuous.
- Every function in $L^2$ diverges at $\dfrac12$.
- The argument $\dfrac12$ lies outside the domain.

## Explanation

Elements of $L^2$ are equivalence classes under equality almost everywhere. Changing a function at a single point does not change its class because the point has measure zero. Yet the point value changes, so the rule depends on the representative.
