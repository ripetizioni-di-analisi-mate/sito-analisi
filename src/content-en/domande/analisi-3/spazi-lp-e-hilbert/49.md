In a Hilbert space, which identity holds for the projection $P_M$ onto any closed linear subspace $M$?

- $P_M\circ P_M=P_M$
- $P_M\circ(I-P_M)=P_M$
- $(I-P_M)\circ P_M=P_M$
- $P_M-(I-P_M)=P_M$

## Explanation

The first projection gives an element of $M$. An element of $M$ has distance zero from $M$, so projection fixes it. Applying the operator a second time therefore returns the same vector.
