For $a\in\mathbb R$, let $f(z)=az+(a-2)\overline z$. For which value of $a$ is the function entire?

- $0$
- $2$
- $1$
- $-2$

## Explanation

The difference quotient is $a+(a-2)$ for real increments and $a-(a-2)$ for imaginary increments. These values agree only if the conjugate term has zero coefficient. For $a=2$ the function reduces to the entire polynomial $2z$.
