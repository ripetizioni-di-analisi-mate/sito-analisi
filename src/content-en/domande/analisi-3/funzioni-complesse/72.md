Use principal square roots and let $z=w=e^{\frac{3\pi i}{4}}$. What is $\dfrac{\sqrt z\sqrt w}{\sqrt{zw}}$?

- $-1$
- $i$
- $-i$
- $1$

## Explanation

The numerator is $e^{\frac{3\pi i}{4}}$ because each argument is halved before multiplication. The product $zw$ has principal argument $-\dfrac\pi2$, so the denominator is $e^{-\frac{\pi i}{4}}$. The exponents differ by $\pi i$, whose exponential is $-1$.
