For which real parameters $a,b$ is $f(x+iy)=5x^2-ay^2+ibxy$ holomorphic on $\mathbb C$?

- $a=5,\quad b=10$
- $a=10,\quad b=5$
- $a=-5,\quad b=10$
- $a=5,\quad b=5$

## Explanation

Both components are real polynomials of class $C^1$, so the sufficient Cauchy–Riemann criterion applies. The first equation requires $10x=bx$ and the second requires $-2ay=-by$ for every $x,y$. Hence $b=10$ and $a=5$.
