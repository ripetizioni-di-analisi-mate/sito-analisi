Let $v(x,y)=x^2-y^2$. Which real part $u$ makes $u+iv$ entire with $u(0,0)=0$?

- $-2xy$
- $x^2-y^2$
- $2xy$
- $-2xy+1$

## Explanation

The Cauchy–Riemann equations give $u_x=v_y=-2y$ and $u_y=-v_x=-2x$. The function $-2xy$ satisfies both and vanishes at the origin. Both components are polynomials, so the sufficient criterion applies, giving the function $iz^2$.
