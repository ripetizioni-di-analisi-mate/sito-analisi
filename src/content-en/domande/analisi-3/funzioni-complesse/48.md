For which $a,b\in\mathbb R$ is $f(x+iy)=ax+y+i(bx+2y)$ entire?

- $a=2,\ b=-1$
- $a=2,\ b=1$
- $a=-2,\ b=-1$
- $a=1,\ b=-2$

## Explanation

The affine components are of class $C^1$. The first Cauchy–Riemann equation sets $a$ equal to $2$ and the second sets $1$ equal to $-b$. With these values the function is $(2-i)z$, so the condition is also sufficient.
