Let $x\ne0$ in a real normed space. Which functional on the subspace $\operatorname{span}\{x\}$ has norm one and takes the value $\|x\|$ at $x$?

- $\ell(tx)=|t|\|x\|$
- $\ell(tx)=t^2\|x\|$
- $\ell(tx)=t\|x\|$
- $\ell(tx)=0$

## Explanation

Every vector on the line has a unique representation $tx$, so $\ell(tx)=t\|x\|$ defines a linear functional. Its absolute value is $|t|\|x\|$, equal to the input norm. Thus it has norm one and takes the required value at $x$.
