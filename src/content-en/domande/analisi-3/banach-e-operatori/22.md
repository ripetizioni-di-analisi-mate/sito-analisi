In $C([0,1])$ with the supremum norm, which set is closed and complete but is not a vector subspace?

- $\{f:f(0)>1\}$
- $\{f:f(0)=1\}$
- $\{f:f(0)=0\}$
- $\{f:f(0)\ne0\}$

## Explanation

Evaluation at zero is continuous, so the preimage of the closed set $\{1\}$ is closed. A closed subset of a complete space is complete. The zero function takes the value zero at that point and is excluded, so the set is not a subspace.
