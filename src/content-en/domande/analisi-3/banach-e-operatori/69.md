On $\ell^2$, let $T_n(x)=nx_n$. Which unit input results from setting $x_{2^k}=2^{-\dfrac{k}{2}}$ for $k\ge1$ and zero elsewhere?

- An input with $\|x\|_2=1$ and $T_{2^k}(x)=2^{\dfrac{k}{2}}$
- An input with $\|x\|_2=1$ and $T_{2^k}(x)=2^{-\dfrac{k}{2}}$
- An input with $\|x\|_2=\sqrt2$ and $T_{2^k}(x)=1$
- An input lying outside $\ell^2$

## Explanation

The squared nonzero coordinates sum to $\sum_{k\ge1}2^{-k}=1$, so the input is on the unit sphere. At the coordinate with index $2^k$ the functional multiplies by $2^k$. This gives $2^{\dfrac{k}{2}}$, which diverges.
