On $C([0,1])$ with the supremum norm, let $Tf(x)=f(\dfrac{x}{2})$. Which property does this operator have?

- It is injective and its range is a proper subspace
- It is an injective isometry
- It has rank one
- It is surjective and has a nonzero kernel

## Explanation

The image of an input depends only on its values on $[0,\dfrac{1}{2}]$, so all functions vanishing on that interval lie in the kernel. For each continuous $g$, set $f(t)=g(2t)$ on the interval and extend by the constant $g(1)$ to obtain $Tf=g$.
