For $a_{ij}=\mathbf1_{\{i=j\}}$, with $i,j\ge1$, which statement holds?

- Both iterated sums equal $+\infty$.
- Both iterated sums equal one.
- Fubini's theorem guarantees a finite value because every section is summable.
- Summing over $i$ first gives one, and summing over $j$ first gives $+\infty$.

## Explanation

Each row and each column contains exactly one entry equal to one, so every inner sum is one. Summing these ones gives infinity in either order, as Tonelli's theorem permits for nonnegative terms.
