On $X=\{a,b,c\}$ with the sigma-algebra generated by $\{a,b\}$, which triple $(f(a),f(b),f(c))$ defines a measurable function?

- $(0,1,1)$
- $(2,2,-1)$
- $(2,-1,2)$
- $(2,3,4)$

## Explanation

The set $\{a,b\}$ is an atom, so no measurable set contains exactly one of $a$ and $b$. A threshold between distinct values at those points would separate them. The triple that assigns both the same value thus satisfies the condition.
