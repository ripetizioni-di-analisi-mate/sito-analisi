On $\mathbb R$, let $h(x)=2\mathbf1_{[0,2]}(x)+3\mathbf1_{[1,4]}(x)$. What is the measure of $\{h\ge4\}$?

- $1$
- $3$
- $2$
- $4$

## Explanation

Where only one indicator is nonzero, the value is two or three, below the threshold. At common points the value is five, so the required set is exactly the intersection $[1,2]$.
