Set $E_n=\{k\in\mathbb N:k\ge n\}$ and use counting measure. Which relation holds?

- Both quantities equal $+\infty$.
- $\mu(\bigcap_n E_n)=0$ and $\lim_n\mu(E_n)=+\infty$
- Both quantities equal zero.
- $\mu(\bigcap_n E_n)=+\infty$ and $\lim_n\mu(E_n)=0$.

## Explanation

Each tail contains infinitely many natural numbers, so its measure is infinite. Each fixed natural number is excluded from all tails starting beyond its index, so the intersection is empty. The first set has infinite measure, and continuity from above does not apply.
