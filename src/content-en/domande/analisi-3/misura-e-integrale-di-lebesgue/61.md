For a measure $\mu$ and a decreasing sequence $E_n$ with $\mu(E_1)=5$, which relation is guaranteed?

- $\mu(\bigcap_n E_n)=\lim_n\mu(E_n)$
- $\lim_n\mu(E_n)=0$
- $\mu(\bigcup_n E_n)=\lim_n\mu(E_n)$
- $\mu(\bigcap_n E_n)=\sum_n\mu(E_n)$

## Explanation

The measures of the sets can be subtracted from that of the first set because it is finite. Their complements relative to the first set increase. Continuity from below for these complements therefore gives continuity from above for the original sequence.
