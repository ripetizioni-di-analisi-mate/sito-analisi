Il settore circolare $D$ è formato dai punti del cerchio $x^2 + y^2 \leq 4$ compresi tra il semiasse $x$ positivo e la bisettrice $y = x$, cioè con $0 \leq y \leq x$. Con quali limitazioni su $\rho$ e $\theta$ si descrive $D$?

- $0 \leq \theta \leq \dfrac{\pi}{4}$, $\ 0 \leq \rho \leq 2$
- $0 \leq \theta \leq \dfrac{\pi}{2}$, $\ 0 \leq \rho \leq 2$
- $0 \leq \theta \leq \dfrac{\pi}{4}$, $\ 0 \leq \rho \leq 4$
- $\dfrac{\pi}{4} \leq \theta \leq \dfrac{\pi}{2}$, $\ 0 \leq \rho \leq 2$

## Spiegazione

Poiché $x^2 + y^2 = \rho^2$, la condizione $x^2 + y^2 \leq 4$ diventa $0 \leq \rho \leq 2$. La condizione $0 \leq y \leq x$ individua i punti compresi tra il semiasse $x$ positivo e la bisettrice $y = x$ del primo quadrante, quindi $0 \leq \theta \leq \dfrac{\pi}{4}$. L'insieme $\dfrac{\pi}{4} \leq \theta \leq \dfrac{\pi}{2}$ descrive invece la parte del primo quadrante sopra la bisettrice, dove $y \geq x$.
