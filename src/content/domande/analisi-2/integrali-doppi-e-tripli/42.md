In coordinate cilindriche, quale descrizione corrisponde al solido $E = \{ (x, y, z) : x^2 + y^2 \leq 4, \ 0 \leq z \leq x^2 + y^2 \}$?

- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 2$, $\ \rho^2 \leq z \leq 4$
- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 4$, $\ 0 \leq z \leq \rho^2$
- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 2$, $\ 0 \leq z \leq \rho^2$
- $0 \leq \theta \leq 2\pi$, $\ 0 \leq \rho \leq 2$, $\ 0 \leq z \leq \rho$

## Spiegazione

In **coordinate cilindriche** si ha $x^2 + y^2 = \rho^2$, quindi la condizione $x^2 + y^2 \leq 4$ diventa $\rho^2 \leq 4$, cioè $0 \leq \rho \leq 2$. La condizione sulla quota diventa $0 \leq z \leq \rho^2$. Le due condizioni non contengono $\theta$, perciò $\theta$ varia in tutto l'intervallo $[0, 2\pi]$ e
$$
E = \left\{ (\rho, \theta, z) :
\begin{cases}
0 \leq \theta \leq 2\pi \\
0 \leq \rho \leq 2 \\
0 \leq z \leq \rho^2
\end{cases}
\right\} .
$$
La condizione $\rho^2 \leq z \leq 4$ descrive la parte del cilindro compresa tra il paraboloide e il piano $z = 4$, che sta sopra $E$.
