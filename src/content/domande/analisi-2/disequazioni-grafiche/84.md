L'insieme $D = \{ (x, y) : 1 \leq x \leq e,\ 0 \leq y \leq \ln x \}$ è scritto come dominio normale rispetto all'asse $x$. Quale scrittura lo descrive come dominio normale rispetto all'asse $y$?

- $0 \leq y \leq 1$, $\ 1 \leq x \leq e^y$
- $1 \leq y \leq e$, $\ 0 \leq x \leq \ln y$
- $0 \leq y \leq 1$, $\ e^y \leq x \leq e$
- $0 \leq y \leq 1$, $\ 1 \leq x \leq e$

## Spiegazione

La curva $y = \ln x$ è crescente e passa per $(1, 0)$ e $(e, 1)$, quindi la proiezione di $D$ sull'asse $y$ è l'intervallo $[0, 1]$. La funzione esponenziale è crescente, perciò $y \leq \ln x$ equivale a $e^y \leq x$. Ogni segmento orizzontale con ordinata tra $0$ e $1$ entra in $D$ dalla curva $x = e^y$, a sinistra, ed esce dalla retta $x = e$, a destra. Quindi $D$ si scrive $0 \leq y \leq 1$, $e^y \leq x \leq e$. La scrittura $1 \leq x \leq e^y$ descrive i punti a sinistra della curva, che stanno sopra il grafico di $\ln x$.
