Quali sono i potenziali su $\mathbb{R}^2$ del campo $F(x, y) = \left( \dfrac{2x}{x^2 + 1} + y, \; x + \cos y \right)$?

- $U(x, y) = \ln (x^2 + 1) + 2xy + \sin y + k$
- $U(x, y) = \ln (x^2 + 1) + xy + \sin y + k$
- $U(x, y) = \arctan x + xy + \sin y + k$
- $U(x, y) = \ln (x^2 + 1) + xy - \sin y + k$

## Spiegazione

Il campo è di classe $C^1$ su $\mathbb{R}^2$ e le derivate incrociate valgono entrambe $1$. Poiché $\mathbb{R}^2$ è semplicemente connesso, il campo è **conservativo**. La funzione $\dfrac{2x}{x^2 + 1}$ è la derivata di $\ln (x^2 + 1)$, quindi integrando $F_1$ rispetto a $x$ si ottiene $U(x, y) = \ln (x^2 + 1) + xy + c(y)$. Imponendo $U_y = F_2$ si ottiene $x + c'(y) = x + \cos y$, quindi $c'(y) = \cos y$ e perciò $c(y) = \sin y + k$. I potenziali sono
$$
U(x, y) = \ln (x^2 + 1) + xy + \sin y + k, \qquad k \in \mathbb{R} .
$$
