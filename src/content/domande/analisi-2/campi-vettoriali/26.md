Il campo $F(x, y) = \left( \dfrac{2x}{1 + x^2 + y^2}, \; \dfrac{2y}{1 + x^2 + y^2} \right)$ è conservativo su $\mathbb{R}^2$. Quali sono i suoi potenziali?

- $U(x, y) = \dfrac{1}{2} \ln (1 + x^2 + y^2) + k$
- $U(x, y) = \ln (1 + x^2) + \ln (1 + y^2) + k$
- $U(x, y) = 2 \ln (1 + x^2 + y^2) + k$
- $U(x, y) = \ln (1 + x^2 + y^2) + k$

## Spiegazione

Con $y$ fissata, l'integrale di $\dfrac{2x}{1 + x^2 + y^2}$ rispetto a $x$ è riconducibile all'integrale immediato $\displaystyle\int \frac{g'(x)}{g(x)} \, dx = \ln |g(x)| + c$, quindi integrando $F_1$ rispetto a $x$ si ottiene $U(x, y) = \ln (1 + x^2 + y^2) + c(y)$. Derivando rispetto a $y$ si ottiene $\dfrac{2y}{1 + x^2 + y^2} + c'(y)$, e imponendo $U_y = F_2$ si ricava $c'(y) = 0$. I potenziali sono perciò $U(x, y) = \ln (1 + x^2 + y^2) + k$ con $k \in \mathbb{R}$. La somma $\ln (1 + x^2) + \ln (1 + y^2)$ ha come derivata rispetto a $x$ la funzione $\dfrac{2x}{1 + x^2}$, diversa da $F_1$.
