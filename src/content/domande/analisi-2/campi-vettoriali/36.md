Quali sono i potenziali su $\mathbb{R}^3$ del campo $F(x, y, z) = (y + z, \; x + z, \; x + y)$?

- $U(x, y, z) = xyz + k$
- $U(x, y, z) = xy + yz + zx + k$
- $U(x, y, z) = 2(xy + yz + zx) + k$
- $U(x, y, z) = \dfrac{(x + y + z)^2}{2} + k$

## Spiegazione

Il rotore del campo è $(1 - 1, \; 1 - 1, \; 1 - 1) = (0, 0, 0)$ e $\mathbb{R}^3$ è semplicemente connesso, quindi il campo è **conservativo**. Integrando $F_1 = y + z$ rispetto a $x$ si ottiene $U = xy + xz + c(y, z)$. Imponendo $U_y = x + z$ si ottiene $c_y(y, z) = z$, quindi $c(y, z) = yz + d(z)$. Imponendo infine $U_z = x + y$ si ottiene $x + y + d'(z) = x + y$, perciò $d$ è costante e i potenziali sono
$$
U(x, y, z) = xy + yz + zx + k, \qquad k \in \mathbb{R} .
$$
