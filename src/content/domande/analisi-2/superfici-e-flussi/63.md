Qual è il prodotto vettoriale $r_u\times r_v$ per $\left( 3 u, \  5 v, \  2 u + 2 v\right)$?

- $\left( -10, \  -6, \  15\right)$
- $\left( 10, \  6, \  -15\right)$
- $\left( 0, \  0, \  15\right)$
- $\left( -6, \  -10, \  15\right)$

## Spiegazione

Le derivate sono $\left( 3, \  0, \  2\right)$ e $\left( 0, \  5, \  2\right)$. Il prodotto vettoriale segue l’ordine indicato.
