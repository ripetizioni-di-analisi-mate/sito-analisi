Qual è il prodotto vettoriale $r_u\times r_v$ per $\left( 4 u, \  2 v, \  7 u + 7 v\right)$?

- $\left( 14, \  28, \  -8\right)$
- $\left( -14, \  -28, \  8\right)$
- $\left( -28, \  -14, \  8\right)$
- $\left( 0, \  0, \  8\right)$

## Spiegazione

Le derivate sono $\left( 4, \  0, \  7\right)$ e $\left( 0, \  2, \  7\right)$. Il prodotto vettoriale segue l’ordine indicato.
