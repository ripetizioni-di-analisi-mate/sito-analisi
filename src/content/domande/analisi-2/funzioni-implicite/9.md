- $2x + 2y + 2z = 6$
- $x + y + 3z = 5$
- $2x + 2y + 3z = 0$
- $2x + 2y + 3z = 7$

## Spiegazione

Si pone $F(x, y, z) = xz + yz^2 + xy - 3$, e risulta $F(1, 1, 1) = 0$, quindi il punto appartiene alla superficie. Le derivate parziali sono $F_x = z + y$, $F_y = z^2 + x$ e $F_z = x + 2yz$, perciò $\nabla F(1, 1, 1) = (2, 2, 3) \neq (0, 0, 0)$. Il piano tangente ha quindi equazione
$$
2(x - 1) + 2(y - 1) + 3(z - 1) = 0 ,
$$
cioè $2x + 2y + 3z = 7$.
