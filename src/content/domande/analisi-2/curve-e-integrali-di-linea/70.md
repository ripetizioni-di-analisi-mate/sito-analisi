Qual è l’accelerazione in $t=0$ per $\left( 3 t, \  5 t^{2}, \  2 t^{3}\right)$?

- $\left( 0, \  10, \  12\right)$
- $\left( 0, \  10, \  0\right)$
- $\left( 3, \  0, \  0\right)$
- $\left( 0, \  5, \  0\right)$

## Spiegazione

Si deriva ogni componente due volte. In zero resta la sola derivata seconda della componente quadratica.
