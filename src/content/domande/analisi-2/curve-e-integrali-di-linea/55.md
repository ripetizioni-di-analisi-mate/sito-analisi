Qual è l’accelerazione in $t=0$ per $\left( 2 t, \  3 t^{2}, \  5 t^{3}\right)$?

- $\left( 0, \  6, \  0\right)$
- $\left( 2, \  0, \  0\right)$
- $\left( 0, \  3, \  0\right)$
- $\left( 0, \  6, \  30\right)$

## Spiegazione

Si deriva ogni componente due volte. In zero resta la sola derivata seconda della componente quadratica.
