Per il prolungamento $2\pi$-periodico di
$$
f(x) =
\begin{cases}
1 & \text{se } 0 \leq x < \frac{\pi}{2} \\
0 & \text{se } -\pi \leq x < 0 \text{ oppure } \frac{\pi}{2} \leq x < \pi
\end{cases}
$$
quanto vale il coefficiente di Fourier $b_2$?

- $\dfrac{2}{\pi}$
- $0$
- $\dfrac{1}{\pi}$
- $\dfrac{1}{2\pi}$

## Spiegazione

La funzione vale $1$ su $\left[ 0, \dfrac{\pi}{2} \right)$ ed è nulla nel resto del periodo, quindi
$$
b_2 = \frac{1}{\pi} \int_0^{\frac{\pi}{2}} \sin(2x)\, dx = \frac{1}{\pi} \left[ -\frac{\cos(2x)}{2} \right]_0^{\frac{\pi}{2}} .
$$
Poiché $\cos\pi = -1$ e $\cos 0 = 1$, si ha $-\dfrac{\cos\pi}{2} + \dfrac{\cos 0}{2} = 1$. Perciò $b_2 = \dfrac{1}{\pi}$.
