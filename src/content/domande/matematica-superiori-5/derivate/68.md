Il polinomio $P(x) = ax^{2} + bx + c$ ha $P(0) = 1$, $P'(0) = 2$ e $P''(0) = 6$. Quale polinomio è?

- $P(x) = 6x^{2} + 2x + 1$
- $P(x) = 3x^{2} + x + 1$
- $P(x) = x^{2} + 2x + 6$
- $P(x) = 3x^{2} + 2x + 1$

## Spiegazione

Si ha $P'(x) = 2ax + b$ e $P''(x) = 2a$. Quindi $P(0) = c$, $P'(0) = b$ e $P''(0) = 2a$. Le condizioni danno $c = 1$, $b = 2$ e $2a = 6$, perciò $a = 3$ e $P(x) = 3x^{2} + 2x + 1$. Il polinomio $6x^{2} + 2x + 1$ si ottiene ponendo $a = P''(0)$, senza dividere per $2$.
