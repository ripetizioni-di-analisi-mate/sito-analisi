Qual è la derivata prima di $f(x)=\dfrac{\sin{\left(3 x + 7 \right)}}{x}$ nel suo dominio di derivabilità?

- $\dfrac{3 \cos{\left(3 x + 7 \right)}}{x}$
- $\dfrac{x \cos{\left(3 x + 7 \right)} - \sin{\left(3 x + 7 \right)}}{x^{2}}$
- $\dfrac{3 x \cos{\left(3 x + 7 \right)} - \sin{\left(3 x + 7 \right)}}{x^{2}}$
- $\dfrac{3 x \cos{\left(3 x + 7 \right)} + \sin{\left(3 x + 7 \right)}}{x^{2}}$

## Spiegazione

La derivata del seno contiene il fattore interno. Nella regola del quoziente si sottrae il termine dovuto alla derivata del denominatore.
