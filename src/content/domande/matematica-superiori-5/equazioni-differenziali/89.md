Tutte le soluzioni dell'equazione $y'' + y = 3\cos(2x)$ sono descritte da una sola delle seguenti famiglie. Quale?

- $y = C_1 \cos x + C_2 \sin x + 3\cos(2x)$
- $y = C_1 \cos x + C_2 \sin x + \cos(2x)$
- $y = C_1 e^{x} + C_2 e^{-x} - \cos(2x)$
- $y = C_1 \cos x + C_2 \sin x - \cos(2x)$

## Spiegazione

L'equazione caratteristica $r^2 + 1 = 0$ ha le radici $\pm i$, quindi l'integrale generale dell'omogenea è $C_1 \cos x + C_2 \sin x$.

Il numero associato al termine noto è $\pm 2i$, che non è radice, perciò si cerca $y_p = a\cos(2x) + b\sin(2x)$. Poiché $y_p'' = -4y_p$, sostituendo si ottiene $-3a\cos(2x) - 3b\sin(2x) = 3\cos(2x)$, quindi $a = -1$ e $b = 0$. L'integrale generale è $y = C_1 \cos x + C_2 \sin x - \cos(2x)$.
