Sia $f(x) = \dfrac{x + a}{(x - 1)(x + 2)}$, con $a$ parametro reale. Per quale valore di $a$ le primitive di $f$ si scrivono senza il termine $\ln|x - 1|$?

- $a = -2$
- $a = 1$
- $a = 2$
- $a = -1$

## Spiegazione

Si decompone $f(x) = \dfrac{A}{x - 1} + \dfrac{B}{x + 2}$, con $x + a = A (x + 2) + B (x - 1)$. Per $x = 1$ si ottiene $1 + a = 3A$, quindi $A = \dfrac{1 + a}{3}$; per $x = -2$ si ottiene $-2 + a = -3B$, quindi $B = \dfrac{2 - a}{3}$. Le primitive sono $A \ln|x - 1| + B \ln|x + 2| + c$, perciò il termine $\ln|x - 1|$ è assente se e solo se $A = 0$, cioè $a = -1$. Per $a = 2$ si annulla invece $B$, e manca il termine $\ln|x + 2|$.
