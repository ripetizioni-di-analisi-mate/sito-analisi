Si integra per parti la funzione $x\,(x + 1)^5$, derivando il fattore $x$. Quale primitiva si ottiene?

- $\dfrac{x (x + 1)^6}{6} - \dfrac{(x + 1)^7}{42}$
- $\dfrac{x (x + 1)^6}{6} + \dfrac{(x + 1)^7}{42}$
- $\dfrac{x^2 (x + 1)^6}{12}$
- $\dfrac{x (x + 1)^6}{6}$

## Spiegazione

Si applica l'**integrazione per parti** con $f(x) = x$ e $g'(x) = (x + 1)^5$. Allora $f'(x) = 1$ e, per la formula delle potenze, $g(x) = \dfrac{(x + 1)^6}{6}$. La formula dà
$$
\int x (x + 1)^5\, dx = \frac{x (x + 1)^6}{6} - \frac{1}{6} \int (x + 1)^6\, dx = \frac{x (x + 1)^6}{6} - \frac{(x + 1)^7}{42} + c .
$$
L'integrale che resta è riconducibile all'integrale immediato di una potenza, perché la derivata di $x + 1$ vale $1$.
