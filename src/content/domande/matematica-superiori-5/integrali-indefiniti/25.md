Quale funzione $F$ soddisfa $F''(x) = 6x$ per ogni $x \in \mathbb{R}$, $F(0) = 1$ e $F'(0) = 2$?

- $F(x) = 3x^3 + 2x + 1$
- $F(x) = x^3 + 2x + 1$
- $F(x) = x^3 + x + 2$
- $F(x) = x^3 + 2x$

## Spiegazione

La funzione $F'$ è una primitiva di $6x$, quindi $F'(x) = 3x^2 + c_1$. La condizione $F'(0) = 2$ dà $c_1 = 2$, perciò $F'(x) = 3x^2 + 2$. La funzione $F$ è allora una primitiva di $3x^2 + 2$, cioè $F(x) = x^3 + 2x + c_2$. La condizione $F(0) = 1$ dà $c_2 = 1$, e quindi $F(x) = x^3 + 2x + 1$.
