Quattro tessere recano A, B, B, C. Si considerano uguali due file se una è il rovescio dell’altra. Quante file diverse si contano?

- $3$
- $8$
- $6$
- $12$

## Spiegazione

Ci sono $\dfrac{4!}{2!}=12$ file orientate. Nessuna è palindroma, perché A e C compaiono una volta ciascuna. Ogni coppia di file inverse va contata una volta.
