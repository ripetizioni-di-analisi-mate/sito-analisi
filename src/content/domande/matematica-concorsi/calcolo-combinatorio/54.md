Con quattro tessere che recano le lettere A, B, B, C si formano file che usano tutte e quattro le tessere. Due file si considerano uguali se una si ottiene leggendo l'altra da destra a sinistra. Quante file diverse si ottengono?

- $3$
- $24$
- $6$
- $12$

## Spiegazione

Senza la condizione sul verso di lettura le file sono le **permutazioni con ripetizione** di quattro tessere in cui B compare due volte, cioè $\dfrac{4!}{2!}=12$. Una fila letta da destra a sinistra coincide con sé stessa soltanto se è simmetrica, e questo è impossibile perché A e C compaiono una volta ciascuna. Quindi le $12$ file si dividono in coppie formate da una fila e dalla sua inversa, e ogni coppia rappresenta una sola fila. Perciò le file diverse sono $\dfrac{12}{2}=6$. Il valore $12$ trascura la condizione sul verso di lettura, e il valore $24$ tratta come distinte le due tessere B.
