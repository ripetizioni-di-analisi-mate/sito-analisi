> In un esperimento alcune colonie di api sono state tenute in serre a temperature diverse. Nelle serre più calde le api hanno iniziato la raccolta del polline più presto al mattino. Il numero totale di voli giornalieri è invece rimasto simile in tutte le serre. I ricercatori stanno ora verificando se lo stesso accada all'aperto.

Quale affermazione è in contrasto con il brano?

- Nelle serre più calde le api hanno cominciato la raccolta in anticipo.
- L'effetto della temperatura all'aperto deve ancora essere verificato.
- Nelle serre più calde le api hanno compiuto molti più voli al giorno.
- Le colonie dell'esperimento vivevano in serre a temperature diverse.

## Spiegazione

Il terzo periodo afferma che il numero di voli giornalieri è rimasto simile in tutte le serre. Un numero di voli molto più alto nelle serre calde **contraddice quindi il brano**. Le altre tre affermazioni riformulano l'inizio anticipato della raccolta, la verifica in corso all'aperto e l'impostazione dell'esperimento.
