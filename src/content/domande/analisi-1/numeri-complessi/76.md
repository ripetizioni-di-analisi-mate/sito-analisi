Nel piano di Gauss, la disequazione $|z + \bar{z}| \leq 2$ individua una striscia. Quale?

- La striscia $-2 \leq x \leq 2$
- La striscia $-1 \leq y \leq 1$
- La striscia $-1 \leq x \leq 1$
- La striscia $0 \leq x \leq 1$

## Spiegazione

Posto $z = x + iy$, si ha $z + \bar{z} = 2x$, che è un numero reale. La disequazione diventa $|2x| \leq 2$, cioè $|x| \leq 1$. Perciò l'insieme è la striscia verticale $-1 \leq x \leq 1$, compresa fra le rette $x = -1$ e $x = 1$, bordo incluso.
