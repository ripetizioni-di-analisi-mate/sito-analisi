In ciascuna coppia le due successioni divergono a $+\infty$, quindi $a_n - b_n$ è nella forma $+\infty - \infty$. Per quale coppia la differenza tende a $5$?

- $a_n = \ln\left(e^5 n\right)$, $b_n = \ln n$
- $a_n = \ln(5n)$, $b_n = \ln n$
- $a_n = \ln\left(n^5\right)$, $b_n = \ln n$
- $a_n = \ln(n + 5)$, $b_n = \ln n$

## Spiegazione

Il limite di una forma $+\infty - \infty$ dipende dalle successioni coinvolte. Per le proprietà dei logaritmi $\ln\left(e^5 n\right) - \ln n = \ln e^5 = 5$ per ogni $n$, quindi la differenza è costante e tende a $5$.

Nelle altre coppie si ha $\ln(5n) - \ln n = \ln 5$, che è circa $1{,}61$, e $\ln\left(n^5\right) - \ln n = 4 \ln n \to +\infty$. Infine $\ln(n + 5) - \ln n = \ln \left( 1 + \dfrac{5}{n} \right) \to 0$.
