Per quali valori reali di $x$ la successione $\left( \dfrac{x - 1}{2} \right)^{n}$ è convergente?

- $-1 < x < 3$
- $-1 < x \leq 3$
- $-1 \leq x \leq 3$
- $-3 < x \leq 1$

## Spiegazione

La successione è geometrica con ragione $q = \dfrac{x - 1}{2}$. Una successione geometrica converge se e solo se $-1 < q \leq 1$, perché tende a $0$ per $|q| < 1$, vale costantemente $1$ per $q = 1$, diverge per $q > 1$ e non ha limite per $q \leq -1$.

La condizione $-1 < \dfrac{x - 1}{2} \leq 1$ equivale a $-2 < x - 1 \leq 2$, cioè a $-1 < x \leq 3$. L'estremo $x = 3$ è compreso, perché dà $q = 1$, mentre $x = -1$ dà $q = -1$ e la successione $(-1)^n$, che non ha limite.
