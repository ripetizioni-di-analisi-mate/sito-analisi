Per dimostrare con un confronto che $a_n = n - 3 \sin n$ diverge a $+\infty$, quale disuguaglianza, valida per ogni $n$, si usa?

- $n - 3 \sin n \leq n + 3$
- $n - 3 \sin n \geq n - 3$
- $n - 3 \sin n \geq -3$
- $n - 3 \sin n \geq n - \sin n$

## Spiegazione

Poiché $\sin n \leq 1$, si ha $-3 \sin n \geq -3$ e quindi $n - 3 \sin n \geq n - 3$ per ogni $n$. La successione $n - 3$ diverge a $+\infty$, perciò per il **confronto per le successioni divergenti** anche $a_n \to +\infty$.

La maggiorazione con $n + 3$ è vera, ma una successione maggiorata da una successione divergente può avere qualsiasi comportamento. La minorazione con $-3$ è vera, ma la costante $-3$ non diverge. La disuguaglianza $n - 3 \sin n \geq n - \sin n$ equivale a $\sin n \leq 0$, che è falsa per esempio per $n = 1$.
