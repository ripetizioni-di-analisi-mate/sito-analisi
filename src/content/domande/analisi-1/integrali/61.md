Con una sostituzione opportuna l'integrale $\displaystyle\int \frac{\cos x}{\sin^2 x + 3 \sin x + 2}\, dx$ si riconduce a quello di una funzione razionale. Quale risultato si ottiene?

- $\ln \left| \dfrac{\sin x + 2}{\sin x + 1} \right| + c$
- $\ln\left( \sin^2 x + 3 \sin x + 2 \right) + c$
- $\cos x \ln \left| \dfrac{\sin x + 1}{\sin x + 2} \right| + c$
- $\ln \left| \dfrac{\sin x + 1}{\sin x + 2} \right| + c$

## Spiegazione

Con la **sostituzione** $t = \sin x$ si ha $dt = \cos x\, dx$, quindi l'integrale diventa $\displaystyle\int \frac{dt}{t^2 + 3t + 2}$. Il denominatore si fattorizza come $(t + 1)(t + 2)$, e da $1 = A(t + 2) + B(t + 1)$ si ottiene $A = 1$ per $t = -1$ e $B = -1$ per $t = -2$. Perciò
$$
\int \frac{dt}{(t + 1)(t + 2)} = \ln|t + 1| - \ln|t + 2| + c = \ln \left| \frac{t + 1}{t + 2} \right| + c ,
$$
e con $t = \sin x$ si ottiene $\ln \left| \dfrac{\sin x + 1}{\sin x + 2} \right| + c$.
