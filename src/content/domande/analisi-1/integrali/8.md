- $\dfrac{x^2}{2} + x + 3 \ln|x + 1| + c$
- $\dfrac{x^2}{2} - x + 3 \ln|x + 1| + c$
- $\dfrac{x^2}{2} - x + \ln|x + 1| + c$
- $\dfrac{x^2}{2} - x + 2 \ln|x + 1| + c$

## Spiegazione

Il grado del numeratore è maggiore del grado del denominatore, quindi si esegue la **divisione con resto**. Il quoziente di $x^2 + 2$ per $x + 1$ è $x - 1$ con resto $3$, perché $(x + 1)(x - 1) + 3 = x^2 + 2$. Perciò
$$
\int \frac{x^2 + 2}{x + 1}\, dx = \int \left( x - 1 + \frac{3}{x + 1} \right) dx = \frac{x^2}{2} - x + 3 \ln|x + 1| + c .
$$
