Il denominatore di $\dfrac{x^2 + 1}{x (x - 1)(x + 1)}$ ha tre radici reali semplici. Qual è l'integrale indefinito della funzione?

- $\ln|x| + \ln|x - 1| + \ln|x + 1| + c$
- $-\ln|x| + \ln|x - 1| + \ln|x + 1| + c$
- $-\ln|x| + 2 \ln|x - 1| + 2 \ln|x + 1| + c$
- $\ln|x| - \ln|x - 1| - \ln|x + 1| + c$

## Spiegazione

Il denominatore ha tre radici reali semplici, $0$, $1$ e $-1$, quindi si decompone in **fratti semplici**:
$$
\frac{x^2 + 1}{x (x - 1)(x + 1)} = \frac{A}{x} + \frac{B}{x - 1} + \frac{C}{x + 1}, \qquad x^2 + 1 = A (x - 1)(x + 1) + B x (x + 1) + C x (x - 1) .
$$
Per $x = 0$ si ottiene $1 = -A$, quindi $A = -1$; per $x = 1$ si ottiene $2 = 2B$, quindi $B = 1$; per $x = -1$ si ottiene $2 = 2C$, quindi $C = 1$. Perciò l'integrale vale $-\ln|x| + \ln|x - 1| + \ln|x + 1| + c$.
