- $x \sin x + \cos x + c$
- $x \sin x - \cos x + c$
- $\dfrac{x^2}{2} \sin x + c$
- $-x \sin x + \cos x + c$

## Spiegazione

Si applica l'**integrazione per parti** derivando il polinomio, quindi $f(x) = x$ e $g'(x) = \cos x$. Allora $f'(x) = 1$ e $g(x) = \sin x$, e la formula dà
$$
\int x \cos x\, dx = x \sin x - \int \sin x\, dx .
$$
Poiché $\displaystyle\int \sin x\, dx = -\cos x + c$, si ottiene $x \sin x - (-\cos x) + c$, perciò il risultato è $x \sin x + \cos x + c$.
