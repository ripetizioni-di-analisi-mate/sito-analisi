Quale funzione è la primitiva di $f(x) = 3x^2 + 2$ che vale $5$ nel punto $x = 1$?

- $x^3 + 2x + 5$
- $x^3 + 2x + 2$
- $x^3 + 2x - 2$
- $x^3 + 4$

## Spiegazione

Dalla tabella degli integrali elementari si ottiene $\displaystyle\int \left( 3x^2 + 2 \right) dx = x^3 + 2x + c$. Poiché due primitive sull'intervallo $\mathbb{R}$ differiscono per una costante, ogni primitiva di $f$ ha la forma $F(x) = x^3 + 2x + c$.

La condizione $F(1) = 5$ dà $1 + 2 + c = 5$, quindi $c = 2$. Perciò la primitiva cercata è $F(x) = x^3 + 2x + 2$.
