- $f'(x) = \dfrac{1}{(x + 1)^2}$
- $f'(x) = -\dfrac{1}{(x + 1)^2}$
- $f'(x) = -\dfrac{1}{x + 1}$
- $f'(x) = -\dfrac{1}{(x + 1)^3}$

## Spiegazione

Il numeratore del rapporto incrementale è $\dfrac{1}{x + h + 1} - \dfrac{1}{x + 1}$. Riducendo allo stesso denominatore si ottiene
$$
\frac{1}{x + h + 1} - \frac{1}{x + 1} = \frac{(x + 1) - (x + h + 1)}{(x + h + 1)(x + 1)} = \frac{-h}{(x + h + 1)(x + 1)} ,
$$
quindi per $h \neq 0$ il rapporto incrementale vale $-\dfrac{1}{(x + h + 1)(x + 1)}$. Per $h \to 0$ il denominatore tende a $(x + 1)^2 \neq 0$, perciò $f'(x) = -\dfrac{1}{(x + 1)^2}$. Il segno meno viene dalla differenza $(x + 1) - (x + h + 1) = -h$.
