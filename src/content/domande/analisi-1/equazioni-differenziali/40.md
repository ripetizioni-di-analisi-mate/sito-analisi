Per l'equazione $y'' + 4y = x + \sin(2x)$, quale forma di soluzione particolare prevede il metodo di somiglianza? Le lettere $a$, $b$, $c$, $d$ indicano costanti da determinare.

- $y_p = a x + b + c \cos(2x) + d \sin(2x)$
- $y_p = x (a x + b) + c \cos(2x) + d \sin(2x)$
- $y_p = a x + b + x \bigl( c \cos(2x) + d \sin(2x) \bigr)$
- $y_p = a x + b + x^2 \bigl( c \cos(2x) + d \sin(2x) \bigr)$

## Spiegazione

L'equazione caratteristica $r^2 + 4 = 0$ ha le radici semplici $\pm 2i$. Per la **linearità** dell'equazione si cerca una soluzione particolare per ciascun termine di $f$ e si sommano i risultati. Al polinomio $x$ è associato il numero $0$, che non è radice, quindi il tentativo è $a x + b$. A $\sin(2x)$ è associato il numero $\pm 2i$, che è radice semplice, quindi il tentativo $c \cos(2x) + d \sin(2x)$ va moltiplicato per $x$. Perciò la forma prevista è $y_p = a x + b + x \bigl( c \cos(2x) + d \sin(2x) \bigr)$.
