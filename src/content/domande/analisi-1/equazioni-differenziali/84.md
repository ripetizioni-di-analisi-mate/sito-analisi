Quale delle seguenti funzioni è una soluzione particolare di $y'' + 16 y=7 \cos{\left(4 x \right)}$?

- $\dfrac{7 x \sin{\left(4 x \right)}}{8}$
- $\dfrac{7 x \sin{\left(4 x \right)}}{4}$
- $\dfrac{7 x \cos{\left(4 x \right)}}{8}$
- $- \dfrac{7 x \sin{\left(4 x \right)}}{8}$

## Spiegazione

Il termine noto è in risonanza con le soluzioni dell’omogenea. Applicando l’operatore a $x \sin{\left(4 x \right)}$ si ottiene $8 \cos{\left(4 x \right)}$.
