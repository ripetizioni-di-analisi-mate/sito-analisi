La funzione $y_p(x) = x$ è soluzione dell'equazione $y' + y = x + 1$. Qual è l'integrale generale dell'equazione?

- $y = x + C e^{x}$
- $y = x + C e^{-x}$
- $y = C x + e^{-x}$
- $y = C \left( x + e^{-x} \right)$

## Spiegazione

Per la **struttura dell'integrale generale**, le soluzioni di un'equazione lineare del primo ordine si ottengono sommando a una soluzione particolare l'integrale generale dell'omogenea associata. L'omogenea associata $y' + y = 0$ ha $a(x) = 1$, quindi il suo integrale generale è $C e^{-x}$. Poiché $y_p = x$ è soluzione della completa, l'integrale generale è $y = x + C e^{-x}$ con $C \in \mathbb{R}$. Le funzioni $C x + e^{-x}$ e $C \left( x + e^{-x} \right)$ soddisfano $y' + y = C (x + 1)$, quindi sono soluzioni soltanto per $C = 1$.
