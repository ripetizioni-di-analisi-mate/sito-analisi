Quale delle seguenti funzioni è una soluzione particolare di $y'' + 4 y=3 \cos{\left(2 x \right)}$?

- $\dfrac{3 x \sin{\left(2 x \right)}}{2}$
- $\dfrac{3 x \sin{\left(2 x \right)}}{4}$
- $- \dfrac{3 x \sin{\left(2 x \right)}}{4}$
- $\dfrac{3 x \cos{\left(2 x \right)}}{4}$

## Spiegazione

Il termine noto è in risonanza con le soluzioni dell’omogenea. Applicando l’operatore a $x \sin{\left(2 x \right)}$ si ottiene $4 \cos{\left(2 x \right)}$.
