Qual è la soluzione del problema $y'' + 4 y=0$ con $y(0)=3$, $y'(0)=10$?

- $- 5 \sin{\left(2 x \right)} + 3 \cos{\left(2 x \right)}$
- $10 \sin{\left(2 x \right)} + 3 \cos{\left(2 x \right)}$
- $5 \sin{\left(2 x \right)} + 3 \cos{\left(2 x \right)}$
- $3 \sin{\left(2 x \right)} + 5 \cos{\left(2 x \right)}$

## Spiegazione

Il coseno vale uno in zero e il seno vale zero. La derivata del termine con il seno in zero è il suo coefficiente moltiplicato per $2$.
