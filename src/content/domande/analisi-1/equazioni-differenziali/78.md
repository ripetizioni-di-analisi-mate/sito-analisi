Qual è la soluzione del problema $y'' + 16 y=0$ con $y(0)=7$, $y'(0)=12$?

- $12 \sin{\left(4 x \right)} + 7 \cos{\left(4 x \right)}$
- $3 \sin{\left(4 x \right)} + 7 \cos{\left(4 x \right)}$
- $7 \sin{\left(4 x \right)} + 3 \cos{\left(4 x \right)}$
- $- 3 \sin{\left(4 x \right)} + 7 \cos{\left(4 x \right)}$

## Spiegazione

Il coseno vale uno in zero e il seno vale zero. La derivata del termine con il seno in zero è il suo coefficiente moltiplicato per $4$.
