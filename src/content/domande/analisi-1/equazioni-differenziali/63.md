Si risolve l'equazione $y' + y = 2\sin x$ con il fattore integrante. Quale integrale generale si ottiene?

- $y = \sin x - \cos x + C e^{x}$
- $y = \sin x - \cos x + C e^{-x}$
- $y = \sin x + \cos x + C e^{-x}$
- $y = -2\cos x + C e^{-x}$

## Spiegazione

L'equazione è lineare con $a(x) = 1$, quindi il fattore integrante è $e^{x}$ e l'equazione equivale a
$$
\left(e^{x} y\right)' = 2e^{x} \sin x .
$$
Integrando due volte per parti si ottiene la primitiva $\displaystyle\int 2e^{x}\sin x\, dx = e^{x}(\sin x - \cos x)$. Quindi $e^{x} y = e^{x}(\sin x - \cos x) + C$ e, dividendo per $e^{x}$, l'integrale generale è $y = \sin x - \cos x + C e^{-x}$ con $C \in \mathbb{R}$.
