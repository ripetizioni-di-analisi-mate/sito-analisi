- $x = \dfrac{\pi}{4} + 2k\pi$ oppure $x = \dfrac{3\pi}{4} + 2k\pi$, con $k \in \mathbb{Z}$
- $x = -\dfrac{\pi}{4} + 2k\pi$ oppure $x = \dfrac{5\pi}{4} + 2k\pi$, con $k \in \mathbb{Z}$
- $x = -\dfrac{\pi}{4} + 2k\pi$ oppure $x = \dfrac{\pi}{4} + 2k\pi$, con $k \in \mathbb{Z}$
- $x = -\dfrac{\pi}{4} + k\pi$, con $k \in \mathbb{Z}$

## Spiegazione

L'equazione equivale a $\sin x = -\dfrac{1}{\sqrt{2}} = -\dfrac{\sqrt{2}}{2}$. Poiché il seno è dispari e $\sin \dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2}$, si ha $\arcsin\left( -\dfrac{\sqrt{2}}{2} \right) = -\dfrac{\pi}{4}$. Le soluzioni di $\sin x = m$ sono $x = \arcsin m + 2k\pi$ oppure $x = \pi - \arcsin m + 2k\pi$, quindi qui $x = -\dfrac{\pi}{4} + 2k\pi$ oppure $x = \pi + \dfrac{\pi}{4} + 2k\pi = \dfrac{5\pi}{4} + 2k\pi$, con $k \in \mathbb{Z}$. Le soluzioni $x = \pm\dfrac{\pi}{4} + 2k\pi$ sono quelle dell'equazione $\cos x = \dfrac{\sqrt{2}}{2}$.
