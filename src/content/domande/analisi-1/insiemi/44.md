Sapendo che $\sinh x = \dfrac{3}{4}$, quanto vale $\cosh x$?

- $\dfrac{\sqrt{7}}{4}$
- $\dfrac{5}{4}$
- $\dfrac{7}{4}$
- $\dfrac{25}{16}$

## Spiegazione

Dall'identità fondamentale $\cosh^2 x - \sinh^2 x = 1$ si ricava $\cosh^2 x = 1 + \dfrac{9}{16} = \dfrac{25}{16}$. Il coseno iperbolico ha immagine $[1, +\infty)$, quindi è positivo e $\cosh x = \dfrac{5}{4}$. Infatti $\sinh x = \dfrac{3}{4}$ per $x = \ln 2$, e $\cosh(\ln 2) = \dfrac{2 + \frac{1}{2}}{2} = \dfrac{5}{4}$. Il valore $\dfrac{\sqrt{7}}{4}$ si ottiene con l'identità trigonometrica $\sin^2 x + \cos^2 x = 1$, che per le funzioni iperboliche non vale. Il valore $\dfrac{25}{16}$ è $\cosh^2 x$.
