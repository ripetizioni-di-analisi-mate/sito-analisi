- $1 < x < 2$
- $-1 < x < 2$
- $x > 2$
- $0 < x < 2$

## Spiegazione

Le condizioni di esistenza dei due logaritmi formano il sistema
$$
\begin{cases}
x > 0 \\[4pt]
x - 1 > 0
\end{cases}
$$
che è soddisfatto per $x > 1$. Per $x > 1$ la somma dei logaritmi è $\log_2 \bigl( x(x - 1) \bigr)$ e $1 = \log_2 2$; poiché la base $2$ è maggiore di $1$, la disequazione equivale a $x(x - 1) < 2$. La disequazione $x^2 - x - 2 < 0$ ha radici $-1$ e $2$, quindi è soddisfatta per $-1 < x < 2$. Le soluzioni sono i punti di $(-1, 2)$ con $x > 1$, cioè $1 < x < 2$.
