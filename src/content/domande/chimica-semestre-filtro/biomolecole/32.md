Quale componente rende anfipatica una molecola di fosfatidilcolina?

- Una sequenza di amminoacidi carichi.
- Uno scheletro composto solo da glucosio.
- Una testa polare unita a due code idrofobe.
- Tre code idrofobe senza testa polare.

## Spiegazione

La testa con fosfato è polare, mentre le catene aciliche interagiscono preferenzialmente con la fase lipidica.
