In un punto si ha uno stato piano di tensione con σₓ = +45 MPa, σᵧ = −15 MPa e τₓᵧ = 0. Quali sono, nell’ordine, le tensioni principali σ₁ ≥ σ₂ ≥ σ₃ dello stato tridimensionale?

- (+45 / 0 / −15) MPa
- (+45 / −15 / 0) MPa
- (+45 / +15 / 0) MPa
- (+30 / 0 / −30) MPa

## Spiegazione

Lo stato piano di tensione impone σ_z = τ_xz = τ_yz = 0. Poiché anche τₓᵧ = 0, il tensore è già diagonale. Le tre componenti normali sono le tensioni principali, da ordinare come +45 ≥ 0 ≥ −15 MPa.
