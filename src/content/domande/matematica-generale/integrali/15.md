Qual è la primitiva $F$ di $f(x) = 6x^2 - 4x + 1$ tale che $F(1) = 5$?

- $F(x) = 2x^3 - 2x^2 + x + 5$
- $F(x) = 6x^3 - 4x^2 + x + 2$
- $F(x) = 2x^3 - 2x^2 + x + 4$
- $F(x) = 2x^3 - 4x^2 + x + 6$

## Spiegazione

Per la **linearità** dell'integrale e per la formula delle potenze si ha $\displaystyle\int 6x^2\,dx = 2x^3$ e $\displaystyle\int 4x\,dx = 2x^2$, quindi le primitive di $f$ sono
$$
F(x) = 2x^3 - 2x^2 + x + c, \qquad c \in \mathbb{R} .
$$
La condizione $F(1) = 5$ dà $2 - 2 + 1 + c = 5$, quindi $c = 4$. Perciò la primitiva cercata è $F(x) = 2x^3 - 2x^2 + x + 4$.
