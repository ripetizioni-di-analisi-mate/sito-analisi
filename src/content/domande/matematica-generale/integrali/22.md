Calcolare $\displaystyle\int x \cos x\,dx$.

- $x \sin x - \cos x + c$
- $\sin x - x \cos x + c$
- $x \sin x + \cos x + c$
- $\dfrac{x^2}{2} \sin x + c$

## Spiegazione

Si applica l'**integrazione per parti** con fattore finito $f(x) = x$ e fattore differenziale $g'(x) = \cos x$, quindi $f'(x) = 1$ e $g(x) = \sin x$. La formula dà
$$
\int x \cos x\,dx = x \sin x - \int \sin x\,dx .
$$
Poiché $\displaystyle\int \sin x\,dx = -\cos x + c$, il risultato è $x \sin x + \cos x + c$.
