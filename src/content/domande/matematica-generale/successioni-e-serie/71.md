Per quali valori reali di $x$ la successione $a_n = (x - 1)^n$ converge?

- $0 < x < 2$
- $0 < x \leq 2$
- $0 \leq x \leq 2$
- $-1 < x \leq 1$

## Spiegazione

La successione è $q^{\,n}$ con $q = x - 1$. Per il limite della successione geometrica, $q^{\,n}$ converge a $0$ se $-1 < q < 1$ e converge a $1$ se $q = 1$, mentre diverge per $q > 1$ ed è irregolare per $q \leq -1$.

Quindi la successione converge se e solo se $-1 < x - 1 \leq 1$, cioè $0 < x \leq 2$.

Per $x = 2$ la successione è costante e vale $1$, perciò converge. Per $x = 0$ la successione è $(-1)^n$, che è irregolare.
