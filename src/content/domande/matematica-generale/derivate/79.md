Qual è la derivata nei punti interni del dominio di $\sqrt{4 x + 7}$?

- $\dfrac{4}{\sqrt{4 x + 7}}$
- $\dfrac{1}{2 \sqrt{4 x + 7}}$
- $\dfrac{2}{\sqrt{4 x + 7}}$
- $4 \sqrt{4 x + 7}$

## Spiegazione

La derivata della radice di $u$ è $\dfrac1{2\sqrt u}$. Per la regola della catena si moltiplica per $u\prime=4$.
