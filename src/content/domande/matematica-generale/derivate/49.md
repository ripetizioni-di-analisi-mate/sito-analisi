Qual è la derivata nei punti interni del dominio di $\sqrt{2 x + 3}$?

- $2 \sqrt{2 x + 3}$
- $\dfrac{1}{2 \sqrt{2 x + 3}}$
- $\dfrac{1}{\sqrt{2 x + 3}}$
- $\dfrac{2}{\sqrt{2 x + 3}}$

## Spiegazione

La derivata della radice di $u$ è $\dfrac1{2\sqrt u}$. Per la regola della catena si moltiplica per $u\prime=2$.
