Qual è la derivata nei punti interni del dominio di $\sqrt{3 x + 5}$?

- $\dfrac{3}{\sqrt{3 x + 5}}$
- $3 \sqrt{3 x + 5}$
- $\dfrac{3}{2 \sqrt{3 x + 5}}$
- $\dfrac{1}{2 \sqrt{3 x + 5}}$

## Spiegazione

La derivata della radice di $u$ è $\dfrac1{2\sqrt u}$. Per la regola della catena si moltiplica per $u\prime=3$.
