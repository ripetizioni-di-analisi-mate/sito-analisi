Un browser usa HTTPS su TCP per inviare una richiesta a un server remoto attraverso il router locale. Quale coppia indica il destinatario immediato sul primo cavo e il servizio finale?

- MAC del router e porta TCP del server.
- MAC del server e porta TCP del router.
- IP del router e MAC del server.
- Porta TCP del router e IP del PC.

## Spiegazione

Il server è remoto, quindi sul primo cavo il frame è destinato alla prossima interfaccia del percorso, cioè quella del router locale. La destinazione immediata è perciò il **MAC del router**. Il servizio finale si individua con la porta TCP di destinazione, che è una porta del server. L'IP di destinazione individua il server per l'inoltro e resta lo stesso lungo tutto il percorso.
