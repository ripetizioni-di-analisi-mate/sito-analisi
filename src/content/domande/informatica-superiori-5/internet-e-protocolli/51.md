Un record MX per `scuola.example` contiene `posta.example`. Per contattare il server di posta tramite IPv4, quale altro dato DNS serve?

- Il record A di `scuola.example` usato per il sito.
- Il record AAAA di `scuola.example`.
- Il record A di `posta.example`.
- Un CNAME dal server Web al resolver locale.

## Spiegazione

Il record `MX` di `scuola.example` contiene il nome del server di posta, `posta.example`, e nessun indirizzo. Per collegarsi tramite IPv4 serve quindi l'indirizzo di `posta.example`, che si trova nel suo record `A`. I record `A` e `AAAA` di `scuola.example` indicano gli indirizzi associati al nome del dominio, per esempio quello del sito, perciò possono essere diversi da quello del server di posta.
