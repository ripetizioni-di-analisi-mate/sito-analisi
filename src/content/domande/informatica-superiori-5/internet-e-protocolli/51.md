Un record MX per `scuola.example` contiene `posta.example`. Per contattare il server di posta tramite IPv4, quale altro dato DNS serve?

- Il record A di `scuola.example` usato per il sito.
- Il record AAAA di `scuola.example`.
- Il record A di `posta.example`.
- Un CNAME dal server Web al resolver locale.

## Spiegazione

Il record MX identifica il server di posta per nome. Il record A di quel nome fornisce l'indirizzo IPv4.
