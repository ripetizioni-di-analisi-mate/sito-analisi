Il resolver non ha dati utili in cache e segue le deleghe DNS. Quale ordine generale usa per trovare il server responsabile di una zona?

- Server autoritativo della zona, radice, dominio di primo livello.
- Dominio di primo livello, server DHCP, radice.
- Radice, dominio di primo livello, server autoritativo della zona.
- Server Web, server autoritativo, radice.

## Spiegazione

Con la cache vuota il resolver non conosce il server autoritativo della zona, quindi parte dalla radice. La radice indica i server del dominio di primo livello, e questi indicano a loro volta il server autoritativo della zona cercata. L'ordine è perciò radice, dominio di primo livello, server autoritativo. Partire dall'autoritativo presuppone di conoscerlo già, e il server DHCP non partecipa alla risoluzione.
