Il resolver non ha dati utili in cache e segue le deleghe DNS. Quale ordine generale usa per trovare il server responsabile di una zona?

- Server autoritativo della zona, radice, dominio di primo livello.
- Dominio di primo livello, server DHCP, radice.
- Radice, dominio di primo livello, server autoritativo della zona.
- Server Web, server autoritativo, radice.

## Spiegazione

Le risposte intermedie indirizzano il resolver verso server via via più specifici fino alla zona cercata.
