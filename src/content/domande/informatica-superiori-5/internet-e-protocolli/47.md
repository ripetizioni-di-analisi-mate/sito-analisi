DHCP indica il resolver `192.0.2.53`. Il record A di `scuola.example` vale `198.51.100.12`. Quale indirizzo identifica il server Web nell'esempio?

- `192.0.2.53`
- L'indirizzo locale del portatile.
- `198.51.100.12`
- L'indirizzo del gateway predefinito.

## Spiegazione

DHCP comunica l'indirizzo del resolver `192.0.2.53`, cioè del server a cui il portatile chiede la risoluzione dei nomi. Il resolver risponde con il record `A` di `scuola.example`, che contiene l'IPv4 del server Web. Perciò il browser apre la connessione verso `198.51.100.12`. Scegliere `192.0.2.53` significa confondere il server che fornisce la risposta con l'indirizzo contenuto nella risposta.
