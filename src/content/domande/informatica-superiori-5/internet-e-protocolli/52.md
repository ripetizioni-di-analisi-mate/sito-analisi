Un client interroga il suo resolver ricorsivo. Qual è il ruolo del server autoritativo per la zona richiesta?

- Assegnare l'IP al client tramite DHCP.
- Stabilire la connessione TCP del browser.
- Sostituire il resolver configurato nel client.
- Pubblicare i dati DNS di quella zona.

## Spiegazione

Un server **autoritativo** pubblica i dati DNS delle zone di cui è responsabile. Il resolver ricorsivo riceve la richiesta del client, interroga se necessario i server autoritativi e restituisce la risposta. Perciò l'autoritativo fornisce i dati della zona e il resolver resta l'interlocutore del client. L'assegnazione dell'IP spetta a DHCP e la connessione TCP si apre fra il browser e il server Web.
