Il programma usa `f(x) <= eps_f` come test sul residuo e accetta `f(x) = -3` con `eps_f = 0.01`. Quale correzione implementa il controllo sul residuo in modo appropriato?

- `f(x) >= -eps_f`
- `f(x) < 0`
- `abs(x) <= eps_f`
- `abs(f(x)) <= eps_f`

## Spiegazione

Il residuo è $|f(x)|$, quindi il test appropriato è `abs(f(x)) <= eps_f`. Con $f(x)=-3$ si ha $|f(x)|=3>0{,}01$, perciò la stima viene respinta. Il test `f(x) <= eps_f` accetta ogni valore negativo, per quanto grande in modulo. Il test `f(x) >= -eps_f` accetta ogni valore positivo, mentre `abs(x) <= eps_f` controlla la variabile invece del valore della funzione.
