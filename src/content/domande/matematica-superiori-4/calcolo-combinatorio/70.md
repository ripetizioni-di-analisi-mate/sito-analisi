Quale delle seguenti uguaglianze è vera?

- $\dbinom{12}{4} = \dbinom{11}{3} + \dbinom{11}{5}$
- $\dbinom{12}{4} = \dbinom{12}{8}$
- $\dbinom{12}{4} = 3 \dbinom{12}{3}$
- $\dbinom{12}{4} = \dbinom{12}{3} + \dbinom{12}{5}$

## Spiegazione

Per la proprietà dei coefficienti binomiali complementari $\dbinom{12}{4} = \dbinom{12}{12 - 4} = \dbinom{12}{8}$, quindi l'uguaglianza $\dbinom{12}{4} = \dbinom{12}{8}$ è vera. La legge di Stifel dà $\dbinom{12}{4} = \dbinom{11}{3} + \dbinom{11}{4} = 165 + 330 = 495$, mentre $\dbinom{11}{3} + \dbinom{11}{5} = 165 + 462 = 627$. Inoltre $\dbinom{12}{3} = 220$, quindi $3 \dbinom{12}{3} = 660$ e $\dbinom{12}{3} + \dbinom{12}{5} = 220 + 792 = 1012$, entrambi diversi da $495$.
