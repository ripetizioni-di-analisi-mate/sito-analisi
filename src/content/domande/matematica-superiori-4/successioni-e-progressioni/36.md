Si vuole dimostrare per induzione la formula $1^3 + 2^3 + \dots + n^3 = \dfrac{n^2(n + 1)^2}{4}$. Quale uguaglianza si deve verificare nel passo induttivo?

- $\dfrac{n^2(n + 1)^2}{4} + n^3 = \dfrac{(n + 1)^2(n + 2)^2}{4}$
- $\dfrac{n^2(n + 1)^2}{4} + (n + 1)^2 = \dfrac{(n + 1)^2(n + 2)^2}{4}$
- $\dfrac{n^2(n + 1)^2}{4} + (n + 1)^3 = \dfrac{(n + 1)^2(n + 2)^2}{2}$
- $\dfrac{n^2(n + 1)^2}{4} + (n + 1)^3 = \dfrac{(n + 1)^2(n + 2)^2}{4}$

## Spiegazione

Nel passo induttivo si suppone vera la formula per $n$ e si aggiunge ai due membri il termine successivo $(n + 1)^3$. Il secondo membro deve diventare la formula scritta con $n + 1$ al posto di $n$, cioè $\dfrac{(n + 1)^2(n + 2)^2}{4}$. L'uguaglianza è vera, perché raccogliendo $\dfrac{(n + 1)^2}{4}$ il primo membro diventa $\dfrac{(n + 1)^2}{4}\left( n^2 + 4n + 4 \right) = \dfrac{(n + 1)^2(n + 2)^2}{4}$.
