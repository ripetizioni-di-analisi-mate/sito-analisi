Quali sono le soluzioni della disequazione $\tan\dfrac{x}{2} < 1$?

- $-\dfrac{\pi}{4} + \dfrac{k\pi}{2} < x < \dfrac{\pi}{8} + \dfrac{k\pi}{2}$
- $-\pi + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $-\pi + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \pi + 2k\pi$

## Spiegazione

Si pone $t = \dfrac{x}{2}$. La disequazione $\tan t < 1$ ha le soluzioni $-\dfrac{\pi}{2} + k\pi < t < \dfrac{\pi}{4} + k\pi$. Moltiplicando tutti i membri per $2$ si ottiene $-\pi + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$. Il periodo diventa $2\pi$, che è il periodo di $\tan\dfrac{x}{2}$.
