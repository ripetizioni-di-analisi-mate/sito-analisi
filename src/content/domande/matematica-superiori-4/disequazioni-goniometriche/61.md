Si risolve la disequazione $\sin x + \cos x \leq -1$ con le formule parametriche, ponendo $t = \tan\dfrac{x}{2}$. Quali sono le soluzioni?

- $\pi + 2k\pi < x \leq \dfrac{3\pi}{2} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi \leq x \leq \pi + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi \leq x \leq 2k\pi$
- $\pi + 2k\pi \leq x \leq \dfrac{3\pi}{2} + 2k\pi$

## Spiegazione

Per $x \neq \pi + 2k\pi$ si sostituiscono $\sin x = \dfrac{2t}{1 + t^2}$ e $\cos x = \dfrac{1 - t^2}{1 + t^2}$ e si moltiplica per $1 + t^2 > 0$. Si ottiene $2t + 1 - t^2 \leq -1 - t^2$, cioè $t \leq -1$. La condizione $\tan\dfrac{x}{2} \leq -1$ dà $-\dfrac{\pi}{2} + k\pi < \dfrac{x}{2} \leq -\dfrac{\pi}{4} + k\pi$, quindi $-\pi + 2k\pi < x \leq -\dfrac{\pi}{2} + 2k\pi$, che, sostituendo $k$ con $k + 1$, si scrive $\pi + 2k\pi < x \leq \dfrac{3\pi}{2} + 2k\pi$. Il valore $x = \pi$, escluso dalla sostituzione, soddisfa la disequazione, perché $\sin\pi + \cos\pi = -1$. Aggiungendo i punti $\pi + 2k\pi$ si ottiene $\pi + 2k\pi \leq x \leq \dfrac{3\pi}{2} + 2k\pi$.
