Quali sono le soluzioni della disequazione $(\sin x - 1)(2\cos x - 1) \geq 0$?

- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$
- $-\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{\pi}{3} + 2k\pi$
- $-\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{\pi}{3} + 2k\pi$ oppure $x = \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi < x < \dfrac{5\pi}{3} + 2k\pi$

## Spiegazione

Il fattore $\sin x - 1$ è negativo per $x \neq \dfrac{\pi}{2} + 2k\pi$ e nullo per $x = \dfrac{\pi}{2} + 2k\pi$. Dove questo fattore è negativo, il prodotto è maggiore o uguale a $0$ quando $2\cos x - 1 \leq 0$, cioè per $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$. I punti $x = \dfrac{\pi}{2} + 2k\pi$, in cui il prodotto vale $0$, sono soluzioni e appartengono già a questo intervallo. Quindi le soluzioni sono $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$.
