- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{13\pi}{6} + 2k\pi$
- $\dfrac{7\pi}{6} + 2k\pi \leq x \leq \dfrac{11\pi}{6} + 2k\pi$ oppure $x = \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$ oppure $x = \dfrac{3\pi}{2} + 2k\pi$

## Spiegazione

Con $t = \sin x$ si ottiene $2t^2 + t - 1 \geq 0$, cioè $(2t - 1)(t + 1) \geq 0$, che vale per $t \leq -1$ oppure $t \geq \dfrac{1}{2}$. Poiché $\sin x \geq -1$ per ogni $x$, la condizione $\sin x \leq -1$ equivale a $\sin x = -1$, cioè a $x = \dfrac{3\pi}{2} + 2k\pi$. La condizione $\sin x \geq \dfrac{1}{2}$ dà $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$. Le soluzioni sono l'unione dei due insiemi, e i punti $\dfrac{3\pi}{2} + 2k\pi$ sono **soluzioni isolate**.
