- $-\dfrac{\pi}{2} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{8} + k\pi \leq x \leq \dfrac{\pi}{8} + k\pi$
- $\dfrac{\pi}{2} + 4k\pi \leq x \leq \dfrac{7\pi}{2} + 4k\pi$
- $-\dfrac{\pi}{2} + 4k\pi \leq x \leq \dfrac{\pi}{2} + 4k\pi$

## Spiegazione

Si pone $t = \dfrac{x}{2}$. Poiché $\arccos\dfrac{\sqrt{2}}{2} = \dfrac{\pi}{4}$, la disequazione $\cos t \geq \dfrac{\sqrt{2}}{2}$ ha le soluzioni $-\dfrac{\pi}{4} + 2k\pi \leq t \leq \dfrac{\pi}{4} + 2k\pi$. Moltiplicando tutti i membri per $2$ si ottiene $-\dfrac{\pi}{2} + 4k\pi \leq x \leq \dfrac{\pi}{2} + 4k\pi$. Anche il periodo si moltiplica per $2$, e infatti il periodo di $\cos\dfrac{x}{2}$ è $4\pi$.
