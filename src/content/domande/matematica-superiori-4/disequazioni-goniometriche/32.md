Quali sono le soluzioni della disequazione $\tan x \leq 0$ nell'intervallo $[0, 2\pi)$?

- $\dfrac{\pi}{2} < x \leq \pi$ oppure $\dfrac{3\pi}{2} < x < 2\pi$
- $\dfrac{\pi}{2} \leq x \leq \pi$ oppure $\dfrac{3\pi}{2} \leq x < 2\pi$
- $x = 0$ oppure $\dfrac{\pi}{2} < x \leq \pi$ oppure $\dfrac{3\pi}{2} < x < 2\pi$
- $0 < x < \dfrac{\pi}{2}$ oppure $\pi < x < \dfrac{3\pi}{2}$

## Spiegazione

La tangente si annulla in $0$ e in $\pi$, non è definita in $\dfrac{\pi}{2}$ e in $\dfrac{3\pi}{2}$, ed è negativa nel secondo e nel quarto quadrante. In $[0, 2\pi)$ si ha quindi $\tan x < 0$ per $\dfrac{\pi}{2} < x < \pi$ e per $\dfrac{3\pi}{2} < x < 2\pi$. A questi intervalli si aggiungono gli zeri $0$ e $\pi$, perché la disuguaglianza è larga. I valori $\dfrac{\pi}{2}$ e $\dfrac{3\pi}{2}$ sono esclusi perché in essi la tangente non è definita.
