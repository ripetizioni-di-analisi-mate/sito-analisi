Quali sono le soluzioni della disequazione $\tan x \geq -1$?

- $-\dfrac{\pi}{2} + k\pi < x \leq -\dfrac{\pi}{4} + k\pi$
- $-\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{\pi}{4} + k\pi$
- $-\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$
- $-\dfrac{\pi}{4} + 2k\pi \leq x < \dfrac{\pi}{2} + 2k\pi$

## Spiegazione

Poiché $\arctan(-1) = -\dfrac{\pi}{4}$ e la tangente è crescente in ogni intervallo $\left( -\dfrac{\pi}{2} + k\pi, \dfrac{\pi}{2} + k\pi \right)$, in ogni ramo la tangente è maggiore o uguale a $-1$ da $-\dfrac{\pi}{4} + k\pi$ fino all'asintoto $\dfrac{\pi}{2} + k\pi$. L'estremo $-\dfrac{\pi}{4} + k\pi$ è compreso perché la disuguaglianza è larga. L'estremo $\dfrac{\pi}{2} + k\pi$ è escluso perché la tangente non vi è definita. Il periodo delle soluzioni è $\pi$, il periodo della tangente.
