Quali sono le soluzioni della disequazione $\cos 3x \leq 0$ nell'intervallo $[0, \pi]$?

- $\dfrac{\pi}{6} \leq x \leq \dfrac{\pi}{2}$
- $\dfrac{\pi}{6} \leq x \leq \dfrac{\pi}{2}$ oppure $\dfrac{5\pi}{6} \leq x \leq \pi$
- $0 \leq x \leq \dfrac{\pi}{6}$ oppure $\dfrac{\pi}{2} \leq x \leq \dfrac{5\pi}{6}$
- $\dfrac{\pi}{6} \leq x \leq \dfrac{\pi}{2}$ oppure $\dfrac{5\pi}{6} \leq x \leq \dfrac{7\pi}{6}$

## Spiegazione

Si pone $t = 3x$. La disequazione $\cos t \leq 0$ ha le soluzioni $\dfrac{\pi}{2} + 2k\pi \leq t \leq \dfrac{3\pi}{2} + 2k\pi$, quindi, dividendo per $3$, si ha $\dfrac{\pi}{6} + \dfrac{2k\pi}{3} \leq x \leq \dfrac{\pi}{2} + \dfrac{2k\pi}{3}$. Con $k = 0$ si ottiene l'intervallo $\left[ \dfrac{\pi}{6}, \dfrac{\pi}{2} \right]$. Con $k = 1$ si ottiene $\left[ \dfrac{5\pi}{6}, \dfrac{7\pi}{6} \right]$, che ha in comune con $[0, \pi]$ la parte $\left[ \dfrac{5\pi}{6}, \pi \right]$. Gli altri valori di $k$ danno intervalli senza punti in comune con $[0, \pi]$.
