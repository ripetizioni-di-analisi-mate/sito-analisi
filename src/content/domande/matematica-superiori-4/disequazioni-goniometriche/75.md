Quali sono le soluzioni della disequazione $\dfrac{2\sin x + 1}{\cos x} > 0$ nell'intervallo $[0, 2\pi)$?

- $0 \leq x < \dfrac{\pi}{2}$ oppure $\dfrac{7\pi}{6} < x < \dfrac{3\pi}{2}$ oppure $\dfrac{11\pi}{6} < x < 2\pi$
- $0 \leq x < \dfrac{\pi}{2}$ oppure $\dfrac{3\pi}{2} < x < 2\pi$
- $\dfrac{\pi}{2} < x < \dfrac{7\pi}{6}$ oppure $\dfrac{3\pi}{2} < x < \dfrac{11\pi}{6}$
- $0 \leq x < \dfrac{\pi}{2}$ oppure $\dfrac{7\pi}{6} < x < \dfrac{3\pi}{2}$

## Spiegazione

In $[0, 2\pi)$ il numeratore $2\sin x + 1$ è positivo per $0 \leq x < \dfrac{7\pi}{6}$ e per $\dfrac{11\pi}{6} < x < 2\pi$, negativo per $\dfrac{7\pi}{6} < x < \dfrac{11\pi}{6}$. Il denominatore $\cos x$ è positivo per $0 \leq x < \dfrac{\pi}{2}$ e per $\dfrac{3\pi}{2} < x < 2\pi$, negativo per $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$. Il quoziente è positivo dove numeratore e denominatore hanno lo stesso segno, cioè in $\left[ 0, \dfrac{\pi}{2} \right)$, in $\left( \dfrac{7\pi}{6}, \dfrac{3\pi}{2} \right)$ e in $\left( \dfrac{11\pi}{6}, 2\pi \right)$. Gli zeri del denominatore $\dfrac{\pi}{2}$ e $\dfrac{3\pi}{2}$ sono esclusi.
