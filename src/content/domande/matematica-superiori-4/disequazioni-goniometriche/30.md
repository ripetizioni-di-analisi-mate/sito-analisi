Quali sono le soluzioni della disequazione $\cos x > -\dfrac{\sqrt{3}}{2}$ nell'intervallo $[0, 2\pi)$?

- $\dfrac{5\pi}{6} < x < \dfrac{7\pi}{6}$
- $0 \leq x < \dfrac{2\pi}{3}$ oppure $\dfrac{4\pi}{3} < x < 2\pi$
- $0 \leq x < \dfrac{5\pi}{6}$ oppure $\dfrac{7\pi}{6} < x < 2\pi$
- $-\dfrac{5\pi}{6} < x < \dfrac{5\pi}{6}$

## Spiegazione

In $[0, 2\pi)$ l'equazione $\cos x = -\dfrac{\sqrt{3}}{2}$ ha le soluzioni $\dfrac{5\pi}{6}$ e $\dfrac{7\pi}{6}$, nel secondo e nel terzo quadrante. Il coseno è minore o uguale a $-\dfrac{\sqrt{3}}{2}$ solo per $\dfrac{5\pi}{6} \leq x \leq \dfrac{7\pi}{6}$, dove i punti della circonferenza stanno vicino a $(-1, 0)$. Quindi nell'intervallo assegnato le soluzioni sono $0 \leq x < \dfrac{5\pi}{6}$ oppure $\dfrac{7\pi}{6} < x < 2\pi$. La scrittura $-\dfrac{5\pi}{6} < x < \dfrac{5\pi}{6}$ descrive le soluzioni in $[-\pi, \pi)$, e i suoi valori negativi non appartengono a $[0, 2\pi)$.
