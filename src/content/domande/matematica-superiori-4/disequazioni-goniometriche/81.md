Quali sono le soluzioni del sistema seguente?
$$
\begin{cases}
2\sin x \geq 1 \\[4pt]
2\cos x \leq 1
\end{cases}
$$

- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x < \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$

## Spiegazione

In $[0, 2\pi)$ la prima disequazione, cioè $\sin x \geq \dfrac{1}{2}$, ha le soluzioni $\dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}$. La seconda, cioè $\cos x \leq \dfrac{1}{2}$, ha le soluzioni $\dfrac{\pi}{3} \leq x \leq \dfrac{5\pi}{3}$. L'intersezione dei due intervalli è $\dfrac{\pi}{3} \leq x \leq \dfrac{5\pi}{6}$, con gli estremi compresi perché entrambe le disuguaglianze sono larghe. Aggiungendo il periodo $2\pi$ si ottengono le soluzioni del sistema.
