Quali sono le soluzioni della disequazione $\tan^2 x \geq 1$?

- $\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{3\pi}{4} + k\pi$
- $-\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{\pi}{4} + k\pi$
- $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{3\pi}{4} + k\pi$, con $x \neq \dfrac{\pi}{2} + k\pi$

## Spiegazione

Con $t = \tan x$ si ottiene $t^2 \geq 1$, cioè $t \leq -1$ oppure $t \geq 1$. In ogni ramo della tangente la condizione $\tan x \geq 1$ dà $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$. La condizione $\tan x \leq -1$ dà $-\dfrac{\pi}{2} + k\pi < x \leq -\dfrac{\pi}{4} + k\pi$, che, sostituendo $k$ con $k + 1$, si scrive $\dfrac{\pi}{2} + k\pi < x \leq \dfrac{3\pi}{4} + k\pi$. Unendo i due insiemi si ottiene $\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{3\pi}{4} + k\pi$, da cui si tolgono i punti $\dfrac{\pi}{2} + k\pi$, dove la tangente non è definita.
