Quali sono le soluzioni della disequazione $\sqrt{3}\sin x - \cos x \geq 1$?

- $2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \pi + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\pi + 2k\pi \leq x \leq \dfrac{7\pi}{3} + 2k\pi$

## Spiegazione

Con il metodo dell'angolo aggiunto si ha $r = \sqrt{3 + 1} = 2$, $\cos\varphi = \dfrac{\sqrt{3}}{2}$ e $\sin\varphi = -\dfrac{1}{2}$, quindi $\varphi = -\dfrac{\pi}{6}$. La disequazione diventa $2\sin\left( x - \dfrac{\pi}{6} \right) \geq 1$, cioè $\sin\left( x - \dfrac{\pi}{6} \right) \geq \dfrac{1}{2}$. L'argomento deve stare tra $\dfrac{\pi}{6} + 2k\pi$ e $\dfrac{5\pi}{6} + 2k\pi$, estremi compresi. Aggiungendo $\dfrac{\pi}{6}$ si ottiene $\dfrac{\pi}{3} + 2k\pi \leq x \leq \pi + 2k\pi$.
