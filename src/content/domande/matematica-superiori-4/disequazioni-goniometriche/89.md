Qual è il dominio della funzione $f(x) = \dfrac{\sqrt{\sin x}}{\cos x}$?

- $2k\pi \leq x \leq \pi + 2k\pi$
- $2k\pi < x < \pi + 2k\pi$, con $x \neq \dfrac{\pi}{2} + 2k\pi$
- $2k\pi \leq x < \dfrac{\pi}{2} + 2k\pi$
- $2k\pi \leq x \leq \pi + 2k\pi$, con $x \neq \dfrac{\pi}{2} + 2k\pi$

## Spiegazione

Il radicando deve essere maggiore o uguale a $0$ e il denominatore diverso da $0$, quindi il dominio è l'insieme delle soluzioni del sistema
$$
\begin{cases}
\sin x \geq 0 \\[4pt]
\cos x \neq 0
\end{cases}
$$
La prima condizione dà $2k\pi \leq x \leq \pi + 2k\pi$. La seconda esclude i punti $\dfrac{\pi}{2} + k\pi$, e di questi solo i punti $\dfrac{\pi}{2} + 2k\pi$ stanno nell'intervallo trovato. Il dominio è quindi $2k\pi \leq x \leq \pi + 2k\pi$, con $x \neq \dfrac{\pi}{2} + 2k\pi$.
