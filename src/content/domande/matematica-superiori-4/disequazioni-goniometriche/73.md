Quali sono le soluzioni della disequazione $\dfrac{\cos x}{1 + \sin x} \geq 0$?

- $-\dfrac{\pi}{2} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \dfrac{3\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x \leq \dfrac{\pi}{2} + 2k\pi$

## Spiegazione

Il denominatore $1 + \sin x$ è positivo per $x \neq \dfrac{3\pi}{2} + 2k\pi$ e si annulla per $x = \dfrac{3\pi}{2} + 2k\pi$. Quindi la disequazione equivale al sistema
$$
\begin{cases}
\cos x \geq 0 \\[4pt]
x \neq \dfrac{3\pi}{2} + 2k\pi
\end{cases}
$$
La prima condizione dà $-\dfrac{\pi}{2} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$. La seconda esclude l'estremo $-\dfrac{\pi}{2} + 2k\pi$, che coincide con $\dfrac{3\pi}{2} + 2(k - 1)\pi$. Le soluzioni sono quindi $-\dfrac{\pi}{2} + 2k\pi < x \leq \dfrac{\pi}{2} + 2k\pi$.
