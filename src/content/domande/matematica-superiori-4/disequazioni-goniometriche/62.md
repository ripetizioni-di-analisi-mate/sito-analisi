Quali sono le soluzioni della disequazione $\sqrt{3}\sin x + \cos x \geq \sqrt{3}$?

- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $2k\pi \leq x \leq \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$

## Spiegazione

Con il metodo dell'angolo aggiunto si ha $r = \sqrt{3 + 1} = 2$, $\cos\varphi = \dfrac{\sqrt{3}}{2}$ e $\sin\varphi = \dfrac{1}{2}$, quindi $\varphi = \dfrac{\pi}{6}$. La disequazione diventa $2\sin\left( x + \dfrac{\pi}{6} \right) \geq \sqrt{3}$, cioè $\sin\left( x + \dfrac{\pi}{6} \right) \geq \dfrac{\sqrt{3}}{2}$. L'argomento deve stare tra $\dfrac{\pi}{3} + 2k\pi$ e $\dfrac{2\pi}{3} + 2k\pi$, estremi compresi. Sottraendo $\dfrac{\pi}{6}$ si ottiene $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$.
