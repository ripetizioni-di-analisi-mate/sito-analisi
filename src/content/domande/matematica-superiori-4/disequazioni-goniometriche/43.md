Quali sono le soluzioni della disequazione $\sin x \geq \dfrac{1}{2}$ nell'intervallo $[-2\pi, 0]$?

- $-\dfrac{5\pi}{6} \leq x \leq -\dfrac{\pi}{6}$
- $-\dfrac{11\pi}{6} \leq x \leq -\dfrac{7\pi}{6}$
- $-2\pi \leq x < -\dfrac{11\pi}{6}$ oppure $-\dfrac{7\pi}{6} < x \leq 0$
- $-\dfrac{5\pi}{3} \leq x \leq -\dfrac{4\pi}{3}$

## Spiegazione

Su $\mathbb{R}$ le soluzioni sono $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$. L'intervallo con $k = 0$ è contenuto in $[0, \pi]$ e non ha punti in $[-2\pi, 0]$. Con $k = -1$ si ottiene $\dfrac{\pi}{6} - 2\pi \leq x \leq \dfrac{5\pi}{6} - 2\pi$, cioè $-\dfrac{11\pi}{6} \leq x \leq -\dfrac{7\pi}{6}$, che è contenuto in $[-2\pi, 0]$. Nell'intervallo $\left[ -\dfrac{5\pi}{6}, -\dfrac{\pi}{6} \right]$ il seno è invece negativo.
