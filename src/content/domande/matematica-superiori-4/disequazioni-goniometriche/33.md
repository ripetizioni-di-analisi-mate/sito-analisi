Quali sono le soluzioni della disequazione $\cot x < \sqrt{3}$?

- $k\pi < x < \dfrac{\pi}{6} + k\pi$
- $\dfrac{\pi}{3} + k\pi < x < \pi + k\pi$
- $\dfrac{\pi}{6} + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{6} + k\pi < x < \pi + k\pi$

## Spiegazione

La cotangente è decrescente in ogni intervallo $(k\pi, \pi + k\pi)$ e $\cot\dfrac{\pi}{6} = \sqrt{3}$. Quindi in ogni intervallo la cotangente è minore di $\sqrt{3}$ da $\dfrac{\pi}{6} + k\pi$ fino all'asintoto $\pi + k\pi$. Le soluzioni sono perciò $\dfrac{\pi}{6} + k\pi < x < \pi + k\pi$. L'estremo destro è escluso perché la cotangente non è definita nei punti $k\pi$.
