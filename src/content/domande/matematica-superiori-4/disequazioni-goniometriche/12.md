- $2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $2k\pi < x \leq \dfrac{5\pi}{6} + 2k\pi$
- $2k\pi < x \leq \dfrac{\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi < x < \pi + 2k\pi$

## Spiegazione

Si lavora nell'intervallo $[0, 2\pi)$. La prima disequazione ha le soluzioni $0 < x < \pi$. La seconda equivale a $\cos x \geq -\dfrac{\sqrt{3}}{2}$, e poiché $\arccos\left( -\dfrac{\sqrt{3}}{2} \right) = \dfrac{5\pi}{6}$, essa vale per $0 \leq x \leq \dfrac{5\pi}{6}$ e per $\dfrac{7\pi}{6} \leq x < 2\pi$. L'intersezione dei due insiemi è $0 < x \leq \dfrac{5\pi}{6}$, e aggiungendo il periodo $2\pi$ si ottengono le soluzioni del sistema.
