Quali sono le soluzioni della disequazione $\tan 2x > 1$?

- $\dfrac{\pi}{8} + k\pi < x < \dfrac{\pi}{4} + k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \pi + 2k\pi$
- $\dfrac{\pi}{8} + \dfrac{k\pi}{2} < x < \dfrac{\pi}{4} + \dfrac{k\pi}{2}$
- $\dfrac{\pi}{8} + \dfrac{k\pi}{2} < x < \dfrac{\pi}{2} + \dfrac{k\pi}{2}$

## Spiegazione

Si pone $t = 2x$. La disequazione $\tan t > 1$ ha le soluzioni $\dfrac{\pi}{4} + k\pi < t < \dfrac{\pi}{2} + k\pi$. Dividendo tutti i membri per $2$ si ottiene $\dfrac{\pi}{8} + \dfrac{k\pi}{2} < x < \dfrac{\pi}{4} + \dfrac{k\pi}{2}$. Il periodo rispetto a $x$ è $\dfrac{\pi}{2}$, perché la tangente con argomento $2x$ ha periodo $\dfrac{\pi}{2}$.
