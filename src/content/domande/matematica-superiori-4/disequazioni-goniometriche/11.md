- $0 < x < \dfrac{\pi}{3}$ oppure $\pi < x < \dfrac{5\pi}{3}$
- $\dfrac{\pi}{3} < x < \pi$ oppure $\dfrac{5\pi}{3} < x < 2\pi$
- $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$
- $\dfrac{\pi}{3} < x \leq \pi$ oppure $\dfrac{5\pi}{3} < x < 2\pi$

## Spiegazione

Nell'intervallo $[0, 2\pi)$ il numeratore $2\cos x - 1$ è positivo per $0 \leq x < \dfrac{\pi}{3}$ e per $\dfrac{5\pi}{3} < x < 2\pi$, negativo per $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$. Il denominatore $\sin x$ è positivo per $0 < x < \pi$, negativo per $\pi < x < 2\pi$, e si annulla in $0$ e in $\pi$, che sono quindi esclusi. Per la regola dei segni il quoziente è negativo dove numeratore e denominatore hanno segni opposti, cioè per $\dfrac{\pi}{3} < x < \pi$ e per $\dfrac{5\pi}{3} < x < 2\pi$. L'estremo $\dfrac{\pi}{3}$ è escluso perché in esso il quoziente vale $0$.
