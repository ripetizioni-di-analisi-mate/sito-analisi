Quali sono le soluzioni della disequazione $\sin 2x > \sin x$ nell'intervallo $[0, 2\pi)$?

- $0 < x < \dfrac{\pi}{3}$ oppure $\dfrac{5\pi}{3} < x < 2\pi$
- $\dfrac{\pi}{3} < x < \pi$ oppure $\dfrac{5\pi}{3} < x < 2\pi$
- $0 < x < \dfrac{\pi}{3}$ oppure $\pi < x < \dfrac{5\pi}{3}$
- $0 < x < \dfrac{\pi}{3}$

## Spiegazione

Con la formula di duplicazione la disequazione diventa $2\sin x\cos x - \sin x > 0$, cioè $\sin x\,(2\cos x - 1) > 0$. In $[0, 2\pi)$ il fattore $\sin x$ è positivo per $0 < x < \pi$ e negativo per $\pi < x < 2\pi$. Il fattore $2\cos x - 1$ è positivo per $0 \leq x < \dfrac{\pi}{3}$ e per $\dfrac{5\pi}{3} < x < 2\pi$, negativo per $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$. Il prodotto è positivo dove i due fattori hanno lo stesso segno, cioè per $0 < x < \dfrac{\pi}{3}$ e per $\pi < x < \dfrac{5\pi}{3}$.
