Quali sono le soluzioni della disequazione $2\cos x + 1 \geq 0$?

- $-\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{4\pi}{3} + 2k\pi$
- $-\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{\pi}{3} + 2k\pi$
- $-\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$

## Spiegazione

Si isola il coseno e si ottiene $\cos x \geq -\dfrac{1}{2}$. Poiché $\arccos\left( -\dfrac{1}{2} \right) = \dfrac{2\pi}{3}$, i punti della circonferenza con ascissa $-\dfrac{1}{2}$ sono associati agli angoli $\dfrac{2\pi}{3}$ e $-\dfrac{2\pi}{3}$. I punti con ascissa maggiore o uguale a $-\dfrac{1}{2}$ formano l'arco tra questi due angoli che passa per $(1, 0)$. Quindi le soluzioni sono $-\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$.
