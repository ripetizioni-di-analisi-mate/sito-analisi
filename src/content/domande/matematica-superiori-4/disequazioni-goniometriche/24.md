Quali sono le soluzioni della disequazione $\sin x < \dfrac{\sqrt{3}}{2}$?

- $\dfrac{2\pi}{3} + 2k\pi < x < \dfrac{7\pi}{3} + 2k\pi$
- $\dfrac{2\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi < x < \dfrac{2\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi < x < \dfrac{5\pi}{3} + 2k\pi$

## Spiegazione

Poiché $\arcsin\dfrac{\sqrt{3}}{2} = \dfrac{\pi}{3}$, la retta $y = \dfrac{\sqrt{3}}{2}$ taglia la circonferenza goniometrica nei punti associati a $\dfrac{\pi}{3}$ e a $\dfrac{2\pi}{3}$. I punti sotto la retta formano l'arco che parte da $\dfrac{2\pi}{3}$ e, passando per $\dfrac{3\pi}{2}$, arriva al punto associato a $\dfrac{\pi}{3}$ dopo un giro. Nella scrittura con $k$ l'estremo sinistro deve essere minore del destro, perciò all'estremo $\dfrac{\pi}{3}$ si aggiunge $2\pi$ e si ottiene $\dfrac{7\pi}{3}$. La scrittura $\dfrac{2\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$ descrive invece un insieme vuoto.
