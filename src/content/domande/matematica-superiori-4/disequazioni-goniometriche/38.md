Quali sono le soluzioni della disequazione $\sin\left( \dfrac{\pi}{4} - x \right) > 0$?

- $-\dfrac{3\pi}{4} + 2k\pi < x < \dfrac{\pi}{4} + 2k\pi$
- $\dfrac{\pi}{4} + 2k\pi < x < \dfrac{5\pi}{4} + 2k\pi$
- $-\dfrac{\pi}{4} + 2k\pi < x < \dfrac{3\pi}{4} + 2k\pi$
- $-\dfrac{3\pi}{4} + k\pi < x < \dfrac{\pi}{4} + k\pi$

## Spiegazione

Si pone $t = \dfrac{\pi}{4} - x$, e la disequazione $\sin t > 0$ ha le soluzioni $2k\pi < t < \pi + 2k\pi$. Sottraendo $\dfrac{\pi}{4}$ a tutti i membri si ottiene $-\dfrac{\pi}{4} + 2k\pi < -x < \dfrac{3\pi}{4} + 2k\pi$. Moltiplicando per $-1$ il verso delle disuguaglianze cambia, quindi $-\dfrac{3\pi}{4} - 2k\pi < x < \dfrac{\pi}{4} - 2k\pi$. Poiché $-k$ varia in tutto $\mathbb{Z}$ come $k$, le soluzioni sono $-\dfrac{3\pi}{4} + 2k\pi < x < \dfrac{\pi}{4} + 2k\pi$.
