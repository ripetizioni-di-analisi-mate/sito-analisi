Quali sono le soluzioni della disequazione $\sin x\cos x < 0$ nell'intervallo $[0, 2\pi)$?

- $\dfrac{\pi}{2} < x < \pi$ oppure $\dfrac{3\pi}{2} < x < 2\pi$
- $0 < x < \dfrac{\pi}{2}$ oppure $\pi < x < \dfrac{3\pi}{2}$
- $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$
- $\pi < x < 2\pi$

## Spiegazione

Il prodotto è negativo quando i due fattori hanno segni opposti. Nel secondo quadrante il seno è positivo e il coseno è negativo, nel quarto quadrante il seno è negativo e il coseno è positivo. Nel primo e nel terzo quadrante i due fattori hanno lo stesso segno. Quindi in $[0, 2\pi)$ le soluzioni sono $\dfrac{\pi}{2} < x < \pi$ oppure $\dfrac{3\pi}{2} < x < 2\pi$, senza gli zeri dei fattori.
