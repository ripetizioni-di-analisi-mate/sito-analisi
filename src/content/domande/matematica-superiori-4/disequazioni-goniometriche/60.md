Quali sono le soluzioni della disequazione $\cos x - \sqrt{3}\sin x > 0$?

- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{5\pi}{6} + 2k\pi$
- $-\dfrac{5\pi}{6} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{2\pi}{3} + 2k\pi$

## Spiegazione

Si scrive il primo membro come $-\sqrt{3}\sin x + \cos x$, con $a = -\sqrt{3}$ e $b = 1$. Allora $r = \sqrt{3 + 1} = 2$, $\cos\varphi = -\dfrac{\sqrt{3}}{2}$ e $\sin\varphi = \dfrac{1}{2}$, quindi $\varphi = \dfrac{5\pi}{6}$. La disequazione diventa $2\sin\left( x + \dfrac{5\pi}{6} \right) > 0$, e l'argomento deve stare tra $2k\pi$ e $\pi + 2k\pi$. Sottraendo $\dfrac{5\pi}{6}$ si ottiene $-\dfrac{5\pi}{6} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$.
