Con $t = \cos x$ la disequazione $2\cos^2 x - 5\cos x + 2 > 0$ diventa $(2t - 1)(t - 2) > 0$, che vale per $t < \dfrac{1}{2}$ oppure $t > 2$. A quale disequazione in $\cos x$ è equivalente la disequazione di partenza?

- $\cos x < \dfrac{1}{2}$
- $\cos x > \dfrac{1}{2}$
- $\cos x > 2$
- $\cos x < 2$

## Spiegazione

Il coseno assume solo valori dell'intervallo $[-1, 1]$, quindi la condizione $\cos x > 2$ non è soddisfatta per nessun $x$. Perciò la disequazione di partenza equivale alla sola condizione $\cos x < \dfrac{1}{2}$. Le sue soluzioni sono $\dfrac{\pi}{3} + 2k\pi < x < \dfrac{5\pi}{3} + 2k\pi$. La condizione $\cos x < 2$ vale invece per ogni $x$, mentre il trinomio è negativo per $\cos x = 1$.
