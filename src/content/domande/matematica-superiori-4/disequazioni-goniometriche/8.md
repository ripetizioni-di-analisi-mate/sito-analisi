- $\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{4\pi}{3} + 2k\pi$
- $-\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$ oppure $x = 2k\pi$
- $\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{4\pi}{3} + 2k\pi$ oppure $x = 2k\pi$

## Spiegazione

Con la formula di duplicazione $\cos 2x = 2\cos^2 x - 1$ la disequazione diventa $2\cos^2 x - \cos x - 1 \geq 0$. Con $t = \cos x$ si ha $(2t + 1)(t - 1) \geq 0$, che vale per $t \leq -\dfrac{1}{2}$ oppure $t \geq 1$. La condizione $\cos x \leq -\dfrac{1}{2}$ dà $\dfrac{2\pi}{3} + 2k\pi \leq x \leq \dfrac{4\pi}{3} + 2k\pi$. Poiché $\cos x \leq 1$ per ogni $x$, la condizione $\cos x \geq 1$ equivale a $\cos x = 1$, cioè a $x = 2k\pi$, e questi punti sono **soluzioni isolate**.
