- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi < x < \dfrac{13\pi}{6} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \dfrac{11\pi}{6} + 2k\pi$
- $\dfrac{2\pi}{3} + 2k\pi < x < 2\pi + 2k\pi$

## Spiegazione

Con il **metodo dell'angolo aggiunto** si ha $r = \sqrt{1 + 3} = 2$, $\cos\varphi = \dfrac{1}{2}$ e $\sin\varphi = \dfrac{\sqrt{3}}{2}$, quindi $\varphi = \dfrac{\pi}{3}$. La disequazione diventa $2\sin\left( x + \dfrac{\pi}{3} \right) < 1$, cioè $\sin\left( x + \dfrac{\pi}{3} \right) < \dfrac{1}{2}$. L'argomento $x + \dfrac{\pi}{3}$ deve stare tra $\dfrac{5\pi}{6} + 2k\pi$ e $\dfrac{13\pi}{6} + 2k\pi$, dove all'estremo destro si è aggiunto un giro. Sottraendo $\dfrac{\pi}{3}$ si ottiene $\dfrac{\pi}{2} + 2k\pi < x < \dfrac{11\pi}{6} + 2k\pi$.
