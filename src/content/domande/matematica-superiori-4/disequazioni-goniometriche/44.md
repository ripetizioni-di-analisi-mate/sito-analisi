Quali sono le soluzioni della disequazione $\tan x > -1$ nell'intervallo $[0, \pi]$?

- $\dfrac{3\pi}{4} < x \leq \pi$
- $0 \leq x < \dfrac{\pi}{2}$ oppure $\dfrac{3\pi}{4} \leq x \leq \pi$
- $-\dfrac{\pi}{4} < x < \dfrac{\pi}{2}$
- $0 \leq x < \dfrac{\pi}{2}$ oppure $\dfrac{3\pi}{4} < x \leq \pi$

## Spiegazione

Poiché $\arctan(-1) = -\dfrac{\pi}{4}$, su $\mathbb{R}$ le soluzioni sono $-\dfrac{\pi}{4} + k\pi < x < \dfrac{\pi}{2} + k\pi$. Con $k = 0$ si ottiene $\left( -\dfrac{\pi}{4}, \dfrac{\pi}{2} \right)$, che ha in comune con $[0, \pi]$ la parte $0 \leq x < \dfrac{\pi}{2}$. Con $k = 1$ si ottiene $\left( \dfrac{3\pi}{4}, \dfrac{3\pi}{2} \right)$, che ha in comune con $[0, \pi]$ la parte $\dfrac{3\pi}{4} < x \leq \pi$. Gli estremi $0$ e $\pi$ sono soluzioni perché $\tan 0 = \tan\pi = 0 > -1$.
