Quali sono le soluzioni della disequazione $\cos 2x + \sin x > 0$?

- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$, con $x \neq \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{7\pi}{6} + 2k\pi < x < \dfrac{11\pi}{6} + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{5\pi}{6} + 2k\pi$

## Spiegazione

Con la formula di duplicazione $\cos 2x = 1 - 2\sin^2 x$ la disequazione diventa $-2\sin^2 x + \sin x + 1 > 0$, cioè $2\sin^2 x - \sin x - 1 < 0$. Con $t = \sin x$ si ha $(2t + 1)(t - 1) < 0$, che vale per $-\dfrac{1}{2} < t < 1$. La condizione $\sin x > -\dfrac{1}{2}$ dà $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$. La condizione $\sin x < 1$ esclude i punti $x = \dfrac{\pi}{2} + 2k\pi$, nei quali il primo membro vale $\cos\pi + 1 = 0$.
