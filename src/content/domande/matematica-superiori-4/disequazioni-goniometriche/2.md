- $0 \leq x < \dfrac{\pi}{3}$ oppure $\dfrac{5\pi}{3} < x \leq 2\pi$
- $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$
- $0 \leq x < \dfrac{\pi}{6}$ oppure $\dfrac{11\pi}{6} < x \leq 2\pi$
- $-\dfrac{\pi}{3} < x < \dfrac{\pi}{3}$

## Spiegazione

Si isola il coseno e si ottiene $\cos x > \dfrac{1}{2}$. Poiché $\arccos\dfrac{1}{2} = \dfrac{\pi}{3}$, i punti della circonferenza goniometrica con ascissa maggiore di $\dfrac{1}{2}$ formano l'arco da $-\dfrac{\pi}{3}$ a $\dfrac{\pi}{3}$ che passa per $(1, 0)$, quindi su $\mathbb{R}$ le soluzioni sono $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$. Nell'intervallo $[0, 2\pi]$ si prendono $k = 0$, che dà $0 \leq x < \dfrac{\pi}{3}$, e $k = 1$, che dà $\dfrac{5\pi}{3} < x \leq 2\pi$. Gli estremi $0$ e $2\pi$ sono compresi perché $\cos 0 = \cos 2\pi = 1 > \dfrac{1}{2}$.
