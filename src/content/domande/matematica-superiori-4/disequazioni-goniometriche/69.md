Quali sono le soluzioni della disequazione $\cos^2 x - \sin^2 x \geq 2\sin x\cos x$?

- $-\dfrac{3\pi}{8} + k\pi \leq x \leq \dfrac{\pi}{8} + k\pi$
- $\dfrac{\pi}{8} + k\pi \leq x \leq \dfrac{5\pi}{8} + k\pi$
- $-\dfrac{3\pi}{8} + 2k\pi \leq x \leq \dfrac{\pi}{8} + 2k\pi$
- $-\dfrac{3\pi}{4} + 2k\pi \leq x \leq \dfrac{\pi}{4} + 2k\pi$

## Spiegazione

Per le formule di duplicazione $\cos^2 x - \sin^2 x = \cos 2x$ e $2\sin x\cos x = \sin 2x$, quindi la disequazione diventa $\cos 2x - \sin 2x \geq 0$. Con il metodo dell'angolo aggiunto, con $a = -1$ e $b = 1$, si ha $r = \sqrt{2}$ e $\varphi = \dfrac{3\pi}{4}$, perciò $\cos 2x - \sin 2x = \sqrt{2}\sin\left( 2x + \dfrac{3\pi}{4} \right)$. La condizione $\sin\left( 2x + \dfrac{3\pi}{4} \right) \geq 0$ dà $2k\pi \leq 2x + \dfrac{3\pi}{4} \leq \pi + 2k\pi$, cioè $-\dfrac{3\pi}{4} + 2k\pi \leq 2x \leq \dfrac{\pi}{4} + 2k\pi$. Dividendo per $2$ si ottiene $-\dfrac{3\pi}{8} + k\pi \leq x \leq \dfrac{\pi}{8} + k\pi$.
