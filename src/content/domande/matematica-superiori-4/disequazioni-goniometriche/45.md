Quali sono le soluzioni della disequazione $4\sin^2 x - 3 \geq 0$?

- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $-\dfrac{\pi}{3} + k\pi \leq x \leq \dfrac{\pi}{3} + k\pi$
- $\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{5\pi}{6} + k\pi$
- $\dfrac{\pi}{3} + k\pi \leq x \leq \dfrac{2\pi}{3} + k\pi$

## Spiegazione

Con $t = \sin x$ si ottiene $4t^2 - 3 \geq 0$, che vale per $t \leq -\dfrac{\sqrt{3}}{2}$ oppure $t \geq \dfrac{\sqrt{3}}{2}$. La condizione $\sin x \geq \dfrac{\sqrt{3}}{2}$ dà $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$, e la condizione $\sin x \leq -\dfrac{\sqrt{3}}{2}$ dà $\dfrac{4\pi}{3} + 2k\pi \leq x \leq \dfrac{5\pi}{3} + 2k\pi$. Il secondo intervallo si ottiene dal primo aggiungendo $\pi$. Quindi le soluzioni si scrivono $\dfrac{\pi}{3} + k\pi \leq x \leq \dfrac{2\pi}{3} + k\pi$.
