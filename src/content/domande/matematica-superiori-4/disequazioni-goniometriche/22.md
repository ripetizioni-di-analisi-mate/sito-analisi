Quali sono le soluzioni della disequazione $2\sin x + 1 > 0$?

- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$
- $\dfrac{7\pi}{6} + 2k\pi < x < \dfrac{11\pi}{6} + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{5\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{4\pi}{3} + 2k\pi$

## Spiegazione

Si isola il seno e si ottiene $\sin x > -\dfrac{1}{2}$. Poiché $\arcsin\left( -\dfrac{1}{2} \right) = -\dfrac{\pi}{6}$, la retta $y = -\dfrac{1}{2}$ taglia la circonferenza goniometrica nei punti associati a $-\dfrac{\pi}{6}$ e a $\pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}$. I punti che stanno sopra questa retta formano l'arco da $-\dfrac{\pi}{6}$ a $\dfrac{7\pi}{6}$ che passa per $\dfrac{\pi}{2}$. Quindi le soluzioni sono $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{7\pi}{6} + 2k\pi$.
