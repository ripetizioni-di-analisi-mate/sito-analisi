- $\dfrac{\pi}{3} + 2k\pi < x \leq \pi + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi < x < \pi + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \pi + 2k\pi$
- $2k\pi \leq x < \dfrac{\pi}{3} + 2k\pi$

## Spiegazione

L'argomento del logaritmo deve essere positivo e il radicando non negativo, quindi il dominio è l'insieme delle soluzioni del sistema
$$
\begin{cases}
1 - 2\cos x > 0 \\[4pt]
\sin x \geq 0
\end{cases}
$$
In $[0, 2\pi)$ la prima condizione, cioè $\cos x < \dfrac{1}{2}$, vale per $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$, e la seconda vale per $0 \leq x \leq \pi$. L'intersezione è $\dfrac{\pi}{3} < x \leq \pi$. L'estremo $\pi$ è compreso perché $\sqrt{\sin\pi} = 0$ esiste e $1 - 2\cos\pi = 3 > 0$.
