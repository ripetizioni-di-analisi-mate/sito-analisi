Qual è il dominio della funzione $f(x) = \ln(\sin x\cos x)$?

- $2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $k\pi \leq x \leq \dfrac{\pi}{2} + k\pi$
- $k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{2} + k\pi < x < \pi + k\pi$

## Spiegazione

L'argomento del logaritmo deve essere positivo, quindi $\sin x\cos x > 0$. Poiché $\sin x\cos x = \dfrac{1}{2}\sin 2x$, la condizione equivale a $\sin 2x > 0$, cioè a $2k\pi < 2x < \pi + 2k\pi$. Dividendo per $2$ si ottiene $k\pi < x < \dfrac{\pi}{2} + k\pi$. Questi intervalli corrispondono al primo e al terzo quadrante, dove seno e coseno hanno lo stesso segno.
