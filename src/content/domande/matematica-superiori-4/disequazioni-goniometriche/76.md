Quali sono le soluzioni della disequazione $\sin x\tan x \geq 0$?

- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$ oppure $x = \pi + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi \leq x \leq \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi < x < \dfrac{3\pi}{2} + 2k\pi$

## Spiegazione

La tangente è definita per $x \neq \dfrac{\pi}{2} + k\pi$, e in questi punti si ha $\sin x\tan x = \dfrac{\sin^2 x}{\cos x}$. Il numeratore $\sin^2 x$ è positivo per $\sin x \neq 0$ e nullo per $x = k\pi$. Dove $\sin x \neq 0$ il quoziente è positivo se e solo se $\cos x > 0$, cioè per $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$. Gli zeri $x = k\pi$ sono soluzioni, e quelli della forma $\pi + 2k\pi$ non appartengono all'intervallo trovato, quindi si aggiungono come **soluzioni isolate**.
