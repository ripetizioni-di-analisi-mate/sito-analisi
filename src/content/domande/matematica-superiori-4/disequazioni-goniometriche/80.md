Quali sono le soluzioni del sistema
$$
\begin{cases}
\tan x > 0 \\[4pt]
\cos x < \dfrac{1}{2}
\end{cases}
$$
nell'intervallo $[0, 2\pi)$?

- $\dfrac{\pi}{3} < x < \dfrac{\pi}{2}$
- $0 < x < \dfrac{\pi}{3}$ oppure $\pi < x < \dfrac{3\pi}{2}$
- $\dfrac{\pi}{3} < x < \dfrac{3\pi}{2}$
- $\dfrac{\pi}{3} < x < \dfrac{\pi}{2}$ oppure $\pi < x < \dfrac{3\pi}{2}$

## Spiegazione

In $[0, 2\pi)$ la tangente è positiva per $0 < x < \dfrac{\pi}{2}$ e per $\pi < x < \dfrac{3\pi}{2}$, cioè nel primo e nel terzo quadrante. La seconda disequazione ha le soluzioni $\dfrac{\pi}{3} < x < \dfrac{5\pi}{3}$. Il primo intervallo della tangente ha in comune con $\left( \dfrac{\pi}{3}, \dfrac{5\pi}{3} \right)$ la parte $\dfrac{\pi}{3} < x < \dfrac{\pi}{2}$, mentre il secondo è contenuto per intero in $\left( \dfrac{\pi}{3}, \dfrac{5\pi}{3} \right)$. Le soluzioni del sistema sono quindi $\dfrac{\pi}{3} < x < \dfrac{\pi}{2}$ oppure $\pi < x < \dfrac{3\pi}{2}$.
