- $\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{3} + k\pi$
- $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$
- $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$, con $x \neq \dfrac{\pi}{2} + k\pi$

## Spiegazione

La disequazione è omogenea di secondo grado con $a = 1$, $b = 0$ e $c = -3$. Per $\cos x \neq 0$ si divide per $\cos^2 x > 0$ e si ottiene $\tan^2 x - 3 > 0$, cioè $\tan x < -\sqrt{3}$ oppure $\tan x > \sqrt{3}$, che danno $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$ con $x \neq \dfrac{\pi}{2} + k\pi$. Per $\cos x = 0$ il primo membro vale $a = 1 > 0$, quindi anche i valori $x = \dfrac{\pi}{2} + k\pi$ sono soluzioni. Unendo le due parti si ottiene $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$, senza esclusioni.
