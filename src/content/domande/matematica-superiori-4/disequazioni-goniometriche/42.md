Quali sono le soluzioni della disequazione $\cos\left( 2x + \dfrac{\pi}{3} \right) > 0$?

- $-\dfrac{5\pi}{12} + k\pi < x < \dfrac{\pi}{12} + k\pi$
- $-\dfrac{5\pi}{12} + 2k\pi < x < \dfrac{\pi}{12} + 2k\pi$
- $-\dfrac{7\pi}{12} + k\pi < x < -\dfrac{\pi}{12} + k\pi$
- $\dfrac{\pi}{12} + k\pi < x < \dfrac{7\pi}{12} + k\pi$

## Spiegazione

Si pone $t = 2x + \dfrac{\pi}{3}$, e la disequazione $\cos t > 0$ ha le soluzioni $-\dfrac{\pi}{2} + 2k\pi < t < \dfrac{\pi}{2} + 2k\pi$. Sottraendo $\dfrac{\pi}{3}$ a tutti i membri si ottiene $-\dfrac{5\pi}{6} + 2k\pi < 2x < \dfrac{\pi}{6} + 2k\pi$. Dividendo per $2$ si ha $-\dfrac{5\pi}{12} + k\pi < x < \dfrac{\pi}{12} + k\pi$. Il termine $\dfrac{\pi}{3}$ si sottrae prima della divisione perché è sommato a $2x$.
