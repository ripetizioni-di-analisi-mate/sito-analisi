Quali sono le soluzioni della disequazione $\cos^2 x + 2\sin x\cos x \geq 1$?

- $k\pi \leq x \leq \arctan 2 + k\pi$
- $\arctan 2 + k\pi \leq x < \dfrac{\pi}{2} + k\pi$
- $-\arctan 2 + k\pi \leq x \leq k\pi$
- $k\pi \leq x \leq \arctan 2 + k\pi$ oppure $x = \dfrac{\pi}{2} + k\pi$

## Spiegazione

Si scrive $1 = \sin^2 x + \cos^2 x$ e si porta tutto al primo membro, ottenendo $-\sin^2 x + 2\sin x\cos x \geq 0$, che è omogenea con $a = -1$, $b = 2$ e $c = 0$. Per $\cos x \neq 0$ si divide per $\cos^2 x > 0$ e si ha $-\tan^2 x + 2\tan x \geq 0$, cioè $\tan x\,(\tan x - 2) \leq 0$. Questa condizione vale per $0 \leq \tan x \leq 2$, cioè per $k\pi \leq x \leq \arctan 2 + k\pi$. Per $\cos x = 0$ il primo membro della forma omogenea vale $a = -1 < 0$, quindi non si aggiungono altre soluzioni.
