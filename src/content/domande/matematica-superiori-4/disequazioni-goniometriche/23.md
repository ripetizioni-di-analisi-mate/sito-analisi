Quali sono le soluzioni della disequazione $\sin x \leq \dfrac{1}{2}$ nell'intervallo $[0, 2\pi)$?

- $\dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}$
- $0 \leq x \leq \dfrac{\pi}{3}$ oppure $\dfrac{2\pi}{3} \leq x < 2\pi$
- $0 \leq x \leq \dfrac{\pi}{6}$ oppure $\dfrac{5\pi}{6} \leq x < 2\pi$
- $0 \leq x < \dfrac{\pi}{6}$ oppure $\dfrac{5\pi}{6} < x < 2\pi$

## Spiegazione

In $[0, 2\pi)$ l'equazione $\sin x = \dfrac{1}{2}$ ha le soluzioni $\dfrac{\pi}{6}$ e $\dfrac{5\pi}{6}$. Il grafico di $y = \sin x$ sta sopra la retta $y = \dfrac{1}{2}$ tra questi due valori, quindi sta sotto la retta nel resto dell'intervallo. Le soluzioni sono $0 \leq x \leq \dfrac{\pi}{6}$ oppure $\dfrac{5\pi}{6} \leq x < 2\pi$. Gli estremi $\dfrac{\pi}{6}$ e $\dfrac{5\pi}{6}$ sono compresi perché la disuguaglianza è larga.
