- $-\dfrac{\pi}{2} + k\pi < x < \dfrac{\pi}{3} + k\pi$
- $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{3} + k\pi$
- $\dfrac{\pi}{3} + k\pi < x < \dfrac{2\pi}{3} + k\pi$
- $-\dfrac{\pi}{6} + k\pi < x < \dfrac{\pi}{6} + k\pi$

## Spiegazione

Con $t = \tan x$ si ottiene $t^2 - 3 < 0$, che vale per $-\sqrt{3} < t < \sqrt{3}$. Poiché $\arctan\sqrt{3} = \dfrac{\pi}{3}$, $\arctan\left( -\sqrt{3} \right) = -\dfrac{\pi}{3}$ e la tangente è crescente in ogni ramo, si ha $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{3} + k\pi$. Il periodo è $\pi$ perché nella disequazione compare solo la tangente.
