Qual è il dominio della funzione $f(x) = \sqrt{1 - 2\sin x}$?

- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{13\pi}{6} + 2k\pi$
- $\dfrac{5\pi}{6} + 2k\pi < x < \dfrac{13\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{7\pi}{6} + 2k\pi$

## Spiegazione

Il radicando deve essere maggiore o uguale a $0$, quindi $1 - 2\sin x \geq 0$, cioè $\sin x \leq \dfrac{1}{2}$. I punti della circonferenza con ordinata minore o uguale a $\dfrac{1}{2}$ formano l'arco da $\dfrac{5\pi}{6}$ a $\dfrac{\pi}{6} + 2\pi = \dfrac{13\pi}{6}$ che passa per $\dfrac{3\pi}{2}$. Gli estremi sono compresi perché in essi il radicando vale $0$. Il dominio è quindi $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{13\pi}{6} + 2k\pi$.
