Qual è il dominio della funzione $f(x) = \sqrt{\tan x - 1}$?

- $\dfrac{\pi}{4} + k\pi \leq x \leq \dfrac{\pi}{2} + k\pi$
- $-\dfrac{\pi}{2} + k\pi < x \leq \dfrac{\pi}{4} + k\pi$
- $\dfrac{\pi}{4} + 2k\pi \leq x < \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$

## Spiegazione

La funzione richiede che la tangente sia definita e che il radicando sia maggiore o uguale a $0$, quindi $x \neq \dfrac{\pi}{2} + k\pi$ e $\tan x \geq 1$. Poiché $\arctan 1 = \dfrac{\pi}{4}$ e la tangente è crescente in ogni ramo, la condizione $\tan x \geq 1$ vale per $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$. L'estremo $\dfrac{\pi}{2} + k\pi$ è escluso perché in esso la tangente non è definita. Il periodo del dominio è $\pi$, il periodo della tangente.
