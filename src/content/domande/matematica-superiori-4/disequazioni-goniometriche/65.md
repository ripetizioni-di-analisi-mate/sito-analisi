Quali sono le soluzioni della disequazione $\sin^2 x + 2\sin x\cos x - 3\cos^2 x \leq 0$?

- $-\arctan 3 + k\pi \leq x \leq \dfrac{\pi}{4} + k\pi$
- $-\dfrac{\pi}{4} + k\pi \leq x \leq \arctan 3 + k\pi$
- $-\arctan 3 + 2k\pi \leq x \leq \dfrac{\pi}{4} + 2k\pi$
- $\dfrac{\pi}{4} + k\pi \leq x < \dfrac{\pi}{2} + k\pi$

## Spiegazione

La disequazione è omogenea con $a = 1$, $b = 2$ e $c = -3$. Per $\cos x \neq 0$ si divide per $\cos^2 x > 0$ e si ottiene $\tan^2 x + 2\tan x - 3 \leq 0$, cioè $(\tan x + 3)(\tan x - 1) \leq 0$. Questa condizione vale per $-3 \leq \tan x \leq 1$, cioè per $-\arctan 3 + k\pi \leq x \leq \dfrac{\pi}{4} + k\pi$, perché $\arctan(-3) = -\arctan 3$. Per $\cos x = 0$ il primo membro vale $a = 1$, che non è minore o uguale a $0$, quindi non si aggiungono altre soluzioni.
