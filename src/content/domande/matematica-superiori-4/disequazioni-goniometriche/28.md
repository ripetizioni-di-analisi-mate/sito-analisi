Quali sono le soluzioni della disequazione $\cos x \leq \dfrac{\sqrt{2}}{2}$?

- $-\dfrac{\pi}{4} + 2k\pi \leq x \leq \dfrac{\pi}{4} + 2k\pi$
- $\dfrac{\pi}{4} + 2k\pi \leq x \leq \dfrac{3\pi}{4} + 2k\pi$
- $\dfrac{\pi}{4} + 2k\pi \leq x \leq \dfrac{7\pi}{4} + 2k\pi$
- $\dfrac{3\pi}{4} + 2k\pi \leq x \leq \dfrac{5\pi}{4} + 2k\pi$

## Spiegazione

Poiché $\arccos\dfrac{\sqrt{2}}{2} = \dfrac{\pi}{4}$, la retta verticale di ascissa $\dfrac{\sqrt{2}}{2}$ taglia la circonferenza goniometrica nei punti associati a $\dfrac{\pi}{4}$ e a $2\pi - \dfrac{\pi}{4} = \dfrac{7\pi}{4}$. I punti con ascissa minore o uguale a $\dfrac{\sqrt{2}}{2}$ stanno a sinistra di questa retta o su di essa, e formano l'arco da $\dfrac{\pi}{4}$ a $\dfrac{7\pi}{4}$ che passa per $\pi$. Quindi le soluzioni sono $\dfrac{\pi}{4} + 2k\pi \leq x \leq \dfrac{7\pi}{4} + 2k\pi$, con gli estremi compresi.
