- $2k\pi < x < \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{12} + k\pi < x < \dfrac{5\pi}{12} + k\pi$
- $k\pi < x < \dfrac{\pi}{3} + k\pi$
- $k\pi < x < \dfrac{2\pi}{3} + k\pi$

## Spiegazione

Si pone $t = 2x + \dfrac{\pi}{6}$. La disequazione $\sin t > \dfrac{1}{2}$ ha le soluzioni $\dfrac{\pi}{6} + 2k\pi < t < \dfrac{5\pi}{6} + 2k\pi$. Sottraendo $\dfrac{\pi}{6}$ a tutti i membri si ottiene $2k\pi < 2x < \dfrac{2\pi}{3} + 2k\pi$. Dividendo per $2$ si ha $k\pi < x < \dfrac{\pi}{3} + k\pi$, perché anche il periodo $2k\pi$ si divide per $2$.
