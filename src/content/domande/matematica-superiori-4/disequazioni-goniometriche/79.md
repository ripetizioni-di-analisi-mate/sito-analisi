Quali sono le soluzioni del sistema seguente?
$$
\begin{cases}
\cos x > 0 \\[4pt]
\sin x < \dfrac{1}{2}
\end{cases}
$$

- $\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{5\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$

## Spiegazione

Si lavora nell'intervallo $[-\pi, \pi)$, che ha ampiezza $2\pi$. La prima disequazione ha le soluzioni $-\dfrac{\pi}{2} < x < \dfrac{\pi}{2}$. La seconda ha le soluzioni $-\pi \leq x < \dfrac{\pi}{6}$ e $\dfrac{5\pi}{6} < x < \pi$, perché il seno è maggiore o uguale a $\dfrac{1}{2}$ solo tra $\dfrac{\pi}{6}$ e $\dfrac{5\pi}{6}$. L'intersezione è $-\dfrac{\pi}{2} < x < \dfrac{\pi}{6}$, e aggiungendo il periodo $2\pi$ si ottengono le soluzioni del sistema.
