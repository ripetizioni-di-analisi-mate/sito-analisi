Quali sono le soluzioni della disequazione $\sin x + \cos x > 0$?

- $\dfrac{\pi}{4} + 2k\pi < x < \dfrac{5\pi}{4} + 2k\pi$
- $-\dfrac{\pi}{4} + 2k\pi < x < \dfrac{3\pi}{4} + 2k\pi$
- $\dfrac{3\pi}{4} + 2k\pi < x < \dfrac{7\pi}{4} + 2k\pi$
- $-\dfrac{\pi}{4} + k\pi < x < \dfrac{3\pi}{4} + k\pi$

## Spiegazione

Con il **metodo dell'angolo aggiunto** si ha $r = \sqrt{1 + 1} = \sqrt{2}$ e $\cos\varphi = \sin\varphi = \dfrac{\sqrt{2}}{2}$, quindi $\varphi = \dfrac{\pi}{4}$. La disequazione diventa $\sqrt{2}\sin\left( x + \dfrac{\pi}{4} \right) > 0$, cioè $\sin\left( x + \dfrac{\pi}{4} \right) > 0$. L'argomento deve stare tra $2k\pi$ e $\pi + 2k\pi$. Sottraendo $\dfrac{\pi}{4}$ si ottiene $-\dfrac{\pi}{4} + 2k\pi < x < \dfrac{3\pi}{4} + 2k\pi$.
