- $\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $-\dfrac{\pi}{2} + k\pi < x < \dfrac{\pi}{3} + k\pi$
- $-\dfrac{\pi}{2} + k\pi < x < \dfrac{\pi}{6} + k\pi$
- $-\dfrac{\pi}{3} + k\pi < x < \dfrac{\pi}{3} + k\pi$

## Spiegazione

La tangente è crescente in ogni intervallo $\left( -\dfrac{\pi}{2} + k\pi, \dfrac{\pi}{2} + k\pi \right)$ e $\arctan\sqrt{3} = \dfrac{\pi}{3}$. Quindi in ogni ramo la tangente è minore di $\sqrt{3}$ dall'asintoto $-\dfrac{\pi}{2} + k\pi$ fino a $\dfrac{\pi}{3} + k\pi$. L'estremo $\dfrac{\pi}{3} + k\pi$ è escluso perché la disuguaglianza è stretta, l'estremo $-\dfrac{\pi}{2} + k\pi$ perché la tangente non vi è definita. Il periodo delle soluzioni è $\pi$, il periodo della tangente.
