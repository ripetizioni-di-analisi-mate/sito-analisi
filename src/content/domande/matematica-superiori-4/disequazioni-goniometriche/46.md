Quali sono le soluzioni della disequazione $\sin^2 x - \sin x < 0$?

- $2k\pi < x < \pi + 2k\pi$
- $2k\pi < x < \pi + 2k\pi$, con $x \neq \dfrac{\pi}{2} + 2k\pi$
- $\pi + 2k\pi < x < 2\pi + 2k\pi$
- $2k\pi < x < \dfrac{\pi}{2} + 2k\pi$

## Spiegazione

Si raccoglie $\sin x$ e si ottiene $\sin x\,(\sin x - 1) < 0$. Con $t = \sin x$ il prodotto $t\,(t - 1)$ è negativo per $0 < t < 1$. La condizione $\sin x > 0$ dà $2k\pi < x < \pi + 2k\pi$, mentre la condizione $\sin x < 1$ esclude i soli punti $x = \dfrac{\pi}{2} + 2k\pi$, dove il seno vale $1$. Le soluzioni sono quindi $2k\pi < x < \pi + 2k\pi$, con $x \neq \dfrac{\pi}{2} + 2k\pi$.
