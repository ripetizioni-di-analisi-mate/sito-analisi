Quali sono le soluzioni della disequazione $\sin x - \cos x \leq -1$?

- $\pi + 2k\pi \leq x \leq \dfrac{3\pi}{2} + 2k\pi$
- $\dfrac{3\pi}{2} + 2k\pi \leq x \leq 2\pi + 2k\pi$
- $\dfrac{5\pi}{4} + 2k\pi \leq x \leq \dfrac{7\pi}{4} + 2k\pi$
- $\dfrac{\pi}{2} + 2k\pi \leq x \leq \pi + 2k\pi$

## Spiegazione

Per la formula dell'angolo aggiunto $\sin x - \cos x = \sqrt{2}\sin\left( x - \dfrac{\pi}{4} \right)$, quindi la disequazione diventa $\sin\left( x - \dfrac{\pi}{4} \right) \leq -\dfrac{1}{\sqrt{2}} = -\dfrac{\sqrt{2}}{2}$. L'argomento deve stare tra $\dfrac{5\pi}{4} + 2k\pi$ e $\dfrac{7\pi}{4} + 2k\pi$, estremi compresi. Aggiungendo $\dfrac{\pi}{4}$ si ottiene $\dfrac{3\pi}{2} + 2k\pi \leq x \leq 2\pi + 2k\pi$. Per $x = 2\pi$ si ha infatti $\sin x - \cos x = 0 - 1 = -1$.
