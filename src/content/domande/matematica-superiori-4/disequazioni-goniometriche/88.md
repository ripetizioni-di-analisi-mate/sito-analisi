Qual è il dominio della funzione $f(x) = \arcsin(2\sin x)$?

- $-\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{\pi}{6} + 2k\pi$
- $\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{5\pi}{6} + k\pi$
- $-\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{\pi}{6} + k\pi$
- Ogni $x$ reale

## Spiegazione

L'argomento dell'arcoseno deve stare in $[-1, 1]$, quindi $-1 \leq 2\sin x \leq 1$, cioè $-\dfrac{1}{2} \leq \sin x \leq \dfrac{1}{2}$. I punti della circonferenza con ordinata compresa tra $-\dfrac{1}{2}$ e $\dfrac{1}{2}$ formano due archi, uno da $-\dfrac{\pi}{6}$ a $\dfrac{\pi}{6}$ e uno da $\dfrac{5\pi}{6}$ a $\dfrac{7\pi}{6}$. Il secondo arco si ottiene dal primo aggiungendo $\pi$. Quindi il dominio è $-\dfrac{\pi}{6} + k\pi \leq x \leq \dfrac{\pi}{6} + k\pi$.
