Quali sono le soluzioni della disequazione $\cos\left( x - \dfrac{\pi}{4} \right) > 0$?

- $-\dfrac{3\pi}{4} + 2k\pi < x < \dfrac{\pi}{4} + 2k\pi$
- $-\dfrac{\pi}{2} + 2k\pi < x < \dfrac{\pi}{2} + 2k\pi$
- $\dfrac{3\pi}{4} + 2k\pi < x < \dfrac{7\pi}{4} + 2k\pi$
- $-\dfrac{\pi}{4} + 2k\pi < x < \dfrac{3\pi}{4} + 2k\pi$

## Spiegazione

Si pone $t = x - \dfrac{\pi}{4}$. La disequazione $\cos t > 0$ ha le soluzioni $-\dfrac{\pi}{2} + 2k\pi < t < \dfrac{\pi}{2} + 2k\pi$, perché il coseno è positivo nel primo e nel quarto quadrante. Aggiungendo $\dfrac{\pi}{4}$ a tutti i membri si ottiene $-\dfrac{\pi}{4} + 2k\pi < x < \dfrac{3\pi}{4} + 2k\pi$. Per $x = 0$ si ha $\cos\left( -\dfrac{\pi}{4} \right) = \dfrac{\sqrt{2}}{2} > 0$, e infatti $0$ appartiene all'intervallo con $k = 0$.
