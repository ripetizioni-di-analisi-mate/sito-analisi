Quali sono le soluzioni del sistema
$$
\begin{cases}
\sin 2x > 0 \\[4pt]
\cos x < 0
\end{cases}
$$
nell'intervallo $[0, 2\pi)$?

- $\dfrac{\pi}{2} < x < \pi$
- $\pi < x < \dfrac{3\pi}{2}$
- $0 < x < \dfrac{\pi}{2}$ oppure $\pi < x < \dfrac{3\pi}{2}$
- $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$

## Spiegazione

Con $t = 2x$ la disequazione $\sin 2x > 0$ dà $k\pi < x < \dfrac{\pi}{2} + k\pi$, quindi in $[0, 2\pi)$ le soluzioni sono $0 < x < \dfrac{\pi}{2}$ e $\pi < x < \dfrac{3\pi}{2}$. La seconda disequazione ha le soluzioni $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$. Il primo intervallo non ha punti in comune con $\left( \dfrac{\pi}{2}, \dfrac{3\pi}{2} \right)$, mentre il secondo è contenuto in esso. Quindi le soluzioni del sistema sono $\pi < x < \dfrac{3\pi}{2}$, gli angoli del terzo quadrante.
