Quali sono le soluzioni della disequazione $\sin^2 x - \sin x\cos x > 0$?

- $\dfrac{\pi}{4} + k\pi < x < \pi + k\pi$, con $x \neq \dfrac{\pi}{2} + k\pi$
- $k\pi < x < \dfrac{\pi}{4} + k\pi$
- $\dfrac{\pi}{4} + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{4} + k\pi < x < \pi + k\pi$

## Spiegazione

La disequazione è omogenea con $a = 1$, $b = -1$ e $c = 0$. Per $\cos x \neq 0$ si divide per $\cos^2 x > 0$ e si ottiene $\tan^2 x - \tan x > 0$, cioè $\tan x < 0$ oppure $\tan x > 1$. In ogni ramo queste condizioni danno $\dfrac{\pi}{4} + k\pi < x < \dfrac{\pi}{2} + k\pi$ e $\dfrac{\pi}{2} + k\pi < x < \pi + k\pi$. Per $\cos x = 0$ il primo membro vale $a = 1 > 0$, quindi anche i punti $\dfrac{\pi}{2} + k\pi$ sono soluzioni. Unendo si ottiene $\dfrac{\pi}{4} + k\pi < x < \pi + k\pi$.
