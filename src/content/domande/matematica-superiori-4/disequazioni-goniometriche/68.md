Quali sono le soluzioni della disequazione $\sin^2 x - 3\sin x\cos x + 2\cos^2 x < 0$?

- $\dfrac{\pi}{4} + k\pi < x < \arctan 2 + k\pi$
- $\dfrac{\pi}{4} + k\pi < x \leq \arctan 2 + k\pi$
- $\arctan 2 + k\pi < x < \dfrac{\pi}{2} + k\pi$
- $\dfrac{\pi}{4} + 2k\pi < x < \arctan 2 + 2k\pi$

## Spiegazione

La disequazione è omogenea con $a = 1$, $b = -3$ e $c = 2$. Per $\cos x \neq 0$ si divide per $\cos^2 x > 0$ e si ottiene $\tan^2 x - 3\tan x + 2 < 0$, cioè $(\tan x - 1)(\tan x - 2) < 0$, che vale per $1 < \tan x < 2$. Poiché la tangente è crescente in ogni ramo, si ha $\dfrac{\pi}{4} + k\pi < x < \arctan 2 + k\pi$. Per $\cos x = 0$ il primo membro vale $a = 1$, che non è negativo, quindi non si aggiungono altre soluzioni.
