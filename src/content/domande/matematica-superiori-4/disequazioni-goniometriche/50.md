Quali sono le soluzioni della disequazione $\cos 2x + 3\sin x - 2 \geq 0$?

- $\dfrac{5\pi}{6} + 2k\pi \leq x \leq \dfrac{13\pi}{6} + 2k\pi$
- $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi \leq x \leq \dfrac{2\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{2} + 2k\pi$

## Spiegazione

Con $\cos 2x = 1 - 2\sin^2 x$ la disequazione diventa $-2\sin^2 x + 3\sin x - 1 \geq 0$, cioè $2\sin^2 x - 3\sin x + 1 \leq 0$. Con $t = \sin x$ il trinomio si scompone in $(2t - 1)(t - 1)$, che è minore o uguale a $0$ per $\dfrac{1}{2} \leq t \leq 1$. La condizione $\sin x \leq 1$ vale per ogni $x$, quindi resta $\sin x \geq \dfrac{1}{2}$. Le soluzioni sono $\dfrac{\pi}{6} + 2k\pi \leq x \leq \dfrac{5\pi}{6} + 2k\pi$.
