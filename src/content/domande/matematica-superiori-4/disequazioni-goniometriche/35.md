Quali sono le soluzioni della disequazione $\tan x < -\sqrt{3}$ nell'intervallo $[0, 2\pi)$?

- $\dfrac{2\pi}{3} < x < \pi$ oppure $\dfrac{5\pi}{3} < x < 2\pi$
- $\dfrac{\pi}{2} < x < \dfrac{2\pi}{3}$ oppure $\dfrac{3\pi}{2} < x < \dfrac{5\pi}{3}$
- $\dfrac{\pi}{2} < x < \dfrac{5\pi}{6}$ oppure $\dfrac{3\pi}{2} < x < \dfrac{11\pi}{6}$
- $\dfrac{\pi}{2} < x < \dfrac{2\pi}{3}$

## Spiegazione

Poiché $\arctan\left( -\sqrt{3} \right) = -\dfrac{\pi}{3}$, su $\mathbb{R}$ le soluzioni sono $-\dfrac{\pi}{2} + k\pi < x < -\dfrac{\pi}{3} + k\pi$. Il periodo della tangente è $\pi$, quindi in $[0, 2\pi)$ cadono due intervalli. Con $k = 1$ si ottiene $\dfrac{\pi}{2} < x < \dfrac{2\pi}{3}$, con $k = 2$ si ottiene $\dfrac{3\pi}{2} < x < \dfrac{5\pi}{3}$.
