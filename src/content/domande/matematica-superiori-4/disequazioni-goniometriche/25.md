Quali sono le soluzioni della disequazione $2\sin x \geq -\sqrt{3}$ nell'intervallo $[0, 2\pi)$?

- $\dfrac{4\pi}{3} \leq x \leq \dfrac{5\pi}{3}$
- $0 \leq x \leq \dfrac{4\pi}{3}$ oppure $\dfrac{5\pi}{3} \leq x < 2\pi$
- $0 \leq x \leq \dfrac{7\pi}{6}$ oppure $\dfrac{11\pi}{6} \leq x < 2\pi$
- $0 \leq x < \dfrac{4\pi}{3}$ oppure $\dfrac{5\pi}{3} < x < 2\pi$

## Spiegazione

Dividendo per $2$ si ottiene $\sin x \geq -\dfrac{\sqrt{3}}{2}$. In $[0, 2\pi)$ l'equazione $\sin x = -\dfrac{\sqrt{3}}{2}$ ha le soluzioni $\dfrac{4\pi}{3}$ e $\dfrac{5\pi}{3}$, nel terzo e nel quarto quadrante. Il grafico del seno sta sotto la retta $y = -\dfrac{\sqrt{3}}{2}$ solo tra questi due valori, quindi sta sopra la retta o la tocca per $0 \leq x \leq \dfrac{4\pi}{3}$ e per $\dfrac{5\pi}{3} \leq x < 2\pi$. Gli estremi $\dfrac{4\pi}{3}$ e $\dfrac{5\pi}{3}$ sono compresi perché la disuguaglianza è larga.
