Quali sono le soluzioni della disequazione $2\cos^2 x + 3\cos x - 2 > 0$?

- $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$
- $\dfrac{\pi}{3} + 2k\pi < x < \dfrac{5\pi}{3} + 2k\pi$
- $-\dfrac{\pi}{6} + 2k\pi < x < \dfrac{\pi}{6} + 2k\pi$
- $\dfrac{2\pi}{3} + 2k\pi < x < \dfrac{4\pi}{3} + 2k\pi$

## Spiegazione

Con $t = \cos x$ si ottiene $2t^2 + 3t - 2 > 0$. Il trinomio ha le radici $\dfrac{1}{2}$ e $-2$, quindi $2t^2 + 3t - 2 = (2t - 1)(t + 2)$, che è positivo per $t < -2$ oppure $t > \dfrac{1}{2}$. Poiché $\cos x \geq -1$ per ogni $x$, la condizione $\cos x < -2$ non ha soluzioni. Resta $\cos x > \dfrac{1}{2}$, cioè $-\dfrac{\pi}{3} + 2k\pi < x < \dfrac{\pi}{3} + 2k\pi$.
