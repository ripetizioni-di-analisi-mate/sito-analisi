Quali sono le soluzioni della disequazione $3^{x^2} \leq 81$?

- $x \leq 2$
- $x \leq -2$ oppure $x \geq 2$
- $-4 \leq x \leq 4$
- $-2 \leq x \leq 2$

## Spiegazione

Poiché $81 = 3^4$, la disequazione si scrive $3^{x^2} \leq 3^4$. La base $3$ è maggiore di $1$, quindi il verso si conserva e si ottiene $x^2 \leq 4$. Perciò le soluzioni sono $-2 \leq x \leq 2$.
