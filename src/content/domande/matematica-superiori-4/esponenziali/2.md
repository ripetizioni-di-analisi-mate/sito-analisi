- $2^{1{,}7} < 4^{0{,}8} < 2^{\sqrt{3}} < \left( \dfrac{1}{2} \right)^{-2}$
- $4^{0{,}8} < 2^{1{,}7} < 2^{\sqrt{3}} < \left( \dfrac{1}{2} \right)^{-2}$
- $\left( \dfrac{1}{2} \right)^{-2} < 4^{0{,}8} < 2^{1{,}7} < 2^{\sqrt{3}}$
- $4^{0{,}8} < 2^{\sqrt{3}} < 2^{1{,}7} < \left( \dfrac{1}{2} \right)^{-2}$

## Spiegazione

Si scrivono i quattro numeri come potenze di base $2$. Poiché $4 = 2^2$, vale $4^{0{,}8} = 2^{1{,}6}$; poiché $\dfrac{1}{2} = 2^{-1}$, vale $\left( \dfrac{1}{2} \right)^{-2} = 2^{2}$. Gli esponenti sono quindi $1{,}6$, $1{,}7$, $\sqrt{3} \approx 1{,}732$ e $2$. La base $2$ è maggiore di $1$, perciò per il **confronto tra potenze con la stessa base** le potenze sono nello stesso ordine degli esponenti, e si ottiene $4^{0{,}8} < 2^{1{,}7} < 2^{\sqrt{3}} < \left( \dfrac{1}{2} \right)^{-2}$.
