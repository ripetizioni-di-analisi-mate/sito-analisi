Per quali valori di $x$ il triangolo di lati $3$, $4$, $x$, con $x > 4$, è ottusangolo?

- $x > 5$
- $4 < x < 5$
- $5 < x < 7$
- $4 < x < 7$

## Spiegazione

Il lato maggiore è $x$, quindi il triangolo è ottusangolo se e solo se l'angolo opposto a $x$ è ottuso, cioè se $x^2 > 3^2 + 4^2 = 25$. Con $x > 4$ questa condizione equivale a $x > 5$. Per la disuguaglianza triangolare deve valere inoltre $x < 3 + 4 = 7$. Perciò il triangolo è ottusangolo per $5 < x < 7$.
