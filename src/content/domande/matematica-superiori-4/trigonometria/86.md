Un triangolo isoscele ha gli angoli alla base di ampiezza $x$, in radianti. Quali sono le limitazioni geometriche per $x$?

- $0 < x < \pi$
- $0 < x < \dfrac{\pi}{3}$
- $\dfrac{\pi}{4} < x < \dfrac{\pi}{2}$
- $0 < x < \dfrac{\pi}{2}$

## Spiegazione

L'angolo al vertice misura $\pi - 2x$, perché la somma degli angoli di un triangolo è $\pi$. Gli angoli di un triangolo sono positivi, quindi devono essere soddisfatte insieme le condizioni
$$
\begin{cases}
x > 0 \\
\pi - 2x > 0 .
\end{cases}
$$
La seconda condizione equivale a $x < \dfrac{\pi}{2}$, perciò le limitazioni sono $0 < x < \dfrac{\pi}{2}$.
