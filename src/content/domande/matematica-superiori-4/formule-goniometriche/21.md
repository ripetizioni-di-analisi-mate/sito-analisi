Per ogni $x$ reale, quale espressione è uguale a $\sin\left( x + \dfrac{\pi}{4} \right)$?

- $\dfrac{\sqrt{2}}{2}\left( \sin x - \cos x \right)$
- $\sqrt{2}\left( \sin x + \cos x \right)$
- $\sin x + \cos x$
- $\dfrac{\sqrt{2}}{2}\left( \sin x + \cos x \right)$

## Spiegazione

Per la formula del **seno della somma**
$$
\sin\left( x + \frac{\pi}{4} \right) = \sin x\cos\frac{\pi}{4} + \cos x\sin\frac{\pi}{4} .
$$
Poiché $\cos\dfrac{\pi}{4} = \sin\dfrac{\pi}{4} = \dfrac{\sqrt{2}}{2}$, raccogliendo si ottiene $\dfrac{\sqrt{2}}{2}\left( \sin x + \cos x \right)$. L'espressione con $\sin x - \cos x$ è invece $\sin\left( x - \dfrac{\pi}{4} \right)$.
