Quali sono le soluzioni della disequazione $\left( \log_2 x \right)^2 < 4$?

- $0 < x < 4$
- $-2 < x < 2$
- $\dfrac{1}{4} < x < 4$
- $0 < x < \dfrac{1}{4}$ oppure $x > 4$

## Spiegazione

La condizione di esistenza è $x > 0$. Si pone $t = \log_2 x$ e si risolve $t^2 < 4$, che è verificata per $-2 < t < 2$.

La base $2$ è maggiore di $1$, quindi il verso si conserva e $-2 < \log_2 x < 2$ equivale a $2^{-2} < x < 2^2$.

Perciò le soluzioni sono $\dfrac{1}{4} < x < 4$.
