Siano $a = \log_2 5$, $b = \log_3 5$ e $c = \log_{\frac{1}{2}} 5$. Quale ordinamento è corretto?

- $b < a < c$
- $c < a < b$
- $c < b < a$
- $a < b < c$

## Spiegazione

Il numero $c$ ha base minore di $1$ e argomento maggiore di $1$, quindi è negativo; infatti $c = -\log_2 5$.

I numeri $a$ e $b$ sono positivi. Poiché $2^2 = 4 < 5 < 8 = 2^3$, si ha $2 < a < 3$. Poiché $3 < 5 < 9$, si ha $1 < b < 2$.

Perciò l'ordinamento corretto è $c < b < a$.
