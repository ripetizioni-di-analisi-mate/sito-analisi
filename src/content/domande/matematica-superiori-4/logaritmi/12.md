- $\dfrac{1}{e} \leq x \leq e$
- $-1 < x \leq 1$
- $\dfrac{1}{e} < x \leq e$
- $0 < x \leq e$

## Spiegazione

La condizione di esistenza è $x > 0$, e il denominatore deve essere diverso da $0$. Si pone $t = \ln x$ e si studia $\dfrac{t - 1}{t + 1} \leq 0$.

Il numeratore si annulla per $t = 1$ e il denominatore per $t = -1$, quindi il quoziente è negativo o nullo per $-1 < t \leq 1$. L'estremo $t = -1$ è escluso perché annulla il denominatore.

Poiché il logaritmo naturale è crescente, $-1 < \ln x \leq 1$ equivale a $e^{-1} < x \leq e$. Perciò le soluzioni sono $\dfrac{1}{e} < x \leq e$.
