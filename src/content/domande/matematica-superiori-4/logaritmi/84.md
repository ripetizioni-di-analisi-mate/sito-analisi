Quali sono le soluzioni della disequazione $\ln (2x - 1) \leq \ln (x + 3)$?

- $x \leq 4$
- $\dfrac{1}{2} < x \leq 4$
- $-3 < x \leq 4$
- $x \geq 4$

## Spiegazione

Il logaritmo naturale è crescente, quindi il verso si conserva. Il sistema contiene le condizioni di esistenza e la disuguaglianza tra gli argomenti:
$$
\begin{cases}
2x - 1 > 0 \\[4pt]
x + 3 > 0 \\[4pt]
2x - 1 \leq x + 3
\end{cases}
\iff
\begin{cases}
x > \dfrac{1}{2} \\[4pt]
x > -3 \\[4pt]
x \leq 4 .
\end{cases}
$$
Perciò le soluzioni sono $\dfrac{1}{2} < x \leq 4$.
