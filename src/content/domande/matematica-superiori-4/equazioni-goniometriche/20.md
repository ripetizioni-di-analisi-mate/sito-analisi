Quali sono le soluzioni dell'equazione $2\sin x - \sqrt{3} = 0$?

- $x = \pm\dfrac{\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{6} + 2k\pi$ oppure $x = \dfrac{5\pi}{6} + 2k\pi$
- $x = \dfrac{\pi}{3} + 2k\pi$ oppure $x = \dfrac{4\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{3} + 2k\pi$ oppure $x = \dfrac{2\pi}{3} + 2k\pi$

## Spiegazione

Si isola il seno e si ottiene $\sin x = \dfrac{\sqrt{3}}{2}$. Poiché $\arcsin\dfrac{\sqrt{3}}{2} = \dfrac{\pi}{3}$, la prima famiglia è $x = \dfrac{\pi}{3} + 2k\pi$. La seconda famiglia è $x = \pi - \dfrac{\pi}{3} + 2k\pi = \dfrac{2\pi}{3} + 2k\pi$. I due angoli stanno nel primo e nel secondo quadrante, dove il seno è positivo.
