Quali sono le soluzioni dell'equazione $2\cos^2 x + \cos x = 0$?

- $x = \pm\dfrac{2\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{2} + k\pi$ oppure $x = \pm\dfrac{\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{2} + k\pi$ oppure $x = \pm\dfrac{2\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{2} + 2k\pi$ oppure $x = \pm\dfrac{2\pi}{3} + 2k\pi$

## Spiegazione

Si raccoglie $\cos x$ e si ottiene $\cos x\,(2\cos x + 1) = 0$. Per la legge di annullamento del prodotto si ha $\cos x = 0$ oppure $\cos x = -\dfrac{1}{2}$. La prima equazione dà $x = \dfrac{\pi}{2} + k\pi$. La seconda dà $x = \pm\dfrac{2\pi}{3} + 2k\pi$, perché $\arccos\left(-\dfrac{1}{2}\right) = \dfrac{2\pi}{3}$.
