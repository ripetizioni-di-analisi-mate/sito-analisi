Quali sono le soluzioni dell'equazione $\tan^2 x - 2\tan x - 3 = 0$?

- $x = \arctan 3 + k\pi$ oppure $x = \dfrac{\pi}{4} + k\pi$
- $x = \arctan 3 + k\pi$ oppure $x = -\dfrac{\pi}{4} + k\pi$
- $x = -\arctan 3 + k\pi$ oppure $x = \dfrac{\pi}{4} + k\pi$
- $x = \arctan 3 + 2k\pi$ oppure $x = -\dfrac{\pi}{4} + 2k\pi$

## Spiegazione

Con $t = \tan x$ si ottiene $t^2 - 2t - 3 = 0$, cioè $(t - 3)(t + 1) = 0$. Le soluzioni $t = 3$ e $t = -1$ sono entrambe accettabili, perché la tangente assume tutti i valori reali. L'equazione $\tan x = 3$ dà $x = \arctan 3 + k\pi$, e l'equazione $\tan x = -1$ dà $x = -\dfrac{\pi}{4} + k\pi$.
