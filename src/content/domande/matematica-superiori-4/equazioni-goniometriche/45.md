Quali sono le soluzioni dell'equazione $\sin x = \cos (2x)$?

- $x = \dfrac{\pi}{6} + 2k\pi$
- $x = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$
- $x = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$ oppure $x = \dfrac{\pi}{2} + 2k\pi$
- $x = \dfrac{\pi}{6} + \dfrac{k\pi}{3}$

## Spiegazione

Per la formula degli archi associati $\cos(2x) = \sin\left(\dfrac{\pi}{2} - 2x\right)$, quindi l'equazione diventa $\sin x = \sin\left(\dfrac{\pi}{2} - 2x\right)$. La prima famiglia dà $x = \dfrac{\pi}{2} - 2x + 2k\pi$, cioè $3x = \dfrac{\pi}{2} + 2k\pi$ e $x = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$. La seconda dà $x = \pi - \dfrac{\pi}{2} + 2x + 2k\pi$, cioè $x = -\dfrac{\pi}{2} - 2k\pi$, che si scrive anche $x = -\dfrac{\pi}{2} + 2k\pi$. Questi valori sono già contenuti nella prima famiglia, che per $k = -1$ dà $-\dfrac{\pi}{2}$, quindi le soluzioni sono $x = \dfrac{\pi}{6} + \dfrac{2k\pi}{3}$.
