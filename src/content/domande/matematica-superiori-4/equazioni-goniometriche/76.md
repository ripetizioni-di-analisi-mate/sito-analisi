Quali sono le soluzioni dell'equazione $\sin^2 x + \sin x\cos x = 0$?

- $x = -\dfrac{\pi}{4} + k\pi$
- $x = k\pi$ oppure $x = \dfrac{\pi}{4} + k\pi$
- $x = \dfrac{\pi}{2} + k\pi$ oppure $x = -\dfrac{\pi}{4} + k\pi$
- $x = k\pi$ oppure $x = -\dfrac{\pi}{4} + k\pi$

## Spiegazione

Il coefficiente di $\sin^2 x$ è $1 \neq 0$, quindi i punti con $\cos x = 0$ non sono soluzioni e si può dividere per $\cos^2 x$. Si ottiene $\tan^2 x + \tan x = 0$, cioè $\tan x\,(\tan x + 1) = 0$. Perciò $\tan x = 0$ oppure $\tan x = -1$. La prima equazione dà $x = k\pi$ e la seconda dà $x = -\dfrac{\pi}{4} + k\pi$.
