Quali sono le soluzioni dell'equazione $\sin x\cos x = \dfrac{\sqrt{3}}{4}$?

- $x = \dfrac{\pi}{6} + 2k\pi$ oppure $x = \dfrac{\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{6} + k\pi$ oppure $x = \dfrac{\pi}{3} + k\pi$
- $x = \dfrac{\pi}{3} + k\pi$ oppure $x = \dfrac{2\pi}{3} + k\pi$
- $x = \dfrac{\pi}{6} + k\pi$

## Spiegazione

Per la formula di duplicazione $\sin x\cos x = \dfrac{1}{2}\sin(2x)$, quindi l'equazione diventa $\sin(2x) = \dfrac{\sqrt{3}}{2}$. Si ha $2x = \dfrac{\pi}{3} + 2k\pi$ oppure $2x = \dfrac{2\pi}{3} + 2k\pi$. Dividendo per $2$ entrambi i termini si ottiene $x = \dfrac{\pi}{6} + k\pi$ oppure $x = \dfrac{\pi}{3} + k\pi$.
