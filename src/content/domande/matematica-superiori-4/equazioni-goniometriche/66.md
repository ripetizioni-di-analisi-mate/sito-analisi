Per quali valori del numero reale $c$ l'equazione $3\sin x + 4\cos x = c$ ha soluzioni?

- $-7 \leq c \leq 7$
- $-5 \leq c \leq 5$
- $-1 \leq c \leq 1$
- $-5 < c < 5$

## Spiegazione

Si ha $r = \sqrt{3^2 + 4^2} = 5$, quindi con il metodo dell'angolo aggiunto l'equazione diventa $5\sin(x + \varphi) = c$. L'equazione $\sin(x + \varphi) = \dfrac{c}{5}$ ha soluzioni se e solo se $-1 \leq \dfrac{c}{5} \leq 1$, cioè se e solo se $-5 \leq c \leq 5$. Gli estremi sono compresi, perché per $c = \pm 5$ si ottiene $\sin(x + \varphi) = \pm 1$, che ha soluzioni.
