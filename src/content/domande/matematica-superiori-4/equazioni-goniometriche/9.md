- $x = \dfrac{\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{6} + k\pi$
- $x = \dfrac{\pi}{6} + 2k\pi$
- $x = \dfrac{5\pi}{6} + 2k\pi$

## Spiegazione

Si ha $a = 1$, $b = \sqrt{3}$ e $r = \sqrt{1 + 3} = 2$, quindi l'angolo aggiunto soddisfa $\cos\varphi = \dfrac{1}{2}$ e $\sin\varphi = \dfrac{\sqrt{3}}{2}$, cioè $\varphi = \dfrac{\pi}{3}$. L'equazione diventa $2\sin\left(x + \dfrac{\pi}{3}\right) = 2$, cioè $\sin\left(x + \dfrac{\pi}{3}\right) = 1$. Per i casi particolari si ha $x + \dfrac{\pi}{3} = \dfrac{\pi}{2} + 2k\pi$, quindi $x = \dfrac{\pi}{6} + 2k\pi$. Le soluzioni formano una sola famiglia, perché $c = r$.
