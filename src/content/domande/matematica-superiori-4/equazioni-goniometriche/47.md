Quali sono le soluzioni dell'equazione $\cos (3x) = -\cos x$?

- $x = \dfrac{k\pi}{2}$
- $x = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$
- $x = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$ oppure $x = \dfrac{\pi}{2} + k\pi$
- $x = \dfrac{\pi}{4} + 2k\pi$ oppure $x = \dfrac{\pi}{2} + 2k\pi$

## Spiegazione

Per la formula $-\cos\alpha = \cos(\pi - \alpha)$ l'equazione diventa $\cos(3x) = \cos(\pi - x)$. La prima famiglia dà $3x = \pi - x + 2k\pi$, cioè $x = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$. La seconda dà $3x = -\pi + x + 2k\pi$, cioè $2x = -\pi + 2k\pi$ e $x = -\dfrac{\pi}{2} + k\pi$, che si scrive anche $x = \dfrac{\pi}{2} + k\pi$. Il valore $\dfrac{\pi}{2}$ non appartiene alla prima famiglia, quindi le soluzioni sono l'unione delle due famiglie.
