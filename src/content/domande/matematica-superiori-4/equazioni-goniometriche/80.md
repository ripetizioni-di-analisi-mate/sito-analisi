Quali sono le soluzioni dell'equazione $\sin^2 x - 2\sqrt{3}\sin x\cos x + 3\cos^2 x = 0$?

- $x = -\dfrac{\pi}{3} + k\pi$
- $x = \dfrac{\pi}{3} + k\pi$
- $x = \dfrac{\pi}{6} + k\pi$
- $x = \dfrac{\pi}{3} + 2k\pi$

## Spiegazione

Il coefficiente di $\sin^2 x$ è $1 \neq 0$, quindi si divide per $\cos^2 x$ e si ottiene $\tan^2 x - 2\sqrt{3}\tan x + 3 = 0$. Il primo membro è il quadrato $\left(\tan x - \sqrt{3}\right)^2$, quindi l'equazione equivale a $\tan x = \sqrt{3}$. Le soluzioni sono perciò $x = \dfrac{\pi}{3} + k\pi$.
