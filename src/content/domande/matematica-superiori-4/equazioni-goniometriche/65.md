Quali sono le soluzioni dell'equazione $\sin x + \cos x = \sqrt{2}$?

- $x = \dfrac{\pi}{4} + k\pi$
- $x = -\dfrac{\pi}{4} + 2k\pi$
- $x = \dfrac{\pi}{4} + 2k\pi$
- $x = \dfrac{\pi}{2} + 2k\pi$

## Spiegazione

Si ha $a = b = 1$ e $r = \sqrt{2}$, quindi l'angolo aggiunto è $\varphi = \dfrac{\pi}{4}$ e l'equazione diventa $\sqrt{2}\sin\left(x + \dfrac{\pi}{4}\right) = \sqrt{2}$. Perciò $\sin\left(x + \dfrac{\pi}{4}\right) = 1$, e per i casi particolari $x + \dfrac{\pi}{4} = \dfrac{\pi}{2} + 2k\pi$. Sottraendo $\dfrac{\pi}{4}$ si ottiene $x = \dfrac{\pi}{4} + 2k\pi$.
