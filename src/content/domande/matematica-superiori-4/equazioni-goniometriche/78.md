Quali sono le soluzioni dell'equazione $\sin^2 x + \sin x\cos x = 1$?

- $x = \dfrac{\pi}{4} + k\pi$
- $x = k\pi$ oppure $x = \dfrac{\pi}{4} + k\pi$
- $x = \dfrac{\pi}{2} + k\pi$ oppure $x = \dfrac{\pi}{4} + k\pi$
- $x = \dfrac{\pi}{2} + k\pi$ oppure $x = -\dfrac{\pi}{4} + k\pi$

## Spiegazione

Si scrive il termine noto come $1 = \sin^2 x + \cos^2 x$, e l'equazione diventa $\sin x\cos x - \cos^2 x = 0$. Il coefficiente di $\sin^2 x$ è ora $0$, quindi si raccoglie $\cos x$ e si ottiene $\cos x\,(\sin x - \cos x) = 0$. Il primo fattore dà $x = \dfrac{\pi}{2} + k\pi$. Il secondo dà $\tan x = 1$, cioè $x = \dfrac{\pi}{4} + k\pi$.
