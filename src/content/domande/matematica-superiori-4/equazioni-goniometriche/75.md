Quali sono le soluzioni dell'equazione $\sin^2 x - 3\cos^2 x = 0$?

- $x = \pm\dfrac{\pi}{3} + k\pi$
- $x = \pm\dfrac{\pi}{6} + k\pi$
- $x = \dfrac{\pi}{3} + k\pi$
- $x = \pm\dfrac{\pi}{3} + 2k\pi$

## Spiegazione

Il coefficiente di $\sin^2 x$ è $1 \neq 0$, quindi i punti con $\cos x = 0$ non sono soluzioni e si può dividere per $\cos^2 x$. Si ottiene $\tan^2 x = 3$, cioè $\tan x = \sqrt{3}$ oppure $\tan x = -\sqrt{3}$. Le soluzioni sono quindi $x = \dfrac{\pi}{3} + k\pi$ oppure $x = -\dfrac{\pi}{3} + k\pi$, che si scrivono insieme $x = \pm\dfrac{\pi}{3} + k\pi$.
