Quali sono le soluzioni dell'equazione $\cos (2x) + 5\sin x - 3 = 0$?

- $x = \dfrac{\pi}{6} + 2k\pi$ oppure $x = \dfrac{5\pi}{6} + 2k\pi$
- $x = \pm\dfrac{\pi}{3} + 2k\pi$
- $x = -\dfrac{\pi}{6} + 2k\pi$ oppure $x = \dfrac{7\pi}{6} + 2k\pi$
- $x = \dfrac{\pi}{6} + 2k\pi$

## Spiegazione

Con la formula di duplicazione $\cos(2x) = 1 - 2\sin^2 x$ l'equazione diventa $1 - 2\sin^2 x + 5\sin x - 3 = 0$, cioè $2\sin^2 x - 5\sin x + 2 = 0$. Con $t = \sin x$ si ha $\Delta = 25 - 16 = 9$, quindi $t = \dfrac{5 \pm 3}{4}$, cioè $t = 2$ oppure $t = \dfrac{1}{2}$. Il valore $t = 2$ non è accettabile, perché il seno non supera $1$. Resta $\sin x = \dfrac{1}{2}$, che dà $x = \dfrac{\pi}{6} + 2k\pi$ oppure $x = \dfrac{5\pi}{6} + 2k\pi$.
