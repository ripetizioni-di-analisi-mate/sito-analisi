Quali sono le soluzioni dell'equazione $\sin\left(x + \dfrac{\pi}{4}\right) = \sin\left(\dfrac{\pi}{4} - x\right)$?

- $x = 2k\pi$
- $x = k\pi$
- $x = \dfrac{\pi}{2} + k\pi$
- $x = \dfrac{k\pi}{2}$

## Spiegazione

Per il teorema sullo stesso seno si ha $x + \dfrac{\pi}{4} = \dfrac{\pi}{4} - x + 2k\pi$ oppure $x + \dfrac{\pi}{4} = \pi - \dfrac{\pi}{4} + x + 2k\pi$. La prima equazione dà $2x = 2k\pi$, cioè $x = k\pi$. La seconda dà $0 = \dfrac{\pi}{2} + 2k\pi$, che è falsa per ogni $k$ intero, quindi non fornisce soluzioni. Le soluzioni sono perciò $x = k\pi$.
