Quali sono le soluzioni dell'equazione $\sqrt{3}\sin x - \cos x = 1$?

- $x = \dfrac{\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{3} + 2k\pi$ oppure $x = \pi + 2k\pi$
- $x = 2k\pi$ oppure $x = \dfrac{2\pi}{3} + 2k\pi$
- $x = \dfrac{\pi}{3} + 2k\pi$ oppure $x = \dfrac{5\pi}{6} + 2k\pi$

## Spiegazione

Si ha $a = \sqrt{3}$, $b = -1$ e $r = 2$, quindi l'angolo aggiunto soddisfa $\cos\varphi = \dfrac{\sqrt{3}}{2}$ e $\sin\varphi = -\dfrac{1}{2}$, cioè $\varphi = -\dfrac{\pi}{6}$. L'equazione diventa $\sin\left(x - \dfrac{\pi}{6}\right) = \dfrac{1}{2}$, perciò $x - \dfrac{\pi}{6} = \dfrac{\pi}{6} + 2k\pi$ oppure $x - \dfrac{\pi}{6} = \dfrac{5\pi}{6} + 2k\pi$. Si ottengono $x = \dfrac{\pi}{3} + 2k\pi$ oppure $x = \pi + 2k\pi$. Per $x = \pi$ si ha infatti $\sqrt{3} \cdot 0 - (-1) = 1$.
