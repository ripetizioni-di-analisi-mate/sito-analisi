- $x = \dfrac{\pi}{4} + k\pi$ oppure $x = \arctan 3 + k\pi$
- $x = \dfrac{\pi}{4} + 2k\pi$ oppure $x = \arctan\dfrac{1}{3} + 2k\pi$
- $x = \dfrac{\pi}{4} + k\pi$ oppure $x = \arctan\dfrac{1}{3} + k\pi$
- $x = -\dfrac{\pi}{4} + k\pi$ oppure $x = -\arctan\dfrac{1}{3} + k\pi$

## Spiegazione

Il coefficiente di $\sin^2 x$ è $3 \neq 0$, quindi i punti con $\cos x = 0$ non sono soluzioni e si può dividere per $\cos^2 x$. Si ottiene $3\tan^2 x - 4\tan x + 1 = 0$, che ha $\Delta = 16 - 12 = 4$, quindi $\tan x = \dfrac{4 \pm 2}{6}$. Le radici sono $\tan x = 1$ e $\tan x = \dfrac{1}{3}$. La prima dà $x = \dfrac{\pi}{4} + k\pi$, la seconda dà $x = \arctan\dfrac{1}{3} + k\pi$.
