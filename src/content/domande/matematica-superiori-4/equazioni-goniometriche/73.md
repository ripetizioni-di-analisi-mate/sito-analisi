Quali sono le soluzioni dell'equazione $\sin x + \cos x = -1$?

- $x = \pi + 2k\pi$ oppure $x = -\dfrac{\pi}{2} + 2k\pi$
- $x = -\dfrac{\pi}{2} + 2k\pi$
- $x = \pi + 2k\pi$ oppure $x = \dfrac{\pi}{2} + 2k\pi$
- $x = \pi + 2k\pi$ oppure $x = -\dfrac{\pi}{4} + k\pi$

## Spiegazione

Nei punti $x = \pi + 2k\pi$ si ha $\sin x + \cos x = 0 - 1 = -1$, quindi questi valori sono soluzioni. Per gli altri valori si pone $t = \tan\dfrac{x}{2}$ e, moltiplicando per $1 + t^2$, si ottiene $2t + 1 - t^2 = -1 - t^2$, cioè $2t + 2 = 0$. Da $t = -1$ segue $\dfrac{x}{2} = -\dfrac{\pi}{4} + k\pi$, cioè $x = -\dfrac{\pi}{2} + 2k\pi$. Le soluzioni sono quindi $x = \pi + 2k\pi$ oppure $x = -\dfrac{\pi}{2} + 2k\pi$.
