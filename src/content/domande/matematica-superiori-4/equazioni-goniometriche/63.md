Quali sono le soluzioni dell'equazione $4\cos^2 x - 3 = 0$?

- $x = \pm\dfrac{\pi}{6} + 2k\pi$
- $x = \pm\dfrac{\pi}{6} + k\pi$
- $x = \pm\dfrac{\pi}{3} + k\pi$
- $x = \dfrac{\pi}{6} + k\pi$

## Spiegazione

L'equazione equivale a $\cos^2 x = \dfrac{3}{4}$, quindi $\cos x = \dfrac{\sqrt{3}}{2}$ oppure $\cos x = -\dfrac{\sqrt{3}}{2}$. La prima equazione dà $x = \pm\dfrac{\pi}{6} + 2k\pi$, la seconda dà $x = \pm\dfrac{5\pi}{6} + 2k\pi$. Poiché $\dfrac{5\pi}{6} = -\dfrac{\pi}{6} + \pi$ e $-\dfrac{5\pi}{6} = \dfrac{\pi}{6} - \pi$, le quattro famiglie si raccolgono in $x = \pm\dfrac{\pi}{6} + k\pi$.
