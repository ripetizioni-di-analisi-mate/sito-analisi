Quali sono le soluzioni dell'equazione $\sin\left(x + \dfrac{\pi}{6}\right) = \dfrac{1}{2}$?

- $x = \dfrac{\pi}{3} + 2k\pi$ oppure $x = \pi + 2k\pi$
- $x = 2k\pi$ oppure $x = \dfrac{5\pi}{6} + 2k\pi$
- $x = 2k\pi$ oppure $x = \dfrac{2\pi}{3} + 2k\pi$
- $x = 2k\pi$ oppure $x = -\dfrac{\pi}{3} + 2k\pi$

## Spiegazione

Con $t = x + \dfrac{\pi}{6}$ l'equazione diventa $\sin t = \dfrac{1}{2}$, che dà $t = \dfrac{\pi}{6} + 2k\pi$ oppure $t = \dfrac{5\pi}{6} + 2k\pi$. Dalla prima famiglia, sottraendo $\dfrac{\pi}{6}$, si ottiene $x = 2k\pi$. Dalla seconda si ottiene $x = \dfrac{5\pi}{6} - \dfrac{\pi}{6} + 2k\pi = \dfrac{2\pi}{3} + 2k\pi$.
