Per quale valore intero di $k$ la famiglia $x = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$ fornisce la soluzione $x = \dfrac{11\pi}{4}$?

- $k = 4$
- $k = 5$
- $k = 10$
- $k = 6$

## Spiegazione

Si impone $\dfrac{\pi}{4} + \dfrac{k\pi}{2} = \dfrac{11\pi}{4}$, quindi $\dfrac{k\pi}{2} = \dfrac{10\pi}{4} = \dfrac{5\pi}{2}$. Moltiplicando per $\dfrac{2}{\pi}$ si ottiene $k = 5$. Con $k = 5$ si ha infatti $\dfrac{\pi}{4} + \dfrac{5\pi}{2} = \dfrac{\pi}{4} + \dfrac{10\pi}{4} = \dfrac{11\pi}{4}$.
