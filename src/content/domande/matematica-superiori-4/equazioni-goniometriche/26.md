Quali sono le soluzioni dell'equazione $2\sin^2 x = 1$?

- $x = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$
- $x = \dfrac{\pi}{4} + k\pi$
- $x = \dfrac{\pi}{4} + 2k\pi$ oppure $x = \dfrac{3\pi}{4} + 2k\pi$
- $x = \pm\dfrac{\pi}{4} + 2k\pi$

## Spiegazione

L'equazione equivale a $\sin^2 x = \dfrac{1}{2}$, quindi $\sin x = \dfrac{\sqrt{2}}{2}$ oppure $\sin x = -\dfrac{\sqrt{2}}{2}$. La prima equazione dà $x = \dfrac{\pi}{4} + 2k\pi$ oppure $x = \dfrac{3\pi}{4} + 2k\pi$, la seconda dà $x = \dfrac{5\pi}{4} + 2k\pi$ oppure $x = \dfrac{7\pi}{4} + 2k\pi$. Gli angoli $\dfrac{\pi}{4}$, $\dfrac{3\pi}{4}$, $\dfrac{5\pi}{4}$, $\dfrac{7\pi}{4}$ distano $\dfrac{\pi}{2}$ l'uno dal successivo, perciò le quattro famiglie si raccolgono in $x = \dfrac{\pi}{4} + \dfrac{k\pi}{2}$.
