Quali sono le soluzioni dell'equazione $\sin x = \cos (3x)$?

- $x = \dfrac{\pi}{8} + \dfrac{k\pi}{2}$
- $x = \dfrac{\pi}{8} + \dfrac{k\pi}{2}$ oppure $x = \dfrac{\pi}{4} + k\pi$
- $x = \dfrac{\pi}{8} + \dfrac{k\pi}{2}$ oppure $x = -\dfrac{\pi}{4} + k\pi$
- $x = \dfrac{\pi}{8} + 2k\pi$ oppure $x = -\dfrac{\pi}{4} + 2k\pi$

## Spiegazione

Poiché $\cos(3x) = \sin\left(\dfrac{\pi}{2} - 3x\right)$, l'equazione diventa $\sin x = \sin\left(\dfrac{\pi}{2} - 3x\right)$. La prima famiglia dà $x = \dfrac{\pi}{2} - 3x + 2k\pi$, cioè $4x = \dfrac{\pi}{2} + 2k\pi$ e $x = \dfrac{\pi}{8} + \dfrac{k\pi}{2}$. La seconda dà $x = \pi - \dfrac{\pi}{2} + 3x + 2k\pi$, cioè $-2x = \dfrac{\pi}{2} + 2k\pi$ e $x = -\dfrac{\pi}{4} - k\pi$, che si scrive anche $x = -\dfrac{\pi}{4} + k\pi$. Le soluzioni sono l'unione delle due famiglie.
