Per bilanciare la reazione chimica
$$
a\, \mathrm{CH_4} + b\, \mathrm{O_2} \to c\, \mathrm{CO_2} + d\, \mathrm{H_2O}
$$
si impone che ogni elemento (carbonio, idrogeno, ossigeno) compaia lo stesso numero di volte a sinistra e a destra. Si ottiene un sistema omogeneo nelle incognite $a, b, c, d$. Qual è la sua soluzione formata dagli interi positivi più piccoli?

- $(a, b, c, d) = (1, 1, 1, 2)$
- $(a, b, c, d) = (1, 2, 1, 1)$
- $(a, b, c, d) = (1, 2, 1, 2)$
- $(a, b, c, d) = (2, 3, 2, 2)$

## Spiegazione

Contando gli atomi di carbonio, di idrogeno e di ossigeno si ottiene il sistema omogeneo
$$
\begin{cases}
a - c = 0 \\[4pt]
4a - 2d = 0 \\[4pt]
2b - 2c - d = 0
\end{cases}
$$
in quattro incognite. Le tre equazioni hanno rango $3$, quindi le soluzioni sono $\infty^{4 - 3} = \infty^1$. Posto $a = t$, la prima equazione dà $c = t$, la seconda dà $d = 2t$ e la terza dà $2b = 2t + 2t$, cioè $b = 2t$. Perciò le soluzioni sono $t\,(1, 2, 1, 2)$, e la soluzione con gli interi positivi più piccoli si ottiene per $t = 1$.
