Quante soluzioni ha il sistema
$$
\begin{cases}
x_1 + x_2 - x_3 + 2x_4 = 1 \\[4pt]
x_2 + x_3 - x_4 = 2 \\[4pt]
x_1 + 2x_2 + x_4 = 3
\end{cases}
$$
nelle incognite $x_1, x_2, x_3, x_4$?

- $\infty^1$ soluzioni
- $\infty^2$ soluzioni
- Una sola soluzione
- Nessuna soluzione

## Spiegazione

La terza riga della matrice completa è la somma delle prime due, perché $(1 \ \ 1 \ \ {-1} \ \ 2 \mid 1) + (0 \ \ 1 \ \ 1 \ \ {-1} \mid 2) = (1 \ \ 2 \ \ 0 \ \ 1 \mid 3)$. Con $R_3 \to R_3 - R_1 - R_2$ la terza riga si annulla, e le prime due formano già una matrice a scala con due pivot. Quindi $\operatorname{rk} A = \operatorname{rk} (A \mid b) = 2$. Per il **teorema di Rouché-Capelli** il sistema è compatibile e le soluzioni sono $\infty^{4 - 2} = \infty^2$. Il numero di parametri liberi è il numero di incognite meno il rango.
