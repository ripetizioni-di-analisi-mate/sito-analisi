Le soluzioni del sistema $A x = b$ nelle incognite $x, y, z$ sono le terne $(1 + 2t, \ -t, \ 3 + t)$ con $t \in \mathbb{R}$. Qual è lo spazio $S_0$ delle soluzioni del sistema omogeneo associato $A x = 0$?

- $\{ (1, 0, 3) + t\,(2, -1, 1) : t \in \mathbb{R} \}$
- $\langle (1, 0, 3) \rangle$
- $\langle (2, 1, 1) \rangle$
- $\langle (2, -1, 1) \rangle$

## Spiegazione

Le soluzioni si scrivono come $(1, 0, 3) + t\,(2, -1, 1)$, quindi $(1, 0, 3)$, ottenuta per $t = 0$, è una soluzione particolare. Per il teorema sulla **struttura delle soluzioni** l'insieme delle soluzioni è $(1, 0, 3) + S_0$. Perciò $S_0$ è formato dalle differenze fra le soluzioni e la soluzione particolare, cioè dai vettori $t\,(2, -1, 1)$, e $S_0 = \langle (2, -1, 1) \rangle$. L'insieme $\{ (1, 0, 3) + t\,(2, -1, 1) \}$ è l'insieme delle soluzioni di $A x = b$, che non contiene l'origine.
