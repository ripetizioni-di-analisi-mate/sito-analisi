- $\{ (1, 0, -2) + t\,(2, 1, 0) : t \in \mathbb{R} \}$
- $\{ (3, 0, 0) + t\,(-2, 1, 0) : t \in \mathbb{R} \}$
- $\{ (1, 0, -2) + t\,(-2, 1, 0) : t \in \mathbb{R} \}$
- $\{ (1, 0, -2) + t\,(-2, 1, 1) : t \in \mathbb{R} \}$

## Spiegazione

Con $R_2 \to R_2 - 2R_1$ la seconda equazione diventa $3z = -6$, quindi $z = -2$. La prima diventa allora $x + 2y = 1$, e posto $y = t$ si ha $x = 1 - 2t$. Le soluzioni sono perciò
$$
(1 - 2t, \ t, \ -2) = (1, 0, -2) + t\,(-2, 1, 0), \qquad t \in \mathbb{R},
$$
dove $(1, 0, -2)$ è una soluzione particolare e $(-2, 1, 0)$ genera le soluzioni del sistema omogeneo associato, come afferma il teorema sulla **struttura delle soluzioni**. La terna $(3, 0, 0)$ soddisfa solo la prima equazione, mentre i vettori $(2, 1, 0)$ e $(-2, 1, 1)$ non risolvono l'omogeneo associato.
