Per quale valore di $c \in \mathbb{R}$ la quadrica
$$
x^2 + 4y^2 - z^2 + 2x - 4z + c = 0
$$
è un cono?

- $c = 3$
- $c = 5$
- $c = -5$
- $c = -3$

## Spiegazione

Completando i quadrati si ha $x^2 + 2x = (x + 1)^2 - 1$ e $-z^2 - 4z = -(z + 2)^2 + 4$, quindi l'equazione diventa
$$
(x + 1)^2 + 4y^2 - (z + 2)^2 + c + 3 = 0 .
$$
I coefficienti $1$, $4$, $-1$ dei quadrati non sono concordi, perciò la quadrica è un cono se e solo se il termine noto $c + 3$ è nullo, cioè per $c = -3$. In questo caso il vertice è il punto $(-1, 0, -2)$; per gli altri valori di $c$ la quadrica è un iperboloide. Il valore $c = 3$ nasce da un errore di segno nel termine noto, e il valore $c = 5$ dal completamento errato $-z^2 - 4z = -(z + 2)^2 - 4$.
