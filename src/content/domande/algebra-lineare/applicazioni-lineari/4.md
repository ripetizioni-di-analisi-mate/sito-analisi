L'endomorfismo $f(x, y, z) = (x + y,\ y + 2z,\ z)$ di $\mathbb{R}^3$ è un isomorfismo. Quale è l'applicazione inversa $f^{-1}$?

- $f^{-1}(x, y, z) = (x - y,\ y - 2z,\ z)$
- $f^{-1}(x, y, z) = (x - y - 2z,\ y - 2z,\ z)$
- $f^{-1}(x, y, z) = (x - y + 2z,\ y + 2z,\ z)$
- $f^{-1}(x, y, z) = (x - y + 2z,\ y - 2z,\ z)$

## Spiegazione

Per trovare $f^{-1}(x, y, z)$ si cerca il vettore $(a, b, c)$ tale che $f(a, b, c) = (x, y, z)$, cioè si risolve il sistema
$$
\begin{cases}
a + b = x \\[4pt]
b + 2c = y \\[4pt]
c = z
\end{cases}
$$
Dalla terza equazione $c = z$, quindi dalla seconda $b = y - 2z$. Sostituendo nella prima si ottiene $a = x - b = x - y + 2z$. Perciò $f^{-1}(x, y, z) = (x - y + 2z,\ y - 2z,\ z)$.
