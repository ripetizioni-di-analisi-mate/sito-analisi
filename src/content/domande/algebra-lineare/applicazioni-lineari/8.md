Sia $T : \mathbb{R}_2[x] \to \mathbb{R}_2[x]$, $T(p) = p + p'$. Quale polinomio $p$ soddisfa $T(p) = x^2$?

- $p(x) = x^2 - 2x$
- $p(x) = x^2 + 2x + 2$
- $p(x) = x^2 - 2x - 2$
- $p(x) = x^2 - 2x + 2$

## Spiegazione

Si scrive $p(x) = a + bx + cx^2$, quindi $p'(x) = b + 2cx$ e
$$
T(p) = (a + b) + (b + 2c)\, x + c\, x^2 .
$$
Uguagliando i coefficienti a quelli di $x^2$ si ottiene il sistema
$$
\begin{cases}
c = 1 \\[4pt]
b + 2c = 0 \\[4pt]
a + b = 0
\end{cases}
$$
perciò $c = 1$, $b = -2$ e $a = 2$, cioè $p(x) = x^2 - 2x + 2$. La matrice di $T$ rispetto a $(1, x, x^2)$ è triangolare con determinante $1$, quindi $T$ è un isomorfismo e questo polinomio è l'unico con la proprietà richiesta.
