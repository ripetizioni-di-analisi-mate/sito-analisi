Sia $f : \mathbb{R}^3 \to \mathbb{R}^3$ lineare con $f(1, 0, 0) = (1, 2, 0)$, $f(0, 1, 0) = (2, 4, 0)$ e $f(0, 0, 1) = (0, 0, 1)$. Quale vettore appartiene a $\ker f$?

- $(1, 2, 0)$
- $(-2, 1, 1)$
- $(2, -1, 0)$
- $(2, 1, 0)$

## Spiegazione

Per la linearità $f(a, b, c) = a\,(1, 2, 0) + b\,(2, 4, 0) + c\,(0, 0, 1) = (a + 2b,\ 2a + 4b,\ c)$. Il vettore $(a, b, c)$ appartiene al nucleo se e solo se
$$
\begin{cases}
a + 2b = 0 \\[4pt]
c = 0
\end{cases}
$$
quindi $\ker f = \langle (2, -1, 0) \rangle$. Per gli altri vettori si ha $f(1, 2, 0) = (5, 10, 0)$, $f(-2, 1, 1) = (0, 0, 1)$ e $f(2, 1, 0) = (4, 8, 0)$, che sono diversi dal vettore nullo.
