Quali sono le coordinate del polinomio $p(x) = 1 + x + x^2$ rispetto alla base $\big( 1,\ x - 1,\ (x - 1)^2 \big)$ di $\mathbb{R}_2[x]$?

- $(1, 1, 1)$
- $(1, 3, 1)$
- $(3, 3, 1)$
- $(3, -1, 1)$

## Spiegazione

Si cercano $a$, $b$, $c$ con $1 + x + x^2 = a + b\,(x - 1) + c\,(x - 1)^2$. Ponendo $x = 1$ si ottiene $a = p(1) = 3$. Derivando e ponendo $x = 1$ si ottiene $b = p'(1) = 1 + 2 = 3$. Il coefficiente di $x^2$ è $c$ a destra e $1$ a sinistra, quindi $c = 1$. Si verifica che $3 + 3\,(x - 1) + (x - 1)^2 = 3 + 3x - 3 + x^2 - 2x + 1 = x^2 + x + 1$. Le coordinate $(1, 1, 1)$ sono quelle rispetto alla base $(1, x, x^2)$.
