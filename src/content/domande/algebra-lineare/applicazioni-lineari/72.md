L'applicazione $T : \mathbb{R}_2[x] \to \mathbb{R}^3$, $T(p) = \big( p(0),\ p(1),\ p(-1) \big)$, è un isomorfismo, quindi esiste un solo polinomio di grado al più $2$ che vale $1$ in $x = 0$, $2$ in $x = 1$ e $4$ in $x = -1$. Quale è questo polinomio?

- $p(x) = 1 + x + 2x^2$
- $p(x) = 2x^2 - x$
- $p(x) = 1 - x + 2x^2$
- $p(x) = 1 - 3x + 4x^2$

## Spiegazione

Si pone $p(x) = a + bx + cx^2$. Le condizioni $p(0) = 1$, $p(1) = 2$ e $p(-1) = 4$ formano il sistema
$$
\begin{cases}
a = 1 \\[4pt]
a + b + c = 2 \\[4pt]
a - b + c = 4
\end{cases}
$$
Sottraendo la terza equazione dalla seconda si ottiene $2b = -2$, quindi $b = -1$, e poi $c = 2 - a - b = 2$. Perciò $p(x) = 1 - x + 2x^2$, l'unico polinomio con questi valori, poiché $T$ è un isomorfismo. Il polinomio $1 - 3x + 4x^2$ verifica le prime due condizioni e vale $8$ in $x = -1$.
