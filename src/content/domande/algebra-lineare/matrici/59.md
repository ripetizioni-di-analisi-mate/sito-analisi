Il vettore riga $u^T = (1 \ \ {-1} \ \ 2)$ viene moltiplicato a destra per la matrice
$$
A = \begin{pmatrix} 2 & 0 & 1 \\ 1 & 3 & -1 \\ 0 & 1 & 1 \end{pmatrix} .
$$
Che vettore riga si ottiene come prodotto $u^T A$?

- $(4 \ \ {-4} \ \ 1)$
- $(1 \ \ {-2} \ \ 3)$
- $(1 \ \ {-1} \ \ 4)$
- $(3 \ \ 5 \ \ 2)$

## Spiegazione

Il prodotto di un vettore riga per una matrice è la combinazione lineare delle righe della matrice con coefficienti le componenti del vettore, come si vede trasponendo $u^T A = (A^T u)^T$. Indicate con $R_1, R_2, R_3$ le righe di $A$, si ha quindi
$$
u^T A = R_1 - R_2 + 2R_3 = (2 \ \ 0 \ \ 1) - (1 \ \ 3 \ \ {-1}) + (0 \ \ 2 \ \ 2) = (1 \ \ {-1} \ \ 4) .
$$
Il vettore $(4 \ \ {-4} \ \ 1)$ è $Au$ scritto in riga, cioè la combinazione delle *colonne* di $A$, e $(1 \ \ {-2} \ \ 3)$ si ottiene dimenticando il coefficiente $2$ della terza riga.
