Si applica il procedimento di Gram-Schmidt ai vettori $v_1 = (1, 1, 1, 1)$, $v_2 = (1, 1, 0, 0)$, $v_3 = (1, 0, 0, 0)$ di $\mathbb{R}^4$, nell'ordine dato. Qual è il terzo vettore $e_3$ della base ortonormale che si ottiene?

- $\dfrac{1}{\sqrt{2}}\,(1, -1, 0, 0)$
- $\dfrac{1}{2\sqrt{3}}\,(3, -1, -1, -1)$
- $\dfrac{1}{2\sqrt{3}}\,(3, -1, 1, 1)$
- $\dfrac{1}{\sqrt{2}}\,(0, 0, 1, -1)$

## Spiegazione

Si pone $u_1 = v_1$. Poiché $\langle v_2, u_1 \rangle = 2$ e $\langle u_1, u_1 \rangle = 4$, si ha $u_2 = v_2 - \dfrac{1}{2}\,u_1 = \dfrac{1}{2}\,(1, 1, -1, -1)$, che si sostituisce con il multiplo $(1, 1, -1, -1)$. Il terzo vettore si ottiene sottraendo a $v_3$ le sue proiezioni su entrambi i vettori già costruiti:
$$
u_3 = (1, 0, 0, 0) - \frac{1}{4}\,(1, 1, 1, 1) - \frac{1}{4}\,(1, 1, -1, -1) = \left( \frac{1}{2}, -\frac{1}{2}, 0, 0 \right) .
$$
Si ha $\|u_3\| = \dfrac{1}{\sqrt{2}}$, quindi la normalizzazione dà $e_3 = \dfrac{1}{\sqrt{2}}\,(1, -1, 0, 0)$.
