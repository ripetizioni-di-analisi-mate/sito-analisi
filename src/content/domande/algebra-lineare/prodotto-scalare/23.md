I vettori $w_1 = (1, 1, 1)$, $w_2 = (1, -2, 1)$, $w_3 = (1, 0, -1)$ formano una base ortogonale di $\mathbb{R}^3$. Quali sono le coordinate di $v = (2, 1, 0)$ rispetto a questa base?

- $(3, 0, 2)$
- $(\sqrt{3}, 0, \sqrt{2})$
- $(2, 1, 0)$
- $(1, 0, 1)$

## Spiegazione

Rispetto a una base ortogonale la coordinata $i$-esima di $v$ è $\dfrac{\langle v, w_i \rangle}{\langle w_i, w_i \rangle}$. Si ottiene
$$
\frac{\langle v, w_1 \rangle}{\langle w_1, w_1 \rangle} = \frac{3}{3} = 1,
\qquad
\frac{\langle v, w_2 \rangle}{\langle w_2, w_2 \rangle} = \frac{0}{6} = 0,
\qquad
\frac{\langle v, w_3 \rangle}{\langle w_3, w_3 \rangle} = \frac{2}{2} = 1 .
$$
Perciò le coordinate sono $(1, 0, 1)$, e infatti $w_1 + w_3 = (2, 1, 0)$. La base non è ortonormale, quindi i soli prodotti scalari $(3, 0, 2)$ non danno le coordinate.
