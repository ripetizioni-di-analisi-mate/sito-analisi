Quale sistema descrive in forma cartesiana il sottospazio $W = \langle (1, 1, 0, 0), (0, 1, 1, 1) \rangle \subseteq \mathbb{R}^4$?

- $\begin{cases} x_1 + x_2 - x_3 = 0 \\ x_3 - x_4 = 0 \end{cases}$
- $\begin{cases} x_1 - x_2 + x_3 = 0 \\ x_3 + x_4 = 0 \end{cases}$
- $\begin{cases} x_1 - x_2 = 0 \\ x_3 - x_4 = 0 \end{cases}$
- $\begin{cases} x_1 - x_2 + x_3 = 0 \\ x_3 - x_4 = 0 \end{cases}$

## Spiegazione

I due generatori non sono proporzionali, quindi $\dim W = 2$ e servono $4 - 2 = 2$ equazioni indipendenti. Il vettore generico di $W$ è $s\,(1, 1, 0, 0) + t\,(0, 1, 1, 1) = (s, \ s + t, \ t, \ t)$, perciò $x_1 = s$, $x_2 = s + t$, $x_3 = x_4 = t$. Eliminando i parametri si ottengono $x_2 = x_1 + x_3$ e $x_3 = x_4$, cioè le equazioni $x_1 - x_2 + x_3 = 0$ e $x_3 - x_4 = 0$. Entrambi i generatori le soddisfano, e le due equazioni sono indipendenti, quindi descrivono $W$.
