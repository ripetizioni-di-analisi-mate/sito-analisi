Quali sono le coordinate di $v = (3, 5, 4)$ rispetto alla base $\mathcal{B} = \big( (1, 1, 0), (0, 1, 1), (1, 0, 1) \big)$ di $\mathbb{R}^3$?

- $(3, 5, 4)$
- $(2, 3, 1)$
- $(1, 3, 2)$
- $(2, 1, 3)$

## Spiegazione

Si cercano $a, b, c$ tali che $a\,(1, 1, 0) + b\,(0, 1, 1) + c\,(1, 0, 1) = (3, 5, 4)$, cioè
$$
\begin{cases}
a + c = 3 \\[4pt]
a + b = 5 \\[4pt]
b + c = 4
\end{cases}
$$
Sommando le tre equazioni si ottiene $2\,(a + b + c) = 12$, quindi $a + b + c = 6$. Sottraendo da questa uguaglianza ciascuna equazione si ricavano $b = 3$, $c = 1$ e $a = 2$. Perciò le **coordinate** di $v$ rispetto a $\mathcal{B}$ sono $(2, 3, 1)$.
