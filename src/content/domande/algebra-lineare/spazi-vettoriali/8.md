$\mathcal{B} = (1, \ 1 + x, \ 1 + x + x^2)$ è una base di $\mathbb{R}_2[x]$. Quali sono le coordinate di $p(x) = 3 - 2x + 5x^2$ rispetto a $\mathcal{B}$?

- $(3, -2, 5)$
- $(-5, 3, 5)$
- $(15, -7, 5)$
- $(5, -7, 5)$

## Spiegazione

Si cercano $a, b, c$ tali che $a \cdot 1 + b\,(1 + x) + c\,(1 + x + x^2) = 3 - 2x + 5x^2$. Il primo membro è $(a + b + c) + (b + c)\,x + c\,x^2$, quindi, uguagliando i coefficienti, si ottiene il sistema
$$
\begin{cases}
a + b + c = 3 \\[4pt]
b + c = -2 \\[4pt]
c = 5
\end{cases}
$$
Dalla terza equazione $c = 5$, dalla seconda $b = -2 - 5 = -7$ e dalla prima $a = 3 + 7 - 5 = 5$. Perciò le **coordinate** di $p$ rispetto a $\mathcal{B}$ sono $(5, -7, 5)$.
