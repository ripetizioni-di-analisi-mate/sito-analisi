Quali sono le coordinate di $p(x) = 1 + 4x + 5x^2$ rispetto alla base $\mathcal{B} = (1 + x, \ x + x^2, \ x^2)$ di $\mathbb{R}_2[x]$?

- $(1, 4, 5)$
- $(1, 5, 0)$
- $(1, 3, 2)$
- $(1, 3, 5)$

## Spiegazione

Si cercano $a, b, c$ tali che $a\,(1 + x) + b\,(x + x^2) + c\,x^2 = 1 + 4x + 5x^2$. Il primo membro è $a + (a + b)\,x + (b + c)\,x^2$, quindi uguagliando i coefficienti si ottiene $a = 1$, $a + b = 4$ e $b + c = 5$. Perciò $b = 4 - 1 = 3$ e $c = 5 - 3 = 2$. Le **coordinate** di $p$ rispetto a $\mathcal{B}$ sono $(1, 3, 2)$.
