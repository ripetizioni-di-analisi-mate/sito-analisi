Qual è la dimensione del sottospazio $W = \{ p \in \mathbb{R}_3[x] : p(1) = p(-1) = 0 \}$?

- $2$
- $1$
- $3$
- $4$

## Spiegazione

Sia $p(x) = a + bx + cx^2 + dx^3$. Le condizioni $p(1) = 0$ e $p(-1) = 0$ danno il sistema omogeneo
$$
\begin{cases}
a + b + c + d = 0 \\[4pt]
a - b + c - d = 0
\end{cases}
$$
nelle coordinate $(a, b, c, d)$ rispetto alla base canonica. Le due equazioni sono indipendenti, quindi la matrice dei coefficienti ha rango $2$ e $\dim W = 4 - 2 = 2$. Infatti il sistema equivale a $c = -a$ e $d = -b$, e $W = \langle 1 - x^2, \ x - x^3 \rangle$.
