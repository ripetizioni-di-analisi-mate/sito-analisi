In $\mathbb{R}^4$ si considerino $U : x_1 + x_2 + x_3 + x_4 = 0$ e $W = \langle (1, -1, 0, 0), (1, 1, 1, 1), (0, 0, 1, -1) \rangle$. Quale sequenza è una base di $U \cap W$?

- $\big( (1, 1, 1, 1) \big)$
- $\big( (1, -1, 0, 0) \big)$
- $\big( (1, -1, 0, 0), \ (0, 0, 1, -1) \big)$
- $\big( (1, -1, 0, 0), \ (1, 1, 1, 1), \ (0, 0, 1, -1) \big)$

## Spiegazione

Il vettore generico di $W$ è $a\,(1, -1, 0, 0) + b\,(1, 1, 1, 1) + c\,(0, 0, 1, -1) = (a + b, \ b - a, \ b + c, \ b - c)$. Sostituendo nell'equazione di $U$ si ottiene $4b = 0$, quindi $b = 0$ e $U \cap W = \langle (1, -1, 0, 0), (0, 0, 1, -1) \rangle$. I due vettori non sono proporzionali, perciò formano una **base** di $U \cap W$, che ha dimensione $2$. Il vettore $(1, 1, 1, 1)$ non sta in $U$, poiché la somma delle sue componenti vale $4$.
