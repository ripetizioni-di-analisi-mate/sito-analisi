Siano $p_1, p_2, p_3, p_4$ quattro polinomi di $\mathbb{R}_3[x]$ linearmente indipendenti. Quale affermazione è vera?

- Generano un sottospazio di dimensione $3$
- Sono dipendenti, perché $\dim \mathbb{R}_3[x] = 3$
- Formano una base di $\mathbb{R}_3[x]$ solo se uno di essi è il polinomio costante $1$
- Formano una base di $\mathbb{R}_3[x]$

## Spiegazione

La base canonica di $\mathbb{R}_3[x]$ è $(1, x, x^2, x^3)$, quindi $\dim \mathbb{R}_3[x] = 4$. Per le **conseguenze della dimensione**, $4$ vettori indipendenti in uno spazio di dimensione $4$ formano una base. Perciò $p_1, p_2, p_3, p_4$ formano una **base** di $\mathbb{R}_3[x]$, qualunque essi siano. Per esempio $(1 + x, \ x, \ x^2, \ x^3)$ è una base che non contiene il polinomio costante $1$.
