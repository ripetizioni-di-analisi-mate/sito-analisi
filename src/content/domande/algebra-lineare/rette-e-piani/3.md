Quali sono le equazioni cartesiane della retta passante per i punti $A = (2, 1, -1)$ e $B = (4, 0, 1)$?

- $\begin{cases} x - 2y = 0 \\ 2y - z - 3 = 0 \end{cases}$
- $\begin{cases} x + 2y - 4 = 0 \\ 2y - z - 3 = 0 \end{cases}$
- $\begin{cases} 2x - y + 2z - 1 = 0 \\ x + 2y - 4 = 0 \end{cases}$
- $\begin{cases} x + 2y - 4 = 0 \\ 2y + z - 1 = 0 \end{cases}$

## Spiegazione

Il vettore $\overrightarrow{AB} = (2, -1, 2)$ è un vettore direttore della retta, quindi le equazioni parametriche sono $x = 2 + 2t$, $y = 1 - t$, $z = -1 + 2t$. Dalla seconda equazione si ricava $t = 1 - y$. Sostituendo nella prima si ottiene $x = 2 + 2(1 - y) = 4 - 2y$, cioè $x + 2y - 4 = 0$. Sostituendo nella terza si ottiene $z = -1 + 2(1 - y) = 1 - 2y$, cioè $2y + z - 1 = 0$. I due piani così ottenuti contengono la retta e non sono paralleli, perciò le loro equazioni sono equazioni cartesiane della retta.
