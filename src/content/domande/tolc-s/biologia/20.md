In un doppio strato fosfolipidico con acqua su entrambi i lati, quale disposizione è energeticamente favorevole?

- Code apolari completamente esposte all’acqua su entrambi i lati
- Tutte le teste soltanto sul lato esterno
- Tutte le code soltanto sul lato citoplasmatico
- Fosfolipidi trasformati in nucleotidi
- Teste polari verso l’acqua e code apolari verso l’interno

## Spiegazione

Le teste polari interagiscono con l’acqua e si dispongono sulle due superfici. Le code apolari si associano nella regione interna, riducendo il contatto con l’acqua. Questa organizzazione deriva dal carattere anfipatico dei fosfolipidi e crea una barriera selettiva. Non richiede che tutte le teste si trovino su un solo lato né una trasformazione chimica in altre biomolecole.
