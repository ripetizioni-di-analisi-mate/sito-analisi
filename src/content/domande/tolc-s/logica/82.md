Per tre attività A, B e C si sa soltanto che A precede B. Quale informazione aggiuntiva rende unico l’ordine?

- C precede B
- C è immediatamente dopo B
- A precede C
- C non è al secondo posto
- A non è al terzo posto

## Spiegazione

Se C è immediatamente dopo B, la coppia BC deve lasciare A prima di B; con tre attività rimane soltanto ABC. La condizione C prima di B ammette ACB e CAB; A prima di C ammette ABC e ACB. Le altre aggiunte lasciano anch’esse più ordini. L’adiacenza di C subito dopo B è quindi l’unica aggiunta proposta che determina tutte le posizioni.
