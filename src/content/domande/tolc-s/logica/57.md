Se il server è raggiungibile, il portale si apre. Anche una copia locale funzionante basta per aprirlo. Il portale è chiuso. Quale frase è necessariamente vera?

- Il server è irraggiungibile e la copia locale funziona.
- Entrambe le condizioni per aprirlo sono verificate.
- Almeno una delle due condizioni per aprirlo è verificata.
- Il server è raggiungibile e la copia locale non funziona.
- Il server è irraggiungibile e la copia locale non funziona.

## Spiegazione

Ciascuna condizione è da sola sufficiente per l’apertura. Poiché il portale è chiuso, il **modus tollens** esclude entrambe le condizioni.
