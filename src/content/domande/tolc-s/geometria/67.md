Si trasla il punto $\left( 3, \  -1\right)$ di un vettore di componenti $\left( 2, \  4\right)$. Quali coordinate si ottengono?

- $\left( 1, \  7\right)$
- $\left( 1, \  3\right)$
- $\left( 1, \  -5\right)$
- $\left( 5, \  -5\right)$
- $\left( 5, \  3\right)$

## Spiegazione

La traslazione aggiunge la prima componente all'ascissa e la seconda all'ordinata. Le coordinate risultano $\left( 5, \  3\right)$.
