Il manuale di un archivio dice «I file ricevuti entro sera vengono numerati il giorno stesso. I file numerati dopo le diciotto vengono pubblicati il giorno seguente». Un file arriva nel primo pomeriggio.

Quale informazione aggiuntiva permette di stabilire se si applica la seconda regola?

- Il numero totale dei file ricevuti il giorno prima.
- L’ora in cui il file è stato scritto.
- La dimensione del file.
- Il nome di chi ha inviato il file.
- L’ora in cui il file è stato numerato.

## Spiegazione

La prima regola fissa il giorno di numerazione. La seconda dipende dall’ora effettiva della numerazione, che può essere diversa dall’ora di arrivo.
