Una griglia a gradini ha file di quattro, quattro, tre e due quadretti, tutte allineate a sinistra. Quanti quadrati completi si vedono, inclusi quelli con lato più lungo di un quadretto?

- $21$
- $13$
- $20$
- $19$

## Spiegazione

Le quattro file contengono $4 + 4 + 3 + 2 = 13$ quadrati di lato uno. Nelle coppie di file consecutive ci sono rispettivamente tre, due e un quadrato di lato due, quindi sei. Soltanto le prime tre file permettono un quadrato di lato tre e il totale è $13 + 6 + 1 = 20$.
