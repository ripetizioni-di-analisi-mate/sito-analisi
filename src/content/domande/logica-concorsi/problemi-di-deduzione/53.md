Cinque pratiche A, B, C, D ed E si lavorano una alla volta. C precede B, D è lavorata subito dopo A e fra E e C c’è esattamente una pratica. Quale ordine è possibile?

- C → A → E → D → B
- C → B → E → A → D
- E → C → A → D → B
- A → D → B → C → E

## Spiegazione

Nell’ordine C, B, E, A, D, C precede B, D segue immediatamente A e solo B separa C da E. Negli altri ordini C ed E sono adiacenti, B precede C oppure D non segue subito A.
