In una stanza esattamente una delle lampade A, B e C è accesa. Se A è accesa, B è accesa. Se B è accesa, C è accesa. Quale lampada è accesa?

- A
- Nessuna
- B
- C

## Spiegazione

A non può essere accesa perché costringerebbe anche B a esserlo. Lo stesso vale per B, che se fosse accesa costringerebbe C a esserlo. Resta C, che può essere accesa con le altre due spente.
