Il sistema approva il file se la firma è valida oppure se interviene un operatore. L’approvazione comporta la comparsa del file nell’elenco pubblico. Un file compare nell’elenco e si sa che la firma non è valida. Quale condizione aggiuntiva basterebbe a dedurre che è intervenuto un operatore?

- I file con firma valida compaiono nell’elenco.
- Quando l’operatore interviene il file viene approvato.
- Per comparire nell’elenco è indispensabile una firma valida o l’intervento di un operatore.
- La firma valida è sufficiente per l’approvazione automatica.

## Spiegazione

La regola aggiuntiva rende **necessario** almeno uno dei due eventi per comparire nell’elenco. Poiché il file compare e la firma non è valida, deve essere intervenuto un operatore.
