Un sito accetta il file solo se ha estensione PDF. Se l’estensione è PDF e la dimensione non supera $5$ MB, il sito lo accetta. Si sa che un file PDF è stato rifiutato. Che cosa si deduce?

- Il file è esattamente di $5$ MB.
- Il file ha un’estensione diversa da PDF.
- Il file supera $5$ MB.
- Il file è più piccolo di $5$ MB.

## Spiegazione

Per un file PDF, avere dimensione non superiore a $5$ MB garantisce l’accettazione. Poiché il file è stato rifiutato, la sua dimensione deve superare $5$ MB.
