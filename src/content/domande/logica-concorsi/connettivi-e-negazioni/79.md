Quale espressione traduce «Per archiviare il file basta che sia validato.»? Poni $A$ = «il file è archiviato» e $B$ = «il file è validato».

- $A \Rightarrow B$
- $A \lor B$
- $A \Leftrightarrow B$
- $B \Rightarrow A$

## Spiegazione

«Basta che» indica una **condizione sufficiente**. La validazione comporta l’archiviazione, quindi la validazione è l’antecedente.
