Una molecola possiede una testa polare e regioni idrocarburiche apolari. Quale organizzazione in acqua è coerente con un fosfolipide di membrana?

- Teste verso l’acqua e regioni apolari associate nell’interno del doppio strato
- Teste polari tutte sepolte e code apolari esposte all’acqua
- Identica affinità per l’acqua delle teste e delle code
- Distribuzione casuale stabile delle code in acqua senza alcuna associazione

## Spiegazione

La molecola è anfipatica perché comprende regioni con diversa affinità per l’acqua. Nel doppio strato le teste possono interagire con i compartimenti acquosi mentre le code si associano nella regione interna. Questa disposizione riduce l’esposizione delle regioni apolari all’acqua. Invertire teste e code o attribuire loro identica affinità cancellerebbe la differenza chimica che spiega l’organizzazione.
