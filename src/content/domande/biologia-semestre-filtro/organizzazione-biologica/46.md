Una molecola ha una testa polare e code idrofobe e si dispone in doppio strato in acqua. Quale classe descrive il caso?

- Triacilglicerolo
- Fosfolipide
- ATP
- NADH

## Spiegazione

Forma doppi strati grazie alla separazione tra testa idrofila e code idrofobe. Le code si associano lontano dall’acqua, mentre le teste restano esposte al solvente.
