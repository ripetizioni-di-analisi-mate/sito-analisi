Quale descrizione spiega meglio il ruolo di «Fosfolipide» nel caso tipico studiato?

- Accoppia reazioni cellulari tramite l’idrolisi o il trasferimento di un gruppo fosfato.
- Forma doppi strati grazie alla separazione tra testa idrofila e code idrofobe.
- Trasporta equivalenti riducenti dalla degradazione dei nutrienti alla catena respiratoria.
- Conserva energia in tre catene aciliche legate al glicerolo.

## Spiegazione

Le code si associano lontano dall’acqua, mentre le teste restano esposte al solvente.
