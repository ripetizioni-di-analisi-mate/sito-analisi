Quale orientamento assumono i fosfolipidi nel doppio strato?

- Teste polari verso l'acqua e code idrofobe verso l'interno.
- Code idrofobe verso l'acqua su entrambe le superfici.
- Tutte le teste al centro e tutte le code fuori.
- Un'unica catena di nucleotidi senza lipidi.

## Spiegazione

La disposizione limita il contatto delle code apolari con l'acqua. La natura anfipatica sostiene la formazione spontanea di doppi strati.
