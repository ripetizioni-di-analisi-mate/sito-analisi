Quali sono le soluzioni della disequazione $2^{x^{2}} < 16$?

- $-2 < x < 2$
- $x < 2$
- $x < -2$ oppure $x > 2$
- $-4 < x < 4$

## Spiegazione

Poiché $16 = 2^{4}$, la disequazione si scrive $2^{x^{2}} < 2^{4}$. La base $2$ è maggiore di $1$, quindi il verso **si mantiene** e la disequazione equivale a $x^{2} < 4$. Il trinomio $x^{2} - 4$ è negativo tra le radici $-2$ e $2$, perciò le soluzioni sono $-2 < x < 2$.
