Quale ordinamento è corretto per i numeri $a = 2^{\frac{1}{2}}$, $b = 3^{\frac{1}{3}}$ e $c = 6^{\frac{1}{6}}$?

- $a < b < c$
- $c < b < a$
- $b < a < c$
- $c < a < b$

## Spiegazione

I tre numeri sono positivi, e la funzione $y = x^{6}$ è strettamente crescente per $x > 0$, quindi confrontare i tre numeri equivale a confrontare le loro seste potenze. Per la regola della potenza di una potenza $a^{6} = 2^{3} = 8$, $b^{6} = 3^{2} = 9$ e $c^{6} = 6^{1} = 6$. Poiché $6 < 8 < 9$, si ottiene $c < a < b$.
