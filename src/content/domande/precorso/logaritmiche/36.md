Quali $x$ verificano la doppia disuguaglianza $1 < \log_3 x < 2$?

- $1 < x < 2$
- $0 < x < 3$ oppure $x > 9$
- $3 < x < 9$
- $0 < x < 9$

## Spiegazione

La condizione di esistenza è $x > 0$. I numeri $1$ e $2$ si scrivono come logaritmi in base $3$, cioè $1 = \log_3 3$ e $2 = \log_3 9$, e la disequazione diventa $\log_3 3 < \log_3 x < \log_3 9$. La base $3$ è maggiore di $1$, quindi la funzione logaritmica è crescente e il verso si mantiene nel passaggio agli argomenti. Si ottiene $3 < x < 9$, e questi valori soddisfano la condizione $x > 0$.
