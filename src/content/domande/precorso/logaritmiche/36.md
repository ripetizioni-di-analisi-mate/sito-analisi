Quali sono le soluzioni della disequazione $\log_5 (2x - 3) \leq 0$?

- $x \leq 2$
- $x \geq 2$
- $\dfrac{3}{2} < x < 2$
- $\dfrac{3}{2} < x \leq 2$

## Spiegazione

Il numero $0$ si scrive $\log_5 1$, quindi la disequazione diventa $\log_5 (2x - 3) \leq \log_5 1$. La base $5$ è maggiore di $1$, perciò il verso si mantiene e, insieme alla condizione di esistenza, si ottiene il sistema
$$
\begin{cases}
2x - 3 \leq 1 \\
2x - 3 > 0
\end{cases}
\iff
\begin{cases}
x \leq 2 \\
x > \dfrac{3}{2}
\end{cases}
$$
Le soluzioni sono quindi $\dfrac{3}{2} < x \leq 2$, con l'estremo $2$ incluso perché $\log_5 1 = 0$.
