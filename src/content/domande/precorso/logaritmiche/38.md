Quali sono le soluzioni della disequazione $\log_2 x + \log_2 (x - 2) < 3$?

- $-2 < x < 4$
- $x > 4$
- $2 < x < 4$
- $0 < x < 4$

## Spiegazione

Le condizioni di esistenza formano il sistema
$$
\begin{cases}
x > 0 \\
x - 2 > 0
\end{cases}
\iff x > 2 .
$$
Sotto queste condizioni si applica la proprietà del logaritmo del prodotto, e la disequazione diventa $\log_2 \bigl(x(x - 2)\bigr) < \log_2 8$. La base è maggiore di $1$, quindi il verso si mantiene e si ottiene $x^{2} - 2x - 8 < 0$, cioè $(x - 4)(x + 2) < 0$, soddisfatta per $-2 < x < 4$. Intersecando con la condizione $x > 2$, le soluzioni sono $2 < x < 4$.
