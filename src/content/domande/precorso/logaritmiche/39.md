Quali sono le soluzioni della disequazione $(\log_2 x)^{2} - \log_2 x - 2 < 0$?

- $-1 < x < 2$
- $\dfrac{1}{2} < x < 4$
- $0 < x < 4$
- $x < \dfrac{1}{2}$ oppure $x > 4$

## Spiegazione

La condizione di esistenza è $x > 0$. Con la sostituzione $t = \log_2 x$ la disequazione diventa $t^{2} - t - 2 < 0$, cioè $(t - 2)(t + 1) < 0$, soddisfatta per $-1 < t < 2$. Quindi $\log_2 \dfrac{1}{2} < \log_2 x < \log_2 4$, e poiché la base $2$ è maggiore di $1$ il verso si mantiene e dà $\dfrac{1}{2} < x < 4$. Questi valori sono positivi, perciò soddisfano la condizione di esistenza.
