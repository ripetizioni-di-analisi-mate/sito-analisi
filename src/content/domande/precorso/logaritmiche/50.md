Dove è negativo il quoziente $\dfrac{\log_2 x}{x - 3}$?

- $0 < x < 1$ oppure $x > 3$
- $0 < x < 3$
- $x < 3$
- $1 < x < 3$

## Spiegazione

Il logaritmo richiede $x > 0$ e il denominatore richiede $x \neq 3$, quindi le condizioni di esistenza formano il sistema
$$
\begin{cases}
x > 0 \\
x \neq 3
\end{cases}
$$
La base $2$ è maggiore di $1$, perciò il numeratore $\log_2 x$ è negativo per $0 < x < 1$, nullo per $x = 1$ e positivo per $x > 1$. Il denominatore $x - 3$ è negativo per $x < 3$ e positivo per $x > 3$. Il quoziente è negativo dove numeratore e denominatore hanno segni opposti, cioè per $1 < x < 3$.
