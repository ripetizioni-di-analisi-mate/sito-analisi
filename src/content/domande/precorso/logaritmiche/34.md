Quali sono le soluzioni della disequazione $\log_2 (x + 3) < 3$?

- $x < 5$
- $x > 5$
- $-3 < x < 5$
- $-3 < x < 3$

## Spiegazione

Il numero $3$ si scrive come logaritmo in base $2$, cioè $3 = \log_2 (2^{3}) = \log_2 8$. La base è maggiore di $1$, quindi il verso si mantiene e si ottiene $x + 3 < 8$. In questo caso la positività dell'argomento non segue dalla disuguaglianza, perciò va scritta nel sistema
$$
\begin{cases}
x + 3 < 8 \\
x + 3 > 0
\end{cases}
\iff
\begin{cases}
x < 5 \\
x > -3
\end{cases}
$$
Le soluzioni sono quindi $-3 < x < 5$.
