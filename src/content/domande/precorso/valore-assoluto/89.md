Risolvendo per zone l'equazione $|x| + |x - 1| + |x - 2| = 4$, qual è l'insieme completo delle soluzioni?

- $x = -1 \ \vee \ x = -\dfrac{1}{3} \ \vee \ x = \dfrac{7}{3} \ \vee \ x = 3$
- $x = \dfrac{7}{3}$
- $x = 0 \ \vee \ x = 1 \ \vee \ x = 2$
- $x = -\dfrac{1}{3} \ \vee \ x = \dfrac{7}{3}$

## Spiegazione

Gli argomenti si annullano in $0$, $1$ e $2$, quindi le zone sono quattro. Per $x < 0$ l'equazione diventa $3 - 3x = 4$, quindi $x = -\dfrac{1}{3}$, che appartiene alla zona. Per $0 \leq x < 1$ diventa $3 - x = 4$, quindi $x = -1$, fuori dalla zona. Per $1 \leq x < 2$ diventa $x + 1 = 4$, quindi $x = 3$, fuori dalla zona. Per $x \geq 2$ diventa $3x - 3 = 4$, quindi $x = \dfrac{7}{3}$, che appartiene alla zona. Le soluzioni sono perciò $x = -\dfrac{1}{3}$ e $x = \dfrac{7}{3}$.
