Qual è l'elenco completo dei numeri reali che soddisfano $|x| = x^2 - 2$?

- $x = 2$
- $x = -2 \ \vee \ x = -1 \ \vee \ x = 1 \ \vee \ x = 2$
- $x = -1 \ \vee \ x = 2$
- $x = -2 \ \vee \ x = 2$

## Spiegazione

L'equazione ha la forma $|A| = B$ con $B = x^2 - 2$, quindi richiede la condizione $x^2 - 2 \geq 0$. Il caso $x = x^2 - 2$ dà $x^2 - x - 2 = 0$, cioè $(x - 2)(x + 1) = 0$, quindi $x = 2$ oppure $x = -1$. Il caso $x = -(x^2 - 2)$ dà $x^2 + x - 2 = 0$, cioè $(x + 2)(x - 1) = 0$, quindi $x = -2$ oppure $x = 1$. In $x = \pm 2$ si ha $x^2 - 2 = 2 \geq 0$, mentre in $x = \pm 1$ si ha $x^2 - 2 = -1 < 0$, perciò le soluzioni sono $x = -2$ e $x = 2$.
