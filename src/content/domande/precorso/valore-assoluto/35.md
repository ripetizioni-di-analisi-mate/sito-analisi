Quali sono le soluzioni della disequazione $|4 - x| \geq 1$?

- $3 \leq x \leq 5$
- $x < 3 \ \vee \ x > 5$
- $x \leq -5 \ \vee \ x \geq -3$
- $x \leq 3 \ \vee \ x \geq 5$

## Spiegazione

Poiché $1 > 0$, la disequazione equivale a $4 - x \leq -1 \ \vee \ 4 - x \geq 1$. Dalla prima si ottiene $-x \leq -5$, cioè $x \geq 5$; dalla seconda si ottiene $-x \geq -3$, cioè $x \leq 3$. Le soluzioni sono l'**unione** delle due semirette, con gli estremi inclusi perché la disuguaglianza è larga. Poiché $|4 - x| = |x - 4|$ è la distanza di $x$ da $4$, si tratta dei punti a distanza almeno $1$ da $4$.
