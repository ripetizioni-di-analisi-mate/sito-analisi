Quali numeri reali $x$ soddisfano la doppia disuguaglianza $2 \leq |x - 1| \leq 5$?

- $-4 \leq x \leq -1 \ \vee \ 3 \leq x \leq 6$
- $-4 \leq x \leq 6$
- $x \leq -1 \ \vee \ x \geq 3$
- $-4 < x < -1 \ \vee \ 3 < x < 6$

## Spiegazione

La doppia disuguaglianza equivale al sistema
$$
\begin{cases}
|x - 1| \geq 2 \\
|x - 1| \leq 5
\end{cases}
$$
Poiché $2 > 0$, la prima condizione equivale a $x - 1 \leq -2 \ \vee \ x - 1 \geq 2$, cioè a $x \leq -1 \ \vee \ x \geq 3$. Poiché $5 > 0$, la seconda equivale a $-5 \leq x - 1 \leq 5$, cioè a $-4 \leq x \leq 6$. Le due condizioni devono valere insieme, quindi le soluzioni sono $-4 \leq x \leq -1 \ \vee \ 3 \leq x \leq 6$, con gli estremi inclusi perché le disuguaglianze sono larghe. Sono i punti la cui distanza da $1$ è compresa fra $2$ e $5$.
