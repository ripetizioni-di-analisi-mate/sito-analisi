- $1 \leq x \leq 3$
- $-3 \leq x \leq -1 \ \vee \ 1 \leq x \leq 3$
- $-3 \leq x \leq 3$
- $-3 < x < -1 \ \vee \ 1 < x < 3$

## Spiegazione

Poiché $4 > 0$, la disequazione equivale a $-4 \leq x^2 - 5 \leq 4$, cioè a $1 \leq x^2 \leq 9$. Le due condizioni vanno soddisfatte insieme:
$$
\begin{cases}
x^2 \geq 1 \\
x^2 \leq 9
\end{cases}
\qquad
\begin{cases}
x \leq -1 \ \vee \ x \geq 1 \\
-3 \leq x \leq 3
\end{cases}
$$
L'intersezione è $-3 \leq x \leq -1 \ \vee \ 1 \leq x \leq 3$. Gli estremi sono inclusi, perché la disuguaglianza è larga e in $x = \pm 1$ e $x = \pm 3$ il primo membro vale esattamente $4$.
