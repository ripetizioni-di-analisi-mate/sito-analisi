Fra i numeri reali $x$, quali soddisfano $|x| + |x + 1| = |2x + 1|$?

- $x \geq 0$
- $x \leq -1 \ \vee \ x \geq 0$
- $x = -1 \ \vee \ x = 0$
- $x < -1 \ \vee \ x > 0$

## Spiegazione

Gli argomenti si annullano in $-1$, in $-\dfrac{1}{2}$ e in $0$, quindi le zone sono quattro. Per $x < -1$ i tre argomenti sono negativi e l'equazione diventa $-x - (x + 1) = -(2x + 1)$, cioè $-2x - 1 = -2x - 1$, vera per ogni $x$ della zona. Per $-1 \leq x < -\dfrac{1}{2}$ diventa $-x + (x + 1) = -(2x + 1)$, cioè $1 = -2x - 1$, che dà $x = -1$, accettabile. Per $-\dfrac{1}{2} \leq x < 0$ diventa $-x + (x + 1) = 2x + 1$, che dà $x = 0$, fuori dalla zona. Per $x \geq 0$ diventa $x + (x + 1) = 2x + 1$, vera per ogni $x$ della zona. Le soluzioni sono perciò $x \leq -1 \ \vee \ x \geq 0$, cioè i valori per cui $x$ e $x + 1$ non hanno segni opposti, come nel caso di uguaglianza della disuguaglianza triangolare.
