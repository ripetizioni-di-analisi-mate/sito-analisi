Quali sono le soluzioni della disequazione $|x^2 - 1| < 3$?

- $x < -2 \ \vee \ x > 2$
- $-2 < x < -\sqrt{2} \ \vee \ \sqrt{2} < x < 2$
- $-2 < x < 2$
- $-2 < x < -1 \ \vee \ 1 < x < 2$

## Spiegazione

Poiché $3 > 0$, la disequazione equivale a $-3 < x^2 - 1 < 3$, cioè al sistema
$$
\begin{cases}
x^2 > -2 \\
x^2 < 4
\end{cases}
$$
La prima condizione è soddisfatta da ogni $x$ reale, perché un quadrato non è mai negativo. La seconda equivale a $-2 < x < 2$. Le soluzioni sono perciò $-2 < x < 2$.
