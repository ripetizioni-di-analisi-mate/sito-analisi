Per $x$ reale, quando vale $|x^3| < x$?

- $x < -1 \ \vee \ 0 < x < 1$
- $-1 < x < 1$
- $0 < x < 1$
- $0 \leq x \leq 1$

## Spiegazione

La disequazione $|A| < B$ equivale al sistema delle due condizioni $A < B$ e $A > -B$:
$$
\begin{cases}
x^3 < x \\
x^3 > -x
\end{cases}
\qquad
\begin{cases}
x(x - 1)(x + 1) < 0 \\
x(x^2 + 1) > 0
\end{cases}
$$
La prima condizione è soddisfatta per $x < -1$ e per $0 < x < 1$. Nella seconda il fattore $x^2 + 1$ è positivo, quindi la condizione equivale a $x > 0$. Le due condizioni devono valere insieme, perciò le soluzioni sono $0 < x < 1$.
