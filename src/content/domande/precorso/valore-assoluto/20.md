Quali sono le soluzioni dell'equazione $|4x + 1| = 9$?

- $x = 2$
- $x = -2 \ \vee \ x = \dfrac{5}{2}$
- $x = -\dfrac{5}{2} \ \vee \ x = 2$
- $x = -2 \ \vee \ x = 2$

## Spiegazione

Poiché $9 > 0$, l'equazione equivale a $4x + 1 = 9 \ \vee \ 4x + 1 = -9$. Dalla prima si ottiene $4x = 8$, quindi $x = 2$. Dalla seconda si ottiene $4x = -10$, quindi $x = -\dfrac{10}{4} = -\dfrac{5}{2}$. Le soluzioni sono perciò $x = -\dfrac{5}{2}$ e $x = 2$.
