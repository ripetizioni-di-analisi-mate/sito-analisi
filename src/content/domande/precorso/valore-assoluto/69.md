Tutte le soluzioni reali di $|x^2 - 4| = 3\,|x|$ sono date da quale elenco?

- $x = -1 \ \vee \ x = 4$
- $x = -4 \ \vee \ x = -1 \ \vee \ x = 1 \ \vee \ x = 4$
- $x = -2 \ \vee \ x = 0 \ \vee \ x = 2$
- $x = 1 \ \vee \ x = 4$

## Spiegazione

Poiché $3\,|x| = |3x|$, l'equazione ha la forma $|A| = |B|$ ed equivale a $x^2 - 4 = 3x \ \vee \ x^2 - 4 = -3x$. La prima diventa $x^2 - 3x - 4 = 0$, cioè $(x - 4)(x + 1) = 0$, con soluzioni $x = 4$ e $x = -1$. La seconda diventa $x^2 + 3x - 4 = 0$, cioè $(x + 4)(x - 1) = 0$, con soluzioni $x = -4$ e $x = 1$. Le soluzioni sono perciò $x = -4$, $x = -1$, $x = 1$ e $x = 4$.
