Quali sono le soluzioni dell'equazione $|x^2 - 4| = |x^2 - 2x|$?

- $x = 2$
- $x = -1 \ \vee \ x = 2$
- $x = -2 \ \vee \ x = 1$
- $x = -2 \ \vee \ x = 2$

## Spiegazione

Due numeri hanno lo stesso valore assoluto quando sono uguali oppure opposti, quindi l'equazione equivale a $x^2 - 4 = x^2 - 2x \ \vee \ x^2 - 4 = -(x^2 - 2x)$. La prima si riduce a $2x = 4$, cioè $x = 2$. La seconda diventa $2x^2 - 2x - 4 = 0$, cioè $x^2 - x - 2 = 0$, con soluzioni $x = 2$ e $x = -1$. L'unione delle soluzioni è perciò $x = -1 \ \vee \ x = 2$.
