Quali sono le soluzioni della disequazione $|x^2 - 5x| > 6$?

- $x < -1 \ \vee \ x > 6$
- $2 < x < 3$
- $-1 < x < 2 \ \vee \ 3 < x < 6$
- $x < -1 \ \vee \ 2 < x < 3 \ \vee \ x > 6$

## Spiegazione

Poiché $6 > 0$, la disequazione equivale a $x^2 - 5x < -6 \ \vee \ x^2 - 5x > 6$. La prima si scrive $x^2 - 5x + 6 < 0$, cioè $(x - 2)(x - 3) < 0$, ed è soddisfatta per $2 < x < 3$. La seconda si scrive $x^2 - 5x - 6 > 0$, cioè $(x - 6)(x + 1) > 0$, ed è soddisfatta per $x < -1$ e per $x > 6$. Le soluzioni sono perciò l'**unione** dei tre intervalli, $x < -1 \ \vee \ 2 < x < 3 \ \vee \ x > 6$.
