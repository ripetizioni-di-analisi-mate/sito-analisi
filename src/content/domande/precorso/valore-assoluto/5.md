- $x = 3$
- $x = -1 \ \vee \ x = 3$
- $x = -1$
- $x = 1 \ \vee \ x = 3$

## Spiegazione

Il primo membro non è mai negativo, quindi l'equazione richiede la condizione $2x \geq 0$, cioè $x \geq 0$:
$$
\begin{cases}
x \geq 0 \\
x + 3 = 2x
\end{cases}
\ \cup \
\begin{cases}
x \geq 0 \\
x + 3 = -2x
\end{cases}
$$
Il primo sistema dà $x = 3$, che soddisfa la condizione. Il secondo dà $3x = -3$, cioè $x = -1$, che non soddisfa la condizione $x \geq 0$ e si **scarta**. L'unica soluzione è perciò $x = 3$.
