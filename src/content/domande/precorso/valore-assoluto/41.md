Dove è vera la disuguaglianza $|x - 1| > x^2 - 1$?

- $-2 < x < 1$
- $x < -2 \ \vee \ x > 1$
- $x < 1$
- $-2 \leq x \leq 1$

## Spiegazione

La disequazione $|A| > B$ equivale all'unione $A > B \ \vee \ A < -B$, senza condizioni sul segno di $B$. La disuguaglianza $x - 1 > x^2 - 1$ diventa $x^2 - x < 0$, soddisfatta per $0 < x < 1$. La disuguaglianza $x - 1 < 1 - x^2$ diventa $x^2 + x - 2 < 0$, cioè $(x + 2)(x - 1) < 0$, soddisfatta per $-2 < x < 1$. L'**unione** dei due intervalli è $-2 < x < 1$.
