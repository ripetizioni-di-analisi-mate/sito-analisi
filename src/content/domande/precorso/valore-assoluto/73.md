Un numero reale $x$ deve soddisfare sia $|x - 1| < 2$ sia $|x + 1| < 2$. Per quali $x$ questo accade?

- $-3 < x < 3$
- $-1 < x < 1$
- $-1 < x < 3$
- $-3 < x < 1$

## Spiegazione

La prima disequazione equivale a $-2 < x - 1 < 2$, cioè $-1 < x < 3$. La seconda equivale a $-2 < x + 1 < 2$, cioè $-3 < x < 1$. Le due condizioni devono valere insieme:
$$
\begin{cases}
-1 < x < 3 \\
-3 < x < 1
\end{cases}
$$
Perciò le soluzioni sono $-1 < x < 1$, cioè i numeri che distano meno di $2$ sia da $1$ sia da $-1$.
