Quali sono le soluzioni della disequazione $|x - 2| \geq |2x + 1|$?

- $x \leq -3 \ \vee \ x \geq \dfrac{1}{3}$
- $-\dfrac{1}{3} \leq x \leq 3$
- $-3 < x < \dfrac{1}{3}$
- $-3 \leq x \leq \dfrac{1}{3}$

## Spiegazione

Poiché i due membri non sono negativi, la disequazione equivale a $(x - 2)^2 \geq (2x + 1)^2$. Sviluppando si ottiene $x^2 - 4x + 4 \geq 4x^2 + 4x + 1$, cioè $3x^2 + 8x - 3 \leq 0$. Il trinomio $3x^2 + 8x - 3 = (3x - 1)(x + 3)$ si annulla in $x = -3$ e in $x = \dfrac{1}{3}$, ed è minore o uguale a zero tra le due radici. Le soluzioni sono perciò $-3 \leq x \leq \dfrac{1}{3}$, con gli estremi inclusi perché la disuguaglianza è larga.
