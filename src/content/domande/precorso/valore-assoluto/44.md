Quali sono le soluzioni dell'equazione $|2x - 4| = |x| + 1$?

- $x = 1$
- $x = 1 \ \vee \ x = 5$
- $x = 3 \ \vee \ x = 5$
- $x = 1 \ \vee \ x = 3 \ \vee \ x = 5$

## Spiegazione

Gli argomenti $2x - 4$ e $x$ si annullano in $2$ e in $0$, quindi le zone sono tre:
$$
\begin{cases}
x < 0 \\
4 - 2x = -x + 1
\end{cases}
\ \cup \
\begin{cases}
0 \leq x < 2 \\
4 - 2x = x + 1
\end{cases}
\ \cup \
\begin{cases}
x \geq 2 \\
2x - 4 = x + 1
\end{cases}
$$
Nella prima zona si ottiene $x = 3$, che non soddisfa $x < 0$ e si scarta. Nella seconda si ottiene $3x = 3$, cioè $x = 1$, accettabile poiché $0 \leq 1 < 2$. Nella terza si ottiene $x = 5$, accettabile poiché $5 \geq 2$. Le soluzioni sono perciò $x = 1$ e $x = 5$.
