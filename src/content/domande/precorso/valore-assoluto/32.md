Quali sono le soluzioni della disequazione $|1 - 2x| < 3$?

- $-2 < x < 1$
- $x < -1 \ \vee \ x > 2$
- $-1 \leq x \leq 2$
- $-1 < x < 2$

## Spiegazione

Poiché $3 > 0$, la disequazione equivale alla doppia disuguaglianza $-3 < 1 - 2x < 3$. Sottraendo $1$ a tutti i membri si ottiene $-4 < -2x < 2$. Dividendo per $-2$, che è negativo, i versi delle disuguaglianze si invertono, quindi $2 > x > -1$, cioè $-1 < x < 2$. Gli estremi sono esclusi perché la disuguaglianza è stretta.
