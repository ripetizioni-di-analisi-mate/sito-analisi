Con il secondo membro $x + 4$ variabile, l'equazione $|x - 1| + |x + 1| = x + 4$ quali soluzioni ammette?

- $x = -\dfrac{4}{3} \ \vee \ x = 4$
- $x = -2 \ \vee \ x = -\dfrac{4}{3} \ \vee \ x = 4$
- $x = 4$
- $x = -1 \ \vee \ x = 1$

## Spiegazione

Gli argomenti si annullano in $-1$ e in $1$. Per $x < -1$ l'equazione diventa $(1 - x) + (-x - 1) = x + 4$, cioè $-2x = x + 4$, quindi $x = -\dfrac{4}{3}$, che è minore di $-1$ e si accetta. Per $-1 \leq x < 1$ diventa $(1 - x) + (x + 1) = x + 4$, cioè $2 = x + 4$, quindi $x = -2$, che non appartiene alla zona e si scarta. Per $x \geq 1$ diventa $(x - 1) + (x + 1) = x + 4$, cioè $2x = x + 4$, quindi $x = 4$, che si accetta. Le soluzioni sono perciò $x = -\dfrac{4}{3}$ e $x = 4$.
