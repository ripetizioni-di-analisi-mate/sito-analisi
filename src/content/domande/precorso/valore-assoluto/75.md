Risolvendo $\dfrac{1}{|x - 3|} > 2$, quale insieme di soluzioni si ottiene?

- $\dfrac{5}{2} < x < \dfrac{7}{2}$
- $x < \dfrac{5}{2} \ \vee \ x > \dfrac{7}{2}$
- $-\dfrac{7}{2} < x < -3 \ \vee \ -3 < x < -\dfrac{5}{2}$
- $\dfrac{5}{2} < x < 3 \ \vee \ 3 < x < \dfrac{7}{2}$

## Spiegazione

La frazione è definita per $x \neq 3$, e per questi valori si ha $|x - 3| > 0$. Moltiplicando i due membri per il numero positivo $|x - 3|$ il verso non cambia, quindi la disequazione equivale a $1 > 2\,|x - 3|$, cioè $|x - 3| < \dfrac{1}{2}$. Questa equivale a $-\dfrac{1}{2} < x - 3 < \dfrac{1}{2}$, perciò $\dfrac{5}{2} < x < \dfrac{7}{2}$. Togliendo il valore $x = 3$, escluso dalla condizione di esistenza, si ottiene $\dfrac{5}{2} < x < 3 \ \vee \ 3 < x < \dfrac{7}{2}$.
