L'equazione $\bigl|\,|x| - 3\,\bigr| = 1$ contiene un valore assoluto dentro un altro. Quali sono tutte le sue soluzioni?

- $x = 2 \ \vee \ x = 4$
- $x = -4 \ \vee \ x = 4$
- $x = -2 \ \vee \ x = 2$
- $x = -4 \ \vee \ x = -2 \ \vee \ x = 2 \ \vee \ x = 4$

## Spiegazione

Poiché $1 > 0$, l'equazione equivale a $|x| - 3 = 1 \ \vee \ |x| - 3 = -1$, cioè $|x| = 4 \ \vee \ |x| = 2$. L'equazione $|x| = 4$ ha le soluzioni $x = \pm 4$, e l'equazione $|x| = 2$ ha le soluzioni $x = \pm 2$. Perciò l'equazione data ha le quattro soluzioni $x = -4$, $x = -2$, $x = 2$ e $x = 4$.
