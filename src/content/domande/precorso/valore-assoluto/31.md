Quali sono le soluzioni della disequazione $|3x + 2| \leq 4$?

- $-2 \leq x \leq \dfrac{2}{3}$
- $-\dfrac{2}{3} \leq x \leq 2$
- $x \leq -2 \ \vee \ x \geq \dfrac{2}{3}$
- $-2 < x < \dfrac{2}{3}$

## Spiegazione

Poiché $4 > 0$, la disequazione equivale alla doppia disuguaglianza $-4 \leq 3x + 2 \leq 4$. Sottraendo $2$ a tutti i membri si ottiene $-6 \leq 3x \leq 2$. Dividendo per $3$, che è positivo, i versi restano invariati, quindi $-2 \leq x \leq \dfrac{2}{3}$. Gli estremi sono inclusi perché la disuguaglianza è larga.
