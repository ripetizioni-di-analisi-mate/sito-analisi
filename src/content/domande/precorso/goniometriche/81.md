Quali $x \in [0, 2\pi)$ soddisfano la disequazione $\dfrac{2\sin x - 1}{\cos x} \geq 0$?

- $\dfrac{\pi}{6} \leq x \leq \dfrac{\pi}{2}$ oppure $\dfrac{5\pi}{6} \leq x \leq \dfrac{3\pi}{2}$
- $\dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}$
- $\dfrac{\pi}{6} \leq x < \dfrac{\pi}{2}$ oppure $\dfrac{5\pi}{6} \leq x < \dfrac{3\pi}{2}$
- $0 \leq x \leq \dfrac{\pi}{6}$, $\dfrac{\pi}{2} < x \leq \dfrac{5\pi}{6}$ oppure $\dfrac{3\pi}{2} < x < 2\pi$

## Spiegazione

Il numeratore è maggiore o uguale a $0$ per $\sin x \geq \dfrac{1}{2}$, cioè per $\dfrac{\pi}{6} \leq x \leq \dfrac{5\pi}{6}$. Il denominatore è positivo per $0 \leq x < \dfrac{\pi}{2}$ e per $\dfrac{3\pi}{2} < x < 2\pi$, è negativo per $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$ e si annulla in $\dfrac{\pi}{2}$ e in $\dfrac{3\pi}{2}$.

La frazione è positiva o nulla dove numeratore e denominatore hanno lo stesso segno oppure il numeratore è nullo. Questo accade per $\dfrac{\pi}{6} \leq x < \dfrac{\pi}{2}$, dove il numeratore è positivo o nullo e il denominatore è positivo, e per $\dfrac{5\pi}{6} \leq x < \dfrac{3\pi}{2}$, dove sono negativi entrambi oppure il numeratore è nullo.

Gli estremi $\dfrac{\pi}{2}$ e $\dfrac{3\pi}{2}$ sono esclusi perché in essi si annulla il denominatore.
