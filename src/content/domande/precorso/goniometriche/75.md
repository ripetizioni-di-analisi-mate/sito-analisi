Per quali $x \in [0, 2\pi)$ si ha $\sin 2x > 0$?

- $0 < x < \dfrac{\pi}{2}$ oppure $\pi < x < \dfrac{3\pi}{2}$
- $0 < x < \pi$
- $0 < x < \dfrac{\pi}{2}$
- $0 \leq x \leq \dfrac{\pi}{2}$ oppure $\pi \leq x \leq \dfrac{3\pi}{2}$

## Spiegazione

Il seno di un angolo $t$ è positivo per $2n\pi < t < \pi + 2n\pi$. Con $t = 2x$ la condizione diventa $2n\pi < 2x < \pi + 2n\pi$, cioè $n\pi < x < \dfrac{\pi}{2} + n\pi$.

In $[0, 2\pi)$ cadono gli intervalli con $n = 0$ e con $n = 1$, cioè $0 < x < \dfrac{\pi}{2}$ e $\pi < x < \dfrac{3\pi}{2}$.

Lo stesso risultato si ottiene da $\sin 2x = 2\sin x\cos x$, che è positivo quando seno e coseno hanno lo stesso segno, cioè nel primo e nel terzo quadrante.
