Con l'identità fondamentale si risolve l'equazione $\sin^2 x + \sin x\cos x = 1$. Quali soluzioni si ottengono?

- $x = \dfrac{\pi}{4} + n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{2} + n\pi$ oppure $x = \dfrac{\pi}{4} + n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{2} + n\pi$ oppure $x = -\dfrac{\pi}{4} + n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{2} + 2n\pi$ oppure $x = \dfrac{\pi}{4} + 2n\pi$, con $n \in \mathbb{Z}$

## Spiegazione

Per l'identità fondamentale $1 = \sin^2 x + \cos^2 x$, quindi l'equazione diventa $\sin x\cos x = \cos^2 x$, cioè
$$
\cos x\,(\sin x - \cos x) = 0 .
$$
Dal primo fattore segue $x = \dfrac{\pi}{2} + n\pi$. Nel secondo fattore i punti con $\cos x = 0$ non danno soluzioni, perché per essi $\sin x = \pm 1$; si può quindi dividere per $\cos x$, e si ottiene $\tan x = 1$, cioè $x = \dfrac{\pi}{4} + n\pi$.

Dividendo l'equazione $\sin x\cos x = \cos^2 x$ per $\cos x$ si perderebbe la famiglia $x = \dfrac{\pi}{2} + n\pi$, che è soluzione perché per essa $\sin^2 x = 1$ e $\sin x\cos x = 0$.
