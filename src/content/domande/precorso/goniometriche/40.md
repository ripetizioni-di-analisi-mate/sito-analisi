Quali sono le soluzioni dell'equazione $\sqrt{3}\sin x - \cos x = 1$?

- $x = \dfrac{\pi}{3} + 2n\pi$ oppure $x = \pi + 2n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{2\pi}{3} + 2n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{3} + 2n\pi$ oppure $x = \dfrac{5\pi}{6} + 2n\pi$, con $n \in \mathbb{Z}$
- $x = 2n\pi$ oppure $x = \dfrac{2\pi}{3} + 2n\pi$, con $n \in \mathbb{Z}$

## Spiegazione

Nell'equazione $a\sin x + b\cos x = c$ si ha $a = \sqrt{3}$ e $b = -1$, quindi $R = \sqrt{3 + 1} = 2$. L'angolo con $\cos\varphi = \dfrac{\sqrt{3}}{2}$ e $\sin\varphi = -\dfrac{1}{2}$ è $\varphi = -\dfrac{\pi}{6}$.

Con il metodo dell'angolo aggiunto l'equazione diventa $2\sin\left(x - \dfrac{\pi}{6}\right) = 1$, cioè $\sin\left(x - \dfrac{\pi}{6}\right) = \dfrac{1}{2}$. Perciò
$$
x - \frac{\pi}{6} = \frac{\pi}{6} + 2n\pi \quad \text{oppure} \quad x - \frac{\pi}{6} = \frac{5\pi}{6} + 2n\pi, \qquad n \in \mathbb{Z} .
$$
Aggiungendo $\dfrac{\pi}{6}$ si ottengono le soluzioni $x = \dfrac{\pi}{3} + 2n\pi$ oppure $x = \pi + 2n\pi$.
