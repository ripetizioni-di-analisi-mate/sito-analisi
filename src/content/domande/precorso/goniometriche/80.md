Il primo membro di $\sin x + \cos x = \sqrt{2}$ si può scrivere con il metodo dell'angolo aggiunto. Quali $x$ risolvono l'equazione?

- $x = \dfrac{\pi}{4} + n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{4} + 2n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{3\pi}{4} + 2n\pi$, con $n \in \mathbb{Z}$
- L'equazione non ha soluzioni

## Spiegazione

Con il metodo dell'angolo aggiunto, per $a = b = 1$ si ha $R = \sqrt{2}$ e $\varphi = \dfrac{\pi}{4}$, perché $\cos\varphi = \sin\varphi = \dfrac{\sqrt{2}}{2}$. Quindi $\sin x + \cos x = \sqrt{2}\sin\left(x + \dfrac{\pi}{4}\right)$.

L'equazione diventa $\sin\left(x + \dfrac{\pi}{4}\right) = 1$, che ha le sole soluzioni $x + \dfrac{\pi}{4} = \dfrac{\pi}{2} + 2n\pi$, cioè $x = \dfrac{\pi}{4} + 2n\pi$.

Il primo membro arriva fino a $R = \sqrt{2}$, perciò l'equazione ha soluzioni anche se $\sqrt{2} > 1$. Per $x = \dfrac{5\pi}{4}$, che appartiene alla famiglia $\dfrac{\pi}{4} + n\pi$, il primo membro vale $-\sqrt{2}$.
