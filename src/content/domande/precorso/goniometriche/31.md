Quali sono le soluzioni dell'equazione $\sin\left(x + \dfrac{\pi}{6}\right) = \cos x$?

- $x = \dfrac{\pi}{6} + 2n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{3} + n\pi$, con $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{6} + \dfrac{n\pi}{2}$, con $n \in \mathbb{Z}$
- $x = \dfrac{\pi}{6} + n\pi$, con $n \in \mathbb{Z}$

## Spiegazione

Dagli angoli associati $\cos x = \sin\left(\dfrac{\pi}{2} - x\right)$, quindi l'equazione diventa $\sin\left(x + \dfrac{\pi}{6}\right) = \sin\left(\dfrac{\pi}{2} - x\right)$. Le due alternative sono
$$
x + \frac{\pi}{6} = \frac{\pi}{2} - x + 2n\pi \quad \text{oppure} \quad x + \frac{\pi}{6} = \frac{\pi}{2} + x + 2n\pi .
$$
Dalla prima $2x = \dfrac{\pi}{3} + 2n\pi$, cioè $x = \dfrac{\pi}{6} + n\pi$. La seconda equivale a $2n\pi = -\dfrac{\pi}{3}$, che non è verificata da alcun intero $n$.

Perciò le soluzioni sono $x = \dfrac{\pi}{6} + n\pi$, con $n \in \mathbb{Z}$.
