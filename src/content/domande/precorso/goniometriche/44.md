Quali sono le soluzioni su $[0, 2\pi)$ della disequazione $2\sin^2 x - \sin x < 0$?

- $0 < x < \dfrac{\pi}{6}$ oppure $\dfrac{5\pi}{6} < x < \pi$
- $\dfrac{\pi}{6} < x < \dfrac{5\pi}{6}$
- $0 < x < \dfrac{\pi}{6}$
- $0 \leq x \leq \dfrac{\pi}{6}$ oppure $\dfrac{5\pi}{6} \leq x \leq \pi$

## Spiegazione

Posto $t = \sin x$, la disequazione diventa $t\,(2t - 1) < 0$. La parabola $y = 2t^2 - t$ è negativa tra le radici $0$ e $\dfrac{1}{2}$, quindi la disequazione equivale al sistema
$$
\begin{cases}
\sin x > 0 \\[4pt]
\sin x < \dfrac{1}{2}
\end{cases}
$$
Su $[0, 2\pi)$ il seno è positivo per $0 < x < \pi$, e in questo intervallo è minore di $\dfrac{1}{2}$ per $0 < x < \dfrac{\pi}{6}$ e per $\dfrac{5\pi}{6} < x < \pi$.

Perciò le soluzioni sono $0 < x < \dfrac{\pi}{6}$ oppure $\dfrac{5\pi}{6} < x < \pi$, con gli estremi esclusi perché la disuguaglianza è stretta.
