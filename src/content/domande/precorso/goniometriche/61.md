In quali punti di $[0, 2\pi)$ il coseno è negativo?

- $\pi < x < 2\pi$
- $\dfrac{\pi}{2} \leq x \leq \dfrac{3\pi}{2}$
- $0 \leq x < \dfrac{\pi}{2}$ oppure $\dfrac{3\pi}{2} < x < 2\pi$
- $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$

## Spiegazione

Il coseno è l'ascissa del punto della circonferenza goniometrica, quindi $\cos x < 0$ quando il punto sta a sinistra dell'asse delle ordinate.

I punti della circonferenza sull'asse delle ordinate corrispondono agli angoli $\dfrac{\pi}{2}$ e $\dfrac{3\pi}{2}$, e l'arco a sinistra dell'asse è quello che passa per il punto di angolo $\pi$.

Perciò la soluzione è $\dfrac{\pi}{2} < x < \dfrac{3\pi}{2}$, con gli estremi esclusi perché in essi il coseno vale $0$. L'intervallo $\pi < x < 2\pi$ è quello in cui il seno è negativo.
