Per quali valori del parametro reale $c$ l'equazione $\sin x + \sqrt{3}\cos x = c$ ha soluzioni?

- $-1 \leq c \leq 1$
- $-2 \leq c \leq 2$
- $-1 - \sqrt{3} \leq c \leq 1 + \sqrt{3}$
- $-4 \leq c \leq 4$

## Spiegazione

Con il metodo dell'angolo aggiunto, per $a = 1$ e $b = \sqrt{3}$ si ha $R = \sqrt{1 + 3} = 2$ e $\varphi = \dfrac{\pi}{3}$, quindi $\sin x + \sqrt{3}\cos x = 2\sin\left(x + \dfrac{\pi}{3}\right)$.

L'equazione diventa $\sin\left(x + \dfrac{\pi}{3}\right) = \dfrac{c}{2}$, che ha soluzioni se e solo se $-1 \leq \dfrac{c}{2} \leq 1$. Perciò l'equazione ha soluzioni per $-2 \leq c \leq 2$.

Il massimo del primo membro è quindi $2$, minore della somma dei coefficienti $1 + \sqrt{3}$.
