Qual è una scomposizione di $5 x^{2} + x - 6$?

- $\left(x + 1\right) \left(5 x + 6\right)$
- $\left(x - 1\right) \left(5 x + 6\right)$
- $\left(x - 1\right) \left(5 x - 6\right)$
- $\left(x + 1\right) \left(5 x - 6\right)$

## Spiegazione

Raggruppando i termini si ottiene la somma di $5 x \left(x - 1\right)$ e $6 x - 6$. Il fattore comune è $x-1$.
