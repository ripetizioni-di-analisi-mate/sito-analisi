In quale prodotto si scompone $x^2 + 6x + 9 - y^2$?

- $(x + 3 - y)^2$
- $(x - 3 - y)(x - 3 + y)$
- $\left( x + 3 - y^2 \right)\left( x + 3 + y^2 \right)$
- $(x + 3 - y)(x + 3 + y)$

## Spiegazione

I primi tre termini formano il **quadrato di binomio** $x^2 + 6x + 9 = (x + 3)^2$, poiché $6x = 2 \cdot x \cdot 3$. Il polinomio diventa $(x + 3)^2 - y^2$, che è una **differenza di quadrati** con $A = x + 3$ e $B = y$. Perciò $x^2 + 6x + 9 - y^2 = (x + 3 - y)(x + 3 + y)$.
