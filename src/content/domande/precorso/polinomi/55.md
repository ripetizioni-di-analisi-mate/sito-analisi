Dividendo un polinomio $P(x)$ per $x^2 + 1$ si ottengono il quoziente $x - 3$ e il resto $2x + 1$. Qual è $P(x)$?

- $x^3 - 3x^2 + 3x - 2$
- $x^3 - 3x^2 + x - 3$
- $x^3 - 3x^2 - x - 4$
- $3x^2 - 5x - 2$

## Spiegazione

Per il **teorema sulla divisione con resto** il dividendo è $P(x) = B(x)\,Q(x) + R(x)$. Il prodotto del divisore per il quoziente è $(x^2 + 1)(x - 3) = x^3 - 3x^2 + x - 3$. Aggiungendo il resto si ottiene $P(x) = x^3 - 3x^2 + x - 3 + 2x + 1 = x^3 - 3x^2 + 3x - 2$. Il resto $2x + 1$ ha grado $1 < 2$, quindi è compatibile con il divisore $x^2 + 1$.
