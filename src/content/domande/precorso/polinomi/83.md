Qual è una scomposizione di $4 x^{2} + x - 5$?

- $\left(x - 1\right) \left(4 x - 5\right)$
- $\left(x + 1\right) \left(4 x - 5\right)$
- $\left(x - 1\right) \left(4 x + 5\right)$
- $\left(x + 1\right) \left(4 x + 5\right)$

## Spiegazione

Raggruppando i termini si ottiene la somma di $4 x \left(x - 1\right)$ e $5 x - 5$. Il fattore comune è $x-1$.
