Qual è una scomposizione di $3 x^{2} + x - 4$?

- $\left(x - 1\right) \left(3 x - 4\right)$
- $\left(x + 1\right) \left(3 x + 4\right)$
- $\left(x + 1\right) \left(3 x - 4\right)$
- $\left(x - 1\right) \left(3 x + 4\right)$

## Spiegazione

Raggruppando i termini si ottiene la somma di $3 x \left(x - 1\right)$ e $4 x - 4$. Il fattore comune è $x-1$.
