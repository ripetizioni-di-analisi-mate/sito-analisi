Per quali valori reali di $x$ è vera la proposizione $x \leq -2 \ \lor \ x^2 \leq 1$?

- $-1 \leq x \leq 1$
- $-2 \leq x \leq 1$
- $x \leq 1$
- $x \leq -2 \ \lor \ -1 \leq x \leq 1$

## Spiegazione

La disuguaglianza $x^2 \leq 1$ è soddisfatta per $-1 \leq x \leq 1$.

Una disgiunzione è vera quando è vera almeno una delle due parti, quindi il suo insieme di verità è l'unione della semiretta $x \leq -2$ con l'intervallo $[-1, 1]$. Perciò la proposizione è vera per $x \leq -2$ oppure $-1 \leq x \leq 1$.

Per $x = -\dfrac{3}{2}$ si ha $x > -2$ e $x^2 = \dfrac{9}{4} > 1$, quindi nessuna delle due parti è vera e la proposizione è falsa.
