Qual è la negazione della proposizione $\forall x \in \mathbb{R} : x \geq 0 \ \land \ x^2 \geq 0$?

- $\exists x \in \mathbb{R} : x < 0 \ \land \ x^2 < 0$
- $\forall x \in \mathbb{R} : x < 0 \ \lor \ x^2 < 0$
- $\exists x \in \mathbb{R} : x < 0 \ \lor \ x^2 < 0$
- $\exists x \in \mathbb{R} : x \leq 0 \ \lor \ x^2 \leq 0$

## Spiegazione

Per la **negazione dei quantificatori** il simbolo $\forall$ diventa $\exists$ e si nega il predicato $x \geq 0 \land x^2 \geq 0$.

Il predicato è una congiunzione, quindi per le **leggi di De Morgan** la sua negazione è la disgiunzione delle negazioni delle due parti. La negazione di $x \geq 0$ è $x < 0$ e la negazione di $x^2 \geq 0$ è $x^2 < 0$, perciò la negazione cercata è
$$
\exists x \in \mathbb{R} : x < 0 \ \lor \ x^2 < 0 .
$$
Questa proposizione è vera, perché per $x = -1$ la prima alternativa $x < 0$ è soddisfatta.
