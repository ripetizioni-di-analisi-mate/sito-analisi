La proposizione $\forall a, b \in \mathbb{R} : (a + b)^2 = a^2 + b^2$ è falsa. Quali coppie $(a, b)$ sono controesempi?

- Tutte le coppie con $a \neq 0 \lor b \neq 0$
- Tutte le coppie con $a \neq 0 \land b \neq 0$
- Soltanto le coppie con $a = b$
- Tutte le coppie con $a = -b$

## Spiegazione

Si ha $(a + b)^2 = a^2 + 2ab + b^2$, quindi l'uguaglianza $(a + b)^2 = a^2 + b^2$ equivale a $2ab = 0$, cioè a $a = 0 \lor b = 0$.

Una coppia è un controesempio quando l'uguaglianza è falsa, cioè quando vale la negazione di $a = 0 \lor b = 0$. Per le **leggi di De Morgan** questa negazione è $a \neq 0 \land b \neq 0$. Perciò i controesempi sono tutte e sole le coppie con **$a \neq 0$ e $b \neq 0$**.

La coppia $(0, 1)$ soddisfa $a \neq 0 \lor b \neq 0$ e verifica l'uguaglianza, perché $1 = 0 + 1$. La coppia $(0, 0)$ ha $a = b = -b$ e verifica l'uguaglianza, mentre la coppia $(1, 2)$ è un controesempio con $a \neq b$.
