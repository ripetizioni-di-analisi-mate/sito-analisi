Per $x$ e $y$ reali, qual è la negazione dell'implicazione $x > 0 \Rightarrow (y > 0 \lor x + y < 1)$?

- $x > 0 \land y \leq 0 \land x + y \geq 1$
- $x > 0 \land (y \leq 0 \lor x + y \geq 1)$
- $x > 0 \Rightarrow (y \leq 0 \land x + y \geq 1)$
- $x \leq 0 \land (y > 0 \lor x + y < 1)$

## Spiegazione

Per la **negazione dell'implicazione** vale $\lnot (p \Rightarrow q) \equiv p \land \lnot q$, quindi si tiene l'ipotesi $x > 0$ e si nega la tesi $y > 0 \lor x + y < 1$.

Per le leggi di De Morgan la negazione della disgiunzione è la congiunzione delle negazioni, cioè $y \leq 0 \land x + y \geq 1$. Perciò la negazione cercata è
$$
x > 0 \land y \leq 0 \land x + y \geq 1 .
$$
Questa proposizione è vera, per esempio, per $x = 2$ e $y = 0$.
