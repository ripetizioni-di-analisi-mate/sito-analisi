Per quali valori reali di $x$ è vera la proposizione $x^2 < 9 \ \land \ x > 1$?

- $-3 < x < 3$
- $1 < x < 3$
- $x > 1$
- $x < -3 \ \lor \ x > 1$

## Spiegazione

La disuguaglianza $x^2 < 9$ è soddisfatta per $-3 < x < 3$.

Una congiunzione è vera quando sono vere entrambe le parti, quindi il suo insieme di verità è l'intersezione dell'intervallo $(-3, 3)$ con la semiretta $x > 1$. Perciò la proposizione è vera per $1 < x < 3$.

Per $x = -1$ la condizione $x^2 < 9$ è soddisfatta e la condizione $x > 1$ non lo è, quindi per $x = -1$ la congiunzione è falsa.
