Qual è la negazione della proposizione "$\forall n \in \mathbb{N} : n^2 + n$ è pari", e quale valore di verità ha?

- $\exists n \in \mathbb{N} : n^2 + n$ è dispari, ed è vera
- $\forall n \in \mathbb{N} : n^2 + n$ è dispari, ed è falsa
- $\exists n \in \mathbb{N} : n^2 + n$ è pari, ed è falsa
- $\exists n \in \mathbb{N} : n^2 + n$ è dispari, ed è falsa

## Spiegazione

La negazione scambia $\forall$ con $\exists$ e nega il predicato. La negazione di "$n^2 + n$ è pari" è "$n^2 + n$ è dispari", quindi la negazione è "$\exists n \in \mathbb{N} : n^2 + n$ è dispari".

Si ha $n^2 + n = n(n + 1)$, prodotto di due naturali consecutivi. Uno dei due fattori è pari, quindi $n^2 + n$ è pari per ogni $n$ naturale.

Perciò la proposizione di partenza è vera e la sua negazione è **falsa**.
