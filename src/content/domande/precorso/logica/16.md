Qual è la negazione della proposizione $x \leq -1 \ \lor \ x > 2$, con $x$ reale?

- $x > -1 \ \lor \ x \leq 2$
- $x \geq -1 \ \land \ x < 2$
- $x > -1 \ \land \ x \leq 2$
- $x \geq -1 \ \land \ x \leq 2$

## Spiegazione

Per le **leggi di De Morgan** la negazione di una disgiunzione è la congiunzione delle negazioni delle due parti.

La negazione di $x \leq -1$ è $x > -1$ e la negazione di $x > 2$ è $x \leq 2$. Perciò la negazione cercata è
$$
x > -1 \ \land \ x \leq 2 ,
$$
cioè $-1 < x \leq 2$.

Il valore $x = -1$ soddisfa $x \leq -1$, quindi rende vera la proposizione di partenza e non appartiene all'insieme di verità della negazione.
