Qual è la negazione della proposizione $\forall x \in \mathbb{R} : x > 0 \Longrightarrow x + 1 > 2$?

- $\exists x \in \mathbb{R} : x > 0 \ \land \ x + 1 \leq 2$
- $\exists x \in \mathbb{R} : x > 0 \Longrightarrow x + 1 \leq 2$
- $\exists x \in \mathbb{R} : x \leq 0 \ \land \ x + 1 > 2$
- $\forall x \in \mathbb{R} : x > 0 \ \land \ x + 1 \leq 2$

## Spiegazione

Per la **negazione dei quantificatori** il simbolo $\forall$ diventa $\exists$ e si nega il predicato, che è l'implicazione $x > 0 \Rightarrow x + 1 > 2$.

Per la **negazione dell'implicazione** vale $\lnot (p \Rightarrow q) \equiv p \land \lnot q$, quindi il predicato negato è la congiunzione dell'ipotesi $x > 0$ con la negazione della tesi. La negazione di $x + 1 > 2$ è $x + 1 \leq 2$, perciò la negazione cercata è
$$
\exists x \in \mathbb{R} : x > 0 \ \land \ x + 1 \leq 2 .
$$
Questa proposizione è vera, perché per $x = \dfrac{1}{2}$ si ha $x > 0$ e $x + 1 = \dfrac{3}{2} \leq 2$.
