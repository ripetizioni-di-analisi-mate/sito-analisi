Per quali $x$ vale la doppia disuguaglianza $-1 < 2x + 3 \leq 7$?

- $-2 \leq x \leq 2$
- $-2 < x < 2$
- $1 < x \leq 5$
- $-2 < x \leq 2$

## Spiegazione

La doppia disuguaglianza equivale al sistema delle disequazioni $2x + 3 > -1$ e $2x + 3 \leq 7$, che devono valere insieme. Sottraendo $3$ ai tre membri si ottiene $-4 < 2x \leq 4$. Dividendo per il numero positivo $2$ i versi si conservano, quindi $-2 < x \leq 2$. L'estremo $-2$ è escluso perché la prima disuguaglianza è stretta, l'estremo $2$ è incluso perché la seconda è larga.
