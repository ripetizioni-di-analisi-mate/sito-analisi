Quali valori di $x$ rendono positivo il prodotto $(2 - x)(x + 1)(x + 4)$?

- $-4 < x < -1$ oppure $x > 2$
- $x \leq -4$ oppure $-1 \leq x \leq 2$
- $x < -4$ oppure $-1 < x < 2$
- $x < -4$ oppure $x > 2$

## Spiegazione

Il fattore $2 - x$ ha il coefficiente di $x$ negativo, quindi è positivo per $x < 2$ e negativo per $x > 2$. Gli altri due fattori sono positivi rispettivamente per $x > -1$ e per $x > -4$. Nella **tabella dei segni** le colonne $x < -4$, $-4 < x < -1$, $-1 < x < 2$, $x > 2$ danno per il prodotto i segni $+$, $-$, $+$, $-$. Perciò il prodotto è positivo per $x < -4$ oppure $-1 < x < 2$.
