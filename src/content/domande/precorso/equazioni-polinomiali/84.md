Determinare dove il prodotto $(x^2 - 9)(x^2 + 2x + 1)$ è negativo.

- $-3 < x < 3$
- $x < -3$ oppure $x > 3$
- $-3 < x < -1$ oppure $-1 < x < 3$
- $x < -3$ oppure $-1 < x < 3$

## Spiegazione

Il secondo fattore è il quadrato $x^2 + 2x + 1 = (x + 1)^2$, positivo per $x \neq -1$ e nullo in $x = -1$. Per il **segno di un fattore elevato a potenza** il prodotto ha quindi il segno di $x^2 - 9$ per ogni $x \neq -1$, mentre in $x = -1$ vale zero. Il binomio $x^2 - 9$ è negativo per $-3 < x < 3$. Il verso $<$ esclude il punto $x = -1$, perciò le soluzioni sono $-3 < x < -1$ oppure $-1 < x < 3$.
