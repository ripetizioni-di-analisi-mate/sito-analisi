Quali sono le soluzioni del sistema seguente?
$$
\begin{cases}
\dfrac{x - 1}{x + 2} \geq 0 \\[8pt]
x^2 < 9
\end{cases}
$$

- $-3 < x \leq -2$ oppure $1 \leq x < 3$
- $-3 < x < -2$ oppure $1 \leq x < 3$
- $1 \leq x < 3$
- $-3 < x < -2$ oppure $1 < x < 3$

## Spiegazione

Nella prima disequazione la condizione di esistenza è $x \neq -2$. Il numeratore è positivo per $x > 1$ e il denominatore per $x > -2$, quindi il quoziente è positivo per $x < -2$ e per $x > 1$. Il verso $\geq$ include lo zero $1$ del numeratore ed esclude $-2$, perciò la prima disequazione ha soluzioni $x < -2$ oppure $x \geq 1$. La seconda disequazione equivale a $x^2 - 9 < 0$; il trinomio $x^2 - 9$ ha radici $\pm 3$ ed è negativo tra le radici, quindi le soluzioni sono $-3 < x < 3$. Le soluzioni del sistema sono l'**intersezione** dei due insiemi, cioè $-3 < x < -2$ oppure $1 \leq x < 3$.
