Quali sono le soluzioni della disequazione $x^4 - 5x^2 + 4 < 0$?

- $-2 < x < -1$ oppure $1 < x < 2$
- $-2 < x < 2$
- $-1 < x < 1$
- $x < -2$ oppure $-1 < x < 1$ oppure $x > 2$

## Spiegazione

Con la sostituzione $t = x^2$ il trinomio $t^2 - 5t + 4$ ha radici $1$ e $4$, quindi $x^4 - 5x^2 + 4 = (x^2 - 1)(x^2 - 4) = (x + 2)(x + 1)(x - 1)(x - 2)$. Gli zeri sono $-2$, $-1$, $1$, $2$, e ogni fattore di primo grado è negativo prima del proprio zero e positivo dopo. Dalla **tabella dei segni** il prodotto risulta negativo nelle colonne con un numero dispari di segni meno, cioè per $-2 < x < -1$ e per $1 < x < 2$. Il verso $<$ esclude gli zeri, quindi le soluzioni sono $-2 < x < -1$ oppure $1 < x < 2$.
