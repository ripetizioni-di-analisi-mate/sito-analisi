Quali valori può assumere l'ascissa $x$ di un punto dell'ellisse $\dfrac{x^2}{25} + \dfrac{y^2}{9} = 1$?

- $-5 \leq x \leq 5$
- $-25 \leq x \leq 25$
- $-10 \leq x \leq 10$
- $x \leq -5$ oppure $x \geq 5$

## Spiegazione

Poiché $\dfrac{y^2}{9} \geq 0$, ogni punto dell'ellisse soddisfa $\dfrac{x^2}{25} \leq 1$, cioè $x^2 \leq 25$, quindi $-5 \leq x \leq 5$. Viceversa, per ogni $x$ con $x^2 \leq 25$ si ha $y^2 = 9\left(1 - \dfrac{x^2}{25}\right) \geq 0$, quindi esiste un punto dell'ellisse con quell'ascissa. Perciò l'ascissa varia fra $-5$ e $5$, le ascisse dei vertici $(\pm 5, 0)$.
