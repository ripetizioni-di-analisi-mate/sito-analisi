Quali valori di $x$ verificano l'equazione $\sqrt{9 - x^2} = x + 3$?

- $x = 0 \ \vee \ x = 3$
- $x = 0$
- $x = -3$
- $x = -3 \ \vee \ x = 0$

## Spiegazione

L'equazione ha la forma $\sqrt{A} = B$, quindi equivale al sistema
$$
\begin{cases}
x + 3 \geq 0 \\
9 - x^2 = (x + 3)^2
\end{cases}
$$
Sviluppando $(x + 3)^2 = x^2 + 6x + 9$, la seconda equazione diventa $2x^2 + 6x = 0$, cioè $2x(x + 3) = 0$, con soluzioni $x = 0$ e $x = -3$. Entrambe soddisfano la condizione $x \geq -3$, quindi nessuna si scarta. Il controllo dà $\sqrt{9} = 3 = 0 + 3$ e $\sqrt{0} = 0 = -3 + 3$, perciò le soluzioni sono $x = -3$ e $x = 0$.
