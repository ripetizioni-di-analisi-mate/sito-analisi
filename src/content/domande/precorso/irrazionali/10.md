- $-2 < x < 3$
- $-6 \leq x < 3$
- $0 \leq x < 3$
- $-6 < x < 3$

## Spiegazione

La disequazione ha la forma $\sqrt{A} > B$, quindi equivale all'unione di due sistemi.
$$
\begin{cases}
x < 0 \\
x + 6 \geq 0
\end{cases}
\ \cup \
\begin{cases}
x \geq 0 \\
x + 6 > x^2
\end{cases}
$$
Il primo sistema dà $-6 \leq x < 0$, con $x = -6$ incluso perché in quel punto la radice esiste e vale $0 > -6$. Nel secondo, la disequazione $x^2 - x - 6 < 0$ equivale a $-2 < x < 3$, quindi con $x \geq 0$ restano i valori $0 \leq x < 3$. L'**unione** dei due sistemi dà $-6 \leq x < 3$.
