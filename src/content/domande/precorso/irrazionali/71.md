Il radicando di $\sqrt{x^2 - 4x + 4}$ è il quadrato di un binomio. Quali numeri reali soddisfano la disequazione $\sqrt{x^2 - 4x + 4} < 3$?

- $-5 < x < 1$
- $x < 5$
- $-1 < x < 5$
- $x < -1 \ \vee \ x > 5$

## Spiegazione

Il radicando è $x^2 - 4x + 4 = (x - 2)^2$, quindi è non negativo per ogni $x$ e $\sqrt{(x - 2)^2} = |x - 2|$. La disequazione diventa $|x - 2| < 3$, che chiede i numeri la cui distanza da $2$ è minore di $3$. Perciò $-3 < x - 2 < 3$, cioè $-1 < x < 5$.
