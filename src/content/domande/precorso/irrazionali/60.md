La funzione $f(x) = \sqrt{x + 3} + \sqrt{x}$ vale $3$ in $x = 1$. Per quali $x$ si ha $f(x) < 3$?

- $0 \leq x \leq 1$
- $-3 \leq x < 1$
- $0 < x < 1$
- $0 \leq x < 1$

## Spiegazione

Le due radici sono definite insieme per $x \geq 0$. La disequazione si scrive $\sqrt{x + 3} < 3 - \sqrt{x}$, che ha la forma $\sqrt{A} < B$ e richiede $3 - \sqrt{x} > 0$, cioè $x < 9$. Con entrambi i membri non negativi l'elevamento al quadrato conserva il verso.
$$
x + 3 < 9 - 6\sqrt{x} + x
$$
Semplificando si ottiene $6\sqrt{x} < 6$, cioè $\sqrt{x} < 1$, quindi $x < 1$. Perciò la soluzione è $0 \leq x < 1$, che soddisfa anche $x < 9$; in $x = 0$ si ha $f(0) = \sqrt{3} < 3$.
