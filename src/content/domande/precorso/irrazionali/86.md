Il radicando di $\sqrt{x^3 - 4x}$ è un polinomio di terzo grado. Qual è il dominio della radice?

- $x \geq 2$
- $-2 \leq x \leq 0 \ \vee \ x \geq 2$
- $x \leq -2 \ \vee \ 0 \leq x \leq 2$
- $-2 < x < 0 \ \vee \ x > 2$

## Spiegazione

La radice è definita dove $x^3 - 4x \geq 0$. Raccogliendo $x$ e scomponendo la differenza di quadrati si ottiene $x^3 - 4x = x(x - 2)(x + 2)$, che si annulla in $x = -2$, $x = 0$ e $x = 2$. Per $x > 2$ i tre fattori sono positivi, quindi il prodotto è positivo. Il segno cambia a ogni zero, perché ogni fattore è di primo grado e si annulla una sola volta. Perciò il prodotto è positivo per $-2 < x < 0$ e per $x > 2$, ed è negativo negli altri intervalli. Aggiungendo gli zeri, dove la radice vale $0$, il dominio è $-2 \leq x \leq 0$ oppure $x \geq 2$.
