Quali sono le soluzioni della disequazione $\sqrt{x^2 - 9} < 4$?

- $-5 < x < 5$
- $3 \leq x < 5$
- $-5 < x \leq -3 \ \vee \ 3 \leq x < 5$
- $-5 < x < -3 \ \vee \ 3 < x < 5$

## Spiegazione

La disequazione ha la forma $\sqrt{A} < B$ con $B = 4 > 0$, quindi equivale al sistema
$$
\begin{cases}
x^2 - 9 \geq 0 \\
x^2 - 9 < 16
\end{cases}
$$
La prima condizione è soddisfatta per $x \leq -3$ oppure $x \geq 3$. La seconda equivale a $x^2 < 25$, cioè $-5 < x < 5$. Gli estremi $x = \pm 3$ sono inclusi, perché lì la radice vale $0 < 4$, mentre $x = \pm 5$ sono esclusi, perché lì la radice vale $4$. Perciò le soluzioni sono $-5 < x \leq -3$ oppure $3 \leq x < 5$.
