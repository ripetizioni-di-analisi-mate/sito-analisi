- $x < 6$
- $-3 < x < 6$
- $-3 \leq x < 0$
- $-3 \leq x < 6$

## Spiegazione

La disequazione ha la forma $\sqrt{A} < B$, quindi equivale al sistema
$$
\begin{cases}
x + 3 \geq 0 \\
3 > 0 \\
x + 3 < 9
\end{cases}
$$
La condizione $3 > 0$ è vera per ogni $x$. La prima condizione dà $x \geq -3$, con l'estremo incluso perché in $x = -3$ la radice vale $0 < 3$. La terza dà $x < 6$, con l'estremo escluso perché in $x = 6$ la radice vale $3$. Perciò la soluzione è $-3 \leq x < 6$.
