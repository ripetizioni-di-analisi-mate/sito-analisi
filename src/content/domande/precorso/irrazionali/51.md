In quale insieme risulta $\sqrt[4]{x + 2} < 2$?

- $-2 \leq x < 14$
- $-2 \leq x < 0$
- $x < 14$
- $-2 < x < 14$

## Spiegazione

La radice quarta, come ogni radice di indice pari, è definita quando il radicando non è negativo, quindi deve essere $x + 2 \geq 0$, cioè $x \geq -2$. Dove la radice è definita i due membri sono non negativi, perciò l'elevamento alla quarta potenza conserva il verso.
$$
x + 2 < 2^4 = 16
$$
Quindi $x < 14$, e insieme alla condizione $x \geq -2$ si ottiene $-2 \leq x < 14$. In $x = -2$ la radice vale $\sqrt[4]{0} = 0 < 2$, perciò l'estremo è incluso.
