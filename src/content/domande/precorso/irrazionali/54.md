La figura mostra la semicirconferenza $y = \sqrt{4 - x^2}$ e la retta $y = x$.

::grafico{f="sqrt(4-x^2);x" xmin=-3 xmax=3 ymin=-2.5 ymax=3 uguale=1}

Per quali $x$ vale la disuguaglianza $\sqrt{4 - x^2} \geq x$?

- $-2 \leq x \leq \sqrt{2}$
- $0 \leq x \leq \sqrt{2}$
- $-\sqrt{2} \leq x \leq \sqrt{2}$
- $-2 < x \leq \sqrt{2}$

## Spiegazione

La disequazione ha la forma $\sqrt{A} \geq B$, quindi equivale all'unione di due sistemi.
$$
\begin{cases}
x < 0 \\
4 - x^2 \geq 0
\end{cases}
\ \cup \
\begin{cases}
x \geq 0 \\
4 - x^2 \geq x^2
\end{cases}
$$
Il primo sistema dà $-2 \leq x < 0$, perché $4 - x^2 \geq 0$ equivale a $-2 \leq x \leq 2$. Nel secondo, la disequazione $2x^2 \leq 4$ equivale a $-\sqrt{2} \leq x \leq \sqrt{2}$, quindi con $x \geq 0$ restano i valori $0 \leq x \leq \sqrt{2}$. L'**unione** dei due sistemi dà $-2 \leq x \leq \sqrt{2}$, cioè le ascisse dei punti in cui la semicirconferenza non sta sotto la retta.
