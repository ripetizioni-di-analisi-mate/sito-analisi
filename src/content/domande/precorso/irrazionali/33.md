Quali sono le soluzioni della disequazione $\sqrt{3x + 1} \leq x + 1$?

- $x \leq 0 \ \vee \ x \geq 1$
- $-\dfrac{1}{3} \leq x \leq 0 \ \vee \ x \geq 1$
- $x \geq 1$
- $-1 \leq x \leq 0 \ \vee \ x \geq 1$

## Spiegazione

La disequazione ha la forma $\sqrt{A} \leq B$, quindi equivale al sistema
$$
\begin{cases}
3x + 1 \geq 0 \\
x + 1 \geq 0 \\
3x + 1 \leq (x + 1)^2
\end{cases}
$$
La terza condizione diventa $x^2 - x \geq 0$, cioè $x(x - 1) \geq 0$, che è soddisfatta per $x \leq 0$ oppure $x \geq 1$. La prima condizione richiede $x \geq -\dfrac{1}{3}$, e la seconda, $x \geq -1$, segue dalla prima. In $x = -\dfrac{1}{3}$ la radice vale $0$ e il secondo membro vale $\dfrac{2}{3}$, quindi l'estremo è incluso. Perciò le soluzioni sono $-\dfrac{1}{3} \leq x \leq 0$ oppure $x \geq 1$.
