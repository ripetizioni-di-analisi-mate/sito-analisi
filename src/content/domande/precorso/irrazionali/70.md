Quali numeri reali appartengono al dominio della funzione $f(x) = \sqrt{x^2 - 1} + \dfrac{1}{\sqrt{5 - x}}$?

- $1 \leq x < 5$
- $x \leq -1 \ \vee \ 1 \leq x \leq 5$
- $x \leq -1 \ \vee \ 1 \leq x < 5$
- $x < -1 \ \vee \ 1 < x < 5$

## Spiegazione

La funzione è definita dove esistono le due radici e il denominatore è diverso da $0$. La radice $\sqrt{5 - x}$ sta al denominatore e vale $0$ solo per $x = 5$, quindi il suo radicando deve essere positivo.
$$
\begin{cases}
x^2 - 1 \geq 0 \\
5 - x > 0
\end{cases}
$$
Il binomio $x^2 - 1$ si annulla in $x = \pm 1$ e, poiché il coefficiente di $x^2$ è positivo, è non negativo per $x \leq -1$ oppure $x \geq 1$. La seconda condizione dà $x < 5$. Perciò il dominio è formato dai valori $x \leq -1$ oppure $1 \leq x < 5$.
