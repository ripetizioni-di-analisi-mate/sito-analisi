Quali sono le soluzioni della disequazione $\sqrt{5 - x} > x - 3$?

- $x < 4$
- $1 < x < 4$
- $3 \leq x < 4$
- $x \leq 5$

## Spiegazione

La disequazione ha la forma $\sqrt{A} > B$, quindi equivale all'unione di due sistemi.
$$
\begin{cases}
x - 3 < 0 \\
5 - x \geq 0
\end{cases}
\ \cup \
\begin{cases}
x - 3 \geq 0 \\
5 - x > (x - 3)^2
\end{cases}
$$
Il primo sistema richiede $x < 3$ e $x \leq 5$, quindi dà $x < 3$. Nel secondo, sviluppando $(x - 3)^2 = x^2 - 6x + 9$, la disequazione diventa $x^2 - 5x + 4 < 0$, cioè $1 < x < 4$, e con $x \geq 3$ restano i valori $3 \leq x < 4$. L'**unione** dei due sistemi dà $x < 4$. In $x = 4$ i due membri valgono entrambi $1$, quindi l'estremo è escluso.
