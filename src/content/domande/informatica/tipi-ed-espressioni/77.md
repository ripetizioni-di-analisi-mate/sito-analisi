All’inizio della sola chiamata a `sample`, `state` vale 1. Qual è l’insieme di tutti i possibili valori restituiti da `sample` secondo C17?

```c
int state = 1;
int tick(void) {
    int old = state;
    state *= 2;
    return old;
}
int sample(void) { return tick() - tick(); }
```

- `{-1}`
- `{-1, 1}`
- `{0}`
- Comportamento indefinito

## Spiegazione

Le esecuzioni delle due chiamate a `tick` non si sovrappongono. La prima eseguita restituisce 1 e porta lo stato a 2. La seconda restituisce 2 e lo porta a 4. Il C17 non impone quale operando della sottrazione venga valutato per primo, perciò il risultato è 1 meno 2 oppure 2 meno 1.
