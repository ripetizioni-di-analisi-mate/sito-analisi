Nel frammento C17, quale affermazione vale per entrambi gli oggetti dopo la seconda dichiarazione? `size_t` è dichiarato in `<stddef.h>`.

```c
int n = 7;
size_t k = sizeof(++n);
```

- `n == 8`, `k == sizeof(int)`
- `n == 8`, `k == 8` garantito
- `n == 7`, `k == sizeof(int)`
- `n == 7`, `k == 7` garantito

## Spiegazione

L’operando di `sizeof` ha tipo `int`, un tipo di dimensione fissa. Per determinarne la dimensione non viene valutato `++n`. La variabile conserva 7 e la dimensione registrata dipende dal tipo `int` dell’implementazione.
