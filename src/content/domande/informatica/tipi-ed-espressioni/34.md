Una realizzazione C17 ha `INT_MIN == -32768` e `INT_MAX == 32767`. Il frammento include `<limits.h>`. Qual è la categoria di comportamento dell’espressione `value % divisor`?

```c
int value = INT_MIN;
int divisor = -1;
int rest = value % divisor;
```

- Definito, con resto $0$.
- Indefinito.
- Definito dall’implementazione.
- Non specificato.

## Spiegazione

Il quoziente matematico di $-32768$ diviso $-1$ è $32768$. Il valore supera il massimo di `int`. La condizione sulla rappresentabilità del quoziente si applica sia alla divisione sia al resto, quindi l’operatore `%` ha comportamento indefinito in questo caso.
