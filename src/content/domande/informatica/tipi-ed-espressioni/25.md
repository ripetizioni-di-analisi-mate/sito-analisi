Determinare il valore di `result` in C17, usando `UINT_MAX` per il massimo di `unsigned int`.

```c
unsigned int amount = 15u;
int divisor = -4;
unsigned int result = amount / divisor;
```

- $3$
- `UINT_MAX / 4u`
- $0$
- Comportamento indefinito.

## Spiegazione

Le conversioni usuali convertono `divisor` a `unsigned int`, poiché il tipo senza segno ha lo stesso rango del tipo con segno. In quel tipo $-4$ diventa `UINT_MAX - 3u`. Il nuovo divisore supera $15$, quindi il quoziente intero è $0$.
