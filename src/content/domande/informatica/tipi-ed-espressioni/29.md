Durante una chiamata a `add`, quali affermazioni sul valore di `total` e sull’ordine di valutazione delle due chiamate valgono in C17?

```c
int left(void) { return 3; }
int right(void) { return 4; }

int add(void)
{
    int total = left() + right();
    return total;
}
```

- $7$ e `left` sempre per prima.
- $7$ e ordine documentato dall’implementazione.
- $3$ o $4$, a seconda dell’ordine.
- $7$ e ordine delle chiamate non specificato.

## Spiegazione

Le due funzioni restituiscono rispettivamente $3$ e $4$. Poiché ciascuna produce il proprio valore indipendentemente dall’altra, la somma vale $7$ in entrambi gli ordini. Il `+` lascia libero l’ordine di valutazione, che in questo caso è non specificato e può cambiare senza cambiare la somma.
