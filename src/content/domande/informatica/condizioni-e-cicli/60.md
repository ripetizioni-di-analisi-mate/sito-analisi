Un rilevatore si ferma al terzo segnale positivo consecutivo. Numerando i campioni da zero, a quale indice si arresta?

```c
int a[] = {2, 6, 0, 1, 3, 4, 8};
int i, run = 0;
for (i = 0; i < 7; ++i) {
    run = a[i] > 0 ? run + 1 : 0;
    if (run == 3) break;
}
```

- `4`
- `3`
- `5`
- `6`

## Spiegazione

Agli indici 0 e 1 la sequenza cresce fino a lunghezza 2. Il campione nullo all’indice 2 azzera `run`. I campioni agli indici 3, 4 e 5 costruiscono quindi una nuova sequenza di lunghezze 1, 2 e 3. Il `break` avviene con `i = 5`, prima dell’incremento del `for`.
