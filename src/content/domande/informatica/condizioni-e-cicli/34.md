Qual è il valore finale di `count`?

```c
int count = 0, j = 0;
for (int i = 0; i < 3; ++i) {
    while (j < 2) {
        ++j;
        ++count;
    }
}
```

- $2$
- $0$
- $3$
- $6$

## Spiegazione

`j` viene inizializzato prima dell’ingresso nel ciclo esterno, quindi la prima riga è la sola che parte con `j` uguale a $0$. Il primo `while` lo porta a $2$ e incrementa `count` due volte. Nelle righe successive `j` conserva $2$, rendendo falsa la guardia interna già al primo controllo. Il conteggio resta $2$.
