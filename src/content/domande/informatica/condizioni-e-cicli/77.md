Un contatore si riduce sottraendo uno quando è dispari e dimezzandolo quando è pari. Quale coppia `(sub, half)` conta i due rami per l’ingresso 13?

```c
int n = 13, sub = 0, half = 0;
while (n > 0) {
    if (n % 2) { --n; ++sub; }
    else { n /= 2; ++half; }
}
```

- `(3, 4)`
- `(4, 3)`
- `(3, 3)`
- `(2, 4)`

## Spiegazione

Le transizioni sono $13\to12\to6\to3\to2\to1\to0$. Le sottrazioni avvengono partendo da 13, 3 e 1, mentre i dimezzamenti avvengono partendo da 12, 6 e 2. Lo zero conclude la scansione prima di entrare in un nuovo ramo.
