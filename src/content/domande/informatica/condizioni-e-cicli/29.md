Qual è il valore finale di `seen`?

```c
int seen = 0, k = 0;
while (k < 6) {
    ++k;
    if (k % 2 == 0) {
        continue;
    }
    seen = 10 * seen + k;
}
```

- $12345$
- $246$
- $135$
- $13$

## Spiegazione

Ogni iterazione incrementa `k` prima dell’eventuale `continue`. Quando `k` è pari, il salto evita l’assegnamento a `seen` e torna al controllo della guardia. I valori usati per l’assegnamento sono quindi $1$, $3$ e $5$. Si ottengono in ordine $1$, $13$ e $135$, mentre il salto con `k` uguale a $6$ lascia quel valore invariato.
