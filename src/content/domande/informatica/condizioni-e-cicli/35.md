Determinare `score` al termine dei due cicli.

```c
int score = 0;
for (int i = 1; i <= 3; ++i) {
    for (int j = 1; j <= 4; ++j) {
        if (i * j >= 6) {
            break;
        }
        score += i;
    }
}
```

- $7$
- $11$
- $14$
- $18$

## Spiegazione

Con `i` uguale a $1$ tutti i quattro valori di `j` mantengono il prodotto sotto $6$, quindi si aggiunge $4$. Con `i` uguale a $2$ si usano solo `j` uguale a $1$ e $2$ e si aggiunge $4$. Con `i` uguale a $3$ si usa il solo `j` uguale a $1$ e si aggiunge $3$. Il totale è $4+4+3=11$.
