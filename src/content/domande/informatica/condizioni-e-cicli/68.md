Una ricerca deve visitare le celle per righe e fermarsi al primo valore negativo. `rows` e `cols` sono interi di tipo `int` e indicano le dimensioni valide della matrice. Quale guardia esterna completa il codice e impedisce di avviare nuove righe dopo il primo riscontro?

```c
int found = 0;
for (int r = 0; /* outer guard */; ++r)
    for (int c = 0; c < cols; ++c)
        if (a[r][c] < 0) { found = 1; break; }
```

- `r < rows || !found`
- `r < rows && !found`
- `r < rows && found`
- `r < rows`

## Spiegazione

Il `break` appartiene al ciclo sulle colonne. Dopo un riscontro termina la riga corrente, ma il `for` esterno esegue ancora il proprio aggiornamento e controlla nuovamente la guardia. Chiedere insieme che la riga esista e che `found` sia falso evita una seconda ricerca. La stessa guardia salta l’intera scansione quando `rows` vale zero.
