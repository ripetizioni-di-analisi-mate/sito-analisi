Un `continue` e un `break` compaiono nello stesso `switch` annidato in un `for`. Quale valore finale ha `mark`?

```c
int mark = 0;
for (int i = 0; i < 3; ++i) {
    switch (i) {
    case 0: continue;
    case 1: break;
    default: mark += 9;
    }
    mark += 3;
}
```

- `15`
- `21`
- `9`
- `12`

## Spiegazione

Per `i = 0`, `continue` raggiunge l’aggiornamento del `for` e salta l’aggiunta di 3. Per `i = 1`, `break` esce soltanto dallo `switch`, quindi si aggiunge 3. Per `i = 2` si aggiungono prima 9 e poi 3. Il totale è `0 + 3 + 12 = 15`.
