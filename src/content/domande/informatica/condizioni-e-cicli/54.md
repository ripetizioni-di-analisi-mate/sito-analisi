Quale valore ha `n` all’uscita? Si deve tenere conto di quando lo `switch` sceglie l’etichetta di ingresso.

```c
int n = 1;
switch (n++) {
case 1: n += 3; break;
case 5: n *= 2; break;
default: n = 0;
}
```

- `4`
- `5`
- `10`
- `0`

## Spiegazione

Il postincremento fornisce il vecchio valore 1 per la selezione e porta `n` a 2. L’esecuzione inizia da `case 1`, che aggiunge 3 ottenendo 5. La modifica di `n` non avvia una nuova selezione delle etichette. Il `break` esce con `n` uguale a 5.
