Si vuole ottenere la somma a segni alterni degli `n` valori di `a`, iniziando con il segno positivo. Il ciclo consuma due valori alla volta. Quale istruzione va nel ramo finale perché il risultato sia corretto per ogni lunghezza da 0 a 100? Si assumano rappresentabili somme e differenze.

```c
int i = 0, total = 0;
while (i + 1 < n) {
    total += a[i] - a[i + 1];
    i += 2;
}
if (i < n) { /* final statement */ }
```

- `total += a[i];`
- `total = a[i];`
- `total -= a[i];`
- `total += i;`

## Spiegazione

Dopo ogni iterazione `i` è pari e `total` contiene il contributo di tutte le coppie già consumate. Per una lunghezza pari o nulla la condizione finale è falsa. Se rimane un valore, si trova all’indice pari `i` e ha quindi segno positivo. Occorre aggiungerlo alla somma già calcolata.
