Un ingresso digitale è inizialmente a livello basso. Quale coppia `(rises, falls)` produce il conteggio dei passaggi tra livelli?

```c
int a[] = {0, 1, 1, 0, 1, 0, 1};
int previous = 0, rises = 0, falls = 0;
for (int i = 0; i < 7; ++i) {
    if (a[i] > previous) ++rises;
    if (a[i] < previous) ++falls;
    previous = a[i];
}
```

- `(2, 3)`
- `(3, 2)`
- `(4, 3)`
- `(3, 3)`

## Spiegazione

La transizione da 0 a 1 avviene agli indici 1, 4 e 6. Quella da 1 a 0 avviene agli indici 3 e 5. I valori consecutivi uguali, come gli 1 agli indici 1 e 2, non segnalano alcun passaggio. La differenza fra salite e discese è 1, coerente con l’ingresso che parte basso e finisce alto.
