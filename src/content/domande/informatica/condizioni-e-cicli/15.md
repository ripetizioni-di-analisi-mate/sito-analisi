Qual è la coppia finale `(x, score)`?

```c
int x = 6, score = 1;
if ((x = 0)) {
    score = 5;
} else {
    score += 2;
}
```

- $(6,5)$
- $(0,5)$
- $(0,3)$
- $(6,3)$

## Spiegazione

L’assegnamento nella guardia memorizza $0$ in `x` e ha come valore il valore assegnato. Poiché la guardia vale $0$, il ramo eseguito è quello dell’`else`. Da `score` iniziale uguale a $1$ si ottiene $1+2=3$. L’aggiornamento di `x` è avvenuto anche se la guardia risulta falsa.
