Qual è la coppia finale `(units, remaining)`?

```c
int remaining = 76, price = 6, units = 0;
while (remaining >= price) {
    remaining -= price;
    ++units;
    if (units % 3 == 0) {
        price += 2;
    }
}
```

- $(10,4)$
- $(9,6)$
- $(9,4)$
- $(8,14)$

## Spiegazione

L’incremento di `price` avviene dopo ogni terna di unità. Dopo la prima terna restano $76-3\cdot 6=58$ unità di risorsa. Le due terne successive costano $3\cdot 8=24$ e $3\cdot 10=30$, quindi dopo nove unità restano $4$. Il prossimo prezzo è $12$ e la guardia è falsa.
