Un vettore di voti contiene soltanto 0 e 1. Il numero di voti `n` è un `int` non negativo. Il seguente conteggio accoppia voti diversi. Quale affermazione vale dopo ogni prefisso, compreso quello vuoto?

```c
int who = 0, bal = 0;
for (int i = 0; i < n; ++i) {
    if (bal == 0) { who = v[i]; bal = 1; }
    else if (who == v[i]) ++bal;
    else --bal;
}
```

- `bal` è la differenza assoluta dei due conteggi e, se è positivo, `who` identifica il valore più frequente.
- `bal` si annulla ogni volta che due voti consecutivi sono diversi.
- `bal` è il totale dei voti uguali a `who` fin dall’inizio.
- `who` è sempre il voto letto per ultimo.

## Spiegazione

All’inizio i due conteggi sono nulli e `bal` vale zero. In parità il nuovo voto crea un vantaggio di uno e sceglie `who`. Con un vantaggio positivo, un voto per `who` lo aumenta di uno e un voto opposto lo riduce di uno. Le transizioni conservano quindi la differenza assoluta e, finché resta positiva, l’identità del valore in vantaggio.
