Un’operazione di due fasi è racchiusa in un `do ... while (0)`. Con `ready = 1` e `valid = 0`, quali valori finali hanno `stage` e `logged`?

```c
int ready = 1, valid = 0, stage = 0, logged = 0;
do {
    if (!ready) break;
    stage = 1;
    if (!valid) break;
    stage = 2;
} while (0);
++logged;
```

- `(2, 1)`
- `(1, 0)`
- `(1, 1)`
- `(0, 1)`

## Spiegazione

Il `do` entra subito nel corpo. La prima verifica consente di assegnare 1 a `stage`. La seconda incontra `!valid` vero ed esce dal `do` prima di assegnare 2. L’istruzione dopo il ciclo viene comunque eseguita e porta `logged` a 1. La guardia costante zero impedirebbe una seconda iterazione anche lungo il percorso completo.
