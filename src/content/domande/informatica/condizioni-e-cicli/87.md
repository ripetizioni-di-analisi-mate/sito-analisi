Una scansione emette un risultato per ogni coppia adiacente di valori uguali che riesce a fondere, altrimenti emette il singolo valore corrente. Il codice conta le emissioni in `w` e le coppie fuse in `merged`, con `0 <= n <= 100`. Quale identità vale a ogni controllo della guardia?

```c
int r = 0, w = 0, merged = 0;
while (r < n) {
    if (r + 1 < n && a[r] == a[r + 1]) {
        r += 2;
        ++merged;
    } else {
        ++r;
    }
    ++w;
}
```

- `r == w - 2 * merged`
- `r == 2 * w + merged`
- `r == w + merged`
- `w == r + merged`

## Spiegazione

Ogni emissione consuma almeno un valore, quindi `w` conta un valore di ingresso per risultato. Ogni fusione consuma inoltre un secondo valore e occorre aggiungere `merged` per ottenere il numero `r` dei valori letti. Nel ramo singolo entrambi i membri crescono di uno e in quello doppio crescono entrambi di due. L’uguaglianza vale già all’avvio.
