Qual è la prossima valutazione dopo il `continue`?

```c
int skip = 1, more = 0, count = 0;
do {
    if (skip) {
        continue;
    }
    ++count;
} while (more);
```

- Esegue l’incremento di `count`.
- Ricomincia il corpo prima di ogni test.
- Restituisce il controllo al chiamante della funzione.
- Valuta la guardia `more`.

## Spiegazione

Con `skip` uguale a $1$, il ramo del `continue` viene eseguito. Nel `do while` il punto di prosecuzione è la guardia in fondo al corpo. L’incremento di `count` viene saltato e `more` viene valutato. Poiché `more` vale $0$, la guardia poi conclude il ciclo.
