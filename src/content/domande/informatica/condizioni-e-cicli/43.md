Qual è la coppia finale `(x, visits)`?

```c
int x = 0, visits = 0;
while (x < 4 && ++visits < 3) {
    x += 2;
}
```

- $(4,2)$
- $(4,3)$
- $(6,3)$
- $(2,2)$

## Spiegazione

I primi due controlli trovano `x` minore di $4$. In entrambi si valuta `++visits < 3`, che risulta vera con `visits` uguale a $1$ e poi a $2$. Il corpo aumenta `x` fino a $4$. Al controllo successivo il primo operando di `&&` è falso, quindi `visits` resta $2$.
