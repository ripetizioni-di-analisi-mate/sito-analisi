Quale valore assume `count` all’uscita dal `for`?

```c
int count = 0;
for (int i = 0; i < 3; ++i) {
    switch (i) {
    case 1:
        break;
    default:
        count += 10;
    }
    ++count;
}
```

- $11$
- $23$
- $12$
- $22$

## Spiegazione

Per `i` uguale a $0$ e a $2$ si esegue `default`, poi l’incremento fuori dallo `switch`. Ciascuna di quelle iterazioni aggiunge $11$. Con `i` uguale a $1$ il `break` esce dallo `switch`, quindi avviene comunque l’incremento esterno. Il contributo di quell’iterazione è $1$ e il totale è $11+1+11=23$.
