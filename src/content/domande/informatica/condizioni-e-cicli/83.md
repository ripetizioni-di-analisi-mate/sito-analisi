Il vettore `a` contiene `n` parentesi tonde, con `0 <= n <= 100`. Una sequenza è bilanciata se ogni chiusura trova un’apertura ancora libera e alla fine tutte le aperture sono chiuse. Quale controllo sui due valori finali riconosce esattamente queste sequenze, compresa quella vuota?

```c
int depth = 0, low = 0;
for (int i = 0; i < n; ++i) {
    depth += (a[i] == '(') ? 1 : -1;
    if (depth < low) low = depth;
}
```

- `depth >= 0 && low <= 0`
- `depth == 0`
- `depth == 0 && low == 0`
- `low == 0`

## Spiegazione

`depth` è il numero di aperture meno quello delle chiusure nel prefisso letto. `low` è il minimo raggiunto da tale differenza, incluso lo zero iniziale. Occorrono sia un saldo finale nullo sia l’assenza di prefissi negativi. La sequenza `)(` ha saldo finale nullo ma scende sotto zero. La sequenza `(()` resta sopra o a zero ma lascia aperta una parentesi.
