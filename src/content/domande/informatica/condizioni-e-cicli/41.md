Quanto vale `steps` alla fine?

```c
int x = -2, steps = 0;
while (x < 20) {
    x = 2 * x + 5;
    ++steps;
}
```

- $3$
- $5$
- $6$
- $4$

## Spiegazione

Poniamo $y=x+5$. L’aggiornamento di `x` raddoppia $y$, perché $(2x+5)+5=2(x+5)$. La guardia impone $y<25$. A partire da $3$ si ottengono $6$, $12$, $24$ e $48$. Il test fallisce per la prima volta a $48$, quindi si sono eseguiti quattro aggiornamenti.
