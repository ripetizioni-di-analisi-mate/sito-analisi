Per i valori non negativi di `n` l’etichetta `A` deve identificare i multipli di 8 e `B` gli altri multipli di 4. Quale guardia va inserita al posto del commento per ottenere la classificazione richiesta?

```c
char label;
if (/* guard */) label = 'A';
else if (n % 4 == 0) label = 'B';
else label = 'C';
```

- `n % 8 == 4`
- `n % 4 != 0`
- `n % 4 == 0`
- `n % 8 == 0`

## Spiegazione

Fra i multipli di 4, il resto modulo 8 è 0 oppure 4. Il primo ramo deve intercettare solo il resto 0. Se questo test fallisce, il secondo ramo riconosce i multipli di 4 rimasti. Usare già nel primo ramo il test di divisibilità per 4 renderebbe irraggiungibile l’assegnamento di `B`.
