A quale `if` appartiene l’`else`?

```c
int x = 2, y = 1, result = 0;
if (x > 0)
    if (y > 2) {
        result = 1;
    } else {
        result = 2;
    }
```

- All’`if` con guardia `x > 0`.
- A entrambi gli `if`.
- A nessuno dei due `if`.
- All’`if` con guardia `y > 2`.

## Spiegazione

Un `else` si associa all’`if` precedente più vicino a cui la sintassi consente di associarlo. Qui l’`if` interno con guardia `y > 2` è quello più vicino ed è privo di un altro `else`. Per associare l’`else` alla guardia esterna si può chiudere l’`if` interno in un blocco delimitato da graffe.
