Quanto vale `crossed` al termine?

```c
int crossed = -1, total = 0;
for (int i = 1; i <= 7; ++i) {
    total += 2 * i;
    if (total >= 12) {
        crossed = i;
        break;
    }
}
```

- $3$
- $2$
- $4$
- $-1$

## Spiegazione

Il test si esegue dopo aver aggiunto `2 * i`. Con `i` uguale a $1$, $2$ e $3$ i valori di `total` sono $2$, $6$ e $12$. Il primo valore che soddisfa `total >= 12` è $12$, raggiunto con `i` uguale a $3$. Quel `i` viene copiato in `crossed` prima del `break`.
