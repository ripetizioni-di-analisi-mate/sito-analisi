Quante coppie vengono contate da `visits`?

```c
int visits = 0;
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 4; ++j) {
        if ((i + j) % 2 == 0) {
            ++visits;
        }
    }
}
```

- $6$
- $5$
- $8$
- $12$

## Spiegazione

La somma `i + j` è pari esattamente quando i due indici hanno la stessa parità. Per ogni `i` ci sono quattro valori di `j`, due pari e due dispari. In ciascuna delle tre righe ci sono quindi due incrementi. Il contatore vale $3\cdot 2=6$.
