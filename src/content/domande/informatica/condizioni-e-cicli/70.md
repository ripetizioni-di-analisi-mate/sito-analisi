Sia `n` un `int` positivo e sia `a` un vettore di `n` interi. Quale espressione è vera dopo la ricerca per ogni contenuto del vettore e può essere valutata con sicurezza anche quando la chiave è assente?

```c
int i = 0;
for (; i < n; ++i)
    if (a[i] == key) break;
```

- `i == n && a[n - 1] == key`
- `i == n || a[i] == key`
- `i < n && a[i] == key`
- `a[i] == key || i == n`

## Spiegazione

Un’uscita con `break` conserva un indice valido e garantisce `a[i] == key`. Un’uscita per esaurimento lascia invece `i == n`. Verificare prima l’uguaglianza con `n` impedisce, grazie al corto circuito, la lettura oltre l’ultimo elemento in questo secondo caso. Scambiare gli operandi richiederebbe la lettura prima del test di fine.
