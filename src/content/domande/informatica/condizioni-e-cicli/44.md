Quale valore assume `value`?

```c
int value = 0;
for (int i = 0; i < 7; ++i) {
    if (i % 2) {
        value += i;
    } else {
        value -= i;
    }
}
```

- $3$
- $-6$
- $9$
- $-3$

## Spiegazione

La guardia interna è vera per gli indici dispari, che vengono aggiunti. Gli indici pari vengono sottratti. Raggruppando in $(0,1)$, $(2,3)$ e $(4,5)$, ogni coppia contribuisce $1$. Resta l’indice $6$, che dà $-6$. Il valore finale è $1+1+1-6=-3$.
