Una funzione deve calcolare la media dei soli campioni strettamente positivi. Con la scansione indicata, quale espressione assegna la media quando `used > 0` e conserva la parte frazionaria? Si supponga che `double` rappresenti esattamente 3,5.

```c
int a[] = {2, -1, 5, 0}, sum = 0, used = 0;
for (int i = 0; i < 4; ++i)
    if (a[i] > 0) { sum += a[i]; ++used; }
```

- `(double)sum / used`
- `(double)(sum / used)`
- `(double)sum / 4`
- `(double)used / sum`

## Spiegazione

La guardia conserva 2 e 5, quindi si ottengono `sum = 7` e `used = 2`. Convertendo `sum` a `double` prima della divisione, il quoziente vale 3,5. Una conversione eseguita dopo la divisione intera darebbe 3. Dividere per 4 conterebbe anche i due campioni scartati.
