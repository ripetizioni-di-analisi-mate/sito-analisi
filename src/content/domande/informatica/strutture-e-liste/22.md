La testa resta `&a`. Quale nodo esce dalla catena dopo l’assegnamento? Si include `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node d = {9, NULL};
struct Node c = {7, &d};
struct Node b = {6, &c};
struct Node a = {3, &b};
b.next = c.next;
```

- `c`
- `a`
- `b`
- `d`

## Spiegazione

`b.next` viene aggiornato con il vecchio successore di `c`, cioè `d`. Il percorso dalla testa diventa `a`, `b`, `d`. Di conseguenza `c` rimane vivo come oggetto automatico e diventa irraggiungibile nella lista.
