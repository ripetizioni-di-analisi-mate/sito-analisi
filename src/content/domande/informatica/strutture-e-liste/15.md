Quale valore finale ha `result` nel frammento C17?

```c
struct Ref { int *slot; int tag; };
int total = 6;
struct Ref a = {&total, 1};
struct Ref b = a;
*b.slot = 8;
b.tag = 4;
int result = *a.slot + a.tag;
```

- $9$
- $12$
- $7$
- $10$

## Spiegazione

La copia rende `a.slot` e `b.slot` due membri distinti contenenti lo stesso indirizzo. La scrittura tramite `b.slot` modifica quindi il valore letto con `a.slot`, che diventa $8$. Il membro `a.tag` conserva $1$. La somma è $8+1=9$.
