Il chiamante esegue `struct Pair a = {2, 5};` e poi `struct Pair b = raised(a);`. Quale coppia `(a.x, b.x)` ottiene?

```c
struct Pair { int x; int y; };

struct Pair raised(struct Pair p)
{
    p.x += p.y;
    return p;
}
```

- $(2,7)$
- $(7,7)$
- $(2,5)$
- $(7,2)$

## Spiegazione

Il parametro `p` è inizializzato con una copia di `a`. La modifica somma $5$ e $2$ nel parametro, quindi il valore restituito ha `x` uguale a $7$. Il chiamante conserva $2$ in `a.x` e usa il risultato per inizializzare `b.x` a $7$.
