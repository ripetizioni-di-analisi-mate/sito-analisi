Che valori hanno `out` e `used`, in quest’ordine, dopo il frammento?

```c
int data[2];
int used = 0;
int out = 44;
if (used > 0) {
    out = data[--used];
}
data[used++] = 6;
```

- $(6,1)$
- $(0,1)$
- $(44,1)$
- $(44,0)$

## Spiegazione

Il controllo `used > 0` è falso quando si prova a estrarre. Si saltano quindi il decremento e l’assegnamento a `out`. La scrittura successiva usa l’indice $0$ e porta `used` a $1$, mentre `out` resta a $44$.
