Qual è la terna delle chiavi di `front`, `rear` e del successore di `last` dopo il frammento? Si include `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node last = {6, NULL};
struct Node first = {2, &last};
struct Node fresh = {9, NULL};
struct Node *front = &first, *rear = &last;
rear->next = &fresh;
rear = &fresh;
```

- $(2,9,9)$
- $(9,9,6)$
- $(2,6,9)$
- $(6,9,2)$

## Spiegazione

L’inserimento copia l’indirizzo del nuovo nodo in `last.next`. La testa designa ancora il nodo di chiave $2$ e la coda ora designa il nodo di chiave $9$. Anche il successore del precedente nodo finale ha chiave $9$.
