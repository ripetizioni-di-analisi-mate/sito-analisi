Quale sequenza di chiavi si ottiene percorrendo la catena da `head`? Si include `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node c = {8, NULL};
struct Node b = {7, NULL};
struct Node a = {4, &c};
struct Node *head = &a;
```

- $(4,7,8)$
- $(4,8)$
- $(8,4)$
- $(4)$

## Spiegazione

`head` designa `a`, quindi la prima chiave è $4$. Il successore di `a` è `c`, con chiave $8$, e il suo successore è nullo. L’oggetto `b` è vivo ma non si trova sul percorso dalla testa.
