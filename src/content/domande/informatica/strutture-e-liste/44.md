Determinare il valore di `value`. I nodi sono vivi per tutta la traccia e si include `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node tail = {9, NULL};
struct Node front = {3, &tail};
struct Node saved = front;
front.next = NULL;
int value = saved.next->key;
```

- $3$
- $0$
- $9$
- Riferimento a puntatore nullo.

## Spiegazione

L’inizializzazione di `saved` copia il valore di `front.next`, cioè l’indirizzo di `tail`. L’assegnamento successivo cambia soltanto il membro `next` di `front`. La copia conserva l’indirizzo del nodo vivo con chiave $9$.
