Quanto vale `v[1]` dopo il frammento?

```c
int v[5] = {3, 1, 7, -2, 4};
for (int i = 0; i < 4; ++i) {
    v[i] += v[i + 1];
}
```

- $4$
- $13$
- $8$
- $6$

## Spiegazione

L’iterazione con `i = 0` cambia soltanto `v[0]`. All’iterazione con `i = 1`, `v[1]` vale ancora $1$ e `v[2]` vale ancora $7$, quindi si assegna $1+7=8$. Le iterazioni successive scrivono in indici maggiori.
