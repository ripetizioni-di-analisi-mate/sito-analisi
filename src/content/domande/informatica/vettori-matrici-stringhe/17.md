Quale indice contiene `best` alla fine del frammento?

```c
int a[5] = {10, 5, 9, 9, 8};
int best = 1;
for (int i = 2; i < 5; ++i) {
    if (a[i] > a[best]) {
        best = i;
    }
}
```

- $2$
- $0$
- $3$
- $4$

## Spiegazione

La scansione parte dall’indice $1$, con valore $5$. All’indice $2$ il valore $9$ lo supera e aggiorna `best`. All’indice $3$ si trova ancora $9$, quindi il confronto stretto lascia invariato l’indice. All’indice $4$ il valore $8$ è minore. Il massimo della porzione è quindi alla prima posizione utile $2$.
