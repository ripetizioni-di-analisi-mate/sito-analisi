Quanto vale `i` quando il ciclo termina?

```c
char a[] = "retr";
char b[] = "retta";
int i = 0;
while (a[i] != '\0' && a[i] == b[i]) {
    ++i;
}
```

- $2$
- $4$
- $3$
- $5$

## Spiegazione

Le coppie di caratteri coincidono agli indici $0$, $1$ e $2$, quindi il ciclo incrementa `i` tre volte. All’indice $3$ le celle contengono `'r'` e `'t'`. L’uguaglianza è falsa e il corpo non si esegue, perciò `i` resta uguale a $3$.
