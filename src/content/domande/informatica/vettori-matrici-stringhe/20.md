Quanto vale `total` alla fine?

```c
int a[4] = {3, -2, 4, 1};
int b[4] = {2, 3, -1, 5};
int total = 0;
for (int i = 0; i < 4; ++i) {
    total += a[i] * b[3 - i];
}
```

- $1$
- $27$
- $29$
- $31$

## Spiegazione

Gli indici di `a` crescono da $0$ a $3$, mentre quelli di `b` decrescono da $3$ a $0$. I prodotti sono $3\cdot5=15$, $(-2)(-1)=2$, $4\cdot3=12$ e $1\cdot2=2$. La somma è $15+2+12+2=31$.
