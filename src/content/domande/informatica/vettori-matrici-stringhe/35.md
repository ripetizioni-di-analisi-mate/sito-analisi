Qual è il valore finale di `runs`?

```c
char s[] = "a--b-c";
int runs = 0;
for (int i = 0; s[i] != '\0'; ++i) {
    if (s[i] == '-' && (i == 0 || s[i - 1] != '-')) {
        ++runs;
    }
}
```

- $3$
- $1$
- $4$
- $2$

## Spiegazione

Il ciclo aumenta il contatore solo all’inizio di una sequenza di trattini. Il trattino all’indice $1$ segue `'a'` e quello all’indice $4$ segue `'b'`, quindi ciascuno avvia una sequenza. Il trattino all’indice $2$ segue un altro trattino e appartiene alla sequenza già contata.
