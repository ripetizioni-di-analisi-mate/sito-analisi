Due sorgenti C17 sono tradotti separatamente e contengono il codice seguente, ciascuno nel file indicato. Un terzo sorgente chiama le due funzioni esterne avendo dichiarazioni compatibili. Quanto vale `left() + right()` una volta collegato ed eseguito il progetto?

`left.c`

```c
static int level(void) { return 3; }
int left(void) { return level(); }
```

`right.c`

```c
static int level(void) { return 11; }
int right(void) { return level(); }
```

- $6$
- $22$
- Collegamento impossibile per due definizioni di `level`
- $14$

## Spiegazione

Ogni definizione `static` è interna alla propria unità. Perciò `left` chiama la funzione che restituisce $3$ e `right` quella che restituisce $11$. I due nomi esterni `left` e `right` sono distinti. La somma è $3+11=14$.
