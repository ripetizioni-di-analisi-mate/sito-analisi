L’header comune dichiara `int score(int value);`. Quale definizione di funzione può comparire nello stesso sorgente dopo l’inclusione dell’header con tipo compatibile? Considerare definizioni esterne ordinarie.

- `int score(unsigned input) { return 1; }`
- `long score(int input) { return 1; }`
- `int score(int a, int b) { return 1; }`
- `int score(int input) { return 1; }`

## Spiegazione

Per la dichiarazione data, `score` deve restituire `int` e avere un solo parametro di tipo `int`. Il nome del parametro può essere diverso. Modificare il tipo del parametro, il tipo restituito o il numero di parametri cambierebbe il tipo di funzione richiesto.
