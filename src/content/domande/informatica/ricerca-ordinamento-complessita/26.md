Il vettore seguente è fuori ordine. Quale valore assume `lo` dopo le istruzioni? Si usa `<stddef.h>`.

```c
int a[] = {4, 8, 1, 9};
size_t lo = 0, hi = 4;
while (lo < hi) {
    size_t mid = lo + (hi - lo) / 2;
    if (a[mid] < 1) {
        lo = mid + 1;
    } else {
        hi = mid;
    }
}
```

- $1$
- $2$
- $0$
- $4$

## Spiegazione

Si parte dal centro $2$, dove il valore $1$ porta il limite destro a $2$. Il valore $8$ al centro $1$ lo porta a $1$, poi il valore $4$ all’indice $0$ lo porta a $0$. I limiti coincidono a $0$. Questo è l’esito del frammento, e l’interpretazione come prima posizione utile richiederebbe un vettore ordinato.
