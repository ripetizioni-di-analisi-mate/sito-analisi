Determinare `found`. Si usa `<stddef.h>`.

```c
int a[] = {2, 7, 2, 1, 2, 4};
size_t found = 6;
for (size_t i = 0; i < 6; ++i) {
    if (a[i] == 2) {
        found = i;
    }
}
```

- $0$
- $2$
- $6$
- $4$

## Spiegazione

L'indice cambia a ogni occorrenza perché il corpo prosegue dopo l’assegnamento. La chiave $2$ compare agli indici $0$, $2$ e $4$, in quest’ordine. Le altre visite non sovrascrivono il risultato, perciò resta l’ultimo indice $4$.
