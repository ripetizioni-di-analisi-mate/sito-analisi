Dopo `pos = lower_bound(a, n, key)`, quale espressione verifica la presenza di `key` e rispetta l’intervallo del vettore?

- `pos < n`
- `pos <= n && a[pos] == key`
- `a[pos] == key && pos < n`
- `pos < n && a[pos] == key`

## Spiegazione

Il `lower_bound` restituisce una posizione fra zero e `n` inclusi. Se è `n`, il test `pos < n` è falso e per corto circuito l’elemento non viene letto. Negli altri casi la posizione è valida, ma può contenere una chiave maggiore di quella cercata. Serve quindi anche il confronto di uguaglianza.
