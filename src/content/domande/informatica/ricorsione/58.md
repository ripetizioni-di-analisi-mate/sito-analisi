Nello stesso programma, partendo dallo stato iniziale, si esegue `unsigned a = stamp(2);` e poi, in un’istruzione distinta, `unsigned b = stamp(1);`. Quali valori si ottengono?

```c
unsigned stamp(unsigned n)
{
    static unsigned seen;
    ++seen;
    if (n == 0u) {
        return seen;
    }
    return stamp(n - 1u);
}
```

- $(3,2)$
- $(3,5)$
- $(1,1)$
- $(2,3)$

## Spiegazione

L’unico oggetto `seen` ha durata statica ed è condiviso da tutte le invocazioni. La prima richiesta passa per $2,1,0$, quindi la base legge $3$. La seconda richiesta parte dallo stesso contatore e passa per $1,0$, portandolo a $5$. Ogni ritorno propaga il valore letto nella propria chiamata di base.
