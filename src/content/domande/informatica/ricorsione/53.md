Ogni stato ha un successore valido in `next`. La funzione deve restituire il numero di passi fino al primo arrivo a `goal` e $-1$ se il limite `left`, compreso tra 0 e 20, non basta. Quale espressione completa il `return` affinché ogni chiamante restituisca la distanza corretta in caso di successo e conservi il fallimento anche risalendo più livelli?

```c
int steps(const int next[], int v, int goal, int left) {
    if (v == goal) return 0;
    if (left == 0) return -1;
    int d = steps(next, next[v], goal, left - 1);
    return /* expression */;
}
```

- `d + 1`
- `d < 0 ? 0 : d + 1`
- `d < 0 ? -1 : d`
- `d < 0 ? -1 : d + 1`

## Spiegazione

Se il figlio restituisce una distanza `d` valida, il chiamante ha già percorso il primo arco e deve aggiungere uno. Se il figlio restituisce $-1$, il budget residuo non consente di raggiungere il bersaglio, quindi neppure il chiamante può restituire una distanza valida. Il valore sentinella deve quindi rimanere $-1$. Un’aggiunta incondizionata trasformerebbe il fallimento in una distanza zero.
