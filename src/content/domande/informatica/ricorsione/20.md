Qual è il minimo intero `n` da $0$ a $20$ per cui `jump(n)` restituisce $4$?

```c
unsigned jump(unsigned n)
{
    if (n < 3u) {
        return 1u;
    }
    return 1u + jump(n - 3u);
}
```

- $8$
- $10$
- $9$
- $12$

## Spiegazione

La funzione conta uno per la chiamata di base e uno per ogni sottrazione di tre. Per restituire $4$ si devono eseguire esattamente tre sottrazioni. Con $8$ si raggiunge $2$ dopo due sottrazioni, mentre con $9$ il cammino $9,6,3,0$ ne contiene tre. Il valore $9$ è quindi il primo ammesso.
