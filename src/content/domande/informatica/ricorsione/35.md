Quante invocazioni logiche si hanno per `gcd(71, 26)`? Contare l’invocazione iniziale e quella del caso base.

```c
unsigned gcd(unsigned a, unsigned b)
{
    if (b == 0u) {
        return a;
    }
    return gcd(b, a % b);
}
```

- $6$
- $5$
- $7$
- $8$

## Spiegazione

Le coppie degli argomenti sono $(71,26)$, $(26,19)$, $(19,7)$, $(7,5)$, $(5,2)$, $(2,1)$ e $(1,0)$. Il resto è definito a ogni passaggio precedente l’ultimo perché il divisore è positivo. Ci sono sei passaggi verso una nuova coppia e sette invocazioni contando anche l’inizio.
