Quante invocazioni logiche compaiono durante `visits(6)`, contando la radice e i casi base?

```c
unsigned visits(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned first = visits(n / 2u);
    if (n % 2u == 0u) {
        return first;
    }
    return first + visits(n / 2u);
}
```

- $4$
- $7$
- $15$
- $8$

## Spiegazione

L’argomento $6$ è pari, quindi produce una sola figlia con argomento $3$. Il nodo $3$ è dispari e produce due chiamate di argomento $1$. Ciascuna di queste ne avvia due con argomento $0$. I livelli hanno pertanto $1$, $1$, $2$ e $4$ invocazioni e il totale vale otto.
