Quale esito ha `sum_empty(NULL, 0)`?

```c
#include <stddef.h>

unsigned sum_empty(const unsigned a[], size_t n)
{
    if (n == 0) {
        return 0u;
    }
    return sum_empty(a, n - 1) + a[n - 1];
}
```

- `0u`
- Comportamento indefinito per una lettura tramite `NULL`
- Comportamento indefinito per la sottrazione da `n`
- `1u`

## Spiegazione

La guardia `n == 0` è vera. Il `return` del ramo base termina la chiamata prima che si raggiunga l’espressione che accede al vettore. Il puntatore nullo viene solo passato come argomento. Il valore di ritorno è `0u`.
