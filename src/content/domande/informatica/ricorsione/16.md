Quanto restituisce `digit_total(5048)`?

```c
unsigned digit_total(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return n % 10u + digit_total(n / 10u);
}
```

- $12$
- $13$
- $17$
- $5048$

## Spiegazione

Per un intero non negativo, `n % 10u` dà l’ultima cifra decimale e `n / 10u` elimina quella cifra. Le chiamate con $5048$, $504$, $50$ e $5$ aggiungono rispettivamente $8$, $4$, $0$ e $5$. Poi si raggiunge lo zero e si ottiene $8+4+0+5=17$.
