Una funzione ricorsiva usa al ritorno il proprio parametro `n` per una sottrazione. Nel codice riportato, quale valore restituisce `alternate(4)`?

```c
int alternate(int n)
{
    if (n == 0) {
        return 0;
    }
    return n - alternate(n - 1);
}
```

- $4$
- $-2$
- $10$
- $2$

## Spiegazione

Partendo dalla base si ottiene $A(0)=0$. Le chiamate sospese calcolano nell’ordine $A(1)=1-0=1$, $A(2)=2-1=1$, $A(3)=3-1=2$ e $A(4)=4-2=2$. La sottrazione non si può riassociare come una somma di tutti gli argomenti.
