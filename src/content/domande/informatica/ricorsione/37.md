Si avvia `collect(9, 2)`. Quali sono le coppie $(n,\mathrm{acc})$ delle prime due chiamate dopo l’inizio, in ordine?

```c
unsigned collect(unsigned n, unsigned acc)
{
    if (n <= 1u) {
        return acc + n;
    }
    return collect(n - 2u, acc + n);
}
```

- $(7,9),(5,16)$
- $(7,11),(5,18)$
- $(7,9),(5,14)$
- $(8,11),(7,19)$

## Spiegazione

Dallo stato $(9,2)$ il nuovo argomento scende a $7$, mentre l’accumulatore vale $2+9=11$. L’aggiornamento somma il vecchio `n`. Al passo seguente il nuovo argomento è $5$ e l’accumulatore vale $11+7=18$.
