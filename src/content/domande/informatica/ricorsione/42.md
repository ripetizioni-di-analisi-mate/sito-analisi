Il contratto di `first` restituisce la prima occorrenza, oppure la lunghezza quando la chiave è assente. Con quale condizione va sostituito `FOUND_IN_PREFIX`?

```c
#include <stddef.h>

size_t first(const unsigned a[], size_t n, unsigned key)
{
    if (n == 0) {
        return n;
    }
    size_t position = first(a, n - 1, key);
    if (FOUND_IN_PREFIX) {
        return position;
    }
    return a[n - 1] == key ? n - 1 : n;
}
```

- `position < n - 1`
- `position < n`
- `position == n - 1`
- `position == 0`

## Spiegazione

La chiamata figlia ha lunghezza `n - 1`. Una prima occorrenza in quel tratto ha indice strettamente minore della sua lunghezza. L’indice uguale a `n - 1` denota invece l’assenza nel prefisso. In quel caso il chiamante deve ancora esaminare l’ultimo elemento del proprio tratto.
