Quale sequenza di caratteri stampa la chiamata `visit(3)`, assumendo che le operazioni di scrittura abbiano successo?

```c
#include <stdio.h>

void visit(unsigned n)
{
    if (n == 0u) {
        putchar('0');
        return;
    }
    printf("%u", n);
    visit(n - 1u);
    printf("%u", n);
}
```

- `3210321`
- `3210`
- `30123`
- `3210123`

## Spiegazione

Prima delle chiamate figlie si stampano $3$, $2$ e $1$. Il ramo base stampa $0$ e ritorna alla chiamata con argomento $1$. Nel ritorno si riprendono nell’ordine le chiamate con argomenti $1$, $2$ e $3$, utilizzando la seconda istruzione di stampa. La sequenza completa è quindi `3210123`.
