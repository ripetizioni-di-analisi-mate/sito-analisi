Calcolare `weighted(3)`.

```c
unsigned weighted(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    unsigned child = weighted(n - 1u);
    return 2u * child + n;
}
```

- $6$
- $11$
- $8$
- $14$

## Spiegazione

Il valore base è $0$. Per $n=1$ si ottiene $2\cdot0+1=1$. Per $n=2$ si calcola $2\cdot1+2=4$. Nella chiamata iniziale il valore figlio è quindi $4$, da cui $2\cdot4+3=11$. Il raddoppio riguarda il risultato figlio prima di aggiungere l’argomento corrente.
