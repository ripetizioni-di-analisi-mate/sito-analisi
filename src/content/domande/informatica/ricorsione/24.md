Si indichi con $S(n)$ il risultato di `sum_even(n)` per $n$ da $0$ a $20$. Per $n>0$ l’ipotesi induttiva è $S(n-1)=(n-1)n$. Quale relazione completa il passo?

```c
unsigned sum_even(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return 2u * n + sum_even(n - 1u);
}
```

- $S(n)=2n+n(n+1)$
- $S(n)=(n-1)n$
- $S(n)=(n-1)(n+2)$
- $S(n)=2n+(n-1)n=n(n+1)$

## Spiegazione

L’ipotesi induttiva fornisce il valore della chiamata con argomento $n-1$. L’istruzione di ritorno aggiunge il nuovo pari $2n$. La somma si fattorizza come $n(2+n-1)=n(n+1)$, che è la formula desiderata al passo $n$.
