Quante invocazioni complessive, compresi inizio e casi base, produce `split_leaves(5)`?

```c
unsigned split_leaves(unsigned n)
{
    if (n <= 1u) {
        return 1u;
    }
    unsigned left = split_leaves(n / 2u);
    unsigned right = split_leaves(n - n / 2u);
    return left + right;
}
```

- $9$
- $4$
- $5$
- $11$

## Spiegazione

Il nodo $5$ genera i nodi $2$ e $3$. Il nodo $2$ genera due foglie di argomento $1$. Il nodo $3$ genera una foglia e un altro nodo $2$, da cui altre due foglie. In totale si contano cinque foglie e quattro nodi interni, quindi nove invocazioni.
