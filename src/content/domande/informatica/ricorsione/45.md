Si assume `UINT_MAX = 65535`. Qual è il massimo `n` tra $0$ e $10$ per cui si ottiene il fattoriale esatto senza riduzione modulo in nessun prodotto?

```c
unsigned factorial(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    return n * factorial(n - 1u);
}
```

- $7$
- $9$
- $10$
- $8$

## Spiegazione

Il caso base dà uno e, finché il prodotto è rappresentabile, la risalita dà il fattoriale dell’argomento. Si ha $8!=40320$, che rientra nel limite, mentre $9!=9\cdot40320=362880$ lo supera. I fattoriali crescono per questi argomenti, e una chiamata con $n>9$ passa comunque per il prodotto con $9$.
