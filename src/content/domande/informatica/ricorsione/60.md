In C17, durante `emit(2)` le scritture sullo standard output riescono. Quali sequenze di caratteri ammette il linguaggio?

```c
#include <stdio.h>

int emit(unsigned n)
{
    if (n < 2u) {
        putchar('0' + (int)n);
        return (int)n;
    }
    return emit(0u) + emit(1u);
}
```

- Soltanto `01`.
- Sia `01` sia `10`.
- Una delle due cifre può essere omessa.
- Soltanto `10`.

## Spiegazione

Il ramo della radice somma i risultati di due chiamate. L’operatore `+` richiede entrambi gli operandi, però non stabilisce quale chiamata venga eseguita per prima. Ognuna delle due chiamate di base stampa una cifra. I risultati numerici sommano sempre a uno, mentre la sequenza delle cifre dipende dall’ordine scelto.
