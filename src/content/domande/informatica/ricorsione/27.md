Durante `explore(4)`, quando è attiva la chiamata discendente di argomento $1$, quanto vale `saved` nel record della chiamata iniziale?

```c
unsigned explore(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    unsigned saved = n + 2u;
    unsigned child = explore(n - 1u);
    return saved + child;
}
```

- $3$
- $4$
- $5$
- $6$

## Spiegazione

La chiamata iniziale con argomento $4$ assegna $6$ a `saved` prima di avviare la figlia. Le chiamate con argomenti minori creano ciascuna un proprio oggetto `saved`. Quando la chiamata di argomento $1$ è attiva, il record iniziale è in attesa e il suo `saved` conserva $6$.
