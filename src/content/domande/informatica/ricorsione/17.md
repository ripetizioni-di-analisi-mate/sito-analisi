Calcolare `scale(4, 3)`.

```c
unsigned scale(unsigned n, unsigned acc)
{
    if (n == 0u) {
        return acc;
    }
    return scale(n - 1u, 2u * acc);
}
```

- $24$
- $48$
- $16$
- $6$

## Spiegazione

Ogni passaggio diminuisce `n` di uno e raddoppia il valore dell’accumulatore. Con l’argomento iniziale $4$ si eseguono quattro raddoppi, da $3$ a $6$, $12$, $24$ e $48$. La chiamata con `n == 0u` restituisce l’ultimo accumulatore. Il risultato corrisponde a $3\cdot2^4$.
