Fra gli input da $0$ a $31$, qual è il massimo che produce al più cinque record logici simultaneamente attivi in `halves(n)`? Contare la chiamata iniziale e il caso base.

```c
unsigned halves(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return 1u + halves(n / 2u);
}
```

- $15$
- $8$
- $16$
- $31$

## Spiegazione

Un massimo di cinque record comprende il caso base e al più quattro passi di dimezzamento. Dopo quattro divisioni intere per due resta la parte intera del quoziente per $16$. Questa vale zero per $n$ fino a $15$. Da $16$ in poi rimane almeno uno, quindi occorre almeno un passo in più.
