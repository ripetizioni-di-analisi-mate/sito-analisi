Per quale argomento proposto la prima chiamata figlia riceve un valore maggiore dell’argomento iniziale? È sufficiente analizzare la prima sottrazione, senza eseguire l’intera ricorsione.

```c
unsigned decrease(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    return decrease(n - 3u);
}
```

- $3$
- $4$
- $5$
- $2$

## Spiegazione

L’input $2$ supera la guardia di base e tenta la sottrazione di tre in tipo `unsigned`. Il risultato viene ridotto modulo il numero di valori del tipo, quindi l’argomento figlio è `UINT_MAX`, maggiore di due. Con gli altri input proposti la prima sottrazione dà invece $0$, $1$ e $2$, tutti minori del rispettivo valore iniziale.
