In `weave(4)`, quali sono, in ordine di avvio, i primi tre argomenti dopo quello della chiamata iniziale?

```c
unsigned weave(unsigned n)
{
    if (n < 2u) {
        return n;
    }
    unsigned first = weave(n - 1u);
    unsigned second = weave(n - 2u);
    return first + second;
}
```

- $(3,2,0)$
- $(3,2,1)$
- $(3,1,2)$
- $(2,3,1)$

## Spiegazione

La prima istruzione di chiamata avvia il figlio con argomento $3$. Il suo primo figlio ha argomento $2$, che a sua volta avvia prima la chiamata di argomento $1$. Queste sono le prime tre invocazioni successive alla radice. Le dichiarazioni che calcolano i secondi figli vengono raggiunte al ritorno dei rispettivi primi figli.
