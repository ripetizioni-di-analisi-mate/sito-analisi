Il vettore `a` contiene $(5,7,2,7,9)$. Calcolare `count_gt(a, 5, 7)`.

```c
#include <stddef.h>

unsigned count_gt(const unsigned a[], size_t n, unsigned limit)
{
    if (n == 0) {
        return 0u;
    }
    return count_gt(a, n - 1, limit) + (a[n - 1] > limit);
}
```

- $0$
- $1$
- $2$
- $3$

## Spiegazione

Il ritorno del prefisso vuoto vale zero. Ogni estensione aggiunge uno quando il nuovo ultimo elemento supera `limit` e zero negli altri casi. Per i due elementi $7$ il confronto è stretto e risulta falso. Solo il valore $9$ dà un contributo unitario, quindi l’esito è $1$.
