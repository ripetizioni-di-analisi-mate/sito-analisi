Calcolare il valore di `path(9)`.

```c
unsigned path(unsigned n)
{
    if (n < 3u) {
        return 2u;
    }
    if (n % 2u == 0u) {
        return 1u + path(n - 2u);
    }
    return 1u + path(n - 3u);
}
```

- $5$
- $3$
- $4$
- $6$

## Spiegazione

L’argomento $9$ è dispari e passa a $6$. Da $6$ si passa a $4$ e poi a $2$, perché entrambi i passi precedenti partono da valori pari. Il ramo con $2$ restituisce $2$. Ciascuno dei tre passi ricorsivi aggiunge uno e il risultato è $2+3=5$.
