Qual è il più piccolo input da $0$ a $12$ che raggiunge il ramo base con argomento $2$ dopo almeno una chiamata ricorsiva?

```c
unsigned bands(unsigned n)
{
    if (n < 3u) {
        return n * n;
    }
    return 1u + bands(n - 3u);
}
```

- $2$
- $3$
- $5$
- $4$

## Spiegazione

Per arrivare a `n = 2u` dopo una discesa bisogna partire da un valore che supera la guardia di base e ha resto due modulo tre. L’input $2$ si ferma subito. Gli input $3$ e $4$ mandano rispettivamente a $0$ e $1$. L’input $5$ è il primo che effettua una chiamata figlia con argomento $2$.
