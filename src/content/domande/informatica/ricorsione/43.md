Quanti operatori `*` vengono valutati nelle espressioni di ritorno durante `power3(5)`, nel conteggio logico sul codice sorgente?

```c
unsigned power3(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned half = power3(n / 2u);
    if (n % 2u == 0u) {
        return half * half;
    }
    return 3u * half * half;
}
```

- $3$
- $5$
- $4$
- $6$

## Spiegazione

Gli argomenti sono $5$, $2$, $1$ e $0$. La base non contiene moltiplicazioni. Nel ramo dispari di $1$ ci sono due operatori `*`, nel ramo pari di $2$ ce n’è uno e nel ramo dispari di $5$ ce ne sono due. Il totale è $2+1+2=5$.
