Quante invocazioni logiche complessive si ottengono con `duplicate(4)` e con `reuse(4)`, rispettivamente? Contare le chiamate iniziali e le foglie.

```c
unsigned duplicate(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    return duplicate(n - 1u) + duplicate(n - 1u);
}

unsigned reuse(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned child = reuse(n - 1u);
    return child + child;
}
```

- $(16,5)$
- $(31,5)$
- $(31,4)$
- $(15,4)$

## Spiegazione

Con `duplicate` ogni nodo positivo crea due figli, anche se gli argomenti coincidono. Per `n = 4u` i livelli contengono $1$, $2$, $4$, $8$ e $16$ nodi, per un totale di $31$. In `reuse` il valore della singola figlia viene salvato e usato due volte. Le chiamate attive lungo il solo cammino hanno argomenti $4$, $3$, $2$, $1$ e $0$, quindi le invocazioni sono cinque.
