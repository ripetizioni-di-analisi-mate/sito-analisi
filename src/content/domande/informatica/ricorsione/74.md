La funzione `pick` riceve un vettore valido di lunghezza tre. Per l’ingresso `{1,2,4}`, quali valori contiene il vettore dopo `pick(a,3)`?

```c
#include <stddef.h>

void pick(int a[], size_t n)
{
    if (n < 2) {
        return;
    }
    pick(a + 1, n - 1);
    a[0] += a[1];
}
```

- $\{7,6,4\}$
- $\{3,6,4\}$
- $\{1,3,7\}$
- $\{1,2,4\}$

## Spiegazione

La chiamata di lunghezza uno lascia il $4$ invariato. La chiamata precedente riprende sul suffisso che comincia con $2$ e scrive $2+4=6$. Infine il record iniziale legge quel $6$ già aggiornato e scrive $1+6=7$. Le letture successive al ritorno vedono le modifiche nel vettore condiviso.
