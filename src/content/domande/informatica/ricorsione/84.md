Nella funzione seguente ogni figlio riceve l’indirizzo della variabile automatica del chiamante. La chiamata iniziale è `frame(2, NULL)`. Quale valore restituisce?

```c
#include <stddef.h>

int frame(int n, int *parent)
{
    int x = n;
    if (parent != NULL) {
        *parent += 10;
    }
    if (n > 0) {
        frame(n - 1, &x);
    }
    return x;
}
```

- $22$
- $2$
- $11$
- $12$

## Spiegazione

Il record iniziale crea `x = 2` e ne passa l’indirizzo al figlio con $n=1$. Quel figlio incrementa di dieci proprio la `x` del record iniziale. La chiamata con $n=0$ incrementa invece la `x` del record con $n=1$. I ritorni figli sono ignorati, quindi il record iniziale restituisce la propria `x`, pari a $12$.
