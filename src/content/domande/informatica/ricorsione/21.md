Si indica con $n_0$ l’argomento iniziale. Quale delle seguenti quantità intere è non negativa e diminuisce strettamente a ogni chiamata ricorsiva?

```c
unsigned reduce(unsigned n)
{
    if (n <= 4u) {
        return n;
    }
    if (n % 2u != 0u) {
        return reduce(n - 3u);
    }
    return reduce(n / 2u);
}
```

- $n\bmod2$
- $n$
- $n_0-n$
- $1$

## Spiegazione

Nel ramo dispari `n > 4u` permette di sottrarre tre mantenendo un valore non negativo. Nel ramo pari la divisione intera per due produce anch’essa un valore strettamente minore di quello di partenza. Perciò $n$ è la misura richiesta. Il resto modulo due può rimanere uguale, per esempio sul passaggio da $8$ a $4$.
