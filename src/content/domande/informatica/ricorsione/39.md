Quale affermazione portabile in C17 descrive il ritorno ricorsivo di `end_bit`?

```c
unsigned end_bit(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    return end_bit(n / 2u);
}
```

- La chiamata è in posizione di coda e C17 garantisce spazio fisico costante.
- La chiamata è in posizione di coda e C17 lascia all’implementazione la gestione dei record fisici.
- La divisione negli argomenti richiede un calcolo dopo il ritorno della figlia.
- C17 impone un record fisico separato per ogni dimezzamento.

## Spiegazione

Il dimezzamento produce l’argomento prima dell’ingresso nella figlia. Al ritorno si restituisce direttamente il valore ottenuto, perciò la chiamata è in coda. L’implementazione può riutilizzare spazio in questo caso. Il C17 specifica il comportamento della macchina astratta e lascia libera quella scelta di implementazione.
