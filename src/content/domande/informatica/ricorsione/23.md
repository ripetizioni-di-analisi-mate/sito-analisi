Su `a = {2, 2, 5, 4, 8}`, quante volte `ordered(a, 5)` confronta due elementi del vettore?

```c
#include <stddef.h>

int ordered(const int a[], size_t n)
{
    if (n < 2) {
        return 1;
    }
    return a[0] <= a[1] && ordered(a + 1, n - 1);
}
```

- $3$
- $2$
- $4$
- $5$

## Spiegazione

La prima chiamata confronta $2$ con $2$ e la seconda confronta $2$ con $5$. Entrambi i confronti sono veri e si può avanzare. La terza chiamata confronta $5$ con $4$, ottenendo falso. Il corto circuito salta l’ultima chiamata figlia, perciò si sono eseguiti tre confronti fra valori.
