La funzione seguente registra il resto della divisione per due di ogni argomento positivo, ma solo dopo il ritorno del figlio. Quale sequenza registra `digits(12)`? Le scritture riescono.

```c
#include <stdio.h>

void digits(unsigned n)
{
    if (n != 0u) {
        digits(n / 2u);
        putchar('0' + (int)(n % 2u));
    }
}
```

- `110`
- `01100`
- `1100`
- `0011`

## Spiegazione

Nella discesa si visitano $12,6,3,1,0$. Il caso con $0$ ritorna senza scrivere. I quattro record sospesi scrivono al ritorno, quindi nell’ordine degli argomenti $1,3,6,12$. Le rispettive parità sono $1,1,0,0$, producendo la scrittura binaria della quantità iniziale senza uno zero aggiuntivo.
