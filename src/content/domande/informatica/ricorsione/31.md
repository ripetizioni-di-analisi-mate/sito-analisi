Durante `sum_to(4, 0)` si considerano gli argomenti correnti `n` e `acc` all’ingresso di ciascuna chiamata. Quale espressione matematica conserva lo stesso valore in tutti questi stati?

```c
unsigned sum_to(unsigned n, unsigned acc)
{
    if (n == 0u) {
        return acc;
    }
    return sum_to(n - 1u, acc + n);
}
```

- $\mathrm{acc}+\dfrac{n(n+1)}{2}$
- $\mathrm{acc}-\dfrac{n(n+1)}{2}$
- $\mathrm{acc}+n$
- $2\,\mathrm{acc}+n$

## Spiegazione

Passando alla figlia, `acc` aumenta di $n$. La somma dei termini ancora da aggiungere passa da $\dfrac{n(n+1)}{2}$ a $\dfrac{(n-1)n}{2}$, quindi diminuisce di $n$. I due cambiamenti si compensano. La quantità vale $10$ all’ingresso iniziale e quando $n=0$ coincide con il risultato.
