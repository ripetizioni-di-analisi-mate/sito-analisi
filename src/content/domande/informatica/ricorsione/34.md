I tre elementi di `a` sono $2$, $0$ e $7$. Calcolare `assemble(a, 3)`.

```c
#include <stddef.h>

unsigned assemble(const unsigned a[], size_t n)
{
    if (n == 0) {
        return 0u;
    }
    return 10u * assemble(a, n - 1) + a[n - 1];
}
```

- $207$
- $27$
- $702$
- $9$

## Spiegazione

Il prefisso vuoto dà $0$. Il prefisso di una cifra dà $10\cdot0+2=2$. Il secondo prefisso dà $10\cdot2+0=20$, anche se la nuova cifra è zero. Estendendolo con l’ultimo elemento si ottiene $10\cdot20+7=207$.
