Completare `CONDITION` affinché per ogni `n` iniziale da $0$ a $30$ la funzione restituisca il resto della divisione per tre mediante sottrazioni successive, con ciascun nuovo argomento strettamente minore del precedente.

```c
unsigned strip(unsigned n)
{
    if (CONDITION) {
        return n;
    }
    return strip(n - 3u);
}
```

- `n == 0u`
- `n == 3u`
- `n < 3u`
- `n > 3u`

## Spiegazione

I possibili resti sono $0$, $1$ e $2$. La condizione `n < 3u` restituisce proprio quei valori e lascia la ricorsione proseguire per ogni `n` almeno uguale a tre. In quel ramo la sottrazione è rappresentabile e conserva il resto della divisione per tre. Provare a partire da `n = 1u` distingue la guardia corretta da una che arresta solo a zero.
