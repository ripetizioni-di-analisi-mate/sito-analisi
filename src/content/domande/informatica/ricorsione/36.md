Il vettore offre esattamente $m\geq1$ elementi leggibili. Quale intervallo descrive tutti gli `n` iniziali per cui il frammento esamina un prefisso valido e restituisce il suo massimo?

```c
#include <stddef.h>

int max_of(const int a[], size_t n)
{
    if (n == 1) {
        return a[0];
    }
    int previous = max_of(a, n - 1);
    return previous < a[n - 1] ? a[n - 1] : previous;
}
```

- $0\leq n\leq m$
- $1\leq n<m$
- $1\leq n\leq m$
- $n=0$

## Spiegazione

Con `n` almeno uno, la discesa raggiunge esattamente il caso base di lunghezza uno. Quando `n` è al massimo `m`, tutti gli accessi del calcolo riguardano elementi disponibili. Con il valore iniziale zero si salterebbe la guardia e si passerebbe alla chiamata figlia il valore di `n - 1` convertito a `size_t`, che è maggiore di zero. L’estremo `n == m` è utilizzabile perché l’indice maggiore che si legge è `m - 1`.
