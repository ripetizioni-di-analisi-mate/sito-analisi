Il programma deve scrivere una sola riga `nessun dato` se non esistono misure valide. Una suite prova soltanto un file vuoto. Quale secondo ingresso applica la **stessa** regola di uscita passando però attraverso la logica di scarto delle righe?

- Un file con una riga valida contenente zero.
- Un file con due misure valide di segno opposto.
- Un file con due righe complete, entrambe non numeriche.
- Un file con una misura valida e una riga rifiutata.

## Spiegazione

Il caso vuoto non entra nel ciclo di convalida. Due righe entrambe rifiutate eseguono invece il parser ma lasciano il conteggio dei validi a zero. Una misura valida uguale a zero è comunque un dato e deve essere distinta dall’assenza di misure.
