Un programma C17 deve creare un rapporto di testo nuovo e segnalare un errore se il percorso identifica già un file esistente. Quale modo di apertura esprime entrambe le richieste in una sola chiamata a `fopen`?

- `"w"`
- `"a"`
- `"wx"`
- `"r+"`

## Spiegazione

Il modificatore `x` con `w` richiede che il file non esista, quindi un file preesistente fa fallire l’apertura. Il modo `w` da solo può troncare il vecchio rapporto, mentre `a` può estenderlo. Il programma controlla il puntatore restituito prima di scrivere.
