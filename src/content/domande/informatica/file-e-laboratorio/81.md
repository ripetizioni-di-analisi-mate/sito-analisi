L’intestazione di un file dichiara due record. La specifica richiede esattamente due righe di dati valide e nessun’altra riga. Il parser legge due record validi e poi una terza riga `X`, prima della normale fine del file. Che cosa deve riportare il collaudo?

- Indeterminatezza, perché la normale fine file non si può distinguere da un errore.
- File conforme se la X non è un numero.
- File conforme perché il numero di record validi è due.
- File non conforme per la presenza di contenuto aggiuntivo.

## Spiegazione

Raggiungere due record soddisfa soltanto il requisito sul numero di dati validi. La specifica vieta anche righe ulteriori. La terza riga dimostra la violazione indipendentemente dal suo contenuto, quindi il parser deve verificare come termina il file.
