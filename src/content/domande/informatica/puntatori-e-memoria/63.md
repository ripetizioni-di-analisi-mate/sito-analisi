Il secondo parametro di `measure` è facoltativo. Con `<stddef.h>` incluso, quale coppia `(score,saved)` si ottiene?

```c
#include <stddef.h>

int measure(int x, int *out) {
    if (out != NULL) *out = x * x;
    return x + 1;
}
void example(void) {
    int saved = 0;
    int score = measure(3, &saved);
    score += measure(4, NULL);
}
```

- $(9,9)$
- $(5,9)$
- $(9,16)$
- $(7,0)$

## Spiegazione

La prima chiamata restituisce 4 e registra $3^2=9$ in `saved`. La seconda restituisce 5 e omette la scrittura perché il parametro di uscita è nullo. `score` vale quindi $4+5=9$ e il valore registrato rimane 9.
