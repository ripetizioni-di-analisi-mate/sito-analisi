Con `<stdlib.h>` incluso, si supponga riuscita la prima allocazione e fallita la seconda. Quanti blocchi ottenuti qui sono ancora in corso di durata quando si esegue l’istruzione `return 0;`?

```c
int *left = malloc(sizeof *left);
int *right = malloc(sizeof *right);
if (left == NULL || right == NULL) {
    free(left);
    free(right);
    return 0;
}
```

- $3$
- $0$
- $1$
- $2$

## Spiegazione

La prima chiamata crea un blocco e la seconda scrive il valore nullo nel puntatore `right`. Il ramo di errore viene eseguito. Al suo interno, `free(left)` termina la durata del solo blocco ottenuto e `free(right)` non ha effetto. Il conteggio di blocchi in corso di durata è $1-1=0$.
