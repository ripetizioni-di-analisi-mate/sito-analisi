Con la funzione indicata si eseguono nell’ordine `int *a = counter();`, `int old = *a;` e `int *b = counter();`. Calcolare `*a + *b - old`.

```c
int *counter(void)
{
    static int count = 4;
    ++count;
    return &count;
}
```

- $5$
- $12$
- $7$
- $6$

## Spiegazione

L’oggetto `count` ha durata statica. La prima chiamata lo porta a $5$ e `old` ne copia il valore. La seconda chiamata porta lo stesso oggetto a $6$. Entrambi i puntatori lo designano, perciò l’espressione vale $6+6-5=7$.
