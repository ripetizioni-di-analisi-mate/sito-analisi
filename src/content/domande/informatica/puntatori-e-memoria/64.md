La struttura `v` viene copiata in `w`. Qual è la coppia `(base[0], v.n)` dopo gli aggiornamenti?

```c
struct View { int *data; int n; };
int base[] = {3, 6, 9};
struct View v = {base, 3};
struct View w = v;
w.n = 1;
w.data[0] = 8;
```

- $(3,1)$
- $(8,1)$
- $(3,3)$
- $(8,3)$

## Spiegazione

La copia duplica i campi della struttura. I campi `n` sono oggetti distinti, quindi `w.n = 1` lascia `v.n` uguale a 3. I campi `data` contengono invece lo stesso indirizzo: la scrittura attraverso `w.data` raggiunge `base[0]`.
