Con questo `typedef`, quale operazione è ammessa dopo l’inizializzazione di `p`?

```c
typedef int *Link;
int x = 3, y = 8;
const Link p = &x;
```

- `p = &x;`
- `*p = y;`
- `p++;`
- `p = &y;`

## Spiegazione

`Link` è il nome dell’intero tipo puntatore. Applicare `const` al nome qualifica il puntatore stesso: `p` conserva l’indirizzo di `x`. L’intero puntato resta modificabile, perciò `*p = y` copia il valore 8 in `x`.
