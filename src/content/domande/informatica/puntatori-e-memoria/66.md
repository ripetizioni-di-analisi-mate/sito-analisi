Si valuta `probe(1, NULL)` con `<stddef.h>` incluso. Quanto vale il risultato del confronto eseguito nella chiamata più interna?

```c
#include <stddef.h>

int probe(int depth, const int *outer) {
    int cell = 5;
    if (depth == 0) return outer == &cell;
    return probe(depth - 1, &cell);
}
```

- Dipende dal verso di crescita della pila.
- $1$
- $0$
- $5$

## Spiegazione

La chiamata esterna è ancora attiva mentre la chiamata interna esegue il confronto. Ciascuna ha la propria variabile automatica `cell`. `outer` punta a quella esterna e `&cell` a quella interna. Due oggetti distinti e simultaneamente in vita danno qui puntatori diversi.
