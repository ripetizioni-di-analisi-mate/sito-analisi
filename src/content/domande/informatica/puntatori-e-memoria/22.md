Quale valore assume `sum` al termine della scansione all’indietro?

```c
const int a[] = {1, -2, 8, 3, 4, -1};
const int *p = a + 6;
int sum = 0;
while (p != a + 3) {
    --p;
    sum += *p;
}
```

- $14$
- $6$
- $3$
- $5$

## Spiegazione

`p` parte dalla posizione successiva all’array. Ogni iterazione arretra prima di leggere, quindi le celle visitate hanno indici $5$, $4$ e $3$. Le letture danno $-1$, $4$ e $3$. La somma vale $-1+4+3=6$. All’arrivo a `a + 3` il test successivo arresta il ciclo.
