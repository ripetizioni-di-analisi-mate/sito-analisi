Il puntatore `p` avanza finché il prefisso corrente coincide con quello di `b`. Entrambi gli array hanno quattro elementi. Quale lunghezza restituisce la funzione con i dati indicati?

```c
#include <stddef.h>

ptrdiff_t prefix(const int a[4], const int b[4]) {
    const int *p = a;
    while (p != a + 4 && *p == b[p - a]) ++p;
    return p - a;
}
/* a = {4,9,2,5}; b = {4,9,8,5} */
```

- $3$
- $4$
- $1$
- $2$

## Spiegazione

Le coppie di indice 0 e 1 hanno valori uguali, quindi dopo due incrementi `p` indica `a[2]`. All’indice 2 si confrontano 2 e 8 e la condizione diventa falsa. La differenza `p - a` misura i due elementi del prefisso, e l’uguaglianza all’indice 3 non viene esaminata.
