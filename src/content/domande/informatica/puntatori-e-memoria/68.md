Un programma ammette una sequenza vuota rappresentata dalla coppia `(NULL,0)`. Quale inizio della funzione `sum(const int *a, size_t n)` tratta questo caso prima di eseguire aritmetica sul puntatore?

- `const int *end = a + n;`
- `int total = a[0];`
- `const int *next = a + 1;`
- `if (n == 0) return 0;`

## Spiegazione

La lunghezza è sufficiente per riconoscere la sequenza vuota. Il ritorno immediato calcola la somma vuota, zero, senza usare `a`. Quando `n` è positivo il contratto dovrà invece fornire un puntatore valido a una sequenza di almeno `n` elementi.
