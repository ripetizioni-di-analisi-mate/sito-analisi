`first` e `last` delimitano una porzione, anche vuota, di uno stesso array. `last` è l’estremo escluso. Quale coppia di operazioni legge l’ultimo elemento soltanto quando esiste?

- `if (first != last) value = first[0];`
- `if (first == last) value = *first;`
- `if (first != last) value = last[-1];`
- `if (first != last) value = *last;`

## Spiegazione

Una porzione non vuota soddisfa `first != last`. In quel ramo `last - 1` designa l’ultimo elemento compreso, e `last[-1]` ne legge il valore. `first[0]` individua il primo elemento, che coincide con l’ultimo solo nelle porzioni di lunghezza uno.
