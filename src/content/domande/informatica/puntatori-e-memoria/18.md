La chiamata è `update(&x, &y)` con `int x = 7, y = 12;`. Qual è la coppia finale $(x,y)$?

```c
void update(int *out, int *alt)
{
    *out = 3;
    out = alt;
    *out += 4;
}
```

- $(3,12)$
- $(7,16)$
- $(3,16)$
- $(7,12)$

## Spiegazione

Il parametro `out` riceve l’indirizzo di `x`, quindi la prima scrittura assegna $3$ a `x`. Poi `out` prende l’indirizzo contenuto in `alt`, cioè quello di `y`. L’incremento tramite la nuova destinazione porta `y` da $12$ a $16$. L’ultima coppia è $(3,16)$.
