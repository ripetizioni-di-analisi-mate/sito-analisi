Con `<string.h>` incluso, `memchr(p,c,n)` restituisce un puntatore al primo dei successivi `n` byte uguale a `c`, oppure `NULL` se manca. In questo frammento C17 quale valore riceve `off`?

```c
const unsigned char a[] = {4, 0, 7, 4, 4};
const unsigned char *p = memchr(a + 1, 4, 3);
int off = p == NULL ? -1 : (int)(p - a);
```

- $3$
- $0$
- $2$
- $-1$

## Spiegazione

La ricerca parte da `a[1]` e comprende tre byte, di valori $0$, $7$ e $4$. Il byte zero fa parte dei dati di questa ricerca a lunghezza esplicita. La prima corrispondenza nell’intervallo è `a[3]`. La sottrazione usa la base `a`, quindi `off` vale $3$.
