Un lettore avanza il cursore del chiamante di un elemento e restituisce il valore consumato. Dopo la chiamata, che cosa valgono `v` e `*next`?

```c
int take(const int **pos) {
    int out = **pos;
    ++*pos;
    return out;
}
void example(void) {
    int a[] = {9, 12, 7};
    const int *next = a + 1;
    int v = take(&next);
}
```

- $(12,12)$
- $(13,7)$
- $(12,7)$
- $(7,7)$

## Spiegazione

All’ingresso `*pos` è il cursore `next` e `**pos` è `a[1]`. La funzione salva 12 in `out`. L’istruzione `++*pos` sposta il cursore del chiamante su `a[2]`, quindi dopo il ritorno `*next` vale 7.
