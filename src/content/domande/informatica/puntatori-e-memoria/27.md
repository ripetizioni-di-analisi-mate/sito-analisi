Disponendo di `<stddef.h>`, si chiama la funzione seguente con `int a[2] = {3, 8};` e `first(a, 0)`. Quale valore si ottiene?

```c
const int *first(const int a[], size_t n)
{
    return n > 0 ? &a[0] : NULL;
}
```

- `a + 1`
- `a + 2`
- `a`
- `NULL`

## Spiegazione

Quando `n` vale zero la condizione dell’operatore condizionale è falsa. Viene valutata l’espressione `NULL`, che restituisce il puntatore nullo del tipo di ritorno. La selezione termina senza leggere una cella.
