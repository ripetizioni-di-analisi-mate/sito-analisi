Quale valore restituisce la lettura di `*p` dopo le dichiarazioni e l’assegnamento?

```c
int x = 4;
const int *p = &x;
int *q = &x;
*q = 11;
```

- $11$
- $15$
- $4$
- $7$

## Spiegazione

La qualifica in `const int *p` limita le modifiche tramite `p`. L’oggetto `x` è stato dichiarato come `int` e resta modificabile tramite `q`. Poiché entrambi lo designano, la lettura con `*p` dopo la scrittura dà $11$.
