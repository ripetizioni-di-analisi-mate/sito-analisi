La stessa cella viene passata come entrambi i parametri di uscita. Quale valore contiene `x` al termine della chiamata?

```c
void split(int total, int *first, int *second) {
    *first = total / 2;
    *second = total - *first;
}
void example(void) {
    int x = 0;
    split(9, &x, &x);
}
```

- $5$
- $0$
- $4$
- $9$

## Spiegazione

La prima istruzione scrive in `x` il quoziente intero $9/2$, cioè 4. L’istruzione successiva legge quel 4 attraverso `first` e scrive $9-4=5$ nella stessa cella attraverso `second`. I due risultati intermedi esistono in tempi diversi.
