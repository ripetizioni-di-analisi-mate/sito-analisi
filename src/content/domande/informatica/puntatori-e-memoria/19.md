Si dichiari `int a = 2, b = 9; int *p = &a;`. Si eseguano `redirect(&p, &b);` e `(*p)++;`. Qual è la coppia $(a,b)$?

```c
void redirect(int **position, int *next)
{
    *position = next;
}
```

- $(3,9)$
- $(2,9)$
- $(2,10)$
- $(10,10)$

## Spiegazione

`&p` designa la variabile puntatore del chiamante. La scrittura attraverso `*position` modifica quindi `p`, che assume l’indirizzo di `b`. In `(*p)++` si incrementa `b` da $9$ a $10$, mentre `a` rimane $2$. Il risultato è $(2,10)$.
