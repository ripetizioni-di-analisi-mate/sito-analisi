Nel frammento la funzione chiamata restituisce il puntatore solo dopo aver inizializzato il blocco. Se l’allocazione riesce, in quale momento termina la durata del blocco?

```c
#include <stdlib.h>

int *make_count(void) {
    int *r = malloc(sizeof *r);
    if (r != NULL) *r = 12;
    return r;
}
void example(void) {
    int *count = make_count();
    if (count != NULL) free(count);
}
```

- Quando il valore 12 viene scritto nel blocco.
- Quando si esegue `return r`, prima che inizi la copia del puntatore.
- Quando il chiamante esegue `free(count)`.
- Quando termina la variabile locale `r`.

## Spiegazione

La durata automatica di `r` riguarda la variabile che contiene l’indirizzo. Il blocco ha durata allocata e il valore del puntatore viene restituito al chiamante. Nel percorso di successo il blocco resta in vita fino alla chiamata a `free(count)`.
