Il frammento è nel corpo di una funzione. Qual è l’esito della lettura con cui si inizializza `result`?

```c
int value = 31;
int *out;
{
    int *copy = &value;
    out = copy;
}
int result = *out;
```

- $0$
- $1$
- $31$
- Comportamento indefinito.

## Spiegazione

Il blocco interno contiene la variabile puntatore `copy`. Prima dell’uscita, `out` ne ha copiato il valore, che designa `value` nel blocco esterno. La durata di `value` è ancora in corso al momento della lettura. La dereferenziazione restituisce quindi $31$.
