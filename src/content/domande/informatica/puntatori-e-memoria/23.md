Quanti elementi legge il seguente ciclo? È disponibile il tipo `size_t`.

```c
int a[4] = {5, 3, 8, 2};
int *first = a + 2;
int *last = a + 2;
size_t count = 0;
for (int *p = first; p != last; ++p) {
    count += (*p > 0);
}
```

- $4$
- $1$
- $2$
- $0$

## Spiegazione

`first` e `last` hanno lo stesso valore, pari ad `a + 2`. Di conseguenza il test iniziale è falso. Il corpo non esegue alcuna lettura e il valore di `count` resta $0$.
