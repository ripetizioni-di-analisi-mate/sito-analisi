In una nuova esecuzione si chiamano in tre istruzioni distinte `score(4)`, `score(-1)` e `score(0)`. Quale valore dà la terza chiamata?

```c
int score(int x)
{
    static int calls = 0;
    int start = 10;
    ++calls;
    return start + calls + x;
}
```

- $11$
- $13$
- $16$
- $10$

## Spiegazione

Ogni chiamata inizializza `start` a `10`. L’oggetto `calls` ha durata statica e conserva il numero raggiunto, quindi dopo i tre incrementi vale in sequenza `1`, `2` e `3`. L’ultimo argomento vale `0`, perciò l’ultimo risultato è $10+3+0=13$.
