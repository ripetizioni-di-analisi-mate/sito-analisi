Determinare il valore di `read_total()`.

```c
int seed = 6;

int get_seed(void)
{
    return seed;
}

int read_total(void)
{
    int seed = 4;
    return 10 * seed + get_seed();
}
```

- $44$
- $64$
- $46$
- $66$

## Spiegazione

Il prodotto dentro `read_total` usa il suo `seed` locale, che vale `4`. Il corpo di `get_seed` trova invece il nome dichiarato a livello di file, che vale `6`. La visibilità dipende dal punto del sorgente in cui compare il nome. Il risultato è $10\cdot4+6=46$.
