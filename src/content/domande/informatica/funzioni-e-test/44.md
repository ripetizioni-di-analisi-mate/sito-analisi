In una nuova esecuzione, quattro istruzioni distinte chiamano `saved_total(0)`, `saved_total(1)`, `saved_total(0)` e `saved_total(1)`. Quanto restituisce la quarta chiamata?

```c
int saved_total(int accepted)
{
    static int total = 9;
    if (!accepted) {
        return total;
    }
    total -= 2;
    return total;
}
```

- $5$
- $1$
- $7$
- $9$

## Spiegazione

La prima e la terza chiamata entrano nel ramo iniziale e restituiscono il valore memorizzato senza aggiornarlo. La seconda e la quarta sottraggono ciascuna `2` all’unico oggetto statico `total`. I valori restituiti sono quindi `9`, `7`, `7` e `5`.
