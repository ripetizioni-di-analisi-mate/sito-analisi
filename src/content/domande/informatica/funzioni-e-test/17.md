Nel chiamante si eseguono `int n = 3;` e poi `int r = advance(++n);`. Quanto vale `10 * n + r` dopo queste istruzioni?

```c
int advance(int value)
{
    value += 2;
    return value;
}
```

- $36$
- $66$
- $45$
- $46$

## Spiegazione

Il preincremento trasforma `n` in `4` prima di passare il valore a `advance`. La funzione aggiunge `2` alla copia locale e restituisce `6`, perciò `r` vale `6`. L’espressione richiesta combina il `4` conservato nel chiamante con il risultato, quindi dà $10\cdot4+6=46$.
