Il contratto richiede il valore assoluto per tutti gli input interi tra −9 e 9. La suite prova −1 e 2 sul corpo mostrato, verifica i due risultati e percorre entrambi i rami. Quale input rivela ancora un errore?

```c
int magnitude(int x)
{
    if (x < 0) return 1;
    return x;
}
```

- $0$
- $1$
- $9$
- $-4$

## Spiegazione

Sul ramo negativo la funzione restituisce sempre 1. L’input −1 fa passare questo ramo perché il suo valore assoluto è proprio 1, ma per −4 l’atteso è 4. I tre input non negativi proposti esercitano il ramo che restituisce correttamente l’argomento.
