La funzione deve restituire `x*x+1` per ogni intero da 0 a 10, anche alla prima chiamata. Il corpo conserva l’ultimo risultato. In un nuovo processo, quale sequenza rivela il difetto già al **primo** confronto con l’oracolo?

```c
int cached(int x)
{
    static int key;
    static int value;
    if (x != key) {
        key = x;
        value = x * x + 1;
    }
    return value;
}
```

- Chiamare con 0 e attendersi 1.
- Chiamare con 1 e attendersi 2.
- Chiamare con 3 e attendersi 10.
- Chiamare con 2 e attendersi 5.

## Spiegazione

All’avvio entrambe le variabili statiche valgono 0. Se anche l’argomento è 0, il confronto salta il calcolo e restituisce lo zero iniziale al posto di 1. Un primo input diverso da zero riempie subito la cache e può nascondere l’errore di inizializzazione.
