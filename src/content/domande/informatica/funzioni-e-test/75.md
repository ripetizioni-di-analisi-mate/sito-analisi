Il modulo corretto produce il codice `x` per input interi da 0 a 8. Una versione difettosa produce `x+1`. Il chiamante restituisce soltanto `code >= 5`. Per quale input un test del solo chiamante rivela il difetto?

- $5$
- $0$
- $8$
- $4$

## Spiegazione

Il risultato esterno cambia quando il codice corretto è ancora sotto 5 e quello difettoso raggiunge la soglia. Occorrono insieme `x < 5` e `x + 1 >= 5`, quindi l’unico intero è 4. Sugli altri input il confronto nasconde la differenza interna.
