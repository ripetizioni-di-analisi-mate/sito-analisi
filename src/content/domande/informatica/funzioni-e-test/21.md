In quattro istruzioni separate si chiamano, nell’ordine, `left()`, `right()`, `right()` e `left()`. Quali risultati danno la terza e la quarta chiamata?

```c
int left(void)
{
    static int count = 3;
    return ++count;
}

int right(void)
{
    static int count = 8;
    return count++;
}
```

- $(10,5)$
- $(9,4)$
- $(9,5)$
- $(8,5)$

## Spiegazione

Le due dichiarazioni di `count` introducono oggetti statici distinti. La prima chiamata a `left` porta il suo contatore a `4`. Le due chiamate a `right` restituiscono `8` e `9`, perché il postincremento produce il valore precedente. L’ultimo `left` esegue il secondo preincremento del suo contatore e restituisce `5`.
