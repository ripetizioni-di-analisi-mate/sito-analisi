Una piccola suite confronta quattro uscite effettive con gli attesi. Le coppie (effettivo, atteso) sono (4,4), (5,6), (3,3), (2,0). Si vuole restituire **il numero di casi falliti**. Con `int failures = 0;`, quale istruzione si deve eseguire una volta per ciascuna coppia?

- `failures = (observed != expected);`
- `failures += (observed == expected) ? 0 : observed;`
- `failures += observed - expected;`
- `failures += (observed != expected);`

## Spiegazione

Il confronto di disuguaglianza produce 1 esattamente sui casi falliti e 0 sugli altri. La somma delle quattro indicazioni è 2. Sommare le differenze conterebbe gli scarti con segno, mentre una semplice assegnazione ricorderebbe soltanto l’ultimo caso.
