Per ogni chiamata il contratto richiede di registrare una visita e di restituire 1 se `n` è positivo, 0 altrimenti. Due chiamate distinte con `2` e `-1` restituiscono i risultati attesi. Quale altro controllo individua il difetto, partendo da `visits == 0`?

```c
static int visits;
int classify(int n)
{
    if (n > 0) return 1;
    ++visits;
    return 0;
}
```

- Attendersi 2 visite dopo le due chiamate.
- Attendersi 1 visita dopo le due chiamate.
- Controllare che il secondo risultato sia pari.
- Controllare che il primo risultato sia positivo.

## Spiegazione

Il ramo positivo esce prima dell’incremento. Soltanto la chiamata con −1 raggiunge `++visits`, perciò il contatore effettivo è 1. L’oracolo per l’effetto esterno richiede 2 e controlla una parte del contratto che i due risultati restituiti lasciano inosservata.
