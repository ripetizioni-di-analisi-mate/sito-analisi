Per quanti interi `n` da $0$ a $16$ inclusi vale `qualifies(n) == 1`?

```c
int large(int n)
{
    return n >= 9;
}

int aligned(int n)
{
    return n % 4 == 0;
}

int qualifies(int n)
{
    return large(n) && aligned(n);
}
```

- $2$
- $1$
- $3$
- $4$

## Spiegazione

La prima funzione ammette gli interi da $9$ in poi. La seconda verifica la divisibilità per $4$. Fra gli interi da $9$ a $16$ inclusi i soli multipli di $4$ sono $12$ e $16$. Si hanno quindi due input che soddisfano entrambe le condizioni.
