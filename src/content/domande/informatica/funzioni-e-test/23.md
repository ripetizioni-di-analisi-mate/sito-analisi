Si chiamano nell’ordine `add_stock(4)`, `add_stock(-2)` e `add_stock(3)` in tre istruzioni distinte nella stessa unità di traduzione. Quanto vale `stock` alla fine?

```c
static int stock = 10;

void add_stock(int value)
{
    if (value < 0) {
        return;
    }
    stock += value;
}
```

- $17$
- $15$
- $10$
- $14$

## Spiegazione

La prima chiamata esegue l’assegnamento e porta `stock` a `14`. L’argomento negativo attiva `return;` prima dell’aggiornamento, quindi il valore resta `14`. L’ultima chiamata aggiunge `3` e si ottiene `17`. La funzione restituisce `void` e l’osservazione riguarda l’oggetto aggiornato.
