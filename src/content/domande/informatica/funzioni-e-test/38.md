Determinare, nell’ordine, `round_up(0)`, `round_up(2)` e `round_up(5)`.

```c
int round_up(int n)
{
    if (n <= 0) {
        return 0;
    }
    return n % 2 == 0 ? n / 2 : n / 2 + 1;
}
```

- $(1,1,3)$
- $(0,2,3)$
- $(0,1,2)$
- $(0,1,3)$

## Spiegazione

Per `n = 0` termina il primo ramo con risultato `0`. Il valore `2` è pari, quindi la divisione esatta dà `1`. Con `5` la divisione intera produce `2` e il resto vale `1`, quindi viene aggiunta un’unità e il risultato è `3`.
