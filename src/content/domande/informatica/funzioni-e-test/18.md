Quale valore restituisce `channel()` in C17? I nomi dei limiti sono quelli di `<limits.h>`.

```c
unsigned int channel(void)
{
    return -1;
}
```

- `0u`
- `1u`
- `INT_MAX`
- `UINT_MAX`

## Spiegazione

Il valore dell’espressione di ritorno è l’intero `-1`. Il `return` lo converte al tipo `unsigned int`. La conversione prende il valore congruente modulo il numero di valori del tipo, che è `UINT_MAX` più uno in aritmetica matematica. Il rappresentante di `-1` è quindi `UINT_MAX`.
