Quali risultati danno `code(-4)`, `code(1)` e `code(3)`, nell’ordine?

```c
int code(int x)
{
    int r = 2;
    if (x < 0) {
        return r - x;
    }
    r += 3;
    if (x == 1) {
        return r * 2;
    }
    return r + x;
}
```

- $(6,10,8)$
- $(9,10,8)$
- $(6,6,8)$
- $(6,10,6)$

## Spiegazione

Con `x = -4` il primo `return` dà $2-(-4)=6$. Per gli altri due input si raggiunge `r += 3` e `r` vale `5`. L’uguaglianza con `1` rende applicabile il secondo ritorno, che dà $5\cdot2=10$. Per `x = 3` si arriva all’ultima istruzione e si ottiene $5+3=8$.
