In una nuova esecuzione si valuta una volta `combine(add(2), add(5))`. Quale insieme descrive i valori permessi da C17 senza fissare l’ordine di valutazione degli argomenti?

```c
int add(int step)
{
    static int total = 0;
    total += step;
    return total;
}

int combine(int a, int b)
{
    return 10 * a + b;
}
```

- $\{27,75\}$
- $\{25,52\}$
- $\{27\}$
- $\{75\}$

## Spiegazione

L’ordine di valutazione degli argomenti non è specificato. Le due esecuzioni del corpo di `add` sono sequenziate l’una rispetto all’altra, quindi una si completa prima dell’altra. Se parte `add(2)`, i parametri sono $(2,7)$ e il risultato è $27$. Se parte `add(5)`, il secondo parametro vale $5$ e il primo vale $7$, quindi il risultato è $75$. La posizione dei parametri resta quella scritta nella chiamata.
