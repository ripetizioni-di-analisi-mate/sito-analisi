Il file che contiene `probe` include `<assert.h>` dopo `#define NDEBUG 0`. Un altro file contiene `main`, include la stessa intestazione senza definire `NDEBUG` e chiama `probe()`. Quale esito ha la chiamata, assumendo che non vi siano altre cause di arresto?

```c
int probe(void)
{
    assert(0);
    return 7;
}
```

- Il comportamento dipende da quale file viene compilato per primo.
- L’asserzione in `probe` arresta sempre il programma.
- `probe()` restituisce 7.
- La definizione a zero di `NDEBUG` impedisce di compilare il programma.

## Spiegazione

L’espansione di `assert` dipende dalla presenza di `NDEBUG` all’inclusione nel file che contiene l’asserzione. Anche una definizione con valore 0 conta come definizione. In `probe` il controllo viene disattivato, indipendentemente dalla configurazione usata per compilare `main`.
