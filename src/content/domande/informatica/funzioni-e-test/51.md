Un’interfaccia pubblica in `measure.h` dichiara `double measure(int);`. Il chiamante include il file, ma l’autore della definizione scrive per errore `int measure(int n) { return n; }` in un secondo file sorgente. Quale scelta rende il conflitto direttamente diagnosticabile compilando il secondo file?

- Convertire il risultato a `double` nel chiamante.
- Compilare per primo il file del chiamante.
- Rinominare il parametro `n` in `value`.
- Includere `measure.h` anche prima della definizione.

## Spiegazione

L’intestazione e la definizione diventano dichiarazioni della stessa funzione visibili nella stessa unità di traduzione. I tipi restituiti `double` e `int` sono incompatibili, quindi il compilatore deve emettere una diagnostica. L’ordine in cui si compilano file separati non introduce questo confronto locale.
