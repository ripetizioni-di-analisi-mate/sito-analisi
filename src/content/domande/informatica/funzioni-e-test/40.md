Con asserzioni attive, quale dei seguenti test esaminati singolarmente fallisce per il codice dato?

```c
int buckets(int n)
{
    return n / 3 + (n % 3 != 0);
}
```

- `assert(buckets(0) == 0);`
- `assert(buckets(8) == 2);`
- `assert(buckets(6) == 2);`
- `assert(buckets(7) == 3);`

## Spiegazione

Nulla si aggiunge quando il resto è zero. Per questo `buckets(0)` dà `0` e `buckets(6)` dà `2`. I numeri `7` e `8` hanno quoziente intero `2` e resti diversi da zero, dunque entrambi producono `3`. Il confronto della chiamata con argomento `8` dà falso se l’atteso è `2`.
