Un sensore può produrre valori `double` negativi fra −1 e 0. Il protocollo richiede di rifiutare ogni lettura negativa prima di scartare la parte frazionaria. Il programma passa la lettura a questa funzione. Quale chiamata dimostra che la verifica avviene troppo tardi?

```c
int admit(int n)
{
    return n >= 0;
}
```

- `admit(1.5)`
- `admit(0.0)`
- `admit(-0.5)`
- `admit(-2.0)`

## Spiegazione

Il prototipo converte −0,5 in `int` troncando verso zero. Nel corpo `n` vale già 0, quindi il confronto accetta la misura. Per distinguere −0,5 da 0 occorre verificare la lettura quando ha ancora il tipo `double`.
