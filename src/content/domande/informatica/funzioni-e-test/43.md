Per interi `amount` da $0$ a $100$, quali resti di `amount` nella divisione per $3$ fanno restituire $1$ ad `adjust`?

```c
int units(int amount)
{
    return amount / 3;
}

int adjust(int amount)
{
    return units(amount + 2) - units(amount);
}
```

- $\{0\}$
- $\{1,2\}$
- $\{0,1\}$
- $\{2\}$

## Spiegazione

Si scriva $\mathrm{amount}=3q+r$ con resto $r$ fra $0$ e $2$. La chiamata `units(amount)` vale $q$. Dopo l’aumento di $2$, il quoziente cresce di uno esattamente quando $r+2\geq3$. Questa condizione vale per $r=1$ e $r=2$, quindi in quei due casi la differenza è $1$.
