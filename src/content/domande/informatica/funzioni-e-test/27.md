Quanto vale `bill(8)`?

```c
int basis(int units)
{
    return 2 * units + 3;
}

int cap(int amount)
{
    if (amount > 15) {
        return 15;
    }
    return amount;
}

int bill(int units)
{
    return 1 + cap(basis(units));
}
```

- $15$
- $16$
- $19$
- $20$

## Spiegazione

La funzione interna calcola `basis(8)`, ossia $2\cdot8+3=19$. Questo valore viene passato a `cap`, che restituisce `15` perché `19 > 15`. Infine `bill` somma `1` al costo già limitato e restituisce `16`.
