Qual è il valore di `status(2)`?

```c
_Bool status(int x)
{
    return x - 4;
}
```

- $-2$
- $0$
- $1$
- $-1$

## Spiegazione

Il corpo valuta prima `x - 4` con `x = 2`, quindi ottiene l’intero `-2`. Il tipo restituito è `_Bool`. La conversione a questo tipo produce `0` per un valore uguale a zero e `1` per ogni valore diverso da zero. Il valore restituito è perciò `1`.
