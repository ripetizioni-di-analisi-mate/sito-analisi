Per `n` intero da 0 a 40, `packet(n)` restituisce `n / 4`. Un secondo modulo registra un allarme esattamente se riceve il codice 3. Quale insieme di input deve attivare l’allarme nel test di integrazione?

- $3,7,11,15$
- $9,10,11,12$
- $12,13,14,15$
- $12,13,14,15,16$

## Spiegazione

Per input non negativi, la divisione intera dà 3 quando l’intero è almeno 12 e minore di 16. Questi quattro valori condividono lo stesso codice intermedio. Con l’input 16 la prima fase restituisce già 4, perciò l’allarme deve restare spento.
