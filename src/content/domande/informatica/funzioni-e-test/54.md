Il progettista vuole inizializzare una variabile con durata statica usando una lettura effettuata alla prima chiamata. In C17 la versione mostrata viola un vincolo. Quale modifica esprime la semantica richiesta se `seed()` deve essere chiamata esattamente una volta e il programma ha un solo thread? Si assuma che `seed()` ritorni normalmente e non richiami `saved_seed`, neppure indirettamente.

```c
int seed(void);
int saved_seed(void)
{
    static int saved = seed();
    return saved;
}
```

- Togliere `static` e mantenere `int saved = seed();`.
- Usare due locali statiche inizializzate a zero e chiamare `seed()` nel corpo quando il flag di inizializzazione è ancora zero.
- Scrivere `static int saved = (int)seed();`.
- Aggiungere `const` a `saved` senza cambiare l’inizializzatore.

## Spiegazione

La chiamata a `seed()` non è un’espressione costante ammessa per inizializzare questo oggetto statico. Nel corpo si può assegnarne il risultato a `saved` e poi impostare il flag. Il flag distinto funziona anche quando la prima lettura restituisce proprio zero.
