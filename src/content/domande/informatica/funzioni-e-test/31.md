Come si classifica la chiamata `divide(0)` con `NDEBUG` assente o definita quando viene incluso `<assert.h>`?

```c
#include <assert.h>

int divide(int n)
{
    assert(n != 0);
    return 21 / n;
}
```

- In entrambe le configurazioni si esegue `abort` prima della divisione.
- Con asserzioni attive la funzione restituisce $0$, con asserzioni disattivate esegue `abort`.
- In entrambe le configurazioni la funzione restituisce $0$.
- Con asserzioni attive si esegue `abort`, con asserzioni disattivate la divisione ha comportamento indefinito.

## Spiegazione

Con l’asserzione attiva, `n != 0` è falsa e la macro provoca la terminazione anomala tramite `abort` prima di arrivare al `return`. Quando `NDEBUG` è definita all’inclusione, l’argomento di `assert` viene eliminato. Si raggiunge quindi una divisione intera per zero, per cui il C17 non definisce un risultato.
