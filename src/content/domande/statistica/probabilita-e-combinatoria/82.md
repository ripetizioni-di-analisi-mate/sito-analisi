Cinque atti distinti sono ordinati in una pila. Si richiede che A preceda B e che C preceda D, con A, B, C e D distinti. Quanti ordini sono ammessi?

- $60$
- $24$
- $20$
- $30$

## Spiegazione

Si raggruppano le file che hanno le stesse posizioni per la coppia A e B e per la coppia C e D. In ogni gruppo si possono scambiare A con B e, indipendentemente, C con D. Si ottengono quattro file distinte, di cui una sola rispetta entrambi gli ordini richiesti. Fra le $5!=120$ file possibili si ottengono quindi $\dfrac{120}{4}=30$ file ammesse.
