Un test z bilatero produce una statistica positiva. Se la coda destra oltre il valore osservato vale $0{,}005$, quanto vale il valore p?

- $\dfrac{1}{200}$
- $\dfrac{199}{200}$
- $\dfrac{1}{100}$
- $\dfrac{99}{100}$

## Spiegazione

Il test bilatero conta gli esiti almeno altrettanto lontani da zero nelle due direzioni. Per simmetria le due code hanno la stessa probabilità.
