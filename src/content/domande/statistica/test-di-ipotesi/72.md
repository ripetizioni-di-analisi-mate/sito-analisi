Un test controlla se la media delle emissioni supera una soglia. L'ipotesi nulla afferma che la media è al più pari alla soglia. Quale evento è un errore di primo tipo?

- Ottenere un mancato rifiuto quando la media supera la soglia.
- Rifiutare quando la media supera la soglia.
- Rifiutare quando la media è effettivamente al più pari alla soglia.
- Ottenere un mancato rifiuto quando la media è sotto la soglia.

## Spiegazione

L'ipotesi nulla comprende le medie inferiori o uguali alla soglia. Se la media vera appartiene a questo insieme e il test rifiuta, si commette un errore di primo tipo. Un rifiuto quando la media supera davvero la soglia è invece una decisione corretta. In quel caso l'eventuale errore sarebbe il mancato rifiuto, cioè un errore di secondo tipo.
