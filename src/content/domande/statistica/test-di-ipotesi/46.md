Un test bilatero di varianza usa code uguali. Il valore della ripartizione chi quadrato nella statistica osservata è $0{,}015$. Qual è il valore p?

- $0{,}97$
- $0{,}03$
- $0{,}015$
- $0{,}985$

## Spiegazione

Si raddoppia la più piccola fra le due probabilità di coda. La coda sinistra vale $0{,}015$, quindi il valore p è $0{,}03$.
