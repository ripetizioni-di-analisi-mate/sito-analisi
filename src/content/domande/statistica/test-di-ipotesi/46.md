Un test bilatero di varianza usa code uguali. Il valore della ripartizione chi quadrato nella statistica osservata è $0{,}015$. Qual è il valore p?

- $0{,}97$
- $0{,}03$
- $0{,}015$
- $0{,}985$

## Spiegazione

La ripartizione fornisce l'area della coda sinistra, pari a $0{,}015$. L'area della coda destra a partire dallo stesso punto è $1-0{,}015=0{,}985$, quindi il valore osservato si trova verso l'estremo inferiore. Nel test bilatero a code uguali si raddoppia la minore delle due probabilità. Si ottiene perciò $p=2\cdot0{,}015=0{,}03$. La regola confronta le probabilità delle code perché la chi quadrato è asimmetrica.
