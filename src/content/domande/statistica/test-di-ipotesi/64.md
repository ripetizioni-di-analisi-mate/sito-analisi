Un test z bilatero produce una statistica positiva. Se la coda destra oltre il valore osservato vale $0{,}007$, quanto vale il valore p?

- $\dfrac{493}{500}$
- $\dfrac{7}{500}$
- $\dfrac{7}{1000}$
- $\dfrac{993}{1000}$

## Spiegazione

Il test bilatero conta gli esiti almeno altrettanto lontani da zero nelle due direzioni. Per simmetria le due code hanno la stessa probabilità.
