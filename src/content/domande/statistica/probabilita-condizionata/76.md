Tra 160 richieste, 90 arrivano via web. Delle richieste web 36 vengono respinte. Qual è la probabilità che una richiesta sia respinta, sapendo che è arrivata via web?

- $\dfrac{3}{5}$
- $\dfrac{2}{5}$
- $\dfrac{9}{16}$
- $\dfrac{9}{40}$

## Spiegazione

Il gruppo di riferimento è quello delle richieste web. Si divide il numero di rifiuti via web per la dimensione di quel gruppo.
