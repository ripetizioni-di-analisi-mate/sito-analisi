Tra 120 richieste, 70 arrivano via web. Delle richieste web 21 vengono respinte. Qual è la probabilità che una richiesta sia respinta, sapendo che è arrivata via web?

- $\dfrac{7}{12}$
- $\dfrac{3}{10}$
- $\dfrac{7}{10}$
- $\dfrac{7}{40}$

## Spiegazione

Il gruppo di riferimento è quello delle richieste web. Si divide il numero di rifiuti via web per la dimensione di quel gruppo.
