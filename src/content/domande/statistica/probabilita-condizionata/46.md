Tra 90 richieste, 50 arrivano via web. Delle richieste web 10 vengono respinte. Qual è la probabilità che una richiesta sia respinta, sapendo che è arrivata via web?

- $\dfrac{1}{5}$
- $\dfrac{4}{5}$
- $\dfrac{5}{9}$
- $\dfrac{1}{9}$

## Spiegazione

Il gruppo di riferimento è quello delle richieste web. Si divide il numero di rifiuti via web per la dimensione di quel gruppo.
