Tra $90$ richieste, $50$ arrivano via web. Tra le richieste web, $10$ vengono respinte e $20$ richiedono un controllo manuale. Otto richieste web respinte hanno richiesto quel controllo. Sapendo che una richiesta web è stata respinta, quanto vale la probabilità che sia stata controllata manualmente?

- $\dfrac{1}{5}$
- $\dfrac{2}{5}$
- $\dfrac{4}{5}$
- $\dfrac{4}{25}$

## Spiegazione

La condizione comprende insieme l'arrivo via web e il rifiuto. Le richieste che soddisfano entrambe sono $10$, di cui $8$ controllate manualmente. Il rapporto vale $\dfrac{4}{5}$.
