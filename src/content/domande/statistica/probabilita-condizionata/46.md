Tra $90$ richieste, $50$ arrivano via web. Tra le richieste web, $10$ vengono respinte e $20$ richiedono un controllo manuale. Otto richieste web respinte hanno richiesto quel controllo. Sapendo che una richiesta web è stata respinta, quanto vale la probabilità che sia stata controllata manualmente?

- $\dfrac{1}{5}$
- $\dfrac{2}{5}$
- $\dfrac{4}{5}$
- $\dfrac{4}{25}$

## Spiegazione

La condizione contiene due informazioni simultanee, l'arrivo via web e il rifiuto. Perciò il gruppo di riferimento è formato dalle $10$ richieste web respinte. Tra queste, $8$ hanno richiesto un controllo manuale, quindi il rapporto è $\dfrac8{10}=\dfrac45$. Dividere per $20$ scambierebbe il ruolo del controllo e del rifiuto all'interno delle richieste web, producendo la probabilità di rifiuto dato il controllo.
