La disequazione $\left( \dfrac{1}{2} \right)^{x^{2}} > \dfrac{1}{16}$ è verificata per:

- $x < -2 \;\vee\; x > 2$
- $x < 2$
- $-4 < x < 4$
- $-2 < x < 2$

## Spiegazione

Poiché $\dfrac{1}{16} = \left(\dfrac{1}{2}\right)^{4}$, la disequazione diventa $\left(\dfrac{1}{2}\right)^{x^{2}} > \left(\dfrac{1}{2}\right)^{4}$. La base è minore di $1$, quindi il **verso si inverte** e si ottiene $x^{2} < 4$, cioè $-2 < x < 2$. Il risultato $x < -2 \;\vee\; x > 2$ conserva il verso, e $x < 2$ estrae la radice trascurando i valori negativi di $x$. Il risultato $-4 < x < 4$ confronta $x^{2}$ con $16$ invece che con $4$.
