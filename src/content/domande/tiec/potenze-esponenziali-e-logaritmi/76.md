Qual è l'insieme delle soluzioni della disequazione $9^{x} - 4 \cdot 3^{x} + 3 \leq 0$?

- $1 \leq x \leq 3$
- $x \leq 0 \;\vee\; x \geq 1$
- $x \leq 1$
- $0 \leq x \leq 1$

## Spiegazione

Con il cambio di variabile $t = 3^{x}$, poiché $9^{x} = t^{2}$, la disequazione diventa $t^{2} - 4t + 3 \leq 0$. Il trinomio ha radici $1$ e $3$ ed è negativo o nullo tra le radici, quindi $1 \leq t \leq 3$. Tornando a $x$ si ha $3^{0} \leq 3^{x} \leq 3^{1}$, e poiché la base $3$ è maggiore di $1$ il verso si conserva, perciò $0 \leq x \leq 1$. Il risultato $1 \leq x \leq 3$ si ferma alla variabile $t$, e $x \leq 0 \;\vee\; x \geq 1$ prende i valori esterni alle radici. Il risultato $x \leq 1$ dimentica la condizione $3^{x} \geq 1$.
