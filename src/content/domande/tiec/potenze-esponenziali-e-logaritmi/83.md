Un numero intero positivo $x$ si scrive con tre cifre. Quale condizione soddisfa $\log_{10} x$?

- $\log_{10} x = 3$
- $3 \leq \log_{10} x < 4$
- $2 < \log_{10} x \leq 3$
- $2 \leq \log_{10} x < 3$

## Spiegazione

Un intero positivo ha tre cifre se e solo se $100 \leq x < 1000$, cioè $10^{2} \leq x < 10^{3}$. Poiché la base $10$ è maggiore di $1$, la funzione $y = \log_{10} x$ è crescente e conserva le disuguaglianze. Perciò $2 \leq \log_{10} x < 3$. Il valore $\log_{10} x = 3$ corrisponde a $x = 1000$, che ha quattro cifre.
