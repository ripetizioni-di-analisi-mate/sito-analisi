La disequazione $\log_{3} (x - 1) + \log_{3} (x + 1) < 1$ è verificata per:

- $-2 < x < 2$
- $1 < x < 2$
- $x < 2$
- $1 < x < \sqrt{2}$

## Spiegazione

Le condizioni di esistenza sono $x - 1 > 0$ e $x + 1 > 0$, che insieme danno $x > 1$. Per la proprietà del logaritmo di un prodotto la disequazione diventa $\log_{3} \left(x^{2} - 1\right) < \log_{3} 3$, e poiché la base è maggiore di $1$ si ottiene $x^{2} - 1 < 3$, cioè $-2 < x < 2$. Intersecando con $x > 1$ si trovano le soluzioni $1 < x < 2$. Il risultato $-2 < x < 2$ dimentica le condizioni di esistenza, e $1 < x < \sqrt{2}$ confronta $x^{2} - 1$ con $1$ invece che con $3^{1} = 3$.
