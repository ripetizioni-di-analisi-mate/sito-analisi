Dati i numeri $a = 2^{45}$, $b = 3^{30}$ e $c = 5^{15}$, quale delle seguenti relazioni è vera?

- $c < a < b$
- $a < b < c$
- $a < c < b$
- $b < a < c$

## Spiegazione

I tre esponenti sono multipli di $15$, quindi per la regola della **potenza di una potenza** si scrivono tutti con esponente $15$. Si ottengono $a = \left(2^{3}\right)^{15} = 8^{15}$, $b = \left(3^{2}\right)^{15} = 9^{15}$ e $c = 5^{15}$. Con lo stesso esponente positivo è maggiore la potenza con la base maggiore, e poiché $5 < 8 < 9$ si ha $c < a < b$. L'ordine $a < b < c$ segue le basi $2 < 3 < 5$, che da sole non decidono il confronto perché gli esponenti sono diversi.
