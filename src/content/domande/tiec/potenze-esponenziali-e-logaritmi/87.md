La disequazione $\log_{2} x < \log_{2} (6 - x)$ è verificata per:

- $x < 3$
- $3 < x < 6$
- $0 < x < 3$
- $0 < x < 6$

## Spiegazione

Le condizioni di esistenza sono $x > 0$ e $6 - x > 0$, quindi $0 < x < 6$. La base $2$ è maggiore di $1$, perciò il verso si conserva e si ottiene $x < 6 - x$, cioè $x < 3$. Le soluzioni devono soddisfare insieme le condizioni di esistenza e la disequazione tra gli argomenti, quindi sono $0 < x < 3$. Il risultato $x < 3$ dimentica le condizioni di esistenza, e $0 < x < 6$ si ferma a esse. L'intervallo $3 < x < 6$ inverte il verso, come se la base fosse minore di $1$.
