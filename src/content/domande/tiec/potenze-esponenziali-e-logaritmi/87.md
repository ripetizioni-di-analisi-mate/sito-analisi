Per quali valori di $x$ è verificata la disequazione $\log_{2} x < \log_{2} (6 - x)$?

- $3 < x < 6$
- $0 < x \leq 3$
- $0 < x < 3$
- $x < 3$

## Spiegazione

Le condizioni di esistenza sono $x > 0$ e $6 - x > 0$, cioè $0 < x < 6$. Poiché la base $2$ è maggiore di $1$, la disequazione tra i logaritmi equivale alla disequazione tra gli argomenti $x < 6 - x$, cioè $x < 3$. Le soluzioni devono soddisfare insieme le due condizioni, quindi
$$
\begin{cases}
0 < x < 6 \\
x < 3
\end{cases}
\iff
0 < x < 3 .
$$
