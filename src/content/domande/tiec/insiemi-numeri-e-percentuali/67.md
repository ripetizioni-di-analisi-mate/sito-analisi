Se $-2 < x < 2$, l'espressione $|x - 2| + |x + 2|$ è uguale a:

- $4$
- $2x$
- $-2x$
- $-4$

## Spiegazione

Per $x < 2$ la quantità $x - 2$ è negativa, quindi $|x - 2| = -(x - 2) = 2 - x$. Per $x > -2$ la quantità $x + 2$ è positiva, quindi $|x + 2| = x + 2$. La somma vale $(2 - x) + (x + 2) = 4$ per ogni $x$ dell'intervallo. L'espressione $2x$ si ottiene togliendo i valori assoluti senza guardare il segno, cioè scrivendo $(x - 2) + (x + 2)$.
