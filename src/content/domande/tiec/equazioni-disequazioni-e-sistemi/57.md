Per quali valori di $x$ è verificata la disequazione $x^4 - 10x^2 + 9 \leq 0$?

- $-3 \leq x \leq -1 \;\vee\; 1 \leq x \leq 3$
- $1 \leq x \leq 9$
- $-3 \leq x \leq 3$
- $1 \leq x \leq 3$

## Spiegazione

Ponendo $t = x^2$ si ottiene $t^2 - 10t + 9 \leq 0$. L'equazione associata ha soluzioni $1$ e $9$, e il trinomio è negativo o nullo per i valori interni, quindi $1 \leq x^2 \leq 9$. La condizione $x^2 \leq 9$ dà $-3 \leq x \leq 3$, mentre $x^2 \geq 1$ dà $x \leq -1 \;\vee\; x \geq 1$. I valori che soddisfano entrambe le condizioni sono $-3 \leq x \leq -1 \;\vee\; 1 \leq x \leq 3$. La risposta $1 \leq x \leq 9$ si ferma all'incognita $t$, e la risposta $1 \leq x \leq 3$ perde i valori negativi.
