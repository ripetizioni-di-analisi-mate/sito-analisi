"Tutti i manager dell'azienda sono laureati. Alcuni laureati dell'azienda parlano cinese." In base a queste premesse, quale delle seguenti affermazioni è corretta?

- Alcuni manager dell'azienda parlano cinese
- Nessun manager dell'azienda parla cinese
- Tutti i laureati dell'azienda sono manager
- Le premesse non stabiliscono se qualche manager parla cinese

## Spiegazione

Nel **diagramma con tre cerchi** il cerchio dei manager sta dentro quello dei laureati, e la seconda premessa mette un elemento nella zona comune a laureati e cinese. Quell'elemento può stare dentro il cerchio dei manager oppure fuori, quindi le premesse sono compatibili sia con un manager che parla cinese sia con nessun manager che parla cinese. Perciò né "Alcuni manager parlano cinese" né "Nessun manager parla cinese" segue dalle premesse. La frase "Tutti i laureati sono manager" rovescia la prima premessa.
