Trovare $u(t,x)$ per $u_t+3u_x=0$ e $u(0,x)=x^2+7$.

- $\left(- 3 t + x\right)^{2} + 7$
- $3 t + x^{2} + 7$
- $\left(- t + x\right)^{2} + 7$
- $\left(3 t + x\right)^{2} + 7$

## Spiegazione

Lungo le rette con velocità $3$ il valore di $u$ resta costante. Il piede della caratteristica è $- 3 t + x$, quindi $\left(- 3 t + x\right)^{2} + 7$.
