Calcolare l’integrale di $z^{2} + 3 i z$ lungo il segmento da $1$ a $6 + i$.

- $\dfrac{\left(6 + i\right)^{3}}{3} + \dfrac{3 i \left(6 + i\right)^{2}}{2}$
- $-1 - 3 i + \left(6 + i\right)^{2} + 3 i \left(6 + i\right)$
- $- \dfrac{1}{3} - \dfrac{3 i}{2} + \dfrac{\left(6 + i\right)^{3}}{3} + \dfrac{3 i \left(6 + i\right)^{2}}{2}$
- $\dfrac{1}{3} - \dfrac{3 i \left(6 + i\right)^{2}}{2} - \dfrac{\left(6 + i\right)^{3}}{3} + \dfrac{3 i}{2}$

## Spiegazione

L’integranda ha primitiva $\dfrac{z^{3}}{3} + \dfrac{3 i z^{2}}{2}$. Si sottrae il valore nel punto iniziale da quello nel punto finale, ottenendo $- \dfrac{1}{3} - \dfrac{3 i}{2} + \dfrac{\left(6 + i\right)^{3}}{3} + \dfrac{3 i \left(6 + i\right)^{2}}{2}$.
