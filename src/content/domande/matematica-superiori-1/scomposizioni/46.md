Scomponi $-3x^2-6x$.

- $3 x \left(x + 2\right)$
- $- 3 x \left(x + 2\right)$
- $- 3 x \left(x - 2\right)$
- $- 3 x - 6$

## Spiegazione

Il fattore comune può essere scelto negativo. Dividendo entrambi i termini per meno $3 x$ si ottengono x e due. Il controllo tramite distribuzione restituisce due termini negativi.

$$
-3x^2-6x=-3x(x+2)
$$

Il risultato è $- 3 x \left(x + 2\right)$.
