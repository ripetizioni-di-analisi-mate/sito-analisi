Una memoria disponibile di $1{,}0\cdot10^6$ byte deve contenere file interi da $3{,}0\cdot10^4$ byte ciascuno. Tratta i dati come esatti e ignora l'intestazione dei file. Quanti file vi entrano al massimo?

- $333$
- $34$
- $30$
- $33$

## Spiegazione

Il quoziente fra capacità e dimensione del file è $100/3=33{,}33\ldots$. Per il numero massimo di file interi si prende l'intero inferiore. Trentatré file occupano $990\,000$ byte, mentre trentaquattro richiederebbero $1\,020\,000$ byte.
