teoria: ["file-oggetto"]

Si assume un driver `cc` compatibile con GCC. `scale.c` è un sorgente C17 valido e il comando seguente termina con successo. Qual è il nome del file di uscita indicato dal comando?

```shell
cc -std=c17 -c scale.c -o scale.o
```

:::soluzione
`scale.o`.
:::
