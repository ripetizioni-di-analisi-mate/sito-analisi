Il programma seguente completa la scrittura senza errori in un ambiente C17 hosted. Indicare se lo stato di terminazione segnalato da `return 0;` indica successo o fallimento.

```c
#include <stdio.h>

int main(void)
{
    printf("%d\n", 7);
    return 0;
}
```

:::soluzione
Successo.
:::
