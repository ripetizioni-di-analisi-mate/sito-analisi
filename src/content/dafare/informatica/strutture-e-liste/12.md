Qual è il valore di `data[2]` dopo i due tentativi di inserimento?

```c
enum { capacity = 3 };
int data[capacity] = {2, 4};
int used = 2;
if (used < capacity) {
    data[used++] = 5;
}
if (used < capacity) {
    data[used++] = 7;
}
```

:::soluzione
$5$.
:::
