Determinare il valore di `key`. Il frammento usa `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node tail = {7, NULL};
struct Node middle = {4, &tail};
struct Node first = {6, &middle};
struct Node *head = &first;
int key = head->next->next->key;
```

:::soluzione
$7$.
:::
