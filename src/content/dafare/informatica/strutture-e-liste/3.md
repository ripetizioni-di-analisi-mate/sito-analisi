---
titolo: "Modifica tramite puntatore a record"
teoria: ["strutture-e-membri"]
parole: ["operatore freccia", "puntatore"]
---

Determinare il valore finale di `counter.value`.

```c
struct Counter { int value; };
struct Counter counter = {8};
struct Counter *link = &counter;
link->value += 5;
```

:::soluzione
$13$.
:::
