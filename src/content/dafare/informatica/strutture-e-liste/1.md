teoria: ["inizializzazione-assegnamento"]

---

Determinare il valore finale di `a.units`.

```c
struct Sample { int code; int units; };
struct Sample a = {.code = 12, .units = 5};
struct Sample b = a;
++b.units;
```

:::soluzione
$5$.
:::
