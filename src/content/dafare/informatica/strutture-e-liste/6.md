Determinare `count`. Il frammento usa `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node tail = {9, NULL};
struct Node first = {2, &tail};
struct Node middle = {5, first.next};
first.next = &middle;
int count = 0;
for (struct Node *p = &first; p != NULL; p = p->next) {
    ++count;
}
```

:::soluzione
$3$.
:::
