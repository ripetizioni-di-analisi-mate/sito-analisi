Quale puntatore rappresenta `head` alla fine? Il nodo è automatico e la rimozione è solo dal collegamento. Si usa `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node only = {6, NULL};
struct Node *head = &only;
head = head->next;
```

:::soluzione
Il puntatore nullo.
:::
