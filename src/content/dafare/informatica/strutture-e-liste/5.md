Determinare `key` dopo l’inserimento. Il frammento usa `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node tail = {11, NULL};
struct Node *head = &tail;
struct Node front = {5, head};
head = &front;
int key = head->next->key;
```

:::soluzione
$11$.
:::
