---
titolo: "Somma dopo aver saltato un nodo"
teoria: ["rimozione-e-rilascio", "invariante-lista"]
parole: ["rimozione interna", "somma delle chiavi"]
---

Determinare il valore finale di `sum`. I nodi sono oggetti automatici. Il frammento usa `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node tail = {3, NULL};
struct Node middle = {5, &tail};
struct Node first = {2, &middle};
first.next = middle.next;
int sum = 0;
for (struct Node *p = &first; p != NULL; p = p->next) {
    sum += p->key;
}
```

:::soluzione
$5$.
:::
