teoria: ["coda-collegata"]

---

La coda contiene il solo nodo automatico `only`. Qual è il valore finale di `rear`? Si usa `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node only = {7, NULL};
struct Node *front = &only, *rear = &only;
front = front->next;
if (front == NULL) {
    rear = NULL;
}
```

:::soluzione
Il puntatore nullo.
:::
