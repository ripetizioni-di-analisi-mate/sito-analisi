---
titolo: "Rilascio di una lista di quattro nodi"
teoria: ["rimozione-e-rilascio", "invariante-lista"]
parole: ["svuotamento", "free"]
---

`head` punta alla testa di una lista aciclica di quattro nodi distinti, ciascuno allocato dinamicamente e di proprietà della lista. Determinare `released`. Si assume visibile il tipo `struct Node` con membro `next` e si usa `<stdlib.h>`.

```c
int released = 0;
while (head != NULL) {
    struct Node *next = head->next;
    free(head);
    head = next;
    ++released;
}
```
