Quante volte si esegue il corpo del ciclo? Il tipo `size_t` è disponibile.

```c
int a[5] = {7, 1, 5, 8, 3};
for (size_t i = 3; i < 3; ++i) {
    a[i] = 0;
}
```

:::soluzione
$$
0 .
$$
:::
