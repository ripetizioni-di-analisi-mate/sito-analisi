---
titolo: "Somma con interi di segno misto"
teoria: ["conversioni-aritmetiche", "interi-unsigned"]
parole: ["segno misto", "conversione a unsigned"]
---

Calcolare il valore di `result` come intero decimale.

```c
int change = -2;
unsigned int count = 10u;
unsigned int result = count + change;
```

:::soluzione
$8$.
:::
