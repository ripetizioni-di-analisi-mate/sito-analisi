---
titolo: "Conversione a int di un valore negativo"
teoria: ["conversioni-assegnamento"]
parole: ["troncamento", "conversione a int"]
---

Determinare `whole`. Si assume una realizzazione conforme all’allegato F di C17 in arrotondamento al più vicino.

```c
double value = -7.5;
int whole = value;
```

:::soluzione
$-7$.
:::
