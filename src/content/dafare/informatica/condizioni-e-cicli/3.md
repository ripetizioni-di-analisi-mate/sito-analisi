---
titolo: "Classificazione sul valore di confine"
teoria: ["selezione-if"]
parole: ["disuguaglianza", "soglia"]
---

Determinare il valore assegnato a `result`.

```c
int points = 18, result;
if (points > 18) {
    result = 3;
} else if (points >= 18) {
    result = 2;
} else {
    result = 1;
}
```

:::soluzione
$$
2 .
$$
:::
