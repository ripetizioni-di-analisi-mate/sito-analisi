---
titolo: "Conteggio su righe crescenti"
teoria: ["cicli-annidati"]
parole: ["coppie di indici", "righe"]
---

Determinare il valore di `count` al termine del frammento.

```c
int count = 0;
for (int i = 1; i <= 4; ++i) {
    for (int j = 0; j < i; ++j) {
        ++count;
    }
}
```

:::soluzione
$$
10 .
$$
:::
