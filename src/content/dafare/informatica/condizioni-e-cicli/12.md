---
titolo: "Arresto del solo ciclo interno"
teoria: ["cicli-annidati", "interruzione-break"]
parole: ["break interno", "valore per riga"]
---

Determinare il valore di `score` al termine del frammento.

```c
int score = 0;
for (int i = 1; i <= 3; ++i) {
    for (int j = 0; j < 5; ++j) {
        if (j == i) {
            break;
        }
        score += 10 * i + j;
    }
}
```

:::soluzione
$$
144 .
$$
:::
