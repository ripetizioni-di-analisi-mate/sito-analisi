---
titolo: "Prosecuzione nel caso successivo"
teoria: ["selezione-switch"]
parole: ["switch", "fall-through"]
---

Determinare il valore di `s` al termine del frammento.

```c
int mode = 2, s = 1;
switch (mode) {
case 1:
    s += 2;
    break;
case 2:
    s *= 3;
    /* fall through */
case 3:
    s += 4;
    break;
default:
    s = 0;
}
```

:::soluzione
$$
7 .
$$
:::
