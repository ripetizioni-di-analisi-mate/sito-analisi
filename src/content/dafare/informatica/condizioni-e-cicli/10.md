---
titolo: "Arresto prima di un’addizione"
teoria: ["interruzione-break", "ciclo-for"]
parole: ["break", "soglia"]
---

Determinare il valore di `s` al termine del frammento.

```c
int s = 0;
for (int i = 1; i <= 7; ++i) {
    if (s > 6) {
        break;
    }
    s += i;
}
```

:::soluzione
$$
10 .
$$
:::
