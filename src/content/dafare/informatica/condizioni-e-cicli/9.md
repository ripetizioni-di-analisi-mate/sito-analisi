---
titolo: "Filtrare multipli con continue"
teoria: ["salto-continue", "ciclo-for"]
parole: ["continue", "multipli"]
---

Determinare il valore di `s` al termine del frammento.

```c
int s = 0;
for (int i = 1; i <= 8; ++i) {
    if (i % 3 == 0) {
        continue;
    }
    s += i;
}
```

:::soluzione
$$
27 .
$$
:::
