Calcolare il valore finale di `hits`. Il frammento è nel corpo di una funzione e `size_t` è dichiarato in `<stddef.h>`.

```c
const int a[] = {6, 1, 6, 4, 6, 9};
const int *last = a + 5;
size_t hits = 0;
for (const int *p = a + 1; p != last; ++p) {
    if (*p == 6) {
        ++hits;
    }
}
```

:::soluzione
$$
2 .
$$
:::
