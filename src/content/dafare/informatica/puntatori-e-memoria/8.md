titolo: "Durata al termine di un blocco"
teoria: ["durata-degli-oggetti-puntati"]
parole: ["durata automatica", "fine del blocco"]
---

Classificare il comportamento che avrebbe una lettura di `*p` al punto indicato. Il frammento è all’interno di una funzione.

```c
int *p;
{
    int reading = 12;
    p = &reading;
}
/* Read *p here */
```

:::soluzione
Comportamento indefinito.
:::
