Quante invocazioni con argomento $2$ compaiono nell’albero logico di `fib(5)`? Si assume $0\leq n\leq10$.

```c
unsigned fib(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    unsigned left = fib(n - 1u);
    unsigned right = fib(n - 2u);
    return left + right;
}
```

:::soluzione
$3$.
:::
