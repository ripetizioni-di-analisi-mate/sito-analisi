---
titolo: "Ordine delle due prime chiamate"
teoria: ["record-attivazione", "sequenza-chiamate"]

---

Indicare, nell’ordine di avvio, i due argomenti delle prime invocazioni dopo l’inizio di `select(3)`. Il dominio è $0\leq n\leq10$.

```c
unsigned select(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    unsigned first = select(n - 2u);
    unsigned second = select(n - 1u);
    return first + second;
}
```

:::soluzione
$(1,2)$.
:::
