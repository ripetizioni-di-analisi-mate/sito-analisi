Per la chiamata `hop(7)`, determinare l’argomento della prima invocazione che esegue il ramo base.

```c
unsigned hop(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    return hop(n - 2u);
}
```

:::soluzione
$1$.
:::
