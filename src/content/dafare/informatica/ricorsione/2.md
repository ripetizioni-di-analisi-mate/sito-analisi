Calcolare il valore restituito da `product(5)`. Il dominio dell’esercizio è $0\leq n\leq8$.

```c
unsigned long product(unsigned n)
{
    if (n == 0u) {
        return 1ul;
    }
    return n * product(n - 1u);
}
```

:::soluzione
$120$.
:::
