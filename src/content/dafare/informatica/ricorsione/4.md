Nel modello dei record logici, qual è il massimo numero di invocazioni simultaneamente attive durante `steps(18)`? Contare la chiamata iniziale e quella del caso base.

```c
unsigned steps(unsigned n)
{
    if (n <= 1u) {
        return 0u;
    }
    return 1u + steps(n / 2u);
}
```

:::soluzione
$5$.
:::
