Determinare il valore restituito da `fib(6)`. Il dominio dell’esercizio è $0\leq n\leq10$.

```c
unsigned fib(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    unsigned left = fib(n - 1u);
    unsigned right = fib(n - 2u);
    return left + right;
}
```

:::soluzione
$8$.
:::
