titolo: "Somma di un vettore per prefissi"

Il vettore `values` contiene in ordine $4$, $1$, $6$ e $2$. Calcolare il valore di `prefix_sum(values, 4)`. Si include `<stddef.h>`.

```c
unsigned prefix_sum(const unsigned a[], size_t n)
{
    if (n == 0) {
        return 0u;
    }
    return prefix_sum(a, n - 1) + a[n - 1];
}
```

:::soluzione
$13$.
:::
