Quante invocazioni logiche di `fork_count` avvengono complessivamente per `fork_count(3)`? Contare radice e foglie. Il dominio è $0\leq n\leq6$.

```c
unsigned fork_count(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned left = fork_count(n - 1u);
    unsigned right = fork_count(n - 1u);
    return left + right;
}
```

:::soluzione
$15$.
:::
