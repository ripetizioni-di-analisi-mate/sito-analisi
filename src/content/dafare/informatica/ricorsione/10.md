---
titolo: "Raggiungibilità del ramo base"
teoria: ["contratto-ricorsivo", "misura-decrescente"]
parole: ["terminazione", "misura"]
---

Nel modello delle chiamate logiche, stabilire se il ramo base viene raggiunto partendo da `repeat(3)`.

```c
unsigned repeat(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return repeat(n);
}
```

:::soluzione
Il ramo base non viene raggiunto.
:::
