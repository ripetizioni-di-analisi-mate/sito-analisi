Determinare il risultato di `twice(9)`. Il dominio è $0\leq n\leq127$.

```c
unsigned twice(unsigned n)
{
    if (n == 0u) {
        return 1u;
    }
    unsigned smaller = twice(n / 2u);
    return 2u * smaller;
}
```

:::soluzione
$16$.
:::
