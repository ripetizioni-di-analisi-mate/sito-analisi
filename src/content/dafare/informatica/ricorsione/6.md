Calcolare il massimo numero di record logici simultaneamente attivi per `fib(5)`. Contare anche il record iniziale e quello del caso base. Si assume $0\leq n\leq10$.

```c
unsigned fib(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    unsigned left = fib(n - 1u);
    unsigned right = fib(n - 2u);
    return left + right;
}
```

:::soluzione
$5$.
:::
