titolo: "Massimo comune divisore ricorsivo"

Calcolare il valore restituito da `gcd(30, 18)` con il seguente codice.

```c
unsigned gcd(unsigned a, unsigned b)
{
    if (b == 0u) {
        return a;
    }
    return gcd(b, a % b);
}
```

:::soluzione
$6$.
:::
