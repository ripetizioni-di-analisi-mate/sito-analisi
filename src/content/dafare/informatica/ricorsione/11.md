Trovare una formula in funzione di $n$ per il valore di `sum(n)` sull’intero intervallo $0\leq n\leq20$.

```c
unsigned sum(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return n + sum(n - 1u);
}
```

:::soluzione
$\dfrac{n(n+1)}{2}$.
:::
