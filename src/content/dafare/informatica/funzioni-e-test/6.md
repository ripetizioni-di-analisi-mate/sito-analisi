---
titolo: "Stato tra chiamate successive"
teoria: [durata-degli-oggetti]
parole: ["static locale", "accumulatore"]
---

All’inizio di una nuova esecuzione si chiamano `add(2)`, `add(-1)` e `add(4)`, in quest’ordine e in tre istruzioni distinte. Quale valore restituisce la terza chiamata?

```c
int add(int step)
{
    static int total = 5;
    total += step;
    return total;
}
```

:::soluzione
$10$.
:::
