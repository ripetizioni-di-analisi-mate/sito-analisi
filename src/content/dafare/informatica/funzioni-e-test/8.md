---

Si assume che `points` sia un intero tra $0$ e $30$ inclusi. Determinare il più piccolo `points` per cui `passed(points)` vale $1$.

```c
int passed(int points)
{
    if (points >= 18) {
        return 1;
    }
    return 0;
}
```

:::soluzione
$18$.
:::
