Nel chiamante si dichiara `int n = 8;` e si inizializza `int r = bump(n);`. Qual è il valore di `n` nel chiamante dopo la chiamata?

```c
int bump(int n)
{
    n += 5;
    return n;
}
```

:::soluzione
$8$.
:::
