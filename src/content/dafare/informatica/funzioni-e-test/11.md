titolo: "Composizione con un minimo"
teoria: [scomposizione, ritorno-dalla-funzione]
parole: ["risultato intermedio", "composizione"]
---

Calcolare il valore restituito da `with_minimum(3)`.

```c
int base_cost(int n)
{
    return 2 * n + 1;
}

int with_minimum(int n)
{
    int cost = base_cost(n);
    return cost < 8 ? 8 : cost;
}
```

:::soluzione
$8$.
:::
