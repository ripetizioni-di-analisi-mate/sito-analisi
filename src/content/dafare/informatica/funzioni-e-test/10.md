Si considera un’implementazione C17 con `INT_MAX` uguale a $32767$. Determinare il massimo valore intero non negativo di `n` per cui questa funzione calcola il quadrato con comportamento definito.

```c
int square_nonnegative(int n)
{
    return n * n;
}
```

:::soluzione
$181$.
:::
