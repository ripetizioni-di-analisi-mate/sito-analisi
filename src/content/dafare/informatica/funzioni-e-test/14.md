La macro `NDEBUG` è definita quando si include `<assert.h>`. Quale intero restituisce `probe()` in questa versione?

```c
#define NDEBUG
#include <assert.h>

int probe(void)
{
    int n = 4;
    assert(++n == 5);
    return n;
}
```

:::soluzione
$4$.
:::
