Si eseguono `cost(2)`, `cost(0)` e `cost(3)` in tre istruzioni distinte. Quante volte si esegue l’inizializzazione `int total = 5;` nella macchina astratta di C?

```c
int cost(int input)
{
    int total = 5;
    total += input;
    return total;
}
```

:::soluzione
$3$ volte.
:::
