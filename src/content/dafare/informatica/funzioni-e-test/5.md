titolo: "Nomi uguali in blocchi distinti"

Calcolare il valore di `read_value(3)` usando la funzione data.

```c
int read_value(int n)
{
    int out = n;
    {
        int n = 4;
        out += n;
    }
    return 10 * out + n;
}
```

:::soluzione
$73$.
:::
