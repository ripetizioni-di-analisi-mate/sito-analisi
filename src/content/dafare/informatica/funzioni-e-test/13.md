Il contratto richiede che `eligible(x)` restituisca $1$ quando `x >= 20` e $0$ altrimenti, per gli interi da $0$ a $100$. Individuare l’unico input del dominio in cui questa implementazione viola il contratto.

```c
int eligible(int x)
{
    return x > 20;
}
```

:::soluzione
$20$.
:::
