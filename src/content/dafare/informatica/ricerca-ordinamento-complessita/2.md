---
titolo: "Confronti senza corrispondenza"
teoria: ["ricerca-lineare", "modello-di-costo"]
parole: ["assenza", "uguaglianza tra chiavi"]
---

Determinare quanti confronti di uguaglianza fra elementi del vettore e chiave vengono eseguiti. Il frammento usa `size_t` da `<stddef.h>`.

```c
int a[] = {9, 2, 6, 3, 2};
int key = 7;
size_t comparisons = 0;
for (size_t i = 0; i < 5; ++i) {
    ++comparisons;
    if (a[i] == key) {
        break;
    }
}
```

:::soluzione
$$
5 .
$$
:::
