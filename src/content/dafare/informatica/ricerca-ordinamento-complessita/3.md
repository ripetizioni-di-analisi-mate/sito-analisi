titolo: "Prove della ricerca dicotomica"
teoria: ["dicotomia-invariante", "modello-di-costo"]
parole: ["punto medio", "confronti"]
---

Determinare il numero di confronti `a[mid] < key` eseguiti dal frammento. Il tipo `size_t` è quello di `<stddef.h>`.

```c
int a[] = {1, 3, 5, 7, 9, 11, 13};
int key = 9;
size_t lo = 0, hi = 7, comparisons = 0;
while (lo < hi) {
    size_t mid = lo + (hi - lo) / 2;
    ++comparisons;
    if (a[mid] < key) {
        lo = mid + 1;
    } else {
        hi = mid;
    }
}
```

:::soluzione
$$
3 .
$$
:::
