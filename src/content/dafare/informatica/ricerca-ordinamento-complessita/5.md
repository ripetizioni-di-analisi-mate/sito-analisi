---
titolo: "Limite inferiore tra duplicati"
teoria: ["lower-bound", "dicotomia-invariante"]
parole: ["duplicati", "prima posizione"]
---

Determinare il valore di `lo` all’uscita dal ciclo. Il frammento usa `size_t` da `<stddef.h>`.

```c
int a[] = {1, 2, 5, 5, 5, 9, 14};
int key = 5;
size_t lo = 0, hi = 7;
while (lo < hi) {
    size_t mid = lo + (hi - lo) / 2;
    if (a[mid] < key) {
        lo = mid + 1;
    } else {
        hi = mid;
    }
}
```

:::soluzione
$$
2 .
$$
:::
