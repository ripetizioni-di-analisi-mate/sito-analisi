---
titolo: "Valore spostato dal primo minimo"
teoria: ["selection-sort"]
parole: ["minimo", "scambio"]
---

Il seguente frammento esegue il primo passo del selection sort. Dare il valore di `a[3]` al termine. Il tipo `size_t` è quello di `<stddef.h>`.

```c
int a[] = {9, 4, 6, 1, 3};
size_t min_index = 0;
for (size_t j = 1; j < 5; ++j) {
    if (a[j] < a[min_index]) {
        min_index = j;
    }
}
int saved = a[0];
a[0] = a[min_index];
a[min_index] = saved;
```

:::soluzione
$$
9 .
$$
:::
