---
titolo: "Spostamenti in un inserimento"
teoria: ["insertion-sort"]

---

Contare le scritture della forma `a[j] = a[j - 1]`. La scrittura finale della chiave è separata. Il frammento usa `size_t` da `<stddef.h>`.

```c
int a[] = {2, 4, 8, 3};
int key = a[3];
size_t j = 3, shifts = 0;
while (j > 0 && a[j - 1] > key) {
    a[j] = a[j - 1];
    --j;
    ++shifts;
}
a[j] = key;
```

:::soluzione
$$
2 .
$$
:::
