Determinare il valore finale di `index`. Il frammento usa `size_t` da `<stddef.h>`.

```c
int a[] = {6, 4, 8, 4};
size_t n = sizeof a / sizeof a[0];
size_t index = n;
for (size_t i = 0; i < n; ++i) {
    if (a[i] == 4) {
        index = i;
        break;
    }
}
```

$$
1 .
$$
:::
