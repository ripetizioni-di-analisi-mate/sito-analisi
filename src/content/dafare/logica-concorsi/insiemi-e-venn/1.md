L'insieme $A = \{x \mid x \text{ è un numero dispari e } 3 \leq x \leq 9\}$ scritto per elencazione è:

- A) $\{1, 3, 5, 7, 9\}$
- B) $\{3, 5, 7, 9\}$
- C) $\{3, 5, 7\}$
- D) $\{4, 6, 8\}$
- E) $\{3, 5, 7, 9, 11\}$

:::soluzione
Risposta B: $A = \{3, 5, 7, 9\}$.
:::
