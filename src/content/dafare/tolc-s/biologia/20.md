In un doppio strato fosfolipidico con acqua su entrambi i lati, quale disposizione è energeticamente favorevole?

- Code apolari completamente esposte all’acqua su entrambi i lati
- Tutte le teste soltanto sul lato esterno
- Tutte le code soltanto sul lato citoplasmatico
- Fosfolipidi trasformati in nucleotidi
- Teste polari verso l’acqua e code apolari verso l’interno
