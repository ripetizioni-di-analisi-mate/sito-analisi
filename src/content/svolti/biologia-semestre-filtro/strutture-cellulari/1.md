## Esercizio 1

Quale orientamento assumono i fosfolipidi nel doppio strato?

- A) Tutte le teste al centro e tutte le code fuori.
- B) Un'unica catena di nucleotidi senza lipidi.
- C) Teste polari verso l'acqua e code idrofobe verso l'interno.
- D) Code idrofobe verso l'acqua su entrambe le superfici.

La risposta corretta è **C**.

<div class="spiegazione">

La disposizione limita il contatto delle code apolari con l'acqua. La natura anfipatica sostiene la formazione spontanea di doppi strati.

</div>

## Esercizio 2

Dove sono esposte le porzioni glucidiche del glicocalice della membrana plasmatica?

- A) Solo nella matrice mitocondriale.
- B) Sul lato extracellulare.
- C) Solo sul lato citosolico.
- D) Nel DNA nucleare.

La risposta corretta è **B**.

<div class="spiegazione">

Le porzioni glucidiche della via secretoria rimangono sul lato non citosolico. Dopo fusione con la membrana plasmatica risultano esterne.

</div>
