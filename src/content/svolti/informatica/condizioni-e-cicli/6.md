## Esercizio 1

Calcolare `count` e descrivere la proprietà comune alle coppie che raggiungono l’incremento.
```c
int count = 0;
for (int i = 0; i < 4; ++i) {
    for (int j = 0; j <= i; ++j) {
        if ((i + j) % 2 == 0) {
            ++count;
        }
    }
}
```

| `i` | `j` con somma pari | Incrementi |
|---:|---|---:|
| 0 | 0 | 1 |
| 1 | 1 | 1 |
| 2 | 0, 2 | 2 |
| 3 | 1, 3 | 2 |

Le coppie hanno indici della stessa parità e `count = 6`.

<div class="spiegazione">

Fissato `i`, il ciclo interno passa per gli interi da `0` a `i`. L’incremento richiede una somma pari, perciò `j` deve essere pari quando `i` è pari e dispari quando `i` è dispari. Si contano per riga i valori di `j` che soddisfano entrambe le condizioni, quindi si sommano gli incrementi.

Un secondo conteggio raggruppa le coppie per parità. Tra gli indici pari $0$ e $2$ esistono due coppie sulla diagonale e una con `j < i`. Tra i dispari $1$ e $3$ si ottengono altre tre coppie per lo stesso motivo. I due gruppi sono disgiunti, dunque il totale è $3+3=6$.

</div>


## Esercizio 2

Determinare `score`. Per ciascuna riga indicare quali colonne contribuiscono all’addizione.
```c
int score = 0;
for (int row = 1; row <= 3; ++row) {
    for (int col = 1; col <= 4; ++col) {
        if (row + col >= 5) {
            break;
        }
        if (col == 1) {
            continue;
        }
        score += 2 * row + col;
    }
}
```

| Riga | Colonne usate | Contributo |
|---:|---|---|
| 1 | 2, 3 | `4 + 5 = 9` |
| 2 | 2 | `6` |
| 3 | nessuna | `0` |

Il punteggio finale è `9 + 6 + 0 = 15`.

<div class="spiegazione">

Per ogni riga il primo candidato di colonna è `1`. In quel punto `row + col` è minore di `5` per tutti e tre i valori di `row`, quindi interviene `continue` e la colonna avanza. In seguito la condizione `row + col >= 5` interrompe il ciclo interno alla prima colonna per cui vale. Si ottengono tre punti di arresto, alle colonne `4`, `3` e `2`. A ciascun arresto il `for` esterno continua con la riga successiva, quando esiste.

Per verificare i contributi si possono risolvere insieme le condizioni $2\le \mathrm{col}\le 4$ e $\mathrm{col}<5-\mathrm{row}$. Per ogni riga la seconda condizione esclude anche tutte le colonne successive alla prima interruzione, perché il valore di `col` cresce. Restano le coppie $(1,2)$, $(1,3)$ e $(2,2)$. Sostituendole in `2 * row + col` si riottengono `4`, `5` e `6`.

</div>


## Esercizio 3

Il frammento cerca, riga per riga, la prima coppia $(i,j)$ con $1\leq i\leq j\leq 5$ e $i\cdot j$ uguale a `target`. Determinare `found`, `fi`, `fj` e `tests` con `target = 12`, poi con `target = 7`.
```c
int target = 12, found = 0, tests = 0, fi = 0, fj = 0;
for (int i = 1; i <= 5 && !found; ++i) {
    for (int j = i; j <= 5; ++j) {
        ++tests;
        if (i * j == target) {
            found = 1;
            fi = i;
            fj = j;
            break;
        }
    }
}
```

| `i` | Prodotti provati con `target = 12` | Test nella riga |
|---:|---|---:|
| 1 | 1, 2, 3, 4, 5 | 5 |
| 2 | 4, 6, 8, 10 | 4 |
| 3 | 9, 12 | 2 |

Con `target = 12` si ottiene `found = 1`, `fi = 3`, `fj = 4` e `tests = 11`. Con `target = 7` si ottiene `found = 0`, `fi = fj = 0` e

$$
\mathrm{tests}=5+4+3+2+1=15 .
$$

<div class="spiegazione">

Nella riga `i` il ciclo interno prova le colonne da `i` a `5`, quindi al più $5-i+1$ valori. Nelle righe `1` e `2` nessun prodotto vale `12`, mentre nella riga `3` il secondo test trova $3\cdot 4=12$. Il `break` termina il solo ciclo interno, perché è il ciclo più interno che lo contiene. Il ciclo esterno esegue allora il proprio aggiornamento, che porta `i` a `4`, e rivaluta la guardia. Poiché `found` vale `1`, la congiunzione `i <= 5 && !found` è falsa e le righe `4` e `5` non vengono esaminate. La variabile `found` nella guardia esterna estende quindi l’uscita ai due livelli.

Il numero `7` è primo e maggiore di `5`, perciò nessuna coppia di interi fra `1` e `5` ha prodotto `7`. In questo caso `found` resta `0`, entrambi i cicli si concludono per guardia falsa e si eseguono tutti i test previsti.

</div>
