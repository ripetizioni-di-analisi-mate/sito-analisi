## Esercizio 1

Scrivere un `while` che sommi gli interi da `1` a `7` scartando con `continue` quelli con resto `1` nella divisione per `3`. Calcolare la somma ottenuta.

```c
int i = 1, sum = 0;
while (i <= 7) {
    int current = i;
    ++i;
    if (current % 3 == 1) {
        continue;
    }
    sum += current;
}
```

$$
\begin{aligned}
\text{Valori scartati} &\quad 1,4,7, \\
\text{Valori sommati} &\quad 2,3,5,6, \\[6pt]
\mathrm{sum} &= 2+3+5+6=16 .
\end{aligned}
$$

<div class="spiegazione">

La variabile `current` conserva il valore da esaminare mentre `i` avanza alla prossima visita. Poiché `++i` precede `continue`, ogni cammino del corpo aggiorna il contatore. Quando `current = 7` la selezione salta l’addizione, però il controllo torna con `i = 8` e rende falsa la guardia. Con l’unico incremento dopo il possibile salto, il dato iniziale `i = 1` riporterebbe invece alla guardia lo stesso stato.

Per verificare la somma, gli interi da $1$ a $7$ danno $\dfrac{7\cdot 8}{2}=28$. Gli scartati danno $1+4+7=12$. Sottraendo si conferma $28-12=16$.

</div>


## Esercizio 2

Calcolare `s` e `i` quando termina il ciclo. Individuare l’ultimo addendo effettivamente usato.
```c
int s = 0, i;
for (i = 1; i <= 9; ++i) {
    if (i % 2 == 0) {
        continue;
    }
    if (s + i > 12) {
        break;
    }
    s += i;
}
```

| Dispari esaminato | Somma proposta | Esito |
|---:|---:|---|
| 1 | 1 | aggiorna `s` |
| 3 | 4 | aggiorna `s` |
| 5 | 9 | aggiorna `s` |
| 7 | 16 | interrompe |

Si esce con `s = 9` e `i = 7`. L’ultimo addendo usato è `5`.

<div class="spiegazione">

La selezione sui pari precede il confronto con il limite. Un valore pari manda quindi il controllo all’aggiornamento del `for` e lascia `s` invariata. Per un dispari, l’espressione `s + i` calcola una somma candidata senza scriverla in `s`. Il primo candidato sopra `12` vale `16`, quando `i = 7`. Si esegue `break` prima di `s += i` e prima dell’aggiornamento del `for`.

Come verifica, la somma dei primi $k$ dispari vale $k^2$. Per tre addendi si ottiene $9\le 12$, mentre con quattro si avrebbe $16>12$. Il prefisso ammissibile contiene quindi tre addendi e termina a `5`.

</div>
