## Esercizio 1

Nel file della figura sono registrate le righe $14$ e $19$. Si apre il file con `"a"` e si aggiunge $6$ come nuova riga. Tutte le operazioni riescono. Determinare il contenuto finale.

![File iniziale con le righe 14 e 19, nuova riga 6.](/immagini/informatica/file-e-laboratorio/dati-svolto-it.png)

```text
14
19
6
```

<div class="spiegazione">

Il modo di accodamento conserva i caratteri del file presente. Le due righe iniziali occupano dunque le prime due posizioni. Dopo `19` c’è già un ritorno a capo, quindi la scrittura di `"6\n"` inizia su una riga distinta. La chiusura riuscita conclude l’operazione. Come verifica, rileggere il file scartando l’ultima riga restituisce esattamente la sequenza iniziale, `14` poi `19`. Il numero di separatori passa da due a tre.

</div>

## Esercizio 2

Un file contiene la riga $51$. Un programma lo apre con `"w"`, scrive `"-6\n"` e lo chiude. Le operazioni riescono. Indicare il contenuto finale e il numero di caratteri trasmessi.

Il file contiene soltanto la riga `-6` con il ritorno a capo. Si trasmettono $1+1+1=3$ caratteri.

<div class="spiegazione">

L’apertura con `"w"` tronca il file. La successiva scrittura parte quindi da un file vuoto e trasmette, nell’ordine, segno meno, cifra sei e ritorno a capo. Verifichiamo contando gli elementi della stringa visibili allo stream. Il terminatore nullo della stringa serve a `fputs` per individuarne la fine e resta nell’array. Dopo la chiusura una lettura per righe trova una sola riga, perché i dati precedenti sono stati rimossi alla riuscita dell’apertura.

</div>

## Esercizio 3

Il file `report.txt` contiene le righe `70`, `80` e `90`. Un programma chiama due volte la funzione seguente sul nome `"report.txt"`, prima con il vettore `{12, 5, -1, 40}` e `count` uguale a $4$, poi con lo stesso vettore e `count` uguale a $0$. Tutte le aperture, le scritture e le chiusure riescono. Determinare il contenuto del file e il valore restituito dopo ciascuna chiamata.

```c
static int write_report(const char *name, const int *values, size_t count)
{
    FILE *out = fopen(name, "w");
    if (out == NULL) {
        return 0;
    }
    int ok = 1;
    for (size_t i = 0; i < count && ok; ++i) {
        if (values[i] < 0 || fprintf(out, "%d\n", values[i]) < 0) {
            ok = 0;
        }
    }
    if (fclose(out) != 0) {
        ok = 0;
    }
    return ok;
}
```

| Chiamata | Contenuto di `report.txt` | Caratteri nel file | Valore restituito |
|---|---|---:|---:|
| prima, `count` uguale a $4$ | `12` e `5` | $5$ | $0$ |
| seconda, `count` uguale a $0$ | nessuna riga | $0$ | $1$ |

<div class="spiegazione">

L’apertura riuscita in modo `"w"` tronca il file, quindi le tre righe iniziali vengono eliminate prima di qualsiasi scrittura. Nella prima chiamata il ciclo scrive `"12\n"` e `"5\n"`, cioè $3+2=5$ caratteri. Al terzo elemento la condizione `values[i] < 0` è vera. Per il cortocircuito di `||`, la chiamata a `fprintf` con $-1$ non viene valutata. Poiché `ok` diventa zero, la guardia `i < count && ok` è falsa e il valore $40$ non viene esaminato. La chiusura si esegue comunque, perciò le due righe già trasmesse restano nel file e la funzione restituisce $0$. Nella seconda chiamata la guardia è falsa già con `i` uguale a zero. L’apertura in `"w"` ha però già troncato il file, e la funzione restituisce $1$ perché nessuna operazione è fallita. Dopo la seconda chiamata il file è quindi **vuoto** e l’esito segnala un successo.

</div>
