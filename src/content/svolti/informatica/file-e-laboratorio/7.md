## Esercizio 1

Scrivere un programma C17 che riceva il nome di un file e stampi la somma delle misure valide di classe $2$. Una riga valida ha al più $60$ caratteri prima del ritorno a capo e contiene due interi decimali, con classe in $[0,2]$ e misura in $[10,30]$. I campi sono separati da spazi o tabulazioni. Sono ammessi spazi iniziali e finali. Tutte le righe del file terminano con un ritorno a capo e il testo non contiene caratteri nulli interni. Scartare le righe non valide e segnalare con l’uscita di errore un problema di I/O o una somma non rappresentabile. Provare con `2 11`, `2 23`, `0 30`, `2 31` e `2 24 5`.

```c
#include <ctype.h>
#include <errno.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static int parse_row(const char *line, int *category, int *reading)
{
    char *end;
    errno = 0;
    long c = strtol(line, &end, 10);
    if (end == line || errno == ERANGE || c < 0 || c > 2 ||
        (*end != ' ' && *end != '\t')) {
        return 0;
    }

    const char *start = end;
    while (*start == ' ' || *start == '\t') {
        ++start;
    }
    if (isspace((unsigned char)*start)) {
        return 0;
    }
    errno = 0;
    long v = strtol(start, &end, 10);
    if (end == start || errno == ERANGE || v < 10 || v > 30) {
        return 0;
    }
    while (isspace((unsigned char)*end)) {
        ++end;
    }
    if (*end != '\0') {
        return 0;
    }
    *category = (int)c;
    *reading = (int)v;
    return 1;
}

int main(int argc, char *argv[])
{
    if (argc != 2) {
        return EXIT_FAILURE;
    }
    FILE *input = fopen(argv[1], "r");
    if (input == NULL) {
        return EXIT_FAILURE;
    }

    char line[64];
    long total = 0;
    int ok = 1;
    while (fgets(line, sizeof line, input) != NULL) {
        char *newline = strchr(line, '\n');
        if (newline == NULL) {
            int ch;
            do {
                ch = fgetc(input);
            } while (ch != EOF && ch != '\n');
            if (ferror(input)) {
                break;
            }
            continue;
        }
        if (newline - line > 60) {
            continue;
        }

        int category, reading;
        if (parse_row(line, &category, &reading) && category == 2) {
            if (total > LONG_MAX - reading) {
                ok = 0;
                break;
            }
            total += reading;
        }
    }
    if (ferror(input)) {
        ok = 0;
    }
    if (fclose(input) != 0) {
        ok = 0;
    }
    if (!ok || printf("%ld\n", total) < 0 || fflush(stdout) == EOF) {
        return EXIT_FAILURE;
    }
    return EXIT_SUCCESS;
}
```

Per questo file l’uscita attesa è `34` seguita da un ritorno a capo.

<div class="spiegazione">

La routine di lettura controlla la riga intera e scarta i caratteri residui delle righe che non stanno nel buffer. `parse_row` controlla entrambi gli interi, il separatore e il terminatore prima di scrivere nei parametri di uscita. L’accumulatore si aggiorna solo dopo l’accettazione della classe richiesta e il controllo del limite di `long`. Dopo ogni riga rimane perciò uguale alla somma delle misure valide della classe già lette. Verifichiamo per enumerazione diretta: le prime due righe contribuiscono con $11$ e $23$, la terza è valida ma appartiene alla classe $0$, la quarta supera il limite e la quinta ha un campo in più. Il totale atteso è $11+23=34$. Come secondo test, un file vuoto esce con successo e stampa `0`.

## Esercizio 2

Per collaudare il programma precedente si costruisce un file con due righe. La prima inizia con $73$ spazi e termina con `2 25` e un ritorno a capo. La seconda è `2 10` seguita da un ritorno a capo. Determinare l’uscita e spiegare quale problema scopre il test.

La prima riga ha più di $60$ caratteri prima del suo separatore e si scarta per intero. L’uscita è `10` seguita da un ritorno a capo.

<div class="spiegazione">

La prima lettura produce un frammento senza ritorno a capo. Se si tornasse subito a leggere e convalidare, il frammento finale potrebbe sembrare una riga indipendente con misura $25$. La procedura consuma invece tutto il resto fino al separatore. La lettura successiva parte dalla seconda riga e la convalida. Un riscontro indipendente è contare le righe fisiche, filtrare la prima perché troppo lunga e sommare l’unica misura rimasta, $10$. Il test distingue il trattamento delle righe da quello dei frammenti.

</div>
