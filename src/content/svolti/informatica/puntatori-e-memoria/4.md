## Esercizio 1

Determinare la coppia finale $(x,y)$ nel corpo della funzione chiamante e la destinazione di `p` al termine. Il corpo mostrato in fondo si esegue dopo le dichiarazioni delle due funzioni.
```c
void retarget_local(int *out, int *target)
{
    out = target;
    *out = 25;
}

void retarget_caller(int **slot, int *target)
{
    *slot = target;
}

/* Caller body */
int x = 3;
int y = 7;
int *p = &x;
retarget_local(p, &y);
*p += 2;
retarget_caller(&p, &y);
*p += 4;
```

| Passaggio | Destinazione di `p` | `x` | `y` |
|---|---|---:|---:|
| Ritorno da `retarget_local` | `x` | 3 | 25 |
| Primo incremento | `x` | 5 | 25 |
| Ritorno da `retarget_caller` | `y` | 5 | 25 |
| Secondo incremento | `y` | 5 | 29 |

La coppia finale è $(5,29)$ e `p` punta a `y`.

<div class="spiegazione">

La prima funzione riceve un indirizzo in `out`, poi cambia quel parametro locale. La scrittura attraverso `out` riguarda `y` e quindi porta `y` a $25$. Al ritorno, `p` nel chiamante conserva l’indirizzo di `x`. La seconda funzione riceve invece in `slot` l’indirizzo della variabile `p`, perciò la scrittura in `*slot` cambia il valore di `p` nel chiamante.

Per verificare il calcolo si attribuiscono gli incrementi agli oggetti su cui avvengono. Il primo modifica solo `x` e vale $3+2=5$. Il secondo modifica solo `y` dopo la scrittura di $25$ e vale $25+4=29$.

</div>

## Esercizio 2

Scrivere una funzione `quotient_and_remainder` che consegni quoziente e resto della divisione intera senza segno attraverso due parametri di uscita. Se il divisore è zero, un parametro è nullo o i due parametri designano lo stesso oggetto, la funzione restituisce `false` senza scrivere. Un parametro non nullo deve designare un `unsigned` modificabile in corso di durata. Verificare il risultato su $29$ diviso $6$ e una successiva chiamata con divisore zero.

```c
#include <stdbool.h>
#include <stddef.h>

bool quotient_and_remainder(unsigned n, unsigned d,
                            unsigned *q, unsigned *r)
{
    if (d == 0 || q == NULL || r == NULL || q == r) {
        return false;
    }
    *q = n / d;
    *r = n % d;
    return true;
}
```

Con due destinazioni distinte, la prima chiamata restituisce `true` e scrive $4$ e $5$. La chiamata con divisore zero restituisce `false` e lascia invariati i due valori.

<div class="spiegazione">

Il controllo avviene prima di ogni calcolo o scrittura, perciò nel ramo di errore i due oggetti conservano i contenuti. Nel ramo valido la divisione è definita perché il divisore è positivo e le due scritture raggiungono oggetti distinti. L’ultima condizione impedisce che il resto sovrascriva il quoziente nel medesimo oggetto.

La coppia ottenuta per $29$ è verificata dalle relazioni $6\cdot4+5=29$ e $0\leq5<6$. In una prova con destinazioni inizializzate a valori sentinella e puntatori uguali, il ritorno deve avvenire prima delle due assegnazioni, quindi il valore sentinella resta presente.

</div>

## Esercizio 3

Determinare i risultati di `locate_extremes`, che consegna attraverso due parametri di uscita la posizione del primo minimo e quella del primo massimo di un intervallo semichiuso. Se l’intervallo è vuoto o un parametro di uscita è nullo, la funzione restituisce `false` senza scrivere. Il chiamante parte da `const int a[] = {7, 2, 9, 2, 9, 4};`, `const int *lo = NULL;` e `const int *hi = NULL;`, poi chiama `locate_extremes(a, a + 6, &lo, &hi)` e `locate_extremes(a + 3, a + 3, &lo, &hi)`. Calcolare anche `hi - lo` e `*hi - *lo` dopo la prima chiamata.

```c
#include <stdbool.h>
#include <stddef.h>

bool locate_extremes(const int *first, const int *last,
                     const int **low, const int **high)
{
    if (first == last || low == NULL || high == NULL) {
        return false;
    }
    *low = first;
    *high = first;
    for (const int *p = first + 1; p != last; ++p) {
        if (*p < **low) {
            *low = p;
        }
        if (*p > **high) {
            *high = p;
        }
    }
    return true;
}
```

La prima chiamata restituisce `true` e scrive `lo = a + 1` e `hi = a + 2`. Quindi `hi - lo` vale $2-1=1$ e `*hi - *lo` vale $9-2=7$. La seconda chiamata restituisce `false` e lascia `lo` e `hi` sugli indici $1$ e $2$.

<div class="spiegazione">

Il chiamante possiede due variabili di tipo `const int *` e passa i loro indirizzi, che hanno tipo `const int **`. Perciò `*low` è la variabile `lo` del chiamante e `**low` è l’intero dell’array che essa designa. La qualifica `const` riguarda l’intero, quindi la funzione può aggiornare le due posizioni e non può scrivere negli elementi.

Dopo il controllo iniziale l’intervallo contiene almeno un elemento, quindi `first + 1` è al più la posizione successiva all’ultimo e il ciclo parte da una posizione ammessa. I confronti sono stretti, perciò un valore uguale al minimo o al massimo corrente lascia invariata la posizione registrata. Per questo il secondo $2$, all’indice $3$, e il secondo $9$, all’indice $4$, non cambiano i risultati. Nella seconda chiamata vale `first == last`, quindi il ritorno avviene prima di ogni scrittura in `*low` e in `*high`.

</div>
