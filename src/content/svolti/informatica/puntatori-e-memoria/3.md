## Esercizio 1

Per `a = {9, 1, 2, 9, 5, 9}`, trovare l’indice dell’elemento designato dal risultato di `first_match(a + 1, a + 5, 9)`. La funzione restituisce il confine finale quando la chiave è assente.

```c
const int *first_match(const int *first, const int *last, int key)
{
    while (first != last && *first != key) {
        ++first;
    }
    return first;
}
```

L’intervallo contiene gli indici $1$, $2$, $3$ e $4$. Le letture sono $1$, $2$ e $9$, in quest’ordine. Il ciclo termina alla terza lettura, quindi il puntatore restituito è `a + 3` e l’indice è $3$.

<div class="spiegazione">

All’inizio di un’iterazione i valori già oltrepassati sono tutti diversi dalla chiave. Il test iniziale verifica il confine prima di leggere l’elemento. Quando viene letto $9$ all’indice $3$, il confronto con la chiave termina il ciclo senza avanzare. La chiamata usa quindi un puntatore al primo elemento uguale alla chiave nell’intervallo dato.

Una verifica separata elenca tutte le occorrenze di $9$ nell’array completo. Sono agli indici $0$, $3$ e $5$. L’intersezione con gli indici $1$–$4$ contiene il solo indice $3$.

</div>

## Esercizio 2

Calcolare `count_at_least(a + 1, a + 4, 9)` per `a = {5, 10, 9, 6, 12}` e `count_at_least(NULL, NULL, 9)`. Il contratto consente il secondo caso per rappresentare un intervallo vuoto.

```c
#include <stddef.h>

size_t count_at_least(const int *first, const int *last, int limit)
{
    size_t count = 0;
    for (const int *p = first; p != last; ++p) {
        if (*p >= limit) {
            ++count;
        }
    }
    return count;
}
```

Nel primo caso si visitano $10$, $9$ e $6$. Il contributo al conteggio è $1+1+0=2$. Nel secondo caso i due estremi sono uguali già al primo confronto, quindi il contatore resta $0$.

<div class="spiegazione">

La posizione di indice $4$, che contiene $12$, è il confine escluso. Fra le tre posizioni interne, i valori $10$ e $9$ soddisfano `>=`, quindi l’uguaglianza alla soglia è inclusa. Nel caso vuoto nullo si esegue il confronto di uguaglianza fra puntatori. Il corpo e l’incremento del puntatore vengono saltati.

Per verificare i risultati si contano le esclusioni. Nel primo intervallo di lunghezza $3$ c’è un valore strettamente minore di $9$, quindi restano $3-1=2$ elementi. L’intervallo vuoto ha lunghezza $0$ e può contribuire solo zero.

</div>
