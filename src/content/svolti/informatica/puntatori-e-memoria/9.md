## Esercizio 1

Scrivere l’output esatto del programma. Si assumono `int` a $32$ bit e scrittura riuscita.

```c
#include <stdio.h>

int main(void)
{
    int a[] = {5, 1, 8, 3, 6};
    int *p = a;
    int *q = a + 4;
    while (p < q) {
        int tmp = *p;
        *p = *q;
        *q = tmp;
        p += 2;
        --q;
    }
    printf("%d", a[0]);
    for (size_t i = 1; i < 5; ++i) {
        printf(" %d", a[i]);
    }
    printf("\n%td %td\n", p - a, p - q);
    return 0;
}
```

| Iterazione | Indici scambiati | Array dopo lo scambio | Indici di `p` e `q` dopo gli aggiornamenti |
|---:|---|---|---|
| 1 | $0$ e $4$ | `{6, 1, 8, 3, 5}` | $2$ e $3$ |
| 2 | $2$ e $3$ | `{6, 1, 3, 8, 5}` | $4$ e $2$ |

```text
6 1 3 8 5
4 2
```

<div class="spiegazione">

Il confronto `p < q` fra puntatori è definito perché entrambi designano elementi dello stesso array, e risulta vero quando l’indice di `p` è minore di quello di `q`. A ogni iterazione `p` avanza di due posizioni e `q` arretra di una. Dopo il secondo scambio `p` ha indice $4$ e `q` ha indice $2$, quindi il confronto è falso e il ciclo termina senza toccare l’indice $1$.

Gli indici calcolati per `p` sono $0$, $2$ e $4$, tutti interni all’array di cinque elementi. Un avanzamento oltre la posizione successiva all’ultimo elemento avrebbe comportamento indefinito, e qui il massimo indice calcolato è $4$. La seconda riga stampa due differenze di puntatori con `%td`, il formato del tipo `ptrdiff_t`. La differenza `p - a` vale $4-0=4$ e `p - q` vale $4-2=2$.

</div>

## Esercizio 2

Scrivere l’output esatto del programma. La funzione `hop` sposta un cursore in avanti di tante posizioni quanto vale l’elemento designato, purché la nuova posizione non superi il confine `end`.

```c
#include <stdio.h>

static int hop(const int **cursor, const int *end)
{
    int step = **cursor;
    if (step <= 0 || step > end - *cursor) {
        return 0;
    }
    *cursor += step;
    return 1;
}

int main(void)
{
    const int a[] = {2, 5, 3, 1, 4, 1, 1};
    const int *end = a + 7;
    const int *c = a;
    int jumps = 0;
    while (c != end && hop(&c, end)) {
        ++jumps;
        printf("%td %d\n", c - a, c != end ? *c : -1);
    }
    printf("jumps=%d\n", jumps);
    return 0;
}
```

| Indice di `c` | Valore letto | `end - c` | Nuovo indice |
|---:|---:|---:|---:|
| 0 | 2 | 7 | 2 |
| 2 | 3 | 5 | 5 |
| 5 | 1 | 2 | 6 |
| 6 | 1 | 1 | 7 |

```text
2 3
5 1
6 1
7 -1
jumps=4
```

<div class="spiegazione">

Il parametro `cursor` ha tipo `const int **` e riceve l’indirizzo di `c`, quindi `*cursor += step` aggiorna la variabile del chiamante. Il test `step > end - *cursor` confronta il salto con il numero di elementi rimasti. Se il salto è accettato, la nuova posizione è al più `end`, cioè la posizione successiva all’ultimo elemento, che appartiene alle posizioni ammesse.

L’ultimo salto parte dall’indice $6$ con valore $1$ e rimane $7-6=1$ elemento, perciò il salto è accettato e `c` diventa uguale a `end`. Nella `printf` l’operatore condizionale valuta soltanto uno dei due operandi finali. Poiché `c != end` è falso, si stampa $-1$ senza leggere `*c`, una lettura che avrebbe comportamento indefinito. Al controllo successivo del `while` il primo operando di `&&` è falso, quindi per il **cortocircuito** la funzione `hop` non viene chiamata e il ciclo termina con quattro salti.

</div>

## Esercizio 3

Scrivere l’output esatto del programma. Si assumono `int` a $32$ bit, allocazioni riuscite e scrittura riuscita.

```c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

static int *make_squares(size_t n)
{
    int *v;
    if (n == 0 || n > SIZE_MAX / sizeof *v) {
        return NULL;
    }
    v = malloc(n * sizeof *v);
    if (v == NULL) {
        return NULL;
    }
    for (size_t i = 0; i < n; ++i) {
        v[i] = (int)(i * i);
    }
    return v;
}

int main(void)
{
    int *v = make_squares(4);
    if (v == NULL) {
        return EXIT_FAILURE;
    }
    int *next = realloc(v, 6 * sizeof *v);
    if (next == NULL) {
        free(v);
        return EXIT_FAILURE;
    }
    v = next;
    v[4] = v[3] - v[1];
    v[5] = v[4] + v[2];
    int *mid = v + 2;
    mid[1] += *mid;
    for (size_t i = 0; i < 6; ++i) {
        printf("%d%c", v[i], i + 1 < 6 ? ' ' : '\n');
    }
    printf("%td\n", (v + 6) - mid);
    free(v);
    return 0;
}
```

$$
\begin{aligned}
(v_0,v_1,v_2,v_3) &= (0,1,4,9) \\[6pt]
v_4 &= v_3-v_1 = 9-1 = 8 \\[6pt]
v_5 &= v_4+v_2 = 8+4 = 12 \\[6pt]
v_3 &= v_3+v_2 = 9+4 = 13
\end{aligned}
$$

```text
0 1 4 13 8 12
4
```

<div class="spiegazione">

La funzione `make_squares` controlla la dimensione prima della moltiplicazione e restituisce un blocco di quattro interi inizializzati con i quadrati degli indici. Il blocco passa al chiamante con il valore di ritorno, quindi `main` ne ha la **proprietà** e lo rilascia alla fine. Il ridimensionamento a sei interi conserva i primi quattro valori, mentre `v[4]` e `v[5]` hanno contenuto indeterminato finché non vengono scritti. Le due assegnazioni successive li scrivono prima di ogni lettura, e i loro secondi membri usano soltanto elementi già inizializzati.

Il puntatore `mid` è calcolato dal blocco ridimensionato, quindi è valido. In `mid[1] += *mid` l’espressione `mid[1]` designa `v[3]` e `*mid` designa `v[2]`, perciò `v[3]` passa da $9$ a $13$. Poiché `v[4]` era già stato calcolato con il valore precedente $9$, resta uguale a $8$. La seconda riga stampa `(v + 6) - mid`, cioè il numero di elementi fra l’indice $2$ e la posizione successiva all’ultimo, che vale $6-2=4$.

</div>
