## Esercizio 1

Copiare in un vettore distinto il testo `"tattica"` eliminando tutti i caratteri `'t'` e mantenendone l’ordine. Scrivere un frammento che produca una stringa C valida anche nel caso in cui tutti i caratteri siano eliminati.

```c
char s[] = "tattica";
char out[sizeof s];
size_t k = 0;

for (size_t i = 0; s[i] != '\0'; ++i) {
    if (s[i] != 't') {
        out[k] = s[i];
        ++k;
    }
}
out[k] = '\0';
```

$$
(i_0,i_1,i_2,i_3)=(1,4,5,6),\qquad k=4 .
$$

```text
aica
```

<div class="spiegazione">

Il frammento usa `size_t` da `<stddef.h>`. Il vettore `s` misura otto byte C perché contiene sette caratteri visibili e un nullo. La stessa capacità è quindi sufficiente per l’uscita. Il ciclo legge i sette caratteri e scarta `'t'` agli indici $0$, $2$ e $3$. Per le altre celle scrive ai successivi indici di uscita $0$, $1$, $2$ e $3$. Dopo l’ultima scrittura $k=4$. Il nullo va in `out[4]` e la stringa è `"aica"`. Se tutti i caratteri sono eliminati, $k$ resta a zero e il nullo è scritto nella prima cella.

Per la verifica si selezionano direttamente nella parola d’ingresso i caratteri agli indici $1$, $4$, $5$ e $6$. Sono rispettivamente `'a'`, `'i'`, `'c'` e `'a'`. Il conteggio $7-3=4$ coincide con $k$, quindi la soluzione conserva tutti e soli i caratteri richiesti.

</div>

## Esercizio 2

Progettare un conteggio delle occorrenze, anche sovrapposte, di una stringa `p` non vuota in una stringa `s`. Applicarlo a `"abababa"` e `"aba"`, indicando gli indici di inizio delle occorrenze.

```c
#include <stddef.h>
#include <string.h>

size_t occurrences(const char s[], const char p[])
{
    size_t n = strlen(s);
    size_t m = strlen(p);
    if (m == 0 || m > n) {
        return 0;
    }
    size_t count = 0;
    for (size_t i = 0; i <= n - m; ++i) {
        if (strncmp(s + i, p, m) == 0) {
            ++count;
        }
    }
    return count;
}
```

$$
7-3=4,\qquad
\{i\mid\texttt{s[i..i+3)}=\texttt{"aba"}\}
 =\{0,2,4\},\qquad N=3 .
$$

<div class="spiegazione">

Entrambi gli argomenti devono essere stringhe C valide. Si calcola una volta la lunghezza di ciascuna. Se il motivo è più lungo del testo, ogni partenza sarebbe fuori dominio, quindi la funzione restituisce zero prima della sottrazione. Con i dati assegnati, l’ultimo inizio ammesso è $4$. Per ciascun inizio si confrontano tre caratteri. Nei cinque tentativi si leggono nell’ordine `"aba"`, `"bab"`, `"aba"`, `"bab"` e `"aba"`. Avanzare di una posizione dopo ogni confronto preserva le occorrenze che condividono caratteri.

Per verificare senza ripetere i confronti, si osserva che il testo alterna `'a'` e `'b'` e comincia da `'a'`. Un'occorrenza di `"aba"` parte dunque da un indice pari e richiede ancora due caratteri disponibili. Gli unici indici pari in $[0,5)$ sono $0$, $2$ e $4$. Il numero di occorrenze è quindi $3$.

</div>
