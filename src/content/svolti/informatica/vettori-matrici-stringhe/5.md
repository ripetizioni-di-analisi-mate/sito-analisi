## Esercizio 1

Calcolare la somma della colonna di indice $2$ nella matrice $4\times3$ seguente. Scrivere una funzione che lavori con una colonna valida e un numero variabile di righe, ciascuna di tre elementi.
$$
M=\begin{pmatrix}
7&1&3\\
-1&4&5\\
2&9&-2\\
3&0&4
\end{pmatrix}.
$$

```c
#include <stddef.h>

int column_sum(const int m[][3], size_t rows, size_t c)
{
    int sum = 0;
    for (size_t r = 0; r < rows; ++r) {
        sum += m[r][c];
    }
    return sum;
}
```

$$
\begin{aligned}
S_2&=m[0][2]+m[1][2]+m[2][2]+m[3][2]\\[6pt]
   &=3+5-2+4=10 .
\end{aligned}
$$

<div class="spiegazione">

Si dichiara la matrice di ingresso con elementi `const int`, e il chiamante passa il numero di righe inizializzate. Il secondo indice resta costante e vale $2$, quindi il ciclo cambia soltanto riga. I valori aggiunti sono nell’ordine $3$, $5$, $-2$ e $4$. Le somme parziali $3$, $8$, $6$ e $10$ sono rappresentabili in `int`. Per una chiamata generale il contratto richiede proprio questo vincolo e un indice di colonna inferiore a tre.

Per verificare la somma, si calcolano le somme delle quattro righe, $11$, $8$, $9$ e $7$. Tutti gli elementi sommano dunque $35$. Le prime due colonne sommano rispettivamente $11$ e $14$, perciò la terza contribuisce $35-11-14=10$. Il controllo usa la stessa matrice attraversata per righe e poi separata per colonne.

</div>

## Esercizio 2

Trasporre la matrice $2\times4$ seguente in una matrice distinta. Dare le dimensioni del risultato e il contenuto di ciascuna riga.
$$
M=\begin{pmatrix}
8&0&-2&5\\
4&7&3&1
\end{pmatrix}.
$$

```c
#include <stddef.h>

void transpose(const int m[][4], int t[][2])
{
    for (size_t r = 0; r < 2; ++r) {
        for (size_t c = 0; c < 4; ++c) {
            t[c][r] = m[r][c];
        }
    }
}
```

$$
T=\begin{pmatrix}
8&4\\
0&7\\
-2&3\\
5&1
\end{pmatrix}.
$$

<div class="spiegazione">

Nell’oggetto di arrivo il primo indice coincide con il secondo indice dell’origine. Il suo insieme di valori è quindi $[0,4)$, da cui le quattro righe. Il secondo indice deriva da una riga dell’origine, perciò varia in $[0,2)$ e richiede due colonne. Si dichiara la sorgente come matrice di `const int` con due righe inizializzate, e la destinazione come `int t[4][2];`. In particolare i due elementi della colonna $2$ sono $-2$ e $3$, quindi formano la riga $2$ della trasposta.

Per la verifica si leggono la colonna $0$ e la colonna $1$ del risultato. La prima restituisce $(8,0,-2,5)$ e la seconda $(4,7,3,1)$. Sono esattamente le due righe della sorgente. Poiché le otto coppie di indici raggiungono otto celle distinte, tutte le celle di arrivo ricevono un valore.

</div>

## Esercizio 3

La funzione seguente dovrebbe trasporre sul posto una matrice quadrata $3\times3$, scambiando `m[r][c]` con `m[c][r]`. Applicarla alla matrice $M$, spiegare perché il risultato coincide con $M$ e correggere i limiti del ciclo interno. Dare il risultato della versione corretta.
$$
M=\begin{pmatrix}
2&-1&5\\
0&3&7\\
4&8&-6
\end{pmatrix}.
$$

```c
#include <stddef.h>

void transpose_in_place(int m[][3])
{
    for (size_t r = 0; r < 3; ++r) {
        for (size_t c = 0; c < 3; ++c) {
            int saved = m[r][c];
            m[r][c] = m[c][r];
            m[c][r] = saved;
        }
    }
}
```

La correzione fa partire il ciclo interno da `c = r + 1`.

```c
#include <stddef.h>

void transpose_in_place(int m[][3])
{
    for (size_t r = 0; r < 3; ++r) {
        for (size_t c = r + 1; c < 3; ++c) {
            int saved = m[r][c];
            m[r][c] = m[c][r];
            m[c][r] = saved;
        }
    }
}
```

$$
T=\begin{pmatrix}
2&0&4\\
-1&3&8\\
5&7&-6
\end{pmatrix}.
$$

<div class="spiegazione">

Nella versione originale ogni coppia di posizioni simmetriche $(r,c)$ e $(c,r)$, con $r\neq c$, viene scambiata due volte. Il primo scambio avviene quando il ciclo esterno vale $\min(r,c)$, il secondo quando vale $\max(r,c)$. Il secondo scambio riporta i due valori nelle posizioni di partenza. Per esempio, con $(r,c)=(0,1)$ le celle `m[0][1]` e `m[1][0]` passano da $-1$ e $0$ a $0$ e $-1$, e con $(r,c)=(1,0)$ tornano a $-1$ e $0$. Le celle della diagonale, con $r=c$, sono scambiate con sé stesse. Di conseguenza ogni cella ha alla fine il valore iniziale e la matrice resta $M$. Con il ciclo interno che parte da $r+1$ si visitano solo le posizioni sopra la diagonale, cioè $(0,1)$, $(0,2)$ e $(1,2)$. Ogni coppia simmetrica viene perciò scambiata una sola volta, con $\dfrac{3\cdot2}{2}=3$ scambi. La trasposizione sul posto richiede una matrice quadrata, perché la trasposta di una matrice $R\times C$ con $R\neq C$ ha forma $C\times R$ e quindi un tipo di riga diverso.

Come verifica si confrontano le righe di $T$ con le colonne di $M$. La colonna $1$ di $M$ è $(-1,3,8)$ e coincide con la riga $1$ di $T$. Lo stesso vale per le colonne $0$ e $2$, che danno $(2,0,4)$ e $(5,7,-6)$.

</div>
