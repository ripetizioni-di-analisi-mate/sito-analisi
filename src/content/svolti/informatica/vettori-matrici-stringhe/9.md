## Esercizio 1

Determinare l’output del programma seguente su una macchina in cui `sizeof(int)` vale $4$ e `sizeof(const int *)` vale $8$. Si assume che la scrittura su `stdout` riesca. Individuare l’errore nella funzione `sum_all`, correggerlo e dare l’output del programma corretto.

```c
#include <stdio.h>
#include <stddef.h>

int sum_all(const int a[])
{
    size_t n = sizeof a / sizeof a[0];
    int sum = 0;
    for (size_t i = 0; i < n; ++i) {
        sum += a[i];
    }
    return sum;
}

int main(void)
{
    int v[6] = {3, 1, 4, 1, 5, 9};
    size_t n = sizeof v / sizeof v[0];
    printf("%zu %d\n", n, sum_all(v));
    return 0;
}
```

$$
\begin{aligned}
\text{in } \texttt{main}:&\quad \frac{\texttt{sizeof v}}{\texttt{sizeof v[0]}}=\frac{24}{4}=6,\\[6pt]
\text{in } \texttt{sum\_all}:&\quad \frac{\texttt{sizeof a}}{\texttt{sizeof a[0]}}=\frac{8}{4}=2,\qquad 3+1=4 .
\end{aligned}
$$

```text
6 4
```

La correzione passa il numero di elementi come parametro.

```c
int sum_all(const int a[], size_t n)
{
    int sum = 0;
    for (size_t i = 0; i < n; ++i) {
        sum += a[i];
    }
    return sum;
}
```

Con la chiamata `sum_all(v, n)` il programma stampa `6 23`.

<div class="spiegazione">

In `main` l’identificatore `v` indica l’oggetto vettore, quindi `sizeof v` vale $6\cdot4=24$ e il quoziente dà il numero di elementi $6$. Nella dichiarazione di `sum_all` il parametro `const int a[]` è adattato a `const int *a`. L’operatore `sizeof a` misura perciò il puntatore e vale $8$, mentre `sizeof a[0]` misura un `int` e vale $4$. La funzione calcola quindi $n=2$ e somma soltanto `a[0]` e `a[1]`, cioè $3+1=4$. Il valore di $n$ calcolato nella funzione dipende perciò soltanto dalle ampiezze di `const int *` e di `int`, qualunque sia la lunghezza del vettore passato. Il compilatore GCC segnala questo caso con l’avviso `-Wsizeof-array-argument`, attivo anche senza `-Wall`. Nella versione corretta il numero di elementi si calcola nel blocco in cui `v` è un oggetto vettore e si passa come argomento di tipo `size_t`. La funzione somma allora i sei elementi, con somme parziali $3$, $4$, $8$, $9$, $14$ e $23$.

Come controllo si osserva che il valore errato $4$ coincide con la somma dei primi $\dfrac{8}{4}=2$ elementi. Su una macchina con puntatori da quattro byte C la funzione errata sommerebbe invece il solo primo elemento.

</div>

## Esercizio 2

Determinare l’output del programma seguente e il contenuto della matrice al termine dei cicli. Si assume che la scrittura su `stdout` riesca.

```c
#include <stdio.h>
#include <stddef.h>

int main(void)
{
    int m[3][4];
    int row[3] = {0};
    int diag = 0;
    for (size_t r = 0; r < 3; ++r) {
        for (size_t c = 0; c < 4; ++c) {
            m[r][c] = (int)((r + 1) * c + r);
            row[r] += m[r][c];
        }
    }
    for (size_t i = 0; i < 3; ++i) {
        diag += m[i][i];
    }
    for (size_t r = 0; r < 3; ++r) {
        printf("%d ", row[r]);
    }
    printf("| %d %d\n", diag, m[2][3] - m[1][3]);
    return 0;
}
```

$$
m=\begin{pmatrix}
0&1&2&3\\
1&3&5&7\\
2&5&8&11
\end{pmatrix},\qquad
\begin{aligned}
\texttt{row} &= (6,16,26),\\[6pt]
\texttt{diag} &= 0+3+8=11,\\[6pt]
m[2][3]-m[1][3] &= 11-7=4 .
\end{aligned}
$$

```text
6 16 26 | 11 4
```

<div class="spiegazione">

La lista `{0}` inizializza il primo elemento di `row` e, poiché la dichiarazione fornisce una lista, anche gli altri due elementi ricevono zero. La matrice `m` ha durata automatica e nessun inizializzatore, quindi il suo contenuto iniziale è indeterminato. Ogni cella però riceve un valore nel ciclo interno prima di essere letta. L’espressione `(r + 1) * c + r` ha operandi `size_t` e vale al più $3\cdot3+2=11$, perciò la conversione a `int` conserva il valore. Con la riga $r$ fissata, il ciclo interno scrive la riga e accumula subito la sua somma in `row[r]`. La diagonale di una matrice $3\times4$ contiene $\min(3,4)=3$ celle, quindi il secondo ciclo usa gli indici $0$, $1$ e $2$, tutti validi anche come indici di colonna. L’ultimo campo confronta due celle della colonna $3$, che valgono $11$ e $7$.

Come controllo si calcola la somma della riga $r$ con la formula. Gli indici di colonna sommano $0+1+2+3=6$, quindi la riga $r$ somma $6(r+1)+4r=10r+6$. Per $r=0,1,2$ si ottengono $6$, $16$ e $26$.

</div>

## Esercizio 3

Il programma seguente conta le lettere di una parola formata da sole lettere minuscole e scrive in `out` ogni lettera che compare più di una volta, seguita dalla sua frequenza. Si assume un insieme di caratteri di esecuzione in cui le lettere da `'a'` a `'z'` hanno codici consecutivi e crescenti, come in ASCII, e che ogni frequenza sia al più $9$. Determinare l’output e il contenuto di `out` fino al terminatore.

```c
#include <stdio.h>
#include <stddef.h>

int main(void)
{
    const char word[] = "banana";
    int freq[26] = {0};
    for (size_t i = 0; word[i] != '\0'; ++i) {
        ++freq[word[i] - 'a'];
    }
    char out[2 * 26 + 1];
    size_t k = 0;
    for (size_t j = 0; j < 26; ++j) {
        if (freq[j] > 1) {
            out[k] = (char)('a' + j);
            out[k + 1] = (char)('0' + freq[j]);
            k += 2;
        }
    }
    out[k] = '\0';
    printf("%s %zu %zu\n", out, k, sizeof word);
    return 0;
}
```

| lettera | `a` | `b` | `n` |
| --- | ---: | ---: | ---: |
| indice in `freq` | $0$ | $1$ | $13$ |
| frequenza | $3$ | $1$ | $2$ |

| $i$ | $0$ | $1$ | $2$ | $3$ | $4$ |
| --- | --- | --- | --- | --- | --- |
| `out[i]` | `'a'` | `'3'` | `'n'` | `'2'` | `'\0'` |

```text
a3n2 4 7
```

<div class="spiegazione">

Il vettore `freq` riceve zero in tutte le $26$ celle, perché la lista `{0}` lascia gli elementi senza valore esplicito a zero. Sotto l’ipotesi sui codici delle lettere, `word[i] - 'a'` è un indice in $[0,26)$, e vale $0$ per `'a'`, $1$ per `'b'` e $13$ per `'n'`. Il primo ciclo legge i sei caratteri di `"banana"` e si arresta sul nullo all’indice $6$, quindi le frequenze finali sono $3$, $1$ e $2$. Il secondo ciclo esamina le lettere in ordine alfabetico e usa $k$ come indice di scrittura, che avanza di due a ogni lettera conservata. La lettera `'b'` ha frequenza $1$ e viene saltata. Le cifre da `'0'` a `'9'` hanno codici consecutivi in ogni insieme di caratteri conforme al C, perciò `'0' + freq[j]` è la cifra della frequenza quando questa è al più $9$. Il terminatore va in `out[4]`, quindi `%s` stampa `a3n2` e $k$ vale $4$. L’operatore `sizeof word` conta i sei caratteri e il nullo del letterale, cioè $7$. La capacità di `out` è $53$, sufficiente anche se tutte le $26$ lettere comparissero almeno due volte, con $2\cdot26$ caratteri e un nullo.

</div>
