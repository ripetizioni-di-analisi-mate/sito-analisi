## Esercizio 1

Scrivere una funzione `sum_range` che sommi gli elementi inizializzati di un vettore nell’intervallo $[lo,hi)$, con $0\le lo\le hi\le n$. Ogni somma parziale è rappresentabile in `int`. Applicarla a `int a[5] = {6, -1, 7, 2, -4};` negli intervalli $[1,4)$ e $[5,5)$.

```c
#include <stddef.h>

int sum_range(const int a[], size_t lo, size_t hi)
{
    int sum = 0;
    for (size_t i = lo; i < hi; ++i) {
        sum += a[i];
    }
    return sum;
}
```

$$
\begin{aligned}
\operatorname{sum}(a,[1,4))&=-1+7+2=8,\\[6pt]
\operatorname{sum}(a,[5,5))&=0 .
\end{aligned}
$$

<div class="spiegazione">

La firma accetta gli estremi perché la funzione riceve accesso agli elementi attraverso un parametro adattato a puntatore. L’oggetto completo ha cinque celle, quindi gli estremi delle due chiamate rientrano nel contratto. Nel primo intervallo si elaborano in successione le celle $1$, $2$ e $3$. I valori dell’accumulatore sono $-1$, $6$ e $8$. Per il secondo intervallo la prima condizione di ciclo è falsa. La funzione preserva il valore iniziale $0$ e non tenta di leggere `a[5]`.

Si può verificare la prima somma usando l’intero vettore. Il totale vale $6-1+7+2-4=10$. Gli elementi esterni al segmento hanno valori $6$ e $-4$, quindi $10-[6+(-4)]=8$. Per la seconda prova la cardinalità dell’intervallo è $5-5=0$, perciò la somma vuota vale zero.

</div>

## Esercizio 2

Invertire sul posto `int a[5] = {2, -4, 6, 8, 3};`. Usare un ciclo che scambi due celle alla volta. La procedura deve funzionare anche quando il chiamante richiede di elaborare zero elementi.

```c
#include <stddef.h>

void reverse(int a[], size_t n)
{
    for (size_t i = 0; i < n / 2; ++i) {
        size_t j = n - 1 - i;
        int saved = a[i];
        a[i] = a[j];
        a[j] = saved;
    }
}
```

$$
\begin{aligned}
(2,-4,6,8,3)&\ \longmapsto\ (3,-4,6,8,2)\\[6pt]
            &\ \longmapsto\ (3,8,6,-4,2) .
\end{aligned}
$$

<div class="spiegazione">

Gli indici speculari soddisfano $i+j=n-1$. Con cinque elementi il primo scambio usa gli indici $0$ e $4$, mentre il secondo usa $1$ e $3$. L’indice $2$ coincide con il proprio speculare, quindi la sua cella rimane a posto. La variabile `saved` conserva il primo valore fino alla scrittura nella seconda cella. Per $n=0$ il test `i < n / 2` è falso a partire dall’inizializzazione del ciclo. L’espressione `n - 1 - i` viene valutata soltanto quando il corpo è eseguito, quindi il caso vuoto evita anche una sottrazione fuori dal dominio previsto.

Per controllare l’ordine, si leggono direttamente gli elementi di ingresso dagli indici $4$, $3$, $2$, $1$ e $0$. Si ottengono $3$, $8$, $6$, $-4$ e $2$, rispettivamente. La lettura all’indietro produce la stessa sequenza dei due scambi.

</div>

## Esercizio 3

La funzione seguente deve ruotare a sinistra di una posizione gli elementi con indice in $[lo,hi)$. Il primo elemento del segmento va nell’ultima cella del segmento e gli altri avanzano di un posto. Il contratto ammette $0\leq lo\leq hi\leq n$, dove $n$ è il numero di elementi del vettore, compreso l’intervallo vuoto. Stabilire per quali chiamate ammesse la funzione non rispetta la specifica, correggerla e applicare la versione corretta a `int a[5] = {2, -4, 6, 8, 3};` negli intervalli $[1,4)$ e $[5,5)$.

```c
#include <stddef.h>

void rotate_left(int a[], size_t lo, size_t hi)
{
    int first = a[lo];
    for (size_t i = lo; i < hi - 1; ++i) {
        a[i] = a[i + 1];
    }
    a[hi - 1] = first;
}
```

La correzione aggiunge un ritorno anticipato per l’intervallo vuoto.

```c
#include <stddef.h>

void rotate_left(int a[], size_t lo, size_t hi)
{
    if (lo == hi) {
        return;
    }
    int first = a[lo];
    for (size_t i = lo; i < hi - 1; ++i) {
        a[i] = a[i + 1];
    }
    a[hi - 1] = first;
}
```

$$
\begin{aligned}
[1,4):&\quad (2,-4,6,8,3)\ \longmapsto\ (2,6,8,-4,3),\\[6pt]
[5,5):&\quad (2,6,8,-4,3)\ \longmapsto\ (2,6,8,-4,3) .
\end{aligned}
$$

<div class="spiegazione">

Per $lo<hi$ la funzione originale usa soltanto indici di $[lo,hi)$, quindi è corretta. Con l’intervallo vuoto legge invece `a[lo]` e scrive in `a[hi - 1]`. Se $0<lo=hi<n$, la scrittura copia `a[lo]` in `a[lo - 1]`, perciò modifica una cella esterna al segmento. Se $lo=hi=n$, la lettura riguarda l’indice $n$, che è fuori dal vettore. Se $lo=hi=0$, l’espressione `hi - 1` si calcola nel tipo senza segno `size_t` e vale `SIZE_MAX`, quindi il ciclo prosegue oltre l’ultima cella. Negli ultimi due casi l’accesso fuori dal vettore ha **comportamento non definito**. Il ritorno anticipato precede ogni accesso, e per $hi>lo\geq0$ la sottrazione `hi - 1` resta non negativa. Nella chiamata su $[1,4)$ si salva $-4$, le celle $1$ e $2$ ricevono $6$ e $8$, e la cella $3$ riceve $-4$. La chiamata su $[5,5)$ termina subito e lascia il vettore invariato.

Come verifica si leggono le celle $1$, $2$ e $3$ del risultato, che contengono $6$, $8$ e $-4$. Sono gli elementi del segmento originale $(-4,6,8)$ letti a partire dal secondo, con il primo in coda. Le celle $0$ e $4$ conservano $2$ e $3$.

</div>
