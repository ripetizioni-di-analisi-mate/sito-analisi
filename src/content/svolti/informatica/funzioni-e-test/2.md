## Esercizio 1

Scrivere il prototipo da porre prima del chiamante per questa definizione di `rate`. Determinare poi il valore e il tipo del risultato di `rate(6, 2)`.

```c
long rate(int units, int band)
{
    return units * (band + 1L);
}
```

Il prototipo è `long rate(int units, int band);`. La chiamata calcola $6(2+1)=18$ e restituisce un `long`.

<div class="spiegazione">

I tipi del prototipo si leggono dalla definizione. Il tipo a sinistra del nome è `long`. Entrambi i parametri sono `int`, quindi gli argomenti $6$ e $2$ arrivano con il tipo già richiesto. Nel corpo il suffisso `L` rende il valore `1L` di tipo `long`, quindi `band + 1L` è calcolato in `long`. Poi anche `units` si converte a `long` per la moltiplicazione. I valori usati sono rappresentabili.

Si può verificare il calcolo come somma di tre addendi uguali a $6$. Per verificare anche il tipo, l’operatore C17 `_Generic` sulla chiamata selezionerebbe l’associazione `long`.

</div>

## Esercizio 2

Determinare il risultato di `classify(-5)`, `classify(0)` e `classify(19)`. Indicare quale `return` si esegue in ciascuna chiamata.

```c
int classify(int x)
{
    if (x < 0) {
        return -1;
    }
    if (x == 0) {
        return 0;
    }
    return 1;
}
```

| `x` | `return` eseguito | Risultato |
| --- | --- | --- |
| $-5$ | `return -1;` | $-1$ |
| $0$ | `return 0;` | $0$ |
| $19$ | `return 1;` | $1$ |

<div class="spiegazione">

Con $-5$ la prima condizione è vera, quindi si torna al chiamante prima di verificare la seconda. Per $0$ il primo confronto è falso e il secondo è vero. Per $19$ entrambi sono falsi, quindi resta l’ultima istruzione. I tre casi coprono tutti gli interi perché ogni intero ha esattamente uno dei segni ammessi dalla classificazione.

Come verifica si usa `(x > 0) - (x < 0)`. I confronti in C producono $0$ oppure $1$. Sui tre argomenti la differenza vale in ordine $-1$, $0$ e $1$, in accordo con i tre percorsi.

</div>
