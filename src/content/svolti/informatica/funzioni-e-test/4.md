## Esercizio 1

Il contratto di `clamp` richiede `lo <= hi`. Il risultato è l’estremo inferiore sotto la fascia, l’estremo superiore sopra la fascia e `x` nella fascia. Verificare precondizione e risultato per `clamp(-1, 0, 4)`, `clamp(4, 0, 4)` e `clamp(3, 5, 5)`.
```c
int clamp(int x, int lo, int hi)
{
    if (x < lo) {
        return lo;
    }
    if (x > hi) {
        return hi;
    }
    return x;
}
```

Le precondizioni sono vere perché $0\leq4$ e $5\leq5$. Nel primo caso vale $-1<0$, quindi il risultato è $0$. Nel secondo $x=4$ è nella fascia, quindi resta $4$. Nel terzo caso $3<5$ e il risultato è $5$.

<div class="spiegazione">

L’implementazione esamina prima se il valore è sotto la fascia. Quando ciò accade, conclude subito con `lo`. Negli altri due rami controlla se si è sopra `hi` e restituisce `x` per un input nella fascia. Con una fascia di ampiezza zero, l’unico intero consentito come risultato dalla postcondizione è l’estremo comune.

Una verifica valuta la formula $\min\{hi,\max\{lo,x\}\}$. I massimi intermedi sono $0$, $4$, $5$. I rispettivi minimi con gli estremi superiori $4$, $4$, $5$ danno $0$, $4$, $5$, in accordo con i rami.

</div>

## Esercizio 2

Su una macchina C17 con `INT_MAX` uguale a $32767$, trovare il massimo `n` non negativo ammesso per valutare `charge(n)` con tutte le operazioni in `int` rappresentabili.
```c
int charge(int n)
{
    return 11 + 7 * n;
}
```

Da $11+7n\leq32767$ segue

$$
n\leq\left\lfloor\frac{32767-11}{7}\right\rfloor=4679 .
$$

Il massimo è $4679$.

<div class="spiegazione">

Poiché `n` è non negativo, anche $7n$ è non negativo. Se la somma è al più $32767$, il prodotto, che è minore della somma, è sicuramente rappresentabile. La funzione matematica cresce con $n$, quindi basta delimitare l’ultimo input ammesso.

Per controllo, $7\cdot4679=32753$ e $11+32753=32764$, entro l’intervallo. Per l’intero successivo, il valore matematico è $32764+7=32771$. Supera il limite, perciò l’espressione C a quell’input non ha un risultato definito sulla macchina ipotizzata.

</div>
