## Esercizio 1

Un intero `score` appartiene al dominio da $0$ a $30$. La specifica assegna $2$ fino a $7$, $4$ da $8$ a $20$ e $6$ da $21$ in poi. Costruire una prova per classe e calcolare gli attesi, usando i rappresentanti $3$, $14$ e $24$.
```c
int tier(int score)
{
    if (score <= 7) {
        return 2;
    }
    if (score <= 20) {
        return 4;
    }
    return 6;
}
```

| Interi della classe | Rappresentante | Atteso |
| --- | --- | --- |
| $[0,7]$ | $3$ | $2$ |
| $[8,20]$ | $14$ | $4$ |
| $[21,30]$ | $24$ | $6$ |

<div class="spiegazione">

Le tre fasce sono non vuote, disgiunte e coprono gli interi del dominio. Ciascun rappresentante sta in una fascia distinta, quindi la copertura è completa. Per l’oracolo si legge la fascia a cui appartiene l’input. Per esempio $14$ soddisfa $8\leq14\leq20$, quindi l’atteso è $4$.

Come verifica separata, per $14$ il primo confronto del codice è falso e il secondo è vero, perciò si raggiunge proprio `return 4;`. Per $3$ è vero il primo confronto, mentre per $24$ sono entrambi falsi. I tre rami concordano con gli attesi.

</div>

## Esercizio 2

Due ingressi interi `x` e `y` sono entrambi tra $-10$ e $10$. La specifica distingue il segno negativo dal caso non negativo per ciascun ingresso. Stabilire il minimo numero di prove per coprire le combinazioni e calcolare gli attesi dei quattro casi scelti usando la funzione.
```c
int zone(int x, int y)
{
    return 2 * (x >= 0) + (y >= 0);
}
```

| `x` | `y` | Atteso |
| --- | --- | --- |
| $-2$ | $-3$ | $0$ |
| $-2$ | $3$ | $1$ |
| $2$ | $-3$ | $2$ |
| $2$ | $3$ | $3$ |

Servono $4$ prove.

<div class="spiegazione">

Ogni ingresso ha due classi e tutte le combinazioni sono possibili nel dominio. Le classi delle coppie sono dunque $2\cdot2=4$. Ogni coppia appartiene a una sola classe, quindi meno di $4$ prove lascerebbero una combinazione scoperta. Le quattro mostrate raggiungono il minimo. Per `x` non negativo si aggiunge $2$, per `y` non negativo si aggiunge $1$.

Per controllo si leggono quegli indicatori come due bit. Gli indici dei casi in tabella sono i valori binari $00$, $01$, $10$ e $11$, che corrispondono agli attesi da $0$ a $3$.

</div>
