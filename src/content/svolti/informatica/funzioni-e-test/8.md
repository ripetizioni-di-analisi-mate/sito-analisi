## Esercizio 1

Determinare il risultato di `report()` con asserzioni attive e con `NDEBUG` definita all’inclusione di `<assert.h>`. Riscrivere il corpo affinché in entrambe le configurazioni si ottenga il risultato della prima.
```c
#include <assert.h>

int report(void)
{
    int n = 7;
    assert(--n >= 0);
    return n;
}
```

Con asserzioni attive si ottiene $6$. Con asserzioni disattivate si ottiene $7$. Il corpo corretto esegue, nell’ordine, `int n = 7;`, `--n;`, `assert(n >= 0);` e `return n;`.

<div class="spiegazione">

Nel primo caso l’argomento dell’asserzione viene valutato. L’operatore `--` decrementa `n` prima del confronto e $6$ soddisfa la condizione. Nel secondo caso la macro elimina la valutazione di quell’argomento. Si ritorna quindi il valore assegnato dall’inizializzazione.

Il controllo della riscrittura avviene sulle istruzioni che modificano `n`. L’inizializzazione gli assegna $7$ e l’istruzione successiva lo porta a $6$, a prescindere dalla macro. L’asserzione riscritta legge `n`, quindi la sua presenza incide solo sul controllo.

</div>

## Esercizio 2

La specifica di `rating` ammette chi ha punteggio almeno $18$, restituendo $1$ in quel caso e $0$ altrimenti. Il programma usa l’oracolo scritto tramite due confronti in `main`. Stabilire il codice di uscita del programma, poi spiegare l’effetto della correzione.
```c
#include <stdlib.h>

int rating(int score)
{
    return score > 18;
}

int main(void)
{
    if (rating(17) != 0) {
        return EXIT_FAILURE;
    }
    if (rating(18) != 1) {
        return EXIT_FAILURE;
    }
    return EXIT_SUCCESS;
}
```

Il confronto a $17$ passa. A $18$ il codice restituisce $0$ e l’atteso è $1$. Il programma termina quindi con `EXIT_FAILURE`. Sostituendo `score > 18` con `score >= 18`, i due confronti passano e si ottiene `EXIT_SUCCESS`.

<div class="spiegazione">

Gli attesi vengono dalla specifica, quindi si calcolano prima di leggere la funzione. Un punteggio di $17$ cade sotto il requisito. Un punteggio di $18$ soddisfa il requisito esattamente. Nel corpo fornito anche $18$ dà $0$ per il confronto stretto, perciò il secondo controllo segnala il difetto.

La verifica della correzione confronta separatamente `17 >= 18` e `18 >= 18`, che valgono $0$ e $1$. In `main` i due controlli sono normali istruzioni `if`. La macro `NDEBUG` riguarda `assert`, quindi questi controlli operano anche in una compilazione che la definisce.

</div>
