## Esercizio 1

Per `0 <= pieces <= 15`, il primo passaggio calcola un subtotale e il secondo accetta importi interi da $0$ a $40$. Verificare che il dominio del secondo passaggio sia rispettato e calcolare `bill(3)` e `bill(6)`.
```c
int subtotal(int pieces)
{
    return 2 * pieces + 3;
}

int min_charge(int amount)
{
    return amount < 11 ? 11 : amount;
}

int bill(int pieces)
{
    return min_charge(subtotal(pieces));
}
```

Agli estremi del dominio `subtotal` vale $3$ e $33$. Il valore cresce con `pieces`, quindi tutti i risultati sono ammessi da `min_charge`. A $3$ si ottengono $9$ e poi $11$. A $6$ si ottengono $15$ e poi $15$.

<div class="spiegazione">

La prima funzione calcola un costo che cresce di $2$ a ogni unità. Il suo minimo e il suo massimo sono quindi $2\cdot0+3=3$ e $2\cdot15+3=33$. Entrambi soddisfano i limiti $0$ e $40$, così il risultato intermedio soddisfa sempre il secondo contratto. A $3$ il costo $9$ ricade sotto la soglia $11$, mentre a $6$ il costo $15$ ricade sopra.

Per verificare i rami si risolve $2p+3<11$ per la quantità intera $p$. La disuguaglianza equivale a $p<4$. Si recupera perciò il minimo a $3$ e il costo ordinario a $6$. Sul confine $p=4$ entrambi i criteri danno $11$.

</div>

## Esercizio 2

Il primo passaggio `raw_level(x)` è ammesso per gli interi da $0$ a $10$. Il secondo passaggio `reduce(level)` accetta soltanto gli interi da $0$ a $19$. Trovare il più grande sottoinsieme del dominio iniziale per cui `reduce(raw_level(x))` rispetta entrambi i contratti.
```c
int raw_level(int x)
{
    return 12 + x;
}

int reduce(int level)
{
    return level / 2;
}
```

Il vincolo del secondo passaggio impone $0\leq12+x\leq19$, quindi $-12\leq x\leq7$. Intersecando con il dominio da $0$ a $10$ si ottengono tutti gli interi da $0$ a $7$.

<div class="spiegazione">

Il primo risultato è l’argomento effettivo del secondo passaggio, perciò va sostituito nella precondizione su `level`. Il limite inferiore è soddisfatto da tutte le quantità iniziali, perché il minimo valore intermedio è $12$. Il limite superiore impone $x\leq7$. Un input maggiore può comunque produrre un intero nell’esecuzione di questo corpo. Quel caso è esterno al contratto dichiarato.

Come controllo si valutano i due input di confine. A $7$ si ottiene $19$, quindi la composizione è ammessa e restituisce $9$. A $8$ l’intermedio è $20$, oltre il dominio di `reduce`. Siccome `raw_level` è crescente, ogni intero ammesso sopra $8$ dal primo contratto viola il secondo.

</div>
