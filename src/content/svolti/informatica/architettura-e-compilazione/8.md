## Esercizio 1

Si traduca `main.c` con `cc -std=c17 -pedantic-errors -c main.c -o main.o` su un driver compatibile con GCC. Al primo tentativo `units_local.h` è assente da tutti i percorsi di ricerca. Al secondo tentativo il file è presente e contiene la dichiarazione `int read_value(void);`. Individuare la fase in cui si manifesta il problema in ciascun tentativo e correggere la chiamata.
```c
#include "units_local.h"

int main(void)
{
    return read_value(5);
}
```

| Tentativo | Fase che rileva il problema |
|---|---|
| Header assente | Preelaborazione |
| Header presente | Controllo dei vincoli del C |

La chiamata corretta è `read_value()`.

<div class="spiegazione">

Al primo tentativo la direttiva `#include` richiede un file inesistente nei percorsi di ricerca. Il driver si ferma prima di produrre il sorgente preelaborato. Al secondo tentativo il contenuto dell’header entra nell’unità. Il parametro scritto come `void` indica che la funzione richiede zero argomenti. Il compilatore può quindi individuare l’argomento $5$ in eccesso.

Per verificare, si rimuove l’argomento e si ripete il comando con l’header presente. Il comando produce `main.o`. La definizione di `read_value` può risiedere in un’altra unità, quindi il relativo riferimento resta disponibile per un collegamento successivo.

</div>

## Esercizio 2

La specifica richiede di incrementare $9$ di uno e poi raddoppiare. Un eseguibile è stato costruito con successo dal sorgente seguente. Supponendo riuscite tutte le scritture, determinare l’uscita del programma, il suo stato di terminazione e la modifica minima che soddisfa la specifica.
```c
#include <stdio.h>

int main(void)
{
    int value = 9;
    printf("%d\n", 2 * value + 1);
    return 0;
}
```

$$
\begin{aligned}
\text{valore stampato} &= 2\cdot9+1=19\\[6pt]
\text{valore richiesto} &= 2\cdot(9+1)=20 .
\end{aligned}
$$

Il programma stampa `19` e un ritorno a capo, poi segnala successo. L’argomento corretto per il valore è `2 * (value + 1)`.

<div class="spiegazione">

La moltiplicazione ha precedenza sull’addizione, quindi l’espressione scritta raddoppia il dato prima di sommare uno. La specifica impone l’ordine opposto, perciò le parentesi rendono `value + 1` un operando della moltiplicazione. `return 0;` comunica successo all’ambiente in entrambi i programmi. Quel valore di ritorno è indipendente dalle cifre scritte su `stdout`.

Per verificare, si eseguono il programma originale e quello corretto acquisendo separatamente l’uscita standard. Il primo produce le cifre di $19$ e il secondo quelle di $20$. Il calcolo distributivo conferma la seconda uscita perché $2(9+1)=2\cdot 9+2$.

</div>

## Esercizio 3

La specifica chiede che il programma stampi la media intera per difetto di $7$ e $9$. La funzione `mean` riceve interi con $0\leq a\leq1000$ e $0\leq b\leq1000$, quindi le somme sono rappresentabili in `int`. Si eseguono nell’ordine i tre comandi indicati su un driver compatibile con GCC. Individuare il comando che fallisce e la fase corrispondente. Correggere il difetto, determinare l’uscita del programma ottenuto e correggere infine il calcolo secondo la specifica.
```c
/* stats.h */
#ifndef STATS_H_INCLUDED
#define STATS_H_INCLUDED
int mean(int a, int b);
#endif
```
```c
/* stats.c */
#include "stats.h"

int average(int a, int b)
{
    return a + b / 2;
}
```
```c
/* main.c */
#include <stdio.h>
#include "stats.h"

int main(void)
{
    printf("%d\n", mean(7, 9));
    return 0;
}
```
```shell
cc -std=c17 -pedantic-errors -c main.c -o main.o
cc -std=c17 -pedantic-errors -c stats.c -o stats.o
cc main.o stats.o -o app
```

| Comando | Esito |
|---|---|
| Traduzione di `main.c` | riuscita |
| Traduzione di `stats.c` | riuscita |
| Collegamento | riferimento irrisolto a `mean` |

Rinominando `average` in `mean` nella definizione, il collegamento riesce e il programma stampa `11`. Con `return (a + b) / 2;` stampa `8`.

$$
\begin{aligned}
7+\left\lfloor\frac{9}{2}\right\rfloor &= 7+4=11\\[6pt]
\left\lfloor\frac{7+9}{2}\right\rfloor &= 8 .
\end{aligned}
$$

<div class="spiegazione">

`main.c` include l’header e vede il prototipo di `mean`, quindi la chiamata soddisfa i vincoli e `main.o` contiene un riferimento esterno a `mean`. Anche `stats.c` si traduce senza diagnostiche, perché `average` è un nome diverso da `mean` e nessuna regola impone a un sorgente di definire le funzioni dichiarate negli header che include. Il difetto si manifesta perciò soltanto al **collegamento**, dove nessuno dei due oggetti definisce `mean`.

Dopo la correzione del nome il programma si costruisce e produce un’uscita errata. La divisione ha precedenza sull’addizione, quindi l’espressione calcola `a + (b / 2)`. La divisione fra interi non negativi tronca il quoziente, perciò `9 / 2` vale `4` e la stampa è `11`. Le parentesi attorno a `a + b` rendono la somma il dividendo, e la stampa diventa `8`, la media per difetto richiesta. Per l’ipotesi sui dati la somma non supera $2000$, quindi resta rappresentabile in `int`.

</div>
