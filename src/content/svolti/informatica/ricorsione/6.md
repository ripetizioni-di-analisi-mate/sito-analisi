## Esercizio 1

Per `score(3)`, scrivere gli argomenti in ordine di avvio e ricavare il risultato finale. Si assume $0\leq n\leq8$.
```c
unsigned score(unsigned n)
{
    if (n <= 1u) {
        return n + 1u;
    }
    unsigned first = score(n - 2u);
    unsigned second = score(n - 1u);
    return first + second;
}
```

L’ordine è $3$, $1$, $2$, $0$, $1$. I due risultati ricevuti dalla radice valgono $2$ e $3$, quindi la chiamata iniziale restituisce $5$.

<div class="spiegazione">

L’inizializzatore di `first` inizia la chiamata con argomento $1$ e la completa prima di passare al successivo. La chiamata con $2$ avvia a sua volta i casi base $0$ e $1$ in quell’ordine. I valori di base sono $1$ per l’argomento zero e $2$ per l’argomento uno. Perciò la chiamata con $2$ restituisce $3$ e la radice aggiunge il $2$ che il suo record aveva conservato.

Per verifica si sommano soltanto i risultati delle foglie. Le foglie in ordine sono $1$, $0$, $1$ e ciascun nodo interno somma i risultati dei figli. Il totale delle foglie è $2+1+2=5$.

</div>

## Esercizio 2

Per `split(3)`, determinare quali argomenti sono ammessi per la prima chiamata avviata dalla radice e calcolare il risultato. Il dominio è $0\leq n\leq8$.
```c
unsigned split(unsigned n)
{
    if (n <= 1u) {
        return 1u;
    }
    return split(n - 1u) + split(n - 2u);
}
```

Il primo figlio può avere argomento $2$ oppure $1$. Il risultato in ogni caso è $3$.

<div class="spiegazione">

I due operandi di `+` corrispondono alla chiamata con argomento $2$ e a quella con argomento $1$. C17 permette di valutare l’uno o l’altro per primo. La chiamata con $1$ restituisce uno. Quella con $2$ somma i risultati dei due casi base e restituisce due. Poiché i due sottoalberi sono indipendenti, entrambi gli ordini producono la somma $2+1$.

Per verificare, si contano le foglie. Il figlio con argomento $2$ ne ha due e il figlio con argomento $1$ è una foglia. Ogni foglia vale uno, quindi il risultato è il numero totale delle foglie.

</div>

## Esercizio 3

Per `tri(4)`, scrivere gli argomenti in ordine di avvio, contare le invocazioni con argomento $2$ e calcolare il risultato. Il dominio è $0\leq n\leq10$.
```c
unsigned tri(unsigned n)
{
    if (n <= 1u) {
        return 1u;
    }
    unsigned a = tri(n - 1u);
    unsigned b = tri(n / 2u);
    unsigned c = tri(n - 2u);
    return a + b + c;
}
```

L’ordine di avvio è $4$, $3$, $2$, $1$, $1$, $0$, $1$, $1$, $2$, $1$, $1$, $0$, $2$, $1$, $1$, $0$.

| Argomento | `a` | `b` | `c` | Valore restituito |
|---:|---:|---:|---:|---:|
| $2$ | $1$ | $1$ | $1$ | $3$ |
| $3$ | $3$ | $1$ | $1$ | $5$ |
| $4$ | $5$ | $3$ | $3$ | $11$ |

Si contano sedici avvii, tre dei quali con argomento $2$. La chiamata `tri(4)` restituisce $11$.

<div class="spiegazione">

Ogni dichiarazione con inizializzatore termina con un’espressione completa, e alla fine di un’espressione completa c’è un punto di sequenza. Perciò la chiamata che inizializza `a` si conclude prima dell’avvio di quella che inizializza `b`, e questa prima di quella per `c`. La radice avvia quindi l’intero sottoalbero di `tri(3)`, cioè $3$, $2$, $1$, $1$, $0$, $1$, $1$. Poi avvia `tri(2)` per $\lfloor\dfrac{4}{2}\rfloor=2$ e infine `tri(2)` per $4-2=2$.

Un’invocazione con argomento $2$ avvia nell’ordine $1$, $1$ e $0$, perché $\lfloor\dfrac{2}{2}\rfloor=1$. Le invocazioni con argomento $2$ sono tre, una dentro `tri(3)` e due figlie dirette della radice. Poiché ogni foglia vale $1$, ciascuna di esse restituisce $3$. L’invocazione con argomento $3$ restituisce $3+1+1=5$ e la radice restituisce $5+3+3=11$.

Con le tre chiamate scritte come operandi dello stesso `+` il valore resterebbe $11$. L’ordine di avvio sarebbe invece non specificato, perché l’operatore `+` lascia non specificato l’ordine di valutazione dei suoi operandi. Come controllo, le foglie sono $11$ e i nodi interni cinque, per un totale di $16$ invocazioni.

</div>
