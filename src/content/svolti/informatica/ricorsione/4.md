## Esercizio 1

Dimostrare che per $0\leq n\leq10$ la funzione `squares(n)` restituisce $\dfrac{n(n+1)(2n+1)}{6}$.
```c
unsigned squares(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return n * n + squares(n - 1u);
}
```

Per $n=0$ il valore restituito e la formula danno zero. Per $n\geq1$ si applica l’ipotesi induttiva alla chiamata con argomento $n-1$.

$$
\begin{aligned}
n^2+\frac{(n-1)n(2n-1)}{6}
 &= \frac{n((n-1)(2n-1)+6n)}{6}\\[6pt]
 &= \frac{n(2n^2+3n+1)}{6}\\[6pt]
 &= \frac{n(n+1)(2n+1)}{6} .
\end{aligned}
$$

<div class="spiegazione">

La misura $n$ diminuisce a ogni chiamata con argomento positivo. Ogni quadrato vale al più $100$ e il totale può essere limitato anche senza la formula, perché si sommano al massimo dieci termini. Il limite $1000$ è sufficiente a garantire la rappresentabilità dei calcoli C. La formula si applica al problema ridotto per ipotesi induttiva. L’addendo $n^2$ porta precisamente al nuovo valore dimostrato dall’identità.

Per controllare un caso distinto dalla base, con $n=4$ il calcolo diretto è $1+4+9+16=30$. La formula dà $\dfrac{4\cdot5\cdot9}{6}=30$.

</div>

## Esercizio 2

Trovare e dimostrare una formula per il risultato di `odd_sum(n)` nel dominio $0\leq n\leq20$.
```c
unsigned odd_sum(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return (2u * n - 1u) + odd_sum(n - 1u);
}
```

La formula è $n^2$. Nel caso base la funzione restituisce $0$. Se la formula vale all’argomento $n-1$, allora

$$
(2n-1)+(n-1)^2=n^2 .
$$

<div class="spiegazione">

Per ogni $n\geq1$ l’espressione `2u * n - 1u` genera il successivo intero dispari. A $n=0$ si chiude prima della sottrazione, quindi nel dominio la sottrazione non va sotto zero. La chiamata usa l’argomento precedente e raggiunge la base. Le somme sono rappresentabili perché si aggiungono al massimo venti valori, ognuno al più $39$. La differenza fra due quadrati consecutivi corrisponde esattamente al termine del codice, quindi il passo induttivo conserva la formula.

Come verifica, per $n=5$ la somma $1+3+5+7+9=25$ coincide con $5^2$.

</div>

## Esercizio 3

Dimostrare che per $0\leq n\leq40$ la funzione `stride_sum(n)` restituisce
$$
f(n)=\begin{cases}
m(m+1) & \text{se } n=2m,\\[4pt]
(m+1)^2 & \text{se } n=2m+1.
\end{cases}
$$
```c
unsigned stride_sum(unsigned n)
{
    if (n <= 1u) {
        return n;
    }
    return n + stride_sum(n - 2u);
}
```

Per $n=0$ e $n=1$ la funzione restituisce $n$, e la formula dà $0\cdot1=0$ e $1^2=1$. Per $n\geq2$ si applica l’ipotesi induttiva all’argomento $n-2$, che ha la stessa parità di $n$.

$$
\begin{aligned}
\text{per } n=2m,\ m\geq1 &\qquad 2m+(m-1)m=m^2+m=m(m+1)\\[6pt]
\text{per } n=2m+1,\ m\geq1 &\qquad (2m+1)+m^2=(m+1)^2 .
\end{aligned}
$$

<div class="spiegazione">

La chiamata interna riduce l’argomento di due, perciò il passo induttivo usa la formula all’argomento $n-2$. La dimostrazione procede quindi per **induzione forte**, con i due casi base $0$ e $1$. Il test `n <= 1u` intercetta entrambi i casi base, quindi la sottrazione `n - 2u` avviene solo per $n\geq2$ e dà sempre un risultato naturale. Con il solo test `n == 0u`, l’argomento $1$ produrrebbe `1u - 2u`, che per l’aritmetica modulare degli interi senza segno vale `UINT_MAX`.

Se $n=2m$ con $m\geq1$, l’argomento $n-2=2(m-1)$ è pari e l’ipotesi induttiva dà $(m-1)m$. Aggiungendo $2m$ si ottiene $m(m+1)$. Se $n=2m+1$ con $m\geq1$, l’argomento $n-2=2(m-1)+1$ è dispari e l’ipotesi dà $m^2$. Aggiungendo $2m+1$ si ottiene $(m+1)^2$. In entrambi i casi il valore restituito coincide con $f(n)$.

La misura $n$ diminuisce di due a ogni chiamata e resta non negativa, quindi la funzione termina. Il valore più grande del dominio è $f(40)=20\cdot21=420$, perciò le somme sono rappresentabili in `unsigned`. Come controllo, `stride_sum(7)` somma $7+5+3+1=16$, che coincide con $(3+1)^2$.

</div>
