## Esercizio 1

Calcolare il risultato di `product(4)` e il numero di invocazioni logiche, incluse la prima e la base. Il dominio della funzione è $0\leq n\leq8$.

![Chiamata iniziale product(4), passo product(n−1) per n positivo, base n=0 con risultato 1.](/immagini/informatica/ricorsione/dati-svolto-it.png)

```c
unsigned long product(unsigned n)
{
    if (n == 0u) {
        return 1ul;
    }
    return n * product(n - 1u);
}
```

| Argomento | Risultato al ritorno |
|---:|---:|
| $0$ | $1$ |
| $1$ | $1$ |
| $2$ | $2$ |
| $3$ | $6$ |
| $4$ | $24$ |

La funzione restituisce $24$ dopo cinque invocazioni logiche.

<div class="spiegazione">

La chiamata con $n=4$ richiede il prodotto fino a $3$. Ogni chiamata positiva successiva fa lo stesso per il proprio argomento, quindi si raggiunge la base $0$ dopo quattro decrementi. La base restituisce l’elemento neutro della moltiplicazione. In risalita, ciascun chiamante moltiplica il risultato ricevuto per il proprio $n$. La prima chiamata, i tre argomenti positivi interni e la base danno cinque invocazioni.

Il prodotto diretto $4\cdot3\cdot2\cdot1=24$ verifica il risultato. Il massimo prodotto del dominio è $40320$, quindi i prodotti intermedi sono rappresentabili in `unsigned long`.

</div>

## Esercizio 2

Nel dominio $0\leq n\leq20$, determinare per `unfold(7)` l’argomento della base e il risultato totale.

```c
unsigned unfold(unsigned n)
{
    if (n <= 2u) {
        return n;
    }
    return 3u + unfold(n - 2u);
}
```

$$
\begin{aligned}
\text{argomenti} &:\quad 7,\ 5,\ 3,\ 1\\[6pt]
\text{ritorno} &= 3+(3+(3+1))=10 .
\end{aligned}
$$

<div class="spiegazione">

Il passo diminuisce l’argomento di due e conserva la sua parità. Partendo da un numero dispari, la prima base raggiungibile è $1$. Si restituisce allora il valore dell’argomento, cioè uno. Ognuna delle tre invocazioni con argomento maggiore di $2$ aggiunge tre alla risposta ricevuta.

Per verifica si contano le sottrazioni che portano da $7$ a $1$. La differenza è $6$, quindi si effettuano tre passi da due. Il ritorno vale $1+3\cdot3=10$. Il controllo usa il numero di passaggi e conferma la ricostruzione riga per riga.

</div>

## Esercizio 3

Nel dominio $0\leq n\leq30$, calcolare `climb(9)`, `climb(10)` e `climb(11)`. Per ciascuna chiamata indicare il caso base raggiunto, il valore che restituisce e il numero di invocazioni.

```c
unsigned climb(unsigned n)
{
    if (n < 3u) {
        return n * n;
    }
    return 2u * climb(n - 3u) + n;
}
```

| Chiamata iniziale | Argomenti | Valore della base | Risultato |
|---|---|---:|---:|
| `climb(9)` | $9$, $6$, $3$, $0$ | $0$ | $33$ |
| `climb(10)` | $10$, $7$, $4$, $1$ | $1$ | $48$ |
| `climb(11)` | $11$, $8$, $5$, $2$ | $4$ | $79$ |

$$
\begin{aligned}
\texttt{climb}(5) &= 2\cdot4+5=13\\[6pt]
\texttt{climb}(8) &= 2\cdot13+8=34\\[6pt]
\texttt{climb}(11) &= 2\cdot34+11=79 .
\end{aligned}
$$

Ognuna delle tre chiamate richiede quattro invocazioni.

<div class="spiegazione">

Il passo ricorsivo sottrae tre e conserva il resto della divisione per $3$. Perciò ogni chiamata raggiunge l’unica base che ha lo stesso resto dell’argomento iniziale. Quindi $9$ arriva alla base $0$, $10$ alla base $1$ e $11$ alla base $2$. Il caso base restituisce il quadrato del proprio argomento, quindi la risalita parte rispettivamente da $0$, $1$ e $4$.

Ciascuna invocazione con argomento almeno $3$ raddoppia il risultato ricevuto e aggiunge il proprio $n$, che resta nel suo record durante la chiamata interna. Per `climb(10)` si ottengono nell’ordine $2\cdot1+4=6$, $2\cdot6+7=19$ e $2\cdot19+10=48$. Per `climb(9)` si ottengono $3$, $12$ e $33$. In tutti e tre i casi la catena comprende tre passi ricorsivi e la base, perciò le invocazioni sono quattro.

Nel dominio il risultato più grande è `climb(29)`, che vale $6109$. Ogni valore intermedio è minore, quindi tutti i calcoli sono rappresentabili anche in un `unsigned` a $16$ bit.

</div>
