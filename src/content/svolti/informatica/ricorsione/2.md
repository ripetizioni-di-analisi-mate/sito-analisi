## Esercizio 1

Dimostrare la terminazione di `reduce` su $0\leq n\leq63$ e trovare quante transizioni ricorsive avvengono a partire da $11$.

```c
unsigned reduce(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    if (n % 2u == 0u) {
        return 1u + reduce(n / 2u);
    }
    return 1u + reduce(n - 1u);
}
```

$$
11 \longrightarrow 10 \longrightarrow 5 \longrightarrow 4
\longrightarrow 2 \longrightarrow 1 \longrightarrow 0.
$$

Si contano sei transizioni.

<div class="spiegazione">

Si usa $n$ come misura. Nel ramo pari con $n>0$, il quoziente `n / 2` è minore di $n$ e resta non negativo. Nel ramo dispari si sottrae uno solo dopo il test di base, quindi anche il nuovo argomento resta nel dominio e scende. Il criterio di terminazione si applica a entrambi i rami. Il valore restituito conta le transizioni perché la base ne conta zero e ogni livello interno aggiunge uno.

Per verifica, le riduzioni da un argomento dispari sono $11\to10$, $5\to4$ e $1\to0$. Le divisioni sono $10\to5$, $4\to2$ e $2\to1$. I due gruppi danno $3+3=6$ passi.

</div>

## Esercizio 2

Nel modello delle chiamate logiche, trovare tutti gli argomenti iniziali in $\{0,1,2,3,4,5\}$ per cui `hold` raggiunge il ramo base.

```c
unsigned hold(unsigned n)
{
    if (n == 0u) {
        return 0u;
    }
    return hold(n - n % 2u);
}
```

| Argomento iniziale | Evoluzione |
|---:|---|
| $0$ | base immediata |
| $1$ | passa a $0$ |
| $2$, $4$ | il nuovo argomento coincide con l’attuale |
| $3$, $5$ | passano rispettivamente a $2$, $4$ |

Raggiungono la base solo $0$ e $1$.

<div class="spiegazione">

Il resto per due è zero sui pari e uno sui dispari. Se il dato è un pari positivo, la sottrazione lascia lo stesso dato e la traccia lo ripete. Se il dato è un dispari maggiore di uno, la prima sottrazione raggiunge un pari positivo, quindi si ricade in quel caso. Il dato $1$ arriva invece esattamente a zero.

Per verificare, l’espressione `n - n % 2u` produce il massimo pari al più uguale a $n$. Questo valore è zero solo per $0$ e $1$. Per qualsiasi altro argomento dell’insieme diventa un pari positivo e rimane fisso.

</div>

## Esercizio 3

Dimostrare che `shift` termina per ogni coppia di argomenti con $a+2b\leq100$ e calcolare `shift(2, 3)`. Mostrare inoltre che né $a$ né $b$, presi da soli, soddisfano il criterio di terminazione per misura naturale.

```c
unsigned shift(unsigned a, unsigned b)
{
    if (b == 0u) {
        if (a == 0u) {
            return 0u;
        }
        return 1u + shift(a - 1u, 0u);
    }
    return 1u + shift(a + 1u, b - 1u);
}
```

$$
\begin{aligned}
&(2,3)\to(3,2)\to(4,1)\to(5,0)\to(4,0)\\[6pt]
&\to(3,0)\to(2,0)\to(1,0)\to(0,0).
\end{aligned}
$$

Con $\mu(a,b)=a+2b$ le misure delle nove invocazioni sono $8$, $7$, $6$, $5$, $4$, $3$, $2$, $1$, $0$. La chiamata `shift(2, 3)` restituisce $8$.

<div class="spiegazione">

Nel ramo con $b>0$ il primo parametro aumenta di uno, perciò $\mu=a$ non decresce. Nel ramo con $b=0$ e $a>0$ il secondo parametro resta zero, quindi neppure $\mu=b$ diminuisce strettamente. La misura $\mu(a,b)=a+2b$ tiene conto di entrambi i rami.

Nel primo ramo la nuova misura è $(a+1)+2(b-1)=a+2b-1$. Nel secondo ramo è $(a-1)+0=a-1$. In entrambi i casi la misura diminuisce esattamente di uno. Le sottrazioni avvengono solo su parametri positivi, quindi ogni nuovo argomento è un intero non negativo e la misura resta naturale. Il **criterio di terminazione per misura naturale** si applica perciò a ogni coppia del dominio.

Ogni transizione aggiunge uno al risultato e abbassa la misura di uno, mentre la base restituisce zero con misura zero. Di conseguenza il valore restituito coincide con la misura iniziale, che per $(2,3)$ è $2+2\cdot3=8$. Il primo parametro non supera mai la misura corrente, che parte da al più $100$, quindi l’incremento `a + 1u` è sempre rappresentabile.

</div>
