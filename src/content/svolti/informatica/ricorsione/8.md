## Esercizio 1

Tradurre la funzione in un ciclo equivalente e verificare il risultato per `tally(5, 2)`. Il dominio soddisfa $0\leq n\leq20$ e $d+\dfrac{n(n+1)}{2}\leq65535$, dove $d$ è il valore di `done`.
```c
unsigned tally(unsigned n, unsigned done)
{
    if (n == 0u) {
        return done;
    }
    return tally(n - 1u, done + n);
}
```

```c
unsigned tally_loop(unsigned n, unsigned done)
{
    while (n != 0u) {
        done += n;
        n -= 1u;
    }
    return done;
}
```

L’argomento $5$ porta l’accumulatore da $2$ a $17$.

<div class="spiegazione">

Ogni chiamata trasferisce la coppia $(n-1,d+n)$. Nel ciclo si aggiunge il vecchio $n$ a `done` prima di decrementare $n$, quindi si realizza la stessa coppia. Il valore restituito dalla chiamata interna è anche il risultato del chiamante, perciò al ciclo basta mantenere una sola coppia corrente. L’invariante $d+\dfrac{n(n+1)}{2}$ resta costante e stabilisce che l’addizione C rimane rappresentabile.

Come verifica, all’inizio l’invariante vale $2+\dfrac{5\cdot6}{2}=17$. Alla fine $n=0$, quindi l’invariante coincide con il valore di `done`. Entrambe le forme restituiscono $17$.

</div>

## Esercizio 2

Per calcolare il massimo comune divisore, ogni passaggio deve trasformare $(a,b)$ in $(b,a\bmod b)$ finché $b>0$. Analizzare il seguente ciclo con $a=35$ e $b=15$. Trovare il risultato effettivo, poi scrivere il corpo corretto e verificare il risultato previsto.
```c
unsigned wrong_gcd(unsigned a, unsigned b)
{
    while (b != 0u) {
        a = b;
        b = a % b;
    }
    return a;
}
```

Il ciclo dato passa da $(35,15)$ a $(15,0)$ e restituisce $15$. Il corpo corretto conserva il resto prima di assegnare i nuovi parametri.

```c
unsigned fixed_gcd(unsigned a, unsigned b)
{
    while (b != 0u) {
        unsigned rest = a % b;
        a = b;
        b = rest;
    }
    return a;
}
```

Il percorso corretto è $(35,15)$, $(15,5)$, $(5,0)$ e il risultato è $5$.

<div class="spiegazione">

Nel primo corpo, l’assegnamento `a = b` fa coincidere i due valori prima del calcolo del resto, quindi il resto diventa zero al primo passo. Nella chiamata ricorsiva di Euclide entrambi i nuovi argomenti provengono invece dalla coppia del chiamante. La variabile `rest` conserva proprio il valore calcolato con la vecchia coppia e permette di riprodurre quello stato nel ciclo.

Per verifica, $5$ divide $35$ e $15$. Inoltre $35-2\cdot15=5$, quindi ogni divisore comune divide anche $5$. Il valore corretto è dunque il massimo comune divisore.

</div>
