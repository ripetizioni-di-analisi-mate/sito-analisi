## Esercizio 1

Si usa la pila di capacità $5$ del capitolo. Da vuota si inseriscono $4$, $9$ e $3$, si eseguono due estrazioni e si inserisce $6$. Trovare i valori estratti e lo stato finale.

| Momento | Prefisso occupato, dalla base | `used` |
|---|---|---|
| Dopo gli inserimenti iniziali | $\langle 4,9,3\rangle$ | $3$ |
| Dopo la prima estrazione | $\langle 4,9\rangle$ | $2$ |
| Dopo la seconda estrazione | $\langle 4\rangle$ | $1$ |
| Alla fine | $\langle 4,6\rangle$ | $2$ |

I due dati estratti sono $3$ e $9$.

<div class="spiegazione">

I tre inserimenti iniziali usano nell’ordine le celle con indici $0$, $1$ e $2$. Con `used` uguale a $3$, la prima estrazione decrementa il contatore a $2$ e legge la cella all’indice $2$, cioè $3$. La seconda estrazione decrementa a $1$ e legge $9$. Resta occupata solo la cella all’indice $0$. Inserire $6$ scrive nella prima cella libera all’indice $1$ e porta il contatore a $2$.

Per verificare si applica la disciplina LIFO direttamente all’ordine di arrivo. Gli ultimi due elementi inseriti prima delle estrazioni sono $9$ e $3$, quindi si estraggono nell’ordine $3$, $9$. Dopo l’ultimo inserimento sono presenti solo $4$ e $6$, con $6$ inserito per ultimo. Il conteggio indipendente $3-2+1=2$ conferma l’occupazione finale.

</div>

## Esercizio 2

Una pila di capacità $5$ contiene $\langle 1,2,3,4,5\rangle$ dalla base. Si tenta di inserire $8$, si estrae un elemento e poi si tenta di inserire $9$. Determinare gli esiti e la cima finale.

| Operazione | Esito | `used` dopo |
|---|---|---|
| Inserire $8$ | Fallimento | $5$ |
| Estrarre | Successo, dato $5$ | $4$ |
| Inserire $9$ | Successo | $5$ |

La cima finale vale $9$.

<div class="spiegazione">

Prima del primo tentativo la pila contiene tanti elementi quanto la capacità. La guardia dell’inserimento restituisce quindi `false` prima di ogni scrittura. L’estrazione trova cinque celle occupate e decrementa `used` a $4$. Legge poi la cella d’indice $4$, che conserva $5$. Il secondo tentativo d’inserimento vede ora una cella libera e scrive $9$ proprio all’indice $4$. L’incremento finale riporta l’occupazione alla capacità.

Come verifica si segue la sola ultima cella. Contiene $5$ fino all’estrazione inclusa, perché il primo tentativo fallisce. Diventa logicamente libera quando `used` scende a $4$. Con il secondo inserimento contiene $9$ e torna nella parte occupata. La cella alla base resta invariata.

</div>

## Esercizio 3

La funzione `check` usa la pila di capacità $5$ del capitolo per controllare le parentesi tonde e quadre di una stringa. Determinare il valore restituito per le quattro stringhe della tabella. Sono visibili `Stack`, `stack_push` e `stack_pop`.

```c
int check(const char *text)
{
    Stack s = {.used = 0};
    for (const char *c = text; *c != '\0'; ++c) {
        if (*c == '(' || *c == '[') {
            if (!stack_push(&s, *c)) {
                return -1;
            }
        } else if (*c == ')' || *c == ']') {
            int open;
            if (!stack_pop(&s, &open)) {
                return 0;
            }
            if ((*c == ')' && open != '(') || (*c == ']' && open != '[')) {
                return 0;
            }
        }
    }
    return s.used == 0;
}
```

| Stringa | Valore restituito | Punto in cui si decide |
|---|---|---|
| `"[()]()"` | $1$ | fine della stringa, pila vuota |
| `"([)]"` | $0$ | terzo carattere, cima `[` |
| `"(()"` | $0$ | fine della stringa, resta `(` |
| `"(([[(())]]))"` | $-1$ | sesta apertura, pila piena |

<div class="spiegazione">

Ogni apertura viene inserita nella pila. Nella chiamata `stack_push(&s, *c)` il carattere viene convertito nel tipo `int` del parametro, quindi la pila conserva il codice del carattere. Ogni chiusura estrae la cima e la confronta con l’apertura corrispondente. Per la **disciplina LIFO** la cima è l’ultima apertura non ancora chiusa, cioè proprio quella che la chiusura deve accoppiare. Nella prima stringa ogni confronto riesce e la pila torna vuota, perciò `s.used == 0` vale $1$.

Nella seconda stringa, dopo `(` e `[`, la cima è `[` e il carattere letto è `)`. Il primo confronto della condizione è vero, quindi la funzione restituisce $0$ prima di leggere l’ultimo carattere. Nella terza stringa l’unica chiusura trova un’apertura, ma alla fine `used` vale $1$ e il confronto finale vale $0$. Nella quarta stringa le prime cinque aperture riempiono la pila. Alla sesta apertura la guardia di `stack_push` restituisce `false`, e `check` restituisce $-1$ senza esaminare le chiusure. Quella stringa è bilanciata, e il valore $-1$ indica soltanto che la sua profondità $6$ supera la capacità.

</div>
