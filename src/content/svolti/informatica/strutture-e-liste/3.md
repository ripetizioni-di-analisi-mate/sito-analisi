## Esercizio 1

Ricostruire le chiavi della lista raggiungibile da `head` alla fine del frammento. I due nodi automatici restano vivi. Si usa `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node *head = NULL;
struct Node x = {2, head};
head = &x;
struct Node y = {3, head};
head = &y;
```

| Momento | Nodi dalla testa |
|---|---|
| Inizio | Lista vuota |
| Dopo il primo aggiornamento | $2$ |
| Dopo il secondo aggiornamento | $\langle 3,2\rangle$ |

<div class="spiegazione">

L’inizializzatore del primo collegamento usa il valore iniziale nullo di `head`. Quindi `x.next` è nullo e, dopo aver assegnato la testa a `&x`, la lista contiene il solo nodo di chiave $2$. Nell’inizializzazione di `y` il valore corrente della testa è `&x`. Il nuovo nodo mantiene dunque un collegamento al nodo già presente. Spostare la testa a `&y` rende il nuovo nodo il primo.

Per controllare l’ordine si parte dalla testa finale e si visita ogni successore. `head` designa `y`, `y.next` designa `x` e `x.next` è nullo. Si ottengono esattamente due visite, nell’ordine $\langle 3,2\rangle$, e la catena si arresta dopo il nodo inserito per primo.

</div>

## Esercizio 2

Determinare l’ordine finale. I nodi automatici restano vivi e si usa `<stddef.h>`.

```c
struct Node { int key; struct Node *next; };
struct Node tail = {21, NULL};
struct Node first = {8, &tail};
struct Node one = {13, first.next};
first.next = &one;
struct Node two = {5, first.next};
first.next = &two;
```

La catena iniziale è $\langle 8,21\rangle$. Il primo inserimento dopo `first` dà $\langle 8,13,21\rangle$. Il secondo dà $\langle 8,5,13,21\rangle$.

<div class="spiegazione">

Il nuovo `one` riceve come successore il precedente `first.next`, che è `&tail`. Assegnando `&one` al collegamento di `first` lo si inserisce quindi tra il primo e l’ultimo nodo. Il secondo inserimento legge il collegamento già aggiornato, quindi `two.next` riceve `&one`. Dopo aver assegnato `&two` al collegamento di `first`, anche `one` e `tail` restano raggiungibili.

Per verificare si ricostruisce il suffisso a partire dalla fine. `tail` termina la sequenza con $21$. `one.next` porta a `tail` e premette $13$. `two.next` porta a `one` e premette $5$. `first.next` porta a `two` e premette $8$. La visita comprende quattro oggetti distinti e conferma l’ordine ottenuto.

</div>

## Esercizio 3

La funzione `insert_sorted` inserisce un nodo in una lista ordinata in modo non decrescente. Partendo dalla lista vuota si inseriscono nell’ordine i nodi automatici `a`, `b`, `c` e `d`, che restano vivi. Ricostruire la lista dopo ogni chiamata e stabilire quale dei due nodi di chiave $7$ precede l’altro. Le chiamate si trovano in `main`. Si assume visibile `Node` e si usa `<stddef.h>`.

```c
void insert_sorted(Node **head, Node *node)
{
    Node **link = head;
    while (*link != NULL && (*link)->key < node->key) {
        link = &(*link)->next;
    }
    node->next = *link;
    *link = node;
}

Node a = {7, NULL}, b = {2, NULL}, c = {9, NULL}, d = {7, NULL};
Node *head = NULL;
insert_sorted(&head, &a);
insert_sorted(&head, &b);
insert_sorted(&head, &c);
insert_sorted(&head, &d);
```

| Nodo inserito | Collegamento modificato | Lista dalla testa |
|---|---|---|
| `a` | `head` | `a` |
| `b` | `head` | `b`, `a` |
| `c` | `a.next` | `b`, `a`, `c` |
| `d` | `b.next` | `b`, `d`, `a`, `c` |

Le chiavi finali sono $\langle 2,7,7,9\rangle$ e il nodo `d` precede il nodo `a`.

<div class="spiegazione">

La variabile `link` contiene l’indirizzo del collegamento da modificare, prima `head` e poi il membro `next` del nodo appena superato. Il ciclo avanza finché la chiave in `*link` è minore della chiave da inserire. Con la lista vuota `*link` è nullo, quindi `a` diventa la testa. Per `b` la chiave $7$ della testa non è minore di $2$, perciò il ciclo non avanza e `b` entra in testa. Per `c` il ciclo supera $2$ e $7$ e si ferma sul successore nullo di `a`, quindi `c` diventa l’ultimo nodo.

Per `d` il ciclo supera $2$ e si ferma su `a`, perché $7<7$ è falso. Allora `d.next` riceve `&a` e `b.next` riceve `&d`. Il nuovo nodo di chiave $7$ si colloca perciò **prima** di quello già presente. Lo stesso codice tratta l’inserimento in testa, in mezzo e in fondo, perché `head` e i membri `next` hanno tutti il tipo `Node *`. Con il confronto `<=` al posto di `<` il ciclo supererebbe anche `a`, e `d` seguirebbe `a`.

</div>
