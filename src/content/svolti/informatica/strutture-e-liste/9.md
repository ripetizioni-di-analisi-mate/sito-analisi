## Esercizio 1

Scrivere la funzione `list_copy` con il contratto seguente. `src` è la testa di una lista lineare, eventualmente vuota, che la funzione non modifica. Se tutte le allocazioni riescono, la funzione memorizza in `*dst` la testa di una nuova lista proprietaria con le stesse chiavi nello stesso ordine e restituisce `true`. Se un’allocazione fallisce, rilascia i nodi già allocati, lascia `*dst` invariato e restituisce `false`. Scrivere poi l’output del programma di prova. Sono visibili `Node`, la funzione `free_list` che rilascia una lista proprietaria, `<stdbool.h>`, `<stdio.h>` e `<stdlib.h>`.

```c
bool list_copy(const Node *src, Node **dst);

int main(void)
{
    Node c = {4, NULL}, b = {1, &c}, a = {3, &b};
    Node *copy = NULL;
    if (!list_copy(&a, &copy)) {
        return EXIT_FAILURE;
    }
    copy->key = 8;
    printf("%d %d\n", a.key, copy->key);
    printf("%d\n", copy->next != &b);
    free_list(copy);
    return EXIT_SUCCESS;
}
```

Una funzione che rispetta il contratto è la seguente.

```c
bool list_copy(const Node *src, Node **dst)
{
    Node *copy = NULL;
    Node **link = &copy;
    for (const Node *p = src; p != NULL; p = p->next) {
        Node *node = malloc(sizeof *node);
        if (node == NULL) {
            free_list(copy);
            return false;
        }
        node->key = p->key;
        node->next = NULL;
        *link = node;
        link = &node->next;
    }
    *dst = copy;
    return true;
}
```

Il programma di prova stampa due righe.

```text
3 8
1
```

<div class="spiegazione">

La copia si costruisce nella variabile locale `copy`, quindi `*dst` cambia soltanto quando la lista nuova è completa. Il puntatore `link` contiene l’indirizzo del collegamento in cui va scritto il prossimo nodo. All’inizio è `&copy`, e dopo ogni nodo diventa l’indirizzo del membro `next` di quel nodo, così le chiavi restano nello stesso ordine. Ogni nodo nuovo riceve il successore nullo prima di essere collegato. Perciò dopo ogni iterazione la copia parziale è una lista lineare terminata dal puntatore nullo, e `free_list(copy)` la può rilasciare quando `malloc` fallisce. Con `src` nullo il ciclo non esegue iterazioni e `*dst` riceve la lista vuota.

Nel programma di prova i nodi di origine sono automatici, mentre quelli della copia sono allocati da `list_copy`. Le due liste hanno nodi distinti, quindi l’assegnamento `copy->key = 8` lascia $3$ in `a.key`. Il successore del primo nodo copiato è diverso da `&b`, perciò il confronto `!=` vale $1$. La copia del solo puntatore di testa avrebbe dato invece due nomi per gli stessi nodi.

</div>

## Esercizio 2

Il programma seguente dovrebbe stampare `2 1` e rilasciare la lista. Individuare i due errori, dire che cosa stampa e correggerlo con il minimo di modifiche.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int key;
    struct Node *next;
} Node;

void push(Node *head, int key)
{
    Node *node = malloc(sizeof *node);
    if (node == NULL) {
        return;
    }
    node->key = key;
    node->next = head;
    head = node;
}

void free_list(Node *head)
{
    for (Node *p = head; p != NULL; p = p->next) {
        free(p);
    }
}

int main(void)
{
    Node *head = NULL;
    push(head, 1);
    push(head, 2);
    for (const Node *p = head; p != NULL; p = p->next) {
        printf("%d ", p->key);
    }
    printf("\n");
    free_list(head);
    return 0;
}
```

Il programma stampa una riga vuota. Le due funzioni corrette sono le seguenti, e in `main` le chiamate diventano `push(&head, 1);` e `push(&head, 2);`.

```c
void push(Node **head, int key)
{
    Node *node = malloc(sizeof *node);
    if (node == NULL) {
        return;
    }
    node->key = key;
    node->next = *head;
    *head = node;
}

void free_list(Node *head)
{
    while (head != NULL) {
        Node *next = head->next;
        free(head);
        head = next;
    }
}
```

Con le correzioni il programma stampa `2 1 ` e poi il ritorno a capo.

<div class="spiegazione">

Il primo errore è in `push`. In C gli argomenti si passano per valore, quindi il parametro `head` è una copia del puntatore di `main`. L’assegnamento `head = node` modifica solo quella copia, e la variabile `head` di `main` resta nulla. Il ciclo di stampa non esegue iterazioni, perciò l’output è una riga vuota. I due nodi allocati non sono raggiungibili da nessun puntatore, e con `-fsanitize=address` il programma termina segnalando due blocchi persi. La correzione passa l’indirizzo della variabile testa, come in `push_front` del capitolo.

Il secondo errore è in `free_list` e non si manifesta finché la lista è vuota. Dopo `free(p)` l’aggiornamento `p = p->next` legge un membro di un oggetto la cui durata è terminata, e ciò ha **comportamento non definito**. GCC 13 lo segnala già in compilazione con l’avviso `-Wuse-after-free`, attivo con `-Wall`. Dopo la prima correzione la lista contiene due nodi, e AddressSanitizer interrompe l’esecuzione con `heap-use-after-free` in lettura. La versione corretta salva il successore prima di `free`, come nel **rilascio completo di una lista**.

</div>

## Esercizio 3

Scrivere l’output esatto del programma. Si assume che ogni allocazione riesca.

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int key;
    struct Node *next;
} Node;

void free_list(Node *head)
{
    while (head != NULL) {
        Node *next = head->next;
        free(head);
        head = next;
    }
}

Node *reverse(Node *head)
{
    Node *done = NULL;
    while (head != NULL) {
        Node *rest = head->next;
        head->next = done;
        done = head;
        head = rest;
    }
    return done;
}

void print(const Node *p)
{
    for (; p != NULL; p = p->next) {
        printf("%d%s", p->key, p->next != NULL ? " -> " : "\n");
    }
}

int main(void)
{
    Node *head = NULL;
    for (int k = 1; k <= 4; ++k) {
        Node *node = malloc(sizeof *node);
        if (node == NULL) {
            free_list(head);
            return EXIT_FAILURE;
        }
        node->key = k * k;
        node->next = head;
        head = node;
    }
    print(head);
    Node *second = head->next;
    head = reverse(head);
    print(head);
    printf("%d %d\n", second->key, second->next->key);
    free_list(head);
    return EXIT_SUCCESS;
}
```

| Iterazione di `reverse` | Nodo spostato | Lista da `done` | Lista da `head` |
|---|---|---|---|
| $1$ | $16$ | $\langle 16\rangle$ | $\langle 9,4,1\rangle$ |
| $2$ | $9$ | $\langle 9,16\rangle$ | $\langle 4,1\rangle$ |
| $3$ | $4$ | $\langle 4,9,16\rangle$ | $\langle 1\rangle$ |
| $4$ | $1$ | $\langle 1,4,9,16\rangle$ | lista vuota |

```text
16 -> 9 -> 4 -> 1
1 -> 4 -> 9 -> 16
9 16
```

<div class="spiegazione">

Il ciclo di `main` inserisce in testa i quadrati $1$, $4$, $9$ e $16$, quindi la lista costruita ha l’ordine inverso, $\langle 16,9,4,1\rangle$. La funzione `print` scrive dopo ogni chiave la freccia, oppure il ritorno a capo quando il successore è nullo, e produce così la prima riga. Il puntatore `second` designa il nodo di chiave $9$.

La funzione `reverse` mantiene due liste disgiunte, quella già invertita che parte da `done` e quella ancora da visitare che parte da `head`. A ogni iterazione il successore viene salvato in `rest` prima di modificare `head->next`, poi il nodo passa in testa a `done`. Senza quel salvataggio l’assegnamento a `head->next` renderebbe irraggiungibile il resto della lista. La funzione non alloca e non rilascia nodi, perciò cambiano soltanto i collegamenti.

Il nodo designato da `second` è quindi lo stesso oggetto di prima. Dopo l’inversione il suo successore è il nodo di chiave $16$, e l’ultima riga è `9 16`. Infine `free_list` rilascia i quattro nodi a partire dalla nuova testa, che li raggiunge tutti.

</div>
