## Strutturare una pagina

:::definizione{#html titolo="Elementi HTML"}
HTML descrive il ruolo del contenuto. `h1` indica il titolo principale, `p` un paragrafo, `ul` un elenco. Una struttura coerente aiuta anche la navigazione con un lettore di schermo.
:::

## Definire l’aspetto

:::definizione{#css titolo="Regole CSS"}
CSS associa regole di presentazione agli elementi. Il selettore `.nota` individua gli elementi con classe `nota`. Una regola può cambiare il colore o la spaziatura senza modificare il ruolo del contenuto.
:::

## Scegliere un formato

:::definizione{#formati titolo="Raster, vettoriale e markup"}
Un’immagine raster è una griglia di pixel. Un’immagine vettoriale descrive forme e curve. XML rappresenta dati mediante elementi annidati e può essere usato per descrivere anche immagini SVG.
:::
