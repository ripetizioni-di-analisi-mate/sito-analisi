A block hangs at rest from a string, and the string pulls the block upward with $15\,\mathrm{N}$. What force does the block exert on the string?

- $15\,\mathrm{N}$, directed upward
- Zero, because the string has negligible mass
- $7.5\,\mathrm{N}$, directed downward
- $15\,\mathrm{N}$, directed downward

## Explanation

The pull of the string on the block and the pull of the block on the string form an **action-reaction pair**. By the **third law** the block pulls the string with the same magnitude, $15\,\mathrm{N}$, in the opposite sense, that is downward.
