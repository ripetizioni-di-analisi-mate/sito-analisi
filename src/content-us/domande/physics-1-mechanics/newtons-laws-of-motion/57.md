Solving a problem with a string, a student obtains $T = -5\,\mathrm{N}$ for its tension. What does this result mean?

- The string pushes the body with $5\,\mathrm{N}$.
- The string cannot be taut in that situation, so it is slack and $T = 0$.
- The tension is $5\,\mathrm{N}$ with the arrow reversed, and the string is still taut.
- The string must break at $5\,\mathrm{N}$.

## Explanation

A string can only pull, so its **tension** satisfies $T \ge 0$. A negative value means that the assumption of a taut string, used to write the equations, is false. The string is slack, $T = 0$, and the problem has to be solved again without it.
